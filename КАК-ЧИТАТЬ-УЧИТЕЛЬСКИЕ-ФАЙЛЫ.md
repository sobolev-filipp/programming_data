# 🔐 Как читать учительские файлы (git-crypt) — памятка для себя

В этом репозитории **учительские файлы зашифрованы** через **git-crypt**: решения, методички,
файлы «для преподавателя». Для посторонних на GitHub они выглядят как бинарный «мусор»
(кнопка **View raw** вместо текста). Ученические файлы (уроки, практика, викторины) —
открытые и нормально читаются на github.com.

Читать зашифрованные файлы можно **только с ключом курса**.

---

## 🗝️ Ключ — самое важное

**Файл ключа:** `course-git-crypt.key` — хранится **вне репозитория**, в защищённом бэкапе у автора (менеджер паролей / защищённое облако). Точный путь здесь не указываем (этот файл публичный).

- Это **единственный** способ расшифровать учительские файлы на новом компьютере.
- **Храни его в надёжном месте** (менеджер паролей, защищённое облако). Потеряешь ключ — решения не восстановить.
- **Никогда не клади ключ в сам репозиторий** и не отправляй в git.

---

## 💻 На этом компьютере (Windows) — уже всё готово

Репозиторий **разблокирован**, файлы на диске лежат в обычном читаемом виде.
Просто открывай их как всегда. Чтобы видеть их **красиво (как на GitHub)**, а не как «сырой» текст:

- **VS Code:** открой `.md` → нажми `Ctrl+Shift+V` (превью на весь экран) или `Ctrl+K` затем `V` (превью сбоку).
- **PyCharm:** открой `.md` → вкладка **Preview** сверху справа.
- Или бесплатные «читалки» markdown: **Obsidian**, **Typora**, **MarkText** — выглядят как GitHub.

Больше ничего делать не нужно.

---

## 🍎 На новом компьютере (Mac) — три шага

1. **Установи git-crypt** (через Homebrew):
   ```bash
   brew install git-crypt
   ```
   *(Если нет Homebrew — поставь его с https://brew.sh, одна команда.)*

2. **Клонируй репозиторий и разблокируй его ключом.** Сначала перенеси файл `course-git-crypt.key`
   на Mac безопасным способом (менеджер паролей / защищённая передача — **не** через публичные каналы):
   ```bash
   git clone https://github.com/sobolev-filipp/programming_data
   cd programming_data
   git-crypt unlock /путь/к/course-git-crypt.key
   ```
   После `unlock` все учительские файлы на диске становятся читаемыми.

3. **Читай с рендером:** в VS Code на Mac — `Cmd+Shift+V`; либо Obsidian/Typora.

> На Mac разблокировку (`git-crypt unlock`) делаешь **один раз** после клонирования — дальше репозиторий остаётся разблокированным.

## ❓ Если файл вдруг показывает «мусор» локально

Значит репозиторий на этом компьютере **не разблокирован** (обычно — свежий клон без ключа).
Выполни один раз: `git-crypt unlock /путь/к/course-git-crypt.key` — и файлы снова читаемы.

---

## ⚠️ Чего нельзя (иначе решения «утекут» открытыми)

- Не отключай git-crypt и не удаляй `.gitattributes`.
- Не переименовывай учительский файл в имя, которого нет в `.gitattributes` (тогда он попадёт на GitHub открытым). Если добавляешь новый тип учительского файла — сначала впиши его имя в `.gitattributes` (см. инструкцию для ИИ рядом).
- Не коммить файл ключа в репозиторий.

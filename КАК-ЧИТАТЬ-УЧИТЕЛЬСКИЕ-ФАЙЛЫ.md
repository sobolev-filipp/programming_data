# 🔐 Как читать учительские файлы (git-crypt) — памятка для себя

В этом репозитории **учительские файлы зашифрованы** через **git-crypt**: решения, методички,
файлы «для преподавателя». Для посторонних на GitHub они выглядят как бинарный «мусор»
(кнопка **View raw** вместо текста). Ученические файлы (уроки, практика, викторины) —
открытые и нормально читаются на github.com.

Читать зашифрованные файлы можно **только с ключом курса**.

---

## 🗝️ Ключ — самое важное

**Файл ключа:** `course-git-crypt.key` — хранится **вне репозитория**, в защищённом бэкапе у автора (менеджер паролей / защищённое облако). Точный путь здесь не указываем (этот файл публичный).

- Это **единственный** способ расшифровать учительские файлы на новом компьютере.
- **Храни его в надёжном месте** (менеджер паролей, защищённое облако). Потеряешь ключ — решения не восстановить.
- **Никогда не клади ключ в сам репозиторий** и не отправляй в git.

---

## 💻 На Windows — разблокировка (в т.ч. после нового клонирования)

⚠️ **Свежий клон ЗАБЛОКИРОВАН:** учительские файлы на диске выглядят «мусором» и начинаются с `GITCRYPT`.
Нужно один раз разблокировать. На Windows есть особенность (кириллица в путях `D:\Работа\…`), поэтому по шагам.
Все команды — в **Git Bash**, из папки репозитория.

**1. Установи git-crypt** (если ещё нет): `scoop install git-crypt` (Scoop) или `choco install git-crypt` (Chocolatey).

**2. Разблокируй ключом:**
```bash
git-crypt unlock "C:/путь/к/course-git-crypt.key"
```
⚠️ На Windows с **кириллицей в путях** эта команда, скорее всего, **упадёт** с ошибкой
`System error: CreateFileA … не удаётся найти указанный путь` — это баг git-crypt (ANSI-функции не понимают кириллицу).
**Это НЕ страшно:** ключ и фильтры при этом уже установлены (проверь — появился файл `.git/git-crypt/keys/default`).
- Если ругается `Working directory not clean` — сначала `git stash`, потом повтори `git-crypt unlock`.
- Совет: скопируй ключ во **временную папку с латинским путём** и указывай её (меньше шансов на сбой).

**3. Доросшифруй файлы силами самого git** (обходит баг: git пишет файлы Unicode-совместимо, а расшифровку
делает через фильтр):
```bash
git ls-files -z | xargs -0 rm -f
git -c core.longpaths=true checkout -- .
```
Это удаляет рабочие копии и **заново выкладывает их расшифрованными**. Займёт пару минут (файлов много).

**4. Проверь.** Открой любой `theory.md` — должен читаться текстом. Если 1–2 файла всё ещё «мусор»,
расшифруй их напрямую через фильтр:
```bash
git-crypt smudge < "путь/к/файлу.md" > tmp && mv -f tmp "путь/к/файлу.md"
```
*(после такого ручного способа файл может показываться в `git status` как изменённый — это косметика от
разных окончаний строк; не коммить его.)*

**Дальше** просто открывай файлы. Красивый рендер (как на GitHub):
- **VS Code:** `Ctrl+Shift+V` (превью на весь экран) или `Ctrl+K`, затем `V` (сбоку).
- **PyCharm:** вкладка **Preview** сверху справа.
- Или **Obsidian / Typora / MarkText**.

> 💡 Разблокировку делаешь **один раз** после клонирования. Переклонировал заново — повтори шаги 2–3.

## 🍎 На новом компьютере (Mac) — три шага

1. **Установи git-crypt** (через Homebrew):
   ```bash
   brew install git-crypt
   ```
   *(Если нет Homebrew — поставь его с https://brew.sh, одна команда.)*

2. **Клонируй репозиторий и разблокируй его ключом.** Сначала перенеси файл `course-git-crypt.key`
   на Mac безопасным способом (менеджер паролей / защищённая передача — **не** через публичные каналы):
   ```bash
   git clone https://github.com/sobolev-filipp/programming_data
   cd programming_data
   git-crypt unlock /путь/к/course-git-crypt.key
   ```
   После `unlock` все учительские файлы на диске становятся читаемыми.

3. **Читай с рендером:** в VS Code на Mac — `Cmd+Shift+V`; либо Obsidian/Typora.

> На Mac разблокировку (`git-crypt unlock`) делаешь **один раз** после клонирования — дальше репозиторий остаётся разблокированным.

## ❓ Если файл вдруг показывает «мусор» локально

Значит репозиторий на этом компьютере **не разблокирован** (обычно — свежий клон без ключа).
- **Windows:** пройди шаги из раздела «💻 На Windows — разблокировка» выше (`git-crypt unlock` + `rm` через `git ls-files` + `git checkout -- .`). Просто `unlock` на кириллических путях **не** дорасшифрует файлы — нужен обходной шаг с `git checkout`.
- **Mac/Linux:** достаточно `git-crypt unlock /путь/к/course-git-crypt.key`.

---

## ⚠️ Чего нельзя (иначе решения «утекут» открытыми)

- Не отключай git-crypt и не удаляй `.gitattributes`.
- Не переименовывай учительский файл в имя, которого нет в `.gitattributes` (тогда он попадёт на GitHub открытым). Если добавляешь новый тип учительского файла — сначала впиши его имя в `.gitattributes` (см. инструкцию для ИИ рядом).
- Не коммить файл ключа в репозиторий.

<h2>Физика</h2>
<p>Физика - о система симуляции физических взаимодействий между объектами в игровой сцене, которая позволяет создавать
    реалистичное поведение: <b>падение</b>, <b>столкновения</b>, <b>отскоки</b>, <b>скольжение</b> и др.</p>

<h3>Ключевые компоненты</h3>
<ol>
<li>
<b>Rigidbody</b> (твёрдое тело) — компонент, который «оживляет» объект, передавая управление физическим движком:
    <ul>
        <li>реагирует на гравитацию;</li>
        <li>воспринимает силы и импульсы;</li>
        <li>участвует в столкновениях.</li>
    </ul>
Важные параметры:
    <ul>
        <li>
            <mark>Mass</mark>(масса) — влияет на инерцию и силу воздействия при столкновениях;
        </li>
        <li>
            <mark>Drag</mark>(сопротивление) — имитирует сопротивление среды, замедляет движение;
        </li>
        <li>
            <mark>Angular Drag</mark>(угловое сопротивление) — замедляет вращение;
        </li>
        <li>
            <mark>Use Gravity</mark> — включает/отключает гравитацию для объекта;
        </li>
        <li>
            <mark>Is Kinematic</mark> — переводит объект в режим управления через скрипты (физика игнорируется).
        </li>
    </ul>
</li>
<br>
<li>
<b>Collider</b> (коллайдер) — невидимая оболочка, определяющая форму объекта для физических взаимодействий:
<ul>
    <li><b>Box Collider</b> — для прямоугольных объектов (ящики, платформы);</li>
    <li><b>Sphere Collider</b> — для сфер (мячи, планеты);</li>
    <li><b>Capsule Collider</b> — для объектов с закруглёнными концами (персонажи);</li>
    <li><b>Mesh Collider</b> — повторяет форму 3D‑модели (сложные объекты);</li>
    <li><b>Wheel Collider</b> — специально для колёс (учёт сцепления, амортизации).</li>
</ul>
</li>
<li>
<br>
<b>Physics Material</b> (физический материал) — настраивает свойства поверхности:  

> Чтобы создать Physics Material, необходимо в папке Assets нажать ЛКМ -> Create -> Physics Material

<ul>
    <li>
        <mark>Bounciness</mark>(упругость) — от 0 (нет отскока) до 1 (идеальный отскок);
    </li>
    <li>
        <mark>Friction</mark>(трение) — от 0 (скользкий) до 1 («липкий»).
    </li>
</ul>
</li>
<br>
<li>
<b>Material</b> - цифровой актив, который определяет, как поверхность объекта взаимодействует со светом и выглядит при рендеринге

> Чтобы создать Material, необходимо в папке Assets нажать ЛКМ -> Create -> Material

<ul>
    <li><b>Albedo</b> - базовый цвет поверхности без учёта освещения. Может быть задан как сплошной цвет или текстура</li>
    <li><b>Normal Map</b> - текстура, которая создаёт иллюзию объёма и мелких деталей поверхности без увеличения полигональной сетки</li>
    <li><b>Metallic</b> - определяет, насколько материал ведёт себя как металл. Значение <mark>1</mark> означает полный металл, <mark>0</mark> — неметалл</li>
    <li><b>Smoothness</b> - регулирует гладкость или шероховатость поверхности. Чем выше значение, тем более гладкой и отражающей будет поверхность</li>
    <li><b>Emission</b> - задаёт собственное свечение объекта. Позволяет материалу излучать свет</li>
    <li><b>Occlusion</b> - имитирует затенение в углублениях, добавляет глубину без дополнительных источников света</li>
    <li><b>Height (Parallax) Map</b> -  используется для параллакс-эффектов и смещения геометрии</li>
    <li><b>Alpha</b> - управляет прозрачностью материала</li>
    </ul>

</li>
</ol>

<br>
<h3>Добавление Rigidbody в наш куб</h3>
<ol>
<li>Добавьте <b>Rigidbody</b> к объекту (в Inspector → Add Component → Physics → Rigidbody).</li>
<li>Назначьте <b>Collider</b> (выбор типа зависит от формы объекта).</li>
<li>Создайте <b>Physics Material</b> (в Assets → Create → Physic Material) и настройте параметры.</li>
<li>Примените материал к <b>Collider</b>.</li>
<li>Для движения используйте методы <b>Rigidbody</b>:
    <ul>
        <li>
            <mark>AddForce()</mark> — приложить силу;
        </li>
        <li>
            <mark>velocity</mark> — задать скорость;
        </li>
        <li>
            <mark>OnCollisionEnter()</mark> — обработать столкновение.
        </li>
    </ul>
</li>
</ol>

<h3>Важные нюансы</h3>
<ul>
<li>Физика обновляется в <mark>Fixed Update</mark>, а не в <b>Update</b> — это обеспечивает стабильность независимо от частоты кадров.</li>
<li>
Для оптимизации:
<ul>
    <li>отключайте физику для невидимых объектов <mark>(isKinematic = true)</mark>;</li>
    <li>используйте простые коллайдеры (<b>Box/Sphere</b>) вместо <b>Mesh Collider</b>;</li>
    <li>ограничивайте количество <b>Rigidbody</b>.</li>
</ul>
</li>
<li>В 2D‑проектах используйте аналоги: <b>Rigidbody2D</b> и <b>Collider2D</b>.</li>
</ul>

> При запуске игры, созданный куб упадет

<br>
<h2>Создание пола, чтобы куб не улетал</h2>
<ol>
    <li><b>GameObject</b> → <b>3D Object</b> → <b>Cube</b></li>
    <li>Увеличиваем по <b>X</b> и <b>Z</b></li>
    <li>Ставим под падающим кубом</li>
</ol>

> Пол не падает, а созданный ранее куб с ним сталкивается

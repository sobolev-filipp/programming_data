<h1>Занятие 2. Добавление скрипта</h1>
<br>

<h2>Понятие Script в Unity</h2>
<p>📜 Script — это:</p>
<ul>
    <li>файл с кодом</li>
    <li>инструкция для объекта</li>
    <li>отвечает на вопрос: «Что объект должен делать?»</li>
</ul>

> Куб без скрипта — просто стоит
> Куб со скриптом — двигается, вращается, реагирует

<hr>
<br>
<h2>Создание Script</h2>

<h3>Шаг 1</h3>
<ol>
    <li>В <b>Assets</b> создайте новую папку <b>Scripts</b></li>
    <li>В <b>Scripts</b>: <b>ПКМ</b> → <b>Create</b> → <b>MonoBehaviour Script</b></li>
    <li>Название: <mark>CubeController</mark></li>
</ol>
<hr>

<h3>Шаг 2. Подключаем скрипт к кубу</h3>
<p>Перетаскиваем <mark>CubeController</mark> на Cube в Hierarchy</p>

> Скрипт работает только тогда, когда он прикреплён к объекту

# 🖼 Изображения и что показать на проекторе · Урок 2

Схемы в папке `изображения/`. Что показать и что проговорить.

---

## 1. `строение-css-правила.svg`
**Когда:** Часть 2 (как устроено правило CSS).
**Что показать:** `h1 { color: red; }` с подписями: селектор (кого), свойство (что), значение (как).
**Проговорить:** «Любой стиль — это правило из трёх частей. Селектор — кого красим, свойство — что меняем, значение — как. Не забываем `:` после свойства и `;` после значения».

## 2. `три-способа-css.svg`
**Когда:** Часть 6 (сравнение способов). Ключевая схема урока.
**Что показать:** три колонки — inline / `<style>` / `<link>` — с плюсами, минусами и «когда использовать».
**Проговорить:** «inline — быстро, но грязно и по одному тегу. `<style>` — стили в одном месте, но только эта страница. `<link>` — отдельный файл, один стиль на весь сайт. Так делают в реальности».

## 3. `link-связь.svg`
**Когда:** Часть 5 (внешний файл через `<link>`).
**Что показать:** `index.html` слева, `style.css` справа, между ними «связь» через `<link>`.
**Проговорить:** «`<link>` в HTML говорит: мой стиль лежит в style.css. Браузер берёт правила оттуда. В HTML стилей не видно — они в отдельном файле».

---

## 💻 Живая демонстрация (обязательно!)

1. Взять готовую визитку/меню с урока 1 — «сейчас раскрасим».
2. Показать **все три способа по очереди** на одном заголовке:
   - inline: `<h1 style="color:red">` — покрасился один;
   - `<style>` в head: `h1{color:navy}` — покрасились все h1;
   - вынести в `style.css` + `<link>` — HTML стал чистым, а стиль работает.
3. Показать **каскад**: inline red vs файл green → победит red.
4. Открыть **DevTools (F12)** и поменять цвет прямо в браузере — «вот где дизайнеры экспериментируют».
5. Emmet вживую: `link:css` + `Tab`, `style` + `Tab`.

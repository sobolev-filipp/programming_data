# 🧰 Лайфхаки · Урок 2 «Подключаем CSS»

Трюки и частые ошибки, чтобы писать стили быстро и без боли.

---

## ⌨️ Emmet — копилка растёт

С урока 1 у нас уже есть `!`, `+`, `*`, `{текст}`, `lorem`. Добавляем полезное для CSS:

| Аббревиатура | Что развернёт |
|--------------|---------------|
| `link:css` + `Tab` | `<link rel="stylesheet" href="style.css">` |
| `style` + `Tab` | `<style></style>` |
| `!` | каркас (в нём уже есть место под `<link>`) |

> 💡 **Внутри `.css`-файла Emmet тоже помогает!** Напиши `bgc` + `Tab` → `background-color: #fff;`, `ta` → `text-align`, `c` → `color: #000;`, `m10` → `margin: 10px;`. Это сокращения свойств — их много, подсматривай в шпаргалке Emmet.

## 🎨 Где брать красивые цвета

- **Именованные цвета** для быстрого старта: `red`, `teal`, `gold`, `crimson`, `navy`, `coral`, `tomato`.
- **Палитры и пипетка:** [coolors.co](https://coolors.co), [Google Color Picker](https://www.google.com/search?q=color+picker) (введи «color picker») — берёшь HEX-код (#RRGGBB) и вставляешь в CSS.
- Картинки добавим на **следующем уроке**, а цвета (HEX/RGB/HSL/oklch) — на уроке 4.

## ⌨️ Горячие клавиши

| Клавиши | Действие |
|---------|----------|
| `Ctrl+S` | сохранить (Live Server обновит браузер) |
| `Ctrl+/` | закомментировать строку (в CSS → `/* */`, в HTML → `<!-- -->`) |
| `Shift+Alt+↓` | продублировать строку (удобно копировать правила) |
| `F12` в браузере | открыть DevTools и «пощупать» стили вживую |

> 💡 **DevTools (F12) — суперсила.** Наведи на элемент → увидишь его CSS справа, можешь менять значения прямо в браузере и сразу видеть результат (это не сохранится в файл — только для экспериментов).

## 🐞 Частые ошибки и как избежать

- **Стили из `.css` не применяются** → неправильный `href` или файл не рядом с HTML. Проверь имя `style.css` буква-в-букву.
- **Забыл `rel="stylesheet"`** → браузер не поймёт, что это стили. Используй Emmet `link:css`, чтобы не ошибиться.
- **Нет `;` между свойствами** → следующее правило «ломается». Ставь `;` после каждого значения.
- **`=` вместо `:`** внутри стиля → не работает. В CSS: `свойство: значение`.
- **Забыл закрыть `}`** → «поехали» все правила ниже. Каждой `{` — своя `}`.
- **Покрасил inline, а нужно всем** → вынеси в `<style>`/`<link>`, чтобы селектор красил все теги сразу.

## 🧭 Правило хорошего тона

С самого начала приучайся к **способу 3** (`<link>` на `style.css`): отдельный файл стилей — это то, как устроены **все настоящие сайты**. inline и `<style>` — для быстрых проб.

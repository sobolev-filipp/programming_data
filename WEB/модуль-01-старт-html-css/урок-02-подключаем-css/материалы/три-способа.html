Три способа подключить CSS ☕

Способ 1 — inline (прямо в теге)

Этот абзац покрашен через style прямо в теге — только он один.

Способ 2 — тег <style> в <head>

Все h1/h2/p покрашены правилами из <style> выше — сразу все одинаково.

Способ 3 — внешний файл style.css через <link>

Самый правильный: стили в отдельном файле, один на весь сайт. См. комментарий в <head>.

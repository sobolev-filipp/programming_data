# Урок 2 «Подключаем CSS» — итого (шпаргалка) 📌

> За 3 минуты вспомнить весь урок. Только суть и примеры.

---

## Главные мысли

1. **HTML** — содержание, **CSS** — оформление (цвет, фон, размеры, расположение).
2. **Правило CSS:** `селектор { свойство: значение; }`. Нужны `:` (после свойства) и `;` (после значения).
3. **3 способа подключить CSS:** inline `style` · `<style>` в `<head>` · `<link>` на внешний `.css`.
4. **Лучший способ — `<link>`** на отдельный `style.css`: один стиль на весь сайт.
5. **Каскад (кратко):** стиль в теге (`inline`) сильнее стиля из файла.

---

## Строение правила

```css
h1 {              /* h1 — селектор (кого) */
    color: red;   /* color — свойство (что), red — значение (как) */
    text-align: center;
}
```

---

## Три способа — код

```html
<!-- 1. inline: прямо в теге (красит ТОЛЬКО этот тег) -->
<h1 style="color: red;">Привет</h1>

<!-- 2. <style> в <head> (красит ВСЕ такие теги на странице) -->
<head>
  <style>
    h1 { color: red; }
  </style>
</head>

<!-- 3. <link> на внешний файл (лучший — один стиль на весь сайт) -->
<head>
  <link rel="stylesheet" href="style.css">
</head>
```
В `style.css` — только правила, без `<style>`:
```css
h1 { color: red; }
```

| Способ | Красит | Когда |
|--------|--------|-------|
| inline `style` | один тег | быстрый тест |
| `<style>` | все теги страницы | одна страница |
| `<link>` ⭐ | весь сайт | почти всегда |

---

## Три первых свойства

```css
h1   { color: navy; }                 /* цвет текста */
body { background-color: #f0f8ff; }   /* цвет фона (страницы) */
h1   { text-align: center; }          /* left / center / right */
```
Комментарий в CSS: `/* так */`.

---

## Главные ошибки

| Проблема | Причина | Лечение |
|----------|---------|---------|
| стили из `.css` не работают | неверный `href`/путь | файл рядом, имя точно совпадает |
| покрасился один тег | использовал inline | вынеси в `<style>`/`<link>` |
| правило «сломалось» | нет `;` | `;` после каждого значения |
| `color= red` | `=` вместо `:` | свойство: значение |

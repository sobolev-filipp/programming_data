# 🧑‍🏫 Часть A. Разбираем вместе (пошагово)

## 1. Что такое правило CSS

**Тема:** стиль в CSS — это правило `селектор { свойство: значение; }`. Селектор — кого красим, свойство — что меняем, значение — как.

**Задание:** пойми правило `h1 { color: red; }`.

**Разбор по шагам:**
1. `h1` — селектор: все заголовки первого уровня.
2. `color` — свойство: цвет текста.
3. `red` — значение: красный.
4. Переводим: «все `h1` сделай красными».

✅ Правило читается: селектор → { свойство: значение; }.

---

## 2. Способ 1 — inline (в теге)

**Тема:** стиль можно написать прямо в теге, в атрибуте `style`. Красит только этот тег.

**Задание:** сделай заголовок красным через `style`.

**Разбор по шагам:**
1. Возьми `<h1>Привет</h1>`.
2. Добавь атрибут: `<h1 style="color: red;">Привет</h1>`.
3. Сохрани — заголовок стал красным.
4. Заметь: внутри `style` пишем только `свойство: значение;` (без селектора).

✅ `<h1 style="color: red;">Привет</h1>`.

---

## 3. Способ 2 — тег `<style>` в `<head>`

**Тема:** все стили страницы можно собрать в теге `<style>` внутри `<head>`. Один селектор красит все такие теги.

**Задание:** покрась все `h1` в тёмно-синий через `<style>`.

**Разбор по шагам:**
1. В `<head>` добавь `<style></style>` (Emmet: напиши `style` + `Tab`).
2. Внутри напиши правило: `h1 { color: navy; }`.
3. Сохрани — покрасились все заголовки `h1` сразу.
4. Сравни с inline: тут одно правило красит все, а не по одному.

✅ `<style> h1 { color: navy; } </style>` в `<head>`.

---

## 4. Способ 3 — внешний файл через `<link>`

**Тема:** лучший способ — стили в отдельном файле `style.css`, подключённом тегом `<link>`.

**Задание:** вынеси стили в `style.css`.

**Разбор по шагам:**
1. Создай рядом с HTML файл `style.css`.
2. Перенеси в него правило (без `<style>`!): `h1 { color: navy; }`.
3. В `<head>` подключи: `<link rel="stylesheet" href="style.css">` (Emmet: `link:css` + `Tab`).
4. Убери тег `<style>` из HTML — всё работает, стили теперь во внешнем файле.

✅ `style.css` с правилами + `<link>` в `<head>`.

---

## 5. Фон, цвет и выравнивание

**Тема:** три главных свойства — `color` (цвет текста), `background-color` (цвет фона), `text-align` (выравнивание).

**Задание:** задай фон страницы, цвет и центрирование заголовка.

**Разбор по шагам:**
1. Фон всей страницы: `body { background-color: #f0f8ff; }`.
2. Цвет заголовка: `h1 { color: navy; }`.
3. Центрируй: добавь в правило `h1` строку `text-align: center;`.
4. Сохрани — светлый фон, тёмно-синий заголовок по центру.

✅ Правила для `body` и `h1` с тремя свойствами.

---

## 6. Селектор по классу — красим не всех, а нужных

**Тема:** селектор по **тегу** (`p`) красит все абзацы. Чтобы выделить **конкретные**, дают им **класс** (имя) и красят по имени. В CSS имя с **точкой** (`.hit`), в HTML — `class="hit"` **без** точки.

**Задание:** из трёх абзацев покрась в красный только два «важных».

**Разбор по шагам:**
1. Сделай три абзаца: `<p>раз</p>`, `<p>два</p>`, `<p>три</p>`.
2. Первому и третьему добавь класс: `<p class="hit">раз</p>` и `<p class="hit">три</p>`.
3. В CSS напиши правило по классу: `.hit { color: crimson; }` (не забудь точку!).
4. Сохрани — покраснели только первый и третий. Средний остался чёрным.
5. Проверь: добавь `class="hit"` среднему — покраснеет и он. Убери — снова чёрный.

✅ HTML `class="hit"` (без точки) + CSS `.hit { color: crimson; }` (с точкой).

# ✍️ Часть B. Теперь сам (с мини-подсказкой)

## Три способа

**7.** Покрась абзац `p` в серый цвет через inline-`style`.
> 💡 `<p style="color: gray;">...</p>`.

**8.** Через `<style>` в `<head>` сделай все `p` зелёными.
> 💡 `<style> p { color: green; } </style>`.

**9.** Вынеси стили из задания 8 в `style.css` и подключи через `<link>`.
> 💡 В файле — правила без `<style>`; в `<head>` — `<link rel="stylesheet" href="style.css">`.

## Классы

**10.** Сделай список из 4 абзацев, повесь класс `important` на два из них и покрась `.important` в оранжевый жирный.
> 💡 HTML `class="important"` (без точки), CSS `.important { color: orange; font-weight: bold; }` (с точкой).

**11.** Придумай класс `.accent` и повесь его и на `h2`, и на один `p` — оба покрась одним правилом.
> 💡 Класс можно вешать на разные теги: `.accent { color: purple; }`.

## Свойства

**12.** Задай тёмный фон страницы и светлый цвет текста (тёмная тема).
> 💡 Фон — у `body` (`#1a1a2e`), текст — у `p` (светлый).

**13.** Выровняй заголовок по центру, а абзац — по правому краю.
> 💡 `h1 { text-align: center; }`, `p { text-align: right; }`.

**14.** Задай фон только заголовку `h1` (не всей странице).
> 💡 `h1 { background-color: gold; }`.

## Собираем и повторяем

**15.** Оформи «Меню кафе» через внешний `style.css`: тёплый фон, коричневые заголовки, центрирование, а «новинку» выдели классом `.new`.
> 💡 Правила для `body`, `h1`, `h2`, `p` + `.new { color: #c0392b; }`. Стили только в файле.

**16.** Одним правилом покрась `h1`, `h2` и всё с классом `.hit` в один цвет (группировка).
> 💡 `h1, h2, .hit { color: teal; }` — селекторы через запятую (теги и классы можно смешивать).

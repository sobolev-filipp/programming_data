# 🧩 Самостоятельная работа · Модуль 1 «Старт: HTML + первые стили»

**Промо-страница «Реклама, которая цепляет»**

> Это итог всего модуля. Работаешь **самостоятельно**, применяя всё, чему научился: теги, подключение CSS, картинки, цвет, типографику и `:hover`. Оценивается законченность и аккуратность. Ниже — подробное описание, требования и подсказки. Можно подглядывать в шпаргалки (`итого.md`) уроков, но не копировать чужой код.

---

## 🎯 Задание

Сделай **промо-страницу (рекламный лендинг)** для чего-нибудь классного — реального или выдуманного:
- любимой **игры**, приложения, гаджета;
- **своего** изобретения (робот, супер-кроссовки, энергетик, город будущего);
- **канала / блога** (YouTube, Twitch);
- **мероприятия** (турнир, фестиваль).

Твоя цель — сделать так, чтобы, попав на страницу, человеку **захотелось** этим воспользоваться. Реклама должна цеплять: яркий заголовок, картинка, преимущества и кнопка-призыв.

**Пример темы:** «SuperBoots — кроссовки, которые ускоряют», «Космо-кафе на Марсе», «Мой Twitch-канал», «Игра Space Run».

---

## 📋 Что должно быть на странице

1. **Шапка-герой (hero):**
   - крупное **название** (`h1`) продукта/канала и **слоган** под ним;
   - **главная картинка** (логотип/фото/постер);
   - яркий цветной фон.
   *Например:* `<h1>SuperBoots ⚡</h1>` + слоган «Беги быстрее ветра».

2. **Блок «Почему это круто» — 3 карточки-преимущества.** Каждая карточка:
   - эмодзи или иконка;
   - короткий заголовок (`h3`);
   - абзац-описание (1–2 предложения).
   *Например:* «⚡ Скорость — разгон за 2 секунды».

3. **Блок «Подробнее»** — заголовок `h2`, картинка и абзац с рассказом.

4. **Кнопка-призыв** (`Купить` / `Подписаться` / `Играть`) с эффектом `:hover`.

5. **Подвал** — короткая финальная фраза (и, по желанию, «контакты»).

Всё оформление — **во внешнем `style.css`**.

---

## ✅ Требования (проверь по списку)

**HTML:**
- ✅ правильный каркас (`!`), `lang="ru"`, `<meta charset="UTF-8">`, свой `<title>`;
- ✅ один `h1`, разделы через `h2`/`h3` (иерархия соблюдена);
- ✅ минимум **2 картинки** с осмысленным `alt`;
- ✅ кнопка-ссылка (`<a>`).

**CSS (подключён через `<link>`):**
- ✅ цветной фон шапки + фон страницы;
- ✅ **гармоничная палитра** — оттенки одного тона HSL;
- ✅ минимум одна картинка оформлена (`border`/`border-radius`);
- ✅ карточки-преимущества оформлены (фон, скругление, отступы);
- ✅ **типографика**: крупный заголовок, `text-shadow` (тень/неон), интервалы (`letter-spacing`/`line-height`);
- ✅ хотя бы один цвет с прозрачностью (`rgba`/`hsla`) **или** через `color-mix`;
- ✅ кнопка реагирует на наведение (`:hover`);
- ✅ читаемый контраст текста везде.

**Аккуратность:**
- ✅ страница открывается без «кракозябр» и «сломанных» картинок;
- ✅ код опрятный, стили только во внешнем файле.

## 💡 Подсказки (как что сделать)

| Что нужно | Приём / свойство |
|-----------|------------------|
| быстро собрать каркас | Emmet: `header>h1+p.slogan+img`, `.card*3` |
| фон шапки и страницы | `background-color` (один тон HSL, разная `L`) |
| круглый логотип/аватар | `border-radius: 50%` |
| карточка-преимущество | `background-color` + `padding` + `border-radius` + `box-shadow` |
| крупный заголовок с эффектом | `font-size` + `text-shadow` + `letter-spacing` |
| полупрозрачный слой на картинке | `background-color: rgba(0,0,0,0.4)` + белый текст |
| кнопка-призыв | `.btn { ... text-decoration:none; }` + `.btn:hover { ... }` |
| подобрать цвета | палитра-пипетка VS Code / [coolors.co](https://coolors.co) |

**Порядок работы:** сначала структура (блоки) → потом текст и картинки → потом стиль (палитра, шрифты, тени) → в конце `:hover`. Не хватай всё сразу.

# Урок 1 «Первая страница» — итого (шпаргалка) 📌

> Открой этот файл, чтобы за 3 минуты **вспомнить весь урок**. Только суть и готовые примеры.

---

## Главные мысли

0. **Интернет** — сеть компьютеров; **сервер** хранит сайты; **браузер** просит страницу и рисует её.
1. **HTML** — язык **разметки**: тегами говорим, где заголовок, где абзац. **Браузер** читает теги сверху вниз и рисует страницу.
2. **Тег** бывает **парный** `<p>...</p>` (закрывающий — со слешем) и **непарный** `<br>`, `<hr>`, `<img>` (закрывать не нужно).
3. **Каркас** страницы: `<!DOCTYPE>` → `<html>` → внутри `<head>` (невидимое) и `<body>` (видимое).
4. **`title` ≠ `h1`**: `title` — имя вкладки (в `head`), `h1` — большой заголовок на странице (в `body`).
5. **Emmet** пишет код за нас: `!`, `+`, `*`, `{текст}`.

---

## Каркас страницы (Emmet: `!` + Enter)

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">   <!-- русские буквы и эмодзи -->
    <title>Имя вкладки</title>
</head>
<body>
    <!-- всё видимое пишем здесь -->
</body>
</html>
```

---

## Теги содержимого

```html
<h1>Главный заголовок</h1>   <!-- h1..h6 по важности -->
<h2>Раздел</h2>
<p>Абзац текста.</p>          <!-- p — абзац -->
<p>Строка<br>с переносом</p>  <!-- br — перенос ВНУТРИ абзаца -->
<hr>                          <!-- hr — линия-разделитель -->
```

| Тег | Что | Пара? |
|-----|-----|-------|
| `h1`–`h6` | заголовки по важности (иерархия!) | да |
| `p` | абзац | да |
| `br` | перенос строки | нет (одиночный) |
| `hr` | горизонтальная линия | нет (одиночный) |
| `title` | имя вкладки (в `head`) | да |

---

## Иерархия заголовков h1–h6

- `h1` — **один** на странице (её название).
- Уровни идут **по порядку**: после `h2` — `h3`, нельзя прыгать `h1 → h4`.
- Выбираем уровень **по смыслу** (важности), а не по размеру. Размер — потом через CSS.

## Emmet (жми `Tab` после аббревиатуры)

| Пишешь | Получаешь |
|--------|-----------|
| `!` | весь каркас страницы |
| `h1` | `<h1></h1>` |
| `h1+p` | `<h1></h1>` и `<p></p>` рядом |
| `p*3` | три пустых `<p>` |
| `h2{Факты}` | `<h2>Факты</h2>` |
| `h2{Факты}+p*3` | заголовок и три абзаца |

## Главные ошибки

| Видно в браузере | Причина | Лечение |
|------------------|---------|---------|
| «кракозябры» вместо русских букв | нет `<meta charset="UTF-8">` | добавь мету в `head` |
| весь текст стал заголовком | не закрыт `</h1>` | закрой тег |
| страница пустая | текст в `head`, а не в `body` | видимое — в `body` |
| абзацы слиплись | текст без `<p>` | оберни в `<p>...</p>` |
| Emmet не работает | файл не `.html` / пробел после `!` | сохрани `.html`, жми `Tab` сразу |

# 🧰 Лайфхаки · Урок 1 «Первая страница»

Трюки, горячие клавиши и частые ошибки — чтобы писать быстрее и не спотыкаться.

---

## ⌨️ Emmet — начинаем коллекционировать

Мы будем добавлять по одному приёму на урок. Сегодняшний набор:

| Аббревиатура | Что развернёт |
|--------------|---------------|
| `!` + `Tab` | весь каркас HTML5-страницы |
| `h1` + `Tab` | `<h1></h1>` |
| `h1+p` | `<h1></h1>` и рядом `<p></p>` |
| `p*3` | три пустых `<p>` |
| `h2{Текст}` | `<h2>Текст</h2>` |
| `lorem` | случайный текст-«рыба» для примера |
| `lorem10` | «рыба» ровно из 10 слов |

> 💡 **`lorem`** — суперфишка: когда лень придумывать текст для примера, напиши `p>lorem` (или пока просто `lorem`) и получишь готовый абзац-заглушку. Это то, чем реально пользуются верстальщики.

Жми `Tab` **сразу** после аббревиатуры, без пробела. Работает только в файлах `.html`.

## ⌨️ Горячие клавиши VS Code

| Клавиши | Действие |
|---------|----------|
| `Ctrl+S` | сохранить (Live Server сразу обновит браузер) |
| `Alt+↑` / `Alt+↓` | двигать строку вверх/вниз |
| `Shift+Alt+↓` | скопировать строку вниз (дублировать) |
| `Ctrl+/` | закомментировать/раскомментировать строку |
| `Ctrl+D` | выделить следующее такое же слово (менять сразу несколько) |
| `Ctrl+U` (в браузере) | посмотреть HTML-код любого сайта |

## 🧲 Автозакрытие тегов

Когда печатаешь `<h1>`, VS Code **сам** дописывает `</h1>`. Не борись с ним — пиши текст между тегами. Если случайно получилось два закрывающих тега — лишний удали.

## 🐞 Частые ошибки и как их избежать

- **«Кракозябры» вместо русских букв** → нет `<meta charset="UTF-8">`. Всегда начинай с каркаса через `!` — мета там уже есть.
- **Весь текст превратился в заголовок** → забыл `</h1>`. Проверь: у каждого парного тега есть пара со слешем.
- **Страница пустая, но вкладка подписана** → написал текст в `head`. Всё видимое — только в `body`.
- **`<br />` или `</br>`** → у одиночных тегов нет пары, пиши просто `<br>` и `<hr>`.
- **Emmet не разворачивается** → файл не сохранён как `.html`, либо жмёшь `Tab` не сразу после аббревиатуры.
- **Много `<br><br><br>` для отступа** → плохая привычка. `br` — только для переноса строки в тексте, а расстояние между блоками сделаем через CSS (следующие уроки).

## 🌟 Мини-хитрости для красоты (пока без CSS)

- **Эмодзи** заменяют картинки: `<h1>Профиль 🎮</h1>`, `<p>Мой топ игр ⚽🏀🎾</p>`.
- **`<hr>`** — быстрый способ визуально разделить разделы.
- **`<strong>` и `<em>`** — выделить важное слово прямо в тексте (жирный/акцент).
- **`&copy;`, `&hearts;`, `&rarr;`** — спецсимволы: © ♥ →. Пишутся как «имя со знаком &».

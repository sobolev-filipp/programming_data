## 💬 Блиц-вопросы

1. Назови 3 способа подключить CSS. Какой лучший?
2. Как устроено правило CSS? (селектор / свойство / значение)
3. Каким свойством красят текст, а каким — фон?
4. Каким тегом вставляют картинку и парный ли он? Зачем `src` и `alt`?
5. Как сделать круглую аватарку из картинки?
6. Что развернёт Emmet из `div>img*3`?

<details><summary>✅ Ответы (для проверки)</summary>

1. inline `style`, `<style>`, `<link>`; лучший — `<link>` на внешний `.css`.
2. `селектор { свойство: значение; }`.
3. `color` — текст, `background-color` — фон.
4. `<img>`, одиночный; `src` — путь к файлу, `alt` — подпись/замена.
5. `border-radius: 50%` (картинка квадратная).
6. `div`, внутри три `img`.
</details>

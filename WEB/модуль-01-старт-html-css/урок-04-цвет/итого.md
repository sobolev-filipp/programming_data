# Урок 4 «Цвет» — итого (шпаргалка) 📌

> За 3 минуты вспомнить весь урок. Только суть и примеры.

---

## Главные мысли

1. Один цвет можно записать **4 способами**: имя, HEX, RGB, HSL — это разные «языки» одного цвета.
2. Цвет задают у `color` (текст), `background-color` (фон), `border-color`/`border` (рамка).
3. **Прозрачность** — alpha `0–1` в `rgba`/`hsla`; `transparent` — совсем прозрачный.
4. **HSL** удобен для оттенков: крути светлоту **L**.
5. 🆕 `oklch()` и `color-mix()` — современные, уже можно.

---

## Четыре формата (один красный)

```css
color: red;                 /* 1. имя (их ~140) */
color: #ff0000;             /* 2. HEX: #RRGGBB (00..ff) */
color: rgb(255, 0, 0);      /* 3. RGB: каналы 0..255 */
color: hsl(0, 100%, 50%);   /* 4. HSL: тон, насыщ%, светлота% */
```
Короткий HEX: `#ff0000` = `#f00`, `#ffffff` = `#fff`.
`#000000` — чёрный, `#ffffff` — белый, `#808080` — серый.

## Прозрачность

```css
background-color: rgba(255, 0, 0, 0.5);   /* полупрозрачный красный */
background-color: hsla(0, 100%, 50%, 0.5);
color: transparent;                        /* совсем прозрачный */
border: 2px solid currentColor;            /* цвет = цвет текста */
```
alpha: `0` невидимо … `1` непрозрачно.

## HSL — подбор оттенков

```css
hsl(210, 90%, 30%)   /* тёмный  */
hsl(210, 90%, 50%)   /* обычный */
hsl(210, 90%, 70%)   /* светлый */  /* меняем только L! */
```
H — тон 0–360°, S — насыщенность %, L — светлота %.

## Современные 🆕

```css
color: oklch(70% 0.15 250);
background: color-mix(in srgb, blue, white);      /* смешать 2 цвета */
background: color-mix(in srgb, red 70%, yellow);
```

## Цветовой круг — сочетания

Берёшь базовый цвет и находишь «друзей» по кругу:

| Сочетание | Как | Настроение |
|-----------|-----|-----------|
| **Контраст** (комплементарное) | 2 противоположных | яркий акцент (кнопки) |
| **Триада** | 3 через равные шаги | живое, детское |
| **Тетрада** | 4 (квадрат) | богатое, но сложное |
| **Аналоговые** | 3 соседних | мягкое, спокойное |

**Правило 60-30-10:** 60% основной цвет, 30% дополнительный, 10% яркий акцент.
🎡 Подбирать: [get-color.ru/color-wheel](https://get-color.ru/color-wheel/) · 🌈 градиенты: [cssgradient.io](https://cssgradient.io/).

## display: ставим блоки в ряд

```css
div { display: block; }         /* по умолчанию: в столбик, во всю ширину */
div { display: inline; }        /* в строку, но без своих размеров */
div { display: inline-block; }  /* в ряд + можно задать width/padding — для карточек ✅ */
```
`<div>` — коробка-контейнер (блочная), `<span>` — обёртка для текста (строчная). Ровные ряды по-настоящему — на Flexbox (дальше).

## Главные ошибки

| Проблема | Причина | Лечение |
|----------|---------|---------|
| цвет не применился | нет `#` в HEX / опечатка | `#` + 6 символов `0–9 a–f` |
| не тот цвет в RGB | число > 255 | каналы `0–255` |
| HSL не работает | нет `%` у S и L | `hsl(0, 100%, 50%)` |
| прозрачность не видна | alpha = 1 / забыл 4-е число | `rgba(..., 0.5)` |

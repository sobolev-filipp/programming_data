# 🧰 Лайфхаки · Урок 4 «Цвет»

Как быстро подбирать цвета и не мучиться с кодами.

---

## 🎨 Палитра-пипетка прямо в VS Code

Наведи курсор на любой цветной код (`#ff0000`, `rgb(...)`, `hsl(...)`) — слева появится **квадратик-превью**. Кликни по нему → откроется **палитра**: выбирай цвет мышкой, код подставится сам. Клик по верхней полоске переключает формат (HEX ↔ RGB ↔ HSL). Это самый быстрый способ подобрать цвет!

---

## 🎡 Цветовой круг — подбор сочетаний

- **[get-color.ru/color-wheel](https://get-color.ru/color-wheel/)** — цветовой круг: выбираешь тип сочетания (комплементарные, триада, аналоговые, тетрада), крутишь — получаешь готовую гамму с HEX-кодами.
- **Как выбрать тип:**
  - яркий акцент/кнопка → **контрастное** (противоположные цвета);
  - спокойная гамма → **аналоговые** (соседние);
  - живая, детская тема → **триада** (3 через равные шаги).
- **Правило 60-30-10:** 60% основной цвет (фон), 30% дополнительный, 10% яркий акцент.

## 🌈 Где брать готовые палитры и градиенты

- [coolors.co](https://coolors.co) — генератор палитр (пробел = новая палитра), сразу даёт HEX-коды.
- [colorhunt.co](https://colorhunt.co) — готовые красивые сочетания.
- [Google «color picker»](https://www.google.com/search?q=color+picker) — пипетка прямо в поиске.
- 🌈 [cssgradient.io](https://cssgradient.io/) — визуальный **генератор градиентов**: собираешь переход мышкой, копируешь готовый CSS. (Большая тема градиентов — в Модуле 3.)

> 💡 Правило новичка: бери **готовую палитру из 3–5 цветов** и используй только их — страница будет выглядеть цельно. Случайные цвета «из головы» часто не сочетаются.

## 🔢 Полезно запомнить

| Хочу | Код |
|------|-----|
| чёрный | `#000000` = `#000` = `rgb(0,0,0)` |
| белый | `#ffffff` = `#fff` = `rgb(255,255,255)` |
| серый | `#808080` = `rgb(128,128,128)` |
| прозрачный | `transparent` |
| полупрозрачный чёрный | `rgba(0,0,0,0.5)` |
| светлее любого цвета | `color-mix(in srgb, цвет, white)` |
| темнее любого цвета | `color-mix(in srgb, цвет, black)` |

## 💡 Трюки с цветом

- **Оттенки одним движением:** в HSL меняй только **L** (светлоту) — получишь готовую гамму от тёмного к светлому.
- **Рамка в цвет текста:** `border: 2px solid currentColor;` — не нужно дублировать цвет.
- **Плашка-подпись на фото:** `rgba(0,0,0,0.4)` + белый текст — читается на любой картинке.
- **`opacity: 0.5`** делает прозрачным **весь** элемент (и текст, и фон), а `rgba` — только один цвет. Выбирай по задаче.
- **Emmet в CSS:** `c#f00` + `Tab` → `color: #f00;`, `bgc` → `background-color:`.

---

## ⚠️ Частые ошибки

- Забыл `#` в HEX (`color: ff0000;`) — не сработает.
- RGB-канал больше 255 (`rgb(300,0,0)`) — обрежется/не тот цвет.
- В HSL забыл `%` у S и L (`hsl(0,100,50)`) — не сработает.
- Ждёшь прозрачность, а alpha не задан (`rgb` вместо `rgba`).
- Тёмный текст на тёмном фоне (или светлый на светлом) — не читается. Проверяй **контраст**.

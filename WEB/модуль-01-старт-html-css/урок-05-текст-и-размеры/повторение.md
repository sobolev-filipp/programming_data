## 💬 Блиц-вопросы

1. Три способа подключить CSS — какой лучший?
2. Каким свойством красят текст, а каким — фон?
3. Как записать цвет четырьмя способами? (имя, HEX, RGB, HSL)
4. Как сделать полупрозрачный цвет?
5. Каким тегом вставляют картинку, и как сделать её круглой?
6. Что развернёт Emmet из `div>img*3`?

<details><summary>✅ Ответы (для проверки)</summary>

1. inline `style`, `<style>`, `<link>`; лучший — `<link>`.
2. `color` — текст, `background-color` — фон.
3. `red` / `#ff0000` / `rgb(255,0,0)` / `hsl(0,100%,50%)`.
4. `rgba(...)`/`hsla(...)` с alpha 0–1.
5. `<img>`; круглая — `border-radius: 50%`.
6. `div`, внутри три `img`.
</details>

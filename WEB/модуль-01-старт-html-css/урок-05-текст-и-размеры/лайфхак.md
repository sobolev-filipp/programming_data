# 🧰 Лайфхаки · Урок 5 «Текст и размеры»

Приёмы, чтобы текст выглядел профессионально.

---

## 📐 Хорошие значения по умолчанию

| Что | Значение | Зачем |
|-----|----------|-------|
| основной текст | `font-size: 16–18px` | комфортно читать |
| заголовок h1 | `font-size: 40–72px` | «вау» и акцент |
| межстрочный | `line-height: 1.5–1.7` | текст «дышит» |
| разрядка заголовка | `letter-spacing: 2–6px` | стильно, «дорого» |
| мельче 14px | ❌ не делай для текста | тяжело читать |

---

## ✨ Красивые тени текста

```css
/* мягкая тень (объём) */
text-shadow: 2px 2px 4px rgba(0,0,0,0.4);

/* неоновое свечение */
text-shadow: 0 0 8px #0ff, 0 0 20px #0ff;

/* «обводка» светлым на фото */
text-shadow: 0 0 4px #000;
```

> 💡 Тень заметнее, если её цвет полупрозрачный (`rgba`). Несколько теней через запятую усиливают эффект.

## ⌨️ Emmet в CSS для текста

| Пишешь | Получаешь |
|--------|-----------|
| `fz24` | `font-size: 24px;` |
| `fw700` | `font-weight: 700;` |
| `lh1.6` | `line-height: 1.6;` |
| `ls2` | `letter-spacing: 2px;` |
| `tt-u` | `text-transform: uppercase;` |
| `td-n` | `text-decoration: none;` |
| `tsh` | `text-shadow: ...;` (заготовка) |

## 🖱️ Про `:hover`

- Пиши **без пробела**: `a:hover`, `.btn:hover`.
- Работает на любом элементе, не только ссылке.
- Меняй что угодно: цвет, размер, разрядку, тень.
- Плавность появления (`transition`) добавим в отдельном модуле — тогда ховеры станут «мягкими».

---

## ⚠️ Частые ошибки

- Забыл единицу: `font-size: 20` (нужно `20px`).
- `line-height: 1.6px` — для межстрочного лучше **число без единицы** (`1.6`).
- Тень слилась с фоном — сделай контрастнее.
- Пробел в `a :hover` — не сработает, пиши `a:hover`.
- Слишком много эффектов сразу — выглядит «пёстро». Лучше 2–3 приёма, но точных.

# 🧑‍🏫 Часть A. Разбираем вместе (пошагово)

## 1. Размер шрифта

**Тема:** `font-size` задаёт размер текста в пикселях. Заголовки крупные, текст — 16–20px.

**Задание:** сделай крупный заголовок и удобный текст.

**Разбор по шагам:**
1. `h1 { font-size: 48px; }` — крупный заголовок.
2. `p { font-size: 18px; }` — текст для чтения.
3. Сохрани — разница видна сразу.
4. Всегда пиши единицу `px`, иначе не сработает.

✅ `font-size: 48px;`.

---

## 2. Толщина и курсив

**Тема:** `font-weight` — толщина (100–900 или bold/normal), `font-style: italic` — курсив.

**Задание:** сделай жирный заголовок и курсивную цитату.

**Разбор по шагам:**
1. `h1 { font-weight: 900; }` — очень жирный.
2. `.quote { font-style: italic; }` — курсив.
3. Добавь тонкий текст: `font-weight: 300;`.
4. Сравни виды «веса» букв.

✅ `font-weight: 900;` и `font-style: italic;`.

---

## 3. Регистр и линии

**Тема:** `text-transform: uppercase` делает КАПС, `text-decoration` добавляет/убирает линии.

**Задание:** заголовок капсом + зачёркнутая «старая цена».

**Разбор по шагам:**
1. `h1 { text-transform: uppercase; }` — заглавные (текст не меняем).
2. `.old { text-decoration: line-through; }` — зачёркнуто.
3. Убери подчёркивание у ссылки: `a { text-decoration: none; }`.
4. Сохрани и проверь.

✅ `text-transform: uppercase;`, `text-decoration: line-through;`.

---

## 4. Интервалы и тень

**Тема:** `line-height` — между строк, `letter-spacing` — между букв, `text-shadow` — тень.

**Задание:** дышащий абзац + заголовок с разрядкой и тенью.

**Разбор по шагам:**
1. `p { line-height: 1.7; }` — строки не слипаются.
2. `h1 { letter-spacing: 5px; }` — разрядка.
3. `h1 { text-shadow: 2px 2px 4px rgba(0,0,0,.4); }` — мягкая тень.
4. Формула тени: X Y размытие цвет.

✅ `line-height`, `letter-spacing`, `text-shadow`.

---

## 5. px vs % и :hover

**Тема:** `px` — фикс, `%` — доля родителя. `:hover` — реакция на наведение.

**Задание:** два блока разной ширины + ссылка с ховером.

**Разбор по шагам:**
1. `.a { width: 250px; }`, `.b { width: 100%; }` — дай фон, сузь окно: `.b` меняется.
2. `a { color: navy; text-decoration: none; }`.
3. `a:hover { color: crimson; text-decoration: underline; }`.
4. Наведи мышь — ссылка меняется. У `:hover` нет пробела перед `:`.

✅ `%` зависит от родителя; `a:hover { ... }`.

# Урок 5 «Текст и размеры» — итого (шпаргалка) 📌

> За 3 минуты вспомнить весь урок. Только суть и примеры.

---

## Главные мысли

1. Типографика — половина красоты сайта: играй размером, толщиной, интервалами, тенью.
2. Размер шрифта — `font-size` (в `px`), не забывай единицу.
3. `line-height` (1.5–1.7) делает текст читаемым; `letter-spacing` — разрядка для заголовков.
4. `text-shadow` — тень и неоновое свечение.
5. **`px`** — фиксированный размер; **`%`** — доля от родителя.
6. **`:hover`** — реакция на наведение мыши.

---

## Свойства текста

```css
h1 {
    font-size: 48px;            /* размер (px) */
    font-weight: 900;           /* толщина: normal/bold или 100–900 */
    font-style: italic;         /* курсив */
    text-transform: uppercase;  /* ЗАГЛАВНЫМИ (или capitalize) */
    text-decoration: underline; /* подчеркнуть / line-through / none */
    letter-spacing: 4px;        /* между буквами */
    line-height: 1.6;           /* между строками */
    text-shadow: 2px 2px 4px rgba(0,0,0,.4);  /* X Y размытие цвет */
}
```

Неоновое свечение:
```css
.neon { color: #0ff; text-shadow: 0 0 10px #0ff, 0 0 20px #0ff; }
```

---

## Размеры блоков: px vs %

```css
.fixed { width: 300px; }   /* всегда 300px */
.fluid { width: 80%; }     /* 80% ширины родителя */
```
**px не меняется · % зависит от родителя.**

---

## Первый интерактив :hover

```css
a { color: navy; text-decoration: none; }
a:hover { color: crimson; text-decoration: underline; }  /* при наведении */
```
`a:hover` — без пробела перед `:`.

## Кнопки

```html
<button class="btn">Действие</button>       <!-- настоящая кнопка -->
<a href="#" class="btn">Переход</a>          <!-- ссылка-кнопка -->
```
```css
.btn { display:inline-block; padding:12px 28px; border:none;
       border-radius:8px; cursor:pointer; text-decoration:none; }
.btn:hover { background-color: darkred; }
```

## Главные ошибки

| Проблема | Причина | Лечение |
|----------|---------|---------|
| текст слипся | нет `line-height` | `line-height: 1.6` |
| размер не сработал | забыл `px` | `font-size: 20px` |
| ссылка подчёркнута | не убрал | `text-decoration: none` |
| тень не видно | слилась с фоном | контрастный/полупрозрачный цвет |
| `:hover` не работает | пробел перед `:` | `a:hover` слитно |

# 🍽️ Тарелки — тренажёр CSS-селекторов

Наша **пародия на CSS Diner** (оригинал не открывается в РФ без VPN, поэтому сделали свою — и без псевдоклассов/псевдоэлементов, которые дети ещё не проходили).

## Как открыть
Просто открой **[`игра.html`](игра.html)** в браузере (двойной клик или через Live Server). Работает **офлайн**, без интернета и без установки.

> ⚠️ Во встроенном предпросмотре редактора игра показывается «картинкой» без кнопок — это нормально. Чтобы играть, открой файл в настоящем браузере (Live Server / двойной клик).

## Что тренируем (12 уровней, по нарастанию, порядок = порядку уроков)
1. Тег — `plate`
2. Тег — `apple`
3. Класс — `.small`
4. Тег + класс — `apple.spicy`
5. Группировка — `apple, cake`
6. Вложенность (потомок) — `plate apple`
7. id — `#special`
8. Прямой потомок — `plate > apple`
9. Универсальный — `*`
10. Соседний — `plate + apple`
11. Следующие соседи — `pizza ~ apple`
12. Комбо-финал — `#menu .hot`

Игрок пишет селектор → игра реально запускает `querySelectorAll` по «столу» и подсвечивает попадания. Засчитывается **любой** селектор, выделяющий ровно нужный набор. Псевдоклассы (`:`) и атрибуты (`[]`) заблокированы — в игре они не нужны.

Справа от стола — две панели: **«Как это работает»** (описание приёма текущего уровня + пример) и **разметка стола** (видна сразу). При наведении на тарелку она подсвечивается в разметке, и наоборот — так ребёнок видит связь «элемент ↔ тег».

## Когда давать (уровни открываются по мере изучения)
- После **урока 2** (тег, класс, тег+класс, группировка) — **уровни 1–5**.
- После **урока 3** (вложенность) — **уровень 6**.
- После **урока 4** (`#id`) — **уровень 7**.
- Комбинаторы `>`, `+`, `~` и `*` (уровни 8–12) — челлендж/бонус (в уроках отдельно не разбираются, но в игре по каждому есть панель «Как это работает» и подсказка).

Есть кнопки **💡 Подсказка** и **📖 Полная шпаргалка** — ребёнок справится сам.

## 💬 Блиц-вопросы

1. Какие **непарные** (одиночные) теги ты уже знаешь? *(подсказка: их сегодня станет на один больше!)*
2. Назови **три способа** подключить CSS. Какой лучший и почему?
3. Как устроено правило CSS? Что такое селектор, свойство, значение?
4. Каким свойством красят фон всей страницы?
5. Что развернёт Emmet из `!`? А из `h2+p*3`?
6. Что сильнее — стиль в теге (`style="..."`) или правило из файла?

<details><summary>✅ Ответы (для проверки)</summary>

1. `<br>`, `<hr>` (сегодня добавится `<img>`).
2. inline `style`, `<style>` в head, `<link>` на внешний `.css`. Лучший — `<link>` (один стиль на весь сайт).
3. `селектор { свойство: значение; }`: кого / что / как.
4. `body { background-color: ...; }`.
5. `!` — каркас; `h2+p*3` — заголовок и три абзаца.
6. Сильнее — inline-стиль в теге.
</details>

## ⚡ Быстрое повторение руками

Открой прошлую страницу (или собери новую через `!`): подключи `style.css` через `<link>`, задай фон и цвет заголовка. Готово? Значит можно добавлять картинки!

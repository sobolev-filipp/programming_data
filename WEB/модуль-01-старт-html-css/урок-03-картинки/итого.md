# Урок 3 «Картинки» — итого (шпаргалка) 📌

> За 3 минуты вспомнить весь урок. Только суть и примеры.

---

## Главные мысли

1. Картинку вставляет **одиночный** тег **`<img>`** (пары нет).
2. **`src`** — путь к файлу; **`alt`** — текст-замена (если не загрузилось) и подпись для незрячих/поисковиков.
3. **Размер** задают `width`/`height`; лучше **только ширину** — пропорции сохранятся.
4. **`border-radius: 50%`** делает круглую аватарку (из квадратной картинки).
5. **Emmet `>`** — вложенность (`div>img*3`).

---

## Вставить картинку

```html
<img src="кот.jpg" alt="Рыжий кот">
<img src="images/кот.jpg" alt="кот">   <!-- если лежит в папке images -->
```
Файл должен лежать **рядом** (или по указанному пути), имя — точно, с расширением.

## Размер

```html
<img src="кот.jpg" alt="кот" width="200">   <!-- в HTML, пиксели -->
```
```css
img { width: 200px; }   /* или */
img { width: 100%; }    /* не вылезает за края */
```
⚠️ Задавай **только ширину** — иначе картинка исказится.

## Картинка-ссылка

```html
<a href="https://site.ru">
    <img src="кот.jpg" alt="кот" width="150">
</a>
```

## Оформление (CSS)

```css
img {
    border: 4px solid gold;   /* рамка */
    border-radius: 12px;      /* мягкие углы */
}
.avatar { border-radius: 50%; }  /* круг-аватарка (картинка квадратная!) */
```

## Emmet

| Пишешь | Получаешь |
|--------|-----------|
| `img` | `<img src="" alt="">` |
| `div>img*3` | `div`, внутри три `img` |
| `a>img` | ссылка с картинкой внутри |

---

## Блоки: `<div>` и `<span>`

- **`<div>`** — «коробка-контейнер», группирует элементы (например, галерею). Ничего не рисует сама.
- **`<span>`** — обёртка для кусочка текста в строке.
- **Блочные** (`div`, `h1`, `p`) — каждый с новой строки, во всю ширину.
- **Строчные** (`img`, `span`, `a`) — стоят в ряд друг за другом.
- Управляет этим свойство `display` (следующий урок).

---

## Главные ошибки

| Проблема | Причина | Лечение |
|----------|---------|---------|
| «сломанный» значок | неверный `src`/нет файла | путь и имя буква-в-букву |
| картинка гигантская | не задан размер | `width` в `px`/`%` |
| кот «сплющен» | задал `width` и `height` наугад | только ширину |
| овал вместо круга | картинка не квадратная | квадратная (или позже `object-fit`) |

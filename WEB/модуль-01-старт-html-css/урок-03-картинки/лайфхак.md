# 🧰 Лайфхаки · Урок 3 «Картинки»

Трюки, где брать картинки и как не поймать «сломанный значок».

---

## ⌨️ Emmet — новый приём `>` и картинки

Копилка: `!`, `+`, `*`, `{текст}`, а теперь **`>`** (вложенность).

| Аббревиатура | Что развернёт |
|--------------|---------------|
| `img` + `Tab` | `<img src="" alt="">` |
| `img[src=кот.jpg]` | `<img src="кот.jpg" alt="">` |
| `div>img*3` | `div`, внутри три `img` |
| `a>img` | ссылка с картинкой внутри |
| `.gallery>img*4` | `<div class="gallery">` с четырьмя `img` |

> 💡 `>` — «внутрь», `+` — «рядом», `*` — «повтор». Комбинируй: `div>(a>img)*4` — четыре картинки-ссылки.

---

## 🖼️ Где брать картинки (бесплатно и легально)

- **Фотостоки:** [unsplash.com](https://unsplash.com), [pexels.com](https://pexels.com), [pixabay.com](https://pixabay.com) — скачал, положил в папку.
- **Иконки:** [flaticon.com](https://www.flaticon.com), [icons8.ru](https://icons8.ru).
- **Заглушки для тренировки:** сервис `https://picsum.photos/300/200` даёт случайную картинку нужного размера прямо по ссылке в `src` (нужен интернет).
- **Готовые в курсе:** `материалы/картинки/` (`кот.svg`, `обложка-игры.svg`).

> ⚠️ Не бери чужие картинки «из гугла» для публикации — там могут быть авторские права. Для учёбы — ок, для реального сайта — только свободные.

---

## 📁 Порядок в проекте

Складывай все картинки в отдельную папку **`images/`** (или `img/`) и пиши путь `src="images/кот.jpg"`. Когда картинок много — так гораздо аккуратнее.

---

## 🎨 Полезные приёмы

- **Круглая аватарка:** `border-radius: 50%` (картинка должна быть квадратной).
- **Не вылезает за края:** `img { width: 100%; }` — картинка подстроится под блок.
- **Только ширина:** задавай `width`, а `height` не трогай — пропорции сохранятся сами.
- **Подсказка при наведении:** `<img ... title="текст">`.
- **Рамка + скругление вместе:** `border` и `border-radius` отлично сочетаются.

---

## 🐞 «Сломанный значок» — чек-лист

Если вместо картинки — значок 🖼️❌:
1. Файл точно лежит **в папке проекта** (рядом с HTML или по указанному пути)?
2. Имя в `src` совпадает **буква-в-букву** (регистр важен: `Кот.jpg` ≠ `кот.jpg`)?
3. Указано **расширение** (`.jpg`, `.png`, `.svg`)?
4. Нет опечаток и лишних пробелов в `src`?
5. Открой картинку двойным кликом — она вообще открывается?

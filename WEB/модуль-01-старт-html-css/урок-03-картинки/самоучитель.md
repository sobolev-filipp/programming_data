# 🧑‍🏫 Часть A. Разбираем вместе (пошагово)

## 1. Вставляем картинку тегом `<img>`

**Тема:** картинку показывает одиночный тег `<img>` с атрибутами `src` (путь к файлу) и `alt` (описание).

**Задание:** покажи картинку на странице.

**Разбор по шагам:**
1. Положи файл картинки (например, `кот.svg`) рядом с `index.html`.
2. В `<body>` напиши: `<img src="кот.svg" alt="Рыжий кот">`.
3. Сохрани — картинка появится в браузере.
4. `<img>` — одиночный тег, закрывать не нужно.

✅ `<img src="кот.svg" alt="Рыжий кот">`.

---

## 2. Зачем `alt` и путь к файлу

**Тема:** если браузер не найдёт файл по `src`, вместо картинки покажется текст `alt`. Имя должно совпадать точно.

**Задание:** проверь, как работает `alt`.

**Разбор по шагам:**
1. Ошибись специально: `<img src="кот999.svg" alt="Рыжий кот">`.
2. Сохрани — увидишь «сломанный» значок и текст «Рыжий кот».
3. Верни правильное имя файла — картинка вернётся.
4. Вывод: `src` — точный путь, `alt` — страховка и подпись.

✅ Понял: точный `src` + осмысленный `alt`.

---

## 3. Размер картинки

**Тема:** размер задают `width` (ширина). Лучше задавать только ширину — высота подстроится, картинка не исказится.

**Задание:** уменьши картинку до 200px.

**Разбор по шагам:**
1. В HTML: `<img src="кот.svg" alt="кот" width="200">`.
2. Или в CSS: `img { width: 200px; }`.
3. Сохрани — картинка стала 200px шириной, пропорции сохранились.
4. Не задавай `height` наугад — иначе «сплющит».

✅ `width="200"` или `img { width: 200px; }`.

---

## 4. Круглая аватарка

**Тема:** `border-radius: 50%` превращает квадратную картинку в круг.

**Задание:** сделай круглую аватарку.

**Разбор по шагам:**
1. В CSS: `img { width: 120px; border-radius: 50%; }`.
2. Добавь рамку: `border: 4px solid gold;`.
3. Сохрани — получилась круглая аватарка с золотой рамкой.
4. Круг ровный, если картинка квадратная.

✅ `img { width:120px; border-radius:50%; border:4px solid gold; }`.

---

## 5. Картинка-ссылка + Emmet `>`

**Тема:** картинку делают кликабельной, обернув в `<a>`. Emmet `>` означает «внутрь».

**Задание:** сделай картинку-ссылку.

**Разбор по шагам:**
1. Набери Emmet `a>img` и нажми `Tab` — получишь `<a href=""><img src="" alt=""></a>`.
2. Впиши в `<a>` адрес: `href="https://ru.wikipedia.org"`.
3. Впиши в `<img>` свои `src` и `alt`.
4. Клик по картинке теперь открывает сайт.

✅ `<a href="..."><img src="..." alt="..."></a>`.

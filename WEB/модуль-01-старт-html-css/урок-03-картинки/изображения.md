# 🖼 Изображения и что показать на проекторе · Урок 3

Схемы в папке `изображения/`. Готовые картинки-ассеты — в `материалы/картинки/`.

---

## 1. `путь-к-картинке.svg`
**Когда:** Часть 1 (первая картинка, `src`).
**Что показать:** файл `кот.jpg` в папке проекта → `<img src="кот.jpg">` → картинка на странице; при неверном имени — «сломанный» значок.
**Проговорить:** «`<img>` не хранит картинку, а показывает путь к файлу. Браузер идёт по `src`, находит файл и рисует. Ошибся в имени — картинки нет».

## 2. `border-radius-круг.svg`
**Когда:** Часть 6 (оформление, скругление).
**Что показать:** квадрат → `border-radius: 20px` (мягкие углы) → `50%` (круг-аватарка).
**Проговорить:** «`border-radius` скругляет углы. `50%` из квадратной картинки делает круг — так рисуют аватарки».

---

## 💻 Живая демонстрация (обязательно!)

1. Перетащить картинку в папку проекта, показать `<img src alt>` — картинка появилась.
2. **Сломать путь** (ошибиться в имени) → показать «сломанный значок» + текст `alt` → починить. Снимает страх ошибки №1.
3. Показать размер: `width="200"` vs `width:100%` (менять ширину окна).
4. `border-radius: 50%` → круглая аватарка вживую.
5. Картинка-ссылка: обернуть в `<a>`, кликнуть.
6. Emmet `div>img*3` — мгновенный каркас галереи.
7. Открыть `материалы/пример-картинка.html` — все приёмы разом.

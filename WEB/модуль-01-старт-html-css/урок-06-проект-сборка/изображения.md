## 💻 Живая демонстрация (обязательно!)

1. **Собрать скелет Emmet-ом** на глазах: `header>img.avatar+h1+p.slogan`, `section.hobbies>h2+.card*3` — «смотрите, каркас за секунды».
2. Подключить `style.css`, задать палитру в одном тоне HSL — показать, как цвета «дружат».
3. По шагам: аватар круглый → карточки с тенью → заголовок с тенью → кнопка с `:hover`.
4. Открыть `материалы/каркас-старт.html` — скелет с подсказками для тех, кто отстал.
5. Подчеркнуть порядок: **структура → содержание → стиль → интерактив**.

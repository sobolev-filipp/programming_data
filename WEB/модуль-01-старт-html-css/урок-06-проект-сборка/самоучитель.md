# 🆘 Самоучитель · Урок 6 «Проект-сборка»

> Пропустил урок или хочешь собрать проект сам? Здесь — **пошаговая сборка** страницы «Обо мне» из всего, что было в модуле. Часть A — собираем вместе; часть B — доделываешь и украшаешь сам. Всего 12 шагов.
>
> 🧰 Нужен VS Code + Live Server. Пригодится квадратное фото (или возьми из `материалы/` любого урока).

---

# 🧑‍🏫 Часть A. Собираем вместе (пошагово)

## 1. Каркас и файлы

**Тема:** страница = HTML-каркас + отдельный `style.css`.

**Шаги:**
1. Создай папку, в ней `index.html`.
2. Разверни каркас через `!`.
3. Поставь `lang="ru"`, `title`, подключи `<link rel="stylesheet" href="style.css">`.
4. Создай рядом пустой `style.css`.

✅ Готов каркас с подключённым CSS.

---

## 2. Шапка: фото + имя

**Шаги:**
1. В `<body>` добавь блок-шапку: `<header class="hero">`.
2. Внутрь — картинку `<img src="avatar.jpg" alt="фото" class="avatar">`, `<h1>Имя</h1>`, `<p class="slogan">слоган</p>`.
3. Положи своё фото в папку и укажи его имя в `src`.

✅ Шапка с аватаром и именем.

---

## 3. Разделы и карточки

**Шаги:**
1. Добавь раздел: `<section class="about"><h2>Обо мне</h2><p>...</p></section>`.
2. Добавь раздел увлечений с тремя `<div class="card">...</div>` (Emmet: `.card*3`).
3. Внизу — кнопку `<a href="#" class="btn">Написать</a>`.

✅ Структура готова (проверь в браузере — пока без стилей).

---

## 4. Палитра в одном тоне

**Тема:** цвета «дружат», если это оттенки одного тона HSL.

**Шаги:**
1. В `style.css`: `body { background-color: hsl(230,30%,96%); color:#1f2937; text-align:center; line-height:1.6; }`.
2. Шапка: `.hero { background-color: hsl(230,60%,55%); color:white; padding:40px; }`.
3. Меняй только светлоту `L` — тон один.

✅ Дружная палитра.

---

## 5. Аватар, карточки, текст, hover

**Шаги:**
1. Аватар: `.avatar { width:120px; border-radius:50%; border:4px solid white; }`.
2. Карточки: `.card { display:inline-block; background:white; width:200px; padding:24px; margin:10px; border-radius:16px; box-shadow:0 6px 16px rgba(0,0,0,.1); }`.
3. Заголовок: `h1 { font-size:44px; text-shadow:0 2px 8px rgba(0,0,0,.3); }`.
4. Кнопка: `.btn { ... text-decoration:none; padding:16px 32px; border-radius:30px; }` и `.btn:hover { background-color: ...; }`.

✅ Страница ожила — фото круглое, карточки с тенью, кнопка реагирует.

---

# ✍️ Часть B. Доделай и укрась сам (с подсказками)

**6.** Впиши свои данные: имя, слоган, текст «обо мне».
> 💡 Меняем только текст между тегами.

**7.** Сделай три свои карточки-увлечения (эмодзи + название + описание).
> 💡 Emmet `.card*3`, потом заполни.

**8.** Подбери свою палитру в одном тоне HSL.
> 💡 Один `H`, разные `L` для фона/шапки/кнопки.

**9.** Оформи слоган курсивом, а дату/подпись — разрядкой.
> 💡 `font-style: italic;`, `letter-spacing`.

**10.** Сделай кнопку с `:hover` (темнеет или меняет цвет).
> 💡 `.btn:hover { background-color: ...; }`.

**11.** Добавь свой раздел (цели / контакты / любимая цитата).
> 💡 Ещё один `<section>` с `h2` и `p`.

**12. 🔴** Сделай вторую страницу и подключи тот же `style.css`.
> 💡 Одинаковый `<link>` — единый стиль сайта.

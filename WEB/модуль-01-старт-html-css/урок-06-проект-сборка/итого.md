# Урок 6 «Проект-сборка» — итого (шпаргалка) 📌

> За 3 минуты вспомнить сборку страницы и весь модуль 1.

---

## Порядок сборки страницы

1. **Структура** — какие блоки и в каком порядке (сначала план!).
2. **Содержание** — HTML: каркас `!`, заголовки, текст, картинки.
3. **Подключить CSS** — `<link>` на `style.css`.
4. **Палитра** — один тон HSL, меняем светлоту → цвета «дружат».
5. **Картинки** — круглая аватарка (`border-radius: 50%`).
6. **Текст** — размеры, тень, интервалы.
7. **Интерактив** — `:hover`.

---

## Скелет страницы

```html
<header class="hero">
    <img src="avatar.jpg" alt="фото" class="avatar">
    <h1>Имя</h1>
    <p class="slogan">Слоган</p>
</header>
<section class="about"><h2>Обо мне</h2><p>...</p></section>
<section class="hobbies">
    <h2>Увлечения</h2>
    <div class="card">...</div>
    <div class="card">...</div>
</section>
<a href="#" class="btn">Кнопка</a>
```

```css
.avatar { width:120px; border-radius:50%; border:4px solid white; }
.card   { display:inline-block; background:white; padding:24px;
          border-radius:16px; box-shadow:0 6px 16px rgba(0,0,0,.1); }
.btn:hover { background-color: hsl(340,80%,45%); }
```

---

## Emmet-турбо (копилка модуля)

| Приём | Что |
|-------|-----|
| `!` | каркас |
| `>` | внутрь |
| `+` | рядом |
| `*N` | повтор |
| `{текст}` | содержимое |
| `.class` `#id` | класс / id |
| `()` | группировка |

Пример: `.gallery>(.card>h3+p)*4` — 4 карточки с заголовком и текстом.

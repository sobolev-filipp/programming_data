## 💬 Блиц по всему модулю

1. Как подключить внешний CSS? Почему это лучший способ?
2. Как сделать круглую аватарку из картинки?
3. Как «подружить» цвета на странице?
4. Каким свойством делают тень у текста? А как оживить кнопку при наведении?
5. Что развернёт Emmet из `.card*3`? А из `section>h2+p`?
6. В каком порядке лучше строить страницу?

<details><summary>✅ Ответы (для проверки)</summary>

1. `<link rel="stylesheet" href="style.css">`; один файл — на весь сайт, чистый HTML.
2. `border-radius: 50%` (фото квадратное).
3. Взять один тон HSL и менять светлоту `L`.
4. `text-shadow`; кнопку — `.btn:hover { ... }`.
5. `.card*3` → три `<div class="card">`; `section>h2+p` → section, внутри h2 и p.
6. Структура → содержание → стиль.
</details>

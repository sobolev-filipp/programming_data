# 🧰 Лайфхаки · Урок 6 «Проект-сборка»

Приёмы, чтобы собирать страницы быстро и красиво.

---

## ⚡ Emmet-турбо: каркас одной строкой

| Аббревиатура | Результат |
|--------------|-----------|
| `!` | каркас страницы |
| `header>img.avatar+h1+p.slogan` | шапка с аватаром, именем, слоганом |
| `.card*3` | три блока `<div class="card">` |
| `section>h2+p` | раздел с заголовком и абзацем |
| `(.item>h2+img+p)*5` | 5 позиций «топа» |
| `.btn{Написать}` | `<a class="btn">Написать</a>` (для `a` можно `a.btn`) |

> 💡 Собери сначала **весь скелет** Emmet-ом, потом наполняй текстом — так быстрее, чем печатать теги руками.

---

## 🎨 Как сделать красиво (правила новичка)

- **Одна палитра.** Возьми один тон HSL, меняй светлоту — цвета сразу «дружат».
- **Воздух.** Не лепи всё вплотную: `padding` внутри блоков, `margin` между ними, `line-height: 1.6`.
- **Один акцент.** Один яркий цвет для кнопки/важного, остальное спокойное.
- **Скругления и тени** делают блоки «дорогими»: `border-radius` + мягкий `box-shadow`.
- **Меньше эффектов — лучше.** 2–3 приёма, но аккуратных.

---

## 🧱 Порядок работы (чтобы не запутаться)

1. **Структура** — накидай блоки (можно Emmet-ом), проверь порядок.
2. **Содержание** — впиши тексты и картинки.
3. **Стиль** — палитра, отступы, шрифты, тени.
4. **Интерактив** — `:hover`.
5. **Проверка** — по чек-листу из урока.

---

## 🐞 Частые проблемы

- Стили не видны → забыл `<link>` / неверный `href`.
- Карточки в столбик → нужен `display: inline-block` (ровные ряды — на Flexbox дальше).
- Аватар-квадрат → фото не квадратное или нет `border-radius: 50%`.
- «Пёстро» → слишком много цветов; вернись к одному тону.
- Текст не читается на фоне → проверь контраст (тёмное на светлом / наоборот).

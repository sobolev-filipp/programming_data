# 🆘 Самоучитель · Урок 1 — Семантика и первый Flexbox

Пропустил урок или хочешь разобраться сам? Иди по шагам. **Часть A** — с полным разбором, **Часть B** — задания с подсказками. В конце ты сам соберёшь шапку сайта на flex.

> Тебе нужны: VS Code + Live Server. Создай папку, в ней `index.html` и `style.css`, подключи стили через `<link rel="stylesheet" href="style.css">`. Как это сделать — в [Справочнике, раздел «С чего начать»](../../Справочник.md#с-чего-начать).

## Часть A — разбираем вместе

### Шаг 1. Что такое семантические теги

Раньше страницу строили из `<div>` — безымянных коробок. Проблема: непонятно, где что. **Семантические теги** — те же коробки, но **с именем**:

```html
<header>Шапка</header>
<nav>Меню</nav>
<main>Главное</main>
<footer>Подвал</footer>
```

Они **блочные** (каждый с новой строки), как `div`. Отличие — в смысле: и человек, и браузер сразу понимают структуру.

👉 Создай `index.html`, собери эти 4 тега внутри `<body>`, впиши в каждый по слову. Открой через Live Server — увидишь 4 строки.

### Шаг 2. Наполняем каркас

```html
<body>
    <header>
        <h1>🎮 Мой сайт</h1>
    </header>
    <nav>
        <a href="#">Главная</a>
        <a href="#">О нас</a>
        <a href="#">Контакты</a>
    </nav>
    <main>
        <h2>Привет!</h2>
        <p>Это моя первая страница с нормальным каркасом.</p>
    </main>
    <footer>
        <p>© 2026 Мой сайт</p>
    </footer>
</body>
```

👉 Скопируй к себе. Ссылки в меню пока идут в строку, потому что `<a>` — строчный тег. Сейчас научимся этим **управлять**.

### Шаг 3. Включаем Flexbox

Flexbox — режим раскладки. Пишем **одну строчку родителю** (тому, внутри кого лежат элементы):

```css
nav {
    display: flex;
    gap: 20px;
}
```

- `display: flex` — дети `nav` (ссылки) встают **в ряд**;
- `gap: 20px` — промежуток между ними.

👉 Добавь это в `style.css`. Поменяй `gap` на `40px` — промежутки станут больше.

> 🧭 Запомни: `display:flex` пишут **контейнеру** (родителю), а командует он **детьми**.

### Шаг 4. Две оси: justify-content и align-items

Как только включили flex, у контейнера две оси:
- **главная** (горизонталь) — ей командует **`justify-content`**;
- **поперечная** (вертикаль) — ей командует **`align-items`**.

```css
.top {
    display: flex;
    justify-content: space-between;  /* раздвинуть по краям */
    align-items: center;             /* по центру высоты */
}
```

`space-between` разведёт детей по краям, `center` поставит их на одну линию по высоте.

👉 Оберни шапку: `<header class="top">` c `<div class="logo">🎮 Мой сайт</div>` и `<nav class="menu">...</nav>`. Задай `.top` стили выше. Логотип уедет влево, меню — вправо.

### Шаг 5. Идеальный центр

Чтобы поставить что-то **ровно по центру** блока:

```css
.box {
    display: flex;
    justify-content: center;
    align-items: center;
    height: 150px;
    background: #e0e7ff;
}
```

👉 Сделай `<div class="box">По центру!</div>` — текст окажется в самом центре блока.

## Семантический каркас

Смысловые теги — это `<div>` с понятным именем. Выглядят как блоки, но код читается как оглавление.

```html
<header>  <!-- шапка: логотип, меню -->
<nav>     <!-- навигация (меню) -->
<main>    <!-- главное содержимое (один на странице!) -->
<footer>  <!-- подвал: копирайт, контакты -->
```

Внутри `<main>`:
- **`<section>`** — смысловой раздел (со своим заголовком);
- **`<article>`** — самостоятельная единица (карточка, новость, пост) — можно «вырезать» целиком;
- **`<aside>`** — блок сбоку (похожее, реклама);
- **`<figure>` + `<figcaption>`** — картинка с подписью.

> Правило: есть подходящий смысловой тег — бери его вместо `div`.

## Flexbox — раскладка в ряд

Одна строчка **родителю** — и дети встают в ряд:

```css
.container { display: flex; }
```

Две оси: **главная** (горизонталь) и **поперечная** (вертикаль).

| Свойство | Ось | Что делает |
|----------|-----|-----------|
| `justify-content` | главная (→) | двигает вдоль ряда |
| `align-items` | поперечная (↓) | выравнивает поперёк |
| `gap` | — | промежутки между детьми |

**`justify-content`:** `flex-start` (по умолч.) · `center` · `flex-end` · `space-between` · `space-around` · `space-evenly`.

**`align-items`:** `stretch` (по умолч.) · `center` · `flex-start` · `flex-end`.

---

## Главные приёмы

**Шапка «логотип ← → меню»:**
```css
.top { display: flex; justify-content: space-between; align-items: center; }
```

**Меню в ряд:**
```css
.menu { display: flex; gap: 20px; }
```

**Идеальный центр (по гор. и верт.):**
```css
.box { display: flex; justify-content: center; align-items: center; }
```

---

## Частые ошибки

| Ошибка | Как правильно |
|--------|---------------|
| `display:flex` написали ребёнку, а не родителю | flex пишут **контейнеру**, он строит детей |
| `gap` не работает | проверь, что `display:flex` есть у того же элемента |
| путают оси | `justify-content` — вдоль ряда, `align-items` — поперёк |
| меню из `<a>` без `nav` | ссылки меню оборачивай в `<nav>` |
| везде `<div>` | есть смысловой тег — бери его |

---

## Что осталось в голове

- `display: flex` родителю → дети в ряд.
- `justify-content` (вдоль) + `align-items` (поперёк) + `gap` (промежутки).
- Скелет: `header` → `nav` → `main` (`section`/`article`/`aside`) → `footer`.
- `<main>` на странице один.

## ⚡ Emmet

| Набери | Получишь |
|--------|----------|
| `header.top` | `<header class="top"></header>` |
| `nav.menu>a*3` | `<nav class="menu">` с тремя `<a>` |
| `header>.logo+nav>a*3` | шапка: логотип + меню из 3 ссылок |
| `main>section>article*2` | `main` → `section` → две `article` |
| `figure>img+figcaption` | картинка с подписью |

> Точка `.` в Emmet = класс, `>` = вложенность, `*` = повтор, `+` = сосед.

## 🎯 Flexbox — приёмы

**«Включил flex — забыл про margin для рядов».** Вместо `margin-right` у каждого элемента — `gap` у контейнера:
```css
.row { display: flex; gap: 16px; }   /* промежутки только между */
```

**Идеальный центр за 3 строки:**
```css
.center { display: flex; justify-content: center; align-items: center; }
```

**Шапка «логотип ← → меню»:**
```css
.top { display: flex; justify-content: space-between; align-items: center; }
```

**Прижать один элемент к краю** (например, кнопку вправо): дай ему `margin-left: auto` — flex «оттолкнёт» его в конец ряда.
```css
.menu .login { margin-left: auto; }
```

## 🐛 Частые ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| ничего не встало в ряд | `display:flex` написан ребёнку | пиши flex **родителю-контейнеру** |
| `gap` игнорируется | нет `display:flex` на этом же элементе | добавь `display:flex` рядом с `gap` |
| элементы «прилипли» друг к другу | нет `gap` | добавь `gap` контейнеру |
| `justify-content` не двигает по вертикали | это свойство **главной** оси (горизонталь) | по вертикали — `align-items` |
| всё растянулось на всю высоту | `align-items: stretch` по умолчанию | поставь `align-items: center`/`flex-start` |
| меню «съехало» вниз | забыл `align-items:center` | добавь его контейнеру шапки |

## 🧠 Как запомнить оси

- **justify** — думай «**j**» как «ряд» (вдоль главной оси, обычно горизонталь).
- **align** — «выровнять поперёк» (вертикаль, если ряд горизонтальный).
- Промежутки — всегда `gap`.

Если повернуть ось вертикально (`flex-direction: column`), оси **меняются ролями**: `justify-content` станет управлять по вертикали, `align-items` — по горизонтали.

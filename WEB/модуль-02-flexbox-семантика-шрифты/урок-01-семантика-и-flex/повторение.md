# 🔁 Разминка · перед Уроком 1 модуля 2

5 минут в начале занятия. Вспоминаем модуль 1 — он нам сегодня пригодится (теги, классы, подключение CSS). Отвечай, потом проверяй себя в `<details>`.

---

**1.** Как подключить внешний файл `style.css` к странице?
<details><summary>Ответ</summary><code>&lt;link rel="stylesheet" href="style.css"&gt;</code> внутри <code>&lt;head&gt;</code>. Emmet: <code>link:css</code>.</details>

**2.** Чем селектор по тегу (`p { }`) отличается от селектора по классу (`.card { }`)?
<details><summary>Ответ</summary>Селектор по тегу красит <b>все</b> такие теги. Класс — только элементы с <code>class="card"</code>. В CSS класс пишут с точкой, в HTML — без точки.</details>

**3.** Что делают `display: block`, `inline`, `inline-block`?
<details><summary>Ответ</summary><code>block</code> — в столбик, во всю ширину; <code>inline</code> — в строку, как слово; <code>inline-block</code> — в ряд, но можно задать ширину/высоту.</details>

**4.** Как сделать картинку круглой?
<details><summary>Ответ</summary><code>border-radius: 50%</code> (картинка должна быть квадратной).</details>

**5.** Чем `<div>` отличается от `<span>`?
<details><summary>Ответ</summary><code>&lt;div&gt;</code> — блочная коробка (с новой строки). <code>&lt;span&gt;</code> — строчная обёртка для части текста (не разрывает строку).</details>

**6.** Как убрать подчёркивание у ссылки?
<details><summary>Ответ</summary><code>text-decoration: none;</code></details>

**7.** Что добавляет реакцию на наведение мыши?
<details><summary>Ответ</summary>Псевдокласс <code>:hover</code>, например <code>a:hover { color: red; }</code> (без пробела перед двоеточием).</details>

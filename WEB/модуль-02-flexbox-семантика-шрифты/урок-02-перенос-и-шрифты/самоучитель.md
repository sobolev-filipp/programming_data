## Часть A — разбираем вместе

### Шаг 1. Карточки в ряд (повтор)

Из прошлого урока: `display: flex` ставит детей в ряд.

```html
<section class="cards">
    <article class="card">1</article>
    <article class="card">2</article>
    <article class="card">3</article>
    <article class="card">4</article>
    <article class="card">5</article>
    <article class="card">6</article>
</section>
```
```css
.card  { width: 180px; height: 100px; background: #c7d2fe; border-radius: 10px; }
.cards { display: flex; gap: 16px; }
```

👉 Открой и сузь окно. Карточки сжимаются и вылезают — потому что ряд **один**.

### Шаг 2. Разрешаем перенос — flex-wrap

```css
.cards { display: flex; flex-wrap: wrap; gap: 16px; }
```

👉 Теперь карточки, которые не влезли, **спускаются на новую строку**. Получилась сетка. `gap` задаёт отступы и между строками.

### Шаг 3. order — меняем порядок

```css
.card:nth-child(5) { order: -1; }
```

👉 Пятая карточка уехала в начало, хотя в HTML стоит пятой. `order` меняет порядок **на экране**. Пишется **ребёнку**.

### Шаг 4. Подключаем шрифт с Google Fonts

1. Зайди на **fonts.google.com**, выбери шрифт, нажми **Get font → Get embed code**.
2. Вставь `<link>` в `<head>`:
```html
<link href="https://fonts.googleapis.com/css2?family=Montserrat&display=swap" rel="stylesheet">
```
3. Примени в CSS:
```css
body { font-family: "Montserrat", sans-serif; }
```

👉 Весь текст поменялся. Два шага: **подключить** (`<link>`) и **применить** (`font-family`).

### Шаг 5. Насыщенность и курсив

```css
h1       { font-weight: 700; }   /* жирный */
.sub     { font-weight: 300; }   /* тонкий */
.quote   { font-style: italic; } /* курсив */
```

👉 Поиграй значениями `font-weight` от 100 до 900.

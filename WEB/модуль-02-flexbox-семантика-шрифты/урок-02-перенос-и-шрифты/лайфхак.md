## 🎯 Flex-сетка

**Сетка карточек в 3 строки:** просто `flex-wrap: wrap` + ширина карточки. Браузер сам решит, сколько влезет в ряд.
```css
.cards { display: flex; flex-wrap: wrap; gap: 20px; }
.card  { width: 220px; }
```

**Карточки одинаковой ширины, тянутся на всю строку:** добавь карточке `flex: 1 1 220px` (вырастут, заполнив ряд; `220px` — минимум). Полностью разберём `flex` в уроке 3.

**Последний ряд не «растягивать» уродливо:** держи `justify-content: flex-start` или `center` — тогда неполный ряд не разъедется.

**`order: -1`** — моментально вытащить элемент в начало, не трогая HTML.

**`align-content` работает только** когда есть перенос (`wrap`), несколько рядов и запас высоты у контейнера. Если «не действует» — проверь эти три условия.

## 🔤 Шрифты

**Правило 2 шрифтов:** максимум два на страницу — один для заголовков, один для текста. Больше — каша.

**Подключай только нужные начертания.** Каждое (400, 700, курсив) — это вес загрузки. На fonts.google.com выбирай галочками только те, что реально нужны.

**Имя с пробелом — в кавычках:** `"Bebas Neue"`, `"Times New Roman"`.

**Всегда семейство в конце стека:** `"Montserrat", sans-serif` — если шрифт не загрузится, текст не исчезнет.

**Хорошие пары шрифтов** (заголовок + текст): Oswald + Roboto · Bebas Neue + Montserrat · Playfair Display + Source Sans · Montserrat + Merriweather.

## 🐛 Частые ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| карточки сжались в один ряд | нет `flex-wrap: wrap` | добавь контейнеру |
| карточки тянутся во всю ширину | нет `width` у карточки | задай ширину |
| `order` не работает | написан контейнеру | пиши **ребёнку** |
| шрифт не поменялся | забыл `<link>` | подключи в `<head>` |
| «кривой» жирный/курсив | начертание не подключено | выбери его на Google Fonts |
| `align-content` не действует | один ряд или нет высоты | нужен `wrap` + несколько рядов + высота |

---

## ⌨️ Полезное

- На fonts.google.com — кнопка **Get font → Get embed code** даёт готовый `<link>`.
- В VS Code `Alt+Shift+F` — форматирование; `Ctrl+D` — выделить следующее такое же имя класса.
- Проверяй перенос, **сужая окно браузера** мышкой — сразу видно, адаптивна ли сетка.

## Перенос и выравнивание во Flexbox

```css
.cards {
    display: flex;
    flex-wrap: wrap;    /* не влезли — на новую строку (из ряда → сетка) */
    gap: 20px;          /* отступы между карточками И между рядами */
}
```

| Свойство | Где пишут | Что делает |
|----------|-----------|-----------|
| `flex-wrap: wrap` | контейнеру | разрешает перенос на новую строку |
| `align-content` | контейнеру | выравнивает **несколько рядов** по вертикали |
| `align-self` | **ребёнку** | выровнять один элемент иначе, чем все |
| `order` | **ребёнку** | изменить порядок на экране (не трогая HTML) |

> Три «выравнивателя»: `justify-content` — вдоль ряда · `align-items` — один ряд поперёк · `align-content` — несколько рядов вместе.

**`order`:** по умолчанию `0`; меньше — левее, больше — правее. `order: -1` вытаскивает в начало.

## Шрифты

**Задать шрифт:** `font-family`. В конце стека — семейство-страховка:
```css
body { font-family: "Montserrat", sans-serif; }
```
Семейства: `serif` (с засечками), `sans-serif` (рубленый), `monospace` (как код), `cursive` (рукописный).

**Google Fonts (2 шага):**
```html
<!-- 1. подключить в <head> -->
<link href="https://fonts.googleapis.com/css2?family=Montserrat&display=swap" rel="stylesheet">
```
```css
/* 2. применить */
body { font-family: "Montserrat", sans-serif; }
```

**Насыщенность и курсив:**
```css
h1    { font-weight: 700; }   /* жирный; 400 — обычный, 100–900 шаг 100 */
.q    { font-style: italic; } /* курсив; normal — прямой */
```

> Жирный/курсив с Google Fonts нужно **выбрать при подключении**, иначе браузер подделает криво.

## Частые ошибки

| Ошибка | Как правильно |
|--------|---------------|
| карточки сжались в один ряд | добавь `flex-wrap: wrap` контейнеру |
| `order`/`align-self` не работают | их пишут **ребёнку**, не контейнеру |
| путают `align-items` и `align-content` | items — один ряд, content — много рядов |
| шрифт не поменялся | забыл `<link>` (подключить) или кавычки у имени с пробелом |
| «кривой» жирный | начертание 700 не подключено на Google Fonts |
| больше 2 шрифтов на странице | 1 для заголовков + 1 для текста, не больше |

---

## Что осталось в голове

- `flex-wrap: wrap` → ряд превращается в сетку с переносом.
- `order`/`align-self` — ребёнку; `align-content` — контейнеру (для рядов).
- Шрифт: сначала **подключить** (Google Fonts), потом **применить** (`font-family`).

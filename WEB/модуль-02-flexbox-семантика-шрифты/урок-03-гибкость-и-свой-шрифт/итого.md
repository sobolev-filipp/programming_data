## Гибкость во Flexbox (пишут ДЕТЯМ-элементам)

| Свойство | Что делает |
|----------|-----------|
| `flex-grow` | доля свободного места (расти). `1` — делить поровну |
| `flex-shrink` | сжиматься ли при нехватке места. `0` — не сжимать |
| `flex-basis` | базовый размер до растягивания |
| `flex` | короткая запись: `grow shrink basis` |

**Самые частые:**
```css
.col { flex: 1; }          /* равные колонки, делят место поровну */
.col { flex: 1 1 220px; }  /* старт 220px, растут и сжимаются */
.box { flex: 0 0 200px; }  /* жёстко 200px, не менять */
.logo{ flex-shrink: 0; }   /* не сжимать */
```

**Границы размеров:**
```css
.col { flex: 1; min-width: 200px; max-width: 340px; }
```

> 🔥 Адаптивная сетка одной связкой:
> ```css
> .cards { display: flex; flex-wrap: wrap; gap: 20px; }
> .card  { flex: 1 1 220px; }   /* растут; не влезли — переносятся */
> ```

## Свой шрифт — @font-face

```css
@font-face {
    font-family: "MyFont";          /* придумали имя */
    src: url("fonts/game.woff2");    /* путь к файлу */
    font-display: swap;              /* текст виден сразу */
}
h1 { font-family: "MyFont", sans-serif; }   /* применили */
```

- `url("...")` — путь к файлу (как `src` у картинки); встретится ещё (фоны, иконки).
- Лучший формат — `.woff2` (лёгкий).
- `font-display: swap` — текст не «мигает» при загрузке.

---

## Частые ошибки

| Ошибка | Как правильно |
|--------|---------------|
| `flex` написали контейнеру | `flex`/`flex-grow` пишут **детям** |
| колонки раздавились на телефоне | добавь `min-width` + `flex-wrap: wrap` |
| логотип сжимается в тесной шапке | `flex-shrink: 0` |
| свой шрифт не подключился | проверь путь в `url()` и имя в `font-family` |
| взял `.ttf`, грузится долго | используй `.woff2` |

---

## Что осталось в голове

- `flex: 1` — делить место поровну (главный приём).
- `flex-shrink: 0` — не сжимать; `min-width` — не раздавить.
- `@font-face` + `url()` — свой шрифт из файла, потом звать по имени.

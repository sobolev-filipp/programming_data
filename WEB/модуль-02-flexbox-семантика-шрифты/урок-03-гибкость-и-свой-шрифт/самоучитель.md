## Часть A — разбираем вместе

### Шаг 1. Колонки, которые делят место

```html
<section class="cols">
    <div class="col">1</div>
    <div class="col">2</div>
    <div class="col">3</div>
</section>
```
```css
.cols { display: flex; gap: 16px; }
.col  { background: #c7d2fe; padding: 20px; }
```

👉 Сейчас колонки — по содержимому, справа пусто. Добавь каждой `flex: 1`:
```css
.col { flex: 1; }
```
Теперь они делят ширину **поровну**. `flex: 1` = «расти и дели место».

### Шаг 2. Одна колонка шире

```css
.col.big { flex: 2; }
```
👉 Колонка с `flex: 2` забирает вдвое больше свободного места. Так делают «выделенный тариф».

### Шаг 3. Не раздавить на телефоне

```css
.col  { flex: 1; min-width: 200px; }
.cols { display: flex; flex-wrap: wrap; gap: 16px; }
```
👉 Сузь окно: колонки не сожмутся в ленточку, а честно перенесутся. Это **адаптивная сетка**.

### Шаг 4. Не сжимать элемент

```css
.logo { flex-shrink: 0; }
```
👉 В тесной шапке логотип с `flex-shrink: 0` сохранит размер, а сожмётся остальное.

### Шаг 5. Свой шрифт из файла

```css
@font-face {
    font-family: "MyFont";
    src: url("fonts/game.woff2");
    font-display: swap;
}
h1 { font-family: "MyFont", sans-serif; }
```
👉 `@font-face` описывает шрифт (имя + путь к файлу через `url()`), потом зовёшь его по имени. Файл клади в папку `fonts/` рядом с CSS. Лучший формат — `.woff2`.

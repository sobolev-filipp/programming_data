## 🎯 Flex-гибкость

**`flex: 1` — волшебное слово.** Равные колонки, «занять остальное место», растягивание — почти всегда это `flex: 1`.

**Адаптивная сетка одной связкой:**
```css
.cards { display: flex; flex-wrap: wrap; gap: 20px; }
.card  { flex: 1 1 220px; }   /* растут; не влезли — переносятся */
```
Браузер сам решит, сколько карточек в ряд.

**«Распорка» — отодвинуть элемент вправо:** между элементами поставь растяжку `flex: 1` (пустой `<div>`), или элементу дай `margin-left: auto`.

**Сайдбар + контент:**
```css
.sidebar { flex: 0 0 260px; }  /* фиксированная ширина */
.content { flex: 1; }          /* занимает остальное */
```

**Не раздавить колонки:** всегда давай `min-width` вместе с `flex: 1` — иначе на телефоне превратятся в ленточку.

**`flex-shrink: 0`** — «не сжимай» (логотип, иконка, аватар в тесном ряду).

## 🔤 Свой шрифт

**Формат `.woff2`** — самый лёгкий и быстрый. Если шрифт в `.ttf`/`.otf` — конвертируй в `.woff2` (онлайн-конвертеры).

**Путь в `url()` — относительный от CSS-файла.** Если `style.css` в корне, а шрифт в `fonts/`, то `url("fonts/game.woff2")`.

**`font-display: swap`** — всегда добавляй: текст виден сразу, не «мигает» пустотой.

**Имя в `@font-face` придумываешь сам** — оно не обязано совпадать с названием файла. Главное — тем же именем звать в `font-family`.

**Легально и бесплатно:** Google Fonts (можно скачать `.woff2`), шрифты с лицензией SIL/OFL. Не бери платные шрифты без лицензии.

## 🐛 Частые ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| `flex` не работает | написан контейнеру | пиши **ребёнку** |
| колонки-ленточки на телефоне | нет `min-width` | добавь `min-width` + `wrap` |
| логотип сжался | нет `flex-shrink: 0` | задай его логотипу |
| свой шрифт не виден | неверный путь в `url()` | проверь папку и имя файла |
| шрифт грузится вечность | тяжёлый `.ttf` | возьми `.woff2`, лишние начертания убери |
| текст «мигает» при загрузке | нет `font-display` | добавь `font-display: swap` |

# 📌 Итого · Урок 4 — Flex-раскладки на практике

Шпаргалка на 3 минуты. Полный разбор — в [урок.md](урок.md).

---

## Главная идея

Большие макеты = **вложенные флекс-контейнеры**. Разбивай страницу на блоки, каждый блок — свой `display: flex`.

---

## 4 типовых паттерна

**1. Шапка (логотип ← → меню):**
```css
.top  { display: flex; justify-content: space-between; align-items: center; }
.menu { display: flex; gap: 20px; }   /* вложенный flex */
```

**2. Горизонтальная карточка (картинка + текст):**
```css
.card-h { display: flex; gap: 16px; align-items: center; }
.cover  { flex-shrink: 0; }   /* картинку не сжимать */
.body   { flex: 1; }          /* текст занимает остальное */
```

**3. Медиа-объект (аватар + текст) — комментарий, отзыв:**
```css
.comment { display: flex; gap: 12px; }
.avatar  { flex-shrink: 0; border-radius: 50%; }
.text    { flex: 1; }
```

**4. Подвал прижат к низу (sticky footer):**
```css
body { min-height: 100vh; display: flex; flex-direction: column; margin: 0; }
main { flex: 1; }   /* main распирает страницу, footer уходит вниз */
```

---

## Важно про `flex-direction: column`

Оси **меняются ролями**:
- `justify-content` — теперь по **вертикали**;
- `align-items` — теперь по **горизонтали**.

---

## Приёмы

- `margin-left: auto` — оттолкнуть элемент в конец ряда (кнопка справа).
- Вкладывай flex во flex без ограничений — так собирают весь интерфейс.

---

## Частые ошибки

| Ошибка | Как правильно |
|--------|---------------|
| подвал «подскакивает» вверх | `body` в column + `main { flex: 1 }` |
| картинка в карточке сжимается | `flex-shrink: 0` картинке |
| в `column` путают оси | `justify` — вертикаль, `align` — горизонталь |
| всё в одном контейнере | разбей на блоки, каждому свой flex |

---

## Что осталось в голове

- Страница = вложенные flex-блоки.
- 4 паттерна: шапка, горизонтальная карточка, медиа-объект, липкий подвал.
- `column` меняет оси ролями.

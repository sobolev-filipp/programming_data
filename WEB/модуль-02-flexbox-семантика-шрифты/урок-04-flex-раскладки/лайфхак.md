# 🧰 Лайфхаки · Урок 4 — Flex-раскладки

Трюки и частые ошибки. Главное — в [уроке](урок.md).

## 🎯 Приёмы-«заготовки»

**Кнопка/элемент к правому краю:**
```css
.push-right { margin-left: auto; }   /* во flex оттолкнёт в конец ряда */
```

**Идеальный центр на весь экран:**
```css
.hero { min-height: 100vh; display: flex; justify-content: center; align-items: center; }
```

**Липкий подвал (всегда внизу):**
```css
body { min-height: 100vh; display: flex; flex-direction: column; margin: 0; }
main { flex: 1; }
```

**Горизонтальная карточка:** картинке `flex-shrink: 0`, тексту `flex: 1`.

**Равные плитки статистики:** каждой `flex: 1` в `display:flex; gap`.

---

## 🧠 Как думать о макете

1. Посмотри на страницу и **раздели на крупные блоки** (шапка / контент / подвал).
2. Каждый блок, где что-то стоит в ряд или колонку, — это **свой `display: flex`**.
3. Внутри блока снова могут быть flex-ряды — **вкладывай** спокойно.
4. «Большое не сжимается» → `flex-shrink: 0`; «занять остальное» → `flex: 1`.

---

## 🐛 Частые ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| подвал в середине | нет липкого подвала | `body` column + `main{flex:1}` |
| картинка в карточке сплющилась | нет `flex-shrink:0` | добавь картинке |
| в `column` `align-items` не центрирует по вертикали | оси поменялись ролями | в column по вертикали — `justify-content` |
| кнопка не уходит вправо | нет распорки | `margin-left:auto` или пустой `flex:1` |
| «всё в кучу» | один огромный контейнер | разбей на блоки, каждому свой flex |

# 🆘 Самоучитель · Урок 4 — Flex-раскладки на практике

Пропустил урок? Иди по шагам. Соберёшь 4 типовых паттерна и цельную страницу.

> Нужны VS Code + Live Server, `index.html` + `style.css`. Забыл как — [Справочник, «С чего начать»](../../Справочник.md#с-чего-начать).

---

## Часть A — разбираем вместе

### Шаг 1. Паттерн «шапка»
```css
.top  { display: flex; justify-content: space-between; align-items: center; }
.menu { display: flex; gap: 20px; }
```
👉 Логотип слева, меню справа. `.menu` внутри — тоже flex (вложение).

### Шаг 2. Паттерн «горизонтальная карточка»
```html
<article class="card-h">
    <div class="cover"></div>
    <div class="body"><h3>Название</h3><p>Описание</p></div>
</article>
```
```css
.card-h { display: flex; gap: 16px; align-items: center; }
.cover  { flex-shrink: 0; width: 100px; height: 70px; }
.body   { flex: 1; }
```
👉 Обложка держит размер, текст занимает остальное.

### Шаг 3. Паттерн «комментарий» (аватар + текст)
```css
.comment { display: flex; gap: 12px; }
.avatar  { flex-shrink: 0; width: 48px; height: 48px; border-radius: 50%; }
.text    { flex: 1; }
```
👉 Тот же приём: кружок слева не сжимается, текст справа.

### Шаг 4. Подвал к низу
```css
body { min-height: 100vh; display: flex; flex-direction: column; margin: 0; }
main { flex: 1; }
```
👉 `main` распирает страницу — подвал всегда внизу. Это «липкий подвал».

### Шаг 5. Собери страницу
Сложи вместе: `header` (шапка) + `main` (пара горизонтальных карточек) + `footer`. Всё — вложенные flex-блоки.

**Задание 3.** Три комментария (аватар + имя + текст).
<details><summary>💡</summary>Каждый — <code>display:flex; gap</code>; аватар круглый, <code>flex-shrink:0</code>.</details>

<details><summary>💡</summary>В column <code>align-items</code> выравнивает по горизонтали.</details>

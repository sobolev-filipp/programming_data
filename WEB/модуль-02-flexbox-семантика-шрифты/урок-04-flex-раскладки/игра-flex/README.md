# 🪖 Игра-тренажёр «Выстрой отряд» — Flexbox

Офлайн-пародия на Flexbox Froggy (оригинал в РФ без VPN не открывается). Запускается в браузере без интернета.

**Файл:** `игра.html` — открыть через Live Server или двойным кликом (нужен настоящий браузер, не предпросмотр редактора — там нет JS).

## Как устроено
- У поля включён `display: flex`. На поле — две наложенные flex-раскладки: **цель** (пунктирные бойцы, к ней применено правильное решение) и **игрок** (синие бойцы, к ним применяются выбранные свойства).
- Ученик кнопками подбирает `flex-direction`, `justify-content`, `align-items`, `gap` так, чтобы синие бойцы встали на пунктирные места.
- Кнопка «Проверить» засчитывает уровень, когда выбранные значения совпали с нужными. Цель видна наглядно благодаря настоящему flex-рендеру браузера.
- Справа — панель «Как это работает» + шпаргалка значений (как в оригинале).

## 10 уровней (по нарастанию)
1. `justify-content: center` — отряд по центру.
2. `justify-content: flex-end` — к правому краю.
3. `align-items: flex-end` — прижать к низу.
4. `justify + align: center` — идеальный центр.
5. `flex-end + flex-end` — правый нижний угол.
6. `justify-content: space-between` — по краям.
7. `flex-direction: column` — в столбик.
8. `column + align: center` — столбик по центру.
9. `justify-content: space-around` — равные отступы вокруг.
10. `column + flex-end + flex-end` — комбо.

## Когда играть
- После **урока 4** (разобраны все приёмы flex) — как закрепление.
- Как разминка в начале уроков самостоятельной/следующего модуля или домашнее задание.
- Отдельного урочного времени не занимает (разминка/ДЗ).

## Методика
- Поощряй проговаривать: «какая ось главная сейчас? какое свойство её двигает?».
- На уровне 7 подчеркни: при `flex-direction: column` оси **меняются ролями** (это частая путаница).
- Данные уровней проверены скриптом (решения валидны, значения существуют).

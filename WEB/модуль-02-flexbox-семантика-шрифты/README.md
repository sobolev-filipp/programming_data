# Модуль 2 — Flexbox, семантика и шрифты

Второй модуль курса WEB. Здесь страницы перестают быть «столбиком текста»: со старта раскладываем их на смысловые блоки и ставим элементы в ряды и колонки через **Flexbox**, а параллельно подключаем красивые **шрифты**. К концу модуля ученик собирает настоящий многосекционный лендинг.

> ⬅️ [План курса](../ПЛАН-КУРСА.md) · Предыдущий модуль: [Модуль 1 «Старт: HTML + первые стили»](../модуль-01-старт-html-css/README.md) · Следующий: Модуль 3 «Контент: ссылки, списки, таблицы»

## Что нового по сравнению с Модулем 1

- Flexbox — от основ до гибкости (`flex: 1`) и типовых раскладок.
- Семантический каркас страницы вместо «супа из `div`».
- Красивые шрифты: Google Fonts и свой шрифт через `@font-face`.
- Применяем прошлый год (по желанию): логотип и ассеты в Illustrator/Photoshop.

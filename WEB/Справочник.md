## С чего начать: файлы, код и подключение CSS

Это самый важный раздел для старта. Прежде чем что-то верстать, нужно понять три вещи: **где живёт код, как создать файлы и как соединить HTML с CSS**. Разберёмся по шагам — это пригодится на первых уроках модуля 1.

Сначала коротко о главном. Сайт — это обычные **текстовые файлы**, которые открывает браузер. Нам нужны два:
- файл с расширением **`.html`** — это сама страница (её содержание: заголовки, текст, картинки);
- файл с расширением **`.css`** — это оформление (цвета, размеры, отступы).

HTML и CSS — два разных языка: HTML отвечает за то, **что** на странице, а CSS — за то, **как** это выглядит. Их специально разделили, чтобы можно было менять дизайн, не трогая текст.

### Что установить

1. **VS Code** — редактор, в котором пишут код (бесплатный).
2. Расширение **Live Server** (открой вкладку Extensions, найди «Live Server» и нажми Install). Оно показывает твою страницу в браузере и **само обновляет** её каждый раз, когда ты сохраняешь файл — очень удобно.

### Шаг 1. Создаём папку и файлы

1. Создай на компьютере **папку** для проекта (например, `мой-сайт`) и открой её в VS Code через `Файл → Открыть папку`. Всегда работай «папкой» — так редактор видит все файлы проекта сразу.
2. Создай внутри файл **`index.html`** (кнопка «New File» в панели файлов, или `Ctrl+N` и сохранить как `index.html`).
   - Имя `index.html` обычно используют для главной страницы: веб-сервер часто открывает её по умолчанию. Запомни это имя.
3. Создай рядом файл **`style.css`** — сюда будем писать оформление.

> Имя файла пиши **латиницей, без пробелов**, и обязательно с расширением (`.html`, `.css`). Файл `index.html` и `style.css` должны лежать в **одной папке** — иначе они «не найдут» друг друга.

### Шаг 2. Каркас HTML

У каждой HTML-страницы есть обязательный «скелет». Писать его руками каждый раз не нужно — в VS Code набери `!` и нажми **Tab** (это возможность [Emmet](Справочник-теги-и-свойства.md#emmet--быстрый-ввод-кода)), и каркас развернётся сам:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Моя страница</title>
</head>
<body>

</body>
</html>
```

Разберём, что это за строки:
- [`<!DOCTYPE html>`](Справочник-теги-и-свойства.md#doctype) — говорит браузеру «это современный HTML». Всегда первая строка.
- [`<html>`](Справочник-теги-и-свойства.md#html) — обёртка **всей** страницы; `lang="ru"` сообщает, что страница на русском.
- [`<head>`](Справочник-теги-и-свойства.md#head) — «служебная» часть, её **не видно** на странице. Внутри: [`<meta charset="UTF-8">`](Справочник-теги-и-свойства.md#meta) (чтобы русские буквы не превратились в «нечитаемые символы») и [`<title>`](Справочник-теги-и-свойства.md#title) — надпись на вкладке браузера.
- [`<body>`](Справочник-теги-и-свойства.md#body) — «тело» страницы: **всё, что видно** (заголовки, текст, картинки), пишем именно здесь.

`viewport` задаёт ширину области просмотра по ширине устройства; это пригодится при адаптивной вёрстке.

### Шаг 3. Как вставлять код в HTML

Весь видимый контент мы пишем **внутри `<body>`**. Контент собирается из тегов.

**Тег** — это команда в угловых скобках, которая говорит, что это за кусочек страницы. Почти все теги **парные**: есть открывающий и закрывающий (у закрывающего — слеш `/`), а между ними — содержимое:

```html
<p>Текст абзаца</p>
```
Здесь `<p>` открывает абзац, `</p>` его закрывает, а между ними — текст.

Некоторые теги **одиночные** (непарные): у них нет содержимого, поэтому и закрывать нечего. Это [`<br>`](Справочник-теги-и-свойства.md#br) (перенос строки), [`<hr>`](Справочник-теги-и-свойства.md#hr) (линия), [`<img>`](Справочник-теги-и-свойства.md#img) (картинка), [`<meta>`](Справочник-теги-и-свойства.md#meta), [`<link>`](Справочник-теги-и-свойства.md#link).

Теги можно **вкладывать** друг в друга — один внутри другого. Главное правило вложенности: что открыли последним, то закрываем первым (как матрёшка).

```html
<body>
    <h1>Привет!</h1>
    <p>Меня зовут Аня. Я учусь делать сайты.</p>
    <p>Вот моя ссылка: <a href="https://example.ru">мой профиль</a></p>
</body>
```

> Отступы (табы перед тегами) браузеру не важны, но нужны **тебе**: по ним сразу видно, какой тег внутри какого. Привыкай делать отступы — в большом коде без них легко запутаться.

### Шаг 4. Как подключить CSS (три способа)

CSS — это оформление. Соединить его с HTML можно тремя способами. Разберём все три и поймём, какой лучше.

**Способ 1 — inline, прямо в теге** (атрибут `style`). Пишем стиль внутри самого тега. Годится, чтобы быстро проверить одну идею, но «засоряет» HTML и красит **только этот один** тег.
```html
<h1 style="color: red;">Заголовок</h1>
```

**Способ 2 — тег [`<style>`](Справочник-теги-и-свойства.md#style) в `<head>`.** Собираем все стили в одном месте. Один селектор красит **все** такие теги сразу. Минус: работает только на **этой** странице.
```html
<head>
    <style>
        h1 { color: navy; }
        p  { color: gray; }
    </style>
</head>
```

**Способ 3 — внешний файл `style.css` через [`<link>`](Справочник-теги-и-свойства.md#link). Это основной способ для проектов курса.** Стили лежат в отдельном файле, а к HTML его **подключают** одной строкой. Плюс огромный: один `style.css` можно подключить **ко всем страницам** сайта — единый стиль, и HTML остаётся чистым.
```html
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Моя страница</title>
    <link rel="stylesheet" href="style.css">
</head>
```
А в самом файле `style.css` — только правила (без `<style>`):
```css
h1 { color: navy; text-align: center; }
```
Здесь `rel="stylesheet"` значит «подключаемый файл — это таблица стилей», а `href="style.css"` — путь к файлу.

> Быстрый ввод: в `<head>` набери `link:css` и нажми **Tab** — Emmet сам напишет строку `<link>` без опечаток.

### Проверка: всё ли работает

Нажми правой кнопкой по `index.html` → **Open with Live Server**. Откроется браузер с твоей страницей. Теперь меняешь код, сохраняешь (`Ctrl+S`) — и страница сама обновляется. Так ты сразу видишь результат.

**Стили не применились?** Самые частые причины: файл `style.css` лежит **не рядом** с `index.html`, или в `href` **опечатка** в имени файла. Имя должно совпадать буква-в-букву (и заглавные/строчные тоже важны).

## Урок 1. Первая страница: текст и заголовки

[Полный урок](модуль-01-старт-html-css/урок-01-первая-страница/урок.md) · [Практика](модуль-01-старт-html-css/урок-01-первая-страница/практика.md) · [Краткое повторение](модуль-01-старт-html-css/урок-01-первая-страница/итого.md)

Текст — основа любой страницы. Но текст бывает разный: большой главный заголовок, подзаголовки разделов, обычные абзацы. Чтобы браузер (и человек, и поисковик) понимал, что из этого важнее, текст размечают специальными тегами. Как создать саму страницу и её каркас — смотри раздел [«С чего начать»](#с-чего-начать-файлы-код-и-подключение-css).

**Заголовки [`<h1>`–`<h6>`](Справочник-теги-и-свойства.md#h1h6).** Это шесть «уровней важности». [`<h1>`](Справочник-теги-и-свойства.md#h1h6) — самый главный заголовок, название всей страницы; в проектах курса используем один главный заголовок. `<h2>` — заголовки больших разделов, `<h3>` — подразделы внутри них, и так до `<h6>`. Думай о них как об оглавлении книги: глава, параграф, пункт. Важно: заголовок выбирают **по смыслу** (насколько он главный), а не потому, что хочется текст покрупнее — размер потом задаст CSS.

**Абзац [`<p>`](Справочник-теги-и-свойства.md#p).** В него оборачивают обычный текст. Каждый абзац — с новой строки, между ними браузер сам делает небольшой отступ. Одна мысль — один абзац.

**Перенос и линия.** [`<br>`](Справочник-теги-и-свойства.md#br) — перенос строки **внутри** абзаца (например, в адресе), [`<hr>`](Справочник-теги-и-свойства.md#hr) — горизонтальная линия, отделяющая один блок от другого.

**Выделения.** [`<strong>`](Справочник-теги-и-свойства.md#strong-em) делает текст важным (жирным), [`<em>`](Справочник-теги-и-свойства.md#strong-em) — акцентным (курсивом). Они выделяют именно **по смыслу**.

**Общий пример:**
```html
<h1>Мой любимый фильм</h1>
<h2>Космос 2049</h2>
<p>Это <strong>лучший</strong> фантастический фильм, что я видел.</p>
<hr>
<p>Жанр: фантастика<br>Год: 2049<br>Режиссёр: А. Иванов</p>
```
Здесь один главный заголовок, один подзаголовок, абзац с важным словом, линия-разделитель и абзац, где строки разбиты через `<br>`.



**Emmet:** `!` создаёт каркас, `h1+p` — соседние элементы, `p*3` — три абзаца, `p{Привет}` — абзац с текстом. Набери сокращение и нажми Tab в HTML-файле.

## Урок 2. Подключаем CSS и селекторы

[Полный урок](модуль-01-старт-html-css/урок-02-подключаем-css/урок.md) · [Практика](модуль-01-старт-html-css/урок-02-подключаем-css/практика.md) · [Краткое повторение](модуль-01-старт-html-css/урок-02-подключаем-css/итого.md)

Как подключить CSS тремя способами — подробно разобрано в разделе [«С чего начать»](#с-чего-начать-файлы-код-и-подключение-css). Здесь поговорим про **селекторы** — это, пожалуй, самая важная идея CSS.

Любое правило CSS выглядит так: `селектор { свойство: значение; }`. **Селектор** — это ответ на вопрос «**кого** красим?». От того, какой селектор выбрать, зависит, на какие элементы подействует стиль. Видов селекторов несколько, и важно понимать разницу между ними.

**1. По тегу.** Пишем просто имя тега — и правило применится ко **всем** таким элементам на странице.
```css
p { color: gray; }      /* абсолютно все абзацы станут серыми */
```
Удобно, когда надо оформить всё сразу (все абзацы, все заголовки). Но что, если один абзац нужно выделить, а остальные оставить? Тег так не умеет — он красит всех одинаково. Для этого есть класс.

**2. По классу.** Мы **даём элементу имя** (класс) и красим по имени. В HTML имя пишут в атрибуте `class` (без точки), а в CSS — с **точкой** впереди.
```html
<p class="hit">Это важный абзац</p>
<p>А это обычный</p>
```
```css
.hit { color: crimson; font-weight: bold; }
```
Покрасится только абзац с `class="hit"`. Класс можно повесить на **сколько угодно** элементов и даже на разные теги — все они получат этот стиль. Классы — главный инструмент: на реальных сайтах почти всё оформляют именно через них.

**3. По `id`.** Похоже на класс, но `id` даётся **одному, уникальному** элементу (на странице такой id — один). В HTML — `id="имя"`, в CSS — с **решёткой** `#имя`.
```css
#header { background: navy; }
```
Классы гибче (их много), `id` берут для чего-то единственного. Ещё `id` нужен для якорей-ссылок (о них — в модуле 3).

**4. Группировка (запятая).** Если одно правило нужно сразу нескольким селекторам — перечисли их через запятую.
```css
h1, h2, .hit { text-align: center; }   /* по центру: и h1, и h2, и всё с классом hit */
```

**5. Вложенный селектор (пробел).** Пробел между именами значит «**внутри**». Так красят элементы только внутри определённого блока.
```css
.gallery img { border-radius: 8px; }   /* только картинки ВНУТРИ .gallery */
```

**6. Несколько классов на одном элементе.** В HTML через пробел можно указать сразу два класса: один задаёт общее, другой — отличие.
```html
<div class="card c1">...</div>   <!-- возьмёт стиль и .card, и .c1 -->
```

> Самая частая путаница: **где ставить точку**. Точка у класса — **только в CSS** (`.hit`). В HTML пишем `class="hit"`, **без** точки.

Хочешь закрепить селекторы в игре — открой тренажёр `модуль-01-старт-html-css/игра-селекторы/игра.html`.

## Урок 3. Картинки

[Полный урок](модуль-01-старт-html-css/урок-03-картинки/урок.md) · [Практика](модуль-01-старт-html-css/урок-03-картинки/практика.md) · [Краткое повторение](модуль-01-старт-html-css/урок-03-картинки/итого.md)

Картинки делают страницу живой. Вставляет их одиночный тег [`<img>`](Справочник-теги-и-свойства.md#img). Главное, что надо понять: `<img>` **не хранит** картинку внутри себя — он только показывает **путь** к файлу (атрибут `src`). Браузер идёт по этому пути, находит файл и рисует его. Поэтому если напутать в пути — вместо картинки будет «сломанный» значок.

Что указываем у картинки:
- `src` — **путь к файлу**. Если картинка лежит рядом с HTML — просто имя: `кот.jpg`. Если в папке `images` — `images/кот.jpg`.
- `alt` — **текст-замена**: что показать/прочитать, если картинка не загрузилась. Его же читают программы для незрячих. Пиши коротко, что на картинке.
- Размер задаём обычно **только по ширине** (`width`) — высота тогда подстроится сама, и фото не сплющится. Если задать и ширину, и высоту «наугад», картинка исказится.

Несколько приёмов:
- Картинку можно сделать **ссылкой** — положить `<img>` внутрь [`<a>`](Справочник-теги-и-свойства.md#a).
- Круглую аватарку делают через [`border-radius: 50%`](Справочник-теги-и-свойства.md#border-radius) (картинка при этом должна быть квадратной, иначе получится овал).

**Общий пример:**
```html
<a href="https://example.ru">
    <img src="images/кот.jpg" alt="Рыжий кот спит на диване" width="200">
</a>
```
```css
img { border-radius: 12px; border: 3px solid gold; }   /* скругление + рамка */
```

### Контейнеры div и span

`div` группирует блоки, `span` выделяет часть строки. Например, `<div class="gallery"><img src="images/cat.jpg" alt="Кот"></div>` позволяет оформить все картинки через `.gallery img`, а `<p>Цена: <span class="price">500 ₽</span></p>` — только цену. Контейнеры сами по себе не задают смысл содержимого; семантические теги появятся в модуле 2.

## Урок 4. Цвет и display

[Полный урок](модуль-01-старт-html-css/урок-04-цвет/урок.md) · [Практика](модуль-01-старт-html-css/урок-04-цвет/практика.md) · [Краткое повторение](модуль-01-старт-html-css/урок-04-цвет/итого.md)

### Цвет

Цвет — первое, что оживляет страницу. Его задают у [`color`](Справочник-теги-и-свойства.md#color) (цвет **текста**), [`background-color`](Справочник-теги-и-свойства.md#background-color) (цвет **фона**), в рамках, тенях. Один и тот же цвет можно записать разными способами — компьютеру всё равно, а тебе удобно выбрать подходящий (подробная таблица — [форматы цвета](Справочник-теги-и-свойства.md#форматы-цвета)):

- **Имя** — `red`, `gold`, `teal`. Есть около 140 готовых названий. Быстро для наброска.
- **HEX** — `#ff5722`. Решётка и 6 символов: по паре на красный, зелёный и синий. Удобно копировать из палитр.
- **RGB** — `rgb(255, 87, 34)`. Три числа 0–255: сколько красного, зелёного и синего света смешать.
- **RGBA** — `rgba(0, 0, 0, 0.5)`. То же плюс четвёртое число — **прозрачность** (alpha) от 0 до 1. `0.5` — полупрозрачный.
- **HSL** — `hsl(14, 100%, 57%)`. Тон (цвет на радуге, 0–360), насыщенность и светлота в процентах. Удобно подбирать оттенки: крутишь светлоту — получаешь тот же цвет светлее/темнее.

Чтобы цвета **сочетались**, дизайнеры используют цветовой круг (сервис get-color.ru) и правило **60-30-10**: 60% — основной цвет, 30% — дополнительный, 10% — яркий акцент (например, кнопка). Так палитра выглядит цельно, а не «попугайно».

**Общий пример (тёмная карточка):**
```css
body  { background-color: #1a1a2e; }                 /* тёмный фон страницы */
h1    { color: gold; text-align: center; }           /* золотой заголовок */
p     { color: #e0e0e0; }                            /* светло-серый текст */
.note { color: rgba(255, 255, 255, 0.6); }           /* полупрозрачная подпись */
```

### display: блоки в ряд

По умолчанию блоки (`<div>`, `<p>`, заголовки) встают **друг под другом**, в столбик. А часто нужно поставить их **в ряд** — например, карточки товаров. За поведение элемента отвечает свойство [`display`](Справочник-теги-и-свойства.md#display).

Главные значения:
- `block` — блок с новой строки, во всю ширину (так по умолчанию ведут себя [`<div>`](Справочник-теги-и-свойства.md#div), `<p>`, `<h1>`). Ему можно задавать ширину, высоту, отступы.
- `inline` — строчный, стоит в строке как слово (так ведут себя [`<span>`](Справочник-теги-и-свойства.md#span), `<a>`). обычные строчные элементы не подчиняются `width` и `height` (изображения — исключение).
- `inline-block` — «золотая середина»: стоит **в ряд**, но при этом слушается ширины, высоты и отступов. Именно это нужно, чтобы выстроить карточки в линию.
- `flex` — включает Flexbox: дети встают в ряд, и ими легко управлять (выровнять, задать промежуток `gap`). Пока используем как готовый «рецепт», подробно — в отдельном модуле.

**Общий пример (карточки в ряд):**
```html
<div class="card">A</div>
<div class="card">B</div>
<div class="card">C</div>
```
```css
.card {
    display: inline-block;   /* карточки встают в линию, а не в столбик */
    width: 150px;
    padding: 20px;
    background: #eee;
    border-radius: 12px;
}
```

### Современные форматы цвета

`oklch(65% 0.18 250)` задаёт светлоту, насыщенность цвета (chroma) и тон. Этот формат удобен для построения палитр с близкой воспринимаемой светлотой. `color-mix(in oklch, #2563eb 80%, white)` смешивает основной цвет с белым. Для прозрачности можно использовать `rgb(0 0 0 / 50%)` или `hsl(220 80% 50% / 0.5)`. Свойство `opacity: 0.5` делает прозрачным весь элемент вместе с детьми, а альфа-канал цвета — только конкретный цвет.

## Урок 5. Текст, размеры и кнопки

[Полный урок](модуль-01-старт-html-css/урок-05-текст-и-размеры/урок.md) · [Практика](модуль-01-старт-html-css/урок-05-текст-и-размеры/практика.md) · [Краткое повторение](модуль-01-старт-html-css/урок-05-текст-и-размеры/итого.md)

### Текст и размеры

Текст можно не только написать, но и красиво оформить — размер, толщину, интервалы. За это отвечают «шрифтовые» свойства:

- [`font-size`](Справочник-теги-и-свойства.md#font-size) — размер букв (в начале курса — в пикселях `px`). `16px` — комфортный основной текст, меньше 12–14px читать трудно.
- [`font-weight`](Справочник-теги-и-свойства.md#font-weight) — толщина: `normal` (обычный), `bold` (жирный) или число `100`–`900` (чем больше, тем толще).
- [`font-style`](Справочник-теги-и-свойства.md#font-style) — `normal` (прямой) или `italic` (курсив).
- [`line-height`](Справочник-теги-и-свойства.md#line-height) — межстрочный интервал. Число-множитель `1.5` делает текст «воздушным» и читаемым.
- [`letter-spacing`](Справочник-теги-и-свойства.md#letter-spacing) — расстояние между буквами (небольшое увеличение делает заголовок аккуратнее).
- [`text-align`](Справочник-теги-и-свойства.md#text-align) — выравнивание (`left`/`center`/`right`), [`text-transform`](Справочник-теги-и-свойства.md#text-transform) — регистр (`uppercase` — всё заглавными), [`text-shadow`](Справочник-теги-и-свойства.md#text-shadow) — тень текста.

Про размеры: `px` — жёсткий фиксированный размер (`40px` — 40 CSS-пикселей). `%` — доля от родителя, удобно для «резиновой» ширины (`width: 100%` — во всю ширину родителя).

**Общий пример (заголовок афиши):**
```css
h1 {
    font-size: 40px;
    font-weight: 800;              /* очень жирный */
    letter-spacing: 3px;           /* буквы раздвинуты */
    text-transform: uppercase;      /* ВСЕ ЗАГЛАВНЫЕ */
    text-shadow: 2px 2px 8px rgba(0,0,0,0.4);
}
```

### Кнопки

Кнопка — это призыв к действию («Купить», «Отправить»). Есть два варианта. Тег [`<button>`](Справочник-теги-и-свойства.md#button) — настоящая кнопка (действие ей добавят позже на JavaScript). А если по клику надо **перейти на другую страницу**, делают **ссылку-кнопку**: берут обычную ссылку `<a>` и оформляют её классом так, чтобы она выглядела как кнопка.

Чтобы кнопка «реагировала» на наведение мыши, добавляют псевдокласс `:hover` — правило, которое срабатывает, когда курсор наведён.

**Общий пример:**
```html
<a href="prices.html" class="btn">Купить</a>
```
```css
.btn {
    display: inline-block;         /* чтобы ссылка вела себя как блок-кнопка */
    background: #e63946;
    color: white;
    padding: 12px 24px;            /* «подушка» внутри — кнопка становится крупнее */
    border-radius: 10px;
    text-decoration: none;         /* убрать подчёркивание у ссылки */
}
.btn:hover { background: #c22f3c; }   /* при наведении — чуть темнее */
```

## Урок 1. Семантика и первый Flexbox

[Полный урок](модуль-02-flexbox-семантика-шрифты/урок-01-семантика-и-flex/урок.md) · [Практика](модуль-02-flexbox-семантика-шрифты/урок-01-семантика-и-flex/практика.md) · [Краткое повторение](модуль-02-flexbox-семантика-шрифты/урок-01-семантика-и-flex/итого.md)

Можно собрать всю страницу из одних [`<div>`](Справочник-теги-и-свойства.md#div) — браузер поймёт. Но получится «суп из div»: по коду не ясно, где шапка, где меню, где подвал. Чтобы было понятнее, придумали **семантические** теги — коробки с понятным смыслом. Внешне они как `<div>` (тоже блоки-контейнеры), но их название сразу говорит, **что** внутри. Это удобнее тебе, а ещё помогает поисковикам и программам для незрячих.

Главные «зоны» страницы:
- [`<header>`](Справочник-теги-и-свойства.md#header-nav-main-footer) — **шапка** (логотип, название, часто меню);
- [`<nav>`](Справочник-теги-и-свойства.md#header-nav-main-footer) — блок **навигации** (ссылки-меню);
- [`<main>`](Справочник-теги-и-свойства.md#header-nav-main-footer) — **основное** содержимое (одно на странице);
- [`<footer>`](Справочник-теги-и-свойства.md#header-nav-main-footer) — **подвал** (контакты, копирайт).

Блоки внутри: [`<section>`, `<article>`, `<aside>`](Справочник-теги-и-свойства.md#section-article-aside) — смысловой раздел, самостоятельный кусок (пост, карточка товара) и дополнительная/боковая информация. А [`<figure>` и `<figcaption>`](Справочник-теги-и-свойства.md#figure-figcaption) — это картинка с подписью.

**Общий пример (каркас страницы):**
```html
<header><h1>Мой блог</h1></header>
<nav><a href="#">Главная</a> <a href="#">Посты</a></nav>
<main>
    <article>
        <h2>Первый пост</h2>
        <p>Текст поста…</p>
    </article>
</main>
<footer>© 2026, Аня</footer>
```

### Как работает Flexbox

Flexbox управляет расположением непосредственных дочерних элементов. Свойство `display: flex` ставят родителю, а не каждой карточке. Если внутри карточки нужно расположить картинку и текст рядом, сама карточка может стать ещё одним flex-контейнером.

| Свойство контейнера | Что делает | Значения |
|---|---|---|
| `display` | Включает Flexbox | `flex` |
| `flex-direction` | Направление главной оси | `row`, `column`, `row-reverse`, `column-reverse` |
| `justify-content` | Распределяет свободное место вдоль главной оси | `flex-start`, `center`, `flex-end`, `space-between`, `space-around`, `space-evenly` |
| `align-items` | Выравнивает элементы поперёк главной оси | `stretch`, `flex-start`, `center`, `flex-end`, `baseline` |
| `gap` | Промежуток между соседними элементами | `16px`, `12px 24px` |

При `row` главная ось горизонтальная, поперечная — вертикальная. При `column` главная ось вертикальная. Поэтому `justify-content: center` не всегда означает горизонтальное центрирование. Чтобы выравнивание было заметно, в контейнере должно быть свободное место.

```html
<header class="top">
    <h1>Game Club</h1>
    <nav class="menu">
        <a href="index.html">Главная</a>
        <a href="games.html">Игры</a>
    </nav>
</header>
```
```css
.top {
    display: flex;
    justify-content: space-between;
    align-items: center;
    gap: 20px;
}
.menu { display: flex; gap: 16px; }
```
Здесь два контейнера: `.top` распределяет заголовок и меню, `.menu` располагает ссылки. `gap` не создаёт отступ от края контейнера — для этого нужен `padding`.

**Проверь себя:** поменяй `flex-direction` у `.top` на `column` и объясни, почему изменилось направление выравнивания. В DevTools можно включить подсветку flex-контейнера.

## Урок 2. Перенос, выравнивание и шрифты

[Полный урок](модуль-02-flexbox-семантика-шрифты/урок-02-перенос-и-шрифты/урок.md) · [Практика](модуль-02-flexbox-семантика-шрифты/урок-02-перенос-и-шрифты/практика.md) · [Краткое повторение](модуль-02-flexbox-семантика-шрифты/урок-02-перенос-и-шрифты/итого.md)

Когда карточек много, они не обязаны помещаться в одну строку. По умолчанию `flex-wrap: nowrap`: контейнер пытается удержать всех детей в одном ряду. `flex-wrap: wrap` разрешает перенос, а `wrap-reverse` меняет направление укладки рядов.

```css
.gallery {
    display: flex;
    flex-wrap: wrap;
    gap: 16px;
    align-items: center;
}
.gallery .card { width: 200px; }
```
Если ширины не хватает, карточка переходит на следующую строку. Это не Grid: каждый ряд Flexbox распределяет пространство самостоятельно.

### Выравнивание рядов и отдельных элементов

- `align-content` распределяет несколько flex-рядов по поперечной оси. Нужны перенос и свободное место по этой оси; на единственном ряду свойство не действует.
- `align-self` переопределяет `align-items` для одного ребёнка, например `align-self: flex-end`.
- `order` меняет визуальный порядок: по умолчанию у всех `0`, меньшие числа идут раньше. Порядок в HTML и переход клавишей Tab не меняются, поэтому не используй `order` для исправления смыслового порядка страницы.

```css
.gallery { height: 500px; align-content: space-between; }
.featured { order: -1; align-self: flex-start; }
```

### Шрифты и запасные варианты

Шрифт сильно меняет настроение страницы. Стандартных шрифтов в системе мало, поэтому красивые **подключают** — двумя способами.

**Способ 1 — Google Fonts.** Это огромная бесплатная библиотека шрифтов. На сайте fonts.google.com выбираешь шрифт (обязательно включи фильтр **Cyrillic**, иначе русские буквы могут не поддерживаться), копируешь готовую строку `<link>` в `<head>` и пишешь имя шрифта в [`font-family`](Справочник-теги-и-свойства.md#font-family):
```html
<link href="https://fonts.googleapis.com/css2?family=Montserrat&display=swap" rel="stylesheet">
```
```css
body { font-family: "Montserrat", Arial, sans-serif; }
```

Шрифтовой стек читается слева направо. Если Montserrat не загрузился или не содержит нужной буквы, браузер попробует следующий вариант. Проверь, что выбранный шрифт поддерживает кириллицу. Для жирного текста подключай нужные начертания, а не только обычное.

```html
<link href="https://fonts.googleapis.com/css2?family=Montserrat:wght@400;700&display=swap" rel="stylesheet">
```
```css
body { font-family: "Montserrat", Arial, sans-serif; font-weight: 400; }
h1 { font-weight: 700; }
.note { font-style: italic; }
```
`font-weight` отвечает за насыщенность, `font-style` — за курсив. Если интернет недоступен, запасной шрифт сохранит читаемость. Локальное подключение разбирается в следующем уроке.

## Урок 3. Гибкие размеры и свой шрифт

[Полный урок](модуль-02-flexbox-семантика-шрифты/урок-03-гибкость-и-свой-шрифт/урок.md) · [Практика](модуль-02-flexbox-семантика-шрифты/урок-03-гибкость-и-свой-шрифт/практика.md) · [Краткое повторение](модуль-02-flexbox-семантика-шрифты/урок-03-гибкость-и-свой-шрифт/итого.md)

Flexbox умеет не только расставлять блоки, но и распределять между ними свободное место. Для этого есть три свойства, которые задают дочерним элементам.

| Свойство | Смысл | Пример |
|---|---|---|
| `flex-grow` | Доля свободного места, которую получит элемент | `1`, `2` |
| `flex-shrink` | Возможность уменьшаться при нехватке места | `1`, `0` |
| `flex-basis` | Начальный размер вдоль главной оси | `200px`, `auto`, `0` |

Если два элемента имеют одинаковую начальную ширину и `flex-grow: 1` и `2`, второй получит вдвое больше именно **свободного места**, а не обязательно будет вдвое шире первого. `flex-shrink: 0` запрещает сжатие, что полезно для аватара. При сжатии учитывается и исходный размер элемента.

```css
.row { display: flex; gap: 20px; }
.left { flex: 1 1 200px; }
.right { flex: 2 1 200px; }
```
Короткая запись `flex: grow shrink basis` объединяет три свойства. `flex: 1` обычно означает `1 1 0%`: элементы делят место с нулевой начальной базой. Для равных карточек учитывай также их содержимое и минимальные размеры.

### Ограничения ширины

`min-width` задаёт нижнюю границу, `max-width` — верхнюю. Например, контейнер шириной `100%` и `max-width: 1000px` не растянется на весь большой экран. `min-width: 0` у гибкого текстового блока помогает ему сжиматься, когда длинное содержимое мешает раскладке.

```css
.wrapper { width: 100%; max-width: 1000px; margin: 0 auto; }
.card { flex: 1 1 220px; min-width: 0; }
```

### Подключение своего шрифта

**Способ 2 — свой шрифт из файла.** Если у тебя есть файл шрифта, его подключают через правило [`@font-face`](Справочник-теги-и-свойства.md#font-face). Сначала «объявляем» шрифт — даём имя и указываем путь к файлу через `url()`, — а потом пользуемся этим именем:
```css
@font-face {
    font-family: "MyFont";                          /* придуманное имя */
    src: url("fonts/myfont.woff2") format("woff2");  /* путь к файлу */
}
h1 { font-family: "MyFont", sans-serif; }            /* пользуемся по имени */
```

Важные детали:
- `url("...")` — это «путь к файлу» внутри CSS (работает как `src` у картинки, только для шрифта).
- `font-family` всегда пишут **стеком** — несколько шрифтов через запятую. Браузер берёт первый, а если его нет — следующий. Последним ставят `sans-serif` (без засечек) или `serif` (с засечками) как запасной вариант.

Добавь `font-display: swap`, чтобы текст оставался видимым во время загрузки. Для разных начертаний объявляй отдельные правила с тем же именем семейства и соответствующим `font-weight`.

```css
@font-face {
    font-family: "Club";
    src: url("fonts/club-regular.woff2") format("woff2");
    font-weight: 400;
    font-style: normal;
    font-display: swap;
}
body { font-family: "Club", Arial, sans-serif; }
```
Путь в `url()` отсчитывается от файла CSS, а не от HTML. Если CSS находится в `css/style.css`, а шрифт в `fonts/`, путь будет `../fonts/club-regular.woff2`. Используй шрифты с лицензией, разрешающей размещение на сайте.




<a id="м2-урок-4"></a>

## Урок 4. Flex-раскладки на практике

[Полный урок](модуль-02-flexbox-семантика-шрифты/урок-04-flex-раскладки/урок.md) · [Практика](модуль-02-flexbox-семантика-шрифты/урок-04-flex-раскладки/практика.md) · [Краткое повторение](модуль-02-flexbox-семантика-шрифты/урок-04-flex-раскладки/итого.md)

Большинство страниц можно собрать из нескольких повторяющихся раскладок. В каждой сначала определяем родителя и его непосредственных детей, затем выбираем ось и способ выравнивания.

### 1. Шапка сайта

```css
.top { display: flex; justify-content: space-between; align-items: center; gap: 20px; }
.menu { display: flex; gap: 16px; flex-wrap: wrap; }
```
Логотип и меню расходятся к краям, ссылки внутри меню образуют отдельный ряд.

### 2. Горизонтальная карточка

```html
<article class="card-h">
    <img class="cover" src="images/game.jpg" alt="Обложка игры">
    <div class="info"><h2>Космический рейс</h2><p>Приключение на далёкой планете.</p></div>
</article>
```
```css
.card-h { display: flex; align-items: center; gap: 16px; }
.cover { width: 120px; flex-shrink: 0; }
.info { flex: 1; min-width: 0; }
```
Картинка сохраняет ширину, а текст занимает оставшееся место. Если убрать `flex-shrink: 0`, при узком контейнере изображение может стать меньше.

### 3. Медиа-объект: аватар и текст

```css
.comment { display: flex; align-items: flex-start; gap: 12px; }
.avatar { width: 64px; height: 64px; border-radius: 50%; flex-shrink: 0; }
.comment-text { flex: 1; min-width: 0; }
```
В отличие от карточки, здесь обычно выравниваем аватар по верхнему краю текста, а не по центру. Такой паттерн подходит для комментариев и профилей.

### 4. Подвал у нижнего края окна

```css
body {
    margin: 0;
    min-height: 100vh;
    display: flex;
    flex-direction: column;
}
main { flex: 1; }
```
`100vh` — высота области просмотра браузера; здесь используем как готовый приём из урока, подробно единицы разбираются в модуле 12. `main` растёт и занимает свободное место, поэтому подвал находится внизу короткой страницы. При длинном содержимом подвал остаётся после него, а не перекрывает текст.

### Сборка страницы профиля

В шапке профиля размести аватар, ник и кнопку. Статистику собери из равных плиток, достижения — из карточек с переносом. Например:

```css
.stats, .achievements { display: flex; flex-wrap: wrap; gap: 16px; }
.stat { flex: 1 1 140px; }
.achievement { flex: 1 1 180px; }
```
Проверь страницу при уменьшении окна: плитки должны переноситься, аватар не должен сжиматься, а подвал не должен закрывать содержимое. Для закрепления открой [тренажёр Flexbox](модуль-02-flexbox-семантика-шрифты/урок-04-flex-раскладки/игра-flex/игра.html).

# Модуль 3 — Контент: ссылки, списки, таблицы

[Карта модуля](модуль-03-контент/README.md)

<a id="м3-урок-1"></a>

## Урок 1. Ссылки и якоря

[Полный урок](модуль-03-контент/урок-01-ссылки/урок.md) · [Практика](модуль-03-контент/урок-01-ссылки/практика.md) · [Краткое повторение](модуль-03-контент/урок-01-ссылки/итого.md)

Ссылки связывают страницы между собой и позволяют переходить по сайту. Делает ссылку тег [`<a>`](Справочник-теги-и-свойства.md#a), а главный атрибут `href` говорит, **куда** вести. Текст между `<a>` и `</a>` — то, на что кликают.

Куда может вести ссылка:
- на **другой сайт**: `href="https://..."` (можно добавить `target="_blank"` — откроется в новой вкладке, не уходя с твоей страницы);
- на **другую страницу** твоего сайта: `href="about.html"`;
- **письмо**: `href="mailto:me@mail.ru"` — откроет почтовую программу;
- **звонок** (на телефоне): `href="tel:+7999..."`.

**Якорь** — это переход к нужному разделу **на той же самой странице** (как «перемотать» вниз к блоку «Контакты»). Работает в два шага: нужному разделу дают `id`, а в ссылке пишут этот id с решёткой.

**Общий пример (меню-якоря):**
```html
<nav>
    <a href="#about">Обо мне</a>
    <a href="#contacts">Контакты</a>
</nav>

<section id="about">...здесь про меня...</section>
<section id="contacts">...здесь контакты...</section>
```
Клик по «Контакты» прокрутит страницу к разделу с `id="contacts"`.

### Состояния ссылки и меню

```css
nav { display: flex; gap: 20px; }
a:link { color: #2458b8; }
a:visited { color: #6943a0; }
a:hover { color: #d04b28; }
a:active { color: #a32d14; }
a:focus { outline: 2px solid #2458b8; }
```
Порядок `:link`, `:visited`, `:hover`, `:active` помогает избежать конфликтов одинаковой специфичности. `:active` действует во время нажатия, а не означает текущую страницу. Для новой вкладки можно явно указать `rel="noopener"` вместе с `target="_blank"`. Не используй `href="#"` вместо настоящего адреса в готовом сайте: он ведёт к началу страницы.

Для перехода в другую папку используй относительный путь: `pages/about.html`, а для возврата на уровень выше — `../index.html`. Якорь другой страницы: `about.html#contacts`.

## Урок 2. Списки

[Полный урок](модуль-03-контент/урок-02-списки/урок.md) · [Практика](модуль-03-контент/урок-02-списки/практика.md) · [Краткое повторение](модуль-03-контент/урок-02-списки/итого.md)

Список — это перечень пунктов. Два главных вида:
- [`<ul>`](Справочник-теги-и-свойства.md#ul) — **маркированный** (перед пунктами точки). Нужен, когда порядок не важен (список покупок, фишки товара).
- [`<ol>`](Справочник-теги-и-свойства.md#ol) — **нумерованный** (1, 2, 3). Нужен, когда порядок важен (шаги инструкции, рейтинг).

Внутри и того, и другого — пункты [`<li>`](Справочник-теги-и-свойства.md#li). В пункт можно положить что угодно: текст, ссылку, картинку.

Вид маркера (или его отсутствие) задаёт CSS-свойство [`list-style-type`](Справочник-теги-и-свойства.md#list-style-type). Самый частый приём — `none`: он **убирает** маркеры, и из списка получается аккуратное **меню** (особенно вместе с `display: flex`, чтобы пункты встали в ряд).

**Общий пример (меню из списка):**
```html
<nav>
  <ul>
    <li><a href="#">Главная</a></li>
    <li><a href="#">О нас</a></li>
    <li><a href="#">Контакты</a></li>
  </ul>
</nav>
```
```css
nav ul { list-style-type: none; display: flex; gap: 20px; }
```
Здесь мы убрали точки и поставили пункты в ряд с промежутком 20px — получилось горизонтальное меню.

### Вложенные списки и словарь

```html
<ol start="3">
    <li>Игры
        <ul><li>Гонки</li><li>Стратегии</li></ul>
    </li>
    <li>Фильмы</li>
</ol>
<dl>
    <dt>HTML</dt><dd>Язык разметки страницы.</dd>
    <dt>CSS</dt><dd>Язык оформления страницы.</dd>
</dl>
```
Вложенный список помещают внутрь `li`, а не между пунктами. `start` задаёт начальный номер `ol`, `reversed` — обратный порядок. `dl` предназначен для пар термин–описание, а не для обычного меню. `list-style-type` принимает `disc`, `circle`, `square`, `decimal`, `lower-roman`, `none`; `list-style-position` управляет положением маркера. У меню часто сбрасывают стандартные `margin` и `padding` списка.

## Урок 3. Таблицы

[Полный урок](модуль-03-контент/урок-03-таблицы/урок.md) · [Практика](модуль-03-контент/урок-03-таблицы/практика.md) · [Краткое повторение](модуль-03-контент/урок-03-таблицы/итого.md)

Таблица нужна, когда данные удобно показать «по строкам и столбцам»: расписание, таблица рекордов, сравнение товаров. Собирается она из нескольких тегов:
- [`<table>`](Справочник-теги-и-свойства.md#table) — вся таблица (обёртка).
- [`<tr>`](Справочник-теги-и-свойства.md#tr) — строка таблицы; внутри неё идут ячейки.
- [`<th>`](Справочник-теги-и-свойства.md#th-td) — ячейка-**заголовок** (жирная, по центру), [`<td>`](Справочник-теги-и-свойства.md#th-td) — обычная ячейка с данными.
- [`<thead>` и `<tbody>`](Справочник-теги-и-свойства.md#thead-tbody) — «шапка» (строка заголовков) и «тело» (строки с данными). Помогают и читать код, и стилизовать.

Полезное:
- `colspan="2"` — растянуть ячейку на 2 столбца, `rowspan="2"` — на 2 строки.
- [`border-collapse: collapse`](Справочник-теги-и-свойства.md#border-collapse) — часто используемый приём для аккуратного вида: он убирает двойные линии между ячейками, сливая их в одну.

**Общий пример:**
```html
<table>
  <thead>
    <tr><th>День</th><th>Урок</th></tr>
  </thead>
  <tbody>
    <tr><td>Пн</td><td>Математика</td></tr>
    <tr><td>Вт</td><td>История</td></tr>
  </tbody>
</table>
```
```css
table  { border-collapse: collapse; }         /* линии ячеек сливаются в одну */
th, td { border: 1px solid #ccc; padding: 8px 14px; }
```

### Подпись, объединение и оформление строк

```html
<table>
    <caption>Результаты турнира</caption>
    <thead><tr><th scope="col">Игрок</th><th scope="col">Очки</th></tr></thead>
    <tbody>
        <tr><td>Луна</td><td>120</td></tr>
        <tr><td>Марс</td><td>95</td></tr>
        <tr><td colspan="2">Турнир завершён</td></tr>
    </tbody>
</table>
```
`caption` — название таблицы; `scope="col"` показывает, что заголовок относится к столбцу. При `colspan="2"` одна ячейка занимает два столбца, поэтому вторую ячейку в этой строке не добавляем. При `rowspan="2"` соответствующее место в следующей строке уже занято.

```css
table { width: 100%; border-collapse: collapse; }
th, td { border: 1px solid #ccc; padding: 10px; }
thead { background: #243b63; color: white; }
tbody tr:nth-child(even) { background: #edf2f8; }
tbody tr:hover { background: #dce8ff; }
```
`nth-child(even)` выбирает чётные строки; подробно селектор изучается в модуле 7. Таблицу используем для данных, не для расположения всей страницы. Не назначай `display: flex` строкам таблицы: это нарушит обычное выравнивание столбцов.

# Модуль 4 — Блочная модель и оформление блоков

[Карта модуля](модуль-04-блоки/README.md)

<a id="м4-урок-1"></a>

## Урок 1. Блочная модель

[Полный урок](модуль-04-блоки/урок-01-блочная-модель/урок.md) · [Практика](модуль-04-блоки/урок-01-блочная-модель/практика.md) · [Краткое повторение](модуль-04-блоки/урок-01-блочная-модель/итого.md)

Это главная идея всей вёрстки: **каждый элемент на странице — прямоугольная коробка.** И у этой коробки есть четыре «слоя», считая изнутри наружу: содержимое → [`padding`](Справочник-теги-и-свойства.md#padding) (внутренний отступ) → [`border`](Справочник-теги-и-свойства.md#border) (рамка) → [`margin`](Справочник-теги-и-свойства.md#margin) (внешний отступ). Поняв эту «коробку», ты поймёшь, как управлять расстояниями на странице.

- **`padding`** — «воздух» **внутри** коробки, между рамкой и содержимым. Как поролон внутри коробки, чтобы вещь не упиралась в стенки. Увеличивает «подушку» вокруг текста.
- **`margin`** — расстояние **снаружи**, между коробками. Раздвигает блоки друг от друга. Особый приём: `margin: 0 auto` центрирует блок по горизонтали.
- **`box-sizing: border-box`** — важная настройка. По умолчанию, если задать блоку `width: 200px` и добавить padding и border, блок станет **шире** 200px (padding и border прибавляются сверху) — и вёрстка «распухает». Значение [`border-box`](Справочник-теги-и-свойства.md#box-sizing) это чинит: тогда padding и border входят внутрь заданной ширины. Поэтому его почти всегда включают сразу для всех элементов.

**Общий пример (карточка):**
```css
* { box-sizing: border-box; }      /* чтобы ширина не распухала — для всех элементов */

.card {
    width: 260px;
    padding: 20px;                  /* воздух внутри */
    margin: 16px auto;              /* отступ снаружи + по центру */
    border: 1px solid #ddd;
}
```

### Как считать размеры и отступы

При `content-box` ширина `200px`, padding `20px` с каждой стороны и border `2px` с каждой стороны дают внешнюю ширину рамки 244px. При `border-box` те же настройки дают 200px, а содержимое занимает 156px. `margin` не входит ни в одну из этих ширин.

Короткая запись отступов: одно значение — все стороны; два — верх/низ и лево/право; три — верх, лево/право, низ; четыре — верх, право, низ, лево (по часовой стрелке). Например, `padding: 10px 20px 30px 40px`.

Вертикальные margin соседних обычных блоков могут схлопываться: два положительных отступа 20px и 30px дают 30px, а не 50px. В flex-контейнере отступы flex-элементов не схлопываются. Для промежутков между карточками удобнее `gap`.

В DevTools выбери элемент через Inspect и открой Computed: схема Box Model покажет фактические размеры содержимого, padding, border и margin. Так проще найти причину лишнего пространства.


<a id="м4-урок-2"></a>

## Урок 2. Границы, скругления и outline

[Полный урок](модуль-04-блоки/урок-02-границы-скругления/урок.md) · [Практика](модуль-04-блоки/урок-02-границы-скругления/практика.md) · [Краткое повторение](модуль-04-блоки/урок-02-границы-скругления/итого.md)

- [`border`](Справочник-теги-и-свойства.md#border) — **рамка**. Значение задаёт три вещи сразу: толщину, стиль и цвет (`2px solid #333`). Стили линии: `solid` (сплошная), `dashed` (штрихи), `dotted` (точки), `double` (двойная).
- [`border-radius`](Справочник-теги-и-свойства.md#border-radius) — **скругление углов**. `16px` — мягкие углы; `50%` на квадратном элементе — идеальный круг (так делают аватарки); очень большое значение `999px` — форма «таблетки» с полукруглыми торцами (частая форма кнопок и бейджей).
- [`outline`](Справочник-теги-и-свойства.md#outline) — **контур снаружи рамки** и главный новый герой урока. Выглядит как `border`, но с принципиальным отличием: `outline` **не занимает места** и **не сдвигает** соседние элементы — он просто рисуется поверх. Поэтому им удобно показывать, что элемент активен (`:focus`): обводка появляется, а вёрстка при этом не «прыгает». Изменение толщины `border` может изменить размеры блока или доступное место внутри него.

**Вложенное скругление.** Если скруглённый блок лежит внутри другого скруглённого (например, картинка-обложка в скруглённой карточке), внутренний радиус делают по формуле: **внешний радиус − padding**. Тогда уголки получаются «параллельными» и смотрятся аккуратно.

**Общий пример:**
```css
.card     { border: 2px solid #333; border-radius: 16px; padding: 10px; }
.card img { border-radius: 6px; }                /* 16 − 10 = 6, уголки параллельны */
button:focus { outline: 3px solid dodgerblue; outline-offset: 2px; }
```

### Форма углов и фокус

`border-radius: 20px 0 20px 0` задаёт углы по часовой стрелке, начиная с верхнего левого. Можно получить форму капли, например `border-radius: 50% 50% 50% 0`. Для вложенных скруглений учитывай также толщину рамки: внутренний радиус примерно равен внешнему минус расстояние между краями; отрицательное значение заменяй нулём.

`outline-offset: 4px` отодвигает контур от рамки. Контур не участвует в расчёте размеров, но может перекрывать соседние элементы. Не убирай фокус у кнопок и ссылок без замены: пользователю клавиатуры нужно видеть, какой элемент выбран.

## Урок 3. Картинки в блоках, тени и фоны

[Полный урок](модуль-04-блоки/урок-03-картинки-тени-фоны/урок.md) · [Практика](модуль-04-блоки/урок-03-картинки-тени-фоны/практика.md) · [Краткое повторение](модуль-04-блоки/урок-03-картинки-тени-фоны/итого.md)

Когда картинка живёт внутри блока-карточки, появляются новые приёмы, чтобы всё выглядело ровно и красиво.

- [`object-fit: cover`](Справочник-теги-и-свойства.md#object-fit) — решает проблему «сплющенных» фото. Если картинке задать и ширину, и высоту (чтобы все обложки были одинаковыми), обычно она искажается. `cover` вписывает картинку в заданный размер **без искажения**, заполняя блок и обрезая лишнее по краям.
- [`aspect-ratio`](Справочник-теги-и-свойства.md#aspect-ratio) — задаёт блоку **пропорции** (`16 / 9` — широкий экран, `1 / 1` — квадрат). Тогда достаточно указать только ширину, а высоту браузер посчитает сам, держа форму. Очень удобно для резиновых обложек.
- [`box-shadow`](Справочник-теги-и-свойства.md#box-shadow) — **тень блока**, делает карточку «приподнятой». Цвет тени бери полупрозрачным (`rgba(...,0.15)`) — так мягче и естественнее.
- **Фоны:** [`background-image`](Справочник-теги-и-свойства.md#background-image) ставит фоновую картинку, а управляют ею [`background-size`](Справочник-теги-и-свойства.md#background-size) (`cover` — заполнить, `contain` — вместить целиком), [`background-position`](Справочник-теги-и-свойства.md#background-position) (где разместить, например `center`) и [`background-repeat`](Справочник-теги-и-свойства.md#background-repeat) (`no-repeat` — не повторять).

**Общий пример (карточка с обложкой):**
```css
.cover {
    width: 100%;
    aspect-ratio: 16 / 9;      /* держим форму широкого экрана */
    object-fit: cover;          /* заполнить, лишнее обрезать */
    border-radius: 12px;
}
.card { box-shadow: 0 8px 20px rgba(0,0,0,0.15); }      /* мягкая тень */
.hero { background: url("fon.jpg") center / cover no-repeat; }
```

### Другие режимы изображения

`object-fit: contain` показывает изображение целиком, оставляя свободное место; `fill` растягивает его и может исказить; `none` сохраняет исходный размер; `scale-down` выбирает меньший результат из `none` и `contain`. `object-position: center top` помогает сохранить важную часть кадра при обрезке.

```html
<picture>
    <source media="(max-width: 600px)" srcset="images/poster-small.jpg">
    <img src="images/poster.jpg" alt="Афиша фильма">
</picture>
<figure>
    <img src="images/scene.jpg" alt="Космическая станция">
    <figcaption>Кадр из фильма</figcaption>
</figure>
```
`picture` выбирает подходящий источник, но внутри обязательно оставляем `img` с запасным файлом и `alt`. Условия `media` подробно изучаются в модуле 12. Фоновое изображение не имеет `alt`, поэтому важную по смыслу картинку вставляй через `img`.

### Тени и область фона

`box-shadow: 0 8px 20px 2px rgba(0,0,0,0.2)` — смещение по X, смещение по Y, размытие, расширение и цвет. `inset` делает тень внутренней. Несколько теней разделяются запятыми. `background-clip: border-box` красит до внешнего края рамки, `padding-box` — до внутреннего края рамки, `content-box` — только содержимое. Для градиентного текста есть `text`.

## Урок 4. Градиенты и карточки

[Полный урок](модуль-04-блоки/урок-04-градиенты/урок.md) · [Практика](модуль-04-блоки/урок-04-градиенты/практика.md) · [Краткое повторение](модуль-04-блоки/урок-04-градиенты/итого.md)

Градиент — это плавный переход между цветами (а не один сплошной цвет). Пишется как значение фона. Градиенты обожают за выразительное оформление: ими делают модные баннеры, кнопки, обложки.

- [`linear-gradient()`](Справочник-теги-и-свойства.md#linear-gradient) — переход **по прямой**. Первым указывают направление (`to right` — слева направо, `180deg` — сверху вниз, `135deg` — по диагонали), затем цвета через запятую (минимум два, можно больше).
- [`radial-gradient()`](Справочник-теги-и-свойства.md#radial-gradient) — переход **кругом из центра** (как блик или свет лампы).
- [`conic-gradient()`](Справочник-теги-и-свойства.md#conic-gradient) — переход **по кругу**, как стрелка часов (для диаграмм-«пирогов» и радужных колец).
- **Градиент к тексту** — красивая фишка: градиент-фон виден только сквозь буквы. Делается через [`background-clip: text`](Справочник-теги-и-свойства.md#background-clip) и прозрачный текст (`color: transparent`).
- **Матовое стекло** (стекломорфизм) — [`backdrop-filter: blur()`](Справочник-теги-и-свойства.md#backdrop-filter) на полупрозрачной плашке: фон за ней становится размытым, как за матовым стеклом.

**Общий пример:**
```css
.banner { background: linear-gradient(135deg, #2965f1, #7c3aed); }   /* диагональ */

.grad-text {
    background: linear-gradient(90deg, #f093fb, #f5576c);
    -webkit-background-clip: text;
    background-clip: text;
    color: transparent;            /* буквы прозрачны — виден градиент */
}
```

### Градиентная рамка

Один из способов — два фоновых слоя и прозрачная рамка. Первый слой ограничиваем внутренней областью, второй — всей областью до внешнего края рамки.

```css
.card {
    border: 3px solid transparent;
    border-radius: 18px;
    background: linear-gradient(#172033, #172033) padding-box,
                linear-gradient(135deg, #38bdf8, #a855f7) border-box;
    color: white;
    padding: 20px;
}
```
Первый фон закрывает середину, второй виден в прозрачной рамке. Порядок слоёв важен: первый рисуется сверху.

### Стеклянная карточка

```css
.glass {
    background: rgba(255, 255, 255, 0.15);
    backdrop-filter: blur(12px);
    border: 1px solid rgba(255, 255, 255, 0.4);
    border-radius: 18px;
    padding: 20px;
}
```
Размытие видно только тогда, когда за карточкой есть фон с деталями и сама карточка полупрозрачна. Не путай `backdrop-filter` с размытием самого текста. Проверяй контраст: декоративный эффект не должен мешать чтению.

## Если что-то не работает

| Проблема | Что проверить |
|---|---|
| CSS не применяется | Путь в `link`, сохранение файла, правильность селектора и фигурных скобок |
| Картинка не видна | `src`, расширение и регистр имени файла |
| Flexbox не работает | `display: flex` задан родителю нужных элементов |
| Карточки не переносятся | `flex-wrap: wrap`, ширина и минимальный размер карточек |
| Шрифт не загрузился | Путь к файлу, имя семейства, доступность сети и поддержка кириллицы |
| Якорь не работает | `href="#имя"` совпадает с уникальным `id="имя"` |
| Блок шире ожидаемого | `box-sizing`, padding, border, margin |
| Фото растянулось | Пропорции и `object-fit` |

Открой DevTools (F12 или Inspect), выбери проблемный элемент и проверь вкладки Styles и Computed. Меняй по одному свойству, чтобы понимать причину результата.

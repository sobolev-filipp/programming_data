## С чего начать: файлы, код и подключение CSS

Это самый важный раздел для старта. Прежде чем что-то верстать, нужно понять три вещи: **где живёт код, как создать файлы и как соединить HTML с CSS**. Разберёмся по шагам — это пригодится на первых уроках модуля 1.

Сначала коротко о главном. Сайт — это обычные **текстовые файлы**, которые открывает браузер. Нам нужны два:
- файл с расширением **`.html`** — это сама страница (её содержание: заголовки, текст, картинки);
- файл с расширением **`.css`** — это оформление (цвета, размеры, отступы).

HTML и CSS — два разных языка: HTML отвечает за то, **что** на странице, а CSS — за то, **как** это выглядит. Их специально разделили, чтобы можно было менять дизайн, не трогая текст.

### Что установить

1. **VS Code** — редактор, в котором пишут код (бесплатный).
2. Расширение **Live Server** (открой вкладку Extensions, найди «Live Server» и нажми Install). Оно показывает твою страницу в браузере и **само обновляет** её каждый раз, когда ты сохраняешь файл — очень удобно.

### Шаг 1. Создаём папку и файлы

1. Создай на компьютере **папку** для проекта (например, `мой-сайт`) и открой её в VS Code через `Файл → Открыть папку`. Всегда работай «папкой» — так редактор видит все файлы проекта сразу.
2. Создай внутри файл **`index.html`** (кнопка «New File» в панели файлов, или `Ctrl+N` и сохранить как `index.html`).
   - Имя `index.html` — особенное: это **главная** страница сайта, браузер открывает её первой. Запомни это имя.
3. Создай рядом файл **`style.css`** — сюда будем писать оформление.

> ⚠️ Имя файла пиши **латиницей, без пробелов**, и обязательно с расширением (`.html`, `.css`). Файл `index.html` и `style.css` должны лежать в **одной папке** — иначе они «не найдут» друг друга.

### Шаг 2. Каркас HTML

У каждой HTML-страницы есть обязательный «скелет». Писать его руками каждый раз не нужно — в VS Code набери `!` и нажми **Tab** (это волшебство [Emmet](Справочник-теги-и-свойства.md#emmet--быстрый-ввод-кода)), и каркас развернётся сам:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Моя страница</title>
</head>
<body>

</body>
</html>
```

Разберём, что это за строки:
- [`<!DOCTYPE html>`](Справочник-теги-и-свойства.md#doctype) — говорит браузеру «это современный HTML». Всегда первая строка.
- [`<html>`](Справочник-теги-и-свойства.md#html) — обёртка **всей** страницы; `lang="ru"` сообщает, что страница на русском.
- [`<head>`](Справочник-теги-и-свойства.md#head) — «служебная» часть, её **не видно** на странице. Внутри: [`<meta charset="UTF-8">`](Справочник-теги-и-свойства.md#meta) (чтобы русские буквы не превратились в «кракозябры») и [`<title>`](Справочник-теги-и-свойства.md#title) — надпись на вкладке браузера.
- [`<body>`](Справочник-теги-и-свойства.md#body) — «тело» страницы: **всё, что видно** (заголовки, текст, картинки), пишем именно здесь.

### Шаг 3. Как вставлять код в HTML

Весь видимый контент мы пишем **внутри `<body>`**. Контент собирается из тегов.

**Тег** — это команда в угловых скобках, которая говорит, что это за кусочек страницы. Почти все теги **парные**: есть открывающий и закрывающий (у закрывающего — слеш `/`), а между ними — содержимое:

```html
<p>Текст абзаца</p>
```
Здесь `<p>` открывает абзац, `</p>` его закрывает, а между ними — текст.

Некоторые теги **одиночные** (непарные): у них нет содержимого, поэтому и закрывать нечего. Это [`<br>`](Справочник-теги-и-свойства.md#br) (перенос строки), [`<hr>`](Справочник-теги-и-свойства.md#hr) (линия), [`<img>`](Справочник-теги-и-свойства.md#img) (картинка), [`<meta>`](Справочник-теги-и-свойства.md#meta), [`<link>`](Справочник-теги-и-свойства.md#link).

Теги можно **вкладывать** друг в друга — один внутри другого. Главное правило вложенности: что открыли последним, то закрываем первым (как матрёшка).

```html
<body>
    <h1>Привет!</h1>
    <p>Меня зовут Аня. Я учусь делать сайты.</p>
    <p>Вот моя ссылка: <a href="https://example.ru">мой профиль</a></p>
</body>
```

> Отступы (табы перед тегами) браузеру не важны, но нужны **тебе**: по ним сразу видно, какой тег внутри какого. Привыкай делать отступы — в большом коде без них легко запутаться.

### Шаг 4. Как подключить CSS (три способа)

CSS — это оформление. Соединить его с HTML можно тремя способами. Разберём все три и поймём, какой лучше.

**Способ 1 — inline, прямо в теге** (атрибут `style`). Пишем стиль внутри самого тега. Годится, чтобы быстро проверить одну идею, но «засоряет» HTML и красит **только этот один** тег.
```html
<h1 style="color: red;">Заголовок</h1>
```

**Способ 2 — тег [`<style>`](Справочник-теги-и-свойства.md#style) в `<head>`.** Собираем все стили в одном месте. Один селектор красит **все** такие теги сразу. Минус: работает только на **этой** странице.
```html
<head>
    <style>
        h1 { color: navy; }
        p  { color: gray; }
    </style>
</head>
```

**Способ 3 — внешний файл `style.css` через [`<link>`](Справочник-теги-и-свойства.md#link). Это самый правильный способ.** Стили лежат в отдельном файле, а к HTML его **подключают** одной строкой. Плюс огромный: один `style.css` можно подключить **ко всем страницам** сайта — единый стиль, и HTML остаётся чистым.
```html
<head>
    <meta charset="UTF-8">
    <title>Моя страница</title>
    <link rel="stylesheet" href="style.css">
</head>
```
А в самом файле `style.css` — только правила (без `<style>`):
```css
h1 { color: navy; text-align: center; }
```
Здесь `rel="stylesheet"` значит «подключаемый файл — это таблица стилей», а `href="style.css"` — путь к файлу.

> Быстрый ввод: в `<head>` набери `link:css` и нажми **Tab** — Emmet сам напишет строку `<link>` без опечаток.

### Проверка: всё ли работает

Нажми правой кнопкой по `index.html` → **Open with Live Server**. Откроется браузер с твоей страницей. Теперь меняешь код, сохраняешь (`Ctrl+S`) — и страница сама обновляется. Так ты сразу видишь результат.

⚠️ **Стили не применились?** Самые частые причины: файл `style.css` лежит **не рядом** с `index.html`, или в `href` **опечатка** в имени файла. Имя должно совпадать буква-в-букву (и заглавные/строчные тоже важны).

# Модуль 1 — Старт: HTML и первые стили

## Урок 1. Первая страница: текст и заголовки

Текст — основа любой страницы. Но текст бывает разный: большой главный заголовок, подзаголовки разделов, обычные абзацы. Чтобы браузер (и человек, и поисковик) понимал, что из этого важнее, текст размечают специальными тегами. Как создать саму страницу и её каркас — смотри раздел [«С чего начать»](#с-чего-начать-файлы-код-и-подключение-css).

**Заголовки [`<h1>`–`<h6>`](Справочник-теги-и-свойства.md#h1h6).** Это шесть «уровней важности». [`<h1>`](Справочник-теги-и-свойства.md#h1h6) — самый главный заголовок, название всей страницы; он должен быть **один**. `<h2>` — заголовки больших разделов, `<h3>` — подразделы внутри них, и так до `<h6>`. Думай о них как об оглавлении книги: глава, параграф, пункт. Важно: заголовок выбирают **по смыслу** (насколько он главный), а не потому, что хочется текст покрупнее — размер потом задаст CSS.

**Абзац [`<p>`](Справочник-теги-и-свойства.md#p).** В него оборачивают обычный текст. Каждый абзац — с новой строки, между ними браузер сам делает небольшой отступ. Одна мысль — один абзац.

**Перенос и линия.** [`<br>`](Справочник-теги-и-свойства.md#br) — перенос строки **внутри** абзаца (например, в адресе), [`<hr>`](Справочник-теги-и-свойства.md#hr) — горизонтальная линия, отделяющая один блок от другого.

**Выделения.** [`<strong>`](Справочник-теги-и-свойства.md#strong-em) делает текст важным (жирным), [`<em>`](Справочник-теги-и-свойства.md#strong-em) — акцентным (курсивом). Они выделяют именно **по смыслу**.

**Общий пример:**
```html
<h1>Мой любимый фильм</h1>
<h2>Космос 2049</h2>
<p>Это <strong>лучший</strong> фантастический фильм, что я видел.</p>
<hr>
<p>Жанр: фантастика<br>Год: 2049<br>Режиссёр: А. Иванов</p>
```
Здесь один главный заголовок, один подзаголовок, абзац с важным словом, линия-разделитель и абзац, где строки разбиты через `<br>`.

## Урок 2. Подключаем CSS и селекторы

Как подключить CSS тремя способами — подробно разобрано в разделе [«С чего начать»](#с-чего-начать-файлы-код-и-подключение-css). Здесь поговорим про **селекторы** — это, пожалуй, самая важная идея CSS.

Любое правило CSS выглядит так: `селектор { свойство: значение; }`. **Селектор** — это ответ на вопрос «**кого** красим?». От того, какой селектор выбрать, зависит, на какие элементы подействует стиль. Видов селекторов несколько, и важно понимать разницу между ними.

**1. По тегу.** Пишем просто имя тега — и правило применится ко **всем** таким элементам на странице.
```css
p { color: gray; }      /* абсолютно все абзацы станут серыми */
```
Удобно, когда надо оформить всё сразу (все абзацы, все заголовки). Но что, если один абзац нужно выделить, а остальные оставить? Тег так не умеет — он красит всех одинаково. Для этого есть класс.

**2. По классу.** Мы **даём элементу имя** (класс) и красим по имени. В HTML имя пишут в атрибуте `class` (без точки), а в CSS — с **точкой** впереди.
```html
<p class="hit">Это важный абзац</p>
<p>А это обычный</p>
```
```css
.hit { color: crimson; font-weight: bold; }
```
Покрасится только абзац с `class="hit"`. Класс можно повесить на **сколько угодно** элементов и даже на разные теги — все они получат этот стиль. Классы — главный инструмент: на реальных сайтах почти всё оформляют именно через них.

**3. По `id`.** Похоже на класс, но `id` даётся **одному, уникальному** элементу (на странице такой id — один). В HTML — `id="имя"`, в CSS — с **решёткой** `#имя`.
```css
#header { background: navy; }
```
Классы гибче (их много), `id` берут для чего-то единственного. Ещё `id` нужен для якорей-ссылок (о них — в модуле 2).

**4. Группировка (запятая).** Если одно правило нужно сразу нескольким селекторам — перечисли их через запятую.
```css
h1, h2, .hit { text-align: center; }   /* по центру: и h1, и h2, и всё с классом hit */
```

**5. Вложенный селектор (пробел).** Пробел между именами значит «**внутри**». Так красят элементы только внутри определённого блока.
```css
.gallery img { border-radius: 8px; }   /* только картинки ВНУТРИ .gallery */
```

**6. Несколько классов на одном элементе.** В HTML через пробел можно указать сразу два класса: один задаёт общее, другой — отличие.
```html
<div class="card c1">...</div>   <!-- возьмёт стиль и .card, и .c1 -->
```

> ⚠️ Самая частая путаница: **где ставить точку**. Точка у класса — **только в CSS** (`.hit`). В HTML пишем `class="hit"`, **без** точки.

Хочешь закрепить селекторы в игре — открой тренажёр `модуль-01-старт-html-css/игра-селекторы/игра.html`.

## Урок 3. Картинки

Картинки делают страницу живой. Вставляет их одиночный тег [`<img>`](Справочник-теги-и-свойства.md#img). Главное, что надо понять: `<img>` **не хранит** картинку внутри себя — он только показывает **путь** к файлу (атрибут `src`). Браузер идёт по этому пути, находит файл и рисует его. Поэтому если напутать в пути — вместо картинки будет «сломанный» значок.

Что указываем у картинки:
- `src` — **путь к файлу**. Если картинка лежит рядом с HTML — просто имя: `кот.jpg`. Если в папке `images` — `images/кот.jpg`.
- `alt` — **текст-замена**: что показать/прочитать, если картинка не загрузилась. Его же читают программы для незрячих. Пиши коротко, что на картинке.
- Размер задаём обычно **только по ширине** (`width`) — высота тогда подстроится сама, и фото не сплющится. Если задать и ширину, и высоту «наугад», картинка исказится.

Несколько приёмов:
- Картинку можно сделать **ссылкой** — положить `<img>` внутрь [`<a>`](Справочник-теги-и-свойства.md#a).
- Круглую аватарку делают через [`border-radius: 50%`](Справочник-теги-и-свойства.md#border-radius) (картинка при этом должна быть квадратной, иначе получится овал).

**Общий пример:**
```html
<a href="https://example.ru">
    <img src="images/кот.jpg" alt="Рыжий кот спит на диване" width="200">
</a>
```
```css
img { border-radius: 12px; border: 3px solid gold; }   /* скругление + рамка */
```

## Урок 4. Цвет и display

### Цвет

Цвет — первое, что оживляет страницу. Его задают у [`color`](Справочник-теги-и-свойства.md#color) (цвет **текста**), [`background-color`](Справочник-теги-и-свойства.md#background-color) (цвет **фона**), в рамках, тенях. Один и тот же цвет можно записать разными способами — компьютеру всё равно, а тебе удобно выбрать подходящий (подробная таблица — [форматы цвета](Справочник-теги-и-свойства.md#форматы-цвета)):

- **Имя** — `red`, `gold`, `teal`. Есть около 140 готовых названий. Быстро для наброска.
- **HEX** — `#ff5722`. Решётка и 6 символов: по паре на красный, зелёный и синий. Удобно копировать из палитр.
- **RGB** — `rgb(255, 87, 34)`. Три числа 0–255: сколько красного, зелёного и синего света смешать.
- **RGBA** — `rgba(0, 0, 0, 0.5)`. То же плюс четвёртое число — **прозрачность** (alpha) от 0 до 1. `0.5` — полупрозрачный.
- **HSL** — `hsl(14, 100%, 57%)`. Тон (цвет на радуге, 0–360), насыщенность и светлота в процентах. Удобно подбирать оттенки: крутишь светлоту — получаешь тот же цвет светлее/темнее.

Чтобы цвета **сочетались**, дизайнеры используют цветовой круг (сервис get-color.ru) и правило **60-30-10**: 60% — основной цвет, 30% — дополнительный, 10% — яркий акцент (например, кнопка). Так палитра выглядит цельно, а не «попугайно».

**Общий пример (тёмная карточка):**
```css
body  { background-color: #1a1a2e; }                 /* тёмный фон страницы */
h1    { color: gold; text-align: center; }           /* золотой заголовок */
p     { color: #e0e0e0; }                            /* светло-серый текст */
.note { color: rgba(255, 255, 255, 0.6); }           /* полупрозрачная подпись */
```

### display: блоки в ряд

По умолчанию блоки (`<div>`, `<p>`, заголовки) встают **друг под другом**, в столбик. А часто нужно поставить их **в ряд** — например, карточки товаров. За поведение элемента отвечает свойство [`display`](Справочник-теги-и-свойства.md#display).

Главные значения:
- `block` — блок с новой строки, во всю ширину (так по умолчанию ведут себя [`<div>`](Справочник-теги-и-свойства.md#div), `<p>`, `<h1>`). Ему можно задавать ширину, высоту, отступы.
- `inline` — строчный, стоит в строке как слово (так ведут себя [`<span>`](Справочник-теги-и-свойства.md#span), `<a>`). Ширину и высоту задать **нельзя**.
- `inline-block` — «золотая середина»: стоит **в ряд**, но при этом слушается ширины, высоты и отступов. Именно это нужно, чтобы выстроить карточки в линию.
- `flex` — включает Flexbox: дети встают в ряд, и ими легко управлять (выровнять, задать промежуток `gap`). Пока используем как готовый «рецепт», подробно — в отдельном модуле.

**Общий пример (карточки в ряд):**
```html
<div class="card">A</div>
<div class="card">B</div>
<div class="card">C</div>
```
```css
.card {
    display: inline-block;   /* карточки встают в линию, а не в столбик */
    width: 150px;
    padding: 20px;
    background: #eee;
    border-radius: 12px;
}
```

## Урок 5. Текст, размеры и кнопки

### Текст и размеры

Текст можно не только написать, но и красиво оформить — размер, толщину, интервалы. За это отвечают «шрифтовые» свойства:

- [`font-size`](Справочник-теги-и-свойства.md#font-size) — размер букв (в начале курса — в пикселях `px`). `16px` — комфортный основной текст, меньше 12–14px читать трудно.
- [`font-weight`](Справочник-теги-и-свойства.md#font-weight) — толщина: `normal` (обычный), `bold` (жирный) или число `100`–`900` (чем больше, тем толще).
- [`font-style`](Справочник-теги-и-свойства.md#font-style) — `normal` (прямой) или `italic` (курсив).
- [`line-height`](Справочник-теги-и-свойства.md#line-height) — межстрочный интервал. Число-множитель `1.5` делает текст «воздушным» и читаемым.
- [`letter-spacing`](Справочник-теги-и-свойства.md#letter-spacing) — расстояние между буквами (небольшое увеличение делает заголовок аккуратнее).
- [`text-align`](Справочник-теги-и-свойства.md#text-align) — выравнивание (`left`/`center`/`right`), [`text-transform`](Справочник-теги-и-свойства.md#text-transform) — регистр (`uppercase` — всё заглавными), [`text-shadow`](Справочник-теги-и-свойства.md#text-shadow) — тень текста.

Про размеры: `px` — жёсткий фиксированный размер (`40px` всегда 40 пикселей). `%` — доля от родителя, удобно для «резиновой» ширины (`width: 100%` — во всю ширину родителя).

**Общий пример (заголовок афиши):**
```css
h1 {
    font-size: 40px;
    font-weight: 800;              /* очень жирный */
    letter-spacing: 3px;           /* буквы раздвинуты */
    text-transform: uppercase;      /* ВСЕ ЗАГЛАВНЫЕ */
    text-shadow: 2px 2px 8px rgba(0,0,0,0.4);
}
```

### Кнопки

Кнопка — это призыв к действию («Купить», «Отправить»). Есть два варианта. Тег [`<button>`](Справочник-теги-и-свойства.md#button) — настоящая кнопка (действие ей добавят позже на JavaScript). А если по клику надо **перейти на другую страницу**, делают **ссылку-кнопку**: берут обычную ссылку `<a>` и оформляют её классом так, чтобы она выглядела как кнопка.

Чтобы кнопка «реагировала» на наведение мыши, добавляют псевдокласс `:hover` — правило, которое срабатывает, когда курсор наведён.

**Общий пример:**
```html
<a href="prices.html" class="btn">Купить</a>
```
```css
.btn {
    display: inline-block;         /* чтобы ссылка вела себя как блок-кнопка */
    background: #e63946;
    color: white;
    padding: 12px 24px;            /* «подушка» внутри — кнопка становится крупнее */
    border-radius: 10px;
    text-decoration: none;         /* убрать подчёркивание у ссылки */
}
.btn:hover { background: #c22f3c; }   /* при наведении — чуть темнее */
```

## Урок 6. Проект «Страница обо мне»

Новой теории в этом уроке нет — это **сборка всего модуля** в одну готовую страницу. Ты объединяешь всё, что уже умеешь: каркас и заголовки (урок 1), подключённый `style.css` и селекторы (урок 2), картинку (урок 3), цвет и карточки в ряд (урок 4), красивый текст и кнопку (урок 5).

Используй этот справочник как **чек-лист**: есть ли правильный каркас? подключён ли CSS через `<link>`? заданы ли цвета фона и текста? стоят ли картинки с `alt`? аккуратно ли оформлен текст? Если на все вопросы «да» — страница готова.

# Модуль 2 — Контент и шрифты

## Урок 1. Ссылки и якоря

Ссылки связывают страницы между собой и позволяют переходить по сайту. Делает ссылку тег [`<a>`](Справочник-теги-и-свойства.md#a), а главный атрибут `href` говорит, **куда** вести. Текст между `<a>` и `</a>` — то, на что кликают.

Куда может вести ссылка:
- на **другой сайт**: `href="https://..."` (можно добавить `target="_blank"` — откроется в новой вкладке, не уходя с твоей страницы);
- на **другую страницу** твоего сайта: `href="about.html"`;
- **письмо**: `href="mailto:me@mail.ru"` — откроет почтовую программу;
- **звонок** (на телефоне): `href="tel:+7999..."`.

**Якорь** — это переход к нужному разделу **на той же самой странице** (как «перемотать» вниз к блоку «Контакты»). Работает в два шага: нужному разделу дают `id`, а в ссылке пишут этот id с решёткой.

**Общий пример (меню-якоря):**
```html
<nav>
    <a href="#about">Обо мне</a>
    <a href="#contacts">Контакты</a>
</nav>

<section id="about">...здесь про меня...</section>
<section id="contacts">...здесь контакты...</section>
```
Клик по «Контакты» прокрутит страницу к разделу с `id="contacts"`.

## Урок 2. Шрифты

Шрифт сильно меняет настроение страницы. Стандартных шрифтов в системе мало, поэтому красивые **подключают** — двумя способами.

**Способ 1 — Google Fonts.** Это огромная бесплатная библиотека шрифтов. На сайте fonts.google.com выбираешь шрифт (обязательно включи фильтр **Cyrillic**, иначе русские буквы могут не поддерживаться), копируешь готовую строку `<link>` в `<head>` и пишешь имя шрифта в [`font-family`](Справочник-теги-и-свойства.md#font-family):
```html
<link href="https://fonts.googleapis.com/css2?family=Montserrat&display=swap" rel="stylesheet">
```
```css
body { font-family: "Montserrat", Arial, sans-serif; }
```

**Способ 2 — свой шрифт из файла.** Если у тебя есть файл шрифта, его подключают через правило [`@font-face`](Справочник-теги-и-свойства.md#font-face). Сначала «объявляем» шрифт — даём имя и указываем путь к файлу через `url()`, — а потом пользуемся этим именем:
```css
@font-face {
    font-family: "MyFont";                          /* придуманное имя */
    src: url("fonts/myfont.woff2") format("woff2");  /* путь к файлу */
}
h1 { font-family: "MyFont", sans-serif; }            /* пользуемся по имени */
```

Важные детали:
- `url("...")` — это «путь к файлу» внутри CSS (работает как `src` у картинки, только для шрифта).
- `font-family` всегда пишут **стеком** — несколько шрифтов через запятую. Браузер берёт первый, а если его нет — следующий. Последним ставят `sans-serif` (без засечек) или `serif` (с засечками) как запасной вариант.

## Урок 3. Списки

Список — это перечень пунктов. Два главных вида:
- [`<ul>`](Справочник-теги-и-свойства.md#ul) — **маркированный** (перед пунктами точки). Нужен, когда порядок не важен (список покупок, фишки товара).
- [`<ol>`](Справочник-теги-и-свойства.md#ol) — **нумерованный** (1, 2, 3). Нужен, когда порядок важен (шаги инструкции, рейтинг).

Внутри и того, и другого — пункты [`<li>`](Справочник-теги-и-свойства.md#li). В пункт можно положить что угодно: текст, ссылку, картинку.

Вид маркера (или его отсутствие) задаёт CSS-свойство [`list-style-type`](Справочник-теги-и-свойства.md#list-style-type). Самый частый приём — `none`: он **убирает** маркеры, и из списка получается аккуратное **меню** (особенно вместе с `display: flex`, чтобы пункты встали в ряд).

**Общий пример (меню из списка):**
```html
<nav>
  <ul>
    <li><a href="#">Главная</a></li>
    <li><a href="#">О нас</a></li>
    <li><a href="#">Контакты</a></li>
  </ul>
</nav>
```
```css
nav ul { list-style-type: none; display: flex; gap: 20px; }
```
Здесь мы убрали точки и поставили пункты в ряд с промежутком 20px — получилось горизонтальное меню.

## Урок 4. Таблицы

Таблица нужна, когда данные удобно показать «по строкам и столбцам»: расписание, таблица рекордов, сравнение товаров. Собирается она из нескольких тегов:
- [`<table>`](Справочник-теги-и-свойства.md#table) — вся таблица (обёртка).
- [`<tr>`](Справочник-теги-и-свойства.md#tr) — строка таблицы; внутри неё идут ячейки.
- [`<th>`](Справочник-теги-и-свойства.md#th-td) — ячейка-**заголовок** (жирная, по центру), [`<td>`](Справочник-теги-и-свойства.md#th-td) — обычная ячейка с данными.
- [`<thead>` и `<tbody>`](Справочник-теги-и-свойства.md#thead-tbody) — «шапка» (строка заголовков) и «тело» (строки с данными). Помогают и читать код, и стилизовать.

Полезное:
- `colspan="2"` — растянуть ячейку на 2 столбца, `rowspan="2"` — на 2 строки.
- [`border-collapse: collapse`](Справочник-теги-и-свойства.md#border-collapse) — **обязательный** приём для аккуратного вида: он убирает двойные линии между ячейками, сливая их в одну.

**Общий пример:**
```html
<table>
  <thead>
    <tr><th>День</th><th>Урок</th></tr>
  </thead>
  <tbody>
    <tr><td>Пн</td><td>Математика</td></tr>
    <tr><td>Вт</td><td>История</td></tr>
  </tbody>
</table>
```
```css
table  { border-collapse: collapse; }         /* линии ячеек сливаются в одну */
th, td { border: 1px solid #ccc; padding: 8px 14px; }
```

# Модуль 3 — Блочная модель и оформление блоков

## Урок 1. Семантика страницы

Можно собрать всю страницу из одних [`<div>`](Справочник-теги-и-свойства.md#div) — браузер поймёт. Но получится «суп из div»: по коду не ясно, где шапка, где меню, где подвал. Чтобы было понятнее, придумали **семантические** теги — коробки с понятным смыслом. Внешне они как `<div>` (тоже блоки-контейнеры), но их название сразу говорит, **что** внутри. Это удобнее тебе, а ещё помогает поисковикам и программам для незрячих.

Главные «зоны» страницы:
- [`<header>`](Справочник-теги-и-свойства.md#header-nav-main-footer) — **шапка** (логотип, название, часто меню);
- [`<nav>`](Справочник-теги-и-свойства.md#header-nav-main-footer) — блок **навигации** (ссылки-меню);
- [`<main>`](Справочник-теги-и-свойства.md#header-nav-main-footer) — **основное** содержимое (одно на странице);
- [`<footer>`](Справочник-теги-и-свойства.md#header-nav-main-footer) — **подвал** (контакты, копирайт).

Блоки внутри: [`<section>`, `<article>`, `<aside>`](Справочник-теги-и-свойства.md#section-article-aside) — смысловой раздел, самостоятельный кусок (пост, карточка товара) и дополнительная/боковая информация. А [`<figure>` и `<figcaption>`](Справочник-теги-и-свойства.md#figure-figcaption) — это картинка с подписью.

**Общий пример (каркас страницы):**
```html
<header><h1>Мой блог</h1></header>
<nav><a href="#">Главная</a> <a href="#">Посты</a></nav>
<main>
    <article>
        <h2>Первый пост</h2>
        <p>Текст поста…</p>
    </article>
</main>
<footer>© 2026, Аня</footer>
```

## Урок 2. Блочная модель

Это главная идея всей вёрстки: **каждый элемент на странице — прямоугольная коробка.** И у этой коробки есть четыре «слоя», считая изнутри наружу: содержимое → [`padding`](Справочник-теги-и-свойства.md#padding) (внутренний отступ) → [`border`](Справочник-теги-и-свойства.md#border) (рамка) → [`margin`](Справочник-теги-и-свойства.md#margin) (внешний отступ). Поняв эту «коробку», ты поймёшь, как управлять расстояниями на странице.

- **`padding`** — «воздух» **внутри** коробки, между рамкой и содержимым. Как поролон внутри коробки, чтобы вещь не упиралась в стенки. Увеличивает «подушку» вокруг текста.
- **`margin`** — расстояние **снаружи**, между коробками. Раздвигает блоки друг от друга. Особый приём: `margin: 0 auto` центрирует блок по горизонтали.
- **`box-sizing: border-box`** — важная настройка. По умолчанию, если задать блоку `width: 200px` и добавить padding и border, блок станет **шире** 200px (padding и border прибавляются сверху) — и вёрстка «распухает». Значение [`border-box`](Справочник-теги-и-свойства.md#box-sizing) это чинит: тогда padding и border входят внутрь заданной ширины. Поэтому его почти всегда включают сразу для всех элементов.

**Общий пример (карточка):**
```css
* { box-sizing: border-box; }      /* чтобы ширина не распухала — для всех элементов */

.card {
    width: 260px;
    padding: 20px;                  /* воздух внутри */
    margin: 16px auto;              /* отступ снаружи + по центру */
    border: 1px solid #ddd;
}
```

## Урок 3. Границы, скругления и outline

- [`border`](Справочник-теги-и-свойства.md#border) — **рамка**. Значение задаёт три вещи сразу: толщину, стиль и цвет (`2px solid #333`). Стили линии: `solid` (сплошная), `dashed` (штрихи), `dotted` (точки), `double` (двойная).
- [`border-radius`](Справочник-теги-и-свойства.md#border-radius) — **скругление углов**. `16px` — мягкие углы; `50%` на квадратном элементе — идеальный круг (так делают аватарки); очень большое значение `999px` — форма «таблетки» с полукруглыми торцами (частая форма кнопок и бейджей).
- [`outline`](Справочник-теги-и-свойства.md#outline) — **контур снаружи рамки** и главный новый герой урока. Выглядит как `border`, но с принципиальным отличием: `outline` **не занимает места** и **не сдвигает** соседние элементы — он просто рисуется поверх. Поэтому им удобно показывать, что элемент активен (`:focus`): обводка появляется, а вёрстка при этом не «прыгает». У `border` такого нет — он раздвигает соседей.

**Вложенное скругление.** Если скруглённый блок лежит внутри другого скруглённого (например, картинка-обложка в скруглённой карточке), внутренний радиус делают по формуле: **внешний радиус − padding**. Тогда уголки получаются «параллельными» и смотрятся аккуратно.

**Общий пример:**
```css
.card     { border: 2px solid #333; border-radius: 16px; padding: 10px; }
.card img { border-radius: 6px; }                /* 16 − 10 = 6, уголки параллельны */
button:focus { outline: 3px solid dodgerblue; outline-offset: 2px; }
```

## Урок 4. Картинки в блоках, тени и фоны

Когда картинка живёт внутри блока-карточки, появляются новые приёмы, чтобы всё выглядело ровно и красиво.

- [`object-fit: cover`](Справочник-теги-и-свойства.md#object-fit) — решает проблему «сплющенных» фото. Если картинке задать и ширину, и высоту (чтобы все обложки были одинаковыми), обычно она искажается. `cover` вписывает картинку в заданный размер **без искажения**, заполняя блок и обрезая лишнее по краям.
- [`aspect-ratio`](Справочник-теги-и-свойства.md#aspect-ratio) — задаёт блоку **пропорции** (`16 / 9` — широкий экран, `1 / 1` — квадрат). Тогда достаточно указать только ширину, а высоту браузер посчитает сам, держа форму. Очень удобно для резиновых обложек.
- [`box-shadow`](Справочник-теги-и-свойства.md#box-shadow) — **тень блока**, делает карточку «приподнятой». Цвет тени бери полупрозрачным (`rgba(...,0.15)`) — так мягче и естественнее.
- **Фоны:** [`background-image`](Справочник-теги-и-свойства.md#background-image) ставит фоновую картинку, а управляют ею [`background-size`](Справочник-теги-и-свойства.md#background-size) (`cover` — заполнить, `contain` — вместить целиком), [`background-position`](Справочник-теги-и-свойства.md#background-position) (где разместить, например `center`) и [`background-repeat`](Справочник-теги-и-свойства.md#background-repeat) (`no-repeat` — не повторять).

**Общий пример (карточка с обложкой):**
```css
.cover {
    width: 100%;
    aspect-ratio: 16 / 9;      /* держим форму широкого экрана */
    object-fit: cover;          /* заполнить, лишнее обрезать */
    border-radius: 12px;
}
.card { box-shadow: 0 8px 20px rgba(0,0,0,0.15); }      /* мягкая тень */
.hero { background: url("fon.jpg") center / cover no-repeat; }
```

## Урок 5. Градиенты

Градиент — это плавный переход между цветами (а не один сплошной цвет). Пишется как значение фона. Градиенты обожают за «вау-эффект»: ими делают модные баннеры, кнопки, обложки.

- [`linear-gradient()`](Справочник-теги-и-свойства.md#linear-gradient) — переход **по прямой**. Первым указывают направление (`to right` — слева направо, `180deg` — сверху вниз, `135deg` — по диагонали), затем цвета через запятую (минимум два, можно больше).
- [`radial-gradient()`](Справочник-теги-и-свойства.md#radial-gradient) — переход **кругом из центра** (как блик или свет лампы).
- [`conic-gradient()`](Справочник-теги-и-свойства.md#conic-gradient) — переход **по кругу**, как стрелка часов (для диаграмм-«пирогов» и радужных колец).
- **Градиент к тексту** — красивая фишка: градиент-фон виден только сквозь буквы. Делается через [`background-clip: text`](Справочник-теги-и-свойства.md#background-clip) и прозрачный текст (`color: transparent`).
- **Матовое стекло** (стекломорфизм) — [`backdrop-filter: blur()`](Справочник-теги-и-свойства.md#backdrop-filter) на полупрозрачной плашке: фон за ней становится размытым, как за матовым стеклом.

**Общий пример:**
```css
.banner { background: linear-gradient(135deg, #2965f1, #7c3aed); }   /* диагональ */

.grad-text {
    background: linear-gradient(90deg, #f093fb, #f5576c);
    -webkit-background-clip: text;
    background-clip: text;
    color: transparent;            /* буквы прозрачны — виден градиент */
}
```

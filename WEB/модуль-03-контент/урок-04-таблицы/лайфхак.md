# 🧰 Лайфхаки · Урок 4 «Таблицы»

Трюки и частые ошибки, чтобы строить таблицы быстро и красиво.

---

## ⌨️ Emmet для таблиц

| Ввод | Развернётся |
|------|-------------|
| `table>tr*3>td*3` | таблица 3×3 |
| `table>tr*4>td*2` | 4 строки по 2 ячейки |
| `table>thead>tr>th*3^^tbody>tr*3>td*3` | таблица с шапкой (3 заголовка) и телом 3×3 |
| `tr>td*3` | одна строка из 3 ячеек (добавить в таблицу) |

> 💡 `^^` в Emmet поднимает на **два** уровня вверх — так `tbody` встаёт рядом с `thead`, а не внутри него.

## 🎨 Рецепт красивой таблицы

```css
table {
    border-collapse: collapse;   /* одинарные рамки — обязательно! */
    width: 100%;
}
th, td {
    border: 1px solid #cbd5e1;
    padding: 12px 16px;
    text-align: left;
}
thead th {
    background-color: #2563eb;    /* цветная шапка */
    color: white;
}
tbody tr:nth-child(even) {
    background-color: #f1f5f9;    /* зебра */
}
tbody tr:hover {
    background-color: #dbeafe;    /* подсветка строки */
}
```

Скопируй этот блок — и любая таблица сразу выглядит опрятно.

---

## 🔢 `:nth-child` — не только even/odd

- `:nth-child(even)` — чётные строки (2, 4, 6…).
- `:nth-child(odd)` — нечётные (1, 3, 5…).
- `:nth-child(3)` — ровно третья.
- `:nth-child(3n)` — каждая третья (3, 6, 9…).

Системно разберём в модуле про псевдоклассы — там `:nth-child` раскроется полностью.

## 🐞 Частые ошибки и как избежать

- **Двойные рамки** → нет `border-collapse: collapse`. Добавь его таблице.
- **Таблица «поехала» после `colspan`** → не убрал лишний `<td>`. Растянул на N столбцов — убери (N−1) ячеек в этой строке.
- **Текст липнет к рамкам** → нет `padding` у `th, td`.
- **Зебра не работает** → правило висит не на `tr`. Пиши `tbody tr:nth-child(even)`.
- **Ячейки не выравниваются** → у `<td>` по умолчанию текст слева, у `<th>` — по центру. Задай `text-align` явно.
- **Вёрстка страницы на таблицах** → так делали 20 лет назад, сейчас **нельзя**. Таблица — только для табличных данных, расположение блоков — Flexbox/Grid.

---

## 🧭 Когда таблица, а когда нет

- **Данные в строках и столбцах** (расписание, цены, характеристики, результаты) → таблица ✅.
- **Расположение блоков на странице** (колонки, карточки, меню) → **НЕ таблица**, а Flexbox/Grid (скоро).
- Простое перечисление → список `<ul>`/`<ol>`, а не таблица.

## 📱 Таблица на телефоне

Широкая таблица не влезает в узкий экран. Решение — обернуть её в блок с прокруткой:
```css
.table-wrap { overflow-x: auto; }
```
```html
<div class="table-wrap"><table>...</table></div>
```
Теперь таблицу можно листать вбок. Подробно про адаптивность — в отдельном модуле.

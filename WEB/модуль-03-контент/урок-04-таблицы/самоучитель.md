# 🧑‍🏫 Часть A. Разбираем вместе (пошагово)

## 1. Первая таблица

**Тема:** таблица строится по строкам: `<table>` → `<tr>` (строка) → `<td>` (ячейка).

**Задание:** сделай таблицу 2×2.

**Разбор по шагам:**
1. Открой контейнер: `<table></table>`.
2. Внутри — строка: `<tr></tr>`.
3. В строке — две ячейки: `<td>Яблоко</td><td>50 руб</td>`.
4. Добавь вторую такую же `<tr>`. Emmet-ускорение: `table>tr*2>td*2`.

✅ 2 строки по 2 ячейки — таблица 2×2.

---

## 2. Шапка `<th>` и подпись `<caption>`

**Тема:** `<th>` — жирный заголовок столбца, `<caption>` — название таблицы.

**Задание:** добавь шапку и подпись.

**Разбор по шагам:**
1. Сразу после `<table>` добавь `<caption>Прайс-лист</caption>`.
2. Первую строку сделай из заголовков: `<tr><th>Товар</th><th>Цена</th></tr>`.
3. Ниже — строки с данными из `<td>`.
4. Сохрани — заголовки жирные, сверху подпись.

✅ `<th>` для шапки, `<caption>` для названия.

---

## 3. Рамки и `border-collapse`

**Тема:** рамки задают ячейкам; двойные убирает `border-collapse: collapse`.

**Задание:** сделай аккуратные рамки.

**Разбор по шагам:**
1. `table, th, td { border: 1px solid #ccc; }` — появились рамки (двойные).
2. Добавь `table { border-collapse: collapse; }` — стали одинарные.
3. Добавь воздух: `th, td { padding: 10px 14px; }`.
4. Сохрани — таблица выглядит аккуратно.

✅ `border-collapse: collapse` + `padding`.

---

## 4. Объединение ячеек

**Тема:** `colspan` объединяет по горизонтали, `rowspan` — по вертикали.

**Задание:** сделай заголовок на всю ширину.

**Разбор по шагам:**
1. Если у таблицы 2 столбца, добавь первой строкой: `<tr><th colspan="2">Заголовок</th></tr>`.
2. Важно: больше ячеек в этой строке НЕ пиши (место занято).
3. Ниже — обычные строки с двумя `<td>`.
4. Сохрани — заголовок растянулся на оба столбца.

✅ `<th colspan="2">` + убрали лишнюю ячейку.

---

## 5. «Зебра»

**Тема:** чередование цвета строк через `:nth-child(even)`.

**Задание:** сделай полосатую таблицу.

**Разбор по шагам:**
1. Заверни данные в `<tbody>`.
2. `tbody tr:nth-child(even) { background-color: #f1f5f9; }` — чётные строки серые.
3. Добавь `tbody tr:hover { background-color: #dbeafe; }` — подсветка.
4. Сохрани — таблица полосатая и «живая».

✅ `:nth-child(even)` + `:hover`.

# ✍️ Часть B. Теперь сам (с мини-подсказкой)

## Строим

**6.** Сделай таблицу 3×3 через Emmet и заполни данными.
> 💡 `table>tr*3>td*3` + Tab.

**7.** Добавь ей шапку из `<th>` и подпись `<caption>`.
> 💡 Первая строка — `<th>`, подпись — сразу после `<table>`.

**8.** Оберни шапку в `<thead>`, данные — в `<tbody>`.
> 💡 `<thead>` вокруг строки заголовков, `<tbody>` — вокруг данных.

## Оформляем

**9.** Сделай одинарные рамки и `padding` в ячейках.
> 💡 `border` + `table { border-collapse: collapse; }` + `padding`.

**10.** Покрась шапку (тёмный фон, белый текст).
> 💡 `thead th { background-color: #2563eb; color: white; }`.

**11.** Сделай «зебру» на чётных строках.
> 💡 `tbody tr:nth-child(even) { background-color: #f1f5f9; }`.

## Объединяем

**12.** Сделай заголовок через `colspan` на все столбцы.
> 💡 `<th colspan="3">` и убери лишние ячейки в строке.

**13.** Объедини две строки через `rowspan`.
> 💡 `<td rowspan="2">`; в следующей строке эту ячейку не пиши.

## Собираем

**14.** Собери расписание на неделю (дни — шапка, уроки — строки) с зеброй.
> 💡 Шапка из `<th>` с днями; зебра по строкам `<tbody>`.

## Со звёздочкой 🔴

**15.** Добавь таблице строку «Итого» через `<tfoot>` и выдели её.
> 💡 `<tfoot>` после `<tbody>`; строку — жирным или своим фоном.

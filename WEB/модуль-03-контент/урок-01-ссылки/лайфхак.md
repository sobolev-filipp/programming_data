# 🧰 Лайфхаки · Урок 1 «Ссылки»

Трюки и частые ошибки, чтобы делать ссылки быстро и без боли.

---

## ⌨️ Emmet — копилка растёт

С прошлых уроков у нас уже есть `!`, `+`, `*`, `>`, `{текст}`, `lorem`. Добавляем для ссылок:

| Аббревиатура | Что развернёт |
|--------------|---------------|
| `a` + `Tab` | `<a href=""></a>` |
| `a[target=_blank]` | `<a href="" target="_blank"></a>` |
| `nav>a*3` | `<nav>` с тремя ссылками |
| `ul>li>a*4` | список из 4 ссылок-пунктов (пригодится в уроке про списки) |
| `^` | подъём на уровень вверх: `nav>a^footer` |

> 💡 **`^` — «вынырнуть» из тега.** После `nav>a` символ `^` выводит наружу: `nav>a{Меню}^section{Контент}` → `nav` и `section` станут **соседями**, а не вложенными.

## 🔗 Полезные приёмы со ссылками

- **`<a href="#">⬆ Наверх</a>`** — прыжок в самый верх страницы (просто решётка).
- **`href="about.html#team"`** — открыть другую страницу и сразу прокрутить к разделу `id="team"`.
- **`download`** — файл скачивается, а не открывается: `<a href="прайс.pdf" download>Скачать прайс</a>`.
- **`title`** — всплывающая подсказка при наведении: `<a href="..." title="Откроется в новой вкладке">`.
- **Плавная прокрутка** ко всем якорям — одной строкой: `html { scroll-behavior: smooth; }`.
- **`scroll-margin-top: 70px;`** разделам — чтобы якорь не прятался под «прилипшим» верхним меню.

## 🎨 Красивые ссылки-кнопки

```css
.btn-link {
    display: inline-block;
    background-color: #2563eb;
    color: #fff;
    padding: 12px 22px;
    border-radius: 10px;
    text-decoration: none;
    transition: 0.2s;        /* плавное изменение при наведении */
}
.btn-link:hover {
    background-color: #1e40af;
    transform: translateY(-2px);   /* кнопка чуть «подпрыгивает» */
}
```

> 💡 **`transition`** делает изменение плавным, а не резким. Подробно разберём в модуле про анимацию — пока просто попробуй, эффект приятный.

## ⌨️ Горячие клавиши

| Клавиши | Действие |
|---------|----------|
| `Ctrl+S` | сохранить (Live Server обновит браузер) |
| `Ctrl+клик` по ссылке в VS Code | перейти к файлу, на который ссылаешься |
| `Alt+Z` | перенос длинных строк по ширине окна |
| `F12` в браузере | DevTools — навести на ссылку и увидеть её стили |

## 🐞 Частые ошибки и как избежать

- **Ссылка ведёт «в никуда»** → у внешнего сайта забыл `https://`. Внешний адрес пиши целиком.
- **Якорь не прыгает** → имя после `#` не совпадает с `id` раздела. Проверь буква-в-букву (и большие/маленькие).
- **`:hover` не работает** → перепутан порядок псевдоклассов. Держи LoVe HAte: `:link → :visited → :hover → :active`.
- **Ссылка открылась поверх страницы, а хотел новую вкладку** → добавь `target="_blank"`.
- **`footer` попал внутрь `nav`** в Emmet → забыл `^` (подъём вверх).
- **`padding` у ссылки не работает** → добавь `display: inline-block` (у строчных элементов вертикальные отступы «не видны»).

## 🎯 Задание

**Придумай свой бренд** — товар, приложение, сервис или заведение, которого ещё нет, — и сделай для него **лендинг** (сайт-презентацию на одну страницу). Твоя задача — как настоящий основатель стартапа: придумать идею, название, «фишки», тарифы и красиво всё подать.

**Придумай что-то своё, например:**
- 👟 умный гаджет («кроссовки, которые заряжают телефон», «рюкзак-навигатор»);
- 📱 приложение или игра-сервис («приложение, которое учит кота командам»);
- 🥤 еда/напиток («энергетик для геймеров», «мороженое-конструктор»);
- 🎮 своя игровая студия или киберспорт-команда;
- 🏫 необычное заведение («антикафе для роботов», «школа магии»).

> ⚠️ **Важно: не бери «любимую игру/фильм»** — здесь ты **изобретаешь своё**, это и есть самое интересное!

**Пример:** «NEON — кроссовки, которые светятся в такт музыке».

## 📋 Что должно быть на странице

1. **Шапка-герой (hero):**
   - **логотип/картинка** бренда (можно сделать с помощью ИИ — см. ниже);
   - **название** (`h1`) красивым шрифтом с Google Fonts + **слоган**;
   - **кнопка-призыв** («Купить», «Скачать», «Попробовать») с `:hover`;
   - фирменный цветной фон (палитра по цветовому кругу).

2. **Меню-навигация** из списка с **якорями** на разделы: «О нас · Возможности · Тарифы · Контакты» (`<ul>` без маркеров, в ряд).

3. **Раздел «Возможности / Фишки» (`h2` + `id`):**
   - **список** (`<ul>`) из 4–6 преимуществ (можно с эмодзи или вложенными подпунктами).

4. **Раздел «Тарифы» (`h2` + `id`):**
   - **таблица** «Базовый / Стандарт / Премиум»: в строках — что входит, в столбцах — тарифы (цена, ✓/✗);
   - шапка `<th>`, `<caption>`, `border-collapse`, **«зебра»** и **объединённая ячейка** (`colspan` — общий заголовок над тарифами).

5. **Раздел «Контакты» (`h2` + `id`):**
   - ссылка-письмо `mailto:` и ссылка-звонок `tel:`;
   - **внешняя** ссылка на «соцсеть» бренда (`target="_blank"`).

6. **Кнопка «⬆ Наверх»** внизу (якорь `#`).

Всё оформление — **во внешнем `style.css`**.

## 🤖 ИИ-помощники (работают в России, без VPN)

Настоящие дизайнеры и разработчики уже вовсю пользуются ИИ. Ты тоже можешь — **чтобы придумать контент и картинки**, а не чтобы он сделал всё за тебя. **Код ты пишешь сам** — это и есть твоя работа и твой навык.

**🎨 Сделать картинки (логотип, фото товара, фон):**
- **Шедеврум** (Яндекс) — [shedevrum.ai](https://shedevrum.ai) или приложение. Бесплатно, по-русски.
- **Kandinsky / Fusion Brain** (Сбер) — [fusionbrain.ai](https://fusionbrain.ai). Рисует картинку по описанию.
- **GigaChat** (Сбер) — [giga.chat](https://giga.chat) — умеет и текст, и картинки (через Kandinsky).

**✍️ Придумать текст (название, слоган, описания «фишек»):**
- **Алиса / YandexGPT** (Яндекс) — приложение Алиса или [ya.ru](https://ya.ru) (режим с ИИ).
- **GigaChat** (Сбер) — [giga.chat](https://giga.chat).

**Как правильно просить ИИ (промт):** пиши **чётко и подробно**. Пример для логотипа:
> «Нарисуй минималистичный логотип для бренда светящихся кроссовок NEON: кроссовок с неоновой подсветкой, тёмный фон, фиолетово-голубые цвета, простой современный стиль».

**Правила умного помощника 🧠:**
- ✅ ИИ — **помощник**, а не «сделай всё за меня». Идея, структура и код — твои.
- ✅ **Проверяй факты** и **переписывай текст своими словами** — ИИ иногда ошибается.
- ✅ Картинку сохрани и вставь через `<img>` (не забудь `alt`!), сожми, если тяжёлая.
- ⚠️ Не выкладывай в промт личные данные (телефон, адрес, фамилию).

## ✅ Требования (проверь по списку)

**Из Модуля 1 (база + стиль):**
- ✅ правильный каркас (`!`), `lang="ru"`, `<meta charset="UTF-8">`, свой `<title>`, один `h1`;
- ✅ минимум **1 картинка** (логотип/товар) с осмысленным `alt`;
- ✅ **гармоничная палитра** (подобрана по цветовому кругу), читаемый контраст;
- ✅ кнопка-призыв реагирует на наведение (`:hover`).

**Из Модуля 2 (контент и шрифты):**
- ✅ подключён **шрифт с Google Fonts** (с кириллицей!), аккуратная типографика;
- ✅ **меню-навигация из списка** с якорями `#` (прокрутка работает);
- ✅ хотя бы одна **внешняя** ссылка `target="_blank"` + `mailto:`/`tel:`;
- ✅ **список** возможностей (`<ul>`/`<ol>`);
- ✅ **таблица тарифов**: `<th>`+`<caption>`, `border-collapse`, «зебра», объединённая ячейка (`colspan`);
- ✅ кнопка «Наверх».

**Аккуратность:**
- ✅ страница открывается без «кракозябр» и «сломанных» картинок;
- ✅ код опрятный, стили только во внешнем `style.css`.

## 💡 Подсказки (как что сделать)

| Что нужно | Приём / свойство |
|-----------|------------------|
| логотип/фото товара | сделать в **Шедеврум/Kandinsky**, вставить `<img src="..." alt="...">` |
| название и слоган | придумать самому или с **Алисой/GigaChat**, оформить `h1` + шрифт |
| меню из списка в ряд | `.menu { list-style: none; padding: 0; display: flex; gap: 18px; }` |
| якорь на раздел | у раздела `id="tariffs"`, ссылка `href="#tariffs"` |
| плавная прокрутка | `html { scroll-behavior: smooth; }` |
| кнопка-призыв | `.btn { display: inline-block; ... text-decoration: none; }` + `.btn:hover { ... }` |
| таблица тарифов | `border-collapse: collapse` + `padding` + зебра `:nth-child(even)` + `<th colspan="3">` |
| фирменная палитра | [get-color.ru/color-wheel](https://get-color.ru/color-wheel/) — база + контрастный акцент |

**Порядок работы:** ① идея, название, палитра → ② структура (разделы с `id`) → ③ картинка и тексты (можно с ИИ) → ④ список и таблица → ⑤ шрифты и цвета → ⑥ меню-якоря, кнопки, `:hover`. Не хватай всё сразу.

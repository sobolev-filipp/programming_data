# Урок 2 «Шрифты» — итого (шпаргалка) 📌

> За 3 минуты вспомнить весь урок. Только суть и примеры.

---

## Главные мысли

1. Шрифт задаёт **`font-family`**. Браузер знает только **системные** шрифты — красивый надо **подключить**.
2. **Стек шрифтов:** список через запятую, в конце — **семейство** (`serif`/`sans-serif`) как страховка.
3. **Google Fonts** — главный способ: **подключить** `<link>` + **применить** `font-family`. Бесплатно.
4. **Свой шрифт** — правило **`@font-face`** с **`url()`** (путь к файлу).
5. **`url()`** — это путь к файлу (шрифт, картинка, иконка). Встретится ещё не раз!

---

## Стек шрифтов

```css
body { font-family: "Montserrat", Arial, sans-serif; }
```
Имя с пробелом — в кавычках. В конце — семейство:

| Семейство | Какой |
|-----------|-------|
| `serif` | с засечками (книжный) |
| `sans-serif` | без засечек (современный) |
| `monospace` | моноширинный (код) |
| `cursive` | рукописный |

---

## Google Fonts — 2 шага

```html
<!-- 1. подключить в <head> (код с fonts.google.com) -->
<link href="https://fonts.googleapis.com/css2?family=Montserrat&display=swap" rel="stylesheet">
```
```css
/* 2. применить */
body { font-family: "Montserrat", sans-serif; }
```
Пара шрифтов (заголовок + текст, не больше 2):
```css
h1   { font-family: "Lobster", cursive; }
body { font-family: "Montserrat", sans-serif; }
```

---

## Насыщенность и курсив

```css
h1      { font-weight: 700; }      /* жирный (= bold) */
p       { font-weight: 400; }      /* обычный (= normal), по умолчанию */
.thin   { font-weight: 300; }      /* тонкий */
.quote  { font-style: italic; }    /* курсив */
.normal { font-style: normal; }    /* прямой, по умолчанию */
```
`font-weight` — число от `100` до `900` (400 = normal, 700 = bold). `font-style` — `normal` (прямой) или `italic` (курсив). Жирный/курсив с Google Fonts надо **выбрать при подключении**.

---

## Свой шрифт: `@font-face` + `url()`

```css
@font-face {
    font-family: "MyGameFont";        /* придумываем имя */
    src: url("fonts/mario.woff2");     /* путь к файлу */
    font-display: swap;                /* текст не «мигает» */
}
h1 { font-family: "MyGameFont", sans-serif; }
```
- `url("...")` — путь к файлу (как `href`/`src`).
- Лучший формат — **`.woff2`** (лёгкий).

---

## Главные ошибки

| Проблема | Причина | Лечение |
|----------|---------|---------|
| шрифт не применился | забыл подключить `<link>` / `@font-face` | сначала подключить, потом применять |
| имя из двух слов не работает | нет кавычек | `"Comic Sans MS"` |
| жирный «кривой» | начертание не подключено | выбрать `700` на Google Fonts |
| текст «мигает» при загрузке | нет `font-display` | добавить `font-display: swap` |

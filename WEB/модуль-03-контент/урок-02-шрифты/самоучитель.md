# 🧑‍🏫 Часть A. Разбираем вместе (пошагово)

## 1. `font-family` и стек

**Тема:** шрифт задаёт `font-family`; список через запятую — запасные варианты; в конце — семейство.

**Задание:** задай `body` шрифт Georgia с запасным serif.

**Разбор по шагам:**
1. В `style.css`: `body { font-family: Georgia; }`.
2. Добавь страховку — семейство: `body { font-family: Georgia, serif; }`.
3. Сохрани — текст стал «книжным», с засечками.
4. Браузер берёт первый доступный шрифт, а если нет — `serif`.

✅ `body { font-family: Georgia, serif; }`.

---

## 2. Подключаем Google Fonts

**Тема:** красивый шрифт нужно подключить (`<link>`) и применить (`font-family`).

**Задание:** подключи любой шрифт с fonts.google.com.

**Разбор по шагам:**
1. Зайди на [fonts.google.com](https://fonts.google.com), выбери шрифт (например, Montserrat).
2. Нажми **Get font → Get embed code**, скопируй тег `<link ...>`.
3. Вставь его в `<head>` своей страницы.
4. Примени: `body { font-family: "Montserrat", sans-serif; }`. Сохрани — шрифт сменился.

✅ `<link>` в `<head>` + `font-family` в CSS.

---

## 3. Жирный и курсив

**Тема:** `font-weight` — толщина, `font-style: italic` — курсив.

**Задание:** сделай заголовок жирным, а цитату — курсивом.

**Разбор по шагам:**
1. Заголовок: `h1 { font-weight: 700; }`.
2. Обычный текст — это `400` (можно не писать).
3. Цитата: `.quote { font-style: italic; }`.
4. Если с Google Fonts жирный «кривой» — выбери начертание `700` при подключении.

✅ `font-weight: 700;` и `font-style: italic;`.

---

## 4. Свой шрифт через `@font-face`

**Тема:** файл шрифта подключают правилом `@font-face` с `url()`.

**Задание:** подключи шрифт из файла.

**Разбор по шагам:**
1. Положи файл (`myfont.woff2`) в папку `fonts/` рядом с CSS.
2. В начале `style.css` опиши: `@font-face { font-family: "MyFont"; src: url("fonts/myfont.woff2"); }`.
3. Примени: `h1 { font-family: "MyFont", sans-serif; }`.
4. `url("...")` — это путь к файлу, как `href` у ссылки.

✅ `@font-face` + `font-family: "MyFont"`.

---

## 5. `font-display: swap`

**Тема:** чтобы текст не пропадал, пока грузится шрифт.

**Задание:** добавь `font-display: swap` в своё `@font-face`.

**Разбор по шагам:**
1. Внутри `@font-face` добавь строку `font-display: swap;`.
2. Теперь текст виден сразу — сначала запасным шрифтом.
3. Когда основной догрузится — он заменится.
4. У Google Fonts это уже включено (`&display=swap` в ссылке).

✅ `font-display: swap;` внутри `@font-face`.

# ✍️ Часть B. Теперь сам (с мини-подсказкой)

## Семейства и Google Fonts

**6.** Сделай четыре абзаца с семействами `serif`, `sans-serif`, `monospace`, `cursive`.
> 💡 Разные классы, у каждого своё `font-family`.

**7.** Подключи шрифт с названием из двух слов (например, "Comic Neue").
> 💡 Имя в кавычках: `font-family: "Comic Neue", cursive;`.

**8.** Подключи пару шрифтов: один для `h1, h2`, другой для `body`.
> 💡 В `<link>` — `family=First&family=Second`; потом два правила.

## Начертания

**9.** Сделай большой тонкий заголовок (`font-weight: 300`).
> 💡 Выбери начертание 300 при подключении, потом `h1 { font-weight: 300; }`.

**10.** Оформи слово внутри абзаца жирным (оберни в `<b>` или класс).
> 💡 `.bold { font-weight: 700; }` или тег `<b>`.

## Свой шрифт

**11.** Подключи скачанный `.woff2` через `@font-face` и примени к заголовку.
> 💡 `@font-face { font-family: "MyFont"; src: url("fonts/файл.woff2"); }`.

**12.** Добавь `font-display: swap` и объясни, зачем он.
> 💡 Текст не «мигает» пустотой при загрузке.

## Собираем

**13.** Собери типографский постер: крупный заголовок одним шрифтом, текст — другим.
> 💡 Тёмный фон, большой `font-size` у заголовка, акцентный цвет.

**14.** Оформи меню кафе двумя шрифтами + кнопка-ссылка «Забронировать».
> 💡 Название — декоративный шрифт, блюда — читаемый; кнопка с прошлого урока.

## Со звёздочкой 🔴

**15.** Сделай короткую запись `font` одной строкой (стиль, вес, размер, семейство).
> 💡 `font: italic 700 22px/1.5 "Montserrat", sans-serif;`.

# Модуль 3 — Контент: ссылки, списки, таблицы

Третий модуль курса WEB. Flex-страницы из Модуля 2 наполняем содержимым и связываем между собой: ссылки и навигация, списки и меню, таблицы данных. Всё раскладываем уже знакомым Flexbox.

> ⬅️ [План курса](../ПЛАН-КУРСА.md) · Предыдущий: [Модуль 2 «Flexbox, семантика и шрифты»](../модуль-02-flexbox-семантика-шрифты/README.md) · Следующий: Модуль 4 «Блочная модель и оформление»

## Уроки

| № | Тема | Что осваиваем | Итоговая практики |
|---|------|---------------|-------------------|
| 1 | [Ссылки](урок-01-ссылки/урок.md) | `<a>`/`href`, `target`, `mailto:`/`tel:`, якоря `#`, `:link/:visited/:hover/:active`, меню-навбар на flex, Emmet `^` | Стартовая страница с навигацией |
| 2 | [Списки](урок-02-списки/урок.md) | `<ul>`/`<ol>`/`<li>`, `<dl>`, `list-style`, вложенные списки, меню из списка на flex, Emmet `ul>li*5` | Топ-5 со списками и меню |
| 3 | [Таблицы](урок-03-таблицы/урок.md) | `table`/`tr`/`td`/`th`/`caption`, `thead`/`tbody`, `colspan`/`rowspan`, `border-collapse`, «зебра» `:nth-child` | Таблица-рейтинг |

- Раскладка (шапка, меню, колонки) — на **Flexbox** из Модуля 2.
- Шрифты — **Google Fonts** / `@font-face` из Модуля 2.
- Структурные селекторы (`:nth-child`) здесь берём как приём для «зебры»; системно — в Модуле 7.

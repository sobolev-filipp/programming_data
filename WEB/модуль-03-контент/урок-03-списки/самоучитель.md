# 🧑‍🏫 Часть A. Разбираем вместе (пошагово)

## 1. Маркированный список `<ul>`

**Тема:** `<ul>` — список с точками; каждый пункт — в `<li>`.

**Задание:** сделай список покупок из 3 пунктов.

**Разбор по шагам:**
1. Открой контейнер: `<ul></ul>`.
2. Внутри добавь пункты: `<li>Хлеб</li>`, `<li>Молоко</li>`, `<li>Сыр</li>`.
3. Сохрани — перед каждым пунктом точка.
4. Emmet-ускорение: `ul>li*3` + Tab.

✅ `<ul><li>Хлеб</li>...</ul>`.

---

## 2. Нумерованный список `<ol>`

**Тема:** `<ol>` — список с номерами; браузер нумерует сам.

**Задание:** сделай список из 3 шагов.

**Разбор по шагам:**
1. Открой `<ol></ol>`.
2. Внутри — пункты `<li>` (те же, что в `<ul>`).
3. Сохрани — пункты пронумерованы 1, 2, 3.
4. Добавь пункт в середину — номера пересчитаются автоматически.

✅ `<ol><li>Шаг</li>...</ol>`.

---

## 3. Меняем маркер

**Тема:** `list-style-type` меняет маркер, `list-style: none` убирает.

**Задание:** смени маркер на квадратики, потом убери совсем.

**Разбор по шагам:**
1. `ul { list-style-type: square; }` — квадратные маркеры.
2. Попробуй `circle` — пустые кружки.
3. `ul { list-style: none; }` — маркеры исчезли.
4. Часто `none` используют для меню и карточек.

✅ `list-style-type: square;` / `list-style: none;`.

---

## 4. Вложенный список

**Тема:** список внутри пункта другого списка — «дерево».

**Задание:** сделай список с подпунктами.

**Разбор по шагам:**
1. Сделай пункт: `<li>Фрукты</li>`.
2. **Внутрь** этого `<li>` (до `</li>`) вложи ещё один `<ul>` с подпунктами.
3. Сохрани — подпункты сдвинулись вправо.
4. Помни: вложенный список — внутри `<li>`, а не между пунктами.

✅ `<li>Фрукты <ul><li>Яблоко</li></ul></li>`.

---

## 5. Меню из списка

**Тема:** меню сайта делают из списка без маркеров, поставив пункты в ряд.

**Задание:** собери горизонтальное меню.

**Разбор по шагам:**
1. Сделай `<ul class="menu">` с 3 пунктами, в каждом — ссылка `<a>`.
2. Убери маркеры и отступ: `.menu { list-style: none; padding: 0; }`.
3. Поставь в ряд: добавь `display: flex; gap: 20px;`.
4. Сохрани — получилось горизонтальное меню.

✅ `.menu { list-style: none; padding: 0; display: flex; gap: 20px; }`.

# ✍️ Часть B. Теперь сам (с мини-подсказкой)

## Виды списков

**6.** Сделай нумерованный список с буквами (A, B, C).
> 💡 `<ol type="A">` или `list-style-type: upper-alpha;`.

**7.** Сделай список с эмодзи-маркерами (без стандартных точек).
> 💡 `list-style: none;` + эмодзи в начале `<li>`.

**8.** Сделай мини-словарик через `<dl>` из 3 пар.
> 💡 `<dt>термин</dt>` + `<dd>описание</dd>` внутри `<dl>`.

## Вложенность

**9.** Собери «дерево»: 2 категории, в каждой по 2 подпункта.
> 💡 Вложенный `<ul>` внутри каждого `<li>`.

**10.** Сделай список «Мой день» (Утро/Вечер) с вложенными делами.
> 💡 Внутри `<li>Утро</li>` — свой `<ul>`.

## Меню и оформление

**11.** Оформи пункты меню как кнопки (фон, padding, скругление, `:hover`).
> 💡 `.menu a { display: inline-block; background: ...; padding: 8px 16px; border-radius: 8px; }`.

**12.** Сделай «Топ-5» нумерованным списком + подключи шрифт с Google Fonts.
> 💡 `<ol>` + `<link>` шрифта + `font-family`.

**13.** Сделай FAQ из `<dl>`, вопросы — жирные.
> 💡 `dt { font-weight: 700; }`.

## Собираем

**14.** Собери страницу «Топ-5»: меню из списка сверху + нумерованный рейтинг + маркированный «почему».
> 💡 Соедини меню (`display: flex`), `<ol>` и `<ul>`.

## Со звёздочкой 🔴

**15.** Поставь спискам свою картинку-маркер через `list-style-image: url(...)`.
> 💡 `ul { list-style-image: url("звезда.png"); }` — `url()` как у шрифтов, путь к файлу.

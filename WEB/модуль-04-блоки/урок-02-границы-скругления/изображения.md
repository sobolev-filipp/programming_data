# 🖼 Изображения и что показать на проекторе · Урок 3 «Скругления и outline»

Схемы в папке `изображения/`. Что показать и что проговорить.

---

## 1. `виды-скругления.svg`
**Когда:** Часть 2 (border-radius глубже).
**Что показать:** мягкие углы (`14px`), «капля» (`46px 0 46px 0`), «таблетка» (`999px`), круг (`50%` — повтор из М1).
**Проговорить:** «border-radius — не только круг. В пикселях — мягкие углы. Разные значения по углам дают «каплю». Огромный радиус (999px) на невысоком блоке — «таблетку». 4 угла идут по часовой с верхнего-левого».

## 2. `вложенное-скругление.svg`
**Когда:** Часть 3 (вложенное скругление). Ключевая схема — по просьбе методиста.
**Что показать:** три карточки: ❌ внутренний = внешнему, ❌ внутренний острый, ✅ внутренний = внешний − padding. Внизу формула.
**Проговорить:** «Когда внутри скруглённой карточки лежит скруглённый блок, их радиусы должны быть согласованы. Правило: внутренний радиус = внешний − padding. Тогда линии углов идут параллельно (концентрично) — аккуратно. Если радиусы одинаковые или внутренний острый — углы «не совпадают».

## 3. `border-vs-outline.svg`
**Когда:** Часть 4 (`outline`).
**Что показать:** слева border (занимает место, двигает соседей, по сторонам), справа outline (не занимает место, рисуется поверх, для `:focus`, `outline-offset`).
**Проговорить:** «border — часть коробки: занимает место и толкает соседей. outline рисуется поверх, снаружи, и место НЕ занимает — соседи не двигаются. Поэтому outline идеален для подсветки выбора (`:focus`)».

---

## 💻 Живая демонстрация (обязательно!)

1. Перебрать `border-radius`: `12px` → `999px` (таблетка) → `40px 0 40px 0` (капля) → `50%`.
2. **Вложенное скругление вживую:** карточка `border-radius:24px; padding:8px` + картинка. Задать картинке 24 (щель), 0 (остро), 16 (идеально) — показать разницу на проекторе.
3. **border vs outline:** три блока в ряд, среднему по очереди `border:8px` (соседи прыгнули) и `outline:8px` (не прыгнули).
4. `outline-offset` — отодвинуть обводку.
5. **Фокус:** нажимать `Tab` по кнопкам/ссылкам — показать обводку; объяснить, почему `outline: none` нельзя.

# 🧰 Лайфхаки · Урок 1 «Семантика»

Трюки и частые ошибки, чтобы строить скелет страницы быстро и правильно.

---

## ⌨️ Emmet — классы и каркас

С этого урока активно используем **классы** через точку:

| Ввод | Развернётся |
|------|-------------|
| `header.top` | `<header class="top"></header>` |
| `nav.menu>ul>li*3>a` | меню-список в `<nav>` |
| `.card` | `<div class="card"></div>` (просто точка = `div` с классом) |
| `main>section>article*3` | main → section → 3 статьи |
| `article>h3+p` | статья с заголовком и абзацем |

> 💡 **Точка без тега = `div`.** `.box` развернётся в `<div class="box">`, потому что `div` — тег по умолчанию. А `span.tag` даст `<span class="tag">`.

**Готовый скелет одной строкой:**
```
header>h1^nav>ul.menu>li*3>a^^main>section>article*2>(h3+p)^^footer>p
```

## 🧭 Как выбрать правильный тег (шпаргалка)

| Что это на странице | Тег |
|---------------------|-----|
| шапка сверху | `<header>` |
| меню-навигация | `<nav>` |
| главное содержимое (одно) | `<main>` |
| тематический раздел | `<section>` |
| новость/пост/карточка (самостоятельная) | `<article>` |
| блок сбоку (похожее, реклама) | `<aside>` |
| подвал снизу | `<footer>` |
| картинка с подписью | `<figure>` + `<figcaption>` |
| кусочек текста | `<span>` |
| «коробка», когда смысла нет | `<div>` |

## 🐞 Частые ошибки и как избежать

- **«Суп из div»** → на каждый смысловой блок есть свой тег. Голый `div` бери, только когда смыслового тега нет.
- **Несколько `<main>`** → `<main>` на странице **один** (главное содержимое одно).
- **`section` без заголовка** → у раздела почти всегда должен быть `h2`/`h3`. Нет заголовка — может, это `<div>`?
- **`article` внутри `article` без нужды** → `article` — для самостоятельных единиц; не вкладывай без причины.
- **`figcaption` без `figure`** → подпись работает только внутри `<figure>`.
- **Думают, что семантика меняет вид** → нет, вид задаёт CSS. Семантика — про смысл.

---

## 💡 Зачем это на самом деле

- **Поисковики** (Google, Яндекс) лучше понимают страницу → сайт выше в поиске (SEO).
- **Незрячие** пользователи со скринридером «перепрыгивают» по разделам (`header` → `main` → `nav`).
- **Код читается** как оглавление — и тебе, и другим разработчикам.
- На реальной работе «суп из div» считается **плохим тоном**.

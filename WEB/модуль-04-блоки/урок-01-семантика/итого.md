# Урок 1 «Семантика» — итого (шпаргалка) 📌

> За 3 минуты вспомнить весь урок. Только суть и примеры.

---

## Главные мысли

1. **Семантический тег** = `<div>` со **смыслом**: выглядит так же, но код понятен людям и программам.
2. **Каркас:** `header` (шапка) · `nav` (меню) · `main` (главное, **один**) · `footer` (подвал).
3. **`section`** — раздел; **`article`** — самостоятельная единица (новость/пост, можно «вырезать»).
4. **`aside`** — блок «сбоку» (похожее, реклама).
5. **`<figure>`/`<figcaption>`** — картинка с подписью.

---

## Скелет страницы

```html
<body>
    <header> <h1>Название</h1> </header>
    <nav> ...меню... </nav>
    <main>
        <section>
            <h2>Раздел</h2>
            <article> <h3>Новость</h3> <p>...</p> </article>
            <article> ... </article>
        </section>
        <aside> <h3>Читайте также</h3> ... </aside>
    </main>
    <footer> <p>© 2026</p> </footer>
</body>
```

| Тег | Что это |
|-----|---------|
| `header` | шапка (вверху) |
| `nav` | навигация (меню) |
| `main` | главное (один на странице) |
| `section` | смысловой раздел |
| `article` | самостоятельная единица |
| `aside` | блок сбоку |
| `footer` | подвал |

---

## Картинка с подписью

```html
<figure>
    <img src="foto.jpg" alt="Описание">
    <figcaption>Подпись к фото</figcaption>
</figure>
```

---

## div / span / display

```css
div  { display: block; }         /* блок, в столбик */
span { display: inline; }        /* кусочек текста в строке */
.x   { display: inline-block; }  /* в ряд + размеры */
```
Семантические теги — все **блочные**, как `div`. Отличие — в смысле.

## Emmet — новое

| Ввод | Результат |
|------|-----------|
| `header.top` | `<header class="top">` (точка = класс) |
| `nav.menu>a*3` | `<nav class="menu">` с 3 ссылками |
| `main>section>article*2` | main → section → 2 статьи |

---

## Как выбрать тег

- Есть смысловой тег (`header`/`nav`/`article`…) → **бери его**.
- Нет → `<div>` (блок) или `<span>` (кусочек текста).
- «Можно опубликовать отдельно?» Да → `article`. Группа/тема → `section`.

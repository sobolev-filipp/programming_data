# 🧰 Лайфхаки · Урок 5 «Градиенты и карточки»

Трюки и частые ошибки для эффектного визуала.

---

## 🌈 Градиенты — быстро и красиво

- **Не подбирай вручную** — генератор [cssgradient.io](https://cssgradient.io/): крутишь цвета мышкой, копируешь готовый CSS.
- **Палитру** для градиента бери на [get-color.ru/color-wheel](https://get-color.ru/color-wheel/) (аналоговые цвета дают мягкий градиент, контрастные — «кислотный»).
- **Много цветов** — просто через запятую: `linear-gradient(90deg, c1, c2, c3, c4)`.
- **Направление:** `to right`, `to bottom`, `135deg`. Диагональ (`135deg`) обычно смотрится дороже.
- **Резкая граница** (флаг, полоса): повтори цвет с одинаковыми `%`: `linear-gradient(#22c55e 50%, #16a34a 50%)`.

---

## 🎨 Градиентный текст — рецепт

```css
.grad-text {
    background: linear-gradient(90deg, #6366f1, #ec4899);
    background-clip: text;
    -webkit-background-clip: text;   /* обязательно для Chrome/Safari */
    color: transparent;
}
```
Забыл `color: transparent` → текст не переливается. Забыл `background-clip: text` → текст исчез целиком.

---

## 🧊 Стекло (glassmorphism) — рецепт

```css
.glass {
    background: rgba(255,255,255,.15);   /* фон-фолбэк — ВСЕГДА */
    backdrop-filter: blur(12px);
    -webkit-backdrop-filter: blur(12px); /* Safari */
    border: 1px solid rgba(255,255,255,.3);
    border-radius: 16px;
}
```
- Работает **только поверх пёстрого фона** (градиент/фото).
- Если браузер не поддержит `backdrop-filter` — останется полупрозрачная карточка (тоже норм).

---

## ✨ Неон и свечение

- Свечение = тень **без смещения**, крупное размытие, цвет в `rgba`: `box-shadow: 0 0 24px rgba(236,72,153,.7)`.
- Усиль на `:hover` + `transition` — кнопка «пульсирует».
- Неоновый текст: `text-shadow: 0 0 10px currentColor`.

---

## 🐞 Частые ошибки и как избежать

- **Градиент не появился** → написал в `color`, а надо в `background`.
- **Градиентный текст пропал** → нет `background-clip: text`; или не виден → нет `color: transparent`.
- **Стекло не размывает** → фон под ним однотонный (нужен градиент/фото).
- **«Кислотный» градиент** → взял слишком контрастные цвета; бери соседние по кругу.
- **conic не круглый** → забыл `border-radius: 50%` на блоке.

---

## 🧭 Про Baseline (современный CSS)

Все свойства урока — **Baseline** (работают во всех свежих браузерах): `conic-gradient`, `background-clip: text`, `backdrop-filter`. Единственное — для `backdrop-filter` держи фон-`rgba` как фолбэк, и дублируй `-webkit-` для Safari.

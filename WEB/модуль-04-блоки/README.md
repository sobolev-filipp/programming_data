# Модуль 4 — Блочная модель и оформление

Четвёртый модуль курса WEB. Понимаем «прямоугольник» элемента (box-model) и учимся делать **красивые блоки** — это база всего визуала. Блоки раскладываем Flexbox из Модуля 2; то, что раньше бралось как рецепт (`padding`, фон), здесь разбираем системно.

> ⬅️ [План курса](../ПЛАН-КУРСА.md) · Предыдущий: [Модуль 3 «Контент: ссылки, списки, таблицы»](../модуль-03-контент/README.md) · Следующий: Модуль 5 «Figma и вёрстка по макету»

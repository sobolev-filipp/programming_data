# 🧰 Лайфхаки · Урок 4 «Картинки в блоках, тени и фоны»

Трюки и частые ошибки для красивых карточек и обложек.

---

## 🖼 Картинки в блоках

- **Золотая пара обложки:** `aspect-ratio` + `object-fit: cover` — блок держит форму, фото заполняет без искажений.
- **object-position** уточняет кадр при `cover`: `object-position: top` (не «отрежет головы» на портретах).
- **Обрезка по углам:** скруглённой карточке дай `overflow: hidden` — обложка обрежется по скруглению.
- **`<img>` или фон?** Содержание (товар, аватар, фото статьи) → `<img>` + `alt`. Украшение (баннер, узор) → `background-image`.

---

## 🌫️ Тени — как делать красиво

- Цвет тени — **всегда полупрозрачный** `rgba(0,0,0,.15)`, не чёрный сплошной.
- **Мягкая, «дорогая» тень:** большое размытие, маленькое смещение: `0 10px 30px rgba(0,0,0,.12)`.
- **Многослойность:** две-три тени через запятую выглядят натуральнее одной.
- **Подъём при наведении:** `:hover` + бо́льшая тень + `transform: translateY(-4px)` + `transition`.
- **Свечение:** `box-shadow: 0 0 20px rgba(цвет, .6)` без смещения — «неон».
- **`inset`** — тень внутрь (вдавленные поля, переключатели).

---

## 🎨 Фоны

```css
/* короткая запись — всё сразу */
background: url("fon.jpg") center / cover no-repeat;
```
- `center / cover` — позиция / размер (не перепутай: размер после `/`).
- Узор-плитка: маленькая картинка + `background-repeat: repeat` (без `cover`).
- Затемнить фото под текст: наложи `linear-gradient(rgba(0,0,0,.5), rgba(0,0,0,.5))` **поверх** url (несколько фонов через запятую) — разберём градиенты на след. уроке.

## ⚡ Оптимизация (важно!)

- Тяжёлые фото **тормозят** сайт. Сжимай их на [squoosh.app](https://squoosh.app) и бери формат **`.webp`**.
- Не ставь фото 4000px в блок 300px — уменьшай заранее.

## 🐞 Частые ошибки и как избежать

- **Фото растянулось/сплющилось** → стоит `object-fit: fill` (по умолчанию). Ставь `cover`.
- **Ряд карточек «прыгает» по высоте** → у обложек разная высота. Дай `aspect-ratio`.
- **Тень выглядит грязной** → цвет без прозрачности. Бери `rgba`.
- **Фон повторился плиткой** → нет `no-repeat`.
- **Обложка вылезла за скруглённые углы** → карточке нужен `overflow: hidden`.
- **Забыл `alt` у `<img>`** → важно для доступности и SEO.

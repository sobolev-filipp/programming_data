# 🧩 Самостоятельная работа · Модуль 3 «Блочная модель и красивые блоки»

**Витрина интернет-магазина «3 товара»** 🛒

> Это итог всего модуля. Задание **конкретное**: ты делаешь страницу-витрину небольшого интернет-магазина с **ровно тремя карточками товаров**. Применяешь всё из модуля: семантику, блочную модель, скругления и тени, картинки в блоках (`object-fit`), фоны и градиенты. Можно подглядывать в шпаргалки (`итого.md`), но не копировать чужой код.

---

## 🎯 Задание

Сделай **главную страницу интернет-магазина** — как настоящий онлайн-магазин, но маленький: шапка с меню, баннер и **три карточки товара** в ряд.

**Выбери, что продаёт твой магазин** (одно из):
- 🎮 видеоигры · 👟 кроссовки · 🎧 гаджеты · 🍬 сладости · 📚 книги.

Придумай магазину **название** и подбери **3 конкретных товара** этой категории. Больше ничего выдумывать не нужно — структура задана ниже, твоя задача — **аккуратно и красиво её собрать**.

**Пример:** магазин кроссовок «STEP» → товары «Air Runner», «Neon Boost», «Classic White».

## 📋 Что должно быть на странице (структура задана)

1. **Шапка `<header>`:** название магазина (логотип) слева и **меню `<nav>`** из 3 пунктов: «Каталог», «Акции», «Контакты» (можно якоря `#`).
2. **Баннер-герой `<section>`** с **градиентным фоном**: крупный заголовок (название магазина или слоган, можно **градиентным текстом**) и кнопка «В каталог».
3. **Каталог `<main>` — ровно 3 карточки товара `<article>`** в ряд, **в одном стиле**. Каждая карточка содержит:
   - **обложку товара** — `<img>` с `object-fit: cover` (одинаковый размер у всех);
   - **название** товара;
   - **короткое описание** (1 строка);
   - **цену** (например, «4 990 ₽»);
   - **бейдж-«таблетку»** («Хит» / «-20%» / «NEW») в углу;
   - **кнопку «В корзину»** с эффектом `:hover`.
4. **Подвал `<footer>`:** копирайт и контакты.
5. Всё оформление — во внешнем **`style.css`**.

---

## ✅ Требования (проверь по списку)

- ✅ семантика: `header`(+`nav`), `main` с тремя `article`, `footer`;
- ✅ применён **`box-sizing: border-box`** (`* { box-sizing: border-box; }`);
- ✅ баннер с **градиентом** (фон и/или градиентный заголовок);
- ✅ 3 карточки **в одном стиле**: `border-radius`, `padding`, **`box-shadow`** (тень `rgba`), `overflow: hidden`;
- ✅ обложки товаров через **`object-fit: cover`** (не растянуты, одинаковый размер);
- ✅ на каждой карточке — **бейдж-«таблетка»** (`border-radius: 999px`) и **цена**;
- ✅ кнопка «В корзину» реагирует на **`:hover`**;
- ✅ гармоничная палитра, страница цельная (не «обрывок»), без «кракозябр» и «сломанных» картинок.

## 💡 Подсказки (как что сделать)

| Что нужно | Приём / свойство |
|-----------|------------------|
| каркас | `header>nav` → `main`(3× `article`) → `footer` |
| ровные обложки | `.cover { aspect-ratio: 4/3; object-fit: cover; width:100%; }` |
| объём карточки | `box-shadow: 0 6px 18px rgba(0,0,0,.12)` |
| обрезать обложку по углам | карточке `overflow: hidden` + `border-radius` |
| бейдж в углу | `position: relative` у карточки + `position: absolute; top/right` у бейджа |
| «таблетка»-бейдж | `border-radius: 999px; padding: 4px 12px` |
| градиентный заголовок | `background: linear-gradient(...); background-clip:text; color:transparent` |
| 3 карточки в ряд | `display: flex; gap: 20px;` (рабочий рецепт) |
| подъём при наведении | `.card:hover { box-shadow:...; transform: translateY(-4px); }` + `transition` |
| палитра / градиент | [get-color.ru/color-wheel](https://get-color.ru/color-wheel/) · [cssgradient.io](https://cssgradient.io/) |

**Порядок работы:** ① название магазина + 3 товара → ② каркас (шапка, баннер, 3 пустые карточки, подвал) → ③ обложки и тексты (можно ИИ) → ④ оформи **одну** карточку до конца (обложка, тень, скругление, бейдж, цена, кнопка) → ⑤ скопируй её стиль на все три → ⑥ баннер с градиентом, `:hover`. Сделай красиво одну — остальные повторят.

## 📊 Как оценивается

| Что смотрим | Баллы |
|-------------|-------|
| Семантический каркас (`header`+`nav`/`main`/3×`article`/`footer`) | 3 |
| Баннер с градиентом (фон/текст) + кнопка | 3 |

| Обложки через `object-fit: cover` + `overflow: hidden` | 3 |

| Гармоничная палитра, цельность страницы, аккуратность | 3 |

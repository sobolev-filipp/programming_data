# 🧑‍🏫 Часть A. Разбираем вместе (пошагово)

## 1. object-fit: cover

**Тема:** `object-fit` управляет тем, как картинка ложится в блок с заданным размером.

**Задание:** впиши фото в блок 280×180 без искажений.

**Разбор по шагам:**
1. `img { width: 280px; height: 180px; }` — фото растянулось (некрасиво).
2. Добавь `object-fit: cover;` — фото заполнило блок, лишнее обрезалось.
3. Сравни с `object-fit: fill` (растяжение) и `contain` (с полями).
4. `cover` — то, что нужно для обложек.

✅ `img { object-fit: cover; }`.

---

## 2. aspect-ratio

**Тема:** блок сам держит пропорцию, высота считается от ширины.

**Задание:** сделай обложку 16:9.

**Разбор по шагам:**
1. `.cover { width: 100%; }`.
2. Добавь `aspect-ratio: 16 / 9;` — высота посчиталась сама.
3. Добавь `object-fit: cover;` — фото красиво заполнит.
4. Меняй ширину — пропорция сохраняется.

✅ `.cover { aspect-ratio: 16/9; object-fit: cover; }`.

---

## 3. box-shadow

**Тема:** тень даёт блоку объём; цвет тени — полупрозрачный.

**Задание:** добавь карточке мягкую тень.

**Разбор по шагам:**
1. `.card { box-shadow: 0 6px 18px rgba(0,0,0,.15); }`.
2. Порядок: смещение-X, смещение-Y, размытие, цвет.
3. Цвет — `rgba(...)` (полупрозрачный), иначе тень «грязная».
4. Попробуй `inset` — тень уйдёт внутрь.

✅ `box-shadow: 0 6px 18px rgba(0,0,0,.15);`.

---

## 4. background-image

**Тема:** картинка как фон блока через `url()` + `background-size: cover`.

**Задание:** сделай баннер с фоновым фото.

**Разбор по шагам:**
1. `.hero { height: 300px; }`.
2. `background-image: url("fon.jpg");`.
3. `background-size: cover; background-position: center; background-repeat: no-repeat;`.
4. Короче: `background: url("fon.jpg") center / cover no-repeat;`.

✅ фон заполняет блок, не повторяется.

---

## 5. Объёмная карточка (сборка)

**Тема:** обложка + скругление + тень + наведение.

**Задание:** собери карточку с обложкой.

**Разбор по шагам:**
1. `.card { border-radius: 16px; overflow: hidden; box-shadow: 0 6px 18px rgba(0,0,0,.12); }`.
2. Обложка: `.cover { width:100%; aspect-ratio:16/9; object-fit:cover; display:block; }`.
3. Текст в `.body { padding: 14px; }`.
4. Наведение: `.card:hover { box-shadow: 0 14px 30px rgba(0,0,0,.2); transform: translateY(-4px); }` + `transition:.2s`.

✅ объёмная карточка с ровной обложкой.

# ✍️ Часть B. Теперь сам (с мини-подсказкой)

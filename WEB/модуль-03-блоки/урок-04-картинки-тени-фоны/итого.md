# Урок 4 «Картинки в блоках, тени и фоны» — итого 📌

> За 3 минуты вспомнить весь урок. Только суть и примеры.

---

## Главные мысли

1. **`object-fit: cover`** вписывает фото в блок **без искажений** (лишнее обрезает).
2. **`aspect-ratio`** держит пропорцию блока (`16/9`, `1/1`) — ряды карточек ровные.
3. **`box-shadow`** даёт объём; цвет тени — полупрозрачный `rgba`.
4. **`background-image: url(...)`** + `background-size: cover` — картинка-фон.
5. **`<img>`** — картинка-содержание; **`background-image`** — картинка-украшение.

---

## object-fit + aspect-ratio

```css
.cover {
    width: 100%;
    aspect-ratio: 16 / 9;   /* пропорция, высота сама */
    object-fit: cover;      /* заполнить без искажений */
    object-position: center;
}
```
| object-fit | что |
|-----------|-----|
| `fill` | растянуть (искажает) ❌ |
| `contain` | целиком, с полями |
| `cover` ⭐ | заполнить, обрезать |

---

## box-shadow

```css
box-shadow: 0 6px 18px rgba(0,0,0,.15);        /* X Y blur цвет */
box-shadow: inset 0 2px 6px rgba(0,0,0,.2);    /* внутрь */
box-shadow: 0 2px 4px rgba(0,0,0,.1), 0 8px 24px rgba(0,0,0,.1); /* две тени */
```
Порядок: **X · Y · blur · [spread] · цвет**. Цвет — полупрозрачный.

**Подъём при наведении:**
```css
.card { box-shadow: 0 4px 12px rgba(0,0,0,.1); transition:.2s; }
.card:hover { box-shadow: 0 12px 28px rgba(0,0,0,.2); transform: translateY(-4px); }
```

---

## background-image

```css
.hero {
    background: url("fon.jpg") center / cover no-repeat;
    height: 300px;
}
```
`background-size`: cover/contain · `position`: center/top · `repeat`: no-repeat/repeat.

**`<picture>`** — разные файлы под разные экраны:
```html
<picture>
    <source media="(max-width:600px)" srcset="mobile.jpg">
    <img src="desktop.jpg" alt="...">
</picture>
```

## Главные ошибки

| Проблема | Причина | Лечение |
|----------|---------|---------|
| фото растянулось | нет `object-fit` (стоит `fill`) | `object-fit: cover` |
| ряд карточек «прыгает» | у обложек разная высота | `aspect-ratio` + `cover` |
| тень «грязная» | цвет без прозрачности | `rgba(0,0,0,.15)` |
| фон повторяется плиткой | нет `no-repeat` | `background-repeat: no-repeat` |
| обложка вылезает за углы | нет обрезки | карточке `overflow: hidden` |

---

## Что осталось в голове

1. Вписываю фото в блок через `object-fit: cover`.
2. Держу пропорции через `aspect-ratio`.
3. Добавляю объём тенью `box-shadow` (rgba).
4. Ставлю фон `background: url(...) center/cover no-repeat`.

# 🧑‍🏫 Часть A. Разбираем вместе (пошагово)

## 1. linear-gradient

**Тема:** градиент — это фон (`background`), плавный переход цвета по прямой.

**Задание:** сделай блок с линейным градиентом.

**Разбор по шагам:**
1. `.box { height: 150px; }`.
2. `background: linear-gradient(to right, #2563eb, #7c3aed);`.
3. Поменяй направление на `135deg` (диагональ).
4. Добавь третий цвет через запятую.

✅ `background: linear-gradient(135deg, #2563eb, #7c3aed);`.

---

## 2. radial и conic

**Тема:** `radial` — из центра, `conic` — по кругу.

**Задание:** сделай радиальный и конический градиенты.

**Разбор по шагам:**
1. Радиальный: `background: radial-gradient(circle, #fde047, #ea580c);`.
2. Конический на круге: блок `border-radius: 50%`.
3. `background: conic-gradient(red, orange, yellow, green, blue, violet, red);`.
4. Получился радужный диск.

✅ `radial-gradient(...)` и `conic-gradient(...)`.

---

## 3. Градиент к тексту

**Тема:** фон виден сквозь буквы через `background-clip: text`.

**Задание:** покрась заголовок градиентом.

**Разбор по шагам:**
1. `.grad { font-size: 48px; font-weight: 800; }`.
2. `background: linear-gradient(90deg, #6366f1, #ec4899);`.
3. `background-clip: text; -webkit-background-clip: text;`.
4. `color: transparent;` — сам текст прозрачный, виден градиент.

✅ 4 строки: background + clip(×2) + transparent.

---

## 4. Стекломорфизм

**Тема:** матовое стекло = полупрозрачный фон + `backdrop-filter: blur`.

**Задание:** сделай стеклянную карточку.

**Разбор по шагам:**
1. Сделай `body` с градиентным фоном (иначе размывать нечего).
2. Карточке: `background: rgba(255,255,255,.15);`.
3. `backdrop-filter: blur(12px);`.
4. Добавь `border: 1px solid rgba(255,255,255,.3); border-radius: 16px;`.

✅ `rgba` + `backdrop-filter: blur()` поверх градиента.

---

## 5. Неоновая кнопка

**Тема:** градиент + свечение через тень.

**Задание:** сделай светящуюся кнопку.

**Разбор по шагам:**
1. `.btn { background: linear-gradient(90deg,#6366f1,#ec4899); border-radius:999px; color:#fff; padding:12px 28px; }`.
2. Свечение: `box-shadow: 0 0 20px rgba(236,72,153,.6);`.
3. `:hover` — усиль свечение и `translateY(-2px)`, добавь `transition:.2s`.
4. `:focus { outline: 3px solid #fff; outline-offset: 3px; }` — доступность.

✅ градиент + `box-shadow` свечение + hover/focus.

# ✍️ Часть B. Теперь сам (с мини-подсказкой)

## Градиенты

**6.** Сделай градиент из 4 цветов по диагонали.
> 💡 `linear-gradient(135deg, c1, c2, c3, c4)`.

**7.** Сделай радиальный градиент со смещённым центром.
> 💡 `radial-gradient(circle at top left, ...)`.

**8.** Сделай радужный диск через `conic-gradient`.
> 💡 Круглый блок + `conic-gradient(...)`.

## Текст и рамка

**9.** Сделай градиентный заголовок.
> 💡 background + `background-clip: text` + `color: transparent`.

**10.** Сделай карточку с градиентной рамкой.
> 💡 `border: 3px solid transparent` + два фона (`padding-box`/`border-box`).

**11.** Сделай неоновую кнопку со свечением и hover.
> 💡 Градиент + `box-shadow: 0 0 20px rgba(...)`.

## Стекло

**12.** Сделай стеклянную карточку на градиентном фоне.
> 💡 `rgba` + `backdrop-filter: blur(12px)`.

**13.** Сделай стеклянное меню-панель поверх фона.
> 💡 Та же формула стекла на широком блоке.

## Собираем

**14.** Собери секцию: градиентный фон + градиентный заголовок + стеклянная карточка + неоновая кнопка.
> 💡 Соедини задания 9, 12, 11 на одном градиентном фоне.

## Со звёздочкой 🔴

# Урок 5 «Градиенты и карточки» — итого 📌

> За 3 минуты вспомнить весь урок. Только суть и примеры.

---

## Главные мысли

1. Градиент — это **фон, нарисованный кодом** (плавный переход цветов). Пишется в `background`.
2. **3 вида:** `linear` (по прямой), `radial` (из центра), `conic` (по кругу).
3. **Градиент к тексту:** `background-clip: text` + `color: transparent`.
4. **Стекло:** `rgba` + `backdrop-filter: blur()` (фон-`rgba` — всегда, как фолбэк).
5. Всё это — **Baseline**, работает в свежих браузерах.

---

## Три градиента

```css
background: linear-gradient(135deg, #2563eb, #7c3aed);         /* по прямой */
background: radial-gradient(circle, #fde047, #ea580c);          /* из центра */
background: conic-gradient(red, orange, yellow, green, blue);   /* по кругу */
```
Цветов — сколько угодно (через запятую). Направление: `to right`, `135deg`.

---

## Градиент к тексту 🎨

```css
.grad {
    background: linear-gradient(90deg, #6366f1, #ec4899);
    background-clip: text;
    -webkit-background-clip: text;
    color: transparent;
}
```

---

## Градиентная рамка

```css
.b {
    border: 3px solid transparent;
    border-radius: 16px;
    background:
        linear-gradient(#fff,#fff) padding-box,
        linear-gradient(135deg,#6366f1,#ec4899) border-box;
}
```

---

## Стекломорфизм 🧊

```css
.glass {
    background: rgba(255,255,255,.15);   /* всегда — фолбэк */
    backdrop-filter: blur(12px);
    border: 1px solid rgba(255,255,255,.3);
    border-radius: 16px;
}
```
Работает поверх пёстрого фона (градиент/фото).

**Неоновая кнопка:** `background: linear-gradient(...)` + `box-shadow: 0 0 20px rgba(цвет,.6)`.

---

## Главные ошибки

| Проблема | Причина | Лечение |
|----------|---------|---------|
| градиентный текст не виден | нет `color: transparent` | добавь его + `background-clip: text` |
| текст стал невидим совсем | нет `background-clip: text` | обрежь фон по буквам |
| стекло «не размывает» | фон под ним однотонный | клади на градиент/фото |
| градиент не появился | написал в `color`, а не `background` | градиент — это фон |

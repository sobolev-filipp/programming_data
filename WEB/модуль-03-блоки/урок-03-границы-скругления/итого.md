# Урок 3 «Скругления и outline» — итого (шпаргалка) 📌

> За 3 минуты вспомнить весь урок. Только суть и примеры.

---

## Главные мысли

1. **`border-radius`** — не только круг: `px`, 4 угла отдельно, «таблетка» `999px`, «капля».
2. **Вложенное скругление:** внутренний радиус = **внешний − padding**.
3. **`outline`** рисуется **снаружи** и **не занимает место** (в отличие от `border`).
4. **`outline-offset`** — зазор между обводкой и блоком.
5. **`:focus` + `outline`** — обводка выбора; **не убирай совсем** (доступность).

---

## border-radius — формы

```css
.card { border-radius: 14px; }              /* мягкие углы */
.leaf { border-radius: 40px 0 40px 0; }     /* «капля» (4 угла по часовой) */
.pill { border-radius: 999px; padding: 6px 16px; }  /* «таблетка» */
.round{ border-radius: 50%; }               /* круг (квадрат) */
```
4 угла: **верх-лево · верх-право · низ-право · низ-лево** (по часовой).

---

## Вложенное скругление 🎯

```css
.card    { border-radius: 24px; padding: 8px; }
.card img{ border-radius: 16px; }   /* 24 − 8 = 16 → углы параллельны */
```
**внутренний = внешний − padding** (концентричные углы).

---

## border vs outline

| | `border` | `outline` |
|---|----------|-----------|
| место занимает | да | **нет** |
| двигает соседей | да | **нет** |
| по сторонам | да | нет |
| зачем | рамки | обводка `:focus` |

```css
.box {
    outline: 3px solid #6366f1;
    outline-offset: 4px;
}
.btn:focus { outline: 3px solid #a5b4fc; outline-offset: 3px; }
```

---

## Главные ошибки

| Проблема | Причина | Лечение |
|----------|---------|---------|
| углы карточки и картинки «не совпали» | одинаковый радиус | внутренний = внешний − padding |
| соседи «сдвинулись» от рамки | использовал `border` | для подсветки бери `outline` |
| с клавиатуры не видно выбор | убрал `outline: none` | не убирай, а замени на свой |
| «таблетка» кривая | подбирал радиус вручную | ставь `999px` |

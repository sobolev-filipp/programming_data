# 🧰 Лайфхаки · Урок 3 «Скругления и outline»

Трюки и частые ошибки, чтобы делать формы и обводки красиво.

---

## 🟢 border-radius — приёмы

- **«Таблетка» без подбора:** `border-radius: 999px` — края всегда идеально полукруглые при любой высоте. Для тегов, бейджей, кнопок-пилюль.
- **Скруглить только верх** (обложки карточек): `border-radius: 16px 16px 0 0` (верх-лево, верх-право, низ-право, низ-лево).
- **4 угла — по часовой:** верх-лево → верх-право → низ-право → низ-лево.
- **Круг:** `border-radius: 50%` только на **квадрате** (иначе овал).
- **Эллипс:** `border-radius: 40px / 20px` — радиус по X и по Y разный.

---

## 🎯 Вложенное скругление — золотое правило

```
внутренний радиус = внешний радиус − padding
```
Карточка `border-radius: 24px; padding: 8px;` → внутренний блок `border-radius: 16px`.
Так углы идут **параллельно** (концентрично) — выглядит профессионально. Это то, что отличает аккуратную вёрстку от «на глаз».

---

## ⭕ border vs outline — когда что

| Нужно | Бери |
|-------|------|
| рамка-оформление, по сторонам, скругление | **`border`** |
| подсветить выбор, не сдвинув соседей | **`outline`** |
| обводка при `Tab` (`:focus`) | **`outline`** |

- `outline` **не занимает место** → идеален для подсветки.
- `outline-offset` — зазор между обводкой и блоком (можно и отрицательный — обводка «внутрь»).

---

## ♿ Доступность — важно

- **Никогда** не пиши `outline: none` без замены — человек с клавиатурой перестанет видеть, где он.
- Если стандартная обводка мешает — **замени** своей: `:focus { outline: 3px solid #6366f1; outline-offset: 3px; }`.
- Ещё лучше — **`:focus-visible`**: обводка при `Tab`, но не при клике мышью.

---

## 🐞 Частые ошибки и как избежать

- **Углы карточки и картинки «не совпали»** → одинаковый радиус. Считай: внутренний = внешний − padding.
- **Соседи «прыгнули» от рамки** → для подсветки бери `outline`, а не `border`.
- **`border-radius: 50%` дал овал** → картинка не квадратная.
- **С клавиатуры не видно фокус** → убрал `outline`. Верни/замени.
- **«Таблетка» кривая** → подбирал радиус вручную; ставь `999px`.

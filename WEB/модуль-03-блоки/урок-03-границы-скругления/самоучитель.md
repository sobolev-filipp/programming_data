# 🧑‍🏫 Часть A. Разбираем вместе (пошагово)

## 1. border-radius в пикселях

**Тема:** `border-radius` скругляет углы; в `px` — мягкие углы карточек.

**Задание:** скругли карточку.

**Разбор по шагам:**
1. Сделай `.card { background: #e0e7ff; padding: 20px; }`.
2. Добавь `border-radius: 16px;` — углы стали мягкими.
3. Поменяй на 8 и 32 — сравни.
4. Чем больше значение, тем круглее углы.

✅ `.card { border-radius: 16px; }`.

---

## 2. «Таблетка» (pill)

**Тема:** очень большой радиус на невысоком блоке = полукруглые края.

**Задание:** сделай тег-таблетку.

**Разбор по шагам:**
1. Сделай `<span class="pill">#тег</span>`.
2. `.pill { display: inline-block; padding: 6px 16px; background: #dbeafe; }`.
3. Добавь `border-radius: 999px;` — края стали полукруглыми.
4. Работает при любой высоте — не надо подбирать вручную.

✅ `.pill { border-radius: 999px; }`.

---

## 3. Вложенное скругление

**Тема:** внутренний радиус = внешний − padding (углы параллельны).

**Задание:** правильно скругли картинку в карточке.

**Разбор по шагам:**
1. `.card { border-radius: 24px; padding: 8px; }`.
2. Посчитай: 24 − 8 = 16.
3. `.card img { border-radius: 16px; width: 100%; }`.
4. Углы карточки и картинки идут параллельно — красиво.

✅ внутренний = внешний − padding.

---

## 4. outline и чем он отличается от border

**Тема:** `outline` рисуется снаружи и НЕ занимает место.

**Задание:** сравни border и outline.

**Разбор по шагам:**
1. Сделай три блока в ряд.
2. Среднему добавь `border: 8px solid` — соседи сдвинулись.
3. Замени на `outline: 8px solid` — соседи НЕ сдвинулись.
4. Вывод: `outline` не входит в размер блока.

✅ `outline` не двигает соседей.

---

## 5. :focus и доступность

**Тема:** обводка при переходе `Tab`; убирать её нельзя.

**Задание:** сделай красивый фокус кнопки.

**Разбор по шагам:**
1. Сделай кнопку `.btn`.
2. `.btn:focus { outline: 3px solid #a5b4fc; outline-offset: 3px; }`.
3. Нажимай `Tab` на странице — обводка появится без мыши.
4. Не пиши `outline: none` — иначе с клавиатуры не видно выбор.

✅ красивый `:focus`, обводку не убираем.

# ✍️ Часть B. Теперь сам (с мини-подсказкой)

## Формы

**6.** Сделай «каплю» — скругли два противоположных угла.
> 💡 `border-radius: 40px 0 40px 0;`.

**7.** Сделай круглую аватарку (повтор из М1).
> 💡 Квадратная картинка + `border-radius: 50%`.

**8.** Сделай 4 «таблетки»-статуса разных цветов.
> 💡 `.pill { border-radius: 999px; }` + модификаторы цвета.

## outline

**9.** Добавь блоку `outline` и отодвинь его через `outline-offset`.
> 💡 `outline: 3px solid #6366f1; outline-offset: 5px;`.

**10.** Сравни: соседи двигаются при `border`, но не при `outline`.
> 💡 Три блока, среднему по очереди border/outline.

**11.** Сделай кнопку с красивым `:focus`, проверь `Tab`.
> 💡 `.btn:focus { outline: 3px solid #a5b4fc; outline-offset: 3px; }`.

## Вложенность

**12.** Карточка `border-radius: 20px; padding: 10px` + картинка с правильным радиусом.
> 💡 20 − 10 = 10 → `img { border-radius: 10px; }`.

**13.** Собери карточку профиля: круглый аватар + теги-таблетки.
> 💡 Аватар `50%`, теги `999px`.

## Со звёздочкой 🔴

**14.** Сделай эллиптические углы через дробь.
> 💡 `border-radius: 40px / 20px;`.

**15.** Сделай `:focus-visible` (обводка только при Tab, не при клике).
> 💡 `.btn:focus-visible { outline: 3px solid #6366f1; }`.

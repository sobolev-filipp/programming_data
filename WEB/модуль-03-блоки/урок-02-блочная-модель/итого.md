# Урок 2 «Блочная модель» — итого (шпаргалка) 📌

> За 3 минуты вспомнить весь урок. Только суть и примеры.

---

## Главные мысли

1. Каждый элемент — **коробка** из 4 слоёв: **content · padding · border · margin**.
2. **`padding`** — воздух **внутри** блока; **`margin`** — расстояние **снаружи**, между блоками.
3. **`box-sizing: border-box`** — обязательно: `width` включает padding и border.
4. **`margin: 0 auto`** центрирует блок (нужна `width`).
5. Вертикальные `margin` **схлопываются** — берётся больший.

---

## Блочная модель

```
┌─────────── margin (снаружи) ───────────┐
│  ┌──────── border (рамка) ─────────┐   │
│  │  ┌───── padding (внутри) ────┐  │   │
│  │  │        content            │  │   │
│  │  └───────────────────────────┘  │   │
│  └─────────────────────────────────┘   │
└─────────────────────────────────────────┘
```

---

## padding и margin

```css
padding: 20px;                 /* все стороны */
padding: 10px 20px;            /* верх-низ / лево-право */
padding: 10px 20px 30px 40px;  /* T R B L (по часовой) */
margin: 0 auto;                /* центрируем блок (нужна width) */
margin-bottom: 30px;           /* отступ снизу */
```
`padding` = внутри · `margin` = снаружи · синтаксис сторон одинаковый.

---

## border: толщина · тип · цвет

```css
border: 3px solid  #6366f1;   /* сплошная */
border: 3px dashed #6366f1;   /* штрихами (пунктир) */
border: 3px dotted #6366f1;   /* точками */
border: 3px double #6366f1;   /* двойная */
border-bottom: 2px dashed #ccc;  /* только снизу */
```
Скругление углов (`border-radius`) и `outline` — на след. уроке.

---

## Обязательный сброс (в начало файла)

```css
* {
    box-sizing: border-box;
    margin: 0;
    padding: 0;
}
```
С `border-box` ширина `width` = content + padding + border (что задал, то и получил).

---

## Схлопывание отступов

```css
.a { margin-bottom: 30px; }
.b { margin-top: 20px; }
/* между ними 30px (больший), а НЕ 50px */
```
Только по вертикали, у соседних блоков.

---

## DevTools (F12)

Elements → навести на блок → внизу схема: content (синий) · padding (зелёный) · border · margin (оранжевый) с числами. Можно менять на месте.

---

## Главные ошибки

| Проблема | Причина | Лечение |
|----------|---------|---------|
| блок шире, чем задал | нет `border-box` | `* { box-sizing: border-box; }` |
| текст липнет к краю | нет `padding` | `padding: 20px` |
| `margin: auto` не центрирует | не задана `width` | задать `width` блоку |
| отступ «меньше» ожидаемого | схлопывание margin | это норма; или `padding` у родителя |

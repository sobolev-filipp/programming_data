# 📝 Практика · Урок 2 «Блочная модель»

**Темы:** блочная модель (content/padding/border/margin), `padding`, `margin`, `margin: 0 auto`, `box-sizing: border-box`, схлопывание отступов, DevTools. Плюс повторяем семантику и оформление блоков.

> 🎯 **Как работать.** Делай в файлах `.html`/`.css`, смотри результат в браузере через Live Server (сохраняй — `Ctrl+S`). **Активно пользуйся DevTools (F12)** — смотри коробку блока. Уровни: 🟢 базовые · 🟡 средние · 🔴 со звёздочкой. 💡 подсказка — это наводка, а не готовый код.
>
> 📌 **Правила игры:** `padding` — внутри, `margin` — снаружи; стороны: 1/2/4 значения (T-R-B-L по часовой); `box-sizing: border-box` в начале файла; `margin: 0 auto` центрирует блок с заданной `width`.

---

## 🟢 Уровень 1 — базовый (обязательно)

**1. Воздух внутри.**
Сделай блок с фоном и текстом. Сначала посмотри — текст липнет к краю. Потом добавь `padding: 20px` и увидь, как появился «воздух» внутри.
> 💡 Подсказка: `.box { background: #dbeafe; padding: 20px; }`.

**2. Padding по сторонам.**
Задай блоку разный padding: сверху-снизу `10px`, слева-справа `30px` (двумя значениями). Проверь в DevTools.
> 💡 Подсказка: `padding: 10px 30px;` — первое верх-низ, второе лево-право.

**3. Расстояние между блоками.**
Сделай три блока подряд и задай каждому `margin-bottom: 20px`, чтобы между ними появились промежутки.
> 💡 Подсказка: `.box { margin-bottom: 20px; }` — отступ снизу у каждого.

**4. Центрируем блок.**
Сделай блок шириной `300px` и центрируй его на странице через `margin: 0 auto`.
> 💡 Подсказка: `.card { width: 300px; margin: 0 auto; }`. Без `width` не сработает.

**5. Обязательный сброс.**
В начало `style.css` добавь сброс: `* { box-sizing: border-box; margin: 0; padding: 0; }`. Понаблюдай, как убрались стандартные отступы браузера.
> 💡 Подсказка: этот блок пиши **самым первым** в файле.

**6. Проверь border-box.**
Сделай блок `width: 200px; padding: 20px; border: 5px solid`. Посмотри его ширину в DevTools без `border-box` и с ним. Убедись, что с ним ширина ровно 200px.
> 💡 Подсказка: `box-sizing: border-box;` включает padding и border в `width`.

**7. Кнопка на padding.**
Сделай ссылку-кнопку, «объём» которой задаётся только через `padding` (например, `12px 24px`). Без padding кнопка «тонкая», с ним — красивая.
> 💡 Подсказка: `.btn { display: inline-block; padding: 12px 24px; background: #6366f1; color: #fff; }`.

## 🟡 Уровень 2 — средний (для уверенности)

**8. Карточка товара.**
Собери карточку: картинка, название, цена, кнопка. Дай ей `padding` (воздух внутри), рамку, центрируй через `margin: 0 auto`. Ширина ~260px.
> 💡 Подсказка: `.card { width: 260px; margin: 0 auto; padding: 20px; border: 1px solid #e2e8f0; }`.

**9. Схлопывание отступов.**
Сделай два блока: у верхнего `margin-bottom: 40px`, у нижнего `margin-top: 20px`. Замерь расстояние в DevTools — там 40, а не 60. Запиши вывод.
> 💡 Подсказка: вертикальные margin схлопываются — берётся больший.

**10. Внутренний и внешний отступ вместе.**
Сделай карточку, где `padding` даёт воздух внутри, а `margin` — расстояние до соседней карточки. Сделай две такие карточки подряд.
> 💡 Подсказка: `padding` — внутрь, `margin-bottom` — между карточками.

**11. Профиль-карточка.**
Собери карточку профиля: круглый аватар (`border-radius: 50%`), имя, описание. Аккуратные отступы внутри, карточка по центру.
> 💡 Подсказка: аватар — `width: 80px; border-radius: 50%;`; карточка — `padding` + `margin: 0 auto`.

**12. Отступы у текста.**
Сделай статью (`article`) с `max-width: 700px`, центрированную, с `padding` по бокам, чтобы текст не прилипал к краям на телефоне.
> 💡 Подсказка: `article { max-width: 700px; margin: 0 auto; padding: 0 16px; }`.

**13. Разбираем в DevTools.**
Возьми любую свою карточку, открой DevTools (F12), наведись и найди на схеме блочной модели значения content, padding, border, margin. Поменяй padding прямо в инспекторе.
> 💡 Подсказка: F12 → Elements → навести → цветная схема внизу справа.

## 🔴 Уровень 3 — со звёздочкой (челлендж)

**14. Ценник с наложением.**
Сделай карточку товара, а на её угол «наложи» бейдж «-30%» через отрицательный `margin` (например, `margin-top: -12px`).
> 💡 Подсказка: отрицательный margin сдвигает блок «наверх/влево»: `margin-top: -12px;`.

**15. Идеальные равные отступы.**
Собери «сетку» из 3 карточек в ряд (через `display: inline-block`) с одинаковыми отступами между ними. Следи, чтобы `box-sizing: border-box` не давал им «разъезжаться».
> 💡 Подсказка: карточкам `display: inline-block; width: ...; margin: 10px;` + `box-sizing: border-box`.

**16. Мини-исследование padding vs margin.**
Сделай два одинаковых цветных блока. Одному добавь `padding: 30px`, другому `margin: 30px`. Объясни в комментарии, почему фон «вырос» только у одного (padding внутри → фон растёт; margin снаружи → фон не меняется).
> 💡 Подсказка: `padding` внутри блока (под фоном), `margin` — снаружи (прозрачный).

## 🏆 Итоговая работа урока — «Билет на мероприятие»

Сделай **красивый билет** — на концерт, матч, кинопремьеру, в кино, на поезд или VIP-проход на турнир. Билет — это идеальная тренировка блочной модели: аккуратные отступы, рамка, центрирование, разделённые части.

**Пример темы:** билет на концерт любимой группы, проход на GameFest, билет в кино на премьеру, посадочный талон на «рейс мечты», VIP-пропуск на турнир.

### 📋 Что должно быть на билете

1. **Карточка-билет по центру страницы** (`margin: 0 auto`, задана `width`).
2. **Шапка билета** — название события (крупно) и, по желанию, «логотип»/эмодзи.
3. **Тело билета** — детали: дата, время, место, ряд/место, цена. Каждая деталь с аккуратными отступами.
4. **«Отрывной корешок»** — отдельная часть билета, отделённая рамкой или пунктирной линией (`border` сверху/снизу).
5. Хорошо продуманные **`padding`** (воздух внутри) и **`margin`** (расстояния между частями).

### ✅ Требования (проверь по списку)
- ✅ в начале `style.css` есть сброс `* { box-sizing: border-box; margin: 0; padding: 0; }`;
- ✅ билет-карточка **центрирован** через `margin: 0 auto` и имеет заданную `width`;
- ✅ у билета есть **`padding`** (содержимое не липнет к краям);
- ✅ есть рамка (`border`) и разделение на части (например, `border-top`/пунктир между телом и корешком);
- ✅ между деталями заданы **`margin`** (не слипаются);
- ✅ гармоничная палитра (по цветовому кругу), читаемый контраст;
- ✅ всё оформление во **внешнем `style.css`**.

### 💡 Подсказки
- Начни со сброса и центрирования: `.ticket { width: 340px; margin: 40px auto; padding: 24px; }`.
- «Отрывной корешок»: отдели пунктиром `border-top: 2px dashed #cbd5e1;` и дай ему свой `padding-top`.
- Детали (дата/место/ряд) — отдельными строками с `margin-bottom`.
- Фон билета — светлый или «фирменный» под тему события; акцентный цвет — для названия.
- Картинку/логотип можно сделать в ИИ ([🧰 сервисы](../../ПОЛЕЗНЫЕ-СЕРВИСЫ.md)).

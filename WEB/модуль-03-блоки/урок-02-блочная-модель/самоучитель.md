# 🧑‍🏫 Часть A. Разбираем вместе (пошагово)

## 1. Что такое блочная модель

**Тема:** каждый элемент — коробка из 4 слоёв: content, padding, border, margin.

**Задание:** пойми разницу padding и margin.

**Разбор по шагам:**
1. `content` — само содержимое (текст/картинка).
2. `padding` — воздух **внутри** блока (между содержимым и рамкой).
3. `border` — рамка вокруг.
4. `margin` — расстояние **снаружи** (до соседей).

✅ padding — внутри, margin — снаружи.

---

## 2. padding — воздух внутри

**Тема:** `padding` отодвигает содержимое от края блока.

**Задание:** дай блоку внутренний отступ.

**Разбор по шагам:**
1. Сделай `<div class="box">Текст</div>`.
2. `.box { background: #dbeafe; }` — текст липнет к краю.
3. Добавь `padding: 20px;` — появился воздух.
4. Попробуй `padding: 10px 30px;` (верх-низ / лево-право).

✅ `.box { padding: 20px; }`.

---

## 3. margin — расстояние снаружи

**Тема:** `margin` отодвигает блок от соседей; `margin: 0 auto` центрирует.

**Задание:** центрируй блок.

**Разбор по шагам:**
1. Задай ширину: `.card { width: 300px; }`.
2. Центрируй: `margin: 0 auto;`.
3. Добавь `margin-bottom: 30px;` — отступ снизу.
4. Без `width` центрирование не сработает.

✅ `.card { width: 300px; margin: 0 auto 30px; }`.

---

## 4. box-sizing: border-box

**Тема:** без него `width` не учитывает padding и border, и блок становится шире.

**Задание:** зафиксируй ширину блока.

**Разбор по шагам:**
1. `.box { width: 200px; padding: 20px; border: 5px solid; }` — реально шире 200.
2. Добавь `box-sizing: border-box;` — теперь ровно 200.
3. Проверь в DevTools (F12).
4. Ставь для всех: `* { box-sizing: border-box; }` в начале файла.

✅ `* { box-sizing: border-box; }`.

---

## 5. Сброс в начале файла

**Тема:** стандартный «reset» для всех современных сайтов.

**Задание:** добавь сброс.

**Разбор по шагам:**
1. В самое начало `style.css` напиши:
2. `* { box-sizing: border-box; margin: 0; padding: 0; }`.
3. Убрались стандартные отступы браузера.
4. Дальше отступы добавляешь осознанно.

✅ Сброс из трёх свойств в начале файла.

# ✍️ Часть B. Теперь сам (с мини-подсказкой)

## Отступы

**6.** Дай блоку `padding` разными значениями по сторонам (2 и 4 значения).
> 💡 `padding: 10px 30px;` и `padding: 10px 20px 30px 40px;` (T-R-B-L).

**7.** Сделай три блока с `margin-bottom` между ними.
> 💡 `.box { margin-bottom: 20px; }`.

**8.** Центрируй блок шириной 300px.
> 💡 `width: 300px; margin: 0 auto;`.

## border-box и DevTools

**9.** Добавь сброс `* { box-sizing: border-box; margin: 0; padding: 0; }`.
> 💡 Пиши первым в `style.css`.

**10.** Замерь схлопывание: верхний `margin-bottom: 40px`, нижний `margin-top: 20px`.
> 💡 В DevTools будет 40, а не 60.

**11.** Открой DevTools, найди схему блочной модели своего блока.
> 💡 F12 → Elements → навести → цветная схема внизу.

## Собираем

**12.** Собери карточку товара (картинка, название, цена, кнопка) с padding, рамкой, по центру.
> 💡 `.card { width: 260px; margin: 0 auto; padding: 20px; border: 1px solid #e2e8f0; }`.

**13.** Сделай кнопку, «объём» которой задаёт только `padding`.
> 💡 `.btn { display: inline-block; padding: 12px 24px; }`.

**14.** Сделай статью `max-width: 700px` по центру с боковым `padding`.
> 💡 `article { max-width: 700px; margin: 0 auto; padding: 0 16px; }`.

## Со звёздочкой 🔴

**15.** Наложи бейдж «-30%» на угол карточки через отрицательный `margin`.
> 💡 `margin-top: -12px;` сдвинет бейдж вверх.

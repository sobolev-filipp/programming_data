# 🧰 Лайфхаки · Урок 2 «Блочная модель»

Трюки и частые ошибки, чтобы управлять отступами без боли.

---

## ⭐ Сброс, с которого начинают ВСЕ

Первым делом в `style.css`:
```css
* {
    box-sizing: border-box;
    margin: 0;
    padding: 0;
}
```
- `border-box` — `width` включает padding и border (что задал, то и получил).
- `margin: 0; padding: 0;` — убирает разные стандартные отступы браузера.

Дальше добавляешь отступы **осознанно**, а не борешься с чужими.

---

## 🧭 Стороны padding/margin — как запомнить

| Значений | Что значит |
|----------|-----------|
| `20px` | все 4 стороны |
| `10px 20px` | верх-низ / лево-право |
| `10px 20px 30px` | верх / лево-право / низ |
| `10px 20px 30px 40px` | **T-R-B-L** (верх, право, низ, лево — по часовой) |

Мнемоника для 4 значений: **«ТРБЛ»** — по часовой стрелке с верха.

---

## 🎯 Центрирование блока

```css
.card {
    width: 300px;       /* обязательно задать ширину */
    margin: 0 auto;     /* auto по бокам = по центру */
}
```
Работает только у блочного элемента с заданной `width`. По вертикали `auto` центрирует во Flexbox (скоро).

## 🔎 DevTools — читаем коробку

- **F12** → вкладка **Elements**.
- Наведи на блок → подсветятся слои: content (синий), padding (зелёный), margin (оранжевый).
- Внизу справа — **схема** с числами всех отступов.
- Меняй значения прямо там — увидишь результат сразу (в файл не сохранится).

## 🐞 Частые ошибки и как избежать

- **Блок шире, чем задал** → нет `border-box`. Добавь сброс.
- **Текст липнет к краям** → нет `padding`. Дай воздуха внутри.
- **`margin: auto` не центрирует** → не задана `width`.
- **Отступ «меньше» ожидаемого** → схлопывание вертикальных `margin` (берётся больший) — это норма.
- **Путают padding и margin** → padding внутри (растёт фон), margin снаружи (прозрачный).
- **Задают `height` и текст обрезается** → высоту обычно НЕ фиксируют, ей управляет содержимое; регулируй `padding`.

---

## 💡 Полезные приёмы

- **`padding` для «объёма» кнопок:** `padding: 12px 24px` вместо жёстких `width`/`height`.
- **`max-width` для читаемости текста:** `article { max-width: 700px; margin: 0 auto; }` — строки не растягиваются на весь экран.
- **`max-width: 100%` картинке** — не даёт ей вылезти за контейнер.
- **Отрицательный `margin`** (`margin-top: -10px`) — «наложить» блоки друг на друга (бейджи, ленты).

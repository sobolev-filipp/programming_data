# 🖼 Изображения и что показать на проекторе · Урок 2 «Блочная модель»

Схемы в папке `изображения/`. Что показать и что проговорить.

---

## 1. `box-model.svg`
**Когда:** Часть 1 (что такое блочная модель). Ключевая схема урока.
**Что показать:** вложенные слои — content (синий), padding (зелёный), border (тёмный), margin (оранжевый), с легендой.
**Проговорить:** «Любой элемент — это коробка из 4 слоёв. В центре content — само содержимое. Вокруг padding — воздух внутри. Потом border — рамка. Снаружи margin — расстояние до соседей. Padding — внутри, margin — снаружи, это главное».

## 2. `стили-border.svg`
**Когда:** Часть 4 (`border`).
**Что показать:** разбор записи `border: 3px solid #6366f1` (толщина · тип · цвет) и образцы типов рамки — `solid`, `dashed`, `dotted`, `double`, `groove`, `none`.
**Проговорить:** «Рамка — это три значения: толщина, тип и цвет. Тип бывает разный: сплошная, штрихами, точками, двойная. Можно задать рамку только с одной стороны — `border-bottom`, например пунктиром для отрывного корешка билета».

## 3. `box-sizing.svg`
**Когда:** Часть 5 (`box-sizing: border-box`).
**Что показать:** слева content-box (width 200, но реально 250 из-за padding+border), справа border-box (ровно 200).
**Проговорить:** «Задали одинаковую width: 200. По умолчанию (content-box) браузер добавляет padding и border сверху — блок становится 250 и вёрстка ломается. С border-box width — это ВСЯ ширина, ровно 200. Поэтому border-box ставят для всех блоков».

---

## 💻 Живая демонстрация (обязательно!)

1. **DevTools (F12)** на любом блоке → показать цветную схему content/padding/border/margin.
2. Добавить блоку `padding` → содержимое отодвинулось от края (фон «вырос»).
3. Добавить `margin` → блок отодвинулся от соседей (фон НЕ вырос).
4. **Ключевое:** блок `width:200; padding:20; border:5` → измерить (250) → добавить `box-sizing: border-box` → стало 200. «Вот почему это ставят всегда».
5. Центрирование `margin: 0 auto` (с width).
6. Схлопывание: два блока с вертикальными margin → показать в DevTools, что берётся больший.

> 🧭 Весь урок держим DevTools открытым — блочная модель понятна, только когда её ВИДИШЬ.

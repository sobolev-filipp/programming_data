# Справочник тегов и CSS-свойств

> Словарь вёрстки. Нужно вспомнить, **что делает тег или свойство, как оно работает и что означают его значения** — загляни сюда. У каждой записи: что это простыми словами, как работает, что значат значения, и примеры.
>
> Это «словарь слов». А если хочешь понять **тему целиком** (как всё собирается вместе) — смотри [Справочник по темам](Справочник.md).
>
> Пока здесь — всё, что проходим в модулях 1–3. Справочник пополняется вместе с курсом.

---

## Как пользоваться

- **Тег** — это «кирпичик» HTML, пишется в угловых скобках: `<p>`. Отвечает за **содержание** (что находится на странице: заголовок, абзац, картинка).
- **Свойство** — это настройка внешнего вида в CSS: `color: red;`. Отвечает за **оформление** (как это выглядит: цвет, размер, отступы).
- **Значение** — это то, что мы ставим у свойства после двоеточия (`red`, `20px`, `center`). У каждого свойства — свой набор возможных значений, и ниже мы разбираем, что они означают.
- В примерах подписано, где HTML, а где CSS: блок с тегами `<...>` — это HTML, блок с `свойство: значение;` — это CSS.

# Теги

## Каркас страницы

Эти теги есть на **каждой** странице — они создают её «скелет». Их пишут один раз сверху, и обычно их разворачивает Emmet по команде `!` (см. [Emmet](#emmet--быстрый-ввод-кода)).

### `<!DOCTYPE>`
Самая первая строка файла. Это не совсем тег, а «объявление»: оно говорит браузеру, что страница написана на **современном HTML5**, и браузер должен показывать её по новым правилам. Если его не написать, браузер включит старый «режим совместимости», и вёрстка может поехать. Пишется один раз, закрывать не нужно.
```html
<!DOCTYPE html>
```

### `<html>`
Главная обёртка **всей** страницы: внутри `<html>` лежит вообще всё остальное (и `<head>`, и `<body>`). Атрибут `lang` сообщает язык страницы — это помогает браузеру и поисковикам, а также правильной проверке орфографии.
```html
<html lang="ru">
  ...вся страница...
</html>
```
- `lang="ru"` — страница на русском, `lang="en"` — на английском.

### `<head>`
«Служебная» часть страницы. Всё, что внутри `<head>`, **не видно** на самой странице — это информация *о* странице и подключения: кодировка, название вкладки, подключение CSS и шрифтов. Представь обложку тетради с подписью «чья тетрадь» — саму тетрадь это не наполняет, но без неё непонятно, что к чему.

### `<meta>`
Короткие «технические записки» о странице. Одиночный тег (закрывать не нужно). Самая важная — **кодировка**: без неё русские буквы могут превратиться в «кракозябры».
```html
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```
- `charset="UTF-8"` — кодировка, при которой русские буквы отображаются правильно. Ставь всегда.
- `viewport` — настройка для телефонов, чтобы страница подстраивалась под ширину экрана (пригодится в модуле про адаптивность).

### `<title>`
Название **вкладки** браузера (не заголовок на самой странице!). Его видно на ярлычке вкладки и в закладках. Живёт внутри `<head>`.
```html
<title>Моя первая страница</title>
```
> Не путай с `<h1>`: `<title>` — надпись на вкладке (в `<head>`), `<h1>` — большой заголовок на самой странице (в `<body>`).

### `<link>`
Подключает к странице **внешний файл**. Чаще всего так подключают CSS. Одиночный тег, живёт в `<head>`.
```html
<link rel="stylesheet" href="style.css">
```
- `rel="stylesheet"` — «связываемый файл — это таблица стилей (CSS)».
- `href="style.css"` — путь к файлу стилей. Имя должно совпадать с настоящим файлом буква-в-букву.

### `<style>`
Позволяет писать CSS **прямо внутри** HTML-страницы (в `<head>`). Удобно для одной маленькой странички, но если сайт из нескольких страниц — лучше вынести стили в отдельный файл и подключить через `<link>`.
```html
<head>
  <style>
    h1 { color: navy; }
    p  { color: gray; }
  </style>
</head>
```

### `<body>`
«Тело» страницы — здесь живёт **всё, что видно** в браузере: заголовки, текст, картинки, кнопки, блоки. Именно внутри `<body>` мы пишем контент.
```html
<body>
  <h1>Привет!</h1>
  <p>Это моя страница.</p>
</body>
```

## Теги текста

### `<h1>`–`<h6>`
Заголовки шести уровней важности. `<h1>` — самый главный заголовок (название страницы, он **один** на странице), `<h2>` — заголовки разделов, `<h3>` — подразделы, и так до `<h6>` — самого мелкого. Это не просто «крупный текст»: заголовки задают **структуру** страницы, по ним ориентируются поисковики и программы для незрячих.
```html
<h1>Мой блог о космосе</h1>
<h2>Планеты</h2>
<h3>Марс</h3>
<h3>Юпитер</h3>
<h2>Звёзды</h2>
```
> ⚠️ Выбирай заголовок **по смыслу** (насколько он важный), а не «потому что крупнее». Нужен крупный, но неважный текст — сделай обычный текст и увеличь [`font-size`](#font-size).

### `<p>`
Абзац текста (**p** — от англ. *paragraph*). Каждый новый `<p>` начинается с новой строки, между абзацами браузер сам делает небольшой отступ. Весь обычный текст на странице оборачивают в абзацы.
```html
<p>Это первый абзац. В нём одна мысль.</p>
<p>А это второй абзац — новая мысль, новая строка.</p>
```

### `<br>`
Перенос строки **внутри** текста (**br** — от *break*, «разрыв»). Одиночный тег. Нужен, когда внутри одного абзаца надо перейти на новую строку, не начиная новый абзац, — например, в адресе или стихах.
```html
<p>Москва, ул. Лесная, 5<br>офис 12<br>этаж 3</p>
```
> Не ставь много `<br>` подряд ради отступов — для расстояний между блоками есть [`margin`](#margin).

### `<hr>`
Горизонтальная линия-разделитель (**hr** — *horizontal rule*). Одиночный тег. Визуально отделяет один смысловой кусок от другого.
```html
<p>О себе…</p>
<hr>
<p>Мои контакты…</p>
```

### `<strong>`, `<em>`
Теги выделения **внутри** текста. `<strong>` — важное (браузер показывает **жирным**), `<em>` — выделение голосом, акцент (показывает *курсивом*). Они выделяют **по смыслу**, а не просто меняют начертание.
```html
<p>Внимание: <strong>поезд уходит в 9:00</strong>.</p>
<p>Это было <em>по-настоящему</em> вкусно.</p>
```

## Ссылки и картинки

### `<a>`
Ссылка — переход куда-либо по клику (**a** — от *anchor*, «якорь»). Главный атрибут `href` говорит, **куда** вести. Текст между тегами — то, на что кликают.
```html
<a href="https://example.ru">Открыть сайт</a>
```
Куда может вести `href`:
- `href="https://..."` — на другой сайт.
- `href="about.html"` — на другую страницу твоего же сайта.
- `href="#contacts"` — к разделу **на этой же** странице (якорь; у раздела должен быть `id="contacts"`).
- `href="mailto:me@mail.ru"` — откроет почту, чтобы написать письмо.
- `href="tel:+79990001122"` — на телефоне начнёт звонок.

Полезный атрибут `target`:
- `target="_blank"` — открыть ссылку в **новой вкладке**, не уходя с текущей страницы.
```html
<a href="https://example.ru" target="_blank">Открыть в новой вкладке</a>
```
Ссылкой можно сделать и картинку — положи [`<img>`](#img) внутрь `<a>`:
```html
<a href="https://example.ru"><img src="logo.png" alt="логотип"></a>
```

### `<img>`
Вставляет картинку. Одиночный тег. Важно понимать: `<img>` **не хранит** картинку внутри себя — он лишь показывает **путь** к файлу, а браузер идёт по этому пути, находит файл и рисует его.
```html
<img src="images/кот.jpg" alt="Рыжий кот" width="200">
```
Что означают атрибуты:
- `src` — путь к файлу картинки (**s**ou**rc**e, «источник»). Например, `кот.jpg` (файл рядом) или `images/кот.jpg` (в папке `images`). Ошибся в пути — вместо картинки будет «сломанный» значок.
- `alt` — текст-замена (**alt**ernative). Показывается, если картинка не загрузилась, и читается программами для незрячих. Пиши коротко, что на картинке.
- `width` / `height` — размеры в пикселях. Задавай обычно **только `width`** — высота подстроится сама, и картинка не сплющится.
```html
<img src="кот.jpg" alt="кот" width="150">   <!-- ширина 150px, высота сама -->
```
> Оформление картинки (рамка, скругление, обрезка) — это уже CSS: [`border`](#border), [`border-radius`](#border-radius), [`object-fit`](#object-fit).

## Контейнеры

### `<div>`
«Коробка-контейнер» (**div** — от *division*, «раздел»). Сам по себе `<div>` ничего не рисует и ничего не значит по смыслу — он просто **группирует** другие элементы, чтобы потом оформить их как одно целое (например, собрать заголовок, картинку и кнопку в одну карточку). `<div>` — блочный: занимает всю ширину и начинается с новой строки.
```html
<div class="card">
  <img src="товар.jpg" alt="товар">
  <h3>Кроссовки</h3>
  <p>5990 ₽</p>
</div>
```
Здесь всё внутри `<div class="card">` можно оформить одним правилом `.card { ... }`.

### `<span>`
Обёртка для **кусочка текста внутри строки** (чтобы, например, покрасить одно слово). В отличие от `<div>`, `<span>` — строчный: он не переносит текст на новую строку и занимает ровно столько места, сколько занимает содержимое.
```html
<p>Осталось <span class="count">3</span> товара по <span class="price">990 ₽</span></p>
```
```css
.price { color: crimson; font-weight: bold; }
```
> Коротко: `<div>` — коробка для **блоков**, `<span>` — обёртка для **части текста**.

## Списки

### `<ul>`
Маркированный список — **u**nordered **l**ist, «неупорядоченный». Перед каждым пунктом браузер рисует маркер (точку). Нужен, когда порядок пунктов не важен (список покупок, список фишек).
```html
<ul>
  <li>Молоко</li>
  <li>Хлеб</li>
  <li>Яблоки</li>
</ul>
```

### `<ol>`
Нумерованный список — **o**rdered **l**ist, «упорядоченный». Браузер сам ставит номера 1, 2, 3… Нужен, когда порядок важен (шаги инструкции, рейтинг).
```html
<ol>
  <li>Включить компьютер</li>
  <li>Открыть VS Code</li>
  <li>Создать файл index.html</li>
</ol>
```

### `<li>`
Один пункт списка (**l**ist **i**tem). Живёт **только** внутри `<ul>` или `<ol>`. Внутри `<li>` можно писать что угодно — текст, ссылку, даже картинку.
```html
<ul>
  <li><a href="#">Пункт-ссылка</a></li>
</ul>
```
Вид маркера (точка, кружок, квадрат) или его отсутствие задаёт CSS-свойство [`list-style-type`](#list-style-type) — например, `none`, чтобы сделать из списка горизонтальное **меню**.

### `<dl>`, `<dt>`, `<dd>`
Список определений (как в словаре): **dl** — обёртка всего списка, **dt** — термин (слово), **dd** — его объяснение.
```html
<dl>
  <dt>HTML</dt>
  <dd>язык разметки — из чего состоит страница</dd>
  <dt>CSS</dt>
  <dd>язык стилей — как страница выглядит</dd>
</dl>
```

## Таблицы

### `<table>`
Таблица — для данных «по строкам и столбцам» (расписание, рекорды, сравнение товаров). Внутри таблицы идут строки [`<tr>`](#tr), а в них — ячейки. Для аккуратного вида почти всегда добавляют CSS [`border-collapse: collapse`](#border-collapse).
```html
<table>
  <caption>Расписание</caption>
  <thead>
    <tr><th>День</th><th>Урок</th></tr>
  </thead>
  <tbody>
    <tr><td>Пн</td><td>Математика</td></tr>
    <tr><td>Вт</td><td>История</td></tr>
  </tbody>
</table>
```
- `<caption>` — подпись-заголовок таблицы (необязательно).

### `<tr>`
Строка таблицы (**t**able **r**ow). Сама по себе пустая — внутри неё идут ячейки `<th>` или `<td>`, по одной на каждый столбец.
```html
<tr><td>Пн</td><td>Математика</td><td>9:00</td></tr>
```

### `<th>`, `<td>`
Ячейки таблицы. `<th>` — ячейка-**заголовок** столбца или строки (**t**able **h**eader): браузер делает её жирной и по центру. `<td>` — обычная ячейка с данными (**t**able **d**ata).
```html
<tr><th>Имя</th><th>Очки</th></tr>
<tr><td>Аня</td><td>95</td></tr>
```
Как объединить ячейки:
- `colspan="2"` — ячейка занимает **2 столбца** (растянута вправо).
- `rowspan="2"` — ячейка занимает **2 строки** (растянута вниз).
```html
<tr><th colspan="2">Итого за неделю</th></tr>
```

### `<thead>`, `<tbody>`
Группируют части таблицы: `<thead>` — «шапка» (строка с заголовками столбцов), `<tbody>` — «тело» (строки с данными). Это делает таблицу понятнее и помогает её стилизовать (например, покрасить только шапку).
```html
<thead><tr><th>Товар</th><th>Цена</th></tr></thead>
<tbody>
  <tr><td>Чай</td><td>120 ₽</td></tr>
  <tr><td>Кофе</td><td>180 ₽</td></tr>
</tbody>
```

## Семантика

«Семантические» теги — это теги-коробки с **понятным смыслом**. Внешне они как `<div>` (тоже блоки-контейнеры), но их название сразу говорит, **что** за блок внутри: шапка, меню, подвал. Это удобнее и тебе (код читается), и браузеру с поисковиками.

### `<header>`, `<nav>`, `<main>`, `<footer>`
Главные «зоны» страницы:
- `<header>` — **шапка**: логотип, название сайта, иногда меню. Обычно вверху.
- `<nav>` — блок **навигации**: набор ссылок-меню.
- `<main>` — **основное** содержимое страницы (одно на странице): то, ради чего человек пришёл.
- `<footer>` — **подвал**: контакты, копирайт, ссылки. Обычно внизу.
```html
<header>
  <h1>Мой сайт</h1>
  <nav>
    <a href="#">Главная</a>
    <a href="#">О нас</a>
    <a href="#">Контакты</a>
  </nav>
</header>
<main>
  ...основной контент...
</main>
<footer>© 2026, Аня</footer>
```

### `<section>`, `<article>`, `<aside>`
Блоки внутри страницы:
- `<section>` — **смысловой раздел** страницы (например, «Отзывы» или «Цены»), обычно со своим заголовком.
- `<article>` — **самостоятельный** кусок, который имеет смысл сам по себе: новость, пост, карточка товара. Его можно «вынести» и он останется понятным.
- `<aside>` — **дополнительная**/боковая информация: сайдбар, реклама, «а ещё почитайте».
```html
<section>
  <h2>Новости</h2>
  <article>
    <h3>Открылся новый филиал</h3>
    <p>Сегодня…</p>
  </article>
</section>
<aside>Полезные ссылки</aside>
```

### `<figure>`, `<figcaption>`
Картинка (или схема) **с подписью**: `<figure>` — обёртка, `<figcaption>` — подпись к ней. Семантически связывает изображение и его описание.
```html
<figure>
  <img src="кот.jpg" alt="рыжий кот спит">
  <figcaption>Мой кот Барсик после обеда</figcaption>
</figure>
```

## Кнопки

### `<button>`
Кнопка, на которую нажимают. Сама по себе она пока **ничего не делает** — действие ей добавят позже на JavaScript. Если же нужно по клику **перейти на другую страницу**, используют не кнопку, а [ссылку](#a), оформленную как кнопка.
```html
<button>Отправить</button>                       <!-- действие добавим на JS -->
<a href="prices.html" class="btn">Купить</a>      <!-- переход по ссылке -->
```
```css
.btn {
  display: inline-block;        /* чтобы ссылка вела себя как кнопка-блок */
  background: #e63946;
  color: white;
  padding: 12px 24px;
  border-radius: 10px;
  text-decoration: none;        /* убрать подчёркивание ссылки */
}
```

# CSS-свойства

## Свойства текста и шрифта

### `color`
Цвет **текста** (именно букв). Значением может быть цвет в любом формате — см. [форматы цвета](#форматы-цвета).
```css
p  { color: #333333; }        /* тёмно-серый текст */
h1 { color: crimson; }        /* по имени цвета */
a  { color: rgb(41, 101, 241); }
```
> Не путай: `color` — цвет **букв**, а цвет **фона** за ними — это [`background-color`](#background-color).

### `font-family`
Шрифт текста. Пишут не один шрифт, а **стек** — несколько через запятую. Браузер берёт первый, а если его нет в системе — следующий, и так далее. Последним ставят «семейство» (`sans-serif` — без засечек, `serif` — с засечками) как запасной вариант.
```css
body { font-family: "Montserrat", Arial, sans-serif; }
h1   { font-family: Georgia, "Times New Roman", serif; }
```
- `"Montserrat"` — красивый шрифт (например, подключённый из Google Fonts). Если его нет — возьмётся `Arial`, а если и его нет — любой `sans-serif`.
> Имена из нескольких слов пиши в кавычках: `"Times New Roman"`.

### `font-size`
Размер шрифта (высота букв). В начале курса задаём в **пикселях** (`px`).
```css
p  { font-size: 16px; }       /* обычный текст */
h1 { font-size: 40px; }       /* крупный заголовок */
small { font-size: 12px; }    /* мелкая подпись */
```
- `16px` — комфортный размер основного текста. Меньше 12–14px читать тяжело.

### `font-weight`
Насыщенность (толщина) букв. Можно словом или числом.
```css
h1   { font-weight: bold; }    /* жирный */
.sub { font-weight: normal; }  /* обычный */
.hero{ font-weight: 800; }     /* очень жирный */
```
Что означают значения:
- `normal` — обычная толщина (это то же, что `400`).
- `bold` — жирный (то же, что `700`).
- числа `100`–`900` с шагом 100 — от самого тонкого (`100`) до самого жирного (`900`). Чем больше число, тем толще. Но доступны только те толщины, которые есть у шрифта.

### `font-style`
Начертание — прямое или наклонное.
```css
em        { font-style: italic; }   /* курсив (наклонный) */
.reset    { font-style: normal; }   /* обычный, прямой */
```
- `normal` — обычные прямые буквы.
- `italic` — курсив (буквы наклонены), используется для акцента или цитат.

### `line-height`
Высота строки — расстояние между строками текста (межстрочный интервал). Делает текст «воздушным» и читаемым. Удобно задавать **числом-множителем** (без единиц): оно умножается на размер шрифта.
```css
p { line-height: 1.5; }    /* строки на 1.5 высоты буквы — комфортно */
h1 { line-height: 1.1; }   /* у крупных заголовков интервал меньше */
```
- `1` — строки впритык (тесно), `1.5`–`1.7` — комфортно для чтения, `2` — очень просторно.

### `letter-spacing`
Расстояние между **буквами**. Небольшое увеличение делает заголовки «дороже» и аккуратнее; отрицательное — сжимает.
```css
h1 { letter-spacing: 2px; }       /* буквы чуть раздвинуты */
.logo { letter-spacing: 4px; text-transform: uppercase; }
.tight { letter-spacing: -1px; }  /* чуть сжать */
```

### `text-align`
Выравнивание текста **по горизонтали** внутри его блока.
```css
h1 { text-align: center; }    /* по центру */
p  { text-align: left; }      /* по левому краю (обычно так) */
.price { text-align: right; } /* по правому краю */
```
Значения:
- `left` — по левому краю (по умолчанию для русского/английского).
- `center` — по центру.
- `right` — по правому краю.
- `justify` — по ширине (ровные края и слева, и справа, как в книге).

### `text-transform`
Меняет **регистр** букв, не трогая сам текст в HTML.
```css
.logo  { text-transform: uppercase; }   /* ВСЕ ЗАГЛАВНЫЕ */
.quiet { text-transform: lowercase; }    /* все строчные */
.name  { text-transform: capitalize; }   /* Каждое Слово С Заглавной */
```
- `uppercase` — ВСЕ БУКВЫ БОЛЬШИЕ.
- `lowercase` — все буквы маленькие.
- `capitalize` — Каждое Слово С Большой Буквы.
- `none` — как написано в HTML.

### `text-decoration`
Линии у текста: подчёркивание, зачёркивание. Чаще всего это свойство используют, чтобы **убрать** подчёркивание у ссылок.
```css
a         { text-decoration: none; }           /* убрать подчёркивание ссылки */
.sale-old { text-decoration: line-through; }    /* зачёркнутая старая цена */
.hint     { text-decoration: underline; }       /* подчеркнуть */
```
- `none` — никаких линий.
- `underline` — подчёркнутый.
- `line-through` — зачёркнутый (удобно для старой цены).

### `text-shadow`
Тень у **текста**. Значение читается так: `сдвиг-вправо сдвиг-вниз размытие цвет`.
```css
h1 { text-shadow: 2px 2px 6px rgba(0,0,0,0.4); }
.neon { text-shadow: 0 0 10px #0ff; }   /* свечение без сдвига */
```
Как читать `2px 2px 6px rgba(0,0,0,0.4)`:
- `2px` — тень сдвинута на 2px **вправо** (отрицательное число — влево).
- `2px` — сдвинута на 2px **вниз** (отрицательное — вверх).
- `6px` — **размытие**: чем больше, тем мягче и расплывчатее тень (`0` — чёткая).
- `rgba(0,0,0,0.4)` — цвет тени; бери полупрозрачный, так естественнее.

### `@font-face`
Особое правило: подключает **свой** шрифт из файла (когда нужного шрифта нет в системе). Сначала мы «объявляем» шрифт — даём ему имя и указываем путь к файлу через `url()`, — а потом пользуемся этим именем в `font-family`.
```css
@font-face {
  font-family: "MyFont";                         /* придуманное имя */
  src: url("fonts/myfont.woff2") format("woff2"); /* путь к файлу шрифта */
}
h1 { font-family: "MyFont", sans-serif; }         /* пользуемся по имени */
```
- `url("...")` — путь к файлу шрифта (как `src` у картинки, только внутри CSS).
- `format("woff2")` — тип файла шрифта (`woff2` — современный и «лёгкий»).
> Про Google Fonts и подробности — [тема «Шрифты»](Справочник.md#урок-2-шрифты).

## Цвет и фон

### `background-color`
Цвет **фона** элемента — заливка за его содержимым. Если задать для `body`, покрасится фон всей страницы; если для блока — только его прямоугольник.
```css
body  { background-color: #f0f8ff; }   /* фон всей страницы */
.card { background-color: white; }      /* фон карточки */
.tag  { background-color: gold; }       /* фон маленькой плашки */
```

### `background-image`
Ставит **картинку** в качестве фона элемента. Путь к картинке пишут через `url()`. Обычно идёт вместе со свойствами ниже (размер, положение, повтор).
```css
.hero { background-image: url("images/fon.jpg"); }
```

### `background-size`
Насколько крупной будет фоновая картинка.
```css
.hero { background-size: cover; }
```
Значения:
- `cover` — картинка **заполняет весь блок** целиком, лишнее по краям обрезается (пустых мест не будет). Самый частый выбор для больших фонов.
- `contain` — картинка **целиком помещается** внутрь, ничего не обрезается, но по краям могут остаться пустые полосы.
- Можно задать размер вручную: `background-size: 200px 100px;` (ширина, высота).

### `background-position`
Где разместить фоновую картинку внутри блока (какую её часть показывать, если она обрезается).
```css
.hero { background-position: center; }     /* по центру */
.hero { background-position: top right; }  /* прижать вверх-вправо */
```
- `center` — по центру (чаще всего).
- `top` / `bottom` / `left` / `right` — прижать к краю.
- Можно сочетать: `top center`, `bottom right`.

### `background-repeat`
Повторять ли (замащивать) фоновую картинку, если она меньше блока.
```css
.hero    { background-repeat: no-repeat; }  /* один раз, без повтора */
.pattern { background-repeat: repeat; }      /* замостить, как плитку */
```
- `no-repeat` — показать один раз (для фото-фонов).
- `repeat` — повторять во все стороны (для мелких узоров-паттернов).

### `background`
«Короткая запись» фона: позволяет задать сразу цвет, картинку, позицию, размер и повтор **в одной строке**. Экономит место.
```css
.hero { background: #222 url("fon.jpg") center / cover no-repeat; }
```
Читается так: цвет `#222` (виден, пока грузится картинка) · картинка `url(...)` · положение `center` · после слэша размер `cover` · `no-repeat` — не повторять.

### `background-clip`
Определяет, по какой области «обрезается» фон. Главная фишка — значение `text`: тогда фон виден **только сквозь буквы** (а сами буквы делают прозрачными). Так получают красивый **градиентный текст**.
```css
.grad-text {
  background: linear-gradient(90deg, #f093fb, #f5576c);
  -webkit-background-clip: text;   /* дубль для Safari/Chrome */
  background-clip: text;
  color: transparent;              /* буквы прозрачны — виден фон */
}
```
> Используется для [градиента к тексту](Справочник.md#урок-5-градиенты). Строка с `-webkit-` нужна, чтобы работало во всех браузерах.

### `opacity`
Прозрачность **всего** элемента целиком — вместе с текстом, фоном и рамкой. Значение от `0` до `1`.
```css
.ghost  { opacity: 0.5; }   /* полупрозрачный */
.hidden { opacity: 0; }     /* невидимый, но место занимает */
```
- `1` — полностью непрозрачный (обычное состояние).
- `0.5` — полупрозрачный (видно наполовину).
- `0` — полностью прозрачный (не видно, но элемент на месте).
> Если нужно сделать полупрозрачным **только цвет** (например, фон, но не текст) — используй не `opacity`, а цвет с прозрачностью: `rgba(0,0,0,0.5)`.

## Рамки, форма, контур

### `border`
Рамка вокруг элемента. Значение задаёт сразу три вещи: `толщина стиль цвет`.
```css
.card { border: 2px solid #333; }       /* тонкая сплошная тёмная рамка */
.note { border: 3px dashed tomato; }     /* пунктирная оранжевая */
```
Как читать `2px solid #333`:
- `2px` — **толщина** рамки.
- `solid` — **стиль** линии. Бывает: `solid` (сплошная), `dashed` (штрихи), `dotted` (точки), `double` (двойная).
- `#333` — **цвет** рамки.

Можно задать рамку только с одной стороны:
```css
.quote { border-left: 4px solid gray; }   /* полоска только слева */
```

### `border-radius`
Скругляет углы элемента. Чем больше значение, тем круглее.
```css
.card   { border-radius: 16px; }   /* мягкие скруглённые углы */
.avatar { border-radius: 50%; }    /* круг (если элемент квадратный) */
.pill   { border-radius: 999px; }  /* «таблетка» — полукруглые торцы */
```
Что означают значения:
- `16px` — радиус скругления в пикселях: небольшое — лёгкое скругление, большое — сильнее.
- `50%` — половина; на **квадратном** элементе превращает его в идеальный круг (так делают круглые аватарки).
- очень большое (`999px`) — получается «таблетка»/«пилюля» с полукруглыми краями (частая форма кнопок и бейджей).

Можно скруглить отдельные углы: `border-radius: 16px 16px 0 0;` (только верхние).

> **Вложенное скругление:** если скруглённый блок лежит внутри другого скруглённого, у внутреннего радиус делают = внешний − `padding`, тогда уголки «параллельны» и смотрятся аккуратно.

### `outline`
Контур **снаружи** рамки. Похож на `border`, но с важным отличием: `outline` **не занимает место** в разметке и **не сдвигает** соседние элементы — он просто рисуется поверх. Поэтому его очень удобно использовать для подсветки активного элемента (`:focus`), чтобы при появлении обводки страница не «дёргалась».
```css
button:focus { outline: 3px solid dodgerblue; outline-offset: 2px; }
```
- Значение — как у `border`: `толщина стиль цвет`.
- `outline-offset` — отодвигает контур от края элемента (зазор).

**Чем отличается от `border`:** `border` раздвигает соседей и влияет на размер блока (если нет `box-sizing: border-box`), а `outline` — нет, он «висит сверху». Подробнее — [тема «Границы, скругления и outline»](Справочник.md#урок-3-границы-скругления-и-outline).

### `box-sizing`
Управляет тем, **как считается ширина и высота** блока. По умолчанию заданная `width` — это ширина только содержимого, а `padding` и `border` **прибавляются** сверху, из-за чего блок становится шире, чем задумано. Значение `border-box` это чинит: тогда `width` включает в себя и padding, и border — размер получается ровно таким, как написано.
```css
* { box-sizing: border-box; }   /* удобно включить сразу для всех элементов */

.card { width: 200px; padding: 20px; border: 2px solid; }
/* с border-box ширина карточки = ровно 200px (padding и border внутри) */
```
Значения:
- `content-box` — поведение по умолчанию: padding и border **добавляются** к width (блок «распухает»).
- `border-box` — padding и border **входят** в width (ничего не распухает). Почти всегда ставят именно его.

## Размеры и отступы

### `width`, `height`
Ширина и высота элемента. В начале курса задаём в пикселях (`px`) или процентах (`%`).
```css
.box { width: 300px; }      /* ровно 300 пикселей */
.box { height: 200px; }
img  { width: 100%; }        /* на всю ширину родителя */
```
Что означают единицы:
- `px` (пиксели) — жёсткий фиксированный размер. `300px` всегда 300px.
- `%` (проценты) — доля от размера **родителя**. `width: 100%` — во всю ширину родителя, `width: 50%` — половина. Удобно для «резиновых» блоков, которые подстраиваются под экран.
> У картинок обычно задают только ширину — высота подстроится сама и фото не исказится.

### `max-width`
**Максимальная** ширина: элемент не станет шире этого значения, но на узком экране спокойно сожмётся. Это основа «резиновой» вёрстки — блок широкий на компьютере и помещается на телефоне.
```css
.container { max-width: 1100px; width: 100%; margin: 0 auto; }
img        { max-width: 100%; }   /* картинка не вылезет за родителя */
```
- `.container` будет шириной до 1100px, а на маленьком экране — во всю доступную ширину.
- `img { max-width: 100% }` — частый приём: картинка никогда не вылезает за свой блок.

### `padding`
**Внутренний** отступ — «воздух» внутри блока, между его рамкой и содержимым. Как поля внутри коробки, чтобы вещи не упирались в стенки.
```css
.card { padding: 20px; }              /* 20px со всех сторон */
.btn  { padding: 10px 20px; }         /* 10px сверху/снизу, 20px слева/справа */
.box  { padding: 10px 20px 30px 40px; } /* сверху, справа, снизу, слева (по часовой) */
```
Как читаются значения:
- одно число — одинаково со всех 4 сторон.
- два числа — первое: сверху и снизу, второе: слева и справа.
- четыре числа — по часовой стрелке: сверху, справа, снизу, слева.
- можно по одной стороне: `padding-top: 10px;`.

### `margin`
**Внешний** отступ — расстояние **снаружи** блока, между ним и соседями. Задаётся так же, как `padding` (одно/два/четыре числа).
```css
.card { margin: 16px; }            /* отступ со всех сторон между карточками */
h2    { margin-top: 40px; }         /* отступ только сверху */
.center { margin: 0 auto; }         /* 0 сверху/снизу, auto по бокам = по центру */
```
Особое значение:
- `margin: 0 auto;` — `auto` по бокам поровну распределяет свободное место слева и справа, **центрируя блок по горизонтали** (у блока должна быть задана ширина или `max-width`).
> Разница с `padding`: `padding` — воздух **внутри** (увеличивает «подушку» вокруг текста), `margin` — расстояние **снаружи** (раздвигает блоки между собой).

## Расположение элементов (display)

### `display`
Одно из главных свойств: определяет, **как элемент ведёт себя и располагается** на странице — отдельным блоком, в строку или как гибкий контейнер.
```css
span  { display: block; }
.card { display: inline-block; width: 160px; }
.menu { display: flex; gap: 16px; }
.hidden { display: none; }
```
Что означают значения:
- `block` — **блок**: занимает всю доступную ширину и начинается с новой строки. Так по умолчанию ведут себя `<div>`, `<p>`, `<h1>`. Им можно задавать ширину, высоту, отступы.
- `inline` — **строчный**: стоит в строке, как слово, и занимает ровно по содержимому. Так ведут себя `<span>`, `<a>`. Ширину и высоту ему задать **нельзя**.
- `inline-block` — «золотая середина»: стоит **в ряд** с другими (как строчный), но при этом **слушается** ширины, высоты и отступов (как блок). Удобно, чтобы поставить карточки или кнопки в линию.
- `flex` — включает **Flexbox**: элемент становится гибким контейнером, а его дети выстраиваются в ряд (или колонку) и ими легко управлять (выровнять, задать промежутки `gap`). Подробно — в отдельном модуле; пока используем как «рецепт», чтобы поставить блоки в ряд.
- `none` — элемент **полностью исчезает** со страницы (и не занимает место).

```css
/* поставить три карточки в ряд двумя способами */
.card { display: inline-block; width: 150px; }     /* способ попроще */
.row  { display: flex; gap: 16px; }                 /* способ поудобнее */
```

## Тени

### `box-shadow`
Тень у **блока** (у всего прямоугольника элемента). Делает карточки «приподнятыми» над страницей. Значение: `сдвиг-вправо сдвиг-вниз размытие цвет`.
```css
.card  { box-shadow: 0 8px 20px rgba(0,0,0,0.15); }   /* мягкая тень снизу */
.btn   { box-shadow: 0 4px 10px rgba(0,0,0,0.25); }
.inset { box-shadow: inset 0 2px 6px rgba(0,0,0,0.3); } /* тень внутрь */
```
Как читать `0 8px 20px rgba(0,0,0,0.15)`:
- `0` — сдвиг **вправо** (здесь 0 — тень ровно снизу).
- `8px` — сдвиг **вниз** (тень падает под блок).
- `20px` — **размытие**: больше значение — мягче и шире тень.
- `rgba(0,0,0,0.15)` — цвет тени.
- `inset` (необязательно, в начале) — тень рисуется **внутрь** элемента, а не наружу.
> ⚠️ Бери цвет тени **полупрозрачным** (`rgba(...,0.15)`), а не сплошным чёрным — так тень выглядит мягко и естественно. Можно задать несколько теней через запятую.

## Списки и таблицы (CSS)

### `list-style-type`
Задаёт вид маркера у пунктов списка (или убирает его).
```css
ul      { list-style-type: square; }   /* квадратные маркеры */
ol      { list-style-type: decimal; }   /* цифры 1, 2, 3 */
nav ul  { list-style-type: none; }      /* убрать маркеры — для меню */
```
Значения:
- `disc` — закрашенная точка (у `<ul>` по умолчанию).
- `circle` — кружок (не закрашенный).
- `square` — квадратик.
- `decimal` — числа 1, 2, 3 (у `<ol>` по умолчанию).
- `none` — **без** маркеров. Главный приём, чтобы превратить список в горизонтальное меню.

### `border-collapse`
Ставится на таблицу `<table>`. По умолчанию у каждой ячейки своя рамка, и рядом они образуют **двойные** линии — выглядит неаккуратно. Значение `collapse` «схлопывает» соседние рамки в одну.
```css
table   { border-collapse: collapse; }
th, td  { border: 1px solid #ccc; padding: 8px 14px; }
```
- `collapse` — границы ячеек сливаются в одну линию (аккуратно). Почти всегда нужно именно это.
- `separate` — поведение по умолчанию: у каждой ячейки отдельная рамка.

## Картинки в блоках

### `object-fit`
Нужно, когда картинке задали **и ширину, и высоту** (например, чтобы все обложки были одинакового размера). Обычно это сплющивает фото. `object-fit` говорит, **как вписать** картинку в такой размер без искажения.
```css
.cover img {
  width: 100%;
  height: 200px;
  object-fit: cover;   /* заполнить блок, лишнее обрезать */
}
```
Значения:
- `cover` — картинка **заполняет** весь заданный прямоугольник, лишнее по краям обрезается. Пропорции сохраняются. Идеально для ровных обложек и аватарок.
- `contain` — картинка **целиком помещается** в прямоугольник без обрезки, но могут остаться пустые полосы.
- `fill` — растянуть по размеру (по умолчанию) — **искажает** картинку, обычно не нужно.

### `aspect-ratio`
Задаёт блоку **пропорции** (отношение ширины к высоте). Тогда можно указать только ширину, а высоту браузер посчитает сам, держа пропорцию. Очень удобно для резиновых обложек, видео и квадратных аватарок.
```css
.poster { width: 100%; aspect-ratio: 16 / 9; }  /* широкий киноэкран */
.avatar { width: 120px; aspect-ratio: 1 / 1; }  /* всегда квадрат */
.card-cover { width: 100%; aspect-ratio: 4 / 3; object-fit: cover; }
```
Как читать `16 / 9`:
- первое число — ширина, второе — высота. `16 / 9` — широкий формат (как телевизор), `1 / 1` — квадрат, `4 / 3` — почти квадратный.
> Чем удобно: при резиновой ширине (`width: 100%`) блок меняет размер вместе с экраном, но форма (пропорции) остаётся правильной.

## Градиенты и эффекты

### `linear-gradient()`
Плавный переход между цветами **по прямой линии**. Пишется как значение фона (в `background`).
```css
.banner { background: linear-gradient(to right, #2965f1, #7c3aed); }  /* слева направо */
.sky    { background: linear-gradient(180deg, #4facfe, #ffffff); }    /* сверху вниз */
.warm   { background: linear-gradient(135deg, #f6d365, #fda085); }    /* по диагонали */
```
Что означают части:
- **направление** — первым: `to right` (слева направо), `to bottom` (сверху вниз), или угол `135deg` (по диагонали). `0deg` — вверх, `90deg` — вправо, `180deg` — вниз.
- **цвета** — через запятую, минимум два. Переход идёт от первого к последнему. Можно и три, и больше: `linear-gradient(red, yellow, green)`.

### `radial-gradient()`
Переход, расходящийся **кругом из центра** (как свет лампы или блик). Первый цвет — в центре, последний — по краям.
```css
.spot { background: radial-gradient(circle, #ffffff, #4facfe); }
.glow { background: radial-gradient(circle at top, #fff, transparent); }
```
- `circle` — форма круга (ещё бывает `ellipse` — овал).
- `at top` / `at center` — где центр градиента.

### `conic-gradient()`
Переход цвета **по кругу**, как стрелка часов обходит циферблат. Используют для диаграмм-«пирогов», радужных колец, индикаторов.
```css
.pie     { background: conic-gradient(#f00, #ff0, #0f0, #00f, #f00); }
.loader  { background: conic-gradient(#4facfe 0% 25%, #eee 25% 100%); }
```
- цвета идут по кругу от 12 часов по часовой стрелке.
- можно указывать доли (`0% 25%`) — для чётких секторов диаграммы.

### `backdrop-filter`
Размывает (или иначе обрабатывает) то, что находится **за** элементом. Самое частое применение — эффект **матового стекла** (стекломорфизм): полупрозрачная плашка, сквозь которую фон виден размытым.
```css
.glass {
  background: rgba(255, 255, 255, 0.15);     /* полупрозрачный фон */
  -webkit-backdrop-filter: blur(10px);        /* дубль для Safari */
  backdrop-filter: blur(10px);                /* размыть то, что сзади */
  border: 1px solid rgba(255,255,255,0.3);
}
```
- `blur(10px)` — сила размытия (больше — сильнее «матовость»).
- Обязательно нужен **полупрозрачный фон** (`rgba(...)`), иначе сквозь плашку ничего не будет видно.
- Строка с `-webkit-` нужна для поддержки в части браузеров.

# Форматы цвета

Один и тот же цвет можно записать разными способами — компьютеру всё равно, выбирай что удобнее в конкретный момент.

| Формат | Пример | Что это и когда удобно |
|--------|--------|------------------------|
| Имя | `red`, `gold`, `teal` | около 140 готовых названий цветов — удобно для быстрого наброска |
| HEX | `#ff5722` | «решётка» и 6 символов (0–9, a–f): по паре на красный, зелёный, синий. Удобно копировать из палитр и дизайна |
| RGB | `rgb(255, 87, 34)` | три числа 0–255: сколько красного, зелёного и синего света смешать |
| RGBA | `rgba(255, 87, 34, 0.5)` | то же + четвёртое число (alpha) 0–1 — прозрачность (0 — невидимый, 1 — плотный) |
| HSL | `hsl(14, 100%, 57%)` | тон (0–360, цвет на радуге), насыщенность (%) и светлота (%). Удобно подбирать оттенки — крути светлоту |
| Современные | `oklch(...)`, `color-mix(...)` | новые форматы: ровные оттенки и смешивание цветов (знакомимся обзорно) |

```css
h1        { color: #ff5722; }                    /* HEX */
.badge    { background-color: rgb(76, 175, 80); } /* RGB */
.overlay  { background-color: rgba(0, 0, 0, 0.5); } /* полупрозрачный чёрный */
.accent   { color: hsl(200, 80%, 50%); }          /* HSL */
```
> Прозрачность (последнее число в `rgba`/`hsla`) идёт от `0` (совсем прозрачный) до `1` (совсем плотный). `0.5` — наполовину.

# Emmet — быстрый ввод кода

Emmet — встроенный в VS Code помощник: ты пишешь короткую **аббревиатуру** и нажимаешь **Tab**, а он разворачивает её в полноценный код. Это сильно ускоряет работу и защищает от опечаток. Разберём знаки, из которых строятся аббревиатуры.

**Основные знаки:**

| Знак | Что значит | Пример → результат |
|------|-----------|--------------------|
| (имя) | тег с таким именем | `p` → `<p></p>` |
| `>` | вложенность («внутрь») | `div>p` → `<div><p></p></div>` |
| `+` | соседний элемент («рядом») | `h1+p` → `<h1></h1><p></p>` |
| `*` | повтор N раз | `li*3` → три `<li></li>` |
| `{}` | текст внутри тега | `h1{Привет}` → `<h1>Привет</h1>` |
| `.` | класс у элемента | `.card` → `<div class="card"></div>` |
| `#` | id у элемента | `#header` → `<div id="header"></div>` |
| `$` | порядковый номер | `li.item$*3` → `item1`, `item2`, `item3` |

**Как это читается вместе.** Аббревиатуры можно комбинировать, как формулу. Например, `ul>li*3` — «создай `<ul>`, а **внутри** (`>`) него — три (`*3`) `<li>`».

**Полезные примеры:**
```
!                    →  целый каркас HTML5-страницы (DOCTYPE, html, head, body)
link:css             →  <link rel="stylesheet" href="style.css">
div.card             →  <div class="card"></div>
img.photo            →  <img src="" alt="" class="photo">
ul>li*4              →  <ul> с четырьмя <li> внутри
div>img*3            →  <div>, а в нём три <img>
table>tr*2>td*3      →  таблица: 2 строки, в каждой по 3 ячейки
ul>li{Пункт $}*5     →  список: «Пункт 1», «Пункт 2» … «Пункт 5»
header>nav>a*3       →  <header>, внутри <nav>, внутри три ссылки <a>
```

- `.` (точка) без имени тега перед ней создаёт `<div>` с этим классом — потому что `div` самый частый контейнер.
- Если указать тег, класс крепится к нему: `p.note` → `<p class="note"></p>`.
- Знак `$` заменяется на номер при повторе `*` — удобно для нумерованных классов или текста.

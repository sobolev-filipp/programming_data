# WEB — вёрстка сайтов: HTML + CSS + Figma + основы JS (курс программирования)

> **135 ак.ч.** · **1 урок = 2 ак.ч. (1,5 часа).** Формат: 2 раза/нед по 1 уроку **или** 1 раз/нед по 2 урока подряд (4 ак.ч.).
> **Возраст:** 5–11 классы.
> **Место в программе:** курс по фронтенду — от первой HTML-страницы до адаптивного сайта с анимацией, дизайна в Figma и «оживления» страниц на JavaScript.
> **Итог года:** каждый ребёнок собирает **своё портфолио-сайт** и **публикует его в интернет** (реальная ссылка).

---

## 🎯 Чему научится ребёнок

- Верстать страницы всеми **часто используемыми тегами** и по всем правилам семантики.
- Знать **все главные приёмы визуала на CSS** — от цвета и теней до градиентов, анимаций и 3D.
- Пользоваться **современным CSS 2026** (только то, чем **уже можно** пользоваться в продакшене, без экспериментального): `:has()`, вложенность, container queries, subgrid, `clamp()`, `oklch()`, `color-mix()`, `<dialog>`, popover и др.
- Писать HTML **быстро** через **Emmet** — осваиваем **постепенно**, от `!` до `div{point $}*10`.
- Делать **разнообразные интересные проекты** почти на каждом уроке (не однотипные) и **вау-фишки**: кардхолдер, градиент к тексту, движение по кругу, стекломорфизм, живые открытки.
- Проектировать дизайн в **Figma** (изучаем **рано**) и **верстать по своему макету**.
- Раскладывать блоки на **Flexbox** (изучаем **рано** — чтобы сразу делать красивые многоколоночные работы) и **Grid**.
- «Оживлять» страницы **основами JavaScript** и подключать **готовые JS-библиотеки** (галерея-lightbox, слайдер).
- **Публиковать** сайт (GitHub Pages).

## 🧩 Сквозные линии курса (важно для сборки)

### ⌨️ Emmet — осваиваем постепенно
| Где | Что добавляем |
|-----|---------------|
| М1 | `!` (каркас), теги-аббревиатуры, `+` (соседи), `*` (повтор), текст `{...}`, `>` (вложенность — в уроке картинок: `div>img*3`) |
| М2 | `^` (подъём), группировка `()` для списков/таблиц (`ul>li*5`, `table>tr*3>td*2`) |
| М3 | `.class`, `#id`, `div.card`, `img.photo` |
| М4+ | нумерация `$` (`li.item$*5`), `div{Пункт $}*10`, комбинации |
| далее | по необходимости закрепляем в `лайфхак.md` каждого урока |

### 🖱 Псевдоклассы — постепенно
- **Рано, как «фишка»:** `:hover`, `:active`, `:focus` появляются уже в М1–М4 (ссылка меняет цвет, кнопка реагирует) — без теории, «на подражании».
- **Полноценно:** структурные и мощные (`nth-child`, `:is/:where`, `:has`, псевдоэлементы) — Модуль 7.

### 📏 Единицы измерения — постепенно
- **М1–М11:** только `px` (размеры) и `%` (резиновая ширина) + `clamp()` в М11.
- **М12 (адаптивность):** вводим `em`, `rem`, `vw/vh/dvh` осмысленно, когда уже ясно «зачем».

### 🎨 Проекты — разнообразные, не однотипные
На **каждом уроке** — свой небольшой интересный проект/фишка на **разные сюжеты** (кафе, космос, игры, музыка, кино, спорт, товар, погода…). **Итоговые задания практики и самостоятельные работы модулей — на разные темы**, чтобы не повторяться. Карта проектов — ниже.

# Урок 1 «Ссылки» — итого (шпаргалка) 📌

> За 3 минуты вспомнить весь урок. Только суть и примеры.

---

## Главные мысли

1. **Ссылка — это дверь.** Тег `<a>`, а `href` — **адрес двери** (куда вести).
2. **Внешняя** ссылка — полный адрес `https://...`; **своя** — имя файла (`about.html`).
3. **`target="_blank"`** — открыть в новой вкладке (для внешних сайтов).
4. **Якорь `#`:** `id="имя"` на разделе + `href="#имя"` в ссылке = прыжок внутри страницы.
5. **4 состояния** ссылки: `:link → :visited → :hover → :active` (**LoVe HAte** — в этом порядке).

---

## Виды ссылок — код

```html
<a href="https://ya.ru" target="_blank" rel="noopener">Внешний сайт</a>
<a href="about.html">Своя страница</a>
<a href="mailto:hi@mail.ru">Написать письмо</a>
<a href="tel:+79001234567">Позвонить</a>
<a href="#rules">К разделу «Правила»</a>
<a href="#">⬆ Наверх</a>
```

| В `href` | Куда ведёт |
|----------|-----------|
| `https://...` | чужой сайт |
| `about.html` | своя страница рядом |
| `mailto:...` | письмо |
| `tel:...` | звонок |
| `#имя` | к разделу с `id="имя"` |

---

## Якорь — 2 шага

```html
<a href="#rules">К правилам</a>   <!-- шаг 2: ссылка с # -->
...
<h2 id="rules">Правила</h2>        <!-- шаг 1: метка id -->
```
Плавная прокрутка: `html { scroll-behavior: smooth; }`.

---

## Стили ссылок

```css
a         { color: #2563eb; text-decoration: none; }
a:hover   { color: #dc2626; text-decoration: underline; }
a:visited { color: #7c3aed; }
```
`text-decoration`: `none` (убрать), `underline` (подчеркнуть), `line-through` (зачеркнуть).

**Ссылка-кнопка / меню:**
```css
nav a {
    display: inline-block;
    background-color: #2563eb; color: #fff;
    padding: 10px 18px; border-radius: 8px;
    text-decoration: none;
}
```

## Emmet — новое

| Аббревиатура | Что развернёт |
|--------------|---------------|
| `a` + `Tab` | `<a href=""></a>` |
| `nav>a*3` | `<nav>` с тремя ссылками |
| `^` | подъём на уровень вверх (`nav>a^footer`) |

---

## Главные ошибки

| Проблема | Причина | Лечение |
|----------|---------|---------|
| ссылка ведёт «в никуда» | забыл `https://` у внешней | внешний сайт — полный адрес |
| якорь не прыгает | имя `#имя` ≠ `id` раздела | имена должны совпадать буква-в-букву |
| `:hover` не работает | перепутан порядок псевдоклассов | LoVe HAte: link→visited→hover→active |
| `footer` попал внутрь `nav` | забыл Emmet `^` | `^` выводит наружу |

## Что осталось в голове

1. Делаю ссылку `<a href="...">` на сайт, свою страницу, почту, телефон.
2. Открываю в новой вкладке через `target="_blank"`.
3. Прыгаю по странице якорями (`id` + `#`).
4. Оформляю 4 состояния ссылки и делаю меню-кнопки в `<nav>`.

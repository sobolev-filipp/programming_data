# 🧰 Лайфхаки · Урок 2 «Шрифты»

Трюки и частые ошибки, чтобы работать со шрифтами быстро и красиво.

---

## 🔤 Google Fonts — как выбрать с умом

- **Не больше 2 шрифтов** на страницу: один для заголовков, один для текста. Три и больше — «цирк».
- **Проверенные пары** (заголовок + текст): `Playfair Display` + `Roboto`, `Oswald` + `Open Sans`, `Lobster` + `Montserrat`, `Bebas Neue` + `Roboto`.
- **Не грузи лишние начертания.** Каждое (тонкое, жирное, курсив) — это вес и время загрузки. Обычно хватает `400` и `700`.
- **Фильтры на fonts.google.com:** по стилю (Serif / Sans / Display / Handwriting), по языку (выбери **Cyrillic**, чтобы шрифт поддерживал русские буквы!).

> ⚠️ **Русские буквы.** Не у каждого шрифта есть кириллица. Если русский текст остался «квадратиками» или сменился на стандартный — у шрифта нет кириллицы. Ставь фильтр **Cyrillic** при выборе.

## 🎨 `url()` — запомни на будущее

`url()` в CSS — это **путь к файлу**. Сегодня мы дали им путь к шрифту, но тем же `url()` подключают:
```css
background-image: url("фон.jpg");     /* фоновая картинка */
list-style-image: url("маркер.png");  /* свой маркер списка */
cursor: url("меч.png"), auto;          /* свой курсор мыши */
```
Везде смысл один: **«файл лежит вот здесь»**. Пути такие же, как в `href`/`src`.

## ⌨️ Emmet и сокращения

| Ввод в CSS | Развернётся |
|------------|-------------|
| `ff` + `Tab` | `font-family: ;` |
| `fw` + `Tab` | `font-weight: ;` |
| `fs` + `Tab` | `font-style: ;` |
| `fz20` + `Tab` | `font-size: 20px;` |
| `@f` + `Tab` | заготовка `@font-face { ... }` |

## 🐞 Частые ошибки и как избежать

- **Шрифт не сменился** → забыл подключить `<link>` (или `@font-face`). Сначала подключить, потом применять.
- **Имя из двух слов не работает** → нет кавычек. Пиши `"Comic Sans MS"`.
- **Жирный/курсив выглядит криво** → начертание не подключено. Выбери `700`/italic на Google Fonts.
- **Русский текст «квадратиками»** → у шрифта нет кириллицы. Выбери шрифт с поддержкой Cyrillic.
- **Текст «мигает» при загрузке** → добавь `font-display: swap`.
- **`url()` не находит файл** → неверный путь. Файл должен лежать там, куда указывает путь (обычно относительно CSS-файла).

## 🧭 Правило хорошего тона

- **Читаемость важнее красоты.** Для основного текста бери спокойный шрифт (`sans-serif`), декоративный оставь для заголовков.
- **Размер и контраст.** Красивый шрифт мелким серым текстом на пёстром фоне — плохо читается. Заголовок — крупный, текст — с достаточным контрастом.

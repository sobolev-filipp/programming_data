# Урок 4 «Таблицы» — итого (шпаргалка) 📌

> За 3 минуты вспомнить весь урок. Только суть и примеры.

---

## Главные мысли

1. Таблица строится **по строкам**: `<table>` → `<tr>` (строка) → `<td>` (ячейка).
2. Сколько `<td>` в строке — **столько столбцов**.
3. **`<th>`** — жирный заголовок; **`<caption>`** — подпись таблицы.
4. **`border-collapse: collapse`** убирает двойные рамки — обязательно.
5. **`colspan`/`rowspan`** объединяют ячейки (и «лишние» `<td>` убираем).

---

## Каркас таблицы

```html
<table>
    <caption>Название</caption>
    <thead>
        <tr><th>День</th><th>Урок</th></tr>       <!-- шапка -->
    </thead>
    <tbody>
        <tr><td>Пн</td><td>Математика</td></tr>    <!-- данные -->
        <tr><td>Вт</td><td>Информатика</td></tr>
    </tbody>
</table>
```

| Тег | Что это |
|-----|---------|
| `<table>` | вся таблица |
| `<tr>` | строка |
| `<td>` | ячейка с данными |
| `<th>` | ячейка-заголовок (жирная) |
| `<caption>` | подпись таблицы |
| `<thead>`/`<tbody>` | шапка / тело |

---

## Рамки и воздух

```css
table { border-collapse: collapse; }        /* одинарные рамки! */
th, td { border: 1px solid #cbd5e1; padding: 10px 14px; }
```

---

## Объединение ячеек

```html
<th colspan="2">Заголовок на 2 столбца</th>   <!-- по горизонтали -->
<td rowspan="2">На 2 строки</td>               <!-- по вертикали -->
```
Растянул на 2 столбца → в этой строке на 1 `<td>` меньше!

---

## «Зебра» и наведение

```css
tbody tr:nth-child(even) { background-color: #f1f5f9; }   /* чётные строки */
tbody tr:hover { background-color: #dbeafe; }             /* подсветка */
thead th { background-color: #2563eb; color: white; }     /* шапка */
```
`even` — чётные, `odd` — нечётные.

|------|-----------|
| `table>tr*3>td*3` | таблица 3×3 |
| `table>tr*4>td*2` | 4 строки по 2 ячейки |

---

## Главные ошибки

| Проблема | Причина | Лечение |
|----------|---------|---------|
| двойные рамки | нет `border-collapse` | `table { border-collapse: collapse; }` |
| таблица «поехала» | `colspan`, но не убрал лишний `<td>` | меньше `<td>` на число объединённых |
| текст липнет к рамкам | нет `padding` | `th, td { padding: 10px; }` |
| зебра не работает | правило не на `tr` | `tbody tr:nth-child(even)` |

---

## Что осталось в голове

1. Строю таблицу из `<table>`/`<tr>`/`<td>`, шапку — из `<th>`.
2. Убираю двойные рамки через `border-collapse: collapse`.
3. Объединяю ячейки `colspan`/`rowspan`.
4. Делаю «зебру» через `:nth-child(even)`.

# Урок 3 «Списки» — итого (шпаргалка) 📌

> За 3 минуты вспомнить весь урок. Только суть и примеры.

---

## Главные мысли

1. Список — это **контейнер** (`<ul>` или `<ol>`), внутри — **пункты** `<li>`.
2. **`<ul>`** — маркированный (точки), порядок неважен. **`<ol>`** — нумерованный (цифры), порядок важен.
3. **`list-style-type`** меняет маркер; **`list-style: none`** — убирает маркеры.
4. Вложенный список кладут **внутрь `<li>`**.
5. **Меню сайта делают из списка** (`list-style: none` + `display: flex`).

---

## Два главных списка

```html
<ul>                    <ol>
    <li>Хлеб</li>           <li>Шаг 1</li>
    <li>Молоко</li>         <li>Шаг 2</li>
</ul>                   </ol>
```
`<ul>` → ● ● ●   ·   `<ol>` → 1. 2. 3.

Атрибуты `<ol>`: `type="A"` (буквы), `start="5"`, `reversed`.

---

## Виды маркеров — `list-style-type`

| Для `<ul>` | Для `<ol>` |
|-----------|-----------|
| `disc` ● (по умолч.) | `decimal` 1,2,3 (по умолч.) |
| `circle` ○ | `lower-alpha` a,b,c |
| `square` ▪ | `upper-roman` I,II,III |
| `none` (убрать) | — |

```css
ul { list-style-type: square; }
ul { list-style: none; }        /* убрать маркеры */
```

---

## Вложенный список

```html
<ul>
    <li>Фрукты
        <ul>
            <li>Яблоко</li>
        </ul>
    </li>
</ul>
```
Вложенный `<ul>` — **внутри** `<li>`, а не между пунктами!

---

## Список описаний `<dl>`

```html
<dl>
    <dt>HTML</dt>
    <dd>язык разметки страницы.</dd>
</dl>
```
`<dt>` — термин, `<dd>` — описание.

---

## Меню из списка

```css
.menu {
    list-style: none;
    padding: 0;
    display: flex;   /* пункты в ряд */
    gap: 20px;
}
```
```html
<ul class="menu">
    <li><a href="#home">Главная</a></li>
</ul>
```

| `ul>li*5` | `<ul>` с 5 пунктами |

| `ul>li*3>a` | список из 3 ссылок |

## Главные ошибки

| Проблема | Причина | Лечение |
|----------|---------|---------|
| нет маркеров/цифр | текст не в `<li>` | каждый пункт — в `<li>` |
| вложенный список «сполз» | стоит между `<li>`, а не внутри | `<ul>` внутрь `<li>` |
| меню осталось столбиком | нет `display: flex` | `.menu { display: flex; gap: 20px; }` |
| остался левый отступ | у списка `padding` | `padding: 0` |

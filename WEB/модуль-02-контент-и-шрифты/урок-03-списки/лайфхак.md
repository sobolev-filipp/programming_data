# 🧰 Лайфхаки · Урок 3 «Списки»

Трюки и частые ошибки, чтобы делать списки быстро и красиво.

---

## ⌨️ Emmet для списков

| Ввод | Развернётся |
|------|-------------|
| `ul>li*5` | `<ul>` с 5 пунктами |
| `ol>li*3` | `<ol>` с 3 пунктами |
| `ul>li*3>a` | список из 3 ссылок (для меню) |
| `ul.menu>li*4>a{Пункт $}` | меню с пунктами «Пункт 1»…«Пункт 4» |
| `dl>(dt+dd)*3` | словарик из 3 пар термин-описание |

> 💡 **`$` в Emmet — нумерация.** `li{Пункт $}*3` создаст «Пункт 1», «Пункт 2», «Пункт 3». Знак `$` подставляет номер повтора.

---

## 🎨 Красивые списки

- **Эмодзи-маркеры:** `list-style: none` + эмодзи в начале пункта — быстро и весело.
- **Свой маркер-картинка:** `list-style-image: url("иконка.png")` — тот же `url()`, что у шрифтов.
- **Цветные маркеры:** `li::marker { color: #e11d48; font-size: 20px; }` — стилизуем сам маркер.
- **Расстояние между пунктами:** `li { margin-bottom: 8px; }` — список «дышит».
- **Список-карточки:** убери маркеры и оформи каждый `<li>` как карточку (фон, padding, скругление).

## 🍔 Меню из списка — шпаргалка

```css
.menu {
    list-style: none;   /* убрали точки */
    padding: 0;         /* убрали левый отступ */
    margin: 0;
    display: flex;       /* пункты в ряд */
    gap: 20px;          /* расстояние */
}
```
- Забыл `padding: 0` → меню «отъедет» вправо (у списка есть отступ по умолчанию).
- `display: flex` подробно разберём в модуле про Flexbox — пока просто рабочий рецепт.

## 🐞 Частые ошибки и как избежать

- **Нет маркеров/номеров** → текст написан не в `<li>`. Каждый пункт — отдельный `<li>`.
- **Вложенный список «сполз»** → он стоит между пунктами, а не внутри `<li>`. Клади `<ul>` **внутрь** нужного `<li>`.
- **Меню осталось столбиком** → нет `display: flex`. Добавь его классу меню.
- **Меню «отъехало» вправо** → у `<ul>` остался `padding`. Поставь `padding: 0`.
- **Перепутал `<ul>` и `<ol>`** → точки вместо цифр или наоборот. `ul` = маркеры, `ol` = номера.
- **`<dt>`/`<dd>` вне `<dl>`** → они работают только внутри контейнера `<dl>`.

---

## 🧭 Когда какой список

- Порядок **неважен** (перечисление) → `<ul>`.
- Порядок **важен** (шаги, рейтинг, инструкция) → `<ol>`.
- Пары «**термин → объяснение**» (словарь, FAQ, характеристики) → `<dl>`.
- **Меню, вкладки, галерея** → тоже список (`<ul>`), просто без маркеров.

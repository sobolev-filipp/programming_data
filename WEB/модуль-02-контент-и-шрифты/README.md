# Модуль 2 — 📄 Контент и шрифты (4 урока, 8 ч)

> Наполняем страницу и **красиво подключаем шрифты** (упор на Google Fonts + свой шрифт через `@font-face`). Базовые картинки уже освоены в Модуле 1. Emmet растёт: добавляем `>` и `^`. Единицы измерения — по-прежнему `px` и `%`.
> ⬅️ [План всего курса](../ПЛАН-КУРСА.md)

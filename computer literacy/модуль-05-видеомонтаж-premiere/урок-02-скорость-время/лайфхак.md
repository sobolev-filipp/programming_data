# Лайфхаки урока 2 — власть над временем без «дёрганья»

> Пять приёмов с **точными шагами**: где кнопка/клавиша, что нажать, что получится.

---

## 🎯 Трюк A — слоу-мо без дырок и наездов

**Правильное замедление:**
1. ПКМ по клипу → **«Скорость/Длительность…»** (`Ctrl+R`).
2. Скорость **40–50%**, обязательно галка **«Волновое изменение, сдвиг конечных клипов»** → «ОК».
3. Клип стал длиннее, соседи подвинулись — без дырок.

> 💡 50% = в 2 раза медленнее, 25% = в 4 раза. Замедляй **только пик**, а не весь клип.

---

## 🎯 Трюк B — скорость под нужную длину (Rate Stretch)

**Когда слоу-мо должно закончиться ровно на бите/склейке:**
1. Инструмент **«Растянуть скорость» (`R`)**.
2. Тяни **край клипа**: длиннее → медленнее, короче → быстрее.
3. Обратно на Выделение (`V`).

> ⚠️ Тянешь край Выделением (`V`) — просто обрежется. Для скорости нужен именно **`R`**.

---

## 🎯 Трюк C — ◀ реверс (время назад)

**Магия и шутки:**
1. ПКМ по клипу → **«Скорость/Длительность…»** (`Ctrl+R`).
2. Галка **«Реверс скорости»** (можно вместе со скоростью, напр. −50%) → «ОК».
3. Видео играет задом наперёд.

> 💡 Возьми клип, где что-то падает/разливается, — реверсом «само соберётся». На реверс-кусках **отключай звук речи** (звучит жутко).

---

## 🎯 Трюк D — ❚❚ стоп-кадр на пике

**Драматичная пауза «замри!»:**
1. Плейхед — точно на **чётком пике** действия.
2. ПКМ по клипу → **«Вставить сегмент удержания кадра»** — в середину вставится заморозка (~2 сек).
3. Длину тяни за край сегмента.

> 💡 Комбо: стоп-кадр **на дропе** музыки → сразу слоу-мо. Кинематографично!

---

## 🎯 Трюк E — ⚡ плавный speed-ramp + гладкое слоу-мо

**Тот самый «whoosh» в замедление:**
1. ПКМ по клипу → **«Показать ключевые кадры» → «Изменение времени» → «Скорость»** (появится жёлтая резинка).
2. **`Ctrl`+клик** — 2 ключа (начало и конец эпик-момента).
3. Между ними **опусти резинку вниз** (слоу-мо).
4. **Раздвинь половинки ключа** — переход станет плавным (горка) = speed-ramp.
5. Гладкость: ПКМ → **«Интерполяция времени» → «Оптический поток»** → **`Enter`** (рендер).

> ⚠️ Без **`Enter`** после Оптического потока слоу-мо тормозит/дёргается при проигрывании.

---

## Итог

| Задача | Точные шаги |
|--------|-------------|
| Слоу-мо | `Ctrl+R` → 40–50% + «Волновое изменение» |
| Ускорение/таймлапс | `Ctrl+R` → 300–800% |
| Скорость под длину | Rate Stretch (`R`) → тянуть край клипа |
| Реверс | `Ctrl+R` → галка «Реверс скорости» |
| Стоп-кадр | Плейхед на пик → ПКМ → «Вставить сегмент удержания кадра» |
| Плавный speed-ramp | Изменение времени → 2 ключа → опустить резинку → раздвинуть ключи |
| Гладкое слоу-мо | Интерполяция времени → «Оптический поток» → `Enter` |

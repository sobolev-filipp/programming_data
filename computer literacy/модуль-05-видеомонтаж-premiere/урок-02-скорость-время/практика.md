# Самостоятельная работа — Видеомонтаж, Урок 2

> 🧑‍🎓 Не повторяем урочный клип! Придумываешь **свой** «эпичный момент» и играешь со временем.

---

## ✅ Задание 1 (для всех) — «Мой эпичный момент» (новый вызов)

Возьми клип с ярким движением и покажи его как в кино — с властью над временем. Выбери **одну** идею (клип — свой с телефона или из стоков):

- 🏀 **Спорт-хайлайт:** бросок/гол/трюк → слоу-мо на моменте попадания + стоп-кадр на празднике;
- 🐕 **Питомец-супергерой:** прыжок/ловля мяча в эпичном слоу-мо;
- 💦 **Стихия:** брызги/всплеск воды или волна в слоу-мо + реверс («вода втягивается»);
- 🛹 **Трюк:** разбег (быстро) → прыжок (слоу-мо) → приземление (стоп-кадр);
- 🍂 **Магия реверса:** что-то падает/рассыпается → реверсом «само собирается».

> ⚡ У каждой идеи есть **пик** — на нём слоу-мо (лучше со speed-ramp), а вокруг — обычная/быстрая скорость.

**🎞 Пример результата** (открой в браузере — **стоп-кадр на пике + реверс**):

![Анимация: объект движется вперёд, замирает стоп-кадром, затем реверс назад](изображения/практика-пример-время.svg)

**Обязательные условия:**
- [ ] Есть **слоу-мо** на пике (Скорость < 100%, с «Волновым изменением»);
- [ ] Есть ещё **минимум один** приём времени: **реверс** ◀ **или** **стоп-кадр** ❚❚ **или** **ускорение/таймлапс** ⏩;
- [ ] Хотя бы попытка **speed-ramp** (плавный влёт в слоу-мо, Изменение времени) — 🎓 обязательно, 🧩 по желанию;
- [ ] Слоу-мо **просчитан** (Оптический поток + `Enter`), играет плавно;
- [ ] Экспорт **MP4** (H.264) + сохранён **`.prproj`**.

## 🔗 Задание 2 (комбо, Урок 1 + Урок 2) — «Эпик под музыку»

Свяжи скорость с ритмом из прошлого урока:
1. Собери **мини-историю** из 2–3 клипов (как в уроке 1: крючок → развитие → финал).
2. Поставь **музыку с дропом** и маркеры на битах (`M`).
3. Сделай так, чтобы **слоу-мо начиналось ровно на дропе**, а после него — быстрые склейки в ритм.

**Результат:** ролик, где время и музыка работают вместе — «влетаем» в слоу-мо на бас, а на финале рубим в ритм.

## ⚡ Задание 3 (разминка-челлендж) — слоу-мо за 5 минут

**За 5 минут:** положи любой клип с движением → **ПКМ → «Скорость/Длительность»** (`Ctrl+R`) → поставь **50%** + галка **«Волновое изменение»** → включи **Оптический поток** (ПКМ → Интерполяция времени) → **`Enter`** → проиграй. Почувствуй, как обычное движение стало эпичным.

---

## 📋 Что проверяем

- [ ] Идея — **свой** эпичный момент (не урочный);
- [ ] Есть **слоу-мо** на пике + ещё один приём (реверс/стоп-кадр/ускорение);
- [ ] Скорость без дырок/наездов («Волновое изменение»);
- [ ] Слоу-мо просчитан (Оптический поток + `Enter`), не дёргается;
- [ ] Экспорт MP4 + `.prproj`;
- [ ] Сделано **«Комбо»** (слоу-мо на дропе + ритм из урока 1).

## 🧩 Для 5–7 классов
- Готовый клип от учителя, **одно** слоу-мо (50%) + **один** реверс — этого достаточно.
- Speed-ramp и Оптический поток — по желанию (или учитель показывает).
- Стоп-кадр — «Добавить остановку кадра».

## 🎓 Для 9–11 классов
- **Двойной speed-ramp** (разгон → глубокое слоу-мо → выкат).
- **Стоп-кадр ровно на дропе** + слоу-мо после.
- **Реверс-петля** (кусок вперёд + он же назад бесшовно).
- Исходники **60/120 fps** для чистого слоу-мо.

## 🖼 Кинозал класса ⚡
Сдай MP4 — устроим показ «эпичных моментов». Голосуем: **самое эпичное слоу-мо** и **самый неожиданный реверс**.

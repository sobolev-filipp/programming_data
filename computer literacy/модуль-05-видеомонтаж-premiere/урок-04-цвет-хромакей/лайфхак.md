# Лайфхаки урока 4 — чистый ключ и киношный цвет

> Пять приёмов с **точными шагами**: где кнопка/инструмент, что нажать, что получится.

---

## 🎯 Трюк A — телепорт за 3 шага (Ultra Key)

**Убрать зелёный фон:**
1. Фон-мир на **V1**, герой на зелёном — на **V2**.
2. «Эффекты» → **Кеинг → Ultra Key** → перетащи на клип героя.
3. «Элементы управления эффектами» → **«Цвет ключа»** → **пипетка** 💧 → клик по **ровному зелёному**.
4. Зелёный исчез — за героем твой мир.

> 💡 Бери пипеткой **средний** зелёный (не самый тёмный/светлый) — ключ выйдет чище.

---

## 🎯 Трюк B — убрать зелёную каёмку

**Чистим край героя:**
1. **«Создание матовости»** → покрути **Прозрачность/Тени/Света**, чтобы фон стал **полностью чёрным**, а герой целым.
2. **«Очистка матовости» → «Сжатие» (Choke)** — чуть подтяни (обрезать каёмку).
3. **«Смягчение» (Soften)** — сгладить край.
4. **«Подавление разлива»** — убрать зелёный **отсвет** на волосах/краях.

> ⚠️ Каёмка = зелёный по контуру. Choke + Подавление разлива её убирают.

---

## 🎯 Трюк C — teal&orange (киношный look)

**Тёплый герой на холодном фоне:**
1. «Цвет Lumetri» → **«Цветовые круги»**.
2. **Тени** → к **бирюзовому (teal)**; **Света** → к **оранжевому (orange)**.
3. **«Виньетка» → «Величина»** в минус (тёмные края).

> 💡 Кожа тёплая, тени холодные — глаз обожает. Виньетка = «дорогой» вид. Не переборщи с силой.

---

## 🎯 Трюк D — корректирующий слой (цвет на всё)

**Один слой красит весь ролик:**
1. «Проект» → **«Новый элемент» → «Корректирующий слой»**.
2. Перетащи на дорожку **сверху** (V3), растяни на всю длину.
3. Красишь **слой** — меняется **весь** ролик. Глазик выключает = сравнить «до/после».

> ⚠️ Слой должен быть **сверху** клипов, иначе не красит.

---

## 🎯 Трюк E — быстрый цвет через LUT

**Киноцвет одним кликом:**
1. «Цвет Lumetri» → **«Креатив»** → выпадающий **«Look»**.
2. Выбери профиль → убавь **«Интенсивность»** до вкуса.

> 💡 LUT — готовый рецепт цвета. Ставь интенсивность 40–70%, не 100% (иначе «перекрас»).

---

## Итог

| Задача | Точные шаги |
|--------|-------------|
| Убрать зелёный фон | Ultra Key → «Цвет ключа» пипеткой по зелёному |
| Убрать каёмку | Матовость (Прозрачность) + Сжатие (Choke) + Подавление разлива |
| Киношный цвет | Lumetri → цветовые круги: тени teal, света orange + виньетка |
| Цвет на весь ролик | Корректирующий слой сверху (V3) + Lumetri |
| Быстрый look | Креатив → Look (LUT) → убавить интенсивность |
| Реализм телепорта | Подогнать яркость/цвет героя под фон |

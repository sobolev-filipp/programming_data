# Лайфхаки урока 3 — титры, голос и чистый звук

> Пять приёмов с **точными шагами**: где кнопка/клавиша, что нажать, что получится.

---

## 🎯 Трюк A — 🤖 голос за кадром без микрофона (TTS)

**Озвучка по тексту за минуту:**
1. Открой [TTSMaker](https://ttsmaker.com/) (или [ttsMP3.com](https://ttsmp3.com/text-to-speech/Russian/)) → язык **Русский** → выбери голос.
2. Впиши текст → **«Озвучить»** → **«Скачать MP3»** (`golos.mp3` в папку проекта).
3. В Premiere: **`Ctrl+I`** → импортируй → перетащи на дорожку **A3**.

> 💡 Это внешний помощник **вне** Adobe — правило «в Premiere без ИИ» не нарушается. Свой голос (микрофон/телефон) — по желанию.

---

## 🎯 Трюк B — читаемый титр (обводка + тень)

**Чтобы текст читался на любом фоне:**
1. «Текст» (`T`) → кликни в мониторе → напечатай.
2. **`Окно → Основные графические элементы` → «Правка»**: включи **Обводку** (контур) и **Тень**, или добавь **Фон** (плашку под текст).
3. Крупный жирный шрифт — заголовки видно даже на телефоне.

> ⚠️ Белый текст на светлом = не читается. Всегда обводка/тень/плашка.

---

## 🎯 Трюк C — кинетический титр (оживить текст)

**Текст, который «выскакивает»:**
1. Выдели титр → **`Окно → Элементы управления эффектами`**.
2. Ключи (значок **секундомера ⏱**):
   - **Непрозрачность:** 0% → 100% за ~10 кадров;
   - **Масштаб:** 70% → 100% за ~12 кадров.
3. Хочешь выезд сбоку (плашка-имя) — ключи по **Положению**.

> 💡 Лёгкое движение = дорогой вид. Не переусердствуй: 10–12 кадров достаточно.

---

## 🎯 Трюк D — субтитры вручную (без ИИ)

**Подписи по фразам:**
1. **`Окно → Текст` → «Подписи»** → **«Создать подписи» → «Создать пустую дорожку»**.
2. **«+»** → впиши фразу → перетащи края под нужный кусок голоса (скраббинг по волне A3).
3. Стиль подписей — в «Основных графических элементах» (шрифт + подложка).

> ⚠️ НЕ жми «Транскрибировать/Речь в текст» — печатаем сами (так по правилам курса).

---

## 🎯 Трюк E — ⚡ дакинг: музыка тише под голос

**Профи-звук в два клика:**
1. **`Окно → Основной звук`** → выдели **музыку** → тип **«Музыка»**.
2. Раздел **«Приглушение (Ducking)»** → приглушать под **«Диалог»** → **«Сгенерировать ключевые кадры»**.
3. Выдели **голос** → тип **«Диалог»**.
4. Готово: музыка сама тише там, где голос, и громче в паузах.

> 💡 Плюс **фейды**: аудиопереход «Постоянная мощность» на края музыки — плавное появление/затухание.

|--------|-------------|
| Голос без микрофона | TTS (TTSMaker) → MP3 → `Ctrl+I` → дорожка A3 |
| Читаемый титр | «Основные граф. элементы» → Обводка/Тень/Фон |
| Оживить титр | Элементы управления эффектами → ключи Непрозрачность/Масштаб |

| Дакинг | Основной звук → Музыка → Приглушение под Диалог → ключи |
| Чистый звук | Голос главный, музыка тише, фейды на краях |

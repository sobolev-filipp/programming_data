# Самостоятельная работа — Фотомагия в Photoshop, Урок 9

> 🎯 Сегодня ты — дизайнер в **студии вывесок и логотипов «ВОЛЬТ»**. К вам приходят за светящимися вывесками, огненными логотипами, золотыми надписями. Стили слоя — не цель, а инструмент: цель — **надпись, которая цепляет взгляд**. Главное правило — **чувство меры** (яркая сердцевина, а не «туман»).

> Делаем по порядку: **разминка** → **свой светящийся логотип** → **вывеска в сцене** → (для смелых) **огненная надпись фильтрами**.

---

## 🎨 Нужен тёмный фон или текстура? Сгенерируй!

Для неона нужен **тёмный фон**, для текстового текста — **текстура** (огонь, космос, золото). Можно сгенерировать по описанию — бесплатно, без регистрации (с учителем; сервисы меняются — проверь перед работой):

| Сервис | Ссылка |
|--------|--------|
| FreeforAI Draw | draw.freeforai.com |
| Pixova | pixova.io |
| Creen AI | creen.ai/ru/ai-image-generator |
| Krea | krea.ai |

**✍️ Как написать промпт:** **ЧТО + КАКОЙ + КАК**. Для фона/текстуры важно: «крупно, без надписей, ровная текстура».
- тёмный фон: `тёмная кирпичная стена ночью, пустая, без надписей, крупный план`
- текстура огня: `яркое пламя на чёрном фоне, крупно, без текста`
- текстура космоса: `звёздное небо, галактика, крупно, без текста`

> ⚠️ Сохраняй в **PNG/JPG**. Генерируем **безопасные** картинки (стены, текстуры, космос — не реальных людей).

## ⚡ Разминка — «Оживи текст» (5 минут)

Напиши любое слово **«Текстом»** (`T`) на тёмном фоне → двойной клик по слою → включи **«Внешнее свечение»** (режим **«Экран»**, яркий цвет) + **«Обводку»**. Готово — слово засветилось.

**🏁 Готово, если:** за минуту слово светится неоном (сердцевина яркая, свечение умеренное).

---

## ✅ Заказ 1 (для всех) — «Светящийся логотип»

Клиент заказал **неоновую вывеску** (не слово из урока!). Тема на выбор: 🎮 логотип игры · 🏪 вывеска магазина мечты · 🎧 название группы · 🍔 неон-реклама.

**Как делать (по шагам):**
1. Открой/создай **тёмный фон** (или сгенерируй — промпт ниже).
2. Напиши слово **«Текстом»** (`T`), округлый жирный шрифт.
3. Двойной клик по слою → собери неон: **Внешнее свечение** (режим «Экран») + **Внутреннее свечение** + **Обводка** + **Тень**.
4. Добавь **значок** рядом: нарисуй **фигурой** `U` или **Пером** `P` *(навык урока 6)* — звезду/молнию/чашку.
5. **Скопируй стиль** с текста на значок (правый клик → «Скопировать/Вставить стиль слоя»).

**Проверь себя:**
- [ ] **Два цвета** неона (например, розовый текст + голубая обводка);
- [ ] Значок тоже светится **тем же стилем**;
- [ ] Фон **тёмный**, свечение **умеренное** (не «туман»); сохранено **PSD + PNG**.

> 🎨 **Промпт фона:** `тёмная бетонная стена ночью с лёгкой подсветкой, пустая, крупный план, без текста`.

## 🔗 Заказ 2 (комбо, уроки 2 + 9) — «Вывеска в сцене»

Соедини **стили слоя** (урок 9) с **выделением и маской** (урок 2):
1. Открой фото **ночного места** (улица, комната, витрина).
2. **Вырежи** объект/себя маской (как в «Телепорте») — или возьми готовый PNG.
3. Помести рядом **свою неоновую вывеску** — будто висит на стене за героем.
4. Добавь от вывески **цветной отсвет** на героя (мягкая кисть, режим «Экран»).

**🏁 Готово, если:** персонаж в атмосферном неон-баре/на ночной улице — мини-постер.

> 🎨 **Промпт сцены:** `ночная улица с неоновыми вывесками, мокрый асфальт, киберпанк, без текста, крупный план`.

## 🎯 А попробуй! (мини-миссии)

**🥇 «Золотая надпись».** Стиль слоя: **Наложение градиента** (тёмно-жёлтый → жёлтый → белый блик) + **Тиснение** → буквы как золото.

**🌌 «Текст из космоса».** *(навык урока 9, Часть 3)* Напиши слово → положи сверху фото **звёздного неба** → `Alt`-клик по границе (обтравка) → буквы заполнятся галактикой. Добавь фиолетовое свечение.

**⚡ «Лазер».** Тонкая яркая линия/слово + мощное **«Внешнее свечение»** (режим «Экран») → лазерный луч.

**🪞 «Отражение».** Дубль вывески → **Отразить по вертикали** → вниз → убавить непрозрачность → режим «Экран» = отражение в мокром асфальте.

**📋 «Единый бренд».** Сделай 3 надписи (логотип + кнопка + заголовок) и **скопируй один стиль** на все — как настоящий бренд-набор.

# Заготовки к уроку 1 (файлы Adobe)

Готовые `.psd`-файлы для **знакомства с программой** (Часть 3 урока). Это учебные
файлы из официального курса *Adobe Photoshop CS6 Classroom in a Book* (2013),
свободно распространявшиеся с изданием. Открываются в любой версии Photoshop.

| Файл | Что внутри | Чему учит |
|------|------------|-----------|
| `01A_Start.psd` | фото старого автомобиля с тусклой фарой | **выделение** (овальная область), инверсия, корректирующий слой **«Кривые»** → сделать фару ярче |
| `01A_End.psd` | тот же кадр с уже яркой фарой | образец результата упражнения A |
| `01B_Start.psd` | фото пляжа со скамейкой | инструмент **«Текст»** + выбор цвета из **«Образцов»** (надпись на песке) |
| `01B_End.psd` | пляж с готовой розовой надписью | образец результата упражнения B |
| `01C_Start.psd` | человек в одноцветном оранжевом галстуке | **кисть по обтравочной маске** (слой `Tie Designs`) → раскрасить только галстук; **отмена** и панель **«История»** |
| `01C_End.psd` | тот же галстук с узором из точек | образец результата упражнения C |

> 💡 **Правило работы:** открывай `*_Start.psd`, делай упражнение, сравнивай с `*_End.psd`.
> Сохраняй под своим именем (**Файл → Сохранить как**), чтобы не портить исходник.

## Как открыть
**Файл → Открыть** → выбери нужный `.psd` из этой папки. Если появится окно
о несовпадении цветового профиля — нажми **ОК**.

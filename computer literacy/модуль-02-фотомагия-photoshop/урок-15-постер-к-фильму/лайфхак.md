# Лайфхаки урока 15 — секреты настоящего киноплаката

> Три приёма, которые превращают «коллаж из фоток» в постер, как в кинотеатре.

---

## 🎯 Трюк A — matte-painting: небо на градиентной маске

Главный секрет реалистичной замены неба **вручную** (без ИИ):

1. Небо — **отдельным слоем поверх** фона, на весь холст.
2. Добавь слою **маску** ▢.
3. Возьми **Градиент** (`G`), чёрно-белый, линейный. Кликни по маске.
4. Проведи **короткий** градиент снизу вверх **по линии горизонта** — низ спрячется (земля), верх останется (небо), стык **растворится**.

> 💡 Если стык всё равно виден — мягкой чёрной кистью (30%) подотри границу на маске. А ещё: **свет неба должен лечь на землю** — подкрась землю в оттенок неба (Цветовой баланс), иначе «не верю».

---

## 🎯 Трюк B — billing block: «титры» делают афишу

Тот самый узкий блок мелких букв внизу — **бесплатный «киночит»**:

1. Внизу постера — **Текст** (`T`), очень мелкий, **по центру**, светло-серый.
2. Сожми буквы по ширине: **Тип → Horizontal Scale ~70%** (узкие, «сплющенные»).
3. Пиши шаблон: `СТУДИЯ … ПРЕДСТАВЛЯЕТ · В ГЛАВНОЙ РОЛИ … · РЕЖИССЁР … · ПРЕМЬЕРА … · 12+`.

> 💡 Мозг зрителя знает: большое название сверху + мелкие титры снизу = «это кино». Даже простой постер с billing block читается как настоящая афиша.

---

## 🎯 Трюк C — «спасение композита»: единство тремя движениями

Если постер выглядит как «разные фотки склеены» — почини это по порядку:

| Проблема | Лекарство |
|----------|-----------|
| Куски разного цвета | **Карта градиента** teal&orange поверх всего, «Мягкий свет» 40% |
| Свет вразнобой | тени всех объектов — **в одну сторону**; притемни/высвети края |
| Герой «парит» | **тень у ног** («Умножение») + контровой свет по контуру |
| Взгляд разбегается | **виньетка** (тёмные углы) ведёт глаз к герою |

> 💡 Правило финала: **единый свет + единый цвет + композиция на героя**. Три вещи спасают почти любой композит.

---

## Итог

| Задача | Решение |
|--------|---------|
| Реалистичное новое небо | небо + **градиентная маска** по горизонту |
| «Киношность» текста | **billing block** + сжатый шрифт |
| Связать все куски | **один цвет** поверх всего (Карта градиента) |
| Приклеить героя | тень у ног + контровой свет |
| Вести взгляд к герою | виньетка + правило третей |
| Не запутаться в слоях | **называй слои и группируй в папки** 📁 |

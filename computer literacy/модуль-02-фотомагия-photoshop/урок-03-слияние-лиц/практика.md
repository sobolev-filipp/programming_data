# Самостоятельная работа — Фотомагия в Photoshop, Урок 3

> 🧑‍🎓 Задание для всех — собери **свой гибрид «человек + животное»**. Учитель помогает с переходом и подгоном.

---

## ✅ Задание 1 (для всех) — «Зверочеловек»

Сплавь портрет человека и морду животного в один портрет.

**Шаги:**
1. Открой портрет, помести сверху морду животного новым слоем.
2. Непрозрачность верхнего слоя → **50%**, выровняй черты (`Ctrl+T`), верни 100%.
3. Добавь **слой-маску**, мягкой кистью (жёсткость 0%, нажим ~30%) **чёрным** плавно спрячь лишнее — оставь «звериную» деталь.
4. Подгони **цвет и свет** обтравочными коррекциями (Цветовой тон, Кривые).
5. Финальный **Фотофильтр** на всё + сохрани **PSD + PNG**.

**Идеи гибридов:** 🦆 утка-человек · 🦁 человек-лев (грива!) · 🐱 котоглаз и усы · 🦉 совиные глаза · 🐶 собачьи уши и нос · 🐸 лягушачий рот.

## 📋 Требования

- [ ] Черты **выровнены** (использована прозрачность 50% при подгонке);
- [ ] Переход сделан **маской и мягкой кистью** (плавно, без резкого шва);
- [ ] Согласованы **цвет и свет** (гибрид смотрится как одно существо);
- [ ] Есть **название** гибрида (подпиши в имени файла);
- [ ] Сохранены **PSD и PNG**.

## 💡 Подсказки

- Не совпал цвет кожи? Пипеткой (`I`) возьми оттенок щеки и подгоняй к нему.
- Виден шов? Пройди по нему мягкой кистью по маске ещё раз, малым нажимом.
- Проверяй плавность перехода клавишей `\` (маска красным поверх фото).

- Убери стык **Штампом** на отдельном слое.
- Сделай **серию из 2 гибридов** одного человека с разными животными.

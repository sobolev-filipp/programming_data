# Лайфхаки урока 3 — слои, режимы наложения и бесшовная кожа

> Четыре приёма, чтобы уверенно рулить слоями и делать монтаж без швов.

---

## 🎯 Трюк A — перебор режимов наложения «вживую»

Не помнишь, какой режим нужен? Встань на список режимов (слева вверху панели слоёв) и **крути колесо мыши** (или жми стрелки ↑↓) — картинка перебирает режимы **в реальном времени**. Остановись на лучшем.

Шпаргалка «что делает»:
| Режим | Эффект |
|-------|--------|
| **Умножение** | затемняет (белое исчезает) — тени |
| **Экран** | осветляет (чёрное исчезает) — свет, блики |
| **Перекрытие** | контраст + цвет сочнее |
| **Мягкий свет** | то же, но нежнее — аккуратная пересветка |

> 💡 Слишком сильно? Урони слою **непрозрачность** — эффект ослабнет.

---

## 🎯 Трюк B — `Ctrl`+клик = загрузить форму слоя как выделение

Зажми **`Ctrl`** и кликни по **миниатюре слоя** (по картинке) — Photoshop выделит всё непрозрачное на этом слое (например, форму лица). Это выделение потом можно **сжать** (`Выделение → Модификация → Сжать`), залить, вырезать «дырку». Основа подготовки к автоналожению.

---

## 🎯 Трюк C — Автоналожение слоёв (бесшовная кожа за один шаг)

Вместо стопки корректирующих слоёв ради подгона тона:
1. Подготовь слои (дубликат тела → `Ctrl`+клик по лицу → `Сжать` 8–10 px → `Delete` на теле).
2. Выдели **два слоя** (лицо + тело), `Редактирование → **Автоналожение слоёв**`.
3. **Панорама** + галочка **«Плавные переходы и цвета»** → `ОК`.

Photoshop сам создаёт маски и выравнивает тон/цвет кожи — граница исчезает. Это **алгоритм**, не ИИ.

---

## 🎯 Трюк D — быстрые клавиши слоёв и кисти

- **Дубликат слоя:** `Ctrl+J`.
- **Порядок:** `Ctrl+]` выше, `Ctrl+[` ниже; `Ctrl+Shift+]`/`[` — в самый верх/низ.
- **Непрозрачность слоя:** возьми Перемещение (`V`) и жми цифры — `3` = 30%, `5` = 50%, `0` = 100%.
- **Кисть:** размер `[` `]`, жёсткость `Shift+[` `Shift+]`, нажим — цифрами; `D` сбрасывает цвета (чёрный/белый), `X` меняет их местами.
- **Проверка маски:** `\` — маска показывается красным поверх фото.

## Итог

| Задача | Решение |
|--------|---------|
| Быстро подобрать режим | колесо мыши по списку режимов |
| Выделить форму слоя | `Ctrl`+клик по миниатюре |
| Сшить кожу без шва | Автоналожение слоёв (Панорама + плавные тона) |
| Пересветить лицо | слой в режиме Мягкий свет, кисть белым/чёрным |
| Найти «швы» | клавиша `\` (маска красным) |
| Не «замылить» при масштабе | смарт-объект (из урока 2) |

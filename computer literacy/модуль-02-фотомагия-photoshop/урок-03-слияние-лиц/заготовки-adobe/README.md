# Заготовки к уроку 3 (Часть 1–2 «Мастерская слоёв»)

Файлы из **официального учебного курса Adobe Photoshop CS6** (Урок 4 «Работа со слоями», стр. 110–123). Используются как учебный пример работы со слоями и режимами наложения.

| Файл | Что это | Где в уроке |
|------|---------|-------------|
| `04Start.psd` | Открытка «HAWAII» — 5 слоёв: Штамп, HAWAII, Цветок, Ананас, Фон | Часть 1, Шаг 0 — открываем и работаем |
| `Beach.psd` | Фото пляжа (отдельный файл) | Часть 1, Шаг 3 — переносим слоем в открытку |
| `04End.psd` | Готовый образец открытки (цель) | образец / самопроверка |
| `FamilyPhoto.psd` | Доп-фото | для своих вариантов открытки |
| `Flower2.psd` | Доп-цветок | для своих вариантов открытки |

**Рендер готовой открытки** — `../изображения/образец-открытка.jpg` (сгенерирован из `04End.psd`).

> Материалы взяты из открытого официального учебного курса Adobe (издание 2013 г.) для образовательных целей.

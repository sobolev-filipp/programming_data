# Компьютерная грамотность и цифровое творчество

Обновлённый курс для детей **5–11 классов**. Объём — **135 ак.ч.** · **1 урок = 2 ак.ч.**
Формат: 2 раза/нед по 1 уроку (2 ак.ч.) **или** 1 раз/нед по 2 урока подряд (4 ак.ч.).

> **Философия курса:** никакой сухой теории. Каждый урок дети **создают конкретную интересную работу** по референсу, осваивая новые «фишки». Уроки **максимально подробные** — с объяснениями «почему» и примерами. Каждый урок — с игрой-**викториной** на закрепление.

## 📚 Навигация — ДВА ПАРАЛЛЕЛЬНЫХ ПЛАНА

Планы **идут параллельно**: модули **1–5** (старт, Photoshop, вектор, Animate, Premiere) и **9–10** (документы/таблицы/презентации, итог) — **одинаковы для всех**. Различается только **профильный блок (модули 6–8)**.

- 🗺 **[ПЛАН-КУРСА.md](ПЛАН-КУРСА.md)** — обзор + все **общие модули** (1–5, 9–10) с уроками.
- 🧒 **[ПЛАН-младшие-5-7.md](ПЛАН-младшие-5-7.md)** — профильный блок младших: Scratch · Kodu · BlockBench.
- 🧑 **[ПЛАН-старшие-9-11.md](ПЛАН-старшие-9-11.md)** — профильный блок старших: App Inventor · HTML/CSS · Roblox.
- 🔧 **[HANDOFF.md](HANDOFF.md)** — правила, конвенции, статус (читать первым при продолжении).

> 🤖 **Нейросети вплетены по всему курсу** (значок 🤖), не отдельным модулем. 🎮 **Каждый урок — с викториной** (`викторина.html`). 📥 Для Adobe — ссылки на исходники в каждом уроке.

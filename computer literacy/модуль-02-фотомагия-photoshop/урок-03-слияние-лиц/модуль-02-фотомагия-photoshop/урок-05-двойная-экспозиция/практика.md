# Самостоятельная работа — Фотомагия в Photoshop, Урок 5

> 🧑‍🎓 Задание для всех — собери **свою двойную экспозицию**. Учитель помогает с режимом и маской.

---

## ✅ Задание 1 (для всех) — «Портрет из…»

Помести внутрь силуэта человека красивую текстуру.

**Шаги:**
1. Открой портрет, вырежи человека («Быстрое выделение» → маска ▢).
2. Подложи **белый фон** (◐ → «Цвет…» → белый → перетащи вниз).
3. Помести текстуру сверху (`Файл → Поместить встроенные…`).
4. Режим наложения текстуры (список «Обычные» вверху панели слоёв) → **«Экран»**.
5. Сделай текстуру **обтравочной** к портрету (`Alt`+клик по границе).
6. Верни лицо маской (чёрным по глазам) — по желанию.
7. Затонируй (◐ → «Карта градиента…») и сохрани **PSD + PNG**.

**Идеи «начинки»:** 🌲 лес · 🏙 город · 🏔 горы · 🌊 волны · ✨ звёздное небо · 🌸 цветы.

## 📋 Требования

- [ ] Использован **режим наложения** («Экран» или другой подходящий);
- [ ] Текстура **ограничена силуэтом** (обтравочная маска);
- [ ] Работа **затонирована** в единый цвет;
- [ ] (по желанию) читаются глаза/лицо;
- [ ] Сохранены **PSD и PNG**.

## 💡 Подсказки

- Бледно? Продублируй текстуру `Ctrl+J`.
- Не сработал «Экран»? Проверь: фон под человеком **белый**, а текстура **контрастная**.
- Тон «наоборот»? В «Карте градиента» поставь галочку **«Инверсия»**.

---

## 🧩 Для 5–7 классов (проще)

- Можно **не вырезать** человека, если у портрета уже светлый фон: просто текстура сверху + режим «Экран».
- Лицо возвращать не обязательно — сплошной силуэт из текстуры тоже красив.

## 🎓 Для 9–11 классов (со звёздочкой)

- Добавь **ветки/птиц за силуэт** (дубль текстуры без обтравки + маска) — Часть 7 урока.
- Сделай **две версии** в разных режимах наложения и разных тонах — сравни.
- Поиграй с **«Умножением»** для тёмной, драматичной версии.

## 🖼 Галерея «Двойные портреты»

Сдай PNG — соберём галерею. Голосуем: **самый атмосферный** и **самый неожиданный**.

# Лайфхаки урока 8 — стили слоя быстро

> Три приёма, чтобы делать эффектный текст быстро и одинаково.

---

## 🎯 Трюк A — копируй стиль целиком

Настроил идеальный неон/золото и хочешь то же на другом слое?
1. **Правой кнопкой по слою** со стилем → **«Скопировать стиль слоя»**.
2. **Правой кнопкой по другому слою** → **«Вставить стиль слоя»**.

Весь набор эффектов перенесётся. А чтобы **перетащить** стиль — зажми `Alt` и потяни значок **fx** с одного слоя на другой.

---

## 🎯 Трюк B — «Глобальное освещение» держит тени в одну сторону

В эффектах **«Тень»** и **«Тиснение»** есть галочка **«Глобальное освещение»**. Если она включена у всех слоёв, **все тени падают в одну сторону** — картинка выглядит цельной. Меняешь угол в одном месте — меняется везде.

> 💡 Правило: разные надписи на одном постере — **одинаковый угол света**. Иначе «разнобой».

---

## 🎯 Трюк C — свечение живёт отдельно

Стиль слоя — не «навсегда»:
- **Выключить** эффект: глазик 👁 рядом с ним в списке fx под слоем.
- **Изменить**: двойной клик по названию эффекта — откроются настройки.
- **Убрать все**: правой кнопкой по слою → «Очистить стиль слоя».

---

## Итог

| Задача | Решение |
|--------|---------|
| Одинаковый стиль на словах | «Скопировать/Вставить стиль слоя» (или `Alt`+перетащить fx) |
| Тени в одну сторону | галочка «Глобальное освещение» |
| Выключить эффект | глазик 👁 в списке fx под слоем |
| Поправить эффект | двойной клик по его названию |
| Свечение как неон | режим «Экран», умеренный размер |

# Самостоятельная работа — Фотомагия в Photoshop, Урок 10

> 🎯 Сегодня ты — художник в **поп-арт студии «ФАБРИКА»** (как у Уорхола!). Заказ — превратить обычные фото в яркие арт-постеры из **плоских кислотных пятен**. Главный приём студии — **честная заливка зон плоским цветом** («Цветовой диапазон» → слой-заливка), а не плавный градиент.

> Делаем по порядку: **разминка** → **поп-арт нового объекта** → **комбо из своей старой работы** → (для смелых) **свой узор-фон**.

---

## ⚡ Разминка — «3 зоны за 3 минуты»

Открой любое контрастное фото → `Изображение → Коррекция → Обесцветить` → ◐ **«Постеризация» = 4** → `Ctrl+Alt+Shift+E` (отпечаток). Готово — фото распалось на плоские зоны, можно красить.

**🏁 Готово, если:** за 3 минуты фото превратилось в трафарет из 3–4 серых пятен.

---

## ✅ Заказ 1 (для всех) — «Поп-арт НЕ про себя» (новый вызов)

На уроке был **свой портрет** — теперь другой объект. Выбери **один**:
- 🐶 **питомец** (свой или из интернета);
- 🎸 **любимый предмет** (кроссовок, гитара, банка колы, наушники — как Уорхол с супом!);
- 🦸 **любимый герой** фильма/игры;
- 👤 **друг** (только с разрешения!).

**Как делать (по шагам, навык урока):**
1. Обесцветить → **Постеризация 3–4** → **`Ctrl+Alt+Shift+E`** (отпечаток «Трафарет»).
2. **«Цветовой диапазон»** по тёмной зоне → **слой-заливка «Цвет»** (плоский поп-цвет). Повтори для средней и светлой зон.
3. Собери плитку в группу (`Ctrl+G`), сделай **минимум 3 плитки** с **разными** палитрами (сетка).

**Проверь себя:**
- [ ] Цвет залит **зонами плоско** (через «Цветовой диапазон»), а не плавным градиентом;
- [ ] Выбрано **настроение палитры** и выдержано: **кислота 90-х** / **ретро 80-х (розово-бирюза)** / **чёрно-жёлтое**;
- [ ] Упрощение — **3–4 уровня** (не «почти фото»); минимум **3 плитки**; сохранено **PSD + PNG**.

> 💡 Предмет (кроссовок, банка) — отличный выбор: чёткая форма, поп-арт из неё смотрится «дизайнерски».

---

## 🔗 Заказ 2 (комбо, прошлые уроки) — «Поп-арт из своей работы»

Возьми **свою готовую работу** и переработай в поп-арт:
- 🐘 **гибрид-зверь** (урок 4) или 🙂↔️🙂 **обмен лицами** (урок 3) → поп-арт постер;
- 🤪 свой **шарж** (урок 8) → поп-арт-версия шаржа (двойная доза веселья!).

**Как:** открой готовый PNG своей работы → Обесцветить → Постеризация → `Ctrl+Alt+Shift+E` → «Цветовой диапазон» + заливки → сетка. Сверху можешь добавить **неоновую подпись** (стили слоя, урок 9).

> Так навык «наслаивается» на навык — работа становится сложнее и интереснее.

## 🎯 А попробуй! (мини-миссии)

**🖤 «Трафарет в 2 краски».** Вместо Постеризации возьми ◐ **«Порог»** → режим слоя **«Умножение»** → под ним слой яркой заливки. Хлёсткий постер в 2 цвета.

**⚫ «Комикс-точки».** Сведи плитку (`Ctrl+E`) → `Фильтр → Оформление → Цветные полутона` (радиус 8) → фирменные точки, как в комиксах.

**🌈 «Палитра-марафон».** Одно фото → три разные палитры заливок подряд → почувствуй, как цвет меняет настроение (повтор у5: можно и «Картой градиента»).

**🪞 «Зеркальная плитка».** В сетке 2×2 отрази одну плитку по горизонтали (`Ctrl+T` → правый клик → «Отразить по горизонтали») — лица «смотрят друг на друга».

**🔲 «Музейная рама».** Белые рамки между плитками: прямоугольное выделение по направляющим → `Редактирование → Выполнить обводку` (белым, 4 px).

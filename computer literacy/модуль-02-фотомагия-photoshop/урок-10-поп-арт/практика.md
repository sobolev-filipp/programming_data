# Самостоятельная работа — Фотомагия в Photoshop, Урок 10

> 🎯 Ты — художник поп-арт студии **«ФАБРИКА»** (так называлась мастерская Уорхола!). Три заказа — **разные**: арт-объект, афиша и переделка старой работы. Главный приём студии — **плоская заливка зон** («Цветовой диапазон» → слой-заливка), а не плавный градиент.

> ⚡ Сначала — **разминка**, потом выбери заказы. Для каждого есть **пошаговый план** и **💡 подсказки**.

---

## ⚡ Разминка — «3 зоны за 3 минуты»

Открой любое контрастное фото → `Изображение → Коррекция → Обесцветить` → ◐ **«Постеризация» = 4** → **`Ctrl+Alt+Shift+E`** (отпечаток). Готово — фото распалось на плоские зоны, можно красить.

**🏁 Готово, если:** за 3 минуты фото стало трафаретом из 3–4 серых пятен.

---

## ✅ Заказ 1 (для всех) — «Арт-объект, а не лицо»

На уроке был портрет — теперь сделай поп-арт **предмета или питомца** (у них чёткая форма — выходит «дизайнерски»). Выбери **один**: 🐶 питомец · 👟 кроссовок · 🎧 наушники · 🥤 банка колы · 🎸 гитара · 🦸 фигурка героя.

**Как делать (по шагам):**
1. Открой фото предмета на **простом** фоне.
2. `Обесцветить` → ◐ **«Постеризация» = 3–4**.
3. **`Ctrl+Alt+Shift+E`** → назови слой «Трафарет».
4. **`Выделение → Цветовой диапазон`** → пипеткой по **тёмной** зоне → «Разброс» ~45 → ОК.
5. ◐ → **«Цвет»** → яркий поп-цвет. Повтори для средней и светлой зон.
6. Собери плитку в группу `Ctrl+G`, сделай **3–4 плитки** с разными палитрами.

**💡 Подсказки:**
- Держись **одного настроения**: кислота 90-х (кислотно-розовый+лайм) · ретро 80-х (розовый+бирюза) · чёрно-жёлтое.
- Цвет зоны меняется **двойным кликом** по квадрату слоя-заливки — перебери быстро.
- Предмет без фона? Вырежи его маской (навык урока 2) — поп-арт станет чище.

**✅ Проверь себя:** цвет залит **зонами плоско** (не градиентом) · 3–4 плитки разных палитр · сохранено **PSD + PNG**.

## 🎬 Заказ 2 (комбо, творческий) — «Афиша в поп-стиле»

Сделай **настоящую афишу** — к выдуманному концерту, выставке или фильму. Это не просто сетка, а **плакат с композицией**: герой + заголовок + фон.

**Как делать (по шагам):**
1. Сделай поп-арт одного героя/предмета (как в Заказе 1) — **одна** крупная плитка по центру (без сетки).
2. **Фон:** залей холст контрастным цветом **или** собери **свой узор** (точки/звёзды) — см. [доп-проект «свой узор»](поп-арт-реклама/поп-арт-реклама.md).
3. **Заголовок:** инструмент **«Текст»** (`T`), крупное жирное слово (название). Дай ему **обводку** и **тень** стилем слоя (навык урока 9).
4. Добавь мелкий текст снизу: дата, место (для правдоподобия).
5. **Точки:** на герое или фоне — `Фильтр → Оформление → Цветные полутона` (радиус 8).

**💡 Подсказки:**
- Композиция «плаката»: герой — крупно, заголовок — сверху или снизу, **не** по центру лица.
- Два-три цвета на весь плакат — и держись их. Больше = пестро.
- Хочешь «комикс»? Добавь **белую рамку** по краю (`Ctrl+A` → `Редактирование → Выполнить обводку`, 12 px).

**🏁 Готово, если:** получился **плакат**, который не стыдно повесить — с именем, героем и фоном в одном стиле.

## 🎯 А попробуй! (мини-миссии с подсказками)

**🖤 «Трафарет в 2 краски».** ◐ **«Порог»** (вместо Постеризации) → отпечаток `Ctrl+Alt+Shift+E` → режим **«Умножение»** → под ним слой-заливка яркого цвета. *Подсказка: уровень «Порога» ~130, чтобы черты не слиплись.*

**⚫ «Комикс-точки везде».** Сведи плитку `Ctrl+E` → `Фильтр → Оформление → Цветные полутона` (радиус 6). *Подсказка: делай на 1–2 плитках, чтобы точки были «фишкой».*

**🌈 «Палитра-марафон».** Одно фото → три разные палитры заливок подряд. *Подсказка: меняй только цвета заливок, зоны не трогай — быстро видно, как цвет меняет настроение.*

**🪞 «Зеркальная плитка».** В сетке 2×2 отрази одну плитку: `Ctrl+T` → правый клик → «Отразить по горизонтали». *Лица «смотрят» друг на друга.*

**🔳 «Сетка 3×3».** Девять плиток вместо четырёх (навык Части 6). *Подсказка: выравнивай через «Перемещение» → панель «Выравнивание».*

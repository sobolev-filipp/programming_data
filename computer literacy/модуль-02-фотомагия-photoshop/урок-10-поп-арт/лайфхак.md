# Лайфхаки урока 9 — поп-арт быстро

> Три приёма, чтобы легко перебирать цвета и держать плитки ровно.

---

## 🎯 Трюк A — мгновенный перебор палитр

«Карта градиента» красит по яркости — значит, **вся палитра меняется одним кликом**:
- Двойной клик по слою **«Карта градиента»** → «Свойства» → клик по градиенту → перетаскивай **точки цвета** и смотри результат вживую.
- В «Редакторе градиента» сверху есть **готовые наборы** — выбирай яркие, экономь время.

> 💡 Для 4 плиток удобно взять **один** контрастный градиент и в каждой копии просто **сдвинуть оттенки** (например, повернуть цвета) — получится серия, а не хаос.

---

## 🎯 Трюк B — ровная сетка по направляющим

1. Нажми `Ctrl+R` — появятся **линейки** сверху и слева.
2. **Тяни от линейки** тонкие голубые **направляющие** на середину по горизонтали и вертикали.
3. Плитки будут **прилипать** к линиям — сетка идеальная.

> Или сразу: `Просмотр → Новая направляющая по макету` → 2 столбца, 2 строки.

---

## 🎯 Трюк C — «Порог» для жёсткого трафарета

Хочешь плакат «в 2 краски» (как трафарет)?
- ◐ → **«Порог»** вместо «Постеризации» → двигай ползунок, пока лицо не станет чётким чёрно-белым силуэтом.
- Дальше та же «Карта градиента» из **двух** контрастных цветов = хлёсткий постер.

---

## Итог

| Задача | Решение |
|--------|---------|
| Быстро сменить палитру | двойной клик по «Карте градиента» |
| Серия, а не хаос | один градиент, сдвиг оттенков в копиях |
| Ровные плитки | линейки `Ctrl+R` + направляющие |
| Жёсткий трафарет | «Порог» вместо «Постеризации» |
| Точки поп-арта | Фильтр → Оформление → Цветные полутона |

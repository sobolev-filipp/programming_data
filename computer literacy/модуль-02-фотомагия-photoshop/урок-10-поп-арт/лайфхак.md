# Лайфхаки урока 10 — поп-арт быстро и ровно

> Четыре приёма: собирать отпечаток, менять цвета зон в один клик, держать плитки ровно и делать жёсткий трафарет.

---

## 🎯 Трюк A — отпечаток всех слоёв (`Ctrl+Alt+Shift+E`)

Перед «Цветовым диапазоном» нужен **плоский пиксельный слой**. Вместо «свести всё» (и потерять живые коррекции) сделай **отпечаток**:
- встань на **верхний** слой → **`Ctrl+Alt+Shift+E`** → появится новый слой с «фотографией» всего видимого.
- Исходники целы — можно вернуться и переделать Постеризацию.

> 💡 Это «сфотографировать текущую картинку на отдельный слой». Пригодится в любом уроке, где фильтр/выделение требует пиксельного слоя.

---

## 🎯 Трюк B — мгновенная смена палитры зон

Цвет каждой зоны живёт в **слое-заливке** — меняется одним кликом:
- **двойной клик по цветному квадрату** слоя-заливки → выбери другой цвет → вся зона мгновенно перекрасилась;
- для 4 плиток удобно держать **одну логику** (тени / кожа / фон) и в каждой копии просто сдвигать 3 цвета — получится **серия**, а не хаос.

> 🔁 Нужен плавный вариант? Вспомни «Карту градиента» с урока 5 — тоже меняет всю палитру одним движением.

---

## 🎯 Трюк C — ровная сетка по направляющим

1. `Просмотр → Новая направляющая по макету` → **2 столбца, 2 строки** (или `Ctrl+R` → тяни направляющие от линеек).
2. Плитки будут **прилипать** к линиям — сетка идеальная.
3. Белые рамки между плитками: выделение по направляющим → `Редактирование → Выполнить обводку` (белым, 4 px).

---

## 🎯 Трюк D — «Порог» для жёсткого трафарета

Хочешь плакат «в 2 краски» (как трафарет)?
- ◐ → **«Порог»** вместо «Постеризации» → двигай ползунок, пока лицо не станет чётким чёрно-белым силуэтом;
- поставь слою режим **«Умножение»** (белое исчезнет), под ним — слой яркой заливки = хлёсткий постер.

---

## Итог

| Задача | Решение |
|--------|---------|
| Выделить зоны без порчи фото | отпечаток `Ctrl+Alt+Shift+E` |
| Выделить сразу все пиксели одной светлоты | `Выделение → Цветовой диапазон` |
| Сменить цвет зоны | двойной клик по квадрату слоя-заливки |
| Серия, а не хаос | одна логика цветов, сдвиг в копиях |
| Ровные плитки | направляющие (`Просмотр → Новая направляющая по макету`) |
| Жёсткий трафарет | «Порог» + режим «Умножение» + заливка под ним |
| Точки поп-арта | `Фильтр → Оформление → Цветные полутона` |

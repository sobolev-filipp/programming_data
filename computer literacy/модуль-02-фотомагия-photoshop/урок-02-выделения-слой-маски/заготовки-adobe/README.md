# Заготовки к уроку 2 (файл Adobe)

Файл для **мастерской выделений** (Часть 2 урока). Это учебный файл из официального
курса *Adobe Photoshop CS6 Classroom in a Book* (глава «Работа с выделенными областями»),
свободно распространявшийся с изданием. Открывается в любой версии Photoshop.

| Файл | Что внутри | Чему учит |
|------|------------|-----------|
| `03Start.psd` | отсканированный лист: деревянное блюдо, коралл, чаша с ракушками, морской ёж, мидия, наутилус, логотип | все инструменты выделения — на каждый объект свой |
| `03End.psd` | те же ракушки, аккуратно разложенные по блюду | образец готовой композиции |

**Какой объект каким инструментом резать (подсказка учителю):**

| Объект | Инструмент | Почему |
|--------|-----------|--------|
| морской ёж / песочный доллар | Быстрое выделение (`W`) | чёткий контур на белом |
| чаша с ракушками | Овальная область (`M`) | ровный овал |
| коралл на белом | Прямоугольная область + Волшебная палочка (вычесть белое) | однотонный фон |
| мидия | Лассо / Прямолинейное лассо (`L`) | произвольный контур |
| наутилус на узорчатой ткани | Магнитное лассо (`L`-группа) | контрастный край |
| логотип | Овальная область из центра (`Alt`) + дубли + поворот | ровный круг + копии |

> 💡 **Правило работы:** открой `03Start.psd`, **сразу сохрани копию** под своим именем
> (**Файл → Сохранить как**, `Ctrl+Shift+S`), чтобы не испортить оригинал. Сравнивай с `03End.psd`.
> В этой композиции нет «правильного» расположения — каждый собирает своё.

## Как открыть
**Файл → Открыть** → `03Start.psd`. Если появится окно о цветовом профиле — нажми **ОК**.

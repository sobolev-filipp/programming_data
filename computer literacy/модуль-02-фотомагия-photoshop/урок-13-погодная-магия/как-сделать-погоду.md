# ⭐ Шпаргалка: как сделать погоду

**Держи рядом, пока работаешь.** Ставь галочку ☑ за каждый готовый шаг.
Здесь коротко, но с пояснениями «что происходит». Полный разбор — в [theory.md](theory.md).

> 🧠 **Весь фокус в трёх шагах:** **Шум** (капли-зёрнышки) → **Размытие в движении** (капли полетели) → режим **«Экран»** (убрать чёрный фон). На этом держатся и дождь, и снег.
> 🖤 Режим **«Экран»** делает всё чёрное невидимым — без него осадки останутся чёрным прямоугольником.
> 🧭 Дождь — косой (ветер, ~75°). Снег — почти прямой. Каждая стихия — на **своём слое**.

---

## 🌧 ДОЖДЬ

*Идея: шум → смазали в струи → убрали чёрное → проредили.*

- [ ] Новый слой → залить **чёрным** (это «тёмная комната» для капель).
- [ ] `Фильтр → Шум → Добавить шум` **~125%**, по Гауссу, **Монохромный**. *(серая «крупа» = капли)*
- [ ] `Фильтр → Размытие → Размытие в движении` — **угол 75°**, смещение 30–50 px. *(капли вытянулись в струи)*
- [ ] Режим слоя **«Экран»**. *(чёрное исчезло, остался дождь)*
- [ ] `Ctrl+L` — **чёрный** ползунок вправо (проредить). «Непрозр.» 60–80%. *(видно сквозь дождь)*
- [ ] 💧 Глубина: дубль (`Ctrl+J`) + движение больше = крупные близкие струи.

---

## ❄️ СНЕГ

*Идея: тот же дождь, но хлопья круглые и падают медленно.*

- [ ] Новый слой → **чёрным** → Шум **~110%** (Монохромный).
- [ ] `Размытие по Гауссу` **1–2 px**. *(острые точки → круглые снежинки)*
- [ ] `Ctrl+L` — **чёрный** ползунок сильно вправо. *(оставить только крупные хлопья)*
- [ ] Режим **«Экран»** → Размытие в движении **80°, всего 5–10 px**. *(снег чуть падает, не струями)*
- [ ] 2 плана (дубль крупнее) + самые большие хлопья белой кистью спереди.

---

## 🌫 ТУМАН

*Идея: Photoshop сам рисует клубы фильтром «Облака».*

- [ ] `D` — цвета чёрный/белый *(из них «Облака» и рисуются)*.
- [ ] Новый слой → `Фильтр → Рендеринг → Облака`. *(`Ctrl+F` — другой узор)*
- [ ] Режим **«Экран»** → «Непрозр.» 40–60%. *(лёгкая дымка)*
- [ ] **Маска** ▢ → чёрной кистью убрать туман с лиц и переднего плана.
- [ ] Оставить **гуще внизу и вдали** — так туман лежит в жизни.

---

## ⚡ МОЛНИЯ

*Идея: нарисовать «клубок жилок» и погасить всё, кроме одной.*

- [ ] Новый слой → **чёрным** → **Градиент** (чёрн→бел) короткой диагональю.
- [ ] `Фильтр → Рендеринг → Разностные облака`. *(`Ctrl+F` — ветвистее)*
- [ ] `Ctrl+I` → `Ctrl+L` чёрный ползунок вправо. *(остаётся тонкая белая ветка)* → наоборот? `Ctrl+I` ещё раз.
- [ ] Режим **«Экран»** → подкрасить голубым (Цветовой тон → «Тонирование»).
- [ ] Под молнией — бело-голубая **вспышка** кистью («Экран»), подсветить небо.

---

## 🎨 НАСТРОЕНИЕ (под любую погоду)

*Идея: холод и сумрак делают кадр киношным. Всё корректирующими слоями ◐ — не портим фото.*

- [ ] **◐ Цветовой баланс** → в тени синий, в света голубой. *(кадр похолодел)*
- [ ] **◐ Кривые** → чуть вниз. *(затемнить, пасмурно)*
- [ ] **Виньетка** — чёрной кистью по углам. *(взгляд в центр)*
- [ ] ☀️ Лучи: чёрный слой «Экран» → `Фильтр → Рендеринг → Блик`.

---

## 💾 СОХРАНИ

- [ ] `.PSD` — все стихии на слоях = «пульт», переключай погоду.
- [ ] `.PNG` — отдельно для каждой погоды.

> ✅ Проверь: сцену видно **сквозь** погоду · осадков в меру · тон под погоду · стихии на отдельных слоях.

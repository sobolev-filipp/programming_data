# Модуль 2 — 🪄 Фотомагия в Photoshop

**30 ак.ч. | 15 уроков × 2 ак.ч. | общий модуль для младших и старших**

> Модуль 2 курса, **одинаков для обоих возрастных треков** (различается только профильный блок, модули 6–8). Полная таблица — в [обзорном плане](../ПЛАН-КУРСА.md).
> **Принцип модуля:** каждый урок — **отдельный «ВАУ»-проект** с новыми необычными инструментами и фишками (не «базовый минимум»). Уроки **максимально подробные** (с точным расположением кнопок), с блоком **«✅ как правильно / ❌ как не надо»**. Для каждого урока — **ссылки на исходники**.

---

## Чему научимся

- Уверенно работать со **слоями, выделениями и масками** — основой всего Photoshop;
- Делать **коллажи, композиты, спецэффекты, ретушь, цветокор**;
- Использовать **стили слоя, режимы наложения, кисти, фильтры**;
- Собирать сложные **композиты вручную** (замена фона/неба, объединение света и цвета);
- Довести проект до результата и **красиво его сохранить/показать**.

> ⚠️ Всё делаем **вручную** — ИИ-функции Photoshop (генеративная заливка, «Выделить предмет», замена неба) **не используем**.

## Что нужно

- **Adobe Photoshop** (по лицензии класса), русский интерфейс.
- Интернет для скачивания бесплатных исходников (ссылки — в каждом уроке).
- Папка ученика для проектов (`.psd` файлы сохраняем!).

## Итог модуля

Каждый ученик сдаёт **постер к воображаемому фильму** (композит из нескольких изображений с эффектами) + `.psd` файл и защищает работу.

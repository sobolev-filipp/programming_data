# 🎨 Совместная практика: рисуем набор иконок погоды — по шагам

**Модуль 2 · Урок 6 · Пошаговый мастер-класс** (делаем всем классом вместе с учителем)

> 🧭 **Что это за файл.** Здесь — **полная пошаговая сборка** набора из 8 иконок погоды: ☁️ Облачно · ☀️ Солнечно · ⛅ Облачно с солнцем · 🌧 Дождь · ❄️ Снег · ⛈ Гроза · 🌙 Ночь · 🌙✨ Ночь со звёздами. Каждый шаг — с картинкой-подсказкой. Инструменты те же, что в [теории](theory.md): **векторные фигуры**, **Объединить/Вычесть**, **сетка**, **стили слоя** и новый для нас инструмент **Перо**.
>
> ⚙️ **Если твоя версия Photoshop новее** — некоторые инструменты называются чуть иначе. Везде, где так, стоит значок 🆕 и написано, **как это теперь**.

## Подготовка — холст и сетка

### Шаг 1. Новый документ + сетка
1. **`Файл → Создать`** (`Ctrl+N`): ширина **600**, высота **600** px, разрешение **72**, фон **Белый**. ОК.
2. Включи сетку: **`Просмотр → Показать → Сетку`**. И привязку: **`Просмотр → Привязать к → Линиям сетки`** *(привязка «притягивает» края фигур к клеткам — всё встаёт ровно).*
3. Настрой клетку: **`Редактирование → Установки → Направляющие, сетка и фрагменты`** (`Ctrl+K`) → **«Линия через каждые: 5 пикселов»**, **«Внутреннее деление: 1»**. ОК. *(1 клетка = 5 px — по ней удобно отмерять размеры фигур.)*

![Новый документ 600×600 и настройки сетки](шаги/1.jpg)

### Шаг 2. Заливаем фон
1. Цвет переднего плана — **`#02C0D1`** (клик по верхнему квадрату цвета → введи код → ОК).
2. Возьми **«Заливка»** (`G`) и кликни по холсту. *(🆕 «Заливка» спрятана в одной группе с «Градиентом» — нажми и подержи значок градиента. Ещё быстрее — `Alt+Backspace`: заливает цветом переднего плана.)*

![Фон залит бирюзовым #02C0D1](шаги/2.jpg)

## ☁️ Иконка 1 — «Облачно» (базовая форма)

Облако — основа **половины** иконок. Соберём его из **кругов + прямоугольника** и склеим в одну фигуру.

### Шаг 3. Четыре круга
1. Цвет переднего плана — **белый** `#FFFFFF`. Возьми **«Эллипс»** (`U`).
2. 🆕 **Как задать точный размер.** Проще всего — **один раз кликни по холсту** инструментом «Эллипс»: откроется окошко «Создать эллипс» — впиши ширину и высоту, ОК. *(Или тяни мышкой с зажатым `Shift` — выйдет ровный круг — и смотри размер в панели **«Свойства»**.)*
3. Нарисуй по очереди **4 круга** и расставь их «шапкой» облака:
   - круг **30×30 px**,
   - ещё **30×30 px** рядом,
   - **35×35 px** сверху по центру,
   - **20×20 px** маленький.

![Первый круг 30×30](шаги/3.jpg)
![Второй круг 30×30 рядом](шаги/4.jpg)
![Круг 35×35 по центру сверху](шаги/5.jpg)
![Маленький круг 20×20](шаги/6.jpg)

### Шаг 4. Низ облака + склейка
1. Возьми **«Прямоугольник»** (`U`) → нарисуй **15×35 px** и поставь так, чтобы он ровно соединил круги снизу (ровное «дно» облака).
2. В **панели слоёв** выдели **все** слои-фигуры облака (клик по верхнему, `Shift`+клик по нижнему).
3. 🆕 **Правый клик по выделенным слоям → «Объединить фигуры»** *(в старых версиях — «Объединить слои»; по-английски Merge Shapes)*. Все кусочки станут **одной фигурой-облаком**.

![Прямоугольник-дно и команда «Объединить фигуры»](шаги/7.jpg)

### Шаг 5. Имя слоя и стиль (объём)
1. Двойной клик по названию слоя → переименуй в **«Облачно»**.
2. Двойной клик по слою (по пустому месту справа от имени) → откроется окно **«Стиль слоя»**. Включи и настрой (как на скринах):
   - **Обводка:** размер 1 px, положение «Снаружи», непрозр. **30%**, цвет **`#648992`**;
   - **Внутреннее свечение:** режим «Мягкий свет», непрозр. 70%, цвет **`#FFFFFF`**, источник «На краях», размер 5 px;
   - **Наложение градиента:** непрозр. 35%, линейный, 90°, переход от **`#648992`** (прозрачного) к **`#FFFFFF`**;
   - **Тень:** цвет `#000000`, непрозр. 35%, угол 90°, смещение 1 px, размер 3 px.
3. ОК. Передвинь иконку «Облачно» в **левый верхний угол** холста.

![Облако со стилем — результат](шаги/8.jpg)
![Стиль слоя: Обводка #648992](шаги/9.jpg)
![Стиль слоя: Внутреннее свечение](шаги/10.jpg)
![Стиль слоя: Наложение градиента](шаги/11.jpg)
![Стиль слоя: Тень](шаги/12.jpg)

## 🌧 Иконка 4 — «Дождь»

### Шаг 10. Ещё одно облако
Сделай ещё **дубликат «Облачно»** (`Ctrl+J`), назови **«Пасмурно. Дождь»**, поставь на свободное место.

![Дубликат облака для дождя](шаги/24.jpg)

### Шаг 11. Мелкая сетка + заготовка капли
1. Для мелких деталей поставь клетку **1 px**: `Редактирование → Установки → Направляющие, сетка и фрагменты` → «Линия через каждые: **1**».
2. Цвет — **`#57DAFF`**. **«Эллипс»** (`U`) → крошечный круг **4×4 px** под облаком.

![Голубой кружок 4×4 под облаком](шаги/25.jpg)

### Шаг 12. Круг → капля (белая Стрелка)
1. 🆕 Возьми **белую «Стрелку»** (`A`) — это **«Выделение узла»** (Direct Selection): она двигает **отдельные точки** фигуры, а не весь слой.
2. Кликни по **верхней точке** кружка и **дважды нажми клавишу ↑** — верх вытянется, кружок станет **каплей**.
3. Переименуй слой в **«Капля дождя»**.

![Тянем верхнюю точку вверх стрелкой ↑](шаги/26.jpg)
![Получилась капля](шаги/27.jpg)

### Шаг 13. Размножь капли
Продублируй «Каплю дождя» (`Ctrl+J`) несколько раз и расставь капли **в два ряда** под облаком (сетка подскажет ровный шаг).

![Капли расставлены под облаком](шаги/28.jpg)

### Шаг 14. Стиль капли + копирование на все
1. Выбери слой «Капля дождя», двойной клик → применяй стили (как на скринах):
   - **Тиснение:** внутренний скос, плавное, глубина 100%, размер 0, угол 120° (галочка «Глобальное освещение»), подсветка «Перекрытие» `#FFFFFF` 75%;
   - **Обводка:** 1 px снаружи, **`#2172DB`**;
   - **Внутреннее свечение:** «Мягкий свет», 60%, `#FFFFFF`, размер 5 px;
   - **Наложение градиента:** «Мягкий свет», 90%, от прозрачного `#000000`;
   - **Тень:** `#000000` 50%, угол 120°, смещение 2 px, размер 4 px.
2. 🔑 **Скопируй стиль на все капли:** ПКМ по слою «Капля дождя» → **«Скопировать стиль слоя»** → выдели **все** слои-капли → ПКМ → **«Вклеить стиль слоя»**.

![Белый кружок 5×5 — центр снежинки](шаги/36.jpg)

### Шаг 17. 🆕 Лучик снежинки (важная замена инструмента!)
Раньше тут брали «Прямоугольник со скруглёнными углами». **В новых версиях Photoshop отдельного такого инструмента нет** — скругление теперь настраивается у обычного прямоугольника:
1. Возьми **«Прямоугольник»** (`U`).
2. Нарисуй узкую палочку **1×3 px**.
3. 🆕 В панели **«Свойства»** (или на верхней панели) найди поле **«Радиус угла»** и поставь **1 px** — уголки чуть скруглятся.
4. Продублируй палочку (`Ctrl+J`) и поставь рядом второй лучик.

![Первая палочка-лучик](шаги/37.jpg)
![Второй лучик (дубликат)](шаги/38.jpg)

### Шаг 18. Собираем 6 лучей поворотом
1. Выдели обе палочки → ПКМ → **«Объединить фигуры»**.
2. Продублируй получившуюся фигуру (`Ctrl+J`) → **`Ctrl+T`** → поверни на **45°** (держи `Shift` — повернёт ровно) → `Enter`.
3. Повтори дубль-поворот ещё раз — получится **снежинка-звёздочка** из лучей.

2. Применяй стили (как на скринах): **Обводка** `#4CA0E0` (35%), **Внутреннее свечение** «Перекрытие» 70% `#FFFFFF`, **Наложение градиента** от `#4CA0E0` к `#FFFFFF`, **Тень** `#000000` 35%.

### Шаг 23. ⚡ Молния — рисуем Пером (`P`)

1. Цвет — **`#FFDF45`**. Возьми **«Перо»** (`P`), режим вверху — **«Фигура»**.
2. Ставь точки-клики **строго по порядку** зигзагом (сетка помогает попадать в углы). Дойдя до конца — **кликни снова по первой точке**, чтобы **замкнуть** контур.

## 🌙 Иконка 7 — «Ночь» (луна = Вычесть фигуру)

### Шаг 25. Два круга
Цвет — **`#FFFFFF`**. **«Эллипс»** (`U`) → нарисуй круг **36×36 px**, затем круг **30×30 px**, сместив его вбок (он «откусит» месяц).

![Два круга для луны](шаги/57.jpg)

### Шаг 26. 🆕 Вычитаем — получаем месяц
1. Выдели оба круга → **«Объединить фигуры»** (чтобы оказались в одном слое-фигуре).
2. Возьми **чёрную «Выделение контура»** (`A`) → кликни **по меньшему кругу**.
3. 🆕 На верхней панели открой **«Операции с контуром»** (значок перекрывающихся квадратиков) → **«Вычесть переднюю фигуру»**. Маленький круг «прорежет» большой — выйдет **полумесяц** 🌙.

![Вычитание круга → полумесяц](шаги/58.jpg)

### Шаг 27. Стиль луны (копируем с облака)
ПКМ по слою **«Облачно»** → «Скопировать стиль слоя». Перейди на слой с луной → ПКМ → **«Вклеить стиль слоя»**.

![Луна со стилем облака](шаги/59.jpg)

### Шаг 28. Поставь луну
Продублируй луну (`Ctrl+J`) — одна останется иконкой «Ночь», со второй сделаем «Ночь со звёздами». Расставь по местам.

## 🌙✨ Иконка 8 — «Ночь со звёздами»

### Шаг 29. Звёзды Многоугольником
1. Возьми **«Многоугольник»** (`U`).
2. 🆕 **Как сделать звезду.** Кликни один раз по холсту — откроется окошко настроек: **число сторон 5**, включи **«Звезда»**, параметр **«Глубина лучей (Indent Sides By) 60%»**. *(В самых новых версиях диалога нет — те же настройки в панели **«Свойства»**: «Стороны» = 5, ползунок **«Соотношение сторон звезды» ≈ 40%**.)*
3. Нарисуй **3 звёздочки** разного размера (например, 11×12, 16×16 и 7×8 px) рядом с луной.
4. Скопируй стиль с луны и **вклей** на звёзды.

## 🏁 Итог — набор готов!

Получился аккуратный набор из **8 иконок погоды** в едином стиле. Сохрани:
- **`.PSD`** — `Файл → Сохранить как…` (все фигуры и стили останутся редактируемыми);
- **`.PNG`** — `Файл → Экспортировать → Быстрый экспорт в PNG`. Нужна **каждая иконка отдельно с прозрачным фоном**? Скрой слой-фон (глаз 👁) и экспортируй по одной, или `Файл → Экспортировать → Слои в файлы`.

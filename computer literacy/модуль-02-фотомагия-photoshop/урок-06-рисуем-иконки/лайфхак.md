# Лайфхаки урока 6 — рисуем фигурами ровно и быстро

> Чтобы иконки выходили аккуратными, одинаковыми и в едином стиле.

---

## 🎯 Трюк A — идеальные фигуры и перемещение на лету

- **`Shift`** при рисовании Эллипса = ровный **круг**; Прямоугольника = **квадрат**.
- **`Alt`** = фигура рисуется **из центра** (удобно совмещать).
- **`Пробел`** (не отпуская кнопку мыши во время рисования) = **двигать** фигуру, не меняя размер. Отпустил пробел — продолжаешь тянуть.

---

## 🎯 Трюк B — Объединить и Вычесть (конструктор форм)

- Несколько фигур → выдели слои → ПКМ → **«Объединить фигуры»** = одна форма (облако из кругов).
- Одна фигура «откусывает» другую: «Выделение контура» (`A`) → клик по фигуре → вверху **«Вычесть переднюю фигуру»** (луна, кольцо, дырка).
- Ещё режимы вверху: **Объединить**, **Вычесть**, **Пересечь**, **Исключить** — пробуй, что получится.

---

## 🎯 Трюк C — единый стиль одним движением

Нарисовал стиль (тень/градиент) у одной иконки:
1. ПКМ по слою → **«Скопировать стиль слоя»**.
2. Выдели остальные иконки → ПКМ → **«Вклеить стиль слоя»**.

> Весь набор мгновенно становится в одном стиле.

---

## 🎯 Трюк D — ровное выравнивание

Выдели несколько слоёв-иконок → инструмент **«Перемещение»** (`V`) → вверху кнопки **выравнивания** (по центру, по краю) и **распределения** (равные промежутки). Иконки встанут идеально ровным рядом.

---

## Итог

| Задача | Решение |
|--------|---------|
| Идеальный круг/квадрат | рисовать с `Shift` |
| Сдвинуть фигуру при рисовании | зажать `Пробел` |
| Собрать сложную форму | Объединить фигуры |
| Вырезать (луна, дырка) | Вычесть переднюю фигуру |
| Единый стиль набора | Скопировать → Вклеить стиль слоя |
| Ровный ряд иконок | выравнивание/распределение (`V`) |

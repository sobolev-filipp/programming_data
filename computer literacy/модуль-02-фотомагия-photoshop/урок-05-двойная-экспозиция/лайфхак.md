# Лайфхаки урока 5 — Карта градиента, обтравка и фото в тексте

> Как быстро тонировать «по-киношному», обтравлять одной клавишей и заполнять фото что угодно.

---

## 🎯 Трюк A — обтравочная маска одной клавишей

Вместо `Alt`+клика по границе:
- выдели верхний слой → **`Ctrl+Alt+G`** — он сразу обтравится к нижнему. Ещё раз `Ctrl+Alt+G` — снять обтравку.

> Так удобно «заливать» фото в силуэт, в текст, в фигуру — верхний слой показывается только по форме нижнего.

---

## 🎯 Трюк B — Карта градиента: пресеты и настроение

1. **◐ → Карта градиента** → кликни по градиентной полосе → шестерёнка/папки → подключи наборы **«Фотографическое тонирование»** — десятки готовых кино-тонов в один клик.
2. Цвета «наоборот»? — галочка **«Инверсия»**.
3. Хочешь сохранить детали, а не плоскую заливку? — поставь слою Карты градиента режим **«Цветность»** (Color).
4. Сила тона — **«Непрозр.»** слоя.

> 💡 Ч/б с характером: градиент **чёрный → белый** = стильное ч/б; сдвинь белый в тёплый беж — «плёнка».

---

## 🎯 Трюк C — фото в тексте/фигуре

Любую форму можно «залить» фотографией:
1. Сделай форму снизу — **текст** (`T`, толстый шрифт) или **фигуру** (сердце, звезда, круг).
2. Положи фото **НАД** ней → **`Ctrl+Alt+G`** (обтравка).
3. Двигай фото (`V`), чтобы в форме оказалась красивая часть.

> Тонкий шрифт плохо «держит» картинку — бери **жирный**.

---

## 🎯 Трюк D — быстрый перебор режимов (повтор урока 3)

Возьми **«Перемещение»** (`V`) и жми **`Shift + +`** / **`Shift + −`** — режим наложения активного слоя листается вперёд/назад. За 5 секунд найдёшь лучший для текстуры.

---

## Итог

| Задача | Решение |
|--------|---------|
| Обтравить слой | `Ctrl+Alt+G` |
| Кино-тон | Карта градиента + пресеты + «Инверсия» |
| Сохранить детали при тоне | режим слоя «Цветность» |
| Фото в тексте/фигуре | форма снизу + фото сверху + `Ctrl+Alt+G` |
| Перебрать режимы | `V`, затем `Shift + +` / `−` |
| Смягчить эффект | убавить «Непрозр.» слоя |

# Самостоятельная работа — Фотомагия в Photoshop, Урок 11

> 🎯 Ты — дизайнер **киберпанк-лейбла «GLITCH/ON»**. Заказы — обложки, постеры, аватары со стильным «глюком». Глитч — это **управляемый хаос**: немного поломки, а не каша.

> ⚡ Сначала **разминка** (главный приём за минуту), потом заказы — у каждого **шаги** и **💡 подсказки**.

---

## ⚡ Разминка — «RGB за минуту»

Открой любое фото → **`Ctrl+J`** → двойной клик по копии → **«Параметры наложения»** → сними галочку канала **«К»** → «Перемещение» (`V`) → стрелка `←` 8–12 раз.

**🏁 Готово, если:** по краям поползло красно-голубое двоение. Главный приём в руках!

---

## ✅ Заказ 1 (для всех) — «Глитч НЕ на себя»

На уроке был свой аватар — теперь **другой** объект. Выбери **один**:
- 🎧 **обложка трека** (объект/абстракция + название);
- 🎮 **постер игры** в стиле киберпанк;
- 🚗 **техника** (машина, робот, дрон) с «глюком»;
- 🔤 **логотип-слово** одним глитчем.

**Как делать (по шагам):**
1. Открой контрастное фото на тёмном фоне (напр. `изображения/исходники/киберпанк-портрет.jpg` или своё).
2. **RGB-сдвиг:** `Ctrl+J` → «Параметры наложения» → выкл. канал «К» → сдвинь стрелками (5–15 px).
3. **Полосы:** `Ctrl+Alt+Shift+E` (отпечаток) → `M` выдели тонкую полосу → `Ctrl+J` → сдвинь вбок. Повтори **2–4** раза.
4. **Помехи:** `Фильтр → Шум → Добавить шум` (4–8%, монохромный).
5. **Неон-тон:** ◐ «Карта градиента» → тёмно-синий → маджента → бирюза.

**💡 Подсказки:**
- Полосы делай **разной** толщины и сдвига — иначе выйдут «жалюзи».
- Сильный сдвиг «съедает» картинку: 5–15 px — в самый раз.
- Глитч ярче в **акцентах** (лицо, край), а не ровным слоем по всему кадру.

**✅ Проверь себя:** RGB-сдвиг + **разные** полосы + помехи + неон-цвет; сохранено **PSD + PNG**.

## 🔗 Заказ 2 (комбо, уроки 2 + 9) — «Киберпанк-обложка»

Собери **цельный постер**: глитч + вырезанный герой + светящийся заголовок.
1. **Герой:** вырежи объект **слой-маской** *(навык урока 2)* и положи на тёмный/неоновый фон (напр. `изображения/исходники/фон-ночь.jpg`).
2. Примени к герою **глитч** (Заказ 1).
3. **Заголовок** — название трека/игры «Текстом» (`T`) со **стилями слоя** *(неон, урок 9)*: Внешнее свечение + Обводка.
4. Дай **и заголовку** лёгкий RGB-сдвиг (дубль текста → выкл. канал «К» → сдвинь на 3–5 px).

**💡 Подсказки:**
- Один-два неоновых цвета на весь постер — бирюза + маджента классика.
- Мелкий моноширинный текст по краю (трек-лист, дата) добавляет «техно».

**🏁 Готово, если:** вышла **обложка**, которую не стыдно поставить на трек: герой, глитч и светящийся глитч-заголовок.

## 🎯 А попробуй! (мини-миссии с подсказками)

**🔵🔴 «Тройной разъезд».** Вторая копия с одним каналом **«С» (Синий)**, сдвинь в **другую** сторону — двоение станет красно-синим, глубоким.

**🟦 «Битые блоки».** `M` → маленький прямоугольник → новый слой → залей неоном → режим **«Разница»**. Пара блоков по краям = «артефакты».

**📺 «Сканлайны».** Узор 1×4 px (2 строки чёрным) → `Определить узор` → заливка узором, непрозрачность 25%. Экран из полосок.

**⏺ «VHS».** Моноширинным шрифтом в углу: `REC ●`, `PLAY ►`, дата — как на кассете.

**▓ «Завис сканер».** Выдели строку 2–3 px → `Ctrl+T` → потяни вниз — ряд размажется вертикально.

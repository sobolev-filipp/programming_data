# ⭐ Шпаргалка-чеклист: распад на частицы

**Короткий список шагов — держи рядом, когда делаешь СВОЙ распад в [практике](практика.md).**
Подробные объяснения — в [theory.md](theory.md). Здесь только галочки ☑.

> 🖤 чёрное **прячет** · 🤍 белое **показывает** · 🧭 все частицы — в **одну** сторону (по позе: бег → вперёд, прыжок → вверх).

---

## 🅰️ Своя кисть (один раз)

- [ ] `Файл → Создать` → **500×500 px**, фон белый.
- [ ] Кисть (`B`), **ЧЁРНЫЙ** → натыкай точек/крошек (или квадратик).
- [ ] `Редактирование → Определить кисть` → имя «Мои частицы».
- [ ] **`F5`:** Динамика формы (Размер 100%) · Рассеивание **250%**, Количество **5**, Вариация **75%** · Интервал ~20%.

> ✅ Один мазок = облако разных частиц. Кучкой? Подними **Рассеивание** и **Количество**.

---

## 1️⃣ Два слоя

- [ ] Вырежи героя (`W` или «Выделить предмет») → `Ctrl+J` → слой **«герой»**.
- [ ] `Ctrl+J` ещё раз → слой **«частицы»**, перетащи его **ПОД** «героя».
- [ ] На «частицах» `Ctrl+T` → **увеличь** и сдвинь **в сторону разлёта**. Enter.

---

## 2️⃣ Ломаем героя (ЧЁРНЫМ)

- [ ] Маска слоя **«герой»** → кисть **ЧЁРНАЯ** (`D`).
- [ ] Прокрась **край** → герой рассыпается. У края сильнее, у тела чуть-чуть.
- [ ] Размер кисти: `[` меньше, `]` больше.

> ⚠️ НЕ ломай всего героя! Бóльшая часть — целая.

---

## 3️⃣ Проявляем частицы (БЕЛЫМ)

- [ ] Слой **«частицы»** → добавь **маску** ▢.
- [ ] Стоя на маске → **`Ctrl+I`** (станет **чёрной**).
- [ ] Кисть **БЕЛАЯ** (`X`) → рисуй **в пустоте сбоку** → летят частицы.

> ⚠️ Белым не проявляется? Проверь: маска «частиц» **чёрная**? Стоишь **на маске**?

---

## 4️⃣ Движение и искры

- [ ] Копию «частиц» → `Фильтр → Размытие → Размытие в движении` → **угол = направление**, смещение ~300–700 px.
- [ ] Новый слой → кисть с **`Alt`** (пипетка) возьми цвет с героя → **цветные частицы**.
- [ ] Лишнее — **Ластиком** (`E`).

---

## 5️⃣ Сохрани

- [ ] `.PSD` (слои целы) + `.PNG`.

---

## ✅ Проверь себя

- [ ] Целая часть **есть**, распад — **у края**.
- [ ] Частицы **разного размера**, в **одну** сторону.
- [ ] Видно **движение**.
- [ ] Сохранил **PSD + PNG**.

🎉 Готово — ты щёлкнул пальцами! 💥

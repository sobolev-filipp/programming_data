# 🧰 Лайфхаки урока 12 — распад без мучений

> Четыре приёма, чтобы частицы летели красиво и естественно.

---

## 🎯 Трюк A — своя кисть за минуту

Не ищи кисти в интернете — **сделай свою**:
1. `Файл → Создать` → 300×300 px, белый фон.
2. Чёрным натыкай пятнышек (или квадратик) → `Редактирование → Определить кисть` → имя.
3. Готово — кисть навсегда в списке. Можно сделать несколько: «пыль», «осколки», «пиксели».

> 💡 Форма пятен = форма частиц. Хочешь квадратные пиксели — рисуй квадратик; хочешь пыль — мелкие точки.

---

## 🎯 Трюк B — «Рассеивание» делает половину работы

Вместо того чтобы «тыкать» каждую частицу:
1. `Окно → Настройки кисти` (`F5`).
2. **«Рассеивание»** — **250%**, Количество **5**, Вариация **75%**: за один мазок кисть раскидает частицы вокруг.
3. **«Динамика формы»** — Размер-колебание **100%**: частицы **разного размера** сами.
4. **«Интервал»** ~20% — плотность частиц вдоль мазка.

> 💡 Один мазок = облако разнокалиберных частиц. Кучкой слиплись? Подними **Рассеивание** и **Количество**.

---

## 🎯 Трюк C — направление = «ветер»

- Реши, **куда** летят частицы (по позе: бег → вперёд, прыжок → вверх), и держись везде.
- У тела — **крупные** и **плотные**; дальше — **мельче** и **реже**.
- Усиль **Размытием в движении** (`Фильтр → Размытие → Размытие в движении`) под тем же углом.

---

## 🎯 Трюк D — две маски, один секрет

- **Ломаешь** героя → кисть **ЧЁРНАЯ**, красишь по маске слоя «герой».
- **Проявляешь** частицы → кисть **БЕЛАЯ**, красишь по маске слоя «частицы» (её сначала `Ctrl+I` в чёрное).
- Промахнулся? Нажми `X` (сменить чёрный/белый) и **верни/убери** — маска всё прощает.

---

## Итог

| Задача | Решение |
|--------|---------|
| Своя кисть-частицы | `Редактирование → Определить кисть` |
| Разный размер частиц сам | «Динамика формы» (F5) |
| Облако за один мазок | «Рассеивание» 250% + Количество 5 (F5) |
| Естественный полёт | одно направление + Размытие в движении |
| Сломать героя | чёрная кисть по маске «герой» |
| Проявить частицы | белая кисть по маске «частицы» (Ctrl+I) |

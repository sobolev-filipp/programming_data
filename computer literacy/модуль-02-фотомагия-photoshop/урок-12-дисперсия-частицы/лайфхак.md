# Лайфхаки урока 11 — распад без мучений

> Три приёма, чтобы частицы летели красиво и естественно.

---

## 🎯 Трюк A — «Рассеивание» делает половину работы

Вместо того чтобы «тыкать» каждую частицу:
1. `Окно → Настройки кисти` (`F5`).
2. Включи **«Рассеивание»** (Scattering) — за один мазок кисть раскидает частицы вокруг.
3. Включи **«Динамика формы»** (Shape Dynamics) — частицы будут **разного размера** сами.

> 💡 Теперь один мазок = облако разнокалиберных частиц. Естественно и быстро.

---

## 🎯 Трюк B — направление = «ветер»

- Реши, **куда** летят частицы, и держись этого **везде**.
- У тела — **крупные** и **плотные**; чем дальше — **мельче** и **реже**.
- Помогает **Размытие в движении** (`Фильтр → Размытие → Размытие в движении`) под тем же углом.

---

## 🎯 Трюк C — две маски, один секрет

- **Прячешь** героя → кисть **ЧЁРНАЯ**, красишь по маске слоя «герой».
- **Проявляешь** пыль → кисть **БЕЛАЯ**, красишь по маске слоя «частицы» (её сначала `Ctrl+I` в чёрное).
- Промахнулся? Нажми `X` (сменить чёрный/белый) и **верни/убери** — маска всё прощает.

---

## Итог

| Задача | Решение |
|--------|---------|
| Разный размер частиц сам | «Динамика формы» (F5) |
| Облако за один мазок | «Рассеивание» (F5) |
| Естественный полёт | одно направление + Размытие в движении |
| Спрятать героя | чёрная кисть по маске «герой» |
| Проявить пыль | белая кисть по маске «частицы» (Ctrl+I) |

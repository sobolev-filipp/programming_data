# Лайфхаки урока 4 — гнуть без потери качества и ровно

> Три приёма, чтобы деформация выглядела аккуратно, а деталь можно было гнуть хоть сто раз.

---

## 🎯 Трюк A — смарт-объект: гни сколько хочешь (главное)

Обычная **Деформация меняет пиксели насовсем** — согнул, применил, качество чуть теряется, а переделать трудно. Решение — **смарт-объект**:

1. В панели слоёв **правой кнопкой по слою с деталью** → **«Преобразовать в смарт-объект»**. На миниатюре слоя появится значок листа.
2. Теперь гни его (`Ctrl+T` → Деформация) сколько угодно — **качество не портится**, а деформацию можно в любой момент **переделать заново**.

> 💡 Правило: собираешься много гнуть/масштабировать — **сначала смарт-объект**, потом деформация.

---

## 🎯 Трюк B — Марионеточная деформация: держи и гни

- Булавка, которую **не трогаешь**, **держит** место — ставь её у основания детали (где крепится), чтобы она не «уползала».
- Булавка, которую **тянешь**, гнёт участок к себе.
- **Повернуть** вокруг булавки: наведи на неё, зажми `Alt` — появится круг вращения.
- Лишнюю булавку удалить: клик по ней + `Delete`.

> Чем больше булавок вдоль детали — тем «суставнее» и точнее изгиб.

---

## 🎯 Трюк C — Штамп «Все слои» для чистого стыка

Чтобы затирать шов **на отдельном слое** (не портя картинку):
1. Создай новый пустой слой над всеми.
2. Возьми «Штамп» (`S`). Вверху в панели параметров у поля **«Образец»** выбери **«Все слои»**.
3. Теперь `Alt`-образец берётся со всей картинки, а красишь по чистому слою — стык можно в любой момент стереть и переделать.

---

## 🎯 Трюк D — пресеты Warp и Быстрая маска

- **Готовые изгибы Warp:** `Ctrl+T` → правый клик → «Деформация» → вверху список **«Деформация»** с формами **Дуга, Флаг, Волна, Рыба** — согни деталь в один клик, потом подправь узлами.
- **Быстрая маска (`Q`)** — выделяй кистью, а не обводи: нажми `Q`, закрась область чёрной кистью (краснеет), `Q` → выделение готово. Белая кисть в этом режиме **стирает** выделение. Удобно для мелких форм (оправа, усы, коготки).

---

## Итог

| Задача | Решение |
|--------|---------|
| Гнуть без потери качества | сначала **смарт-объект**, потом деформация |
| Быстрый изгиб формой | пресеты Warp (Дуга/Флаг/Волна) |
| Закрепить основание детали | булавка Puppet Warp, которую не трогаешь |
| Повернуть у булавки | навести + `Alt` |
| Живая поза | Puppet Warp: булавки + чуть двинь |
| Выделить кистью | **Быстрая маска** (`Q`) |
| Чистый стык | Штамп на новом слое, «Образец: Все слои» |

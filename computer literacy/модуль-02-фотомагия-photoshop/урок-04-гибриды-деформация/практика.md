# Самостоятельная работа — Фотомагия в Photoshop, Урок 4

> 🧬 Сегодня ты — **генетик-фотограф**: создаёшь несуществующих зверей и «фотографируешь» их как настоящих. Не повторяем «собако-слона» — придумывай своё!

> 🆕 **Как открыть файлы.** `Файл → Открыть` (`Ctrl+O`) — основа-животное; деталь добавляй `Файл → Поместить встроенные…`. Сразу сохраняйся: `Файл → Сохранить как…` → **PSD**. Где брать фото — в конце урока («Материалы»).

---

## 🥇 Миссия 1 — «Невиданный зверь» (для всех)

Собери **своё** существо из частей 2–3 животных. Придумай ему **имя**, **среду обитания** и **характер** (добрый? хитрый?).

Идеи пар (или придумай круче): 🦒 кото-жираф · 🦌 зайце-олень · 🦋 рыбо-бабочка · 🦚 кото-павлин · 🐊 утко-крокодил.

**Обязательно:**
- [ ] деталь вырезана **маской** (пушистый край — через **«Выделение и маска»**);
- [ ] деталь **согнута** (Warp с пресетом Дуга/Флаг **и/или** Марионеточная деформация);
- [ ] зверю задана **живая поза** (Puppet Warp — машет/тянется/смотрит);
- [ ] стык **сшит** (мягкая маска + Штамп `S`), цвет/свет сведены;
- [ ] есть **тень из силуэта** — зверь «стоит», а не парит;
- [ ] сохранено **PSD + PNG**, придумано имя.

---

## 🥈 Миссия 2 — «Зверь в своём мире» (комбо, уроки 1–4)

Теперь «поселим» зверя в среду — соберём кадр из **всех** пройденных приёмов:

1. **Вырежи** готового зверя маской и **помести на фон-место** (саванна, лес, космос) — как «Телепорт» из **урока 2**.
2. **Согласуй свет и цвет** зверя с фоном — режимами наложения (**урок 3**) или Camera Raw (`Shift+Ctrl+A`, **урок 2**) на смарт-объекте.
3. Добавь **тень на землю** и, если хочешь, **атмосферу** (туман/лучи отдельным слоем в режиме «Экран»).
4. Подпиши кадр, будто это фото из «Зоопарка будущего».

**Результат:** твой зверь живёт в настоящем месте — кадр, в котором собраны слои, маски, режимы наложения, смарт-объект **и** деформация.

> 💡 Свет фона слева? Значит и тень зверя должна падать вправо. Смотри, откуда светит — это главный секрет правдоподобия.

## 🥉 Миссия 3 — Разминка-челлендж (5 минут)

Выбери **одно**:
- **Оживи вещь.** Возьми фото игрушки/предмета → `Редактирование → Марионеточная деформация` → 3–4 булавки → сделай «живую» позу (машущую руку, изгиб).
- **Поймай волосы.** Возьми портрет → грубо выдели → «Выделение и маска» → «Уточнить края» по волосам. Успей за 5 минут.

## 🎯 А попробуй! (мини-миссии с инструкцией)

Бонусы для смелых — каждый со своей мини-инструкцией:

**🎬 «Кадры движения» (мостик к GIF, урок 14).**
1. Задай зверю позу Puppet Warp, сохрани `поза-1.png`.
2. Слегка измени позу (хобот выше), сохрани `поза-2.png`.
3. Быстро переключай их — зверь «шевелится».

**🐉 «Дракон из ящерицы».**
1. Найди фото ящерицы + крыло (летучей мыши/птицы).
2. Вырежи крыло маской, поставь на спину, **Warp → пресет «Дуга»** — крыло изогнулось.
3. Продублируй крыло (`Ctrl+J`), `Редактирование → Трансформирование → Отразить по горизонтали` — второе крыло.

**✨ «Неоновый зверь».**
1. `Q` → закрась деталь → `Q` → (если надо `Shift+Ctrl+I`).
2. `Ctrl+U` → подними **Насыщенность** и крути **Цветовой тон** — деталь светится неоном.

**🌑 «Кино-тень».**
1. `Ctrl`+клик по силуэту зверя → новый слой под ним → `Shift+F5` чёрным.
2. `Наклон` вбок + `Размытие по Гауссу` + непрозрачность 30% — драматичная длинная тень.

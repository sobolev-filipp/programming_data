# Самостоятельная работа — Фотомагия в Photoshop, Урок 4

> 🧑‍🎓 Задание для всех — собери **своё существо-гибрид**. Учитель помогает с деформацией и стыком.

---

## ✅ Задание 1 (для всех) — «Небывалый зверь»

Пересади одному животному яркую деталь другого и **согни** её по форме.

**Шаги:**
1. Открой «основу» (`Файл → Открыть`), помести сверху фото с деталью (`Файл → Поместить встроенные…`).
2. Вырежи деталь **«Быстрым выделением»** → внизу панели слоёв кнопка **маски** ▢.
3. Поставь на место (`Ctrl+T`), подбери размер/поворот.
4. **Согни:** `Ctrl+T` → правой кнопкой → **«Деформация»**, затем **`Редактирование → Марионеточная деформация`** (булавки).
5. Спрячь стык мягкой маской + **«Штамп»** (`S`).
6. Согласуй **цвет и свет** обтравочными коррекциями (◐ внизу панели слоёв).
7. Сохрани **PSD + PNG**.

**Идеи:** 🐘 собако-слон (хобот) · 🦒 кото-жираф (шея) · 🦌 зайце-олень (рога) · 🦋 рыбо-бабочка (крылья) · 🦚 котопавлин (хвост).

## 📋 Требования

- [ ] Деталь **вырезана маской** (не ластиком);
- [ ] Деталь **согнута** Деформацией и/или Марионеточной деформацией (не «палкой»);
- [ ] Стык **сглажен** (маска/Штамп) — шва почти не видно;
- [ ] Согласованы **цвет и свет**;
- [ ] Есть **название** существа; сохранены **PSD и PNG**.

## 💡 Подсказки

- Тяни узлы/булавки **понемногу** — резко дёрнешь, картинка «поедет».
- Штампом бери образец **рядом** со стыком (`Alt`-клик), чтобы шерсть/кожа совпали.
- Виден шов? Пройди по нему мягкой кистью по маске ещё раз, малым нажимом.

## 🧩 Для 5–7 классов (проще)

- Возьми **короткую деталь** (уши, рог), которую почти не надо гнуть.
- Достаточно: вырезать → поставить → чуть согнуть Деформацией → сгладить стык.

## 🎓 Для 9–11 классов (со звёздочкой)

- Собери существо из **2 деталей** от разных животных.
- Перед деформацией сделай деталь **смарт-объектом** (правой кнопкой по слою → «Преобразовать в смарт-объект»), чтобы гнуть без потери качества.
- Добавь **тень** от детали на теле и проверь единый свет.

---

## 🖼 Галерея «Зоопарк гибридов»

Сдай PNG — соберём зоопарк класса. Голосуем: **самый смешной** и **самый реалистичный** зверь.

## Что сдать

- `существо_*.psd` + `существо_*.png` с названием;
- *(9–11)* существо из 2 деталей или разбор, где применял Марионеточную деформацию.

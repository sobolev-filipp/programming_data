# Лайфхаки урока 14 — GIF без мучений

> Три приёма, чтобы анимация была плавной, а GIF — лёгким.

---

## 🎯 Трюк A — движение делает Tween

Не двигай объект вручную по кадрам:
1. Сделай **два** кадра: старт и финиш (объект в двух положениях).
2. Выдели **оба** (клик + `Shift`+клик).
3. **«Создать промежуточные кадры»** → 5 кадров, Параметры: **Положение**.

> 💡 Tween умеет не только «Положение», но и **«Непрозрачность»** (плавное появление/исчезание) и «Эффекты». Пробуй!

---

## 🎯 Трюк B — тайминг: движение быстро, финал держим

- Кадрам движения — **0.05–0.1 с** (быстро, плавно).
- **Последнему** кадру (пуанту) — **1–2 с**, чтобы зритель успел прочитать/разглядеть.
- Меняй время сразу нескольким кадрам: выдели их (`Shift`) и задай длительность одному — применится ко всем.

---

## 🎯 Трюк C — лёгкий GIF

GIF раздувается быстро. Держи его маленьким:
- **Размер** ~500–800 пикс по ширине (`Изображение → Размер изображения`).
- Меньше **кадров** и меньше **цветов** (в «Сохранить для Web» — 64–128).
- Короткая петля (1–2 секунды) — мем не должен быть длинным.

---

## Итог

| Задача | Решение |
|--------|---------|
| Плавное движение | 2 кадра + «Создать промежуточные кадры» |
| Плавное появление | Tween с параметром «Непрозрачность» |
| Задержать финал | последнему кадру 1–2 с |
| Зациклить | «Постоянно» внизу Шкалы времени |
| Лёгкий GIF | меньше размер/кадры/цвета |

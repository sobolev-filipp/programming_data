# Самостоятельная работа — Фотомагия в Photoshop, Урок 15 «GIF-анимация»

> 🎬 **Ты — аниматор мемов!** Урочные очки «Deal With It» мы сделали вместе — теперь оживляешь **свои** картинки и работы прошлых уроков.
>
> **Правила студии:**
> - урочный мем **не повторяем** — придумай **свою** анимацию;
> - движение делаем **плавным** (через промежуточные кадры), а не «прыжком»;
> - в конце — **GIF** (+ сохранить PSD со слоями и кадрами).
>
> ⭐ Сбился в шагах? Держи рядом [шпаргалку с картинками-инструкциями](как-сделать-gif.md) — весь путь кадры → цикл → GIF.

## 😎 Задание 1 (для всех) — «Свой живой мем»

**Бриф:** «Сделай гифку, которую захочется отправить другу!» Выбери **одну** идею:

| Идея | Как | Кадры |
|------|-----|-------|
| 🎩 **Что-то прилетает** | корона/шляпа/шарик опускается на героя | старт (над головой) → финиш (на голове) + **Tween** |
| 😉 **Подмигивание** | герой подмигивает | 2 кадра: глаза открыты / один закрыт |
| ✨ **Мигающая надпись** | текст появляется-исчезает | 2 кадра: текст вкл / выкл (или Tween «Непрозрачность») |
| 🌀 **Дрожание** | объект трясётся от злости/смеха | 3 кадра со сдвигом объекта |

**Как делать (пошагово):**
1. Подготовь слои (фон + объект-PNG + текст), **назови** их.
2. `Окно → Шкала времени` → **«Создать анимацию кадра»**.
3. Поставь **старт** и **финиш**, выдели оба → **«Создать промежуточные кадры»** (5 шт, Положение).
4. Настрой **тайминг** (движение 0,1 с, финал 1–2 с) и **«Постоянно»**.
5. `Файл → Экспортировать → Сохранить для Web` → **GIF**.

**✅ Гифка принята, если:**
- [ ] движение **плавное** (Tween), а не прыжок;
- [ ] финалу дана **пауза** (1–2 с);
- [ ] зациклено **«Постоянно»**;
- [ ] экспортировано в **GIF** + сохранён PSD.

> 💡 **Подсказка:** объект-PNG обязательно с **прозрачным фоном** — иначе будет лететь белый прямоугольник.

## 🔗 Задание 2 (комбо: оживи прошлую работу) — «Картина ожила»

Возьми **готовую работу** прошлого урока и **анимируй** её:

- 🎆 **Глитч-луп** (урок 10 «Глитч»): 3 кадра с разным RGB-сдвигом и полосами — картинка «глючит» по кругу.
- 🌧 **Дождь-луп** (урок 13 «Погода»): 2–3 кадра со сдвинутым слоем дождя — дождь «идёт».
- 💥 **Искры-луп** (урок 12 «Дисперсия»): кадры с чуть разными частицами — взрыв «дышит».
- 🦆 **Моргающий гибрид** (уроки 3–4): заставь своё существо подмигивать.

**Результат:** твоя старая картинка ожила и крутится в GIF — покажи «было → стало».

## ⚡ Задание 3 (блиц на скорость, 5 минут) — «GIF за минуту»

**За 5 минут** сделай простейший GIF из **2 кадров** (например, эмодзи появляется/исчезает), зацикли **«Постоянно»**, экспортируй. Тренируем весь путь: кадры → цикл → GIF.

## 🎯 А попробуй (мини-вызовы по желанию)

- **🌈 Плавное появление.** Tween с параметром **«Непрозрачность»** — пусть надпись или объект проявляется из ничего, а не включается резко.
- **🎬 Мини-история (3 сцены).** Собери гифку из трёх «актов»: объект прилетел → сделал что-то → надпись. Каждый акт — пауза подольше.
- **🎞 Шкала видео (9–11).** Переключи Шкалу времени в режим **видео** и подвигай объект **ключевыми кадрами** — как во «взрослой» анимации.
- **🪶 Самый лёгкий GIF.** Устрой челлендж: та же анимация, но минимальный вес (меньше цветов/кадров/размер). Сравни вес до и после.

## 📋 Что проверяем (критерии)

- [ ] Анимация — **своя** идея (не урочные очки);
- [ ] Движение плавное (Tween), тайминг, цикл «Постоянно»;
- [ ] Сделано **«Комбо»** (оживил прошлую работу);
- [ ] Экспортировано в **GIF** + сохранён PSD.

## 🧩 Для 5–7 классов
- Хватит **2–3 кадров** (подмигивание / мигание / прилетает объект) + экспорт GIF. Промежуточные кадры — по желанию.
- Блиц (Задание 3) — обязательно, он быстрый.

## 🎓 Для 9–11 классов
- Движение через **Tween**, плавное появление «Непрозрачностью»;
- **Шкала видео** с ключевыми кадрами;
- **Оптимизация** GIF (число цветов, размер) + комбо «глитч-луп» / «дождь-луп».

## 🖼 Галерея «GIF класса»
Сдай GIF — соберём весёлую ленту анимаций. Номинации: **😂 самый смешной**, **🌊 самый плавный**, **🪶 самый лёгкий**, **🎬 лучшая мини-история**.

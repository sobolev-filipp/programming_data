# Компьютерная грамотность и цифровое творчество — ОБЩИЙ план (обзор)

> **Объём:** 135 ак.ч. · **1 урок = 2 ак.ч. (1,5 часа).** Формат: 2 раза/нед по 1 уроку **или** 1 раз/нед по 2 урока подряд (4 ак.ч.).
> **Принцип:** минимум сухой теории — каждый урок **создаём конкретную интересную работу** по референсу, осваивая новые «фишки». Уроки **максимально подробные**, с объяснениями «почему» и примерами. Для каждой темы — **ссылки на исходники** для скачивания.

## 👥 Два трека (отдельные планы)

Курс идёт **двумя отдельными планами** под возраст:

- 🧒 **[План для младших (5–7 классы)](ПЛАН-младшие-5-7.md)** — упор на игры и творчество: Scratch, Kodu, BlockBench, стоп-моушн, Canva.
- 🧑 **[План для старших (9–11 классы)](ПЛАН-старшие-9-11.md)** — упор на глубину и реальные навыки: App Inventor, HTML/CSS, Python/бот, продвинутый монтаж.

**Творческий блок Adobe (Photoshop, Illustrator+вектор, Animate) — ОБЩИЙ и одинаковый для обоих треков** (описан ниже). Внутри уроков есть подсказки 🧩 «для младших» (проще) и 🎓 «для старших» (глубже) — по темпу, а не по программе.

## 🤖 Сквозные принципы (в обоих планах)

- 🤖 **ИИ вплетён по ходу** (значок 🤖), не отдельным модулем: идеи, черновики, генеративная заливка, помощь с кодом. Правило — ИИ помогает думать, а не думает за ученика.
- 🎮 **Каждый урок** — игры/разминки по ходу + **викторина `викторина.html`** на закрепление (со смешными вопросами и «на подумать»).
- ⌨️ **Слепая печать** — 5-минутная разминка в начале части уроков (Клавогонки).
- 📥 Adobe — **по лицензии**; в каждом уроке ссылки на исходники (фото/текстуры/кисти).

## 🧭 Формат каждого урока (папка урока)

| `повторение.md` | учитель | разминка 5 мин |

# 🖥 Как добавить презентацию к уроку — конвенция курса

Памятка (для себя и для ИИ): у любого урока может быть **офлайн-презентация для проектора**.
Ниже — где хранить, как назвать, как подключить к уроку и что проверить. Делаем везде одинаково.

> ✅ Готовый эталон: [`модуль-01-цифровой-фундамент/урок-01-устройство-и-безопасность/презентация.html`](модуль-01-цифровой-фундамент/урок-01-устройство-и-безопасность/презентация.html) — так и делаем во всех уроках.

---

## 📍 Где хранить и как назвать

- **Файл лежит в папке своего урока** — рядом с `theory.md`, `викторина.html`.
- **Имя: `презентация.html`** (одна презентация на урок; папка урока сама даёт контекст).
  - Если презентаций несколько — `презентация-<короткая-тема>.html` (напр. `презентация-блок-b.html`).
- ⚠️ **Без пробелов и скобок** в имени (иначе ломаются markdown-ссылки). `Компьютер с нуля (офлайн).html` → **переименовать** в `презентация.html`.

## 📦 Требования к файлу — должен быть САМОДОСТАТОЧНЫМ (офлайн)

В классе может не быть интернета, поэтому:

- Экспортировать из редактора (Claude Design и т.п.) как **offline / self-contained / bundled** — чтобы всё было внутри одного `.html`.
- **Нельзя** внешних `<script src="https://…">` — код должен быть **вшит** в файл (иначе без сети не запустится).
- Картинки — как `data:`-URI внутри файла; шрифты — вшитые или Google Fonts (у них есть фолбэк, переживёт офлайн).
- **Проверка:** открыть файл на компьютере **без интернета** — слайды должны работать.

> 💡 Как проверить, что нет внешних загрузок кода (из папки репозитория):
> ```bash
> grep -oiE "<script[^>]*src=[\"'][^\"']*[\"']" "презентация.html"   # должно быть ПУСТО
> ```

## 🔧 Шаги: перенести и подключить (4 шага)

**1. Перенести файл в папку урока и переименовать** (пример для урока 1 модуля 1):
```bash
cd "D:/Работа/GitHub/programming_data"
mv "Компьютер с нуля (офлайн).html" \
   "computer literacy/модуль-01-цифровой-фундамент/урок-01-устройство-и-безопасность/презентация.html"
```

**2. Проверить файл** (я его не создавал → смотрю перед включением): `<title>`, нет внешних `<script src>`, тема совпадает с уроком.

**3. Добавить ссылку в шапку `theory.md`** — в блок навигации сверху вставить строку:
```markdown
> 🖥 **Презентация урока для проектора** (офлайн, интернет не нужен) — [презентация.html](презентация.html): открой двойным кликом в браузере и веди урок по слайдам.
```

**4. Добавить пометку в `изображения.md`** (файл «что показать на проекторе») — сверху:
```markdown
> 🖥 **Готовая презентация для проектора — [презентация.html](презентация.html)** (офлайн, интернет не нужен): открой двойным кликом в браузере. Ниже — дополнительные картинки, если ведёшь без презентации.
```

**5. Закоммитить:**
```bash
git add "computer literacy/.../презентация.html" "computer literacy/.../theory.md" "computer literacy/.../изображения.md"
git commit -m "<курс> у<N>: добавлена офлайн-презентация к уроку"
git push
```

---

## 🔐 Шифровать или нет (git-crypt)

- **По умолчанию `презентация.html` — ОТКРЫТЫЙ** (как `викторина.html`): это класс-материал для показа, не «ответы». В маску `.gitattributes` его добавлять **не нужно**.
- Если хочешь, чтобы презентацию видели **только учителя** (по ключу): добавить строку
  `презентация.html   filter=git-crypt diff=git-crypt` в корневой `.gitattributes`, затем **переиндексировать** файл (git rm --cached + git add), иначе он останется открытым в истории. Подробности — в [`ИНСТРУКЦИЯ-ДЛЯ-ИИ-git-crypt.md`](../ИНСТРУКЦИЯ-ДЛЯ-ИИ-git-crypt.md).
- ⚠️ Учительские файлы урока (`theory.md`, `преподавателю.md`, `изображения.md`) остаются зашифрованными как обычно — презентация на это не влияет.

## ✅ Чек-лист

- [ ] Файл в папке нужного урока, имя `презентация.html` (без пробелов/скобок).
- [ ] Открывается **без интернета**, нет внешних `<script src>`.
- [ ] Ссылка добавлена в шапку `theory.md`.
- [ ] Пометка добавлена в `изображения.md`.
- [ ] Решено про шифрование (по умолчанию — открытый).
- [ ] `git add` → `commit` → `push`.

> 📝 Отдельно: **промпт для генерации** самой презентации (маскоты, слайды, стиль) — это другой этап, он не про этот файл. Здесь только про то, **как готовую презентацию положить в урок**.

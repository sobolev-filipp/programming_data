# Компьютерная грамотность и цифровое творчество

Обновлённый курс для детей **5–11 классов**. Объём — **135 академических часов**.
Формат: 2 раза/нед по 1,5 ч (2 ак.ч.) **или** 1 раз/нед по 3 ч (4 ак.ч.).

> **Философия курса:** никакой сухой теории. На каждом уроке дети **создают конкретную интересную работу** по реальному референсу, осваивая новые «фишки». Теория — по ходу и через игры/аналогии. Уроки делятся по возрасту: базовая часть общая, старшим — углублённо.

## 📚 Навигация

- 🗺 **[ПЛАН-КУРСА.md](ПЛАН-КУРСА.md)** — полный план всех модулей и уроков (источник истины).
- 🔧 **[HANDOFF.md](HANDOFF.md)** — правила, конвенции, статус (читать первым при продолжении).
- 📁 **[справочники/](справочники/)** — где скачивать материалы, горячие клавиши и т.д.

> 🤖 **Нейросети — не отдельным модулем, а вплетены по всему курсу** (значок 🤖), особенно в работе с документами. ИИ помогает думать, а не думает за ученика.

> 🎮 **Каждый урок заканчивается викториной/мини-игрой на закрепление** (`викторина.html` — открывается в браузере, удобно на проекторе). Начало курса бодрое; «сухие» темы (документы/таблицы) — в конце.

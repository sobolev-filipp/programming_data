# Разминка — Анимация, Урок 2

> ⏱ 5 минут. Повторяем прошлый урок — сегодня объект полетит по кривой.

---

## Быстрый повтор (устно)

1. Что такое ключевой кадр? *(кадр, где что-то изменил; `F6`)*
2. Зачем мяч сжимается/растягивается? *(сжатие-растяжение = живое, упругое движение)*
3. Что нужно сделать перед анимацией движения? *(преобразовать в **символ** `F8`)*
4. Как проиграть ролик? *(Enter)*
5. Что такое тайминг? *(мало кадров = быстро, много = медленно)*

## Интрига урока

> «Мяч прыгал вверх-вниз. А как заставить объект лететь **красиво** — по дуге, по **петле**, как самолётик в небе? Секрет: всё живое движется **по кривым**, не по прямой. Сегодня запустим **ракету по петле** 🚀 — с поворотом носа по пути и разгоном. Выглядит как в настоящем мультике!»

## Мини-показ (на проекторе)

1. Покажи два полёта: по **прямой** (скучно, «робот») и по **дуге/петле** (живо). Разница очевидна.
2. Покажи галочку **«Ориентировать по траектории»**: нос ракеты сам поворачивается по пути.
3. 2–3 ролика с полётами по петле для настроя.

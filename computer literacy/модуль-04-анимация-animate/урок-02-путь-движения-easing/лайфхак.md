# Лайфхаки урока 2 — красивый полёт

> Три приёма с **точными шагами**: где кнопка, что нажать, что получится.

---

## 🎯 Трюк A — изогнуть траекторию (не тяни за точку!)

**Как согнуть путь:**
1. Сделай анимацию движения (символ → ПКМ по кадрам → «Создать анимацию движения» → передвинь символ на последнем кадре). Появится **пунктирная траектория**.
2. Возьми **«Выделение»** (`V`) → наведи **на линию** пути **между** точками (у курсора появится маленькая дуга) → **тяни** — линия выгнется.
3. Для **петли** — тяни сильнее / добавь точку **«Пером»** (`P`) на пути и вытяни её усы.
4. Двигать сами точки-узлы — **«Прямое выделение»** (`A`).

> ⚠️ Тянешь за **точку** — она просто переедет, путь не согнётся. Гни **линию** между точками.

---

## 🎯 Трюк B — «Ориентировать по траектории» (объект рулит)

1. Выдели **диапазон** анимации (синие/оранжевые кадры).
2. Панель **«Свойства»** → раздел **«Вращение»** → галочка **«Ориентировать по траектории»**.
3. Теперь нос объекта **поворачивается по направлению** движения — ракета/самолёт «рулит» по пути, а не летит боком.

> 💡 Рисуй символ **носом вправо** (по направлению «вперёд») — тогда ориентация по пути выглядит правильно.

---

## 🎯 Трюк C — плавность (разгон/торможение)

1. Выдели диапазон → «Свойства» → поле **«Замедление» (Ease)**.
2. **Минус** (напр. −50) = **разгон** (медленно стартует → быстро). **Плюс** (+50) = **торможение** (быстро → плавно останавливается).
3. Тонко — **«Редактор движения»**: двойной клик по диапазону → нарисуй кривую скорости «медленно-быстро-медленно».

> 💡 Природа почти всё начинает и заканчивает **плавно**. Разгон на старте + торможение на финише = живое движение, а не «трактор».

---

## Итог

| Задача | Точные шаги |
|--------|-------------|
| Согнуть путь | «Выделение» (`V`) → тянуть **линию** траектории |
| Петля | сильнее тянуть / точка «Пером» (`P`) + усы |
| Нос по пути | «Свойства» → Вращение → **«Ориентировать по траектории»** |
| Разгон | «Свойства» → **Замедление** = минус |
| Торможение | Замедление = плюс |
| Точная скорость | **«Редактор движения»** (двойной клик по диапазону) |

# Лайфхаки урока 3 — морфинг без «мятой» формы

> Три приёма с **точными шагами**: где кнопка, что нажать, что получится.

---

## 🎯 Трюк A — морфинг только для фигур (не символов!)

**Как правильно начать:**
1. Нарисуй форму «Овалом»/«Пером» — это должна быть **чистая заливка** (фигура).
2. Проверь: выдели её — если вокруг **синяя рамка группы** или значок символа, разбери: **`Изменить → Разделить`** (`Ctrl+B`).
3. На другом кадре (`F7`/`F6`) сделай **другую** фигуру.
4. **Правый клик** по кадрам между → **«Создать анимацию формы»** → диапазон станет **зелёным**.

> ⚠️ Диапазон **синий/оранжевый** = это анимация **движения** (для символов). Морфинг — **зелёный** (для фигур). Перепутал — не сработает.

---

## 🎯 Трюк B — фигурные подсказки (a, b, c по кругу)

Форма «мнётся» и выворачивается? Управляй перетеканием:
1. Встань на **первый** кадр пары → **`Изменить → Фигура → Добавить фигурную подсказку`** (`Ctrl+Shift+H`) → появится **красный «a»** → поставь на заметную точку (остриё/нос).
2. Перейди на **последний** кадр пары → там **зелёный «a»** → поставь на **ту же по смыслу** точку второй фигуры.
3. Добавь **b, c, d** — **по порядку и по кругу** (по часовой) на **обеих** фигурах.

> 💡 Правило: одинаковый **порядок и расположение** подсказок на обеих формах — тогда программа знает, «какая точка куда едет».

---

## 🎯 Трюк C — цвет, тайминг, цикл

- **Цвет** перетекает **сам**, если у фигур **разная заливка** — бери контрастные цвета.
- **«Задержать» форму:** после её ключевого кадра добавь пару обычных кадров (`F5`) — форма «замрёт» на миг.
- **Бесшовный цикл:** сделай **последнюю** форму = **первой** (скопируй кадр 1 в конец) — GIF крутится без «скачка».

> 💡 Похожие по числу «выступов» формы (круг↔сердце) морфятся легче, чем очень разные (круг↔буква). Начинай с похожих.

## Итог

| Задача | Точные шаги |
|--------|-------------|
| Начать морфинг | Фигура (не символ! `Ctrl+B`) → ПКМ по кадрам → **«Создать анимацию формы»** (зелёный) |
| Убрать «мятость» | **Фигурные подсказки** (`Ctrl+Shift+H`), a-b-c по кругу |
| Перетекание цвета | разные заливки у фигур |
| Задержать форму | обычные кадры (`F5`) после ключевого |
| Бесшовный цикл | последняя форма = первой |

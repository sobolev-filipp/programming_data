# Лайфхаки урока 4 — риг, звук и кнопка без боли

> Четыре приёма с **точными шагами**: где кнопка, что нажать, что получится.

---

## 🎯 Трюк A — правильная цепочка костей (IK, которая не «выворачивается»)

**Как ставить кости, чтобы рука гнулась естественно:**
1. Убедись, что детали руки — **символы** (`F8`), не «сырые» фигуры.
2. Возьми **«Кость» (Bone Tool)** на панели слева (значок 🦴) или клавишу **`M`**.
3. Веди кости **от туловища к кончику**: протяни **плечо → локоть**, потом **локоть → кисть**. Всегда «изнутри наружу».
4. Детали сами уедут на **зелёный слой «Арматура»** — это правильно.
5. Проверь: «Выделение» (`V`) → потяни **за кисть** — гнётся вся рука. Это **IK**.

> 💡 Если рука выгибается неестественно — выдели кость → **Свойства → «Вращение соединения → Ограничить»** и задай угол (напр. локоть 0–140°). Сустав перестанет «переламываться».

> ⚠️ Кость **не цепляется**? Детали не связаны/не символы, или ведёшь кость «снаружи внутрь». Веди от плеча.

---

## 🎯 Трюк B — «Поток» (Stream): чтобы рот не разъехался с голосом

**Порядок, при котором звук всегда совпадает с кадрами:**
1. **`Файл → Импорт → Импортировать в библиотеку…`** → звук ляжет в **Библиотеку**.
2. Отдельный слой **«звук»** → встань на нужный кадр → перетащи звук из Библиотеки на сцену (появится **синяя волна**).
3. **Свойства → раздел «Звук» → «Синхронизация»** → выбери **«Поток» (Stream)**.
4. **Дотяни кадры** `F5` на всех слоях до **конца синей волны** — иначе звук оборвётся.

> 💡 «Поток» = звук привязан к плейхеду (едет вместе с таймлайном) → рот успевает за голосом. «Событие» = звук живёт сам по себе (для липсинка **не** годится).

---

## 🎯 Трюк C — «ленивый» липсинк за 3 формы рта

Не нужен идеальный липсинк — нужна **иллюзия речи**:
1. Нарисуй **3 формы рта**: **закрыт** (чёрточка), **открыт круглый** (О/А), **широкий** (И/Е).
2. **Скраббинг:** тяни плейхед по синей волне — слушай, где гласные.
3. На слое «рот» ставь `F6`/`F7` и меняй форму: **гласная → рот открыт**, **М/П/Б → рот закрыт**.
4. Между слогами возвращай **закрытый** рот. Смена 2–3 раза за слово — уже «говорит».

> 💡 Секрет: главное — **открывать рот на гласных** и **закрывать на М/П/Б**. Точность по каждому звуку не нужна.

## 🎯 Трюк D — кнопка без единой строчки кода (Фрагменты кода)

**Запуск анимации по клику — почти без программирования:**
1. Слой «код», **кадр 1** → `F9` → впиши `this.stop();` (маскот замрёт и ждёт).
2. Кадр начала речи → **Свойства → «Метка кадра»** впиши `говорит` (красный флажок).
3. Кнопку в символ (`F8` → «Кнопка»), выдели её → **Свойства → «Имя экземпляра»**: `btnPrivet`.
4. **`Окно → Фрагменты кода` → HTML5 Canvas → «Щёлкните, чтобы перейти к кадру и играть»** → двойной клик → укажи метку `говорит`. Код впишется **сам**.
5. Последний кадр речи → снова `this.stop();`.
6. Проверь: **`Ctrl+Enter`** → наведи (подсветка) → клик → маскот машет и говорит.

> ⚠️ Не работает клик? Проверь: (1) `this.stop();` на кадре 1 стоит; (2) у кнопки есть **имя экземпляра** (`btnPrivet`) в Свойствах; (3) документ — **HTML5 Canvas** (код JavaScript, не ActionScript).

## Итог

| Задача | Точные шаги |
|--------|-------------|
| Риг руки (IK) | Символы → «Кость» (`M`) → кости плечо→локоть→кисть → тяни за кисть |
| Не «выворачивается» | Свойства кости → «Вращение → Ограничить», задать угол |
| Звук в такт | Импорт в Библиотеку → на слой «звук» → синхронизация **«Поток»** → `F5` до конца волны |
| Липсинк | 3 формы рта, скраббинг по волне, открыт на гласных / закрыт на М-П-Б |
| Кнопка-триггер | `this.stop();` (кадр 1) + метка `говорит` + имя `btnPrivet` + Фрагмент кода |
| Проверить с кликом | `Ctrl+Enter` (Тестировать в браузере) |

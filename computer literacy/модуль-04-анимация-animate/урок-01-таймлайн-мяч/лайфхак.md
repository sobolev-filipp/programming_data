# Лайфхаки урока 1 — анимация как оживший рисунок

> Три приёма с **точными шагами**: где кнопка, какой кадр, что получится.

---

## 🎯 Трюк A — ключевые кадры и «луковичная кожа»

**Как быстро расставлять кадры:**
1. Кликни ячейку кадра на таймлайне → **`F6`** = **ключевой кадр** (копирует содержимое, чтобы менять).
2. `F5` — **продлить** кадр (объект «держится»), `Shift+F5` — удалить.
3. Внизу шкалы включи **«Луковичная кожа»** (Onion Skin) — увидишь **призраки** соседних кадров.
4. Двигай объект «Выделением» (`V`), ориентируясь на призраки — так ведёшь его по **дуге** и ровняешь расстояния.

> 💡 Проиграть — **Enter**; листать по кадру — **`,`** и **`.`** (запятая/точка).

---

## 🎯 Трюк B — сжатие-растяжение «Свободным трансформированием»

**Как сделать (`Q`):**
1. Выдели объект → возьми **«Свободное трансформирование»** (`Q`) — вокруг появятся **ручки**.
2. **Растяжение (в полёте):** тяни **верхнюю/нижнюю** ручку — объект вытягивается по движению.
3. **Сжатие (удар):** тяни ручку внутрь по высоте и наружу по ширине — «блин».
4. Делай это **в разных ключевых кадрах** (полёт → удар → отскок).

> 💡 **Сохраняй «объём»:** сплющил по высоте — **расширь по ширине** (и наоборот). Тогда мяч кажется упругим, а не «сдувшимся».

---

## 🎯 Трюк C — анимация движения (motion tween)

**Как заставить объект ехать самому:**
1. Сначала **`F8`** — преврати объект в **символ** (без символа tween не работает!). Тип «Фрагмент ролика».
2. **Правый клик** по диапазону кадров → **«Создать анимацию движения»** — диапазон окрасится.
3. Встань на **последний** кадр диапазона → **передвинь символ** в новое место → появится **траектория** с точками.
4. **Плавность:** выдели tween → «Свойства» → **«Замедление» (Ease)**: **−** число = разгон, **+** = торможение.

> 💡 Траекторию-путь можно **изогнуть**: тяни её «Выделением» — объект поедет по дуге (подробнее в уроке 2).

## Итог

| Задача | Точные шаги |
|--------|-------------|
| Ключевой кадр | ячейка → **`F6`**; продлить — `F5` |
| Видеть соседние кадры | **«Луковичная кожа»** внизу шкалы |
| Растянуть/сплющить | **«Свободное трансформирование»** (`Q`) |
| Проиграть / по кадру | **Enter** / `,` `.` |
| Объект едет сам | **`F8`** символ → ПКМ **«Создать анимацию движения»** |
| Разгон/торможение | «Свойства» → **Замедление (Ease)** |

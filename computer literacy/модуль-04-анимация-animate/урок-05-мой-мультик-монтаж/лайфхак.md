# Лайфхаки урока 5 — собрать мультик быстро и красиво

> Четыре приёма с **точными шагами**: где кнопка, что нажать, что получится.

---

## 🎯 Трюк A — раскадровка за 5 минут (план вместо хаоса)

**Как не «зависнуть» в программе:**
1. Лист → **3 квадрата** = 3 сцены.
2. В каждом — набросок + подпись «что происходит».
3. Проставь **тайминг**: сцена ≈ **3–4 сек** (при 24 к/с это 72–96 кадров).
4. Только теперь открывай Animate — ты знаешь, что и в каком порядке делать.

> 💡 Правило истории: **начало (кто/где) → середина (что случилось) → конец (чем кончилось)**. Даже 10 сек должны иметь развязку.

---

## 🎯 Трюк B — плавный переход «в чёрное» (Альфа-шторка)

**Кино-переход между сценами:**
1. Верхний слой `шторка` → **чёрный прямоугольник** на весь кадр → **`F8`** (символ).
2. **Правый клик → «Создать анимацию движения»**.
3. Первый ключ: **Свойства → Эффект цвета → Альфа = 0%** (прозрачный).
4. Последний ключ: **Альфа = 100%** (сцена ушла в чёрное).
5. В начале следующей сцены — наоборот: **Альфа 100% → 0%** (выходим из чёрного).

> 💡 Шторка должна быть **верхним** слоем (кроме титров), иначе затемнение спрячется за героем. Проще всего — «встык» без шторки (тоже монтаж).

---

## 🎯 Трюк C — титры, которые «проявляются»

**Дорогой вид названия и «Конец»:**
1. «Текст» (`T`) → впиши название → крупно, ярко.
2. Текст → **`F8`** (символ) — иначе Альфа не сработает!
3. **Анимация движения** → Альфа **0% → 100%** за ~12–15 кадров (плавно появился).
4. Подержи ~1 сек, потом **100% → 0%** (растворился) → пошла сцена.
5. Для «КОНЕЦ» — то же самое на тёмном фоне в конце.

> ⚠️ Текст **не в символе** → Альфы нет, эффект не выйдет. Сначала `F8`, потом крути Альфу.

---

## 🎯 Трюк D — правильный экспорт (GIF vs MP4)

**Куда что сохранять:**

| Нужно | Как |
|-------|-----|
| Быстрая **немая** версия (чат, стена класса) | `Файл → Экспорт → Экспортировать анимированный GIF…` (проверь зацикливание) |
| Мультик **со звуком/музыкой** (портфолио) | `Файл → Экспорт → Экспортировать видео/медиа…` → Media Encoder → **H.264 (MP4)** |
| Интерактив (**кнопки** работают) | `Файл → Экспорт → Экспортировать ролик…` (HTML5) |
| Исходник для правок | `Ctrl+S` → **`.fla`** |

> ⚠️ **GIF не хранит звук!** Мультик с музыкой сохраняй в **MP4**. GIF — только для немой демонстрации.

## Итог

| Задача | Точные шаги |
|--------|-------------|
| План истории | Раскадровка: 3 квадрата, наброски, тайминг 3–4 сек |
| Переход между сценами | Слой `шторка` сверху → чёрный прямоугольник-символ → tween Альфа 0↔100 |

| Немая версия | Экспорт **анимированный GIF** (с зацикливанием) |

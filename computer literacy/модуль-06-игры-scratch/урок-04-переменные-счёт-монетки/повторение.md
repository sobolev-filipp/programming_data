## 🎮 Разминка-игра «Живой счётчик» (3 мин)

Без компьютера — чтобы почувствовать, что такое **переменная-счёт**.

1. Учитель — «коробочка **счёт**», показывает пальцами число (сейчас `0`).
2. Дети кидают мячик в корзину. **Каждое попадание** — учитель говорит: «изменить счёт **на 1**» и показывает на палец больше.
3. Новый раунд — «**установить** счёт **в 0**» (обнулили, показывает кулак).

**Вывод для детей:**
- **Счёт** — это число, которое **где-то хранится** и **меняется** по ходу игры.
- Есть две команды: **обнулить** (установить в 0) и **прибавить** (изменить на 1). Ровно это сегодня сделаем в Scratch!

## 🔑 Новые слова урока

| Слово | Простыми словами |
|-------|------------------|
| **Переменная** | коробочка с именем для числа (счёт, жизни, время) |
| **`установить в`** | положить в коробочку число (например, 0) |
| **`изменить на`** | прибавить к числу (или отнять, если минус) |
| **Оператор** | «калькулятор»: `+`, `×`, `выдать случайное` |
| **Таймер** | встроенный секундомер (`сбросить таймер`, `таймер`) |
| **`ждать до`** | «стой, пока не случится …» |

# 🎯 Практика к уроку 7 — «Сделай свою игру с уровнями»

**Модуль 6 · Урок 7 · Самостоятельная работа**

## 🌟 Новый вызов — «Космический лифт» 🚀🪐 (главный проект)

Сделай игру, где герой поднимается **по этажам-планетам**: собрал топливо на этаже — летит выше. Это **другой сюжет**, но тот же навык — **сообщения и смена экранов**.

**Что нужно сделать:**
1. **4 фона:** `старт`, `земля`, `луна`, `марс` (и по желанию `финиш`).
2. **Кнопка «Старт»** → `передать [лететь]`, спрятаться.
3. **Сцена-дирижёр:** `когда я получу [лететь]` → по переменной `этаж` выбирает нужный фон (`если этаж = 1 → земля` и т.д.).
4. **Ракета-герой:** появляется по `лететь`, управляется стрелками, собирает **3 канистры топлива** (клоны).
5. **Переменная `топливо`:** собрал 3 → `изменить [этаж] на 1` → `передать [лететь]` (следующая планета, топливо снова 0).
6. **Финал:** долетел до Марса (`этаж = 4`) → `передать [финиш]` → фон `финиш` + «Ты покорил космос! 🏆».

> 🎨 **Сделай своим:** свои планеты-фоны, свой звук взлёта на каждом этаже, надпись с названием планеты на старте уровня (`когда я получу [лететь] → сказать [ЛУНА] 1 сек`).

**✅ Проект готов, если:** есть стартовый экран, минимум **3 разных этажа-фона**, переход между ними **через сообщение**, сбор топлива открывает следующий этаж, и есть **финальный экран**.

## 🔗 Комбо с прошлыми уроками (соединяем навыки)

Добавь в «Космический лифт» **хотя бы одно** (лучше два):

- 🎲 **Урок 5 (клоны + случайность):** канистры топлива появляются в **случайных** местах этажа (клоны).
- 🚀 **Урок 6 (стрельба):** на «Марсе» летают астероиды-клоны — сбивай их пробелом (пули-клоны), не дай задеть ракету.
- 🔢 **Урок 4 (переменные):** веди `всего топлива` за всю игру и покажи на финале.
- ⏱ **Урок 4 (таймер):** засеки, за сколько секунд прошёл все этажи (`сбросить таймер` на старте, показать на финале).
- 🐭 **Урок 3 (условия/касание):** на одном этаже — лава (красный цвет): коснулся → `передать [лететь]` заново (упал вниз).

> 🏆 **Комбо-мастер:** уровни (у.7) + клоны-топливо (у.5) + сбивание астероидов (у.6) + таймер (у.4) = настоящая космическая аркада!

## ⚡ Разминка-челлендж (по желанию, для быстрых)

Мини-задания на **10–15 минут** каждое — по сообщениям:

1. **🎬 Заставка:** перед стартом — 3-секундная надпись «представляет…» → потом `передать [меню]` → показать кнопку.
2. **🔀 Случайный уровень:** кнопка «Играть» ставит `этаж` в `случайное от 1 до 3` — каждый раз другой первый уровень.
3. **🗣 Босс дразнит:** на последнем этаже спрайт-босс `когда я получу [лететь] → сказать [Не пройдёшь!]`.
4. **🎵 Музыка по экранам:** `когда я получу [меню]` — одна музыка, `когда я получу [лететь]` — другая (`остановить все звуки` перед сменой).
5. **⏸ Пауза:** клавиша `p` → `передать [пауза]`; все `когда я получу [пауза] → стоп [другие скрипты спрайта]`.

## 🧩 Ветка для 5–7 классов (проще)

- Хватит **2 этажей** (старт → земля → луна → финиш).
- Топливо — **не клоны**, а 3 обычных спрайта; собрал все → `передать [лететь]`.
- Учитель даёт готовые фоны с именами.
- Главное — показать, что **кнопка кричит сигнал**, а Сцена **меняет экран**.

## 🎓 Ветка для 9–11 классов (сложнее)

- **5+ этажей**, на каждом — своё препятствие.
- **Меню выбора уровня:** кнопки 1–3, каждая ставит `этаж` и `передать [лететь]`.
- **Экран проигрыша:** переменная `топливо-бак` тает; кончилось → `передать [провал]`.
- **Сохранение прогресса:** переменная `лучший этаж` помнит рекорд между играми.

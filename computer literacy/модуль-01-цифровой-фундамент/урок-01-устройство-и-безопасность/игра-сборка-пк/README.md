# 🖥 Игра «Собери свой компьютер» (Godot 4)

Учебная 3D-игра к **уроку 1 модуля 1** («Устройство компьютера»). Ребёнок вращает
корпус, читает карточку о каждой детали и по очереди устанавливает комплектующие
в правильном порядке. В конце — «включение» собранного ПК.

## Как запустить
1. Установи **Godot 4** (4.3+), бесплатно: https://godotengine.org/download
2. Godot → **Import** → выбери файл `project.godot` из этой папки → **Import & Edit**.
3. Нажми **▶ (F5)**. При первом запуске Godot импортирует модели `.glb` (пару секунд).

## Управление (для детей)
- **Тянуть мышью** — вращать корпус. **Колесо мыши** — приблизить/отдалить.
- Слева — карточка «что это за деталь». Справа — порядок сборки с галочками.
- Подсвеченное голубое место показывает, куда ставить текущую деталь — **кликни по нему**.
- Кнопка **↺ Заново** (или клавиша **R**) — начать сборку сначала.

## Модели деталей
Лежат в папке `models/` в формате `.glb`:
`case, motherboard, cpu, cooler, ram, gpu, ssd, psu`.
Игра сама подгоняет размер каждой модели. Если какого-то файла нет — на его месте
появится подпись «? нет модели» (заглушка), игру это не ломает.
Чтобы заменить деталь — просто положи новый файл с тем же именем в `models/`.

## Режим настройки позиций — клавиша F1
У каждой скачанной модели свой масштаб и ориентация, поэтому места деталей внутри
корпуса, возможно, придётся подогнать. Нажми **F1** и для текущей детали:
- **стрелки** — двигать по X/Z, **PageUp/PageDown** — по высоте (Y);
- **`[` `]`** — уменьшить/увеличить размер; **`,` `.`** — повернуть.

Внизу слева показываются точные значения `pos / size / rotY`. Перепиши их в таблицу
`PARTS` в начале `Main.gd` (или пришли мне — вставлю), чтобы закрепить.

## Готовые сборки (папка `build/`, в git не коммитятся)
Пресеты уже настроены (`export_presets.cfg`), обе платформы собираются командой:
```
# Windows (.exe, один файл — модели внутри)
"D:/Работа/IT-Compot/Gaming/Godot/Godot 4/Godot 4.exe" --headless --path . --export-release "Windows Desktop" build/Собери-ПК.exe

# macOS (.app в .zip)
"D:/Работа/IT-Compot/Gaming/Godot/Godot 4/Godot 4.exe" --headless --path . --export-release "macOS" build/Собери-ПК-mac.zip
```
Или из редактора: **Project → Export → выбрать пресет → Export Project**. Godot на целевом ПК не нужен.

- **Windows:** скопировать `Собери-ПК.exe` на любой ПК, запустить двойным кликом.
- **macOS:** распаковать `Собери-ПК-mac.zip`, получится `Собери-ПК.app`. Сборка **без подписи Apple**,
  поэтому при первом запуске: правый клик по `.app` → **Открыть** → подтвердить. Если ругается на
  «повреждён» — в Терминале выполнить `xattr -cr "Собери-ПК.app"` и запустить снова.

> Для сборки macOS в настройках проекта включён импорт текстур **ETC2 ASTC** (иначе Godot не
> экспортирует universal-сборку) — трогать не нужно.

## Лицензии моделей
Перед публикацией в общий доступ оформи `models/ЛИЦЕНЗИИ.md`: автор + ссылка +
лицензия каждой модели (годятся только **CC0** или **CC-BY** с указанием автора).

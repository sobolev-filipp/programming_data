# Лайфхаки урока 1 — иконки как у профи

> Три приёма с **точными шагами**: где кнопка, что нажать, что получится.

---

## 🎯 Трюк A — сложное = сумма простого (булевы операции)

Не рисуй форму «от руки». Собери из простых фигур и применяй **булеву операцию**.

**Как сделать (по шагам):**
1. Нарисуй 2+ фигуры и **выдели их** (инструмент «Перемещение» `V`, обведи рамкой или кликай с `Shift`).
2. Вверху по центру, на панели инструментов, появится **иконка «Булевы группы»** — два **пересечённых квадратика** со стрелкой **▾**. Нажми **▾**.
3. Выбери операцию:
   - **Объединение (Union)** — «сварить» в один силуэт *(корпус + плавники + нос → ракета)*.
   - **Вычитание (Subtract)** — верхняя фигура **вырезает** дырку *(окно ракеты, полумесяц)*.
   - **Пересечение (Intersect)** — оставить только **общую** часть *(лепесток, листик)*.
   - **Исключение (Exclude)** — убрать пересечение, оставить «бублик».

> 💡 **Булева группа живая.** В **панели слоёв слева** у группы есть **треугольник ▸** — раскрой его: все исходные фигуры целы, можно кликнуть и подвинуть. Ничего не «запекается».

> ⚠️ Для **Вычитания/Пересечения** важен **порядок**: режет/оставляет по **верхней** фигуре. Если вышло наоборот — в панели слоёв перетащи фигуру выше/ниже.

## 🎯 Трюк B — единый стиль набора

Чтобы иконки были «семьёй», задай общие настройки — **через панель Design справа**.

**Как сделать:**
1. **Сохрани палитру как стили:** выдели фигуру → справа в блоке **Fill** нажми иконку **«Стили» ⁙** (четыре точки) → **+** → назови цвет (напр. «Красный-бренд»). Теперь этот цвет — в один клик на любой фигуре.
2. **Одинаковое скругление:** выдели фигуру → справа поле **«Corner radius»** (иконка уголка ⌜) → впиши одно и то же число всем (напр. `8`).
3. **Единый размер фреймов:** кликни фрейм → справа поля **W/H** → у всех иконок сделай `512 × 512`.
4. **Один визуальный вес:** не делай одну иконку жирной, другую тонкой — одинаковая «толщина» деталей.

> 💡 Проверка: **уменьши масштаб** (`Shift+0` — по размеру) и посмотри на набор издалека. Если иконка «выпадает» цветом/весом — поправь.

## 🎯 Трюк C — правильный экспорт

**Как экспортировать (по шагам):**
1. Кликни **фрейм** целиком (по его названию в панели слоёв) — не отдельный объект.
2. Справа **внизу** панели Design — секция **«Export»** → нажми **+**.
3. Выбери формат в выпадающем списке:
   - **SVG** — настоящий вектор (для сайта, Illustrator; любой размер).
   - **PNG** — картинка с прозрачным фоном; слева задай множитель **2x** или **3x** (чётче на телефоне/ретине).
4. Нажми **«Export …»** → выбери папку.

> 💡 **Ровно по центру фрейма:** выдели объект (он должен быть «внутри» фрейма) → справа вверху панели Design — ряд иконок выравнивания → **«Align horizontal centers»** и **«Align vertical centers»**. Иконка встанет идеально по центру.

## Итог

| Задача | Точные шаги |
|--------|-------------|
| Сложная форма | Выделить 2+ → верх: «Булевы группы» ▾ → Объединение/Вычитание |
| Дырка/вырез | **Вычитание** (режущая фигура — сверху) |
| Сохранить цвет | Fill → ⁙ «Стили» → **+** |
| Скругление всем | справа поле **Corner radius** |
| Ровно по центру | справа вверху — иконки **Align center** |
| Экспорт | фрейм → **Export** (внизу справа) → **+** → SVG / PNG 2x |

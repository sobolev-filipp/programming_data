# Лайфхаки урока 13 — фирменный стиль как система

> Три приёма с **точными шагами**: где кнопка, что нажать, что получится.

---

## 🎯 Трюк A — единство через «Образцы»

**Как собрать палитру и красить из неё:**
1. Открой `Окно → Образцы`.
2. Задай цвет (двойной клик по «Заливке» → `#`) → **перетащи квадрат «Заливка»** (низ панели инструментов) на панель «Образцы». Так все **3–4** фирменных цвета.
3. Крась **любой** элемент кликом по образцу — логотип, иконки, карточку, узор.
4. **Один характер форм:** знак округлый → иконки тоже округлые (одинаковые скругления, одинаковая толщина линий).
5. Правишь образец (двойной клик по нему) — цвет обновляется **везде**.

> 💡 Прищурься на набор. Элемент «выпадает» по цвету/форме — верни в общий стиль.

---

## 🎯 Трюк B — логотип, который работает

1. **Тест «маленький»:** `Ctrl+C`/`Ctrl+V` → уменьши копию (угол рамки + `Shift`) до ~32–40 px — узнаётся?
2. **Одноцветная версия:** выдели весь логотип → двойной клик по «Заливке» → **один** цвет (чёрный) — читается силуэтом?
3. **Тёмная/светлая:** копия лого на светлом фоне и на тёмном (белая версия) — настоящий лого живёт в любом фоне.
4. **Узор из знака:** выдели иконку/элемент → `Объект → Узор → Создать` → «Готово» → применяй из «Образцов». Сразу «родной».

> 💡 **Мокап продаёт:** нарисуй простой стакан/футболку/вывеску и налепи логотип — бренд «оживает».

## 🎯 Трюк C — защита без волнения

Держи **4 ответа** наготове (можно записать на бумаге):
1. **Марка** — что продаёт/делает.
2. **Идея знака** — почему такой символ и цвета.
3. **Приёмы (3–4)** — перо/отражение, Обработка контуров, градиент, узор…
4. **Что сложно / чем горжусь.**

Говори про **решения**, а не «просто красиво»: «взял округлые формы и зелёный — бренд про свежесть». Регламент — **1 минута**.

> 💡 Умение объяснить свой стиль ценится как сам дизайн — навык на всю жизнь.

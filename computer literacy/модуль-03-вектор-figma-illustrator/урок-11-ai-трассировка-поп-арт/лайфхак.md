# Лайфхаки урока 11 — трассировка и поп-арт

> Три приёма с **точными шагами**: где кнопка, что нажать, что получится.

---

## 🎯 Трюк A — мало тонов = чистый стиль

**Как настроить (панель `Окно → Трассировка изображения`):**
1. Помести фото (`Файл → Поместить`) → вверху нажми **«Встроить»**.
2. Выдели фото → `Объект → Трассировка изображения → Создать` (или кнопка **«Трассировка изображения»** на панели управления вверху).
3. В панели настроек:
   - **Режим: Цвет**; **Палитра: Ограниченная**; **Цвета: 4–5** (не 20!);
   - раскрой **«Дополнительно»**: **Контуры ~75%**, **Углы ~70%**, **Шум ~20–25** (убирает мелкие пятнышки);
   - галочка **«Просмотр»**.
4. Хочешь трафарет — **Режим: Чёрно-белый** + крути **Порог**.

> 💡 Меньше тонов = легче красить и «дороже» поп-арт. Много цветов = каша.

---

## 🎯 Трюк B — «Выделить одинаковые» вместо мучений

1. Сначала **«Разобрать»** (кнопка Expand вверху) — иначе фигур ещё нет, красить нечего.
2. Кликни фигуру одного тона (`V`) → `Выделение → Одинаковые → **Цвет заливки**` → выделились **все** такие.
3. Двойной клик по «Заливке» → новый цвет → перекрасился **весь тон** сразу.
4. Так же **чистить фон:** кликни фон → «Выделить одинаковые» → `Delete`.

---

## 🎯 Трюк C — поп-арт «на максимум»

- **Кислотная палитра:** розовый / циан / жёлтый / лайм — дерзко.
- **Сетка 2×2:** выдели портрет → `Ctrl+G` → `Ctrl+C`/`Ctrl+V` ×3 → расставь 4 плитки → в каждой смени палитру («Выделить одинаковые»).
- **Полутона-фон:** прямоугольник-фон → `Окно → Библиотеки образцов → Узоры → Базовая графика_Точки` → кликни образец (зальётся точками).
- **Чёрная обводка** главным фигурам (панель «Обводка», 2–3 пт) — «трафаретный» вид.

> 💡 Быстро примерить палитры: выдели портрет → на панели управления/«Свойства» кнопка **«Перекрасить»** → крути колесо (ручной подбор, не ИИ).

## Итог

| Задача | Точные шаги |
|--------|-------------|
| Фото → вектор | `Объект → Трассировка → Создать`; панель: Цвет, Цвета 4–5 |

| Сделать редактируемым | кнопка **«Разобрать» (Expand)** |

| Комикс-фон | `Библиотеки образцов → Узоры → Точки` |

# Лайфхаки урока 11 — трассировка и поп-арт

> Три приёма, чтобы фото красиво стало вектором, а поп-арт «зазвучал».

---

## 🎯 Трюк A — мало тонов = чистый стиль

- В панели «Трассировка изображения»: **Режим Цвет**, **Цвета 4–5** (не 20!).
- **Шум (Noise) 20–25** — убирает мелкие пятнышки-«мусор».
- Контуры ~75%, Углы ~70% — форма чётче.
- Хочешь трафарет — **Чёрно-белый** + ползунок **Порог**.

> 💡 Чем меньше тонов, тем **легче красить** и тем «дороже» поп-арт. Много цветов = каша.

---

## 🎯 Трюк B — «Выделить одинаковые» вместо мучений

- Кликни фигуру одного тона → `Выделение → Одинаковые → **Цвет заливки**` → выделились **все** такие.
- Теперь один раз задай новый цвет — перекрасился **весь тон** сразу.
- Так же удобно **чистить** (выделил фон-цвет → `Delete`).

> 💡 Не забудь сперва **«Разобрать» (Expand)** — иначе фигур ещё нет, красить нечего.

---

## 🎯 Трюк C — поп-арт «на максимум»

- **Кислотная палитра:** розовый/циан/жёлтый/лайм — не бойся дерзости.
- **Сетка 2×2:** один портрет, 4 палитры = постер Уорхола.
- **Полутона:** фон-плашке дай **узор из точек** (`Окно → Библиотеки образцов → Узоры → Точки`) — комикс-вайб.
- **Чёрная обводка** главным фигурам — «трафаретный» вид.

> 💡 Быстро примерить палитры — кнопка **«Перекрасить»** (Recolor, ручной подбор, не ИИ): крутишь колесо и смотришь варианты.

---

## Итог

| Задача | Решение |
|--------|---------|
| Фото → вектор | **Трассировка изображения** (Цвет, 4–5) |
| Убрать «мусор» | ползунок **Шум** повыше |
| Сделать редактируемым | **Разобрать (Expand)** |
| Перекрасить тон разом | **Выделить одинаковые → Цвет заливки** |
| Постер Уорхола | сетка **2×2**, 4 палитры |
| Комикс-фон | **узор из точек** (полутона) |

# Лайфхаки урока 4 — интерфейсы как профи

> Три приёма с **точными шагами**: где кнопка, что нажать, что получится.

---

## 🎯 Трюк A — автолейаут вместо линейки

**Как сделать:**
1. Выдели элементы (`V`, рамкой) → нажми **`Shift+A`**. Появится рамка-контейнер (автолейаут).
2. Справа в панели Design возникнет секция **«Auto layout»**. Там настрой:
   - **Направление** — стрелки **↓** (вертикально) / **→** (горизонтально);
   - **Промежуток (gap)** — число между элементами;
   - **Отступы (padding)** — поля внутри контейнера (можно раздельно по сторонам).
3. **Список** = вертикальный автолейаут: добавил строку — остальные **сдвинулись сами**.
4. **Вкладывай** автолейауты: строка (гор.) внутри списка (верт.) внутри экрана.

> ⚠️ Убрать автолейаут — `Shift+A` ещё раз (или в секции Auto layout нажать «−»).

## 🎯 Трюк B — Hug / Fill / Fixed (магия размеров)

Режим размера задаётся **справа, у полей ширины (W) и высоты (H)** — рядом с числом есть **выпадающий список**:

1. Выдели элемент внутри автолейаута.
2. Кликни список у поля **W** (или **H**) и выбери:
   - **Hug contents** — контейнер **сжат под контент** (кнопка сама по тексту);
   - **Fill container** — элемент **растянут** на всю ширину контейнера (распор);
   - **Fixed** — жёсткий размер.

> 💡 Хочешь, чтобы «время» уехало вправо от названия трека? Выдели **название** → ширину поставь **Fill container** — оно раздвинет строку, время прижмётся к правому краю.

## 🎯 Трюк C — прототип и Smart Animate

**Как связать экраны:**
1. Вверху справа переключись на вкладку **«Prototype»**.
2. Выдели элемент (напр. строку списка) — на его краю появится **синий кружок ○**. **Тяни** от него стрелку на нужный **фрейм-экран**.
3. В окошке связи: триггер **«On tap»** → действие **«Navigate to»** → выбери экран → анимация «Instant» / «Move in».
4. **Проверить:** кнопка **▶ (Play)** справа вверху → тыкай прототип.
5. **Поделиться:** кнопка **«Share»** вверху → «Copy link» — любой откроет в браузере, без установки.

> 💡 **Smart Animate:** если один и тот же элемент (обложка) есть на **двух** экранах — выбери анимацию перехода **«Smart animate»**: Figma **плавно** превратит один в другой (обложка «вырастает») — «кино» почти без усилий.

## Итог

| Задача | Точные шаги |
|--------|-------------|
| Ровные отступы | Выделить → **`Shift+A`** → секция Auto layout (gap/padding/направление) |
| Кнопка по тексту | ширина **Hug contents** (список у поля W) |
| Распор лево-право | одному элементу — **Fill container** |
| Переход экранов | Prototype → синий ○ → тянуть → **On tap → Navigate to** |
| Плавный переход | анимация **Smart animate** |
| Показать другу | **Share** → Copy link |

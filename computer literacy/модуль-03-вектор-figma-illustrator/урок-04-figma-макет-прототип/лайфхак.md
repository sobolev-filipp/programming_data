# Лайфхаки урока 4 — интерфейсы как профи

> Три приёма, чтобы макет собирался быстро и «работал».

---

## 🎯 Трюк A — автолейаут вместо линейки

- Выдели элементы → **`Shift+A`** → они выстроились в ряд/столбик с равными отступами.
- Настрой **направление** (↓/→), **промежуток (gap)** и **отступы (padding)**.
- **Список** = вертикальный автолейаут: добавляешь строку — остальные сдвигаются сами.
- **Никогда** не расставляй строки списка вручную по пикселям.

> 💡 Автолейауты можно **вкладывать**: строка (гор.) внутри списка (верт.) внутри экрана. Так собран любой интерфейс.

---

## 🎯 Трюк B — Hug / Fill / Fixed (магия размеров)

- **Hug (по содержимому):** контейнер сжимается под контент — кнопка сама по тексту.
- **Fill (заполнить):** элемент растягивается на всю ширину контейнера — так делают распор (название слева, время справа).
- **Fixed (фиксированный):** жёсткий размер.

> 💡 Хочешь, чтобы «время» уехало вправо от названия? Дай названию ширину **Fill** — оно раздвинет строку, и время прижмётся к краю.

---

## 🎯 Трюк C — прототип и Smart Animate

- Вкладка **Prototype** → тяни синюю стрелку от элемента к экрану → «On tap → Navigate to».
- **▶ Play** — проверь переходы. **Share** — дай ссылку, любой потыкает без установки.
- **Smart Animate:** если одинаковый элемент есть на двух экранах (обложка), Figma **плавно** превратит один в другой — «кино»-переход почти без усилий.

> 💡 Ссылка на живой прототип — сильнейший экспонат портфолио: «вот моё приложение, потыкай сам».

---

## Итог

| Задача | Решение |
|--------|---------|
| Ровные отступы | **Автолейаут** (gap, padding) |
| Кнопка по тексту | ширина **Hug** |
| Распор (лево-право) | ширине одного элемента — **Fill** |
| Живой список | вертикальный автолейаут + строка-компонент |
| Переход между экранами | Prototype → «On tap → Navigate to» |
| Плавный переход | **Smart Animate** |
| Показать другу | **Share** → ссылка на прототип |

# Лайфхаки урока 4 — отступы, слои и нажатия

> Три приёма с шагами и проверкой результата. Они встроены в основной урок.

## Приём A — выбрать контейнер через Layers

1. Слева раскрой Журнал → Контент журнала → Список.
2. Чтобы добавить строку, выбери экземпляр целиком, затем Ctrl+D. Проверь, что копия вложена внутрь списка.
3. Если копия лежит поверх соседей, проверь Ignore auto layout / абсолютное положение. Верни обычное участие в потоке.
4. Добавление и удаление строки должно менять высоту списка и сохранять gap 12.

**Ошибка:** переместить строку рядом со списком, а потом подгонять её координаты. Верни вложенность вместо ручного выравнивания.

## Приём B — сначала размер родителя, потом Fill ребёнка

1. Выбери «Дело» → W Fixed 342, H Hug.
2. У номера оставь Fixed 40 × 40.
3. У блока «Тексты» задай W Fill, H Hug. Внутри названия разреши перенос и автоматическую высоту.
4. Временно напиши длинное название: строка должна вырасти по высоте, номер — остаться прежнего размера.

**Что проверить:** padding 12 со всех сторон, gap 12. Для текста остаётся 266 px. Не ставь одновременно Hug родителю и Fill ребёнку по ширине.

## Приём C — отличить переход от оверлея

1. Первая строка журнала: On click → Navigate to → Досье.
2. Показать улику: On click → Open overlay → Улика, Center.
3. Закрыть: On click → Close overlay. Новая цель не требуется.
4. Начни Present с Журнала и пройди весь маршрут. После закрытия улики должно оставаться досье.

**Ошибка:** поставить Navigate to на улику. Окно тогда заменит экран, а не откроется поверх. На время отладки выбери Instant — анимация не скрывает ошибочную цель.

## Шпаргалка

| Симптом | Что проверить |
|---|---|
| Фон кнопки не растёт | Hug у контейнера, текст по содержимому |
| Нет Fill | Родитель Auto layout, его ширина определена |
| Строки перекрываются | Вложенность и Ignore auto layout |
| Нажимается весь экран | Источник взаимодействия |
| Улика открылась как экран | Open overlay вместо Navigate to |
| Закрытие отправило в журнал | Close overlay вместо Navigate to |

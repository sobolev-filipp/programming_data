# Лайфхаки урока 8 — милый персонаж без мучений

> Три приёма с **точными шагами**: где кнопка, что нажать, что получится.

---

## 🎯 Трюк A — всё из овалов + обрезка

**Как обрезать деталь по телу («Пересечение»):**
1. Любую часть (тело, животик, крыло) рисуй **«Эллипсом»** (`L`) — клик по холсту → ввод Ш×В. Подгоняй точки «Прямым выделением» (`A`).
2. Деталь торчит за тело? Выдели **тело** → `Ctrl+C`, `Ctrl+F` (копия поверх) → `Shift+Ctrl+]` (на самый верх).
3. Выдели **эту копию + деталь** → `Окно → Обработка контуров` → **«Пересечение»** (3-я кнопка) → деталь обрежется ровно по силуэту тела.

> 💡 Держи **лишнюю копию тела** сбоку — это «трафарет-нож» для обрезки любых деталей (крыло, животик, узор).

---

## 🎯 Трюк B — симметрия отражением

**Как сделать вторую парную деталь:**
1. Сгруппируй деталь (глаз: белок+зрачок+блик) `Ctrl+G` — чтобы скопировалась целиком.
2. Возьми **«Отражение»** (`O`).
3. **Зажми `Alt` и кликни по вертикальному центру тела** (`Ctrl+U` — Быстрые направляющие помогут поймать центр) → окно «Отражение».
4. **Ось: Вертикальная → «Копировать»**. Вторая деталь — ровно напротив.

> 💡 Что **на оси** (клюв, животик, макушка) — рисуй один раз, **не** отражай.

---

## 🎯 Трюк C — формула «кавай»

- **Большая голова, огромные глаза** (глаз ≈ ⅓ ширины тела) + **белый блик** на зрачке.
- **Всё круглое** — никаких острых углов.
- **Румянец:** «Эллипс» розовый → `Окно → Прозрачность` (`Shift+Ctrl+F10`) → **Непрозрачность 50%**.
- **Сдвинутый зрачок** (чуть вниз-к центру) = «мимими».
- **Объём:** тело → `Окно → Градиент` (`Ctrl+F9`) → **Радиальный**, свет тянем инструментом «Градиент» (`G`) вверх; под ногами — тень-эллипс (радиальный серый→прозрачный, `Shift+Ctrl+[` в самый низ).

> 💡 **Стикерпак:** `Ctrl+C`/`Ctrl+V` героя → меняй **только глаза/рот/бровки** → радость/сон/удивление.

## Итог

| Задача | Точные шаги |
|--------|-------------|
| Части ровно по телу | копия тела (`Ctrl+F`→`Shift+Ctrl+]`) + **Пересечение** |
| Симметрия | группа → `O` → Alt-клик по центру → **«Копировать»** |
| Румянец мягкий | «Прозрачность» → **50%** |
| Объём | «Градиент» → **Радиальный** + тень снизу |
| Стикерпак | копия героя, менять только лицо |

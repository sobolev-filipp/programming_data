# Лайфхаки урока 8 — милый персонаж без мучений

> Три приёма, чтобы герой вышел ровным и «мимишным».

---

## 🎯 Трюк A — всё из овалов + обрезка

- Любую часть (тело, животик, крыло) делай **овалом**, потом «подгоняй» точками (`A`).
- Деталь торчит за тело? Скопируй тело (`Ctrl+C`→`Ctrl+F`), подними наверх (`Shift+Ctrl+]`), выдели с деталью → **«Пересечение»** — обрежется ровно по силуэту.
- Так все части «сидят» в контуре героя, как влитые.

> 💡 Держи **копию тела** отдельно — она твой «трафарет-нож» для обрезки любых деталей.

---

## 🎯 Трюк B — симметрия отражением

- Крыло / лапку / глаз сделай **один раз** → «Отражение» (`O`) → `Alt`-клик по центру тела → **«Вертикальная» → «Копировать»**.
- Вторая половина — идеально ровная и на месте.
- Что **на оси** (клюв, животик, макушка) — рисуй один раз, не отражай.

> 💡 Сгруппируй глаз (`Ctrl+G`) до отражения — скопируется весь глаз целиком (белок + зрачок + блик).

---

## 🎯 Трюк C — формула «кавай»

- **Большая голова, огромные глаза** (с белым бликом!), короткие лапки.
- **Всё круглое** — никаких острых углов.
- **Румянец** (розовые кружки 50%) + **сдвинутый зрачок** = «мимими».
- Объём — **радиальный градиент** (тело, животик) + мягкая **тень** под героем.

> 💡 Набор эмоций из одного героя: копируй и меняй **только глаза/бровки/рот** — получишь стикерпак (радость, сон, удивление).

---

## Итог

| Задача | Решение |
|--------|---------|
| Части ровно по телу | копия тела + **«Пересечение»** |
| Симметрия | **«Отражение → Копировать»** |
| Милый взгляд | большие глаза + блик + сдвинутый зрачок |
| Объём | радиальный градиент + тень |
| Стикерпак | копия героя, менять только лицо |

# Лайфхаки урока 3 — работать как дизайн-профи

> Три приёма, которые экономят часы и держат набор идеально ровным.

---

## 🎯 Трюк A — компонент: рисуй раз, используй сто раз

- Собрал элемент (карту, кнопку, аватар) → **«Create component»** (`Ctrl+Alt+K`) → фиолетовый ромб ◆.
- Ставь на холст **копии** (◇), а не рисуй заново.
- Нужно поменять всем сразу (рамку, форму)? Правь **мастер** — копии обновятся.
- В копии меняй только **текст / цвет / картинку** (это «переопределения», override) — связь не рвётся.

> 💡 Держи мастер **отдельно «на полке»** (или на отдельной странице), а в работе — копии. Не потеряешь оригинал.

---

## 🎯 Трюк B — стили = единый вид без усилий

- Сохрани цвета как **стили цвета** (⁙ рядом с Fill/Stroke → +). Применяй из списка одним кликом.
- Сохрани шрифты как **стили текста** (заголовок, подпись).
- Поменял стиль в одном месте — **обновилось везде**, где он применён.

> 💡 Правило: **ни одного «случайного» цвета**. Всё из палитры-стилей — тогда набор выглядит профессионально.

---

## 🎯 Трюк C — градиент за «дороговизну»

- Плоский цвет = простенько. **Градиент из 2 близких оттенков** = объём и «премиум».
- **Линейный** — переход по прямой (фон карты сверху-вниз).
- **Радиальный** — свечение из центра (ореол за портретом героя).
- Не бери слишком контрастные цвета в один градиент — будет «грязь». Лучше два оттенка одного цвета.

> 💡 Готовые красивые пары — на [uiGradients](https://uigradients.com/). Подсмотри и повтори стопами.

---

## Итог

| Задача | Решение |
|--------|---------|
| Набор одинаковых элементов | **Компонент** + копии |
| Поменять всем разом | Правка **мастера** |
| Разное в копиях | Override: текст/цвет/картинка |
| Единые цвета/шрифты | **Стили** цвета и текста |
| «Дорогой» вид | **Градиент** из 2 оттенков |
| Свечение за героем | **Радиальный** градиент |

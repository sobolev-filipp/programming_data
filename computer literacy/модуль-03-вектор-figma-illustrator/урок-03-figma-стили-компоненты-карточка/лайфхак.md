# Лайфхаки урока 3 — работать как дизайн-профи

> Три приёма с **точными шагами**: где кнопка, что нажать, что получится.

---

## 🎯 Трюк A — компонент: рисуй раз, используй сто раз

**Как сделать:**
1. Собери элемент (карту/кнопку) → выдели всё → `Ctrl+G` (группа).
2. **Правый клик → «Create component»** (или кнопка-**ромб ◆** вверху по центру; клавиши `Ctrl+Alt+K`). У группы появится **фиолетовый ромб ◆** — это **мастер**.
3. Отодвинь мастер «на полку» сбоку. Для работы бери **копии:** `Ctrl+C` / `Ctrl+V` (у копий ромб **пустой** ◇), **или** слева вкладка **«Assets»** → перетащи компонент на холст.
4. **Поменять всем сразу** (рамку/форму): правь **мастер** — все копии обновятся.
5. **В копии** меняй только **текст / цвет / картинку** (двойной клик по элементу внутри копии) — это override, связь цела.

> ⚠️ Не «разгруппировывай» и не «Detach» копию без нужды — порвётся связь с мастером.

## 🎯 Трюк B — стили = единый вид без усилий

**Как сохранить и применить (панель Design справа):**
1. **Стиль цвета:** выдели фигуру → в блоке **Fill** (или **Stroke**) нажми иконку **«Стили» ⁙** (четыре точки) → **+** → назови (напр. «Фон-фиолет»). Готово — цвет в списке.
2. **Стиль текста:** выдели текст, настрой шрифт/размер → в блоке **Text** нажми **⁙** → **+** → назови («Имя героя», «Подпись»).
3. **Применить:** выдели новый объект → нажми **⁙** → выбери стиль из списка (один клик).
4. **Поменять стиль:** правый клик по стилю в списке → «Edit style» → изменил → **обновилось везде**, где применён.

> 💡 Правило: **ни одного «случайного» цвета**. Всё — из стилей.

## 🎯 Трюк C — градиент за «дороговизну»

**Как сделать (панель Design → Fill):**
1. Выдели фигуру → в блоке **Fill** кликни **цветной квадрат** (откроется палитра).
2. Вверху палитры — выпадающий список типа: смени **«Solid»** на **«Linear»** (линейный) или **«Radial»** (радиальный).
3. На фигуре появятся **точки-стопы** (◦——◦). Кликни левый стоп → задай цвет; кликни правый → второй оттенок. **Добавить стоп** — клик по линии градиента.
4. **Направление:** тяни за манипулятор-линию на фигуре (для «Linear» — сверху вниз).

- **Линейный** — переход по прямой (фон карты).
- **Радиальный** — свечение из центра (ореол за портретом).
- Бери **2 близких оттенка одного цвета** — иначе «грязь».

> 💡 Готовые пары — [uiGradients](https://uigradients.com/): подсмотри hex и повтори в стопах.

## Итог

| Задача | Точные шаги |
|--------|-------------|
| Набор одинаковых | Группа → ПКМ **Create component** (`Ctrl+Alt+K`) → копии |
| Поменять всем | Править **мастер** ◆ |
| Разное в копиях | Двойной клик в копии → текст/цвет/картинка |
| Сохранить цвет/шрифт | Fill/Text → **⁙ Стили** → **+** |
| «Дорогой» вид | Fill → тип **Linear/Radial**, 2 оттенка |

### Подсказки по Figma

| Что хочешь сделать | Где искать |
|---|---|
| Создать рабочую область | F — Frame; W и H в Design |
| Нарисовать фигуры | R — прямоугольник, O — эллипс |
| Объединить или вырезать фигуры | Выдели обе фигуры и открой меню Boolean operations. Для Subtract вырезающая фигура сверху |
| Нарисовать кривую | P — Pen; клик создаёт угол, протяжка — направляющие |
| Исправить кривую | Двойной клик по вектору, затем выдели точку или её ус |
| Сохранить цвет | Fill → меню стилей → создание стиля |
| Создать повторяемый элемент | Create component, экземпляры бери из Assets |
| Сделать автоматические отступы | Shift+A, настрой Padding и Gap |
| Соединить экраны | Prototype → On click → Navigate to; проверка через Present |
| Сохранить картинку | Выдели фрейм → Export → PNG или SVG |

На Mac вместо Ctrl в обычных командах копирования и дублирования используй Cmd. Для пера можно дополнительно потренироваться в [The Bézier Game](https://bezier.method.ac/), но сочетания клавиш в игре и Figma могут отличаться.

## Illustrator

В старых инструкциях внешний вид панелей может отличаться от установленной версии. Не ищи кнопку по одному только цвету или рисунку: сначала прочитай, какое действие она выполняет.

| В старой инструкции | Что искать сейчас |
|---|---|
| Навигатор (если речь об объединении фигур) | Окно → Обработка контуров (Pathfinder). Настоящий Navigator служит для просмотра документа |
| Добавить | Unite — объединение фигур |
| Вычесть | Minus Front — вычитание верхней фигуры |
| Разделить | Divide — разделение по пересечениям; при необходимости разгруппируй результат |
| Command | Ctrl на Windows, Cmd на Mac |
| Веб-документ | Файл → Создать, RGB, единицы — пиксели |
| Градиент | Окно → Градиент; G для управления направлением |
| Градиентная сетка | U — Mesh; добавляй точки постепенно |
| Редактирование точек | A — Direct Selection; V выделяет объект целиком |
| Перо | P; клик для угла, протяжка для кривой; Alt/Option для независимой направляющей |

Если фигура исчезла после Pathfinder, отмени действие и проверь порядок объектов. Перед сложной операцией оставь копию исходных фигур в стороне. Если не получается изменить цвет, проверь, что активна заливка, а не обводка. Все рисунки выполняй вручную, без генеративных функций.

## Как сохранить работу

В Figma оставь редактируемый файл и экспортируй PNG. В Illustrator сохрани исходник AI и экспортируй PNG или SVG. Выбирай работы по освоенным инструментам, а не по скорости выполнения.

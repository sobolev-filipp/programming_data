# Лайфхаки урока 7 — глянец за минуту

> Три приёма с **точными шагами**: где кнопка, что нажать, что получится.

---

## 🎯 Трюк A — шар из круга одним градиентом

**Как сделать (панель `Окно → Градиент`, `Ctrl+F9`):**
1. Выдели круг → кликни **миниатюру градиента** в панели (заливка станет градиентной).
2. В списке **«Тип»** выбери **Радиальный**.
3. На **ползунке** снизу — две **остановки** (квадратики). **Двойной клик** по левой → светлый оттенок; по правой → тёмный оттенок **того же цвета**.
4. Возьми инструмент **«Градиент»** (`G`) и **протяни** линию из **верх-лева вниз-вправо** — светлый блик уедет к «лампе».
5. **Мягче переход:** кликни **под ползунком** посередине → добавится третья остановка (промежуточный тон).

> 💡 **Радиальный** = шары и блики; **Линейный** = стекло, металл, небо (переход по прямой).

---

## 🎯 Трюк B — блик через прозрачную остановку

**Как сделать:**
1. Нарисуй белый овал/дугу поверх объекта.
2. В панели «Градиент» тип **Линейный**, обе остановки **белые**.
3. **Двойной клик** по нижней остановке → в панели появится поле **«Непрозрачность»** → поставь **0**. У верхней оставь ~60.
4. 👀 Блик **растворится** в теле, а не будет «наклейкой».
5. Самый яркий блик — **маленькая** белая точка (непрозрачность ~90).

> 💡 Формула глянца: **тёмный низ** + **яркий маленький блик сверху** + мягкая **тень под объектом**.

---

## 🎯 Трюк C — Градиентная сетка без страха

**Как сделать:**
1. Выдели фигуру → `Объект → Создать сетку градиента…` → **Строки 4, Столбцы 4**, «Вид: К центру» → ОК. Авто-объём готов.
2. **Красим узлы:** возьми **«Прямое выделение»** (`A`) → кликни **узел-ромбик** (подсветится крупнее) → двойной клик по «Заливке» → задай цвет.
   - низ-право → **тёмный** (тень), верх-лево → **светлый** (бок), самый верх-лево → **почти белый** (блик).
3. **Нужен ещё узел** для перехода — возьми **«Сетка»** (`U`) и кликни по фигуре точечно.
4. Не делай сетку 20×20 — крась 3–4 узла, этого хватает.

> 💡 **Рефлекс:** у **нижнего** края в тени сделай узел чуть **светлее** — объект «оживёт».

## Итог

| Задача | Точные шаги |
|--------|-------------|
| Объём шара | Градиент → **Радиальный**, 2 оттенка |
| Направление света | «Градиент» (`G`) — тянуть от блика |
| Мокрый блеск | белый градиент, нижняя остановка → **Непрозрачность 0** |
| Реалистичный фрукт | `Объект → Создать сетку градиента` (4×4) + красить узлы (`A`) |
| «Приклеить» к столу | тень-эллипс (радиальный серый→прозрачн.) под объектом |
| Оживить объём | узел-рефлекс снизу чуть светлее |

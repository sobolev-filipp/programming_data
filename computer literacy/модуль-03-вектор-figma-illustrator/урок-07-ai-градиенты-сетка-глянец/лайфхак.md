# Лайфхаки урока 7 — глянец за минуту

> Три приёма, чтобы объект «засиял» объёмом.

---

## 🎯 Трюк A — шар из круга одним градиентом

- Круг → **Радиальный** градиент: центр **светлый**, край **тёмный** (один цвет, два оттенка).
- «Градиент» (`G`) → **потяни из верх-лева** — блик уедет к «лампе».
- Добавь третью остановку посередине — переход мягче.

> 💡 Радиальный = шары и блики; Линейный = стекло, металл, небо (переход по прямой).

---

## 🎯 Трюк B — блик через прозрачную остановку

- Белый овал/дуга поверх → в «Градиент» сделай его **белым линейным**, где вторая остановка — **непрозрачность 0**.
- Блик **растворится** в теле, а не будет «наклейкой».
- Самый яркий блик — **маленькая** точка (непрозрачность 90). Большой белый блин = дёшево.

> 💡 Формула глянца: **тёмный низ** (тень тела) + **яркий маленький блик сверху** + мягкая **тень под объектом**.

---

## 🎯 Трюк C — Градиентная сетка без страха

- `Объект → Создать сетку градиента` → **4×4**, «К центру» — авто-объём за секунду.
- Крась **только 3–4 узла**: тёмный (тень, низ-право), светлый (бок, верх-лево), почти белый (блик).
- Выбирай узел «Прямым выделением» (`A`) и задавай цвет.
- Не делай сетку 20×20 — запутаешься; добавляй узлы «Сеткой» (`U`) точечно, где нужен переход.

> 💡 Рефлекс (отражённый свет) у **нижнего края** в тени делает объект «живым» — чуть светлее там.

---

## Итог

| Задача | Решение |
|--------|---------|
| Объём шара | Радиальный градиент (свет→тень) |
| Направление света | «Градиент» (`G`) — тянуть от блика |
| Мокрый блеск | белый градиент с остановкой «непрозрачность 0» |
| Реалистичный фрукт | Градиентная сетка (4×4, красить узлы) |
| «Приклеить» к столу | мягкая тень-эллипс под объектом |
| Оживить объём | рефлекс снизу в тени |

# Лайфхаки — перенос без потерянных деталей

## 1. Сначала группа, потом перспектива

В Layers выбери Пиццу целиком, проверь движением V, что начинка и корочка перемещаются вместе. Esc выводит из изоляции. Сохрани плоскую копию до переноса. Не выделяй только верхний треугольник маски.

## 2. Не путай стрелки

V — обычное выделение. Shift+V — выбор перспективы. При активном Shift+V клавиша2 выбирает горизонтальную плоскость. Перед переносом смотри на виджет куба. На передний план исправляет перекрытие, но не ошибочно выбранную плоскость.

## 3. Помидор не нужно приклеивать к крышке

Файл → Поместить → tomato.psd. Фотографию рядом с коробкой двигай V, сохраняй пропорции в Transform. В Links проверь Link/Embed. Если передаёшь только AI, встроенное изображение надёжнее внешней связи.

## Шпаргалка

| Задача | Команда |
|---|---|
| Вписать область | Ctrl+0 |
| Контуры / обычный вид | Ctrl+Y |
| Группа | Ctrl+G |
| Маска | Ctrl+7 |
| Сетка / выбор перспективы | Shift+P / Shift+V |
| Горизонтальная плоскость | 2 при активном инструменте перспективы |
| Разместить фото | Файл → Поместить |
| Проверить связь фото | Окно → Связи |

## Один ломтик — несколько экземпляров

Сначала доведи до конца один рисунок салями и сгруппируй его. Затем создай символ через Окно → Символы → Новый символ. Перетаскивай миниатюру из панели на пиццу инструментом «Выделение» (V). Так не придётся по отдельности переносить маленькие вкрапления каждого ломтика. Маску создавай для всей начинки; цветной Сыр оставляй отдельным контуром снизу.

# Лайфхаки урока 2 — перо без боли

> Три приёма с **точными шагами**: где кнопка, что нажать, что получится.

---

## 🎯 Трюк A — правило «мало точек, много усов»

Плавность дают **не количество точек**, а длина **направляющих (усов)**.

**Как делать пером (`P`):**
1. **Клик** = ставит точку с **прямым** отрезком (угол).
2. **Клик и, не отпуская, потяни** = ставит точку с **усами** → отрезок выгибается **дугой**. Чем **длиннее** тянешь ус, тем круче изгиб.
3. Ставь точку **только там, где кривая меняет направление** (вершина «горки», впадина «волны») — не между ними.
4. Целая дуга = **2 точки** с усами, а не десять.

> 💡 Мысленно: точки — «гвоздики», усы — «резинки», задающие провисание линии между гвоздиками.

> ⚠️ Много точек = кривая «пилит». Заметил лишние — удали: «Прямое выделение» (`A`) → кликни точку → `Delete`.

## 🎯 Трюк B — угол ↔ кривая (правка точки)

Форму правят **после** рисования, в режиме редактирования вектора.

**Как сделать:**
1. **Двойной клик** по контуру (инструментом `V`) → включится **режим правки** (видны точки-узлы).
2. **Угол → плавно:** наведи на **угловую** точку — рядом появится курсор **«Изгиб» (Bend)** (изогнутая стрелка) → **потяни** от точки → вытянутся усы, угол станет дугой.
3. **Плавно → угол:** **двойной клик** по гладкой точке — она станет **угловой** (усы уберутся).
4. **Двигать точку** — «Прямое выделение» (`A`), тянуть саму точку.

> 💡 Один контур смешивает: у сердечка ❤ **верх** — две дуги (протяжка), **низ** — острый угол (клик).

## 🎯 Трюк C — «логотип обязан работать маленьким»

**Как проверить и подстраховать:**
1. **Тест «аватарка»:** выдели логотип → `Ctrl+C`, `Ctrl+V` → уменьши копию (тяни угол рамки с `Shift`) до **~40 px**. Детали слиплись? — упрости знак (убери мелочи).
2. **Одноцветная версия:** выдели все фигуры логотипа → в панели **Fill** справа задай **один** цвет (напр. чёрный) → силуэт должен **читаться**. Хороший лого работает и в один цвет (печать, штамп).
3. **Держи мало деталей** — сила знака в простоте.

> 💡 Прокачать руку: [The Bézier Game](https://bezier.method.ac/) — 10 минут игры, и перо слушается.

## Итог

| Задача | Точные шаги |
|--------|-------------|
| Плавная дуга | Перо `P` → **клик-и-потяни**, мало точек |
| Острый пик | Перо `P` → просто **клик** |
| Угол сделать кривым | Двойной клик по контуру → навести на точку → **Bend** → потянуть |
| Кривую сделать углом | Двойной клик по гладкой точке |
| Удалить лишнюю точку | `A` → точка → `Delete` |
| Проверить лого | Копия → уменьшить до ~40px + одноцветная (Fill → 1 цвет) |

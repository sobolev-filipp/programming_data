# Лайфхаки урока 6 — симметрия и чистое перо

> Три приёма с **точными шагами**: где кнопка, что нажать, что получится.

---

## 🎯 Трюк A — рисуй половину, отражай целое

**Как сделать (по шагам):**
1. **Ось:** `Ctrl+R` (показать линейки) → **тяни от левой линейки** вправо — вытянется **вертикальная направляющая**. Поставь её на центр.
2. Нарисуй пером (`P`) **одну половину** мордочки; точки на оси клади **ровно на направляющую** (включи `Просмотр → Быстрые направляющие` `Ctrl+U` — прилипнут).
3. Выдели половину (`V`) → возьми **«Отражение»** (`O`, в группе с «Поворот» `R`).
4. **Зажми `Alt` и кликни точно по направляющей** — откроется окно «Отражение».
5. Выбери **Ось: Вертикальная** → нажми **«Копировать»** (не «ОК»!). Появится зеркальная половина.
6. Выдели **обе** половины → `Окно → Обработка контуров` → **«Соединение»** — шов по центру исчезнет.

> ⚠️ **«ОК» vs «Копировать»:** «ОК» просто перевернёт оригинал; вторую половину создаёт только **«Копировать»**.

---

## 🎯 Трюк B — «Опорная точка»: угол ↔ кривая

Инструмент **«Опорная точка»** — в группе с **Пером** (`P`): **зажми** иконку Пера → выпадет группа → выбери **«Опорная точка»** (клавиша `Shift+C`).

1. **Угол → плавно:** **потяни** за угловую точку → вытянутся усы, угол станет дугой (щека, макушка).
2. **Плавно → угол:** **кликни** по гладкой точке → станет острой (кончик уха, подбородок).
3. **Двигать саму точку** — «Прямое выделение» (`A`).

> 💡 Смешивай в одном контуре: уши — острые (клик), щёки — плавные (протяжка).

---

## 🎯 Трюк C — что на оси, что сбоку + проверка

- Всё **на оси** (нос, макушка, подбородок) — рисуй **один раз**, не отражай.
- Всё **сбоку** (ухо, глаз, щека) — рисуй **справа** и **отражай** (`O` → Alt-клик → «Копировать»).
- **Тест «аватарка»:** `Ctrl+C`/`Ctrl+V` → уменьши копию (угол рамки + `Shift`) до ~40px — узнаётся?
- **Одноцветная версия:** выдели весь логотип → двойной клик по «Заливке» → один цвет (чёрный) — читается силуэтом?

> 💡 «На миллион» — **негативное пространство:** спрячь деталь в вырезе (улыбка из фона, ухо из выемки) через «Минус верхний».

## Итог

| Задача | Точные шаги |
|--------|-------------|
| Идеальная симметрия | половина → `O` → Alt-клик по оси → **«Копировать»** |
| Убрать шов | обе половины → «Обработка контуров» → **Соединение** |
| Угол → кривая | **«Опорная точка»** (`Shift+C`) → потянуть точку |
| Кривая → угол | **«Опорная точка»** → кликнуть точку |
| Деталь на оси | рисовать один раз (не отражать) |
| Проверить лого | копия ~40px + одноцветная (одна «Заливка») |

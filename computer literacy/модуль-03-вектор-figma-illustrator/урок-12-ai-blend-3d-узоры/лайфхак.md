# Лайфхаки урока 12 — Blend, 3D и узоры

> Три приёма, чтобы постер собирался быстро и «звучал».

---

## 🎯 Трюк A — Переход (Blend): 2 фигуры → много

- Выдели **две** фигуры → `Объект → Переход → Создать` (`Alt+Ctrl+B`).
- Число элементов: `Объект → Переход → Параметры перехода` → «Интервалы: **Заданное число шагов**», задай N.
- **Ряд** — две фигуры на одной линии; **веер** — копию повернуть вокруг центра; **гирлянда** — `Заменить траекторию` кривой.
- «Плавный цвет» между двумя оттенками = мягкое **свечение/неон**.

> 💡 Blend **живой**: подвинь любую из двух фигур — весь ряд/веер пересчитается сам.

---

## 🎯 Трюк B — 3D без каши

- Текст/фигуру → `Эффект → 3D и материалы → Выдавливание и фаска`.
- Крути **кубик**-виджет для угла; **Глубина 60–90** (не 300!).
- Эффект **живой** (в «Внешний вид») — правь угол/глубину когда угодно.
- Готов — `Объект → Разобрать оформление` (перед экспортом надёжнее).

> 💡 Небольшой поворот (X −18°, Y −26°) читается лучше, чем сильный разворот боком.

---

## 🎯 Трюк C — узор как фон, а не как шум

- Готовые: `Окно → Библиотеки образцов → Узоры`. Свой: `Объект → Узор → Создать`.
- Применяй как **заливку** фигуры (клик по образцу).
- Держи узор **бледным** (низкая непрозрачность / близкий к фону цвет) — он **фон**, не главное.
- Масштаб плитки: свой узор можно уменьшить/увеличить в «Параметрах узора».

> 💡 Порядок постера: фон → **узор** → лучи (Blend) → 3D-заголовок → монетки/звёзды. Так ничего не перекрывает главное.

---

## Итог

| Задача | Решение |
|--------|---------|
| Ряд/веер/гирлянда | **Переход (Blend)** «Число шагов» |
| Неон/свечение | Blend «Плавный цвет» |
| Объём букв | **3D → Выдавливание** (глубина 60–90) |
| Повторяющийся фон | **Узор (Pattern)**, бледный |
| Правка эффектов | панель **«Внешний вид»** |
| Надёжный экспорт | **Разобрать оформление** |

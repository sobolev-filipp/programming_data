# Лайфхаки урока 12 — Blend, 3D и узоры

> Три приёма с **точными шагами**: где кнопка, что нажать, что получится.

---

## 🎯 Трюк A — Переход (Blend): 2 фигуры → много

**Как сделать:**
1. Выдели **две** фигуры (`V`) → `Объект → Переход → **Создать**` (`Alt+Ctrl+B`).
2. Задай количество: `Объект → Переход → **Параметры перехода…**` → «Интервалы: **Заданное число шагов**» → впиши N (напр. 10) → ОК.
3. Формы:
   - **Ряд** — две фигуры на одной линии (монетки);
   - **Веер** — копию **повернуть вокруг центра**: возьми «Поворот» (`R`) → `Alt`-клик по центру → задай угол (напр. 160°) → «Копировать», потом Переход;
   - **Гирлянда** — `Объект → Переход → **Заменить траекторию**` кривой-пером.
4. **Неон/свечение** — «Интервалы: Плавный цвет» между тёмной и светлой линией.

> 💡 Blend **живой**: подвинь любую из двух опорных фигур — весь ряд/веер пересчитается сам.

---

## 🎯 Трюк B — 3D без каши

**Как сделать:**
1. Выдели текст/фигуру (`V`) → `Эффект → 3D и материалы → **Выдавливание и фаска…**` *(старые версии: `Эффект → 3D → Выдавливание и скос`)*.
2. В окне: крути **кубик**-виджет (или задай углы X **−18°**, Y **−26°**); **«Глубина выдавливания» 60–90** (не 300!). Галочка «Просмотр».
3. Эффект **живой** — двойной клик по нему в `Окно → Внешний вид` правит угол/глубину.
4. Перед экспортом надёжнее «запечь»: `Объект → Разобрать оформление`.

> 💡 Небольшой поворот читается лучше, чем сильный разворот боком.

---

## 🎯 Трюк C — узор как фон, а не как шум

**Как сделать:**
1. **Свой узор:** выдели пару мелких фигур → `Объект → Узор → **Создать**` → в окне «Параметры узора» тип «Кирпич по горизонтали», масштаб плитки → вверху **«Готово»**. Узор попал в `Окно → Образцы`.
2. **Готовый:** `Окно → Библиотеки образцов → Узоры → …`.
3. **Применить:** выдели прямоугольник → **кликни образец-узор** в «Образцах» (зальётся).
4. Держи узор **бледным:** `Окно → Прозрачность` → низкая непрозрачность, или близкий к фону цвет.

> 💡 Порядок постера: фон → **узор** → лучи (Blend) → 3D-заголовок → монетки/звёзды.

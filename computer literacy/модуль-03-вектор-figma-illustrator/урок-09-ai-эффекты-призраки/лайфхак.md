# Лайфхаки урока 9 — эффекты как магия

> Три приёма с **точными шагами**: где кнопка, что нажать, что получится.

---

## 🎯 Трюк A — эффект = «фильтр поверх фигуры»

**Как управлять эффектом (панель `Окно → Внешний вид`, `Shift+F6`):**
1. Применить: выдели фигуру (`V`) → меню **`Эффект → …`** (напр. Искажение и трансформация → Зигзаг). Включи галочку **«Просмотр»**.
2. **Изменить:** в панели «Внешний вид» появится строка эффекта — **двойной клик** по ней → правь параметры вживую.
3. **Снять:** выдели строку эффекта → значок **корзины** внизу панели.
4. **Порядок:** несколько эффектов → **перетаскивай** строки в панели (порядок меняет результат).
5. **«Запечь»:** `Объект → Разобрать оформление` — эффект станет настоящими точками.

> 💡 Пока не уверен — держи эффект **живым**. «Запекай» только в конце (или перед экспортом).

---

## 🎯 Трюк B — один Зигзаг, два результата

В окне **`Эффект → Искажение и трансформация → Зигзаг`**:
- переключатель **точек** внизу: **«Гладко»** → волны (оборка, вода, флаг); **«Углом»** → зубцы (звезда, трещина, «зубастик»).
- **«Складки на сегмент»:** меньше = крупные волны; больше = мелкая рябь.
- **«Размер»** — высота волны (8–12 хватает).

**Втягивание и раздувание** (`Эффект → … → Втягивание и раздувание`): ползунок влево (**Втягивание**) → искра/звезда; вправо (**Раздувание**) → пухлые лепестки/облачка.

> 💡 Начинай с **маленьких** значений + «Просмотр» — эффекты быстро «уходят в кашу».

---

## 🎯 Трюк C — стек эффектов и графстиль

1. На одну фигуру навесь **несколько** эффектов подряд (Зигзаг + Скругление углов + Деформация) — все появятся в «Внешний вид».
2. **Порядок решает:** перетащи Скругление выше/ниже Зигзага — вид разный.
3. **Сохранить связку:** открой `Окно → Стили графики` → выдели фигуру → нажми **«Новый стиль графики»** (иконка листа внизу панели). Теперь применяй весь набор эффектов к другим фигурам **одним кликом** по образцу.

> 💡 **Деформация** (`Эффект → Деформация → Дуга/Флаг/Раздувание`) гнёт **весь** объект — «оживляет» (на ветру, в движении).

## Итог

| Задача | Точные шаги |
|--------|-------------|
| Волнистый низ | `Эффект → … → Зигзаг` → точки **«Гладко»** |
| Зубцы/колючки | Зигзаг → точки **«Углом»** |
| Искра из звезды | `Эффект → … → Втягивание` (ползунок влево) |
| Дрожащий край | `Эффект → … → Огрубление` |
| Изогнуть объект | `Эффект → Деформация → Дуга/Флаг` |
| Править/снять | панель **«Внешний вид»** (`Shift+F6`): двойной клик / корзина |
| Сохранить набор | `Окно → Стили графики` → **Новый стиль** |

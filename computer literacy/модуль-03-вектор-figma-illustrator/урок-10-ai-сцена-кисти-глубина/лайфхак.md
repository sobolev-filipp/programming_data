# Лайфхаки урока 10 — глубина и атмосфера

> Три приёма с **точными шагами**: где кнопка, что нажать, что получится.

---

## 🎯 Трюк A — атмосферная перспектива (планы на слоях)

**Как сделать:**
1. Открой `Окно → Слои` (`F7`) → создай слои кнопкой **«Создать новый слой»** (иконка листа ＋ внизу панели): «небо», «дальний», «средний», «передний».
2. Кликни нужный слой → рисуй на нём (объект появится именно там).
3. Правило цвета/размера:
   - **Дальнее** = светлее, бледнее, меньше, ближе к цвету неба, меньше деталей;
   - **Ближнее** = темнее, насыщеннее, крупнее, больше деталей.
4. Двигать/красить план целиком — выдели его слой и работай.

> 💡 Тест глубины: прищурься. Дальнее «сливается» с небом, ближнее — тёмное и чёткое → глубина есть.

---

## 🎯 Трюк B — длинная тень правильно

**Как сделать (надёжный способ — наклон копии):**
1. Реши, **откуда свет** → тени идут в **противоположную** сторону, под **одним** углом (45°).
2. Выдели объект (`V`) → `Ctrl+C`, `Ctrl+B` (копия **позади**). Залей копию **чёрным**.
3. `Объект → Трансформировать → **Наклон…**` → **Угол 45°**, ось **Горизонтальная** → ОК. Тень «повалилась».
4. `Окно → Прозрачность` → режим **«Умножение»**, **Непрозрачность 25%**.
5. **Обрежь по земле:** «Прямоугольник» на нижнюю часть поверх теней → выдели прямоугольник + тени → `Объект → Обтравочная маска → Создать` (`Ctrl+7`).
6. 🎓 Идеально ровная: копия + сдвиг по диагонали много раз через `Объект → Переход → Создать`, потом «Соединение».

> ⚠️ Разнобой теней — признак новичка. Один свет = все тени в одну сторону.

---

## 🎯 Трюк C — кисти и «Ширина»

1. **«Ширина» (`Shift+W`)** — в группе с «Масштаб» на панели инструментов. Наведи на **середину** линии (курсор с кружком) → **тяни в стороны** → линия раздуется. Пара протяжек = пухлое облако/холм.
2. **Кисти:** `Окно → Кисти` (`F5`) → меню панели (☰) → **«Открыть библиотеку кистей» → Художественные / Декоративные** → выбери → рисуй «Кистью» (`B`) как обводку.
3. **Своя кисть:** нарисуй фигуру (звезду/дерево) → перетащи её на панель «Кисти» → выбери тип (Рассеивающая/Узорчатая) → «печатай» вдоль линии.

> 💡 Дальние облака/птицы делай **мельче и бледнее** — перспектива работает и в небе.

## Итог

| Ощущение «далеко» | светлее + меньше; планы на **слоях** (`F7`) |
| Длинная тень | `Ctrl+B` → залить чёрным → **Наклон 45°** → «Умножение» 25% → маска `Ctrl+7` |
| Пухлое облако/линия | **«Ширина»** (`Shift+W`) — тянуть за середину |
| Фактурный штрих | `Окно → Кисти` → библиотеки → «Кисть» `B` |
| Своя кисть | фигуру перетащить на панель «Кисти» |

# 🔄 Профильный блок старших (модули 6–8, 40 ч)

## Модуль 6 — 📱 Своё приложение: App Inventor (8 уроков, 16 ч)

> Собираем **настоящее Android-приложение** из блоков — можно установить на свой телефон.

| Урок | Тема и проект | Приёмы (логика) |
|------|---------------|------------------|
| 1 | Интерфейс, экраны, компоненты → **приложение-визитка** | дизайнер + блоки, события |
| 2 | Кнопки, картинки, звук → **«Говорящий кот» (звуковая доска)** | обработчики событий |
| 3 | Переменные, условия → **викторина-приложение** | переменные, ветвление |
| 4 | Списки и циклы → **приложение-список / угадайка** | списки, циклы |
| 5 | Датчики (акселерометр, GPS) → **игра «наклоняй» / шагомер** | сенсоры |
| 6 | Canvas/рисование → **игра-рисовалка / крестики-нолики** | холст, координаты |
| 7 | Хранение данных, переходы экранов → **приложение с сохранением** | база, навигация |
| 8 | 🏆 **Своё приложение** → установка на телефон + защита | сборка APK, презентация |

## Модуль 7 — 🌐 Сайты: HTML/CSS (7 уроков, 14 ч)

| Урок | Тема и проект | Приёмы |
|------|---------------|--------|
| 1 | Как устроены сайты; теги, структура → **первая страница** | HTML-скелет, заголовки |
| 2 | Текст, картинки, ссылки, списки → **контентная страница** | теги контента |
| 3 | CSS: цвета, шрифты, фоны → **стилизация** | селекторы, свойства |
| 4 | Блочная модель, отступы → **аккуратная вёрстка** | box model, margin/padding |
| 5 | Flexbox → **адаптивный макет** | flex-контейнеры |
| 6 | Карточки, кнопки, hover → **интерактивный вид** | псевдоклассы, переходы |
| 7 | 🏆 🤖 **Сайт-портфолио** (+чуть JS) → публикация | скрипты, деплой, защита |

## Модуль 8 — 🎮 Своя игра на движке: Roblox Studio (5 уроков, 10 ч)

> Настоящий игровой движок: собрать и **опубликовать** свою игру (замена Python — он есть в отдельном курсе).

| Урок | Тема и проект | Приёмы |
|------|---------------|--------|
| 1 | Интерфейс Roblox Studio, части, ландшафт → **своя карта** | Parts, материалы, рельеф |
| 2 | Свойства, якоря, механики → **полоса препятствий (obby)** | физика, чекпоинты |
| 3 | Скрипты Lua: события, переменные → **ловушки, кнопки, очки** | основы Lua, события |
| 4 | Игровая логика: спавн, счёт, лидерборд → **мини-игра** | переменные, таблица лидеров |
| 5 | 🏆 **Своя игра** → публикация в Roblox + защита | публикация, тест, презентация |

> 🔁 По желанию группы Roblox можно заменить на **Construct 3** (2D-игры) из банка доп-тем.

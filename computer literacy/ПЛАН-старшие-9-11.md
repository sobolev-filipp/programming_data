Профильный блок старших — начальная разработка. У младших в этих же слотах — Scratch, Kodu, BlockBench. Python в этом курсе не берём — он изучается в отдельном курсе, вместо него Roblox. Программы профильного блока: App Inventor и редактор кода для сайтов работают в браузере, Roblox Studio устанавливается; все бесплатны. App Inventor тестируем на телефоне через приложение AI2 Companion.

> **Про веб-модуль.** В этом курсе сайты делаем на **Bootstrap** — готовом наборе стилей и компонентов: ученик быстро собирает красивый адаптивный сайт из блоков, почти без ручного CSS. Это знакомство с вебом «на результат». **Полноценная веб-вёрстка** (HTML, CSS с нуля, Flexbox/Grid, Figma, JavaScript) — это отдельный курс следующего года, поэтому здесь в глубину CSS не уходим.

Собираем настоящее Android-приложение из блоков — его можно установить на свой телефон. Тестируем на телефонах через AI2 Companion (QR-код). Интерфейс App Inventor оставляем на английском (иначе имена блоков по-русски приводят к ошибкам).

| Урок | Тема и проект | Приёмы |
|------|---------------|--------|
| [1](модуль-06-app-inventor/урок-01-интерфейс-первое-приложение/theory.md) | Интерфейс, компоненты, событие Click → «Нажми меня» (иконка в Illustrator) | Designer и Blocks, Label/Button/Image, свойства, `when Click → set Text`, тест на телефоне |
| [2](модуль-06-app-inventor/урок-02-питомец-сетка-экраны/theory.md) | «Мой питомец» — реагирует на действия, сетка кнопок, второй экран (своя графика PS + AI) | ряд, столбик, сетка (Arrangements), переходы между экранами, много Click, смена картинки |

### Модуль 7 — Сайты на Bootstrap (7 уроков, 14 ч)

Знакомство с вебом «на результат»: подключаем **Bootstrap** по CDN и собираем красивый адаптивный сайт из готовых компонентов, почти без ручного CSS. Немного базового HTML нужно, чтобы понимать структуру страницы; всё оформление — готовыми классами Bootstrap. Глубокая вёрстка (CSS с нуля, Flexbox/Grid, Figma, JS) — отдельный веб-курс следующего года.

| Урок | Тема и проект | Приёмы |
|------|---------------|--------|
| 1 | Как устроены сайты; первая страница + подключение Bootstrap | HTML-скелет (теги, заголовки, абзацы), подключение Bootstrap по CDN, Live Server |
| 2 | Готовые блоки и типографика → «О себе» | контейнеры (`container`), типографика, кнопки, бейджи, иконки (Bootstrap Icons) |
| 3 | Сетка и адаптивность → страница под телефон и ПК | grid-система (`row`/`col`), брейкпоинты (`col-md-…`), адаптивные колонки |
| 4 | Карточки и утилиты → галерея карточек | `card`, кнопки, утилиты отступов/цвета/тени (`m-`, `p-`, `bg-`, `shadow`), hover |
| 5 | Навбар и компоненты → шапка сайта и меню | `navbar`, `nav`, `collapse` (бургер), готовые компоненты (alert, badge, list-group) |
| 6 | Форма и модальное окно → форма обратной связи | формы Bootstrap, валидация, `modal`, всплывающие уведомления |
| 7 | Сайт-портфолио и публикация | сборка одностраничника из компонентов, тема/цвета, деплой (GitHub Pages), защита |

### Модуль 8 — Своя игра на движке: Roblox Studio (5 уроков, 10 ч)

Настоящий игровой движок: собрать и опубликовать свою игру (замена Python — он есть в отдельном курсе).

| Урок | Тема и проект | Приёмы |
|------|---------------|--------|
| 1 | Интерфейс Roblox Studio, части, ландшафт → своя карта | Parts, материалы, рельеф |
| 2 | Свойства, якоря, механики → полоса препятствий (obby) | физика, чекпоинты |
| 3 | Скрипты Lua: события, переменные → ловушки, кнопки, очки | основы Lua, события |
| 4 | Игровая логика: спавн, счёт, таблица лидеров → мини-игра | переменные, лидерборд |
| 5 | Своя игра → публикация в Roblox и защита | публикация, тест, презентация |

По желанию группы Roblox можно заменить на Construct 3 (2D-игры) из банка дополнительных тем.

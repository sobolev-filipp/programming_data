# 🎯 Практика — Урок 1: «Дай приложению лицо»

> Практика — это **не повтор урока**, а новый вызов. Сегодня ты нарисуешь приложению **свою иконку в Illustrator** (как у настоящих приложений в маркете) и прокачаешь его отклик. Комбинируем **графику (Illustrator) + приложение (App Inventor)** — это и есть сила нашего курса.

Открой свой проект `MyFirstApp` (или сделай копию `Projects → Save project as… → MyFirstApp_v2`, чтобы урочный вариант остался цел).

---

## 🚀 Новый вызов — «Иконка приложения» (Illustrator → App Inventor)

У каждого приложения на телефоне есть **иконка** — маленькая картинка-«лицо». Сделаем свою.

### Часть A — Рисуем иконку в Illustrator

1. Создай документ **512 × 512 px** (File → New, единицы — пиксели).
2. **Цветной фон:** нарисуй скруглённый квадрат на весь холст (`Rounded Rectangle Tool`), залей ярким цветом или градиентом.
3. **Один простой символ** по центру: молния ⚡, робот 🤖, кнопка, ракета, буква твоего имени. Инструменты: `Ellipse`, `Rectangle`, `Shape Builder`, `Pen`.
4. Правило хорошей иконки: **крупный символ, минимум мелких деталей, читается издалека**.
5. Экспорт: `File → Export → Export As…` → формат **PNG** → `icon.png`.

> 💡 **Почему просто?** Иконку видно размером с ноготь. Всё мелкое сольётся. Сильные иконки = 1 форма + 1–2 цвета (вспомни Telegram, Instagram — простые).

### Часть B — Ставим иконку в приложение

1. В App Inventor открой **Дизайнер**, выдели в Компонентах **`Screen1`**.
2. В Свойствах найди **`Icon`** (Иконка) → `Upload File…` → выбери `icon.png`.
3. Эту же картинку можно поставить в **`Image1`** на экране (`Picture` → выбрать `icon.png`).
4. 👀 На телефоне через Companion иконку внутри увидишь сразу; как иконку на рабочем столе — когда соберём `.apk` в конце модуля.

## 🔗 Комбо — «Кнопка-настроение» (собираем навыки вместе)

Прокачай логику из урока: пусть кнопка меняет **сразу несколько вещей**.

1. Добавь вторую кнопку `Button2` с текстом **«Сбросить»**.
2. В **Blocks** собери (интерфейс — на English, блоки английские):
   - `when Button1.Click do` → `set Label2.Text to "Отличный день! 😄"` **и** `set Label2.TextColor to` (зелёный) **и** `set Image1.Picture to "icon.png"`.
   - `when Button2.Click do` → `set Label2.Text to "Здесь появится ответ"` **и** вернуть цвет/картинку как было.
3. 👀 Теперь одна кнопка «включает настроение», вторая — «сбрасывает». Это уже **два события** в одном приложении.

> 🧠 **Что закрепили:** несколько действий в одном событии, работа с разными свойствами (`Text`, `TextColor`, `Picture`), несколько кнопок.

## ⚡ Разминка-челлендж (на скорость)

Кто быстрее и аккуратнее:

- **«Три свойства за минуту»:** поменяй у `Button1` цвет фона, размер шрифта и форму (`Shape` → rounded) — уложись в минуту.
- **«Слепой поиск»:** учитель называет компонент (`Slider`, `CheckBox`, `Switch`) — найди его в Палитре за 10 секунд. Кто первый показал — балл.
- **«Ре-коннект»:** отключи Companion и подключись заново по QR быстрее соседа.

## 🧩 Полегче (если сложно)

- Иконку можно сделать **проще**: цветной фон + одна буква твоего имени крупным шрифтом. Этого достаточно.
- Комбо-часть пропусти — хватит одной кнопки из урока. Главное — **поставить свою иконку** и увидеть её на телефоне.

## 🎓 Посложнее (если легко)

- Сделай **счётчик нажатий**: `initialize global n to 0`, при клике `set global n to (get global n + 1)`, а в `set Label2.Text to` через блок `join` покажи `"Нажато раз: " + get global n`.
- Добавь **`Sound`** (по нажатию `call Sound1.Play`) и **`Switch`** (переключатель «День/Ночь»), который меняет `set Screen1.BackgroundColor to`.
- Придумай приложению **имя и тему** (визитка, счётчик, «кнопка радости») — это заготовка твоего итогового проекта модуля.

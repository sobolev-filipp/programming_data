# 🧰 Лайфхаки урока 1 (App Inventor)

Короткие трюки, которые экономят время и нервы. Интерфейс — всегда **English**.

## 📲 Тест без телефона — эмулятор
Нет телефона или Wi-Fi? В App Inventor есть **виртуальный телефон**:
- `Connect → Emulator`. Первый раз попросит поставить **aiStarter** (маленькая программа на ПК) — учитель ставит заранее.
- Эмулятор медленнее живого телефона, но для проверки блоков хватает.

## 🔄 Companion «завис» — быстрый ре-коннект
- `Connect → Reset Connection`, потом снова `Connect → AI Companion`.
- Каждый раз генерируется **новый QR/код** — старый не подходит, сканируй свежий.
- 90% проблем = **телефон и ПК в разных сетях**. Проверь Wi-Fi в первую очередь.

## 📐 `Fill parent` / `Automatic` / `Pixels`
Управление размером компонента (`Width`/`Height`):
- **`Automatic`** — по содержимому (кнопка по длине текста).
- **`Fill parent`** — растянуть на всю ширину/высоту.
- **`Pixels`** — точный размер числом.
Хочешь кнопку во весь экран → `Fill parent`.

## 🧱 Ровная раскладка — Arrangements
Компоненты по умолчанию падают **сверху вниз**. Чтобы поставить их **в ряд** или сеткой:
- Palette → **`Layout`** → перетащи **`HorizontalArrangement`** (в ряд) или **`VerticalArrangement`** (столбиком), а внутрь клади кнопки/картинки.
- Так делают панели и меню.

## 🏷 Переименуй компоненты сразу
`Button1`, `Label2` — трудно не запутаться. В **Components** → **`Rename`** дай понятные имена: `BtnHello`, `LblAnswer`. В блоках их имена станут читаемыми.

## 🎨 Цвет — не только из списка
В свойстве цвета внизу есть **`Custom…`** — можно задать любой оттенок (и прозрачность). Пригодится для фирменного стиля приложения.

## 💾 Про сохранение
- Проект сохраняется **сам** в облаке Google. Кнопки «Save» искать не нужно.
- Но перед важным изменением делай копию: `Projects → Save project as…` — если сломал, вернёшься к рабочей версии.
- Забрать проект файлом: `Projects → Export selected project (.aia)`.

## ⌨️ Мелкие ускорители Blocks
- **ПКМ по блоку → Duplicate** — копия блока (не собирай заново).
- **ПКМ по пустому полю → Clean up Blocks** — аккуратно выстроит все блоки.
- **Перетащить блок в корзину** 🗑 (внизу справа) — удалить.
- **ПКМ → Add Comment** — подписать блок (полезно в больших проектах).

> 💡 Золотое правило теста: **сначала маленький кусок → проверил на телефоне → потом дальше.** Так ошибку видно сразу, а не в конце.

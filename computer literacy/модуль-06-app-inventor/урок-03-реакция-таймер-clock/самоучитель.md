# 🆘 Самоучитель — Урок 3 «Реакция» (таймер, счёт, случайность)

Пройди по порядку: 🟢 подробно → 🟡 коротко → 🔴 сам. Интерфейс App Inventor — **English**, блоки английские.

> 🌐 [appinventor.mit.edu](https://appinventor.mit.edu/) → Create Apps! · проект `ReactionGame`.
> 🎁 Готовые ассеты (цель, арена) — в `материалы/ассеты/`.

---

## 🟢 Ступень 1 — «Разбираемся»

**1. Загрузи ассеты.** `Media → Upload File…`: `target.png`, `background.png` (и `target_gold.png`, если будешь делать бонус).

**2. Фон и заголовок.** `Screen1` → `BackgroundImage = background.png`, `Title = "Реакция"`.

**3. Панель (ряд).** `HorizontalArrangement` наверх → внутрь две `Label`: `LblTime` (`"Время: 15"`) и `LblScore` (`"Счёт: 0"`).

**4. Цель.** `Button` по центру → переименуй `BtnTarget`, `Image = target.png`, `Text` пусто, `Enabled = false`.

**5. Старт и результат.** `Button` `BtnStart` (`"▶ Старт"`), `Label` `LblResult` (пусто).

**6. Часы.** Palette → `Sensors` → `Clock` → `Clock1`: `TimerInterval = 1000`, `TimerEnabled = false`.

**7. Переменные.** `Blocks` → `Variables`: `initialize global score to 0`, `initialize global time to 15`.

**8. Кнопка «Старт».** `when BtnStart.Click do`: обнули `score`/`time`, обнови обе `Label`, очисти `LblResult`, `set BtnTarget.Enabled to true`, `set Clock1.TimerEnabled to true`.

**9. Проверь.** Пока таймер не тикает в блоках — но кнопка «Старт» уже должна включать `Clock1`. (Тик добавим дальше.)

---

## 🟡 Ступень 2 — «Закрепляем»

**10.** Цель: `when BtnTarget.Click do → set global score to (score + random integer from 1 to 3)` → обнови `LblScore` через `join`.

**11.** Таймер: `when Clock1.Timer do → set global time to (time − 1)` → обнови `LblTime` через `join`.

**12.** Окончание: внутри `Clock1.Timer` добавь `if (time ≤ 0) then`: выключи `Clock1.TimerEnabled`, выключи `BtnTarget.Enabled`, покажи результат в `LblResult`.

**13.** Тест на телефоне: «Старт» → отсчёт, лови цель, на нуле — результат.

**14.** Сыграй пару раз: убедись, что «Старт» **обнуляет** счёт и время.

---

## 🔴 Ступень 3 — «Проверь себя»

**15.** Сделай `TimerInterval = 500` — время идёт вдвое быстрее. Что поменялось в ощущении?

**16.** Добавь «золотую цель»: `random integer 1..5`, если `= 1` → `+5` и картинка `target_gold.png` (`if/else`).

**17.** Заведи `global best` (рекорд) и показывай его в результате, если счёт больше прежнего.

**18.** Экспортируй `.aia` и сохрани скриншот игры на телефоне.

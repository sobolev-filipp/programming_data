# 🧰 Лайфхаки урока 3 (таймер, счёт, случайность)

## ⏱ Clock — три вещи, которые надо помнить
- **`TimerInterval`** — в **миллисекундах**: `1000` = раз в секунду, `500` = дважды, `100` = 10 раз.
- **`TimerEnabled`** — рубильник: `true` тикает, `false` стоит. Держи `false` в Дизайнере, включай в «Старт».
- **`Clock.Timer`** — событие «прошёл интервал». Весь «поштучный» ход времени — здесь.
- Можно поставить **несколько Clock** с разными интервалами (один — отсчёт, другой — анимация).

## 🔢 join — склейка текста и чисел
- Надпись «Счёт: 7» = `join("Счёт: ", score)` (категория `Text`).
- Числа **не** приклеивают через `+` (это сложение). Текст — только `join`. Можно несколько: `join("Счёт: ", score, " · Рекорд: ", best)`.

## 🎲 random — случайность
- `random integer from 1 to 6` — «кубик»: целое число в диапазоне.
- `random fraction` — дробь 0..1. `random set seed` — фиксировать «случайность» для отладки.
- Хочешь случайный элемент из списка — `pick a random item` (списки — урок 4/7).

## 🛡 Мелкие «античиты» и баги
- **Цель до старта не жать:** `BtnTarget.Enabled = false` в Дизайнере, `true` — в «Старт», снова `false` — в конце.
- **Время в минус:** обязательно `set Clock1.TimerEnabled to false` при `time ≤ 0`. Иначе тикает вечно.
- **Двойной старт:** если жать «Старт» во время игры — просто обнуляется. Это нормально (перезапуск).
- **Сброс:** всё, что должно «начинаться заново», обнуляй **в «Старт»** (score, time, картинку цели, результат).

## ⚡ Темп = один параметр
Сложность игры регулируется в основном **`TimerInterval`** и стартовым `time`. Меняешь два числа — получаешь «легко/норма/хард». Не нужно переписывать логику.

## 🏆 Рекорд и статистика
- `global best` — храни лучший счёт (в конце: `if score > best then best = score`).
- Между запусками рекорд теряется — сохраним в **`TinyDB`** (урок 7).

# 🧰 Лайфхаки урока 2 (раскладки, экраны, графика)

## 🧱 Раскладки — каркас любого экрана
- **`HorizontalArrangement`** — в ряд, **`VerticalArrangement`** — в столбик, **`TableArrangement`** — сетка (`Rows`/`Columns`).
- **Вкладывай раскладки друг в друга:** ряд внутри столбика, сетка внутри ряда — так строят сложные макеты.
- Хочешь центр? У раскладки `AlignHorizontal = Center`, `AlignVertical = Center`, а `Width = Fill parent`.
- Нужен «воздух» между элементами — компонент `Layout → HorizontalArrangement` пустой как распорка, или свойство `Spacing`/пустой `Label`.

## 🖥 Экраны — правила без багов
- **Каждый экран самостоятелен:** свои компоненты, свои блоки. Собираешь блоки — сначала **переключись на нужный экран** (список вверху).
- **Назад = `close screen`** (закрывает текущий, возвращает на предыдущий). Не открывай Screen1 через `open another screen` для возврата — экраны будут копиться «стопкой» и съедать память.
- **Передать данные:** `open another screen with start value` (отправить) + `get start value` (принять на `Screen.Initialize`). Для больших данных — `TinyDB` (урок 7).
- `Screen1` — всегда стартовый, переименовать нельзя. Остальные называй понятно (`ProfileScreen`, `GameScreen`).

## 🖼 Графика — размеры и вес
- Настроения питомца — PNG **с прозрачностью**, одинакового размера (чтобы не «прыгали» при смене).
- Держи имена в одном стиле: `pet.png`, `pet_happy.png`, `pet_eat.png` — легко подставлять в блоки.
- Иконки — вектор из Illustrator, экспорт крупным PNG, в приложении `Width/Height` ~90 px.

## 🏷 Именуй компоненты сразу
`Button1..6` → путаница в сетке. Переименуй по действию: `BtnFeed`, `BtnPlay`, `BtnSleep`. В блоках сразу понятно, какая кнопка что делает.

## ⚡ Дублируй обработчики
Реакции похожи (`set PetImage.Picture to "…"`). Собрал одну — **ПКМ → Duplicate**, поменяй имя кнопки и файл. Быстрее, чем собирать заново.

## 🔊 Реакция «богаче»
В один `Click` можно положить **несколько** действий: сменить картинку **и** проиграть звук **и** сказать фразу. Порядок сверху вниз.

## 🎨 Пайплайн ассета (повтор-маршрут)
**Photoshop/Illustrator → Export PNG → App Inventor `Media` → `Picture`/`Image`/`BackgroundImage`.** Один путь для любой картинки во всех уроках.

> 💡 Тестируй по кусочку: собрал панель → проверил; добавил сетку → проверил; сделал 2-й экран → проверил переход. Так баг видно сразу.

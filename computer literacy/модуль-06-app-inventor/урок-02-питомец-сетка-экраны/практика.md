# 🎯 Практика — Урок 2: «Прокачай питомца»

> Практика — не повтор урока, а новый вызов. Усилим **раскладки, экраны и графику**: добавим настроения, экран-игру и «передачу данных» между экранами.

Открой проект `MyPet` (или копию: `Projects → Save project as… → MyPet_v2`).

---

## 🚀 Новый вызов — «Экран-игра: покорми питомца»

Сделаем **третий экран** с мини-игрой и научимся **передавать данные между экранами**.

1. **`Add Screen…` → `GameScreen`.** На нём: питомец (`Image`), надпись-счёт (`Label`), кнопка «🍖 Кормить».
2. **Blocks (GameScreen):** `initialize global fed to 0`; `when BtnFeed.Click do → set global fed to (get global fed + 1)` → `set LabelScore.Text to (join "Покормлен: " (get global fed))` → `set PetImage.Picture to "pet_eat.png"`.
3. **Навигация:** на Screen1 кнопка «Играть» → `open another screen "GameScreen"`; на GameScreen кнопка «◀» → `close screen`.
4. 👀 Отдельный экран-игра со своим счётом. Так растут настоящие приложения — по экранам.

> 🧠 **Что закрепили:** третий экран, переменная-счёт, `join` (склейка текста), навигация.

---

## 🖥 Комбо — «Имя питомца между экранами»

Пусть профиль показывает **имя, которое ты ввёл**.

1. На Screen1 добавь `TextBox` (`TxtName`) и кнопку «Сохранить имя».
2. Переход в профиль передаёт имя: `open another screen with start value` → значение `TxtName.Text`.
3. На Screen2 при старте: `when Screen2.Initialize do → set LabelName.Text to (get start value)`.
4. 👀 Ввёл «Мурзик» на главной → в профиле написано «Мурзик». Экраны **обменялись данными**.

---

## 🎨 Графика-комбо — «Больше настроений» (Photoshop/Illustrator)

1. В **Photoshop** сделай ещё 2 настроения питомца: `pet_wash.png` (в пене), `pet_love.png` (сердечки). *(Слои, кисти, маска.)*
2. В **Illustrator** — иконку новой кнопки (🛁 «мыть»). Экспорт PNG.
3. Подключи: `when BtnWash.Click do → set PetImage.Picture to "pet_wash.png"`.
4. 👀 Питомец умеет больше — и всё это **твоя** графика.

---

## ⚡ Разминка-челлендж (на скорость)

- **«Идеальная сетка»:** заверни 6 кнопок в `TableArrangement` 3×2, выровняй, одинаковые размеры — за 3 минуты.
- **«Ряд + столбик»:** собери верхнюю панель из `HorizontalArrangement`, а сбоку — `VerticalArrangement` с двумя кнопками.
- **«Туда-обратно»:** сделай навигацию Screen1 ⇄ Screen2 так, чтобы «Назад» всегда работал (`close screen`).

---

## 🧩 Полегче (если сложно)
- Хватит **двух** настроений (`pet.png`, `pet_happy.png`) и сетки **2×2**.
- Второй экран — только надпись «Профиль» и кнопка «Назад». Главное — **переход работает**.

## 🎓 Посложнее (если легко)
- **«Сытость тает».** Заготовка к уроку 3: добавь `Clock` (пока не трогаем — только положи компонент) и придумай, как питомец мог бы «хотеть есть» со временем.
- **Тема оформления:** переключатель `Switch` меняет фон день/ночь (`Screen1.BackgroundImage`).
- **Звук на каждое действие:** свой короткий звук в `Sound` для «поел», «поиграл».

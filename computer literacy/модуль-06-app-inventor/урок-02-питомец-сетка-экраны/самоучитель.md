# 🆘 Самоучитель — Урок 2 «Мой питомец» (раскладки, сетка, экраны)

Пройди по порядку: 🟢 подробно → 🟡 коротко → 🔴 сам. Интерфейс App Inventor — **English**, блоки английские.

> 🌐 [appinventor.mit.edu](https://appinventor.mit.edu/) → Create Apps! · проект `MyPet`.

---

## 🟢 Ступень 1 — «Разбираемся»

**1. Ассеты в Adobe.** Photoshop: питомец `pet.png` + `pet_happy.png` (PNG-прозрачность) + фон `background.png`. Illustrator: 2–3 иконки-кнопки (PNG).

**2. Загрузи ассеты.** App Inventor → `Media → Upload File…` — залей все PNG.

**3. Фон экрана.** `Screen1` → `BackgroundImage = background.png`, `Title = "Мой питомец"`.

**4. Верхняя панель (РЯД).** Palette → `Layout` → перетащи **`HorizontalArrangement`** наверх. Внутрь: `Label` (имя питомца) и `Button` `BtnSettings` (`Image = btn-settings.png`).

**5. Питомец.** Перетащи `Image` под панель, переименуй в `PetImage`, `Picture = pet.png`, покрупнее.

**6. Сетка кнопок (СЕТКА).** Palette → `Layout` → **`TableArrangement`**, задай `Columns = 3`, `Rows = 2`. Внутрь — кнопки с иконками, `Text` очисти, переименуй `BtnFeed`, `BtnPlay`, `BtnSleep`, `BtnPet`, `BtnTalk`.

**7. Невидимые.** Palette → `Media` → перетащи `Sound` (`Sound1`) и `TextToSpeech` (`TextToSpeech1`).

**8. Первая реакция.** `Blocks` → `BtnPlay`: `when BtnPlay.Click do → set PetImage.Picture to "pet_happy.png"`.

**9. Ещё реакции.** По образцу: `BtnFeed` → `pet_eat.png`; `BtnSleep` → `pet_sleep.png`. *(ПКМ → Duplicate ускоряет.)*

---

## 🟡 Ступень 2 — «Закрепляем»

**10.** `BtnTalk`: `when BtnTalk.Click do → call TextToSpeech1.Speak message "Мяу! Привет!"`.

**11.** Добавь второй экран: вверху `Add Screen…` → `Screen2`. Собери на нём `Label` «Профиль», `Image` питомца, кнопку `BtnBack` («◀ Назад»).

**12.** Навигация: на Screen1 `when BtnSettings.Click do → open another screen screenName "Screen2"`.

**13.** На Screen2: `when BtnBack.Click do → close screen`. *(Блоки собираешь, переключившись на Screen2!)*

**14.** Проверь на телефоне: реакции питомца + переход на профиль и назад.

---

## 🔴 Ступень 3 — «Проверь себя»

**15.** Сделай сетку кнопок ровной 3×2, все кнопки одного размера, панель имени — на всю ширину.

**16.** Добавь кнопку «мыть» с новым настроением питомца (`pet_wash.png` из Photoshop).

**17.** Передай имя питомца с TextBox на Screen2 (`open another screen with start value` → `get start value`).

**18.** Экспортируй `.aia` и сохрани скриншоты обоих экранов.

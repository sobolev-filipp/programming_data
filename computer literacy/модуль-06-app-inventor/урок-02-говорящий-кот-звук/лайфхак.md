# 🧰 Лайфхаки урока 2 (звук, речь, своя графика)

## 🖼 Своя графика — правильные размеры
- **Кот и любые «наклейки»** — PNG **с прозрачностью** (иначе будет белый прямоугольник поверх фона).
- **Фон экрана** — вертикаль ~**1080×1920**, чтобы не растягивался.
- **Иконки кнопок** — квадрат (например 512×512), потом в приложении задай `Width/Height` ~90 px.
- Экономь вес: иконки и наклейки экспортируй в **PNG-8** или ужимай — приложение будет легче.

## 🔤 Имя файла = имя в блоке
- В блоке `set Sound1.Source to "meow.mp3"` имя должно **точно** совпадать с тем, что в `Media` — **включая расширение** и регистр.
- Совет: имена файлов — **латиницей, без пробелов** (`meow.mp3`, а не `мяу 1.mp3`).

## 🔊 Sound vs Player
- **`Sound`** — для **коротких** эффектов (мяу, клик), до ~5 сек. Мгновенно.
- **`Player`** — для **длинных** треков (музыка), с паузой/громкостью/повтором.
- Кнопка-звук → `Sound`. Фоновая музыка → `Player`.

## 🗣 TextToSpeech (речь без микрофона)
- `call TextToSpeech1.Speak message "…"` — телефон **произносит** текст. Микрофон не нужен.
- Русский голос: должен быть установлен в системе (Настройки → Язык/Синтез речи). Нет русского — фраза на английском сработает всегда.
- Свойства `Pitch` (высота) и `SpeechRate` (скорость) — сделай коту смешной «мультяшный» голос: `Pitch` повыше.

## 🧱 Ровные кнопки — Arrangements
- `HorizontalArrangement` — в ряд, `VerticalArrangement` — столбиком, `TableArrangement` — сеткой (для доски 2×2, 3×3).
- Внутри Arrangement выставляй `AlignHorizontal/Vertical = Center`, а самому Arrangement можно `Width = Fill parent`.

## 🏷 Именуй компоненты сразу
`Button1/Button2` → путаница. Переименуй: `BtnMeow`, `BtnPurr`, `BtnSay`. В блоках имена станут читаемыми — не перепутаешь, какая кнопка что делает.

## ⚡ Дублируй блоки
Кнопки похожи (set Source + call Play). Собрал одну связку → **ПКМ → Duplicate** → поменяй имя кнопки и файл. Быстрее, чем собирать заново.

## 🎨 Пайплайн ассета (запомни маршрут)
**Photoshop/Illustrator → Экспорт PNG → App Inventor `Media` → свойство `Picture`/`Image`/`BackgroundImage`.** Один и тот же путь для любой картинки в любом уроке модуля.

> 💡 Тестируй по кусочку: сделал одну кнопку → проверил на телефоне → дальше. Так сразу видно, если имя файла не совпало.

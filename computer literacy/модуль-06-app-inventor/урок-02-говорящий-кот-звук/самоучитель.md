# 🆘 Самоучитель — Урок 2 «Говорящий кот» (App Inventor + Adobe)

Пройди по порядку: 🟢 подробно → 🟡 коротко → 🔴 сам. Интерфейс App Inventor — **English**. Блоки пишем по-английски.

> 🌐 [appinventor.mit.edu](https://appinventor.mit.edu/) → Create Apps! · проект `TalkingCat`.

---

## 🟢 Ступень 1 — «Разбираемся»

**1. Кот в Photoshop.** Открой фото → `Выделение → Предмет` → удали фон → `Экспортировать как → PNG` (прозрачность) → `cat.png`.

**2. Фон в Photoshop.** Новый документ 1080×1920 → залей цветом/градиентом → PNG → `background.png`.

**3. Иконка в Illustrator.** Артборд 512×512 → круг + символ (лапка) → `Экспорт → PNG` → `btn-meow.png`. Сделай ещё 1–2 иконки.

**4. Загрузи ассеты.** App Inventor → раздел `Media` → `Upload File…` → залей все PNG и звук `meow.mp3`.

**5. Фон экрана.** `Screen1` → Properties → `BackgroundImage` = `background.png`.

**6. Кот на экран.** Перетащи `Image` → `Picture` = `cat.png`, размер покрупнее.

**7. Ряд кнопок.** Palette → `Layout` → `HorizontalArrangement` под кота. Внутрь — `Button`, у него `Image` = `btn-meow.png`, `Text` очисти. Переименуй в `BtnMeow`.

**8. Невидимые компоненты.** Palette → `Media` → перетащи `Sound` (станет `Sound1`) и `TextToSpeech` (`TextToSpeech1`).

**9. Первый блок звука.** `Blocks` → `BtnMeow`: собери `when BtnMeow.Click do` → внутрь `set Sound1.Source to "meow.mp3"` → `call Sound1.Play`.

---

## 🟡 Ступень 2 — «Закрепляем»

**10.** Добавь вторую кнопку `BtnSay` со своей иконкой.

**11.** Собери речь: `when BtnSay.Click do → call TextToSpeech1.Speak message "Привет! Я говорящий кот!"`.

**12.** Подключи телефон (`Connect → AI Companion`, QR, одна Wi-Fi) и проверь: кнопки играют звук и кот говорит.

**13.** Если TTS молчит/акцент — проверь русский голос в настройках телефона (или поставь фразу на английском).

**14.** Сделай кнопки одинакового размера (`Width`/`Height` = 90 pixels) и выровняй ряд по центру.

---

## 🔴 Ступень 3 — «Проверь себя»

**15.** Добавь третью кнопку с другим звуком (`purr.mp3`) — по образцу `BtnMeow`.

**16.** Сделай **кота-повторюшку**: `TextBox` + кнопка → кот произносит введённый текст (`TextBox1.Text`).

**17.** По нажатию одной из кнопок меняй вид кота на `cat_happy.png` (сделай второй костюм в Photoshop).

**18.** Экспортируй проект `.aia` и сохрани скриншоты своих ассетов (кот + иконка).

---

## Главные мысли

1. **Кортеж `(...)`** — список, который НЕЛЬЗЯ менять (круглые скобки).
2. Читать можно: индекс, `len`, срез, `in`, перебор. Менять — нет.
3. **Распаковка:** `x, y = point` — разложить по переменным.
4. Обмен: `a, b = b, a`. В цикле: `for x, y in points`.
5. Функция возвращает несколько значений — это кортеж (`return a, b`).

---

## Кортеж vs список

```python
lst = [1, 2, 3]     # список — квадратные [ ], можно менять
tpl = (1, 2, 3)     # кортеж — круглые ( ), менять НЕЛЬЗЯ

lst[0] = 9          # ок
tpl[0] = 9          # TypeError!
```

Читается одинаково: `tpl[0]`, `len(tpl)`, `tpl[1:]`, `for x in tpl`.

⚠️ Кортеж из одного: `(5,)` — с запятой! `(5)` — просто число.

---

## Распаковка

```python
point = (3, 5)
x, y = point            # x=3, y=5

a, b = b, a             # обмен местами

for x, y in points:     # распаковка в цикле
    ...
```

## Функция возвращает кортеж

```python
def min_max(nums):
    return min(nums), max(nums)

low, high = min_max([7, 2, 9])   # 2, 9
```

---

## Зачем кортеж

- Координаты `(x, y)`, цвет `(255, 128, 0)`, дата — то, что не меняется.
- 🎓 Кортеж может быть КЛЮЧОМ словаря (список — нет).

## 🐢 Художник по точкам (10 заданий)

Готова `house` — список вершин-кортежей. Команды `move_to(p)`, `line_to(p)`, `dot(p)`.

```python
move_to(house[0])
for point in house:
    line_to(point)
```

Сдвиг/отражение — распакуй и собери новый кортеж:
```python
for point in house:
    x, y = point
    line_to((x + 4, y))     # нельзя менять — создаём новое
```

---

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| `TypeError` при `tpl[0]=..` | кортеж заморожен | собери новый кортеж |
| `(5)` — число | нет запятой | `(5,)` |
| `too many values` | имён меньше, чем в кортеже | слева столько же имён |

---

## Что должно остаться в голове

1. Кортеж `( )` — заморожен; список `[ ]` — меняется.
2. Распаковка: `x, y = point`.
3. Обмен: `a, b = b, a`.
4. `return a, b` — вернуть несколько значений.
5. 🐢 фигуру двигаем, собирая НОВЫЙ кортеж `(x+4, y)`.

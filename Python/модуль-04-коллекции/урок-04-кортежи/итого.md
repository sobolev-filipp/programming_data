## Главные мысли

1. **Кортеж `(...)`** — неизменяемая последовательность (круглые скобки).
2. Читать можно: индекс, `len`, срез, `in`, перебор. Менять — нет.
3. **Распаковка:** `x, y = point` — разложить по переменным.
4. Обмен: `a, b = b, a`. В цикле: `for x, y in points`.
5. Функция возвращает несколько значений — это кортеж (`return a, b`).

---

## Кортеж vs список

```python
lst = [1, 2, 3]     # список — квадратные [ ], можно менять
tpl = (1, 2, 3)     # кортеж — круглые ( ), менять НЕЛЬЗЯ

lst[0] = 9          # ок
tpl[0] = 9          # TypeError!
```

Читается одинаково: `tpl[0]`, `len(tpl)`, `tpl[1:]`, `for x in tpl`.

 Кортеж из одного: `(5,)` — с запятой! `(5)` — просто число.

---

## Распаковка

```python
point = (3, 5)
x, y = point            # x=3, y=5

a, b = b, a             # обмен местами

for x, y in points:     # распаковка в цикле
    ...
```

## Готовая функция может отдать пару

```python
q, r = divmod(17, 5)    # divmod вернул кортеж (3, 2)
print(q, r)             # 3 2
```

---

## Зачем кортеж

- Координаты `(x, y)`, цвет `(255, 128, 0)`, дата — то, что не меняется.
- `divmod` и другие готовые функции возвращают сразу пару — кортеж.

---

## Рисуем по клеткам

```python
column((3, 5))  # две точки в столбце 0
column(())      # пропуск столбца 1
column((4,))    # одна точка в столбце 2
```

Каждый вызов переходит на следующий столбец. В цикле можно вычислять высоту: `column((i + 1,))`. Файл [рисуем_по_клеткам.py](материалы/рисуем_по_клеткам.py), задания — в [практике](практика.md).

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| `TypeError` при `tpl[0]=..` | кортеж заморожен | собери новый кортеж |
| `(5)` — число | нет запятой | `(5,)` |
| `too many values` | имён меньше, чем в кортеже | слева столько же имён |

---

## Что должно остаться в голове

1. Кортеж `( )` — заморожен; список `[ ]` — меняется.
2. Распаковка: `x, y = point`.
3. Обмен: `a, b = b, a`.
4. `return a, b` — вернуть несколько значений.
5. В графическом практикуме кортеж задаёт высоты точек в столбце.

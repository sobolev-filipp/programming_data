# Разминка перед уроком 4 (5 минут) 🔁

> Повторяем списки, срезы и индексы (Уроки 1–3). Устно или в `проба.py`.

---

## 1. Блиц-вопросы (устно)

1. В каких скобках записывают список? *(квадратные `[ ]`)*
2. Что вернёт `lst[0]`? *(первый элемент)*
3. Как взять последние 3 элемента? *(`lst[-3:]`)*
4. Можно ли изменить элемент списка (`lst[0] = 9`)? *(да, список изменяемый)*
5. Можно ли изменить букву строки (`word[0] = "X"`)? *(нет, строка неизменяемая)*

---

## 2. Предскажи вывод

```python
point = [3, 5]
point[0] = 10
print(point)
x = point[0]
y = point[1]
print(x, y)
```

<details><summary>Ответ</summary>

`[10, 5]` · `10 5`.
</details>

---

## 3. Подумай

```python
# хотим взять x и y из точки одной строкой
point = [3, 5]
# ... как получить сразу x=3 и y=5?
```

<details><summary>Идея</summary>

Можно `x = point[0]; y = point[1]` — две строки. Сегодня узнаем короче: **распаковку** `x, y = point` — сразу два имени. И познакомимся с **кортежем** — «замороженным» списком для координат.
</details>

---

## 4. Мостик к теме

Список изменяемый — это хорошо, но иногда данные должны быть **постоянными**: координата точки, цвет, дата. Для такого есть **кортеж** — список в круглых скобках, который нельзя менять. Сегодня — кортежи, распаковка и рисование фигур по точкам. 🔒

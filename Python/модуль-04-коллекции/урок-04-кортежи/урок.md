## Что мы сделаем сегодня и что получим (3 минуты)

В прошлых уроках мы работали со списками: добавляли элементы, удаляли их и меняли местами. Но представим, что в игре нужно хранить положение героя: `x = 4`, `y = 7`. Эти два числа относятся к одной точке. Можно объединить их в одну запись `(4, 7)`. Это **кортеж**.

К концу занятия ученик сможет создать кортеж, обратиться к элементам по индексу, сделать срез, перебрать элементы, распаковать координаты и передать кортеж функции. Итоговый файл — `материалы/рисуем_по_клеткам.py`: ученик указывает кортеж высот, программа рисует точки в очередном столбце.

## Часть 0 — Разминка: когда список неудобен (5 минут)

Предложите ребятам представить координаты персонажа. Сначала используем список:

```python
position = [4, 7]
print(position)
position[0] = 100
print(position)
```
Получим `[4, 7]`, а затем `[100, 7]`. Изменение сработало. Иногда это полезно, но координаты конкретной точки, дату рождения или цвет, выбранный для оформления, мы хотим передавать как готовую запись. Здесь пригодится кортеж. **Важно:** кортеж не делает переменную навсегда постоянной: он запрещает изменять элементы самого объекта.

## Часть 1 — Создаём кортеж и отличаем его от списка (12 минут)

Кортеж (`tuple`) — упорядоченная последовательность элементов. В отличие от списка, элементы самого кортежа нельзя заменить, добавить или удалить. В нём можно хранить числа, строки и другие объекты. Порядок сохраняется, одинаковые значения разрешены.


### Список и кортеж рядом

```python
colors_list = ["red", "green", "blue"]
colors_tuple = ("red", "green", "blue")
print(type(colors_list))
print(type(colors_tuple))
```

**Результат:**

```text
<class 'list'>
<class 'tuple'>
```

Квадратные скобки создают список, а запись значений через запятые — кортеж. Круглые скобки обычно делают запись понятнее.

**Проверь себя.** Создай кортеж из трёх любимых игр и выведи его тип.

### Кортеж без скобок

```python
point = 4, 7
print(point)
print(type(point))
```

**Результат:**

```text
(4, 7)
<class 'tuple'>
```

Python ориентируется прежде всего на **запятые**. Поэтому `4, 7` — тоже кортеж. Но для читаемости курса используем `(4, 7)`.

### Пустой кортеж и один элемент

```python
empty = ()
one = (5,)
not_tuple = (5)
print(len(empty))
print(type(one))
print(type(not_tuple))
```

**Результат:**

```text
0
<class 'tuple'>
<class 'int'>
```

В `(5,)` запятая обязательна. Запись `(5)` — просто число в скобках. Это одна из самых частых ошибок начинающих.
**Обсудим:** зачем нужен кортеж из одного элемента? Например, функция `column((5,))` получает именно последовательность высот, даже если точка только одна.

## Часть 2 — Индексы, отрицательные индексы и срезы (12 минут)

У кортежа, как и у списка, индексация начинается с нуля. Отрицательный индекс отсчитывает элементы справа налево. По индексу получаем **один элемент**, а срезом — **новый кортеж**.


### Читаем координаты и элементы

```python
player = ("Маша", 12, 85, "лучник")
print(player[0])
print(player[2])
print(player[-1])
print(len(player))
```

**Результат:**

```text
Маша
85
лучник
4
```

`player[0]` — имя; `player[2]` — очки; `player[-1]` — последний элемент. `len()` возвращает количество элементов.

**Проверь себя.** Что выведет `player[-2]`?

### Срезы кортежа

```python
scores = (10, 20, 30, 40, 50, 60)
print(scores[:3])
print(scores[-2:])
print(scores[1:5:2])
print(scores[::-1])
```

**Результат:**

```text
(10, 20, 30)
(50, 60)
(20, 40)
(60, 50, 40, 30, 20, 10)
```

Правила те же, что в уроке 3: `start` включается, `stop` не включается, `step` задаёт шаг. Срез не меняет исходный кортеж.

**Проверь себя.** Получить из `scores` кортеж `(30, 40, 50)`.
![Схема индексов](изображения/кортеж-индексы.svg)

**Ошибка для обсуждения:** `player[4]` вызовет `IndexError`, потому что допустимы индексы от `0` до `3`.

## Часть 3 — Неизменяемость: что разрешено, а что нет (10 минут)

Кортеж можно читать, перебирать, сравнивать, использовать в вычислениях. Но изменить его отдельный элемент нельзя.


### Проверяем запрет на изменение

```python
point = (3, 8)
# point[0] = 10  # Если убрать #, возникнет TypeError
new_point = (10, point[1])
print(point)
print(new_point)
```

**Результат:**

```text
(3, 8)
(10, 8)
```

Мы не исправили старую точку, а создали **новую**. Именно так обычно обновляют координаты, если выбрали кортеж для их хранения.

### Преобразуем список в кортеж и обратно

```python
items = ["меч", "щит", "лук"]
fixed_items = tuple(items)
print(fixed_items)
copy_items = list(fixed_items)
copy_items.append("зелье")
print(copy_items)
```

**Результат:**

```text
('меч', 'щит', 'лук')
['меч', 'щит', 'лук', 'зелье']
```

`tuple()` создаёт кортеж из последовательности, `list()` — список. Если нужно изменить набор, часто удобнее сначала получить список.
**Тонкость для сильных учеников.** Если внутри кортежа лежит список, содержимое вложенного списка можно менять: `data = ([1, 2], "готово"); data[0].append(3)`. Сам кортеж по-прежнему хранит ссылку на тот же список. Неизменяемость кортежа не означает глубокую неизменяемость всего, что внутри.

## Часть 4 — Перебираем кортеж в цикле (10 минут)

В цикле `for` можно получить сами элементы или их индексы. Покажите сначала простой перебор, затем задачу с накоплением результата.


### Каждый элемент по очереди

```python
levels = (2, 5, 3)
for level in levels:
    print("Уровень:", level)
```

**Результат:**

```text
Уровень: 2
Уровень: 5
Уровень: 3
```

Первая итерация: `level = 2`; вторая: `level = 5`; третья: `level = 3`. После последнего элемента цикл заканчивается.

### Считаем сумму и среднее

```python
scores = (8, 10, 7, 9)
total = 0
for score in scores:
    total += score
print("Сумма:", total)
print("Среднее:", total / len(scores))
```

**Результат:**

```text
Сумма: 34
Среднее: 8.5
```

На каждом шаге добавляем очередное число к `total`. Делить на количество элементов нужно после завершения цикла.

**Проверь себя.** Измени оценки так, чтобы среднее было 9.

### Нужны и индекс, и значение

```python
names = ("Аня", "Борис", "Вика")
for index, name in enumerate(names, start=1):
    print(index, name)
```

**Результат:**

```text
1 Аня
2 Борис
3 Вика
```

`enumerate()` выдаёт пары: порядковый номер и элемент. Две переменные сразу принимают их значения. Здесь `start=1` нужен только для красивой нумерации, индексы самого кортежа всё равно начинаются с нуля.
Можно перебрать индексы и через `range(len(names))`, но `enumerate()` обычно проще, когда одновременно нужны позиция и элемент.

## Часть 5 — Распаковка: координаты, цвет, данные игрока (10 минут)

Распаковка позволяет присвоить элементы кортежа нескольким переменным одной строкой. Число переменных должно соответствовать числу значений, если не используется звёздочка `*`.


### Разбираем точку на x и y

```python
point = (6, 9)
x, y = point
print("X:", x)
print("Y:", y)
```

**Результат:**

```text
X: 6
Y: 9
```

Справа находится один кортеж из двух элементов. Слева две переменные. Python присваивает `6` переменной `x`, а `9` — переменной `y`.

**Проверь себя.** Поменяй координаты местами одной строкой: `x, y = y, x`.

### Распаковка в цикле

```python
points = ((1, 2), (3, 5), (7, 4))
for x, y in points:
    print(f"Точка: x={x}, y={y}")
```

**Результат:**

```text
Точка: x=1, y=2
Точка: x=3, y=5
Точка: x=7, y=4
```

Внешний кортеж содержит три точки. На каждой итерации берём одну внутреннюю пару и сразу раскладываем её на `x` и `y`. Это пригодится в графических проектах.

### Распаковка со звёздочкой

```python
record = ("Аня", 5, 4, 5, 5)
name, *grades = record
print(name)
print(grades)
```

**Результат:**

```text
Аня
[5, 4, 5, 5]
```

Звёздочка собирает оставшиеся элементы **в список**. Это дополнительный приём; главное для урока — обычная распаковка пар.
![Схема распаковки](изображения/распаковка.svg)

**Типичная ошибка:** `x, y = (1, 2, 3)` выдаст `ValueError`: три значения нельзя распаковать ровно в две переменные.

## Часть 6 — Операции и методы кортежа (8 минут)

Кортежи можно объединять оператором `+`, повторять оператором `*`, проверять наличие значения через `in`. У кортежа только два собственных метода для поиска: `count()` и `index()`.


### Объединение и повторение

```python
a = (1, 2)
b = (3, 4)
print(a + b)
print((0,) * 3)
print(3 in a)
```

**Результат:**

```text
(1, 2, 3, 4)
(0, 0, 0)
False
```

Сложение и умножение создают новые кортежи, исходные `a` и `b` не меняются.

### Сколько раз встречается число и где оно впервые

```python
numbers = (4, 2, 4, 7, 4)
print(numbers.count(4))
print(numbers.index(7))
```

**Результат:**

```text
3
3
```

`count(4)` подсчитывает вхождения четвёрки. `index(7)` возвращает индекс первого совпадения. Если элемента нет, `index()` вызовет `ValueError`: перед поиском можно проверить `7 in numbers`.
| Команда | Что делает | Пример |
|---|---|---|
| `len(t)` | Количество элементов | `len((1, 2))` → `2` |
| `x in t` | Проверка наличия | `2 in (1, 2)` → `True` |
| `t.count(x)` | Число совпадений | `(1, 1, 2).count(1)` → `2` |
| `t.index(x)` | Индекс первого совпадения | `(4, 5).index(5)` → `1` |
| `tuple(data)` | Создаёт кортеж | `tuple([1, 2])` → `(1, 2)` |

Сравнение кортежей происходит слева направо: `(2, 1) > (1, 100)`, потому что уже первые элементы `2` и `1` различаются. Это не сравнение сумм.

## Часть 7 — Кортежи в функциях и небольших проектах (8 минут)

### Функция возвращает две координаты

```python
def move_right(point):
    x, y = point
    return (x + 1, y)

hero = (4, 6)
hero = move_right(hero)
print(hero)
```

**Результат:**

```text
(5, 6)
```

Функция получает одну точку, распаковывает координаты и возвращает новый кортеж. Присваивание `hero = ...` заменяет значение переменной новым объектом.

### Цвет пикселя

```python
pixel = (255, 128, 0)
red, green, blue = pixel
print(f"R={red}, G={green}, B={blue}")
```

**Результат:**

```text
R=255, G=128, B=0
```

Три числа всегда относятся к одному цвету. Кортеж удобно передавать целиком, не перепутав порядок каналов.
**Мини-проект «Маршрут героя».** Задайте `route = ((1, 1), (2, 1), (2, 2), (3, 2))`. Переберите маршрут и выведите каждую точку с номером шага. Затем найдите точку с максимальным `x`. Обсудите, почему здесь удобно хранить каждую координату отдельной парой.

## Часть 8 — Практикум «Рисуем по клеткам» (основная практика)

Откройте `материалы/рисуем_по_клеткам.py` в PyCharm или VS Code и запустите. В программе уже подготовлено поле. Ученики меняют только участок своего алгоритма. Функция `column()` принимает **кортеж номеров строк** и рисует точки в следующем столбце.

```python
column((5, 6, 7))  # три точки в первом столбце
column((0,))     # пропускаем следующий столбец
column((4,))     # одна точка в третьем столбце
```
**Почему `(4,)`, а не `(4)`?** Во втором случае передаётся число, а функция ожидает кортеж. Этот пример связывает правило из части 1 с реальной задачей.

![Как функция рисует столбцы](изображения/столбцы.svg)

Теперь создадим диагональ: ```python
for i in range(10):
    column((i + 1,))
```
На первой итерации `i = 0`, значит рисуем строку 1; затем строку 2 и так далее. Десять вызовов создадут десять столбцов. Для двух линий в одном столбце передаём пару высот: `column((5, 7))`.

![Цикл и столбцы](изображения/цикл-столбцы.svg)

## Разбор частых ошибок

| Ошибка | Почему происходит | Как исправить |
|---|---|---|
| `(5)` вместо `(5,)` | Создано число, а не кортеж | Поставить запятую |
| `point[2]` у пары | Есть только индексы 0 и 1 | Проверить `len(point)` |
| `point[0] = 10` | Кортеж неизменяем | Создать новый кортеж |
| `x, y = (1, 2, 3)` | Количество переменных не совпадает | Использовать три переменные или `*` |
| `tuple.append(5)` | У кортежа нет `append()` | Создать новый кортеж или использовать список |
| `column([1, 2])` | Практикум ожидает кортеж | Передать `(1, 2)` |

Для каждого случая предложите сначала предсказать ошибку, а затем проверить код. Не нужно заучивать текст исключений: важнее понимать причину.

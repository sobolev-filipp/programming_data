## Часть 0 — Разминка: список можно испортить (5 минут)

Список удобен, но его **легко изменить по ошибке**:

```python
point = [3, 5]      # координата как список
point[0] = 999      # упс — случайно сдвинули точку
```

А координата точки, цвет или дата меняться **не должны**. Хочется «заморозить» набор. Для этого — **кортеж**.

---

## Часть 1 — Кортеж: замороженный список (15 минут)

**Кортеж** записывают в **круглых** скобках. Всё остальное — как у списка (индекс, `len`, перебор), кроме одного: **менять нельзя**.

```python
point = (3, 5)         # кортеж из двух чисел
print(point[0])        # 3 — по индексу, как в списке
print(len(point))      # 2
```

**Неизменяемость** — главное свойство:

```python
point[0] = 99          #  TypeError: 'tuple' object does not support item assignment
```

![Схема: список можно менять, кортеж заморожен](изображения/кортеж-заморожен.svg)

>  **Список `[ ]` — квадратные скобки, кортеж `( )` — круглые.** Список меняется (`append`, `sort`, `lst[0]=...`), кортеж — нет. Читать кортеж (индекс, срез, `in`, перебор) можно, а изменять — нельзя.

>  **Кортеж из одного элемента — с запятой!** `(5)` — это просто число 5 в скобках. Кортеж из одного элемента — `(5,)` (с запятой). Мелочь, но легко забыть.

>  **Мини-задание 1 (2 мин):** заведи кортеж `color = (255, 128, 0)`. Выведи первый и последний элемент и длину. Попробуй `color[0] = 0` — увидишь ошибку.
> <details><summary> подсказка</summary><code>color[0]</code>, <code>color[-1]</code>, <code>len(color)</code>; присваивание даст TypeError.</details>

### Дополнительные операции

```python
levels = (2, 4, 6, 4)
print(levels[-1])       # 4
print(levels[1:3])      # (4, 6)
print(6 in levels)      # True
print(levels.count(4)) # 2
print(levels.index(6)) # 2
print((1, 2) + (3,))   # (1, 2, 3)
print((1, 2) * 2)      # (1, 2, 1, 2)
print(tuple([1, 2]))   # (1, 2)
```

Сложение и умножение создают новый кортеж. У кортежа нет `append`, `remove` или `sort`. `sorted(levels)` вернёт новый список. Пустой кортеж — `()`, а `1, 2` без скобок тоже образует кортеж. Именно запятая создаёт кортеж из одного элемента.

Кортеж неизменяем: нельзя заменить его элементы. Но переменной можно присвоить другой кортеж. Если внутри кортежа лежит список, содержимое этого списка по-прежнему можно менять. Это не делает сам кортеж изменяемым.

## Часть 2 — Распаковка: разложить по переменным (12 минут)

Главное удобство кортежа — **распаковка**: одной строкой разложить его по переменным.

```python
point = (3, 5)
x, y = point           # x = 3, y = 5
print(x, y)
```

![Схема: распаковка кортежа в переменные + обмен](изображения/распаковка.svg)

**Обмен значениями без временной переменной** — тоже распаковка кортежа:

```python
a, b = 10, 20
a, b = b, a            # теперь a = 20, b = 10
```

-  Справа собирается кортеж `(b, a)`, слева он распаковывается в `a, b`. Классический трюк «поменять местами».

**Распаковка прямо в цикле** — очень удобно для списка кортежей:

```python
points = [(0, 0), (3, 4), (6, 0)]
for x, y in points:    # каждый кортеж сразу разложен в x, y
    print(f"x={x}, y={y}")
```

>  **`for x, y in points` — читай «для каждой точки (x, y)».** Не нужно писать `point[0]`, `point[1]` — Python сам раскладывает пару в два имени. Так удобно ходить по координатам.

>  **Мини-задание 2 (3 мин):** дан список `people = [("Аня", 12), ("Боря", 13)]`. Выведи через распаковку `for name, age in people:` строки вида `Аня — 12 лет`.
> <details><summary> подсказка</summary><code>for name, age in people: print(f"{name} — {age} лет")</code>.</details>

## Часть 3 — Зачем кортеж: координаты, цвета, готовые пары (8 минут)

Где кортежи особенно удобны:

**Координаты и цвета — постоянные наборы:**
```python
start = (0, 0)             # точка на карте
ORANGE = (234, 88, 12)     # цвет RGB — не меняется
```
Точку или цвет незачем править по одному числу — их берут целиком. Кортеж это подчёркивает: набор постоянный.

**Некоторые готовые функции тоже отдают сразу пару — кортеж.** Например, встроенная `divmod` считает **частное и остаток** одним вызовом:
```python
result = divmod(17, 5)     # result = (3, 2) — это кортеж
print(result)              # (3, 2)

q, r = divmod(17, 5)       # сразу распаковываем пару в две переменные
print(q, r)                # 3 2   (17 = 3 * 5 + 2)
```

-  `divmod` вернул пару `(частное, остаток)` — кортеж, а `q, r = ...` его распаковал. Так одна команда «отдаёт сразу две вещи».

>  **Мини-задание 3 (2 мин):** вызови `divmod(23, 4)`, распакуй результат в переменные `q` и `r` и выведи строку `23 = q*4 + r`.
> <details><summary> подсказка</summary>Результат <code>divmod</code> — это готовый кортеж; распаковка — как в Части 2.</details>

## Часть 4 — Практикум: рисуем по клеткам (45 минут)

Открой [рисуем_по_клеткам.py](материалы/рисуем_по_клеткам.py). Это локальный шаблон на `turtle`: поле и проверка уже готовы, как в заданиях с пылесосом. Запусти файл в PyCharm или VS Code. Откроется отдельное окно с сеткой.

### Как читать поле

Слева направо идут столбцы 0–17, снизу вверх — высоты 1–15. Мы не передаём координату x: программа сама помнит текущий столбец. В начале это 0. Кортеж хранит номера высот, на которых нужно поставить точки.

```python
column((1, 3, 5))  # столбец 0
column(())         # столбец 1 пропускаем
column((2,))       # столбец 2
```

![Три вызова column](изображения/столбцы.svg)

Разберём двойные скобки: внешние — вызов функции, внутренние — кортеж. В `column((2,))` запятая обязательна. Пустой кортеж `()` не содержит высот, но переход вправо всё равно происходит. Старый вариант `column((0,))` также работает: ноль не рисуется.

### Рисуем с помощью цикла

Если нужно пять столбцов с точкой на высоте 3, нет смысла повторять команду пять раз:

```python
for i in range(5):
    column((3,))
```

А теперь пусть высота меняется. На первом шаге i равно 0, поэтому высота 1; на втором — 2. Кортеж создаётся заново на каждой итерации.

```python
for i in range(5):
    column((i + 1,))
```

![Диагональ из пяти точек](изображения/цикл-столбцы.svg)

## Разбор частых ошибок

| Симптом | Что случилось | Как починить |
|---------|---------------|--------------|
| `TypeError: ... item assignment` | пытался изменить кортеж | кортеж менять нельзя; собери новый |
| `(5)` оказалось числом | кортеж из 1 элемента без запятой | пиши `(5,)` |
| `ValueError: too many values to unpack` | переменных меньше, чем в кортеже | слева столько же имён, сколько элементов |
| рисунок смещён | лишний вызов column | проверь число вызовов и пустые столбцы |
| перепутал скобки | список в круглых / кортеж в квадратных | список `[ ]`, кортеж `( )` |

>  **Главное правило:** кортеж не меняют — из него берут (индекс, распаковка) и на его основе **создают новое**.

## Итог урока (5 минут)

Кортеж — надёжный «замороженный» набор:

-  **Кортеж `(...)`** — как список, но **менять нельзя** (круглые скобки).
-  Читать можно: индекс, `len`, срез, `in`, перебор.
-  **Распаковка** `x, y = point`; обмен `a, b = b, a`; в цикле `for x, y in points`.
-  Готовая функция может отдать сразу пару — кортеж (`q, r = divmod(17, 5)`).
-  Берут для констант: координаты, цвет RGB, дата.
-   «Рисуем по клеткам»: кортеж высот задаёт точки одного столбца; цикл строит узор.

>  Главное: **кортеж — неизменяемый набор; его распаковывают (`x, y = point`) и на его основе создают новый.** Быстро повторить — в [итого.md](итого.md).

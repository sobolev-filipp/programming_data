# Лайфхаки урока 4 «Кортежи» 🧰

> Приёмы, чтобы кортежи работали на тебя.

---

## 🎯 Список `[ ]` меняется, кортеж `( )` — нет

```python
lst = [1, 2, 3]     # можно менять
tpl = (1, 2, 3)     # заморожен
```

Берёшь кортеж, когда данные НЕ должны меняться: координаты, цвет, дата, пара-ключ.

---

## 🎯 Распаковка вместо индексов

```python
x = point[0]        # длинно
y = point[1]
x, y = point        # ✅ одной строкой
```

Читается яснее и короче. В цикле — `for x, y in points`.

---

## 🎯 Обмен местами — в одну строку

```python
a, b = b, a         # без временной переменной
```

Работает, потому что справа собирается кортеж `(b, a)`.

---

## 🎯 Готовая функция может отдать пару

```python
q, r = divmod(17, 5)    # divmod вернул кортеж (3, 2)
```

Некоторые встроенные функции возвращают сразу несколько значений — пару-кортеж; её распаковываешь при получении.

---

## 🎯 Кортеж из одного — с запятой!

```python
(5)     # это число 5 (скобки для порядка действий)
(5,)    # это кортеж из одного элемента
```

Запятая делает кортеж, а не скобки.

---

## 🎯 Менять нельзя — создавай новое

```python
point = (3, 5)
point = (point[0] + 1, point[1])   # новый кортеж, сдвиг вправо
```

Неизменяемые данные не правят «на месте» — собирают заново.

---

## 🐢 Художник: двигаем фигуру через новый кортеж

Вершину-кортеж нельзя изменить, поэтому для сдвига распакуй и собери новую точку:
```python
for x, y in house:
    line_to((x + 4, y))
```

---

## 🐞 Топ-5 ошибок

1. **`point[0] = 9`** → `TypeError`: кортеж менять нельзя.
2. **`(5)` вместо `(5,)`** → получил число, а не кортеж.
3. **`x, y, z = (1, 2)`** → `ValueError`: имён больше, чем элементов.
4. **Перепутал скобки:** список `[ ]`, кортеж `( )`.
5. **Пытался «сдвинуть» изменением** — нужно собрать новый кортеж.

---

## 🎓 Для продвинутых

- **`a, *rest = (1, 2, 3, 4)`** — «звёздочка» ловит остаток в список (`rest = [2, 3, 4]`).
- **Кортежи быстрее и легче списков** — Python использует их для «неизменяемых пачек» данных.
- **Готовые функции часто отдают кортеж** (например `divmod`) — потому и удобна распаковка `q, r = ...`.
- **Кортеж пригодится дальше** — в Уроке 5 (словари) им можно помечать пары «ключа».

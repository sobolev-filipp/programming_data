## 1. `изображения/итоги-списка.svg` 📊
**Когда:** Часть 1 (итоги), 5–19 мин.

Список `scores` из 5 чисел, вниз стрелка → карточки результатов: `len→5`, `sum→402`, `max→95` (зелёная), `min→60` (красная), среднее `sum/len=80.4`. Внизу — формула победителя.

**Как обсудить:**
- Одна команда берёт **весь список** и отдаёт **одно число**.
- `max` зелёным, `min` красным — крайние значения.
- Победитель — `players[scores.index(max(scores))]`: позиция лучшего → имя.

## 2. `изображения/сортировка.svg` 🔀
**Когда:** Части 2–3 (сортировка), 19–43 мин.

Слева `new = sorted(nums)` — создаёт новый список (`nums` цел). Справа `nums.sort()` — меняет сам список (было → стало). Внизу — сортировка по ключу `key=len` и `key=str.lower`.

**Как обсудить:**
- Главное: **`sorted` копирует, `sort` меняет** (и возвращает `None`).
- Почему это важно: параллельные списки (имена+очки) нельзя сортировать порознь.
- Ключ `key=` — по какому признаку сравнивать (длина, регистр). Скобок у функции нет.

## 3. `изображения/диаграмма-turtle.svg` 🐢
**Когда:** Часть 5 (диаграмма), 53–68 мин.

Готовая столбчатая диаграмма (столбцы 8,5,10,3,7; самый высокий — зелёный) + панель кода `for score in scores: bar(score)`. Внизу — команды каркаса и подсказка про `TASK`.

**Как обсудить:**
- Команда `bar(value)` рисует **один** столбец; цикл проходит список — рисует все.
- Диаграмма любой длины строится **одной строкой** цикла.
- `TASK`: 1 — как есть, 2 — отсортированный (лесенка), 3 — макс зелёным (`max`).

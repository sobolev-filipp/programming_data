## Главные мысли

1. **Итоги — одной командой:** `len`, `sum`, `max`, `min`.
2. **Среднее** = `sum(lst) / len(lst)` (потом `round(x, 1)`).
3. **`sort()` меняет список, `sorted()` даёт новый** (оригинал цел).
4. **По ключу:** `key=len` (по длине), `key=str.lower` (без регистра).
5. **Фильтр:** пустой список → перебор → `if` → `append`.

---

## Итоги списка

```python
scores = [82, 95, 70, 95, 60]
len(scores)   # 5
sum(scores)   # 402
max(scores)   # 95
min(scores)   # 60
sum(scores) / len(scores)   # 80.4 — среднее
```

## Сортировка

```python
sorted(scores, reverse=True)   # НОВЫЙ по убыванию, оригинал цел
scores.sort()                  # меняет САМ список (вернёт None)

sorted(words, key=len)         # по длине
sorted(names, key=str.lower)   # без учёта регистра
```

**Топ-3:** `top = sorted(scores, reverse=True)` → `top[0], top[1], top[2]`.

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| `None` после сортировки | `x = lst.sort()` | `sorted(lst)` |
| `ValueError` на `max` | список пуст | `if len(lst) > 0:` |
| `key=len()` не сортирует | скобки у ключа | `key=len` без скобок |
| среднее без дроби | делил `//` | дели `/`, потом `round` |

## Что должно остаться в голове

1. `sum/max/min/len` — итоги одной командой.
2. Среднее = сумма / количество.
3. `sort` меняет, `sorted` копирует.
4. `key=len` / `key=str.lower` — сортировка по признаку.
5. Фильтр = `[]` + `for` + `if` + `append`.

## 📖 Что нужно знать за 2 минуты

Готовые функции считают итоги **всего списка** одной командой:
```python
scores = [82, 95, 70, 95, 60]
len(scores)   # 5
sum(scores)   # 402
max(scores)   # 95
min(scores)   # 60
sum(scores) / len(scores)   # 80.4 — среднее
```
Сортировка: `sorted(lst)` — новый список, `lst.sort()` — меняет сам. По ключу: `sorted(words, key=len)`, `sorted(names, key=str.lower)`.
Фильтр: пустой список → перебор → `if` → `append`.

## Часть A — задания с пошаговым разбором

### Задание 1. Сумма и среднее
**Тема:** `sum`, `len`.

**Разбор по шагам:**
1. Заведи список: `marks = [4, 5, 3, 5]`.
2. Посчитай сумму и среднее:
```python
marks = [4, 5, 3, 5]
print(sum(marks))                 # 17
print(sum(marks) / len(marks))    # 4.25
```
3. Среднее — сумма, делённая на количество.

✅ `sum` и `len` — готовые, цикл писать не надо.

---

### Задание 2. Максимум и минимум
**Тема:** `max`, `min`.

**Разбор по шагам:**
1. Список температур: `temps = [12, 19, 7, 25]`.
2. Найди крайние значения:
```python
temps = [12, 19, 7, 25]
print("тепло:", max(temps))   # 25
print("холод:", min(temps))   # 7
```

✅ `max`/`min` берут крайние элементы.

---

### Задание 3. Сортировка новым списком
**Тема:** `sorted`.

**Разбор по шагам:**
1. Список очков: `scores = [82, 95, 70]`.
2. Отсортируй по убыванию, не портя оригинал:
```python
scores = [82, 95, 70]
ranking = sorted(scores, reverse=True)
print(ranking)   # [95, 82, 70]
print(scores)    # [82, 95, 70] — цел
```

✅ `sorted` не трогает исходный список.

---

### Задание 4. Победитель
**Тема:** `max` + `index`.

**Разбор по шагам:**
1. Два списка: `players = ["Аня", "Борис", "Вика"]`, `scores = [82, 95, 70]`.
2. Найди имя лучшего:
```python
players = ["Аня", "Борис", "Вика"]
scores = [82, 95, 70]
best = max(scores)                    # 95
winner = players[scores.index(best)]  # players[1] -> "Борис"
print(winner)
```

✅ Позиция лучшего счёта = позиция имени победителя.

---

### Задание 5. Сортировка по ключу
**Тема:** `key=`.

**Разбор по шагам:**
1. Список слов: `words = ["дом", "я", "школа"]`.
2. Отсортируй по длине:
```python
words = ["дом", "я", "школа"]
print(sorted(words, key=len))   # ['я', 'дом', 'школа']
```
3. `key=len` — «сравнивай по длине». Скобок у `len` нет.

✅ `key=` задаёт признак сортировки.

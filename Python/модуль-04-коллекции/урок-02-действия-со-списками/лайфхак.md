# Лайфхаки урока 2 «Действия со списками» 🧰

> Приёмы, чтобы считать итоги и сортировать списки без ошибок.

---

## 🎯 Итоги — готовыми командами

```python
len(lst)   # сколько
sum(lst)   # сумма
max(lst)   # наибольший
min(lst)   # наименьший
sum(lst) / len(lst)   # среднее
```

Не пиши цикл ради суммы — `sum` уже есть. Цикл нужен только для **фильтра** (выбрать по условию).

---

## 🎯 `sort()` меняет, `sorted()` копирует

```python
lst.sort()            # меняет сам lst (вернёт None)
new = sorted(lst)     # новый список, lst цел
```

Работаешь с параллельными списками (имена + очки)? **Не сортируй их порознь** — «разъедутся». Сортируй копию через `sorted` или не сортируй вовсе, а ищи через `max`/`index`.

---

## 🎯 `key=` — имя функции БЕЗ скобок

```python
sorted(words, key=len)        # ✅ по длине
sorted(words, key=len())      # ❌ ошибка — скобки лишние
sorted(names, key=str.lower)  # ✅ без учёта регистра
```

Python сам применит функцию к каждому элементу.

---

## 🎯 Победитель без ручного поиска

```python
winner = players[scores.index(max(scores))]
```

`max` — лучший счёт, `index` — его позиция, по позиции — имя. Три команды вместо цикла с проверками.

---

## 🎯 Фильтр — шаблон на всю жизнь

```python
result = []                 # 1. пустой список
for x in data:              # 2. перебор
    if условие:             # 3. отбор
        result.append(x)    # 4. сохранить
```

Чётные, длинные слова, дорогие товары, выше среднего — всё по этому шаблону.

---

## 🎯 Осторожно с пустым списком

```python
max([])   # ❌ ValueError
sum([])   # 0  — а вот сумма пустого ок
```

`max`/`min` на пустом падают. Проверяй: `if len(lst) > 0:`.

---

## 🐞 Топ-5 ошибок

1. **`new = lst.sort()`** → `None`. Для копии — `sorted(lst)`.
2. **`max([])`** → `ValueError`. Сначала проверь длину.
3. **`key=len()`** со скобками → ошибка. Пиши `key=len`.
4. **Среднее через `//`** теряет дробь. Дели `/`, потом `round(x, 1)`.
5. **Отсортировал только очки, а имена нет** → перепутались пары.

---

## 🎓 Для продвинутых

- **`sorted(lst)[:3]`** — топ-3 срезом (срезы — Урок 3).
- **`key=lambda ...`** — сортировка по своему правилу (например, список пар по второму элементу). Лямбды — позже, но идея та же: `key` задаёт признак.
- **`sum(lst) / len(lst)`** ломается на пустом списке (деление на 0) — защищайся проверкой.
- **`max(scores)` при ничьей** вернёт первый из равных максимумов; `index` даст позицию первого. Для «всех победителей» — фильтр `if s == max(scores)`.

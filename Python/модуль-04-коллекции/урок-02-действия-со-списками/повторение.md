## 1. Блиц-вопросы (устно)

1. Как добавить элемент в конец списка? *(`lst.append(x)`)*
2. Что вернёт `lst[-1]`? *(последний элемент)*
3. Чем `sort()` отличается от `sorted()`? *(sort меняет сам список, sorted даёт новый)*
4. Как узнать длину списка? *(`len(lst)`)*
5. Как перебрать список циклом? *(`for x in lst:`)*

---

## 2. Предскажи вывод

```python
nums = [4, 2, 7, 1]
nums.append(5)
print(nums)
print(len(nums))
```

<details><summary>Ответ</summary>

`[4, 2, 7, 1, 5]` · `5`.
</details>

---

## 3. Найди ошибку

```python
scores = [5, 3, 8]
scores = scores.sort()
print(scores)
```

<details><summary>Что не так?</summary>

`sort()` меняет список **на месте** и возвращает `None`. После `scores = scores.sort()` в `scores` окажется `None` — список потерян. Правильно — просто `scores.sort()` (без `scores =`), либо `scores = sorted(scores)`.
</details>

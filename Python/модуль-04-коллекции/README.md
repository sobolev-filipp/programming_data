## Идеи и приёмы модуля

- **Списки вглубь** — изменяемость, добавление/удаление, методы, сортировка.
- **Срезы** `[start:stop:step]` — ключевая схема с границами и шагом.
- **Кортежи** — неизменяемые наборы (координаты, константы), распаковка.
- **Словари** `dict` — ключ→значение (телефонная книга, инвентарь).
- **Множества** `set` — уникальные элементы, пересечение/объединение.
- **Проект** — список словарей как мини-таблица данных.
- 🐢 Turtle-практика (scaffold) в Уроках 2 и 4: диаграмма по списку, фигура по точкам-кортежам.

# Практика урока 1 «Списки вглубь» ✍️

> **20 задач** в 3 уровнях. Сначала — короткая разминка на команды, потом **настоящие мини-программы**, где список работает на тебя.
> 🟢 разминка · 🟡 мини-программы · 🔴 со звёздочкой. Помни: методы `append`, `remove`, `sort` меняют список **на месте** (не пиши `lst = lst.append(...)`).

## 🟢 Уровень 1 — разминка (закрепляем команды, по 2–4 строки)

**1.1 — Плейлист.** Создай список из четырёх песен (названия в кавычках). Выведи первую песню, последнюю песню и общее количество песен.
> 💡 Последний элемент удобно взять отрицательным индексом `[-1]`.

**1.2 — Добавь трек.** Создай список из трёх игр и добавь в его конец четвёртую. Выведи получившийся список.

**1.3 — Замена по индексу.** Дан список `["чай", "кофе", "сок"]`. Замени средний элемент на `"какао"`, обращаясь к нему по индексу. Выведи результат.

**1.4 — Удали по названию.** Дан список блюд из пяти пунктов. Удали из него одно конкретное блюдо **по названию** (не по номеру) и выведи, что осталось.

**1.5 — Сними последний.** Дан список чисел. Сними с конца последний элемент так, чтобы он сохранился в отдельной переменной, и выведи, что именно ты снял и что осталось в списке.
> 💡 Есть метод, который и удаляет последний, и возвращает его.

**1.6 — Наведи порядок.** Дан список чисел вразнобой. Отсортируй его по возрастанию, потом переверни в обратный порядок. Выведи список после каждого шага.

## 🟡 Уровень 2 — мини-программы (применяем на практике)

**2.1 — Список дел на день.** Спроси у пользователя три дела (три раза `input`) и складывай их в список. Потом выведи список дел пронумерованным:
```
Твои дела на сегодня:
1. ...
2. ...
3. ...
```
> 💡 Номера к элементам удобно добавляет `enumerate` (можно и просто вести счётчик).

**2.2 — Очередь в столовой.** Дан список из трёх имён — это очередь. Пришёл новый человек (добавь его в конец). Первого в очереди обслужили — он уходит (убери самого первого). После каждого события выводи, кто сейчас в очереди.
> 💡 «Самый первый» — это индекс 0; снять его умеет `pop`.

**2.3 — Список гостей.** Заведи список гостей праздника. Один гость подтвердил — добавь его. Другой отменил — удали его по имени, но **сначала проверь**, что он вообще в списке (если нет — выведи «такого гостя нет»). В конце выведи, сколько гостей придёт.
> 💡 Проверить наличие помогает `in`.

**2.4 — Любимую песню — в начало.** Дан плейлист из пяти песен. Пользователь называет любимую (она точно есть в списке). Перенеси её на первое место: убери с текущего места и вставь в начало. Выведи новый плейлист.
> 💡 Вставить на позицию 0 умеет `insert`.

**2.5 — Случайный фильм на вечер.** Заведи список из шести фильмов. Программа сама выбирает один случайный и предлагает его посмотреть: `Сегодня смотрим: ...`.
> 💡 Случайный элемент списка даёт `random.choice`.

**2.6 — Турнирная таблица.** Заведи список результатов игроков (числа). После матча добавился новый результат — допиши его в список. Отсортируй результаты по убыванию и выведи их. Первый в отсортированном списке — победитель, объяви его результат.

**2.7 — Корзина покупок.** Сделай мини-приложение с меню в цикле `while`: `[1]` добавить товар, `[2]` убрать последний добавленный, `[3]` показать корзину, `[4]` выход. Пункты храни в списке.
> 💡 «Убрать последний» — это `pop` без номера.

**2.8 — Отбираем команду.** Дан список из восьми игроков. Собери случайную команду из трёх человек: три раза выбери случайного игрока, добавь его в список команды и **убери из общего списка**, чтобы он не попал дважды. Выведи состав команды.
> 💡 Выбирать — `random.choice`, убирать выбранного — `remove`.

## 🔴 Уровень 3 — со звёздочкой (сборка и защита от ошибок)

**3.1 — Приложение «Список дел».** Собери полноценное меню в цикле `while`: `[1]` добавить дело, `[2]` удалить дело по его номеру из списка, `[3]` показать все дела с номерами, `[4]` выход. Помни: номер, который вводит человек, на 1 больше индекса.

**3.2 — Убери все повторы.** Дан список, где какое-то число (например, 2) встречается несколько раз. Удали из списка ВСЕ двойки, а не только первую. Выведи очищенный список.
> 💡 `remove` убирает лишь первое совпадение — повторяй, пока двойки ещё остаются (`while ... in ...`).

**3.3 — Своя сортировка (без `sort`).** Не используя `sort`/`sorted`, отсортируй список по убыванию так: в цикле находи наибольший элемент, переноси его в новый список и убирай из старого — пока старый не опустеет.
> 💡 Наибольший ищи циклом (перебор с запоминанием рекордсмена), как учились в Модуле 3.

**3.4 — Угадай, где приз.** Программа прячет приз в случайной клетке списка из пяти ячеек (запомни случайный индекс). Пользователь вводит номер клетки (0–4). Если угадал — «Приз твой!», иначе — «Пусто, приз был в клетке N».
> 💡 Случайный индекс — `random.randint(0, 4)`; сравни его с вводом пользователя.

**3.5 — Живая очередь.** Смоделируй очередь в цикле: пока в списке есть люди, на каждом шаге обслуживай первого (убирай из начала) и выводи, кого обслужили и сколько осталось. Останови, когда очередь опустеет.

**3.6 — Поменяй местами.** Дан список. Поменяй местами его первый и последний элементы в одну строку (без временной переменной) и выведи результат.
> 💡 Вспомни приём одновременного присваивания `a, b = b, a` из будущего урока про кортежи — он работает и для элементов списка.

## ✅ Как проверить себя

- Ты не присваиваешь результат `append`/`sort` обратно в переменную (эти методы возвращают `None`).
- Для «последнего» пишешь отрицательный индекс, а не считаешь длину.
- В приложении переводишь номер пользователя в индекс, отнимая 1.
- Перед удалением по значению проверяешь `in`, чтобы программа не упала.

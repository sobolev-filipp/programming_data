# Практика урока 1 «Списки вглубь» ✍️

> **24 задачи** в 3 уровнях. Читай задание целиком — там сказано, что сделать и что должно получиться. Подсказка есть только там, где легко застрять.

## 🟢 Уровень 1 — базовые (индекс, добавить, удалить)

**1.1 — Плейлист.** Создай список из четырёх песен (названия в кавычках). Выведи первую песню, последнюю песню и общее количество песен.
> 💡 Последний элемент удобно взять отрицательным индексом.

**1.2 — Добавь трек.** Создай список из трёх игр и добавь в его конец четвёртую. Выведи получившийся список.

**1.3 — Пустая корзина.** Заведи пустой список `cart = []`. Добавь в него по одному три товара, затем выведи корзину.

**1.4 — Замена по индексу.** Дан список `["чай", "кофе", "сок"]`. Замени средний элемент на `"какао"`, обращаясь к нему по индексу. Выведи результат.

**1.5 — Удали по названию.** Дан список блюд. Удали из него одно конкретное блюдо по его названию (не по номеру).

**1.6 — Сними последний.** Дан список чисел. Сними с конца последний элемент так, чтобы он сохранился в отдельной переменной, и выведи, что именно ты снял.
> 💡 Есть метод, который и удаляет последний, и возвращает его.

**1.7 — Последний двумя способами.** Дан список оценок. Выведи последнюю оценку двумя способами: через отрицательный индекс и через длину списка.

**1.8 — Считаем после изменений.** Заведи список друзей, добавь двоих, удали одного и выведи, сколько друзей осталось.

## 🟡 Уровень 2 — средние (insert, pop, методы)

**2.1 — Вставь в начало.** Дан список задач. Вставь новую задачу на самое первое место (на позицию 0), не удаляя остальные.
> 💡 Для вставки на конкретную позицию есть отдельный метод.

**2.2 — Добавь сразу несколько.** К списку `["меч", "щит"]` добавь одним действием сразу два предмета: `"лук"` и `"зелье"`.
> 💡 `append` добавит их как один вложенный список — нужен другой метод.

**2.3 — Сколько повторов.** В списке `[1, 2, 2, 3, 2]` посчитай, сколько раз встречается число 2.

**2.4 — На каком месте.** В списке городов найди, на какой позиции (индексе) стоит «Москва».

**2.5 — Сортировка.** Дан список чисел вразнобой. Отсортируй его по возрастанию, затем — по убыванию.

**2.6 — Разворот.** Дан список из пяти элементов. Переверни его так, чтобы порядок стал обратным.

**2.7 — Удали по номеру.** Дан список `[10, 20, 30, 40]`. Удали элемент, стоящий на индексе 2, и выведи, что осталось.

**2.8 — Очистка.** Заведи список рекордов, выведи его, затем полностью очисти и выведи снова (должен стать пустым).

**2.9 — Копия без потери.** Дан список `data = [3, 1, 2]`. Получи отсортированную копию, не меняя `data`. Выведи и копию, и оригинал.
> 💡 Есть функция сортировки, которая возвращает НОВЫЙ список.

**2.10 — Список с номерами.** Заведи список дел и выведи его пронумерованным: `1. …`, `2. …` и так далее.
> 💡 Номера к элементам удобно добавляет `enumerate`.

## 🔴 Уровень 3 — со звёздочкой (сборка и защита от ошибок)

**3.1 — Приложение «Список дел».** Собери меню в цикле `while`: команды «добавить», «удалить по номеру», «показать список» и «выход». Помни, что номер, который вводит человек, на 1 больше индекса.

**3.2 — Безопасное удаление.** Прежде чем удалять элемент по значению, проверь, что он вообще есть в списке. Если нет — выведи сообщение, а не роняй программу.
> 💡 Проверить наличие помогает `in`.

**3.3 — Топ игроков.** Дан список очков. Добавь в него новый результат, отсортируй по убыванию и выведи тройку лучших.

**3.4 — Убери все повторы.** Дан список, где число 2 встречается несколько раз. Удали ВСЕ двойки (не только первую).
> 💡 `remove` убирает лишь первое совпадение — повтори, пока двойки ещё остаются.

**3.5 — Поменяй местами.** Дан список. Поменяй местами его первый и последний элементы.

**3.6 — Своя сортировка.** Не используя `sort`, найди в списке максимум, перенеси его в новый список, и повторяй, пока старый не опустеет. Получится список, отсортированный по убыванию.

## ✅ Как проверить себя

- Ты не присваиваешь результат `append`/`sort` обратно в переменную (эти методы возвращают `None`).
- Для «последнего» пишешь отрицательный индекс, а не считаешь длину.
- В приложении переводишь номер пользователя в индекс, отнимая 1.

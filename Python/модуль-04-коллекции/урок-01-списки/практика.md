# 📝 Практика · Урок 1 «Списки вглубь»

**Темы:** список и индексы (`[0]`, `[-1]`), `len`, добавление (`append`, `insert`, `extend`), удаление (`remove`, `pop`, `del`, `clear`), проверка `in`, сортировка `sort`/`sorted`/`reverse`. Плюс повторяем циклы, условия, `random`, строки.

> 🎯 **Как работать:** решай по порядку и запускай после каждой задачи. Уровни: 🟢 разминка (закрепляем команды) · 🟡 мини-программы (список работает на тебя) · 🔴 со звёздочкой (сборка и защита от ошибок). В каждой задаче сказано, **что сделать** и **что получится**. Подсказка — наводка на идею, не готовый код, и она есть не у каждой задачи.
>
> 📌 Помни: методы `append`, `remove`, `sort` меняют список **на месте** и возвращают `None` — не пиши `lst = lst.append(...)`. Последний элемент бери индексом `[-1]`. `sum`/`max`/`min` будут в Уроке 2 — пока максимум ищем циклом.

## 🟢 Уровень 1 — разминка (команды, по 2–4 строки)

**1. Плейлист.** Создай список из четырёх песен (названия в кавычках). Выведи первую песню, последнюю песню и общее количество песен.
> 💡 Последний элемент удобно взять отрицательным индексом `[-1]`, не считая длину.

**2. Добавь трек.** Создай список из трёх игр и добавь в его конец четвёртую. Выведи получившийся список.
> 💡 Добавить элемент в конец умеет метод `append`.

**3. Замена по индексу.** Дан список `["чай", "кофе", "сок"]`. Замени средний элемент на `"какао"`, обращаясь к нему по индексу. Выведи результат.

**4. Удали по названию.** Дан список блюд из пяти пунктов. Удали из него одно конкретное блюдо **по названию** (не по номеру) и выведи, что осталось.
> 💡 Удалить элемент по значению умеет метод `remove`.

**5. Сними последний.** Дан список чисел. Сними с конца последний элемент так, чтобы он сохранился в отдельной переменной, и выведи, что именно ты снял и что осталось в списке.
> 💡 Есть метод, который и удаляет последний элемент, и **возвращает** его.

**6. Наведи порядок.** Дан список чисел вразнобой. Отсортируй его по возрастанию, потом переверни в обратный порядок. Выведи список после каждого шага.

**7. Почётное место.** Дан список участников. Пришёл особый гость — поставь его в самое **начало** списка (на позицию 0), не трогая остальных. Выведи результат.
> 💡 Вставить элемент на конкретную позицию умеет метод `insert`.

**8. Склей два списка.** Даны два списка: фрукты и овощи. Объедини их в один список покупок (добавь все овощи в конец списка фруктов) и выведи.
> 💡 Добавить сразу все элементы другого списка умеет метод `extend`.

**9. Удали по номеру.** Дан список из пяти дел. Удали третье по счёту дело (помни: у третьего индекс 2) и выведи остаток.
> 💡 Удалить элемент по индексу можно командой `del список[индекс]`.

**10. Список столбиком.** *(вспоминаем циклы)* Дан список из пяти любимых игр. Выведи их по одной на строке с помощью цикла `for`.

## 🟡 Уровень 2 — мини-программы

**11. Список дел на день.** Спроси у пользователя три дела (три раза `input`), складывая их в список, а потом выведи список пронумерованным:
```
Твои дела на сегодня:
1. ...
2. ...
3. ...
```
> 💡 Начни с пустого списка `[]` и на каждом вводе делай `append`; номера добавит `enumerate(..., start=1)`.

**12. Очередь в столовой.** Дан список из трёх имён — это очередь. Пришёл новый человек (добавь его в конец). Первого в очереди обслужили — он уходит (убери самого первого). После каждого события выводи, кто сейчас в очереди.
> 💡 «Самый первый» — это индекс 0; снять его умеет `pop(0)`.

**13. Список гостей.** Заведи список гостей праздника. Один гость подтвердил — добавь его. Другой отменил — удали его по имени, но **сначала проверь**, что он вообще в списке (если нет — выведи «такого гостя нет»). В конце выведи, сколько гостей придёт.
> 💡 Проверить наличие перед удалением помогает `in` — иначе `remove` уронит программу.

**14. Любимую песню — в начало.** Дан плейлист из пяти песен. Пользователь называет любимую (она точно есть в списке). Перенеси её на первое место: убери с текущего места и вставь в начало. Выведи новый плейлист.
> 💡 Сначала `remove` с текущего места, потом `insert(0, ...)` в начало.

**15. Случайный фильм на вечер.** *(вспоминаем урок 3 модуля 1)* Заведи список из шести фильмов. Программа сама выбирает один случайный и предлагает его: `Сегодня смотрим: Матрица`.
> 💡 Случайный элемент списка даёт `random.choice`.

**16. Турнирная таблица.** Заведи список результатов игроков (числа). После матча добавился новый результат — допиши его в список. Отсортируй результаты по убыванию и выведи их. Первый в отсортированном списке — победитель, объяви его результат.
> 💡 Сортировку по убыванию даёт `sort(reverse=True)`; победитель — элемент `[0]`.

**17. Корзина покупок.** Сделай мини-приложение с меню в цикле `while`: `[1]` добавить товар, `[2]` убрать последний добавленный, `[3]` показать корзину, `[4]` выход. Товары храни в списке.
> 💡 «Убрать последний» — это `pop()` без номера; меню повторяется в `while True` с выходом по `break`.

**18. Отбираем команду.** *(вспоминаем random)* Дан список из восьми игроков. Собери случайную команду из трёх человек: три раза выбери случайного игрока, добавь его в команду и **убери из общего списка**, чтобы он не попал дважды. Выведи состав команды.
> 💡 Выбирать — `random.choice`, убирать выбранного — `remove`.

**19. Сколько отличников.** *(на подумать)* Дан список оценок всего класса. Посчитай циклом, сколько в нём пятёрок, и выведи это число. Для `[5, 4, 5, 3, 5]` → `Пятёрок: 3`.
> 💡 Перебирай список и веди счётчик, увеличивая его на каждой пятёрке.

**20. Новый лидер.** В рейтинге уже есть игроки. Появился новичок, которого нужно поставить сразу на **второе** место (индекс 1), не трогая первого. Вставь его туда и выведи обновлённый рейтинг.
> 💡 `insert(1, ...)` поставит элемент на позицию с индексом 1.

**21. На каком месте.** *(на подумать)* Дан список участников забега в порядке финиша. Спроси имя и выведи, каким по счёту он финишировал (место = индекс + 1). Если такого нет — сообщи об этом.
> 💡 Перебирай список с `enumerate`, сравнивай имя и при совпадении выводи место и прекращай поиск (`break`).

**22. Перемешай колоду.** *(вспоминаем random)* Заведи список из шести карт и перемешай его случайным образом, а потом выведи — как тасование колоды перед игрой.
> 💡 Перемешать список на месте умеет `random.shuffle(список)`.

## 🔴 Уровень 3 — со звёздочкой (сборка и защита от ошибок)

**23. Приложение «Список дел».** Собери полноценное меню в цикле `while`: `[1]` добавить дело, `[2]` удалить дело по его номеру, `[3]` показать все дела с номерами, `[4]` выход. Помни: номер, который вводит человек, на 1 больше индекса.
> 💡 При удалении переведи номер в индекс (`n - 1`) и проверь, что он в допустимых границах.

**24. Убери все повторы.** Дан список, где какое-то число (например, 2) встречается несколько раз. Удали из списка **все** двойки, а не только первую. Выведи очищенный список.
> 💡 `remove` убирает лишь первое совпадение — повторяй его, пока двойки ещё остаются (`while 2 in nums`).

**25. Своя сортировка (без `sort`).** Не используя `sort`/`sorted`, отсортируй список по убыванию так: в цикле находи наибольший элемент, переноси его в новый список и убирай из старого — пока старый не опустеет.
> 💡 Наибольший ищи циклом (перебор с запоминанием рекордсмена), как учились в Модуле 3.

**26. Угадай, где приз.** *(вспоминаем random)* Программа прячет приз в случайной клетке из пяти (запомни случайный индекс 0–4). Пользователь вводит номер клетки. Угадал — `Приз твой!`, иначе — `Пусто, приз был в клетке N`.

**27. Живая очередь.** Смоделируй очередь в цикле: пока в списке есть люди, на каждом шаге обслуживай первого (убирай из начала) и выводи, кого обслужили и сколько осталось. Останови, когда очередь опустеет.
> 💡 Повторяй `pop(0)`, пока `len(queue) > 0`.

**28. Поменяй местами.** Дан список. Поменяй местами его первый и последний элементы в одну строку (без временной переменной) и выведи результат.
> 💡 Работает приём одновременного присваивания: `a[0], a[-1] = a[-1], a[0]`.

**29. Список-палиндром.** *(на подумать)* Дан список чисел. Определи, читается ли он одинаково с начала и с конца (например, `[1, 2, 3, 2, 1]` — да, а `[1, 2, 3]` — нет). Выведи `Палиндром` или `Нет`.
> 💡 Сравнивай пары «с краёв к центру»: первый с последним, второй с предпоследним — по индексам `i` и `-1-i`, ведя флаг.

**30. Змейка растёт.** *(финал)* Смоделируй тело змейки списком из нескольких клеток. В цикле спрашивай, съела ли змейка еду: если `да` — пристрой новую голову (добавь элемент), если `нет` — отрежь хвост (убери первый элемент). После каждого хода показывай длину змейки. Заверши по слову `стоп`.
> 💡 Рост — `append` (голова), движение без еды — `pop(0)` (хвост); весь процесс — в игровом цикле `while True` с `break` на «стоп».

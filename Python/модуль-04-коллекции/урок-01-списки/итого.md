## Главные мысли

1. **Список ИЗМЕНЯЕМЫЙ** — один список живёт всю программу, его правят на месте.
2. **Индекс с 0**; `lst[-1]` — последний, `lst[-2]` — предпоследний.
3. `lst[i] = ...` — заменить элемент по индексу.
4. Методы-изменялки (`append/sort/reverse/remove`) меняют на месте и возвращают **`None`**.
5. Пользователь считает с 1, Python с 0 → `pop(number - 1)`.

---

## Обращение и правка

```python
tracks = ["Muse", "Coldplay", "Kino"]
tracks[0]       # "Muse"    — первый
tracks[-1]      # "Kino"    — последний
tracks[1] = "U2"    # заменить элемент на месте
len(tracks)     # 3
```

---

## Добавить

```python
lst.append(x)          # ОДИН элемент в конец
lst.insert(i, x)       # вставить на позицию i (соседи сдвинутся)
lst.extend([a, b])     # НЕСКОЛЬКО элементов
```

## Удалить

```python
lst.remove(x)     # по ЗНАЧЕНИЮ (первое совпадение)
lst.pop()         # снять ПОСЛЕДНИЙ и вернуть его
lst.pop(i)        # снять по индексу и вернуть
del lst[i]        # удалить по индексу (без возврата)
lst.clear()       # очистить весь список
```

---

## Методы-помощники

| Метод | Что делает |
|-------|-----------|
| `lst.count(x)` | сколько раз встречается x |
| `lst.index(x)` | позиция первого x |
| `lst.sort()` | сортирует САМ список |
| `lst.sort(reverse=True)` | по убыванию |
| `sorted(lst)` | НОВЫЙ отсортированный (оригинал цел) |
| `lst.reverse()` | развернуть задом наперёд |

## Приложение «Список дел» (каркас)

```python
tasks = []
while True:
    choice = input("[1] добавить [2] удалить [4] выход: ")
    if choice == "1":
        tasks.append(input("Дело: "))
    elif choice == "2":
        n = int(input("Номер: "))
        tasks.pop(n - 1)          # номер 1 -> индекс 0
    elif choice == "4":
        break
```

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| `IndexError` | индекс за границей | последний = `-1` или `len-1` |
| `ValueError` | `remove` не нашёл | сначала `if x in lst:` |
| список стал `None` | `lst = lst.append(x)` | просто `lst.append(x)` |
| список в списке | `append([...])` | нужен `extend([...])` |

## Что должно остаться в голове

1. Список можно менять: `lst[i] = ...`.
2. Добавить — `append`/`insert`/`extend`; удалить — `remove`/`pop`/`del`/`clear`.
3. `lst[-1]` — последний.
4. `sort` меняет сам список, `sorted` даёт новый.
5. `pop(number - 1)` — из номера в индекс.

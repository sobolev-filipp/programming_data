## 📖 Что нужно знать за 2 минуты

Список — набор элементов в квадратных скобках. Его можно **менять**:
```python
lst = ["a", "b", "c"]
lst[0]              # "a"   — по индексу (с 0)
lst[-1]            # "c"   — последний
lst[1] = "X"        # заменить элемент на месте
lst.append("d")     # добавить в конец
lst.insert(0, "z")  # вставить на позицию
lst.remove("b")     # удалить по значению
x = lst.pop()       # снять последний и вернуть
lst.sort()          # отсортировать сам список
```
Методы-изменялки (`append/sort/remove`) меняют список **на месте** и возвращают `None` — не пиши `lst = lst.append(...)`.

## Часть A — задания с пошаговым разбором

### Задание 1. Обращение по индексу
**Тема:** индекс и `-1`.

**Разбор по шагам:**
1. Заведи список: `tracks = ["Muse", "Coldplay", "Kino"]`.
2. Выведи первый и последний:
```python
tracks = ["Muse", "Coldplay", "Kino"]
print(tracks[0])    # Muse
print(tracks[-1])   # Kino
```
3. `[0]` — первый, `[-1]` — всегда последний.

✅ Нумерация с нуля; отрицательный индекс — с конца.

---

### Задание 2. Изменить элемент
**Тема:** `lst[i] = ...`.

**Разбор по шагам:**
1. Возьми список: `marks = [3, 4, 5]`.
2. Исправь второй элемент:
```python
marks = [3, 4, 5]
marks[1] = 2
print(marks)    # [3, 2, 5]
```
3. Список изменился на месте — это тот же `marks`.

✅ Список изменяемый, в отличие от строки.

---

### Задание 3. Добавить в конец
**Тема:** `append`.

**Разбор по шагам:**
1. Заведи пустой список: `cart = []`.
2. Добавь два товара:
```python
cart = []
cart.append("хлеб")
cart.append("молоко")
print(cart)    # ['хлеб', 'молоко']
```
3. Каждый `append` кладёт один элемент в конец.

✅ Список рос с нуля.

---

### Задание 4. Удалить элемент
**Тема:** `remove` и `pop`.

**Разбор по шагам:**
1. Список: `food = ["суп", "салат", "чай"]`.
2. Убери по значению и сними последний:
```python
food = ["суп", "салат", "чай"]
food.remove("салат")   # по значению
last = food.pop()      # снять последний и вернуть
print(food, "| снял:", last)   # ['суп'] | снял: чай
```
3. `remove` — по значению, `pop` — снимает и отдаёт.

✅ Два разных способа удаления под разные задачи.

---

### Задание 5. Сортировка
**Тема:** `sort`.

**Разбор по шагам:**
1. Список чисел: `nums = [5, 1, 3, 2]`.
2. Отсортируй по возрастанию и убыванию:
```python
nums = [5, 1, 3, 2]
nums.sort()
print(nums)              # [1, 2, 3, 5]
nums.sort(reverse=True)
print(nums)              # [5, 3, 2, 1]
```
3. `sort()` меняет сам список.

✅ Для нового списка без изменения оригинала — `sorted(nums)`.

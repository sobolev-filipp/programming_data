# Лайфхаки урока 1 «Списки вглубь» 🧰

> Приёмы, чтобы списки менялись именно так, как ты хочешь.

---

## 🎯 `[-1]` — «последний», не считая длины

```python
lst[-1]    # последний
lst[-2]    # предпоследний
```

Забудь про `lst[len(lst) - 1]` — `lst[-1]` короче и не ошибётся.

---

## 🎯 Методы-изменялки возвращают `None`

```python
nums = [3, 1, 2]
nums = nums.sort()     # ❌ теперь nums == None, список потерян!
nums.sort()            # ✅ просто вызови, список изменится сам
```

Правило: `append`, `insert`, `remove`, `sort`, `reverse`, `clear` **меняют список на месте**. Не пиши `x = lst.метод(...)`.

---

## 🎯 `append` vs `extend`

```python
lst.append([1, 2])    # добавит ОДИН элемент — список [1, 2] внутри
lst.extend([1, 2])    # добавит ДВА элемента: 1 и 2
```

Один элемент — `append`. Несколько из другого списка — `extend`.

---

## 🎯 `sort` меняет, `sorted` копирует

```python
lst.sort()            # меняет сам lst
new = sorted(lst)     # новый список, lst не тронут
```

Нужен исходный порядок — бери `sorted`.

---

## 🎯 Удалить все вхождения

`remove` убирает только **первое** совпадение. Чтобы убрать все:

```python
while 2 in nums:
    nums.remove(2)
```

---

## 🎯 Номер пользователя → индекс Python

Люди считают с 1, Python — с 0. При работе с вводом:

```python
number = int(input("Номер: "))
lst.pop(number - 1)     # номер 1 -> индекс 0
```

---

## 🐞 Топ-5 ошибок

1. **`lst = lst.append(x)`** → список стал `None`. Пиши `lst.append(x)`.
2. **`lst[5]` в списке из 3 элементов** → `IndexError`. Последний индекс — `-1`.
3. **`remove(x)`, а `x` нет в списке** → `ValueError`. Сначала `if x in lst:`.
4. **`append([a, b])`** вместо `extend` → вложенный список.
5. **Путаница номер/индекс** при удалении → `pop(number - 1)`.

---

## 🎓 Для продвинутых

- **`list.copy()` или `lst[:]`** — сделать настоящую копию. Простое `new = lst` не копирует, а даёт **второе имя тому же списку** (изменишь один — изменится «оба»). Это тема ссылок — вернёмся к ней со срезами (Урок 3).
- **`del lst[1:3]`** удаляет сразу диапазон (срез) — забежим вперёд в Уроке 3.
- **`sort(key=len)`** сортирует по длине, `sort(key=str.lower)` — без учёта регистра. Ключи разберём в Уроке 2.
- **`enumerate`** (номер+элемент) из Модуля 3 идеально подходит для вывода списков с нумерацией.

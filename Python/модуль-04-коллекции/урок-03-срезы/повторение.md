# Разминка перед уроком 3 (5 минут) 🔁

> Повторяем индексы и действия со списками (Уроки 1–2). Устно или в `проба.py`.

---

## 1. Блиц-вопросы (устно)

1. Какой индекс у первого элемента? *(0)*
2. Что вернёт `lst[-1]`? *(последний элемент)*
3. Как отсортировать список, не портя оригинал? *(`sorted(lst)`)*
4. Что вернёт `len([10, 20, 30])`? *(3)*
5. Можно ли менять строку по индексу (`word[0]="X"`)? *(нет, строка неизменяемая)*

---

## 2. Предскажи вывод

```python
data = [0, 1, 2, 3, 4, 5]
print(data[0])
print(data[-1])
print(len(data))
```

<details><summary>Ответ</summary>

`0` · `5` · `6`.
</details>

---

## 3. Подумай

```python
tracks = ["A", "B", "C", "D", "E"]
# как вывести ПЕРВЫЕ ТРИ элемента?
```

<details><summary>Идея</summary>

По индексу пришлось бы: `tracks[0], tracks[1], tracks[2]` — длинно. Сегодня узнаем короткий способ — **срез** `tracks[:3]`, который сразу даёт `['A', 'B', 'C']`.
</details>

---

## 4. Мостик к теме

Индекс даёт **один** элемент. А если нужен **кусок** — первые три, последние пять, каждый второй, слово наоборот? Для этого есть **срез** `a[start:stop:step]`. Сегодня научимся резать списки и строки как угодно — и поиграем в «Пылесос по срезам». ✂️

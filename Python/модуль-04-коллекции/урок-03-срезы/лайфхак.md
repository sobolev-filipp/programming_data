# Лайфхаки урока 3 «Срезы» 🧰

> Приёмы, чтобы срезы работали как надо.

---

## 🎯 stop не входит — как у range

```python
data[2:5]   # [2, 3, 4]  — пятёрки НЕТ
```

Длина среза = `stop - start`. Нужно «до N включительно» — бери `[:N+1]`.

---

## 🎯 Три приёма-чемпиона

```python
data[::-1]   # перевернуть (список ИЛИ строку)
data[:]      # безопасная копия
data[1:-1]   # обрезать первый и последний
```

Запомни эти три — они встречаются чаще всего.

---

## 🎯 `[::-1]` — переворот, не `[-1]`

```python
data[-1]     # ОДИН элемент (последний)
data[::-1]   # ВЕСЬ список наоборот
```

Не путай: один минус-индекс — элемент; `[::-1]` — разворот.

---

## 🎯 Копия: `data[:]`, а не `new = data`

```python
b = data            # ❌ то же имя — «меняются оба»
b = data[:]         # ✅ настоящая копия
b = data.copy()     # ✅ то же самое, читается яснее
```

Проверка: измени копию и посмотри на оригинал — он должен остаться прежним.

---

## 🎯 Срез не падает за краем

```python
data[100]     # ❌ IndexError
data[5:100]   # ✅ [5..конца] — «сколько есть»
```

Не уверен в длине — срез безопаснее индекса.

---

## 🎯 Пустые границы = «весь список»

```python
data[:]      # всё (копия)
data[:5]     # с начала до 5
data[5:]     # с 5 до конца
data[::2]    # всё, но через один
```

Опущенная граница подставляется автоматически.

---

## 🐢 Пылесос по срезам: думай про границы

Замусорены клетки a..b? Нужен `cells[a:b+1]` — верхняя граница на 1 больше (иначе не уберёшь последнюю). Каждая вторая — `cells[::2]`. Всё справа налево — `cells[::-1]`.

---

## 🐞 Топ-5 ошибок

1. **`[2:5]` ждал 5 элементов** — их 3 (stop не входит).
2. **`new = data`** вместо `data[:]` → «меняются оба».
3. **`[-1]`** вместо `[::-1]` → взял один элемент, а не перевернул.
4. **Забыл про шаг** в `[2:8:2]` → это 2, 4, 6, а не 2..7.
5. **Пылесос: `cells[a:b]`** пропустил клетку b → верх бери `b+1`.

---

## 🎓 Для продвинутых

- **`del data[2:5]`** удаляет сразу диапазон; **`data[2:5] = [99]`** заменяет кусок.
- **Срез строки не меняет строку** (она неизменяемая) — но читать/переворачивать можно.
- **`data[::-2]`** — задом наперёд через один.
- **Копия среза поверхностная:** для простых чисел/строк это полноценная копия; вложенные списки — тема на будущее.
- **`[:]` для очистки:** `data[:] = []` очищает список на месте, сохраняя все ссылки на него.

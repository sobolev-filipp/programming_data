# Лайфхаки урока 6 «Множества + перебор словаря» 🧰

> Приёмы, чтобы множества и словари работали на тебя.

---

## 🎯 Убрать дубли — одной командой

```python
unique = set(список)          # только разные значения
count = len(set(список))      # сколько разных
```

Короче любого цикла с `not in`.

---

## 🎯 Быстрая проверка «есть или нет»

```python
if x in множество:   # у множества это очень быстро
    ...
```

Если часто проверяешь принадлежность к большому набору — множество быстрее списка.

---

## 🎯 Объединение, пересечение, разность

```python
a | b     # всё вместе (объединение)
a & b     # только общее (пересечение)
a - b     # только у a (разность)
a ^ b     # только у одного из двух (симметрическая разность)
```

Общие теги, общие друзья, «что различается» — это всё операции над множествами.

---

## 🎯 Перебор словаря парами

```python
for k, v in d.items():        # сразу ключ И значение
    print(k, v)
```

Не нужно `d[k]` — пара сама распаковывается. Хочешь только ключи — `for k in d`, только значения — `for v in d.values()`.

---

## 🎯 Пустое множество — `set()`, а не `{}`

```python
s = set()     # пустое множество
d = {}        # это пустой СЛОВАРЬ, не множество!
```

Частая ловушка. Пустые фигурные скобки — всегда словарь.

---

## 🎯 Уникальность + порядок вместе

```python
seen = set()
result = []
for x in data:
    if x not in seen:
        seen.add(x)
        result.append(x)
```

`set()` быстро проверяет «уже видел», а список хранит порядок.

---

## 🐞 Топ-5 ошибок

1. **`{}` вместо `set()`** — получил пустой словарь.
2. **`s[0]`** — у множества нет индексов (`TypeError`).
3. **`.remove(x)` для отсутствующего** — `KeyError`; бери `.discard(x)`.
4. **`"Кот"` и `"кот"`** — разные элементы (регистр важен).
5. **`for k, v in d`** без `.items()` — пары даёт именно `.items()`.

---

## 🎓 Для продвинутых

- **`set("слово")`** — уникальные буквы строки.
- **Множество нельзя положить в множество** (оно изменяемое); для этого есть `frozenset` — «замороженное» множество.
- **Проверка подмножества:** `a <= b` — все ли элементы `a` есть в `b`.
- **`.items()` даёт кортежи** `(ключ, значение)` — потому и работает распаковка `for k, v`.

## 1. Блиц-вопросы (устно)

1. Как убрать из списка первое совпадение по значению? *(`.remove(x)`)*
2. Что вернёт `d["ключ"]`, если ключа нет? *(`KeyError`)*
3. Как безопасно достать значение по ключу? *(`.get(key, запасное)`)*
4. Как проверить, есть ли элемент в списке? *(`элемент in список`)*
5. Что такое распаковка кортежа? *(`x, y = пара` — разложить по переменным)*

---

## 2. Предскажи вывод

```python
words = ["кот", "пёс", "кот", "кот"]
unique = []
for w in words:
    if w not in unique:
        unique.append(w)
print(unique)
```

<details><summary>Ответ</summary>

`['кот', 'пёс']` — добавляли только новые слова.
</details>

---

## 3. Подумай

```python
# хотим оставить в списке только РАЗНЫЕ значения одной командой
nums = [1, 2, 2, 3, 3, 3]
# как получить {1, 2, 3} без цикла?
```

<details><summary>Идея</summary>

Сегодня узнаем: `set(nums)` мгновенно уберёт все повторы. Это **множество** — набор уникальных значений.
</details>

---

## 4. Мостик к теме

Список умеет хранить повторы, а словарь — пары «ключ→значение». Но для «только разных значений» (уникальные теги, гости без дублей) есть **множество** `set`: оно само выкидывает повторы и умеет объединять/пересекать наборы. Плюс сегодня научимся перебирать словарь **сразу парами** — `for k, v in d.items()`. 🔗

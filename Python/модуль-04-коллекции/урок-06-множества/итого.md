## Главные мысли

1. **Множество `{...}`** — только УНИКАЛЬНЫЕ элементы, без порядка и индексов.
2. `set(список)` — мгновенно убирает дубли.
3. Операции: `|` объединение, `&` пересечение, `-` разность.
4. Пустое множество — `set()`, а НЕ `{}` (это словарь!).
5. Перебор словаря парами: `for k, v in d.items()`.

---

## Множество

```python
tags = {"код", "код", "игра"}   # {'код', 'игра'} — дубль ушёл
set(["кот", "кот", "пёс"])      # {'кот', 'пёс'}
len(tags)                       # сколько разных
"код" in tags                   # True (быстро!)
tags.add("java")                # добавить
tags.discard("игра")            # удалить (не падает)
empty = set()                   # пустое множество
```

⚠️ У множества НЕТ порядка: `tags[0]` — ошибка.

---

## Операции (круги Венна)

```python
a = {"питон", "код", "игра"}
b = {"код", "игра", "музыка"}
a | b     # {'питон','код','игра','музыка'}  — ВСЁ вместе (объединение)
a & b     # {'код','игра'}                   — только ОБЩЕЕ (пересечение)
a - b     # {'питон'}                        — только у a (разность)
```

Словами: `a.union(b)`, `a.intersection(b)`, `a.difference(b)`.

---

## Перебор словаря парами

```python
prices = {"кофе": 120, "чай": 80}
for dish, price in prices.items():   # сразу ключ И значение
    print(f"{dish}: {price} руб")
```

Пары `.items()` — это кортежи `(ключ, значение)`, а `for k, v` их распаковывает.

---

## Собрать вместе: теги

```python
all_tags = set()
for post in posts:
    all_tags = all_tags | post       # объединяем множества

popularity = {}
for post in posts:
    for tag in post:
        popularity[tag] = popularity.get(tag, 0) + 1
for tag, n in popularity.items():
    print(tag, n)
```

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| `{}` — словарь | пустое `{}` = dict | пустое множество `set()` |
| `s[0]` ошибка | у set нет индексов | проверяй `in` |
| `.remove()` → KeyError | нет элемента | бери `.discard()` |
| перепутал `|`/`&` | не та операция | `|` всё, `&` общее |

---

## Что должно остаться в голове

1. Множество `{ }` — уникальные, без порядка.
2. `set(список)` — убрать дубли.
3. `|` всё вместе, `&` только общее, `-` только у первого.
4. Пустое множество — `set()`.
5. `for k, v in d.items()` — перебор словаря парами.

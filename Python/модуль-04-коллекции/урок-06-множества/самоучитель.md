## 📖 Что нужно знать за 2 минуты

Множество — коллекция **уникальных** элементов в фигурных скобках, без порядка:
```python
tags = {"код", "код", "игра"}   # {'код', 'игра'} — дубль ушёл
set(["кот", "кот", "пёс"])      # {'кот', 'пёс'}  — убрать дубли из списка
"код" in tags                   # True
tags.add("java"); tags.discard("игра")
empty = set()                   # пустое множество (НЕ {} — это словарь)
```
Операции: `a | b` (объединение), `a & b` (пересечение), `a - b` (разность).
Перебор словаря парами: `for k, v in d.items()`.

## Часть A — задания с пошаговым разбором

### Задание 1. Создать множество
**Тема:** `{ }`, уникальность.

**Разбор по шагам:**
1. Заведи множество с повторами:
```python
s = {1, 2, 2, 3}
print(s)          # {1, 2, 3}
print(len(s))     # 3
```

✅ Повторы исчезают сами.

---

### Задание 2. Убрать дубли из списка
**Тема:** `set(список)`.

**Разбор по шагам:**
1. Преврати список в множество:
```python
words = ["кот", "пёс", "кот"]
print(set(words))   # {'кот', 'пёс'}
```

✅ Самый быстрый способ «оставить только разные».

---

### Задание 3. Проверка и изменение
**Тема:** `in`, `add`, `discard`.

**Разбор по шагам:**
```python
s = {"код", "игра"}
print("код" in s)   # True
s.add("арт")
s.discard("игра")
print(s)
```

✅ `add` — добавить, `discard` — убрать без ошибки.

---

### Задание 4. Объединение и пересечение
**Тема:** `|` и `&`.

**Разбор по шагам:**
```python
a = {1, 2, 3}
b = {2, 3, 4}
print(a | b)   # {1, 2, 3, 4} — всё вместе
print(a & b)   # {2, 3}       — только общее
```

✅ `|` — объединение, `&` — пересечение.

---

### Задание 5. Перебор словаря парами
**Тема:** `for k, v in d.items()`.

**Разбор по шагам:**
```python
prices = {"кофе": 120, "чай": 80}
for dish, price in prices.items():
    print(f"{dish}: {price}")
```

✅ Сразу и ключ, и значение — без `prices[dish]`.

## Часть B — задания с мини-подсказками

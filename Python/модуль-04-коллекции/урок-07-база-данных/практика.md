# 📝 Практика · Урок 7 «Мини-база данных»

**Темы:** список словарей = таблица, доступ `таблица[i]["поле"]`, перебор/поиск/фильтр по полю, итоги (сумма, среднее, чемпион), счётчик по полю, сортировка по полю через пары-кортежи `(поле, имя)` + `sort`, вложенный список в словаре, меню-приложение. Плюс повторяем всё из модуля: списки, кортежи, словари, `random`, циклы, условия.

> 🎯 **Как работать:** решай по порядку и запускай после каждой задачи. Уровни: 🟢 разминка (список словарей) · 🟡 мини-программы (каталог, журнал, рейтинг) · 🔴 со звёздочкой (фильтры и мини-база). В каждой задаче сказано, **что сделать** и **что получится**. Подсказка — наводка на идею, не готовый код, и она есть не у каждой задачи.
>
> 📌 Помни: поле записи достаёшь в два шага — `таблица[номер]["поле"]`. Поиск и фильтр — это перебор с `if` по нужному полю. Сортировать по полю удобно через пары-кортежи `(поле, имя)` (список словарей напрямую `sort` не умеет — своих функций-ключей ещё нет).

## 🟢 Уровень 1 — разминка (список словарей)

**1. Первая запись.** Дан список из трёх героев-словарей (поля `"имя"`, `"hp"`). Выведи весь первый словарь целиком и отдельно — имя второго героя.

**2. Всех по строке.** Пройди список героев циклом и выведи каждого в виде `Маг — hp 70`.

**3. Сколько записей.** Выведи, сколько всего героев в таблице (`len`).

**4. Добавить героя.** Добавь в список нового героя-словаря через `append` и выведи новое количество записей.

**5. Изменить поле.** У первого героя уменьши `hp` на 20 (получил урон) и выведи его новое значение.

**6. Удалить запись.** Удали из таблицы героя с индексом 1 и выведи, кто остался (только имена).

**7. Поле по номеру.** Выведи `hp` третьего героя (индекс 2), обратившись к полю в два шага.
> 💡 `таблица[2]["hp"]` — сначала берём запись по номеру, потом из неё поле.

**8. Суммарный hp.** *(на подумать)* Посчитай суммарное здоровье всей команды — сложи поле `hp` у всех героев и выведи.
> 💡 Заведи копилку, перебери список и прибавляй `hero["hp"]`.

## 🟡 Уровень 2 — мини-программы

**9. Каталог книг.** Создай список из 4 книг-словарей с полями `"название"` и `"год"`. Выведи весь каталог строками `Дюна — 1965`, а затем найди и выведи год книги по её названию.

**10. Фильтр товаров.** Дан список товаров-словарей (`"название"`, `"цена"`). Собери в новый список все товары дешевле 100 и выведи их названия и цены.
> 💡 Фильтр: пустой список → перебор → условие по полю `g["цена"] < 100` → `append`.

**11. Классный журнал.** Дан список учеников-словарей (`"имя"`, `"оценка"`). Посчитай средний балл класса (округли до десятых) и выведи имена тех, у кого оценка 4 и выше.

**12. Найти игрока.** Дан список игроков-словарей. Спроси у пользователя имя и выведи всю запись этого игрока, а если такого нет — `игрок не найден`.
> 💡 Заведи `found = None`, в цикле присваивай запись при совпадении, потом проверь.

**13. Самый дорогой.** Дан список товаров. Найди товар с самой высокой ценой (перебор с запоминанием рекордсмена) и выведи его название и цену.

**14. Сколько кого.** Дан список героев с полем `"класс"`. Посчитай словарём-счётчиком, сколько героев каждого класса, и выведи результат парами (`воин — 2`).
> 💡 `counts[k] = counts.get(k, 0) + 1`, потом `.items()`.

**15. Рейтинг по очкам.** Дан список игроков (`"имя"`, `"очки"`). Построй рейтинг по убыванию очков: собери пары `(очки, имя)`, отсортируй и выведи.
> 💡 Кортежи сортируются по первому элементу — поставь очки первыми, затем `sort(reverse=True)`.

**16. Мини-меню.** Сделай приложение с меню в цикле `while`: `[1]` показать всех героев, `[2]` добавить героя (спросить имя и hp), `[3]` выход. Данные храни списком словарей.

**17. Раздать статы.** *(вспоминаем random)* Дан список имён героев. Для каждого собери словарь-запись с полями `"имя"` и случайным `"hp"` (от 50 до 100), складывая записи в таблицу (`append`). Потом выведи всю таблицу строками.
> 💡 Идёшь по именам, на каждом создаёшь `{"имя": name, "hp": random.randint(50, 100)}` и добавляешь в список.

**18. Средний hp команды.** *(на подумать)* Дан список героев с полем `"hp"`. Посчитай средний hp всей команды (сумма hp делить на число героев), округли до десятых.
> 💡 Сумму поля собери циклом, а потом подели на `len` списка.

## 🔴 Уровень 3 — со звёздочкой

**19. Средний по классу.** Дан список героев (`"класс"`, `"hp"`). Посчитай средний hp только среди «воинов» (сначала отфильтруй воинов в отдельный список, потом посчитай среднее по ним).

**20. Топ-3 по полю.** Дан список игроков с очками. Выведи тройку лучших: собери пары `(очки, имя)`, отсортируй по убыванию и возьми первые три (срез из Урока 3).

**21. Кто сдал экзамен.** Дан список студентов (`"имя"`, `"балл"`). Собери отдельный список имён тех, у кого балл ≥ 60, и выведи, сколько человек сдало.

**22. Инвентарь героя.** Создай героя-словарь, у которого поле `"вещи"` — это список. Добавь в его инвентарь два предмета (через `append` к вложенному списку) и выведи все вещи героя.
> 💡 `hero["вещи"].append("меч")` — добавляем в список ВНУТРИ словаря.

**23. Отчёт по городам.** Дан список людей-словарей с полем `"город"`. Построй отчёт «город → сколько человек» словарём-счётчиком и выведи парами. Затем назови город, где людей больше всего.

**24. Мини-база (CRUD).** *(финал модуля)* Расширь приложение из задачи 16: добавь команды `[3]` найти героя по имени и `[4]` удалить героя по имени (перед удалением проверь, что он есть). Итого меню: показать / добавить / найти / удалить / выход.

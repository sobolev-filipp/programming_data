## 🟢 Уровень 1 — разминка (список словарей)

**1.1 — Первая запись.** Дан список из трёх героев-словарей (поля `"имя"`, `"hp"`). Выведи весь первый словарь целиком и отдельно — имя второго героя.

**1.2 — Всех по строке.** Пройди список героев циклом и выведи каждого в виде `Маг — hp 70`.

**1.3 — Сколько записей.** Выведи, сколько всего героев в таблице (`len`).

**1.4 — Добавить героя.** Добавь в список нового героя-словаря через `append` и выведи новое количество записей.

**1.5 — Изменить поле.** У первого героя уменьши `hp` на 20 (получил урон) и выведи его новое значение.

**1.6 — Удалить запись.** Удали из таблицы героя с индексом 1 и выведи, кто остался (только имена).

## 🟡 Уровень 2 — мини-программы (применяем на практике)

**2.1 — Каталог книг.** Создай список из 4 книг-словарей с полями `"название"` и `"год"`. Выведи весь каталог строками `Название — 2019`, а затем найди и выведи год книги по её названию.

**2.2 — Фильтр товаров.** Дан список товаров-словарей (`"название"`, `"цена"`). Собери в новый список все товары дешевле 100 и выведи их названия и цены.
> 💡 Фильтр: пустой список → перебор → условие по полю `hero["цена"] < 100` → `append`.

**2.3 — Классный журнал.** Дан список учеников-словарей (`"имя"`, `"оценка"`). Посчитай средний балл класса (округли до десятых) и выведи имена тех, у кого оценка 4 и выше.

**2.4 — Найти игрока.** Дан список игроков-словарей. Спроси у пользователя имя (`input`) и выведи всю запись этого игрока, а если такого нет — «игрок не найден».
> 💡 Заведи `найден = None`, в цикле присваивай запись при совпадении, потом проверь.

**2.5 — Самый дорогой.** Дан список товаров. Найди товар с самой высокой ценой (перебор с запоминанием рекордсмена) и выведи его название и цену.

**2.6 — Сколько кого.** Дан список героев с полем `"класс"`. Посчитай словарём-счётчиком, сколько героев каждого класса, и выведи результат парами (`воин — 2`).
> 💡 `по_классам[к] = по_классам.get(к, 0) + 1`, потом `.items()`.

**2.7 — Рейтинг по очкам.** Дан список игроков (`"имя"`, `"очки"`). Построй рейтинг по убыванию очков: собери пары `(очки, имя)`, отсортируй и выведи.
> 💡 Кортежи сортируются по первому элементу — поставь очки первыми.

**2.8 — Мини-меню.** Сделай приложение с меню в цикле `while`: `[1]` показать всех героев, `[2]` добавить героя (спросить имя и hp), `[3]` выход. Данные храни списком словарей.

## 🔴 Уровень 3 — со звёздочкой

**3.1 — Средний по классу.** Дан список героев (`"класс"`, `"hp"`). Посчитай средний hp только среди «воинов» (сначала отфильтруй, потом посчитай среднее по отфильтрованным).

**3.2 — Топ-3 по полю.** Дан список игроков с очками. Выведи тройку лучших: собери пары `(очки, имя)`, отсортируй по убыванию и возьми первые три (срез из Урока 3).

**3.3 — Кто сдал экзамен.** Дан список студентов (`"имя"`, `"балл"`). Собери отдельный список имён тех, у кого балл ≥ 60, и выведи, сколько человек сдало.

**3.4 — Инвентарь героя.** Создай героя-словарь, у которого поле `"вещи"` — это список. Добавь в его инвентарь два предмета (через `append` к вложенному списку) и выведи все вещи героя.
> 💡 `hero["вещи"].append("меч")` — добавляем в список ВНУТРИ словаря.

**3.5 — Отчёт по городам.** Дан список людей-словарей с полем `"город"`. Построй отчёт «город → сколько человек» словарём-счётчиком и выведи парами. Затем назови город, где людей больше всего.

**3.6 — Мини-база (CRUD).** Расширь приложение из 2.8: добавь команды `[3]` найти героя по имени и `[4]` удалить героя по имени (перед удалением проверь, что он есть). Итого меню: показать / добавить / найти / удалить / выход.

## ✅ Как проверить себя

- Поле записи достаёшь в два шага: `таблица[номер]["поле"]`.
- Поиск и фильтр — это перебор с `if` по нужному полю.
- Сортируешь по полю через пары-кортежи `(поле, имя)`, а не пытаешься `sort` список словарей.

## 📖 Что нужно знать за 2 минуты

Таблица данных — это **список словарей**: каждая запись — словарь, вся таблица — список.
```python
heroes = [
    {"имя": "Рыцарь", "hp": 100},
    {"имя": "Маг",    "hp": 70},
]
heroes[1]            # весь Маг (словарь)
heroes[1]["hp"]      # 70 — сначала [1] (список), потом ["hp"] (словарь)
for hero in heroes:  # перебор записей
    print(hero["имя"], hero["hp"])
heroes.append({...}) # добавить запись
```
Поиск/фильтр — перебор с `if` по полю. Сортировка по полю — через пары-кортежи `(поле, имя)`.

## Часть A — задания с пошаговым разбором

### Задание 1. Создать таблицу
**Тема:** список словарей.
```python
heroes = [{"имя": "Маг", "hp": 70}, {"имя": "Вор", "hp": 60}]
print(heroes[0]["имя"])   # Маг
print(len(heroes))        # 2
```
✅ Запись — словарь, таблица — список записей.

---

### Задание 2. Перебор записей
**Тема:** `for hero in heroes`.
```python
for hero in heroes:
    print(f"{hero['имя']} — hp {hero['hp']}")
```
✅ На каждом шаге `hero` — словарь; поле берём по ключу.

---

### Задание 3. Добавить и изменить
**Тема:** `append`, изменение поля.
```python
heroes.append({"имя": "Лучник", "hp": 80})
heroes[0]["hp"] = 50
print(heroes)
```
✅ Добавляем словарь; поле меняем `heroes[i]["поле"] = ...`.

---

### Задание 4. Поиск по полю
**Тема:** перебор + `if`.
```python
найден = None
for hero in heroes:
    if hero["имя"] == "Маг":
        найден = hero
print(найден)
```
✅ Заводим `None`, присваиваем при совпадении.

---

### Задание 5. Фильтр
**Тема:** собрать подходящие записи.
```python
сильные = []
for hero in heroes:
    if hero["hp"] >= 70:
        сильные.append(hero)
print(len(сильные))
```
✅ Пустой список → перебор → условие по полю → `append`.

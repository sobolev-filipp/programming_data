## Главные мысли

1. **Таблица данных = список словарей.** Запись — словарь, вся таблица — список записей.
2. Доступ в два шага: `heroes[i]["поле"]` (номер строки → ключ поля).
3. Перебор: `for hero in heroes: ... hero["hp"]`.
4. Поиск и фильтр — перебор с `if` по полю.
5. Сортировка по полю — через пары-кортежи `(поле, имя)` + `sort`.

---

## Таблица и доступ

```python
heroes = [
    {"имя": "Рыцарь", "класс": "воин", "hp": 100},
    {"имя": "Маг",    "класс": "маг",  "hp": 70},
]
heroes[1]            # весь Маг (словарь)
heroes[1]["hp"]      # 70 — сначала [1] (список), потом ["hp"] (словарь)
len(heroes)          # сколько записей
heroes.append({...}) # добавить запись
heroes[0]["hp"] = 90 # изменить поле
heroes.pop(0)        # удалить запись
```

---

## Поиск и фильтр

```python
# поиск по полю
найден = None
for hero in heroes:
    if hero["имя"] == "Маг":
        найден = hero

# фильтр в новый список
воины = []
for hero in heroes:
    if hero["класс"] == "воин":
        воины.append(hero)
```

---

## Итоги и чемпион

```python
сумма = 0
for hero in heroes:
    сумма += hero["hp"]
среднее = сумма / len(heroes)

чемпион = heroes[0]
for hero in heroes:
    if hero["hp"] > чемпион["hp"]:
        чемпион = hero
```

---

## Сортировка по полю (через кортежи)

```python
пары = []
for hero in heroes:
    пары.append((hero["hp"], hero["имя"]))
пары.sort(reverse=True)      # по убыванию hp
for hp, имя in пары:
    print(имя, hp)
```

Кортеж ставит нужное поле первым — сортировка идёт по нему. (Своих функций/lambda ещё нет — они в Модуле 5.)

---

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| `heroes["имя"]` TypeError | список по ключу | `heroes[0]["имя"]` |
| `KeyError` | опечатка/регистр ключа | ключ точно как задан |
| использовал `None` | не проверил поиск | `if найден is not None` |
| данные «разъехались» | параллельные списки | одна запись = один словарь |

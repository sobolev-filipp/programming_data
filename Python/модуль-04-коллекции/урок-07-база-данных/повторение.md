# Разминка перед уроком 7 (5 минут) 🔁

> Повторяем словари, списки и кортежи (Уроки 1–6). Устно или в `проба.py`.

---

## 1. Блиц-вопросы (устно)

1. Как достать значение из словаря по ключу? *(`d["ключ"]`)*
2. Как перебрать словарь сразу парами? *(`for k, v in d.items()`)*
3. Как добавить элемент в список? *(`список.append(x)`)*
4. Как отсортировать список кортежей? *(`.sort()` — по первому элементу)*
5. Что вернёт `[(70, "Маг"), (100, "Рыцарь")]` после сортировки? *(сначала (70,...), потом (100,...))*

---

## 2. Предскажи вывод

```python
hero = {"имя": "Маг", "hp": 70}
print(hero["имя"])
hero["hp"] = hero["hp"] - 20
print(hero["hp"])
```

<details><summary>Ответ</summary>

`Маг` · `50`.
</details>

---

## 3. Подумай

```python
# храним героев тремя списками — неудобно:
имена = ["Рыцарь", "Маг"]
hp = [100, 70]
# hp Мага — это hp[1]. А если вставить героя в середину — всё «съедет».
# Как хранить всё об одном герое ВМЕСТЕ?
```

<details><summary>Идея</summary>

Сегодня узнаем: каждый герой — **словарь** `{"имя": "Маг", "hp": 70}`, а все герои — **список словарей**. Так вся информация о герое лежит в одной записи.
</details>

---

## 4. Мостик к теме

Словарь хранит поля одного объекта, список хранит много объектов. Соединим их: **список словарей** — это таблица данных, как в настоящей базе. Сегодня — финал модуля: мини-база персонажей (показать, найти, отфильтровать, отсортировать). 🗃️

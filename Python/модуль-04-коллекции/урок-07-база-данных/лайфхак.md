# Лайфхаки урока 7 «Мини-база данных» 🧰

> Приёмы для работы с таблицами-словарями.

---

## 🎯 Запись = словарь, таблица = список словарей

```python
heroes = [{"имя": "Маг", "hp": 70}, {"имя": "Вор", "hp": 60}]
```

Вся информация об объекте — в одном словаре. Много объектов — список таких словарей. Так данные не «разъезжаются».

---

## 🎯 Доступ в два шага

```python
heroes[1]["hp"]      # сначала строка [1], потом поле ["hp"]
```

`[номер]` — это работа списка, `[ключ]` — работа словаря. Не путай: `heroes["hp"]` — ошибка.

---

---

## 🎯 Фильтр записей = фильтр чисел, но по полю

```python
результат = []
for hero in heroes:
    if hero["hp"] >= 80:
        результат.append(hero)
```

Та же схема, что в Уроке 2, только условие смотрит на поле записи.

---

## 🎯 Сортировка по полю без своих функций

```python
пары = []
for hero in heroes:
    пары.append((hero["hp"], hero["имя"]))
пары.sort(reverse=True)
```

Кортеж ставит поле первым — сортировка идёт по нему. (Аккуратный способ, пока не прошли `def`/lambda — они в Модуле 5.)

---

## 🎯 Отчёт «сколько кого» — счётчик по полю

```python
по_классам = {}
for hero in heroes:
    k = hero["класс"]
    по_классам[k] = по_классам.get(k, 0) + 1
```

Группировка записей по полю — основа любых отчётов.

---

## 🐞 Топ-5 ошибок

1. **`heroes["имя"]`** — список по ключу → `TypeError`. Нужно `heroes[0]["имя"]`.
2. **`KeyError`** — опечатка или регистр ключа (`"HP"` ≠ `"hp"`).
3. **Использовал результат поиска без проверки** — а он `None`.
4. **Параллельные списки** вместо записей — данные «съезжают».
5. **`sort` списка словарей** без ключа — собирай пары `(поле, ...)`.

---

## 🎓 Для продвинутых

- **Вложенность:** поле может быть списком (`"вещи": []`) или словарём (карточка внутри карточки).
- **Группировка + список:** можно копить `d.setdefault(поле, []).append(запись)` — раскладывать записи по группам.
- **`in` по полю:** проверить, есть ли запись с нужным полем, удобно флагом `найден`.
- В **Модуле 5** появятся свои функции `def` — тогда поиск/фильтр/сортировку по полю можно будет оформить одной командой и сортировать `sorted(..., key=...)`.

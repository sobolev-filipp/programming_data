## 🎯 `.get()` вместо падения

```python
book["Кот"]              # ❌ KeyError — программа падает
book.get("Кот")          # ✅ None — тихо
book.get("Кот", "нет")   # ✅ запасное значение
```

Не уверен, есть ли ключ, — всегда `.get()`. Это спасает от `KeyError`.

---

## 🎯 Добавить и изменить — одна и та же строка

```python
d[key] = value
```

Ключа не было — пара добавится. Был — значение заменится. Отдельной команды «добавить» не нужно.

---

## 🎯 Словарь-счётчик (запомни этот приём!)

```python
counts = {}
for x in data:
    counts[x] = counts.get(x, 0) + 1
```

Считает, сколько раз что встретилось: буквы в слове, голоса, добыча в инвентарь. `.get(x, 0)` даёт 0 для нового ключа — не нужно проверять «а был ли он».

---

## 🎯 Проверка ключа через `in`

```python
if name in book:
    print(book[name])
else:
    print("нет контакта")
```

`in` у словаря проверяет **ключи**, а не значения.

---

## 🎯 Перебор идёт по ключам

```python
for name in book:            # это КЛЮЧИ
    print(name, book[name])  # значение достаём по ключу
```

Хочешь только значения — `for v in book.values()`. Хочешь и то и то (пары) — `.items()` (удобная распаковка `for k, v in ...` будет в Уроке 6).

---

## 🎯 Сумма/максимум по значениям

```python
sum(inventory.values())      # сколько всего
max(prices.values())         # самая большая цена
```

Готовые функции работают со «списком значений» из `.values()`.

---

## 🐞 Топ-5 ошибок

1. **`d["нет_такого"]`** → `KeyError`: бери `.get()` или проверь `in`.
2. **Перепутал скобки:** словарь — фигурные `{ }`, не `[ ]` и не `( )`.
3. **Регистр ключа:** `"аня"` и `"Аня"` — разные ключи.
4. **Список как ключ** → `unhashable type: 'list'`: ключ — строка/число/кортеж.
5. **Ждал значения, а `for k in d` дал ключи** — значение бери `d[k]`.

---

## 🎓 Для продвинутых

- **`dict.setdefault(k, 0)`** — «дай значение или заведи с 0» (короче ветвлений).
- **Значением может быть что угодно** — список, другой словарь (вложенные словари → карточки героев).
- **Ключом — только неизменяемое** (строка, число, кортеж). Поэтому кортеж-координата `(x, y)` — валидный ключ, а список — нет.
- **`.get(k, 0) + 1`** — сердце любого счётчика; в Уроке 6 к нему добавятся множества `set` для уникальных элементов.

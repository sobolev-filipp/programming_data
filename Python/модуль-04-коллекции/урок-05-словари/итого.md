## Главные мысли

1. **Словарь `{ключ: значение}`** — хранит пары, ищет **по ключу**, а не по номеру.
2. Достаём значение: `d[key]`. Нет ключа → **`KeyError`**.
3. Безопасно: `d.get(key)` → `None` (или запасное `d.get(key, "нет")`).
4. Добавить и изменить — одинаково: `d[key] = value`. Ключ уникален.
5. Перебор `for k in d` идёт **по ключам**; значение — `d[k]`.

---

## Создание и доступ

```python
book = {"Аня": "555-01", "Боря": "555-02"}
book["Аня"]        # "555-01"  — по ключу
len(book)          # 2         — сколько пар
book["Кот"]        # KeyError! — ключа нет
```

⚠️ Скобки: список `[ ]`, кортеж `( )`, **словарь `{ }`**.

---

## Добавить / изменить / удалить

```python
book["Гена"] = "555-04"     # ключа не было -> добавили
book["Аня"]  = "555-99"     # ключ был    -> заменили
del book["Боря"]            # удалить пару
val = book.pop("Гена")      # удалить и вернуть значение
```

---

## Безопасный доступ и проверка

```python
book.get("Аня")             # "555-01"
book.get("Кот")             # None (не падает)
book.get("Кот", "нет")      # "нет" (запасное)
"Аня" in book               # True — есть ли ключ
```

💡 Не уверен в ключе — `.get()` или `in`. Уверен — можно `[ ]`.

---

## Три взгляда и перебор

```python
book.keys()      # ключи
book.values()    # значения
book.items()     # пары (ключ, значение) — кортежи

for name in book:                # по ключам
    print(name, book[name])

sum(inventory.values())          # сумма значений-чисел
```

🔜 `for k, v in book.items()` — в Уроке 6.

## Словарь-счётчик (важный приём)

```python
counts = {}
for x in loot:
    counts[x] = counts.get(x, 0) + 1   # было (или 0) + 1
```

Считает, сколько раз что встретилось (инвентарь, голоса).

---

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| `KeyError` | нет такого ключа | `.get()` или `in` |
| перепутал скобки | словарь — `{ }` | не `[ ]` и не `( )` |
| `"аня"` ≠ `"Аня"` | регистр/пробел в ключе | ключ пишется точно |
| `unhashable type: 'list'` | список как ключ | ключ — строка/число/кортеж |

---

## Что должно остаться в голове

1. Словарь `{ }` — пары «ключ → значение», доступ `d[key]`.
2. Нет ключа → `KeyError`; безопасно — `.get()` / `in`.
3. `d[k] = v` — добавить ИЛИ изменить.
4. Перебор по ключам: `for k in d: ... d[k]`.
5. Счётчик: `d[x] = d.get(x, 0) + 1`.

# Разминка перед уроком 5 (5 минут) 🔁

> Повторяем списки, кортежи и распаковку (Уроки 1–4). Устно или в `проба.py`.

---

## 1. Блиц-вопросы (устно)

1. В каких скобках список, а в каких кортеж? *(список `[ ]`, кортеж `( )`)*
2. Что вернёт `lst[0]`? *(первый элемент по номеру)*
3. Можно ли изменить кортеж? *(нет, он заморожен)*
4. Что делает `x, y = point`? *(распаковка — разложить по переменным)*
5. Как проверить, есть ли элемент в списке? *(`элемент in список`)*

---

## 2. Предскажи вывод

```python
book = [("Аня", "555-01"), ("Боря", "555-02")]
for name, phone in book:
    print(name, "->", phone)
```

<details><summary>Ответ</summary>

`Аня -> 555-01` · `Боря -> 555-02`. (Список пар-кортежей с распаковкой.)
</details>

---

## 3. Подумай

```python
# в списке телефон ищем по НОМЕРУ элемента:
phones = ["555-01", "555-02", "555-03"]
# а как бы найти телефон именно АНИ, не помня её номер в списке?
```

<details><summary>Идея</summary>

В списке пришлось бы помнить, что Аня — элемент №0. Неудобно! Сегодня узнаем про **словарь**: там значение достают **по имени-ключу** — `book["Аня"]`, а не по номеру.
</details>

---

## 4. Мостик к теме

Список и кортеж хранят данные **по номерам** (`0, 1, 2...`). Но телефон Ани мы помним как «телефон **Ани**», а не «элемент №3». Хочется искать **по имени**. Для этого есть **словарь** `{ключ: значение}` — телефонная книга, инвентарь, меню. Сегодня — про него. 🔑

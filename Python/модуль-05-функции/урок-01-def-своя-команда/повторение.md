## ⚡ Блиц по Модулю 4 «Коллекции» (1–2 мин)

1. Чем список `[1, 2, 3]` отличается от кортежа `(1, 2, 3)`?
2. Как узнать длину списка `games`?
3. Что вернёт `d.get("x", 0)`, если ключа `"x"` в словаре нет?
4. Как добавить элемент в конец списка?
5. Что делает `set([1, 1, 2, 2, 3])`?

<details><summary>Ответы</summary>

1. Список **изменяемый** (можно менять элементы), кортеж — **нет**. 2. `len(games)`. 3. Вернёт `0` (значение по умолчанию), ошибки не будет. 4. `games.append(x)`. 5. Уберёт дубли → `{1, 2, 3}` (множество, порядок не гарантирован).
</details>

## 🔮 Предскажи вывод (2 мин)

Что напечатает каждый фрагмент? Сначала ответь, потом проверь.

**A.**
```python
word = "питон"
print(word * 3)
```

**B.**
```python
nums = [5, 2, 8, 1]
print(max(nums), min(nums), sum(nums))
```

**C.**
```python
for i in range(1, 4):
    print(i, "x", 2, "=", i * 2)
```

<details><summary>Ответы</summary>

**A.** `питонпитонпитон` (строка размножилась 3 раза, без пробелов). **B.** `8 1 16`. **C.**
```
1 x 2 = 2
2 x 2 = 4
3 x 2 = 6
```
</details>

## Что такое функция

**Функция — это своя команда, которую ты сам придумал и назвал.** Мы весь год пользовались чужими командами (`print`, `input`, `len`). Теперь научимся делать свои.

Делается в два шага:
1. **Объявить** командой `def` — описать, что команда делает.
2. **Вызвать** — написать её имя со скобками, чтобы она сработала.

```python
def hello():          # 1) объявили команду hello
    print("Привет!")  #    тело - с отступом

hello()               # 2) вызвали - напечаталось "Привет!"
```

> ⚠️ Если только объявить и не вызвать — на экране будет **пусто**. `def` сам по себе ничего не печатает.

## Задание 1 (с разбором) — первая функция

Сделай функцию `ura()`, которая печатает `Ура! Получилось!`, и вызови её два раза.

**Разбор:**
```python
def ura():                    # def + имя + () + :
    print("Ура! Получилось!") # тело с отступом (Tab или 4 пробела)

ura()                         # первый вызов
ura()                         # второй вызов
```
Запусти — строка напечатается дважды. Поздравляю, это твоя первая команда!

## Задание 2 (с разбором) — функция-рамка

Сделай функцию `ramka()`, которая печатает три строки: `*****`, `* HI *`, `*****`. Вызови её.

**Разбор:**
```python
def ramka():
    print("*****")
    print("* HI *")
    print("*****")

ramka()
```
Все три `print` — с отступом, значит все они внутри функции. Один вызов `ramka()` печатает сразу все три строки.

## Задание 3 (с разбором) — параметр

Сделай функцию `privet(name)`, которая печатает `Привет, <имя>!`. Вызови для двух имён.

**Разбор:**
```python
def privet(name):              # name - параметр (окошко для данных)
    print("Привет,", name + "!")

privet("Аня")    # name = "Аня"  -> Привет, Аня!
privet("Боря")   # name = "Боря" -> Привет, Боря!
```
То, что в скобках при вызове, попадает в `name`. Одна функция — разные приветствия.

## Задание 4 (с разбором) — порядок: сначала объяви

Почему эта программа падает? Исправь её.
```python
pok()
def pok():
    print("Пока!")
```

**Разбор:** вызов `pok()` стоит **выше** определения — на этой строке Python ещё «не знает» такой команды, будет `NameError`. Правило: **определение — вверху, вызов — ниже.**
```python
def pok():
    print("Пока!")

pok()            # теперь всё хорошо
```

## Задание 5 (с разбором) — два параметра

Сделай функцию `summa(a, b)`, которая печатает `a + b = результат`.

**Разбор:**
```python
def summa(a, b):               # два параметра через запятую
    print(f"{a} + {b} = {a + b}")

summa(3, 5)      # 3 + 5 = 8
summa(10, 7)     # 10 + 7 = 17
```
При вызове первое число попадает в `a`, второе в `b` — **по порядку**.

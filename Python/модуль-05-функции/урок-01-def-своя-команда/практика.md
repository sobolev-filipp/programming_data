# 📝 Практика · Урок 1 «Своя команда для черепашки» (`def`)

**Темы:** объявление функции `def имя():`, тело по отступу, вызов `имя()`, правило «сначала объяви — потом вызывай», параметры (один и несколько), порядок аргументов. Плюс повторяем всё прошлое: `input`, `if/elif/else`, циклы `for/while`, `random`, строки, списки — но теперь **внутри своих функций**.

> 🎯 **Как работать:** решай по порядку и запускай после каждой задачи. Уровни: 🟢 разминка (простые функции) · 🟡 мини-программы (функции с данными и логикой внутри) · 🔴 со звёздочкой (функции зовут функции, мини-приложения) · 🐢 практикум в песочнице черепашки. В каждой задаче сказано, **что сделать** и **что получится**. Подсказка — наводка на идею, не готовый код, и она есть не у каждой задачи.
>
> 📌 Важно для этого урока: функция пока **делает** действие (печатает, рисует), но ещё **не возвращает** ответ (`return` будет в Уроке 2). Поэтому результат показываем через `print` *внутри* функции. И помни: все `def` — вверху, вызовы — ниже.

## 🟢 Уровень 1 — разминка (первые свои команды)

**1. Своя команда «привет».** Сделай функцию `privet()` без параметров: пусть печатает две строки — `Привет!` и `Доброе утро!`. Потом вызови её **три раза подряд**. Так ты увидишь: описал команду один раз, а работает сколько нужно.

**2. Разделитель.** Напиши функцию `liniya()`, которая печатает строку из 20 дефисов (`--------------------`). Выведи с её помощью «бутерброд»: строка текста → `liniya()` → другая строка текста → `liniya()`. Удобный разделитель между блоками.
> 💡 Строку из одинаковых символов можно получить умножением: вспомни, что делает `"-" * 20`.

**3. Приветствие по имени.** Сделай функцию `privet_name(name)` с одним параметром. Пусть печатает `Привет, <имя>! Рады тебя видеть.`. Вызови её для трёх разных друзей — одна команда, а приветствие каждый раз своё.

**4. Квадрат числа.** Напиши функцию `kvadrat(a)`: пусть печатает число и его квадрат в виде `7 в квадрате = 49`. Проверь на числах 7, 9 и 12 — три вызова.

**5. Эхо.** Сделай функцию `povtori(slovo)`, которая печатает переданное слово **три раза в одну строку** через пробел (например, `povtori("гав")` → `гав гав гав`). Вызови для двух разных слов.
> 💡 Размножить строку поможет `*`, а пробел между повторами можно вшить прямо в слово-множитель.

**6. Сумма двух чисел.** Напиши функцию `summa(a, b)` с двумя параметрами: пусть печатает пример в виде `3 + 5 = 8`. Проверь на парах (3, 5) и (10, 20).

**7. Предскажи вывод.** *(на подумать)* Не запуская, определи, что напечатает программа, и запиши ответ. Потом проверь запуском.
```python
def ab():
    print("A")
    print("B")

print("Старт")
ab()
print("Середина")
ab()
print("Конец")
```

## 🟡 Уровень 2 — мини-программы (логика внутри функции)

**8. Открытка в рамке.** Сделай функцию `otkrytka(name, povod)` с двумя параметрами. Пусть печатает открытку в звёздочках:
```
****************
Дорогой Аня
Поздравляю с: Днём рождения
****************
```
Вызови для двух разных людей и поводов.

**9. Чёт или нечет.** *(повторяем `if/else` и `%`)* Напиши функцию `chetnoe(n)`: если число `n` делится на 2 без остатка — печатает `<n> - чётное`, иначе `<n> - нечётное`. Проверь на 4, 7 и 10.
> 💡 Остаток от деления даёт `%`. Условие — обычный `if/else` внутри тела функции.

**10. Бросок кубика.** *(повторяем `random`)* Сделай функцию `kubik()`, которая бросает игральный кубик — печатает случайное число от 1 до 6. Вызови три раза: получится три разных (или нет!) броска. Не забудь `import random` вверху.

**11. Таблица умножения.** *(повторяем цикл `for`)* Напиши функцию `tablica(n)`, которая печатает таблицу умножения числа `n` от 1 до 10 строками вида `7 x 1 = 7`, `7 x 2 = 14`, … Вызови для `tablica(7)`.
> 💡 Внутри функции — цикл `for i in range(1, 11)`. Печатай латинскую `x`, а не знак умножения (иначе на Windows программа упадёт).

**12. Приветствие по времени.** *(повторяем `if/elif/else`)* Сделай функцию `privet_po_chasu(hour)`: по номеру часа (0–23) печатает `Доброе утро` (5–11), `Добрый день` (12–17), `Добрый вечер` (18–22) или `Доброй ночи` (остальное). Проверь на 9, 15, 20 и 2.

**13. Сумма списка.** *(повторяем списки)* Напиши функцию `summa_spiska(numbers)`, которая принимает **список чисел** и печатает их сумму. Проверь на `summa_spiska([10, 20, 30])` → `Сумма: 60`.
> 💡 Внутри заведи копилку `total = 0`, перебери список циклом и прибавляй каждый элемент.

**14. Самый большой.** *(повторяем поиск максимума)* Сделай функцию `maximum(numbers)`, которая принимает список чисел и печатает наибольшее. Проверь на `[4, 9, 2, 15, 7]` → `Максимум: 15`. (Встроенным `max` не пользуйся — найди циклом, для тренировки.)

**15. Считаем гласные.** *(повторяем строки)* Напиши функцию `glasnye(word)`, которая печатает, сколько в слове гласных букв (`а е ё и о у ы э ю я`). Проверь на `glasnye("программирование")` → `Гласных: 7`.
> 💡 Счётчик + перебор букв циклом; букву проверяй через `in "аеёиоуыэюя"`.

**16. Награда за очки.** *(на подумать, `if`-лестница)* Сделай функцию `nagrada(ochki)`: 90 и больше → `Золото`, 70–89 → `Серебро`, 50–69 → `Бронза`, меньше 50 → `В следующий раз повезёт`. Проверь на 95, 75, 55 и 30.

**17. Стоимость покупки.** *(на подумать, арифметика)* Напиши функцию `stoimost(kolichestvo, cena)`, которая печатает, сколько стоит покупка: например, 3 шт по 50 руб → `Итого: 150 руб`. Проверь на (3, 50) и (10, 99).

**18. Процент выполнения.** *(на подумать)* Сделай функцию `progress(sdelano, vsego)`, которая печатает процент выполнения задания. Например, `progress(3, 4)` → `Выполнено: 75.0%`. Проверь ещё на `(7, 10)`.
> 💡 Процент — это `сделано / всего * 100`. Можно округлить через `round(..., 1)`.

## 🔴 Уровень 3 — со звёздочкой

**19. Карточка героя.** Сделай две функции: `liniya()` (печатает `----------`) и `kartochka(name, hp)`. Внутри `kartochka` **вызови** `liniya()`, потом напечатай имя и hp, потом снова `liniya()`. Получится карточка в линиях. Это функция, которая зовёт другую функцию!
```
----------
Герой: Рыцарь
HP: 100
----------
```

**20. Меню в цикле.** *(повторяем `while`)* Напиши функцию `menu()`, которая печатает три пункта: `[1] Играть`, `[2] Правила`, `[3] Выход`. Затем сделай цикл `while True`: показывай меню функцией `menu()`, спрашивай выбор; на `1` печатай `Погнали!`, на `2` — `Правила простые...`, на `3` — выходи из цикла. Меню рисуется одной командой.

**21. Дуэль на кубиках.** *(повторяем `random` + `if`)* Сделай функцию `duel(name1, name2)`: каждому игроку брось кубик (случайное 1–6), напечатай оба броска и объяви, кто выиграл (или ничью). Проверь на `duel("Аня", "Боря")`.
> 💡 Два случайных числа внутри функции, затем сравнение трёх веток: больше / меньше / равно.

**22. Стена из символов.** *(на подумать, вложенный цикл)* Напиши функцию `stena(symbol, n)`, которая печатает квадрат `n` на `n` из переданного символа. Например, `stena("#", 3)`:
```
###
###
###
```
Проверь ещё на `stena("*", 5)`.
> 💡 Одну строку из `n` символов даёт `symbol * n`. Чтобы получить `n` таких строк — повтори печать в цикле `for`.

**23. Сколько будет через год.** *(на подумать)* Сделай функцию `pozdravlenie(name, vozrast)`: пусть печатает поздравление и считает, сколько человеку исполнится **через 5 лет**. Например, `pozdravlenie("Аня", 12)` → `Аня, тебе 12! А через 5 лет будет 17.`

**24. Проверка делимости.** *(на подумать, `%`)* Напиши функцию `delitsya(a, b)`, которая печатает, делится ли `a` на `b` без остатка: `15 делится на 3 нацело` или `14 на 3 не делится (остаток 2)`. Проверь на (15, 3) и (14, 3).
> 💡 Нацело — когда `a % b == 0`. В ветке «не делится» сам остаток — это `a % b`.

## 🐢 Практикум в песочнице: свои команды для черепашки

Открой файл `материалы/черепашка_команды.py`. Поле 16×16 клеток, и дана **одна** готовая команда. Твоя работа — **сочинять свои команды через `def`** и рисовать ими. Меняй номер в строке `TASK = ...` и пиши свой код в блоке «ТВОИ КОМАНДЫ».

**Команды каркаса:**

`paint(x, y)` — закрасить одну клетку с координатами `(x, y)`; `x` вправо `0..15`, `y` вверх `0..15`.

`paint(x, y, "green")` — то же, но закрасить своим цветом (`"red"`, `"blue"`, `"green"`, `"#2563eb"`, …).

**Задания:**

**1. Команда hline.** Сочини функцию `hline(x1, x2, y)` — закрашивает горизонтальную линию клеток на высоте `y` от `x1` до `x2`. Внутри — цикл `for` по `x`, каждая клетка через `paint`. Нарисуй ею две линии: нижнюю `hline(2, 13, 2)` и верхнюю `hline(2, 13, 13)`.

**2. Команда vline.** По образцу `hline` сочини `vline(x, y1, y2)` — вертикальную линию в столбце `x` от `y1` до `y2`. Нарисуй левую и правую стенки поля двумя вызовами.

**3. Команда box (заливка).** Сочини `box(x1, y1, x2, y2)` — закрашивает прямоугольник целиком. Внутри — вложенный цикл: по всем `x` и по всем `y`. Нарисуй закрашенный квадрат `box(5, 5, 10, 10)`.

**4. Рамка.** Собери функцию `ramka(x1, y1, x2, y2)`, которая рисует только **контур** прямоугольника (не заливку): две горизонтальные линии (`hline`) и две вертикальные (`vline`). Внутри одной своей функции зови другие свои функции!

**5. Крестик.** Сочини `krestik(y)` — рисует крест: одну горизонтальную линию через всё поле на высоте `y` и одну вертикальную по центру. Используй `hline` и `vline`.

**6. Флаг из трёх полос.** Нарисуй флаг: три широкие горизонтальные полосы разного цвета. Сделай функцию `polosa(y1, y2, color)` (заливка прямоугольника во всю ширину поля цветом `color`) и вызови её три раза для трёх цветов, одну над другой.
> 💡 `polosa` — это почти `box` во всю ширину (`x` от 0 до 15), только с параметром-цветом; цвет передай дальше в `paint(x, y, color)`.

**7. Лесенка.** Нарисуй ступеньки: первая горизонтальная линия короткая внизу слева, каждая следующая — выше и правее. Сделай это циклом, вызывая `hline` со сдвигом на каждом шаге.

**8. Квадрат заданного размера.** Сочини `kvadrat(x, y, size)` — рисует контур квадрата со стороной `size`, левый нижний угол в `(x, y)`. Нарисуй два квадрата разного размера в разных местах поля.
> 💡 Правый верхний угол — это `(x + size, y + size)`. Дальше это обычная рамка по четырём сторонам.

**9. Шахматка.** Закрась клетки поля в шахматном порядке (через одну). Пройди все клетки двумя вложенными циклами и крась только те, где сумма координат чётная (`(x + y) % 2 == 0`).

**10. Твоя буква.** *(творческое)* Из линий `hline`/`vline`/`box` собери первую букву своего имени на поле. Заверни рисунок в свою функцию с понятным именем (например, `bukva_A()`).

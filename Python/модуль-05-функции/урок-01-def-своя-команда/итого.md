# 📌 Итого · Урок 1 «Своя команда для черепашки» (`def`)

> Шпаргалка «вспомнить за 3 минуты». Главные мысли → код → ошибки → чек-лист.

---

## 🧠 Главные мысли

1. **Функция — своё имя для куска кода.** Повторяется действие — не копируй, заведи функцию.
2. **Объявить (`def`) ≠ выполнить.** `def` только *запоминает* команду. Чтобы она сработала — её надо **вызвать** по имени.
3. **Вызов = прыжок в тело и возврат.** Python уходит в функцию, выполняет её и возвращается на то же место.
4. **Сначала объяви, потом вызывай.** Все `def` — вверху файла, вызовы — ниже.
5. **Параметры — данные на вход.** Что передашь в скобках при вызове (аргумент), то попадёт в параметр внутри. Порядок важен!

---

## 💻 Мини-шпаргалка кода

**Функция без параметров:**
```python
def ramka():                 # объявили (def + имя + () + :)
    print("+-----+")         # тело - с отступом
    print("| HI  |")
    print("+-----+")

ramka()                      # вызвали (имя со скобками)
ramka()                      # можно сколько угодно раз
```

**Функция с параметром:**
```python
def privet(name):            # name - параметр
    print("Привет,", name)

privet("Аня")                # аргумент "Аня" -> name
privet("Боря")
```

**Несколько параметров (по порядку!):**
```python
def summa(a, b):
    print(f"{a} + {b} = {a + b}")

summa(3, 5)                  # 3 + 5 = 8
```

**🐢 Своя команда для черепашки:**
```python
def hline(x1, x2, y):        # дана только paint(x, y)
    for x in range(x1, x2 + 1):
        paint(x, y)

hline(2, 10, 4)              # линия одной командой
```

## 🐞 Частые ошибки

| Симптом | Причина | Лечение |
|---|---|---|
| Пусто на экране | объявил, но не вызвал | добавь `имя()` |
| `NameError: ... not defined` | вызов выше `def` | перенеси `def` вверх |
| `IndentationError` | нет отступа в теле | строки внутри — с отступом |
| `TypeError: missing ... argument` | мало аргументов | дай столько, сколько параметров |
| вывелось `<function ...>` | забыл скобки | вызов — `ramka()`, а не `ramka` |

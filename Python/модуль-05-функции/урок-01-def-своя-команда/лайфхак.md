# 🧰 Лайфхаки · Урок 1 «Функции `def`»

> Трюки, горячие клавиши и таблица частых ошибок. Доп-слой к уроку.

---

## 💡 Трюки

- **Имя функции — глагол-действие.** `show_menu`, `draw_box`, `ask_name`, `print_card`. Тогда вызов читается как приказ: «покажи меню». Это стандарт — старшим пригодится в любом языке.
- **Все `def` — вверху файла.** Сначала «склад команд» (определения), ниже — основная программа (вызовы). Так никогда не поймаешь `NameError` из-за порядка.
- **Пустая функция-заглушка.** Если задумал функцию, но ещё не написал тело, поставь `pass` — Python не ругнётся:
  ```python
  def bonus():
      pass        # сделаю позже
  ```
- **Документируй строкой.** Первая строка в кавычках сразу под `def` — подсказка, что функция делает (видно при наведении в редакторе):
  ```python
  def ramka():
      """Печатает рамку с приветствием."""
      ...
  ```
- **Табуляция — вперёд, Shift+Tab — назад.** Выдели строки и жми Tab, чтобы занести их в тело функции, Shift+Tab — чтобы вынести. Быстрее, чем расставлять пробелы вручную.
- **Повторяется код — F-сигнал «Function».** Увидел два одинаковых куска — первый кандидат на `def`. Это и короче, и правится в одном месте.

## ⌨️ Горячие клавиши (PyCharm / VS Code)

| Клавиши | Что делает |
|---|---|
| `Tab` / `Shift+Tab` | увеличить / уменьшить отступ выделенного |
| `Ctrl` + клик по имени функции | прыгнуть к её определению |
| `Ctrl` + `/` | закомментировать/раскомментировать строку |
| `Ctrl` + `D` (PyCharm) / `Ctrl`+`C` пустой строки (VS Code) | дублировать строку |

## 🐞 Таблица частых ошибок

| Сообщение / симптом | Причина | Лечение |
|---|---|---|
| (пусто на экране) | объявил функцию, но не вызвал | добавь строку `имя()` ниже |
| `NameError: name 'f' is not defined` | вызвал функцию **выше** её `def` | перенеси `def` вверх файла |
| `IndentationError: expected an indented block after ...` | нет отступа в теле функции | строки внутри — с отступом (Tab) |
| `TypeError: f() missing 1 required positional argument: 'b'` | передал **мало** аргументов | дай столько же, сколько параметров в `def` |
| `TypeError: f() takes 2 positional arguments but 3 were given` | передал **много** аргументов | убери лишний |
| функция «не сработала», вывелось `<function f at 0x...>` | забыл скобки: написал `f` вместо `f()` | вызов — всегда со скобками |
| данные перепутались местами | аргументы встали не по порядку | порядок аргументов = порядок параметров |
| `SyntaxError` на строке `def` | забыл `:` в конце | `def имя():` — двоеточие обязательно |

## 🧠 Запомни одной фразой

> **`def` — описал команду. `имя()` — позвал её. Что в скобках при вызове — то и внутри параметра.**

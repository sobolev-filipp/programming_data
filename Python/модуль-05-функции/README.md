# Модуль 5 — 🧩 Функции (5 уроков, 10 ч) 🔄 В РАБОТЕ (1/5)

> Учимся **создавать свои команды** — функции. Выносим повторяющийся код под имя, передаём данные через параметры, возвращаем результат, разбираемся с областью видимости и доходим до рекурсии. Стек вызовов — на схеме «матрёшка». Turtle — песочница, где ребёнок пишет **свои** команды (`paint/hline/vline/box`).

## Идеи и приёмы модуля

- **Функция = своё имя для куска кода** — не копировать, а назвать (принцип DRY).
- **Объявить ≠ выполнить**; вызов — прыжок в тело и возврат.
- **Параметры и аргументы** — данные на вход; порядок важен.
- **`return`** — функция не только делает, но и *возвращает* ответ (Урок 2).
- **Область видимости** — где живут переменные (Урок 4).
- **Рекурсия** — функция зовёт саму себя; стек вызовов «матрёшка» (Урок 5).
- 🐢 Turtle — песочница «свои команды»: ребёнок сам сочиняет функции-кисти.

# 🔁 Разминка (5 минут) · Урок 3

> Вспоминаем уроки 1–2 (переменные, f-строки, арифметика, склейка строк) — сегодня добавим к ним случайность.

## 🎤 Блиц-вопросы (устно, 2 мин)

1. Что делает f-строка `f"Счёт: {score}"`? (подставляет переменную)
2. Чем `17 // 5` отличается от `17 / 5`? (целое 3 vs дробное 3.4)
3. Что даёт `17 % 5`? (остаток 2)
4. Что вернёт `"ня" * 3`? (`няняня`)
5. Почему `"5" + "5"` = `"55"`, а не `10`? (это строки, идёт склейка)

## 🔥 Предскажи вывод (у проектора, 2 мин)

```python
a = 3
b = 4
print(f"Сумма: {a + b}, произведение: {a * b}")   # ? → Сумма: 7, произведение: 12
print("=" * 10)                                    # ? → ==========
name = "гера"
print(name.upper())                                # ? → ГЕРА
```

> 💡 Всё это мы уже умеем. Сегодня программа научится делать то, что мы **не можем предсказать заранее** — выдавать случайное. Это оживит любые проекты.

Наберите и запустите (первое знакомство со случайностью):

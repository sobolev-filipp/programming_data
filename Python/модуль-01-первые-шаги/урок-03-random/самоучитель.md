> Формат: **краткое напоминание темы → задание**. Первые 5 — с пошаговым разбором, дальше — с мини-подсказками. Всего 16 заданий. Не забывай `import` в начале файла!

# 🧑‍🏫 Часть A. Разбираем вместе

## 1. Подключаем библиотеку

**Тема:** библиотека — ящик готовых инструментов. Подключаем командой `import` в начале файла.

**Задание:** подключи `random` и выведи случайное число от 1 до 10.

**Разбор по шагам:**
1. Первая строка файла: `import random`.
2. Возьми инструмент через точку: `random.randint(1, 10)`.
3. Выведи: `print(random.randint(1, 10))`.
4. Запусти несколько раз — число меняется.

✅ `import random` + `print(random.randint(1, 10))`.

---

## 2. Бросаем кубик

**Тема:** `random.randint(a, b)` — случайное целое, оба конца включены.

**Задание:** брось кубик и выведи `Выпало: N`.

**Разбор по шагам:**
1. `import random`.
2. `dice = random.randint(1, 6)`.
3. `print(f"Выпало: {dice}")`.
4. Проверь: значение бывает и 1, и 6.

✅ `randint(1, 6)` → f-строка.

---

## 3. Случайный выбор

**Тема:** `random.choice([...])` выбирает один вариант из списка (в квадратных скобках).

**Задание:** программа выбирает случайную еду на обед из 4 вариантов.

**Разбор по шагам:**
1. `import random`.
2. `food = random.choice(["суп", "паста", "плов", "салат"])`.
3. `print(f"Сегодня на обед: {food}")`.
4. Запусти несколько раз — блюдо меняется.

✅ `choice` со списком вариантов.

---

## 4. Библиотека math

**Тема:** `math` — точные вычисления: `sqrt` (корень), `pi`, `floor`/`ceil` (округление вниз/вверх).

**Задание:** спроси число и выведи его квадратный корень.

**Разбор по шагам:**
1. `import math`.
2. `n = int(input("Число: "))`.
3. `print(f"Корень из {n} = {math.sqrt(n)}")`.
4. Проверь: `sqrt(16)` = `4.0`.

✅ `import math` + `math.sqrt(n)`.

---

## 5. Собираем предсказателя

**Тема:** соединяем `input` + `choice` — программа отвечает на вопрос случайно.

**Задание:** спроси вопрос и дай случайный ответ из 3 вариантов.

**Разбор по шагам:**
1. `import random`.
2. `q = input("Твой вопрос: ")`.
3. `ans = random.choice(["Да", "Нет", "Спроси позже"])`.
4. `print(f"Ответ: {ans}")`.

✅ Магия предсказателя = `input` + `choice`.

## Главные мысли

1. **Библиотека — ящик готовых инструментов.** Не пиши с нуля — подключи `import` и пользуйся.
2. **`import` — в самом верху файла**, один раз. Дальше инструменты берём через точку: `random.randint(...)`.
3. **`randint(a, b)` включает оба конца** — `randint(1, 6)` даёт 6 вариантов.
4. **`choice([...])`** выбирает один вариант из списка — сердце игр.

---

## Библиотека random

```python
import random

random.randint(1, 6)          # случайное ЦЕЛОЕ 1..6 (оба включены)
random.choice(["A", "B", "C"])# случайный ВЫБОР из вариантов
random.random()               # дробное 0.0 .. 1.0 (шанс)
random.shuffle(колода)        # перемешать список (Модуль 4)
random.uniform(1.5, 6.5)      # случайное ДРОБНОЕ в диапазоне
```

**Шаблоны:**
```python
dice = random.randint(1, 6)
coin = random.randint(0, 1)                       # монетка
answer = random.choice(["Да", "Нет", "Позже"])
pin = random.randint(1000, 9999)                  # 4-значный код
```

## Библиотека math

```python
import math

math.sqrt(16)     # 4.0   корень
math.pi           # 3.1415...
math.floor(4.7)   # 4   вниз (пол)
math.ceil(4.2)    # 5   вверх (потолок)
```

`floor` — всегда вниз, `ceil` — всегда вверх, `round` — к ближайшему.

## Главные ошибки

| Сообщение | Причина | Лечение |
|-----------|---------|---------|
| `NameError: name 'random'...` | забыл `import random` | добавь импорт в начало |
| `ModuleNotFoundError` | опечатка в имени библиотеки | пиши точно: `random`, `math` |
| `TypeError` при склейке | число + строка через `+` | оберни число в `str()` |
| `choice` ругается | нет `[ ]` вокруг вариантов | `choice(["a","b"])` |

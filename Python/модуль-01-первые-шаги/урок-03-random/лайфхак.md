# 🧰 Лайфхаки и разбор ошибок · Урок 3

## ⚡ Быстрые трюки

- **`import` — всегда наверху.** Все `import` собирай в первых строках файла: так сразу видно, какие библиотеки нужны.
- **`randint` включает оба конца.** `randint(1, 6)` = 6 вариантов (и 1, и 6). Не путай с некоторыми языками, где верхняя граница не входит.
- **Случайность вызывается каждый раз.** Если сохранил `x = random.randint(1, 6)`, то `x` — уже зафиксированное число. Нужно новое — вызови `randint` ещё раз.
- **`choice` вместо кучи `if`.** Выбрать один из вариантов проще через `random.choice([...])`, чем писать условия.
- **Список ответов в несколько строк** — можно и нужно для читаемости: Python видит, что список не закрыт, пока нет `]`.
- **`math.ceil` для «сколько нужно».** Коробки, машины, страницы — почти всегда округление ВВЕРХ (`ceil`), а не `round`.

## 🐞 Частые ошибки и что значат

| Сообщение | Что случилось | Как чинить |
|-----------|---------------|-----------|
| `NameError: name 'random' is not defined` | нет `import random` | добавь импорт в начало файла |
| `ModuleNotFoundError: No module named 'randon'` | опечатка в имени | точно: `random`, `math` |
| `TypeError: can only concatenate str...` | склейка числа со строкой | оберни в `str(...)` |
| `random.choice("a","b")` — ошибка | нет `[ ]` | `random.choice(["a","b"])` |
| «результат всегда одинаковый» | значение сохранено один раз | вызови случайную функцию снова |

> 💡 **Проверка «а случайно ли?»:** запусти программу 3–4 раза. Если результат меняется — работает. Если нет — скорее всего, ты сохранил значение один раз и печатаешь его повторно.

## 🎯 Полезно знать

- `random.random()` (без аргументов) даёт дробное 0.0–1.0 — основа «шансов» (`< 0.3` = 30%), пригодится с условиями.
- `import random as r` — псевдоним: короче писать `r.randint(...)`. Аккуратно: для новичков лучше полное имя `random`.
- Библиотек тысячи (`math`, `datetime`, `turtle`, позже `requests`, `wikipedia`) — принцип один: `import`, потом `имя.инструмент()`.

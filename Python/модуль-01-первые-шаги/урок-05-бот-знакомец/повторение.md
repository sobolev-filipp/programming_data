# 🔁 Разминка (5 минут) · Урок 5 (итоговый)

> Сегодня собираем весь модуль. Быстро прогоним всё, что понадобится: ввод, числа, строки, `random`, `datetime`.

## 🎤 Блиц-марафон (устно, 3 мин) — по одному из каждого урока

1. **Урок 1:** зачем буква `f` перед строкой? (подставляет переменные)
2. **Урок 2:** что даёт `17 % 5`? (остаток 2); какой индекс у первого символа? (0)
3. **Урок 3:** как подключить библиотеку? (`import`); что делает `random.choice([...])`? (случайный выбор)
4. **Урок 4:** как узнать сегодняшнюю дату? (`datetime.date.today()`); что даёт `(a - b).days`? (дни между датами)

## 🔥 Предскажи вывод (у проектора, 1 мин)

```python
greet = ["ночь", "утро", "день", "вечер"]
print(greet[14 // 6])     # ? → день (14 // 6 = 2)
print(greet[20 // 6])     # ? → вечер (20 // 6 = 3)
```

> 💡 Это ядро сегодняшнего трюка: `час // 6` превращается в номер части суток, а список даёт нужное слово. Никаких `if` — пока!

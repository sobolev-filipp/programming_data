# 🧑‍🏫 Часть A. Строим бота вместе (пошагово)

## 1. Текущий час

**Тема:** `datetime.datetime.now().hour` даёт текущий час (0–23).

**Задание:** выведи, который сейчас час.

**Разбор по шагам:**
1. `import datetime`.
2. `hour = datetime.datetime.now().hour`.
3. `print(hour)`.
4. Увидишь число 0–23.

✅ `datetime.datetime.now().hour`.

---

## 2. Приветствие по времени (трюк без if)

**Тема:** `hour // 6` даёт номер части суток (0–3); берём фразу из списка.

**Задание:** поздоровайся по времени суток.

**Разбор по шагам:**
1. `greetings = ["Доброй ночи", "Доброе утро", "Добрый день", "Добрый вечер"]`.
2. `hour = datetime.datetime.now().hour`.
3. `print(greetings[hour // 6])`.
4. Проверь: `20 // 6 = 3` → «Добрый вечер».

✅ `greetings[hour // 6]`.

---

## 3. Знакомство

**Тема:** `input` для имени, `int(input)` для возраста — как в уроке 1.

**Задание:** спроси имя и возраст, поздоровайся по имени.

**Разбор по шагам:**
1. `name = input("Как тебя зовут? ").strip()`.
2. `age = int(input("Сколько тебе лет? "))`.
3. `print(f"Приятно, {name}!")`.
4. `print(f"Через 10 лет тебе будет {age + 10}.")`.

✅ `input` + `int(input)` + f-строки.

---

## 4. Сколько дней живёшь

**Тема:** разница дат из урока 4 даёт число прожитых дней.

**Задание:** спроси дату рождения и посчитай дни жизни.

**Разбор по шагам:**
1. `year = int(input("Год: "))`, `month = ...`, `day = ...`.
2. `birthday = datetime.date(year, month, day)`.
3. `days = (datetime.date.today() - birthday).days`.
4. `print(f"Ты живёшь уже {days} дней!")`.

✅ `(today - birthday).days`.

---

## 5. Случайный совет

**Тема:** `random.choice` из урока 3 даёт разный совет каждый раз.

**Задание:** пусть бот даёт случайный совет.

**Разбор по шагам:**
1. `import random`.
2. `advice = random.choice(["Улыбнись!", "Попей воды", "Ты молодец"])`.
3. `print(f"Совет: {advice}")`.

✅ `random.choice([...])`.

## Приём урока: приветствие по времени

```python
import datetime
hour = datetime.datetime.now().hour          # текущий час 0..23
greetings = ["Доброй ночи", "Доброе утро", "Добрый день", "Добрый вечер"]
print(greetings[hour // 6])                  # 0-5→0, 6-11→1, 12-17→2, 18-23→3
```

## Главные ошибки всего модуля

| Сообщение | Причина | Лечение |
|-----------|---------|---------|
| `NameError` | нет `import` или текст без кавычек | импорт вверху; текст в `" "` |
| `TypeError: ...concatenate str` | `str + int` | оберни в `str()` или `int()` |
| `ValueError: invalid literal for int()` | `int()` от слова | только числа |
| `ZeroDivisionError` | деление на 0 | не делить на 0 |
| `IndexError` | индекс > `len − 1` | максимум `len − 1` |
| эмодзи в `print` | Windows-консоль | эмодзи только в тексте |

## Главные мысли

1. **Числа и строки — разные миры.** `+` числа складывает, строки склеивает; `*` числа умножает, строки повторяет.
2. **`/` всегда даёт дробное** (`float`), даже `10 / 2 = 5.0`. Нужен целый результат — бери `//`.
3. **Порядок операций:** скобки → `**` → `* / // %` → `+ -`. Не уверен — ставь скобки.
4. **Индексы с нуля.** Первый символ — `[0]`, последний — `[-1]` или `[len − 1]`.

## Арифметика

```python
a + b      # сложение
a - b      # вычитание
a * b      # умножение (звёздочка!)
a / b      # деление → дробное (3.4)
a // b     # деление НАЦЕЛО (3)
a % b      # ОСТАТОК (2)
a ** b     # степень (2 ** 3 = 8)
```

**Полезные идиомы:**
```python
sec // 60, sec % 60      # секунды → минуты и секунды
n % 2                    # 0 = чётное, 1 = нечётное
9 ** 0.5                 # квадратный корень (3.0)
round(3.14159, 2)        # 3.14 (округление)
```

## Порядок операций

```python
2 + 3 * 4      # 14  (сначала *)
(2 + 3) * 4    # 20  (сначала скобки)
```

---

## Методы строк

```python
name.upper()     # ВСЁ БОЛЬШИМИ
name.lower()     # всё маленькими
name.title()     # Каждое Слово С Большой
name.strip()     # убрать пробелы по краям
name.replace("а", "о")   # замена
len(name)        # длина (число символов)
```

⚠️ Методы строк — только у строк! `age.upper()` (число) → `AttributeError`. Сначала `str(age)`.

---

## Символы по индексу

```python
word = "Python"
word[0]     # 'P'  (первый, индекс 0)
word[-1]    # 'n'  (последний)
len(word)   # 6
# максимальный индекс = len − 1 = 5
```

---

## Главные ошибки

| Сообщение | Причина | Лечение |
|-----------|---------|---------|
| `ZeroDivisionError` | деление на 0 | не делить на 0 |
| `AttributeError: 'int'...upper` | метод строки у числа | `str(число)` |
| `IndexError: ...out of range` | индекс > len−1 | максимум `len−1` |
| `ValueError` | `int()` от слова | `int()` только для чисел |

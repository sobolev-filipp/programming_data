# 🧑‍🏫 Часть A. Разбираем вместе

## 1. Арифметика

**Тема:** Python считает операциями `+ - * /`. Умножение — звёздочка `*`. Деление `/` даёт дробное число.

**Задание:** посчитай и выведи, сколько стоят 7 шоколадок по 45 рублей.

**Разбор по шагам:**
1. Заведи переменные: `price = 45`, `count = 7`.
2. Посчитай: `total = price * count`.
3. Выведи f-строкой: `print(f"Итого: {total} руб.")`.
4. Запусти — увидишь `Итого: 315 руб.`

✅ `total = price * count` → `315`.

---

## 2. Деление нацело `//` и остаток `%`

**Тема:** `//` — сколько раз влезло целиком, `%` — что осталось.

**Задание:** 130 секунд — это сколько полных минут и сколько секунд?

**Разбор по шагам:**
1. `seconds = 130`.
2. Минуты: `seconds // 60` → `2`.
3. Секунды: `seconds % 60` → `10`.
4. `print(f"{seconds} сек = {seconds // 60} мин {seconds % 60} сек")`.

✅ `130 сек = 2 мин 10 сек`.

---

## 3. Степень и порядок операций

**Тема:** степень — `**`. Сначала считается `**`, потом `* /`, потом `+ -`. Скобки — первыми.

**Задание:** посчитай `2 + 3 * 4` и `(2 + 3) * 4`, объясни разницу.

**Разбор по шагам:**
1. `print(2 + 3 * 4)` → сначала `3*4=12`, потом `+2` → `14`.
2. `print((2 + 3) * 4)` → сначала скобки `5`, потом `*4` → `20`.
3. Вывод: скобки меняют порядок и результат.

✅ `14` и `20` — скобки решают.

---

## 4. Методы строк

**Тема:** у строки есть умения-методы через точку: `.upper() .lower() .title()`. Длина — `len()`.

**Задание:** спроси имя и выведи его тремя способами: БОЛЬШИМИ, маленькими, С Большой.

**Разбор по шагам:**
1. `name = input("Имя: ")`.
2. `print(name.upper())` — БОЛЬШИМИ.
3. `print(name.lower())` — маленькими.
4. `print(name.title())` — С Большой Буквы.

✅ Три метода, вызываются через точку у переменной-строки.

---

## 5. Символы по индексу

**Тема:** буквы строки пронумерованы с 0. Первая — `[0]`, последняя — `[-1]`.

**Задание:** спроси слово и выведи его первую и последнюю буквы.

**Разбор по шагам:**
1. `word = input("Слово: ")`.
2. Первая буква: `word[0]`.
3. Последняя: `word[-1]`.
4. `print(f"Первая: {word[0]}, последняя: {word[-1]}")`.

✅ Нумерация с нуля; `[-1]` — удобный способ взять последний символ.

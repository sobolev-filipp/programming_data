# 🧰 Лайфхаки и разбор ошибок · Урок 2

## ⚡ Быстрые трюки

- **`//` vs `/`:** нужен целый результат (страницы, коробки, ряды) — бери `//`. Нужна точность (среднее, деньги) — `/`.
- **Остаток `%` — суперсила:** `n % 2` мгновенно отвечает «чётное?»; `час % 24`, `угол % 360` — «закольцевать» число.
- **Ставь скобки не думая:** `(a + b) / 2` понятнее, чем `a + b / 2`. Скобки бесплатны, ошибки — дорого.
- **Округление:** `round(x, 2)` или прямо в f-строке `f"{x:.2f}"` — покажет ровно 2 знака (для рублей и копеек).
- **Цепочка методов:** можно `"  Гера  ".strip().upper()` → `"ГЕРА"` (сначала обрезали, потом подняли регистр).
- **`len` для проверки:** `len(password)` подскажет, не слишком ли короткий пароль (пригодится в проектах).

## 🐞 Частые ошибки и что значат

| Сообщение | Что случилось | Как чинить |
|-----------|---------------|-----------|
| `ZeroDivisionError: division by zero` | делишь на 0 (`/`, `//`, `%`) | не делить на 0; проверку — в Модуле 2 |
| `AttributeError: 'int' object has no attribute 'upper'` | метод строки у числа | `str(число).upper()` |
| `IndexError: string index out of range` | индекс больше `len − 1` | максимум — `len − 1`; последний удобнее `[-1]` |
| `TypeError: can only concatenate str...` | склеиваешь строку и число | оберни число в `str()` |
| результат `3.4`, ждал `3` | это `/` (дробное) | нужен целый — `//` |

> 💡 **Отладка «в лоб»:** не понимаешь, что в переменной — выведи `print(x, type(x))`. Увидишь и значение, и тип. Половина ошибок урока — это «думал число, а там строка».

## 🎯 Мини-привычки

- Проверяй граничные случаи: деление на 0, пустой ввод, число вместо строки.
- Для денег — `float` и округление до 2 знаков.
- Длинную формулу разбей на шаги с понятными именами (`total`, `average`), а не считай всё в одной строке.

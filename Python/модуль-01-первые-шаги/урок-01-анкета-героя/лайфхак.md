# 🧰 Лайфхаки и разбор ошибок · Урок 1

## ⚡ Быстрые трюки

- **Запуск одной клавишей:** в Thonny — `F5`, в VS Code — `Ctrl+F5` (запустить без отладки). Не тянись каждый раз к кнопке мышкой.
- **Копия строки:** поставь курсор на строку и `Ctrl+C`, `Ctrl+V` — удобно, когда нужно несколько похожих `print`.
- **Комментарий-переключатель:** выдели строки и `Ctrl+/` — редактор закомментирует/раскомментирует их (удобно временно «выключить» кусок кода).
- **Пробел после запятой в `print`:** не нужен для работы, но `print("a", "b")` сам ставит пробел между `a` и `b`.
- **Пустая строка:** `print()` без ничего — печатает пустую строку (отступ). Удобно для красоты вывода.

## 🐞 Три самых частых ошибки и что они значат

| Сообщение | Что случилось | Как чинить |
|-----------|---------------|-----------|
| `SyntaxError: unterminated string literal` | не закрыл кавычку | проверь пары `" "` в строке из сообщения |
| `SyntaxError` возле скобки | не закрыл скобку `)` | проверь, что каждой `(` соответствует `)` |
| `NameError: name '...' is not defined` | использовал имя без кавычек/до создания | текст бери в кавычки; переменную создай **до** использования |
| `ValueError: invalid literal for int()` | обернул в `int()` не-число (слово) | `int()` только для чисел, не для имени/города |
| `TypeError: can only concatenate str` | сложил строку и число | либо оберни число в `str()`, либо число читай через `int()` |

> 💡 **Золотое правило чтения ошибки:** смотри на **последнюю строку** (там суть) и на **номер строки** (`line 5`) — там и ищи проблему. Ошибка не ругает тебя, а показывает, где споткнулась.

## ⚠️ Ловушка Windows: эмодзи в `print()` могут «уронить» программу

Если написать `print("Привет! 👋")` и запускать **в обычной консоли Windows** (не в Thonny), можно получить `UnicodeEncodeError` — консоль Windows по умолчанию не умеет некоторые эмодзи.

- ✅ **Безопасно:** обычный текст и кириллица печатаются нормально. Эмодзи оставляй для комментариев и текста урока, **а не** внутри `print`.
- 🎓 Если очень хочется эмодзи в выводе: в начале файла добавь
  ```python
  import sys
  sys.stdout.reconfigure(encoding="utf-8")
  ```
  либо запускай в Thonny/VS Code (там UTF-8 по умолчанию).

## 🎯 Мини-привычки хорошего кода уже сейчас

- **Понятные имена:** `age`, `score`, `name` — а не `a`, `s`, `x`.
- **Комментарий над непонятным местом**, а не над каждой строкой.
- **Сохраняй часто** (`Ctrl+S`) — особенно перед запуском.
- **Читай код сверху вниз, как Python** — если сам не понимаешь порядок, компьютер тоже «сделает не то».

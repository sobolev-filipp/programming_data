## Главные мысли

1. **Программа = команды по порядку, сверху вниз.** Компьютер делает ровно то, что написано.
2. **`print()`** выводит на экран. **f-строка** `f"...{переменная}..."` — самый удобный способ вывода.
3. **Переменная — коробка** с именем. Знак `=` значит «положи справа в коробку слева».
4. **Тип решает, что можно делать.** `42` (число) ≠ `"42"` (текст).
5. **`input()` всегда даёт строку.** Чтобы считать — оберни в `int()`.
6. **Ошибка — это подсказка.** Смотри последнюю строку сообщения и номер строки.

---

## Вывод на экран

```python
print("Привет!")                 # обычный текст
print("Возраст:", age)           # через запятую (пробел сам)
print(f"Мне {age} лет")          # f-строка — переменная прямо в тексте
print(f"Через год: {age + 1}")   # внутри {} можно считать
print()                          # пустая строка-отступ
```

⚠️ Забыл букву `f` → `print("Мне {age} лет")` выведет буквально `Мне {age} лет`.

## Переменные

```python
name = "Гера"     # str — текст в кавычках
age = 12          # int — целое число
height = 1.5       # float — дробное (ТОЧКА, не запятая)

age = 13          # положили новое значение поверх старого
```

Имена: латиница, цифры, `_`. Нельзя с цифры (`2age`) и с пробелом (`my age` → `my_age`).

---

## Типы данных

| Тип | Что | Пример | Проверка |
|-----|-----|--------|----------|
| `int` | целое | `12` | `type(12)` |
| `float` | дробное | `3.14` | `type(3.14)` |
| `str` | текст | `"Гера"` | `type("Гера")` |
| `bool` | да/нет | `True` | (Модуль 2) |

**`42` ≠ `"42"`:** число можно сложить, строку — только склеить.

---

## Строки: склейка и повтор

```python
"Гарри" + " " + "Поттер"    # 'Гарри Поттер'  (склейка +)
"ха" * 3                    # 'хахаха'        (повтор *)
"=" * 20                    # '===================='  (рамка!)
"2" + "2"                   # '22' — это склейка, а НЕ 4!
```

---

## Ввод от пользователя

```python
name = input("Как тебя зовут? ")        # всегда СТРОКА
age = int(input("Сколько лет? "))       # число (обернули в int)
price = float(input("Цена? "))          # дробное число
```

Превращения: `int("12")` → `12` · `float("1.5")` → `1.5` · `str(12)` → `"12"`.

## Главные ошибки

| Сообщение | Причина | Лечение |
|-----------|---------|---------|
| `NameError` | текст без кавычек | текст в `" "` |
| `SyntaxError` | не закрыта кавычка/скобка | проверь пары `" "` и `( )` |
| `TypeError: can only concatenate str...` | `str + int` через `+` | оберни ввод в `int()` |
| `ValueError: invalid literal for int()` | `int()` от слова | `int()` только для чисел |
| выводит `{age}` буквально | забыл `f` | `f"..."` |

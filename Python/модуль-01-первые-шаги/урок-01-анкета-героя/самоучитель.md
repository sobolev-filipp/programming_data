# 🧑‍🏫 Часть A. Разбираем вместе (пошагово)

## 1. `print()` — вывод на экран

**Тема:** команда `print("текст")` печатает то, что в скобках. Текст — в кавычках.

**Задание:** выведи на экран `Я учусь программировать!`

**Разбор по шагам:**
1. Напиши команду `print`.
2. Поставь скобки: `print()`.
3. Внутри — текст в кавычках: `print("Я учусь программировать!")`.
4. Нажми Run ▶ — внизу появится твоя фраза.

✅ Готово: `print("Я учусь программировать!")`

---

## 2. Несколько строк по порядку

**Тема:** команды выполняются сверху вниз. Один `print` = одна строка.

**Задание:** выведи три строки — приветствие, имя, возраст.

**Разбор по шагам:**
1. Первая строка: `print("Привет!")`.
2. Ниже вторая: `print("Меня зовут Гера")`.
3. Ниже третья: `print("Мне 12 лет")`.
4. Запусти — три строки появятся в том же порядке.

✅ Три команды `print` подряд, каждая со своим текстом.

---

## 3. Переменная — коробка с данными

**Тема:** `name = "Гера"` кладёт значение в коробку с именем `name`. Знак `=` значит «положи».

**Задание:** сохрани имя в переменную и выведи `Меня зовут <имя>`.

**Разбор по шагам:**
1. Заведи коробку: `name = "Гера"` (текст — в кавычках!).
2. Выведи: `print("Меня зовут", name)`.
3. Заметь: `"Меня зовут"` в кавычках (текст), а `name` без кавычек (печатаем содержимое коробки).
4. Сравни с `print("Меня зовут", "name")` — увидишь разницу (напечатается слово «name»).

✅ `name = "Гера"` затем `print("Меня зовут", name)`.

---

## 4. f-строка — красивый вывод

**Тема:** буква `f` перед кавычками разрешает вставлять переменные прямо в текст, в `{ }`.

**Задание:** выведи `Меня зовут Гера, мне 12 лет.` через f-строку.

**Разбор по шагам:**
1. Заведи две коробки: `name = "Гера"` и `age = 12`.
2. Поставь `f` перед кавычками: `print(f"...")`.
3. Вставь переменные в фигурных скобках: `print(f"Меня зовут {name}, мне {age} лет.")`.
4. Запусти — Python подставит значения на места `{name}` и `{age}`.

✅ `print(f"Меня зовут {name}, мне {age} лет.")`

---

## 5. `input()` + ловушка с числом

**Тема:** `input()` спрашивает у пользователя и **всегда возвращает строку**. Чтобы считать — оборачиваем в `int()`.

**Задание:** спроси возраст и выведи, сколько будет через 10 лет.

**Разбор по шагам:**
1. Попробуй сначала так: `age = input("Возраст: ")` и `print(age + 10)`.
2. Запусти — получишь `TypeError`: нельзя склеить строку и число.
3. Почему? `input()` дал строку `"12"`, а не число.
4. Почини: оберни ввод в `int()` — `age = int(input("Возраст: "))`.
5. Выведи f-строкой: `print(f"Через 10 лет: {age + 10}")`.

✅ `age = int(input("Возраст: "))` затем `print(f"Через 10 лет: {age + 10}")`.

# ✍️ Часть B. Теперь сам (с мини-подсказкой)

## Вывод и f-строки

**6.** Выведи «рамку» из 20 знаков `=`, под ней слово `МЕНЮ`, под ним ещё рамку.
> 💡 `print("=" * 20)`, повтор строки — через `*`.

**7.** Заведи `city = "Казань"` и выведи f-строкой `Я живу в городе Казань.`
> 💡 `f"Я живу в городе {city}."`

**8.** Выведи f-строкой `2 + 2 = 4`, но число `4` посчитай внутри `{ }`, а не пиши руками.
> 💡 Внутри фигурных скобок можно считать: `{2 + 2}`.

## Переменные и типы

**9.** Заведи `score = 0`, выведи; поменяй на `score = 100`, выведи снова.
> 💡 Второе присваивание кладёт новое значение поверх старого.

**10.** Создай три переменные: целое, дробное и строку. Выведи тип каждой.
> 💡 `print(type(x))` для каждой. Дробное — с точкой: `1.5`.

**11.** Объясни в комментарии `#`, почему `"5" + "5"` даёт `"55"`, а не `10`.
> 💡 Для строк `+` — склейка, не сложение. Тип решает.

## Ввод от пользователя

**12.** Спроси имя и любимый цвет, выведи f-строкой `<имя> любит <цвет> цвет.`
> 💡 Два `input()` в две переменные, потом f-строка. `int()` не нужен — это текст.

**13.** Спроси два числа и выведи их сумму (числом, не склейкой!).
> 💡 Оба ввода через `int(input())`, иначе `+` склеит строки.

**14.** Спроси цену и количество, выведи общую стоимость f-строкой.
> 💡 `int(input())` для обоих, результат — произведение `*`.

**15.** Спроси возраст и выведи примерный год рождения (`2026 - возраст`).
> 💡 `age = int(input(...))`, затем `{2026 - age}` в f-строке.

## Со звёздочкой 🔴

**16.** Спроси имя и фамилию, собери логин: имя маленькими буквами + первая буква фамилии.
> 💡 `name.lower()` делает строчными; первый символ — `last[0]`; склей через `+`.

**17.** «Красивый чек»: спроси товар, цену и количество — выведи чек в рамках из `=` с итогом.
> 💡 Комбинируй `"=" * 25`, f-строки и `цена * количество`. Сверься с идеей из [`материалы/анкета.py`](материалы/анкета.py).

## Часть 1 — Первая программа: `print()` (10 минут)

Самая знаменитая первая программа в мире — вывести на экран приветствие. Напиши в редакторе **одну строку**:

```python
print("Привет, мир!")
```

Нажми **Run ▶** (в Thonny — зелёная кнопка, в VS Code — треугольник вверху справа).

- 👀 **Что видишь:** внизу, в **консоли** (чёрное или белое поле результата), появилась надпись `Привет, мир!`. 🎉

Поздравляю — ты дал компьютеру команду, и он её выполнил! Разберём, что произошло:

![Схема: код в редакторе → Python-интерпретатор читает и выполняет → результат в консоли](изображения/редактор-интерпретатор-результат.svg)

- **`print`** — это **команда «напечатай на экран»** (по-английски «печатать»).
- **Круглые скобки `( )`** — в них кладём то, **что** напечатать.
- **Кавычки `" "`** — говорят Python: «внутри — обычный **текст**, не команда». Текст в кавычках называется **строкой**.

> 💡 **Как это работает (важно понять сразу):** ты пишешь код в **редакторе** → нажимаешь Run → **интерпретатор Python** читает твой файл **строчку за строчкой сверху вниз** и выполняет команды → результат появляется в **консоли**. Компьютер не «понимает смысл» — он просто честно выполняет команды по порядку.

Теперь добавь ещё строки — программа выполнит их **по очереди**:

```python
print("Привет, мир!")
print("Меня зовут Python.")
print("Я выполняю команды по порядку.")
```

- 👀 **Что видишь:** три строки, одна под другой — ровно в том порядке, как написаны.

> ⚠️ **Частая ошибка №1 — забыть кавычки:** `print(Привет)` → Python подумает, что `Привет` это команда или переменная, которой нет, и выдаст ошибку. Текст — **всегда в кавычках**.
> ⚠️ **Частая ошибка №2 — русская буква вместо латинской:** команда пишется латиницей `print`, а не «рrint». Редактор подсветит.

## Часть 2 — Комментарии: заметки для человека (5 минут)

Иногда в коде нужно оставить пояснение — для себя или для того, кто будет читать. Для этого есть **комментарии**: всё после значка **`#`** Python **игнорирует**.

```python
# Это моя первая программа. Python эту строку не выполняет.
print("Привет!")  # а этот комментарий — справа от команды
```

- 👀 **Что видишь:** на экране только `Привет!`. Строки с `#` — как записка на полях: их видит человек, но не компьютер.

> 💡 **Зачем нужны комментарии:** объяснить сложное место, временно «выключить» строку кода (поставил `#` — и она не выполняется), оставить себе напоминание. Хорошие программисты комментируют то, что **непонятно с первого взгляда**.

## Часть 3 — Ошибки — это нормально! (5 минут)

Специально сделаем ошибку, чтобы **не бояться** красного текста:

```python
print("Привет)
```

- 👀 **Что видишь:** Python ругается — что-то вроде `SyntaxError: unterminated string literal` (не закрыта кавычка).

> 💡 **Ошибка (Error) — это не поломка, а подсказка.** Python говорит: «я не понял вот это место». Смотри на **последнюю строку** сообщения (там суть) и на **номер строки**, где споткнулся. Почти все ошибки новичка — это забытая кавычка, скобка или опечатка в команде.

## Часть 4 — Переменные: коробки для данных (15 минут)

Программа станет полезной, когда начнёт **запоминать** данные. Для этого есть **переменные** — это как подписанные коробки: кладёшь значение и пользуешься им по имени.

```python
name = "Гера"
age = 12
```

Читается так: «в коробку с именем `name` положи текст `"Гера"`; в коробку `age` положи число `12`».

![Схема: переменная age = 12 как коробка с именем, значением и типом](изображения/переменная-коробка.svg)

- **Имя переменной** (`name`, `age`) — слева от `=`. Мы придумываем его сами.
- **Знак `=`** — это **НЕ «равно» из математики**, а **«положи»**: значение справа кладётся в коробку слева. Направление — **справа налево** ⬅.
- **Значение** — справа от `=`.

Теперь имя можно использовать вместо самого значения:

```python
name = "Гера"
age = 12
print(name)          # напечатает: Гера
print("Возраст:", age)   # напечатает: Возраст: 12
```

- 👀 **Что видишь:** `Гера`, затем `Возраст: 12`. Python подставил вместо `name` то, что лежит в коробке.

> 💡 **`print` умеет печатать несколько вещей через запятую:** `print("Возраст:", age)` — Python поставит между ними пробел сам. Обрати внимание: `"Возраст:"` в кавычках (это текст), а `age` без кавычек (это переменная — печатаем её содержимое).

**Значение можно менять** — коробка на то и коробка:

```python
age = 12
print(age)   # 12
age = 13     # положили новое значение — старое стёрлось
print(age)   # 13
```

**Правила имён переменных:**
- ✅ латинские буквы, цифры, `_`: `name`, `player_score`, `age2`.
- ❌ нельзя начинать с цифры (`2age` — ошибка), нельзя пробелы (`my age` — ошибка, пиши `my_age`).
- 💡 имя должно быть **понятным**: `age` лучше, чем `a`; `score` лучше, чем `x`.

> ⚠️ **Ошибка:** `name = Гера` (без кавычек справа). Python решит, что `Гера` — это другая переменная, которой нет → `NameError`. Текст **всегда в кавычках**, а имя переменной — без.

## Часть 5 — Типы данных: что за содержимое? (10 минут)

В коробках лежат **разные виды** данных, и Python это различает. Четыре главных типа:

![Схема: четыре типа — int (целое), float (дробное), str (строка), bool (да/нет)](изображения/типы-данных.svg)

| Тип | Что это | Примеры | Как узнать |
|-----|---------|---------|-----------|
| **`int`** | целое число | `12`, `0`, `-5`, `2025` | без кавычек, без точки |
| **`float`** | дробное число | `3.14`, `1.5`, `-0.7` | с **точкой** (не запятой!) |
| **`str`** | строка (текст) | `"Гера"`, `"привет"`, `"42"` | в **кавычках** |
| **`bool`** | «да/нет» | `True`, `False` | без кавычек, с большой буквы (изучим в Модуле 2) |

Узнать тип можно командой **`type()`**:

```python
print(type(12))       # <class 'int'>
print(type(3.14))     # <class 'float'>
print(type("Гера"))   # <class 'str'>
```

> ⚠️ **Самое важное различие: `42` и `"42"` — это РАЗНОЕ!**
> - `42` (тип `int`) — число, его можно **сложить**: `42 + 8` = `50`.
> - `"42"` (тип `str`) — текст, его можно только **склеить**: `"42" + "8"` = `"428"`.
>
> Тип определяет, **что можно делать** со значением. Это причина большинства ошибок новичков — запомни этот момент.

## Часть 6 — `input()`: спрашиваем у пользователя (15 минут)

Пока программа знает только то, что мы вписали сами. Настоящая программа **спрашивает** пользователя. Для этого — команда **`input()`**:

```python
name = input("Как тебя зовут? ")
print("Привет,", name)
```

Запусти ▶.
- 👀 **Что видишь:** в консоли появился вопрос `Как тебя зовут?` и мигает курсор — программа **ждёт**. Напечатай своё имя, нажми **Enter**.
- 👀 Программа продолжила: `Привет, <твоё имя>`.

![Схема: пользователь печатает → input() отдаёт ответ программе → print() выводит на экран](изображения/ввод-вывод.svg)

Как это работает:
- **`input("текст-вопрос")`** — показывает вопрос и **ждёт**, пока пользователь напечатает ответ и нажмёт Enter.
- Ответ **возвращается** и его нужно **куда-то положить** — в переменную: `name = input(...)`.

> ⚠️ **ГЛАВНАЯ ловушка урока:** `input()` **всегда возвращает строку (`str`)** — даже если пользователь ввёл число! Проверь:
> ```python
> age = input("Сколько тебе лет? ")
> print(type(age))   # <class 'str'> — это текст, а не число!
> ```
> Если попробовать посчитать `age + 1`, будет ошибка: нельзя складывать текст и число. Как это чинить — в следующей части.

## Часть 7 — Приведение типов: `int(input())` (10 минут)

Чтобы ответ пользователя стал **числом**, его надо **преобразовать** — «обернуть» в `int()` (для целых) или `float()` (для дробных):

```python
age = int(input("Сколько тебе лет? "))
print("Через 10 лет тебе будет", age + 10)
```

- 👀 **Что видишь:** ввёл `12` → программа посчитала `12 + 10` и вывела `Через 10 лет тебе будет 22`. Теперь `age` — настоящее число, с ним можно считать!

Разберём «матрёшку» `int(input(...))` — читаем **изнутри наружу**:
1. `input("Сколько тебе лет? ")` — спросил, получил текст `"12"`.
2. `int("12")` — превратил текст `"12"` в число `12`.
3. `age = ...` — положил число в коробку `age`.

| Команда | Из чего | Во что |
|---------|---------|--------|
| `int("12")` | строка | целое число `12` |
| `float("1.5")` | строка | дробное `1.5` |
| `str(12)` | число | строка `"12"` |

> ⚠️ **Ошибка:** `int("привет")` — Python не может превратить слово в число → `ValueError`. Оборачивай в `int()` только то, где ожидаешь число (возраст, количество), а не имя или город.

## Часть 8 — Собираем «Анкету героя» 🏆 (15 минут)

Теперь соединим всё в одну программу. Печатай по частям, запускай и проверяй после каждого блока.

```python
# ===== АНКЕТА ГЕРОЯ =====

# 1. Спрашиваем данные
name = input("Как тебя зовут? ")
age = int(input("Сколько тебе лет? "))
game = input("Любимая игра? ")
city = input("Из какого ты города? ")

# 2. Считаем возраст через 10 лет
age_future = age + 10

# 3. Красиво выводим анкету
print()                       # пустая строка-отступ
print("===== АНКЕТА ГЕРОЯ =====")
print("Привет,", name, "из города", city, "!")
print("Тебе сейчас", age, "лет, а через 10 будет", age_future, ".")
print("Твоя любимая игра —", game, ". Отличный выбор!")
```

- 👀 **Что видишь:** программа задаёт 4 вопроса, а потом собирает из ответов персональную анкету с подсчётом. Это уже **настоящее приложение**, которое можно показать другу — и у него получится своя анкета.

> 💡 **Разбор:** обрати внимание — только `age` мы обернули в `int()` (с ним считаем), а `name`, `game`, `city` оставили строками (их не считаем, только показываем). `age_future = age + 10` — сначала **посчитали и запомнили**, потом вывели. Так код чище.

> 🧩 **Для 5–7 классов (проще):** хватит трёх вопросов (имя, возраст, игра) без подсчёта через 10 лет — главное, чтобы программа спрашивала и здоровалась по имени.

## ✅ Как правильно / ❌ Как НЕ надо (первая программа)

| ❌ Как НЕ надо | ✅ Как правильно |
|----------------|------------------|
| `print(Привет)` — текст без кавычек | `print("Привет")` — текст в кавычках |
| `name = Гера` — значение-текст без кавычек | `name = "Гера"` |
| `age = input(...)` и потом `age + 1` | `age = int(input(...))` — обернуть в `int()` |
| `2age`, `my age` — плохие имена | `age2`, `my_age` — латиница, `_`, без пробелов |
| Файл `анкета.txt` | Файл **`анкета.py`** |
| Русская `рrint` (буква «р») | Латинская `print` |
| Запятая в дробях: `3,14` | Точка: `3.14` |

> ⚠️ Если программа не запускается — проверь в первую очередь: **кавычки** (закрыты ли), **скобки** (закрыты ли), **латиница** в командах, **номер строки** из сообщения об ошибке.

## 🎓 Часть 9 — Для тех, кто хочет глубже (по времени)

- **`f`-строки (загляни вперёд):** вместо `print("Привет,", name)` можно писать красивее — `print(f"Привет, {name}!")`. Буква `f` перед кавычками разрешает вставлять переменные в `{ }`. Подробно — на уроке 2.
- **Своя формула:** добавь в анкету расчёт — «в каком году ты родился»: `year = 2026 - age` (используй `datetime` на уроке 4, чтобы брать текущий год автоматически).
- **Проверка типов:** после каждого `input` выведи `type(...)` и убедись, где строка, а где число.
- **`\n` — перенос строки:** `print("Строка1\nСтрока2")` выведет две строки. Символ `\n` внутри строки означает «здесь перенеси на новую строку».

> 🏆 Ты понял главное: **программа хранит данные в переменных и выполняет команды по порядку сверху вниз.** Дальше — **урок 2 «Калькулятор + генератор ников»**: научимся считать и красиво работать с текстом.

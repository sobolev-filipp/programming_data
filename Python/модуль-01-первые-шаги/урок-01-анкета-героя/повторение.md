## 🌉 Мостик: то же самое, но словами

В Scratch мы собирали программы из блоков. В Python — из **слов-команд**. Идея та же!

| В Scratch (год назад) | В Python (теперь) |
|-----------------------|-------------------|
| блок `сказать [Привет!]` | `print("Привет!")` |
| «переменная» с ползунком | `score = 0` |
| `когда нажат флажок` (старт) | программа стартует с первой строки |
| блоки идут сверху вниз | команды выполняются сверху вниз |

> 💡 Главное сходство: **и там, и там программа — это команды по порядку**. Главное отличие: в Python мы **печатаем** команды, поэтому важна точность (кавычки, скобки, латиница).

## 🎤 Блиц-вопросы классу (устно, 2 мин)

1. Что делал в Scratch блок «сказать»? (показывал текст) — в Python это будет команда `print`.
2. Зачем нужна была переменная в игре? (хранить счёт, жизни) — сегодня заведём переменные и в Python.
3. Если блоки в Scratch перепутать местами — что будет? (программа сделает не то) — в Python порядок строк так же важен.

## Главные мысли

1. **Дата — особый тип данных**, а не текст. С датами можно считать (вычитать, сравнивать).
2. **`date.today()`** возвращает сегодняшнюю дату сама.
3. **Разница двух дат** даёт число дней через `.days`.
4. **Свойства даты — без скобок:** `.year`, `.month`, `.day`. Методы — со скобками: `.today()`, `.weekday()`.

---

## Библиотека datetime

```python
import datetime

today = datetime.date.today()          # сегодня
d = datetime.date(2013, 3, 14)         # своя дата: год, месяц, день

today.year        # 2026   (без скобок!)
today.month       # 8
today.day         # 9
today.weekday()   # 0=пн, 1=вт, ... 6=вс (со скобками)
```

**Разница дат:**
```python
diff = today - birthday      # промежуток
diff.days                    # сколько дней между датами
age_years = diff.days // 365 # примерный возраст
```

**День недели по названию:**
```python
names = ["понедельник","вторник","среда","четверг","пятница","суббота","воскресенье"]
print(names[today.weekday()])
```

## Библиотека time

```python
import time

time.sleep(2)      # пауза 2 секунды
time.sleep(0.5)    # можно дробное — полсекунды
```

**Таймер обратного отсчёта** (пока «руками», циклы — Модуль 3):
```python
print(3); time.sleep(1)
print(2); time.sleep(1)
print(1); time.sleep(1)
print("ПУСК!")
```

## Главные ошибки

| Сообщение | Причина | Лечение |
|-----------|---------|---------|
| `NameError: name 'datetime'` | нет `import datetime` | добавь импорт |
| `ValueError: day is out of range` | 30 февраля и т.п. | реальная дата |
| `ValueError: month must be in 1..12` | месяц вне 1–12 | месяц 1–12 |
| скобки у `.day()` | свойство со скобками | `.day` без скобок |

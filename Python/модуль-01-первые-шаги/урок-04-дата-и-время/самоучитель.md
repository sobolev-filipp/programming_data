# 🧑‍🏫 Часть A. Разбираем вместе

## 1. Сегодняшняя дата

**Тема:** `datetime.date.today()` возвращает сегодняшнюю дату.

**Задание:** выведи сегодняшнюю дату.

**Разбор по шагам:**
1. `import datetime`.
2. `today = datetime.date.today()`.
3. `print(today)`.
4. Увидишь дату в формате `2026-08-09`.

✅ `datetime.date.today()`.

---

## 2. Части даты

**Тема:** у даты есть свойства `.year`, `.month`, `.day` — **без скобок**.

**Задание:** выведи отдельно год, месяц и день сегодня.

**Разбор по шагам:**
1. `today = datetime.date.today()`.
2. `print(today.year)` — год.
3. `print(today.month)` — месяц.
4. `print(today.day)` — день.

✅ Свойства даты пишем без скобок.

---

## 3. Своя дата

**Тема:** дату собирают командой `datetime.date(год, месяц, день)` — порядок строгий.

**Задание:** создай дату 14 марта 2013 и выведи её.

**Разбор по шагам:**
1. `bd = datetime.date(2013, 3, 14)`.
2. `print(bd)` → `2013-03-14`.
3. Помни порядок: сначала год, потом месяц, потом день.

✅ `datetime.date(2013, 3, 14)`.

---

## 4. Разница дат

**Тема:** одну дату можно вычесть из другой; у результата есть `.days`.

**Задание:** посчитай, сколько дней ты прожил.

**Разбор по шагам:**
1. `today = datetime.date.today()`.
2. `bd = datetime.date(2013, 3, 14)` (своя дата).
3. `diff = today - bd`.
4. `print(diff.days)` — число прожитых дней.

✅ `(today - bd).days`.

---

## 5. Пауза

**Тема:** `time.sleep(секунды)` останавливает программу на заданное время.

**Задание:** выведи «Старт через 2 секунды», подожди 2 секунды, выведи «Поехали!».

**Разбор по шагам:**
1. `import time`.
2. `print("Старт через 2 секунды")`.
3. `time.sleep(2)`.
4. `print("Поехали!")`.

✅ `time.sleep(2)` делает паузу.

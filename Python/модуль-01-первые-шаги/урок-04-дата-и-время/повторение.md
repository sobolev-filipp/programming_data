## 🔥 Предскажи вывод (у проектора, 2 мин)

```python
import random
print(random.choice(["Пн", "Вт", "Ср"]))   # ? → один из трёх дней
days = ["Пн", "Вт", "Ср", "Чт", "Пт"]
print(days[2])                              # ? → Ср (индекс 2!)
print(730 // 365)                           # ? → 2 (примерно 2 года в днях)
```

> 💡 Сегодня мы будем **брать элемент списка по номеру дня недели** (`days[weekday]`) и **делить дни на 365**, чтобы узнать возраст. Всё это — знакомые инструменты, просто применим к датам.

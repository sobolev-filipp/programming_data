# 🧰 Лайфхаки и разбор ошибок · Урок 4

## ⚡ Быстрые трюки

- **Свойства — без скобок, методы — со скобками.** `.year`, `.month`, `.day` — без `()`. `.today()`, `.weekday()` — со `()`. Запомни: свойство — это «что уже есть», метод — «сделай действие».
- **Порядок в дате: год, месяц, день.** `datetime.date(2013, 3, 14)` — 14 марта. Всегда так, не перепутай.
- **Разница дат сама учитывает високосные годы** — не считай дни руками, просто `(a - b).days`.
- **`weekday()`: 0 = понедельник, 6 = воскресенье.** Название бери из списка по этому номеру.
- **`time.sleep()` понимает дробные:** `time.sleep(0.5)` — полсекунды, `time.sleep(0.1)` — быстрый эффект.
- **Красивый формат даты:** `today.strftime("%d.%m.%Y")` → `09.08.2026` (как в России).

## 🐞 Частые ошибки и что значат

| Сообщение | Что случилось | Как чинить |
|-----------|---------------|-----------|
| `NameError: name 'datetime'` | нет `import datetime` | добавь импорт в начало |
| `ValueError: day is out of range for month` | 30 февраля, 31 апреля… | проверь день для месяца |
| `ValueError: month must be in 1..12` | месяц вне 1–12 | месяц — число 1–12 |
| `TypeError: 'int' object is not callable` при `today.day()` | поставил скобки у свойства | `.day` без скобок |
| эмодзи в `print` → крах на Windows | эмодзи в выводе | эмодзи только в тексте/комментариях |

> 💡 **Проверка даты:** если сомневаешься, что за дата в переменной — выведи `print(d, d.weekday())`. Увидишь и дату, и день недели.

## 🎯 Полезно знать

- `datetime.datetime.now()` — дата **и время** (`.hour`, `.minute`, `.second`).
- Прибавить/отнять дни: `today + datetime.timedelta(days=7)` — через неделю.
- Секундомер: `start = time.time()` … `time.time() - start` — сколько секунд прошло (пригодится для «на скорость»).
- Даты можно **сравнивать**: `birthday < today` вернёт `True/False` — это мостик к условиям (Модуль 2).

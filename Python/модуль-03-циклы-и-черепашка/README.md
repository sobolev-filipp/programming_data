## Библиотеки модуля

- `random` (встроенная) — знаем из Модуля 1, применяем в «Угадай число» (Урок 1).
- `turtle` (встроенная) — черепашья графика (Уроки 3–5). **Чиним под desktop:** `screen.mainloop()`/`turtle.done()`, `Screen().tracer(...)`.

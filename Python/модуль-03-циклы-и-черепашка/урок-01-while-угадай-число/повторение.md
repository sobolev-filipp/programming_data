# Разминка перед уроком 1 (5 минут) 🔁

> Повторяем Модуль 2 (`if/elif/else`, счётчик `+=`) и `random` из Модуля 1 — на них строится цикл. Устно или в `проба.py`.

---

## 1. Блиц-вопросы (устно)

1. Что вернёт `7 > 3`? Какой это тип? *(True; bool)*
2. Сколько веток `if/elif/else` сработает? *(ровно одна)*
3. Что делает `score += 1`? *(увеличивает score на 1)*
4. Как загадать случайное число от 1 до 6? *(`random.randint(1, 6)`)*
5. Зачем `int(input(...))`? *(ввод приходит строкой, нужно число)*

---

## 2. Предскажи вывод

```python
x = 0
x += 1
x += 1
x += 1
print(x)
```

<details><summary>Ответ</summary>

`3` — три раза прибавили по 1.
</details>

---

## 3. Найди неудобство

```python
guess = int(input("Число: "))
if guess == 42:
    print("Угадал")
else:
    print("Нет")
# и всё — одна попытка
```

<details><summary>В чём неудобство?</summary>

Даётся **только одна** попытка. Чтобы дать много попыток, пришлось бы копировать код. Сегодня научим программу **повторять** сама — циклом `while`.
</details>

---

## 4. Мостик к теме

Пока код выполнялся сверху вниз **один раз**. Но компьютер создан, чтобы **повторять**: считать до 100, спрашивать пароль снова, играть раунд за раундом. Сегодня — цикл `while` («пока») и выход `break`. Соберём игру «Угадай число». 🔁

# Что показать на проекторе — урок 1 «Цикл while» 🖼

> Три SVG-схемы. Открываются в браузере (`Ctrl+O` или перетащи файл). Показывай в момент из [преподавателю.md](преподавателю.md).

---

## 1. `изображения/виток-while.svg` 🔁
**Когда:** Часть 1 (первый `while`), 9–21 мин. Держи на экране весь блок.

Схема одного витка: рамка `count = 1` → ромб-условие `count <= 5 ?` → ветка **True** (зелёная) в тело `print(count); count += 1` → пунктирная стрелка **назад к проверке**; ветка **False** (красная) → «выход из цикла».

**Как обсудить:**
- Веди пальцем по кругу: «проверили → выполнили тело → вернулись к проверке». Это и есть «виток».
- Подчеркни: тело (тёмная рамка) с **отступом**; выход — когда условие стало False.
- Свяжи с тремя частями: начало (верхняя рамка), условие (ромб), изменение (`count += 1` в теле).

## 2. `изображения/счётчик-в-while.svg` 🔢
**Когда:** Часть 2 (вечный цикл), 21–27 мин.

Слева — трассировка: таблица значений `count` по виткам (1→2→…→6), где на `count = 6` условие ложно и цикл выходит. Справа — красная карточка «Забыл `count += 1`?»: код без изменения → `count` всегда 1 → **бесконечный цикл**, останавливаем `Ctrl+C`.

**Как обсудить:**
- Пройди таблицу строка за строкой — покажи, как переменная «доезжает» до границы.
- Затем закрой пальцем строку `count += 1` в коде — «что теперь? столбик застрял на 1». Это вечный цикл.
- Обязательно проговори `Ctrl+C` как аварийный тормоз.

## 3. `изображения/угадай-число.svg` 🎯
**Когда:** Часть 4 (проект), 39–55 мин.

Поток игры: настройка (`secret`, `attempts`) → пунктирная рамка `while True:` внутри которой ввод + `attempts += 1`, два ромба `guess < secret?` («Больше!») и `guess > secret?` («Меньше!») с возвратом «снова спросить», а ветка «иначе — равно» ведёт в «Верно!» → `break` → выход.

**Как обсудить:**
- Покажи, что подсказки «Больше/Меньше» **возвращают** нас в начало цикла (стрелка «снова спросить»).
- Единственный выход — зелёная ветка «равно» и `break`.
- Свяжи с Модулем 2: внутри цикла работает знакомая лестница `if/elif/else`.

## 💡 Общие советы
- Схемы светлые, читаются с задних парт; масштаб `Ctrl` + `+`.
- `виток-while.svg` полезно держать открытой всю Часть 1 — как памятку «трёх частей».
- Приём «предскажи»: по `счётчик-в-while.svg` закрой колонку результата и спрашивай, на каком `count` цикл остановится.

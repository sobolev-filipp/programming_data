# Лайфхаки урока 1 «Цикл while» 🧰

> Приёмы, чтобы циклы работали и не зависали.

---

## 🎯 Правило трёх частей

Написал `while` — проверь, что есть **все три**:

```python
n = 1              # 1) НАЧАЛО — переменная до цикла
while n <= 5:      # 2) УСЛОВИЕ — с двоеточием
    print(n)
    n += 1         # 3) ИЗМЕНЕНИЕ — иначе вечный цикл
```

Нет пункта 3 — цикл крутится вечно. Это ошибка №1 у новичков.

---

## 🎯 Спасение от зависания: Ctrl + C

Программа печатает без конца или «висит»? Нажми **`Ctrl + C`** в терминале — аварийная остановка. Работает всегда. Запомни как огнетушитель.

---

## 🎯 Трассировка «на бумаге»

Не уверен, что цикл остановится? Выпиши значения переменной по виткам:

```
n:  1 → 2 → 3 → 4 → 5 → 6   (6 > 5, стоп ✅)
```

Если столбик **не приближается** к границе условия — цикл вечный.

---

## 🎯 Шаблон «повторяй, пока не…»

Не знаешь заранее, сколько раз повторять? Бери `while True` + `break`:

```python
while True:
    ответ = input("Продолжить? (да/нет) ").lower().strip()
    if ответ != "да":
        break
    # ... тело ...
```

`while True` крутится всегда — выход только через `break` внутри `if`.

---

## 🎯 Счётчик и копилка внутри цикла

```python
count = 0          # сколько раз
total = 0          # сумма чего-то
while ...:
    count += 1
    total += число
```

Заводи такие переменные **до** цикла (со значения 0), а меняй **внутри**.

---

## 🎯 Флаг результата после цикла

Хочешь узнать, «случилось ли что-то» в цикле — заведи `bool`-флаг:

```python
found = False
while ...:
    if нашли:
        found = True
        break
if found:
    print("нашли!")
else:
    print("не нашли")
```

---

## 🐞 Топ-5 ошибок

1. **Забыл `+= 1`** → вечный цикл. Останови `Ctrl+C`, добавь изменение.
2. **Нет `:` после условия** → `SyntaxError`.
3. **Тело без отступа** → `IndentationError`.
4. **`while True` без `break`** → не выйдет никогда.
5. **`break` вне цикла** → `SyntaxError`. Он живёт только внутри `while`/`for`.

---

## 💡 Хитрость: угадать за 7 попыток

В «Угадай число» называй **середину** диапазона: 50 → 25/75 → … Каждый шаг делит остаток пополам, поэтому любое число 1–100 угадывается максимум за **7** попыток. Это метод «деления пополам» — им же компьютер ищет в отсортированных данных.

---

## 🎓 Для продвинутых

- **`continue`** — «пропусти остаток тела и перейди к следующему витку» (в отличие от `break`, который выходит совсем). Разберём в Модуле 3 глубже.
- **Цикл может ни разу не выполниться:** если условие ложно сразу (`while 1 > 5:`), тело не запустится вообще — это нормально.
- **`while` vs `for`:** `while` — когда **не знаем число повторов** (пока не угадает). `for` (следующий урок) — когда **знаем** (ровно 10 раз, по списку).

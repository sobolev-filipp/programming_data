## 📖 Что нужно знать за 2 минуты

Цикл `while` повторяет тело, **пока** условие истинно:
```python
count = 1              # начало
while count <= 5:      # условие (двоеточие!)
    print(count)       # тело (с отступом) — повторяется
    count += 1         # изменение — иначе вечный цикл
```
`while True` повторяет **всегда**, а `break` **выходит** из цикла. Зависло — **`Ctrl+C`**.

## Часть A — задания с пошаговым разбором

### Задание 1. Первый цикл
**Тема:** счёт от 1 до 5.

**Разбор по шагам:**
1. Заводим переменную до цикла: `count = 1`.
2. Пишем условие с двоеточием: `while count <= 5:`.
3. В теле (с отступом) печатаем и **меняем** переменную:
```python
count = 1
while count <= 5:
    print(count)
    count += 1
print("Готово")
```
4. Запусти. Печатает 1 2 3 4 5, потом «Готово».

✅ Без `count += 1` был бы вечный цикл.

---

### Задание 2. Обратный отсчёт
**Тема:** уменьшаем переменную.

**Разбор по шагам:**
1. Старт с большого: `n = 5`.
2. Условие — пока больше нуля: `while n > 0:`.
3. В теле печатаем и **уменьшаем**:
```python
n = 5
while n > 0:
    print(n)
    n -= 1
print("Старт!")
```
4. Печатает 5 4 3 2 1, потом «Старт!».

✅ Здесь к False приближает `n -= 1`.

---

### Задание 3. Копилка суммы
**Тема:** накопитель внутри цикла.

**Разбор по шагам:**
1. Заводим копилку и счётчик: `total = 0`, `n = 1`.
2. Пока `n <= 10` — прибавляем `n` к копилке:
```python
total = 0
n = 1
while n <= 10:
    total += n
    n += 1
print(f"Сумма = {total}")
```
3. Ответ 55. Копилку завели **до** цикла, меняем **внутри**.

✅ `total += n` — тот же приём, что счёт очков, но в цикле.

### Задание 4. while True + break
**Тема:** повторяй, пока не введут верное.

**Разбор по шагам:**
1. `while True:` — крутимся всегда.
2. Спрашиваем пароль, проверяем, выходим по `break`:
```python
while True:
    p = input("Пароль: ")
    if p == "1234":
        print("Открыто!")
        break
    print("Неверно, ещё раз.")
```
3. Пока не введут `1234` — просит снова. Верно → `break`.

✅ `while True` выходит только через `break`.

---

### Задание 5. Мини-игра «Угадай»
**Тема:** цикл + условия + random.

**Разбор по шагам:**
1. `import random`, `secret = random.randint(1, 10)`.
2. В цикле спрашиваем и сравниваем:
```python
import random
secret = random.randint(1, 10)
while True:
    guess = int(input("Число 1-10: "))
    if guess < secret:
        print("Больше!")
    elif guess > secret:
        print("Меньше!")
    else:
        print("Угадал!")
        break
```
3. Подсказки ведут к числу, `break` завершает при победе.

✅ `if/elif/else` спокойно живут внутри `while`.

## Часть B — задания с мини-подсказками

### Задание 6. Чётные до 20

### Задание 8. Стоп-слово
Проси слова, пока не введут `стоп`.

В игре «Угадай» добавь `attempts += 1` и выведи число попыток при победе.
> 💡 Заведи `attempts = 0` до цикла.

### Задание 10. Сумма до нуля
Складывай числа, пока не введут 0.
> 💡 `if n == 0: break`, иначе `total += n`.

### Задание 11. Повтори N раз
Спроси N, выведи `Ура` ровно N раз.
> 💡 `i = 0`, `while i < N:` внутри `i += 1`.

### Задание 12. Накопить очки
Складывай очки, пока сумма `< 20`.
> 💡 Условие прямо в while: `while total < 20:`.

### Задание 13. Только положительное
Проси число, пока не введут `> 0`.
> 💡 `if n > 0: break`.

### Задание 14. Максимум
Числа до 0, выведи наибольшее.
> 💡 `best = 0`, `if n > best: best = n`.

### Задание 15. 🎓 Факториал
Посчитай 5! циклом.
> 💡 `result = 1`, `result *= n`, `n += 1`.

### Задание 16. 🎓 Сумма цифр
Число → сумма его цифр.
> 💡 `n % 10` (последняя цифра), `n //= 10`.

### Задание 17. 🎓 Игра с лимитом
«Угадай число» на 7 попыток, флаг `won`.
> 💡 `while attempts < 7:` + `if not won:` после.

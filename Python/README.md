# 🐍 Python + 🎮 Godot — курс программирования (2 год)

Курс программирования для 5–11 классов, **2 год обучения** (после компьютерной грамотности, перед C#+Unity). **135 ак.ч.**, урок = 2 ак.ч. (1,5 ч).

👉 **Полная карта курса — в [ПЛАН-КУРСА.md](ПЛАН-КУРСА.md).**

## Что внутри

- **Python-ядро (~90 ч):** от первой программы до приложений с окном (Tkinter). Плотная теория, SVG-схемы, «вкусные» практики с реальными библиотеками (`turtle`, `random`, `pyjokes`, `wikipedia`, `requests`/погода, `json`).
- **Godot-блок (~45 ч):** геймдев на 2D-играх — платформер, Dino, Flappy Bird, Змейка, Shooter 2D, Terraria.

## Структура

```
модуль-01-первые-шаги/ … модуль-12-terraria-и-итог/
   └── урок-XX-тема/
         урок.md · практика.md · повторение.md · самоучитель.md
         лайфхак.md · преподавателю.md · изображения.md · викторина.html
         изображения/ · материалы/
банк-заданий/        — накопительные задачи по темам (домашка/резерв)
справочники/         — шпаргалки (синтаксис, turtle, tkinter, GDScript)
материалы-общие/     — общие ассеты (иконки, стартовые проекты Godot)
```

## Формат урока

Каждый урок — отдельная папка из 8–9 файлов (см. [ПЛАН-КУРСА.md](ПЛАН-КУРСА.md) → «Формат каждого урока»). Планка качества и стиль — как в курсе 1 года.

## Главные мысли

1. **`while условие:`** — повторяет тело, **ПОКА** условие True.
2. У цикла **три части**: начало (переменная) → условие → **изменение** внутри тела.
3. Нет изменения → **вечный цикл**. Остановить — **`Ctrl + C`**.
4. **`while True`** — «повторяй всегда», выход даёт только **`break`**.
5. **`break`** — выйти из цикла немедленно.

---

## Скелет цикла

```python
count = 1              # 1) начало
while count <= 5:      # 2) условие (+ двоеточие!)
    print(count)       # 3) тело (с отступом)
    count += 1         #    изменение → приближаем к False
print("готово")        # вне цикла
```

Печатает 1 2 3 4 5. На count = 6 условие ложно — выход.

## Три рабочих шаблона

```python
# счёт вверх
n = 1
while n <= 10:
    print(n)
    n += 1

# обратный отсчёт
n = 5
while n > 0:
    print(n)
    n -= 1

# копилка суммы
total = 0
n = 1
while n <= 100:
    total += n
    n += 1
```

## 🆕 Список + while (мостик к for)

```python
games = ["Minecraft", "Roblox", "Sims"]
i = 0
while i < len(games):     # идём по индексам 0,1,2
    print(games[i])
    i += 1
```

Списки знакомы по КНБ (Модуль 2). Перебирать их удобнее циклом `for` — Урок 2.

## while True + break

```python
while True:
    x = input("Пароль: ")
    if x == "1234":
        print("Открыто")
        break          # выходим
    print("Ещё раз")
```

`while True` сам не остановится — выход только через `break`.

## Игра «Угадай число» (ядро)

```python
import random
secret = random.randint(1, 100)
attempts = 0
while True:
    guess = int(input("Вариант: "))
    attempts += 1
    if guess < secret:
        print("Больше!")
    elif guess > secret:
        print("Меньше!")
    else:
        print(f"Верно за {attempts}!")
        break
```

«Больше!» = загаданное больше твоего. Стратегия — всегда середина (≤7 попыток).

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| печатает без конца | нет `count += 1` | меняй переменную; `Ctrl+C` |
| `SyntaxError` на while | нет `:` | `while ...:` |
| `IndentationError` | тело без отступа | 4 пробела |
| `while True` не выходит | нет `break` | `if ...: break` |
| `break` — SyntaxError | `break` вне цикла | только внутри `while`/`for` |

---

## Что должно остаться в голове

1. `while` = «повторяй, пока условие True».
2. Начало → условие → изменение (иначе вечный цикл).
3. `Ctrl+C` останавливает зависший цикл.
4. `while True` + `break` = «повторяй, пока не случится нужное».
5. Внутри цикла спокойно живут `if/elif/else` и счётчики `+=`.

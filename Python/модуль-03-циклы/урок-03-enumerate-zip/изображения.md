## 1. `изображения/enumerate.svg` 🔢
**Когда:** Часть 1 (`enumerate`), 5–19 мин.

Список `games` слева → `enumerate` → пары `(i, game)`: `i=0` + `"Minecraft"` и т.д. Внизу — фиолетовая плашка про `start=1`.

**Как обсудить:**
- Подчеркни: `enumerate` отдаёт **пару** — номер и элемент; поэтому слева `for i, game in ...` — **две** переменные.
- Номера по умолчанию с 0; `start=1` — с единицы (места, пункты).
- Свяжи с ручным счётчиком из разминки: `enumerate` делает `i += 1` сам.

## 2. `изображения/zip.svg` 🤝
**Когда:** Часть 2 (`zip`), 19–33 мин.

Два списка (names сверху, scores снизу) «сшиваются» стрелками-молнией в пары `Аня, 15` / `Боря, 22` / `Вика, 8`. Внизу — предупреждение про разную длину.

**Как обсудить:**
- Метафора **молнии**: `zip` соединяет элементы из одинаковых позиций.
- `names[0]` и `scores[0]` — про одного игрока; списки должны быть «в ногу».
- Разная длина → идёт по короткому (лишнее отбрасывается). Покажи на примере.

## 3. `изображения/sleep-анимация.svg` ⏳
**Когда:** Часть 4 (`time.sleep`), 43–57 мин.

Три кадра прогресс-бара (30% → 60% → 100%) со стрелками `time.sleep(0.2)`; справа пояснение «одна строка перерисовывается». Внизу — код.

**Как обсудить:**
- `time.sleep(t)` — пауза между кадрами; без неё всё мелькнёт мгновенно.
- `end="\r"` — курсор в начало строки, следующий `print` пишет поверх → «движение».
- В конце обязательно пустой `print()`, иначе текст «наедет» на бар.

## 4. `изображения/пылесос-список.svg` 🐢
**Когда:** Часть 5 (игра «Пылесос по списку»), 57–72 мин.

Комната-сетка с мусором, у каждой точки — координаты `(x, y)`. Справа два списка `trash_x`/`trash_y`, стрелка `zip → пары` и код с `for x, y in zip(...): go_to(x, y); clean()`.

**Как обсудить:**
- Свяжи: координаты точки лежат в РАЗНЫХ списках (X отдельно, Y отдельно), `zip` собирает их в пары.
- Покажи, что пара `(x, y)` — ровно аргументы `go_to(x, y)`.
- 🎓 `enumerate` добавит номер убранного мусора.

## 💡 Общие советы
- Схемы светлые, читаются с задних парт; масштаб `Ctrl` + `+`.
- `enumerate.svg` и `zip.svg` держи рядом — дети путают, кто из них про номер, кто про два списка.
- `пылесос-список.svg` — лучший «мостик» от абстрактного `zip` к наглядному действию (пары координат → маршрут).
- Лучший эффект даёт **живой запуск** `анимация.py` на проекторе после схемы `sleep-анимация.svg`.

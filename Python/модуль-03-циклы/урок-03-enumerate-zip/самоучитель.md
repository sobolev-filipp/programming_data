## 📖 Что нужно знать за 2 минуты

```python
# enumerate — номер + значение
for i, x in enumerate(items):          # 0 x, 1 y, ...
for n, x in enumerate(items, start=1): # 1 x, 2 y, ...

# zip — два списка сразу
for a, b in zip(A, B):                 # пары (A[0],B[0]), (A[1],B[1])...

# итоги списка чисел
sum(nums), max(nums), min(nums), len(nums)

# пауза
import time
time.sleep(0.5)
```
Слева от `in` — столько переменных, сколько в паре. `zip` идёт по короткому списку.

## Часть A — задания с пошаговым разбором

### Задание 1. enumerate — номера
**Тема:** номер + значение.

**Разбор по шагам:**
1. Список: `fruits = ["яблоко", "банан", "слива"]`.
2. Пройди с номером:
```python
fruits = ["яблоко", "банан", "слива"]
for i, fruit in enumerate(fruits):
    print(i, fruit)
```
3. Вывод: `0 яблоко`, `1 банан`, `2 слива`.

✅ Две переменные: номер и элемент.

---

### Задание 2. start=1
**Тема:** счёт с единицы.

**Разбор по шагам:**
1. Добавь `start=1`:
```python
for place, fruit in enumerate(fruits, start=1):
    print(f"{place}. {fruit}")
```
2. Теперь `1. яблоко`, `2. банан`, `3. слива`.

✅ `start=1` — для мест и списков.

---

### Задание 3. zip — два списка
**Тема:** пары из двух списков.

**Разбор по шагам:**
1. Два списка одной длины:
```python
names = ["Аня", "Боря"]
scores = [15, 22]
for name, score in zip(names, scores):
    print(f"{name}: {score}")
```
2. Вывод: `Аня: 15`, `Боря: 22`.

✅ `zip` берёт из одинаковых позиций.

---

### Задание 4. Итоги списка
**Тема:** sum/max/min/len.

**Разбор по шагам:**
1. Список чисел: `scores = [15, 22, 8]`.
2. Посчитай встроенными:
```python
scores = [15, 22, 8]
print("Сумма:", sum(scores))
print("Лучший:", max(scores))
print("Игроков:", len(scores))
```

✅ Не нужен цикл для простых итогов.

---

### Задание 5. Прогресс-бар
**Тема:** time.sleep + end="\r".

**Разбор по шагам:**
1. Подключи время: `import time`.
2. Рисуй растущую полоску на месте:
```python
import time
for i in range(1, 11):
    bar = "#" * i + "." * (10 - i)
    print(f"[{bar}] {i*10}%", end="\r")
    time.sleep(0.2)
print()
print("Готово!")
```
3. Полоска растёт, не печатаясь в столбик.

✅ `end="\r"` перерисовывает строку, `sleep` даёт паузу.

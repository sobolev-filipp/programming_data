## 1. Блиц-вопросы (устно)

1. Как читается `for x in games`? *(для каждого элемента)*
2. Что даёт `range(1, 5)`? *(1 2 3 4 — 5 не входит)*
3. Как вывести в одну строку? *(`print(x, end=" ")`)*
4. Что делает `score += 1`? *(увеличивает счётчик)*
5. Как узнать длину списка? *(`len(список)`)*

---

## 2. Предскажи вывод

```python
for c in "код":
    print(c)
```

<details><summary>Ответ</summary>

`к`, `о`, `д` — по букве на строке.
</details>

---

## 3. Найди неудобство

```python
games = ["Minecraft", "Roblox", "Sims"]
i = 1
for game in games:
    print(i, game)
    i += 1
```

<details><summary>В чём неудобство?</summary>

Ручной счётчик `i` и `i += 1` — легко забыть увеличить. Сегодня `enumerate` сам ведёт номер: `for i, game in enumerate(games)`.
</details>

---

## 4. Мостик к теме

`for` перебирает **один** список. Но данные часто парами (игрок + очки) и с номерами (1-е место). Сегодня — `enumerate` (номер+значение), `zip` (два списка сразу), итоги `sum/max`, и анимация через `time.sleep`. 🏆

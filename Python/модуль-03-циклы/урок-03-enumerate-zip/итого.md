## Главные мысли

1. **`enumerate`** — номер + значение; `start=1` для счёта с 1.
2. **`zip`** — два списка **параллельно**, в пары. По короткому, если длины разные.
3. Итоги списка: **`sum` / `max` / `min` / `len`** (для чисел).
4. Подсчёт **по условию** — цикл + `if` + счётчик.
5. **`time.sleep(t)`** — пауза; **`end="\r"`** — перерисовать строку (прогресс-бар).

---

## enumerate — номер + значение

```python
for i, game in enumerate(games):        # 0 Minecraft, 1 Roblox, ...
    print(i, game)

for place, game in enumerate(games, start=1):   # 1, 2, 3 ...
    print(f"{place}. {game}")
```

Слева от `in` — ДВЕ переменные (номер, элемент).

---

## zip — два списка сразу

```python
for name, score in zip(names, scores):
    print(f"{name}: {score}")
```

`names[0]` и `scores[0]` — про одного. Разная длина → по короткому.

---

## Итоги списка

```python
sum(scores)    # сумма
max(scores)    # наибольшее
min(scores)    # наименьшее
len(scores)    # количество
```

Подсчёт по условию:
```python
count = 0
for x in scores:
    if x >= 20:
        count += 1
```

## time.sleep + \r

```python
import time
for i in range(1, 11):
    bar = "#" * i + "." * (10 - i)
    print(f"[{bar}] {i*10}%", end="\r")   # перерисовка на месте
    time.sleep(0.2)
print()        # перевод строки в конце
```

`time.sleep(секунды)` — пауза. `\r` — курсор в начало строки.

## 🐢 Пылесос по списку (zip)

Мусор задан двумя списками координат. Команды: `go_to(x, y)`, `clean()`.

```python
for x, y in zip(trash_x, trash_y):   # пары (x, y)
    go_to(x, y)
    clean()
```

🎓 Нумерация: `for i, (x, y) in enumerate(zip(trash_x, trash_y), start=1):`

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| пара `(0, 'x')` | одна переменная | `for i, x in ...` |
| номера с 0 | нет `start=1` | `enumerate(..., start=1)` |
| zip коротит | разная длина | одинаковая длина |
| бар в столбик | нет `end="\r"` | добавь `end="\r"` |
| `NameError: time` | нет import | `import time` |

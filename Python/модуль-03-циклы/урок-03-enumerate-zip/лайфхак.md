# Лайфхаки урока 3 «enumerate, zip, накопители» 🧰

> Приёмы, чтобы работать с парами и итогами списков.

---

## 🎯 Нужен номер — бери enumerate

Вместо ручного `i = 0 ... i += 1`:

```python
for i, item in enumerate(items):        # номер сам растёт
    print(i, item)
```

Считать с 1 (места, пункты) — `enumerate(items, start=1)`.

---

## 🎯 Два списка — бери zip

Если `names[k]` и `scores[k]` про одно и то же — не ходи по индексам, соедини через `zip`:

```python
for name, score in zip(names, scores):
    ...
```

Держи списки **одной длины** — иначе `zip` обрежет по короткому.

---

## 🎯 Слева от `in` — столько переменных, сколько в паре

```python
for i, x in enumerate(xs):      # пара (номер, значение) → 2 переменные
for a, b in zip(A, B):          # пара (из A, из B) → 2 переменные
```

Одна переменная — и в неё попадёт **весь кортеж** `(0, "x")`.

---

## 🎯 Итоги без цикла

```python
sum(nums)   max(nums)   min(nums)   len(nums)
```

Среднее: `sum(nums) / len(nums)`. Подсчёт **по условию** — уже цикл + `if` + счётчик.

---

## 🎯 Анимация: time.sleep + \r

```python
import time
print(text, end="\r")   # перерисовать эту же строку
time.sleep(0.2)         # пауза
```

- `\r` — «в начало строки» (как `\n` — «новая строка»).
- В конце анимации сделай пустой `print()`, иначе следующий текст «наедет».
- Меньше пауза → быстрее анимация.

---

## 🎯 Прогресс-бар из символов

```python
bar = "#" * done + "." * (total - done)
print(f"[{bar}]", end="\r")
```

`#` — заполнено, `.` — пусто. Меняй символы: `=`, `█`, `*`.

---

## 🐞 Топ-5 ошибок

1. **Одна переменная для пары** → в ней кортеж `(0,'x')`. Пиши две.
2. **Забыл `start=1`** → номера с 0.
3. **Списки разной длины в `zip`** → потеря хвоста.
4. **Нет `end="\r"`** → бар печатается в столбик.
5. **Забыл `import time`** → `NameError`.

---

## 🎓 Для продвинутых

- **`enumerate(zip(a, b), start=1)`** — номер + пара сразу: `for i, (name, score) in ...`.
- **`zip` трёх списков:** `for a, b, c in zip(A, B, C)` — идут втроём в ногу.
- **`sum` с условием одной строкой** (🎓): `sum(1 for x in nums if x >= 20)` — «сколько ≥ 20». Разберём генераторы позже.
- **`sleep`-анимация и turtle:** в графике вместо `\r` двигают саму черепашку — тот же принцип «кадр за кадром».

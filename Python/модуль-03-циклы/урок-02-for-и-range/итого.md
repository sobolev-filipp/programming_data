## Главные мысли

1. **`for x in коллекция:`** — берёт элементы **по одному**, без счётчика.
2. Перебрать можно **список** (по элементам), **строку** (по буквам), **`range`** (числа).
3. **`range`: start входит, stop НЕ входит.** `range(1, 11)` = 1..10.
4. Приём **`print(end=" ")`** — печать в одну строку; `"*" * k` — повтор строки.
5. `for` для списков лучше `while` — короче и не зациклится.

---

## Перебор — три вида

```python
# список — по элементам
for game in ["Minecraft", "Roblox"]:
    print(game)

# строка — по буквам
for letter in "кот":
    print(letter)

# range — числа
for i in range(1, 6):     # 1 2 3 4 5
    print(i)
```

---

## range — три формы

| Запись | Числа |
|--------|-------|
| `range(5)` | 0 1 2 3 4 |
| `range(1, 6)` | 1 2 3 4 5 |
| `range(2, 11, 2)` | 2 4 6 8 10 |
| `range(5, 0, -1)` | 5 4 3 2 1 |

**stop не входит!** «до 10» → `range(1, 11)`.

---

## Печать в одну строку

```python
for i in range(1, 6):
    print(i, end=" ")     # 1 2 3 4 5
print()                   # перевод строки в конце
```

---

## Таблица умножения

```python
n = int(input("Число: "))
for i in range(1, 11):
    print(f"{n} x {i} = {n * i}")
```

## Ёлочка

```python
for i in range(1, height + 1):
    print(" " * (height - i) + "*" * (2 * i - 1))
```

## 🐢 Игра «Умный пылесос» (turtle-каркас)

Команды: `right() left() up() down() clean()`, флаг `wall`. Меняй `TASK`.

```python
TASK = 1           # номер задания
for i in range(9):        # ряд мусора справа
    right()
    clean()
```

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| нет ×10 в таблице | `range(1,10)` | `range(1,11)` |
| `SyntaxError` на for | нет `:` | `for i in range(...):` |
| всё в столбик | нет `end` | `print(x, end=" ")` |
| начал с 0 | `range(n)` от 0 | `range(1, n+1)` |

---

## Что должно остаться в голове

1. `for x in что-то` — «для каждого».
2. Список, строка, range — всё перебирается одинаково.
3. `range`: start входит, stop нет.
4. `end=" "` — в одну строку; `"*"*k` — повтор.
5. 🐢 пылесос: собрать ряд/столбец/диагональ мусора циклом.

## 📖 Что нужно знать за 2 минуты

`for` перебирает коллекцию **по одному элементу**:
```python
for x in [10, 20, 30]:   # список
    print(x)
for c in "кот":          # строка (по буквам)
    print(c)
for i in range(1, 6):    # числа 1..5
    print(i)
```
`range(a, b)` — числа от a до **b−1** (stop не входит!). `range(a, b, шаг)` — с шагом.
Приём `print(x, end=" ")` — печать в одну строку.

### Задание 1. Перебор списка
**Тема:** `for` по списку.

**Разбор по шагам:**
1. Заведи список: `colors = ["красный", "жёлтый", "зелёный"]`.
2. Пройди по нему:
```python
colors = ["красный", "жёлтый", "зелёный"]
for color in colors:
    print(color)
```
3. Никакого индекса — `for` сам берёт каждый.

✅ `for color in colors` = «для каждого цвета».

---

### Задание 2. Перебор строки
**Тема:** `for` по буквам.

**Разбор по шагам:**
1. Возьми слово: `word = "Привет"`.
2. Пройди по буквам:
```python
word = "Привет"
for letter in word:
    print(letter)
```
3. Каждая буква — на своей строке.

✅ Строка перебирается как последовательность символов.

### Задание 3. range — числа
**Тема:** `range(a, b)`.

**Разбор по шагам:**
1. Выведи числа 1..5:
```python
for i in range(1, 6):
    print(i)
```
2. Заметь: `6` **не** печатается — stop не входит.
3. Для «до 10» нужно `range(1, 11)`.

✅ `range(a, b)` — от a до b−1.

### Задание 4. Повторить N раз
**Тема:** `range(n)`.

**Разбор по шагам:**
1. Спроси N: `n = int(input("Сколько раз? "))`.
2. Повтори:
```python
n = int(input("Сколько раз? "))
for i in range(n):
    print("Привет!")
```
3. `range(n)` даёт n чисел (0..n−1) — значит n повторов.

✅ Само число `i` можно не использовать.

### Задание 5. Таблица умножения
**Тема:** `for` + `range` + f-строка.

**Разбор по шагам:**

2. Пройди 1..10 и печатай произведение:

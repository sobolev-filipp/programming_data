# Лайфхаки урока 2 «Цикл for и range» 🧰

> Приёмы, чтобы `for` и `range` работали как надо.

---

## 🎯 «для каждого» — читай вслух

`for game in games:` = «для каждой игры в списке games». Если фраза звучит осмысленно — цикл написан верно. Имя переменной бери в единственном числе: `for card in cards`.

---

## 🎯 Правило `range`: stop НЕ входит

```python
range(1, 6)    # 1 2 3 4 5   — шестёрки НЕТ
range(1, 11)   # 1..10       — для «до 10» верхняя граница 11
```

Хочешь числа «до N включительно» — пиши `range(1, N + 1)`.

---

## 🎯 `range(n)` начинает с нуля

```python
range(5)   # 0 1 2 3 4  (пять чисел, но с 0!)
```

Нужно «повторить 5 раз», а само число не важно — `for _ in range(5):` (подчёркивание = «переменная не нужна»).

---

## 🎯 `print(end=...)` — управляем концом строки

```python
print("a", end=" ")   # после — пробел, не перевод строки
print("b", end="")    # вообще ничего
print("c")            # обычный перевод строки
# выведет: a bc
```

Для «в одну строку» — `end=" "`, а в конце пустой `print()`.

---

## 🎯 Повтор строки — `*`

```python
"=" * 20      # ===================
" " * 4       # четыре пробела
"ха" * 3      # хахаха
```

Рамки, отступы, ёлочки — всё на умножении строк.

---

## 🎯 for или while?

- Знаешь, **что перебрать** (список/строку) или **сколько раз** → `for`.
- Повторять, **пока не случится** событие (угадал, ввели «стоп») → `while`.

По списку — почти всегда `for`: он короче и не зациклится.

## 🐞 Топ-5 ошибок

1. **`range(1, 10)` вместо `range(1, 11)`** → потерял последнее число.
2. **Нет `:` после `for`** → `SyntaxError`.
3. **Тело без отступа** → `IndentationError`.
4. **Ждал печать в ряд, а вышел столбик** → добавь `end=" "`.
5. **`for c in ["слово"]`** перебирает список из одной строки, а не буквы. Для букв — `for c in "слово"`.

## 🎓 Для продвинутых

- **`for` по строке даёт символы**, по списку — элементы, по словарю (Модуль 4) — ключи. Всё это «последовательности».
- **`range` — «ленивый»:** не создаёт список чисел в памяти, а выдаёт их по одному. Поэтому `range(1000000)` не тормозит.
- **Вложенный цикл** (цикл в цикле) — таблицы и узоры — тема Урока 4.
- **`enumerate`/`zip`** (номер+значение, два списка сразу) — следующий урок.

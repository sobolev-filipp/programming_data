# Что показать на проекторе — урок 2 «Цикл for и range» 🖼

> Три SVG-схемы. Открываются в браузере (`Ctrl+O` или перетащи файл). Показывай в момент из [преподавателю.md](преподавателю.md).

## 1. `изображения/for-перебор.svg` 🔁
**Когда:** Части 1–2 (`for` по списку и строке), 5–29 мин.

Две ленты: сверху список `games` (Minecraft/Roblox/Sims) → элемент за элементом попадает в переменную `game` → `print(game)`; снизу строка `"кот"` перебирается по буквам в `ch`.

**Как обсудить:**
- Веди пальцем: «первый элемент → в переменную → тело; второй → в переменную → тело…».
- Подчеркни: **нет индекса, нет `+= 1`** — `for` сам берёт по одному.
- Строка внизу — что она **тоже** последовательность: перебирается по буквам так же, как список по элементам.

## 2. `изображения/range-лента.svg` 🔢
**Когда:** Часть 3 (`range`), 29–47 мин. **Ключевая схема урока.**

Три числовые ленты: `range(1, 6)` (6 перечёркнута — не входит), `range(2, 11, 2)` (шаг 2), `range(5, 0, -1)` (обратный отсчёт). Справа — `range(n)` от нуля.

**Как обсудить:**
- Главное: **start входит (зелёный), stop НЕ входит (красный перечёркнут)**. Отсюда `range(1, 11)` для «до 10».
- Покажи шаг: во второй ленте перепрыгиваем нечётные; в третьей — идём назад.
- Напомни `range(5)` = 0 1 2 3 4 (с нуля).

## 3. `изображения/пылесос.svg` 🐢
**Когда:** Часть 5 (игра «Умный пылесос»), 59–74 мин.

Комната-сетка 10×10: пылесос (оранжевый) слева, ряд мусора (серые точки), убранные клетки (синие), стрелка «едем вправо». Справа — команды (`right/left/up/down/clean`, флаг `wall`) и код с `TASK` + циклом.

**Как обсудить:**
- Покажи цель: собрать ВЕСЬ мусор, проехав по клеткам и вызывая `clean()`.
- Свяжи ряд мусора с циклом: 9 клеток → `for i in range(9): right(); clean()`.
- Мотивация цикла: без `for` — 18 строк, с циклом — 3. И `TASK` меняет расстановку мусора (12 заданий).

## Библиотеки и приёмы модуля

- `random` (встроенная) — «Угадай число», генераторы.
- `time` (встроенная) — `time.sleep` для пауз/анимаций (бегущая строка, прогресс-бар).
- Консольные трюки: `print(end=)`, `print(sep=)`, возврат каретки `\r`.
- `turtle` (встроенная) — **как игра-практика «Умный пылесос»**: комната-сетка, команды `right/left/up/down/clean` (английские), флаг `wall`, `TASK` открывает задания растущей сложности. Ученик пишет **только алгоритм на циклах**. **Адаптировано под desktop** (`turtle.tracer`/`turtle.done()`). Не «нарисуй фигуру», а «пройди задание».

# Лайфхаки урока 4 «Вложенные циклы, break, continue» 🧰

> Приёмы для таблиц, узоров и управления циклом.

---

## 🎯 Читай вложенный цикл «строки → столбцы»

```python
for row in range(H):        # СТРОКИ
    for col in range(W):    # СТОЛБЦЫ в строке
        ...                 # одна клетка
    print()                 # конец строки
```

Спроси себя: «сколько строк?» → внешний; «что в каждой строке?» → внутренний.

---

## 🎯 `print()` для переноса — ПОСЛЕ внутреннего

Самая частая ошибка — таблица склеивается в одну строку. Лечение: `print()` **после** внутреннего цикла, но **внутри** внешнего (с отступом внешнего).

---

## 🎯 Ровные столбцы — форматирование ширины

```python
print(f"{row*col:4}", end="")   # число в поле шириной 4
```

`:4` выравнивает по правому краю в 4 символа — столбцы получаются ровными.

---

## 🎯 Узор = «сколько строк и что в строке»

- Прямоугольник: внутренний `range(W)` — фиксированная ширина.
- Треугольник: внутренний `range(row)` — ширина растёт со строкой.
- Шахматка: внутри `if (row+col) % 2 == 0`.

Меняешь внутренний цикл/условие — меняется узор.

---

## 🎯 break — «нашёл, хватит»

```python
for x in data:
    if подходит(x):
        print(x)
        break        # дальше не ищем
```

Экономит время: не проходим остаток зря.

---

## 🎯 continue — «пропущу этот, идём дальше»

```python
for x in data:
    if x пустой:
        continue     # пропускаем плохой элемент
    обработать(x)
```

Чище, чем большой `if` вокруг всего тела.

---

## 🎯 break во вложенном выходит из ОДНОГО цикла

`break` покидает **ближайший** (внутренний) цикл, внешний идёт дальше. Нужно выйти из обоих — заведи флаг:

```python
found = False
for row in ...:
    for col in ...:
        if нашли:
            found = True
            break
    if found:
        break
```

---

## 🐞 Топ-5 ошибок

1. **Нет `print()` после внутреннего** → таблица в одну строку.
2. **Одинаковый отступ** → тело попало не в тот цикл.
3. **Внутренний не зависит от `row`**, а нужен треугольник.
4. **Ждал выход из обоих циклов**, а `break` вышел из одного.
5. **`break`/`continue` вне цикла** → `SyntaxError`.

---

## 🎓 Для продвинутых

- **Три уровня вложенности** (куб, 3D-таблица) — редко, но бывает. Каждый уровень — свой отступ.
- **`else` у цикла** (🎓): блок `for ... else` выполнится, если цикл **не** прервали `break` — удобно для «не нашли».
- **Читаемость:** глубокая вложенность (3–4 уровня) — сигнал вынести часть в **функцию** (Модуль 5).

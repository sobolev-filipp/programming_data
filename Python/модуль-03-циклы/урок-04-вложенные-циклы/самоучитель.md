## 📖 Что нужно знать за 2 минуты

```python
# вложенный цикл: внутренний проходит весь на каждом шаге внешнего
for row in range(3):        # строки
    for col in range(3):    # столбцы
        print(row, col)
    print()                 # перенос строки — ПОСЛЕ внутреннего

# break — выйти из цикла; continue — пропустить виток
for n in range(10):
    if n == 5: break        # стоп
    if n % 2: continue      # пропустить нечётные
    print(n)
```

## Часть A — задания с пошаговым разбором

### Задание 1. Прямоугольник
**Тема:** двойной цикл.

**Разбор по шагам:**
1. Внешний — строки, внутренний — символы:
```python
for row in range(4):
    for col in range(10):
        print("#", end="")
    print()
```
2. `print()` после внутреннего переносит строку.

✅ 4 строки по 10 `#`.

---

### Задание 2. Таблица умножения
**Тема:** таблица 10×10.

**Разбор по шагам:**
1. Строки × столбцы, произведение в клетку:
```python
for row in range(1, 11):
    for col in range(1, 11):
        print(f"{row*col:4}", end="")
    print()
```
2. `:4` — ровные столбцы.

✅ Красивая таблица Пифагора.

---

### Задание 3. Треугольник
**Тема:** внутренний зависит от внешнего.

**Разбор по шагам:**
1. В строке `row` печатаем `row` звёзд:
```python
for row in range(1, 6):
    for col in range(row):
        print("*", end="")
    print()
```
2. `range(row)` — вот связь: строка 1 → 1 звезда, строка 5 → 5.

✅ Ступенчатый треугольник.

---

### Задание 4. break
**Тема:** выйти досрочно.

**Разбор по шагам:**
1. Ищем первое число, кратное 7:
```python
for n in range(1, 100):
    if n % 7 == 0:
        print("Нашли:", n)
        break
```
2. `break` завершает цикл сразу.

✅ Не считаем до 100 зря.

---

### Задание 5. continue
**Тема:** пропустить виток.

**Разбор по шагам:**
1. Числа 1..10, кроме кратных 3:
```python
for n in range(1, 11):
    if n % 3 == 0:
        continue
    print(n, end=" ")
```
2. `continue` пропускает `print`, но цикл идёт дальше.

✅ Вывод: 1 2 4 5 7 8 10.

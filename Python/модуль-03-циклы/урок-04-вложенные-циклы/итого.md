# Урок 4 «Вложенные циклы, break, continue» — итого 📌

---

## Главные мысли

1. **Вложенный цикл** — цикл внутри цикла. Внутренний проходит **весь** на каждом шаге внешнего.
2. Внешний — **строки**, внутренний — **столбцы**. Так строятся таблицы и узоры.
3. Перенос строки — `print()` **после** внутреннего цикла (внутри внешнего).
4. **`break`** — выйти из цикла досрочно. **`continue`** — пропустить виток.
5. Во вложенном `break`/`continue` действуют на **свой** (ближайший) цикл.

---

## Скелет вложенного цикла

```python
for row in range(3):        # внешний (строки)
    for col in range(3):    # внутренний (столбцы)
        print(row, col)     # тело: 3 × 3 = 9 раз
    print()                 # перенос строки — ПОСЛЕ внутреннего
```

---

## Таблица и узоры

```python
# таблица умножения 10x10
for row in range(1, 11):
    for col in range(1, 11):
        print(f"{row*col:4}", end="")
    print()

# треугольник (внутренний зависит от внешнего)
for row in range(1, 6):
    for col in range(row):
        print("*", end="")
    print()

# шахматка
for row in range(8):
    for col in range(8):
        print("#" if (row+col) % 2 == 0 else ".", end="")
    print()
```

---

## break и continue

```python
for n in range(1, 100):
    if n % 7 == 0:
        print(n); break        # нашли — выходим

for n in range(1, 11):
    if n % 3 == 0:
        continue               # пропускаем кратные 3
    print(n, end=" ")
```

`break` — стоп совсем. `continue` — пропустить один виток.

## 🐢 Пылесос: убрать область

Команды: `go_to(x, y)`, `clean()`. Меняй `TASK`.

```python
for row in range(2, 7):        # строки области
    for col in range(2, 7):    # столбцы области
        go_to(col, row)
        clean()
```

🎓 Шахматка: внутри `if (row+col) % 2 != 0: continue`.

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| таблица в 1 строку | нет `print()` после внутреннего | добавь `print()` |
| строки одинаковые | внутренний не зависит от row | `range(row)` |
| break вышел рано | выходит из внутреннего | флаг/условие снаружи |
| continue/break вне цикла | `SyntaxError` | только внутри цикла |

## Что должно остаться в голове

1. Вложенный цикл: внутренний проходит весь на каждом шаге внешнего.
2. Строки × столбцы; `print()` для переноса — после внутреннего.
3. Внутренний может зависеть от внешнего (`range(row)`).
4. `break` — выйти, `continue` — пропустить.
5. 🐢 область = двойной цикл.

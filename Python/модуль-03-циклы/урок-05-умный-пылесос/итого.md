# Урок 5 «Умный пылесос — практикум» — итого 📌

> Шпаргалка по выбору цикла и сенсорам.

---

## Главные мысли

1. **Под каждую задачу — свой цикл.** Знаешь длину → `for`; едешь «до стены» → `while` + сенсор; область → вложенный.
2. **Сенсоры стен** (`wall_right/left/up/down`, `wall`) — читаем в условии `while`.
3. **Координаты `x, y`** — текущая клетка пылесоса.
4. Вся комната — **«змейка»**: `for`(строки) + `while`(до стены) + флаг направления.
5. Убрать только нужные клетки — `continue` по условию (`(x+y)%2`).

---

## Команды и сенсоры

```
right() left() up() down()   # движение
clean()                      # убрать мусор
wall_right wall_left wall_up wall_down wall   # сенсоры (True/False)
x, y                         # координаты пылесоса (0..9)
```

---

## for или while?

```python
# длина ИЗВЕСТНА → for
for i in range(9):
    right(); clean()

# длина НЕизвестна («до стены») → while + сенсор
while not wall_right:
    right(); clean()
```

---

## Весь ряд от края до края

```python
while not wall_left:      # к левому краю
    left()
clean()
while not wall_right:     # обратно, убирая
    right(); clean()
```

---

## Змейка (вся комната)

```python
going_right = True
for row in range(10):
    clean()
    while (going_right and not wall_right) or (not going_right and not wall_left):
        right() if going_right else left()
        clean()
    if not wall_up:
        up()
    going_right = not going_right
```

---

## Шахматка / ромб — с continue

```python
# внутри маршрута:
if (x + y) % 2 != 0:
    continue          # пропускаем «белые» клетки
clean()
```

---

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| пылесос покраснел | лишний шаг | `while not сенсор` или точный `range` |
| `while` вечный | нет движения в теле | добавь `right()`/`up()` |
| змейка сбилась | не переключил флаг | `going_right = not going_right` |
| убрал лишнее | нет условия | `if ...: continue` |

---

## Что должно остаться в голове

1. Выбор цикла: for (знаю длину) / while (до стены) / вложенный (область).
2. Сенсоры `wall_*` — глаза пылесоса.
3. Змейка = for + while + флаг.
4. `continue` + `x,y` — убрать только нужное.
5. В `while` всегда есть движение к стене.

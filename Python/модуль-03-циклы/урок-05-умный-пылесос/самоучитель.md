# Самоучитель урока 5 «Умный пылесос — практикум» 🆘

> Разбираешься сам? Здесь — разбор ключевых приёмов практикума по шагам. Открой [`материалы/пылесос_практикум.py`](материалы/пылесос_практикум.py), ставь нужный `TASK` и пробуй.
> Опирается на Уроки 1–4 (`while`, `for`, `range`, вложенные, `break`/`continue`).

---

## 📖 Что нужно знать за 2 минуты

- Команды: `right() left() up() down() clean()`.
- Сенсоры: `wall_right wall_left wall_up wall_down wall` (True/False), координаты `x, y`.
- Выбор цикла: длина известна → `for`; «до стены» → `while` + сенсор; область → вложенный.

---

## Приём 1. Ряд известной длины — `for` (TASK 1)

**Разбор:**
1. Мусор — 9 клеток вправо от старта.
2. Делаем 9 раз «вправо + убрать»:
```python
for i in range(9):
    right()
    clean()
```

✅ Число шагов известно → берём `for`.

---

## Приём 2. Ряд неизвестной длины — `while` + сенсор (TASK 5)

**Разбор:**
1. Мусор справа, но считать не хотим.
2. Едем, ПОКА справа не стена:
```python
while not wall_right:
    right()
    clean()
```
3. Пылесос сам остановится у стены.

✅ «До стены» → `while not wall_right`.

---

## Приём 3. Доехать, потом убрать (TASK 7)

**Разбор:**
1. Мусор только у правой стены.
2. Сначала доезжаем (без уборки), потом убираем:
```python
while not wall_right:
    right()
clean()
```

✅ Движение и уборку можно разделять.

---

## Приём 4. Весь ряд от края до края (TASK 8)

**Разбор:**
1. Стоим в середине ряда.
2. Едем к левой стене, затем вправо до правой, убирая:
```python
while not wall_left:
    left()
clean()
while not wall_right:
    right()
    clean()
```

✅ Два `while` подряд — «туда» и «обратно».

---

## Приём 5. Периметр (TASK 9)

**Разбор:**
1. Старт в углу `(0,0)`.
2. Обходим край четырьмя циклами:
```python
clean()
while not wall_right:
    right(); clean()
while not wall_up:
    up(); clean()
while not wall_left:
    left(); clean()
while not wall_down:
    down(); clean()
```

✅ Четыре стены — четыре `while`.

---

## Приём 6. Змейка — вся комната (TASK 11)

**Разбор:**
1. Идём по строкам (`for row`), в каждой — до стены (`while`), меняя направление флагом:
```python
going_right = True
for row in range(10):
    clean()
    while (going_right and not wall_right) or (not going_right and not wall_left):
        right() if going_right else left()
        clean()
    if not wall_up:
        up()
    going_right = not going_right
```
2. `going_right` переключается после каждой строки.

✅ `for` + `while` + флаг — всё вместе.

---

## Приём 7. Убрать только нужное — `continue` (TASK 12, 14, 16)

**Разбор (шахматка):**
1. Идём змейкой по всей комнате, но убираем только «чёрные»:
```python
# внутри маршрута, перед clean():
if (x + y) % 2 != 0:
    continue          # пропускаем «белую» клетку
clean()
```
2. Для чётных столбцов — `if x % 2 != 0: continue`; для ромба — `if abs(x-4)+abs(y-4) > 3: continue`.

✅ `continue` + координаты `x, y` = убираем выборочно.

# Лайфхаки урока 5 «Умный пылесос — практикум» 🧰

> Приёмы, чтобы решать задания пылесосу быстро и без «врезался в стену».

---

## 🎯 Выбор цикла за 1 секунду

- «Еду, пока не упрусь» → `while not wall_right:` (или другой сенсор). **Это главный приём: комната случайная, длину не угадать.**
- «Повторяю фиксированное число раз (10 строк комнаты)» → `for row in range(10):`.
- «Заливаю область» → вложенный цикл (`for` в `for`) или змейка.

---

## 🎯 Читай сенсор в условии while

```python
while not wall_right:    # пока справа НЕ стена
    right()
    clean()
```

Пылесос сам остановится у стены — клетки считать не надо. Работает в комнате любой ширины.

---

## 🎯 В теле while ОБЯЗАТЕЛЬНО движение

Если внутри `while not wall_right:` нет `right()`, сенсор никогда не станет True → **вечный цикл**. Всегда двигайся к стене внутри `while`.

---

## 🎯 Весь ряд: сначала к стене, потом обратно

```python
while not wall_left:     # доехали до левого края
    left()
clean()
while not wall_right:    # и назад, убирая
    right()
    clean()
```

Так уберёшь ряд, даже если стоишь в его середине.

---

## 🎯 Змейка = for + while + флаг

- `for row in range(10)` — по строкам.
- внутри `while` — едем по строке до стены.
- `going_right = not going_right` — меняем направление после строки.
- `if not wall_up: up()` — поднимаемся (кроме последней строки).

---

## 🎯 Убрать только нужные клетки — continue + x, y

```python
if (x + y) % 2 != 0:
    continue        # пропускаем «белые» клетки (шахматка)
clean()
```

`x`, `y` — координаты пылесоса; по ним решаем, убирать клетку или пропустить.

---

## 🎯 Отладка: уменьшай/увеличивай скорость

Пылесос едет слишком быстро/медленно? Поменяй `_STEP_DELAY` вверху файла (например, `0.03` — быстро, `0.3` — медленно), чтобы разглядеть маршрут.

---

## 🐞 Топ-5 ошибок

1. **Посчитал шаги `range(N)`** → «врезался в стену» (комната-то случайная). Едешь до стены — бери `while not сенсор`.
2. **Нет движения в `while`** → вечный цикл.
3. **Забыл переключить флаг** → змейка едет не туда.
4. **Нет `continue`-условия** → убрал лишние клетки.
5. **`for range(фикс)` в комнате неизвестной ширины** → лучше `while` + сенсор.

## 🎓 Для продвинутых

- **Убрать всё оптимально** — змейкой за один проход (задание 11).
- **Ромб/узор** — маршрут «змейкой» по всей комнате + `continue` по формуле (`abs(x-4)+abs(y-4) <= 3`).
- **Внутренние стены** — в задании 13 комнату перегораживает стена. Сенсор `wall_right` одинаково чувствует и край комнаты, и внутреннюю стену, поэтому алгоритм «до стены» из задания 1 работает и там.
- **Свои задания** — придумай свою расстановку мусора и стен и реши её.

## 📖 Что нужно знать за 2 минуты

- Игра — это `while True` с выходом `break` по концу.
- Строка растёт копилкой: `s = ""`, потом `s += кусочек`.
- `in` проверяет вхождение; `str(число)` — для склейки.
- Вложенные циклы + параметр `size` = узор любого размера.

## Проект A — Виселица (по шагам)

### Шаг 1. Слово и переменные
```python
import random
secret = random.choice(["питон", "кодер", "робот"])
guessed = []
mistakes = 0
```

### Шаг 2. Маска слова
```python
mask = ""
for letter in secret:
    if letter in guessed:
        mask += letter
    else:
        mask += "_"
print(mask)
```

### Шаг 3. Игровой цикл
```python
while True:
    # (собрать и показать маску — код из шага 2)
    if "_" not in mask:
        print("Победа!"); break
    if mistakes >= 6:
        print("Проигрыш:", secret); break
    guess = input("Буква: ").lower().strip()
    if guess in secret:
        guessed.append(guess)
    else:
        mistakes += 1
```

✅ Игра = показать → проверить → ход, в цикле с `break`.

## Проект B — Генератор

### Пароль (копилка-строка)
```python
import random
symbols = "abcdefghijklmnopqrstuvwxyz0123456789!@#$"
password = ""
for i in range(int(input("Длина: "))):
    password += random.choice(symbols)
print(password)
```

### Ник (склейка)
```python
adj = ["Быстрый", "Дикий", "Тёмный"]
noun = ["Волк", "Дракон", "Феникс"]
nick = random.choice(adj) + random.choice(noun) + str(random.randint(1, 99))
print(nick)
```

✅ Копим строку `+=` или склеиваем куски `+` (число через `str`).

## Проект C — ASCII-арт

### Ромб
```python
size = int(input("Размер: "))
for row in range(1, size + 1):
    print(" " * (size - row) + "*" * (2 * row - 1))
for row in range(size - 1, 0, -1):
    print(" " * (size - row) + "*" * (2 * row - 1))
```

### Числовой треугольник
```python
for row in range(1, size + 1):
    line = ""
    for col in range(1, row + 1):
        line += str(col)
    print(line)
```

✅ Вложенные циклы строят строки; `size` меняет масштаб.

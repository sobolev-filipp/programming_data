# Лайфхаки урока 6 «Интересные программы» 🧰

> Приёмы для игр, генераторов и узоров.

---

## 🎯 Игровой цикл = три части

```python
while True:
    # 1) показать состояние (маску, поле, счёт)
    # 2) проверить конец → break
    # 3) принять ход игрока
```

Почти любая текстовая игра строится по этой схеме.

---

## 🎯 Строка-копилка

```python
result = ""            # начинаем с пустой
for ...:
    result += кусочек  # добавляем по одному
```

Так собирают пароль, маску слова, строку узора. Заводи копилку **до** цикла.

---

## 🎯 `in` — проверка вхождения

```python
if "а" in word:        # есть ли буква в слове
if guess in guessed:   # называли ли уже эту букву
```

Работает и для строк, и для списков — очень удобно в играх.

---

## 🎯 `str()` при склейке с числом

```python
"Дракон" + str(42)     # "Дракон42"
"Уровень " + str(level)
```

Строку и число напрямую сложить нельзя — сначала `str(число)`.

---

## 🎯 `random.choice` из готовых кусочков

```python
nick = random.choice(adj) + random.choice(noun) + str(random.randint(1, 99))
```

Ники, фразы, реплики — всё собирается из списков случайным выбором.

---

## 🎯 Параметризация узора

```python
size = int(input("Размер: "))
# дальше size управляет и пробелами, и звёздами
" " * (size - row) + "*" * (2*row - 1)
```

Один параметр — узор любого масштаба. Не пиши цифры «руками».

---

## 🎯 Отладка игры — временно раскрой секрет

```python
print("[секрет]", secret)   # видно загаданное слово при проверке
```

Проверил логику — убери отладочный `print`.

---

## 🐞 Топ-5 ошибок

1. **Нет `break`** → игра не заканчивается.
2. **Маску собрал вне цикла** → она не обновляется.
3. **`"a" + 5`** → ошибка; нужно `"a" + str(5)`.
4. **`+=` вне цикла** → пароль/маска пустые.
5. **Цифры в узоре «руками»** → не масштабируется; используй `size`.

---

## 🎓 Для продвинутых

- **Виселица с рисунком** — по числу ошибок печатай стадии «виселицы» (список строк-картинок).
- **Надёжный пароль** — гарантируй хотя бы одну цифру и один спецсимвол (проверка после генерации).
- **Свой ASCII-арт** — ёлка, сердце, буквы; всё через вложенные циклы и условия.
- **Дальше — коллекции (Модуль 4):** данные игр удобно хранить в списках и словарях.

## Главные мысли

1. **Игра = цикл** «показать → проверить конец (`break`) → спросить».
2. **Генератор = строка-копилка**: `s = ""`, в цикле `s += random.choice(...)`.
3. **Узор = вложенные циклы** + параметр `size`.
4. `in` проверяет вхождение: `буква in слове`, `элемент in списке`.
5. При склейке числа со строкой — `str(число)`.

---

## Виселица (ядро)

```python
while True:
    mask = ""
    for letter in secret:
        mask += letter if letter in guessed else "_"
    print(mask)
    if "_" not in mask: print("Победа"); break
    if mistakes >= 6:   print("Проигрыш"); break
    guess = input("Буква: ").lower()
    if guess in secret: guessed.append(guess)
    else: mistakes += 1
```

## ASCII-узор

```python
# ромб
for row in range(1, size + 1):
    print(" " * (size - row) + "*" * (2 * row - 1))
for row in range(size - 1, 0, -1):
    print(" " * (size - row) + "*" * (2 * row - 1))
```

Один `size` — узор любого размера (параметризация).

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| игра не кончается | нет `break` | `if ...: break` |
| маска старая | собрал вне цикла | строить каждый виток |
| `"ник"+42` ошибка | строка + число | `+ str(42)` |
| пароль пустой | `+=` вне цикла | внутри `for` |

---

## Что должно остаться в голове

1. Игра — цикл с `break` на конце.
2. Копилка-строка растёт через `+=`.
3. `random.choice` + `+` собирают ник/пароль.
4. Вложенные циклы + `size` = узор любого масштаба.
5. `str()` при склейке числа со строкой.

# Python + Godot — курс программирования (2 год обучения)

> **135 ак.ч.** · **1 урок = 2 ак.ч. (1,5 часа).** Формат: 2 раза/нед по 1 уроку **или** 1 раз/нед по 2 урока подряд (4 ак.ч.).
> **Возраст:** 5–11 классы, **единый трек** с метками 🧩 «для младших проще» и 🎓 «для старших глубже».
> **Место в программе:** 1 год — компьютерная грамотность и цифровое творчество; **2 год — программирование на Python + основы геймдева в Godot**; 3 год — C# + Unity.

## 🎯 Принципы курса (что обновили относительно прошлой версии)

1. **Плотная теория с механикой «как работает»** — не сухие определения, а «данные → действие → результат» + разбор «почему именно так». Каждая новая конструкция объясняется на пальцах и на схеме.
2. **SVG-схемы в каждом уроке** — визуализируем то, что трудно понять словами: индексы в `for`/срезах, стек вызовов функции, ссылки списков, поток `if/elif/else`, порядок выполнения цикла `while`, сцена-дерево узлов в Godot. Схемы лежат в папке `изображения/` и открываются в браузере.
3. **Много интерактива на уроке** — после каждой новой команды **мини-задание ✍️** на закрепление тут же (1–3 мин, напр. «введи имя и возраст и выведи их»); «предскажи вывод», «найди ошибку», **разбор возможных ошибок** (что Python пишет и почему), живой разбор у проектора, викторина `викторина.html`. У каждого урока — **`итого.md`** (шпаргалка для быстрого повторения).
4. **«Вкусные» практики, а не сухие задачи** — вместе с темой изучаем **настоящие библиотеки** как сквозную линию курса: `random`, **`datetime`/`time`/`calendar`** (дата и время — рано и подробно), `math`, `turtle`, шутки (`pyjokes`), `wikipedia`, погода через API (`requests`), `json`, визуальные (`emoji`, `qrcode`, `matplotlib`), `tkinter`. Делаем приложения, которые хочется показать друзьям (прогноз погоды с графиком, генератор шуток, «сколько дней до дня рождения», калькулятор с окном). **Правило: почти в каждом модуле — минимум одна новая библиотека.**
5. **Turtle-практики со scaffold-кодом** — берём удачные задания из прошлого курса («Умный пылесос», рисование по осям), **чиним под запуск на компьютере** (desktop-turtle, а не онлайн-редактор) и добавляем новые в том же стиле: даём стартовый код + набор команд, ученик пишет алгоритм.
6. **Godot на 2D-играх** — учим движок через понятные проекты (платформер → аркады → змейка → shooter 2D → terraria). **3D-мультиплеер `shooter-3d` исключён** — детям он оказался слишком сложным.
7. **Обязательная практика в каждом уроке — 15–30 задач** (3 уровня 🟢🟡🔴) с **короткими подсказками «как делать» (не решением)** в `практика.md`. Плюс **банк заданий** по темам (`банк-заданий/`) — накопительные задачи: дошли до условий — вот задачи на условия и всё пройденное ранее; добавили циклы — вот на условия+циклы. Уроки уплотнены: каждый честно занимает 1,5 ч и не «слишком лёгкий» (дети не маленькие) — мелкие темы объединены.

# 📌 Порядок работы (для методиста)

1. **Этот план — карта.** Уроки создаём **по одному** в полном формате (папка из 8–9 файлов + `викторина.html`).
2. Начинаем с **Модуля 1** и идём по порядку; Godot-блок — после того как готов Python-блок.
3. SVG-схемы — обязательная часть каждого урока (ключевые: индексы `for`/срезы, стек функций, дерево узлов Godot).
4. Turtle- и Godot-стартовые коды кладём в `материалы/` урока, **проверенные на запуск с компьютера**.
5. Банк заданий пополняем параллельно по мере прохождения тем.

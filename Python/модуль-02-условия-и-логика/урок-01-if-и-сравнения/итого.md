## Главные мысли

1. **`if` — вопрос «да/нет».** Условие `True` → блок выполняется; `False` → пропускается.
2. **Три обязательные детали `if`:** слово `if`, **двоеточие `:`** в конце, **отступ** у тела (4 пробела).
3. **`=` кладёт, `==` сравнивает.** В условии всегда `==` (две равно).
4. **Ответ сравнения — тип `bool`:** только `True` или `False`.

---

## Сравнения (6 штук)

```python
a > b      # больше
a < b      # меньше
a >= b     # больше или равно
a <= b     # меньше или равно
a == b     # РАВНО (две равно!)
a != b     # не равно
```

Ответ — `True` или `False`:
```python
5 > 3      # True
5 == 5     # True
"Гера" == "гера"   # False (регистр важен!)
```

---

## `if` — шаблон

```python
if age >= 18:            # if + условие + ДВОЕТОЧИЕ
    print("Проходи!")    # ОТСТУП = тело (только если True)
print("Дальше...")       # без отступа = выполняется всегда
```

Несколько независимых `if` — каждый решает сам:
```python
if age >= 18:  print("Взрослый")
if age >= 65:  print("Скидка")
if age < 18:   print("Рано")
```

---

## Сравнение строк

```python
if password.lower() == "python":   # .lower() убирает разницу регистра
    print("Верно!")
```

---

## 🎓 Вложенный if

```python
if age >= 18:
    print("Взрослый")
    if age >= 65:            # проверяется только если внешний True
        print("Скидка")      # двойной отступ (8 пробелов)
```

## Главные ошибки

| Сообщение | Причина | Лечение |
|-----------|---------|---------|
| `SyntaxError: expected ':'` | забыл `:` после `if` | поставь `:` |
| `IndentationError: expected an indented block` | нет отступа у тела | отступ 4 пробела |
| `IndentationError: unindent does not match` | разный отступ в блоке | одинаковый у всех строк |
| `SyntaxError` возле `=` | `if age = 18:` (одна равно) | сравнение — `==` |

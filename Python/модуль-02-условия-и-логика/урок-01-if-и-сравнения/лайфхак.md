# Лайфхаки урока 1 «if и сравнения» 🧰

> Трюки, горячие клавиши и типичные ошибки — чтобы `if` давался легко.

---

## ⚡ Горячие клавиши редактора

| Клавиша | Что делает |
|---------|-----------|
| **Enter** после `if ...:` | редактор **сам ставит отступ** — не набирай пробелы вручную |
| **Tab** | добавить отступ (4 пробела) |
| **Shift+Tab** | убрать отступ (выйти из блока) |
| **Backspace** в начале строки | «съедает» сразу 4 пробела отступа |

💡 Никогда не считай пробелы вручную — жми **Enter** и **Tab**, редактор сделает отступ ровным.

---

## 🎯 Трюк: `= `vs `==` — как не путать

- Одна равно `=` — «**положи**» (в коробку): читай как стрелку `age ← 18`.
- Две равно `==` — «**равно ли?**»: читай как вопрос «age равен 18?».

Правило: **внутри `if` почти всегда `==`.** Если написал одну равно в условии — Python подскажет `SyntaxError`.

---

## 🎯 Трюк: сравнение без мучений с регистром

Пользователь введёт `Да`, `да`, `ДА` — а ты ждёшь `"да"`. Приведи ввод к одному регистру:

```python
answer = input("Продолжить? ").lower()   # сразу .lower()
if answer == "да":
    print("Поехали!")
```

Теперь подойдут любые варианты регистра.

---

## 🎯 Трюк: убрать лишние пробелы у ввода

Пользователь случайно нажал пробел — `" да "`. Спасает `.strip()`:

```python
answer = input("Ответ: ").strip().lower()   # убрали пробелы И регистр
```

## 🐞 Топ-5 ошибок новичка (и лечение)

1. **Забыл `:`** → `SyntaxError: expected ':'`. Двоеточие в конце строки `if`.
2. **Нет отступа** → `IndentationError`. После `:` — Enter, тело с отступом.
3. **`=` вместо `==`** в условии → `SyntaxError`. Сравнение — две равно.
4. **Смешал отступы** (где 2 пробела, где 4) → `IndentationError`. Не мешай Tab и пробелы — выбери Tab везде.
5. **Сравнил строку с числом:** `if age == "18":` при `age = int(...)` — всегда `False`. Сравнивай число с числом (`== 18`), строку со строкой (`== "18"`).

---

## 💡 Мини-хитрость: «предскажи ветку»

Перед запуском **вслух скажи**, какой `if` сработает при твоём вводе. Совпало с выводом — понял тему. Не совпало — нашёл, где заблуждался. Это лучший способ проверить себя.

---

## 🎓 Для продвинутых

- **Цепочка сравнений** (только в Python!): `if 0 < age < 18:` — «age между 0 и 18». Читается как в математике.
- **`bool` — это числа:** `True` равен `1`, `False` равен `0`. Проверь: `print(True + True)` → `2`. Пригодится, когда будем считать очки в викторине (Урок 4).

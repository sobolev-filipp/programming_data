## 1. Блиц-вопросы (устно)

1. Что возвращает `input()` — число или строку? *(всегда строку)*
2. Как превратить ответ `input()` в целое число? *(`int(input(...))`)*
3. Что напечатает `print(f"Мне {2 + 3} года")`? *(`Мне 5 года`)*
4. Чем `42` отличается от `"42"`? *(число и строка — разные типы)*
5. Какой тип у `3.14`? А у `"да"`? *(`float`; `str`)*

---

## 2. Предскажи вывод

```python
a = 10
b = 3
print(a + b)
print(a * b)
print(a / b)
print(a // b)
print(a % b)
```

<details><summary>Ответ</summary>

`13`, `30`, `3.3333333333333335`, `3`, `1`
</details>

---

## 3. Найди ошибку

```python
age = input("Возраст: ")
print(age + 10)
```

<details><summary>Ответ</summary>

`input()` даёт строку → `str + int` → `TypeError`. Чинить: `age = int(input("Возраст: "))`.
</details>

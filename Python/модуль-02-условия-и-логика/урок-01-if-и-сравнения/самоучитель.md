## 📖 Что нужно знать за 2 минуты

**Сравнение** — вопрос к Python, ответ — `True` (да) или `False` (нет):
`>` больше · `<` меньше · `>=` больше-или-равно · `<=` меньше-или-равно · `==` **равно** (две равно!) · `!=` не равно.

**`if`** выполняет блок, только если условие `True`:
```python
if age >= 18:          # if + условие + ДВОЕТОЧИЕ
    print("Проходи")   # ОТСТУП = тело
```
Три обязательные вещи: слово `if`, `:` в конце, **отступ** у тела.

### Задание 1. Первое сравнение
**Тема:** сравнение возвращает `True`/`False`.
**Задача:** выведи ответ на вопрос «5 больше 2?».

**Разбор по шагам:**
1. Сравнение «5 больше 2» пишется `5 > 2`.
2. Чтобы увидеть ответ — оберни в `print`.
```python
print(5 > 2)
```
3. Запусти. Увидишь `True`. Python ответил «да».

✅ Готово. Поменяй на `5 < 2` — получишь `False`.

### Задание 2. Первый `if`
**Тема:** `if` выполняет блок при `True`.
**Задача:** если переменной `age` присвоено 20, вывести `Взрослый`.

**Разбор по шагам:**
1. Заведём переменную: `age = 20`.
2. Пишем условие со словом `if`, сравнением и **двоеточием**:
   `if age >= 18:`
3. Нажимаем **Enter** — редактор сам сделает отступ. Пишем тело:
   `print("Взрослый")`
```python
age = 20
if age >= 18:
    print("Взрослый")
```
4. Запусти → `Взрослый`. Теперь поменяй `age = 10` и запусти: **ничего** не выведется (условие ложно).

✅ Ты сделал первую программу, которая выбирает.

### Задание 3. Спрашиваем у пользователя
**Тема:** `if` + `input` + `int()`.
**Задача:** спросить возраст и, если `>= 18`, вывести `Проходи`.

**Разбор по шагам:**
1. Спросим возраст. Помним из Модуля 1: `input()` даёт строку, для сравнения как число нужен `int()`:
   `age = int(input("Возраст: "))`
2. Условие:
   `if age >= 18:`
3. Тело с отступом:
   `print("Проходи")`
```python
age = int(input("Возраст: "))
if age >= 18:
    print("Проходи")
```
4. Запусти дважды — введи 25 (выведет `Проходи`) и 12 (тишина).

✅ Разобрался, зачем `int()`: без него сравнивалась бы строка.

### Задание 4. Две ветки
**Тема:** два независимых `if`.
**Задача:** сказать `Взрослый` или `Ребёнок` в зависимости от возраста.

**Разбор по шагам:**
1. Спросим возраст: `age = int(input("Возраст: "))`.
2. Первый `if` — для взрослых:
   `if age >= 18:` → `print("Взрослый")`
3. Второй `if` — для детей, условие **противоположное**:
   `if age < 18:` → `print("Ребёнок")`
```python
age = int(input("Возраст: "))
if age >= 18:
    print("Взрослый")
if age < 18:
    print("Ребёнок")
```
4. Проверь на 40 и 10. Всегда срабатывает **ровно один** `if` — условия не пересекаются.

✅ Заметь: писать два условия неудобно. В Уроке 2 их заменит `else` — одна строка вместо второго `if`.

### Задание 5. Сравнение строк и пароль
**Тема:** `==` со строками, регистр, `.lower()`.
**Задача:** спросить пароль; если он `"питон"` (в любом регистре) — `Доступ открыт`.

**Разбор по шагам:**
1. Спросим и **сразу приведём к строчным** буквам, чтобы регистр не мешал:
   `password = input("Пароль: ").lower()`
2. Сравним со строкой через `==`:
   `if password == "питон":`
3. Тело:
   `print("Доступ открыт")`
```python
password = input("Пароль: ").lower()
if password == "питон":
    print("Доступ открыт")
```
4. Введи `Питон`, `ПИТОН`, `питон` — все подойдут, потому что `.lower()` превратил их в `питон`.

✅ Понял, почему регистр важен и как его «выключить».

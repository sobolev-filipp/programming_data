# Что показать на проекторе — урок 1 «if и сравнения» 🖼

> Три SVG-схемы. Открываются в браузере (перетащи файл или `Ctrl+O`). Показывай в момент, указанный в [преподавателю.md](преподавателю.md).

---

## 1. `изображения/операторы-сравнения.svg` ⚖️
**Когда:** Часть 1 (сравнения), 5–17 мин.

Шесть карточек-операторов (`> < >= <= == !=`) с примером и ответом `True`/`False`, плюс большой жёлтый блок-предупреждение **`=` vs `==`**.

**Как обсудить:**
- Пройдись по карточкам: «5 больше 3? — да, `True`». Пусть класс отвечает **до** того, как покажешь ответ.
- Задержись на жёлтом блоке: `=` кладёт, `==` сравнивает. Это ошибка №1 всего курса — проговори дважды.
- Вывод внизу: ответ любого сравнения — тип `bool`, только `True`/`False`.

---

## 2. `изображения/блок-схема-if.svg` 🔀
**Когда:** Часть 2 (первый `if`), 17–32 мин.

Слева — код `if age >= 18:`, справа — блок-схема: ромб-условие → ветка **Да ✅** (тело выполняется) и **Нет ❌** (тело пропускается) → «программа идёт дальше».

**Как обсудить:**
- «`if` — это развилка на дороге. Условие верно → идём по зелёной ветке (выполняем блок). Неверно → по красной (пропускаем)».
- Свяжи с кодом: отступ у `print` = «это тело if», то, что стоит на зелёной ветке.
- Покажи в редакторе: поменяй `age` с 20 на 15 — ветка меняется, вывод пропадает.

---

## 3. `изображения/отступ-и-вложенность.svg` ↹
**Когда:** Часть 3 (несколько `if`, отступ) и Часть 6 (🎓 вложенность), 32–44 мин.

Слева — обычный `if`: подсвечено тело (с отступом) и строка без отступа («выполнится всегда»). Справа 🎓 — вложенный `if` с двойным отступом. Внизу красный блок с двумя ошибками отступа.

**Как обсудить:**
- Левая часть: «зелёное с отступом — только если условие True; белое без отступа — всегда». Это ключевая идея.
- Красный блок — прочитай вслух обе ошибки (`SyntaxError` без `:`, `IndentationError` без отступа). Тут же **сломай код нарочно** и покажи эти сообщения в реальной консоли.
- Правая часть (🎓) — только для старших: `if` внутри `if`, двойной отступ.

## 💡 Общие советы по показу
- Схемы — светлые, читаются с последней парты; при необходимости увеличь масштаб браузера `Ctrl` + `+`.
- Каждую схему полезно показать **до** кода (гипотеза) и **вернуться** к ней после запуска (проверка).
- Схемы можно раздать как памятку — они самодостаточны.

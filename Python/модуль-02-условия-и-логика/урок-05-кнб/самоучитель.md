## 📖 Что нужно знать за 2 минуты

Игра = список фигур + случайный ход компьютера + сравнение + лестница победителя.
```python
import random
options = ["камень", "ножницы", "бумага"]   # 🆕 список: индексы 0,1,2
comp = random.choice(options)               # случайный элемент списка
player = input("Выбор: ").lower().strip()

if player not in options:                   # 🆕 проверка ввода одной строкой
    print("Не понял выбор")
elif player == comp:
    print("Ничья")
elif player == "камень" and comp == "ножницы":
    print("Ты выиграл")
# ... ещё 2 победы игрока ...
else:
    print("Компьютер выиграл")   # умный else
```
Порядок: **защита → ничья → победы игрока → else**. По обе стороны `and` — полные сравнения.
🆕 **Списки:** `options[0]` — первый (счёт с 0), `len(options)` — сколько элементов, `x in options` — есть ли внутри. Перебор — Модуль 3, глубже — Модуль 4.

### Задание 3. Ничья
**Тема:** первое условие.
**Задача:** если фигуры равны — «Ничья».

**Разбор по шагам:**
1. Сравним игрока и компьютер:

```python
comp = random.choice(["камень", "ножницы", "бумага"])
if player == comp:
    print("Ничья!")

    print("Фигуры разные — играем дальше")
```
2. Ничью проверяем **первой** — это упростит остальное.

### Задание 5. Полная лестница победителя
**Тема:** ничья → 3 победы → else.
**Задача:** определить исход в любом случае.

**Разбор по шагам:**
1. Ничья первой веткой.
2. Три победы игрока через `elif ... and ...`.
3. Всё остальное — `else` (победа компьютера).
```python
if player == comp:
    print("Ничья!")
elif player == "камень" and comp == "ножницы":
    print("Ты выиграл!")
elif player == "ножницы" and comp == "бумага":
    print("Ты выиграл!")
elif player == "бумага" and comp == "камень":
    print("Ты выиграл!")
else:
    print("Компьютер выиграл!")
```
4. `else` накрывает три победы компьютера сразу — не пиши их отдельно.

✅ Готовая игра! Проверь три исхода (зафиксируй `comp` для отладки).

## Главные мысли

1. **Сложное правило = простые условия по порядку.** Сначала ничья, потом победы игрока, потом `else`.
2. **«Умный `else`»:** если ничью и победы игрока уже отсекли, в `else` остаётся ровно победа компьютера.
3. **Порядок веток решает всё** (как в Уроке 2): ничью — вверх.
4. **По обе стороны `and` — полные сравнения** (`comp == "ножницы"`, не просто `"ножницы"`).

---

## Правила (что кого бьёт)

```
камень  бьёт  ножницы
ножницы бьёт  бумагу
бумага  бьёт  камень
одинаковые    → ничья
```

## Ход компьютера + игрока

```python
import random
comp = random.choice(["камень", "ножницы", "бумага"])
player = input("Твой выбор: ").lower().strip()
```

---

## Логика победителя

```python
if player == comp:
    print("Ничья!")
elif player == "камень" and comp == "ножницы":
    print("Ты выиграл!")
elif player == "ножницы" and comp == "бумага":
    print("Ты выиграл!")
elif player == "бумага" and comp == "камень":
    print("Ты выиграл!")
else:
    print("Компьютер выиграл!")   # умный else
```

Короче — три победы через `or` (скобки обязательны):
```python
elif (player=="камень" and comp=="ножницы") or (player=="ножницы" and comp=="бумага") or (player=="бумага" and comp=="камень"):
    print("Ты выиграл!")
```

## Счёт серии (копилки из Урока 4)

```python
wins = 0; losses = 0
# в ветке победы игрока:  wins += 1
# в ветке победы компа:   losses += 1
if wins > losses: print("Чемпион - ты!")
elif losses > wins: print("Победил компьютер")
else: print("Ничья по серии")
```

---

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| неверный победитель | ничья не первой веткой | ничья → вверх |
| `and "ножницы"` | справа не сравнение | `and comp == "ножницы"` |
| `NameError: wins` | нет `wins = 0` | заведи копилки до раундов |
| ввод не распознан | регистр/пробел | `.lower().strip()` |

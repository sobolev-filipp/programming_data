## 3. Найди ошибку

```python
if player == "камень" and "ножницы":
    print("Победа")
```

<details><summary>В чём ошибка?</summary>

Справа от `and` стоит просто строка `"ножницы"` (всегда «истинна»), а не сравнение. Нужно `and comp == "ножницы"` (правило Урока 3).
</details>

## 4. Мостик к теме

## 🎯 «Умный else» — не расписывай лишнее

Из 9 случаев КНБ:
- 3 — ничья (отсекаем одной веткой `player == comp`),
- 3 — победа игрока (три `elif ... and ...`),
- 3 — победа компьютера → всё, что **осталось** → один `else`.

Не пиши три победы компьютера отдельно — их накрывает `else`. Меньше кода, меньше ошибок.

Ничью проверяй **первой** (после защиты ввода). Если она окажется ниже побед игрока — часть ничьих «утечёт» не туда. Правило Урока 2 работает и здесь.

## 🎯 Полное сравнение по обе стороны and

```python
# ❌ так НЕ работает
elif player == "камень" and "ножницы":
# ✅ правильно
elif player == "камень" and comp == "ножницы":
```
Закрой пальцем левую часть `and` — правая должна быть законченным сравнением.

---

## 🎯 Три победы в одну ветку через or

```python
elif (player=="камень" and comp=="ножницы") \
  or (player=="ножницы" and comp=="бумага") \
  or (player=="бумага" and comp=="камень"):
    print("Ты выиграл!")
```
Скобки обязательны: `and` сильнее `or` (приоритет из Урока 3). Так короче, но менее наглядно — выбирай по вкусу.

## 🎯 Отладка случайной игры

Чтобы проверить конкретный исход, временно **зафиксируй** ход компьютера:
```python
comp = "ножницы"   # вместо random.choice(...) на время отладки
```
Проверил ничью/победу/поражение — верни `random.choice(...)`.

---

## 🎯 Защита ввода — через список и `not in`

Игрок может опечататься. Первой веткой лови «не фигуру» — коротко, через список:
```python
options = ["камень", "ножницы", "бумага"]
if player not in options:
    print("Не понял выбор.")
```
Это заменяет длинное `player != "камень" and player != "ножницы" and player != "бумага"` одной строкой. Чем длиннее список допустимых значений — тем сильнее выигрыш.

## 🆕 🎯 Списки — мини-памятка

```python
options = ["камень", "ножницы", "бумага"]
options[0]           # первый элемент (счёт с НУЛЯ!)
options[-1]          # последний ("бумага") — минус считает с конца
len(options)         # 3
"камень" in options  # True — быстрый поиск
random.choice(options)  # случайный элемент
```
Пока — только это. Перебрать список циклом — Модуль 3 (`for`); добавлять/удалять/сортировать — Модуль 4.

## 🐞 Топ-5 ошибок

1. **Ничья не первой** → неверный победитель. Ничью — вверх.
2. **`and "ножницы"`** без сравнения → всегда True. Пиши `and comp == "ножницы"`.
3. **Забыл `.lower()`** → «Камень» не распознан.
4. **`wins += 1` без `wins = 0`** → `NameError`. Заведи копилки.
5. **Эмодзи в `print`** → крах на Windows. Фигуры — словами.

## 🎓 Для продвинутых

- **Серия до N побед / много раундов** — это про **цикл** (`while`/`for`, Модуль 3). Пока раунды пишем подряд (см. `кнб_три_раунда.py`) — и видно, зачем нужен цикл.
- **Ничьи в статистику:** третья копилка `draws += 1`.
- **«Ящерица и Спок»:** 5 фигур, 10 победных пар — та же логика, больше веток (или таблица победителей — уже со списками, Модуль 4).
- **Стратегия бота:** позже (со списками и подсчётом) можно сделать, чтобы компьютер «подмечал» твой любимый ход.

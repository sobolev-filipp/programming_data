# Что показать на проекторе — урок 4 «Викторина + pyjokes» 🖼

> Три SVG-схемы. Открываются в браузере (`Ctrl+O` или перетащи файл). Показывай в момент из [преподавателю.md](преподавателю.md).

---

## 1. `изображения/счётчик-очков.svg` 🔢
**Когда:** Часть 1 (копилка), 5–17 мин.

Слева `score = 0`, дальше по шагам: верный ответ → `+1`, неверный → без изменений; справа большой итог `score = 2` и процент. Внизу — короткая запись `+=`.

**Как обсудить:**
- «Копилка: заводим в 0, добавляем по 1 за правильный ответ».
- Покажи, что при неверном ответе счёт **не меняется**.
- Внизу: `score += 1` = `score = score + 1`; заодно `-=`, `*=` (жизни, монеты).

---

## 2. `изображения/поток-викторины.svg` 🎯
**Когда:** Часть 2 (вопрос + счёт), 17–31 мин.

Схема одного вопроса: `score = 0` → `input` → ромб «ответ верный?» → **Да** («Верно!», `score += 1`) / **Нет** (правильный ответ). Пунктиром — «повторяем для каждого вопроса», внизу итог + награда.

**Как обсудить:**
- Каждый вопрос устроен **одинаково**: спросили → сравнили → начислили или нет.
- Очко — на ветке «Да» (внутри `if`).
- Заметка сбоку: вопросы пишем подряд, потому что цикла ещё нет (Модуль 3) — хороший мостик вперёд.

---

## 3. `изображения/pip-и-библиотеки.svg` 📦
**Когда:** Часть 3 (`pip install`), 31–45 мин.

Слева — встроенные библиотеки (`random`, `datetime`, `math`, ✅ просто import), справа — внешние (`pyjokes`, `requests`, 🌐 надо поставить). Внизу поток: `pip install pyjokes` (терминал) → склад PyPI → `import` в коде.

**Как обсудить:**
- Две породы библиотек: встроенные (уже есть) и внешние (ставим через `pip`).
- **`pip install` — в терминале, `import` — в коде** (разные места!).
- Тут же **вживую** поставь `pyjokes` в терминале проектора и покажи шутку.
- Внизу: забыл поставить → `ModuleNotFoundError` (та же ошибка, что в Модуле 1 без импорта).

## 💡 Общие советы
- Схемы светлые, читаются с задних парт; масштаб `Ctrl` + `+`.
- `pip-и-библиотеки.svg` держи рядом с реальным терминалом — сравнение «схема ↔ настоящая установка» очень заходит.
- Приём «предскажи счёт»: перед запуском спроси класс, сколько очков наберётся при таких-то ответах.

## 🎯 Копилка: заведи, потом меняй

Любой счётчик — это два шага:
```python
score = 0        # 1) завести ДО использования
score += 1       # 2) менять по ходу
```
Если сразу `score += 1` без `score = 0` — `NameError`. Правило: **сначала создай, потом прибавляй.**

---

## 🎯 `+=` и его родня

```python
score += 1     # score = score + 1   (прибавить)
lives -= 1     # отнять
coins *= 2     # умножить
```
Читается вслух: «прибавь к score единицу». Экономит писанину и меньше опечаток.

---

## 🎯 Очко — ВНУТРИ `if`

Самая частая ошибка счёта — начислить очко не в той ветке:
```python
if answer == "париж":
    print("Верно!")
    score += 1        # ✅ с отступом — внутри if
score += 1            # ❌ без отступа — прибавится ВСЕГДА, даже при ошибке
```
Проверка: ответь неправильно — если очки всё равно растут, `score += 1` вылез из `if`.

---

## 🎯 Приводи ответ пользователя

Пользователь введёт `Париж`, ` париж `, `ПАРИЖ`. Приведи сразу:
```python
answer = input("Столица? ").lower().strip()
```
`.lower()` — регистр, `.strip()` — лишние пробелы. Теперь сравнение честное.

---

## 🎯 Несколько верных ответов — `or`

```python
if answer == "голубое" or answer == "синее":
    score += 1
```
Помни: по обе стороны `or` — полные сравнения (`answer == "синее"`, не просто `"синее"`).

## 📦 Внешние библиотеки и `pip`

- **Ставим один раз** в терминале: `pip install pyjokes`. Потом `import` работает везде.
- **Не срабатывает `pip`?** Попробуй `python -m pip install pyjokes`.
- **`ModuleNotFoundError`** — почти всегда «забыл поставить». Поставь и запусти снова.
- **Терминал ≠ код:** `pip install ...` пишут **в терминале** (вкладка Terminal), а не в `.py`-файле.
- **Нет интернета/не ставится?** Возьми [`материалы/викторина_без_pip.py`](материалы/викторина_без_pip.py) — там шутки из `random.choice`, установка не нужна.

## 🐞 Топ-5 ошибок

1. **`score += 1` без `score = 0`** → `NameError`. Заведи копилку выше.
2. **`score += 1` без отступа** → очки растут всегда. Внутрь `if`.
3. **Забыл `pip install`** → `ModuleNotFoundError`. Поставь библиотеку.
4. **Забыл `.lower()`** → правильный ответ не засчитан из-за регистра.
5. **`import pyjokes` в терминале / `pip` в коде** — перепутал места. `pip` — терминал, `import` — код.

## 🎓 Для продвинутых

- **Категории шуток:** `pyjokes.get_joke(language="en", category="neutral")`.
- **Целый процент через `//`:** `score * 100 // 5` — без дробей, без `:.0f`.
- **Много вопросов = много копипасты.** Это сигнал: пора **цикл** (Модуль 3) — тогда викторина ужмётся в несколько строк, а вопросы будут в списке.
- **`True == 1`:** можно даже считать очки суммой булевых (`score = (a=="париж") + (b=="56")`), но читаемее — через `if`.

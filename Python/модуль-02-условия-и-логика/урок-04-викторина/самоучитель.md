score = 0

if answer.lower().strip() == "париж":

## Часть A — задания с пошаговым разбором

### Задание 1. Первая копилка
**Тема:** переменная растёт.
**Задача:** прибавить 1 три раза и вывести.

**Разбор по шагам:**
1. Заведём копилку: `score = 0`.
2. Прибавим три раза:
```python
score = 0
score += 1
score += 1
score += 1
print(score)     # 3
```
3. `+=` — короткая запись `score = score + 1`.

✅ Копилка растёт по 1.

---

### Задание 2. Родня `+=`
**Тема:** `-=`, `*=`.
**Задача:** монеты и жизни.

**Разбор по шагам:**
1. `coins = 10`, добавим 5: `coins += 5` → 15.
2. `lives = 3`, отнимем 1: `lives -= 1` → 2.
```python
coins = 10
coins += 5
lives = 3
lives -= 1
print(coins, lives)   # 15 2
```

✅ `+=`, `-=`, `*=` меняют переменную.

---

### Задание 3. Один вопрос со счётом
**Тема:** `if/else` + очко.
**Задача:** спросить столицу Франции, засчитать верный ответ.

**Разбор по шагам:**
1. Заведём счёт: `score = 0`.
2. Спросим и приведём ввод: `answer = input("Столица Франции? ").lower().strip()`.
3. Проверим и начислим **внутри** `if`:
```python
score = 0
answer = input("Столица Франции? ").lower().strip()
if answer == "париж":
    print("Верно!")
    score += 1
else:
    print("Неверно. Правильно: Париж.")
print(f"Очков: {score}")
```
4. Ответь неправильно — очко **не** прибавится.

✅ Очко начисляется внутри ветки `if`.

### Задание 5. Процент результата
**Тема:** подсчёт процента.
**Задача:** из счёта сделать процент.

**Разбор по шагам:**
1. Пусть `score = 2` из 3 вопросов.
2. Процент: `percent = score / 3 * 100`.
3. Выведем без дробей (`:.0f`):
```python
score = 2
percent = score / 3 * 100
print(f"{score} из 3 ({percent:.0f}%)")   # 2 из 3 (67%)
```

✅ Процент = очки делить на количество, умножить на 100.

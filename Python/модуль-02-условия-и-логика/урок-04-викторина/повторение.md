## 1. Блиц-вопросы (устно)

1. Что вернёт `if/else` — сколько веток сработает? *(ровно одна)*

3. Как сравнить строку без учёта регистра? *(`.lower()`)*
4. Что делает `import`? *(подключает библиотеку)*
5. Знак `=` — это «равно» или «положи»? *(положи в переменную)*

## 2. Предскажи вывод

```python
x = 0
x = x + 1
x = x + 1
x = x + 1
print(x)
```

<details><summary>Ответ</summary>

`3`. Каждая строка берёт старое `x` и прибавляет 1. Сегодня узнаем короткую запись `x += 1`.
</details>

---

## 3. Найди ошибку

```python
answer = input("Столица? ")
if answer == "париж":
    print("Верно")
```

<details><summary>Почему «Париж» не засчитывается?</summary>

Пользователь введёт `Париж` с большой буквы, а сравнение с `"париж"` строгое. Нужно `answer.lower()`.
</details>

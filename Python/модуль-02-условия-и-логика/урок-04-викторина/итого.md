## Главные мысли

1. **Счётчик-копилка:** заведи в `0`, прибавляй по ходу — `score += 1`.
2. **`+=` = сокращение** для `score = score + 1`. Есть `-=`, `*=`.
3. **Библиотеки бывают встроенные** (`random`, `datetime` — просто `import`) **и внешние** (`pyjokes` — сначала `pip install`).
4. **Начисляй очко ВНУТРИ ветки `if`** (с отступом), копилку заводи выше.

---

## Счётчик (копилка)

```python
score = 0          # завести до использования
score += 1         # +1  (то же, что score = score + 1)
lives -= 1         # -1
coins *= 2         # удвоить
```

---

## Один вопрос викторины

```python
answer = input("Столица Франции? ").lower().strip()
if answer == "париж":
    print("Верно!")
    score += 1          # очко — ВНУТРИ if
else:
    print("Неверно. Правильно: Париж.")
```

Несколько верных вариантов — через `or`:
```python
if answer == "голубое" or answer == "синее":
    score += 1
```

## Процент

```python
percent = score / 5 * 100
print(f"{score} из 5 ({percent:.0f}%)")   # :.0f — без дробей
```

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| `ModuleNotFoundError: 'pyjokes'` | забыл `pip install` | поставь через `pip` |
| `NameError: 'score'` | нет `score = 0` выше | заведи копилку до `+=` |
| очки не растут | `score += 1` без отступа (вне if) | начисляй внутри `if` |
| ответ не засчитан | регистр/пробел | `input(...).lower().strip()` |

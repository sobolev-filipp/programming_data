## Главные мысли

1. **`if/elif/else` — лестница.** Python идёт сверху вниз и берёт **первое** верное условие, остальные пропускает.
2. **Срабатывает ровно ОДНА ветка** (в отличие от нескольких независимых `if`).
3. **`else`** — «а иначе», без условия. **`elif`** — «а иначе если», с условием.
4. **Порядок веток решает всё:** для `>=` — от большего к меньшему; защита ввода — наверх.

---

## Шаблоны

```python
# if / else — две ветки
if age >= 18:
    print("Взрослый")
else:
    print("Ребёнок")

# лестница if / elif / else
if ball >= 90:
    print("5")
elif ball >= 75:
    print("4")
elif ball >= 60:
    print("3")
else:
    print("2")
```

---

## Порядок для диапазонов

```python
# ✅ от БОЛЬШЕГО к меньшему
if ball >= 90: ...
elif ball >= 75: ...
elif ball >= 60: ...

# ❌ наоборот — балл 95 поймает первый же >= 60 → «тройка»
```

Правило: **частное условие — выше, общее — ниже.**

## elif со строками + защита

```python
color = input("Свет? ").lower().strip()
if color == "красный":
    print("Стой")
elif color == "зелёный":
    print("Иди")
else:
    print("Не цвет светофора")   # else ловит всё лишнее
```

Защита ввода — первыми ветками:
```python
if ball > 100:
    print("Слишком много")
elif ball < 0:
    print("Слишком мало")
elif ...
```

---

## if vs elif — в чём разница

| Несколько `if` | Лестница `if/elif` |
|----------------|--------------------|
| проверяется каждый | до первого True |
| могут сработать несколько | ровно одна ветка |
| независимые проверки | альтернативы |

---

## Главные ошибки

| Сообщение / симптом | Причина | Лечение |
|---------------------|---------|---------|
| `SyntaxError` на `else if` | нужно слитно | пиши `elif` |
| `SyntaxError` на `else x:` | у `else` есть условие | условие → в `elif` |
| ответ неверный, но не падает | плохой **порядок** веток | частное выше общего, проверь границы |
| `IndentationError` | сбит отступ | `if/elif/else` без отступа, тела — с отступом |

---

## Что должно остаться в голове

1. Лестница берёт **первое** верное условие и останавливается.
2. `else` — без условия, `elif` — с условием.
3. Срабатывает ровно одна ветка.
4. Для `>=` иду от большего к меньшему; защиту ввода ставлю первой.
5. 🎓 Точный диапазон — цепочка `75 <= ball < 90`.

# Лайфхаки урока 2 «else / elif» 🧰

> Трюки, приёмы и типичные ошибки — чтобы лестница веток получалась с первого раза.

---

## 🎯 Главный приём: «от большего к меньшему»

Когда ветки с `>=`, всегда выстраивай пороги **по убыванию**:

```python
if score >= 90: ...     # сначала самый строгий
elif score >= 75: ...
elif score >= 60: ...
else: ...               # всё остальное
```

Проверить себя: возьми большое значение (95). Если оно попадает в **верхнюю** ветку — порядок верный.

---

## 🎯 Тест границами

`elif` легко ошибиться на 1. Прогони **пограничные** числа:

- порог 90 → проверь `89` и `90` (должны попасть в **разные** ветки);
- порог 60 → проверь `59` и `60`.

Если `90` даёт «4» вместо «5» — у тебя `> 90` вместо `>= 90`. Классика.

---

## 🎯 `else` — всегда последняя страховка

Добавляй `else` в конце, даже если «все случаи учтены». Он поймает то, о чём ты не подумал: опечатку, пустой ввод, отрицательное число.

```python
else:
    print("Не понял ответ, попробуй ещё раз.")
```

---

## 🎯 Защита ввода — вверху лестницы

Сначала отсекай «мусор», потом считай:

```python
if age < 0:
    print("Возраст не бывает отрицательным")
elif age > 120:
    print("Столько не живут :)")
elif age >= 18:
    print("Взрослый")
else:
    print("Ребёнок")
```

---

## 🐞 Топ-5 ошибок (и лечение)

1. **`else if` вместо `elif`** → `SyntaxError`. В Python слитно: `elif`.
2. **Условие у `else`** (`else x > 5:`) → `SyntaxError`. У `else` условия нет.
3. **Неверный порядок веток** → программа **не падает**, но ответ неверный. Частное — выше.
4. **`> ` вместо `>=`** на границе → значение-граница уходит не в ту ветку. Реши заранее, куда относится ровно 90.
5. **Лишний `if` вместо `elif`** → сработает несколько веток. Если варианты — альтернативы, соединяй их в **одну** лестницу через `elif`.

---

## 💡 Приём «предскажи ветку»

Перед запуском ткни пальцем: «при вводе 82 сработает **вот эта** строка». Запусти — проверь. Совпало — понял лестницу.

---

## ⚡ Горячая клавиша

- Выделить несколько строк + **Tab / Shift+Tab** — сдвинуть отступ целого блока сразу (удобно, когда оборачиваешь код в `if/else`).

---

## 🎓 Для продвинутых

- **Точный диапазон:** `elif 75 <= ball < 90:` — читается как в математике, порядок веток тогда не критичен (но код длиннее).
- **`elif` вместо вложенного `if`:** длинную вложенность из Урока 1 часто можно «распрямить» в плоскую лестницу `elif` — читать легче.
- **Match (Python 3.10+):** для выбора по значению есть `match/case` — но это позже; пока лестница `elif` универсальна.

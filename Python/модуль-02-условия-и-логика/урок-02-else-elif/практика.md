## 🟢 Уровень 1 — базовые (`if/else`, простой `elif`)

**1.1 — Чёт/нечет.** Спроси число. Если чётное — `Чётное`, иначе — `Нечётное` (через `else`).
> 💡 `if n % 2 == 0:` … `else:`.

**1.2 — Проходной балл.** Спроси балл. `>= 60` → `Сдал`, иначе → `Не сдал`.
> 💡 `if/else`, одна граница.

**1.3 — Совершеннолетие.** Спроси возраст. `>= 18` → `Взрослый`, иначе → `Ребёнок`.
> 💡 `if/else`.

**1.4 — Знак числа.** Спроси число. `> 0` → `Плюс`, `< 0` → `Минус`, иначе → `Ноль`.
> 💡 `if / elif / else` — три ветки.

**1.5 — Оценка (3 варианта).** Спроси балл. `>= 90` → `5`, `>= 70` → `4`, иначе → `3`.
> 💡 От большего к меньшему: `if` `elif` `else`.

**1.6 — День или ночь.** Спроси час (0–23). `>= 6` и `< 22` пока сделай так: `>= 22` → `Ночь`, `>= 6` → `День`, `else` → `Ночь`. (Порядок!)
> 💡 Подумай, куда попадёт 23 и куда 3. Проверь границы.

**1.7 — Светофор.** Спроси цвет (строкой). Три ветки + `else` «не цвет светофора».
> 💡 `.lower()`, три `==`, `else`.

**1.8 — Пропуск на фильм.** Спроси возраст. `>= 18` → `Любой фильм`, `>= 12` → `С родителями`, иначе → `Только детские`.
> 💡 От большего к меньшему.

## 🟡 Уровень 2 — средние (диапазоны, порядок, строки)

**2.1 — Оценка 2–5.** Полная лестница: `>= 90`→5, `>= 75`→4, `>= 60`→3, else→2.
> 💡 Ровно как в уроке. Проверь 90, 89, 60, 59.

**2.2 — Уровень воды.** Спроси уровень (см). `>= 100` → `Опасно`, `>= 50` → `Норма`, иначе → `Мало`.
> 💡 Порог по убыванию.

**2.3 — Размер одежды.** Спроси рост. `< 160` → `S`, `< 175` → `M`, `< 190` → `L`, иначе → `XL`.
> 💡 Здесь `<` — значит порядок **от меньшего к большему** (наоборот, чем с `>=`!). Подумай почему.

**2.4 — Категория ИМТ (упрощённо).** Спроси условный индекс. `< 18` → `Мало`, `< 25` → `Норма`, `< 30` → `Много`, иначе → `Очень много`.
> 💡 С `<` идём по возрастанию порогов.

**2.5 — Оценка буквой.** Спроси балл, выведи `A/B/C/D/F` по диапазонам (90/80/70/60).
> 💡 5 веток, от большего.

**2.6 — Времена года.** Спроси номер месяца (1–12). Выведи сезон. Защити ввод (`> 12` / `< 1`).
> 💡 12/1/2 → зима и т.д. Можно `elif month <= 2:`… думай о порядке; защита — сверху.

**2.7 — Меню игры.** Спроси пункт (1/2/3). `1` → `Играть`, `2` → `Настройки`, `3` → `Выход`, else → `Нет пункта`.
> 💡 `==` по числам + `else`.

**2.8 — Оружие и урон.** Спроси `меч/лук/магия`, выведи урон 10/7/12, else → `Нет оружия`.
> 💡 Строки, `.lower()`, `else`.

**2.9 — Скидка по сумме.** Спроси сумму покупки. `>= 5000` → `20%`, `>= 2000` → `10%`, `>= 1000` → `5%`, else → `без скидки`.
> 💡 От большего к меньшему.

**2.10 — Защита ввода + возраст.** Спроси возраст. `< 0` → `ошибка`, `> 120` → `ошибка`, `>= 18` → `Взрослый`, else → `Ребёнок`.
> 💡 Две ветки-защиты сверху лестницы.

## 🔴 Уровень 3 — со звёздочкой (комбинации, точные диапазоны)

**3.1 — Оценка с плюсом/минусом.** Балл → `5`, `5-`, `4+`, `4`… Раздели диапазоны точнее (напр. `>= 95`→`5`, `>= 90`→`5-`, `>= 85`→`4+`…).
> 💡 Много `elif`, строго по убыванию.

**3.2 — Калькулятор с операцией.** Спроси два числа и знак (`+ - * /`). По знаку (`elif` со строкой) выведи результат.
> 💡 `op = input()`, ветки `if op == "+":` … Для `/` подумай про деление на 0 (можно ветка-защита).

**3.3 — Треугольник существует?** Спроси три стороны. Если самая большая меньше суммы двух других — `Существует`, иначе `Нет`. (Пока без `and` — сравни max с суммой.)
> 💡 Найди большую сторону через сравнения (или предположи, что третья — большая) и сравни с суммой двух. Полная версия — после `and` в Уроке 3.

**3.4 — Знаки зодиака (по месяцу, упрощённо).** Спроси месяц, выведи «примерный» знак (по одному на месяц). 12 веток.
> 💡 Длинная лестница `elif month == 1:` … Защити ввод.

**3.5 — Точные диапазоны 🎓.** Перепиши задачу 2.1 через **цепочки** `90 <= ball <= 100`, `75 <= ball < 90` и т.д. Сравни длину с версией «от большего».
> 💡 `elif 75 <= ball < 90:`.

**3.6 — Мини-РПГ бой.** Спроси HP. `> 70` → `Здоров`, `> 30` → `Ранен`, `> 0` → `При смерти`, else → `Погиб`.
> 💡 От большего к меньшему; `else` для `<= 0`.

**3.7 — Округление до оценки настроения.** Спроси число 1–10. `>= 8` → `Отличное`, `>= 5` → `Нормальное`, `>= 3` → `Так себе`, else → `Плохое`. Защити ввод (`> 10`, `< 1`).
> 💡 Защита сверху + лестница.

## ✅ Как проверить себя

- На любой ввод срабатывает **ровно одна** ветка.
- Граничные значения (89/90, 59/60) попадают **туда, куда задумано**.
- Программа не падает и **не даёт неверный ответ** из-за порядка веток.

> 🏆 Осилил 🔴? В Уроке 3 добавим `and/or/not` — и условия станут ещё мощнее (одна ветка на «взрослый И есть билет»).

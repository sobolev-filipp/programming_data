## 1. Блиц-вопросы (устно)

1. Чем `=` отличается от `==`? *(положить / сравнить)*
2. Что обязательно в конце строки `if`? *(двоеточие `:`)*
3. Что вернёт `10 >= 10`? *(True)*
4. Сколько отдельных `if` подряд можно поставить? *(сколько угодно, проверится каждый)*
5. Что показывает отступ у строки внутри `if`? *(что это тело if)*

---

## 2. Предскажи вывод

```python
x = 5
if x > 3:
    print("A")
if x > 10:
    print("B")
if x == 5:
    print("C")
```

<details><summary>Ответ</summary>

`A` и `C`. Сработали **два** независимых `if` (x>3 и x==5), `B` — нет. Сегодня узнаем, как сделать, чтобы срабатывала только одна ветка.
</details>

---

## 3. Найди неудобство

```python
age = int(input())
if age >= 18:
    print("Взрослый")
if age < 18:
    print("Ребёнок")
```

<details><summary>В чём неудобство?</summary>

Дважды пишем про границу 18 и дважды проверяем условие. Сегодня заменим второй `if` на `else` — короче и надёжнее.
</details>

---

## 4. Мостик к теме

Несколько `if` работают, но: (1) громоздко, (2) иногда срабатывает несколько веток, когда нужна одна. Сегодня — `else` и `elif`: **лестница**, из которой выполняется **ровно одна** ветка. 🪜

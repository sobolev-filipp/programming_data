## 📖 Что нужно знать за 2 минуты

**`else`** — вторая ветка, «а иначе» (без условия):
```python
if age >= 18:
    print("Взрослый")
else:
    print("Ребёнок")
```

**`elif`** — «а иначе если», для многих вариантов. Вместе получается **лестница**:
```python
if ball >= 90:
    print("5")
elif ball >= 75:
    print("4")
else:
    print("3 и ниже")
```
Python идёт сверху вниз и берёт **первое** верное условие. Срабатывает **ровно одна** ветка. **Порядок важен:** для `>=` — от большего к меньшему.

## Часть A — задания с пошаговым разбором

### Задание 1. Первый `else`
**Тема:** две ветки вместо двух `if`.
**Задача:** сказать `Чётное` или `Нечётное`.

**Разбор по шагам:**
1. Спросим число: `n = int(input("Число: "))`.
2. Проверим на чётность: `if n % 2 == 0:` → `print("Чётное")`.
3. Все остальные случаи — через `else`:
```python
n = int(input("Число: "))
if n % 2 == 0:
    print("Чётное")
else:
    print("Нечётное")
```
4. Введи 4 и 7. Заметь: **не нужен** второй `if n % 2 != 0` — `else` берёт всё остальное.

✅ Понял: `else` — «во всех остальных случаях».

### Задание 2. Первая лестница `elif`
**Тема:** больше двух вариантов.
**Задача:** оценка `5/4/3` по трём диапазонам.

**Разбор по шагам:**
1. `ball = int(input("Балл: "))`.
2. Самый строгий порог — первым:
   `if ball >= 90:` → `print("5")`
3. Следующий — через `elif`:
   `elif ball >= 75:` → `print("4")`
4. Всё остальное — `else`:
```python
ball = int(input("Балл: "))
if ball >= 90:
    print("5")
elif ball >= 75:
    print("4")
else:
    print("3 или ниже")
```
5. Введи 95, 80, 50. Каждый — одна оценка.

✅ Лестница: первое верное условие выигрывает.

### Задание 3. Порядок веток
**Тема:** почему порядок важен.
**Задача:** увидеть ошибку своими глазами.

**Разбор по шагам:**
1. Набери **специально неправильный** порядок:
```python
ball = 95
if ball >= 60:
    print("3")
elif ball >= 90:
    print("5")
```
2. Запусти. Получишь **«3»** — хотя балл 95!
3. Почему: `95 >= 60` — правда, лестница взяла **первую** ветку и остановилась.
4. Почини — переставь от большего к меньшему:
```python
if ball >= 90:
    print("5")
elif ball >= 60:
    print("3")
```

✅ Запомнил: частное (строгое) условие — выше общего.

---

### Задание 4. Три ветки: знак числа
**Тема:** `if / elif / else` на три исхода.
**Задача:** `Плюс` / `Минус` / `Ноль`.

**Разбор по шагам:**
1. `n = int(input("Число: "))`.
2. `if n > 0:` → `print("Плюс")`.
3. `elif n < 0:` → `print("Минус")`.
4. `else:` → `print("Ноль")` (осталось единственное — ноль).
```python
n = int(input("Число: "))
if n > 0:
    print("Плюс")
elif n < 0:
    print("Минус")
else:
    print("Ноль")
```
5. Проверь -3, 0, 7.

✅ `else` ловит единственный оставшийся случай — ноль.

---

### Задание 5. `elif` со строками: светофор
**Тема:** ветки по строке + `else`-страховка.
**Задача:** ответ по цвету светофора.

**Разбор по шагам:**
1. Спросим и уберём регистр/пробелы:
   `color = input("Свет? ").lower().strip()`
2. Три ветки по значению:
   `if color == "красный":` … `elif color == "зелёный":` …
3. Незнакомый ввод — `else`:
```python
color = input("Свет? ").lower().strip()
if color == "красный":
    print("Стой")
elif color == "жёлтый":
    print("Жди")
elif color == "зелёный":
    print("Иди")
else:
    print("Не цвет светофора")
```
4. Введи `Красный`, ` ЗЕЛЁНЫЙ `, `синий`.

✅ `else` поймал опечатку/лишнее.

## 📖 Что нужно знать за 2 минуты

Логические операторы соединяют условия:
```python
a and b     # оба True → True (строгий)
a or b      # хотя бы одно True → True (добрый)
not a       # переворот True↔False
```
По обе стороны `and`/`or` — **полное** условие: `age>=10 and age<=15` (не `10<=age and <=15`).
Условие можно положить в **bool-переменную**: `can_ride = height >= 140`.

## Часть A — задания с пошаговым разбором

### Задание 1. Первое `and`
**Тема:** оба условия сразу.
**Задача:** пустить в клуб, если возраст от 18 до 65.

**Разбор по шагам:**
1. Спросим возраст: `age = int(input("Возраст: "))`.
2. Нужно, чтобы возраст был `>= 18` **И** `<= 65` — соединяем через `and`:
   `if age >= 18 and age <= 65:`
3. Иначе — `else`:
```python
age = int(input("Возраст: "))
if age >= 18 and age <= 65:
    print("Проходи")
else:
    print("Нельзя")
```
4. Проверь 30 (проходи), 15 (нельзя), 70 (нельзя).

✅ `and` — оба условия должны быть True.

---

### Задание 2. Первое `or`
**Тема:** хватит одного.
**Задача:** скидка студентам или пенсионерам.

**Разбор по шагам:**
1. Превратим ответы в bool:
   `is_student = input("Студент? (да/нет) ").lower() == "да"`
   `is_senior = input("Пенсионер? (да/нет) ").lower() == "да"`
2. Скидка, если хоть одно True — `or`:
```python
is_student = input("Студент? (да/нет) ").lower() == "да"
is_senior = input("Пенсионер? (да/нет) ").lower() == "да"
if is_student or is_senior:
    print("Скидка!")
else:
    print("Без скидки")
```
3. Проверь да/нет, нет/да, нет/нет.

✅ `or` — достаточно одного True.

---

### Задание 3. Первое `not`
**Тема:** переворот.
**Задача:** пустить, если НЕ забанен.

**Разбор по шагам:**
1. `banned = input("В чёрном списке? (да/нет) ").lower() == "да"`.
2. Пускаем, когда `banned` — False, то есть `not banned` — True:
```python
banned = input("В чёрном списке? (да/нет) ").lower() == "да"
if not banned:
    print("Добро пожаловать")
else:
    print("Вход запрещён")
```
3. Читается как «если не забанен».

✅ `not` переворачивает True↔False.

---

### Задание 4. bool-переменная
**Тема:** вынести условие в переменную.
**Задача:** «можно на аттракцион» = рост ≥ 140 и возраст ≥ 10.

**Разбор по шагам:**
1. Спросим рост и возраст (`int(input(...))`).
2. Заведём **понятную** переменную:
   `can_ride = height >= 140 and age >= 10`
3. Используем её как готовый True/False:
```python
height = int(input("Рост: "))
age = int(input("Возраст: "))
can_ride = height >= 140 and age >= 10
if can_ride:
    print("Проходи")
else:
    print("Нельзя")
```
4. `if can_ride:` читается как «если можно кататься».

✅ Условие в переменной делает код понятным.

---

### Задание 5. Три оператора вместе
**Тема:** `and`, `or`, `not` в одной программе.
**Задача:** пустить, если (рост ≥ 140 **и** возраст ≥ 10) **и не** идёт дождь.

**Разбор по шагам:**
1. Рост, возраст, дождь (`rain = ... == "да"`).
2. Соберём допуск и добавим погоду:
```python
height = int(input("Рост: "))
age = int(input("Возраст: "))
rain = input("Дождь? (да/нет) ").lower() == "да"
can_ride = height >= 140 and age >= 10
if can_ride and not rain:
    print("Проходи")
else:
    print("Сегодня нет")
```
3. Проверь: 150/12/нет → проходи; 150/12/да → нет (дождь).

✅ Скобки-переменные + `and not` читаются легко.

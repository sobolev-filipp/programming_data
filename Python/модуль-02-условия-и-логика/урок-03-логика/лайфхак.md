# Лайфхаки урока 3 «Логика and/or/not» 🧰

> Приёмы, чтобы логика читалась легко и не путалась.

---

## 🎯 Тест «ОБА или ОДНО?»

Перед тем как написать `and` или `or`, спроси себя словами:
- «Нужны **оба** условия?» → `and`.
- «Хватит **хотя бы одного**?» → `or`.

Это снимает 90% ошибок «перепутал and/or».

---

## 🎯 Правило полного условия

По **обе** стороны `and`/`or` — самостоятельное сравнение:

```python
# ❌ так НЕ работает
if day == "суббота" or "воскресенье":
if age >= 10 and 15:

# ✅ правильно
if day == "суббота" or day == "воскресенье":
if age >= 10 and age <= 15:
```

Проверка: закрой пальцем одну сторону `or`/`and` — оставшееся должно быть законченным условием (давать True/False само по себе).

---

## 🎯 bool-переменные с понятным именем

Длинное условие вынеси в переменную — код станет как текст:

```python
can_ride = height >= 140 and age >= 10
is_weekend = day == "сб" or day == "вс"
if can_ride and not is_weekend:
    ...
```

Имена бери «да/нет»-смысла: `is_...`, `has_...`, `can_...`, `..._ok`.

---

## 🎯 Пиши `if x:`, а не `if x == True:`

```python
if is_banned == True:     # лишнее
if is_banned:             # так короче и читается «если забанен»
if not is_banned:         # «если НЕ забанен»
```

---

## 🎯 Ответ «да/нет» → сразу bool

Частый приём — превратить ответ пользователя в True/False одной строкой:

```python
agree = input("Согласен? (да/нет) ").lower().strip() == "да"
# теперь agree — это True или False
if agree:
    ...
```

---

## 🐞 Топ-5 ошибок

1. **`x == "а" or "б"`** → всегда True. Справа от `or` нужно **условие**.
2. **`10 <= age and <= 15`** → `SyntaxError`. Оба сравнения полные.
3. **`true`/`false`** маленькими → `NameError`. Только `True`/`False`.
4. **Перепутал `and`/`or`** → неверная логика. Тест «ОБА или ОДНО?».
5. **`and`+`or` без скобок** → неожиданный ответ. Ставь скобки.

---

## 💡 Хитрость: цепочка вместо and

Для диапазона Python разрешает математическую запись:

```python
if 10 <= age <= 15:       # то же, что age>=10 and age<=15
```

Коротко и понятно — но работает **только** для сравнений одной переменной.

---

## 🎓 Для продвинутых

- **Приоритет:** `not` → `and` → `or`. `and` «сильнее» `or` (как `×` перед `+`).
- **Короткое замыкание:** в `a and b`, если `a` уже False, `b` даже не проверяется (Python экономит). В `a or b` — наоборот: True слева, и правое не смотрят. Пригодится позже для защиты (`if x != 0 and 10 / x > 1`).
- **`True == 1`, `False == 0`:** можно **складывать** ответы — считать, сколько условий выполнено. Основа подсчёта очков в Уроке 4.

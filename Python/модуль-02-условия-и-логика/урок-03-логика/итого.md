# Урок 3 «Логика and/or/not» — итого (шпаргалка) 📌

---

## Главные мысли

1. **`and`** — нужны **ОБА** условия True (строгий: «всё или ничего»).
2. **`or`** — хватит **ХОТЯ БЫ одного** True (добрый: «спасатель»).
3. **`not`** — **переворачивает** True ↔ False.
4. **По обе стороны `and`/`or` — полные условия** (`age>=10 and age<=15`, не `10<=age and <=15`).
5. Условие можно **положить в bool-переменную** с понятным именем.

---

## Три оператора

```python
a and b     # True, только если ОБА True
a or b      # True, если ХОТЯ БЫ одно True
not a       # переворот: not True = False, not False = True
```

```python
# примеры
height >= 140 and age >= 10      # и рост, и возраст (числа)
login == "admin" and pass == "1234"   # и логин, и пароль (строки)
is_student or is_senior          # студент или пенсионер
not is_banned                    # не в чёрном списке
```

**Диапазон — цепочкой (короткий способ):**
```python
if 5 < a < 10:        # то же, что a > 5 and a < 10
if 20 <= t <= 25:     # то же, что t >= 20 and t <= 25
```
Работает только для ОДНОЙ переменной.

---

## Таблица истинности

| A | B | `and` | `or` | `not A` |
|---|---|-------|------|---------|
| T | T | **T** | **T** | F |
| T | F | F | **T** | F |
| F | T | F | **T** | **T** |
| F | F | F | F | **T** |

`and` → True лишь в 1 строке. `or` → False лишь в 1 строке.

---

## bool-переменные (профи-приём)

```python
solo_ok = height >= 140 and age >= 10
adult_ok = with_adult and height >= 120
if solo_ok or adult_ok:      # читается как по-русски
    print("Проходи")
```

`if x:` вместо `if x == True:` · `if not x:` вместо `if x == False:`.

---

## 🎓 Приоритет

Сначала **not**, потом **and**, потом **or** (`and` как `×`, `or` как `+`).
Не уверен — **скобки**: `(a and b) or c`.
Факт: `True == 1`, `False == 0` → `True + True == 2`.

---

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| `x == "а" or "б"` всегда True | справа не условие | `x=="а" or x=="б"` |
| `age>=10 and 15` не диапазон | справа не сравнение | `age>=10 and age<=15` |
| `NameError: true` | маленькая буква | `True`/`False` |
| не тот ответ | перепутал and/or | «ОБА или ОДНО?» |
| странный ответ and+or | приоритет | ставь скобки |

---

## Что должно остаться в голове

1. `and` — все, `or` — хотя бы один, `not` — наоборот.
2. По обе стороны `and`/`or` — полные сравнения.
3. Условие → bool-переменная с понятным именем.
4. `if x:` / `if not x:` вместо сравнения с True/False.
5. 🎓 not→and→or; скобки решают.

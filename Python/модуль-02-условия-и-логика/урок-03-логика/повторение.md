# Разминка перед уроком 3 (5 минут) 🔁

> Повторяем Уроки 1–2 (`if`, сравнения, `elif`) — на них строится логика. Устно или в `проба.py`.

---

## 1. Блиц-вопросы (устно)

1. Что вернёт `5 >= 5`? А `4 != 4`? *(True; False)*
2. Какой тип у результата сравнения? *(bool)*
3. Сколько веток лестницы `if/elif/else` сработает? *(ровно одна)*
4. Куда ставят защиту ввода в лестнице? *(в первые ветки)*
5. Как сравнить строку без учёта регистра? *(`.lower()`)*

---

## 2. Предскажи вывод

```python
print(10 > 3)
print(10 == 3)
print(2 < 1)
print("да" == "да")
```

<details><summary>Ответ</summary>

`True`, `False`, `False`, `True`
</details>

---

## 3. Найди неудобство

```python
if height >= 140:
    if age >= 10:
        print("Проходи")
```

<details><summary>В чём неудобство?</summary>

Два уровня вложенности ради «рост И возраст», и трудно приписать «иначе». Сегодня заменим на одно условие через `and`.
</details>

---

## 4. Мостик к теме

Пока каждое `if` проверяло **одно** условие. Но правила бывают составными: «рост **и** возраст», «студент **или** пенсионер», «**не** забанен». Сегодня — `and`, `or`, `not`: соединяем условия в одно. 🧠

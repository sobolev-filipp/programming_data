## Модуль 1 — Первые шаги

### Урок 1.1 — Переменные, ввод и вывод

#### Переменная — коробка с именем

Переменная хранит значение под именем. Создаём через `=` (это «положить», а не «равно»):

```python
name = "Аня"       # строка (текст в кавычках)
age = 12           # целое число (без кавычек)
height = 1.5       # дробное число (точка, не запятая!)
```

#### `print` — вывести на экран

```python
print("Привет!")            # Привет!
print("Меня зовут", name)   # Меня зовут Аня   (запятая ставит пробел)
```

#### f-строки — вставить значение в текст

Буква `f` перед кавычками, значение — в фигурных скобках `{}`. Это главный способ вывода в курсе:

```python
print(f"Меня зовут {name}, мне {age} лет")   # Меня зовут Аня, мне 12 лет
print(f"Через год будет {age + 1}")          # Через год будет 13 (внутри можно считать)
```

#### `input` — спросить у пользователя

`input` **всегда возвращает строку** (текст), даже если ввели число!

```python
name = input("Как тебя зовут? ")      # то, что ввёл человек, попадёт в name
age = input("Сколько тебе лет? ")     # ВНИМАНИЕ: тут age — это ТЕКСТ "12", а не число
```

Чтобы считать введённое число — переведи его в число функцией `int` (целое) или `float` (дробное):

```python
age = int(input("Сколько тебе лет? "))     # теперь age — число 12
print(age + 1)                             # 13 — можно считать
```

#### Типы данных и `type`

```python
type("Аня")   # <class 'str'>   — строка (string)
type(12)      # <class 'int'>   — целое (integer)
type(1.5)     # <class 'float'> — дробное
```

#### Частые ошибки

- `age + 1`, где `age` пришёл из `input` без `int(...)` → `TypeError: can only concatenate str`. Нельзя сложить текст и число.
- Дробное — через **точку** (`1.5`), запятая `1,5` — это уже не одно число.

| Слово | Что значит |
|---|---|
| `=` | положить значение в переменную |
| `print(...)` | вывести на экран |
| `input(...)` | спросить у пользователя (вернёт текст) |
| `int(...)` / `float(...)` | превратить текст в число |
| f-строка `f"...{x}..."` | текст с подставленным значением |

### Урок 1.2 — Числа и калькулятор

#### Арифметика

```python
7 + 2     # 9    сложение
7 - 2     # 5    вычитание
7 * 2     # 14   умножение (звёздочка!)
7 / 2     # 3.5  деление (всегда дробное)
7 // 2    # 3    целая часть от деления (сколько целых раз поместилось)
7 % 2     # 1    остаток от деления
2 ** 3    # 8    степень (2 в кубе)
```

> 💡 **`//` и `%` — пара.** `17 // 5 = 3` (целых пятёрок), `17 % 5 = 2` (остаток). Вместе дают «разложить»: 17 конфет на 5 детей → по 3, и 2 лишние.

#### Округление

```python
round(3.14159, 2)   # 3.14   — до двух знаков
round(4.5)          # 4 или 5 (округляет до целого)
```

#### Собираем ник (склейка строк)

Строки можно **складывать** `+` и **размножать** `*`:

```python
name = "Кот"
nick = name + "_2000"     # Кот_2000  — склеили
line = "=" * 10           # ==========  — размножили символ
```

> ⚠️ Склеивать `+` можно только **текст с текстом**. Число сначала переведи в текст: `"Уровень " + str(5)`.

| Операция | Знак | Пример |
|---|---|---|
| деление целое / остаток | `//` `%` | `17 // 5 = 3`, `17 % 5 = 2` |
| степень | `**` | `3 ** 2 = 9` |
| склеить строки | `+` | `"а" + "б"` |
| размножить строку | `*` | `"ля" * 3` |

### Урок 1.3 — Случайность: `random`

Чтобы программа выдавала случайное — подключаем библиотеку:

```python
import random    # пишется один раз вверху файла

random.randint(1, 6)              # случайное ЦЕЛОЕ от 1 до 6 (оба края входят) — кубик
random.choice(["камень", "ножницы", "бумага"])   # случайный элемент списка
random.random()                   # дробное от 0 до 1
```

> `random.randint(a, b)` — **оба** числа могут выпасть (и `a`, и `b`). Это удобно для кубика, монетки, лотереи.

#### Частые ошибки

- Забыл `import random` → `NameError: name 'random' is not defined`.
- `random.randint(1, 6.5)` → ошибка: границы — только целые.

### Урок 2.1 — `if` и сравнения

**`if`** («если») выполняет код, только если условие — правда.

```python
age = int(input("Возраст: "))

if age >= 18:
    print("Проходите")      # напечатается, только если условие верно
print("Конец")              # это БЕЗ отступа — печатается всегда
```

- После `if условие:` — **двоеточие**, а строки внутри — **с отступом** (Tab / 4 пробела). Отступ показывает, что относится к `if`.

#### Знаки сравнения

```python
a == b    # равно (ДВА знака равно! один = это «положить»)
a != b    # не равно
a > b     # больше
a < b     # меньше
a >= b    # больше или равно
a <= b    # меньше или равно
```

#### Цепочка сравнений

Python понимает «двойное» сравнение как в математике:

```python
if 5 < a < 10:              # a больше 5 И меньше 10 — одной строкой
    print("от 5 до 10")
```

#### Сравнение текста без учёта регистра

```python
answer = input("Да/нет? ")
if answer.lower() == "да":   # .lower() делает буквы маленькими → "ДА", "Да", "да" сработают
    print("Согласен")
```

#### Вложенный `if`

Один `if` внутри другого — проверка «и то, и это»:

```python
if login == "admin":
    if password == "1234":
        print("Вход выполнен")
```

> ⚠️ Самая частая ошибка: `if a = 5` вместо `if a == 5`. Сравнение — **два** знака равно.

### Урок 2.2 — `else` и `elif`

**`else`** («иначе») — что делать, если условие НЕ выполнилось:

```python
if age >= 18:
    print("Взрослый")
else:
    print("Ещё нет")
```

**`elif`** («иначе если») — несколько вариантов по очереди. Проверяются сверху вниз, срабатывает **первый** подходящий:

```python
if ball >= 90:
    print("Отлично")
elif ball >= 70:
    print("Хорошо")
elif ball >= 50:
    print("Нормально")
else:
    print("Повтори")
```

> 💡 **Порядок важен!** Ветки проверяются по очереди, поэтому идут от строгого к мягкому (сначала `>= 90`, потом `>= 70`). Как только нашлось верное — остальные пропускаются.

#### Защита ввода

```python
age = int(input("Возраст: "))
if age < 0:
    print("Так не бывает")
elif age > 120:
    print("Слишком много")
else:
    print(f"Тебе {age}")
```

### Урок 2.3 — Логика: `and`, `or`, `not`

Соединяем несколько условий в одно:

```python
# and — нужны ОБА условия
if age >= 7 and age <= 14:
    print("Детский билет")

# or — достаточно ХОТЯ БЫ ОДНОГО
if day == "сб" or day == "вс":
    print("Выходной")

# not — переворачивает (правда ↔ ложь)
if not raining:
    print("Зонт не нужен")
```

#### Логический тип `bool`

У условия всего два значения: `True` (правда) и `False` (ложь).

```python
x = 5 > 3        # True
is_adult = age >= 18    # в переменной можно хранить правду/ложь
```

> 💡 Скобки задают порядок: `(a or b) and c`. Сначала — что в скобках.

| Оператор | Срабатывает, когда |
|---|---|
| `and` | **оба** условия верны |
| `or` | **хотя бы одно** верно |
| `not` | переворачивает: `not True` = `False` |

### Урок 2.4 — Счётчики и `pip`

#### Копилки: `+=`, `-=`, `*=`

Короткая запись «прибавить к себе»:

```python
score = 0
score += 10      # то же, что score = score + 10  → 10

lives = 3
lives -= 1       # 2  (отнять)
```

Это основа **счётчиков** (очки, жизни, правильные ответы).


### Урок 2.5 — Знакомство со списками

**Список** — много значений в одной переменной, в квадратных скобках:

```python
figures = ["камень", "ножницы", "бумага"]

figures[0]              # "камень"  — первый (счёт с 0!)
```

### Урок 3.1 — `while`

**`while`** («пока») повторяет код, **пока условие верно**:

```python
count = 1
while count <= 3:        # пока count не больше 3
    print(count)         # 1, потом 2, потом 3
    count += 1           # ОБЯЗАТЕЛЬНО меняем — иначе цикл вечный!
```

У цикла `while` три части: **начало** (`count = 1`), **условие** (`count <= 3`), **изменение** (`count += 1`).

#### `while True` и `break`

«Бесконечный» цикл, из которого выходим по условию через `break`:

```python
while True:
    answer = input("Пароль: ")
    if answer == "1234":
        break            # выйти из цикла
    print("Неверно, ещё раз")
```

> ⚠️ **Вечный цикл.** Если забыть менять переменную в условии — программа зависнет. Останови её клавишами `Ctrl + C`.

### Урок 3.2 — `for` и `range`

**`for`** проходит по каждому элементу — списка, строки или диапазона:

```python
for figure in ["камень", "ножницы", "бумага"]:
    print(figure)        # печатает каждое по очереди

for letter in "кот":
    print(letter)        # к / о / т  — строка по буквам
```

#### `range` — диапазон чисел

```python
range(5)         # 0, 1, 2, 3, 4           (пять чисел с нуля)
range(1, 6)      # 1, 2, 3, 4, 5           (стоп НЕ входит!)
range(2, 11, 2)  # 2, 4, 6, 8, 10          (шаг 2)

for i in range(1, 6):
    print(i)             # 1 2 3 4 5
```

> ⚠️ В `range(1, 6)` число 6 **не входит** — цикл идёт до 5. Запомни: «стоп не включается».

#### Печать без перехода на новую строку

```python
for i in range(1, 6):
    print(i, end=" ")    # 1 2 3 4 5  — всё в одну строку через пробел
```

### Урок 3.3 — `enumerate`, `zip`, накопители

#### `enumerate` — номер + значение

```python
for i, name in enumerate(["Аня", "Боря"], start=1):
    print(i, name)       # 1 Аня / 2 Боря
```

#### `zip` — два списка параллельно

```python
names = ["Аня", "Боря"]
ages = [12, 13]
for name, age in zip(names, ages):
    print(name, age)     # Аня 12 / Боря 13
```

#### Накопители (собрать итог циклом)

```python
total = 0
for x in [10, 20, 30]:
    total += x           # копим сумму
print(total)             # 60
```

Готовые функции делают то же короче:

```python
sum([10, 20, 30])    # 60   — сумма
max([4, 9, 2])       # 9    — наибольшее
min([4, 9, 2])       # 2    — наименьшее
len([4, 9, 2])       # 3    — сколько
```

#### Анимация: `time.sleep`

```python
import time
time.sleep(1)        # пауза 1 секунда
print("Загрузка...", end="\r")   # \r — вернуть курсор в начало строки (перезапись)
```

### Урок 3.4 — Вложенные циклы, `break`/`continue`

**Цикл внутри цикла** — для таблиц и узоров. Внешний — строки, внутренний — столбцы:

```python
for row in range(1, 4):          # 3 строки
    for col in range(1, 4):      # в каждой — 3 столбца
        print(f"{row},{col}", end=" ")
    print()                      # перенос строки после каждого ряда
```

#### `break` и `continue`

```python
for i in range(1, 10):
    if i == 5:
        break        # ПОЛНОСТЬЮ выйти из цикла
for i in range(1, 6):
    if i == 3:
        continue     # пропустить ТОЛЬКО этот шаг, идти дальше
    print(i)         # 1 2 4 5  (тройку пропустили)
```

| Команда | Что делает |
|---|---|
| `break` | выйти из цикла совсем |
| `continue` | пропустить текущий шаг, продолжить цикл |

### Урок 3.5 — Черепашка «Умный пылесос»

Практикум: робот-пылесос ездит по комнате-сетке и собирает мусор. Ты пишешь **только алгоритм** из готовых команд (всё по-английски):

```python
right()      # шаг вправо
left()       # шаг влево
up()         # шаг вверх
down()       # шаг вниз
clean()      # убрать мусор в клетке
```

Есть **сенсоры стен** — проверить, есть ли стена рядом:

```python
while not wall_right:    # пока справа нет стены
    right()
    clean()
```

> 💡 Правило: **`for`** — если знаешь, сколько шагов; **`while` + сенсор** — если едешь «до стены».

### Урок 4.1 — Списки вглубь

Список можно **менять** (в отличие от строки). Создаём и правим по индексу:

```python
games = ["Minecraft", "Roblox", "Sims"]
games[0]              # "Minecraft"  — первый
games[-1]             # "Sims"       — последний (отрицательный индекс с конца)
games[0] = "Dota"     # заменить на месте
```

#### Добавить

```python
games.append("CS")          # добавить в КОНЕЦ
games.insert(0, "Tetris")   # вставить на позицию 0 (в начало)
games.extend(["A", "B"])    # добавить СРАЗУ несколько по отдельности
```

#### Удалить

```python
games.remove("Roblox")   # по ЗНАЧЕНИЮ (убирает первое совпадение)
games.pop()              # снять ПОСЛЕДНИЙ и отдать его
games.pop(0)             # снять по номеру
del games[1]             # удалить по номеру
games.clear()            # очистить весь список
```

#### Полезное

```python
games.count("CS")    # сколько раз встречается
games.index("CS")    # на какой позиции (первое совпадение)
games.sort()         # отсортировать НА МЕСТЕ (сам список меняется)
games.reverse()      # перевернуть
sorted(games)        # вернуть НОВЫЙ отсортированный (оригинал цел)
```

> ⚠️ **Главная ловушка:** `games = games.sort()` сломает список! `sort()` меняет на месте и возвращает `None`. Пиши просто `games.sort()`.

### Урок 4.2 — Действия со списками

```python
scores = [82, 95, 70, 88]

sum(scores)                  # 335  — сумма
max(scores)                  # 95   — наибольший
min(scores)                  # 70   — наименьший
len(scores)                  # 4

# среднее
round(sum(scores) / len(scores), 1)   # 83.8
```

#### Сортировка по признаку (`key=`)

```python
words = ["кот", "бегемот", "ёж"]
sorted(words, key=len)              # по длине: ['ёж', 'кот', 'бегемот']
sorted(names, key=str.lower)        # по алфавиту без учёта регистра
sorted(scores, reverse=True)        # по убыванию
```

#### Фильтр (отобрать подходящие)

```python
high = []
for s in scores:
    if s >= 85:
        high.append(s)       # [95, 88]
```

### Урок 4.3 — Срезы

Срез `[start:stop:step]` берёт **кусок** списка или строки. `stop` **не входит**:

```python
a = [10, 20, 30, 40, 50]
a[1:4]      # [20, 30, 40]   — с 1 по 4 (4 не входит)
a[:3]       # [10, 20, 30]   — с начала по 3
a[2:]       # [30, 40, 50]   — с 2 до конца
a[-2:]      # [40, 50]       — последние два
a[::2]      # [10, 30, 50]   — каждый второй (шаг 2)
a[::-1]     # [50,40,30,20,10] — задом наперёд
a[:]        # копия всего списка
```

Для строк работает так же:

```python
word = "питон"
word[::-1]              # "нотип"  — перевернули
word == word[::-1]      # проверка на палиндром
```

> ⚠️ `new = a` — это **не копия**, а второе имя того же списка (изменишь одно — изменится и другое). Настоящая копия — `a[:]` или `a.copy()`.

### Урок 4.4 — Кортежи

**Кортеж** — как список, но **неизменяемый** («замороженный»). В круглых скобках:

```python
point = (3, 5)
point[0]            # 3    — читать можно
point[0] = 9        # ОШИБКА TypeError — менять нельзя!
```

Используют для того, что не должно меняться: координаты, цвет RGB, константы.

#### Распаковка — разложить по переменным

```python
point = (3, 5)
x, y = point        # x = 3, y = 5  сразу обе
a, b = b, a         # обмен значениями в одну строку
```

В цикле:

```python
points = [(0, 0), (1, 2), (3, 4)]
for x, y in points:
    print(x, y)
```

#### `divmod` — частное и остаток сразу

```python
divmod(17, 5)       # (3, 2)  — 3 целых и 2 в остатке (это кортеж)
q, r = divmod(17, 5)   # q = 3, r = 2
```

### Урок 4.5 — Словари

**Словарь** — пары «ключ → значение». В фигурных скобках:

```python
hero = {"имя": "Маг", "hp": 70}

hero["имя"]                 # "Маг"   — достать по ключу
hero["hp"] = 100            # изменить (или добавить новый ключ)
hero["level"] = 5           # добавить новую пару
del hero["hp"]              # удалить пару
"имя" in hero               # True    — есть ли такой КЛЮЧ
len(hero)                   # сколько пар
```

> ⚠️ `hero["телефон"]`, если такого ключа нет → `KeyError`. Безопасно — через `.get`:

```python
hero.get("телефон")          # None (не падает)
hero.get("телефон", "нет")    # "нет" — запасное значение
```

#### Перебор

```python
for key in hero:             # идём по КЛЮЧАМ
    print(key, hero[key])

hero.keys()      # все ключи
hero.values()    # все значения
```

#### Словарь-счётчик (очень частый приём)

Посчитать, сколько раз встречается каждое:

```python
votes = ["кот", "пёс", "кот", "кот"]
counts = {}
for v in votes:
    counts[v] = counts.get(v, 0) + 1
print(counts)        # {'кот': 3, 'пёс': 1}
```

### Урок 4.6 — Множества

**Множество** — только **уникальные** элементы, без порядка и без индексов. В фигурных скобках:

```python
tags = {"питон", "код", "игра"}

set([1, 1, 2, 2, 3])    # {1, 2, 3}   — убрать дубли из списка
len(set(words))         # сколько РАЗНЫХ слов

"код" in tags           # True
tags.add("арт")         # добавить
tags.discard("игра")    # убрать (без ошибки, если нет)
```

#### Операции с множествами

```python
a = {1, 2, 3}; b = {3, 4, 5}
a | b     # {1,2,3,4,5}  — объединение (всё вместе)
a & b     # {3}          — пересечение (общее)
a - b     # {1, 2}       — разность (только у a)
a ^ b     # {1,2,4,5}    — только у одного из двух
```

#### Перебор словаря парами — `.items()`

```python
menu = {"кофе": 120, "чай": 80}
for dish, price in menu.items():
    print(f"{dish} — {price} руб")
```

> ⚠️ Пустое множество — это `set()`, а **не** `{}` (пустые фигурные скобки — это пустой словарь).

### Урок 4.7 — Мини-база данных

Итог модуля: **список словарей** = таблица (каждый словарь — строка таблицы):

```python
heroes = [
    {"имя": "Рыцарь", "hp": 100},
    {"имя": "Маг", "hp": 70},
]

heroes[0]["имя"]     # "Рыцарь"  — запись по номеру, потом поле
for hero in heroes:
    print(hero["имя"], hero["hp"])
```

#### Поиск по полю

```python
name = "Маг"
found = None
for hero in heroes:
    if hero["имя"] == name:
        found = hero
print(found)         # вся запись или None
```

#### Сортировка по полю (через пары-кортежи)

Список словарей напрямую не сортируется — собираем пары `(поле, имя)`:

```python
pairs = []
for p in players:
    pairs.append((p["очки"], p["имя"]))
pairs.sort(reverse=True)     # по убыванию очков
```

На этом строят мини-приложение с меню: показать / добавить / найти / удалить запись.

### Урок 5.1 — Свои функции `def`

**Функция** — своя команда, которую ты сам придумал и назвал. Чтобы не копировать один и тот же код.

Два шага: **объявить** (`def`) и **вызвать** (имя со скобками).

```python
def ramka():                 # объявили команду (def + имя + () + :)
    print("+-----+")         # тело — с отступом
    print("| HI  |")
    print("+-----+")

ramka()                      # вызвали — рамка напечаталась
ramka()                      # можно сколько угодно раз
```

> ⚠️ **Объявить ≠ выполнить.** Один `def` ничего не печатает. Нужен **вызов** `ramka()`. И `def` должен стоять **выше** вызова (иначе `NameError`).

#### Параметры — данные на вход

Что передашь в скобках при вызове (**аргумент**), попадёт в переменную-**параметр** внутри:

```python
def privet(name):            # name — параметр
    print("Привет,", name)

privet("Аня")                # Привет, Аня
privet("Боря")               # Привет, Боря  (одна функция — разный результат)
```

Несколько параметров — через запятую, **важен порядок**:

```python
def summa(a, b):
    print(f"{a} + {b} = {a + b}")

summa(3, 5)                  # 3 + 5 = 8
```

#### Функция может звать другую функцию

```python
def liniya():
    print("----------")

def kartochka(name):
    liniya()                 # зовём свою же функцию
    print("Герой:", name)
    liniya()

kartochka("Маг")
```

| Слово | Что значит |
|---|---|
| `def имя():` | объявить (создать) функцию |
| тело (отступ) | что функция делает |
| `имя()` | вызвать функцию |
| параметр | переменная в скобках для данных на вход |
| аргумент | то, что передаём в скобках при вызове |

> ⚠️ Самые частые ошибки: забыл **вызвать** (пусто на экране); вызвал **выше** `def` (`NameError`); передал не столько аргументов, сколько параметров (`TypeError`); забыл **скобки** при вызове (`ramka` вместо `ramka()`).

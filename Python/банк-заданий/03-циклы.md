# 🏦 Банк заданий 03 — Циклы

**Темы (накопительно):** всё из [банка 02](02-условия.md) + **цикл `while`**, условие продолжения, `while True`, выход `break`, счётчики и копилки в цикле. *(Задачи на `for`/`range` и вложенные циклы добавятся по мере прохождения уроков 2–7.)*

> 🎯 Отдельный пул для домашки, резерва и повторения — **не повторяет** практику урока. Уровни: 🟢 базовые · 🟡 средние · 🔴 со звёздочкой. Подсказки — короткие наводки. Ответы спрятаны в конце (открой `▸ Ответы`, только если застрял).
>
> ⚠️ В каждом цикле спроси себя: **что сделает условие ложным (или где `break`)?** — чтобы не поймать вечный цикл. Зависло — **`Ctrl+C`**.

---

## 🟢 Базовые (простой счётчик)

1. Выведи числа от 1 до 20 через `while`.
2. Выведи обратный отсчёт от 10 до 1, затем `Пуск!`.
3. Выведи чётные числа от 2 до 30.
4. Выведи числа, кратные 5, от 5 до 100.
5. Посчитай сумму чисел от 1 до 20 (копилка `total`).
6. Выведи слово `Ура` ровно 7 раз (счётчик `i`).
7. Выведи `10, 20, 30, ... 100` (шаг 10).
8. Посчитай сумму чётных чисел от 2 до 20.

## 🟡 Средние (while True + break, ввод)

9. Спрашивай пароль, пока не введут `open`. Тогда `Открыто` и выход.
10. Спрашивай слова, пока не введут `стоп`; каждое печатай с `!`.
11. Складывай вводимые числа, пока не введут `0`; выведи сумму.
12. Проси число, пока не введут положительное; выведи его квадрат.
13. «Ещё раунд?»: печатай `Играем`, пока отвечают `да`.
14. Посчитай, сколько чисел ввёл пользователь до слова `хватит` (счётчик).
15. Проси очки и складывай, пока сумма `< 50`; потом `Уровень пройден`.
16. Найди максимум среди вводимых чисел (до `0`).
17. Меню: `1-Играть`, `2-Выход`; крутись, пока не выберут `2`.
18. Проси число, пока не введут число от 1 до 6 (кубик); лови неверный ввод в цикле.

## 🔴 Со звёздочкой (игры и алгоритмы)

19. Собери «Угадай число» (1–100): `random.randint`, `Больше/Меньше/Верно`, счётчик попыток, `break`.
20. 🎓 «Угадай число» с лимитом 7 попыток и флагом `won`; при провале покажи загаданное.
21. 🎓 «Компьютер угадывает тебя»: держи границы `low/high`, называй середину, двигай границы по ответу `больше/меньше/верно`.
22. Посчитай факториал числа `n` (например 5! = 120) циклом.
23. 🎓 Дано число — посчитай сумму его цифр (`% 10` и `// 10`).
24. 🎓 «Копилка на мечту»: цель 1000; проси вклады, пока не накопится, печатай остаток до цели.

**5.** `total = 0; n = 1` / `while n <= 20:` / `total += n; n += 1` → 210.
**9.** `while True:` / `p = input(...)` / `if p == "open": print("Открыто"); break` / `print("Неверно")`.
**11.** `total = 0` / `while True:` / `n = int(input(...))` / `if n == 0: break` / `total += n`.
**16.** `best = 0` / `while True:` / `n=int(input(...))` / `if n == 0: break` / `if n > best: best = n`.
**19.**
```python
import random
secret = random.randint(1, 100)
attempts = 0
while True:
    guess = int(input("Вариант: "))
    attempts += 1
    if guess < secret:
        print("Больше!")
    elif guess > secret:
        print("Меньше!")
    else:
        print(f"Верно за {attempts}!")
        break
```
**21.** `low, high = 1, 100` / `while True:` / `mid = (low+high)//2` / спрашиваем; `если больше: low = mid+1`, `если меньше: high = mid-1`, `верно: break`.
**22.** `result = 1; k = 1` / `while k <= n:` / `result *= k; k += 1`.
**23.** `total = 0` / `while n > 0:` / `total += n % 10; n //= 10`.

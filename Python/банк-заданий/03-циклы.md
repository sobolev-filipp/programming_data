# 🏦 Банк заданий 03 — Циклы

**Темы (накопительно):** всё из [банка 02](02-условия.md) + **цикл `while`** (`while True`, `break`, счётчики), **цикл `for`** (перебор списков/строк, `range`, `end=`), **`enumerate`/`zip`**, итоги списка (`sum/max/min/len`), `time.sleep`, **вложенные циклы**, `break`/`continue`, программы на циклах (игры, генераторы, ASCII-арт).

> 🎯 Отдельный пул для домашки, резерва и повторения — **не повторяет** практику урока. Уровни: 🟢 базовые · 🟡 средние · 🔴 со звёздочкой. Подсказки — короткие наводки. Ответы спрятаны в конце (открой `▸ Ответы`, только если застрял).
>
> ⚠️ В каждом цикле спроси себя: **что сделает условие ложным (или где `break`)?** — чтобы не поймать вечный цикл. Зависло — **`Ctrl+C`**.

**Темы (накопительно):** всё из [банка 03](03-циклы.md) + **списки вглубь** (`append/insert/extend`, `remove/pop/del/clear`, изменение по индексу, `[-1]`, `count/index`, `sort/sorted/reverse`), кортежи, срезы, словари, множества.

> 🎯 Отдельный пул для домашки, резерва и повторения — **не повторяет** практику урока. Уровни: 🟢 базовые · 🟡 средние · 🔴 со звёздочкой. Подсказки — короткие наводки. Ответы спрятаны в конце (открой `▸ Ответы`, только если застрял).

> ⚠️ Помни: методы-изменялки (`append/sort/remove/reverse`) меняют список **на месте** и возвращают `None` — не пиши `lst = lst.метод(...)`.

## 📋 Списки: изменение, добавление, удаление (Урок 1)

### 🟢 Базовые

1. Заведи список из 5 городов. Выведи первый, последний (`[-1]`) и длину.
2. В списке `["чай", "кофе", "сок"]` замени средний элемент на `"вода"` по индексу.
3. Создай пустую корзину `[]` и добавь `append`-ом 4 товара. Выведи её.
4. Из списка удали один элемент по значению (`remove`).
5. Сними последний элемент списка через `pop` в переменную и выведи, что снял.
6. Добавь в список новый элемент на позицию 0 (`insert`).
7. Посчитай длину списка после двух `append` и одного `remove`.
8. Выведи предпоследний элемент списка через отрицательный индекс.

### 🟡 Средние

9. К списку `["меч", "щит"]` добавь сразу три предмета через `extend`.
10. В списке `[1, 2, 2, 3, 2]` посчитай, сколько раз встречается `2` (`count`).
11. Найди позицию элемента `"Москва"` в списке городов (`index`).
12. Отсортируй список чисел по возрастанию и по убыванию (`sort` / `sort(reverse=True)`).
13. Разверни список из 6 элементов задом наперёд (`reverse`).
14. Удали элемент по индексу 2 через `del`.
15. Дан `data = [3, 1, 2]`. Получи отсортированную копию через `sorted`, не меняя `data`. Выведи оба.
16. Выведи список дел с номерами (`1. ...`, `2. ...`) через `enumerate`.

### 🔴 Со звёздочкой

17. 🎓 Собери приложение «Список дел»: меню в `while` (добавить/удалить/показать/выход), удаление через `pop(number - 1)`.
18. 🎓 Безопасно удали элемент: только если он есть (`if x in lst`), иначе сообщи «нет такого».
19. 🎓 Удали ВСЕ вхождения числа из списка (`while x in lst: lst.remove(x)`).
20. 🎓 Поменяй местами первый и последний элементы (`lst[0], lst[-1] = lst[-1], lst[0]`).
21. 🎓 «Топ игроков»: добавь результат, отсортируй по убыванию, выведи первые три.

## 📊 Действия со списками: итоги, сортировка, фильтр (Урок 2)

### 🟢 Базовые

22. Дан список чисел — выведи их сумму и количество (`sum`, `len`).
23. Выведи максимум и минимум списка (`max`, `min`).
24. Посчитай среднее списка оценок, округли до 1 знака (`round(sum/len, 1)`).
25. Отсортируй список чисел по возрастанию новым списком (`sorted`).
26. Отсортируй тот же список по убыванию (`sorted(..., reverse=True)`).
27. Выведи размах списка — разницу максимума и минимума.
28. Дан список температур за неделю — выведи самую высокую, низкую и среднюю.

### 🟡 Средние

29. Дан список очков — выведи три лучших результата (топ-3 через `sorted` + индексы).
30. Два списка (имена, очки) — выведи имя игрока с максимальным счётом (`index` + `max`).
31. Отсортируй список слов по длине (`key=len`).
32. Отсортируй имена без учёта регистра (`key=str.lower`).
33. Дан `data` — получи отсортированную копию через `sorted`, докажи, что оригинал цел.
34. Выведи имя аутсайдера — игрока с минимальным счётом.
35. Отсортируй города по алфавиту и выведи с номерами (`enumerate(sorted(...))`).

### 🔴 Со звёздочкой

36. 🎓 Собери в новый список фильтром тех, у кого счёт ≥ 80 (`[]`+`for`+`if`+`append`).
37. 🎓 Из списка чисел собери только чётные.
38. 🎓 Посчитай средний балл, затем собери в список тех, кто выше среднего.
39. 🎓 Посчитай сумму и максимум списка ЦИКЛОМ (без `sum`/`max`) и сверь со встроенными.
40. 🐢 В каркасе `диаграмма.py` построй столбчатую диаграмму по списку (`for v in scores: bar(v)`), потом отсортируй перед выводом.

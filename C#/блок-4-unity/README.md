# Блок 4 — 🎮 Unity: создание игр (22 урока, 44 ч)

> Делаем игры на движке **Unity** с C#-скриптами. **Самый большой блок курса. Каждый шаг — подробно, со скриншотами** (по просьбе методиста): установка, интерфейс, объекты, компоненты, физика, скрипты, префабы, полноценный 2D-платформер, тайлы, враги, UI, звук, сборка.

# 📦 Материалы урока 3 — проект «Калькулятор»

Здесь **два файла**, которые ученик собирает в этом уроке:

- [`MainPage.xaml`](MainPage.xaml) — внешность: экран-`Label` и кнопки, расставленные по **`Grid`** (сетке);
- [`MainPage.xaml.cs`](MainPage.xaml.cs) — логика: набор числа, операции, `switch` для вычисления, сброс.

## Как этим пользоваться

Весь MAUI-проект в репозиторий **не кладём** (папки `bin/obj/Platforms` генерируются сами). Вместо этого:

1. Создай новый MAUI-проект с именем **`CalcApp`**:
   - **Windows (Visual Studio):** Создание проекта → шаблон **.NET MAUI App** → имя `CalcApp` → .NET 10.0.
   - **Mac (VS Code):** `dotnet new maui -o CalcApp`
2. **Замени** содержимое сгенерированных `MainPage.xaml` и `MainPage.xaml.cs` на файлы отсюда.
3. Запусти:
   - **Windows:** платформа **Windows Machine** → ▶ (F5).
   - **Mac:** `dotnet build -t:Run -f net10.0-maccatalyst`

> ⚠️ **Важно про имя проекта.** В `MainPage.xaml.cs` первая строка — `namespace CalcApp;`, а в `MainPage.xaml` — `x:Class="CalcApp.MainPage"`. Слово `CalcApp` должно **совпадать с именем твоего проекта**. Назвал иначе — поменяй `CalcApp` на своё имя в обоих файлах.

## Что умеет

Набор числа цифрами, операции `+ − × ÷`, кнопка `=` (через `switch`), сброс `C`. Длинный «хвост» деления подрезается через `Math.Round(result, 4)`. Считать можно цепочкой (результат становится первым числом следующего действия). Деление на 0 защищено (даёт 0).

## Проверено

Код собран на **.NET 10** (`net10.0-windows`) — сборка успешна, **0 ошибок, 0 предупреждений**. Логика вычислений проверена прогоном: `12+8=20`, затем `×3=60`; `10÷3=3,3333`; `5÷0=0`.

## 📚 Что мы делаем

Приложение **«Калькулятор»**: сверху экран, под ним 4×4 кнопки (цифры, `+ − × ÷`, `=`, `C`). Учимся главному — расставлять элементы **сеткой `Grid`** по строкам и столбцам. Логика вычислений вся из блока 1 (`switch`, `Convert.ToDouble`, `Math.Round`).

---

## Шаг 0. Что такое Grid (коротко)

- **`Grid`** — макет-**таблица**: делит место на **строки** и **столбцы**, на пересечении — **ячейки**.
- Каждому элементу мы **сами** говорим ячейку: `Grid.Row="строка" Grid.Column="столбец"`.
- Нумерация — **с нуля**: первая строка — `Row="0"`, второй столбец — `Column="1"`.

Бери `Grid`, когда элементы ложатся таблицей (как кнопки калькулятора).

## Шаг 2. Пустая сетка

Открой `MainPage.xaml`. Удали всё **внутри** `<ContentPage>...</ContentPage>` и поставь сетку. Странице — тёмный фон:

```xml
<ContentPage xmlns="http://schemas.microsoft.com/dotnet/2021/maui"
             xmlns:x="http://schemas.microsoft.com/winfx/2009/xaml"
             x:Class="CalcApp.MainPage"
             BackgroundColor="#1E1E2E">

    <Grid RowDefinitions="100,70,70,70,70"
          ColumnDefinitions="*,*,*,*"
          RowSpacing="10" ColumnSpacing="10" Padding="16"
          VerticalOptions="Center">

    </Grid>

</ContentPage>
```

- `RowDefinitions="100,70,70,70,70"` — 5 строк (первая под экран — повыше);
- `ColumnDefinitions="*,*,*,*"` — 4 равных столбца;
- `RowSpacing`/`ColumnSpacing` — зазор между кнопками; `Padding` — от краёв.

**Запусти.** Экран пустой и тёмный — каркас готов. ✅

## Шаг 3. Экран

Первым внутрь сетки — метку-экран, растянутую на все 4 столбца:

```xml
<Label x:Name="Display" Grid.Row="0" Grid.Column="0" Grid.ColumnSpan="4"
       Text="0" FontSize="48" TextColor="White"
       HorizontalOptions="End" VerticalOptions="Center" />
```

- `x:Name="Display"` — будем менять из кода;
- `Grid.ColumnSpan="4"` — на всю ширину;
- `HorizontalOptions="End"` — число прижато вправо.

**Запусти.** Вверху справа — белый ноль. ✅

## Шаг 4. Кнопки — ряд за рядом

Добавляй кнопки под экраном. **Каждой** указывай строку и столбец. Ряд 1 (7 8 9 ÷):

```xml
<Button Grid.Row="1" Grid.Column="0" Text="7" FontSize="24" Clicked="OnDigit" />
<Button Grid.Row="1" Grid.Column="1" Text="8" FontSize="24" Clicked="OnDigit" />
<Button Grid.Row="1" Grid.Column="2" Text="9" FontSize="24" Clicked="OnDigit" />
<Button Grid.Row="1" Grid.Column="3" Text="÷" FontSize="24" BackgroundColor="#F59E0B" Clicked="OnOperation" />
```

Ряды 2 и 3 (4 5 6 × и 1 2 3 −) — по образцу, меняем `Grid.Row`, `Grid.Column` и текст:

```xml
<Button Grid.Row="2" Grid.Column="0" Text="4" FontSize="24" Clicked="OnDigit" />
<Button Grid.Row="2" Grid.Column="1" Text="5" FontSize="24" Clicked="OnDigit" />
<Button Grid.Row="2" Grid.Column="2" Text="6" FontSize="24" Clicked="OnDigit" />
<Button Grid.Row="2" Grid.Column="3" Text="×" FontSize="24" BackgroundColor="#F59E0B" Clicked="OnOperation" />

<Button Grid.Row="3" Grid.Column="0" Text="1" FontSize="24" Clicked="OnDigit" />
<Button Grid.Row="3" Grid.Column="1" Text="2" FontSize="24" Clicked="OnDigit" />
<Button Grid.Row="3" Grid.Column="2" Text="3" FontSize="24" Clicked="OnDigit" />
<Button Grid.Row="3" Grid.Column="3" Text="−" FontSize="24" BackgroundColor="#F59E0B" Clicked="OnOperation" />
```

Нижний ряд (0 C = +):

```xml
<Button Grid.Row="4" Grid.Column="0" Text="0" FontSize="24" Clicked="OnDigit" />
<Button Grid.Row="4" Grid.Column="1" Text="C" FontSize="24" BackgroundColor="#EF4444" TextColor="White" Clicked="OnClear" />
<Button Grid.Row="4" Grid.Column="2" Text="=" FontSize="24" BackgroundColor="#22C55E" TextColor="White" Clicked="OnEquals" />
<Button Grid.Row="4" Grid.Column="3" Text="+" FontSize="24" BackgroundColor="#F59E0B" Clicked="OnOperation" />
```

**Запусти.** Кнопки стоят ровной сеткой 4×4. Нажатия пока дают ошибку «метод не найден» — это нормально, идём в C#.

## Шаг 5. Три переменные-памяти

Открой `MainPage.xaml.cs`. Заведи **в классе** три переменные:

```csharp
namespace CalcApp;

public partial class MainPage : ContentPage
{
    string current = "";      // что набираем сейчас
    double stored = 0;        // запомненное первое число
    string op = "";           // операция: +, −, ×, ÷

    public MainPage()
    {
        InitializeComponent();
    }
}
```

## Шаг 6. Цифры (один метод на всех)

Внутри класса, ниже конструктора, добавь:

```csharp
private void OnDigit(object? sender, EventArgs e)
{
    Button b = (Button)sender!;   // какая кнопка нажата
    current += b.Text;            // добавили её цифру
    Display.Text = current;       // показали
}
```

- `sender` — «кто позвал метод», то есть нажатая кнопка;
- `(Button)sender` — говорим, что это кнопка, и берём её `Text`.

**Запусти.** Нажимай цифры — они набираются на экране. ✅

## Шаг 7. Операции и «=»

```csharp
private void OnOperation(object? sender, EventArgs e)
{
    if (current == "") return;
    stored = Convert.ToDouble(current);   // запомнили первое число
    op = ((Button)sender!).Text;          // запомнили знак
    current = "";                         // ждём второе число
}

private void OnEquals(object? sender, EventArgs e)
{
    if (current == "" || op == "") return;
    double second = Convert.ToDouble(current);
    double result = 0;
    switch (op)
    {
        case "+": result = stored + second; break;
        case "−": result = stored - second; break;
        case "×": result = stored * second; break;
        case "÷": result = second != 0 ? stored / second : 0; break;
    }
    result = Math.Round(result, 4);
    Display.Text = result.ToString();
    current = result.ToString();
    op = "";
}
```

**Запусти.** `12 + 8 =` → `20`. 🎉

## Шаг 8. Сброс «C»

```csharp
private void OnClear(object? sender, EventArgs e)
{
    current = "";
    stored = 0;
    op = "";
    Display.Text = "0";
}
```

**Проверь:** `7 × 6 =` (42), `9 − 4 =` (5), `8 ÷ 0 =` (0), потом `C` (снова 0).

## 🧩 Если что-то не собирается

| Ошибка | Причина | Что делать |
|--------|---------|-----------|
| кнопки налезли в один угол | забыл `Grid.Row`/`Grid.Column` | задай координаты каждой |
| кнопка не в той ячейке | нумерация с нуля | второй столбец — `Column="1"`, не `"2"` |
| «метод не найден» | имя в `Clicked` ≠ имя метода | сверь буква в букву |
| `Display` «не существует» | нет `x:Name="Display"` | добавь имя метке-экрану |
| экран не на всю ширину | нет `Grid.ColumnSpan="4"` | добавь span |
| `10÷3` длинный хвост | не округлил | `Math.Round(result, 4)` |

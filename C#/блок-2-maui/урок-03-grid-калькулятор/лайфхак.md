# 🧰 Лайфхаки и частые ошибки · Урок 3 (Блок 2) «Сетка Grid»

> Grid — про координаты. Большинство «граблей» тут — **нумерация с нуля** и **забытые `Grid.Row`/`Grid.Column`**. Здесь — что помогает.

---

## 💡 Трюки

1. **Нумерация с нуля.** Второй столбец — это `Column="1"`, третья строка — `Row="2"`. Как индексы массива. Промах на единицу — ошибка №1 урока.
2. **Забыл координаты — сел в (0,0).** Если у элемента нет `Grid.Row`/`Grid.Column`, он молча встаёт в левую верхнюю ячейку и накладывается на соседа. «Пропал» элемент — проверь координаты.
3. **Короткая запись размеров.** `RowDefinitions="100,70,70"` и `ColumnDefinitions="*,*,*,*"` — быстрее и понятнее «длинной» формы с `<RowDefinition>`. Пиши коротко.
4. **`*` делит место поровну.** Четыре `*,*,*,*` = четыре равные колонки. А `2*` даёт вдвое больше: `ColumnDefinitions="*,2*"` — второй столбец вдвое шире.
5. **`Auto` под содержимое.** Для строки-подписи или кнопки, которая должна быть «ровно по тексту», ставь `Auto`.
6. **Шапка через Span.** Заголовок/экран кладут в строку 0 и растягивают `Grid.ColumnSpan` на всю ширину — стандартный приём.
7. **Hot Reload для размеров.** Меняй `RowDefinitions`/`ColumnSpacing` при запущенном приложении — сетка перестраивается на лету. Удобно ловить пропорции.
8. **Один метод на много кнопок — `sender`.** `Button b = (Button)sender;` внутри обработчика даёт саму нажатую кнопку (её `Text`). Не нужно писать по методу на каждую цифру.
9. **Длинный хвост — `Math.Round`.** `10 ÷ 3` = `3,3333333…`. `Math.Round(result, 4)` оставит `3,3333`. (`Math` — из блока 1.)

## 🐞 Частые ошибки

| Что видишь | Причина | Лечение |
|-----------|---------|---------|
| элементы свалились в один угол | у них нет `Grid.Row`/`Grid.Column` | задай координаты каждому (по умолчанию 0,0) |
| элемент на одну ячейку не там | нумерация с нуля | второй столбец = `Column="1"` |
| кнопки «слиплись» | нет `RowSpacing`/`ColumnSpacing` | добавь зазоры (8–12) |
| экран не растянулся | нет `Grid.ColumnSpan` | `Grid.ColumnSpan="4"` |
| строк/столбцов не хватает | в `RowDefinitions`/`ColumnDefinitions` меньше, чем `Grid.Row`/`Column` у элементов | добавь нужное число строк/столбцов |
| «метод не найден» | имя в `Clicked` ≠ имя метода | сверь буква в букву |
| `Display` «не существует» | нет `x:Name` у экрана | добавь имя |
| `10÷3` = длинный хвост | не округлили | `Math.Round(result, 4)` |
| деление на 0 «ломает» | не защитили | `second != 0 ? stored/second : 0` |

## ✅ Чек «калькулятор готов»

1. Кнопки стоят **ровной сеткой** 4×4, экран — на всю ширину сверху.
2. Цифры набираются, `+ − × ÷` и `=` считают, `C` сбрасывает.
3. Деление на 0 не «ломает» приложение.
4. Ты можешь объяснить, что такое `Grid.Row`/`Grid.Column` и почему нумерация с нуля.

## 🧩 Мини-повторение из блока 1

Что выведет `switch`?
```csharp
string op = "+";
switch (op)
{
    case "+": Console.WriteLine("сложение"); break;
    case "-": Console.WriteLine("вычитание"); break;
}
```
*(Ответ: «сложение».)* Сегодня ровно такой `switch` посчитает результат в калькуляторе.

## ⚡ Что будет сегодня

## 🔮 Что выведет этот код? (повтор блока 1 + урока 2, на подумать)

Логика калькулятора сегодня — чистый C# из блока 1. Предскажи:

1.
```csharp
string op = "*";
switch (op) { case "+": Console.WriteLine("плюс"); break;
              default:  Console.WriteLine("другое"); break; }
```
2. Подковырка (как в калькуляторе):
```csharp
double r = Convert.ToDouble("10") / Convert.ToDouble("4");
Console.WriteLine(Math.Round(r, 2));
```
3. Подковырка (защита от ÷0):
```csharp
int a = 5, b = 0;
Console.WriteLine(b == 0 ? "нельзя" : (a / b).ToString());
```

<details><summary>✅ Ответы и почему</summary>

1. `другое` — ни один `case` не подошёл, сработал `default`.
2. `2,5` — оба `Convert.ToDouble` дали дробные → деление настоящее; `Math.Round(…,2)` = 2,5 (ru-RU запятая).
3. `нельзя` — тернарник проверил `b == 0` и не стал делить (иначе было бы падение).
</details>

## 🐞 Есть ли здесь ошибка? (или всё верно?)

1. `switch (op) { case "+": Console.WriteLine("плюс"); case "-": Console.WriteLine("минус"); }`
2. `double x = 10 / 4;` (ожидаем 2,5)
3. `int n = Convert.ToInt32("abc");`
4. `<VerticalStackLayout Spacing="20" Padding="16"> ... </VerticalStackLayout>`
5. `<Label Spacing="10" Text="Привет" />`

<details><summary>✅ Ответы</summary>

1. ❌ Нет `break;` после `case "+"` → ошибка «cannot fall through».
2. ⚠️ Подвох: `10 / 4` — целое деление = `2` (не 2,5). Нужно `10.0 / 4`.
3. ❌ Упадёт при запуске: «abc» не число (для ввода — `int.TryParse`).
4. ✅ Верно — `Spacing`/`Padding` есть у стека.
5. ❌ `Spacing` — свойство **стека**, а не `Label`.
</details>

> ⚙️ **Учителю.** Ключевая ловушка урока — **нумерация с нуля** (второй столбец = `Column="1"`) и «пропавший» элемент, у которого забыли координаты (он молча садится в ячейку 0,0). Блоки выше повторяют `switch`/`Convert`/деление (блок 1) и свойства стеков (урок 2) — логика калькулятора вся оттуда. Проговорите это заранее. Логика калькулятора вся из блока 1 (`switch`, тернарник, `Convert.ToDouble`, `Math.Round`) — это приятный момент «MAUI = тот же C#».

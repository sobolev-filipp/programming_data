## 🧩 Мини-повторение из блока 1

Что выведет `switch`?
```csharp
string op = "+";
switch (op)
{
    case "+": Console.WriteLine("сложение"); break;
    case "-": Console.WriteLine("вычитание"); break;
}
```
*(Ответ: «сложение».)* Сегодня ровно такой `switch` посчитает результат в калькуляторе.

## ⚡ Что будет сегодня

- Разберём макет **`Grid`** (сетка): строки, столбцы, ячейки.
- Научимся задавать размеры (`*`, `Auto`, число) и класть элемент по координатам (`Grid.Row`/`Grid.Column`).
- Растянем элемент на несколько ячеек (`ColumnSpan`).
- Соберём **«Калькулятор»** — кнопки сеткой + вычисление через `switch`.

> ⚙️ **Учителю.** Ключевая ловушка урока — **нумерация с нуля** (второй столбец = `Column="1"`) и «пропавший» элемент, у которого забыли координаты (он молча садится в ячейку 0,0). Проговорите это заранее. Хорошо зайдёт аналогия с игрой «морской бой» / шахматами (координаты клетки). У детей на Windows — **Windows Machine** + Hot Reload (менять размеры строк/столбцов вживую очень наглядно), у вас на Mac — VS Code + `dotnet build -t:Run -f net10.0-maccatalyst`. Логика калькулятора вся из блока 1 (`switch`, тернарник, `Convert.ToDouble`, `Math.Round`) — это приятный момент «MAUI = тот же C#».

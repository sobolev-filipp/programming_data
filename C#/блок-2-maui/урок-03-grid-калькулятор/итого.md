## Главная мысль

**`Grid`** — макет-**таблица**: строки (rows) и столбцы (columns). В каждую **ячейку** кладём элемент **по координатам**. Нумерация — **с нуля** (как индексы массива).

Бери `Grid`, когда элементы ложатся таблицей (кнопки калькулятора, форма, игровое поле). Для простого столбика/ряда хватит стека.

---

## Каркас сетки

```xml
<Grid RowDefinitions="100,70,70"
      ColumnDefinitions="*,*,*,*"
      RowSpacing="10" ColumnSpacing="10" Padding="16">
    ...
</Grid>
```

| Что | Значение |
|-----|----------|
| `RowDefinitions="100,70,70"` | 3 строки: 100, 70, 70 |
| `ColumnDefinitions="*,*,*,*"` | 4 равных столбца |
| число (`70`) | фиксированный размер |
| `*` | делит оставшееся место поровну (`2*` — вдвое больше) |
| `Auto` | по размеру содержимого |
| `RowSpacing`/`ColumnSpacing` | зазор между строками/столбцами |
| `Padding` | отступ от краёв сетки |

---

## Кладём элементы

```xml
<Label Text="0" Grid.Row="0" Grid.Column="0" Grid.ColumnSpan="4" />  <!-- на всю ширину -->
<Button Text="7" Grid.Row="1" Grid.Column="0" />
<Button Text="÷" Grid.Row="1" Grid.Column="3" />
```

| Свойство | Что делает |
|----------|-----------|
| `Grid.Row="1"` | строка 1 (вторая сверху) |
| `Grid.Column="3"` | столбец 3 (четвёртый слева) |
| `Grid.ColumnSpan="4"` | растянуть на 4 столбца |
| `Grid.RowSpan="2"` | растянуть на 2 строки |

> ⚠️ Забыл `Grid.Row`/`Grid.Column` → элемент садится в ячейку **(0,0)** и наложится на соседа.

## Логика калькулятора (вся из блока 1)

```csharp
string current = ""; double stored = 0; string op = "";

private void OnDigit(object? sender, EventArgs e)
{
    Button b = (Button)sender!;        // какая кнопка нажата
    current += b.Text;                 // добавить цифру
    Display.Text = current;
}
private void OnOperation(object? sender, EventArgs e)
{
    if (current == "") return;
    stored = Convert.ToDouble(current);
    op = ((Button)sender!).Text;
    current = "";
}
private void OnEquals(object? sender, EventArgs e)
{
    if (current == "" || op == "") return;
    double second = Convert.ToDouble(current);
    double result = 0;
    switch (op)                          // switch по операции
    {
        case "+": result = stored + second; break;
        case "−": result = stored - second; break;
        case "×": result = stored * second; break;
        case "÷": result = second != 0 ? stored / second : 0; break;
    }
    result = Math.Round(result, 4);      // подрезать длинный хвост
    Display.Text = result.ToString();
}
```

- **`sender`** — «кто позвал»: один метод на много кнопок.
- Внутри — знакомые `switch`, тернарник, `Convert.ToDouble`, `Math.Round`.

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| элементы налезли в один угол | забыл `Grid.Row`/`Grid.Column` | задай координаты (по умолчанию 0,0) |
| промах на одну ячейку | нумерация с нуля | второй столбец = `Column="1"` |
| кнопки «слиплись» | нет `RowSpacing`/`ColumnSpacing` | добавь зазоры |
| экран не на всю ширину | нет `ColumnSpan` | `Grid.ColumnSpan="4"` |
| `10÷3` — длинный хвост | не округлил | `Math.Round(result, 4)` |

## 📖 Справочник контролов урока (свойства · события · XAML/C#)

### `Grid` — сетка (таблица)
- **Свойства:** `RowDefinitions` — строки (напр. `"100,70,*"`) · `ColumnDefinitions` — столбцы (`"*,*,*,*"`; размеры: число / `*` / `2*` / `Auto`) · `RowSpacing`, `ColumnSpacing` — зазоры · `Padding` — от краёв · `BackgroundColor` · `x:Name`.
- **Присоединённые свойства (ставятся у элементов внутри сетки):** `Grid.Row`, `Grid.Column` (нумерация **с нуля**) · `Grid.RowSpan`, `Grid.ColumnSpan` (растянуть на несколько ячеек).
- **События:** нет (контейнер).
- **XAML:**
  ```xml
  <Grid RowDefinitions="Auto,*" ColumnDefinitions="*,*" RowSpacing="8" ColumnSpacing="8">
      <Label Grid.Row="0" Grid.Column="0" Grid.ColumnSpan="2" Text="Заголовок" />
      <Button Grid.Row="1" Grid.Column="1" Text="OK" />
  </Grid>
  ```
- **C#:** `Grid.SetRow(label, 0); Grid.SetColumn(label, 1);` (задать ячейку из кода).

### Приём: один обработчик на много кнопок — `sender`
- В любом обработчике `sender` — тот элемент, что вызвал событие. Приводим и берём свойства:
  `Button b = (Button)sender!;  string t = b.Text;`

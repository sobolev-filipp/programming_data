1. Что такое `Entry` и как прочитать введённое? (`Entry.Text`)

4. С какого числа начинается индекс массива (блок 1)? (**с нуля** — как `SelectedIndex` у списка)
5. Что такое `DateTime` и как его форматируют (блок 1)? (дата/время; `:dd.MM.yyyy`)

## 🧩 Мини-повторение из блока 1

Что выведет код?
```csharp
double x = 7.8;
int n = (int)x;
Console.WriteLine(n);
```
*(Ответ: 7 — дробь отброшена.)* Сегодня так же превратим `Slider.Value` в целое число.

## 🔮 Что выведет этот код? (повтор блока 1 + урока 4, на подумать)

Предскажи вывод, **не запуская**:

1. `double v = 6.9; Console.WriteLine((int)v);`
2. Подковырка (индекс как `SelectedIndex`):
```csharp
int[] prices = { 300, 450, 600 };
int idx = 1;
Console.WriteLine(prices[idx]);
```
3. `string text = "Аня"; Console.WriteLine($"Привет, {text}! ({text.Length} букв)");`

<details><summary>✅ Ответы и почему</summary>

1. `6` — приведение `(int)` **отбрасывает** дробь (так же превратим `Slider.Value`).
2. `450` — `prices[1]` это **второй** элемент (счёт с 0). Так цена берётся по `SelectedIndex`.
3. `Привет, Аня! (3 букв)` — интерполяция вставила имя и его длину.
</details>

## 🐞 Есть ли здесь ошибка? (или всё верно?)

1. `int price = prices[SizePicker.SelectedIndex];` (ничего не выбрали в `Picker`)
2. `int spicy = SpicySlider.Value;`
3. `if (int.TryParse(AgeEntry.Text, out int a)) { ... }`
4. `string name = NameEntry.Text; if (string.IsNullOrWhiteSpace(name)) { ... }`
5. `DateTime d = OrderDate.Date;` (.NET 10)

<details><summary>✅ Ответы</summary>

1. ⚠️ Пока не выбрали, `SelectedIndex` = **−1** → `prices[-1]` уронит приложение. Сначала проверь `== -1`.
2. ❌ `Value` — это `double`; нужно привести: `int spicy = (int)SpicySlider.Value;`.
3. ✅ Верно.
4. ✅ Верно.
5. ❌ В .NET 10 `Date` — это `DateTime?`; бери `OrderDate.Date ?? DateTime.Today`.
</details>

> ⚙️ **Учителю.** Урок наглядный и «щёлкательный» — дети любят двигать ползунки. Блоки выше повторяют приведение `(int)` и индекс-массив (блок 1), `Entry`/`TryParse` (урок 4) и подводят к `SelectedIndex == -1` и `Date ?? DateTime.Today`. Три сквозные вещи проговорить заранее: (1) `Slider`/`Stepper` дают `Value` типа **double** — для целого числа приводим `(int)` (мостик к блоку 1); (2) у `Picker` `SelectedIndex` = **−1**, пока не выбрали — обязательно проверять; (3) `SelectedIndex` удобно использовать как индекс массива (цены по размеру). У детей — Windows Machine + Hot Reload; у вас — Mac VS Code + `dotnet build -t:Run -f net10.0-maccatalyst`. Живые метки (`ValueChanged`) очень заходят — покажите первыми.

# 🔁 Разминка (5 минут) · Блок 2, Урок 5

> В прошлый раз человек **печатал** текст в `Entry`. Сегодня научимся принимать **выбор** без печати: переключатели, ползунки, списки. Сначала вспомним.

## 🎤 Блиц-вопросы (устно, 3 мин)

1. Что такое `Entry` и как прочитать введённое? (`Entry.Text`)
2. Что такое `bool` и какие у него значения? (`true`/`false`)
3. Что делает приведение `(int)6.9`? (отбрасывает дробь → 6) — сегодня пригодится для ползунков!
4. С какого числа начинается индекс массива (блок 1)? (**с нуля** — как `SelectedIndex` у списка)
5. Что такое `DateTime` и как его форматируют (блок 1)? (дата/время; `:dd.MM.yyyy`)

## 🧩 Мини-повторение из блока 1

Что выведет код?
```csharp
double x = 7.8;
int n = (int)x;
Console.WriteLine(n);
```
*(Ответ: 7 — дробь отброшена.)* Сегодня так же превратим `Slider.Value` в целое число.

## ⚡ Что будет сегодня

- Контролы **выбора**: `Switch`, `CheckBox` (да/нет), `Slider`, `Stepper` (число), `Picker` (список), `DatePicker` (дата).
- Чтение выбранного: `IsToggled`, `IsChecked`, `Value`, `SelectedIndex`, `Date`.
- Новые события: `Toggled`, `ValueChanged`, `SelectedIndexChanged` — и «живые» подписи.
- Приложение **«Собери пиццу»** — из выбранного считаем цену.

> ⚙️ **Учителю.** Урок наглядный и «щёлкательный» — дети любят двигать ползунки. Три сквозные вещи проговорить заранее: (1) `Slider`/`Stepper` дают `Value` типа **double** — для целого числа приводим `(int)` (мостик к блоку 1); (2) у `Picker` `SelectedIndex` = **−1**, пока не выбрали — обязательно проверять; (3) `SelectedIndex` удобно использовать как индекс массива (цены по размеру). У детей — Windows Machine + Hot Reload; у вас — Mac VS Code + `dotnet build -t:Run -f net10.0-maccatalyst`. Живые метки (`ValueChanged`) очень заходят — покажите первыми.

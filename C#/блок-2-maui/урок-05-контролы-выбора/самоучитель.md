## 📚 Что мы делаем

Приложение **«Собери пиццу»**: человек выбирает размер, количество, добавки — контролами (переключатели, ползунки, список), а приложение считает цену. Учимся принимать **выбор** без печати.

---

## Шаг 0. Идея

- **Контрол выбора** = **значение** (что выбрано) + **событие** (когда поменяли).
- Читаем значение так же, как читали `Entry.Text`: `Switch.IsToggled`, `Slider.Value`, `Picker.SelectedIndex` и т.д.

## Шаг 4. Количество — Stepper с живой меткой

```xml
<Label x:Name="QtyLabel" Text="Количество: 1" FontSize="16" />
<Stepper x:Name="QtyStepper" Minimum="1" Maximum="10" Increment="1" Value="1"
         ValueChanged="OnQtyChanged" HorizontalOptions="Center" />
```

Теперь код: открой `MainPage.xaml.cs`, внутри класса добавь метод:

```csharp
private void OnQtyChanged(object? sender, ValueChangedEventArgs e)
{
    QtyLabel.Text = $"Количество: {(int)e.NewValue}";
}
```

- `Value`/`e.NewValue` — **дробные** (`double`), поэтому `(int)` для целого.

**Запусти.** Жми ± — число рядом меняется. ✅

## Шаг 9. Считаем заказ

В `MainPage.xaml.cs` добавь:

```csharp
private void OnOrder(object? sender, EventArgs e)
{
    if (SizePicker.SelectedIndex == -1)
    {
        ResultLabel.Text = "Сначала выбери размер пиццы!";
        return;
    }

    int[] prices = { 300, 450, 600 };
    int basePrice = prices[SizePicker.SelectedIndex];
    int qty = (int)QtyStepper.Value;
    int total = basePrice * qty;

    if (CheeseSwitch.IsToggled) total += 50 * qty;
    if (DeliveryCheck.IsChecked) total += 150;

    int spicy = (int)SpicySlider.Value;
    DateTime date = OrderDate.Date ?? DateTime.Today;   // Date — DateTime?; ?? = «нет даты → сегодня»
    ResultLabel.Text = $"{SizePicker.SelectedItem} ×{qty}, острота {spicy}/10\n"
                     + $"Дата: {date:dd.MM.yyyy}\n"
                     + $"Итого: {total} ₽";
}
```

Что происходит:
1. проверяем, что размер выбран (`SelectedIndex != -1`);
2. по индексу берём цену из массива, умножаем на количество;
3. прибавляем сыр и доставку по условиям;
4. собираем итог с датой.

**Запусти и проверь:** разные размеры/количества; сыр вкл/выкл; доставка; и случай «не выбрал размер».

> ✅ Весь C# целиком — в [материалы/MainPage.xaml.cs](материалы/MainPage.xaml.cs).

## 🧩 Если что-то не собирается

| Ошибка | Причина | Что делать |
|--------|---------|-----------|
| падает при «Оформить» | не проверил `SelectedIndex == -1` | добавь проверку до чтения выбора |
| количество дробное (1,0) | `Value` — `double` | приведи `(int)` |
| живая метка молчит | неверный параметр обработчика | `ValueChanged` → `ValueChangedEventArgs e` |
| `SizePicker`/`CheeseSwitch` «не существует» | нет `x:Name` | добавь имя контролу |
| «метод не найден» | имя события ≠ имя метода | сверь буква в букву |
| контрол без подписи | у него нет текста | поставь рядом `Label` |

# 🧰 Лайфхаки и частые ошибки · Урок 5 (Блок 2) «Контролы выбора»

> Контролы выбора — про «значение + событие». Главные «грабли»: `SelectedIndex = -1`, `Value` типа `double`, и контрол без подписи. Здесь — что помогает.

---

## 💡 Трюки

1. **Значение читаем как `Entry.Text`.** У каждого контрола своё свойство: `IsToggled`, `IsChecked`, `Value`, `SelectedIndex`, `Date`. Прочитал — работай как в блоке 1.
2. **`SelectedIndex == -1` — «не выбрали».** У `Picker` пока ничего не выбрано, индекс равен −1. Всегда проверяй **до** использования, иначе `prices[-1]` уронит приложение.
3. **`Value` — это `double`.** У `Slider` и `Stepper` значение дробное. Нужно целое (количество, уровень) — приводи `(int)Value`.
4. **Индекс как ключ к данным.** `SelectedIndex` (0,1,2…) — готовый индекс массива: `prices[SelectedIndex]`, `names[SelectedIndex]`. Мощный приём из блока 1.
5. **Подпись — рядом.** У `Switch`/`CheckBox`/`Slider` нет своего текста. Ставь `Label` рядом в `HorizontalStackLayout` (урок 2), чтобы было понятно, за что отвечает контрол.
6. **Живые метки — `ValueChanged`.** Показывай значение ползунка/степпера на лету: в обработчике бери `e.NewValue`.
7. **Начальное значение и границы.** `Stepper`/`Slider`: задавай `Minimum`, `Maximum`, стартовое `Value`, у степпера ещё `Increment` (шаг). Иначе поведение неожиданное.
8. **`Picker` можно наполнять из кода.** Кроме `<Picker.Items>` в XAML, список можно задать `ItemsSource` из C# (пригодится в уроках про списки).
9. **`DatePicker.Date` — `DateTime?` (в .NET 10).** Дата может быть «не выбрана», поэтому бери `DateTime d = OrderDate.Date ?? DateTime.Today;` — и дальше это обычный `DateTime` из блока 1 (`.Day`, `.DayOfWeek`, `:dd.MM.yyyy`, `AddDays`, разность дат). Оператор `??` — та же страховка, что `?? ""` для пустого поля в уроке 4. Можно ограничить `MinimumDate`/`MaximumDate`.
10. **`Switch` vs `CheckBox`.** Оба — да/нет. `Switch` привычнее для «настроек» (вкл/выкл), `CheckBox` — для «согласия»/«галочки в списке». Свойства разные: `IsToggled` и `IsChecked`.

## 🐞 Частые ошибки

| Что видишь | Причина | Лечение |
|-----------|---------|---------|
| падает при чтении выбора | `SelectedIndex = -1` (не выбрали) | проверь `if (SelectedIndex == -1) return;` |
| число получилось дробным (2,0) | `Value` — `double` | приведи `(int)Value` |
| живая метка не обновляется | не тот параметр обработчика | `ValueChanged` → `ValueChangedEventArgs e`, `e.NewValue` |
| путаю `IsToggled`/`IsChecked` | у `Switch` одно, у `CheckBox` другое | `Switch.IsToggled`, `CheckBox.IsChecked` |
| контрол «непонятный» | нет подписи | добавь рядом `Label` |
| нет `.AddDays`/`.DayOfWeek` у `DatePicker.Date` | `Date` — это `DateTime?` | сперва `Date ?? DateTime.Today` |
| `SizePicker` «не существует» | нет `x:Name` | добавь имя |
| «метод не найден» | имя события ≠ метод | сверь буква в букву |

## ✅ Чек «пицца готова»

1. Все контролы работают: список, ±, тумблер, ползунок (живая метка), галочка, дата.
2. Кнопка считает цену; «не выбрал размер» → вежливая просьба, без вылета.
3. Ты можешь назвать свойство-значение и событие для каждого контрола.
4. Понимаешь, почему `Value` приводим к `(int)` и что значит `SelectedIndex == -1`.

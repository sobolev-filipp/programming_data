# Урок 5 (Блок 2) «Контролы выбора» — итого (шпаргалка) 📌

> Открой, чтобы за 3 минуты вспомнить контролы выбора. Имена элементов и методов — по-английски.

---

## Главная мысль

**Контрол выбора = значение (что выбрано) + событие (когда поменяли).** Человек выбирает мышью/пальцем — мы читаем значение, как читали `Entry.Text`.

| Контрол | Значение (читаем) | Тип | Событие |
|---------|-------------------|-----|---------|
| `Switch` | `IsToggled` | bool | `Toggled` |
| `CheckBox` | `IsChecked` | bool | `CheckedChanged` |
| `Slider` | `Value` | double | `ValueChanged` |
| `Stepper` | `Value` | double | `ValueChanged` |
| `Picker` | `SelectedIndex` / `SelectedItem` | int / object | `SelectedIndexChanged` |
| `DatePicker` | `Date` | DateTime? | `DateSelected` |

---

## В XAML

```xml
<Switch x:Name="CheeseSwitch" />
<CheckBox x:Name="DeliveryCheck" />
<Slider x:Name="SpicySlider" Minimum="0" Maximum="10" ValueChanged="OnSpicyChanged" />
<Stepper x:Name="QtyStepper" Minimum="1" Maximum="10" Increment="1" Value="1" ValueChanged="OnQtyChanged" />
<Picker x:Name="SizePicker" Title="Выбери размер">
    <Picker.Items>
        <x:String>Маленькая</x:String>
        <x:String>Средняя</x:String>
        <x:String>Большая</x:String>
    </Picker.Items>
</Picker>
<DatePicker x:Name="OrderDate" />
```

---

## Читаем из кода

```csharp
bool cheese = CheeseSwitch.IsToggled;
bool delivery = DeliveryCheck.IsChecked;
int qty = (int)QtyStepper.Value;          // Value — double! приводим (int)
int spicy = (int)SpicySlider.Value;
DateTime date = OrderDate.Date ?? DateTime.Today;   // Date — DateTime?; ?? даёт запасное значение

if (SizePicker.SelectedIndex == -1) { /* не выбрали! */ return; }
int[] prices = { 300, 450, 600 };
int price = prices[SizePicker.SelectedIndex];   // индекс как ключ массива
string size = SizePicker.SelectedItem.ToString();
```

## Живая подпись (ValueChanged)

```csharp
private void OnSpicyChanged(object? sender, ValueChangedEventArgs e)
{
    SpicyLabel.Text = $"Острота: {(int)e.NewValue}/10";   // e.NewValue — новое значение
}
```

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| приложение падает / берёт не то | не проверил `SelectedIndex == -1` | сначала проверь, что выбрали |
| дробное число вместо целого | `Value` — это `double` | приведи `(int)Value` |
| живая метка не работает | не тот параметр обработчика | `ValueChanged` → `ValueChangedEventArgs e`, `e.NewValue` |
| контрол «без подписи» | у него нет текста внутри | поставь рядом `Label` |
| не работает `.AddDays`/`.DayOfWeek` у даты | `Date` — это `DateTime?` | сначала `Date ?? DateTime.Today` |
| `SizePicker` «не существует» | нет `x:Name` | добавь имя |

## 📖 Справочник контролов урока (свойства · события · XAML/C#)

### `Switch` — тумблер (да/нет)
- **Свойства:** `IsToggled` (bool) · `OnColor` — цвет во включённом виде · `ThumbColor` — цвет «бегунка» · `IsEnabled`.
- **События:** `Toggled` (`sender` = `Switch`, `e` = `ToggledEventArgs` → `e.Value`).
- **XAML:** `<Switch x:Name="CheeseSwitch" Toggled="OnToggled" />`
- **C#:** `void OnToggled(object? sender, ToggledEventArgs e) { bool on = e.Value; }`

### `CheckBox` — галочка (да/нет)
- **Свойства:** `IsChecked` (bool) · `Color` — цвет галочки · `IsEnabled`.
- **События:** `CheckedChanged` (`e` = `CheckedChangedEventArgs` → `e.Value`).
- **XAML:** `<CheckBox x:Name="DeliveryCheck" CheckedChanged="OnChecked" />`
- **C#:** `bool delivery = DeliveryCheck.IsChecked;`

### `Slider` — ползунок (число из диапазона)
- **Свойства:** `Value` (**double**) · `Minimum`, `Maximum` (double) · `MinimumTrackColor`, `MaximumTrackColor`, `ThumbColor`.
- **События:** `ValueChanged` (`e` = `ValueChangedEventArgs` → `e.NewValue`, `e.OldValue`); `DragStarted`, `DragCompleted`.
- **XAML:** `<Slider x:Name="SpicySlider" Minimum="0" Maximum="10" ValueChanged="OnSpicy" />`
- **C#:** `void OnSpicy(object? sender, ValueChangedEventArgs e) { int v = (int)e.NewValue; }`

### `Stepper` — число кнопками ±
- **Свойства:** `Value` (**double**) · `Minimum`, `Maximum` · `Increment` — шаг · `IsEnabled`.
- **События:** `ValueChanged` (`ValueChangedEventArgs` → `e.NewValue`, `e.OldValue`).
- **XAML:** `<Stepper x:Name="QtyStepper" Minimum="1" Maximum="10" Increment="1" ValueChanged="OnQty" />`
- **C#:** `int qty = (int)QtyStepper.Value;`

### `Picker` — выбор одного из списка
- **Свойства:** `Title` — подсказка · `SelectedIndex` (int, **−1** если не выбрали) · `SelectedItem` (object) · `ItemsSource` (список из кода) или `<Picker.Items>` (в XAML) · `TextColor`, `TitleColor`, `FontSize`.
- **События:** `SelectedIndexChanged` (`sender` = `Picker`, `e` = `EventArgs`).
- **XAML:**
  ```xml
  <Picker x:Name="SizePicker" Title="Размер" SelectedIndexChanged="OnSize">
      <Picker.Items>
          <x:String>Маленькая</x:String>
          <x:String>Средняя</x:String>
      </Picker.Items>
  </Picker>
  ```
- **C#:** `if (SizePicker.SelectedIndex != -1) { var item = SizePicker.SelectedItem; }`

### `DatePicker` — выбор даты
- **Свойства:** `Date` (**`DateTime?`** в .NET 10 → бери `Date ?? DateTime.Today`) · `MinimumDate`, `MaximumDate` (DateTime) · `Format` — напр. `"dd.MM.yyyy"` · `TextColor`, `FontSize`.
- **События:** `DateSelected` (`sender` = `DatePicker`, `e` = `DateChangedEventArgs` → `e.NewDate`, `e.OldDate` — тоже `DateTime?`).
- **XAML:** `<DatePicker x:Name="OrderDate" Format="dd.MM.yyyy" DateSelected="OnDate" />`
- **C#:** `DateTime d = OrderDate.Date ?? DateTime.Today;`

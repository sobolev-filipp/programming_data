# Урок 6 (Блок 2) «Стили и ресурсы» — итого (шпаргалка) 📌

> Открой, чтобы за 3 минуты вспомнить стили и оформление. Имена ресурсов — по-английски.

---

## Главная мысль

**Оформление описываем ОДИН раз → используем МНОГО раз → меняем в ОДНОМ месте.** Вместо повтора `FontSize`/`TextColor` у каждого элемента — ресурс или стиль по имени.

| Инструмент | Что это | Как берём |
|-----------|---------|-----------|
| ресурс (`<Color>`, `<x:Double>`) | одно именованное значение | `{StaticResource Имя}` |
| явный `Style` (`x:Key`) | набор свойств под именем | `Style="{StaticResource Имя}"` |
| неявный `Style` (без `x:Key`) | оформляет ВСЕ элементы `TargetType` | применяется сам |
| `App.xaml` | те же ресурсы для ВСЕХ страниц | `{StaticResource ...}` везде |

**Приоритет:** свойство на элементе > явный стиль > неявный стиль.

---

## Ресурсы (в словаре)

```xml
<ContentPage.Resources>
    <ResourceDictionary>
        <Color x:Key="Brand">#6F4E37</Color>
        <x:Double x:Key="TitleSize">22</x:Double>
    </ResourceDictionary>
</ContentPage.Resources>
```
```xml
<Label TextColor="{StaticResource Brand}" FontSize="{StaticResource TitleSize}" />
```

## Стиль

```xml
<Style x:Key="DishTitle" TargetType="Label">
    <Setter Property="FontSize" Value="22" />
    <Setter Property="FontAttributes" Value="Bold" />
    <Setter Property="TextColor" Value="{StaticResource Brand}" />
</Style>
```
```xml
<Label Text="Капучино" Style="{StaticResource DishTitle}" />
```

## Неявный стиль (без x:Key — цепляет всех)

```xml
<Style TargetType="Label">
    <Setter Property="TextColor" Value="#3A2A1A" />
</Style>
```

## Border (карточка) и Image

```xml
<Border Stroke="#E5D5C5" StrokeThickness="1" Background="#FFFFFF"
        Padding="16" StrokeShape="RoundRectangle 14">
    <VerticalStackLayout> ... </VerticalStackLayout>
</Border>

<Image Source="dotnet_bot.png" HeightRequest="90" Aspect="AspectFit" />
```

## Глобальная тема (App.xaml) и свет/тьма

```xml
<!-- App.xaml -->
<Application.Resources>
    <ResourceDictionary>
        <Color x:Key="Brand">#6F4E37</Color>
        <Style TargetType="Label"> ... </Style>
    </ResourceDictionary>
</Application.Resources>
```
```xml
<Label TextColor="{AppThemeBinding Light=#3A2A1A, Dark=#FFF8F0}" />
```

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| `StaticResource ... not found` | опечатка в имени / ресурс объявлен ниже | имя ресурса точь-в-точь; объявляй в `Resources` |
| стиль «не применился» | забыл `Style="{StaticResource ...}"` или не тот `TargetType` | `TargetType` = тип элемента; проверь ссылку |
| ВСЕ метки вдруг перекрасились | неявный стиль `Label` задел всех | для особенных — явный стиль с `x:Key` |
| `Border` пустой/ошибка | внутри больше одного элемента | у `Border` ровно ОДИН ребёнок (заверни в стек) |
| углы не скруглились | нет `StrokeShape` | `StrokeShape="RoundRectangle 14"` |
| картинка не видна | имя с пробелом/кириллицей, не в `Resources/Images` | латиница, положить в `Resources/Images`, писать только имя |
| глобальный ресурс не виден | объявлен на странице, а нужен везде | перенести в `App.xaml` |

## 📖 Справочник контролов урока (свойства · события · XAML/C#)

### `ResourceDictionary` — словарь ресурсов
- **Где:** `<ContentPage.Resources>` (одна страница) или `<Application.Resources>` в `App.xaml` (всё приложение).
- **Что кладём:** `<Color x:Key>`, `<x:Double x:Key>`, `<x:String x:Key>`, `<Style x:Key>`; чужие словари — через `<ResourceDictionary.MergedDictionaries>`.
- **XAML:** `<ResourceDictionary><Color x:Key="Brand">#6F4E37</Color></ResourceDictionary>`
- **Берём:** `{StaticResource Brand}`.

### `Style` — набор свойств
- **Свойства (атрибуты):** `x:Key` — имя (у неявного нет) · `TargetType` — тип элемента (обязателен) · `BasedOn="{StaticResource ...}"` — наследовать от другого стиля.
- **Внутри:** `<Setter Property="..." Value="..." />` — по одному на каждое свойство; в `Value` можно `{StaticResource ...}`.
- **XAML:**
  ```xml
  <Style x:Key="PriceTag" TargetType="Label">
      <Setter Property="TextColor" Value="#B5651D" />
      <Setter Property="FontAttributes" Value="Bold" />
  </Style>
  ```
- **Применяем:** `<Label Style="{StaticResource PriceTag}" />` (у неявного — автоматически ко всем `Label`).

### `Border` — рамка-карточка
- **Свойства:** `Stroke` — цвет рамки · `StrokeThickness` (double) — толщина · `Background` — заливка · `StrokeShape` — форма (`RoundRectangle 14` / `Rectangle` / `Ellipse`) · `Padding` — отступ до содержимого · `StrokeDashArray` — пунктир · `WidthRequest`/`HeightRequest`.
- **Содержимое:** ровно **один** дочерний элемент (внутри — стек/`Grid`).
- **События:** особых нет (оформление через свойства/`Style`).
- **XAML:** `<Border Style="{StaticResource CardStyle}"> <VerticalStackLayout>…</VerticalStackLayout> </Border>`
- **C#:** `myBorder.Stroke = Colors.Gray;  myBorder.Padding = new Thickness(16);`

### `Image` — картинка
- **Свойства:** `Source` — имя файла из `Resources/Images` (латиницей) или URL · `Aspect` — `AspectFit`/`AspectFill`/`Fill` · `HeightRequest`/`WidthRequest` · `Opacity` · `IsAnimationPlaying` (gif).
- **События:** своих событий выбора нет (клик — жестом, позже).
- **XAML:** `<Image Source="logo.png" HeightRequest="90" Aspect="AspectFit" />`
- **C#:** `logo.Source = "logo.png";`

### `AppThemeBinding` — значение под тему (бонус)
- **Что:** подставляет разные значения для светлой/тёмной темы.
- **XAML:** `TextColor="{AppThemeBinding Light=#3A2A1A, Dark=#FFF8F0}"`

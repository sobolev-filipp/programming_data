# Самоучитель к уроку 6 (Блок 2). Стили и ресурсы — «Меню кафе» с нуля ☕

> Пропустил урок или собираешь дома? Ничего страшного. Здесь мы **с самого начала** соберём меню кафе и по дороге разберём стили. Иди по шагам, не пропуская. После каждого шага **запускай** и смотри на экран.

---

## Что нам понадобится

- Установленная среда (Visual Studio на Windows или VS Code + `dotnet` на Mac) — как в уроке 1.
- Новый проект **.NET MAUI App**. Назовём его, например, `CafeApp`.
  - VS: *Create a new project → .NET MAUI App → CafeApp*.
  - Mac/VS Code: в терминале `dotnet new maui -o CafeApp`, затем открой папку.

Мы будем править всего два файла: `MainPage.xaml` (внешность) и `MainPage.xaml.cs` (логика). Иногда заглянем в `App.xaml`.

---

## Идея урока в одном предложении

Раньше мы у **каждого** элемента писали цвет и размер отдельно. Сегодня научимся описывать оформление **один раз** и применять ко многим элементам. Это называется **стили и ресурсы**.

---

## Шаг 1. Пустая страница с фоном

Открой `MainPage.xaml` и замени всё содержимое на это:

```xml
<?xml version="1.0" encoding="utf-8" ?>
<ContentPage xmlns="http://schemas.microsoft.com/dotnet/2021/maui"
             xmlns:x="http://schemas.microsoft.com/winfx/2009/xaml"
             x:Class="CafeApp.MainPage"
             BackgroundColor="#FFF8F0">
    <VerticalStackLayout Padding="20" Spacing="16">
        <Label Text="Кафе Уют" FontSize="22" />
    </VerticalStackLayout>
</ContentPage>
```

Запусти. Должна появиться кремовая страница с надписью. Пока всё как в прошлых уроках — цвет и размер прописаны прямо у элементов.

> Если `x:Class` у тебя не `CafeApp.MainPage` — не трогай его, оставь как было в твоём проекте (там имя твоего проекта).

---

## Шаг 2. Первый ресурс — цвет с именем

Сейчас цвет `#FFF8F0` «спрятан» в атрибуте. Вынесем его в **ресурс** — значение с именем. Добавь блок `<ContentPage.Resources>` сразу после строки с `x:Class`/`BackgroundColor`:

```xml
    <ContentPage.Resources>
        <ResourceDictionary>
            <Color x:Key="PageBg">#FFF8F0</Color>
            <Color x:Key="Brand">#6F4E37</Color>
        </ResourceDictionary>
    </ContentPage.Resources>
```

Теперь используем ресурсы по имени. Поменяй строку страницы и метку:

```xml
<ContentPage ... BackgroundColor="{StaticResource PageBg}">
    ...
    <Label Text="Кафе Уют" FontSize="22" TextColor="{StaticResource Brand}" />
```

Запусти — вид тот же, но теперь цвета живут в одном месте. **Проверь силу ресурса:** поменяй `Brand` на `#0066CC` — надпись посинеет. Верни коричневый.

> 💡 `{StaticResource Имя}` = «подставь сюда значение ресурса с этим именем».

---

## Шаг 3. Стиль — набор свойств

У заголовка обычно не один параметр, а несколько: размер, жирность, цвет. Соберём их в **стиль**. Добавь в `<ResourceDictionary>` (рядом с цветами):

```xml
<Style x:Key="DishTitle" TargetType="Label">
    <Setter Property="FontSize" Value="22" />
    <Setter Property="FontAttributes" Value="Bold" />
    <Setter Property="TextColor" Value="{StaticResource Brand}" />
</Style>
```

И примени к метке — теперь у неё вместо трёх атрибутов один `Style`:

```xml
<Label Text="Кафе Уют" Style="{StaticResource DishTitle}" HorizontalOptions="Center" />
```

Запусти. Заголовок жирный, кофейный, крупный — а в разметке чисто.

> `TargetType="Label"` — стиль для меток. Без него будет ошибка.

---

## Шаг 4. Карточка блюда — Border

Блюда покажем **карточками**. Карточка — это `Border` (рамка с фоном и скруглением), внутри стек с текстом. Добавь внутрь `VerticalStackLayout` (под заголовком):

```xml
<Border Stroke="#E5D5C5" StrokeThickness="1" Background="White"
        Padding="16" StrokeShape="RoundRectangle 14">
    <VerticalStackLayout Spacing="4">
        <Label Text="Капучино" Style="{StaticResource DishTitle}" />
        <Label Text="Нежная молочная пенка на эспрессо." />
        <Label Text="180 ₽" />
    </VerticalStackLayout>
</Border>
```

Запусти — появилась белая карточка со скруглёнными углами.

> ⚠️ Внутри `Border` — **ровно один** элемент. Поэтому три метки мы завернули в `VerticalStackLayout`.

---

## Шаг 5. Стиль карточки + стиль цены (главный шаг!)

Сейчас у `Border` пять атрибутов оформления. А карточек будет много — не писать же это каждый раз. Вынесем в стиль. Добавь в `<ResourceDictionary>`:

```xml
<Style x:Key="CardStyle" TargetType="Border">
    <Setter Property="Background" Value="White" />
    <Setter Property="Stroke" Value="#E5D5C5" />
    <Setter Property="StrokeThickness" Value="1" />
    <Setter Property="Padding" Value="16" />
    <Setter Property="StrokeShape" Value="RoundRectangle 14" />
</Style>

<Style x:Key="PriceTag" TargetType="Label">
    <Setter Property="TextColor" Value="#B5651D" />
    <Setter Property="FontAttributes" Value="Bold" />
</Style>
```

Теперь у карточки — один атрибут, у цены — один:

```xml
<Border Style="{StaticResource CardStyle}">
    <VerticalStackLayout Spacing="4">
        <Label Text="Капучино" Style="{StaticResource DishTitle}" />
        <Label Text="Нежная молочная пенка на эспрессо." />
        <Label Text="180 ₽" Style="{StaticResource PriceTag}" />
    </VerticalStackLayout>
</Border>
```

Запусти — вид тот же, но код готов к копированию.

---

## Шаг 6. Ещё две карточки — почувствуй экономию

Скопируй карточку **дважды** и поменяй только текст:

```xml
<Border Style="{StaticResource CardStyle}">
    <VerticalStackLayout Spacing="4">
        <Label Text="Чизкейк" Style="{StaticResource DishTitle}" />
        <Label Text="Классический десерт из сливочного сыра." />
        <Label Text="250 ₽" Style="{StaticResource PriceTag}" />
    </VerticalStackLayout>
</Border>

<Border Style="{StaticResource CardStyle}">
    <VerticalStackLayout Spacing="4">
        <Label Text="Круассан" Style="{StaticResource DishTitle}" />
        <Label Text="Хрустящий, с шоколадной начинкой." />
        <Label Text="120 ₽" Style="{StaticResource PriceTag}" />
    </VerticalStackLayout>
</Border>
```

Запусти — три одинаково красивые карточки, а оформление писали **один раз**. Вот ради этого весь урок.

**Проверь магию:** поменяй в `CardStyle` `RoundRectangle 14` на `RoundRectangle 26` — округлятся **все три** карточки сразу.

## Шаг 7. Логотип и прокрутка

Добавь картинку над заголовком и оберни всё в `ScrollView` (чтобы длинное меню прокручивалось). Оберни `VerticalStackLayout` так:

```xml
<ScrollView>
    <VerticalStackLayout Padding="20" Spacing="16">
        <Image Source="dotnet_bot.png" HeightRequest="90" Aspect="AspectFit" />
        <Label Text="☕ Кафе «Уют»" Style="{StaticResource DishTitle}" HorizontalOptions="Center" />
        <!-- твои три карточки -->
    </VerticalStackLayout>
</ScrollView>
```

`dotnet_bot.png` уже лежит в проекте (`Resources/Images`). Запусти — сверху робот, ниже меню, всё крутится.

## Шаг 8. Немного логики — номер стола (по желанию)

Добавь под карточками:

```xml
<Label x:Name="TableLabel" Text="Стол: 1" />
<Stepper x:Name="TableStepper" Minimum="1" Maximum="20" Increment="1" Value="1"
         ValueChanged="OnTableChanged" HorizontalOptions="Center" />
<Button Text="Позвать официанта" Clicked="OnCall" />
<Label x:Name="ResultLabel" Style="{StaticResource PriceTag}" HorizontalOptions="Center" />
```

Открой `MainPage.xaml.cs` и добавь два метода в класс:

```csharp
private void OnTableChanged(object? sender, ValueChangedEventArgs e)
{
    TableLabel.Text = $"Стол: {(int)e.NewValue}";
}

private void OnCall(object? sender, EventArgs e)
{
    int table = (int)TableStepper.Value;
    ResultLabel.Text = $"Официант идёт к столу №{table}";
}
```

> Это повтор урока 5: `Stepper` даёт `double`, приводим `(int)`; событие `ValueChanged`.

Запусти — двигаешь степпер, жмёшь кнопку, получаешь сообщение.

## Шаг 9 (по желанию). Единая тема в App.xaml

Хочешь, чтобы цвета работали на всех страницах приложения? Перенеси их в `App.xaml`. Открой `App.xaml` и добавь внутрь `<ResourceDictionary>` (после `MergedDictionaries`):

```xml
<Color x:Key="Brand">#6F4E37</Color>
<Color x:Key="PageBg">#FFF8F0</Color>
```

Теперь эти ресурсы видны везде, и из `MainPage.xaml` их можно убрать. Готовый пример — в `материалы/App.xaml`.

---

## Готово! 🎉

Ты собрал меню кафе и понял главное:
- **ресурс** — значение с именем (`{StaticResource}`);
- **стиль** — набор свойств, применяется ко многим элементам;
- **неявный стиль** (без `x:Key`) — оформляет всех сам;
- **`Border`** — карточка, **`Image`** — картинка;
- меняешь оформление **в одном месте** — меняется везде.

Сверься с эталоном: [материалы/MainPage.xaml](материалы/MainPage.xaml) и [материалы/MainPage.xaml.cs](материалы/MainPage.xaml.cs). Затем берись за [практику](практика.md).

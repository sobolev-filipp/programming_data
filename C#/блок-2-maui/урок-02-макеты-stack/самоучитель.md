## 📚 Что мы делаем

Приложение **«Карточка профиля»** — аккуратная визитка: слева аватар, справа имя и роль, ниже пара строк информации и кнопка «Лайк». Главное, чему учимся, — **расставлять элементы**: столбиком, в ряд и вложенно (стопка внутри стопки).

---

## Шаг 0. Что такое макет (коротко)

- **Макет (layout)** — контейнер-коробка, который сам расставляет элементы внутри.
- Две главные «стопки» (Stack = стопка):
  - **`VerticalStackLayout`** — элементы **друг под другом** (столбик);
  - **`HorizontalStackLayout`** — элементы **в ряд** (слева направо).
- Реальные экраны = **стопки, вложенные друг в друга** (как матрёшки).

Запомни: **выбрал контейнер — выбрал направление.**

## Шаг 2. Очисти экран и поставь фон

Открой `MainPage.xaml`. Удали всё **внутри** `<ContentPage>...</ContentPage>` и оставь одну внешнюю вертикальную стопку. Странице зададим мягкий фон:

```xml
<ContentPage xmlns="http://schemas.microsoft.com/dotnet/2021/maui"
             xmlns:x="http://schemas.microsoft.com/winfx/2009/xaml"
             x:Class="ProfileCard.MainPage"
             BackgroundColor="#F0F4FF">

    <VerticalStackLayout Padding="24" Spacing="18" VerticalOptions="Center">

    </VerticalStackLayout>

</ContentPage>
```

- `BackgroundColor="#F0F4FF"` — светло-голубой фон всей страницы.
- `Padding="24"` — отступ от краёв, `Spacing="18"` — расстояние между будущими элементами, `VerticalOptions="Center"` — всё по центру по высоте.

**Запусти.** Пока пусто, но фон голубой. ✅

## Шаг 3. Пробуем столбик (проверка понимания)

Временно впиши внутрь стопки три метки:

**Запусти.** Они встали **друг под другом** — это и есть `VerticalStackLayout`.

## Шаг 4. Шапка: аватар и имя/роль (вложенные стеки!)

Хотим: **аватар слева, а справа имя над ролью**. Значит: внешняя коробка шапки — **горизонтальная** (аватар и блок в ряд), а внутри справа — **вертикальная** (имя над ролью).

Впиши внутрь внешней стопки:
```xml
<HorizontalStackLayout Spacing="16" HorizontalOptions="Center">

    <Label Text="🦊" FontSize="64" VerticalOptions="Center" />

    <VerticalStackLayout Spacing="2" VerticalOptions="Center">
        <Label Text="Алиса" FontSize="28" FontAttributes="Bold" />
        <Label Text="Гейм-дизайнер" FontSize="16" TextColor="Gray" />
    </VerticalStackLayout>

</HorizontalStackLayout>
```

Разбор:
- внешний `HorizontalStackLayout` — ставит аватар и блок **в ряд**;
- `Label "🦊"` — крупный эмодзи-аватар, `VerticalOptions="Center"` выравнивает его по центру блока справа;
- вложенный `VerticalStackLayout` — имя и роль **друг под другом**;
- `FontAttributes="Bold"` — имя жирным; `TextColor="Gray"` — роль серым (помельче).

**Запусти.** Должно быть:
```
🦊   Алиса
     Гейм-дизайнер
```

> ⚠️ Если «поехало» — проверь, что **закрыты оба** тега: `</VerticalStackLayout>` (внутренний) и `</HorizontalStackLayout>` (внешний). Отступы-лесенкой помогают не запутаться.

## Шаг 5. Строки информации

Ниже шапки добавь две строки «подпись: значение». Каждая строка — маленькая **горизонтальная** стопка:

```xml
<HorizontalStackLayout Spacing="8">
    <Label Text="Город:" FontSize="18" />
    <Label Text="Казань" FontSize="18" FontAttributes="Bold" />
</HorizontalStackLayout>

<HorizontalStackLayout Spacing="8">
    <Label Text="Любит:" FontSize="18" />
    <Label Text="платформеры" FontSize="18" FontAttributes="Bold" />
</HorizontalStackLayout>

```

Эти две стопки лежат во **внешней вертикальной** — поэтому сами строки идут друг под другом, а слова внутри каждой — в ряд. Вот вложенность в действии.

**Запусти.** Под шапкой появились две строки. ✅

## Шаг 6. Кнопка «Лайк» со счётчиком (как в уроке 1)

Внизу — кнопка и рядом число лайков. Число меняем из кода → даём ему `x:Name`:

```xml
<HorizontalStackLayout Spacing="10" HorizontalOptions="Center">
    <Button Text="❤ Лайк" Clicked="OnLikeClicked" />
    <Label x:Name="LikesLabel" Text="0" FontSize="24" VerticalOptions="Center" />
</HorizontalStackLayout>
```

Метод `OnLikeClicked` пока не написан — сейчас добавим в C#.

## Шаг 7. Логика лайка (`MainPage.xaml.cs`)

Открой `MainPage.xaml.cs`. Добавь переменную `likes` **в класс** и метод-обработчик:

```csharp
namespace ProfileCard;

public partial class MainPage : ContentPage
{
    int likes = 0;

    public MainPage()
    {
        InitializeComponent();
    }

    private void OnLikeClicked(object? sender, EventArgs e)
    {
        likes++;
        LikesLabel.Text = likes.ToString();
    }
}
```

- `int likes = 0;` — объявлен **в классе**, поэтому помнит значение между нажатиями;
- имя `OnLikeClicked` **совпадает** с `Clicked="OnLikeClicked"` в XAML;
- `likes++;` — +1, затем показываем число в метке `LikesLabel`.

**Запусти. Нажми «Лайк» — число растёт!** 🎉

## Шаг 8. Меняем макет из кода (необязательно, но интересно)

Дай внешней стопке имя — тогда ею можно управлять из C#:
```xml
<VerticalStackLayout x:Name="Card" Padding="24" Spacing="18" VerticalOptions="Center">
```
Добавь кнопку:
```xml
<Button Text="Просторнее" Clicked="OnSpaceClicked" HorizontalOptions="Center" />
```
И метод:
```csharp
private void OnSpaceClicked(object? sender, EventArgs e)
{
    Card.Spacing = 40;
}
```
**Запусти, нажми «Просторнее»** — карточка раздвинется. Контейнер — такой же элемент, им тоже можно управлять по имени.

> ✅ Весь C# целиком — в [материалы/MainPage.xaml.cs](материалы/MainPage.xaml.cs).

## 🧩 Если что-то не собирается

| Ошибка | Причина | Что делать |
|--------|---------|-----------|
| экран «поехал», XAML-ошибка | не закрыт вложенный тег | у каждого `<...>` должен быть парный `</...>`; сверь по отступам |
| элементы столбиком вместо ряда | положил в `VerticalStackLayout` | оберни в `HorizontalStackLayout` |
| «обработчик `OnLikeClicked` не найден» | имя в `Clicked` ≠ имя метода | сверь имена буква в букву |
| `LikesLabel`/`Card` «не существует» | забыл `x:Name` | добавь имя элементу/контейнеру |
| лайки «сбрасываются» | `int likes` объявлен внутри метода | вынеси в класс (Шаг 7) |

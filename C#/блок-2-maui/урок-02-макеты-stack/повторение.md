## 🔮 Что покажет метка? (повторяем урок 1, на подумать)

Логика — тот же C#. Предскажи, что окажется в `CountLabel.Text`:

1. `int count = 0; count += 5; count--; CountLabel.Text = count.ToString();`
2. `CountLabel.Text = "Счёт: " + 2 * 3;`
3. Подковырка: `count` — поле класса, кнопка вызывает `count++`. Нажали **3 раза**. Что в `count`?
4. Подковырка: `int count = 10; CountLabel.Text = count + "";`

<details><summary>✅ Ответы и почему</summary>

1. `4` — 0 + 5 = 5, затем `count--` → 4; `.ToString()` даёт строку для метки.
2. `Счёт: 6` — `2 * 3` = 6 посчиталось раньше склейки со строкой.
3. `3` — ❗поле класса **помнит** значение между нажатиями; три `count++` → 3. (Будь `count` внутри метода — каждый раз обнулялся бы.)
4. `10` — `count + ""` — хитрый способ превратить число в строку (склейка с пустой строкой).
</details>

## 🐞 Есть ли здесь ошибка? (или всё верно?)

1. XAML: `<Label Text="Привет" >`
2. `<Button Text="+1" Clicked="OnPlus" />`, а метод в C# называется `OnPlusClicked`
3. `CountLabel.Text = count;` (где `count` — `int`)
4. `<Label x:Name="Title" Text="Профиль" />`
5. Счётчик `int count` объявлен **внутри** метода кнопки

<details><summary>✅ Ответы</summary>

1. ❌ Тег не закрыт — нужно `/>` в конце (или `</Label>`).
2. ❌ Имена не совпадают: в `Clicked` и у метода должно быть одно имя.
3. ❌ `Text` — строка; нужно `count.ToString()` (или `$"{count}"`).
4. ✅ Верно.
5. ❌ Внутри метода счётчик обнуляется каждый раз — его надо объявить **полем класса**.
</details>

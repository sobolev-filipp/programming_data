# Урок 2 (Блок 2) «Макеты: стеки» — итого (шпаргалка) 📌

> Открой, чтобы за 3 минуты вспомнить, как расставлять элементы. Имена элементов и методов — по-английски.

---

## Главная мысль

**Макет (layout)** — контейнер, который сам расставляет вложенные элементы. Выбираешь контейнер — выбираешь **направление**.

| Контейнер | Как ставит элементы |
|-----------|---------------------|
| `VerticalStackLayout` | **столбиком** (сверху вниз) |
| `HorizontalStackLayout` | **в ряд** (слева направо) |

---

## Расстояния и выравнивание

| Свойство | Что делает |
|----------|-----------|
| `Spacing="20"` | расстояние **между** элементами внутри стопки |
| `Padding="30"` | отступ **от краёв** контейнера до элементов |
| `HorizontalOptions` | прижать по горизонтали: `Start` / `Center` / `End` / `Fill` |
| `VerticalOptions` | прижать по вертикали: `Start` / `Center` / `End` / `Fill` |
| `FontAttributes="Bold"` | жирный текст |

`Padding` можно задать по сторонам: `Padding="40,10"` (бока, верх/низ) или `Padding="10,20,10,40"` (слева, сверху, справа, снизу).

---

## Вложенные стеки (главный приём)

Стопка **внутри** стопки. Снаружи — одно направление, внутри — другое.

```xml
<!-- аватар СЛЕВА + (имя НАД ролью) СПРАВА -->
<HorizontalStackLayout Spacing="16">
    <Label Text="🦊" FontSize="64" VerticalOptions="Center" />

    <VerticalStackLayout Spacing="2" VerticalOptions="Center">
        <Label Text="Алиса" FontSize="28" FontAttributes="Bold" />
        <Label Text="Гейм-дизайнер" FontSize="16" TextColor="Gray" />
    </VerticalStackLayout>
</HorizontalStackLayout>
```

Результат:
```
🦊   Алиса
     Гейм-дизайнер
```

> 💡 Приём: сначала нарисуй на бумаге **коробки** (что в ряд, что столбиком), потом переведи коробки в теги. Вложенная коробка = вложенный тег. **Не забывай закрывать** каждый тег!

---

## Менять макет из кода

Контейнеру тоже можно дать `x:Name` и управлять им из C#:

```xml
<VerticalStackLayout x:Name="Card" Spacing="18"> ... </VerticalStackLayout>
```
```csharp
Card.Spacing = 40;                 // раздвинуть содержимое
Card.BackgroundColor = Colors.LightYellow;   // цвет — из класса Colors
```

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| элементы встали столбиком, а хотел в ряд | положил в `VerticalStackLayout` | оберни в `HorizontalStackLayout` |
| ошибка XAML / «поехал» экран | не закрыт вложенный тег | у каждого `<...>` должен быть свой `</...>`; делай отступы-лесенку |
| элементы «слиплись» | нет `Spacing`/`Padding` | добавь расстояния контейнеру |
| `Card` «не существует» в C# | нет `x:Name="Card"` у стопки | дай контейнеру имя |
| текст не жирный | нет свойства | добавь `FontAttributes="Bold"` |

## 📖 Справочник контролов урока (свойства · события · XAML/C#)

### `HorizontalStackLayout` — стопка (ряд)
- **Свойства:** `Spacing` — между элементами · `Padding` — от краёв · `HorizontalOptions`/`VerticalOptions` · `BackgroundColor` · `IsVisible` · `x:Name`.
- **События:** нет (контейнер).
- **XAML:** `<HorizontalStackLayout Spacing="10"> ... </HorizontalStackLayout>`
- **C#:** `var row = new HorizontalStackLayout { Spacing = 10 };`

### `VerticalStackLayout` — стопка (столбик)
- **Свойства:** те же (`Spacing`, `Padding`, `HorizontalOptions`/`VerticalOptions`, `BackgroundColor`, `x:Name`). Ставит элементы друг под другом.
- **XAML:** `<VerticalStackLayout Spacing="18" Padding="24"> ... </VerticalStackLayout>`
- **Из кода:** `Card.Spacing = 40;` (если у стопки есть `x:Name="Card"`).

### Выравнивание — `HorizontalOptions` / `VerticalOptions` (у любого элемента)
- **Значения (`LayoutOptions`):** `Start` — к началу · `Center` — по центру · `End` — к концу · `Fill` — растянуть.
- **XAML:** `<Label Text="Справа" HorizontalOptions="End" />`
- **C#:** `label.HorizontalOptions = LayoutOptions.End;`

### `Label` — доп. свойства этого урока
- `FontAttributes="Bold"` — жирный текст · `WidthRequest`/`HeightRequest` — желаемый размер (пригодилось для ровных колонок).

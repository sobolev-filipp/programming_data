# Шпаргалка

VerticalStackLayout — столбик; HorizontalStackLayout — ряд. Spacing — между элементами, Padding — внутри, Margin — снаружи. Border содержит один элемент. ScrollView прокручивает содержимое.

```csharp
HeroLayout.Spacing = 8;
HeroBorder.Padding = new Thickness(12);
DetailsPanel.IsVisible = !DetailsPanel.IsVisible;
```

Проверь имена, вложенность и запуск.

# Итоги

VerticalStackLayout и HorizontalStackLayout размещают элементы; Border оформляет один дочерний элемент; ScrollView прокручивает; Entry.TextChanged реагирует на ввод, Picker.SelectedIndexChanged — на выбор, CheckBox.CheckedChanged — на флажок. Общий метод UpdateShip пересчитывает цену с нуля.

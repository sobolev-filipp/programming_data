## 🟢 Уровень 1 — базовый (закрепляем)

**1.** Сделай кнопку, которая по нажатию показывает окно: заголовок «Привет», текст «Ты нажал кнопку!», кнопка «OK».
- **Должно получиться:** всплывает окошко с приветствием.
- 💡 Подсказка: `await DisplayAlertAsync("Привет", "...", "OK");`; обработчик — `async`.

**2.** Добавь в обработчик из задания 1 слово `async` (если забыл) и `await`. Запусти.
- **Должно получиться:** без ошибок на `await`.
- 💡 Подсказка: `private async void OnClick(...)`.

**3.** Кнопка показывает окно «Готово», текст «Сохранено!», кнопка закрытия «Класс!».
- **Должно получиться:** третий аргумент — надпись на кнопке.
- 💡 Подсказка: третий аргумент `DisplayAlertAsync` — текст кнопки.

**4.** Сделай кнопку «Спросить»: окно-вопрос «Продолжить? Да / Нет». Результат положи в `bool`.
- **Должно получиться:** окно с двумя кнопками.
- 💡 Подсказка: `bool ok = await DisplayAlertAsync("...", "...", "Да", "Нет");`.

**5.** После вопроса из задания 4: если «Да» — метка «Поехали!», если «Нет» — «Ладно, отмена».
- **Должно получиться:** текст метки зависит от выбора.
- 💡 Подсказка: `if (ok) ... else ...`.

**6.** Сделай кнопку «Выключить меня»: по нажатию сама становится серой.
- **Должно получиться:** нажал — кнопка погасла.
- 💡 Подсказка: через `sender` или по имени: `IsEnabled = false`.

**7.** Две кнопки: «Спрятать» прячет метку (`IsVisible=false`), «Показать» — показывает.
- **Должно получиться:** метка исчезает и появляется.
- 💡 Подсказка: `MyLabel.IsVisible = false / true`.

**8.** Кнопка `RestartButton` изначально спрятана в XAML (`IsVisible="False"`). Другая кнопка её показывает.
- **Должно получиться:** сначала кнопки нет, потом появляется.
- 💡 Подсказка: `IsVisible="False"` в теге + из кода `= true`.

**9.** Три кнопки «Красный/Зелёный/Синий» ведут в ОДИН обработчик. По `sender` узнай текст и запиши в метку «Выбран: …».
- **Должно получиться:** метка показывает нажатый цвет.
- 💡 Подсказка: `if (sender is Button btn) ResultLabel.Text = "Выбран: " + btn.Text;`.

**10.** В задании 9: по нажатию любой кнопки перекрась фон страницы в выбранный цвет.
- **Должно получиться:** фон меняется под кнопку.
- 💡 Подсказка: `this.BackgroundColor = Colors.Red` и т.п. (по `btn.Text` через `switch`).

**11.** Кнопка «Удалить» показывает подтверждение «Точно удалить? Да/Нет». По «Да» — метка «Удалено», по «Нет» — ничего.
- **Должно получиться:** без «Да» ничего не происходит.
- 💡 Подсказка: `if (!yes) return;` — ранний выход.

**12.** Кнопка «Старт»: по нажатию сама гаснет (`IsEnabled=false`) и показывает кнопку «Стоп» (`IsVisible=true`).
- **Должно получиться:** «Старт» серый, «Стоп» появился.
- 💡 Подсказка: два свойства подряд у двух элементов.

## 🟡 Уровень 2 — средний (комбинируем и думаем)

**13.** Мини-викторина: вопрос + 3 кнопки-ответа (один обработчик). Верный ответ — окно «Верно!», неверный — «Неверно».
- **Должно получиться:** реакция зависит от нажатой кнопки.
- 💡 Подсказка: `string correct = "..."`; сравни с `btn.Text`.

**14.** В задании 13 после ответа выключи все три кнопки (`IsEnabled=false`), чтобы нельзя было ответить дважды.
- **Должно получиться:** кнопки гаснут после первого ответа.
- 💡 Подсказка: обратись к каждой по `x:Name`.

**15.** Добавь кнопку «Заново»: появляется после ответа, включает кнопки обратно и прячется сама.
- **Должно получиться:** цикл «ответил → заново → снова можно».
- 💡 Подсказка: `IsEnabled=true` всем + `RestartButton.IsVisible=false`.

**16.** «Заново» из задания 15 переспрашивает «Начать сначала? Да/Нет» и сбрасывает только по «Да».
- **Должно получиться:** случайно сбросить нельзя.
- 💡 Подсказка: `DisplayAlertAsync(...,"Да","Нет")` + `if (!yes) return;`.

**17.** Форма: `Entry` имени + кнопка «Отправить». Кнопка серая (`IsEnabled=false`), пока имя пустое; при вводе — включается.
- **Должно получиться:** пустое имя → кнопка недоступна.
- 💡 Подсказка: событие `TextChanged` (ур.4) → `SendButton.IsEnabled = !string.IsNullOrWhiteSpace(e.NewTextValue)`.

**18.** Калькулятор из двух `Entry` и кнопки «=»: если ввод не число — окно «Ошибка: введите число».
- **Должно получиться:** на «абв» выскакивает окно-ошибка.
- 💡 Подсказка: `int.TryParse` (ур.4) → если `false`, покажи `DisplayAlertAsync`.

**19.** Светофор: 3 кнопки «Красный/Жёлтый/Зелёный» (один обработчик). Перекрашивают метку-«кружок» и пишут «Стой/Жди/Иди».
- **Должно получиться:** цвет + подпись зависят от кнопки.
- 💡 Подсказка: `switch (btn.Text)` по тексту.

**20.** 🔎 **Найди ошибку.** На строке `await DisplayAlertAsync(...)` компилятор ругается:
  ```csharp
  private void OnClick(object? sender, EventArgs e)
  {
      await DisplayAlertAsync("Хей", "Привет", "OK");
  }
  ```
- 💡 Подсказка: чего не хватает в заголовке метода?

**21.** 🔎 **Найди ошибку.** Не компилируется:
  ```csharp
  private void OnAnswer(object? sender, EventArgs e)
  {
      string t = sender.Text;   // ← ошибка
  }
  ```
- 💡 Подсказка: какого типа `sender`? Есть ли у `object` свойство `Text`?

**22.** 🤔 **Предскажи.** Что будет, если убрать `await` перед `DisplayAlertAsync` в задании 5 (метод оставить `async`)? Запиши, потом проверь.
- 💡 Подсказка: код не станет ждать закрытия окна — что тогда с `bool ok`?

**23.** Кнопка «Выйти» с подтверждением «Точно выйти? Да/Нет»; по «Да» — покажи прощальное окно «Пока!», по «Нет» — ничего.
- **Должно получиться:** два окна подряд по «Да».
- 💡 Подсказка: два `await DisplayAlertAsync` в одном методе, второй — внутри `if`.

## 🔴 Уровень 3 — со звёздочкой (собери сам)

**24.** Викторина из **3 вопросов**: показываешь вопрос за вопросом, считаешь очки, в конце окно «Твой счёт: N из 3».
- **Должно получиться:** проходишь 3 вопроса, видишь итог.
- 💡 Подсказка: массивы вопросов/ответов (ур.6 блока 1) + счётчик номера вопроса; меняй `QuestionLabel.Text`.

**25.** «Кликер с лимитом»: кнопка «+1» считает до 10, затем гаснет (`IsEnabled=false`) и окно «Достигнут максимум!».
- **Должно получиться:** после 10 кнопка недоступна.
- 💡 Подсказка: счётчик (ур.1) + проверка `if (count >= 10)`.

**26.** «Тест-ответ с блокировкой»: 4 кнопки, после ответа подсвети правильную зелёной, неправильную (если нажал) — красной, выключи все.
- **Должно получиться:** видно, где был верный ответ.
- 💡 Подсказка: `btn.BackgroundColor = Colors.Green/Red`; правильную найди по имени/тексту.

**27.** «Заказ» (повтор ур.5): выбор в `Picker` + `Stepper` количества + кнопка «Оформить» с подтверждением «Заказать N шт.? Да/Нет».
- **Должно получиться:** подтверждение показывает выбранное; заказ только по «Да».
- 💡 Подсказка: собери текст с выбором и подставь в сообщение `DisplayAlertAsync`.

**28.** «Форма с валидацией»: имя (`Entry`) + возраст (`Entry` Numeric). Кнопка «Готово» серая, пока оба поля не заполнены корректно; иначе окно с тем, что не так.
- **Должно получиться:** кнопка включается только при валидных данных.
- 💡 Подсказка: проверяй в `TextChanged` обоих полей; `int.TryParse` для возраста.

**29.** «Голосование»: 3 кнопки-варианта (один обработчик), считай голоса в переменных, метка показывает счёт каждого; кнопка «Итог» окном объявляет победителя.
- **Должно получиться:** голоса растут, «Итог» называет лидера.
- 💡 Подсказка: по `btn.Text` увеличивай нужный счётчик; победитель — сравнение чисел (тернарник/`if`).

**30.** «Мини-игра "Сапёр-лайт" 3×3» (повтор Grid, ур.3): 9 кнопок (один обработчик). Одна — «мина» (окно «Бум!» + все гаснут), остальные — «чисто» (кнопка зеленеет и гаснет).
- **Должно получиться:** нажал мину — конец; нажал чистую — она открылась.
- 💡 Подсказка: `Grid` 3×3 (ур.3); «мину» задай заранее (по тексту/имени); `sender` даёт нажатую кнопку.

## 2. Что такое sender (заход в тему)

Посмотри на заголовок обработчика:

```csharp
private void OnClick(object? sender, EventArgs e) { }
```

- Как думаешь, что означает `sender` — «отправитель»?
- Если три кнопки ведут в этот один метод, поможет ли `sender` понять, какую именно нажали?

<details><summary>Мысль</summary>
`sender` — это сам элемент, который вызвал событие. По нему один обработчик узнаёт, какая из кнопок сработала. Сегодня разовьём это глубже (`sender is Button btn`).
</details>

## 3. Мостик из блока 1

1. Что делает `if (!ok) return;` — «ранний выход»?
2. Как проверить, что строка не пустая? (`string.IsNullOrWhiteSpace`)
3. Как безопасно превратить текст в число, не уронив программу? (`int.TryParse`)

<details><summary>Ответы</summary>

1. Если условие плохое — сразу выйти из метода, дальше не выполнять.
2. `string.IsNullOrWhiteSpace(s)` → `true`, если пусто/пробелы.
3. `int.TryParse(s, out int n)` → `true`/`false`; при `true` число в `n`.
</details>

Всё это пригодится: сегодня приложение будет **спрашивать** («Точно?») и **проверять** ввод, показывая окна.

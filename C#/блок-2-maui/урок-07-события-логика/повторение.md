## 2. Что такое sender (заход в тему)

Посмотри на заголовок обработчика:

```csharp
private void OnClick(object? sender, EventArgs e) { }
```

- Как думаешь, что означает `sender` — «отправитель»?
- Если три кнопки ведут в этот один метод, поможет ли `sender` понять, какую именно нажали?

<details><summary>Мысль</summary>
`sender` — это сам элемент, который вызвал событие. По нему один обработчик узнаёт, какая из кнопок сработала. Сегодня разовьём это глубже (`sender is Button btn`).
</details>

## 3. Мостик из блока 1

1. Что делает `if (!ok) return;` — «ранний выход»?
2. Как проверить, что строка не пустая? (`string.IsNullOrWhiteSpace`)
3. Как безопасно превратить текст в число, не уронив программу? (`int.TryParse`)

<details><summary>Ответы</summary>

1. Если условие плохое — сразу выйти из метода, дальше не выполнять.
2. `string.IsNullOrWhiteSpace(s)` → `true`, если пусто/пробелы.
3. `int.TryParse(s, out int n)` → `true`/`false`; при `true` число в `n`.
</details>

Всё это пригодится: сегодня приложение будет **спрашивать** («Точно?») и **проверять** ввод, показывая окна.

## 5. 🔮 Что выведет этот код? (повтор уроков 5–6, на подумать)

Предскажи, что окажется на метке/в выводе, **не запуская**:

1. `int count = 3; count += 2; ResultLabel.Text = $"Итого: {count}";`
2. Подковырка (кнопка с `Text="Красный"` ведёт в обработчик):
```csharp
Button b = (Button)sender;
ResultLabel.Text = "Выбран: " + b.Text;
```
3. `bool delivery = false; Console.WriteLine(600 + (delivery ? 150 : 0));`

<details><summary>✅ Ответы и почему</summary>

1. `Итого: 5` — 3 + 2 = 5, интерполяция вставила в текст.
2. `Выбран: Красный` — `(Button)sender` даёт нажатую кнопку, читаем её `Text` (это разовьём сегодня).
3. `600` — доставки нет (`false`), тернарник добавил 0.
</details>

## 6. 🐞 Есть ли здесь ошибка? (или всё верно?)

1. `<Label Style="{StaticResource Title}" />` (ресурс `Title` объявлен выше)
2. `<Border><Label Text="A"/><Label Text="B"/></Border>`
3. `<Style TargetType="Label"><Setter Property="FontSize" Value="20"/></Style>`
4. `<Border CornerRadius="12" />` (хотим скруглить углы)
5. `string s = "7"; int n = s;`

<details><summary>✅ Ответы</summary>

1. ✅ Верно — стиль применяется по имени.
2. ❌ У `Border` только **один** ребёнок — заверни метки в стек.
3. ✅ Верно — это неявный стиль для всех `Label`.
4. ❌ У `Border` скругление задаёт `StrokeShape="RoundRectangle 12"` (`CornerRadius` — у `Frame`/`Button`).
5. ❌ Строку нельзя класть в `int` напрямую — нужен `int.Parse`/`TryParse`.
</details>

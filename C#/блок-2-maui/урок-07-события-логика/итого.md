# Урок 7 (Блок 2) «События и логика глубже» — итого (шпаргалка) 📌

> Открой, чтобы за 3 минуты вспомнить события, `sender`, окна и управление элементами. Имена — по-английски.

---

## Главная мысль

Приложение **реагирует** (по `sender`), **спрашивает** (`DisplayAlertAsync`) и **управляет** элементами (`IsEnabled`/`IsVisible`).

| Инструмент | Зачем | Ключ |
|-----------|-------|------|
| `sender` | узнать, кто нажал | `sender is Button btn` |
| `DisplayAlertAsync` | окно-сообщение / вопрос | `await ...("...","...","OK")` |
| `async`/`await` | дождаться ответа окна | метод `async`, вызов `await` |
| `IsEnabled` | активен / серый | `btn.IsEnabled = false;` |
| `IsVisible` | виден / спрятан | `btn.IsVisible = false;` |

---

## sender — один обработчик на много кнопок

```xml
<Button Text="Париж" Clicked="OnAnswer" />
<Button Text="Лондон" Clicked="OnAnswer" />
```
```csharp
private void OnAnswer(object? sender, EventArgs e)
{
    if (sender is not Button btn) return;   // sender → кнопка btn
    string answer = btn.Text;               // текст нажатой кнопки
}
```

## DisplayAlertAsync — окно

```csharp
// Сообщение (одна кнопка):
await DisplayAlertAsync("Готово", "Сохранено!", "OK");

// Вопрос (две кнопки → bool):
bool yes = await DisplayAlertAsync("Удаление", "Точно удалить?", "Да", "Нет");
if (!yes) return;   // «Нет» — выходим
```
Обработчик при этом — `async`:
```csharp
private async void OnClick(object? sender, EventArgs e) { ... }
```

## IsEnabled / IsVisible

```csharp
Btn1.IsEnabled = false;          // серая, не нажать
RestartButton.IsVisible = true;  // появилась
ResultLabel.IsVisible = false;   // спряталась
```
```xml
<Button x:Name="RestartButton" Text="Заново" IsVisible="False" />
```

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| ошибка на `await` | метод не `async` | добавь `async` в заголовок обработчика |
| `DisplayAlert` подчёркнут (устарел) | в .NET 10 имя другое | используй `DisplayAlertAsync` |
| окно показалось, но код помчался дальше | забыл `await` | поставь `await` перед вызовом |
| один обработчик путает кнопки | не читаешь `sender` | `if (sender is Button btn)` → `btn.Text` |
| «object не имеет .Text» | `sender` — это `object?` | сначала приведи к `Button` (`is`/`(Button)`) |
| кнопка не гаснет | перепутал свойства | серый — `IsEnabled=false`; спрятать — `IsVisible=false` |
| элемент исчез, а место осталось | так не бывает у `IsVisible` | `IsVisible=false` убирает и место (в отличие от `Opacity`) |

## 📖 Справочник урока (события · окна · свойства)

### `sender` — кто вызвал событие
- **Что:** первый параметр обработчика `object? sender` — сам элемент, вызвавший событие.
- **Зачем:** один обработчик на много элементов; узнаём сработавший.
- **Достать элемент:** `if (sender is Button btn) { ... }` (безопасно) или `(Button)sender` (жёстко, из ур.3).
- **C#:** `private void OnAny(object? sender, EventArgs e) { if (sender is Button b) { var t = b.Text; } }`

### `DisplayAlertAsync` — всплывающее окно
- **Сообщение:** `await DisplayAlertAsync("Заголовок", "Текст", "OK")` — показать и закрыть.
- **Вопрос:** `bool ok = await DisplayAlertAsync("Заголовок", "Текст", "Да", "Нет")` — возвращает `true` (первая кнопка) / `false` (вторая).
- **Требует:** `async` у метода, `await` перед вызовом.
- ⚠️ **.NET 10:** имя со словом `Async` (старое `DisplayAlert` устарело).

### `async` / `await`
- **`async`** — ставим в заголовок метода-обработчика: «метод умеет ждать».
- **`await`** — перед строкой, которую надо дождаться (например `DisplayAlertAsync`): «дождись, потом иди дальше».

### `IsEnabled` — активность
- **Свойство:** `bool`. `true` — работает; `false` — серый, нельзя нажать/вводить. Есть у любого элемента.
- **XAML:** `<Button IsEnabled="False" />` · **C#:** `btn.IsEnabled = false;`

### `IsVisible` — видимость
- **Свойство:** `bool`. `true` — виден; `false` — спрятан и **не занимает места**. Есть у любого элемента.
- **XAML:** `<Button IsVisible="False" />` · **C#:** `btn.IsVisible = true;`

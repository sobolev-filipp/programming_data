# Самоучитель к уроку 7 (Блок 2). События и логика — «Викторина» с нуля 🎯

> Пропустил урок или собираешь дома? Соберём викторину с самого начала и по дороге разберём события, всплывающие окна и управление элементами. Иди по шагам, после каждого — **запускай**.

---

## Что понадобится

- Среда (Visual Studio на Windows или VS Code + `dotnet` на Mac) — как в прошлых уроках.
- Новый проект **.NET MAUI App**, назовём `QuizApp`.
  - VS: *Create a new project → .NET MAUI App → QuizApp*.
  - Mac/VS Code: `dotnet new maui -o QuizApp`.

Правим два файла: `MainPage.xaml` (внешность) и `MainPage.xaml.cs` (логика).

---

## Идея урока в одном предложении

Приложение перестаёт «молчать»: оно **реагирует** на разные кнопки (через `sender`), **показывает окна** (`DisplayAlertAsync`) и **включает/прячет** элементы (`IsEnabled`/`IsVisible`).

---

## Шаг 1. Вопрос и три кнопки-ответа

Открой `MainPage.xaml`, замени содержимое:

```xml
<?xml version="1.0" encoding="utf-8" ?>
<ContentPage xmlns="http://schemas.microsoft.com/dotnet/2021/maui"
             xmlns:x="http://schemas.microsoft.com/winfx/2009/xaml"
             x:Class="QuizApp.MainPage"
             BackgroundColor="#EEF2FF">
    <VerticalStackLayout Padding="24" Spacing="14">
        <Label Text="🎯 Викторина" FontSize="28" FontAttributes="Bold" HorizontalOptions="Center" />
        <Label x:Name="QuestionLabel" Text="Столица Франции?" FontSize="20" HorizontalOptions="Center" />

        <Button x:Name="Btn1" Text="Париж" Clicked="OnAnswer" />
        <Button x:Name="Btn2" Text="Лондон" Clicked="OnAnswer" />
        <Button x:Name="Btn3" Text="Берлин" Clicked="OnAnswer" />

        <Label x:Name="ResultLabel" FontSize="18" HorizontalOptions="Center" />
    </VerticalStackLayout>
</ContentPage>
```

Заметь: все три кнопки ведут в **один** обработчик `OnAnswer`.

> Если `x:Class` в твоём проекте другой — оставь как было (там имя твоего проекта).

---

## Шаг 2. Узнаём, какую кнопку нажали (sender)

Открой `MainPage.xaml.cs`. Вверху класса добавь правильный ответ, а в класс — обработчик:

```csharp
string correct = "Париж";

private void OnAnswer(object? sender, EventArgs e)
{
    if (sender is not Button btn) return;   // sender — это кнопка? кладём в btn
    ResultLabel.Text = "Ты выбрал: " + btn.Text;
}
```

Запусти. Нажимаешь любую кнопку — метка показывает её текст. Это и есть сила `sender`: **один метод** на **три кнопки**.

---

## Шаг 3. Всплывающее окно (DisplayAlertAsync)

Покажем окно с реакцией. Перепиши обработчик — добавь `async` и `await`:

```csharp
private async void OnAnswer(object? sender, EventArgs e)
{
    if (sender is not Button btn) return;
    string answer = btn.Text;

    if (answer == correct)
        await DisplayAlertAsync("Результат", "Верно! 🎉", "OK");
    else
        await DisplayAlertAsync("Результат", $"Неверно. Правильный ответ: {correct}", "OK");
}
```

Запусти. Теперь после нажатия выскакивает окошко.

> **Почему `async` и `await`?** Окно ждёт, пока нажмёшь «OK». `async` в заголовке метода = «умею ждать», `await` перед окном = «дождись, потом дальше». Правило: **показываешь окно → метод `async`, перед окном `await`.**
>
> ⚠️ Метод называется `DisplayAlertAsync` (со словом `Async`) — это важно в .NET 10.

---

## Шаг 4. Выключаем кнопки после ответа

Чтобы нельзя было ответить дважды, погасим кнопки. Добавь в конец `OnAnswer`:

```csharp
    Btn1.IsEnabled = false;
    Btn2.IsEnabled = false;
    Btn3.IsEnabled = false;
```

Запусти — после ответа кнопки серые, не нажимаются. `IsEnabled = false` = «выключено».

---

## Шаг 5. Кнопка «Заново» (IsVisible)

Добавь кнопку в XAML под `ResultLabel` — сразу спрятанной:

```xml
<Button x:Name="RestartButton" Text="Пройти заново" Clicked="OnRestart" IsVisible="False" />
```

В конце `OnAnswer` покажи её:

```csharp
    RestartButton.IsVisible = true;   // появилась после ответа
```

Запусти — после ответа снизу возникает кнопка «Пройти заново». `IsVisible` управляет видимостью.

---

## Шаг 6. «Заново» с подтверждением

Добавь обработчик `OnRestart` — он спросит подтверждение и сбросит викторину:

```csharp
private async void OnRestart(object? sender, EventArgs e)
{
    bool yes = await DisplayAlertAsync("Заново?", "Начать викторину сначала?", "Да", "Нет");
    if (!yes) return;                 // нажал «Нет» — выходим

    Btn1.IsEnabled = true;            // включаем кнопки
    Btn2.IsEnabled = true;
    Btn3.IsEnabled = true;
    ResultLabel.Text = "";
    RestartButton.IsVisible = false;  // снова прячем «Заново»
}
```

Запусти. Жмёшь «Заново» → окно «Начать сначала? Да / Нет». По «Да» всё сбрасывается, по «Нет» — ничего.

> **Окно-вопрос** возвращает `bool`: `true` если нажали первую кнопку («Да»), `false` — вторую («Нет»). `if (!yes) return;` — «не согласился → выходим».

## Готово! 🎉

Ты собрал викторину и понял главное:
- **`sender`** — кто нажал (`sender is Button btn` → `btn.Text`); один обработчик на много кнопок;
- **`DisplayAlertAsync`** — окно-сообщение (`"OK"`) и окно-вопрос (`"Да","Нет"` → `bool`);
- **`async`/`await`** — чтобы дождаться ответа окна;
- **`IsEnabled`** — серый/активный; **`IsVisible`** — спрятан/виден.

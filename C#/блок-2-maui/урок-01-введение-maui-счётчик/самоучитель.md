# Самоучитель — Моё настроение

Если пропустил занятие, открой [урок](урок.md) и начни с создания проекта. Выполняй разделы по порядку, запускай приложение после каждого шага. Не копируй весь проект с другой платформы. Сравни свои файлы с [XAML](материалы/MainPage.xaml) и [C#](материалы/MainPage.xaml.cs), затем выполни два задания из [практики](практика.md) и пройди [викторину](викторина.html).

## Проверка структуры проекта

Открой `Platforms/Android/AndroidManifest.xml` и `Platforms/Windows/Package.appxmanifest`. Найди объявленные разрешения Android и объясни, чем объявление разрешения отличается от согласия пользователя. Сверься с разделом «Манифесты приложения и разрешения» в [теории](урок.md). Не меняй настройки для приложения настроения.

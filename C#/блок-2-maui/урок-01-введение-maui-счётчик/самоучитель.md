# 🆘 Самоучитель — Урок 1 (Блок 2) «Введение в MAUI + Счётчик»

**Собираем первое приложение с окном — с самого начала, по шагам.**

> Пропустил урок или собираешь дома? Иди строго по шагам. **Каждый шаг — делай и запускай.** Не спеши: цель — понять, как приложение устроено, а не пробежать быстро. Готовые файлы — в [материалы/](материалы/).

---

## 📚 Что мы делаем

Приложение **«Счётчик»**: на экране крупное число и три кнопки — **+1**, **−1**, **Сброс**. Нажимаешь — число меняется. Это маленький, но **настоящий** пример того, как работает любое приложение: *человек нажал → код сработал → экран обновился*.

---

## Шаг 0. Что такое MAUI (коротко)

- **MAUI** — способ делать приложения с окном на C# сразу для Windows, Android, Mac и iPhone.
- Каждый экран — это **два файла**:
  - `MainPage.xaml` — **как выглядит** (текст, кнопки) — язык **XAML** (теги в угловых скобках, как HTML);
  - `MainPage.xaml.cs` — **что делает** (логика) — язык **C#** (знакомый по блоку 1).

Запомни картинку: **XAML — внешность, C# — мозг.**

---

## Шаг 1. Подготовь среду (один раз)

**Windows:** установи **Visual Studio 2022** и в установщике отметь workload **«Разработка мобильных приложений на .NET»** (это MAUI).
**Mac:** установи **VS Code**, **.NET 10 SDK**, затем в терминале:
```bash
sudo dotnet workload install maui --source https://api.nuget.org/v3/index.json
xcode-select --install
```
Проверь, что .NET на месте:
```bash
dotnet --version
```
Ждём номер вида `10.0.xxx`. Если так — среда готова.

---

## Шаг 2. Создай проект

**Windows (Visual Studio):** Создание проекта → шаблон **.NET MAUI App** → имя **`CounterApp`** → Framework **.NET 10.0** → Создать.

**Mac (VS Code):**
```bash
dotnet new maui -o CounterApp
cd CounterApp
code .
```

Открой проект. Тебе нужны всего два файла: **`MainPage.xaml`** и **`MainPage.xaml.cs`**. Остальное (папки `Platforms`, `Resources`, `MauiProgram.cs`…) создалось само — не трогай.

---

## Шаг 3. Проверь, что всё запускается (Hello, World)

Ничего пока не меняя, запусти проект **как есть**:
- **Windows:** вверху выбери платформу **Windows Machine** → нажми ▶ (или **F5**).
- **Mac:** `dotnet build -t:Run -f net10.0-maccatalyst`

Первый запуск долгий (до пары минут) — это нормально. Появится окно с роботом и кнопкой «Click me».
✅ Если окно появилось — среда работает. Закрой окно (это остановит приложение) и идём делать своё.

> 🐞 Не запустилось? **Mac:** `rm -rf bin obj` затем `dotnet restore` и снова запуск. **Windows:** проверь, что стоит workload MAUI (Шаг 1).

## Шаг 4. Очисти экран под себя

Открой `MainPage.xaml`. Удали всё **внутри** `<ContentPage>...</ContentPage>` и оставь пустой контейнер-стопку:

```xml
<ContentPage xmlns="http://schemas.microsoft.com/dotnet/2021/maui"
             xmlns:x="http://schemas.microsoft.com/winfx/2009/xaml"
             x:Class="CounterApp.MainPage">

    <VerticalStackLayout Padding="30" Spacing="20" VerticalOptions="Center">

    </VerticalStackLayout>

</ContentPage>
```

- `VerticalStackLayout` — «стопка»: элементы встанут друг под другом.
- `Padding="30"` — отступ от краёв, `Spacing="20"` — расстояние между элементами, `VerticalOptions="Center"` — по центру экрана.
- Строчки `xmlns` и `x:Class` **не трогай** — они служебные.

## Шаг 5. Заголовок

Внутрь стопки впиши первую метку:
```xml
<Label Text="Мой счётчик"
       FontSize="32"
       HorizontalOptions="Center" />
```
- `Label` — текст на экране; `Text` — что написано; `FontSize` — размер; `HorizontalOptions="Center"` — по центру.

**Запусти.** Вверху — надпись «Мой счётчик». ✅

---

## Шаг 6. Большое число с именем

Ниже заголовка добавь метку-счётчик. Ей нужно **имя**, чтобы менять из кода:
```xml
<Label x:Name="CountLabel"
       Text="0"
       FontSize="80"
       HorizontalOptions="Center" />
```
- 🔑 **`x:Name="CountLabel"`** — самое важное. Теперь в C# можно писать `CountLabel.Text = ...`.
- `Text="0"` — начинаем с нуля; `FontSize="80"` — очень крупно.

**Запусти.** Под заголовком — большой ноль. ✅

---

## Шаг 7. Три кнопки

Ниже числа добавь три кнопки. Каждая обещает свой метод в `Clicked`:
```xml
<Button Text="+1" Clicked="OnPlusClicked" />
<Button Text="-1" Clicked="OnMinusClicked" />
<Button Text="Сброс" Clicked="OnResetClicked" />
```

Методов ещё нет — если запустить сейчас, будет ошибка «метод не найден». Это нормально. Идём в C#.

> ✅ Весь XAML целиком — в [материалы/MainPage.xaml](материалы/MainPage.xaml).

---

## Шаг 8. Мозг: переменная-счётчик

Открой `MainPage.xaml.cs`. Он выглядит примерно так:
```csharp
namespace CounterApp;

public partial class MainPage : ContentPage
{
    public MainPage()
    {
        InitializeComponent();
    }
}
```

Добавь **переменную `count`** — сразу под строкой `public partial class MainPage : ContentPage {`:
```csharp
int count = 0;
```
Важно: она объявлена **в классе** (а не внутри метода) — поэтому помнит своё значение между нажатиями.

- `InitializeComponent();` — не трогай. Она связывает C# с XAML (без неё код не увидит `CountLabel` и кнопки).

---

## Шаг 9. Метод кнопки «+1»

Внутри класса, **ниже** конструктора `public MainPage() {...}`, добавь:
```csharp
private void OnPlusClicked(object? sender, EventArgs e)
{
    count++;
    CountLabel.Text = count.ToString();
}
```
Разбор:
- имя `OnPlusClicked` **совпадает** с `Clicked="OnPlusClicked"` в XAML;
- `(object? sender, EventArgs e)` — обязательная «подпись» обработчика кнопки, пиши всегда так;
- `count++;` — увеличили число;
- `CountLabel.Text = count.ToString();` — показали его в метке (число → строку через `.ToString()`).

**Запусти. Нажми «+1» — число растёт!** 🎉

---

## Шаг 10. Кнопки «−1» и «Сброс»

Добавь ещё два метода по образцу:
```csharp
private void OnMinusClicked(object? sender, EventArgs e)
{
    count--;
    CountLabel.Text = count.ToString();
}

private void OnResetClicked(object? sender, EventArgs e)
{
    count = 0;
    CountLabel.Text = count.ToString();
}
```

**Запусти и проверь:**
- «+1» — растёт;
- «−1» — уменьшается (можно уйти в минус — это ок);
- «Сброс» — снова 0.

> ✅ Весь C# целиком — в [материалы/MainPage.xaml.cs](материалы/MainPage.xaml.cs).

## 🧩 Если что-то не собирается

| Ошибка | Причина | Что делать |
|--------|---------|-----------|
| «обработчик `OnPlusClicked` не найден» | в XAML `Clicked="..."` есть, а метода в C# нет (или имя другое) | сверь имена **буква в букву** |
| `CountLabel` «не существует в текущем контексте» | забыл `x:Name="CountLabel"` в XAML | добавь имя метке |
| число не меняется на экране | после `count++` не обновил метку | допиши `CountLabel.Text = count.ToString();` |
| счётчик всегда 0 или 1 | `int count` написан **внутри** метода | вынеси его в класс (Шаг 8) |
| приложение не запускается вообще | среда/workload | Windows: проверь workload MAUI; Mac: `rm -rf bin obj` + `dotnet restore` |

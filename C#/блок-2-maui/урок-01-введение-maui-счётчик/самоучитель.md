# Самоучитель — Урок 1 «Знакомство с MAUI. Моё настроение»

**Блок 2 · Урок 1 | Для пропустивших или для закрепления**

> Напоминание темы → задания с разбором → самостоятельные задания.

## Мини-теория за 5 минут

MAUI позволяет использовать общий C# и XAML для нескольких платформ. XAML описывает экран, C# — действия. `x:Name` даёт имя объекту, `Clicked` связывает кнопку с методом. `Label.Text` меняет надпись, `Image.Source` — изображение. Картинки лежат в `Resources/Images`. Манифесты в `Platforms` описывают платформенные настройки; опасные разрешения требуют согласия пользователя.

## Подготовка

Создай новый .NET MAUI App на локальном диске, запусти шаблон. Если не запускается, открой [справочник среды](../../справочники/среда-VisualStudio-и-VSCode.md). Сохрани исходные xmlns и x:Class страницы, namespace класса и InitializeComponent(). Для каждого задания используй отдельную копию страницы или проект: замени содержимое ContentPage на VerticalStackLayout, вставь в него разметку примера. Старые обработчики и поля предыдущего упражнения удали. В примерах используются стандартные пространства имён MAUI и System.

## Задания с разбором (делаем вместе)

### 1. Первая кнопка

В `MainPage.xaml`, внутри контейнера:

```xml
<Label x:Name="ResultLabel" Text="Привет!" />
<Button Text="Изменить" Clicked="OnChangeClicked" />
```

В `MainPage.xaml.cs`, внутри класса `MainPage` (не внутри конструктора):

```csharp
private void OnChangeClicked(object? sender, EventArgs e)
{
    ResultLabel.Text = "Кнопка работает!";
}
```

**Проверка:** До нажатия видно «Привет!», после — «Кнопка работает!». Имя метода совпадает с Clicked.

### 2. Скрываем надпись

В `MainPage.xaml`, внутри контейнера:

```xml
<Label x:Name="SecretLabel" Text="Секрет" IsVisible="False" />
<Button Text="Показать" Clicked="OnShowClicked" />
```

В `MainPage.xaml.cs`, внутри класса `MainPage` (не внутри конструктора):

```csharp
private void OnShowClicked(object? sender, EventArgs e)
{
    SecretLabel.IsVisible = true;
}
```

**Проверка:** Надпись появляется после нажатия; повторное нажатие не меняет результат.

### 3. Счётчик очков

В `MainPage.xaml`, внутри контейнера:

```xml
<Label x:Name="ScoreLabel" Text="0" />
<Button Text="+1" Clicked="OnAddClicked" />
```

В `MainPage.xaml.cs`, внутри класса `MainPage` (не внутри конструктора):

```csharp
private int score = 0;
private void OnAddClicked(object? sender, EventArgs e)
{
    score++;
    ScoreLabel.Text = score.ToString();
}
```

**Проверка:** Три нажатия дают 3. Поле score хранится между вызовами.

### 4. Картинка и цвет

В `MainPage.xaml`, внутри контейнера:

```xml
<Image x:Name="Picture" Source="mood_happy.png" HeightRequest="120" />
<Button Text="Спокойствие" Clicked="OnCalmClicked" />
```

В `MainPage.xaml.cs`, внутри класса `MainPage` (не внутри конструктора):

```csharp
private void OnCalmClicked(object? sender, EventArgs e)
{
    Picture.Source = "mood_calm.png";
    BackgroundColor = Colors.LightBlue;
}
```

**Проверка:** Скопируй PNG из материалов в Resources/Images до запуска. Картинка и фон меняются.

### 5. Общий метод

В `MainPage.xaml`, внутри контейнера:

```xml
<Label x:Name="StatusLabel" Text="Ожидание" />
<Button Text="Старт" Clicked="OnStartClicked" />
<Button Text="Стоп" Clicked="OnStopClicked" />
```

В `MainPage.xaml.cs`, внутри класса `MainPage` (не внутри конструктора):

```csharp
private void SetStatus(string text, Color color)
{
    StatusLabel.Text = text;
    BackgroundColor = color;
}
private void OnStartClicked(object? sender, EventArgs e)
{
    SetStatus("Работа", Colors.LightGreen);
}
private void OnStopClicked(object? sender, EventArgs e)
{
    SetStatus("Стоп", Colors.LightPink);
}
```

**Проверка:** Обе кнопки вызывают один метод с разными аргументами.

**Задание:** Переключай три картинки по кругу.

### Обработчики и фон страницы

Для `Button.Clicked` используй `private void OnButtonClicked(object? sender, EventArgs e)`. Знак `?` допускает значение `null` у sender. Обычный метод не обязан принимать эти параметры. Внутри MainPage строка `BackgroundColor = Color.FromArgb("#E2F7F5");` меняет фон всей страницы. После правок сохрани файлы и пересобери приложение. Полный код проекта — в конце [урока](урок.md).

private void OnColorClicked(object? sender, EventArgs e)

}

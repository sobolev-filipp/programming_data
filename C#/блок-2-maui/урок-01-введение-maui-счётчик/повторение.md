## 🔮 Что выведет этот код? (повторяем C# из блока 1, на подумать)

Логика в MAUI — тот же C#. Предскажи вывод, **не запуская**:

1. `int count = 0; count++; count++; Console.WriteLine(count);`
2. `int count = 5; Console.WriteLine("Счёт: " + count);`
3. `int count = 5; Console.WriteLine("Счёт: " + count.ToString());`
4. Подковырка: `int n = 3; Console.WriteLine(n + 1 + "!");`

<details><summary>✅ Ответы и почему</summary>

1. `2` — два раза `count++` (каждый +1).
2. `Счёт: 5` — число склеивается со строкой.
3. `Счёт: 5` — `.ToString()` делает из числа строку (именно так зададим `Label.Text` сегодня).
4. `4!` — ❗сначала `n + 1` = 4 (числа), потом `4 + "!"` = «4!» (склейка). Будь `"!" + 1 + n` — вышло бы «!13».
</details>

## 🐞 Есть ли здесь ошибка? (или всё верно?)

1. `int count; count++;`
2. `Console.WriteLine("Счёт: " count);`
3. `int count = 0; count = count + 1;`
4. `string s = 5;`
5. `int count = 7; Console.WriteLine(count.ToString());`

<details><summary>✅ Ответы</summary>

1. ❌ `count` не задан начальным значением — нужно `int count = 0;`.
2. ❌ Забыт `+` между строкой и `count`.
3. ✅ Верно — то же, что `count++`.
4. ❌ В `string` нельзя класть число: нужно `"5"` или `5.ToString()`.
5. ✅ Верно — выведет 7.
</details>

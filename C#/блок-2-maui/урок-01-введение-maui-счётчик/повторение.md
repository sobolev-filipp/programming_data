## Быстрый разогрев (2 мин)

В консольном проекте:

```csharp
int score = 0;
score += 2;
Console.WriteLine(score);
```

## Что нового будет сегодня

Сегодня вместо Console.WriteLine будем менять свойства элементов на экране; вместо последовательного ввода — реагировать на события.

## Что выведет этот код? (на подумать)

Предскажи вывод.

1. `int n = 3; n += 2; Console.WriteLine(n);`
2. `Console.WriteLine(Math.Clamp(120, 0, 100));`
3. `string[] names = { "Луна", "Марс" }; Console.WriteLine(names[1]);`
4. `Console.WriteLine(7.ToString());`

<details><summary>Ответы и почему</summary>

1. 5 — прибавили 2.
2. 100 — верхняя граница.
3. Марс — индексация с нуля.
4. 7 — число преобразовано в строку.

</details>

## Есть ли здесь ошибка?

1. `int n = "5";`
2. `string s = 5.ToString();`
3. `int[] a = { 1, 2 }; Console.WriteLine(a[2]);`
4. `int x = Random.Shared.Next(1, 7);`

<details><summary>Ответы</summary>

1. Ошибка типов: нужна строка или число.
2. Верно.
3. IndexOutOfRangeException: последний индекс 1.
4. Верно: от 1 до 6.

</details>

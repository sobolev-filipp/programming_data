# 🔁 Разминка (5 минут) · Блок 2, Урок 1

> Сегодня начинаем **новый блок** — от консоли переходим к приложениям с окном. Вспомним, что уже умеем, — оно пригодится.

## 🎤 Блиц-вопросы (устно, 3 мин)

1. Как в блоке 1 мы **показывали текст** человеку? (`Console.WriteLine`) → сегодня это будет элемент `Label`.
2. Как **читали ввод** человека? (`Console.ReadLine`) → скоро это будет поле `Entry`.
3. Что такое **переменная** и что делает `count++`? (хранит значение; увеличивает на 1) → сегодня `count` будет считать нажатия.
4. Что такое **метод**? (кусок кода с именем, который можно вызвать) → сегодня метод будет срабатывать при нажатии кнопки.
5. На каком языке мы писали весь блок 1? (**C#**) → он остаётся! Добавится только новый язык разметки — **XAML**.

## 🌉 Мостик: было в консоли → станет в приложении

| Блок 1 (консоль) | Блок 2 (MAUI) |
|------------------|---------------|
| `Console.WriteLine("Привет")` | `<Label Text="Привет" />` |
| `Console.ReadLine()` | `<Entry />` (поле ввода) |
| «нажми Enter, чтобы продолжить» | `<Button Text="Дальше" />` |
| чёрное окно с текстом | настоящее окно с кнопками |

> ⚙️ **Учителю.** Это первый и самый «средовой» урок блока — заложи время на установку/настройку (workload MAUI). Идти медленно, по §-шагам, после каждого — запуск. У детей на Windows — Visual Studio (платформа **Windows Machine** — быстрее всего для проверки); у тебя на Mac — VS Code + `dotnet build -t:Run -f net10.0-maccatalyst` (сверься со шпаргалкой `Работа С# в VS Code.docx`). Первый запуск MAUI долгий — предупреди детей, чтоб не пугались. Цель урока — не объём кода, а **понимание связки XAML↔C#** на маленьком примере.

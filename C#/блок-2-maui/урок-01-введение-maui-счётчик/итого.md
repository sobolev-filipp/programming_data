## Главная мысль

**Приложение MAUI = два файла на каждый экран:**

| Файл | Язык | За что отвечает |
|------|------|-----------------|
| `MainPage.xaml` | XAML | **внешность** (что видно) |
| `MainPage.xaml.cs` | C# | **логика** (что делает) |

---

## Базовые элементы XAML

```xml
<!-- контейнер: элементы встают друг под другом -->
<VerticalStackLayout Padding="30" Spacing="20" VerticalOptions="Center">

    <Label Text="Мой счётчик" FontSize="32" HorizontalOptions="Center" />

    <!-- метка с ИМЕНЕМ — её меняем из кода -->
    <Label x:Name="CountLabel" Text="0" FontSize="80" HorizontalOptions="Center" />

    <Button Text="+1" Clicked="OnPlusClicked" />
</VerticalStackLayout>
```

| Элемент | Что это |
|---------|---------|
| `ContentPage` | один экран приложения |
| `VerticalStackLayout` | стопка элементов (друг под другом) |
| `Label` | текст на экране (как `Console.WriteLine`) |
| `Button` | кнопка |

| Свойство | Что делает |
|----------|-----------|
| `Text="..."` | надпись |
| `FontSize="80"` | размер шрифта |
| `HorizontalOptions="Center"` | по центру по горизонтали |
| `Padding` / `Spacing` | отступ от краёв / между элементами |
| `x:Name="CountLabel"` | **имя** — чтобы менять из C# |
| `Clicked="OnPlusClicked"` | какой метод звать при нажатии |

## C# code-behind

```csharp
public partial class MainPage : ContentPage
{
    int count = 0;                       // помнит число (объявлен в классе!)

    public MainPage() { InitializeComponent(); }   // связывает C# с XAML

    private void OnPlusClicked(object? sender, EventArgs e)
    {
        count++;
        CountLabel.Text = count.ToString();   // меняем метку по её имени
    }
}
```

- **Обработчик** кнопки: `private void ИмяМетода(object? sender, EventArgs e)`.
- Имя метода в C# = имя в `Clicked="..."` в XAML.
- Меняем экран: `Элемент.Свойство = значение;` → `CountLabel.Text = count.ToString();`
- Число → строку: `count.ToString()`.

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| «метод не найден» при сборке | `Clicked="OnPlusClicked"` есть, а метода нет | добавь метод с **тем же** именем |
| `CountLabel` «не существует» в C# | забыл `x:Name="CountLabel"` в XAML | добавь имя метке |
| число не меняется | не обновил `CountLabel.Text` | после `count++` — `CountLabel.Text = count.ToString();` |
| счётчик всегда 0/1 | `int count` объявлен **внутри** метода | объявляй в **классе**, не в методе |

# Итоги урока
- XAML описывает экран, C# — поведение.
- Label выводит текст, Button вызывает Clicked, Image показывает ресурс.
- x:Name связывает элемент с кодом; InitializeComponent загружает разметку.
- Text, TextColor, Source и BackgroundColor можно менять из обработчика.
- Общий метод с параметрами уменьшает повторение.

Проверь себя: [викторина](викторина.html).

# Урок 1 «Моё настроение» — итого (шпаргалка)

> Открой, чтобы за 3 минуты вспомнить урок.

## Главные мысли

1. Начинай с запуска чистого шаблона.
2. Имена элементов — PascalCase: MoodLabel, MoodImage.
3. Все кнопки могут вызывать MoodBtn; sender хранит нажатую кнопку.
4. Цвет в XAML — #RRGGBB, в C# — Colors, Color.FromRgb или Color.FromArgb.
5. Картинки называй mood_happy.png; в Source указывай имя без папки.
6. Отключить кнопку можно через IsEnabled, скрыть — через IsVisible.
7. Манифесты не удаляй; разрешения добавляй только при необходимости.

## XAML и C#

```xml
<Label x:Name="MoodLabel" Text="Привет" />
<Button Text="Изменить" Clicked="OnChangeClicked" />
```

```csharp
private void OnChangeClicked(object? sender, EventArgs e)
{
    MoodLabel.Text = "Готово";
    MoodLabel.TextColor = Colors.DarkBlue;
}
```

## Изображения и цвета

```xml
<Image x:Name="MoodImage" Source="mood_happy.png" Aspect="AspectFit" />
```

```csharp
MoodImage.Source = "mood_calm.png";
BackgroundColor = Color.FromArgb("#E2F7F5");
```

## Структура проекта

| Файл | Назначение |
|---|---|
| MainPage.xaml | Интерфейс |
| MainPage.xaml.cs | Логика страницы |
| Resources/Images | Картинки |
| Resources/Styles | Цвета и стили |
| Platforms/Android/AndroidManifest.xml | Настройки Android и разрешения |
| Platforms/Windows/Package.appxmanifest | Настройки пакета Windows |

Манифест не заменяет запрос разрешения у пользователя. Для приложения настроения дополнительные разрешения не нужны.

## Общий обработчик

```csharp
private void MoodBtn(object? sender, EventArgs e)
{
    if (sender is Button button)
    {
        BackgroundColor = button.BackgroundColor;
        if (button == HappyBtn)
            MoodImage.Source = "mood_happy.png";
    }
}
```

Для остальных кнопок добавь else if. sender — источник события, e — данные события. `Color.FromRgb(255, 0, 0)` и `Color.FromArgb("#FF0000")` создают одинаковый красный цвет.

## Главные ошибки

| Симптом | Причина | Решение |
|---|---|---|
| Не найден AndroidManifest.xml | путь или неполный шаблон | создай тестовый проект на локальном диске |
| InitializeComponent не найден | ошибка XAML или несовпадение класса | проверь первую ошибку сборки и x:Class |
| Clicked не найден | не совпадает имя или сигнатура | private void OnClick(object? sender, EventArgs e) |
| Имя Label не найдено | нет x:Name | добавь x:Name и проверь регистр |
| Картинка пустая | неверное имя или ресурс | Resources/Images, MauiImage, пересборка |
| Счёт сбрасывается | локальная переменная | поле класса |

### Обработчики и фон страницы

Для `Button.Clicked` используй `private void OnButtonClicked(object? sender, EventArgs e)`. Знак `?` допускает значение `null` у sender. Обычный метод не обязан принимать эти параметры. Внутри MainPage строка `BackgroundColor = Color.FromArgb("#E2F7F5");` меняет фон всей страницы. После правок сохрани файлы и пересобери приложение. Полный код проекта — в конце [урока](урок.md).

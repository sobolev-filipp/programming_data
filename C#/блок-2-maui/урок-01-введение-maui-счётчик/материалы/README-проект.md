# Запуск проекта MoodApp
Создай стандартный .NET MAUI App с именем `MoodApp` на локальном диске. Используй версию SDK, установленную и проверенную преподавателем. Замени только MainPage.xaml и MainPage.xaml.cs файлами из этой папки. Скопируй три PNG из Resources/Images в одноимённую папку проекта (Build Action: MauiImage). Не заменяй csproj, AppShell или Platforms. Если имя проекта другое, исправь namespace и x:Class одновременно. Windows: Windows Machine → F5. Mac: `dotnet build -t:Run -f net10.0-maccatalyst` для проекта .NET 10; для другой версии подставь её TFM из csproj. Это исходники страницы, не самостоятельный проект.

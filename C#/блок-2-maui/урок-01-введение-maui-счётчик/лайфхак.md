# 🧰 Лайфхаки и частые ошибки · Урок 1 (Блок 2) «MAUI + Счётчик»

> Первый урок MAUI — больше всего «граблей» связано со **средой и запуском**. Здесь собрано, что помогает.

---

## 💡 Трюки

1. **Проверяй на Windows Machine.** Самый быстрый способ увидеть результат на Windows — платформа **Windows Machine** (не эмулятор Android — он грузится минутами). На Mac — `maccatalyst` (маковое окно), тоже быстро.
2. **Меняй по одному свойству и запускай.** Не пиши сразу десять свойств — добавил одно, посмотрел, что изменилось. Так понимаешь, что за что отвечает.
3. **Копируй имена целиком.** Имя в `Clicked="OnPlusClicked"` и имя метода в C# должны совпадать буква в букву. Проще скопировать, чем набирать заново.
4. **`x:Name` — только тем, кого меняешь.** Если элемент просто стоит и не меняется (заголовок), имя ему не нужно. Нужно — числу, полю, всему, что трогаешь из кода.
5. **Число → строка.** `Label.Text` хочет строку, поэтому число переводим: `CountLabel.Text = count.ToString();`. (Или через интерполяцию: `CountLabel.Text = $"{count}";` — как в блоке 1.)
6. **Горячая перезагрузка (Hot Reload).** В Visual Studio при запущенном приложении можно менять XAML — и он обновляется **на лету**, без перезапуска. Очень удобно подбирать цвета/размеры.
7. **Цвета: XAML vs C#.** В XAML цвет — строкой (`TextColor="Purple"`), в C# — через класс `Colors` (`BackgroundColor = Colors.Purple;`). Это одно из главных отличий двух языков.

## 🐞 Частые ошибки

| Что видишь | Причина | Лечение |
|-----------|---------|---------|
| нет шаблона **.NET MAUI App** при создании | не установлен workload MAUI | Windows: Visual Studio Installer → Изменить → отметить «Разработка мобильных приложений на .NET». Mac: `dotnet workload install maui` |
| `dotnet: command not found` | не установлен .NET SDK / не перезапущен терминал | установить .NET 10 SDK, перезапустить терминал |
| «обработчик `OnPlusClicked` не найден» | имя в `Clicked` ≠ имя метода в C# | сверить имена буква в букву |
| `CountLabel` «не существует» | нет `x:Name="CountLabel"` в XAML | добавить имя метке |
| экран не меняется при нажатии | забыл обновить `.Text` после изменения `count` | дописать `CountLabel.Text = count.ToString();` |
| счётчик «сбрасывается» сам | `int count` объявлен внутри метода | объявить в классе |
| проект «не собирается» после копирования файлов | не совпадает имя проекта и `namespace`/`x:Class` | назвать проект `CounterApp` **или** поменять `CounterApp` в обоих файлах на своё имя |
| долго собирается / завис (Mac) | «мусор» в папках сборки | `rm -rf bin obj`, затем `dotnet restore` |
| эмулятор Android не стартует (Windows) | не создано устройство | проверяй на **Windows Machine**; Android — через Диспетчер устройств Android, если нужен именно телефон |

## 🍎 Команды-помощники (Mac / VS Code)

```bash
dotnet build -t:Run -f net10.0-maccatalyst   # собрать и запустить (маковое окно)
rm -rf bin obj                               # почистить, если «капризничает»
dotnet restore                               # пересобрать служебные файлы
dotnet clean                                 # очистить кэш сборки
dotnet nuget locals all --clear             # очистить кэш пакетов NuGet (крайний случай)
```
Полная шпаргалка — в [`../справочники/среда-VisualStudio-и-VSCode.md`](../справочники/среда-VisualStudio-и-VSCode.md).

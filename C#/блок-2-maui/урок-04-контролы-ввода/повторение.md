# 🔁 Разминка (5 минут) · Блок 2, Урок 4

> До сих пор человек либо смотрел на готовый текст, либо нажимал кнопки. Сегодня научимся принимать **напечатанный** текст — как `Console.ReadLine` в блоке 1, только в окне. Сначала вспомним.

## 🎤 Блиц-вопросы (устно, 3 мин)

1. Как в блоке 1 мы **читали** то, что ввёл человек? (`Console.ReadLine()`)
2. Как из строки-ввода сделать число **безопасно**, чтобы программа не упала? (`int.TryParse`)
3. Что такое **интерполяция строк** `$"Привет, {name}!"`? (вставка значения переменной в текст)
4. Зачем элементу `x:Name`? (чтобы обратиться к нему из кода)
5. Чем `Label` отличается от кнопки? (`Label` показывает текст, кнопка — нажимается)

## 🧩 Мини-повторение из блока 1

Что делает этот код, если ввели «абв»?
```csharp
if (int.TryParse(text, out int n))
    Console.WriteLine("Число: " + n);
else
    Console.WriteLine("Это не число");
```
*(Ответ: выведет «Это не число» — и не упадёт.)* Сегодня ровно так проверим поле возраста.

## ⚡ Что будет сегодня

- Поле ввода **`Entry`** — «`ReadLine` с окном»; читаем `Entry.Text`.
- Подсказка `Placeholder`, цифровая клавиатура, скрытый пароль.
- Проверка ввода: пусто? число? (`IsNullOrWhiteSpace`, `int.TryParse`).
- Многострочное поле **`Editor`** и «живой» ввод (`TextChanged`).
- Приложение **«Анкета»** — собирает профиль из напечатанного.

## 🔮 Что выведет этот код? (повтор блока 1 + урока 3, на подумать)

Предскажи вывод, **не запуская**:

1. `int.TryParse("12", out int age); Console.WriteLine($"Через год: {age + 1}");`
2. `string s = "Привет"; Console.WriteLine($"Длина: {s.Length}");`
3. Подковырка: `string name = "   "; Console.WriteLine(string.IsNullOrWhiteSpace(name));`

<details><summary>✅ Ответы и почему</summary>

1. `Через год: 13` — «12» разобралось в число, `age + 1` = 13.
2. `Длина: 6` — в «Привет» 6 букв; `$"...{s.Length}..."` вставляет значение.
3. `True` — ❗`IsNullOrWhiteSpace` считает строку из одних **пробелов** пустой.
</details>

## 🐞 Есть ли здесь ошибка? (или всё верно?)

1. `int age = Convert.ToInt32(AgeEntry.Text);` (текст ввёл человек)
2. `<Button Grid.Row="5" />` в сетке из 5 строк
3. `if (int.TryParse(s, out int n)) { ... }`
4. `<Entry Placeholder="Имя" x:Name="NameEntry" />`
5. `<Button Text="OK" />` в `Grid` **без** `Grid.Row`/`Grid.Column`

<details><summary>✅ Ответы</summary>

1. ⚠️ Опасно: если человек ввёл не число — `Convert` уронит приложение. Для ввода бери `int.TryParse`.
2. ❌ Строки нумеруются 0..4; `Row="5"` — за краем, кнопка «пропадёт».
3. ✅ Верно — безопасная проверка.
4. ✅ Верно.
5. ⚠️ Без координат кнопка молча сядет в ячейку (0,0) поверх соседа.
</details>

> ⚙️ **Учителю.** Урок отлично «рифмуется» с блоком 1: `Entry` = `ReadLine`, проверки — те же `IsNullOrWhiteSpace`/`int.TryParse`. Блоки выше повторяют это + нумерацию ячеек Grid с нуля (урок 3). Подчеркните это — снимает страх перед новым. Две частые путаницы: (1) `Placeholder` ≠ `Text` (подсказка не является введённым значением); (2) `Entry.Text` может быть пустым/`null` — поэтому проверяем перед использованием. `Keyboard="Numeric"` на ПК не блокирует буквы — число всё равно валидируем в коде. У детей — Windows Machine + Hot Reload; у вас — Mac VS Code + `dotnet build -t:Run -f net10.0-maccatalyst`. Живой `TextChanged` очень нравится детям — покажите первым, зажигает интерес.

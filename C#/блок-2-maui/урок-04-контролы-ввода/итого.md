# Урок 4 (Блок 2) «Поля ввода Entry/Editor» — итого (шпаргалка) 📌

> Открой, чтобы за 3 минуты вспомнить поля ввода. Имена элементов и методов — по-английски.

---

## Главная мысль

**`Entry` = `Console.ReadLine` с окном.** Человек печатает в поле — мы читаем `Entry.Text` из кода и работаем как в блоке 1.

| Элемент | Для чего |
|---------|----------|
| `Entry` | одна строка: имя, город, возраст, пароль |
| `Editor` | много строк: рассказ, отзыв, заметка |

---

## Поле в XAML

```xml
<Entry x:Name="NameEntry" Placeholder="Введи имя" />
<Entry Placeholder="Возраст" Keyboard="Numeric" />
<Entry Placeholder="Пароль"  IsPassword="True" />
<Editor x:Name="AboutEditor" Placeholder="О себе..." HeightRequest="100" />
```

| Свойство | Что делает |
|----------|-----------|
| `Placeholder` | бледная подсказка в пустом поле (**не** текст!) |
| `Keyboard="Numeric"` | цифровая клавиатура на телефоне |
| `IsPassword="True"` | прячет ввод точками |
| `MaxLength` | ограничение длины |
| `HeightRequest` | высота (для `Editor`) |

---

## Читаем и проверяем (C#)

```csharp
string name = NameEntry.Text;                 // забрали текст

if (string.IsNullOrWhiteSpace(name))          // пусто?
{
    ResultLabel.Text = "Впиши имя!";
    return;
}

if (int.TryParse(AgeEntry.Text, out int age)) // число?
    ResultLabel.Text = $"Тебе {age} лет.";
else
    ResultLabel.Text = "Возраст введи числом.";
```

- `IsNullOrWhiteSpace` — пусто/пробелы;
- **`int.TryParse`** (а не `Convert`!) — не упадёт на «абв»;
- ответ собираем интерполяцией `$"...{name}..."`.

## Живой ввод — `TextChanged`

```xml
<Entry x:Name="NameEntry" TextChanged="OnNameChanged" />
```
```csharp
private void OnNameChanged(object? sender, TextChangedEventArgs e)
{
    HelloLabel.Text = $"Привет, {e.NewTextValue}!";   // текущий текст поля
}
```

- кнопка → `Clicked`, поле → `TextChanged`;
- `e.NewTextValue` — что в поле прямо сейчас.

---

## Много полей → `ScrollView`

```xml
<ScrollView>
    <VerticalStackLayout>...</VerticalStackLayout>
</ScrollView>
```
Прокрутка, если содержимое/клавиатура не влезают. Внутри — **один** ребёнок.

---

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| читаю поле, а там пусто | перепутал `Placeholder` и `Text` | подсказка ≠ введённое; читай `.Text` |
| приложение падает на «абв» | `Convert.ToInt32` ввода | используй `int.TryParse` |
| `NameEntry` «не существует» | нет `x:Name` | добавь имя полю |
| нижние поля не видно | клавиатура закрыла | оберни форму в `ScrollView` |
| живое приветствие не работает | не то событие/параметр | `TextChanged`, параметр `TextChangedEventArgs e` |

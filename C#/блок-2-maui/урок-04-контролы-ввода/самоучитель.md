## 📚 Что мы делаем

Приложение **«Анкета»**: человек печатает имя, возраст и пару слов о себе, а приложение собирает из этого профиль. Учимся главному — **принимать текст, который напечатал человек** (поле `Entry`), и работать с ним, как с `ReadLine` в блоке 1.

---

## Шаг 0. Идея

- **`Entry`** — поле ввода на одну строку. Это «`Console.ReadLine()` с окном».
- Человек печатает → мы читаем `Entry.Text` из кода → собираем ответ.
- Для длинного текста есть **`Editor`** (многострочное поле).

## Шаг 2. Прокручиваемая форма

Открой `MainPage.xaml`. Удали всё **внутри** `<ContentPage>...</ContentPage>` и поставь прокрутку с вертикальной стопкой:

```xml
<ContentPage xmlns="http://schemas.microsoft.com/dotnet/2021/maui"
             xmlns:x="http://schemas.microsoft.com/winfx/2009/xaml"
             x:Class="ProfileApp.MainPage"
             BackgroundColor="#F0F4FF">

    <ScrollView>
        <VerticalStackLayout Padding="24" Spacing="14">

        </VerticalStackLayout>
    </ScrollView>

</ContentPage>
```

- `ScrollView` — прокрутка (если клавиатура закроет нижние поля);
- внутри — одна вертикальная стопка для всех элементов.

**Запусти.** Пусто, но каркас готов. ✅

---

## Шаг 3. Поле имени

Внутрь стопки добавь заголовок, подпись и поле:

```xml
<Label Text="Моя анкета" FontSize="28" FontAttributes="Bold" HorizontalOptions="Center" />

<Label Text="Как тебя зовут?" FontSize="16" />
<Entry x:Name="NameEntry" Placeholder="Введи имя" />
```

- `Entry` — поле ввода; `x:Name="NameEntry"` — чтобы прочитать из кода;
- `Placeholder` — бледная подсказка (исчезает при наборе).

**Запусти.** Щёлкни в поле, напечатай имя. ✅

---

## Шаг 4. Живое приветствие (TextChanged)

Добавь под полем метку и повесь на поле событие `TextChanged`:

```xml
<Entry x:Name="NameEntry" Placeholder="Введи имя" TextChanged="OnNameChanged" />
<Label x:Name="HelloLabel" Text="Привет!" FontSize="16" TextColor="Gray" />
```

(в теге `NameEntry` добавилось `TextChanged="OnNameChanged"`.)

Теперь код. Открой `MainPage.xaml.cs`, внутри класса добавь метод:

```csharp
private void OnNameChanged(object? sender, TextChangedEventArgs e)
{
    HelloLabel.Text = $"Привет, {e.NewTextValue}!";
}
```

- `TextChanged` срабатывает на **каждый** символ;
- `e.NewTextValue` — что в поле сейчас.

**Запусти.** Печатаешь имя — надпись меняется вживую. ✨

---

## Шаг 5. Возраст и рассказ о себе

Вернись в XAML, добавь ещё поля:

```xml
<Label Text="Сколько тебе лет?" FontSize="16" />
<Entry x:Name="AgeEntry" Placeholder="Например, 14" Keyboard="Numeric" />

<Label Text="Расскажи о себе:" FontSize="16" />
<Editor x:Name="AboutEditor" Placeholder="Пара слов о себе..." HeightRequest="100" />
```

- `Keyboard="Numeric"` — цифровая клавиатура для возраста;
- `Editor` — многострочное поле; `HeightRequest="100"` — высота под несколько строк.

**Запусти.** Появились поле возраста и большое поле «о себе». ✅

## Шаг 7. Логика кнопки «Готово»

В `MainPage.xaml.cs` добавь метод:

```csharp
private void OnDone(object? sender, EventArgs e)
{
    string name = NameEntry.Text;
    if (string.IsNullOrWhiteSpace(name))
    {
        ResultLabel.Text = "Впиши, пожалуйста, имя!";
        return;
    }

    string about = AboutEditor.Text;

    if (int.TryParse(AgeEntry.Text, out int age))
        ResultLabel.Text = $"Привет, {name}! Тебе {age} лет.\nО себе: {about}";
    else
        ResultLabel.Text = $"Привет, {name}! А возраст введи числом.";
}
```

Что происходит:
1. читаем имя; если пусто (`IsNullOrWhiteSpace`) — просим вписать и выходим (`return`);
2. читаем рассказ о себе;
3. пробуем возраст через `int.TryParse`: число → полный профиль; не число → просим ввести число.

**Запусти и проверь:**
- всё заполнено → собирается профиль;
- пустое имя → «Впиши, пожалуйста, имя!»;
- в возрасте буквы → «А возраст введи числом.».

> ✅ Весь C# целиком — в [материалы/MainPage.xaml.cs](материалы/MainPage.xaml.cs).

## 🧩 Если что-то не собирается

| Ошибка | Причина | Что делать |
|--------|---------|-----------|
| читаю поле — пусто | перепутал `Placeholder` и `Text` | подсказка ≠ введённое; читай `.Text` |
| падает на буквах в возрасте | `Convert.ToInt32` | замени на `int.TryParse` |
| `NameEntry`/`AgeEntry` «не существует» | нет `x:Name` | добавь имя полю |
| «метод не найден» | имя в `Clicked`/`TextChanged` ≠ имя метода | сверь буква в букву |
| живое приветствие не работает | неверный параметр обработчика | у `TextChanged` параметр `TextChangedEventArgs e` |
| нижние поля прячутся под клавиатурой | нет прокрутки | оберни форму в `ScrollView` |

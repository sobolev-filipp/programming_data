# C# + MAUI + Unity — курс программирования (3 год обучения)

> **135 ак.ч.** · **1 урок = 2 ак.ч. (1,5 часа).** Формат: **1 раз/нед по 2 ак.ч. (1,5 ч)** или **1 раз/нед по 4 ак.ч. (3 ч, два урока подряд)**.
> **Возраст:** 6–11 классы
> **Место в программе:** 1 год — компьютерная грамотность и цифровое творчество; 2 год — программирование на Python + основы геймдева в Godot; **3 год — C# + MAUI (приложения с БД) + Unity (игры)**.

## 🎯 Идея года

Дети уже год писали на Python: знают переменные, ввод-вывод, условия, циклы, списки, функции. **Мы не учим программировать с нуля — мы переносим знакомые идеи на C# и идём дальше: к классам (ООП), к настоящим приложениям с окном и базой данных и к играм на движке Unity.**

- **Азы — повторяем на новом языке, а не разжёвываем.** Условия, переменные, ввод-вывод — даём **кратко: синтаксис C# и отличия от Python**. На **циклах останавливаемся подробнее** — там реальные отличия (`for(int i=…; i<…; i++)`, `do-while`, `foreach`, инкремент `i++`), и на них строится дальше многое.
- **Главное новое года:** строгая **типизация**, **компиляция**, **классы и объекты (ООП — отдельные уроки)**, массивы и `List<T>`, а потом — **MAUI** (приложения) и **Unity** (игры, самый большой блок).
- Каждый урок — **осязаемый результат**: программа, экран приложения или играбельная сцена.

## 💻 Две среды разработки в каждом уроке (важно)

Дети работают в **Visual Studio на Windows**. У преподавателя — **Mac, где Visual Studio нет**, поэтому работаем в **VS Code + `dotnet` CLI**. Поэтому в каждом уроке, где создаём/запускаем проект:

- **Основной путь — Visual Studio (Windows):** пошагово, со скриншотами (создать проект, кнопка ▶ Run, менеджер NuGet и т.д.).
- **Рядом — свёрнутый блок `🍎 На Mac в VS Code`** с эквивалентными командами `dotnet`:

  ```bash
  dotnet --version                 # проверить .NET (нужен .NET 10)
  dotnet new console -o MyApp      # консольный проект
  dotnet run                       # запуск
  dotnet build -t:Run -f net10.0-maccatalyst   # запуск MAUI на Mac
  ```

- Полный справочник команд и настройка обеих сред — в **[`справочники/среда-VisualStudio-и-VSCode.md`](справочники/среда-VisualStudio-и-VSCode.md)**; в уроках — короткий блок + ссылка.

> Версия платформы курса — **.NET 10**. Unity — **Unity 6 / 2022 LTS** (уточняется под установленную версию).

# Блок 3 — 🗄 SQL + MAUI: приложения с базой данных (12 уроков, 24 ч)

> Приложения, которые **помнят данные между запусками**. Лёгкий SQL через **SQLite** + пакет `sqlite-net-pcl`. Учим CRUD (создать/прочитать/обновить/удалить), связи таблиц, `async/await` — на понятных проектах.

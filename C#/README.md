 **Полный план курса — [ПЛАН-КУРСА.md](ПЛАН-КУРСА.md).**
 **Продолжаешь работу / новая сессия? Читай первым делом — [HANDOFF.md](HANDOFF.md)** (все правила, формат, статус, техтонкости).

**Статус:** Блок 1 — по существующим материалам; блок MAUI — переработаны уроки 1–2, остальные ожидают обновления.

## Как устроен урок

Каждый урок — папка с файлами (формат как в курсе Python 2-го года): `урок.md` (конспект), `итого.md` (шпаргалка), `практика.md` (задачи 3 уровней), `самоучитель.md`, `повторение.md`, `лайфхак.md`, `изображения.md` + `изображения/`, `викторина.html`, `материалы/` (код/проекты). Учительские `преподавателю.md` и `практика-решения.md` — материалы для преподавателя; в рабочем репозитории предусмотрен git-crypt.

## Среда разработки

- **Windows (ученики):** Visual Studio 2026 + .NET 10; временно VS 2022 + совместимый MAUI 8/9.
- **Mac (преподаватель):** VS Code + C# Dev Kit + `dotnet` CLI.

В каждом уроке — **двойные инструкции**. Полный справочник: [`справочники/среда-VisualStudio-и-VSCode.md`](справочники/среда-VisualStudio-и-VSCode.md).

## Проверка знаний

В конце каждого урока открываем `викторина.html` в браузере. Интернет не нужен. Вопросы и варианты перемешиваются при каждом запуске и повторном прохождении. У каждого вопроса четыре сопоставимых по длине и сложности варианта, один правильный ответ и пояснение. Цвет фона меняется от урока к уроку.

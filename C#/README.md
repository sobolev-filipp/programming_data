## Как устроен урок

Каждый урок — папка с файлами (формат как в курсе Python 2-го года): `урок.md` (конспект), `итого.md` (шпаргалка), `практика.md` (задачи 3 уровней), `самоучитель.md`, `повторение.md`, `лайфхак.md`, `изображения.md` + `изображения/`, `викторина.html`, `материалы/` (код/проекты). Учительские `преподавателю.md` и `практика-решения.md` — зашифрованы (git-crypt).

## Среда разработки

- **Windows (ученики):** Visual Studio 2022 + .NET 10.
- **Mac (преподаватель):** VS Code + C# Dev Kit + `dotnet` CLI.

В каждом уроке — **двойные инструкции**. Полный справочник: [`справочники/среда-VisualStudio-и-VSCode.md`](справочники/среда-VisualStudio-и-VSCode.md).

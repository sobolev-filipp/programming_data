## 4. ⭐ ВСЕ ПРАВИЛА (это самое главное — соблюдать во всех уроках)

### 4.1 Имена — по-английски (стандарт C#)
- **Переменные/параметры — `camelCase`** (`playerScore`, `heroHp`, `firstName`).
- **Методы/константы — `PascalCase`** (`Attack()`, `DrawHp()`, `MaxLevel`).
- Тексты на экране (`Console.WriteLine("Привет")`) и **комментарии — по-русски**; идентификаторы — **только латиница**.
- C# технически разрешает русские имена, но это **плохая привычка** — не допускать. В Уроке 1 есть вводная плашка про это правило.

### 4.2 Уроки не поверхностные + встроенные методы попутно с темой
- Раскрывать тему **вглубь**, вместе с ней давать **нужные встроенные методы**. Уже вплетено: **Math** (ур.1), **DateTime/TimeSpan** (ур.2), **Random** (ур.4), **foreach-приёмы** (ур.5), **LINQ** Max/Min/Sum/Average/Count (ур.6), **return/ref/out/рекурсия** (ур.7).
- В новых уроках так же: List/Dictionary методы (ур.8), File-методы + try/catch (ур.9) и т.д.

### 4.3 Интересные примеры/проекты + можно новые команды/библиотеки
- В каждом уроке — хотя бы один **эффектный пример/мини-проект** (визуальный или игровой).
- Разрешено вводить новые «фишки» ради вовлечённости. Уже используем: `Console.ForegroundColor`/`ConsoleColor`/`Console.ResetColor()` (цвет), `System.Threading.Thread.Sleep(ms)` (пауза/анимация), `new string('*', n)` (повтор символа), диаграммы-бары `new string('█', value/scale)`.

### 4.4 Практика — понятная, не сухая
- Каждая задача: короткий **контекст/зачем** + чёткое «что сделать» + блок **«Должно получиться:»** с примером вывода + **💡 подсказка** (наводка, НЕ готовый код).
- Не писать «Заведи int x и выведи» — писать по-детски понятно с ожидаемым результатом.

### 4.5 Несколько примеров под каждым блоком + мини-задания
- Под каждой новой конструкцией — **2+ разных примера** и **мини-задание ✍️** сразу после.

### 4.6 Лайфхаки вплетать в `урок.md`
- Ключевые трюки — **инлайн-выноски «💡 Лайфхак: …»** прямо в теле урока, а не только в `лайфхак.md` (учитель просил, чтобы не читать отдельный файл). `лайфхак.md` — доп. слой.

### 4.7 Двойные инструкции по среде
- В каждом уроке с проектом: основной путь **Visual Studio (Windows)** + свёрнутый `<details>` блок **«🍎 На Mac в VS Code»** с `dotnet`-командами. Полный справочник — `справочники/среда-VisualStudio-и-VSCode.md`.

### 4.8 SVG-схемы (стиль)

## 5. Технические тонкости C# (проверено на .NET 10)

- **Всё проверять запуском:** создать проект `dotnet new console -o ... -f net10.0`, скопировать код в `Program.cs`, `dotnet run`. Проекты уроков должны реально работать.
- **Локаль ru-RU:** `double` печатается **через запятую** (`87,5`), хотя в коде пишем через точку (`87.5`). В уроках это честно объяснено — не «исправлять».
- **Nullable-предупреждение (CS8600/CS8602):** `string x = Console.ReadLine();` даёт **жёлтое** предупреждение (не ошибку). В уроках объясняем детям: «жёлтое = совет, красное = ошибка». Число из ввода — `Convert.ToInt32(Console.ReadLine())` (убирает часть warning; аналог `int(input())`).
- **Эмодзи в `Console.WriteLine`** могут отображаться «квадратами» в старой консоли Windows → в коде-выводе эмодзи избегаем (в тексте/комментариях — можно); при желании `Console.OutputEncoding = System.Text.Encoding.UTF8;`.
- **top-level statements:** пишем код сразу (без `class`/`Main`), методы — как **локальные функции** внизу файла (`static` не нужен). ⚠️ **Локальные функции НЕ перегружаются** — вместо перегрузки даём параметр по умолчанию; перегрузку/`static`/класс показываем только в «Глубже» (полноценно — в ООП, ур.10–11).
- **LINQ** (`.Max()/.Sum()/.Average()/.Count(x=>...)/.OrderByDescending()`) и `System.Threading.Thread.Sleep` работают **из коробки** (implicit usings в .NET 10).
- **git-crypt:** `практика-решения.md` и `преподавателю.md` шифруются автоматически по имени (те же имена, что в Python). Новых учительских имён не вводить без правки `.gitattributes`.
- **Кириллические пути** (`D:\Работа\...`): временные файлы для проверки класть в ASCII-путь (scratchpad/`%TEMP%`), иначе возможны проблемы на Windows.

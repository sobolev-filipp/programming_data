## 📚 Мини-теория за 5 минут

Методы строки — через точку `строка.Метод()`:
- `s.Length` — длина (**без скобок!**);
- `s.ToUpper()` / `s.ToLower()` — регистр;
- `s.Trim()` — убрать пробелы по краям;
- `s.Substring(0, 3)` — кусок; `s[0]` — символ (с 0);
- `s.Replace("а", "о")` — заменить; `s.Contains("а")` — есть ли (`true/false`).

⚠️ Метод возвращает **новую** строку: `s = s.ToUpper();`.

**Дата и время — два героя:**
- **`DateTime`** — **МОМЕНТ** («когда»): `DateTime.Now`, `new DateTime(2026,9,20,14,30,0)`; части `.Year/.Day/.DayOfWeek`; формат `ToString("dd.MM.yyyy")`, `ToString("HH:mm")`; `now.AddDays(7)`.
- **`TimeSpan`** — **ПРОМЕЖУТОК** («сколько длится»): `new TimeSpan(2,15,0)`, `TimeSpan.FromMinutes(120)`; **части** `.Hours/.Minutes`, **всего** `.TotalHours/.TotalMinutes`.
- Арифметика: `момент − момент = промежуток`; `момент ± промежуток = момент`.

## ✍️ Задания с разбором (делаем вместе)

### Задание 1. Длина слова
```csharp
string word = "черепаха";
Console.WriteLine($"Букв: {word.Length}");   // 8
```
✅ `.Length` — без скобок.

### Задание 2. Регистр
```csharp
string s = "Привет";
Console.WriteLine(s.ToUpper());   // ПРИВЕТ
Console.WriteLine(s.ToLower());   // привет
```

### Задание 3. Первый символ
```csharp
string word = "динозавр";
Console.WriteLine(word[0]);   // д — символ под номером 0
```

### Задание 4. Кусок строки
```csharp
string word = "программа";
Console.WriteLine(word.Substring(0, 4));   // прог
```

### Задание 5. Сегодняшняя дата
```csharp
Console.WriteLine(DateTime.Now.ToString("dd.MM.yyyy"));
```

## 🧩 Задания с подсказками (сам)

### Задание 6
**Тема:** замена.
**Задание:** в «корова» замени «о» на «а».
> 💡 `"корова".Replace("о", "а")`.

### Задание 7
**Тема:** `Trim` + цепочка.
**Задание:** спроси имя (с пробелами), выведи чистое имя заглавными.
> 💡 `Console.ReadLine().Trim().ToUpper()`.

### Задание 8
**Тема:** поиск.
**Задание:** спроси слово, проверь, есть ли в нём «а».
> 💡 `word.Contains("а")`.

### Задание 9
**Тема:** инициалы.
**Задание:** спроси имя и фамилию, выведи инициалы с точками.
> 💡 `firstName.Substring(0,1) + "." + lastName.Substring(0,1) + "."`.

### Задание 10
**Тема:** время и день недели.
**Задание:** выведи текущее время (`HH:mm`) и день недели.
> 💡 `DateTime.Now.ToString("HH:mm")`, `DateTime.Now.DayOfWeek`.

### Задание 11
**Тема:** дата в будущем.
**Задание:** выведи дату через 10 дней.
> 💡 `DateTime.Now.AddDays(10).ToString("dd.MM.yyyy")`.

### Задание 12
**Тема:** разница дат.
**Задание:** посчитай, сколько дней прошло от твоей даты рождения.
> 💡 `(DateTime.Now - new DateTime(2013,5,20)).Days`.

### Задание 13
**Тема:** `TimeSpan` — части vs всего.
**Задание:** заведи `new TimeSpan(2, 15, 0)` и выведи его `.Hours`, `.Minutes` и `.TotalMinutes`.
> 💡 `.Hours` = 2, `.Minutes` = 15 (части), `.TotalMinutes` = 135 (всё в минутах).

### Задание 14
**Тема:** момент + промежуток.
**Задание:** вылет `new DateTime(2026, 9, 20, 14, 30, 0)`, полёт `new TimeSpan(3, 40, 0)`. Выведи время прибытия (`HH:mm`).
> 💡 Сложи `departure + flight` — получится `DateTime`; `.ToString("HH:mm")` → `18:10`.

### Задание 15
**Тема:** примерный возраст.
**Задание:** по своей дате рождения выведи примерный возраст в годах.
> 💡 `(int)((DateTime.Today - birth).TotalDays / 365.25)`.

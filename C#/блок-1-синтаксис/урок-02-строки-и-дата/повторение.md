## 🎤 Блиц-вопросы (устно, 2 мин)

## ⌨️ Быстрый разогрев (2 мин)

Набери и запусти — вспоминаем ввод и `$"..."`:
```csharp
Console.Write("Как тебя зовут? ");
string name = Console.ReadLine();
Console.WriteLine($"Привет, {name}!");
```

- Работает — отлично. Сегодня научим программу **обрабатывать** это имя: делать заглавным, считать буквы, брать куски.

## 🌉 Что нового будет сегодня

- **Методы строк** через точку: `имя.ToUpper()`, `имя.Length`, `имя.Substring(0,3)` (в Python было `s.upper()`, `len(s)`, `s[0:3]`).
- **Символ по индексу** `имя[0]` (счёт с 0 — как в Python).
- **Поиск** в строке: `Contains`, `IndexOf`.

## 🔮 Что выведет этот код? (повторяем урок 1, на подумать)

Предскажи вывод, **не запуская**:

1. `Console.WriteLine(10 / 4);`
2. `Console.WriteLine(10.0 / 4);`
3. `Console.WriteLine("Сумма: " + 2 + 3);`
4. `Console.WriteLine("Сумма: " + (2 + 3));`
5. `Console.WriteLine((int)'A');`

<details><summary>✅ Ответы и почему</summary>

1. `2` — оба числа целые, деление **нацело** отбрасывает дробь.
2. `2,5` — есть `double`, делится по-настоящему (на рус. Windows — через запятую).
3. `Сумма: 23` — ❗слева направо: `"Сумма: " + 2` = `"Сумма: 2"`, затем `+ 3` = `"Сумма: 23"` (это **склейка**, не сложение!).
4. `Сумма: 5` — скобки посчитали `2 + 3 = 5` **до** склейки.
5. `65` — это **код** символа `'A'` (из нового в уроке 1: `(int)символ`).
</details>

## 🐞 Есть ли здесь ошибка? (или всё верно?)

Для каждой строки реши: есть ошибка и какая — или всё правильно.

1. `int age = "15";`
2. `double price = 9,99;`
3. `char c = "X";`
4. `int n = Convert.ToInt32(Console.ReadLine())`
5. `Console.WriteLine($"Цена: {price}");`

<details><summary>✅ Ответы</summary>

1. ❌ В `int` нельзя класть строку в кавычках. Нужно `int age = 15;`.
2. ❌ В коде дробь — через **точку**: `9.99`.
3. ❌ `char` — **одинарные** кавычки: `'X'` (двойные — это строка).
4. ❌ Нет `;` в конце команды.
5. ✅ Верно (если `price` объявлена выше).
</details>

> ⚙️ Учителю: проверь, что все помнят `$"..."` и ввод. Кто быстро — пусть выведет имя дважды: как есть и через `ToUpper()`. Разбери «подковырку» №3 из блока «что выведет» — про склейку слева направо: это частая ошибка.

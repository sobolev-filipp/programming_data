## Главные мысли

1. У строки есть **методы** — действия через точку: `name.ToUpper()`.
2. **`.Length` — без скобок** (свойство), методы — со скобками.
3. **Метод возвращает НОВУЮ строку**, старую не меняет: `s = s.ToUpper();`.
4. Символы нумеруются **с 0**: `s[0]` — первый, `s[Length-1]` — последний.
5. Дата: `DateTime.Now` + части (`.Year/.Day/.DayOfWeek`), формат `ToString(...)`, разница дат — `TimeSpan`.
6. **Имена переменных — по-английски** (`firstName`, `city`).

---

## Основные методы строк

```csharp
string s = "  Привет  ";
s.Length                 // 10 (со скобками — ошибка!)
s.ToUpper()              // "  ПРИВЕТ  "
s.ToLower()              // "  привет  "
s.Trim()                 // "Привет"
s.Trim().ToUpper()       // "ПРИВЕТ"  — цепочка методов
"привет".Substring(0, 3) // "при"
"привет".Substring(3)    // "вет"
"привет"[0]              // 'п'  — символ по индексу (с 0!)
"молоко".Replace("о","а")// "малака"
```

| Метод | Что | Пример |
|-------|-----|--------|
| `.Length` | длина (без `()`) | `"кот"→3` |
| `.ToUpper()`/`.ToLower()` | регистр | `"да"→"ДА"` |
| `.Trim()` | обрезать пробелы | `" ok "→"ok"` |
| `.Substring(i,n)` | кусок | `"привет"→"при"` |
| `.Replace(a,b)` | заменить | `"ток"→"том"` |
| `s[i]` | символ по индексу | `"кот"[0]→'к'` |

## Дата и время

```csharp
DateTime now = DateTime.Now;
now.Year   now.Month   now.Day   now.Hour   now.DayOfWeek   // части даты
now.ToString("dd.MM.yyyy")   // 18.08.2026 (MM — месяц, большие!)
now.ToString("HH:mm")        // 19:18

DateTime birthday = new DateTime(2013, 5, 20);
TimeSpan lived = DateTime.Now - birthday;   // промежуток
lived.Days                                  // целых дней
now.AddDays(7)     now.AddYears(1)          // прибавить время
```

Сколько дней до Нового года:
```csharp
DateTime ny = new DateTime(DateTime.Now.Year + 1, 1, 1);
int left = (ny - DateTime.Now).Days;
```

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| `.Length()` ошибка | скобки у свойства | `.Length` без `()` |
| `ToUpper` «не сработал» | не использовал результат | `s = s.ToUpper()` |
| `IndexOutOfRange` | символ за границей | индексы `0..Length-1` |
| дата «наоборот»/месяц не тот | перепутал формат | `dd.MM.yyyy` (`MM` — месяц, `mm` — минуты) |

## Главные мысли

1. У строки есть **методы** — действия через точку: `name.ToUpper()`.
2. **`.Length` — без скобок** (свойство), методы — со скобками.
3. **Метод возвращает НОВУЮ строку**, старую не меняет: `s = s.ToUpper();`.
4. Символы нумеруются **с 0**: `s[0]` — первый, `s[Length-1]` — последний.
5. **`DateTime` — момент** («когда»), **`TimeSpan` — промежуток** («сколько»). Момент − момент = промежуток; момент ± промежуток = момент.
6. У `TimeSpan` есть **части** (`.Hours/.Minutes`) и **всего** (`.TotalHours/.TotalMinutes`) — не путать.
7. **Имена переменных — по-английски** (`firstName`, `city`).

## Основные методы строк

```csharp
string s = "  Привет  ";
s.Length                 // 10 (со скобками — ошибка!)
s.ToUpper()              // "  ПРИВЕТ  "
s.ToLower()              // "  привет  "
s.Trim()                 // "Привет"
s.Trim().ToUpper()       // "ПРИВЕТ"  — цепочка методов
"привет".Substring(0, 3) // "при"
"привет".Substring(3)    // "вет"
"привет"[0]              // 'п'  — символ по индексу (с 0!)
"молоко".Replace("о","а")// "малака"
```

| Метод | Что | Пример |
|-------|-----|--------|
| `.Length` | длина (без `()`) | `"кот"→3` |
| `.ToUpper()`/`.ToLower()` | регистр | `"да"→"ДА"` |
| `.Trim()` | обрезать пробелы | `" ok "→"ok"` |
| `.Substring(i,n)` | кусок | `"привет"→"при"` |
| `.Replace(a,b)` | заменить | `"ток"→"том"` |
| `s[i]` | символ по индексу | `"кот"[0]→'к'` |

## Дата и время: `DateTime` vs `TimeSpan`

- **`DateTime`** — **МОМЕНТ** («когда», точка на календаре): `20.09.2026 14:30`.
- **`TimeSpan`** — **ПРОМЕЖУТОК** («сколько длится», отрезок): `2 ч 15 мин`.

**Арифметика (запомнить!):**

| Действие | Результат |
|----------|-----------|
| момент − момент | промежуток (`TimeSpan`) |
| момент + промежуток | момент (`DateTime`) |
| момент − промежуток | момент (`DateTime`) |

### `DateTime` (момент)

```csharp
DateTime now = DateTime.Now;          // сейчас (дата+время)
DateTime today = DateTime.Today;      // только дата
DateTime d = new DateTime(2026, 9, 20, 14, 30, 0);  // конкретный момент
now.Year  now.Month  now.Day  now.Hour  now.Minute  now.DayOfWeek  // части (int)
now.ToString("dd.MM.yyyy")   // 20.09.2026  (MM — месяц, большие!)
now.ToString("HH:mm")        // 14:30
now.AddDays(7)   now.AddHours(3)   now.AddYears(1)   // прибавить → новый DateTime
```

### `TimeSpan` (промежуток)

```csharp
TimeSpan a = DateTime.Now - d;          // 1) разница моментов
TimeSpan b = new TimeSpan(2, 15, 0);    // 2) собрать: часы, минуты, секунды
TimeSpan c = TimeSpan.FromMinutes(120); // 3) из одной единицы (=2 часа)

b.Days  b.Hours  b.Minutes        // ЧАСТИ: 0, 2, 15  (Hours≤23, Minutes≤59)
b.TotalHours  b.TotalMinutes      // ВСЕГО: 2.25, 135 (дробные)
```

> ⚠️ **Частая путаница:** `.Hours` = 2 (часть), `.TotalHours` = 2.25 (всего). Для «7 дн 5 ч 32 мин» бери **части**; для «всего N часов» — **`.Total…`**.

Пример (аэропорт): `arrival = departure + flight;` (момент), `wait = arrival - DateTime.Now;` (промежуток).

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| `.Length()` ошибка | скобки у свойства | `.Length` без `()` |
| `ToUpper` «не сработал» | не использовал результат | `s = s.ToUpper()` |
| `IndexOutOfRange` | символ за границей | индексы `0..Length-1` |
| дата «наоборот»/месяц не тот | перепутал формат | `dd.MM.yyyy` (`MM` — месяц, `mm` — минуты) |
| промежуток «2.25» вместо «2 ч 15 м» | взял `.TotalHours`, а нужны части | части — `.Hours`/`.Minutes`; всего — `.Total…` |

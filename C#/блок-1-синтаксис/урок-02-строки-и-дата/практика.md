# 🏋️ Практика — Урок 2 «Строки: работа с текстом + дата»

**Блок 1 · Урок 2 | Задачи в 3 уровнях**

> Пиши и **сразу запускай** каждую задачу (F5 / `dotnet run`). У каждой есть блок **«Должно получиться»** и **💡 подсказка**.
> 📌 Шпаргалка: длина `s.Length` (без скобок!) · регистр `s.ToUpper()`/`s.ToLower()` · очистка `s.Trim()` · кусок `s.Substring(0,3)` · символ `s[0]` (с 0) · замена `s.Replace("а","о")` · поиск `s.Contains("а")` · дата `DateTime.Now.ToString("dd.MM.yyyy")`, части `.Year/.Day/.DayOfWeek`, разница дат `(d1 - d2).Days`, `.AddDays(n)`. **Имена — латиницей.**

---

## 🟢 Уровень 1 — базовый

**1. Длина слова.**
Заведи `string word = "динозавр"` и выведи, сколько в нём букв.
**Должно получиться:**
```
Букв: 8
```
> 💡 `word.Length` — без скобок.

**2. Кричим слово.**
Заведи `string word = "привет"` и выведи его ЗАГЛАВНЫМИ.
**Должно получиться:**
```
ПРИВЕТ
```
> 💡 `word.ToUpper()`.

**3. Первая буква.**
Заведи `string name = "Рыцарь"` и выведи только его первый символ.
**Должно получиться:**
```
Первая буква: Р
```
> 💡 `name[0]` — счёт с 0.

**4. Убираем пробелы.**
Заведи `string input = "   ок   "` и выведи его без пробелов, в рамке `[]`.
**Должно получиться:**
```
[ок]
```
> 💡 `$"[{input.Trim()}]"`.

**5. Какое сегодня число.**
Выведи сегодняшнюю дату в формате `дд.мм.гггг` и текущий год отдельно.
**Должно получиться (пример):**
```
Сегодня: 18.08.2026
Год: 2026
```
> 💡 `DateTime.Now.ToString("dd.MM.yyyy")` и `DateTime.Now.Year`.

---

## 🟡 Уровень 2 — средний

**6. Первые три буквы.**
Заведи `string word = "программа"` и выведи его первые три буквы.
**Должно получиться:**
```
про
```
> 💡 `word.Substring(0, 3)`.

**7. Замена буквы.**
Заведи `string word = "молоко"` и замени все «о» на «а».
**Должно получиться:**
```
малака
```
> 💡 `word.Replace("о", "а")`.

**8. Вежливое приветствие.**
Спроси имя (можно с пробелами). Убери пробелы и выведи имя ЗАГЛАВНЫМИ.
**Должно получиться (ввели «  аня  »):**
```
Как тебя зовут?   аня  
Привет, АНЯ!
```
> 💡 `Console.ReadLine().Trim().ToUpper()`.

**9. Есть ли буква?**
Спроси слово и проверь (`true/false`), есть ли в нём буква «о».
**Должно получиться:**
```
Слово: молоко
Есть «о»: True
```
> 💡 `word.Contains("о")`.

**10. Инициалы.**
Спроси имя и фамилию, выведи инициалы с точками.
**Должно получиться:**
```
Имя: Пётр
Фамилия: Иванов
Инициалы: П.И.
```
> 💡 `firstName.Substring(0,1) + "." + lastName.Substring(0,1) + "."`.

**11. Который час.**
Выведи текущее время в формате `HH:mm` и день недели.
**Должно получиться (пример):**
```
Время: 19:18
День недели: Tuesday
```
> 💡 `DateTime.Now.ToString("HH:mm")` и `DateTime.Now.DayOfWeek`.

**12. Через неделю.**
Выведи, какая дата будет через 7 дней (формат `дд.мм.гггг`).
**Должно получиться (пример):**
```
Через неделю: 25.08.2026
```
> 💡 `DateTime.Now.AddDays(7).ToString("dd.MM.yyyy")`.

## 🔴 Уровень 3 — со звёздочкой

**13. Генератор логина.**
Спроси имя и фамилию, сделай логин: имя строчными + длина фамилии.
**Должно получиться:**
```
Имя: Аня
Фамилия: Котова
Логин: аня6
```
> 💡 `$"{firstName.ToLower()}{lastName.Length}"`.

**14. Спрячь телефон.**
Заведи `string phone = "9161234567"` и выведи так, чтобы были видны только последние 4 цифры, а перед ними — звёздочки.
**Должно получиться:**
```
***4567
```
> 💡 `$"***{phone.Substring(phone.Length - 4)}"`.

**15. Сколько ты живёшь.**
Заведи свою дату рождения через `new DateTime(год, месяц, день)` и выведи, сколько дней ты уже прожил(а).
**Должно получиться (пример):**
```
Прожито дней: 4838
```
> 💡 `int days = (DateTime.Now - new DateTime(2013, 5, 20)).Days;`.

**16. Сколько дней до Нового года.**
Посчитай и выведи, сколько дней осталось до 1 января следующего года.
**Должно получиться (пример):**
```
До Нового года: 135 дней
```
> 💡 `DateTime ny = new DateTime(DateTime.Now.Year + 1, 1, 1);` затем `(ny - DateTime.Now).Days`.

**17. Полный профиль.**
Спроси имя (с очисткой) и выведи: имя ЗАГЛАВНЫМИ, число букв, первую букву и сегодняшнюю дату — четырьмя строками.
**Должно получиться (пример):**
```
Как тебя зовут? Аня
Имя: АНЯ
Букв: 3
Первая буква: А
Дата: 18.08.2026
```
> 💡 Соедини `Trim()`, `ToUpper()`, `Length`, `[0]`, `ToString("dd.MM.yyyy")`.

# 🏋️ Практика — Урок 2 «Строки: работа с текстом + дата»

**Блок 1 · Урок 2 | 30 заданий в 3 уровнях по сложности**

> Пиши и **сразу запускай** каждую задачу (F5 / `dotnet run`). У каждой — блок **«Должно получиться»** и **💡 подсказка**.
> 🟢 базовый · 🟡 средний · 🔴 со звёздочкой. Сложность растёт плавно. Часть задач **повторяет урок 1** (арифметика, `/` и `%`, ввод) — чтобы не забывалось.
> 📌 Шпаргалка: длина `s.Length` (без скобок!) · регистр `s.ToUpper()`/`s.ToLower()` · очистка `s.Trim()` · кусок `s.Substring(старт, длина)` · символ `s[0]` (с 0) · замена `s.Replace("а","о")` · поиск `s.Contains("а")`/`s.StartsWith(..)`/`s.IndexOf(..)` · дата `DateTime.Now`, формат `.ToString("dd.MM.yyyy")`, части `.Year/.Day/.DayOfWeek`, разница `(d1 - d2).Days`, `.AddDays(n)`. **Имена — латиницей.**
> 💡 Подсказки — это **наводки** (какой метод вспомнить), а не готовый код. Сначала попробуй сам.

## 🟢 Уровень 1 — базовый (примени изученное)

**1. Длина слова.**
Заведи переменную `string word = "динозавр"`. Программа должна посчитать, **сколько в слове букв**, и вывести это число с подписью.
**Должно получиться:**
```
Букв: 8
```
> 💡 У строки есть свойство, которое возвращает число символов. Пишется без скобок.

**2. Кричим слово.**
Заведи `string word = "привет"` и выведи это же слово, но **целиком заглавными буквами** (как будто кричишь).
**Должно получиться:**
```
ПРИВЕТ
```
> 💡 Есть метод, который делает все буквы строки заглавными («вверх»).

**3. Шёпот.**
Заведи `string word = "ГРОМКО"` (написано капсом) и выведи его **маленькими буквами**.
**Должно получиться:**
```
громко
```
> 💡 Метод-противоположность заглавным — делает буквы строчными («вниз»).

**4. Первая буква.**
Заведи `string name = "Рыцарь"`. Выведи **только самый первый символ** имени.
**Должно получиться:**
```
Первая буква: Р
```
> 💡 К символу строки обращаются по номеру в квадратных скобках. Помни: нумерация начинается с 0.

**5. Последняя буква.**
Заведи `string word = "кот"`. Выведи **последний символ** слова. Важно: слово может быть любой длины, поэтому «последний» нужно вычислить, а не написать номер руками.
**Должно получиться:**
```
Последняя буква: т
```
> 💡 Номер последнего символа — на единицу меньше длины слова (ведь счёт с нуля). Сначала вычисли этот номер, потом возьми символ по нему.

**6. Первые три буквы.**
Заведи `string word = "программа"`. Выведи **кусочек из первых трёх букв**.
**Должно получиться:**
```
про
```
> 💡 Есть метод, который вырезает часть строки: ему говорят, **с какой позиции** начать и **сколько символов** взять.

**7. Замена буквы.**
Заведи `string word = "молоко"`. Замени в нём **все буквы «о» на «а»** и выведи результат.
**Должно получиться:**
```
малака
```
> 💡 Есть метод замены: ему передают, **что** менять и **на что**.

**8. Убираем лишние пробелы.**
Заведи `string input = "   ок   "` (с пробелами по краям). Выведи слово **без крайних пробелов**, а чтобы было видно, что пробелов не осталось, помести его в квадратные скобки `[ ]`.
**Должно получиться:**
```
[ок]
```
> 💡 Есть метод, который срезает пробелы по краям строки. Скобки допиши сам вокруг результата.

**9. Какое сегодня число.**
Выведи **сегодняшнюю дату** в формате «день.месяц.год», а следующей строкой — **отдельно текущий год**.
**Должно получиться (пример):**
```
Сегодня: 06.09.2026
Год: 2026
```
> 💡 Текущий момент даёт `DateTime.Now`. Для красивого формата у даты есть метод форматирования (шаблон `"dd.MM.yyyy"`), а для года — отдельное свойство.

**10. Есть ли буква?**
Заведи `string word = "молоко"`. Проверь, **есть ли в слове буква «о»**, и выведи результат (`True`/`False`).
**Должно получиться:**
```
Есть «о»: True
```
> 💡 Есть метод, который отвечает «да/нет» на вопрос «содержит ли строка вот это».

## 🟡 Уровень 2 — средний (сложнее, комбинируем)

**11. Вежливое приветствие.**
Спроси у пользователя имя. Он может случайно ввести его **с лишними пробелами** и маленькими буквами. Приведи имя в порядок — **убери пробелы по краям и сделай его заглавными** — и поздоровайся.
**Должно получиться (ввели «  аня  »):**
```
Как тебя зовут?   аня  
Привет, АНЯ!
```
> 💡 Тебе нужны два действия над строкой: срезать пробелы и поднять регистр. Их можно применить **одно за другим** (сначала одно, к результату — второе).

**12. Инициалы.**
Спроси имя и фамилию отдельно. Составь из них **инициалы с точками** (первая буква имени, точка, первая буква фамилии, точка).
**Должно получиться (Пётр Иванов):**
```
Инициалы: П.И.
```
> 💡 Первую букву можно взять как кусочек длиной 1 с позиции 0. Точки просто допиши между кусочками.

**13. Который час.**
Выведи **текущее время** в формате «часы:минуты» и, следующей строкой, **какой сегодня день недели**.
**Должно получиться (пример):**
```
Время: 19:18
День недели: Sunday
```
> 💡 Время форматируется шаблоном `"HH:mm"` (внимание: большие `MM` — это месяц, а минуты — маленькие `mm`!). День недели у даты — отдельное свойство, печатается по-английски.

**14. Что будет через неделю.**
Выведи, **какая дата будет ровно через 7 дней** от сегодня (в формате «день.месяц.год»).
**Должно получиться (пример):**
```
Через неделю: 13.09.2026
```
> 💡 У даты есть метод, который прибавляет дни. Прибавь 7, а потом отформатируй результат как в задаче 9.

**15. Очки за имя.** *(повтор урока 1: арифметика)*
Спроси имя. Выведи, **сколько в нём букв**, и придумай «очки» за имя — пусть это будет **число букв, умноженное на 10**.
**Должно получиться (Аня):**
```
Букв: 3
Очки: 30
```
> 💡 Длина строки — это обычное число, и с ним работает арифметика из урока 1. Умножь его на 10.

**16. Где стоит буква.**
Заведи `string word = "робот"`. Найди и выведи **на каком месте (номере) стоит буква «б»**.
**Должно получиться:**
```
Позиция «б»: 2
```
> 💡 Есть метод, который возвращает **номер первого совпадения** символа в строке. Счёт с нуля.

**17. Слово на нужную букву.**
Спроси у пользователя слово и проверь, **начинается ли оно с буквы «а»**. Выведи `True`/`False`.
**Должно получиться (апельсин):**
```
Начинается на «а»: True
```
> 💡 Есть метод, который проверяет **начало** строки (по-английски «starts with»).

**18. Длина без пробелов.** *(повтор: комбинируем методы)*
Заведи фразу `string phrase = "я учу код"`. Посчитай, **сколько в ней символов, если не считать пробелы**.
**Должно получиться:**
```
Без пробелов: 7
```
> 💡 Действуй в два шага: сначала **убери все пробелы** (замени пробел на «пусто»), а потом у того, что получилось, спроси **длину**.

**19. Дни в недели.** *(повтор урока 1: `/` и `%`)*
Спроси у пользователя число дней. Выведи, **сколько это полных недель и сколько дней остаётся** сверх них.
**Должно получиться (30):**
```
Это 4 недели и 2 дня
```
> 💡 Полных недель — это деление нацело на 7. «Остаток» дней даёт оператор остатка `%` (вспомни урок 1).

**20. Предскажи вывод.**
Не запуская, подумай и **запиши, что выведет каждая строка**. Потом проверь запуском.
```csharp
string w = "кот";
w.ToUpper();
Console.WriteLine(w);
Console.WriteLine(w.ToUpper());
```
**Должно получиться:** два твоих предсказания и объяснение, **почему первая строка — не «КОТ»**.
> 💡 Подумай: методы строк не меняют саму строку, а **возвращают новую**. Во второй строке `w.ToUpper()` вызвали, но результат нигде не сохранили — что тогда осталось в `w`?

## 🔴 Уровень 3 — со звёздочкой (собери целое)

**21. Генератор логина.** *(повтор: длина как число)*
Спроси имя и фамилию. Собери из них **логин по правилу**: имя маленькими буквами, а сразу за ним — **число букв в фамилии**.
**Должно получиться (Аня Котова):**
```
Логин: аня6
```
> 💡 Понадобятся: перевод имени в строчные и длина фамилии (это число). Склей их в одну строку — например, через интерполяцию.

**22. Спрячь телефон.**
Заведи `string phone = "9161234567"`. Выведи номер так, чтобы **были видны только последние 4 цифры**, а перед ними стояли звёздочки `***`.
**Должно получиться:**
```
***4567
```
> 💡 Нужно взять **хвост** строки — последние 4 символа. Начальную позицию хвоста вычисли как «длина минус 4» и вырежь кусок оттуда до конца. Звёздочки допиши спереди.

**23. Школьная почта.**
Спроси имя и фамилию. Составь **школьный e-mail** по образцу `имя.фамилия@school.ru` — всё маленькими буквами.
**Должно получиться (Аня Котова):**
```
аня.котова@school.ru
```
> 💡 Переведи имя и фамилию в строчные и собери адрес: имя, точка, фамилия, а затем `@school.ru`.

**24. Сколько ты живёшь.**
Заведи **свою дату рождения** (её создают так: `new DateTime(год, месяц, день)`). Посчитай и выведи, **сколько всего дней ты уже прожил(а)**.
**Должно получиться (пример):**
```
Прожито дней: 4858
```
> 💡 Если из сегодняшней даты вычесть дату рождения, получится «промежуток». У промежутка есть свойство, показывающее, сколько в нём **дней**.

**25. До Нового года.**
Посчитай и выведи, **сколько дней осталось до 1 января следующего года**.
**Должно получиться (пример):**
```
До Нового года: 117 дней
```
> 💡 Собери дату «1 января следующего года» (год = текущий + 1) и вычти из неё сегодняшнюю дату. Дальше — как в задаче 24, возьми дни.

**26. Возраст по году рождения.** *(повтор урока 1: ввод + арифметика)*
Спроси имя и **год рождения**. Выведи приветствие, в котором **посчитан примерный возраст**.
**Должно получиться (Аня, 2013):**
```
Аня, тебе примерно 13 лет
```
> 💡 Год рождения читай как число (не забудь превратить ввод в `int`). Возраст — это разница между текущим годом и годом рождения. Текущий год можно взять у даты.

**27. Найди и почини ошибку.**
Ученик хотел вывести длину слова и его кусочек, но программа **падает при запуске**. Найди **две ошибки** и почини их:
```csharp
string s = "кот";
Console.WriteLine(s.Length());
string piece = s.Substring(1, 5);
```
**Должно получиться:** длина печатается (`3`), а кусочек берётся **без выхода за границы** слова.
> 💡 Первая ошибка: длина — это свойство, у него **не должно быть скобок**. Вторая: слово «кот» короткое, а метод просит 5 символов начиная со второго — их столько нет. Попроси меньше или бери «до конца».

**28. Красивое ФИО.**
Спроси фамилию, имя и отчество (три отдельных ввода). Выведи их в формате **«Фамилия И.О.»** (фамилия полностью, а имя и отчество — только первыми буквами с точками).
**Должно получиться (Иванов Пётр Сергеевич):**
```
Иванов П.С.
```
> 💡 От имени и отчества возьми по первой букве (кусочек длиной 1 с позиции 0) и добавь точки. Фамилию оставь целиком.

**29. Полный профиль.** *(сборка урока)*
Спроси имя (пользователь может ввести с пробелами). Выведи о нём **сразу несколько фактов**: имя заглавными, сколько в нём букв, его первую и последнюю буквы и сегодняшнюю дату.
**Должно получиться (пример, ввели « аня »):**
```
Имя: АНЯ
Букв: 3
Первая: А, последняя: Я
Дата: 06.09.2026
```
> 💡 Здесь пригодится почти всё из урока сразу: срезать пробелы, поднять регистр, узнать длину, взять символ по индексу (первый и последний) и отформатировать дату.

**30. Свой генератор.**
Придумай и собери **свой** генератор, который берёт введённые данные и составляет из них строку по твоему правилу. На выбор:
- 🎮 **никнейм** — из первых букв имени и любимого числа;
- 🔑 **«пароль»** — из кусочков имени, города и года;
- 🎂 **поздравление** — с именем и сегодняшней датой.
**Должно получиться:** программа спрашивает данные и выдаёт строку, собранную по твоей задумке.
> 💡 Используй знакомые приёмы: вырезать кусочки (`Substring`), менять регистр, склеивать строки; если нужно число — вспомни ввод и арифметику из урока 1.

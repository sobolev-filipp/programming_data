# 🧰 Лайфхаки и частые ошибки · Урок 2 «Строки: работа с текстом»

> Трюки и «грабли» по строкам и дате.

---

## 💡 Трюки

1. **`.Length` — без скобок** (свойство). `ToUpper()`, `Trim()` — со скобками (методы).
2. **Цепочка методов:** `Console.ReadLine().Trim().ToUpper()` — прочитать, обрезать пробелы, сделать заглавными за один раз.
3. **Метод возвращает новую строку** — сохраняй результат: `s = s.Trim();`.
4. **Последние N символов:** `s.Substring(s.Length - N)`.
5. **Проверки через `Contains`/`StartsWith`** дают `bool` — очень пригодятся в условиях (урок 3): `if (почта.Contains("@")) ...`.
6. **`IndexOf` вернул -1** — значит не нашёл (а не «нашёл на месте 0»!).
7. **Спецсимволы:** `\n` — новая строка, `\t` — табуляция, `\"` — кавычка внутри строки.
8. **Формат даты:** `ToString("dd.MM.yyyy")` (дни-месяц-год), `ToString("HH:mm")` (часы:минуты). `MM` — месяц, `mm` — минуты.

---

## 🐞 Частые ошибки

| Что видишь | Причина | Лечение |
|-----------|---------|---------|
| `Length()` — ошибка | скобки у свойства | `.Length` **без** скобок |
| строка не изменилась после `ToUpper()` | метод даёт НОВУЮ строку | `s = s.ToUpper();` или выведи результат |
| `IndexOutOfRangeException` (`s[10]`) | символ за границей | индексы `0..Length-1` |
| `ArgumentOutOfRangeException` (`Substring`) | кусок длиннее строки | не выходи за `s.Length` |
| `IndexOf` дал `-1` | искомого нет | `-1` значит «не найдено» |
| пробелы «прилипли» к имени | не обрезал ввод | `Console.ReadLine().Trim()` |
| `Contains` не находит | разный регистр | сравни в одном регистре: `s.ToLower().Contains("а")` |

---

## 🌍 Регистр при поиске

`"Привет".Contains("привет")` → **False** (разный регистр!). Чтобы искать без учёта регистра — приведи обе стороны к одному регистру:
```csharp
"Привет".ToLower().Contains("привет")   // True
```

## ✅ Чек «всё понял»

1. Знаю длину (`.Length` без скобок) и меняю регистр (`ToUpper/ToLower`).
2. Чищу пробелы `Trim()`, соединяю методы цепочкой.
3. Беру кусок `Substring` и символ `s[0]` (счёт с 0), помню про границы.
4. Ищу `Contains`/`IndexOf`; вывожу дату `ToString("dd.MM.yyyy")`.

## 📚 Мини-теория за 5 минут

**Массив** — много значений одного типа под одним именем:
```csharp
int[] scores = { 40, 90, 65 };   // со значениями
int[] a = new int[5];            // 5 пустых ячеек (нули)
```
- Ячейка по номеру: `scores[0]` (с 0!); длина `scores.Length` (без скобок); последний `scores[scores.Length - 1]`.
- Размер **не меняется** (в отличие от списка Python).

**Перебор:** `for` (нужен номер) или `foreach`.
**Итоги руками:** накопитель (`sum += n`, `if (n > max) max = n`).
**Готовые методы:** `a.Sum()`, `a.Max()`, `a.Min()`, `a.Average()`, `a.Count(x => x > 50)`.
**Сортировка:** `Array.Sort(a)`, вывод `string.Join(" ", a)`.

## ✍️ Задания с разбором (делаем вместе)

### Задание 1. Первый и длина
```csharp
int[] a = { 3, 6, 9 };
Console.WriteLine(a[0]);        // 3
Console.WriteLine(a.Length);    // 3
```

### Задание 2. Все элементы
```csharp
int[] a = { 2, 4, 6, 8 };
foreach (int n in a) Console.WriteLine(n);
```

### Задание 3. Сумма готовым методом
```csharp
int[] a = { 10, 20, 30 };
Console.WriteLine(a.Sum());   // 60
```
✅ `.Sum()` — не нужен цикл.

### Задание 4. Максимум
```csharp
int[] a = { 5, 12, 3, 8 };
Console.WriteLine(a.Max());   // 12
```

### Задание 5. Сортировка
```csharp
int[] a = { 4, 1, 3, 2 };
Array.Sort(a);
Console.WriteLine(string.Join(" ", a));   // 1 2 3 4
```

**Задание:** посчитай среднее `{ 50, 70, 90 }` готовым методом.

### Задание 8
**Тема:** сколько по условию.
**Задание:** сколько чисел в `{ 4, 9, 2, 7, 1 }` больше 3.

### Задание 9
**Тема:** параллельные массивы.
**Задание:** выведи «имя — возраст» для `string[] names` и `int[] ages` (по 3).
> 💡 `for (int i = 0; i < names.Length; i++) ...`.

### Задание 10
**Тема:** максимум вручную.
**Задание:** найди максимум в `{ 4, 12, 7 }` без готового метода (накопителем).

**Тема:** 2D-поле.
**Задание:** создай `int[,] map = new int[2,2]`, поставь `map[0,0]=1`, выведи поле.

# 🧰 Лайфхаки и частые ошибки · Урок 6 «Массивы»

> Трюки и «грабли» по массивам. Главное уже показано в уроке — здесь собрано вместе.

---

## 💡 Трюки

1. **`string.Join(" ", a)`** — вывести массив одной строкой без цикла (как `" ".join()` в Python). Разделитель любой: `", "`, `" | "`.
2. **`Array.Sort(a)` + `Array.Reverse(a)`** = сортировка по убыванию.
3. **Сортировать два массива вместе:** `Array.Sort(очки, игроки)` — сортирует `очки` и переставляет `игроки` синхронно (готовый рейтинг!).
4. **Заполнить случайными:** цикл `a[i] = rnd.Next(1, 100);`.
5. **`.Length` — без скобок** (свойство). У 2D — `GetLength(0)` строки, `GetLength(1)` столбцы.
6. **Диаграмма из массива:** `new string('█', a[i] / масштаб)` — бар пропорционально значению (визуально круто).
7. **`new int[5]` уже заполнен нулями** — не надо обнулять вручную.

## 🐞 Частые ошибки

| Что видишь | Причина | Лечение |
|-----------|---------|---------|
| `IndexOutOfRangeException` | вышел за границу (`a[a.Length]`) | индексы `0..Length-1`; последний `a[Length-1]` |
| ищу `a.append(...)`, `a.Add(...)` | массив **не растёт** | задай размер сразу или используй `List` (Урок 8) |
| `Length()` — ошибка | скобки у свойства | `.Length` без скобок |
| `foreach` «не меняет» массив | он только читает | для записи — `for` c индексом (`a[i] = ...`) |
| `Array.Sort` «ничего не вернул» | он меняет **сам** массив | после `Array.Sort(a)` смотри сам `a` |
| данные «разъехались» | параллельные массивы разной длины | держи одинаковую длину, не путай индексы |
| смешал типы в массиве | `int[]` хранит только `int` | один массив — один тип |

## 🎯 Массив или List (на будущее)

- **Массив** (`int[]`) — когда число элементов **известно и не меняется** (дни недели, оценки за четверть, поле игры).
- **`List`** (Урок 8) — когда элементы **добавляются/удаляются** по ходу (список дел, корзина). Это «массив, который растёт».

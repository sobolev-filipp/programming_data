## ⌨️ Быстрый разогрев (2 мин)

Набери и запусти — это уже массив и его перебор:
```csharp
int[] scores = { 40, 90, 65 };
foreach (int s in scores)
    Console.WriteLine(s);
```

- Вывелись три числа — значит, массив создан и перебран. Сегодня научимся считать по нему итоги и сортировать.

## 🌉 Что нового будет сегодня

- **Массив** `int[]` — много значений под одним именем, доступ по номеру `a[0]`.
- Отличие от списка Python: **размер фиксирован**, массив не растёт.
- Итоги (сумма/макс/среднее), сортировка `Array.Sort`, параллельные массивы, диаграмма.

## 🔮 Что выведет этот код? (повторяем урок 5, на подумать)

Предскажи вывод, **не запуская**:

1. `foreach (char c in "abc") Console.Write(c + ".");`
2. `Console.WriteLine(new string('*', 5));`
3. Подковырка (вложенные циклы):
```csharp
for (int i = 1; i <= 2; i++)
    for (int j = 1; j <= 3; j++)
        Console.Write("*");
```
4. Подковырка (`do-while`):
```csharp
int n = 10;
do { Console.Write(n + " "); n++; } while (n < 5);
```

<details><summary>✅ Ответы и почему</summary>

1. `a.b.c.` — перебор по буквам, после каждой добавляем «.».
2. `*****` — `new string('*', 5)` повторяет символ 5 раз.
3. `******` (6 звёзд) — ❗внутренний цикл (3 раза) крутится на **каждый** шаг внешнего (2 раза): 2×3 = 6.
4. `10 ` — ❗`do-while` выполняет тело **хотя бы раз**, даже если условие (`10 < 5`) сразу ложно.
</details>

## 🐞 Есть ли здесь ошибка? (или всё верно?)

1. `do { Console.Write("hi"); } while (x > 0)`
2. `int[] a = {1,2,3}; foreach (int n in a) n = n * 2;`
3. `foreach (char c in "кот") Console.WriteLine(c);`
4. `string line = new string("*", 5);`
5. `Console.WriteLine(new string('=', 10));`

<details><summary>✅ Ответы</summary>

1. ❌ Нет `;` после `while (x > 0)`.
2. ❌ Переменную `foreach` менять нельзя (она «только чтение») — для записи нужен `for` с индексом.
3. ✅ Верно — выведет к, о, т по строкам.
4. ❌ `new string` ждёт **символ** в одинарных кавычках: `'*'`, а не строку `"*"`.
5. ✅ Верно — строка из 10 знаков `=`.
</details>

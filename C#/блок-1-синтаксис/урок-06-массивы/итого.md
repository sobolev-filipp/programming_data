# Урок 6 «Массивы» — итого (шпаргалка) 📌

> Открой, чтобы за 3 минуты вспомнить урок. Только суть и примеры.

---

## Главные мысли

1. **Массив** — пронумерованные ячейки одного типа под общим именем.
2. Индексы идут **с 0**; последний — `a[a.Length - 1]`.
3. **Размер фиксирован** (в отличие от списка Python) — массив не растёт.
4. `.Length` — длина (**без скобок**).
5. Перебор — `for` (нужен номер) или `foreach` (просто пройти).
6. Итоги — накопителем; сортировка — `Array.Sort` / `Array.Reverse`.

---

## Создание и доступ

```csharp
int[] scores = { 40, 90, 65, 20 };   // со значениями
int[] marks = new int[5];            // 5 нулей

scores[0]                  // 40 (первый)
scores[scores.Length - 1]  // 20 (последний)
scores[2] = 100;           // изменить ячейку
scores.Length              // 4
```

⚠️ `scores[4]` у массива из 4 ячеек → `IndexOutOfRangeException`.

---

## Перебор

```csharp
for (int i = 0; i < a.Length; i++)   // нужен номер
    Console.WriteLine($"{i}: {a[i]}");

foreach (int n in a)                 // просто пройти
    Console.WriteLine(n);
```

---

## Итоги и сортировка

```csharp
int sum = 0, max = a[0];
foreach (int n in a) { sum += n; if (n > max) max = n; }
double average = a.Average();   // готовый метод

Array.Sort(a);                 // по возрастанию
Array.Reverse(a);              // перевернуть
Console.WriteLine(string.Join(" ", a));   // вывод одной строкой
```

## Строки и параллельные массивы

```csharp
string[] players = { "Аня", "Боря" };
int[] scores     = {  40,    90   };
players[1]  // Боря   ↔  scores[1]  // 90  (один игрок)
```

## Готовые методы (LINQ)

```csharp
int[] scores = { 40, 90, 65, 20 };
scores.Max()     // 90
scores.Min()     // 20
scores.Sum()     // 215
scores.Average() // 53,75 (дробное!)
scores.Count(x => x > 50)   // 2 — сколько больше 50
Array.IndexOf(scores, 65)   // 2 — где 65 (или -1)
scores.Contains(90)         // True
```
💡 Решает готовый метод — бери его, а не цикл.

## 2D (кратко)

```csharp
int[,] field = new int[3, 4];
field[1, 2] = 7;
field.GetLength(0)  // строки = 3
field.GetLength(1)  // столбцы = 4
```

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| `IndexOutOfRange` | вышел за границу | индексы `0..Length-1` |
| нет `append` | массив не растёт | `List` (Урок 8) |
| `.Length()` | скобки у свойства | `.Length` без `()` |
| данные разъехались | параллельные массивы разной длины | одинаковая длина |

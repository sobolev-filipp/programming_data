> 🧭 **Как читать урок.** Пока переменная хранила **одно** значение. А если нужно хранить **100 очков** или **имена всех игроков**? Для этого есть **массив** — «коробка с ячейками под номерами». В Python это был список, но у массива C# важное отличие: **размер задают заранее и он не меняется**. Переберём массивы циклами, посчитаем итоги (в т.ч. **готовыми методами**), отсортируем — и построим таблицу рекордов с диаграммой. Имена переменных — **по-английски**.

**Задача:** хранить много значений в массиве, перебирать его, считать итоги (руками и **готовыми методами `Max/Min/Sum/Average`**), сортировать; собрать «Топ игроков» с диаграммой.

> 💡 **Главная мысль урока:** **массив — это пронумерованные ячейки под общим именем** (`scores[0]`, `scores[1]`…). Размер фиксирован, а обрабатывают массив либо циклом, либо **готовым методом**.

## Часть 0 — Разминка: список Python → массив C# (5 минут)

**Python (прошлый год):**
```python
scores = [40, 90, 65]
print(scores[0])         # 40
scores.append(20)        # список умеет расти
```

**C# (сегодня):**
```csharp
int[] scores = { 40, 90, 65 };
Console.WriteLine(scores[0]);   // 40
// scores.append(20)  ← так НЕЛЬЗЯ: у массива фиксированный размер!
```

| Python (список) | C# (массив) |
|-----------------|-------------|
| `scores = [40, 90]` | `int[] scores = { 40, 90 };` |
| хранит что угодно | все элементы **одного типа** (`int[]`) |
| умеет расти (`append`) | **размер фиксирован** |
| `len(scores)` | `scores.Length` |

> 🐍 **Мостик:** индексы и перебор — как в Python. Но массив **не растёт**. (Растущий список `List` — в Уроке 8.)

## Часть 1 — Что такое массив и как его создать (12 минут)

Массив создают **двумя способами**:

```csharp
int[] scores = { 40, 90, 65, 20 };   // 1) сразу со значениями
int[] marks = new int[5];            // 2) пустой на 5 ячеек (заполнится нулями)
```

**Доступ к ячейке — по индексу в `[ ]`**, счёт **с 0**:
```csharp
Console.WriteLine(scores[0]);    // 40 — первый
scores[2] = 100;                 // изменить третью ячейку
```

![Схема: массив scores {40,90,65,20} с индексами 0..3, scores[1]=90, Length=4](изображения/массив-индексы.svg)

**Длина массива — `.Length`:**
```csharp
Console.WriteLine(scores.Length);            // 4
Console.WriteLine(scores[scores.Length - 1]);// 20 — последний (индекс Length-1)
```

> ⚠️ **Границы!** У массива из 4 ячеек индексы `0..3`. `scores[4]` → `IndexOutOfRangeException`. Последний — всегда `Length - 1`.

> ✍️ **Мини-задание 1 (3 мин):** заведи `int[] days = { 31, 28, 31, 30 }` и выведи первый элемент, последний и сколько всего.
> <details><summary>💡 подсказка</summary><code>days[0]</code>, <code>days[days.Length-1]</code>, <code>days.Length</code>.</details>

## Часть 2 — Перебор массива (10 минут)

**`for` — когда нужен номер (индекс):**
```csharp
int[] scores = { 40, 90, 65, 20 };
for (int i = 0; i < scores.Length; i++)
    Console.WriteLine($"Игрок {i + 1}: {scores[i]} очков");
```

**`foreach` — когда номер не важен:**
```csharp
foreach (int s in scores)
    Console.WriteLine(s);
```

**Заполнить массив с клавиатуры** — через `for`:
```csharp
int[] marks = new int[3];
for (int i = 0; i < marks.Length; i++)
{
    Console.Write($"Балл {i + 1}: ");
    marks[i] = Convert.ToInt32(Console.ReadLine());
}
```

> 💡 **Лайфхак: `for` или `foreach`?** Нужен номер или **менять** элементы — `for` (`scores[i] = ...`). Просто прочитать — `foreach`.

> ✍️ **Мини-задание 2 (3 мин):** заведи массив из 5 чисел и через `foreach` выведи каждое, умноженное на 2.
> <details><summary>💡 подсказка</summary><code>foreach (int n in numbers) Console.WriteLine(n * 2);</code></details>

## Часть 3 — Итоги вручную и сортировка (12 минут)

**Сумма, максимум** — перебором с накопителем (приём из Урока 4):
```csharp
int[] scores = { 40, 90, 65, 20 };
int sum = 0, max = scores[0];
foreach (int s in scores)
{
    sum += s;                 // копим сумму
    if (s > max) max = s;     // запоминаем наибольший
}
Console.WriteLine($"Сумма: {sum}, максимум: {max}");
```

**Сортировка — готовые команды** `Array.Sort` и `Array.Reverse`:
```csharp
int[] numbers = { 5, 2, 8, 1 };
Array.Sort(numbers);              // по возрастанию: 1 2 5 8
Array.Reverse(numbers);          // перевернуть: 8 5 2 1
Console.WriteLine(string.Join(" ", numbers));   // 8 5 2 1
```

> 💡 **Лайфхак: `string.Join`** выводит массив одной строкой: `string.Join(" ", numbers)` → `"8 5 2 1"` (как `" ".join(...)` в Python).

> ✍️ **Мини-задание 3 (3 мин):** массив `{ 7, 3, 9, 1, 5 }` отсортируй по возрастанию и выведи через `string.Join`.
> <details><summary>💡 подсказка</summary><code>Array.Sort(a);</code> затем <code>Console.WriteLine(string.Join(", ", a));</code></details>

## Часть 4 — ⭐ Готовые методы: `Max`, `Sum`, `Average`… (12 минут)

Считать сумму или максимум циклом можно, но C# уже умеет это **готовыми методами** — просто зови их прямо у массива:

```csharp
int[] scores = { 40, 90, 65, 20 };
Console.WriteLine(scores.Max());       // 90    — наибольший
Console.WriteLine(scores.Min());       // 20    — наименьший
Console.WriteLine(scores.Sum());       // 215   — сумма
Console.WriteLine(scores.Average());   // 53,75 — среднее (дробное!)
```

**Поиск в массиве:**
```csharp
Console.WriteLine(Array.IndexOf(scores, 65));  // 2  — на каком месте 65 (или -1)
Console.WriteLine(scores.Contains(90));        // True — есть ли 90
```

**Сколько подходит под условие** — `Count` с «правилом-стрелочкой» `x => …` (читается: «для каждого `x` проверить …»):
```csharp
Console.WriteLine(scores.Count(x => x > 50));  // 2 — сколько чисел больше 50
```

**Сортировка по убыванию — одной строкой:**
```csharp
int[] top = scores.OrderByDescending(x => x).ToArray();  // 90 65 40 20
Console.WriteLine(string.Join(" ", top));
```

> 💡 **Лайфхак: решает готовый метод — бери его, а не цикл.** `scores.Max()` короче и понятнее, чем цикл с `if`. Эти методы (`Max/Min/Sum/Average/Count`) называют **LINQ** — они есть у массивов, `List` и других коллекций.

> ✍️ **Мини-задание 4 (3 мин):** для `int[] a = { 12, 7, 25, 3, 18 }` выведи через готовые методы: максимум, среднее и сколько чисел больше 10.
> <details><summary>💡 подсказка</summary><code>a.Max()</code>, <code>a.Average()</code>, <code>a.Count(x => x > 10)</code>.</details>

## Часть 5 — Массив строк и параллельные массивы (10 минут)

Массив бывает не только из чисел — например, **`string[]`** из имён:
```csharp
string[] players = { "Аня", "Боря", "Вика" };
foreach (string name in players)
    Console.WriteLine(name);
```

**Параллельные массивы** — два массива, где элемент под одним индексом связан: `players[i]` набрал `scores[i]`.
```csharp
string[] players = { "Аня", "Боря", "Вика" };
int[] scores     = {  40,    90,     65   };
for (int i = 0; i < players.Length; i++)
    Console.WriteLine($"{players[i]}: {scores[i]} очков");
```

- 👀 Держи массивы **одной длины** и не путай индексы: `players[1]` и `scores[1]` — про одного игрока (Боря, 90).

> ✍️ **Мини-задание 5 (3 мин):** заведи `string[] fruits` и `int[] prices` (по 3 элемента) и выведи «фрукт — цена».
> <details><summary>💡 подсказка</summary><code>for (int i = 0; i &lt; fruits.Length; i++) Console.WriteLine($"{fruits[i]} — {prices[i]}");</code></details>

## Часть 6 — Двумерные массивы (кратко) (8 минут)

Для **таблиц и игровых полей** есть двумерный массив `int[,]` — «строки × столбцы»:
```csharp
int[,] field = new int[3, 4];        // 3 строки, 4 столбца (все нули)
field[1, 2] = 7;                     // строка 1, столбец 2 → 7
Console.WriteLine(field.GetLength(0));// 3 — число строк
Console.WriteLine(field.GetLength(1));// 4 — число столбцов
```

Перебор — вложенными циклами (Урок 5!):
```csharp
for (int r = 0; r < field.GetLength(0); r++)
{
    for (int c = 0; c < field.GetLength(1); c++)
        Console.Write(field[r, c] + " ");
    Console.WriteLine();
}
```

- 👀 `field[строка, столбец]` — две координаты. На этом строятся «крестики-нолики», «морской бой», карты уровней.

> ✍️ **Мини-задание 6 (2 мин):** создай `int[,] map = new int[2, 2]`, поставь `map[0,0] = 1` и выведи всё поле вложенными циклами.
> <details><summary>💡 подсказка</summary>Два цикла по <code>GetLength(0)</code> и <code>GetLength(1)</code>.</details>

## Часть 7 — 🏆 Проект «Топ игроков» с диаграммой (14 минут)

Соберём таблицу рекордов: параллельные массивы, поиск чемпиона и **диаграмма-бары**. Готовый код — в [`материалы/Program.cs`](материалы/Program.cs):

```csharp
string[] players = { "Аня", "Боря", "Вика", "Гена" };
int[] scores     = {  40,    90,     65,     20   };

// чемпион (параллельные массивы)
int max = scores[0];
string champion = players[0];
for (int i = 1; i < scores.Length; i++)
    if (scores[i] > max) { max = scores[i]; champion = players[i]; }

// диаграмма: длина бара = scores / 5
Console.WriteLine("=== ТОП ИГРОКОВ ===");
for (int i = 0; i < players.Length; i++)
{
    Console.Write($"{players[i],-6} ");                 // имя по левому краю
    Console.WriteLine(new string('█', scores[i] / 5));   // бар из блоков
}

Console.ForegroundColor = ConsoleColor.Yellow;
Console.WriteLine($"🏆 Чемпион: {champion} ({max} очков)");
Console.ResetColor();
Console.WriteLine($"Средний балл: {scores.Average()}");  // готовый метод!
```

- 👀 Здесь сошлось всё: массивы, параллельные индексы (имя ↔ очки), цикл-поиск чемпиона, узор `new string` (бар), цвет и готовый `scores.Average()`.

> 🧩 **Для 5–7 классов:** выведи имена и очки списком. 🎓 **Глубже:** покажи максимум через `scores.Max()` и сколько игроков набрали больше 50 (`scores.Count(x => x > 50)`).

## 🐞 Разбор частых ошибок

| Симптом | Что случилось | Как починить |
|---------|---------------|--------------|
| `IndexOutOfRangeException` | вышел за границу (`a[a.Length]`) | индексы `0..Length-1`; последний — `a[Length-1]` |
| хочу `a.append(...)` — нет такого | массив **не растёт** | задай размер сразу, или используй `List` (Урок 8) |
| `Length()` — ошибка | скобки у свойства | `.Length` — **без** скобок |
| данные «разъехались» | параллельные массивы разной длины | держи их одной длины |
| `Array.Sort` «не работает» | ждал новый массив | `Array.Sort(a)` меняет **сам** массив `a` |
| `Average()` дал дробь | среднее — дробное | это нормально; для округления — `Math.Round(a.Average(), 1)` |
| `new int[5]` уже с нулями | думал, что пусто | пустой `int`-массив заполнен нулями |

> ⚠️ **Главное правило:** массив — фиксированные ячейки `0..Length-1`. Итоги — накопителем или готовыми методами (`Max/Sum/Average`); сортировка — `Array.Sort`.

## 🎓 Глубже

**Сортировка двух массивов вместе:** `Array.Sort(scores, players)` — сортирует `scores` и переставляет `players` синхронно (готовый рейтинг!).

**Фильтр через LINQ:** `scores.Where(x => x > 50).ToArray()` — новый массив только из чисел больше 50.

**Массив случайных чисел:**
```csharp
Random rnd = new Random();
int[] lottery = new int[6];
for (int i = 0; i < lottery.Length; i++) lottery[i] = rnd.Next(1, 50);
```

**`foreach` не меняет элементы** — только читает; для записи нужен `for` (`a[i] = ...`).

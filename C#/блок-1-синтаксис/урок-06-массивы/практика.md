# 🏋️ Практика — Урок 6 «Массивы»

**Блок 1 · Урок 6 | 30 заданий в 3 уровнях по сложности**

> Пиши и **сразу запускай** (F5 / `dotnet run`). У каждой задачи — **«Должно получиться»** и **💡 подсказка**.
> 🟢 базовый · 🟡 средний · 🔴 со звёздочкой. Часть задач **повторяет уроки 1–5** (циклы, `%`, `double`, строки) — чтобы не забывалось.
> 📌 Шпаргалка: массив `int[] a = { 10, 20, 30 };` или `new int[5]` · элемент `a[0]` (с 0) · размер `a.Length` · перебор `for`/`foreach` · `Array.Sort(a)`, `Array.Reverse(a)`, `Array.IndexOf(a, x)` · в строку `string.Join(" ", a)` · готовые: `a.Max()`, `a.Min()`, `a.Sum()`, `a.Average()`, `a.Count(x => условие)`. **Имена — латиницей.**
> 💡 Подсказки — это **наводки** (какой приём вспомнить), а не готовый код.

## 🟢 Уровень 1 — базовый (примени изученное)

**1. Мой первый массив.**
Заведи массив из 5 любимых чисел и выведи **все элементы** через пробел в одну строку.
**Должно получиться (пример):**
```
5 3 8 1 9
```
> 💡 Массив задаётся в фигурных скобках. Чтобы вывести все элементы, перебери их `foreach` (печатая через `Write` с пробелом) — или сразу собери в строку готовым способом склейки массива.

**2. Массив с клавиатуры.**
Спроси у пользователя 5 чисел по очереди, сложи их в массив и потом выведи все.
**Должно получиться (ввели 10, 20, 30, 40, 50):**
```
Твой массив: 10 20 30 40 50
```
> 💡 Создай пустой массив на 5 мест (`new int[5]`). В цикле `for` по индексу `i` записывай очередное введённое число в `a[i]`.

**3. Сумма массива.**
Заведи массив `int[] a = { 5, 3, 8, 1, 9 }` и посчитай **сумму** его элементов.
**Должно получиться:**
```
Сумма: 26
```
> 💡 Либо копилка + `foreach` (как в уроке 5), либо готовый метод, который сразу считает сумму массива.

**4. Самое большое.**
В том же массиве найди **наибольший** элемент.
**Должно получиться:**
```
Максимум: 9
```
> 💡 Есть готовый метод, возвращающий наибольший элемент массива. (Или найди «рекордсменом» вручную, как в уроке 5.)

**5. Самое маленькое.**
Найди **наименьший** элемент массива.
**Должно получиться:**
```
Минимум: 1
```
> 💡 Есть парный к максимуму готовый метод для наименьшего.

**6. Средний балл.** *(повтор урока 1: `double`)*
Заведи массив оценок `int[] marks = { 4, 5, 3, 5, 3 }` и посчитай **средний балл** (округли до 2 знаков).
**Должно получиться:**
```
Средний балл: 4
```
> 💡 Есть готовый метод для среднего. Он уже возвращает дробное значение — просто округли его до двух знаков.

**7. Размер и края.**
Заведи массив и выведи, **сколько в нём элементов**, а также его **первый** и **последний** элементы.
**Должно получиться (для { 5, 3, 8, 1, 9 }):**
```
Элементов: 5
Первый: 5
Последний: 9
```
> 💡 Число элементов — свойство `Length`. Последний элемент стоит на индексе `Length - 1` (счёт с 0).

**8. Красивый вывод.**
Заведи массив и выведи его в виде `[5, 3, 8, 1, 9]` (элементы через запятую в скобках).
**Должно получиться:**
```
[5, 3, 8, 1, 9]
```
> 💡 Есть готовый способ склеить массив в строку с любым разделителем (здесь разделитель — «, »). Скобки допиши вокруг.

**9. Наведём порядок.**
Заведи массив вперемешку и **отсортируй** его по возрастанию, потом выведи.
**Должно получиться (из { 5, 3, 8, 1, 9 }):**
```
1 3 5 8 9
```
> 💡 Есть готовая команда сортировки массива «на месте». После неё выведи массив как в задаче 1.

**10. Задом наперёд.**
Заведи массив и выведи его элементы **в обратном порядке**.
**Должно получиться (из { 1, 2, 3, 4, 5 }):**
```
5 4 3 2 1
```
> 💡 Есть готовая команда, которая переворачивает массив «на месте». (Или пройди его циклом `for` от последнего индекса к нулевому.)

## 🟡 Уровень 2 — средний (считаем и ищем)

**11. Сколько чётных.** *(повтор урока 1: `%`)*
Заведи массив и посчитай, **сколько в нём чётных чисел**.
**Должно получиться (для { 3, 8, 1, 6, 2, 7 }):**
```
Чётных: 3
```
> 💡 Либо счётчик + `foreach` с условием чётности, либо готовый метод подсчёта по условию, которому передают «правило» в виде `x => x % 2 == 0`.

**12. Больше среднего.**
Посчитай, **сколько элементов больше среднего** значения массива.
**Должно получиться (для { 5, 3, 8, 1, 9 }, среднее 5,2):**
```
Выше среднего: 2
```
> 💡 Сначала вычисли среднее (готовым методом), сохрани его в переменную. Потом перебором посчитай, сколько элементов его превышают.

**13. Где стоит число.**
Заведи массив и спроси число. Выведи, **на каком месте (индексе)** оно стоит, или что его нет.
**Должно получиться (ищем 8 в { 5, 3, 8, 1, 9 }):**
```
Число 8 на месте 2
```
> 💡 Есть готовый метод поиска индекса элемента. Он возвращает `-1`, если элемента нет — обработай этот случай условием.

**14. Список имён.**
Заведи массив имён `string[] names = { "Аня", "Боря", "Вика" }`. Выведи их по одному с номером.
**Должно получиться:**
```
1. Аня
2. Боря
3. Вика
```
> 💡 Массив бывает не только из чисел, но и из строк. Перебери его циклом `for` по индексу, чтобы был номер (`i + 1`).

**15. Имя и очки.**
Заведи **два параллельных массива**: имена и их очки (одинаковой длины). Выведи «имя: очки» для каждого.
**Должно получиться:**
```
Аня: 70
Боря: 95
Вика: 88
```
> 💡 Параллельные массивы связаны по индексу: `names[i]` и `scores[i]` — про одного человека. Иди по индексу `i` и печатай пару.

**16. Кто лидер.**
В тех же параллельных массивах найди **имя того, у кого больше всех очков**.
**Должно получиться:**
```
Лидер: Боря (95)
```
> 💡 Найди **индекс** максимума (перебором запоминай индекс, где очки больше текущего рекорда), а потом по этому индексу возьми и имя, и очки.

**17. По убыванию.**
Заведи массив чисел и выведи их **от большего к меньшему**.
**Должно получиться (из { 5, 3, 8, 1, 9 }):**
```
9 8 5 3 1
```
> 💡 Отсортируй по возрастанию готовой командой, а потом переверни массив. (Или используй сортировку по убыванию `OrderByDescending`.)

**18. Гистограмма.** *(повтор урока 5: узоры)*
Заведи массив чисел и нарисуй **гистограмму**: каждое число — строка из стольких звёзд, каково значение.
**Должно получиться (для { 3, 7, 2, 5 }):**
```
***
*******
**
*****
```
> 💡 Перебери массив и на каждое число печатай строку из стольких звёзд (`new string('*', число)` из урока 1).

**19. Сумма только чётных.** *(повтор урока 1: `%`)*
Посчитай **сумму только чётных** элементов массива.
**Должно получиться (для { 5, 3, 8, 1, 9, 4 }):**
```
Сумма чётных: 12
```
> 💡 Заведи копилку, перебирай массив и прибавляй элемент только тогда, когда он чётный.

**20. Предскажи вывод.**
Не запуская, скажи, что напечатает код и **не будет ли ошибки**. Потом проверь.
```csharp
int[] a = { 10, 20, 30 };
for (int i = 0; i <= a.Length; i++)
    Console.WriteLine(a[i]);
```
**Должно получиться:** объяснение, **на каком шаге программа сломается и почему**.
> 💡 В массиве из 3 элементов индексы — 0, 1, 2. А до какого индекса дойдёт цикл с условием `i <= a.Length`? Обращение к несуществующему индексу вызывает ошибку.

## 🔴 Уровень 3 — со звёздочкой (собери целое)

**21. Тройка призёров.**
Заведи массив результатов и выведи **три самых больших** значения (пьедестал).
**Должно получиться (из { 5, 3, 8, 1, 9, 7 }):**
```
1 место: 9
2 место: 8
3 место: 7
```
> 💡 Отсортируй массив по убыванию, а потом выведи первые три элемента (индексы 0, 1, 2).

**22. Полная статистика.**
Заведи массив и выведи по нему **отчёт**: количество, сумма, среднее, минимум и максимум.
**Должно получиться (для { 5, 3, 8, 1, 9 }):**
```
Количество: 5
Сумма: 26
Среднее: 5,2
Минимум: 1
Максимум: 9
```
> 💡 Каждую величину даёт свой готовый метод (`Length`, `Sum`, `Average`, `Min`, `Max`). Среднее округли до двух знаков.

**23. Есть или нет.**
Заведи массив и спроси число. Ответь, **есть оно в массиве или нет** (`да`/`нет`).
**Должно получиться (ищем 4 в { 5, 3, 8, 1, 9 }):**
```
Числа 4 в массиве нет
```
> 💡 Поиск индекса возвращает `-1`, если элемента нет. Значит, «есть» — это когда результат поиска **не** равен `-1`.

**24. Отчёт по классу.** *(повтор урока 1: арифметика)*
В параллельных массивах (имена + баллы) выведи каждого ученика, а в конце — **средний балл по классу** и **имя лучшего**.
**Должно получиться:**
```
Аня: 70
Боря: 95
Вика: 88
Средний балл: 84,33
Лучший: Боря
```
> 💡 Собери вместе приёмы задач 15 и 16: перебор пар, сумма баллов для среднего, поиск индекса максимума для имени лидера.

**25. Таблица-сетка (2D).**
Заведи двумерный массив 3×3 (`int[,]`) и выведи его в виде таблицы (по строкам).
**Должно получиться:**
```
1 2 3
4 5 6
7 8 9
```
> 💡 У двумерного массива два индекса: `m[i, j]` — строка `i`, столбец `j`. Нужны **вложенные** циклы: внешний по строкам, внутренний по столбцам (перевод строки — после внутреннего).

**26. Найди и почини ошибку.**
Программа должна вывести все элементы массива, но падает с ошибкой:
```csharp
int[] a = { 10, 20, 30 };
for (int i = 1; i <= a.Length; i++)
    Console.WriteLine(a[i]);
```
**Должно получиться:** выводятся 10, 20, 30 без ошибок.
> 💡 Две беды с границами: индексы начинаются с **0** (а не с 1), и последний индекс — это `Length - 1` (а не `Length`). Поправь и старт, и условие цикла.

**27. Второй по величине.**
Заведи массив и найди **второе по величине** число (не максимум, а следующее за ним).
**Должно получиться (для { 5, 3, 8, 1, 9 }):**
```
Второе по величине: 8
```
> 💡 Самый простой путь — отсортировать по убыванию и взять элемент с индексом 1. (Продвинуто: пройти массив, держа два «рекорда» — первый и второй.)

**28. Переворот своими руками.**
Переверни массив **без** готовой команды `Array.Reverse` — только циклом.
**Должно получиться (из { 1, 2, 3, 4, 5 }):**
```
5 4 3 2 1
```
> 💡 Меняй местами пары «с краёв к центру»: первый с последним, второй с предпоследним и т.д. Для обмена двух значений понадобится временная переменная. Цикл идёт только до середины.

**29. Рейтинг с диаграммой.** *(повтор урока 5: узоры + параллельные)*
В параллельных массивах (имена игроков + очки) выведи для каждого имя и **полоску из звёзд**, длина которой отражает очки (например, одна звезда за каждые 10 очков).
**Должно получиться (пример):**
```
Аня   | *******
Боря  | *********
Вика  | ********
```
> 💡 Иди по индексу. Длину полоски посчитай делением очков на 10 (целочисленным). Полоску собери `new string('*', длина)`.

**30. Свой анализатор.**
Собери **свою** программу-анализатор массива данных — на выбор:
- 🌡 температуры за неделю: средняя, самый тёплый/холодный день;
- 🛒 цены товаров: самая дорогая/дешёвая, средняя, сколько дороже 100;
- 🎮 очки игроков: рейтинг по убыванию с диаграммой.
**Должно получиться:** осмысленный отчёт по твоему массиву данных.
> 💡 Собери знакомое: заполнение массива, готовые методы (`Max/Min/Average/Sum/Count`), сортировку и — по желанию — диаграмму из звёзд.

# 🏋️ Практика — Урок 6 «Массивы»

**Блок 1 · Урок 6 | Задачи в 3 уровнях**

> Пиши и **сразу запускай** каждую задачу (F5 / `dotnet run`). У каждой есть блок **«Должно получиться»** и **💡 подсказка**.
> 📌 Шпаргалка: `int[] a = { 1, 2, 3 };` или `new int[5]`; ячейка `a[0]` (с 0!); длина `a.Length`; перебор `for`/`foreach`; готовые методы `a.Max()`/`a.Min()`/`a.Sum()`/`a.Average()`/`a.Count(x => ...)`; `Array.Sort(a)`, `Array.IndexOf(a, x)`; вывод `string.Join(" ", a)`. **Имена — латиницей.**

---

## 🟢 Уровень 1 — базовый

**1. Знакомство с массивом.**
Заведи `int[] numbers = { 5, 8, 3, 10, 1 }`. Выведи первый элемент, последний и сколько всего.
**Должно получиться:**
```
Первый: 5
Последний: 1
Всего: 5
```
> 💡 `numbers[0]`, `numbers[numbers.Length - 1]`, `numbers.Length`.

**2. Все элементы.**
Выведи все числа из `{ 4, 8, 15, 16, 23 }`, каждое с новой строки (через `foreach`).
**Должно получиться:**
```
4
8
15
16
23
```
> 💡 `foreach (int n in numbers) Console.WriteLine(n);`.

**3. Сумма массива (готовым методом).**
Посчитай сумму `{ 10, 20, 30, 40 }` через `.Sum()`.
**Должно получиться:**
```
Сумма: 100
```
> 💡 `numbers.Sum()`.

**4. Максимум (готовым методом).**
Найди наибольшее в `{ 7, 2, 9, 4, 6 }` через `.Max()`.
**Должно получиться:**
```
Максимум: 9
```
> 💡 `numbers.Max()`.

---

## 🟡 Уровень 2 — средний

**5. Заполни с клавиатуры.**
Создай массив на 3 числа, заполни вводом (через `for`), потом выведи все три одной строкой.
**Должно получиться:**
```
Число 1: 5
Число 2: 8
Число 3: 2
Ты ввёл: 5 8 2
```
> 💡 В цикле `a[i] = Convert.ToInt32(Console.ReadLine());`, вывод — `string.Join(" ", a)`.

**6. Среднее и лучший.**
Для `{ 60, 80, 100, 40 }` выведи среднее и максимум готовыми методами.
**Должно получиться:**
```
Среднее: 70
Лучший: 100
```
> 💡 `a.Average()` и `a.Max()`.

**7. Сортировка.**
Отсортируй `{ 7, 3, 9, 1, 5 }` по возрастанию и выведи одной строкой.
**Должно получиться:**
```
1, 3, 5, 7, 9
```
> 💡 `Array.Sort(a);` затем `Console.WriteLine(string.Join(", ", a));`.

**8. Сколько больше 50.**
В `{ 40, 90, 65, 20, 55 }` посчитай, сколько чисел больше 50 — через `.Count(...)`.
**Должно получиться:**
```
Больше 50: 3
```
> 💡 `a.Count(x => x > 50)`.

**9. Прайс-лист (параллельные массивы).**
Заведи `string[] products = { "Хлеб", "Молоко", "Сыр" }` и `int[] prices = { 30, 70, 250 }`. Выведи «товар — цена».
**Должно получиться:**
```
Хлеб — 30
Молоко — 70
Сыр — 250
```
> 💡 `for (int i = 0; i < products.Length; i++) Console.WriteLine($"{products[i]} — {prices[i]}");`.

## 🔴 Уровень 3 — со звёздочкой

**10. Топ игроков с диаграммой.**
Заведи параллельные массивы имён и очков, найди чемпиона и нарисуй диаграмму-бары (длина бара = очки / 5), чемпиона выведи жёлтым.
**Должно получиться (пример):**
```
=== ТОП ИГРОКОВ ===
Аня    ████████
Боря   ██████████████████
...
🏆 Чемпион: Боря (90 очков)
```
> 💡 Это проект урока: параллельные массивы, `new string('█', scores[i]/5)`, `Console.ForegroundColor`.

**11. Максимум и его номер.**
Заполни массив из 6 случайных чисел (1..100), выведи их, найди максимум и **на каком он месте** (индекс + 1).
**Должно получиться (пример):**
```
Числа: 12 88 45 90 7 33
Максимум 90 на месте 4
```
> 💡 Ищи руками: `if (a[i] > max) { max = a[i]; pos = i; }`; «место» = `pos + 1`. Или `Array.IndexOf(a, a.Max())`.

**12. Игровое поле (2D).**
Создай `int[,] map = new int[3, 3]`, поставь «клад» `map[1,1] = 1`, выведи поле вложенными циклами (1 — клад, 0 — пусто).
**Должно получиться:**
```
0 0 0
0 1 0
0 0 0
```
> 💡 Два цикла по `GetLength(0)` и `GetLength(1)`, внутри `Console.Write(map[r,c] + " ")`, после ряда `WriteLine()`.

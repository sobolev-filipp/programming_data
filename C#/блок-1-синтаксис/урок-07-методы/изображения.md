# 🖼 Изображения к уроку 7 — что показать на проекторе

Одна ключевая схема (метод как машина).

---

## `метод-схема.svg` — метод: вход → работа → выход
**Когда показать:** Часть 3 (`return`) — держать на экране, пока разбираете возврат и «печатает vs возвращает».

**Что на схеме:** слева входят **параметры** (`a = 2`, `b = 3`), в центре «машина» — тело метода `int Add(int a, int b) { return a + b; }`, справа выходит **результат** `return 5`. Внизу — две карточки: `void` (ДЕЛАЕТ, результата нет) и типизированный (`int/string…`, ВОЗВРАЩАЕТ через `return`, результат можно использовать).

**Что сказать:** «Метод — это машина: подаём параметры, внутри происходит работа, наружу выходит результат через `return`. Если метод `void` — он просто что-то делает и ничего не отдаёт. Если у метода есть тип (`int`, `string`) — он возвращает значение, которое можно положить в переменную и использовать дальше».

**Приём на проекторе:** написать `int r = Add(2, 3);` и показать, что `r` теперь можно использовать (`r + 1`). Затем сравнить с `void ПечатьСуммы(...)`, результат которого использовать нельзя. Прямой мостик: Python `return` vs `print`.

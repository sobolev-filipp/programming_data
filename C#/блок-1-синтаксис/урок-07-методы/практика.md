# 🏋️ Практика — Урок 7 «Методы»

**Блок 1 · Урок 7 | 30 заданий в 3 уровнях по сложности**

> Пиши и **сразу запускай** (F5 / `dotnet run`). У каждой задачи — **«Должно получиться»** и **💡 подсказка**.
> 🟢 базовый · 🟡 средний · 🔴 со звёздочкой. Часть задач **повторяет уроки 1–6** (массивы, строки, `%`, циклы) — теперь оформляй их как **методы**.
> 📌 Шпаргалка: метод `int Sum(int a, int b) { return a + b; }` · без результата — `void` · короткий метод стрелкой `int Square(int n) => n * n;` · параметр по умолчанию `void Hi(string name = "друг")` · массив-параметр `int Sum(int[] a)` · менять оригинал — `ref`, вернуть несколько — `out` · рекурсия — метод зовёт сам себя. Методы пиши **внизу** файла (после основного кода). **Имена методов — `PascalCase`, переменные — `camelCase`.**
> 💡 Подсказки — это **наводки** (какой приём вспомнить), а не готовый код.

## 🟢 Уровень 1 — базовый (примени изученное)

**1. Приветствие.**
Напиши метод `Greet`, который принимает имя и печатает «Привет, <имя>!». Вызови его для трёх разных имён.
**Должно получиться:**
```
Привет, Аня!
Привет, Боря!
Привет, Вика!
```
> 💡 Метод ничего не возвращает — значит, его тип `void`. Имя приходит параметром `string`. Внутри — обычный `WriteLine` с интерполяцией.

**2. Квадрат числа.**
Напиши метод `Square`, который **возвращает** квадрат переданного числа. Выведи квадрат числа 7.
**Должно получиться:**
```
49
```
> 💡 Раз метод отдаёт результат, у него тип `int` и внутри `return`. Возвращает он `n * n`.

**3. Сумма двух чисел.**
Напиши метод `Sum(a, b)`, который возвращает их сумму. Проверь на 3 и 4.
**Должно получиться:**
```
Сумма: 7
```
> 💡 Два параметра `int`, внутри `return a + b`. Результат подставь в вывод.

**4. Чётное ли число.** *(повтор урока 1: `%`)*
Напиши метод `IsEven(n)`, который **возвращает `true`/`false`** — чётное число или нет. Проверь на 10 и 7.
**Должно получиться:**
```
10 чётное: True
7 чётное: False
```
> 💡 Метод, возвращающий «да/нет», имеет тип `bool`. Внутри верни результат сравнения остатка с нулём (само сравнение уже даёт `true`/`false`).

**5. Большее из двух.**
Напиши метод `Max(a, b)`, возвращающий большее из двух чисел. Проверь на 8 и 5.
**Должно получиться:**
```
Больше: 8
```
> 💡 Внутри — условие: если `a` больше, верни `a`, иначе `b`. Можно и тернарником в одну строку.

**6. Приветствие с умолчанием.**
Сделай метод `Hi`, у которого имя — **параметр по умолчанию** «друг». Вызови его один раз без аргумента и один раз с именем.
**Должно получиться:**
```
Привет, друг!
Привет, Аня!
```
> 💡 Значение по умолчанию задаётся прямо в описании параметра: `string name = "друг"`. Если при вызове аргумент не передать — подставится оно.

**7. Линия из звёзд.** *(повтор урока 1)*
Напиши метод `Line(n)`, который печатает строку из `n` звёзд. Вызови его для 3, 5 и 7.
**Должно получиться:**
```
***
*****
*******
```
> 💡 Метод типа `void`. Внутри собери строку из повторов приёмом `new string('*', n)` и выведи.

**8. Площадь прямоугольника.**
Напиши метод `Area(a, b)`, возвращающий площадь. Выведи площадь прямоугольника 4×6.
**Должно получиться:**
```
Площадь: 24
```
> 💡 Два параметра, `return a * b`.

**9. Куб числа стрелкой.**
Напиши **короткий** метод-стрелку `Cube`, возвращающий куб числа (n·n·n). Проверь на 3.
**Должно получиться:**
```
27
```
> 💡 Короткий метод из одного выражения пишут через `=>` без `{}` и без слова `return`: тело — сразу выражение `n * n * n`.

**10. Три приветствия.**
Заведи массив имён и вызови метод `Greet` из задачи 1 **для каждого** имени в цикле.
**Должно получиться (для { "Аня", "Боря" }):**
```
Привет, Аня!
Привет, Боря!
```
> 💡 Перебери массив имён `foreach` и на каждом шаге зови `Greet` с текущим именем. Один метод — много вызовов.

## 🟡 Уровень 2 — средний (методы над данными)

**11. Сумма массива.** *(повтор урока 6)*
Напиши метод `SumArray(int[] a)`, возвращающий сумму всех элементов. Проверь на { 5, 3, 8, 1, 9 }.
**Должно получиться:**
```
Сумма: 26
```
> 💡 Массив передаётся как параметр `int[] a`. Внутри — знакомая копилка с `foreach`, в конце `return`.

**12. Максимум массива.** *(повтор урока 6)*
Напиши метод `MaxArray(int[] a)`, возвращающий наибольший элемент.
**Должно получиться (для { 5, 3, 8, 1, 9 }):**
```
Максимум: 9
```
> 💡 Внутри — приём «рекордсмен» (старт с первого элемента), в конце верни рекорд.

**13. Считаем гласные.** *(повтор урока 5: строки)*
Напиши метод `CountVowels(string word)`, возвращающий число гласных в слове.
**Должно получиться (для «программа»):**
```
Гласных: 3
```
> 💡 Внутри перебирай буквы и считай те, что входят в строку-«список гласных» (метод `Contains`). Верни счётчик.

**14. Среднее массива.** *(повтор урока 1: `double`)*
Напиши метод `Average(int[] a)`, возвращающий среднее (дробное) значение.
**Должно получиться (для { 4, 5, 3, 5, 3 }):**
```
Среднее: 4
```
> 💡 Тип результата — `double`. Сумму подели на количество (`a.Length`) «дробным» делением. Округление сделаешь уже при выводе.

**15. Простое число.** *(повтор урока 4)*
Напиши метод `IsPrime(n)`, возвращающий `true`, если число простое. Проверь на 17 и 12.
**Должно получиться:**
```
17 простое: True
12 простое: False
```
> 💡 Внутри перебирай делители от 2 до числа: если нашёлся делитель — сразу `return false`; если цикл прошёл без делителей — `return true`. Ранний `return` заменяет флажок.

**16. Переворот слова.** *(повтор урока 5)*
Напиши метод `Reverse(string word)`, возвращающий слово задом наперёд.
**Должно получиться (для «кот»):**
```
ток
```
> 💡 Внутри собери результат, дописывая каждую букву в начало, и верни его.

**17. Периметр через сумму.**
Напиши метод `Sum3(a, b, c)` и с его помощью посчитай периметр треугольника со сторонами 3, 4, 5 (позови метод, не складывай в основном коде).
**Должно получиться:**
```
Периметр: 12
```
> 💡 Смысл — переиспользовать метод: напиши `Sum3`, возвращающий сумму трёх чисел, и вызови его для сторон. Один метод пригодится для любых троек.

**18. Факториал циклом.**
Напиши метод `Factorial(n)`, возвращающий факториал (произведение 1·2·…·n). Проверь на 5.
**Должно получиться:**
```
5! = 120
```
> 💡 Внутри — копилка-произведение (старт с 1, урок 4), в конце `return`.

**19. Предскажи вывод.**
Не запуская, скажи, что напечатает код и **что вернёт метод**. Потом проверь.
```csharp
Console.WriteLine(Test(4));

int Test(int n)
{
    if (n > 3) return n * 10;
    Console.WriteLine("не больше 3");
    return 0;
}
```
**Должно получиться:** объяснение, **почему строка «не больше 3» не печатается**.
> 💡 `return` не просто отдаёт значение — он **сразу завершает** метод. Что произойдёт, когда условие `n > 3` истинно?

**20. Оценка методом.** *(повтор урока 3: switch)*
Напиши метод `Grade(score)`, возвращающий оценку словом (90+ «отлично», 75+ «хорошо», 60+ «удовл», иначе «плохо»). Проверь на нескольких баллах.
**Должно получиться (82):**
```
Хорошо
```
> 💡 Внутри — цепочка `if/else if` с `return` в каждой ветке (или `switch`-выражение). Тип результата — `string`.

## 🔴 Уровень 3 — со звёздочкой (ref, out, рекурсия)

**21. Обмен значений.**
Напиши метод `Swap`, который **меняет местами** два переданных числа (у самих переменных снаружи).
**Должно получиться (было a=1, b=2):**
```
До: 1 2
После: 2 1
```
> 💡 Чтобы метод менял **оригиналы**, параметры объявляют с `ref`. Внутри обмен делают через временную переменную (как в уроке 6, задача 28).

**22. Минимум и максимум сразу.**
Напиши метод `MinMax`, который по массиву **возвращает два значения** — минимум и максимум — через `out`.
**Должно получиться (для { 5, 3, 8, 1, 9 }):**
```
Минимум: 1
Максимум: 9
```
> 💡 `out`-параметры — способ «вернуть несколько результатов». Объяви два `out int` и заполни их внутри метода перебором.

**23. Факториал рекурсией.**
Напиши метод `Factorial(n)`, который вызывает **сам себя** (рекурсия), а не использует цикл. Проверь на 5.
**Должно получиться:**
```
5! = 120
```
> 💡 У рекурсии две части: **база** (при n = 1 или 0 верни 1 — дальше не спускаемся) и **шаг** (иначе верни `n * Factorial(n - 1)`). Без базы будет бесконечный спуск.

**24. Степень рекурсией.**
Напиши рекурсивный метод `Power(base, exp)` — основание в степени. Проверь на 2 и 5.
**Должно получиться:**
```
2^5 = 32
```
> 💡 База: степень 0 → результат 1. Шаг: `base * Power(base, exp - 1)`.

**25. Обратный отсчёт рекурсией.**
Напиши рекурсивный метод `Countdown(n)`, который печатает числа от n до 1, а потом «Пуск!».
**Должно получиться (n = 3):**
```
3
2
1
Пуск!
```
> 💡 База: если n стало 0 — напечатай «Пуск!» и выходи. Шаг: напечатай n и вызови `Countdown(n - 1)`.

**26. Калькулятор-метод.** *(повтор урока 3: switch)*
Напиши метод `Calc(a, b, sign)`, который возвращает результат операции по знаку (`+ - * /`). Позови его для нескольких операций.
**Должно получиться (8, 2, «*»):**
```
Результат: 16
```
> 💡 Внутри — `switch` по знаку, в каждой ветке `return` своего результата. Для деления предусмотри случай нуля.

**27. Найди и почини ошибку.**
Метод должен возвращать площадь, но код не компилируется:
```csharp
int Area(int a, int b)
{
    Console.WriteLine(a * b);
}
```
**Должно получиться:** метод `Area(4, 6)` возвращает `24`, и его результат можно вывести или использовать в расчёте.
> 💡 Метод объявлен как `int` (обещает вернуть число), но внутри ничего не **возвращает** — только печатает. Реши: либо он и правда должен **возвращать** результат (тогда что добавить?), либо это `void`-метод. По условию нужен именно возвращающий.

**28. Мини-библиотека.** *(сборка)*
Собери **несколько своих методов** (например `Square`, `IsEven`, `Max`, `SumArray`) и меню, которое по выбору пользователя вызывает нужный. Повторяй, пока не выберут выход.
**Должно получиться:** программа-меню, где каждый пункт зовёт свой метод.
> 💡 Соедини знакомое: методы (этот урок), `while(true)` + `break` и `switch` по выбору (уроки 3–4). Каждый пункт меню — вызов одного метода.

**29. RPG-удар.**
Напиши метод `Attack`, который уменьшает здоровье цели на случайный урон и печатает полоску здоровья из символов. Позови его несколько раз в «бою».
**Должно получиться (пример):**
```
Удар на 12! HP: [#######___] 70
Удар на 20! HP: [#####_____] 50
```
> 💡 Урон бери `Random` (урок 4). Полоску собери из символов по текущему HP (сколько «делений» осталось). Здоровье удобно передавать и возвращать/менять через `ref`.

**30. Свой набор методов.**
Придумай и собери **свою** маленькую «библиотеку» методов на одну тему — на выбор:
- 📐 геометрия: площади круга, квадрата, треугольника;
- 🔤 текст: перевернуть, посчитать буквы, сделать КАПСом;
- 🎲 игра: бросок кубика, проверка победы, подсчёт очков.
**Должно получиться:** 3–4 осмысленных метода, которые ты вызываешь из основного кода.
> 💡 Каждый метод — одно понятное действие с параметрами и (обычно) `return`. Собери их в одном файле и продемонстрируй вызовы.

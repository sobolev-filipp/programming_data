# 🏋️ Практика — Урок 7 «Методы»

**Блок 1 · Урок 7 | Задачи в 3 уровнях**

> Пиши и **сразу запускай** каждую задачу (F5 / `dotnet run`). У каждой есть блок **«Должно получиться»** и **💡 подсказка**.
> 📌 Шпаргалка: метод пишут внизу файла. `void Name(параметры) { ... }` — делает; `int Name(...) { return ...; }` — возвращает. Короткая запись: `int Cube(int x) => x*x*x;`. Массив-параметр — `int[] a`. `ref` — менять оригинал, `out` — вернуть несколько значений. Рекурсия — метод зовёт сам себя (с базой). **Имена: методы `PascalCase`, переменные `camelCase`.** Не забудь **вызвать** метод!

---

## 🟢 Уровень 1 — базовый

**1. Приветствие-метод.**
Напиши метод `void Welcome()`, печатающий «Добро пожаловать!», и вызови его **дважды**.
**Должно получиться:**
```
Добро пожаловать!
Добро пожаловать!
```
> 💡 `void Welcome() => Console.WriteLine("Добро пожаловать!");`, затем `Welcome();` два раза.

**2. Линия нужной длины.**
Напиши `void Line(int n)`, печатающий строку из `n` звёздочек. Вызови `Line(5)` и `Line(10)`.
**Должно получиться:**
```
*****
**********
```
> 💡 `void Line(int n) => Console.WriteLine(new string('*', n));`.

**3. Удвоитель.**
Напиши `int Double(int x)`, возвращающий `x * 2`. Выведи `Double(7)`.
**Должно получиться:**
```
14
```
> 💡 `int Double(int x) => x * 2;`, затем `Console.WriteLine(Double(7));`.

**4. Сумма двух.**
Напиши `int Add(int a, int b)` и выведи `Add(15, 27)`.
**Должно получиться:**
```
42
```
> 💡 `int Add(int a, int b) => a + b;`.

## 🟡 Уровень 2 — средний

**5. Приветствие по имени.**
Напиши `void Greet(string name)` и вызови для двух имён.
**Должно получиться:**
```
Привет, Аня!
Привет, Боря!
```
> 💡 `void Greet(string name) => Console.WriteLine($"Привет, {name}!");`.

**6. Кто больше.**
Напиши `int Max(int a, int b)`, возвращающий большее. Выведи `Max(8, 3)`.
**Должно получиться:**
```
8
```
> 💡 Тернарник: `=> a > b ? a : b;`.

**7. Чётное?**
Напиши `bool IsEven(int n)`. Выведи `IsEven(4)` и `IsEven(7)`.
**Должно получиться:**
```
True
False
```
> 💡 `bool IsEven(int n) => n % 2 == 0;`.

**8. Сумма массива (массив-параметр).**
Напиши `int Sum(int[] a)`, возвращающий сумму всех элементов. Проверь на `{ 10, 20, 30 }`.
**Должно получиться:**
```
Сумма: 60
```
> 💡 Внутри — `int total = 0; foreach (int x in a) total += x; return total;`.

**9. Максимум массива.**
Напиши `int Max(int[] a)`, возвращающий наибольший элемент. Проверь на `{ 4, 12, 7, 9 }`.
**Должно получиться:**
```
Максимум: 12
```
> 💡 `int m = a[0]; foreach (int x in a) if (x > m) m = x; return m;`.

## 🔴 Уровень 3 — со звёздочкой

**10. Обмен через `ref`.**
Напиши `void Swap(ref int a, ref int b)`, меняющий значения местами. Проверь на двух числах.
**Должно получиться:**
```
До: 3 и 8
После: 8 и 3
```
> 💡 Через временную: `int t = a; a = b; b = t;`. При вызове — `Swap(ref x, ref y);`.

**11. Минимум и максимум через `out`.**
Напиши `void MinMax(int[] a, out int min, out int max)`. Проверь на `{ 5, 2, 9, 1 }`.
**Должно получиться:**
```
Мин: 1, Макс: 9
```
> 💡 Присвой оба `out` внутри метода: `min = a[0]; max = a[0];`, потом перебор.

**12. Факториал (рекурсия).**
Напиши **рекурсивный** метод `int Factorial(int n)` и выведи `Factorial(5)`.
**Должно получиться:**
```
120
```
> 💡 База: `if (n <= 1) return 1;`. Шаг: `return n * Factorial(n - 1);`.

**13. Степень (рекурсия).**
Напиши рекурсивный `int Power(int a, int b)` — `a` в степени `b`. Выведи `Power(2, 10)`.
**Должно получиться:**
```
1024
```
> 💡 База: `if (b == 0) return 1;`. Шаг: `return a * Power(a, b - 1);`.

**14. Мини RPG-удар.**
Напиши `int Damage()` (случайное 10..20) и `void DrawHp(string name, int hp)` (рисует `█` в количестве `hp/5`). Ударь дракона (hp=60) три раза в цикле и рисуй его полосу.
**Должно получиться (пример):**
```
Дракон HP 45 █████████
Дракон HP 32 ██████
Дракон HP 19 ███
```
> 💡 `int Damage() => rnd.Next(10, 21);` (rnd создать до методов); в цикле `hp -= Damage(); DrawHp("Дракон", hp);`.

## 📚 Мини-теория за 5 минут

**Метод** — своя команда. Пишут внизу файла, вызывают по имени.
- `void Name(...) { ... }` — **делает**; `int Name(...) { return ...; }` — **возвращает**.
- Короткая запись: `int Cube(int x) => x * x * x;`.
- Параметры — **с типами**; можно передать **массив** `int[] a`.
- **`ref`** — метод меняет оригинал; **`out`** — метод возвращает несколько значений.
- **Рекурсия** — метод вызывает сам себя (с **базой** — когда остановиться).
- Метод надо **вызвать**: `Name(...)`.

### Задание 4. Массив как параметр
**Задание:** метод `Sum(int[] a)` возвращает сумму массива.
```csharp
int[] nums = { 1, 2, 3 };
Console.WriteLine(Sum(nums));   // 6
int Sum(int[] a)
{
    int total = 0;
    foreach (int x in a) total += x;
    return total;
}
```

### Задание 5. Рекурсия
**Задание:** факториал через рекурсию.
```csharp
Console.WriteLine(Factorial(5));   // 120
int Factorial(int n)
{
    if (n <= 1) return 1;            // база
    return n * Factorial(n - 1);     // шаг
}
```
✅ Без базы (`if`) была бы бесконечная рекурсия.

# 🧰 Лайфхаки и частые ошибки · Урок 7 «Методы»

> Трюки и «грабли» по методам. Главное уже показано в уроке — здесь собрано вместе.

---

## 💡 Трюки

1. **Короткая запись `=>`** для метода из одной строки: `int Cube(int x) => x*x*x;` — без `{ }` и `return`.
2. **Правило «не повторяйся» (DRY):** написал один и тот же код дважды — вынеси в метод. Менять потом — в одном месте.
3. **Понятные имена** методов = код читается как рассказ: `DrawHp()`, `CalcDamage()`.
4. **Метод вызывает метод** — большие задачи собирают из маленьких «кирпичиков».
5. **Параметр по умолчанию** заменяет «варианты» метода: `void Greet(string name = "гость")`.
6. **Выделить код в метод автоматически:** в Visual Studio выдели кусок → `Ctrl+.` → «Extract Method».
7. **Локальные функции** (внизу `Program.cs`) — `static` не нужен; можно вызывать даже до их определения.

## 🐞 Частые ошибки

| Что видишь | Причина | Лечение |
|-----------|---------|---------|
| `not all code paths return a value` | типизированный метод без `return` | верни значение из всех веток |
| метод «ничего не делает» | забыл его **вызвать** | определить мало — нужен вызов `Name(...)` |
| `cannot convert 'string' to 'int'` | тип аргумента не совпал с параметром | передай значение нужного типа |
| `No overload ... takes N arguments` | передал не столько аргументов | число/порядок аргументов = как в параметрах |
| хочу использовать результат `void` | `void` ничего не возвращает | сделай метод типизированным + `return` |
| `local function ... already defined` | пытался «перегрузить» локальную функцию | у локальных функций нет перегрузки — используй параметр по умолчанию |

## 🎯 void или с возвратом — что выбрать

- **`void`** — метод что-то **делает** и результат не нужен: печать, рисование, изменение на экране.
- **Типизированный (`int`, `string`, `bool`…)** — метод **считает и отдаёт** результат, который используешь дальше (в переменной, в вычислении, в условии).

## ✅ Чек «всё понял»

1. Пишу метод (`void` или с типом) и **вызываю** его.
2. Передаю параметры с типами; знаю про параметр по умолчанию.
3. Возвращаю результат через `return` и использую его.
4. Понимаю разницу «печатает» (`void`) и «возвращает».

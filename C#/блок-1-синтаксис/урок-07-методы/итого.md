# Урок 7 «Методы» — итого (шпаргалка) 📌

> Открой, чтобы за 3 минуты вспомнить урок. Только суть и примеры. Методы — `PascalCase`, переменные — `camelCase`.

---

## Главные мысли

1. **Метод** — своя команда: пишешь один раз, вызываешь много.
2. `void Name(...)` — **делает**; `int Name(...)` + **`return`** — **возвращает**.
3. **Параметры — с типами**: `void Greet(string name)`; можно передать **массив** `int[] a`.
4. **`ref`** — метод меняет оригинал; **`out`** — метод возвращает несколько значений.
5. **Рекурсия** — метод вызывает сам себя; обязательно с **базой** (когда остановиться).
6. Метод надо и **написать**, и **вызвать** (`Name(...)`).

---

## Объявление и вызов

```csharp
Greet("Аня");                  // вызов
int s = Add(2, 3);             // вызов с результатом

void Greet(string name) => Console.WriteLine($"Привет, {name}!");   // делает
int Add(int a, int b) => a + b;                                     // возвращает
```

`void` — печатает/рисует; типизированный — возвращает значение (можно использовать: `int r = Square(4);`).

## Массив как параметр

```csharp
int Sum(int[] a)
{
    int total = 0;
    foreach (int x in a) total += x;
    return total;
}
Console.WriteLine(Sum(new[] { 1, 2, 3 }));   // 6
```
⚠️ Массив передаётся по ссылке — если менять ячейки внутри, снаружи тоже изменится.

## ref и out

```csharp
void AddBonus(ref int value, int bonus) { value += bonus; }
int coins = 10;  AddBonus(ref coins, 5);  // coins = 15

void MinMax(int[] a, out int min, out int max)
{
    min = a[0]; max = a[0];
    foreach (int x in a) { if (x < min) min = x; if (x > max) max = x; }
}
MinMax(new[]{5,2,9}, out int lo, out int hi);   // lo=2, hi=9
```
`ref`/`out` пишут и при объявлении, **и** при вызове.

## Рекурсия

```csharp
int Factorial(int n)
{
    if (n <= 1) return 1;            // база
    return n * Factorial(n - 1);     // шаг
}
Factorial(5);   // 120
```
Без базы → `StackOverflowException`.

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| `not all code paths return a value` | нет `return` во всех ветках | верни значение везде |
| метод «ничего не делает» | забыл **вызвать** | `Name(...)` |
| `ref`/`out` ошибка | нет `ref`/`out` при вызове | пиши их и в вызове |
| `StackOverflowException` | рекурсия без базы | добавь условие остановки |

## Что должно остаться в голове

1. Пишу метод (`void` или с типом) и **вызываю** его.
2. Передаю параметры с типами, в т.ч. **массив**.
3. Возвращаю `return`; знаю `ref` (менять оригинал) и `out` (несколько значений).
4. Умею рекурсию (метод вызывает сам себя, с базой).

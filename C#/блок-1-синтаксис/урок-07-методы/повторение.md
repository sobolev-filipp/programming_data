## ⌨️ Быстрый разогрев (2 мин)

Набери и запусти — это уже метод:
```csharp
Hello();

void Hello() => Console.WriteLine("Привет!");
```

- «Привет!» вывелось дважды, а написали мы его **один раз** — в этом сила методов. Сегодня научимся передавать в них данные и возвращать результат.

## 🌉 Что нового будет сегодня

- **Метод** — своя команда (как `def` в Python), но с **типами** у параметров и результата.
- `void` (делает) vs типизированный (`return` возвращает).
- Параметры с типами, параметр по умолчанию.

## 🔮 Что выведет этот код? (повторяем урок 6, на подумать)

Предскажи вывод, **не запуская**:

1. `int[] a = {10, 20, 30}; Console.WriteLine(a[1]);`
2. `int[] a = {5, 3, 8, 1}; Array.Sort(a); Console.WriteLine(a[0]);`
3. Подковырка:
```csharp
int[] a = {2, 4, 6};
int sum = 0;
foreach (int n in a) sum += n;
Console.WriteLine(sum);
```
4. `int[] a = {1, 2, 3}; Console.WriteLine(a.Length);`

<details><summary>✅ Ответы и почему</summary>

1. `20` — индекс 1 это **второй** элемент (счёт с 0).
2. `1` — после `Array.Sort` массив по возрастанию: `1 3 5 8`, первый — `1`.
3. `12` — накопитель складывает все: 2+4+6.
4. `3` — `Length` это **количество** элементов (а индексы при этом 0..2).
</details>

## 🐞 Есть ли здесь ошибка? (или всё верно?)

1. `int[] a = new int[3]; a[3] = 5;`
2. `int[] a = {1, 2, 3}; a.Add(4);`
3. `int[] a = {1, 2, 3}; Console.WriteLine(a[a.Length]);`
4. `int[] a = {4, 7, 2}; int max = a.Max();`
5. `int[] a = {1, 2, 3}; Console.WriteLine(a.Length);`

<details><summary>✅ Ответы</summary>

1. ❌ Индексы 0..2; `a[3]` — выход за границу.
2. ❌ У массива нет `Add` — он не растёт (это умеет `List`).
3. ❌ `a[a.Length]` за границей: нужно `a[a.Length - 1]` для последнего.
4. ✅ Верно — `max` станет 7.
5. ✅ Верно — выведет 3.
</details>

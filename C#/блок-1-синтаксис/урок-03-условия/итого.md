# Урок 3 «Условия + switch» — итого (шпаргалка) 📌

> Открой, чтобы за 3 минуты вспомнить урок. Только суть и примеры.

---

## Главные мысли

1. `if` в C#: условие в **`( )`**, тело в **`{ }`**; сравнение — **`==`** (двойное!).
2. Логика: `&&` (И), `||` (ИЛИ), `!` (НЕ) — вместо `and/or/not`.
3. Лестница `if / else if / else` — срабатывает **первая** подходящая ветка.
4. **`switch`** — выбор из многих по одному значению; в каждом `case` обязателен **`break`**; `default` — «иначе».
5. `switch`-выражение `x switch { ... => ..., _ => ... }` — короткий выбор значения.
6. Тернарник `условие ? да : нет` — выбор из двух в одну строку.

---

## if / else if / else

```csharp
if (очки >= 90)      Console.WriteLine("5");
else if (очки >= 75) Console.WriteLine("4");
else if (очки >= 60) Console.WriteLine("3");
else                 Console.WriteLine("2");
```

| Сравнение | `==` `!=` `>` `<` `>=` `<=` |
|-----------|------------------------------|
| Логика | `&&` И · `\|\|` ИЛИ · `!` НЕ |

⚠️ `=` — «положи», `==` — «сравни». В условии — `==`.

---

## switch (главное новое!)

```csharp
switch (day)
{
    case 1: case 2: case 3: case 4: case 5:
        Console.WriteLine("Будний"); break;   // группировка
    case 6:
    case 7:
        Console.WriteLine("Выходной"); break;
    default:
        Console.WriteLine("Нет такого"); break;
}
```

- `case значение:` — если совпало.
- **`break;`** — обязателен в конце каждого `case`.
- `default:` — если ничего не подошло.
- Работает и со строками: `case "старт":`.

### switch-выражение (короткая форма)
```csharp
string grade = mark switch
{
    5 => "отлично",
    4 => "хорошо",
    _ => "плохо"      // _ = «всё остальное»
};
```

## Тернарник

```csharp
string who = age >= 18 ? "взрослый" : "ребёнок";
```

---

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| `Control cannot fall through` | забыл `break` | `break;` в конце `case` |
| условие «сломалось» | `=` вместо `==` | сравнение — `==` |
| `&&`/`\|\|` не работают | написал `and`/`or` | в C# — `&&`, `\|\|`, `!` |
| `switch` не совпал | регистр/пробелы в строке | `.Trim()`, единый регистр |

---

## Что должно остаться в голове

1. Пишу `if (условие) { ... } else { ... }`; сравнение `==`.
2. Логика `&& || !`; лестница `else if`.
3. **Умею `switch`**: `case`, `break`, `default`, группировка, строки.
4. Знаю короткие формы: `switch`-выражение и тернарник `?:`.

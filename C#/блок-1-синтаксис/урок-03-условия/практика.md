# 🏋️ Практика — Урок 3 «Условия: if / else / switch»

**Блок 1 · Урок 3 | 30 заданий в 3 уровнях по сложности**

> Пиши и **сразу запускай** (F5 / `dotnet run`). У каждой задачи — **«Должно получиться»** и **💡 подсказка**.
> 🟢 базовый · 🟡 средний · 🔴 со звёздочкой. Часть задач **повторяет уроки 1–2** (арифметика, `%`, строки, дата) — чтобы не забывалось.
> 📌 Шпаргалка: сравнения `> < >= <= == !=` · «и» `&&`, «или» `||`, «не» `!` · `if (усл) {...} else if (усл) {...} else {...}` · `switch (x) { case 1: ...; break; default: ...; }` · тернарник `усл ? A : B`. **Имена — латиницей.**
> 💡 Подсказки — это **наводки** (какую идею/приём вспомнить), а не готовый код.

## 🟢 Уровень 1 — базовый (примени изученное)

**1. Чёт или нечёт.** *(повтор урока 1: `%`)*
Заведи `int n = 7`. Программа должна определить, **чётное это число или нечётное**, и вывести подходящее слово.
**Должно получиться:**
```
Нечётное
```
> 💡 Число чётное, когда остаток от деления на 2 равен нулю. Остаток даёт оператор `%` из урока 1. Сравни его с нулём в условии.

**2. Плюс, минус или ноль.**
Заведи `int n = -5`. Программа должна разобрать **три случая** и вывести, положительное число, отрицательное или это ноль.
**Должно получиться:**
```
Отрицательное
```
> 💡 Тут три ветки: первое условие проверяет «больше нуля», второе — «меньше нуля», а всё остальное (`else`) — это ноль.

**3. Большое число.**
Заведи `int n = 250`. Выведи «больше сотни», если число превышает 100, и «сто и меньше» в противном случае.
**Должно получиться:**
```
Больше сотни
```
> 💡 Одно условие со сравнением «больше 100» и ветка `else`.

**4. Совершеннолетний?**
Спроси у пользователя возраст. Выведи «взрослый», если ему **18 или больше**, и «ребёнок», если меньше.
**Должно получиться (ввели 20):**
```
Взрослый
```
> 💡 Возраст читай числом (не забудь превратить ввод в `int`). Сравнение «18 и старше» — это «больше или равно».

**5. Кто больше.**
Заведи два числа `int a = 8, b = 5`. Программа должна сравнить их и вывести **то, которое больше**.
**Должно получиться:**
```
Больше: 8
```
> 💡 Сравни `a` и `b`; в одной ветке выведи первое, в `else` — второе.

**6. Сдал или нет.**
Заведи `int score = 72`. Если баллов **60 или больше** — выведи «сдал», иначе «пересдача».
**Должно получиться:**
```
Сдал
```
> 💡 Условие — «набрал не меньше 60».

**7. Оценка словом.**
Заведи `int mark = 5`. Пользуясь конструкцией `switch`, выведи оценку словом: 5 — «отлично», 4 — «хорошо», 3 — «удовл», остальное — «плохо».
**Должно получиться:**
```
Отлично
```
> 💡 На каждое значение — свой `case` со своим текстом и `break`. Случай «всё остальное» — это `default`.

**8. Одной строкой.** *(повтор урока 1: `%`)*
Заведи `int n = 10`. Определи, чётное оно или нет, но не через `if`, а **тернарным оператором** — в одну строку.
**Должно получиться:**
```
чёт
```
> 💡 Тернарник устроен как «условие ? если-да : если-нет». Условие чётности — то же, что в задаче 1.

**9. Пароль.** *(повтор урока 2: строки)*
Спроси у пользователя пароль. Если он в точности равен `"1234"` — выведи «доступ разрешён», иначе «отказано».
**Должно получиться (ввели 1234):**
```
Доступ разрешён
```
> 💡 Строки тоже сравнивают на равенство двойным знаком `==` (как числа).

**10. День недели по номеру.**
Заведи `int day = 3`. Через `switch` выведи название дня (1 — понедельник, 2 — вторник, … 7 — воскресенье).
**Должно получиться:**
```
Среда
```
> 💡 Семь веток `case`, каждая со своим названием и `break`. Про `default` для «нет такого дня» тоже не забудь.

## 🟡 Уровень 2 — средний (цепочки и логика)

**11. Оценка по баллам.**
Спроси балл от 0 до 100 и переведи его в оценку словом по правилу: 90 и выше — «отлично», от 75 — «хорошо», от 60 — «удовл», ниже — «плохо».
**Должно получиться (ввели 82):**
```
Хорошо
```
> 💡 Тут нужна **цепочка** `if / else if / else`. Важен порядок: проверяй пороги **от большего к меньшему**, иначе высокий балл «поймает» не та ветка.

**12. Максимум из трёх.**
Заведи три числа `int a = 7, b = 3, c = 9`. Найди и выведи **наибольшее** из них.
**Должно получиться:**
```
Максимум: 9
```
> 💡 Можно сравнивать вложенными `if`, а можно короче — вспомни готовый метод для поиска большего из двух чисел (урок 1) и примени его дважды.

**13. Категория возраста.**
Спроси возраст и определи категорию: младше 12 — «ребёнок», от 12 до 17 — «подросток», 18 и старше — «взрослый».
**Должно получиться (ввели 14):**
```
Подросток
```
> 💡 Средний диапазон «12–17» получится сам: если первая ветка «младше 12» не сработала, значит возраст уже ≥ 12, и достаточно проверить «младше 18».

**14. Билет в кино.**
Спроси возраст зрителя и возрастной рейтинг фильма (например, 16). Пусти на фильм, только если возраст **не меньше** рейтинга.
**Должно получиться (возраст 14, рейтинг 16):**
```
На фильм нельзя
```
> 💡 Оба значения — числа. Условие «пустить» — «возраст больше или равен рейтингу».

**15. Чётное и большое.** *(повтор урока 1: `%`)*
Спроси число и выведи «да» **только если оно одновременно чётное И больше 10**. Иначе — «нет».
**Должно получиться (ввели 12):**
```
Да
```
> 💡 Два требования должны выполниться **вместе** — соедини их оператором «и» (`&&`). Первое — про чётность (остаток), второе — про «больше 10».

**16. Выходной?** *(повтор урока 2: дата)*
Спроси номер дня недели (1–7). Определи, выходной это (суббота 6 или воскресенье 7) или будни.
**Должно получиться (ввели 6):**
```
Выходной
```
> 💡 Выходной — это «день равен 6 **или** равен 7». «Или» — это оператор `||`.

**17. Скидка по сумме.** *(повтор урока 1: арифметика)*
Спроси сумму покупки. Определи скидку: от 5000 — 20%, от 2000 — 10%, иначе 0%. Выведи процент скидки и итоговую сумму к оплате.
**Должно получиться (ввели 3000):**
```
Скидка: 10%
К оплате: 2700
```
> 💡 Сначала цепочкой `if/else if` выбери **процент** скидки. Потом посчитай оплату — вычти из суммы её долю (вспомни, как считали скидку в уроке 1).

**18. Время суток.** *(повтор урока 2: дата)*
Возьми текущий час (`DateTime.Now.Hour`). Выведи: до 6 — «ночь», до 12 — «утро», до 18 — «день», позже — «вечер».
**Должно получиться (пример, сейчас 15 часов):**
```
Сейчас день
```
> 💡 Цепочка `if/else if` по значению часа, начиная с самого раннего порога (6, потом 12, потом 18).

**19. Треугольник существует?**
Спроси три стороны. Определи, **можно ли из них сложить треугольник**. Правило: сумма любых двух сторон должна быть больше третьей.
**Должно получиться (3, 4, 5):**
```
Треугольник существует
```
> 💡 Должны выполниться **сразу три** неравенства (для каждой пары сторон). Соедини все три условия оператором «и» (`&&`).

**20. Предскажи вывод.**
Не запуская, скажи, что выведет код. Потом поменяй `x` на `-3` и снова предскажи. Проверь оба варианта запуском.
```csharp
int x = 5;
if (x > 0 && x < 10)
    Console.WriteLine("одна цифра, положительное");
else
    Console.WriteLine("нет");
```
**Должно получиться:** два предсказания с объяснением, **как работает `&&`**.
> 💡 Подумай: `&&` истинно, только когда истинны **обе** части. При `x = -3` первая часть («больше нуля») уже ложна — что тогда со всем условием?

## 🔴 Уровень 3 — со звёздочкой (собери целое)

**21. Калькулятор.** *(повтор урока 1: арифметика)*
Спроси два числа и знак операции (`+`, `-`, `*` или `/`). С помощью `switch` по знаку посчитай и выведи результат. Отдельно предусмотри случай **деления на ноль**, чтобы программа не упала.
**Должно получиться (8, 2, *):**
```
Результат: 16
```
> 💡 В `switch` сделай по одной ветке `case` на каждый знак. Внутри ветки деления перед вычислением проверь условием, что второе число **не ноль**.

**22. Камень-ножницы-бумага.**
Спроси выбор двух игроков (каждый вводит «камень», «ножницы» или «бумага»). Определи, кто победил, или объяви ничью.
**Должно получиться (камень против ножницы):**
```
Победил первый
```
> 💡 Сначала отдельно проверь ничью (выборы совпали). Первый выигрывает в трёх известных парах (камень бьёт ножницы, ножницы — бумагу, бумага — камень) — их удобно перечислить через «или». Всё остальное — победа второго.

**23. Светофор.**
Спроси цвет светофора («красный», «жёлтый» или «зелёный»). Через `switch` выведи, что делать пешеходу.
**Должно получиться (зелёный):**
```
Иди
```
> 💡 По ветке `case` на каждый цвет. Для незнакомого слова добавь `default` с сообщением.

**24. Касса.** *(повтор урока 1)*
Спроси цену товара и сколько денег дал покупатель. Если денег хватает — выведи сдачу; если не хватает — выведи, сколько **не хватает**.
**Должно получиться (цена 340, дали 500):**
```
Сдача: 160
```
> 💡 Сравни «дали» и «цену». В одной ветке посчитай разницу как сдачу, в другой — как недостачу.

**25. Високосный год.** *(повтор урока 1: `%`)*
Спроси год и определи, **високосный** он или обычный.
**Должно получиться (2024):**
```
2024 — високосный
```
> 💡 Правило хитрое: год високосный, если делится на 4, **но не** на 100 — **или** если делится на 400. Тебе понадобятся и `&&`, и `||`, и скобки, чтобы правильно сгруппировать условия. Делимость проверяется остатком `%`.

**26. Найди и почини ошибку.**
Программа должна пускать только взрослых, но что-то не так. Найди и исправь ошибку:
```csharp
int age = 10;
if (age = 18)
    Console.WriteLine("Взрослый");
else
    Console.WriteLine("Ребёнок");
```
**Должно получиться:** при `age = 10` программа выводит «Ребёнок».
> 💡 Посмотри на условие: сравнение чисел пишется **двумя** знаками равенства, а не одним. И подумай ещё: «взрослый» — это ровно 18 или «18 и старше»?

**27. Оценка + похвала.** *(сборка)*
Спроси имя и балл. Выведи строкой: имя, оценку словом и подходящую фразу-похвалу («молодец!» для хороших оценок, «старайся!» для слабых).
**Должно получиться (Аня, 5):**
```
Аня: отлично — молодец!
```
> 💡 Оценку словом определи как в задачах 7/11. Похвалу выбери по порогу балла (можно тернарником). Всё собери в одну строку.

**28. Приветствие по времени.** *(повтор урока 2: дата)*
Возьми текущее время. Выведи его в формате «часы:минуты» и подходящее приветствие: доброе утро / день / вечер / доброй ночи.
**Должно получиться (пример, 19:18):**
```
19:18 — добрый вечер
```
> 💡 Само приветствие выбери по текущему часу цепочкой условий (как в задаче 18), а время выведи через формат даты из урока 2.

**29. Мини-квест.**
Спроси у игрока, куда он пойдёт («лес», «пещера» или «река»). Через `switch` выдай **свой исход** для каждого пути, а для всего остального (`default`) — «ты заблудился».
**Должно получиться (пещера):**
```
В пещере ты нашёл сундук с золотом!
```
> 💡 На каждый вариант — своя ветка `case` со своим текстом-исходом. Придумай их сам.

**30. Свой умный помощник.**
Сделай **свою** программу, которая по введённым данным даёт разумный совет через условия. На выбор:
- 🌡 по температуре советует одежду (мороз / прохладно / тепло / жара);
- 🎒 по дню недели говорит, какие сегодня уроки;
- 🍽 по времени суток советует «завтрак / обед / ужин».
**Должно получиться:** программа спрашивает данные и выдаёт подходящий совет.
> 💡 Где сравниваешь числа (температуру) — используй пороги и `if/else if`; где выбираешь из названий (день, приём пищи) — удобнее `switch`.

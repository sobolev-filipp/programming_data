# 🏋️ Практика — Урок 3 «Условия + switch»

**Блок 1 · Урок 3 | Задачи в 3 уровнях**

> Пиши и **сразу запускай** каждую задачу (F5 / `dotnet run`). У каждой есть блок **«Должно получиться»** и **💡 подсказка** (наводка, не готовый код).
> 📌 Шпаргалка: условие в `( )`, тело в `{ }`; сравнение **`==`**; логика `&&` `||` `!`; лестница `if / else if / else`; **`switch (x) { case знач: ... break; default: ... break; }`** — не забудь `break`; тернарник `условие ? да : нет`.

---

## 🟢 Уровень 1 — базовый

**1. Пускать или рано.**
Спроси возраст и выведи «Можно» если он `>= 12`, иначе «Рано».
**Должно получиться:**
```
Твой возраст? 10
Рано
```
> 💡 `if (age >= 12) ... else ...`.

**2. Чётное или нечётное.**
Спроси число и выведи, чётное оно или нет.
**Должно получиться:**
```
Число? 7
Нечётное
```
> 💡 `if (n % 2 == 0) ...` — остаток из Урока 1.

**3. Знак числа.**
Спроси число и выведи «Положительное», «Отрицательное» или «Ноль».
**Должно получиться:**
```
Число? -4
Отрицательное
```
> 💡 Лестница: `if (n > 0) ... else if (n < 0) ... else ...`.

**4. Светофор (switch).**
Спроси число 1–3 и через **switch** выведи цвет: 1 — красный, 2 — жёлтый, 3 — зелёный, иначе — «нет такого».
**Должно получиться:**
```
Сигнал (1-3)? 2
Жёлтый
```
> 💡 `switch (n) { case 1: ... break; ... default: ... break; }`.

---

## 🟡 Уровень 2 — средний

**5. Оценка словами (else if).**
Спроси оценку 2–5 и выведи её словом («отлично/хорошо/удовлетворительно/плохо»).
**Должно получиться:**
```
Оценка? 4
хорошо
```
> 💡 `if (mark == 5) ... else if (mark == 4) ... else ...`.

**6. День недели (switch).**
Спроси число 1–7 и через **switch** выведи, будний это день или выходной (6 и 7 — выходной).
**Должно получиться:**
```
День (1-7)? 6
Выходной!
```
> 💡 Группировка: `case 1: case 2: ... case 5: ... break; case 6: case 7: ... break;`.

**7. Команда робота (switch по строке).**
Спроси команду и через **switch** ответь: «старт» → «Поехали», «стоп» → «Стоим», «пауза» → «Ждём», иначе → «Не понял».
**Должно получиться:**
```
Команда? стоп
Стоим
```
> 💡 `switch (cmd) { case "старт": ... break; ... }`.

**8. Порог (тернарник).**
Спроси число и через тернарник выведи «Много» если `> 100`, иначе «Мало».
**Должно получиться:**
```
Число? 250
Много
```
> 💡 `n > 100 ? "Много" : "Мало"`.

**9. Оценка через switch-выражение.**
Спроси балл 2–5 и через **switch-выражение** (`x switch { ... }`) получи слово-оценку в переменную, потом выведи.
**Должно получиться:**
```
Балл? 5
отлично
```
> 💡 `string t = mark switch { 5 => "отлично", 4 => "хорошо", 3 => "удовл", _ => "плохо" };`.

---

## 🔴 Уровень 3 — со звёздочкой

**10. Меню-калькулятор (switch).**
Спроси два числа и действие (`+ - * /`). Через **switch** посчитай и выведи результат. Для `/` проверь деление на ноль.
**Должно получиться:**
```
Первое число: 10
Действие (+, -, *, /): /
Второе число: 0
На ноль делить нельзя!
```
> 💡 `switch (op) { case "+": ... break; case "/": if (b == 0) ... else ... break; default: ... }`.

**11. Время года (switch с группировкой).**
Спроси номер месяца 1–12 и через **switch** выведи время года (12,1,2 — зима; 3,4,5 — весна; 6,7,8 — лето; 9,10,11 — осень).
**Должно получиться:**
```
Месяц (1-12)? 4
Весна
```
> 💡 Группируй `case`: `case 3: case 4: case 5: ... break;`.

**12. Оценка по баллам (switch с диапазоном).**
Спроси балл 0–100 и через **switch-выражение с диапазоном** выведи оценку: `>= 90` → «5», `>= 75` → «4», `>= 60` → «3», иначе «2».
**Должно получиться:**
```
Балл (0-100)? 82
Оценка: 4
```
> 💡 `mark switch { >= 90 => "5", >= 75 => "4", >= 60 => "3", _ => "2" }`.

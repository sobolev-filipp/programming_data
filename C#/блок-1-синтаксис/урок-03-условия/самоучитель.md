## 📚 Мини-теория за 5 минут

**if / else** — условие в круглых скобках, тело в фигурных:
```csharp
if (score >= 60) { Console.WriteLine("Зачёт"); }
else            { Console.WriteLine("Нет"); }
```
Сравнение: `==` `!=` `>` `<` `>=` `<=` (равно — **двойное** `==`).
Логика: `&&` (И), `||` (ИЛИ), `!` (НЕ).
Лестница: `if / else if / else` — сработает первая подходящая ветка.

**switch** — выбор из многих по значению:
```csharp
switch (n)
{
    case 1: Console.WriteLine("один"); break;   // не забудь break!
    case 2: Console.WriteLine("два");  break;
    default: Console.WriteLine("другое"); break;
}
```
**switch-выражение** (короткая форма): `x switch { 1 => "...", _ => "..." }`.
**Тернарник:** `условие ? да : нет`.

## ✍️ Задания с разбором (делаем вместе)

### Задание 1. Первое условие
**Тема:** if/else.
**Задание:** спроси число и выведи «Плюс», если оно `> 0`, иначе «Не плюс».

**Разбор:**
```csharp
Console.Write("Число? ");
int n = Convert.ToInt32(Console.ReadLine());
if (n > 0) Console.WriteLine("Плюс");
else       Console.WriteLine("Не плюс");
```
✅ Условие — в `( )`, каждая ветка — своя команда.

### Задание 2. Чётность
**Тема:** `%` в условии.
**Задание:** спроси число и выведи «Чётное»/«Нечётное».

**Разбор:**
```csharp
int n = Convert.ToInt32(Console.ReadLine());
if (n % 2 == 0) Console.WriteLine("Чётное");
else            Console.WriteLine("Нечётное");
```

### Задание 3. Лестница else if
**Тема:** `else if`.
**Задание:** спроси оценку 3–5, выведи словом.

**Разбор:**
```csharp
int mark = Convert.ToInt32(Console.ReadLine());
if (mark == 5)      Console.WriteLine("отлично");
else if (mark == 4) Console.WriteLine("хорошо");
else             Console.WriteLine("удовлетворительно");
```
✅ Сработает первая подходящая ветка.

### Задание 4. Первый switch
**Тема:** `switch` (новое!).
**Задание:** спроси число 1–3 и через switch выведи цвет светофора.

**Разбор по шагам:**
1. `switch (n)` — смотрим на значение.
2. Каждый вариант — `case`, в конце `break`.
3. `default` — если не совпало.
```csharp
int n = Convert.ToInt32(Console.ReadLine());
switch (n)
{
    case 1: Console.WriteLine("Красный"); break;
    case 2: Console.WriteLine("Жёлтый"); break;
    case 3: Console.WriteLine("Зелёный"); break;
    default: Console.WriteLine("Нет такого"); break;
}
```
✅ Забудешь `break` — будет ошибка!

### Задание 5. switch по строке
**Тема:** switch со строкой.
**Задание:** спроси команду и ответь: «старт»→«Поехали», «стоп»→«Стоим», иначе «Не понял».

**Разбор:**
```csharp
string cmd = Console.ReadLine().Trim();
switch (cmd)
{
    case "старт": Console.WriteLine("Поехали"); break;
    case "стоп":  Console.WriteLine("Стоим"); break;
    default:      Console.WriteLine("Не понял"); break;
}
```

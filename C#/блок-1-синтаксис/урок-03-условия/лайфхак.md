# 🧰 Лайфхаки и частые ошибки · Урок 3 «Условия + switch»

> Трюки и «грабли» по условиям и `switch`.

---

## 💡 Трюки

1. **`switch` быстро печатается:** набери `switch` + Tab, Visual Studio развернёт заготовку. А `case` можно достроить через `Ctrl+.` (по значению переменной).
2. **`switch` вместо длинной лестницы `else if`** — когда сравниваешь **одно** значение со списком вариантов. Читается чище.
3. **Группировка `case`** — если для нескольких значений действие одно: `case 1: case 2: ... break;`.
4. **`switch`-выражение** — когда надо просто **выбрать значение**: `string s = x switch { ... };` (короче, без `break`).
5. **Тернарник** для «в одну строку»: `Console.WriteLine(n % 2 == 0 ? "чёт" : "нечёт");`.
6. **`bool` из строк** прямо в условие: `if (почта.Contains("@")) ...` — методы из Урока 2 работают в `if`.

---

## 🐞 Частые ошибки

| Что видишь | Причина | Лечение |
|-----------|---------|---------|
| `Control cannot fall through to another case` | забыл `break;` | в конце каждого `case` — `break;` |
| условие всегда истинно / ошибка | `=` вместо `==` | сравнение — двойное `==` |
| `; expected` у `case 3` | нет двоеточия | `case 3:` (с двоеточием) |
| `The name 'and' does not exist` | написал `and`/`or`/`not` | в C# — `&&`, `\|\|`, `!` |
| `switch` не заходит в `case "стоп"` | пробелы/регистр во вводе | `Console.ReadLine().Trim()`, единый регистр |
| сработала «не та» ветка `else if` | порядок веток | проверки идут сверху вниз, первая подходящая |
| `if (5 < a < 10)` — ошибка | так писать нельзя | через `&&`: `a > 5 && a < 10` |

---

## 🎯 if vs switch — что выбрать

- **`if / else if`** — когда условия **разные** (`возраст >= 18`, `почта.Contains("@")`, диапазоны).
- **`switch`** — когда сравниваешь **одно значение** с набором вариантов (день недели, команда, знак действия, номер меню).

---

## ✅ Чек «всё понял»

1. Пишу `if (условие) { ... } else { ... }`, помню `==`.
2. Логика `&& || !`; лестница `else if` (первая подходящая ветка).
3. Умею `switch` с `case`/`break`/`default` и группировкой.
4. Знаю короткие формы: `switch`-выражение и тернарник `?:`.

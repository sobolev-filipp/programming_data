# Урок 10 «ООП: классы и объекты» — итого (шпаргалка) 📌

> Открой, чтобы за 3 минуты вспомнить урок. Только суть и примеры. Классы/методы/свойства — `PascalCase`, поля-переменные — `camelCase`.

---

## Главные мысли

1. **Класс** — чертёж (свой тип); **объект** — то, что сделано по чертежу через `new`.
2. **Поля** — данные объекта; **методы** — его поведение; вместе = объект.
3. **Конструктор** создаёт объект сразу с данными (имя как у класса, без типа).
4. **Свойство** (`get/set`) — «умное поле» с проверкой; `value` — присваиваемое значение.
5. **`static`** — общее для всего класса (вызов через класс); обычное — у каждого объекта своё.
6. **Перегрузка** — методы/конструкторы с одним именем, но разными параметрами.

---

## Класс, объект, поля

```csharp
class Hero
{
    public string Name;   // поле
    public int Hp;        // поле
}

Hero hero = new Hero();   // объект
hero.Name = "Артур";
hero.Hp = 100;
Console.WriteLine(hero.Name);   // через точку
```

## Методы и this

```csharp
class Hero
{
    public string Name;
    public int Hp;
    public void Introduce() => Console.WriteLine($"Я {Name}, HP={Hp}");
    public void TakeDamage(int d) { Hp -= d; }
    public void SetName(string name) { this.Name = name; }  // this — «я сам»
}
hero.Introduce();
```

## Конструктор (+ перегрузка)

```csharp
public Hero(string name, int hp) { Name = name; Hp = hp; }
public Hero(string name) : this(name, 100) { }   // hp по умолчанию

Hero a = new Hero("Артур", 80);
Hero b = new Hero("Мерлин");     // hp = 100
```

## Свойства get/set

```csharp
private int hp;
public int Hp
{
    get { return hp; }
    set { hp = value < 0 ? 0 : value; }   // проверка
}
public string Name { get; set; }          // авто-свойство
public bool IsAlive => Hp > 0;            // вычисляемое (только get)
```

## static и перегрузка

```csharp
public static int Count = 0;   // общее для всех; Count++ в конструкторе
Console.WriteLine(Hero.Count);  // через КЛАСС

public static void Show(int x)    => ...   // перегрузка:
public static void Show(string x) => ...   // одно имя, разные типы
```

## Мостики Python → C#

| Python | C# |
|--------|-----|
| `class Hero:` | `class Hero { ... }` |
| `def __init__(self, ...)` | конструктор `public Hero(...)` |
| `self.hp` | `this.Hp` (или просто `Hp`) |
| `h = Hero(...)` | `Hero h = new Hero(...)` |
| `@property` | свойство `get/set` |

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| `NullReferenceException` | забыл `new` | создай объект через `new` |
| «нет конструктора на N аргументов» | не столько аргументов | передавай как в конструкторе |
| поле не видно снаружи | нет `public` | ставь `public` |
| `Hp` ушёл в минус | это поле, не свойство | сделай свойство с проверкой |

---

## 📚 Мини-теория за 5 минут

**Класс** — чертёж (свой тип данных), **объект** — то, что сделано по чертежу.
- Класс пишут **внизу файла**: `class Hero { public string Name; public int Hp; }`.
- Объект создают через `new`: `Hero h = new Hero();`, к полям — через точку `h.Name`.
- **Методы** внутри класса — поведение объекта; видят его поля напрямую.
- **Конструктор** — метод с именем класса без типа; создаёт объект сразу с данными.
- **Свойство** — «умное поле» с `get/set`; в `set` доступно `value` (можно проверять).
- **`static`** — общее для всего класса (вызов через класс). **Перегрузка** — одно имя, разные параметры.

## ✍️ Задания с разбором (делаем вместе)

### Задание 1. Первый класс и объект
```csharp
Hero h = new Hero();
h.Name = "Артур";
h.Hp = 100;
Console.WriteLine($"{h.Name}, HP={h.Hp}");

class Hero { public string Name; public int Hp; }
```
✅ Класс — внизу; объект создали `new`, поля заполнили через точку.

### Задание 2. Метод класса
```csharp
Hero h = new Hero(); h.Name = "Артур"; h.Hp = 100;
h.Introduce();

class Hero
{
    public string Name;
    public int Hp;
    public void Introduce() => Console.WriteLine($"Я {Name}, HP={Hp}");
}
```
✅ Метод внутри класса видит поля `Name`/`Hp` своего объекта.

### Задание 3. Конструктор
```csharp
Hero h = new Hero("Мерлин", 80);
h.Introduce();

class Hero
{
    public string Name;
    public int Hp;
    public Hero(string name, int hp) { Name = name; Hp = hp; }
    public void Introduce() => Console.WriteLine($"Я {Name}, HP={Hp}");
}
```
✅ Конструктор задаёт поля при рождении — объект готов одной строкой.

### Задание 4. Свойство с проверкой
```csharp
Hero h = new Hero();
h.Hp = -20;
Console.WriteLine(h.Hp);   // 0 — сеттер не пустил в минус

class Hero
{
    private int hp;
    public int Hp
    {
        get { return hp; }
        set { hp = value < 0 ? 0 : value; }
    }
}
```
✅ Свойство защищает данные: снаружи как поле, но с проверкой.

### Задание 5. static-счётчик
```csharp
new Hero("Артур"); new Hero("Мерлин");
Console.WriteLine(Hero.Count);   // 2

class Hero
{
    public string Name;
    public static int Count = 0;
    public Hero(string name) { Name = name; Count++; }
}
```
✅ `Count` один на весь класс; читаем через класс `Hero.Count`.

### Задание 7
**Тема:** метод.
**Задание:** добавь `Car` метод `Beep()` — печатает «{Model}: Бип-бип!».
> 💡 Внутри метода поле `Model` видно по имени, без точки.

### Задание 8
**Тема:** конструктор.
**Задание:** сделай конструктор `Car(string model, int speed)`, создай машину одной строкой.
> 💡 Метод с именем класса без типа; внутри присвой поля из параметров.

### Задание 9
**Тема:** свойство.
**Задание:** сделай `Speed` свойством, которое не даёт скорости стать отрицательной.

### Задание 10
**Тема:** static.
**Задание:** заведи `public static int Total`, увеличивай в конструкторе, выведи число созданных машин.

# 🧰 Лайфхаки и частые ошибки · Урок 10 «ООП: классы и объекты»

> Трюки и «грабли» по классам и объектам. Главное уже показано в уроке — здесь собрано вместе.

---

## 💡 Трюки

1. **Класс — свой тип.** `Hero`, `Player`, `Car` — как `int`, только твой. Имя — `PascalCase`.
2. **Класс пиши внизу файла** (после основного кода) — в top-level программе так требуется. В больших проектах — в отдельном файле `Hero.cs`.
3. **Авто-свойство** для простых полей: `public string Name { get; set; }` — коротко, без ручного хранилища.
4. **Вычисляемое свойство** (только `get`): `public bool IsAlive => Hp > 0;` — не хранится, считается на лету.
5. **`: this(...)`** в конструкторе — вызвать другой свой конструктор, не дублируя код.
6. **`this.Поле = параметр`** — когда имена совпадают; делает намерение явным.
7. **`static` для «общего»**: счётчик объектов, настройки класса, вспомогательные методы (как `Math.Max`).
8. **Инициализатор объекта:** `new Hero { Name = "Артур", Hp = 100 };` — заполнить публичные поля/свойства без конструктора.

## 🐞 Частые ошибки

| Что видишь | Причина | Лечение |
|-----------|---------|---------|
| `NullReferenceException` | забыл `new` — объекта нет | создай объект: `Hero h = new Hero(...)` |
| `does not contain a constructor that takes N arguments` | аргументы `new` не совпали с конструктором | передавай как в конструкторе (или добавь нужный) |
| поле/метод «не виден» снаружи | нет `public` (по умолчанию `private`) | ставь `public` тому, что нужно снаружи |
| класс «не компилируется» в начале файла | объявил класс перед top-level кодом | перенеси класс **вниз**, после основного кода |
| `Hp` уходит в минус | это поле, а не свойство | сделай свойство с проверкой в `set` |
| `static`-поле читаю через объект | путаю уровень | читай через класс: `Hero.Count` |
| «перегрузка не работает» | методы отличаются только именем возврата | перегрузка — по **параметрам** (тип/число), не по возврату |

---

## 🎯 Поле или свойство — что выбрать

- **Поле** (`public int X;`) — простое хранилище, когда проверки не нужны.
- **Свойство** (`get/set`) — когда нужно **контролировать** значение (не в минус, не больше максимума), считать на лету или делать «только чтение» (`get; private set;`).

> 💡 Хорошая привычка: снаружи класса открывать **свойства**, а не голые поля — потом легко добавить проверку, ничего не ломая.

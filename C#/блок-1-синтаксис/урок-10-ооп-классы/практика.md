# 🏋️ Практика — Урок 10 «ООП: классы и объекты»

**Блок 1 · Урок 10 | 30 заданий в 3 уровнях по сложности**

> Пиши и **сразу запускай** (F5 / `dotnet run`). У каждой задачи — **«Должно получиться»** и **💡 подсказка**.
> 🟢 базовый · 🟡 средний · 🔴 со звёздочкой. Часть задач **повторяет уроки 1–9** (Math, условия, циклы, коллекции) — теперь оформляй их через **классы**.
> 📌 Шпаргалка: класс `class Cat { public string Name; }` · объект `Cat c = new Cat();` · поле `c.Name` · метод внутри класса, обращение к своим полям через `this` · конструктор `public Cat(string name) { Name = name; }` · свойство `public int Age { get; set; }` · вычисляемое `public bool IsAdult => Age >= 18;` · общее для всех `static`. Классы пиши **внизу** файла. **Классы/методы — `PascalCase`, поля — тоже `PascalCase` (публичные), переменные — `camelCase`.**
> 💡 Подсказки — **наводки**, а не готовый код.

## 🟢 Уровень 1 — базовый (примени изученное)

**1. Класс «Кот».**
Опиши класс `Cat` с двумя полями: имя и возраст. Создай одного кота, задай ему имя и возраст, выведи их.
**Должно получиться (пример):**
```
Кот Барсик, возраст 3
```
> 💡 Сначала опиши класс с полями (внизу файла), потом создай объект через `new` и заполни его поля.

**2. Кот умеет мяукать.**
Добавь классу `Cat` метод `Meow`, который печатает «Мяу!». Вызови его у своего кота.
**Должно получиться:**
```
Мяу!
```
> 💡 Метод пишется **внутри** класса. Вызывают его у объекта через точку.

**3. Кот представляется (`this`).**
Пусть метод `Meow` печатает **имя** этого кота: «Барсик говорит: Мяу!». Используй поле объекта внутри метода.
**Должно получиться:**
```
Барсик говорит: Мяу!
```
> 💡 Внутри метода класс видит **свои** поля. Чтобы подчеркнуть, что речь о «своём» имени, к нему обращаются через `this`.

**4. Конструктор кота.**
Добавь классу `Cat` **конструктор**, который сразу задаёт имя и возраст при создании. Создай кота в одну строку.
**Должно получиться:**
```
Кот Мурзик, возраст 5
```
> 💡 Конструктор — это особый «метод» с именем как у класса, без типа результата. Он принимает данные и раскладывает их по полям.

**5. Много котов.**
Создай **трёх разных** котов из одного класса и выведи каждого. Убедись, что они независимы.
**Должно получиться:**
```
Барсик, 3
Мурзик, 5
Рыжик, 1
```
> 💡 Один класс — сколько угодно объектов. Каждый `new` создаёт новый, отдельный объект со своими данными.

**6. Прямоугольник.**
Опиши класс `Rectangle` с шириной и высотой и методом `Area`, который возвращает площадь. Создай прямоугольник 4×6 и выведи площадь.
**Должно получиться:**
```
Площадь: 24
```
> 💡 Метод `Area` считает по полям **своего** объекта и возвращает результат.

**7. Ученик.**
Опиши класс `Student` с именем и оценкой и методом `Info`, который печатает «Имя: … , оценка: …». Создай ученика и покажи его.
**Должно получиться:**
```
Имя: Аня, оценка: 5
```
> 💡 Поля задай через конструктор, а `Info` пусть красиво выводит их через интерполяцию.

**8. Кот подрос.**
Создай кота, а потом **измени его возраст** уже после создания и снова выведи.
**Должно получиться:**
```
Было: 3
Стало: 4
```
> 💡 К полю объекта можно обращаться и на чтение, и на запись: `cat.Age = ...`.

**9. Круг.** *(повтор урока 1: Math)*
Опиши класс `Circle` с радиусом и методом `Area`, возвращающим площадь круга (округли до 2 знаков). Проверь на радиусе 5.
**Должно получиться:**
```
Площадь круга: 78,54
```
> 💡 Внутри метода пригодятся `Math.PI` и возведение радиуса в квадрат, а округлить поможет `Math.Round`.

**10. Объявление о рождении.**
Пусть конструктор кота при создании **сам печатает** «Родился котёнок <имя>!». Создай пару котов и посмотри на сообщения.
**Должно получиться:**
```
Родился котёнок Барсик!
Родился котёнок Мурзик!
```
> 💡 В теле конструктора можно не только раскладывать поля, но и выполнять любой код — например, вывод.

## 🟡 Уровень 2 — средний (свойства, static, перегрузка)

**11. Возраст без глупостей.**
Сделай у класса `Cat` возраст **свойством с проверкой**: если пытаются задать отрицательный возраст — оставляй 0.
**Должно получиться (пробуем задать −5):**
```
Возраст: 0
```
> 💡 Свойство — это «умное поле» с блоками `get` и `set`. Внутри `set` проверь новое значение (`value`) условием, прежде чем сохранить.

**12. Авто-свойства.**
Перепиши поля класса `Student` (имя и оценка) как **авто-свойства** `{ get; set; }`. Убедись, что всё работает как раньше.
**Должно получиться:** программа ведёт себя так же, но поля объявлены короче.
> 💡 Если проверок не нужно, свойство можно записать коротко: `public int Grade { get; set; }` — компилятор сам сделает хранилище.

**13. Взрослый ли кот.**
Добавь классу `Cat` **вычисляемое свойство** `IsAdult`, которое равно `true`, если возраст 3 и больше. Ничего хранить не нужно — оно считается на лету.
**Должно получиться (коту 5):**
```
Взрослый: True
```
> 💡 Вычисляемое свойство пишут через стрелку: оно возвращает результат сравнения, а не хранит отдельное значение.

**14. Счётчик котов (`static`).**
Сделай так, чтобы класс сам считал, **сколько всего котов создано**. Создай нескольких и выведи общее число.
**Должно получиться (создали 3):**
```
Всего котов: 3
```
> 💡 «Общее для всех объектов» значение делают `static`. Увеличивай его в конструкторе — он срабатывает на каждое создание. Обращаются к нему через **имя класса**, а не объект.

**15. Два удара (перегрузка).**
Добавь классу `Hero` два метода `Attack`: один бьёт на стандартные 10, другой принимает урон числом. Вызови оба.
**Должно получиться:**
```
Удар на 10
Удар на 25
```
> 💡 Два метода с одним именем, но **разным набором параметров** — это перегрузка. Компилятор сам выберет нужный по тому, что ты передал при вызове.

**16. Два конструктора.**
Дай классу `Cat` **два конструктора**: один принимает имя и возраст, другой — только имя (тогда возраст пусть будет 1). Второй пусть **переиспользует** первый.
**Должно получиться:**
```
Барсик, 3
Безымянный, 1
```
> 💡 Конструкторов тоже может быть несколько (перегрузка). Чтобы не повторять код, короткий конструктор может вызвать полный через `: this(...)`.

**17. Банковский счёт.** *(повтор урока 3: условия)*
Опиши класс `BankAccount` с балансом и методами `Deposit` (положить) и `Withdraw` (снять). Снять больше, чем есть, нельзя.
**Должно получиться:**
```
Баланс: 100
Снять 150? Недостаточно средств
Баланс: 100
```
> 💡 В `Deposit` прибавляй к балансу, в `Withdraw` — сначала проверь условием, хватает ли денег, и только тогда вычитай.

**18. Средняя оценка ученика.** *(повтор урока 6: массивы)*
Дай классу `Student` поле-массив оценок и метод `Average`, возвращающий средний балл.
**Должно получиться (оценки 5, 4, 3):**
```
Средний балл: 4
```
> 💡 Внутри метода перебери массив оценок объекта и посчитай среднее (не забудь про «дробное» деление из урока 1).

**19. Предскажи вывод.**
Не запуская, скажи, что выведет код. Потом проверь.
```csharp
Cat a = new Cat("Барсик");
Cat b = a;
b.Name = "Мурзик";
Console.WriteLine(a.Name);
```
**Должно получиться:** предсказание и объяснение, **почему у `a` тоже изменилось имя**.
> 💡 Объект — это не сама «коробка», а **ссылка** на неё. `b = a` не создаёт нового кота: обе переменные показывают на **одного и того же**. (Про это подробно — в теме ссылок.)

**20. Секундомер.**
Опиши класс `Counter` со значением и методами `Increment` (увеличить на 1) и `Reset` (обнулить). Понажимай и проверь.
**Должно получиться:**
```
0 → 1 → 2 → 0
```
> 💡 Значение — поле объекта; методы просто меняют его. Это тот же счётчик из прошлых уроков, но «завёрнутый» в объект.

## 🔴 Уровень 3 — со звёздочкой (классы + коллекции)

**21. Список котов.** *(повтор урока 8: List)*
Создай `List<Cat>`, добавь несколько котов и выведи каждого методом `Info`.
**Должно получиться:**
```
Барсик, 3
Мурзик, 5
```
> 💡 В списке можно хранить не только числа и строки, но и **объекты**: `List<Cat>`. Перебирай его `foreach` и зови метод у каждого.

**22. Самый старший кот.** *(повтор урока 6: максимум)*
В `List<Cat>` найди и выведи имя **самого старшего** кота.
**Должно получиться:**
```
Старший: Мурзик (5)
```
> 💡 Приём «рекордсмен» из урока 6, но сравниваем поле `Age` у объектов. Запоминай объект-лидера, а в конце возьми его имя.

**23. Магазин товаров.** *(повтор урока 8: коллекции)*
Опиши класс `Product` (название, цена). Сделай список товаров и посчитай **общую стоимость**.
**Должно получиться:**
```
Хлеб: 40
Молоко: 70
Итого: 110
```
> 💡 Каждый товар — объект `Product`. Перебирай список и складывай цены (поле `Price`) в копилку.

**24. Калькулятор-помощник (`static`).**
Опиши класс `MathHelper` со **статическим** методом `Square(n)`, который возвращает квадрат числа. Вызови его **без создания объекта**.
**Должно получиться:**
```
Квадрат 7: 49
```
> 💡 `static`-метод принадлежит классу, а не объекту, — как `Math.Sqrt`. Зовут его через имя класса: `MathHelper.Square(7)`.

**25. Найди и почини ошибку.**
Программа падает при запуске:
```csharp
Cat c;
c.Name = "Барсик";
Console.WriteLine(c.Name);
```
**Должно получиться:** программа выводит `Барсик` без ошибок.
> 💡 Переменную объявили, но сам объект **не создали** — «коробки» ещё нет, класть в неё поле некуда. Чего не хватает перед использованием (какое ключевое слово создаёт объект)?

**26. Игральный кубик.** *(повтор урока 4: Random)*
Опиши класс `Dice` с методом `Roll`, возвращающим случайное число от 1 до 6. Брось кубик несколько раз.
**Должно получиться (пример):**
```
Выпало: 4
Выпало: 2
Выпало: 6
```
> 💡 Внутри метода `Roll` используй `Random` из урока 4. Один класс `Dice` — можно бросать сколько угодно раз.

**27. Герой со здоровьем.** *(повтор урока 3: условия)*
Опиши класс `Hero` с именем и здоровьем (100), методом `TakeDamage(dmg)` (уменьшает HP, но не ниже 0) и вычисляемым свойством `IsAlive`.
**Должно получиться:**
```
Рыцарь получает 70 урона, HP: 30
Рыцарь получает 50 урона, HP: 0
Жив: False
```
> 💡 В `TakeDamage` уменьшай здоровье, но условием не дай ему уйти в минус. `IsAlive` — вычисляемое свойство: «здоровье больше нуля».

**28. Арена: Герой против Монстра.** *(мини-проект)*
Сделай два объекта (`Hero` и `Enemy`), которые по очереди бьют друг друга в цикле, пока один не проиграет. Выводи ход боя.
**Должно получиться:** пошаговый бой до победы одного из бойцов.
> 💡 Соедини классы с циклом `while`: пока оба живы, каждый бьёт другого (можно случайным уроном). Здоровье и удары — методы/поля классов.

**29. Плейлист.** *(повтор урока 8: List внутри класса)*
Опиши класс `Playlist` c внутренним списком песен и методами `Add(song)` и `ShowAll`. Добавь несколько песен и покажи их.
**Должно получиться:**
```
1. Song A
2. Song B
```
> 💡 Поле класса может быть `List<string>`. Метод `Add` добавляет в этот список, `ShowAll` перебирает его с номерами.

**30. Свой класс.**
Придумай и опиши **свой** класс на интересную тебе тему — на выбор:
- 🚗 `Car` (марка, скорость, метод «разогнаться»);
- 🐶 `Dog` (имя, сытость, методы «покормить»/«погулять»);
- 📱 `Phone` (заряд, методы «поюзать»/«зарядить»).
**Должно получиться:** класс с полями/свойствами, конструктором и хотя бы одним осмысленным методом, и пара объектов из него.
> 💡 Реши, какие у объекта **данные** (поля/свойства) и какое **поведение** (методы). Собери класс внизу файла, создай объекты вверху и подёргай их методы.

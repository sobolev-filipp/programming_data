# 🏋️ Практика — Урок 10 «ООП: классы и объекты»

**Блок 1 · Урок 10 | Задачи в 3 уровнях**

> Пиши и **сразу запускай** каждую задачу (F5 / `dotnet run`). У каждой есть блок **«Должно получиться»**. Подсказки 💡 есть только там, где легко застрять, — и они **наводят**, а не дают готовый код.
> 📌 Что помнить: класс (чертёж) пишут **внизу файла**: `class Hero { public string Name; ... }`. Объект — `Hero h = new Hero(...)`, к полям — через точку `h.Name`. **Конструктор** — метод с именем класса без типа. **Свойство** — `public int Hp { get {...} set {...} }`, внутри `set` доступно `value`. **`static`** — общее для всех, зовём через класс. **Имена: классы/методы/свойства `PascalCase`, поля `camelCase`.**

## 🟢 Уровень 1 — базовый

**1. Первый класс.**
Опиши класс `Dog` с двумя полями: `Name` (строка) и `Age` (число). В основном коде создай одного пса через `new`, заполни его поля и выведи их.
**Должно получиться:**
```
Пёс Рекс, возраст 4
```
> 💡 Класс размещают в самом низу файла, после основного кода. Объект создают так: `Dog d = new Dog();`, а поля заполняют через точку.

**2. Два разных объекта.**
По тому же классу `Dog` создай **двух** разных псов с разными именами и возрастом. Выведи обоих — убедись, что у каждого свои данные.
**Должно получиться:**
```
Рекс, 4
Барон, 2
```
> 💡 `new Dog()` вызывают дважды — получатся два независимых объекта. Поменяешь поля одного — второй не изменится.

**3. Метод-поведение.**
Добавь классу `Dog` метод `Bark()`, который печатает «{Name} говорит: Гав!». Создай пса и позови метод.
**Должно получиться:**
```
Рекс говорит: Гав!
```
> 💡 Метод пишут внутри класса; внутри него имя объекта видно просто как `Name` (без точки).

**4. Класс «Книга».**
Опиши класс `Book` с полями `Title` (название) и `Pages` (число страниц). Создай книгу и выведи «Книга "{Title}", страниц: {Pages}».
**Должно получиться:**
```
Книга "Хоббит", страниц: 320
```

## 🟡 Уровень 2 — средний

**5. Конструктор.**
Добавь классу `Dog` конструктор `Dog(string name, int age)`, чтобы пса можно было создать **одной строкой** `new Dog("Рекс", 4)`. Создай двух псов через конструктор и выведи их.
**Должно получиться:**
```
Рекс, 4
Барон, 2
```
> 💡 Конструктор — метод с именем класса и **без типа возврата**. Внутри присвой поля из параметров.

**6. Счёт в игре.**
Опиши класс `Player` с полями `Name` и `Score` и методом `AddPoints(int n)`, который прибавляет очки к `Score`. Создай игрока, начисли ему очки дважды и выведи итог.
**Должно получиться:**
```
Аня заработала 30 очков
```
> 💡 Внутри метода меняй поле объекта: `Score += n;`. Вызови метод два раза с разными числами.

**7. Свойство с проверкой.**
В классе `Player` сделай `Score` **свойством**, которое не даёт очкам стать отрицательными (в `set` отрицательное превращай в 0). Проверь: после `player.Score = -10;` должно быть 0.
**Должно получиться:**
```
Очки: 0
```
> 💡 Заведи приватное поле-хранилище `private int score;`, а публичное свойство `Score` в сеттере проверяй `value` перед присвоением.

**8. Прямоугольник и площадь.**
Опиши класс `Rectangle` с полями `Width` и `Height` и **вычисляемым свойством** `Area` (только `get`), которое возвращает `Width * Height`. Создай прямоугольник 4×5 и выведи площадь.
**Должно получиться:**
```
Площадь: 20
```
> 💡 Вычисляемое свойство не хранит значение, а считает его на лету: `public int Area => Width * Height;`.

**9. Счётчик объектов (static).**
В классе `Player` заведи `public static int Total`, увеличивай его в конструкторе. Создай трёх игроков и выведи, сколько игроков всего создано.
**Должно получиться:**
```
Всего игроков: 3
```
> 💡 `static`-поле общее для всех объектов. Увеличивай его в конструкторе (`Total++`), а читай **через класс**: `Player.Total`.

## 🔴 Уровень 3 — со звёздочкой

**10. Перегрузка конструктора.**
У класса `Player` сделай **два** конструктора: `Player(string name, int score)` и `Player(string name)` — второй ставит `Score = 100` по умолчанию (через `: this(...)`). Создай двух игроков — с очками и без.
**Должно получиться:**
```
Аня: 50
Боря: 100
```
> 💡 Короткий конструктор перенаправляет в полный: `public Player(string name) : this(name, 100) { }` — не дублируя код.

**11. Перегрузка метода.**
Опиши класс `Logger` со статическим методом `Print`, перегруженным для трёх типов: `int`, `string`, `bool`. Каждый печатает по-своему. Вызови все три.
**Должно получиться:**
```
целое: 7
текст: привет
да/нет: True
```
> 💡 Три метода с одним именем `Print`, но разными типами параметра — C# сам выберет нужный по аргументу.

**12. Банковский счёт.**
Опиши класс `Account` с полем `Owner` и свойством `Balance` (нельзя уводить в минус). Методы: `Deposit(int sum)` (положить) и `Withdraw(int sum)` (снять, но если денег не хватает — вывести «Недостаточно средств» и не менять баланс). Проверь на нескольких операциях.
**Должно получиться (пример):**
```
Аня положила 100. Баланс: 100
Аня сняла 40. Баланс: 60
Недостаточно средств
```
> 💡 В `Withdraw` сначала сравни `sum` с `Balance`: если больше — сообщи и `return`, иначе уменьшай баланс.

**13. Мини-арена (два объекта взаимодействуют).**
Опиши класс `Fighter` с полями `Name`, свойством `Hp` (не в минус) и методом `Attack(Fighter target)`, который отнимает у цели 20 HP и печатает результат. Создай двух бойцов и обменяйся парой ударов.
**Должно получиться (пример):**
```
Артур бьёт: Дракон HP=80
Дракон бьёт: Артур HP=80
```
> 💡 Метод принимает **другой объект** того же класса: `Attack(Fighter target)`, внутри — `target.Hp -= 20;`. Полный образец боя — в [материалы/Program.cs](материалы/Program.cs).

## ⌨️ Быстрый разогрев (2 мин)

Набери и запусти — это уже класс и объект:
```csharp
Cat cat = new Cat();
cat.Name = "Барсик";
Console.WriteLine("Кот: " + cat.Name);

class Cat
{
    public string Name;
}
```

- Мы описали свой тип `Cat` (чертёж) и создали объект `cat` по нему. `cat.Name` — поле этого объекта. Сегодня научим объекты хранить много данных, действовать и рождаться с готовыми значениями.

## 🔮 Что выведет этот код? (повторяем урок 9, на подумать)

Предскажи вывод, **не запуская**:

1. `int.TryParse("50", out int n); Console.WriteLine(n + 10);`
2. Подковырка (`TryParse` на «не числе»):
```csharp
bool ok = int.TryParse("абв", out int n);
Console.WriteLine(ok + " " + n);
```
3. Подковырка (`try/catch`):
```csharp
int a = 10, b = 0;
try { int x = a / b; }
catch { Console.WriteLine("поймали"); }
```
4. `try { Console.Write("A"); } finally { Console.Write("B"); }`

<details><summary>✅ Ответы и почему</summary>

1. `60` — «50» разобралось в число, `n` = 50, плюс 10.
2. `False 0` — ❗на «абв» `TryParse` возвращает `false`, а `n` остаётся `0` (программа НЕ падает).
3. `поймали` — деление на 0 бросает ошибку, её ловит `catch`.
4. `AB` — `finally` выполняется в любом случае, после `try`.
</details>

## 🐞 Есть ли здесь ошибка? (или всё верно?)

1. `int n = Convert.ToInt32("котик");`
2. `if (File.Exists("a.txt")) { string t = File.ReadAllText("a.txt"); }`
3. `try { int x = 5; }` (и больше ничего)
4. `int.TryParse("7", out int n); Console.WriteLine(n);`
5. `File.WriteAllText("f.txt", 123);`

<details><summary>✅ Ответы</summary>

1. ❌ Упадёт при запуске (`FormatException`): «котик» — не число. Для ввода бери `int.TryParse`.
2. ✅ Верно — сначала проверка `File.Exists`, безопасно.
3. ❌ После `try` обязателен `catch` или `finally`.
4. ✅ Верно — выведет 7.
5. ❌ Второй аргумент — **строка**, а не число: `"123"` (или `123.ToString()`).
</details>

# Урок 11 «ООП: наследование и инкапсуляция» — итого (шпаргалка) 📌

> Открой, чтобы за 3 минуты вспомнить урок. Только суть и примеры. Классы/методы/свойства — `PascalCase`, поля — `camelCase`.

---

## Главные мысли

1. **Наследование** — `class Child : Parent`: наследник берёт всё от родителя.
2. **`base(...)`** — вызвать конструктор родителя; **`base.Method()`** — его версию метода.
3. **`virtual`** (в родителе) + **`override`** (в наследнике) — переопределить поведение.
4. **Полиморфизм** — `List<Родитель>` из разных наследников; каждый действует по-своему.
5. **Инкапсуляция** — `private`/`protected` прячут данные, `public`-методы дают безопасный доступ.
6. Три кита ООП: **инкапсуляция**, **наследование**, **полиморфизм**.

---

## Наследование и base

```csharp
class Account                                      // родитель
{
    public string Owner;
    protected int balance;
    public int Balance => balance;
    public Account(string owner, int start) { Owner = owner; balance = start; }
    public void Deposit(int sum) { if (sum > 0) balance += sum; }
}

class SavingsAccount : Account                     // наследник (вклад)
{
    public SavingsAccount(string owner, int start) : base(owner, start) { }  // конструктор родителя
    public void AddInterest() => balance += balance / 20;   // своё: +5%
}

SavingsAccount s = new SavingsAccount("Аня", 1000);
s.Deposit(500);    // унаследовано от Account
s.AddInterest();   // своё
```

## virtual / override + base.Method()

```csharp
class Account { public virtual void ApplyMonthly() => Console.WriteLine("без изменений"); }
class SavingsAccount : Account { public override void ApplyMonthly() { balance += balance/20; } }  // +5%
class CheckingAccount : Account { public override void ApplyMonthly() { balance -= 10; } }         // -10
class SalaryAccount : Account
{
    public override void ApplyMonthly()
    {
        base.ApplyMonthly();     // как родитель
        balance += salary;       // и своё
    }
}
```

## Полиморфизм

```csharp
List<Account> bank = new() { new SavingsAccount("Аня", 1000), new CheckingAccount("Боря", 500) };
foreach (Account a in bank) a.ApplyMonthly();   // каждый счёт — по-своему
```

## Инкапсуляция (private / protected / public)

```csharp
class Account
{
    protected int balance;                    // закрыт снаружи, открыт наследникам
    public int Balance => balance;            // только чтение
    public void Deposit(int s) { if (s > 0) balance += s; }
    public void Withdraw(int s)
    {
        if (s > balance) { Console.WriteLine("Недостаточно"); return; }
        balance -= s;
    }
}
// acc.balance = 999;   // ❌ ошибка — balance закрыт
```

Модификаторы: `public` (все) · `private` (только сам класс) · `protected` (класс + наследники).

## Мостики Python → C#

| Python | C# |
|--------|-----|
| `class SavingsAccount(Account):` | `class SavingsAccount : Account` |
| `super().__init__(...)` | `: base(...)` |
| `def apply_monthly(self)` переопределить | `override void ApplyMonthly()` |
| `self._balance` (соглашение) | `protected int balance;` (по-настоящему скрыто) |

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| «нет конструктора 0 аргументов» | наследник не вызвал `base(...)` | добавь `: base(...)` |
| «нечего override» | забыл `virtual` у родителя | пометь метод `virtual` |
| в списке все одинаковы | метод не `virtual`/`override` | пара `virtual` + `override` |
| поле меняют снаружи | забыл `private`/`protected` | прячь данные |

---

## Что должно остаться в голове

1. Пишу `class Child : Parent`, вызываю `: base(...)`.
2. Переопределяю методы: `virtual` в родителе, `override` в ребёнке; знаю `base.Method()`.
3. Складываю разных наследников в `List<Родитель>` — полиморфизм.
4. Прячу данные `private`/`protected`, открываю `public`-методами (инкапсуляция).

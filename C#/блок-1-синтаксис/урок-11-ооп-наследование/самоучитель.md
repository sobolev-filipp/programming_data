---

## 📚 Мини-теория за 5 минут

**Наследование** — взять готовый класс-родитель и добавить своё.
- Наследник: `class Dog : Animal { }` — получает все поля и методы `Animal`.
- Конструктор родителя вызывают через `: base(...)`.
- **`virtual`** (в родителе) + **`override`** (в наследнике) — переопределить метод.
- **`base.Method()`** — вызвать версию родителя внутри наследника.

**Полиморфизм** — разные наследники в `List<Родитель>`; каждый действует по-своему.

**Инкапсуляция** — прятать данные: поле `private`, доступ через `public`-методы/свойства.

## ✍️ Задания с разбором (делаем вместе)

### Задание 1. Родитель и наследник
```csharp
Dog d = new Dog();
d.Name = "Рекс";
d.Eat();               // метод унаследован от Animal

class Animal { public string Name; public void Eat() => Console.WriteLine($"{Name} ест"); }
class Dog : Animal { }
```
✅ `Dog` не пишет `Eat()` — берёт его у `Animal`.

### Задание 2. Наследник добавляет своё
```csharp
Dog d = new Dog(); d.Name = "Рекс";
d.Bark();

class Animal { public string Name; }
class Dog : Animal { public void Bark() => Console.WriteLine($"{Name}: Гав!"); }
```

### Задание 3. Конструктор родителя (base)
```csharp
Dog d = new Dog("Рекс");
d.Eat();

class Animal
{
    public string Name;
    public Animal(string name) { Name = name; }
    public void Eat() => Console.WriteLine($"{Name} ест");
}
class Dog : Animal { public Dog(string name) : base(name) { } }
```
✅ `: base(name)` передаёт имя конструктору родителя.

### Задание 4. virtual / override
```csharp
Dog d = new Dog(); Cat c = new Cat();
d.Voice();   // Гав!
c.Voice();   // Мяу!

class Animal { public string Name; public virtual void Voice() => Console.WriteLine("..."); }
class Dog : Animal { public override void Voice() => Console.WriteLine("Гав!"); }
class Cat : Animal { public override void Voice() => Console.WriteLine("Мяу!"); }
```
✅ `virtual` разрешает менять, `override` — своя версия.

### Задание 5. Инкапсуляция
```csharp
Safe s = new Safe(100);
s.Add(50);
s.Show();      // В сейфе: 150

class Safe
{
    private int money;               // снаружи не достать
    public Safe(int start) { money = start; }
    public void Add(int sum) { if (sum > 0) money += sum; }
    public void Show() => Console.WriteLine($"В сейфе: {money}");
}
```
✅ `money` спрятан; менять только через `Add`.

**Задание:** в `Bird` сделай `virtual Voice()`, переопредели в `Parrot` («Попка дурак!»).

**Тема:** полиморфизм.
**Задание:** сложи двух разных птиц в `List<Bird>` и вызови `Voice()` у каждой.

**Тема:** base.Method().
**Задание:** наследник, чей `Voice()` вызывает `base.Voice()` и добавляет своё.

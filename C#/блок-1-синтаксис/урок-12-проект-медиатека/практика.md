# 🏋️ Практика — Урок 12 «Финальный проект: Медиатека»

**Блок 1 · Урок 12 | Дорабатываем проект и делаем свой каталог**

> Это финальный проект, поэтому практика — не отдельные задачки, а **улучшения твоей медиатеки** и **свой собственный каталог**. Бери готовый проект из [материалы/Program.cs](материалы/Program.cs) и дорабатывай. После каждого улучшения — **запускай и проверяй**. Подсказки 💡 — наводки, а не готовый код.
> 📌 Напоминание, из чего собран проект: родитель `MediaItem` → наследники `Book`/`Movie` (у каждого свой `Info()`); каталог — `List<MediaItem>`; меню — `while(true)` + методы; год защищаем `int.TryParse`; сохраняем/читаем через `File.*` + `try/catch`.

---

## 🟢 Уровень 1 — базовые улучшения

**1. Добавь игры.**
Сейчас в медиатеке живут книги и фильмы. Добавь третий вид записи — **игру**. Сделай класс `Game : MediaItem` с полем `Platform` (платформа: «PC», «PlayStation»…) и своим методом `Info()`, например: `[игра] "название" — платформа, год`. Потом добавь в меню пункт «добавить игру» (по образцу «добавить книгу»).
**Должно получиться (в списке):**
```
[игра] "Minecraft" — PC, 2011
```
> 💡 Класс `Game` делается точь-в-точь как `Book`, только вместо `Author` — `Platform`. Не забудь метод `AddGame`, похожий на `AddBook`.

**2. Показывай номер у каждой записи.**
Пусть при показе каталога каждая запись идёт с номером: `1.`, `2.`, `3.`… Так удобнее читать список.
**Должно получиться:**
```
В каталоге 2 записей:
  1. [книга] "Хоббит" — Толкин, 1937
  2. [фильм] "Матрица" — реж. Вачовски, 1999
```
> 💡 В методе `ShowAll` вместо `foreach` возьми обычный `for` с индексом `i` — тогда номер это `i + 1`, а запись `list[i]`.

**3. Пункт «сколько всего».**
Добавь в меню пункт, который печатает, **сколько записей** сейчас в каталоге.
**Должно получиться:**
```
Всего записей: 5
```
> 💡 Размер списка — это `catalog.Count`.

## 🟡 Уровень 2 — интереснее

**4. Сколько книг, а сколько фильмов.**
Добавь пункт меню, который считает **отдельно** книги и фильмы и выводит оба числа. Чтобы понять, книга перед нами или фильм, используй проверку типа: `if (m is Book) ...`.
**Должно получиться:**
```
Книг: 3, фильмов: 2
```
> 💡 Заведи два счётчика (`books`, `movies`), пройди каталог `foreach` и увеличивай нужный: `if (m is Book) books++; else if (m is Movie) movies++;`.

**5. Удаление по названию.**
Добавь пункт «удалить». Программа спрашивает название, и все записи с таким названием убираются из каталога.
**Должно получиться (после удаления «Матрица»):**
```
Удалено. Осталось записей: 4
```
> 💡 У списка есть метод `RemoveAll`, который убирает всё по условию: `catalog.RemoveAll(m => m.Title == title);`. Он вернёт, сколько удалил.

**6. Фильтр «только новинки».**
Добавь пункт «показать новинки» — печатает только записи **новее 2000 года**.
**Должно получиться (пример):**
```
[фильм] "Матрица" — реж. Вачовски, 1999   ← НЕ покажется (1999)
[игра] "Minecraft" — PC, 2011             ← покажется
```
> 💡 В цикле показывай запись только если `m.Year > 2000` (обычный `if` внутри `foreach`).

**7. Защити и другие вводы.**
Сейчас через `TryParse` защищён только год. А что если пользователь в пункте меню введёт букву вместо цифры? Проверь, что программа на это не падает (у нас выбор читается строкой и сравнивается — уже безопасно). Убедись сам: запусти и введи «абв» в меню.
**Должно получиться:**
```
Твой выбор: абв
Нет такого пункта меню.
```
> 💡 Ничего писать не надо — просто проверь поведение. Если хочешь, добавь свой вид «неизвестной команды» с подсказкой.

## 🔴 Уровень 3 — со звёздочкой

**8. Оценка и сортировка по ней.**
Добавь всем записям поле `Rating` (оценка 1–10). Спрашивай её при добавлении (тоже через `TryParse`!). Добавь пункт «сортировать по оценке» — от лучших к худшим.
**Должно получиться (пример):**
```
[фильм] "Матрица" — реж. Вачовски, 1999 (оценка 10)
[книга] "1984" — Оруэлл, 1949 (оценка 8)
```
> 💡 Поле `Rating` добавь в `MediaItem` (оно общее для всех). Сортировка от большего: `catalog.OrderByDescending(m => m.Rating).ToList()`. Не забудь дописать оценку в `Info()` и в `ToLine()`/загрузку.

**9. Быстрый поиск через `Dictionary`.**
Сделай так, чтобы запись можно было мгновенно найти по точному названию. Заведи `Dictionary<string, MediaItem>` (название → запись) и добавляй туда записи вместе со списком. Поиск тогда — одна строка через `TryGetValue`.
**Должно получиться:**
```
Найдено: [книга] "Хоббит" — Толкин, 1937
```
> 💡 При добавлении клади и в список, и в словарь: `index[title] = item;`. Поиск — `if (index.TryGetValue(name, out MediaItem found)) ...` (словарь и `TryGetValue` — из урока 8).

**10. 🏆 Свой каталог.**
Сделай **свою** программу-каталог на другую тему — структура остаётся той же, меняются только классы. Выбери, что тебе интересно:
- **Каталог игр** (жанр, платформа);
- **Кулинарная книга** (рецепт: время готовки, сложность);
- **Коллекция** (марки, карточки, монеты);
- **Список дел** с категориями.
Сделай родителя и 2 наследника, каталог `List`, меню и сохранение в файл.
**Должно получиться:** твоё рабочее приложение, которое сохраняет данные между запусками.
> 💡 Скопируй медиатеку и замени `Book`/`Movie` на свои классы, а `Title`/`Year` — на свои поля. Вся «обвязка» (меню, список, файл) почти не меняется — в этом и польза хорошей структуры.

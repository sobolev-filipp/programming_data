## ⌨️ Быстрый разогрев (2 мин)

Набери — это уже «мини-каталог» из двух записей:
```csharp
List<MediaItem> catalog = new List<MediaItem>();
catalog.Add(new Book("Хоббит", 1937, "Толкин"));
catalog.Add(new Movie("Матрица", 1999, "Вачовски"));
foreach (MediaItem m in catalog) Console.WriteLine(m.Info());

class MediaItem
{
    public string Title; public int Year;
    public MediaItem(string t, int y) { Title = t; Year = y; }
    public virtual string Info() => $"\"{Title}\" ({Year})";
}
class Book : MediaItem
{
    public string Author;
    public Book(string t, int y, string a) : base(t, y) => Author = a;
    public override string Info() => $"[книга] \"{Title}\" — {Author}, {Year}";
}
class Movie : MediaItem
{
    public string Director;
    public Movie(string t, int y, string d) : base(t, y) => Director = d;
    public override string Info() => $"[фильм] \"{Title}\" — реж. {Director}, {Year}";
}
```

- Две разные записи в одном списке, и каждая печатается по-своему. Сегодня добавим к этому меню, поиск, сортировку и **сохранение в файл** — получится настоящее приложение.

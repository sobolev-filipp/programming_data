## ⌨️ Быстрый разогрев (2 мин)

Набери — это уже «мини-каталог» из двух записей:
```csharp
List<MediaItem> catalog = new List<MediaItem>();
catalog.Add(new Book("Хоббит", 1937, "Толкин"));
catalog.Add(new Movie("Матрица", 1999, "Вачовски"));
foreach (MediaItem m in catalog) Console.WriteLine(m.Info());

class MediaItem
{
    public string Title; public int Year;
    public MediaItem(string t, int y) { Title = t; Year = y; }
    public virtual string Info() => $"\"{Title}\" ({Year})";
}
class Book : MediaItem
{
    public string Author;
    public Book(string t, int y, string a) : base(t, y) => Author = a;
    public override string Info() => $"[книга] \"{Title}\" — {Author}, {Year}";
}
class Movie : MediaItem
{
    public string Director;
    public Movie(string t, int y, string d) : base(t, y) => Director = d;
    public override string Info() => $"[фильм] \"{Title}\" — реж. {Director}, {Year}";
}
```

- Две разные записи в одном списке, и каждая печатается по-своему. Сегодня добавим к этому меню, поиск, сортировку и **сохранение в файл** — получится настоящее приложение.

## 🔮 Что выведет этот код? (весь блок 1, на подумать)

Предскажи вывод, **не запуская**:

1. `Console.WriteLine(10 % 3 + " " + 10 / 3);`
2. `string[] words = { "кот", "пёс", "ёж" }; Console.WriteLine(words.Length + ": " + words[0].ToUpper());`
3. Подковырка (полиморфизм, по разогреву выше):
```csharp
MediaItem m = new Book("Хоббит", 1937, "Толкин");
Console.WriteLine(m.Info());
```
4. `int[] a = {5, 2, 8, 1}; Array.Sort(a); Console.WriteLine(a[0] + "–" + a[3]);`

<details><summary>✅ Ответы и почему</summary>

1. `1 3` — `10 % 3` = 1 (остаток), `10 / 3` = 3 (целое деление); между ними склеен пробел.
2. `3: КОТ` — у массива 3 слова (`Length`), а `words[0].ToUpper()` = «КОТ».
3. `[книга] "Хоббит" — Толкин, 1937` — ❗хоть переменная типа `MediaItem`, вызывается **версия наследника** `Book` (это и есть полиморфизм, `virtual`/`override`).
4. `1–8` — после `Array.Sort`: `1 2 5 8`; первый и последний.
</details>

## 🐞 Есть ли здесь ошибка? (или всё верно?)

1. `double x = 5 / 2; Console.WriteLine(x);`
2. `char c = 'AB';`
3. `List<int> nums = {1, 2, 3};`
4. `if (score = 100) { Console.WriteLine("рекорд"); }`
5. `string s = null; Console.WriteLine(s.Length);`

<details><summary>✅ Ответы</summary>

1. ⚠️ Подвох: `5 / 2` — **целое** деление = 2, `x` станет `2` (а не 2,5). Чтобы вышло 2,5: `5.0 / 2`.
2. ❌ `char` — ровно один символ: `'A'`. Для двух символов нужна строка `"AB"`.
3. ❌ Нужен `new`: `List<int> nums = new List<int>{1, 2, 3};`.
4. ❌ `=` — присваивание; для сравнения нужно `==` (а условие вообще требует `bool`).
5. ❌ `s` равно `null` → `s.Length` уронит программу (NullReference).
</details>

# 🧰 Лайфхаки и частые ошибки · Урок 12 «Медиатека»

> Трюки и «грабли» при сборке большого проекта. Главное — в уроке; здесь собрано вместе.

---

## 💡 Трюки

1. **Собирай по частям.** Не пиши всё сразу: сначала классы, потом список, потом меню, потом файл. После каждого куска — запуск.
2. **Главный цикл — короткий.** Действия прячь в методы (`AddBook`, `Save`…). `while` только раздаёт команды по номеру.
3. **Полиморфизм экономит `if`-ы.** `m.Info()` сам выберет книжный или фильмовый вид — не нужно `if (это книга)…`.
4. **`ToLower()` для поиска** — чтобы «матрица» находила «Матрица».
5. **Формат строки файла** — «тип;поле;поле;…». При загрузке `Split(';')` разбирает обратно, а первое поле (`BOOK`/`MOVIE`) говорит, какой объект создать.
6. **`TryParse` на каждый ввод числа** (год, оценка) — иначе буква уронит программу.
7. **`RemoveAll(m => условие)`** — удалить все подходящие записи одной строкой.
8. **`OrderBy` / `OrderByDescending`** — сортировка по любому полю: `.OrderBy(m => m.Year)`.

---

## 🐞 Частые ошибки

| Что видишь | Причина | Лечение |
|-----------|---------|---------|
| после загрузки каталог пуст | забыл `catalog = Load(...)` | присвой результат метода |
| новый тип (`Game`) не грузится | не добавил его в `Load` | допиши ветку `else if (p[0] == "GAME")` |
| `IndexOutOfRange`/`Null` при загрузке | в строке файла меньше частей | проверь `p.Length` или лови `try/catch` |
| все записи печатаются одинаково | `Info()` не `virtual`/`override` | пометь в родителе `virtual`, в детях `override` |
| поиск не находит | забыл `ToLower()` с обеих сторон | приводи к нижнему регистру |
| год «съел» буквы / падение | ввод без `TryParse` | спрашивай через `AskYear` |
| «файл не создался» | ищешь не в той папке | смотри `bin\Debug\net10.0` |

---

## 🎯 Как расширять проект без боли

- Новый вид записи = **новый класс-наследник** + ветка в меню + ветка в `Load`. Остальное не трогаешь.
- Новое поле у всех (оценка) — добавь в **родитель** `MediaItem`, оно появится у всех.
- Хочешь другой каталог (игры, рецепты)? Меняй только **классы и поля** — меню, список и файл почти те же.

## ✅ Чек «проект готов»

1. Можно добавить книгу и фильм, показать весь список.
2. Работают поиск и сортировка.
3. Сохранение в файл и загрузка после перезапуска возвращают данные.
4. Кривой ввод (буквы вместо года) не роняет программу.

## Классы (наследование)

```csharp
class MediaItem
{
    public string Title;
    public int Year;
    public MediaItem(string title, int year) { Title = title; Year = year; }
    public virtual string Info() => $"\"{Title}\" ({Year})";
    public virtual string ToLine() => $"MEDIA;{Title};{Year}";
}
class Book : MediaItem
{
    public string Author;
    public Book(string t, int y, string a) : base(t, y) => Author = a;
    public override string Info() => $"[книга] \"{Title}\" — {Author}, {Year}";
    public override string ToLine() => $"BOOK;{Title};{Year};{Author}";
}
class Movie : MediaItem { /* так же, с Director */ }
```

## Каталог + показ (полиморфизм)

```csharp
List<MediaItem> catalog = new();
catalog.Add(new Book("Хоббит", 1937, "Толкин"));
catalog.Add(new Movie("Матрица", 1999, "Вачовски"));

foreach (MediaItem m in catalog)
    Console.WriteLine(m.Info());     // каждый — по-своему
```

## Сохранение / загрузка

```csharp
// сохранить
List<string> lines = new();
foreach (MediaItem m in catalog) lines.Add(m.ToLine());
File.WriteAllLines(file, lines);

// загрузить
foreach (string line in File.ReadAllLines(file))
{
    string[] p = line.Split(';');
    if (!int.TryParse(p[2], out int year)) continue;
    if (p[0] == "BOOK")  catalog.Add(new Book(p[1], year, p[3]));
    else if (p[0] == "MOVIE") catalog.Add(new Movie(p[1], year, p[3]));
}
```

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| после загрузки пусто | не присвоил `catalog = Load(...)` | присвой результат |
| `NullReferenceException` | в строке меньше частей | проверь `p.Length` / `try/catch` |
| поиск не находит | регистр | `ToLower()` с обеих сторон |
| все печатаются одинаково | нет `virtual`/`override` | пометь `Info()` |

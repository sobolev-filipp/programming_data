## Шаг 1. Классы записей

Сначала опиши, из чего состоит запись каталога. Общее (название, год) — в родителе, различия — в наследниках.
```csharp
class MediaItem
{
    public string Title;
    public int Year;
    public MediaItem(string title, int year) { Title = title; Year = year; }
    public virtual string Info() => $"\"{Title}\" ({Year})";
}
class Book : MediaItem
{
    public string Author;
    public Book(string t, int y, string a) : base(t, y) => Author = a;
    public override string Info() => $"[книга] \"{Title}\" — {Author}, {Year}";
}
class Movie : MediaItem
{
    public string Director;
    public Movie(string t, int y, string d) : base(t, y) => Director = d;
    public override string Info() => $"[фильм] \"{Title}\" — реж. {Director}, {Year}";
}
```
✅ Проверь: создай книгу и фильм, выведи `Info()` — печатаются по-разному (полиморфизм).

## Шаг 2. Каталог-список

```csharp
List<MediaItem> catalog = new List<MediaItem>();
catalog.Add(new Book("Хоббит", 1937, "Толкин"));
catalog.Add(new Movie("Матрица", 1999, "Вачовски"));

foreach (MediaItem m in catalog)
    Console.WriteLine(m.Info());
```
✅ Один цикл — разные записи печатаются каждая по-своему.

while (true)

## Шаг 4. Защита года

```csharp
int AskYear()
{
    int year;
    Console.Write("Год: ");
    while (!int.TryParse(Console.ReadLine(), out year))
        Console.Write("Нужно число! Год: ");
    return year;
}
```
✅ Введи буквы — программа переспросит, а не упадёт.

## 🧩 Если что-то не собирается

- Классы должны быть **внизу** файла (после основного кода).
- После загрузки не забудь `catalog = Load(...)` (присвоить!).
- Год спрашивай через `AskYear` (с `TryParse`).
- Метод `Info()` в родителе — `virtual`, в наследниках — `override`.

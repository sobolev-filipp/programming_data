> Открой, чтобы за 3 минуты вспомнить урок. Только суть и примеры. Переменные — `camelCase`, методы — `PascalCase`.

## Главные мысли

1. **Файл** — память навсегда (на диске); переменная — только на время работы.
2. Запись: **`WriteAllText`** (перезаписать) и **`AppendAllText`** (дописать).
3. Чтение: **`ReadAllText`** (весь текст) / **`ReadAllLines`** (массив строк) — после **`File.Exists`**.
4. **Исключение** — ошибка во время работы; без защиты программа падает.
5. **`try/catch`** ловит ошибку — программа продолжает работать.
6. **`int.TryParse`** — проверить, число ли ввели, без `try/catch`.

## Файлы

```csharp
File.WriteAllText("d.txt", "первая строка\n");   // создать/перезаписать
File.AppendAllText("d.txt", "ещё строка\n");     // дописать в конец
File.WriteAllLines("d.txt", new[] { "a", "b" }); // массив по строкам

if (File.Exists("d.txt"))                        // проверь перед чтением!
{
    string all = File.ReadAllText("d.txt");      // весь файл
    string[] lines = File.ReadAllLines("d.txt"); // по строкам
    Console.WriteLine(lines.Length);
}
```

## try / catch / finally

```csharp
try
{
    int n = Convert.ToInt32("абв");   // опасное действие
}
catch (FormatException ex)            // поймали нужный тип
{
    Console.WriteLine("Не число: " + ex.Message);
}
finally
{
    Console.WriteLine("выполнится всегда");   // необязателен
}
```

### Таблица главных исключений

| Исключение | Когда | Как не допустить |
|-----------|-------|------------------|
| `FormatException` | не-число в число (`Convert.ToInt32("абв")`) | `int.TryParse` |
| `DivideByZeroException` | целое ÷ 0 | `if (b != 0)` |
| `IndexOutOfRangeException` | `a[i]` за границей массива | `i < a.Length` |
| `ArgumentOutOfRangeException` | неверный индекс у `List` | `i < list.Count` |
| `KeyNotFoundException` | нет ключа в словаре | `ContainsKey`/`TryGetValue` |
| `NullReferenceException` | метод/свойство у `null` | `if (s != null)` |
| `FileNotFoundException` | нет файла | `File.Exists` |
| `OverflowException` | число не влезло в `int` | следи за диапазоном |

`catch (ИмяОшибки)` ловит конкретный тип; `catch (Exception ex)` — любую.

### Когда что использовать

- проверить **ввод на число** → `int.TryParse` (не `try/catch`);
- перед **чтением файла** → `File.Exists`;
- **деление**, где делитель может быть 0 → `if (b != 0)`;
- **ключ словаря** → `ContainsKey`/`TryGetValue`;
- **индекс** массива/списка → проверь `< Length`/`Count`;
- опасное, что заранее не угадать → `try/catch`.

**Правило:** где можно проверить заранее — проверяй заранее; `try/catch` — на остальное.

## throw — бросить свою ошибку

```csharp
if (age < 0) throw new ArgumentException("Возраст < 0!");
```

## int.TryParse — защита ввода

```csharp
if (int.TryParse(input, out int number))
    Console.WriteLine(number * 2);
else
    Console.WriteLine("Это не число!");

// переспрашивать, пока не введут число:
while (!int.TryParse(Console.ReadLine(), out int x))
    Console.WriteLine("Нужно число!");
```

## Мостики Python → C#

| Python | C# |
|--------|-----|
| `open(f,"w").write(s)` | `File.WriteAllText(f, s)` |
| `open(f).read()` | `File.ReadAllText(f)` |
| `try / except` | `try / catch` |
| `except ValueError:` | `catch (FormatException)` |
| `finally:` | `finally` |

---

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| `FileNotFoundException` | нет файла | `File.Exists` перед чтением |
| запись стёрла старое | `WriteAllText` перезаписывает | бери `AppendAllText` |
| строки слиплись | нет `\n` | добавь `\n` / `WriteAllLines` |
| `FormatException` | не число в `Convert` | `try/catch` или `int.TryParse` |

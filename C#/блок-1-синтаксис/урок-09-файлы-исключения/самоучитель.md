## 📚 Мини-теория за 5 минут

**Файлы** — память, которая остаётся после закрытия программы.
- Запись: `File.WriteAllText(файл, текст)` (перезаписывает), `File.AppendAllText(файл, текст)` (дописывает).
- Чтение: `File.ReadAllText(файл)` (весь текст), `File.ReadAllLines(файл)` (массив строк).
- Перед чтением проверяй `File.Exists(файл)` — вдруг файла ещё нет.

**Исключения** — ошибки во время работы (не число, деление на ноль, нет файла). Без защиты программа падает.
- `try { опасный код } catch (Тип) { что делать при ошибке }` — программа не падает.
- `finally { ... }` — выполнится всегда (необязателен). `throw new ...(...)` — бросить свою ошибку.
- `int.TryParse(строка, out int n)` — проверить, число ли, без `try/catch`.

## ✍️ Задания с разбором (делаем вместе)

### Задание 1. Записать в файл
```csharp
File.WriteAllText("test.txt", "Привет, файл!\n");
Console.WriteLine("Готово, проверь test.txt рядом с программой");
```
✅ Файл появится в папке `bin\Debug\net10.0`.

### Задание 2. Дописать и прочитать
```csharp
File.AppendAllText("test.txt", "вторая строка\n");
string text = File.ReadAllText("test.txt");
Console.Write(text);
```
✅ `AppendAllText` не стирает первую строку, а добавляет вторую.

### Задание 3. Проверить наличие файла
```csharp
if (File.Exists("test.txt"))
    Console.WriteLine("Файл есть, читаю: " + File.ReadAllText("test.txt"));
else
    Console.WriteLine("Файла нет");
```

### Задание 4. Поймать ошибку
**Задание:** перевести «абв» в число и не дать программе упасть.
```csharp
try
{
    int n = Convert.ToInt32("абв");
    Console.WriteLine(n);
}
catch (FormatException)
{
    Console.WriteLine("Это не число!");
}
Console.WriteLine("Программа работает дальше");
```
✅ Без `try/catch` тут была бы «красная» ошибка и остановка.

### Задание 5. Защита ввода
**Задание:** проверить ввод пользователя через `int.TryParse`.
```csharp
Console.Write("Число: ");
if (int.TryParse(Console.ReadLine(), out int n))
    Console.WriteLine($"Квадрат: {n * n}");
else
    Console.WriteLine("Не число!");
```
✅ `TryParse` вернул `true` — число готово в `n`; `false` — сработал `else`.

# 🏋️ Практика — Урок 9 «Файлы и исключения»

**Блок 1 · Урок 9 | Задачи в 3 уровнях**

> Пиши и **сразу запускай** каждую задачу (F5 / `dotnet run`). У каждой есть блок **«Должно получиться»** — это то, что должно появиться на экране (или в файле). Подсказки 💡 есть только там, где легко застрять, — и они **наводят**, а не дают готовый код.
> 📌 Что помнить: запись — `File.WriteAllText(файл, текст)` (перезаписывает) и `File.AppendAllText(файл, текст)` (дописывает); чтение — `File.ReadAllText` / `File.ReadAllLines` **после** `File.Exists`. Опасный код — в `try { } catch (Тип) { }`. Проверка ввода — `int.TryParse(строка, out int n)`. Файлы появляются рядом с программой (в папке `bin`). **Имена переменных — по-английски, `camelCase`.**

---

## 🟢 Уровень 1 — базовый

**1. Первая запись в файл.**
Создай файл `hello.txt` и запиши в него строку «Привет из C#!». Затем сам(а) открой этот файл в проводнике/редакторе и убедись, что текст на месте. Файл ищи рядом с программой (папка `bin\Debug\net10.0`).
**Должно получиться (в файле `hello.txt`):**
```
Привет из C#!
```
> 💡 Запись одной строкой делает `File.WriteAllText(имяФайла, текст)` — открывать и закрывать файл вручную не нужно.

**2. Дневник в три строки.**
Заведи файл `diary.txt`. Сначала запиши первую строку через `WriteAllText`, а потом **допиши** ещё две строки через `AppendAllText` (чтобы первая не стёрлась). В каждой строке в конце ставь `\n`.
**Должно получиться (в файле):**
```
Понедельник: выучил файлы
Вторник: выучил try-catch
Среда: отдых
```
> 💡 `WriteAllText` создаёт/перезаписывает файл, а вот `AppendAllText` **дописывает в конец**, ничего не стирая. Если строки слиплись — забыл `\n`.

**3. Прочитать файл.**
Прочитай файл `diary.txt` из прошлой задачи через `ReadAllText` и выведи его содержимое на экран.
**Должно получиться (на экране):**
```
Понедельник: выучил файлы
Вторник: выучил try-catch
Среда: отдых
```
> 💡 `File.ReadAllText` возвращает весь файл одной строкой — её достаточно просто вывести.

**4. Есть ли файл?**
Проверь через `File.Exists`, существует ли файл `diary.txt`, а потом — файл `нет-такого.txt`. Для каждого выведи понятное сообщение.
**Должно получиться:**
```
diary.txt: файл есть
нет-такого.txt: файла нет
```
> 💡 `File.Exists(файл)` отвечает `true`/`false` — используй его в `if/else`.

## 🟡 Уровень 2 — средний

**5. Счётчик строк.**
В файле `diary.txt` три строки. Прочитай файл в массив строк через `ReadAllLines` и выведи, **сколько строк** в файле. Перед чтением обязательно проверь, что файл существует.
**Должно получиться:**
```
В дневнике записей: 3
```
> 💡 `ReadAllLines` даёт массив строк — а у массива есть привычный `.Length`.

**6. Список покупок в файл и обратно.**
Заведи в программе `List<string>` из 4 покупок. Сохрани его в файл `shopping.txt` (каждая покупка — с новой строки), потом прочитай файл обратно и выведи покупки с номерами (1., 2., …).
**Должно получиться:**
```
1. хлеб
2. молоко
3. сыр
4. яблоки
```
> 💡 Целый список/массив разложить по строкам умеет `File.WriteAllLines`. Обратно прочитать — `ReadAllLines`, дальше обычный `for` с номером `i + 1`.

**7. Ловим не-число.**
Попроси у пользователя число и переведи его через `Convert.ToInt32` **внутри `try`**. Если ввели цифры — выведи это число, умноженное на 2. Если ввели буквы — программа не должна упасть: в `catch (FormatException)` напиши «Это не число!».
**Должно получиться (ввели «пять»):**
```
Введите число: пять
Это не число!
```
> 💡 Помести опасную строчку `Convert.ToInt32(...)` внутрь `try { }`, а сообщение — в `catch (FormatException) { }`.

**8. Деление без падений.**
Попроси два числа `a` и `b` и выведи `a / b`. Оберни деление в `try/catch`, чтобы при `b = 0` программа не падала, а писала «На ноль делить нельзя».
**Должно получиться (ввели 10 и 0):**
```
На ноль делить нельзя
```
> 💡 Деление на ноль бросает `DivideByZeroException` — именно этот тип и лови в `catch`.

**9. Защита ввода через TryParse.**
Попроси возраст. Проверь ввод через `int.TryParse` (без `try/catch`). Если это число — напиши «Тебе N лет», если нет — «Возраст вводят цифрами».
**Должно получиться (ввели 12):**
```
Тебе 12 лет
```
> 💡 `if (int.TryParse(input, out int age)) { ... } else { ... }` — внутри `if` переменная `age` уже готова.

## 🔴 Уровень 3 — со звёздочкой

**10. Упрямый ввод.**
Сделай так, чтобы программа **переспрашивала** число до тех пор, пока пользователь не введёт корректное. Как только ввели число — поприветствуй его («Отлично, твоё число: N»).
**Должно получиться (ввели «abc», потом «пусто», потом 7):**
```
Введите число: abc
Нужно число! Повтори:
Введите число: пусто
Нужно число! Повтори:
Введите число: 7
Отлично, твоё число: 7
```
> 💡 Хорошо ложится на `while` с условием-отрицанием: пока `!int.TryParse(...)` — повторяй запрос. Не забудь читать новую строку внутри цикла.

**11. Безопасное чтение дневника.**
Сделай программу, которая при запуске **показывает дневник, если он есть**, и пишет «Дневник пуст», если файла ещё нет. Оберни на всякий случай чтение в `try/catch` (вдруг файл повреждён) — в `catch` выведи текст ошибки через `ex.Message`.
**Должно получиться (файла нет):**
```
Дневник пуст — записей ещё нет.
```
> 💡 Сначала `if (File.Exists(...))`, а внутри — `try { читаем и печатаем } catch (Exception ex) { печатаем ex.Message }`.

**12. Своя ошибка через throw.**
Напиши метод `void Register(string name, int age)`. Если `age < 0` или `age > 120` — брось `throw new ArgumentException("Некорректный возраст")`. Вызови метод дважды в `try/catch`: один раз с нормальным возрастом, другой — с `-5`, и поймай ошибку.
**Должно получиться:**
```
Зарегистрирован: Аня (10 лет)
Ошибка: Некорректный возраст
```
> 💡 Внутри метода проверь условие и `throw`, если данные плохие. Вызовы оберни в `try`, а сообщение лови в `catch (ArgumentException ex)` и печатай `ex.Message`.

**13. Дневник рекордов (мини-версия).**
Сделай меню (`while (true)`): **1** — добавить рекорд (имя + очки, очки проверить через `int.TryParse`, сохранить строкой `имя;очки` в файл `records.txt` через `AppendAllText`); **2** — показать все рекорды (прочитать файл, каждую строку разбить `Split(';')`, вывести «имя: очки очков»); **0** — выход.
**Должно получиться (пример работы):**
```
Выбор: 1
Имя: Артур
Очки: 100
Сохранено!
Выбор: 2
  Артур: 100 очков
```
> 💡 Это уменьшенная версия проекта урока. Для показа не забудь `File.Exists`. Строку `"Артур;100"` на части разбивает `line.Split(';')` — получишь массив, где `[0]` имя, `[1]` очки. Полный образец — в [материалы/Program.cs](материалы/Program.cs).

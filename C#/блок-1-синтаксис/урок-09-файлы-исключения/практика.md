# 🏋️ Практика — Урок 9 «Файлы и исключения»

**Блок 1 · Урок 9 | 30 заданий в 3 уровнях по сложности**

> Пиши и **сразу запускай** (F5 / `dotnet run`). У каждой задачи — **«Должно получиться»** и **💡 подсказка**.
> 🟢 базовый · 🟡 средний · 🔴 со звёздочкой. Часть задач **повторяет уроки 1–8** (циклы, коллекции, методы, дата) — чтобы не забывалось.
> 📌 Шпаргалка: записать `File.WriteAllText(путь, текст)` · дописать `File.AppendAllText(...)` · записать строки `File.WriteAllLines(путь, массив)` · прочитать всё `File.ReadAllText(путь)` · по строкам `File.ReadAllLines(путь)` · есть ли файл `File.Exists(путь)` · защита от ошибок `try { ... } catch (Тип e) { ... }` · всегда после — `finally` · своя ошибка — `throw` · безопасный ввод числа — `int.TryParse(строка, out n)` · разбить строку — `s.Split(';')`. **Имена — латиницей.**
> 💡 Файл появляется рядом с программой (папка `bin\Debug\net10.0`). Подсказки — **наводки**, а не готовый код.

## 🟢 Уровень 1 — базовый (примени изученное)

**1. Первая запись в файл.**
Запиши в файл `note.txt` строку «Привет из C#!» и убедись (открыв файл), что она там появилась.
**Должно получиться (в файле note.txt):**
```
Привет из C#!
```
> 💡 Одна команда `File.WriteAllText`, которой передают **имя файла** и **текст**.

**2. Дневник в одну строку.**
Допиши в тот же файл ещё две строки (не стирая первую). Проверь, что все три на месте.
**Должно получиться:**
```
Привет из C#!
Вторая запись
Третья запись
```
> 💡 `WriteAllText` **перезаписывает** файл, а вот дописывать (не стирая) умеет `AppendAllText`. Не забудь перевод строки в конце.

**3. Прочитать файл.**
Прочитай содержимое `note.txt` целиком и выведи на экран.
**Должно получиться:** на экране появляется весь текст файла.
> 💡 Прочитать весь файл одной строкой поможет `File.ReadAllText`.

**4. Файл по строкам.**
Прочитай `note.txt` **построчно** и выведи каждую строку с номером.
**Должно получиться:**
```
1. Привет из C#!
2. Вторая запись
```
> 💡 `File.ReadAllLines` возвращает **массив строк** — дальше перебери его циклом `for` (чтобы был номер).

**5. А есть ли файл.**
Проверь, существует ли файл `secret.txt`, и выведи «есть» или «нет».
**Должно получиться (если файла нет):**
```
Файла нет
```
> 💡 Проверку наличия делает `File.Exists`, возвращая `true`/`false`.

**6. Список чисел в файл.** *(повтор урока 6)*
Заведи массив чисел и запиши его в файл `nums.txt` — **каждое число на своей строке**.
**Должно получиться (в файле):**
```
10
20
30
```
> 💡 Для записи массива по строкам есть `File.WriteAllLines`, которому передают путь и массив.

**7. Ловим деление на ноль.**
Попробуй поделить 10 на 0 внутри защиты `try/catch`, чтобы программа **не упала**, а вывела понятное сообщение.
**Должно получиться:**
```
На ноль делить нельзя!
```
> 💡 Опасное действие помести в `try`, а обработку — в `catch (DivideByZeroException)`.

**8. Ловим неверный ввод.**
Спроси у пользователя число и попробуй прибавить к нему 10. Если ввели **не число** — не дай программе упасть, выведи «Это не число».
**Должно получиться (ввели «привет»):**
```
Введи число: привет
Это не число
```
> 💡 Оберни ввод и вычисление в `try`, а в `catch (FormatException)` выведи сообщение об ошибке.

**9. Безопасный ввод.**
Спроси число через `int.TryParse` и выведи «Ок, число N» или «Не получилось».
**Должно получиться (ввели 5):**
```
Ок, число 5
```
> 💡 `int.TryParse(строка, out n)` возвращает `true`, если удалось, и кладёт результат в `n`. Проверь этот `true/false` условием.

**10. Сохрани ответ.**
Спроси у пользователя его имя и запиши его в файл `name.txt`.
**Должно получиться (в файле):**
```
Аня
```
> 💡 Прочитай ввод и передай его в `File.WriteAllText`.

## 🟡 Уровень 2 — средний (файлы + логика)

**11. Дневник записей.** *(повтор урока 8: перебор)*
Сделай так: пользователь вводит запись, она **дописывается** в файл `diary.txt`, а потом программа выводит **все** записи из файла.
**Должно получиться:**
```
Твоя запись: сегодня учил C#
--- Все записи ---
вчера гулял
сегодня учил C#
```
> 💡 Дописывай `AppendAllText`, а показывай — прочитав `ReadAllLines` и перебрав.

**12. Счётчик запусков.**
Пусть программа считает, **сколько раз её запускали**: читает число из файла `runs.txt`, увеличивает и записывает обратно. Если файла ещё нет — начни с 1.
**Должно получиться (при третьем запуске):**
```
Запуск №3
```
> 💡 Если `File.Exists` — прочитай число (`ReadAllText` + превратить в `int`), иначе считай, что было 0. Прибавь 1 и запиши обратно `WriteAllText`.

**13. Переспрашивай, пока не число.** *(повтор урока 4: цикл)*
Спрашивай число, пока пользователь не введёт корректное (через `int.TryParse`), потом выведи его квадрат.
**Должно получиться:**
```
Число: abc
Нужно число! Ещё раз.
Число: 6
Квадрат: 36
```
> 💡 Крути цикл `while`, пока `int.TryParse` возвращает `false`. Как только `true` — выходи и считай.

**14. Сумма чисел из файла.** *(повтор урока 6)*
В файле `nums.txt` записаны числа (по одному на строке). Прочитай их и выведи **сумму**.
**Должно получиться (для 10, 20, 30):**
```
Сумма: 60
```
> 💡 Прочитай строки `ReadAllLines`, каждую преврати в число и складывай в копилку.

**15. Разбор строки.** *(повтор урока 2: строки)*
Дана строка `string record = "Аня;95"`. Разбери её на **имя** и **балл** и выведи по отдельности.
**Должно получиться:**
```
Имя: Аня
Балл: 95
```
> 💡 Разбить строку по разделителю умеет `Split(';')` — он вернёт массив кусочков.

**16. Две ошибки — два catch.**
В одном `try` сделай два опасных действия (деление на ноль и превращение «abc» в число) и обработай их **разными** `catch`.
**Должно получиться:**
```
Поймана ошибка деления
```
> 💡 После `try` можно поставить несколько `catch` — каждый ловит свой тип (`DivideByZeroException`, `FormatException`). Сработает тот, что подходит первой возникшей ошибке.

**17. Блок finally.**
Сделай `try/catch` с любым опасным действием и добавь `finally`, который выводит «Проверка завершена» **в любом случае**.
**Должно получиться (даже при ошибке):**
```
Произошла ошибка
Проверка завершена
```
> 💡 Блок `finally` выполняется всегда — и когда была ошибка, и когда нет. Помести туда завершающее сообщение.

**18. Массив туда и обратно.** *(повтор урока 6)*
Запиши массив чисел в файл, затем **прочитай его обратно** в массив и выведи сумму — чтобы убедиться, что данные вернулись.
**Должно получиться:**
```
Записали: 5 3 8 1 9
Прочитали, сумма: 26
```
> 💡 Записать — `WriteAllLines`. Прочитать — `ReadAllLines` (получишь строки), каждую преврати в число.

**19. Предскажи вывод.**
Не запуская, скажи, что напечатает код и **в каком порядке**. Потом проверь.
```csharp
try
{
    Console.WriteLine("до");
    int x = 10 / 0;
    Console.WriteLine("после");
}
catch (DivideByZeroException)
{
    Console.WriteLine("поймал");
}
Console.WriteLine("конец");
```
**Должно получиться:** список строк по порядку и объяснение, **почему «после» не печатается**.
> 💡 Как только в `try` возникает ошибка, выполнение **прыгает** в `catch`, пропуская остаток `try`. Что успеет напечататься до ошибки, а что — нет?

**20. Безопасный калькулятор.** *(повтор урока 3)*
Спроси два числа и знак. Считай результат, но защити программу и от **неверного ввода чисел** (`TryParse`), и от **деления на ноль**.
**Должно получиться (10, 0, «/»):**
```
На ноль делить нельзя
```
> 💡 Числа читай через `int.TryParse` (если не число — сообщи и не считай). Перед делением проверь, что второе число не ноль.

## 🔴 Уровень 3 — со звёздочкой (собери целое)

**21. Дневник рекордов.** *(повтор урока 2: дата)*
Пользователь вводит результат игры, программа дописывает в файл строку «балл;дата», а по команде показывает все рекорды и **лучший**.
**Должно получиться:**
```
--- Рекорды ---
120;06.09.2026
95;05.09.2026
Лучший: 120
```
> 💡 Строку собирай как «балл;сегодняшняя дата» (дата из урока 2) и дописывай `AppendAllText`. При показе разбирай каждую строку `Split(';')`, балл превращай в число и ищи максимум.

**22. Список дел с сохранением.** *(повтор урока 8: List)*
Сделай список задач, который **сохраняется в файл** и **загружается** при новом запуске (чтобы дела не терялись).
**Должно получиться:** добавленные вчера дела видны и сегодня.
> 💡 Дела храни в `List<string>`. Сохраняй список `WriteAllLines`. При старте, если файл есть (`File.Exists`), загрузи строки обратно в список.

**23. Своя ошибка (`throw`).**
Спроси возраст. Если ввели **отрицательное** число — «выброси» свою ошибку с понятным текстом и поймай её.
**Должно получиться (ввели −5):**
```
Ошибка: возраст не может быть отрицательным
```
> 💡 Проверь условие и, если плохо, выполни `throw new Exception("...")`. Вокруг — `try/catch`, который поймает и выведет текст ошибки (`e.Message`).

**24. Менеджер заметок.**
Пользователь вводит **название** заметки и её текст. Программа сохраняет текст в файл с этим названием (например, `идея.txt`).
**Должно получиться:** создаётся файл с именем заметки и введённым текстом внутри.
> 💡 Имя файла собери из названия заметки плюс `.txt` (склейка строк). Текст запиши `WriteAllText`.

**25. Найди и почини ошибку.**
Программа должна читать файл, но падает, если файла нет:
```csharp
string text = File.ReadAllText("data.txt");
Console.WriteLine(text);
```
**Должно получиться:** если файл есть — покажи текст, если нет — «Файл не найден» (без падения).
> 💡 Два способа: проверить `File.Exists` перед чтением **или** обернуть чтение в `try/catch (FileNotFoundException)`. Выбери любой.

**26. Таблица результатов.** *(повтор урока 8: разбор строк)*
В файле `scores.txt` строки вида «имя;балл». Прочитай их, выведи всех и найди **имя лучшего**.
**Должно получиться:**
```
Аня: 70
Боря: 95
Вика: 88
Лучший: Боря
```
> 💡 Каждую строку разбирай `Split(';')`: первый кусок — имя, второй — балл (преврати в число). Ищи имя с наибольшим баллом (приём «рекордсмен» из урока 6).

**27. Частота слов в файл.** *(повтор урока 8: словарь)*
Посчитай, сколько раз встречается каждое число в массиве, и **сохрани отчёт** в файл `report.txt`.
**Должно получиться (в файле, для 1,2,2,3,3,3):**
```
1: 1 раз
2: 2 раза
3: 3 раза
```
> 💡 Посчитай частоты словарём-счётчиком (урок 8), собери строки отчёта в список, запиши `WriteAllLines`.

**28. Метод безопасного ввода.** *(повтор урока 7: методы)*
Напиши **метод** `AskInt`, который спрашивает число и переспрашивает, пока не введут корректное. Используй его дважды.
**Должно получиться:** метод возвращает гарантированно число, программа не падает на буквах.
> 💡 Внутри метода — цикл с `int.TryParse`, пока не получится. Метод возвращает `int`. Один раз написал — зовёшь где угодно.

**29. Лог программы.** *(повтор урока 2: дата)*
Пусть при каждом запуске программа **дописывает** в файл `log.txt` строку с текущей датой и временем.
**Должно получиться (в файле после нескольких запусков):**
```
Запуск: 06.09.2026 19:18
Запуск: 06.09.2026 19:20
```
> 💡 Собери строку с `DateTime.Now` (формат из урока 2) и допиши `AppendAllText` с переводом строки.

**30. Свой файловый проект.**
Собери **свою** программу, которая помнит данные между запусками — на выбор:
- 📔 личный дневник (дописывать записи с датой, читать все);
- 🏆 таблица рекордов игры (имя;очки, топ);
- 📝 список покупок, который сохраняется и загружается.
**Должно получиться:** данные **не теряются** после закрытия программы.
> 💡 Главный цикл: показать/добавить/сохранить. Обязательно проведи проверку: добавил → закрыл → снова открыл → данные на месте.

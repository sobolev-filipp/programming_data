# 🖼 Изображения к уроку 9 — что показать на проекторе

Две схемы: «файл — память навсегда» и «try/catch — поймать ошибку».

---

## `файл-запись-чтение.svg` — файл: запись и чтение
**Когда показать:** Часть 1 — при введении файлов; держать при разборе чтения (Часть 2).

**Что на схеме:** слева «Программа» (переменные/списки, «закрыл — всё стёрлось»), справа файл `records.txt` на диске («остаётся после выхода»). Синяя стрелка вправо — **запись** (`WriteAllText` перезаписать, `AppendAllText` дописать); зелёная влево — **чтение** (`ReadAllText` весь текст, `ReadAllLines` по строкам). Внизу предупреждение: перед чтением — `File.Exists`.

**Что сказать:** «Пока данные в переменных — они живут только пока программа открыта. Файл — это память на диске: записал — и данные остаются даже после выключения. Записать можно двумя способами: `WriteAllText` стирает старое и пишет заново, а `AppendAllText` дописывает в конец. Прочитать — `ReadAllText` (всё сразу) или `ReadAllLines` (по строчкам в массив). Но сначала всегда проверь `File.Exists` — вдруг файла ещё нет».

**Приём на проекторе:** записать строку, закрыть программу, открыть файл в проводнике — данные на месте. Потом `AppendAllText` ещё раз — показать, что дописалось, а не стёрлось.

## `try-catch-схема.svg` — try / catch / finally
**Когда показать:** Часть 3 — при введении исключений; держать при разборе `finally` (Часть 4).

**Что на схеме:** слева «❌ Без try» — код `Convert.ToInt32("абв")` и 💥 `FormatException` (программа падает). Справа «✅ С try» — три блока сверху вниз: голубой `try` (опасный код) → оранжевый `catch` (поймать, не упасть) → зелёный `finally` (выполнится всегда). Слева-внизу карточка «Как читать»: try — попробуй, catch — поймай, finally — сделай в конце; мостик к Python `try/except/finally`.

**Что сказать:** «Без защиты кривой ввод рушит всю программу — красная ошибка, всё останавливается. `try` говорит „попробуй это опасное“, `catch` — „если сломается, поймай и продолжи“. Программа не падает, а печатает понятное сообщение. `finally` — то, что нужно сделать в любом случае (необязателен). В Python было `try/except`, в C# — `try/catch`».

**Приём на проекторе:** сначала запустить `Convert.ToInt32("абв")` **без** `try` — показать «красное» падение. Потом обернуть в `try/catch` — программа выжила. Это главный «вау-момент» урока.

## ⌨️ Быстрый разогрев (2 мин)

Набери и запусти — программа сохранит текст в файл и прочитает обратно:
```csharp
File.WriteAllText("razminka.txt", "Привет из файла!");
string text = File.ReadAllText("razminka.txt");
Console.WriteLine("Из файла прочитано: " + text);
```

- Мы записали строку на диск и тут же её прочитали. Файл `razminka.txt` появился рядом с программой — теперь данные **не исчезнут** после закрытия. В этом суть файлов.

## 🌉 Что нового будет сегодня

- **Файлы:** `File.WriteAllText` / `AppendAllText` / `ReadAllText` / `ReadAllLines` + `File.Exists`.
- **Исключения:** `try / catch / finally`, `throw`, типы ошибок.
- **`int.TryParse`** — защита ввода без падений.
- Проект — «Дневник рекордов» с сохранением в файл.

> ⚙️ Учителю: мотивация — «где хранятся рекорды в играх после выключения?» (в файле). Мостик Python сильный: `open/read/write`, `try/except` знакомы. `out` в `TryParse` — прямая отсылка к Уроку 7. Автор просил **усилить try-catch** — заложены Часть 3–4 (типы ошибок, `finally`, `throw`) + практика.

## ⌨️ Быстрый разогрев (2 мин)

Набери и запусти — программа сохранит текст в файл и прочитает обратно:
```csharp
File.WriteAllText("razminka.txt", "Привет из файла!");
string text = File.ReadAllText("razminka.txt");
Console.WriteLine("Из файла прочитано: " + text);
```

- Мы записали строку на диск и тут же её прочитали. Файл `razminka.txt` появился рядом с программой — теперь данные **не исчезнут** после закрытия. В этом суть файлов.

## 🌉 Что нового будет сегодня

- **Исключения:** `try / catch / finally`, `throw`, типы ошибок.
- **`int.TryParse`** — защита ввода без падений.
- Проект — «Дневник рекордов» с сохранением в файл.

## 🔮 Что выведет этот код? (повторяем урок 8, на подумать)

Предскажи вывод, **не запуская**:

1. `List<int> nums = new List<int>{ 10, 20, 30 }; nums.Add(40); Console.WriteLine(nums.Count);`
2. Подковырка (`RemoveAt`):
```csharp
List<string> a = new List<string>{ "a", "b", "c" };
a.RemoveAt(0);
Console.WriteLine(a[0]);
```
3. Подковырка (повтор ключа в словаре):
```csharp
var age = new Dictionary<string,int>();
age["Аня"] = 13;
age["Аня"] = 14;
Console.WriteLine(age["Аня"]);
```
4. `List<int> a = new List<int>{ 3, 1, 2 }; a.Sort(); Console.WriteLine(a[0] + " " + a[2]);`

<details><summary>✅ Ответы и почему</summary>

1. `4` — было 3, добавили ещё один → `Count` = 4.
2. `b` — удалили элемент с индексом 0 («a»), теперь на месте 0 стоит бывший «b».
3. `14` — ❗ключ уникален: запись по тому же ключу **перезаписывает** значение.
4. `1 3` — после `Sort`: `1 2 3`, печатаем первый и последний.
</details>

## 🐞 Есть ли здесь ошибка? (или всё верно?)

1. `List<int> a = new List<int>(); Console.WriteLine(a.Length);`
2. `var d = new Dictionary<string,int>(); int x = d["нет"];`
3. `List<string> a = new(); a.Add("x"); Console.WriteLine(a[0]);`
4. `List<int> a = new List<int>{1, 2}; a.RemoveAt(5);`
5. `var d = new Dictionary<string,int>(); d["кот"] = 1; Console.WriteLine(d.ContainsKey("кот"));`

<details><summary>✅ Ответы</summary>

1. ❌ У `List` размер — `Count`, а не `Length`.
2. ❌ Ключа «нет» в словаре → `KeyNotFoundException`. Нужен `ContainsKey`/`TryGetValue`.
3. ✅ Верно — выведет «x».
4. ❌ В списке из 2 элементов индексы 0..1; `RemoveAt(5)` — за границей.
5. ✅ Верно — выведет `True`.
</details>

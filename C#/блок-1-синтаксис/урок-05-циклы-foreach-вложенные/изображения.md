## `вложенные-циклы.svg` — цикл в цикле
**Когда показать:** Часть 3 (вложенные циклы) — держать на экране весь блок про сетки и узоры.

**Что на схеме:** слева — код: внешний цикл `for i` (синий, «строки») и внутри него внутренний `for j` (оранжевый, «столбцы»). Справа — результат-сетка 3×3 из пар `(i,j)`: для каждой строки `i` внутренний `j` пробегает слева направо весь ряд. Внизу — напоминание: внешний = строки, внутренний = что в строке, а `Console.WriteLine()` переводит на новую строку.

**Что сказать:** «Внешний цикл идёт по строкам, внутренний — по столбцам. Для каждого `i` внутренний `j` прокручивается полностью — получается ряд. В конце ряда `WriteLine()` переводит на новую строку. Так же строятся все узоры».

**Приём на проекторе:** прогнать глазами `(1,1)(1,2)(1,3)`, затем `(2,…)`. Специально убрать `WriteLine()` → показать «слипшийся» вывод в одну строку → вернуть. Дальше сразу рисовать пирамиду/ёлочку — дети видят результат.

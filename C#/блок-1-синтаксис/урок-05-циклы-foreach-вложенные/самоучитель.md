## 📚 Мини-теория за 5 минут

**`do-while`** — тело сначала выполняется, потом проверка (хотя бы раз):
```csharp
do { ... } while (условие);   // ; в конце!
```
**`foreach`** — перебор всех элементов без счётчика:
```csharp
foreach (char c in "кот") Console.WriteLine(c);
```
**Вложенный цикл** — цикл в цикле (внешний-строки, внутренний-столбцы), после внутреннего — `Console.WriteLine()`.
**`new string('*', n)`** — строка из `n` символов (как `"*"*n`).
**Цвет:** `Console.ForegroundColor = ConsoleColor.Green; ... Console.ResetColor();`.

## ✍️ Задания с разбором (делаем вместе)

### Задание 1. do-while
**Тема:** цикл, который сработает хотя бы раз.
**Задание:** выводи «Привет» и спрашивай «ещё? (да/нет)», пока отвечают «да».

**Разбор:**
```csharp
string answer;
do
{
    Console.WriteLine("Привет!");
    Console.Write("Ещё? (да/нет): ");
    answer = Console.ReadLine();
} while (answer == "да");
```
✅ Первый «Привет» покажется до всякой проверки.

### Задание 2. foreach по строке
**Тема:** перебор букв.
**Задание:** выведи каждую букву слова «мир» в столбик.

**Разбор:**
```csharp
foreach (char c in "мир")
    Console.WriteLine(c);      // м / и / р
```

### Задание 3. foreach по массиву
**Тема:** перебор чисел.
**Задание:** найди сумму чисел `{5, 10, 15}`.

**Разбор:**
```csharp
int[] numbers = { 5, 10, 15 };
int sum = 0;
foreach (int n in numbers) sum += n;
Console.WriteLine(sum);        // 30
```

### Задание 4. Вложенные циклы
**Тема:** цикл в цикле.
**Задание:** выведи квадрат 3×3 из звёздочек.

**Разбор по шагам:**
1. Внешний цикл — 3 строки.
2. Внутренний — 3 звёздочки в строке.
3. После внутреннего — перевод строки.
```csharp
for (int r = 0; r < 3; r++)
{
    for (int c = 0; c < 3; c++) Console.Write("*");
    Console.WriteLine();
}
```

### Задание 5. Пирамида
**Тема:** узор через `new string`.
**Задание:** нарисуй пирамиду из 4 строк символом `#`.

**Разбор:**
```csharp
for (int i = 1; i <= 4; i++)
    Console.WriteLine(new string('#', i));   // #, ##, ###, ####
```

# Урок 5 «Циклы-2: do-while, foreach, вложенные» — итого 📌

> Открой, чтобы за 3 минуты вспомнить урок. Только суть и примеры.

---

## Главные мысли

1. **`do-while`** — тело выполняется **хотя бы раз** (условие проверяется внизу). После `while(...)` — **`;`**.
2. **`foreach`** — перебор всех элементов без счётчика (как `for x in` в Python).
3. **Вложенный цикл** — цикл в цикле: внешний = строки, внутренний = столбцы.
4. После внутреннего цикла — `Console.WriteLine()` (новая строка).
5. `new string('*', n)` — строка из `n` символов (как `"*"*n` в Python).
6. Цвет: `Console.ForegroundColor = ConsoleColor.Green; ... Console.ResetColor();`.

---

## do-while

```csharp
do
{
    Console.Write("Меню [0-выход]: ");
    выбор = Console.ReadLine();
} while (выбор != "0");     // ← ; обязательна
```
`while` может ни разу не сработать; `do-while` — минимум один раз.

---

## foreach

```csharp
foreach (char c in "кот") Console.WriteLine(c);   // к, о, т
int[] scores = { 10, 25, 7 };
int sum = 0;
foreach (int s in scores) sum += s;
```
Нужен номер или менять элемент → бери `for`. Просто пройти → `foreach`.

---

## Вложенные циклы

```csharp
for (int i = 1; i <= 3; i++)        // строки
{
    for (int j = 1; j <= 3; j++)    // столбцы
        Console.Write($"({i},{j}) ");
    Console.WriteLine();           // конец строки
}
```

Внутренний прокручивается ПОЛНОСТЬЮ для каждого шага внешнего.

## Узоры

```csharp
new string('#', i)                 // ##### (i символов)

Console.Write(new string(' ', n-строка));

// шахматка
Console.Write((r + c) % 2 == 0 ? "██" : "  ");
```

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| `; expected` | нет `;` после `} while(...)` | поставь `;` |
| узор в одну строку | нет `WriteLine()` после внутреннего | перевод строки в конце ряда |
| `foreach` не меняет элемент | он только для чтения | нужно менять → `for` |
| цвет залип | забыл `ResetColor()` | верни цвет после вывода |

## Что должно остаться в голове

1. `do-while` — хотя бы раз; `;` после `while`.
2. `foreach` — перебор без счётчика.
3. Вложенные циклы: внешний-строки, внутренний-столбцы, `WriteLine()` в конце ряда.
4. Рисую узоры `new string(символ, n)`, включаю цвет.

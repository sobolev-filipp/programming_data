# 🏋️ Практика — Урок 5 «Циклы-2: do-while, foreach, вложенные»

**Блок 1 · Урок 5 | Задачи в 3 уровнях**

> Пиши и **сразу запускай** каждую задачу (F5 / `dotnet run`). У каждой есть блок **«Должно получиться»** и **💡 подсказка**.
> 📌 Шпаргалка: `do { ... } while (условие);` (тело хотя бы раз, `;` в конце!); `foreach (тип x in коллекция) ...` (перебор без счётчика); вложенный цикл — цикл в цикле (после внутреннего — `Console.WriteLine()`); `new string('*', n)` — строка из `n` символов.

---

## 🟢 Уровень 1 — базовый

**1. Повторяй до нуля (do-while).**
Через `do-while` спрашивай число и выводи его, пока не введут `0`.
**Должно получиться:**
```
Число (0 - выход): 7
Ты ввёл: 7
Число (0 - выход): 0
Стоп!
```
> 💡 `do { ... } while (n != 0);`. Число читай внутри цикла.

**2. Буквы в столбик (foreach).**
Спроси слово и через `foreach` выведи каждую букву на новой строке.
**Должно получиться (слово «кот»):**
```
к
о
т
```
> 💡 `foreach (char c in word) Console.WriteLine(c);`.

**3. Сумма очков (foreach).**
Есть массив `int[] очки = { 10, 25, 7, 42 };`. Через `foreach` посчитай и выведи их сумму.
**Должно получиться:**
```
Сумма: 84
```
> 💡 `int sum = 0; foreach (int s in scores) sum += s;`.

**4. Квадрат из звёздочек (вложенные).**
Выведи квадрат 5×5 из `*` (5 строк по 5 звёздочек).
**Должно получиться:**
```
*****
*****
*****
*****
*****
```
> 💡 Внешний — 5 строк; внутренний печатает `*` 5 раз; в конце — `Console.WriteLine()`.

---

## 🟡 Уровень 2 — средний

**5. Пирамида.**
Спроси размер `n` и нарисуй пирамиду из `#` (в строке `i` — `i` символов).
**Должно получиться (n = 4):**
```
#
##
###
####
```
> 💡 `for (int i = 1; i <= n; i++) Console.WriteLine(new string('#', i));`.

**6. Таблица умножения сеткой.**
Вложенными циклами выведи таблицу умножения 5×5 ровными столбцами.
**Должно получиться:**
```
   1   2   3   4   5
   2   4   6   8  10
   ...
```
> 💡 Внутри — `Console.Write($"{a * b,4}");`, после ряда — `Console.WriteLine()`.

**7. Меню (do-while).**
Через `do-while` показывай меню `[1 — привет, 0 — выход]` и реагируй, пока не введут `0`.
**Должно получиться:**
```
Меню [1-привет, 0-выход]: 1
Привет!
Меню [1-привет, 0-выход]: 0
Пока!
```
> 💡 `do { ... switch/if ... } while (выбор != "0");`.

**8. Сколько гласных (foreach).**
Спроси слово и посчитай, сколько в нём гласных букв (а, е, ё, и, о, у, ы, э, ю, я).
**Должно получиться:**
```
Слово: программа
Гласных: 3
```
> 💡 `foreach (char c in word) if ("аеёиоуыэюя".Contains(c)) count++;`.

**9. Ёлочка.**
Спроси размер `n` и нарисуй ёлочку (отступ + нечётное число звёзд).
**Должно получиться (n = 4):**
```
   *
  ***
 *****
*******
```
> 💡 Отступ `new string(' ', n - строка)`, звёзды `new string('*', строка * 2 - 1)`.

## 🔴 Уровень 3 — со звёздочкой

**10. Шахматка.**
Спроси размер `n` и нарисуй шахматное поле `n×n` (закрашено `██`, если сумма координат чётная).
**Должно получиться (n = 4):**
```
██  ██
  ██  ██
██  ██
  ██  ██
```
> 💡 Вложенные циклы; `Console.Write((r + c) % 2 == 0 ? "██" : "  ");`.

**11. Ромб.**
Нарисуй ромб размера `n` (пирамида вверх + перевёрнутая пирамида).
**Должно получиться (n = 3):**
```
  *
 ***
*****
 ***
  *
```
> 💡 Два цикла подряд: первый `i` от 1 до n, второй — от n−1 до 1. В каждом — отступ + звёзды.

**12. Генератор узоров.**
Спроси, какой узор нарисовать (1-ёлочка, 2-пирамида, 3-шахматка), и размер — нарисуй выбранный (ёлочку — зелёным).
**Должно получиться:** выбранный узор нужного размера.
> 💡 Это проект урока: `switch (choice)` + циклы + `Console.ForegroundColor`.

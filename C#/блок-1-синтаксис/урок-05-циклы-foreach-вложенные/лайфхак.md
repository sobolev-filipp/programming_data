# 🧰 Лайфхаки и частые ошибки · Урок 5 «Циклы-2»

> Трюки и «грабли» по `do-while`, `foreach`, вложенным циклам и узорам. Главное уже показано в уроке — здесь собрано вместе.

---

## 💡 Трюки

1. **`new string('*', n)`** — быстрый способ повторить символ `n` раз (как `"*"*n` в Python). Идеален для узоров и рамок.
2. **`foreach` короче и безопаснее `for`**, когда номер не нужен — не ошибёшься с границами.
3. **Выравнивание в столбцы:** `$"{x,4}"` — число займёт 4 позиции (по правому краю), `$"{x,-4}"` — по левому. Так таблицы получаются ровными.
4. **Цвет консоли:** `Console.ForegroundColor = ConsoleColor.Green;` (есть `Red`, `Yellow`, `Cyan`, `Magenta`…), в конце — `Console.ResetColor();`.
5. **`do-while` для меню** — меню показывается сразу, повтор — пока не выберут «выход».
6. **Ромб = две пирамиды**: цикл вверх (`i` растёт) + цикл вниз (`i` убывает).
7. **Анимация узора:** между строками поставь `System.Threading.Thread.Sleep(150);` — узор будет «прорисовываться».

## 🐞 Частые ошибки

| Что видишь | Причина | Лечение |
|-----------|---------|---------|
| `; expected` | нет `;` после `} while (условие)` | поставь `;` |
| узор вывелся в одну строку | нет `Console.WriteLine()` после внутреннего цикла | перевод строки в конце ряда |
| строки «съехали» | перепутал `Write` и `WriteLine` | внутри ряда — `Write`, в конце — `WriteLine()` |
| `foreach` «не меняет» элементы | `foreach` — только чтение | нужно менять/номер → `for` с индексом |
| цвет остался на весь экран | забыл `Console.ResetColor()` | верни цвет после вывода |
| `do-while` крутится вечно | условие не меняется в теле | меняй переменную условия внутри |
| ёлочка кривая | неверная формула звёзд/отступа | звёзды `строка*2-1`, отступ `n-строка` |

## 🎯 for / while / do-while / foreach — когда что

- **`for`** — известно число повторов, нужен счётчик (номер).
- **`while`** — повтор по условию, может ни разу не выполниться.
- **`do-while`** — как `while`, но **хотя бы раз** (меню, «повторить?»).
- **`foreach`** — пройти по всем элементам коллекции без счётчика.

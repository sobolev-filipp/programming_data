## 🎤 Блиц-вопросы (устно, 2 мин)

2. Что делает `break`? а `continue`? (выйти / пропустить шаг)
3. Как повторить символ `n` раз в C#? (сегодня узнаем: `new string('*', n)`)
4. Как в Python перебирали буквы строки? (`for c in "слово"`) — сегодня это будет `foreach`.

## ⌨️ Быстрый разогрев (2 мин)

Набери и запусти — это уже `foreach`:
```csharp
foreach (char c in "Привет")
    Console.Write(c + "-");
```

- Вывелось `П-р-и-в-е-т-` — цикл прошёл по всем буквам без счётчика. Сегодня разберём такие циклы и научимся рисовать узоры.

## 🌉 Что нового будет сегодня

- **`do-while`** — цикл, который срабатывает хотя бы раз (удобно для меню).
- **`foreach`** — перебор без счётчика.
- **Вложенные циклы** — цикл в цикле → таблицы и **узоры** (пирамида, ёлочка, шахматка).

## 🔮 Что выведет этот код? (повторяем урок 4, на подумать)

Предскажи вывод, **не запуская**:

1. `for (int i = 0; i < 5; i += 2) Console.Write(i + " ");`
2. `int i = 5; while (i > 0) { Console.Write(i + " "); i--; }`
3. Подковырка (`continue`):
```csharp
for (int i = 1; i <= 5; i++) { if (i == 3) continue; Console.Write(i + " "); }
```
4. Подковырка (`break`):
```csharp
for (int i = 1; i <= 10; i++) { if (i == 4) break; Console.Write(i + " "); }
```

<details><summary>✅ Ответы и почему</summary>

1. `0 2 4 ` — шаг `i += 2`: 0, 2, 4 (на 6 условие `i < 5` уже ложно).
2. `5 4 3 2 1 ` — старт 5, каждый раз `i--`.
3. `1 2 4 5 ` — `continue` пропускает **только** шаг `i == 3`, остальные печатаются.
4. `1 2 3 ` — `break` на `i == 4` полностью **выходит** из цикла (4 уже не печатается).
</details>

## 🐞 Есть ли здесь ошибка? (или всё верно?)

1. `for (int i = 1, i <= 5, i++) Console.Write(i);`
2. `int n = 3; while (n > 0) { Console.WriteLine(n); }`
3. `for (int i = 0; i < 3; i++) Console.Write(i);`
4. `Random r = new Random(); int x = r.Next(1, 7);`
5. Нужно случайное число от 1 до 100: `r.Next(1, 100);`

<details><summary>✅ Ответы</summary>

1. ❌ Части `for` разделяют `;`, а не запятой.
2. ❌ Нет `n--` → `n` не меняется → **бесконечный** цикл.
3. ✅ Верно, выведет `012`.
4. ✅ Верно — даст число 1..6.
5. ⚠️ Ошибка смысла: `Next(1, 100)` даёт 1..99 (верх не входит). Для 1..100 нужно `Next(1, 101)`.
</details>

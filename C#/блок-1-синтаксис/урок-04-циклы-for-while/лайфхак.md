# 🧰 Лайфхаки и частые ошибки · Урок 4 «Циклы: for и while»

> Трюки и «грабли» по циклам. Самые важные из них уже показаны в уроке — здесь собрано вместе + дополнительно.

---

## 💡 Трюки

1. **`for` + Tab Tab** — Visual Studio развернёт готовый шаблон цикла. `while` + Tab — шаблон `while`.
2. **`i++` — короткая запись** `i = i + 1`. Ещё есть `i += 2`, `i *= 2` (умножить), `i--`.
3. **`while (true)` + `break`** — когда число повторов заранее неизвестно (ждём правильный ввод, победу в игре).
4. **`Random` создавай ОДИН раз** до цикла. `new Random()` внутри быстрого цикла даёт повторы.
5. **`Random.Next(1, 7)`** = 1..6 — верхняя граница **не входит**. Для 1..100 → `Next(1, 101)`.
6. **Накопитель:** заведи переменную до цикла (`сумма = 0`, `факт = 1`) и копи в ней внутри (`сумма += i`, `факт *= i`).
7. **`Ctrl+C`** останавливает зависшую программу (бесконечный цикл) — как в Python.

## 🐞 Частые ошибки

| Что видишь | Причина | Лечение |
|-----------|---------|---------|
| консоль «висит», печатает без конца | бесконечный цикл (нет `i++`/`n--`/`break`) | меняй переменную условия; стоп — `Ctrl+C` |
| `; expected` в `for` | поставил `,` вместо `;` | три части через `;` |
| цикл сделал на 1 повтор больше/меньше | путаница `<` и `<=` | реши: включать последнее число (`<=`) или нет (`<`) |
| `Random` выдаёт одинаковое | создан `new Random()` в цикле | создай один раз до цикла |
| `Next(1, 100)` не даёт 100 | верхняя граница исключается | пиши `Next(1, 101)` |
| `i` «не существует» после цикла | переменная `for` живёт только внутри | заведи её до цикла, если нужна снаружи |
| накопитель всегда 0 | обнулял внутри цикла | заводи `сумма = 0` ДО цикла |

## 🎯 for или while — что выбрать

- **`for`** — когда **известно число повторов** или есть счётчик (посчитать до N, таблица, перебор чисел).
- **`while`** — когда повторяем **по условию/до события** (пока не угадал, пока не ввели «стоп»).

## ⌨️ Быстрый разогрев (2 мин)

Набери и запусти — это уже цикл `for` по-новому:
```csharp
for (int i = 1; i <= 3; i++)
    Console.WriteLine($"Привет №{i}");
```

- Вывелось три приветствия — значит, цикл сработал три раза. Сегодня разберём, из чего он состоит.

## 🌉 Что нового будет сегодня

- **`for`** пишется иначе, чем в Python: **три части** `for (начало; условие; шаг)`.
- Короткие записи `i++`, `i += 2`.
- `while (true)` + `break`; случайные числа `Random`.

## 🔮 Что выведет этот код? (повторяем урок 3, на подумать)

Предскажи вывод, **не запуская**:

1. `int n = 7;` → `Console.WriteLine(n % 2 == 0 ? "чёт" : "нечёт");`
2. `Console.WriteLine(10 > 5 && 3 > 7);`
3. Подковырка (смотри внимательно на скобки!):
```csharp
int a = 5;
if (a > 10)
    Console.WriteLine("A");
    Console.WriteLine("B");
```
4. `int day = 6;` →
```csharp
switch (day) { case 6: case 7: Console.WriteLine("выходной"); break;
               default: Console.WriteLine("будни"); break; }
```

<details><summary>✅ Ответы и почему</summary>

1. `нечёт` — 7 на 2 не делится нацело (`7 % 2` = 1, не 0).
2. `False` — `&&` истинно, только если **оба** верны; `3 > 7` ложно.
3. `B` — ❗без `{ }` к `if` относится **только первая** строка. `a` не больше 10 → `"A"` пропущено, а `"B"` выполняется **всегда**.
4. `выходной` — 6 попадает в общую ветку `case 6: case 7:`.
</details>

## 🐞 Есть ли здесь ошибка? (или всё верно?)

1. `if (x = 5) { ... }`
2. `if (age > 12 and age < 18) { ... }`
3. `switch (n) { case 1: Console.WriteLine("раз"); case 2: Console.WriteLine("два"); }`
4. `if (n % 2 == 0) Console.WriteLine("чёт");`
5. `string cmd = "go"; switch (cmd) { case "go": Console.WriteLine("едем"); break; }`

<details><summary>✅ Ответы</summary>

1. ❌ `=` — присваивание; для сравнения нужно `==`.
2. ❌ В C# логическое И — `&&`, а не слово `and`.
3. ❌ Нет `break;` после `case 1` → ошибка «Control cannot fall through».
4. ✅ Верно.
5. ✅ Верно — `switch` работает со строками.
</details>

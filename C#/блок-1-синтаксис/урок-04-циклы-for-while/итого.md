# Урок 4 «Циклы: for и while» — итого (шпаргалка) 📌

> Открой, чтобы за 3 минуты вспомнить урок. Только суть и примеры.

---

## Главные мысли

1. **`for` — три части:** `for (начало; условие; шаг)`, разделены `;`.
2. Шаг счётчика: `i++` (+1), `i--` (−1), `i += 2` (шаг 2).
3. `while (условие)` — повтор, пока истинно; **сам меняй переменную** условия!
4. `while (true)` + `break` — «повторяй, пока не случится событие».
5. `break` — выйти из цикла; `continue` — пропустить текущий шаг.
6. `Random.Next(a, b)` — случайное от `a` до `b−1` (**верхняя граница не входит**).

---

## for

```csharp
for (int i = 1; i <= 5; i++) Console.Write(i + " ");   // 1 2 3 4 5
for (int i = 10; i >= 1; i--) ...                      // обратный отсчёт
for (int i = 0; i <= 10; i += 2) ...                   // 0 2 4 6 8 10

int сумма = 0;
for (int i = 1; i <= 100; i++) сумма += i;             // накопитель: 5050
```

- `int i = 1` — начало (один раз) · `i <= 5` — условие (перед каждым повтором) · `i++` — шаг (после повтора).

---

## while

```csharp
int заряд = 5;
while (charge > 0) { Console.Write(charge); charge--; }   // не забудь charge--!

while (true)                    // «до события»
{
    string s = Console.ReadLine();
    if (s == "стоп") break;
}
```

---

## break / continue

```csharp
if (i == 5) break;      // выйти из цикла
if (i == 3) continue;   // пропустить этот шаг
```

---

## Random

```csharp
Random rnd = new Random();   // ОДИН раз, до цикла
int кубик = rnd.Next(1, 7);  // 1..6 (7 не входит!)
int сотка = rnd.Next(1, 101);// 1..100
```

---

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| консоль «висит» | забыл `i++`/`n--`/`break` | меняй счётчик; стоп — `Ctrl+C` |
| `for` не собирается | `,` вместо `;` | три части через `;` |
| «уехал» на 1 | путаница `<` / `<=` | реши, включать ли границу |
| `Random` повторяется | создан в цикле | создай один раз до цикла |
| `Next(1,100)` без 100 | верх не входит | пиши `Next(1, 101)` |

## Что должно остаться в голове

1. Пишу `for` из трёх частей; меняю счётчик `i++`/`i--`/`i += 2`.
2. Пишу `while`, не забываю менять переменную; знаю `while (true)` + `break`.
3. Управляю циклом: `break`, `continue`.
4. Беру случайное число `rnd.Next(a, b)` (верх не входит).

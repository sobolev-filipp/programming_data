# 🖼 Изображения к уроку 4 — что показать на проекторе

Одна ключевая схема (главная тема — устройство `for`).

---

## `for-анатомия.svg` — три части цикла for
**Когда показать:** Часть 1 (`for`) — держать на экране весь блок про `for`.

**Что на схеме:** сверху строка `for (int i = 1; i <= 5; i++)` с тремя подсвеченными частями — **начало** (зелёное `int i = 1`), **условие** (синее `i <= 5`), **шаг** (оранжевое `i++`). Ниже — блок-схема потока: начало → проверка условия (ромб) → истина → тело → шаг → снова проверка; ложь → выход.

**Что сказать:** «`for` — это три части в скобках через `;`. Начало выполняется один раз. Потом крутится: проверка условия → тело → шаг → снова проверка. Как только условие ложно — выходим».

**Приём на проекторе:** ткнуть по очереди в каждую из трёх частей и назвать её; затем «прогнать» глазами стрелки потока для `i = 1, 2, 3…`. Отдельно показать бесконечный цикл (убрать `i++`) → консоль «висит» → `Ctrl+C`.

---

> 💡 Схема — SVG, откроется в любом браузере и не «поедет» на большом экране.

---

## 📚 Мини-теория за 5 минут

**`for` — три части** в скобках через `;`:
```csharp
for (int i = 1; i <= 5; i++)   // начало; условие; шаг
    Console.WriteLine(i);
```
- `int i = 1` — начало (один раз); `i <= 5` — пока повторять; `i++` — как менять счётчик.
- Шаг: `i++` (+1), `i--` (−1), `i += 2` (шаг 2).

**`while`** — повтор, пока условие истинно (сам меняй переменную!):
```csharp
int n = 5;
while (n > 0) { Console.Write(n); n--; }
```
`while (true) { ... if (готово) break; }` — «до события».

**Управление:** `break` — выйти, `continue` — пропустить шаг.
**Случайное число:** `Random rnd = new Random();` → `rnd.Next(1, 7)` = 1..6 (7 не входит).

## ✍️ Задания с разбором (делаем вместе)

### Задание 1. Считаем до 10
**Тема:** `for` вперёд.
**Задание:** выведи числа от 1 до 10.

**Разбор:**
```csharp
for (int i = 1; i <= 10; i++)
    Console.Write(i + " ");
```
✅ Начало `i = 1`, условие `i <= 10`, шаг `i++`.

### Задание 2. Обратный отсчёт
**Тема:** `for` назад.
**Задание:** выведи числа от 5 до 1.

**Разбор:**
```csharp
for (int i = 5; i >= 1; i--)
    Console.Write(i + " ");
```
✅ Стартуем с 5, условие `i >= 1`, шаг `i--` (уменьшаем).

### Задание 3. Сумма
**Тема:** накопитель.
**Задание:** посчитай сумму чисел от 1 до 10.

**Разбор:**
1. Заводим `сумма = 0` **до** цикла.
2. В цикле добавляем: `сумма += i`.
```csharp
int сумма = 0;
for (int i = 1; i <= 10; i++) сумма += i;
Console.WriteLine(сумма);   // 55
```

### Задание 4. while
**Тема:** цикл `while`.
**Задание:** выведи числа от 3 до 1 циклом `while`.

**Разбор:**
```csharp
int n = 3;
while (n >= 1)
{
    Console.Write(n + " ");
    n--;                 // без этого — вечный цикл!
}
```

### Задание 5. Кубик
**Тема:** `Random`.
**Задание:** «брось кубик» — выведи случайное число от 1 до 6.

**Разбор:**
```csharp
Random rnd = new Random();
int кубик = rnd.Next(1, 7);   // 7 не входит → 1..6
Console.WriteLine($"Выпало: {кубик}");
```

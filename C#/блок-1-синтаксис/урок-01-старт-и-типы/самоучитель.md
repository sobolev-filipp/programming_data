---

## 📚 Мини-теория за 5 минут

| Что | Python | C# |
|-----|--------|-----|
| Вывод | `print("текст")` | `Console.WriteLine("текст");` |
| Переменная | `x = 5` | `int x = 5;` (нужен **тип**) |
| Конец команды | ничего | **`;`** |
| Блок кода | отступы | **`{ }`** |
| Вставить в текст | `f"{x}"` | `$"{x}"` |

**Пять типов данных:**
- `int` — целое: `int x = 5;`
- `double` — дробное (через **точку**): `double y = 3.5;`
- `string` — текст в **двойных** кавычках: `string s = "привет";`
- `bool` — `true`/`false`: `bool b = true;`
- `char` — **один** символ в **одинарных** кавычках: `char c = 'A';`

**Арифметика и Math:** `+ - * / %`; деление целых — нацело; `Math.Round/Max/Min/Abs/Pow/Sqrt`.
**Ввод:** `string name = Console.ReadLine();`; число — `Convert.ToInt32(Console.ReadLine())` (ReadLine всегда даёт строку!).
**Комментарий:** `// заметка`.

## ✍️ Задания с разбором (делаем вместе)

### Задание 1. Первый вывод
**Тема:** `Console.WriteLine("...");`.
**Задание:** выведи `Я пишу на C#!`.
```csharp
Console.WriteLine("Я пишу на C#!");
```
✅ В конце — `;`.

### Задание 2. Две строки
**Тема:** каждая `WriteLine` — с новой строки.
```csharp
Console.WriteLine("Иван");
Console.WriteLine("Казань");
```

### Задание 3. Число в переменной
**Тема:** `тип имя = значение;`.
```csharp
int age = 12;
Console.WriteLine($"Мне {age} лет");
```
✅ Имя переменной — латиницей (`age`).

### Задание 4. Дробное число
**Тема:** `double` — дробь через **точку**.
```csharp
double height = 1.7;
Console.WriteLine($"Мой рост: {height}");
```
✅ `1,7` через запятую — ошибка. Только точка!

### Задание 5. Все типы сразу
**Тема:** пять типов.
```csharp
int level = 3;
double money = 99.9;
string name = "Гоблин";
bool isEvil = true;
char mark = 'G';

Console.WriteLine($"Уровень: {level}");
Console.WriteLine($"Деньги: {money}");
Console.WriteLine($"Имя: {name}");
Console.WriteLine($"Злой: {isEvil}");
Console.WriteLine($"Метка: {mark}");
```

## 🧩 Задания с подсказками (делаешь сам)

### Задание 6
**Тема:** склейка `+`.
**Задание:** выведи `Привет, Аня!`, где `string name = "Аня";` — собери через `+`.
> 💡 `"Привет, " + name + "!"`.

### Задание 7
**Тема:** интерполяция.
**Задание:** то же приветствие через `$"..."`.
> 💡 `Console.WriteLine($"Привет, {name}!");`.

### Задание 8
**Тема:** `bool`.
**Задание:** `bool isRaining = false;` — выведи `Дождь: False`.
> 💡 Значение — `false` (маленькими), в выводе `False`.

### Задание 9
**Тема:** `char`.
**Задание:** заведи первую букву имени в `char` и выведи.
> 💡 Одинарные кавычки: `char letter = 'И';`.

### Задание 10
**Тема:** вычисление в выводе.
**Задание:** `int a = 8; int b = 5;` — выведи их сумму.
> 💡 `$"Сумма: {a + b}"`.

### Задание 11
**Тема:** `Math`.
**Задание:** выведи `Math.Max(20, 7)`, `Math.Sqrt(49)` и `Math.Round(3.14159, 1)`.
> 💡 `Math.Max`, `Math.Sqrt`, `Math.Round(x, 1)`.

### Задание 12
**Тема:** `const`.
**Задание:** `const int MaxScore = 100;`, `int score = 72;` — выведи `Осталось: 28`.
> 💡 `{MaxScore - score}`.

### Задание 13
**Тема:** `var`.
**Задание:** `var city = "Сочи";` и `var year = 2026;` — выведи обе.
> 💡 `var` сам поймёт: `"Сочи"` — строка, `2026` — целое.

### Задание 14
**Тема:** визитка из переменных.
**Задание:** `string name`, `char heroClass`, `int level`, `double health`, `bool alive` — выведи 5 строк.
> 💡 Проверь кавычки и точку в `double`.

### Задание 15
**Тема:** деление и тип.
**Задание:** выведи `7 / 2` и `7.0 / 2` двумя строками.
> 💡 Первое `3` (нацело), второе `3,5`. Тип решает.

## 🎤 Ввод с клавиатуры

### Задание 16 (разбираем вместе)
**Тема:** чтение ввода + превращение в число.
**Задание:** спроси число и выведи его +5.
```csharp
Console.Write("Число? ");
int n = Convert.ToInt32(Console.ReadLine());
Console.WriteLine($"+5 = {n + 5}");
```
✅ Без `Convert.ToInt32` сложение со строкой не сработает.

### Задание 17
**Тема:** ввод строки.
**Задание:** спроси имя и выведи `Привет, ...!`.
> 💡 `string name = Console.ReadLine();` — имя превращать не надо.

### Задание 18
**Тема:** два числа.
**Задание:** спроси два числа и выведи их сумму.
> 💡 Дважды `Convert.ToInt32(Console.ReadLine())`.

### Задание 19
**Тема:** мини-анкета.
**Задание:** спроси имя (строка) и уровень (число), выведи `До максимума: {100 - level}`.
> 💡 Имя — строка, уровень — через `Convert.ToInt32`.

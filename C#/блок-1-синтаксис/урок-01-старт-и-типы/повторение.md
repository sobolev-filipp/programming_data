# 🔁 Разминка (5 минут) · Урок 1

> Это **первый урок C#**, но не первый урок программирования — целый год был Python. Поэтому разминка = **мостик из Python** в C# + настрой на новый синтаксис.

## 🌉 Мостик: то же самое на двух языках

Идея команд — та же, меняется оформление.

| В Python (прошлый год) | В C# (теперь) |
|------------------------|---------------|
| `print("Привет!")` | `Console.WriteLine("Привет!");` |
| `name = input("Кто ты? ")` | `string name = Console.ReadLine();` |
| `age = int(input())` | `int age = Convert.ToInt32(Console.ReadLine());` |
| `score = 0` | `int score = 0;` |
| блоки — по отступам | блоки — в `{ }` |
| запускается сразу | сначала **компилируется** |

> 💡 Главное сходство: **программа — это команды по порядку, сверху вниз**. Главные отличия C#: **тип** перед именем, **`;`** в конце команды, **`{ }`** вместо отступов.

## 🎤 Блиц-вопросы классу (устно, 2 мин)

1. Как в Python вывести текст? (`print`) — в C# это `Console.WriteLine`.
2. Что делал `input()`? (спрашивал у пользователя) — в C# это `Console.ReadLine()`.
3. `input()` возвращал число или строку? (строку!) — в C# `ReadLine()` тоже **всегда строку**.
4. Как в Python число из ввода получали? (`int(input())`) — запомним аналог в C#.

## 🔮 Что выведет этот код? (Python-разминка «на подумать»)

Ты знаешь Python — **предскажи вывод, не запуская**. Эти «закавыки» сегодня встретятся и в C#!

1. `print("5" + "5")` → ?
2. `print(7 // 2)` → ?
3. `print(7 % 2)` → ?
4. `print(2 + 3 * 4)` → ?
5. `print(10 / 2)` → ?

<details><summary>✅ Ответы и почему</summary>

1. `55` — строки не складываются, а **склеиваются** (сегодня увидим то же в C#).
2. `3` — **целое деление** отбрасывает дробь (в C# `10 / 3` тоже даст целое!).
3. `1` — `%` это **остаток** от деления.
4. `14` — сначала `*`, потом `+` (приоритет как в математике).
5. `5.0` — обычное деление даёт дробное число.
</details>

## 🐞 Найди ошибку — или её нет? (забегаем в C#)

Скоро это будет C#. В каждой строке реши: **есть ошибка и где — или всё верно?** (ответы проверим по ходу урока.)

1. `Console.WriteLine("Привет")`
2. `string name = 'Аня';`
3. `int age = 15;`
4. `Console.WriteLine("Мне {age} лет");`
5. `double height = 1,75;`

<details><summary>✅ Ответы</summary>

1. ❌ Нет `;` в конце команды.
2. ❌ Строка — в **двойных** кавычках (`"Аня"`), одинарные `'...'` только для одного символа (`char`).
3. ✅ Всё верно.
4. ⚠️ Ошибка смысла: без `$` перед кавычками выведется буквально `Мне {age} лет`. Нужно `$"Мне {age} лет"`.
5. ❌ В коде дробь пишут через **точку**: `1.75` (запятая появляется только при выводе).
</details>

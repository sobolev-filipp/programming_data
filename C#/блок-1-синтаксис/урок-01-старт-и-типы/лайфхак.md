# 🧰 Лайфхаки и частые ошибки · Урок 1 «Старт C#»

> Трюки, горячие клавиши и «грабли», на которые наступают все новички в C#. Загляни сюда, если что-то не запускается.

---

## ⌨️ Горячие клавиши Visual Studio

| Клавиши | Что делает |
|---------|-----------|
| **F5** | запустить программу (с отладкой) |
| **Ctrl+F5** | запустить без отладки (окно не закроется сразу) |
| **Ctrl+.** | «лампочка» — быстрые исправления/подсказки |
| **Ctrl+K, Ctrl+D** | автоформатирование кода (выровнять) |
| **Ctrl+Space** | подсказка-автодополнение (что можно написать) |
| **Ctrl+/** | закомментировать/раскомментировать строку |

> 🍎 В VS Code: запуск — `dotnet run` в терминале; автоформат — `Shift+Alt+F`.

---

## 💡 Трюки

1. **Печатаешь `cw` + Tab Tab** — Visual Studio сам развернёт `Console.WriteLine();`. Быстрый ввод самой частой команды!
2. **Скобки и кавычки закрываются сами.** Написал `(` — редактор ставит `)`. Написал `"` — сразу пару. Не удаляй вторую.
3. **Окно консоли закрывается мгновенно?** Запускай через **Ctrl+F5** — тогда останется надпись «Press any key».
4. **Не хочешь писать тип** — используй `var`: `var x = 5;`. Тип определится сам.
5. **Красивый вывод — всегда `$"..."`.** Забудь про склейку `+`, она длиннее и легко ошибиться с пробелами.
6. **Имена переменных — по-английски** (`heroName`, `playerScore`), методы/константы — с большой буквы (`Attack`, `MaxLevel`). C# разрешает и русские имена, но так не принято — приучайся к латинице.

## 🐞 Частые ошибки и лечение

| Что видишь | Причина | Лечение |
|-----------|---------|---------|
| `; expected` | забыл `;` в конце строки | поставь `;` |
| `} expected` | не хватает `}` | скобки всегда парами `{ }` |
| `The name 'Console' does not exist` | опечатка / не то слово | пиши `Console` с большой буквы |
| выводит `{name}` буквально | забыл `$` перед кавычками | `$"...{name}..."` |
| `Cannot implicitly convert 'string' to 'int'` | кладёшь текст в число: `int x = "5";` | число без кавычек: `int x = 5;` |
| `Cannot convert string to int` при `+` | считаешь введённую строку как число | оберни ввод в `Convert.ToInt32(...)` |
| `System.FormatException` при запуске | в число ввели буквы или пусто | вводи только цифры |
| `Too many characters in character literal` | `char c = "AB";` или двойные кавычки | один символ в одинарных: `char c = 'A';` |
| `True`/`False` красным | написал с большой буквы | `true` / `false` |
| дробь 87,5 подчёркнута | в коде запятая | в коде — точка: `87.5` |

## 🟡 Про жёлтое подчёркивание `Console.ReadLine()`

Visual Studio подчёркивает `ReadLine()` **жёлтой** волнистой линией (`CS8600`). Это **предупреждение, не ошибка** — программа работает. Правило для новичка:

- 🟥 **красная** линия = ошибка, программа не запустится → надо чинить;
- 🟨 **жёлтая** линия = предупреждение/совет → можно не трогать.

Причину (про «пустой ввод / null») разберём позже.

## 🌍 Кириллица и эмодзи в консоли

- **Русские буквы** в `Console.WriteLine` печатаются нормально.
- **Эмодзи** внутри вывода могут показаться «квадратами» в старой консоли Windows. Если очень хочется — добавь первой строкой:
  ```csharp
  Console.OutputEncoding = System.Text.Encoding.UTF8;
  ```
- В **тексте и комментариях** эмодзи безопасны всегда.

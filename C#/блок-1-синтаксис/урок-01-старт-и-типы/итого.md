## Главные мысли

1. **C# — компилируемый:** сначала весь код переводится компилятором, потом запускается.
2. **Каждая команда заканчивается `;`**, блоки кода — в `{ }` (в Python это делали отступы).
3. **У каждой переменной есть тип:** `тип имя = значение;`. **Имена — по-английски** (`camelCase`).
4. **Вывод — `Console.WriteLine(...)`.** Красивый вывод — через `$"...{переменная}..."`.
5. **Ввод — `Console.ReadLine()`.** Он **всегда даёт строку** — чтобы считать, оберни в `Convert.ToInt32(...)`.
6. **Тип решает, что можно делать:** `5` (число) ≠ `"5"` (строка).

## Вывод на экран

```csharp
Console.WriteLine("Привет!");            // текст + новая строка
Console.Write("без ");                   // без перехода на новую строку
Console.WriteLine($"Уровень: {level}");  // $ — вставить переменную (как f-строка)
Console.WriteLine($"Итог: {level + 1}"); // внутри {} можно считать
```

⚠️ Забыл `$` → `Console.WriteLine("Уровень: {level}")` выведет буквально `Уровень: {level}`.

## Переменные и типы

```csharp
int level = 5;           // целое
double health = 87.5;    // дробное (ТОЧКА, не запятая)
string name = "Рыцарь";  // текст — ДВОЙНЫЕ кавычки
bool alive = true;       // true / false (маленькими)
char heroClass = 'В';    // ОДИН символ — ОДИНАРНЫЕ кавычки
```

| Тип | Что | Пример | Кавычки |
|-----|-----|--------|---------|
| `int` | целое | `5` | — |
| `double` | дробное | `87.5` | — (точка!) |
| `string` | текст | `"Маг"` | двойные `"..."` |
| `bool` | да/нет | `true` | — |
| `char` | символ | `'В'` | одинарные `'...'` |

Имена переменных — латиницей `camelCase` (`heroName`), константы — `PascalCase` (`MaxLevel`).
Ещё: `var x = 5;` (тип сам поймётся), `const int MaxLevel = 100;` (менять нельзя).

## Символы (`char`) — чуть больше

```csharp
char c = 'A';
int code = (int)c;            // 65  — символ как код
char next = (char)(code + 1); // 'B' — код как символ
string s = c.ToString();      // "A" — символ → строка
char first = "Привет"[0];     // 'П' — символ из строки
char.IsDigit('7')   // true   — цифра?
char.IsLetter('?')  // false  — буква?
char.ToUpper('а')   // 'А'    — заглавная
'7' - '0'           // 7      — символ-цифра → число (трюк)
```

## Конвертация: как превратить один тип в другой

| Что нужно | Способы | Пример |
|-----------|---------|--------|
| строка → целое | `Convert.ToInt32(...)` / `int.Parse(...)` | `int.Parse("42")` → `42` |
| строка → дробное | `Convert.ToDouble(...)` / `double.Parse(...)` | `double.Parse("3,14")` → `3,14` |
| число → строка | `.ToString()` / `$"..."` | `(255).ToString()` → `"255"` |
| дробное → целое | приведение `(int)` (дробь **отбросится**) | `(int)87.9` → `87` |
| символ ↔ код | приведение `(int)` / `(char)` | `(int)'A'`→`65`; `(char)66`→`'B'` |

Три «семьи»: **в число** — `Parse`/`Convert`; **в строку** — `.ToString()`/`$"..."`; **числа↔символы** — приведение `(int)`/`(double)`/`(char)`. `Parse` и `Convert` делают одно и то же; приведение `(int)` **отбрасывает** дробь, а не округляет.

## Арифметика и Math

```csharp
a + b   a - b   a * b   a % b   // % — остаток
10 / 3          // 3   — оба int, нацело
(double)10 / 3  // 3,33 — есть double
Math.Round(3.14159, 2)  // 3,14
Math.Max(7, 10)         // 10
Math.Min(7, 10)         // 7
Math.Abs(-5)            // 5
Math.Pow(2, 10)         // 1024
Math.Sqrt(144)          // 12
```

## Ввод от пользователя

```csharp
Console.Write("Как зовут? ");
string name = Console.ReadLine();                   // текст — всегда СТРОКА

Console.Write("Уровень? ");
int level = Convert.ToInt32(Console.ReadLine());    // целое:  строку → int

Console.Write("Рост? ");
double height = Convert.ToDouble(Console.ReadLine());// дробное: строку → double (вводят 1,62 с ЗАПЯТОЙ)

Console.Write("Оценка буквой? ");
char grade = Console.ReadLine()[0];                 // один символ — берём первый [0]
```

| Что вводим | Как прочитать |
|------------|---------------|
| текст | `Console.ReadLine()` |
| целое число | `Convert.ToInt32(Console.ReadLine())` |
| дробное число | `Convert.ToDouble(Console.ReadLine())` (ввод через **запятую**) |
| один символ | `Console.ReadLine()[0]` |

Мостик из Python: `int(input())` → `Convert.ToInt32(Console.ReadLine())`.

## Главные ошибки

| Сообщение | Причина | Лечение |
|-----------|---------|---------|
| `; expected` | забыл `;` | поставь `;` в конце команды |
| выводит `{name}` буквально | забыл `$` | `$"...{name}..."` |
| `cannot convert string to int` | считаешь строку как число | оберни в `Convert.ToInt32(...)` |
| `FormatException` при запуске | в число ввели буквы/пусто | вводи только цифры |
| `'AB' too many characters` | в `char` больше 1 символа | один символ в `'...'` |
| `True/False` не работает | большая буква | `true` / `false` |

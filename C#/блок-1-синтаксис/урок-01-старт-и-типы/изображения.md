# 🖼 Изображения к уроку 1 — что показать на проекторе

Четыре схемы. Открывай их на весь экран в нужный момент урока.

---

## 1. `компиляция.svg` — как работает C#
**Когда показать:** Часть 1 (среда и первая программа), когда объясняешь «компилируемый vs интерпретируемый».

**Что на схеме:** сверху путь C# — `код Program.cs → компилятор (переводит ВЕСЬ код) → готовая программа .exe → запуск`. Снизу для сравнения путь Python — `код .py → интерпретатор читает строку за строкой → результат сразу`.

**Что сказать:** «В Python строки выполнялись сразу, по одной. В C# сначала весь код переводится в программу — и уже она запускается. Поэтому C# ловит многие ошибки ещё ДО запуска».

---

## 2. `типы-данных.svg` — пять типов
**Когда показать:** Часть 3 (переменные и типы).

**Что на схеме:** пять карточек — `int` (5), `double` (87.5, точка!), `string` («Маг», двойные кавычки), `bool` (true/false), `char` ('В', одинарные кавычки). Внизу напоминание: `5` (int) ≠ `"5"` (string).

**Что сказать:** «Тип — это что за содержимое коробки. В C# тип пишем ПЕРЕД именем. Обрати внимание: `double` — через точку, `string` — двойные кавычки, `char` — одинарные».

---

## 3. `деление-по-типу.svg` — деление зависит от типа
**Когда показать:** Часть 5 (арифметика), при разборе деления.

**Что на схеме:** слева `int / int`: `10 / 3` → дробь отбрасывается → `3`. Справа `(double)10 / 3` → `3,33` (+ `Math.Round`).

**Что сказать:** «Одно и то же 10 / 3 даёт разное! Целые делятся нацело, дробь отбрасывается. Нужна дробь — приведи одно число к double».

---

## 4. `ввод-вывод.svg` — ReadLine и превращение в число
**Когда показать:** Часть 6 (ввод с клавиатуры) — ключевая схема урока.

**Что на схеме:** пользователь печатает → `ReadLine()` даёт **строку** `"5"` → `Convert.ToInt32` превращает её в **число** `5` → результат на экране. Внизу красное предупреждение: `ReadLine()` ВСЕГДА возвращает строку.

**Что сказать:** «Как и `input()` в Python, `ReadLine()` всегда отдаёт строку — даже если ввели цифры. Чтобы считать, превращаем строку в число через `Convert.ToInt32`».

# 🏋️ Практика — Урок 1 «Старт C#: ввод-вывод и типы»

**Блок 1 · Урок 1 | Задачи в 3 уровнях**

> Каждую задачу пиши и **сразу запускай**: Visual Studio ▶ (F5), на Mac — `dotnet run`. Смотри, что вывелось.
> 🟢 базовые · 🟡 средние · 🔴 со звёздочкой. У каждой задачи есть блок **«Должно получиться»** и **💡 подсказка**.
> 📌 Быстрая шпаргалка: вывод `Console.WriteLine("...");` · переменная `тип имя = значение;` (**имя латиницей**) · вставить `$"...{name}..."` · ввод `Console.ReadLine()` (строка!) · число из ввода `Convert.ToInt32(Console.ReadLine())` · `Math.Round/Max/Min/Abs/Pow/Sqrt`.

---

## 🟢 Уровень 1 — базовый (разминка)

**1. Первое сообщение.**
Выведи на экран одну строку — расскажи, что ты изучаешь.
**Должно получиться:**
```
Привет, я изучаю C#!
```
> 💡 Одна команда `Console.WriteLine("...");`. Текст — в кавычках, в конце `;`.

**2. Рассказ о себе в три строки.**
Выведи **тремя отдельными командами** три факта: своё имя, свой город и любимый предмет — каждый с новой строки.
**Должно получиться (пример):**
```
Иван
Казань
Информатика
```
> 💡 Три команды `Console.WriteLine("...");` подряд.

**3. Сколько тебе лет.**
Заведи переменную `int age` со своим возрастом и выведи фразу про возраст, подставив переменную.
**Должно получиться (если age = 12):**
```
Мне 12 лет
```
> 💡 `int age = 12;`, потом `Console.WriteLine($"Мне {age} лет");`. Не забудь `$`.

**4. Твой рост.**
Заведи `double height` (например `1.62`) и выведи его с подписью.
**Должно получиться:**
```
Мой рост: 1,62
```
> 💡 Дробь в коде — через **точку** (`1.62`), тип `double`. На экране покажет запятую — это нормально.

**5. Любимая игра.**
Заведи `string favoriteGame` и выведи «Люблю играть в …», подставив название.
**Должно получиться:**
```
Люблю играть в Minecraft
```
> 💡 Вставь переменную: `$"Люблю играть в {favoriteGame}"`.

**6. Да или нет.**
Заведи `bool isSummer = true` и выведи, лето сейчас или нет.
**Должно получиться:**
```
Сейчас лето: True
```
> 💡 Значение пишется `true` (маленькими), на экране покажется `True`. Вывод: `$"Сейчас лето: {isSummer}"`.

**7. Первая буква имени.**
Заведи `char firstLetter` — первую букву своего имени — и выведи её.
**Должно получиться (для «Пётр»):**
```
Первая буква: П
```
> 💡 `char` — **один символ** в **одинарных** кавычках: `'П'`.

## 🟡 Уровень 2 — средний

**8. Визитка ученика.**
Собери про себя 4 переменные: `string name`, `int age`, `string grade`, `double averageMark`. Выведи их четырьмя строками через `$"..."`.
**Должно получиться (пример):**
```
Имя: Аня
Возраст: 13
Класс: 7Б
Средняя оценка: 4,6
```
> 💡 Каждое поле — отдельная `WriteLine`.

**9. Коллекция типов.**
Заведи по одной переменной **каждого** из пяти типов (`int`, `double`, `string`, `bool`, `char`) и выведи каждую с подписью.
**Должно получиться (пример):**
```
int: 5
double: 3,14
string: привет
bool: False
char: X
```
> 💡 5 переменных + 5 строк. `string` — двойные кавычки, `char` — одинарные.

**10. Два способа вывести одно и то же.**
Выведи `Игра: Minecraft, уровень: 12` **двумя способами**: (а) через `$"..."` и (б) склейкой `+`.
**Должно получиться (обе строки одинаковые):**
```
Игра: Minecraft, уровень: 12
Игра: Minecraft, уровень: 12
```
> 💡 Способ (б): `"Игра: " + game + ", уровень: " + level`.

**11. Считает сама программа.**
Заведи `int coins = 50` и `int bonus = 30`. Выведи, сколько монет всего — число **посчитай в коде**.
**Должно получиться:**
```
Всего монет: 80
```
> 💡 Внутри `$"...{ }"`: `{coins + bonus}`.

**12. Полоска здоровья.**
Заведи `const int MaxHp = 100` и `int hp = 70`. Выведи сколько жизней из максимума и сколько осталось добрать (посчитай в коде).
**Должно получиться:**
```
Жизни: 70 из 100
Осталось добрать: 30
```
> 💡 «Осталось» = `MaxHp - hp`. `const` менять нельзя.

**13. То же, но через `var`.**
Перепиши задачу 8, заменив все типы на `var`. Проверь, что работает так же.
> 💡 `var name = "Аня";` — компилятор сам поймёт тип.

**14. Заметки в коде.**
Добавь комментарий `//` над кодом и в конце одной строки. Убедись, что на вывод они не влияют.
> 💡 `// это заметка` — компьютер пропускает такие строки.

## 🔴 Уровень 3 — со звёздочкой

**15. Полная визитка героя с расчётом.**
Заведи `string name`, `int level`, `double health` и `const int MaxLevel = 100`. Выведи визитку и сколько уровней до максимума.
**Должно получиться (пример):**
```
Имя: Рыцарь
Уровень: 5
Здоровье: 87,5
До максимума: 95 уровней
```
> 💡 «Осталось» считай в выводе: `{MaxLevel - level}`.

**16. Периметр и площадь квадрата.**
Заведи `int side = 6`. Выведи периметр (`side * 4`) и площадь (`side * side`) — обе величины посчитай в коде.
**Должно получиться:**
```
Периметр: 24
Площадь: 36
```
> 💡 Внутри `$"..."`: `{side * 4}` и `{side * side}`.

**17. Загадка деления.**
Выведи результат `7 / 2` и `7.0 / 2` двумя строками. В комментарии объясни, почему числа разные.
**Должно получиться:**
```
3
3,5
```
> 💡 `int / int` делит **нацело** (3), с `double` (7.0) — 3,5. Тип решает!

**18. Сила Math.**
Заведи `double r = 4`. Через `Math` выведи: площадь круга (`Math.PI * Math.Pow(r, 2)`, округли до 2 знаков), большее из чисел `Math.Max(15, 42)` и корень `Math.Sqrt(81)`.
**Должно получиться:**
```
Площадь круга: 50,27
Больше: 42
Корень: 9
```
> 💡 `Math.Round(площадь, 2)`, `Math.Max(15, 42)`, `Math.Sqrt(81)`.

**19. Карточка персонажа в рамке.**
Собери карточку из **6** переменных разных типов (`char rank = 'S'`, `bool online`…). Выведи её в рамке из `=`.
**Должно получиться (пример):**
```
====================
Имя: Тень
Класс: П, ранг: S
Уровень: 14
Здоровье: 120
Онлайн: True
====================
```
> 💡 Рамку — обычным `Console.WriteLine("====================");` сверху и снизу.

## 🎤 Ввод с клавиатуры (задания 20–24)

> `Console.ReadLine()` возвращает **строку**; чтобы считать как число — оберни в `Convert.ToInt32(Console.ReadLine())`.

**20. 🟢 Знакомство.**
Спроси имя и поздоровайся по имени.
**Должно получиться (ввели «Аня»):**
```
Как тебя зовут? Аня
Привет, Аня!
```
> 💡 `string name = Console.ReadLine();`, ответь через `$"..."`.

**21. 🟢 Повтори за мной.**
Спроси любимое число и выведи его обратно.
**Должно получиться:**
```
Твоё число? 7
Ты ввёл: 7
```
> 💡 Тут число можно не превращать — просто прочитать строку и вывести.

**22. 🟡 Плюс десять.**
Спроси число и выведи его, увеличенное на 10.
**Должно получиться:**
```
Введи число: 5
Стало: 15
```
> 💡 `int n = Convert.ToInt32(Console.ReadLine());`, потом `{n + 10}`.

**23. 🟡 Живая анкета героя.**
Спроси имя героя (строка) и уровень (число). Выведи визитку и сколько уровней до максимума (`100 - level`).
**Должно получиться:**
```
Как зовут героя? Маг
Какой у героя уровень? 7
Имя: Маг
Уровень: 7
До максимума: 93 уровней
```
> 💡 Имя — `ReadLine()`, уровень — через `Convert.ToInt32(...)`.

**24. 🔴 Калькулятор возраста.**
Спроси год рождения и текущий год, выведи примерный возраст.
**Должно получиться:**
```
Год рождения: 2013
Текущий год: 2026
Тебе примерно 13 лет
```
> 💡 Оба ввода — через `Convert.ToInt32`. Возраст = `currentYear - birthYear`.

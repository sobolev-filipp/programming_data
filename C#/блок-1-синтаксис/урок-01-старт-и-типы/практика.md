# 🏋️ Практика — Урок 1 «Старт C#: ввод-вывод и типы»

**Блок 1 · Урок 1 | 30 заданий в 3 уровнях по сложности**

> Каждую задачу пиши и **сразу запускай**: Visual Studio ▶ (F5), на Mac — `dotnet run`. Смотри, что вывелось.
> 🟢 базовый (закрепляем) · 🟡 средний (сложнее, считаем формулы) · 🔴 со звёздочкой (собираем целое). Делай по порядку — сложность растёт плавно.
> 📌 Шпаргалка: вывод `Console.WriteLine("...");` · переменная `тип имя = значение;` (**имя латиницей**) · вставка `$"...{name}..."` · ввод `Console.ReadLine()` (строка!) · число из ввода `Convert.ToInt32(Console.ReadLine())` · дробь из ввода `Convert.ToDouble(...)` · арифметика `+ - * / %` · `Math.Round/Max/Min/Sqrt/Pow/PI`.
> 💡 Подсказки — **наводки**, а не готовый код. Сначала думай сам.

## 🟢 Уровень 1 — базовый (примени изученное)

**1. Рассказ о себе.** Выведи **тремя командами** имя, город и любимый предмет — каждый с новой строки.
**Должно получиться (пример):**
```
Иван
Казань
Информатика
```
> 💡 Три раза `Console.WriteLine("...");`.

**2. Пять типов.** Заведи по переменной каждого типа (`int`, `double`, `string`, `bool`, `char`) и выведи с подписью.
**Должно получиться (пример):**
```
int: 5
double: 3,14
string: привет
bool: False
char: X
```
> 💡 `string` — двойные кавычки, `char` — одинарные, дробь — через точку.

**3. Визитка через `$`.** Заведи `string name`, `int age`, `string grade` и выведи их через интерполяцию.
**Должно получиться (пример):**
```
Имя: Аня
Возраст: 13
Класс: 7Б
```
> 💡 Не забудь `$` перед кавычками.

**4. Считает программа.** `int coins = 50`, `int bonus = 30`. Выведи, сколько всего — число **посчитай в коде**.
**Должно получиться:**
```
Всего монет: 80
```
> 💡 Внутри `$"...{ }"` можно писать `{coins + bonus}`.

**5. Периметр и площадь квадрата.** `int side = 6`. Выведи периметр и площадь (посчитай в коде).
**Должно получиться:**
```
Периметр: 24
Площадь: 36
```
> 💡 Периметр `side * 4`, площадь `side * side`.

**6. Полоска здоровья.** `const int MaxHp = 100`, `int hp = 70`. Выведи «жизни из максимума» и «сколько добрать».
**Должно получиться:**
```
Жизни: 70 из 100
Осталось добрать: 30
```
> 💡 «Осталось» = `MaxHp - hp`. `const` менять нельзя.

**7. Сила `Math`.** `double r = 4`. Выведи площадь круга (округли до 2 знаков), `Math.Max(15, 42)` и `Math.Sqrt(81)`.
**Должно получиться:**
```
Площадь круга: 50,27
Больше: 42
Корень: 9
```
> 💡 Площадь `Math.PI * Math.Pow(r, 2)`, округление `Math.Round(..., 2)`.

**8. Два способа вывода.** Выведи `Игра: Minecraft, уровень: 12` двумя способами: через `$"..."` и склейкой `+`.
**Должно получиться (две одинаковые строки):**
```
Игра: Minecraft, уровень: 12
Игра: Minecraft, уровень: 12
```
> 💡 Склейка: `"Игра: " + game + ", уровень: " + level`.

**9. Знакомство (ввод).** Спроси имя и поздоровайся по имени.
**Должно получиться (ввели «Аня»):**
```
Как тебя зовут? Аня
Привет, Аня!
```
> 💡 `Console.Write` — вопрос без переноса; имя — `Console.ReadLine()`.

**10. Плюс десять (ввод-число).** Спроси число и выведи его +10.
**Должно получиться:**
```
Введи число: 5
Стало: 15
```
> 💡 Строку ввода преврати в число: `Convert.ToInt32(Console.ReadLine())`.

## 🟡 Уровень 2 — средний (сложнее, считаем формулы)

**11. Прямоугольник с клавиатуры.** Спроси стороны `a` и `b`, выведи периметр и площадь.
**Должно получиться (a=5, b=3):**
```
Периметр: 16
Площадь: 15
```
> 💡 Оба ввода — через `Convert.ToInt32`. Периметр `(a + b) * 2`.

**12. Магазин со скидкой.** Товар стоит `200`, берут `3` штуки, скидка `10%`. Посчитай в коде «без скидки» и «к оплате».
**Должно получиться:**
```
Без скидки: 600
К оплате: 540
```
> 💡 Скидка 10% = платим 90%, то есть `× 0.9`. Подумай, какой тип нужен для дробной доли.

**13. Сдача в магазине.** Спроси стоимость покупки и сколько денег дали. Выведи сдачу.
**Должно получиться:**
```
Стоимость: 340
Дали: 500
Сдача: 160
```
> 💡 Сдача = «дали» − «стоимость». Оба ввода — числа.

**14. Скорость.** Спроси скорость (км/ч) и время (ч). Выведи пройденное расстояние.
**Должно получиться (60 и 3):**
```
Расстояние: 180 км
```
> 💡 Путь = скорость × время.

**15. Секунды → минуты и секунды.** `int seconds = 200`. Выведи, сколько это минут и секунд.
**Должно получиться:**
```
3 мин 20 сек
```
> 💡 Целых минут — деление нацело на 60. «Лишние» секунды — остаток `%`.

**16. Средняя оценка.** Спроси три оценки. Выведи среднее (может быть дробным!).
**Должно получиться (5, 4, 4):**
```
Средний балл: 4,33
```
> 💡 Чтобы среднее было дробным, делить надо на `3.0`, а не на `3`. Округли `Math.Round(..., 2)`.

**17. Температура C → F.** Спроси температуру в градусах Цельсия. Переведи в Фаренгейты (`F = C × 9/5 + 32`).
**Должно получиться (25):**
```
25°C = 77°F
```
> 💡 Чтобы `9/5` не превратилось в `1` (целое деление!), пиши `9.0/5`. Температуру бери `double`.

**18. Предскажи вывод.** Не запуская, запиши, что выведут строки. Потом проверь.
```csharp
Console.WriteLine(10 / 3);
Console.WriteLine(10.0 / 3);
Console.WriteLine(10 % 3);
```
**Должно получиться:** три предсказания и объяснение, почему первые две строки разные.
> 💡 `/` двух целых — деление **нацело**; один `double` включает дробь; `%` — остаток.

**19. Гипотенуза.** Спроси два катета прямоугольного треугольника. Выведи гипотенузу (`√(a² + b²)`).
**Должно получиться (3 и 4):**
```
Гипотенуза: 5
```
> 💡 `Math.Sqrt(a*a + b*b)`. Стороны удобно взять `double`.

**20. Копилка.** Спроси, сколько денег уже есть и сколько стоит мечта. Выведи, сколько ещё не хватает.
**Должно получиться (есть 800, мечта 1200):**
```
Не хватает: 400
```
> 💡 «Не хватает» = цель − накоплено.

## 🔴 Уровень 3 — со звёздочкой (собери целое)

**21. Чек в магазине.** Спроси название товара, цену и количество. Выведи аккуратный чек с итогом (цена × количество).
**Должно получиться (пример):**
```
Товар: Молоко
Цена: 70
Количество: 2
Итого: 140
```
> 💡 Название — строка, цена и количество — числа (`Convert`). Итог посчитай в коде.

**22. Пицца поровну.** Спроси, сколько кусков пиццы и сколько друзей. Выведи, по сколько каждому и сколько кусков останется лишними.
**Должно получиться (10 кусков, 3 друга):**
```
Каждому по: 3
Останется: 1
```
> 💡 «Поровну» — деление нацело `/`, «останется» — остаток `%`.

**23. Часы, минуты, секунды.** Спроси общее число секунд (например 3725) и выведи, сколько это часов, минут и секунд.
**Должно получиться:**
```
1 ч 2 мин 5 сек
```
> 💡 Часы — нацело на 3600. Из остатка (`% 3600`) достань минуты (нацело на 60) и секунды (`% 60`). Разбей по шагам.

**24. Сумма цифр двузначного числа.** Спроси двузначное число и выведи сумму его цифр.
**Должно получиться (47):**
```
Сумма цифр: 11
```
> 💡 Первая цифра двузначного — это `n / 10` (нацело), вторая — `n % 10`. Сложи их.

**25. Найди и почини ошибку.** Ученик хотел вывести `Мне 12 лет` и завести оценку буквой, но не работает. Найди **две** ошибки и почини:
```csharp
int age = 12;
Console.WriteLine("Мне {age} лет");
char grade = "A";
```
**Должно получиться:** первая строка печатает `Мне 12 лет`, `grade` хранит букву без ошибки.
> 💡 Одна ошибка — почему `{age}` печатается как есть (чего нет перед кавычками?). Вторая — `char` хранит один символ, кавычки у него особые.

**26. Всё о круге.** Спроси радиус. Выведи диаметр, длину окружности (`2πr`) и площадь (`πr²`), округляя до 2 знаков.
**Должно получиться (r = 5):**
```
Диаметр: 10
Длина окружности: 31,42
Площадь: 78,54
```
> 💡 `Math.PI`, `Math.Round(..., 2)`. Диаметр — `2 * r`.

**27. Конвертер валют.** Спроси сумму в рублях и курс доллара. Выведи, сколько это долларов (округли до 2 знаков).
**Должно получиться (1000 руб, курс 90):**
```
1000 руб = 11,11 $
```
> 💡 Доллары = рубли / курс. Чтобы вышла дробь, делить надо «по-дробному» (`double`).

**28. Мой калькулятор.** Придумай и собери **свой** маленький калькулятор жизненной ситуации: расход бензина, время до дня рождения в днях, стоимость поездки на такси (посадка + за км) — что угодно. Программа спрашивает данные и **сама считает** ответ.
**Должно получиться:** рабочий калькулятор на твою тему.
> 💡 Выбери формулу под задачу. Где ответ дробный — тип `double`; где «поровну и остаток» — `/` и `%`.

**29. Генератор карточки.** Собери карточку (героя/питомца/машины) из полей **разных типов** (`string`, `int`, `double`, `bool`, `char`) и выведи в рамке. Добавь один расчёт (например «до максимума осталось …»).
**Должно получиться (пример):**
```
====================
Имя: Тень
Ранг: S
Уровень: 14 (до максимума: 86)
Здоровье: 120,5
Онлайн: True
====================
```
> 💡 Рамку рисуй `Console.WriteLine("====================");`. Расчёт — вычитание внутри `$"..."`.

**30. Диалог-анкета.** Сделай программу, которая по очереди спрашивает имя, возраст и рост, а в конце выводит красивую анкету и **сколько лет исполнится через 5 лет**.
**Должно получиться (пример):**
```
Имя: Аня
Возраст: 13
Рост: 1,62
Через 5 лет тебе будет: 18
```
> 💡 Имя — строка, возраст — `Convert.ToInt32`, рост — `Convert.ToDouble`. «Через 5 лет» — `age + 5`.

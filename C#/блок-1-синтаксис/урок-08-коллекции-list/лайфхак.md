# 🧰 Лайфхаки и частые ошибки · Урок 8 «Коллекции: List и Dictionary»

> Трюки и «грабли» по спискам и словарям. Главное уже показано в уроке — здесь собрано вместе.

---

## 💡 Трюки

1. **Короткое создание `new()`** — тип уже слева: `List<int> nums = new();`, `Dictionary<string,int> d = new();`.
2. **Список сразу с данными:** `new() { 40, 90, 65 }`; словарь сразу с парами: `new() { ["меч"] = 100, ["щит"] = 60 }`.
3. **`string.Join(", ", list)`** печатает весь список одной строкой — без цикла.
4. **`.Count` (не `.Length`!)** — размер списка и словаря. У массива был `.Length` — легко перепутать.
5. **`TryGetValue`** — «два в одном»: и проверяет ключ, и достаёт значение (как `out` в методах, Урок 7).
6. **Счётчик за 3 строки:** `if (d.ContainsKey(k)) d[k]++; else d[k] = 1;` — запомни как шаблон.
7. **LINQ работает и по списку:** `list.Max()`, `list.Sum()`, `list.Count(x => ...)` — как по массиву в Уроке 6.
8. **`var` для краткости:** `var bag = new List<string>();` — тип виден справа.

## 🐞 Частые ошибки

| Что видишь | Причина | Лечение |
|-----------|---------|---------|
| `'List<T>' does not contain ... 'Length'` | у списка размер — `.Count` | пиши `list.Count` |
| `ArgumentOutOfRangeException` | индекс вне `0..Count-1` (`list[Count]`, `RemoveAt` не туда) | проверяй границы |
| `KeyNotFoundException` | взял `dict[ключ]`, а ключа нет | сначала `ContainsKey` или `TryGetValue` |
| значение в словаре «затёрлось» | присвоил по существующему ключу | ключи уникальны: тот же ключ = замена |
| `Remove` убрал не всё | `Remove` удаляет только **первое** совпадение | повтори или чисти циклом |
| `The type or namespace ... could not be found` | забыл тип в `< >` | `List<string>`, `Dictionary<string,int>` |
| менял список **внутри** `foreach` → ошибка | нельзя `Add`/`Remove` во время перебора | собери изменения отдельно, применяй после цикла |

## 🎯 List или Dictionary — что выбрать

- **`List<T>`** — когда важен **порядок** и доступ по **номеру** (список дел, очередь, история ходов, инвентарь).
- **`Dictionary<K,V>`** — когда нужно **быстро найти по имени/ключу** (цена товара по названию, счёт команды, телефон по имени, счётчик).

> 💡 Часто их используют **вместе**: `List` хранит предметы, `Dictionary` считает, сколько каждого (как в проекте «Инвентарь героя»).

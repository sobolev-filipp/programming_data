## 📚 Мини-теория за 5 минут

**`List<T>`** — «массив, который растёт». Тип элементов пишут в `< >`.
- Создать: `List<string> bag = new();` (или сразу `new() { "меч", "щит" }`).
- `Add(x)` — добавить, `Remove(x)` / `RemoveAt(i)` — удалить, `Insert(i, x)` — вставить.
- Размер — **`.Count`** (не `.Length`!), элемент — `bag[i]`.
- Поиск — `Contains(x)` (есть?), `IndexOf(x)` (где?). Порядок — `Sort()`, `Reverse()`.

**`Dictionary<K,V>`** — «ключ → значение» (словарь `{ }` из Python).
- Создать: `Dictionary<string,int> prices = new();`.
- Положить/заменить: `prices["меч"] = 100;`. Прочитать: `prices["меч"]`.
- Проверить ключ: `ContainsKey("меч")`; безопасно взять: `TryGetValue("меч", out int p)`.
- Перебор: `foreach (var pair in prices)` → `pair.Key`, `pair.Value`.

## ✍️ Задания с разбором (делаем вместе)

### Задание 1. Первый список
```csharp
List<string> bag = new();
bag.Add("меч");
bag.Add("щит");
Console.WriteLine(bag.Count);   // 2
Console.WriteLine(bag[0]);      // меч
```
✅ Список создали пустым и наполнили `Add`.

### Задание 2. Перебор
```csharp
List<string> pets = new() { "кот", "пёс", "хомяк" };
foreach (string p in pets) Console.WriteLine(p);
```

### Задание 3. Удаление и размер
```csharp
List<int> nums = new() { 10, 20, 30 };
nums.Remove(20);                // → 10, 30
Console.WriteLine(nums.Count);  // 2
```
✅ `Remove` убирает по значению; `Count` показывает новый размер.

### Задание 4. Первый словарь
```csharp
Dictionary<string, int> prices = new();
prices["меч"] = 100;
prices["щит"] = 60;
Console.WriteLine(prices["меч"]);          // 100
Console.WriteLine(prices.ContainsKey("лук")); // False
```

### Задание 5. Счётчик через словарь
**Задание:** посчитать, сколько каждого предмета в массиве.
```csharp
string[] loot = { "золото", "меч", "золото" };
Dictionary<string, int> counter = new();
foreach (string item in loot)
{
    if (counter.ContainsKey(item)) counter[item]++;  // уже был — +1
    else counter[item] = 1;                           // впервые — 1
}
foreach (var pair in counter)
    Console.WriteLine($"{pair.Key}: {pair.Value}");   // золото: 2 / меч: 1
```
✅ Схема счётчика: `ContainsKey` → `++`, иначе `= 1`.

## 🧩 Задания с подсказками (сам)

### Задание 6
**Тема:** список растёт.
**Задание:** заведи `List<string>` из 3 песен, добавь 4-ю через `Add`, выведи количество.
> 💡 `playlist.Add("...")`, затем `playlist.Count`.

### Задание 7
**Тема:** поиск.
**Задание:** для списка предметов проверь `Contains("зелье")` и найди `IndexOf("щит")`.
> 💡 `bag.Contains("зелье")`, `bag.IndexOf("щит")` (−1, если нет).

### Задание 8
**Тема:** сортировка.
**Задание:** отсортируй `List<int> { 5, 1, 9, 3 }` и выведи через `string.Join`.
> 💡 `nums.Sort();` затем `Console.WriteLine(string.Join(", ", nums));`.

### Задание 9
**Тема:** словарь.
**Задание:** заведи `Dictionary<string,string>` (страна → столица), 2 пары, выведи одну по ключу.
> 💡 `caps["Франция"] = "Париж";`, потом `Console.WriteLine(caps["Франция"]);`.

### Задание 10
**Тема:** безопасный доступ.
**Задание:** возьми значение по ключу через `TryGetValue`, а если ключа нет — напиши «не найдено».
> 💡 `if (d.TryGetValue(key, out int v)) ... else Console.WriteLine("не найдено");`.

### Задание 11
**Тема:** перебор словаря.
**Задание:** выведи все пары словаря как «ключ = значение».
> 💡 `foreach (var pair in d) Console.WriteLine($"{pair.Key} = {pair.Value}");`.

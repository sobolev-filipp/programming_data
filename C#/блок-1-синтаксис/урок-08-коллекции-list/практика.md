# 🏋️ Практика — Урок 8 «Коллекции: List и Dictionary»

**Блок 1 · Урок 8 | Задачи в 3 уровнях**

> Пиши и **сразу запускай** каждую задачу (F5 / `dotnet run`). У каждой есть блок **«Должно получиться»** — это то, что должно появиться на экране. Подсказки 💡 есть только там, где легко застрять, — и они **наводят**, а не дают готовый код.
> 📌 Что помнить: `List<T> x = new();` — список, который растёт (`Add`/`Insert`/`Remove`/`RemoveAt`), размер — `.Count` (не `.Length`!), элемент — `x[i]` (с нуля). `Dictionary<K,V> d = new();` — «ключ → значение»: кладём и читаем по ключу `d["меч"]`, проверяем ключ через `ContainsKey`. **Имена переменных — по-английски, `camelCase`.**

---

## 🟢 Уровень 1 — базовый

**1. Список друзей.**
Ты делаешь игру и хочешь хранить имена друзей, которых можно позвать в команду. Заведи список строк `friends` и положи в него **трёх** друзей. В конце программа должна сообщить, **сколько** друзей в списке.
**Должно получиться:**
```
Друзей: 3
```
> 💡 Размер списка узнают через `.Count` (а не `.Length`, как было у массива).

**2. Рюкзак растёт.**
Заведи **пустой** список `bag` и по одному положи в него `Add`-ом три предмета (например: меч, щит, зелье). Затем выведи **первый** предмет в рюкзаке и **последний**.
**Должно получиться:**
```
Первый: меч
Последний: зелье
```
> 💡 Первый предмет — `bag[0]`. А чтобы взять последний, не зная заранее длину, используй номер `bag.Count - 1`.

**3. Список питомцев.**
Есть готовый список питомцев: `List<string> pets = new() { "кот", "пёс", "хомяк" };`. Выведи всех питомцев — **каждого с новой строки**.
**Должно получиться:**
```
кот
пёс
хомяк
```

**4. Есть ли предмет?**
У продавца в магазине есть товары: `List<string> shop = new() { "яблоко", "банан" };`. Проверь, есть ли в магазине «банан», а потом — «манго», и выведи результат проверки (`True`/`False`) для каждого.
**Должно получиться:**
```
банан: True
манго: False
```
> 💡 «Есть ли такой элемент?» — это метод `Contains`, он отвечает `True` или `False`.

## 🟡 Уровень 2 — средний

**5. Уборка в списке.**
Есть числа: `List<int> nums = new() { 10, 20, 30, 40 };`. Сделай два удаления: убери **значение** `20` и убери элемент, который стоит **на месте [0]**. Потом выведи, что осталось, одной строкой через запятую.
**Должно получиться:**
```
30, 40
```
> 💡 Убрать по значению — `Remove(20)`; убрать по номеру места — `RemoveAt(0)`. Одной строкой список печатает `string.Join(", ", nums)`.

**6. Турнирная таблица.**
Есть очки игроков: `List<int> scores = new() { 40, 90, 65, 20 };`. Сначала отсортируй список и выведи его (от меньшего к большему). Потом переверни список, чтобы **лучшие были сверху**, и снова выведи.
**Должно получиться:**
```
20, 40, 65, 90
90, 65, 40, 20
```
> 💡 `Sort()` ставит по возрастанию; чтобы получить обратный порядок, после сортировки примени `Reverse()`.

**7. Дневник оценок.**
За неделю ученик получил оценки: `List<int> marks = new() { 5, 3, 4, 5, 2 };`. Посчитай и выведи **средний балл** и **сколько было пятёрок**.
**Должно получиться:**
```
Средний балл: 3,8
Пятёрок: 2
```
> 💡 Среднее — `marks.Average()` (на русской системе печатается через запятую — это нормально). «Сколько пятёрок» — это подсчёт по условию: `Count` с условием, что элемент равен 5.

**8. Прайс-лист магазина.**
Заведи словарь `prices`, где **ключ — название товара**, а **значение — цена (число)**. Добавь два товара: «меч» за 100 и «щит» за 60. Затем выведи цену меча, взяв её из словаря по ключу.
**Должно получиться:**
```
Меч стоит 100
```
> 💡 Кладут и читают по ключу в квадратных скобках: `prices["меч"] = 100;`, а прочитать — `prices["меч"]`.

**9. Проверка склада.**
Возьми тот же словарь `prices` (меч, щит). Проверь, **есть ли на складе** товар «щит», а потом — «лук», и выведи результат для каждого (`True`/`False`).
**Должно получиться:**
```
щит: True
лук: False
```
> 💡 Для проверки **ключа** словаря есть отдельный метод — `ContainsKey` (не `Contains`, как у списка).

**10. Отряд героев.**
Заведи словарь `squad`, где **ключ — имя героя**, а **значение — его уровень**. Добавь трёх героев с разными уровнями. Затем выведи **весь отряд** в виде «имя — уровень», каждого с новой строки.
**Должно получиться (пример):**
```
Артур — 5
Мерлин — 9
Гвен — 4
```
> 💡 Перебрать все пары словаря помогает `foreach`. У каждой пары есть две части: `.Key` (ключ) и `.Value` (значение).

## 🔴 Уровень 3 — со звёздочкой

**11. Расписание уроков.**
Сделай электронное расписание. Заведи словарь `schedule`: **ключ — день недели**, **значение — уроки этого дня** (одной строкой, через запятую). Заполни хотя бы 3 дня. Затем спроси у пользователя день (`Console.ReadLine()`) и покажи уроки на этот день. А если такого дня в расписании нет — напиши, что это выходной.
**Должно получиться (ввели «Среда»):**
```
Какой день? Среда
Уроки: Информатика, Химия, Литература
```
**Должно получиться (ввели «Суббота»):**
```
Какой день? Суббота
Выходной — уроков нет!
```
> 💡 Прежде чем показать `schedule[day]`, проверь через `ContainsKey`, что такой день вообще есть, — иначе программа упадёт с ошибкой на несуществующем ключе.

**12. Безопасный прайс.**
Снова прайс-лист (меч=100, щит=60). Спроси у пользователя название товара и выведи его цену. Но если такого товара нет — не дай программе упасть, а вежливо напиши «Нет в прайсе».
**Должно получиться (ввели «лук»):**
```
Введите товар: лук
Нет в прайсе.
```
> 💡 Здесь удобен `TryGetValue`: он **за один раз** и проверяет, есть ли ключ, и достаёт значение (помнишь `out` из Урока 7? — тут он же).

**13. Счётчик голосов.**
На голосовании собрали ответы: `string[] votes = { "да", "нет", "да", "да", "нет" };`. Построй словарь-счётчик и выведи, **сколько раз** прозвучал каждый ответ.
**Должно получиться:**
```
да: 3
нет: 2
```
> 💡 Иди по массиву в цикле. Для каждого ответа: если такой ключ в словаре уже есть — увеличь его на 1; если встретился впервые — заведи его со значением 1.

**14. Копилка чисел.**
Собери числа от пользователя в список. В цикле спрашивай число за числом; как только ввели **пустую строку** (просто Enter) — заканчивай ввод. После этого выведи: **сколько** чисел ввели, **самое большое** и **среднее**.
**Должно получиться (ввели 5, 8, 3, Enter):**
```
Чисел: 3, максимум: 8, среднее: 5,33...
```
> 💡 Заведи пустой `List<int>` и добавляй в него введённые числа `Add`-ом. Строку из ввода в число превращает `Convert.ToInt32(...)`. Дальше пригодятся `Count`, `Max()` и `Average()`.

**15. Инвентарь с меню.**
Собери маленький «Инвентарь героя» с меню в цикле `while (true)`:
- **1** — спросить название предмета и добавить его в список;
- **2** — показать все предметы **с номерами** (1., 2., 3. …);
- **0** — выйти из программы.
**Должно получиться (пример работы):**
```
1 — добавить  2 — показать  0 — выход
Выбор: 1
Что добавить? меч
Выбор: 2
  1. меч
```
> 💡 Читай выбор пользователя строкой и сравнивай: `if (choice == "1") ...`. Чтобы показать список **с номерами**, удобнее обычный `for` с индексом `i` — тогда номер это `i + 1`, а сам предмет `bag[i]`.

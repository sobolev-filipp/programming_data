**Блок 1 · Урок 8 | 30 заданий в 3 уровнях по сложности**

> Пиши и **сразу запускай** (F5 / `dotnet run`). У каждой задачи — **«Должно получиться»** и **💡 подсказка**.
> 🟢 базовый · 🟡 средний · 🔴 со звёздочкой. Часть задач **повторяет уроки 1–7** (циклы, `%`, методы, LINQ) — чтобы не забывалось.
> 📌 Шпаргалка: список `List<string> items = new List<string>();` · `items.Add(x)`, `Insert(i, x)`, `Remove(x)`, `RemoveAt(i)`, `Contains(x)`, `IndexOf(x)`, `Count`, `Sort()`, `Reverse()`, `Clear()` · перебор `foreach` · словарь `Dictionary<string,int> d = new();` · `d[key] = value`, `d.ContainsKey(key)`, `d.TryGetValue(key, out v)`, перебор `foreach (var pair in d) { pair.Key, pair.Value }`. **Имена — латиницей.**
> 💡 Подсказки — это **наводки** (какой метод/приём вспомнить), а не готовый код.

## 🟢 Уровень 1 — базовый (примени изученное)

**1. Список покупок.**
Создай список строк, добавь в него 3 продукта и выведи все элементы по одному.
**Должно получиться (пример):**
```
хлеб
молоко
сыр
```
> 💡 Создай `List<string>`, добавляй элементы методом `Add`, потом перебери список `foreach`.

**2. Добавили и передумали.**
Создай список, добавь 4 элемента, потом **удали один** (по значению) и выведи, что осталось.
**Должно получиться (убрали «сыр»):**
```
хлеб
молоко
яблоки
```
> 💡 Убрать элемент по значению можно методом `Remove`, которому передают, **что** удалить.

**3. Сколько всего.**
Создай список и выведи, **сколько в нём элементов**.
**Должно получиться (3 элемента):**
```
В списке 3 элемента
```
> 💡 У списка количество элементов — это свойство `Count` (в отличие от массива, где было `Length`).

**4. Есть ли в списке.**
Создай список продуктов и проверь, **есть ли в нём «молоко»** (`да`/`нет`).
**Должно получиться:**
```
Молоко есть: True
```
> 💡 Проверить наличие элемента можно методом `Contains`.

**5. На каком месте.**
Найди и выведи, **на какой позиции (индексе)** стоит «сыр» в списке.
**Должно получиться (если сыр третий):**
```
Сыр на месте: 2
```
> 💡 Позицию элемента возвращает метод `IndexOf` (счёт с 0). Если элемента нет — вернёт −1.

**6. Вставить в начало.**
Создай список и **вставь новый элемент в самое начало** (на позицию 0), потом выведи список.
**Должно получиться (вставили «важное» первым):**
```
важное
хлеб
молоко
```
> 💡 Вставить на конкретную позицию можно методом `Insert`, которому говорят **куда** (индекс) и **что** вставить.

**7. Удалить по номеру.**
Создай список и **удали второй элемент** (по индексу), выведи остаток.
**Должно получиться (убрали элемент с индексом 1):**
```
хлеб
сыр
```
> 💡 Удалить по позиции (а не по значению) — метод `RemoveAt`, которому дают индекс.

**8. Наведём порядок.**
Создай список слов вперемешку и **отсортируй** его по алфавиту, потом выведи.
**Должно получиться (из «сыр, хлеб, молоко»):**
```
молоко
сыр
хлеб
```
> 💡 У списка есть метод `Sort()`, который упорядочивает его «на месте».

**9. Словарь цен.**
Создай словарь «продукт → цена» с несколькими товарами и выведи **цену молока**.
**Должно получиться:**
```
Молоко стоит 70
```
> 💡 Словарь хранит пары. Значение по ключу берут так: `prices["молоко"]`.

**10. Все пары словаря.**
Создай словарь «продукт → цена» и выведи **все пары** в виде «продукт: цена».
**Должно получиться:**
```
хлеб: 40
молоко: 70
```
> 💡 Перебери словарь `foreach (var pair in prices)`; у пары есть `pair.Key` (ключ) и `pair.Value` (значение).

## 🟡 Уровень 2 — средний (считаем и ищем)

**11. Итоги по списку чисел.** *(повтор урока 6: LINQ)*
Создай `List<int>` и выведи его **сумму, максимум и среднее** готовыми методами.
**Должно получиться (для 5, 3, 8, 1, 9):**
```
Сумма: 26
Максимум: 9
Среднее: 5,2
```
> 💡 Как и у массива, у списка работают `Sum()`, `Max()`, `Average()`. Среднее округли до 2 знаков.

**12. Копим список с клавиатуры.**
Спрашивай у пользователя числа и добавляй их в список, пока не введут 0. Потом выведи, сколько чисел собрал и их сумму.
**Должно получиться (ввели 10, 20, 5, 0):**
```
Собрано чисел: 3
Сумма: 35
```
> 💡 В цикле `while(true)` читай число; если это 0 — `break`, иначе добавляй в список. Плюс списка — он **растёт сам**, размер заранее не нужен.

**13. Сколько больше порога.** *(повтор урока 6: `Count(=>)`)*
Создай список чисел и посчитай, **сколько из них больше 5**.
**Должно получиться (для 5, 3, 8, 1, 9):**
```
Больше 5: 2
```
> 💡 Метод `Count` умеет считать по правилу: передай ему условие в виде `x => x > 5`.

**14. Счётчик букв.** *(повтор урока 5: строки)*
Спроси слово и посчитай, **сколько раз встречается каждая буква**, с помощью словаря «буква → количество».
**Должно получиться (для «миссисипи»):**
```
м: 1
и: 4
с: 3
п: 1
```
> 💡 Перебирай буквы. Если буква уже есть в словаре — увеличь её значение; если нет — заведи со значением 1. Наличие ключа проверяет `ContainsKey`.

**15. Телефонная книга.**
Создай словарь «имя → телефон». Спроси имя и выведи телефон, а если такого имени нет — вежливо сообщи об этом.
**Должно получиться (нет «Пети»):**
```
Имя: Петя
Такого контакта нет
```
> 💡 Безопасно достать значение помогает `TryGetValue`: он и проверяет наличие, и выдаёт значение. Если вернул `false` — ключа нет.

**16. Убрать всё лишнее.** *(повтор урока 1: `%`)*
Создай список чисел и **удали из него все чётные**, выведи что осталось.
**Должно получиться (из 5, 3, 8, 1, 9, 4):**
```
5 3 1 9
```
> 💡 У списка есть метод `RemoveAll`, который убирает все элементы, подходящие под правило. Правило чётности передают ему в виде `x => x % 2 == 0`.

**17. Список дел с номерами.**
Собери список задач (добавь несколько) и выведи их **пронумерованным списком**.
**Должно получиться:**
```
1. сделать уроки
2. погулять
3. почитать
```
> 💡 Перебирай по индексу `for` (чтобы был номер `i + 1`), а элемент бери как `list[i]`.

**18. Среднее по списку методом.** *(повтор урока 7: методы)*
Напиши **метод**, который принимает `List<int>` и возвращает среднее значение. Проверь его.
**Должно получиться (для 4, 5, 3, 5, 3):**
```
Среднее: 4
```
> 💡 Метод типа `double` с параметром `List<int>`. Внутри — `Sum()` подели на `Count` «дробным» делением.

**19. Предскажи вывод.**
Не запуская, скажи, что выведет код. Потом проверь.
```csharp
var list = new List<int> { 10, 20, 30 };
list.Add(40);
list.RemoveAt(0);
Console.WriteLine(list.Count);
Console.WriteLine(list[0]);
```
**Должно получиться:** два предсказания с объяснением, **как изменился список** после добавления и удаления.
> 💡 Пройди по шагам: сначала стало 4 элемента, потом удалили самый первый (индекс 0). Что теперь под индексом 0 и сколько всего элементов?

**20. Уникальные слова.**
Спрашивай слова и добавляй в список, но **только если такого ещё нет** (без повторов). Останавливайся на слове «стоп».
**Должно получиться (ввели кот, пёс, кот, стоп):**
```
Уникальные: кот, пёс
```
> 💡 Перед добавлением проверяй `Contains`: добавляй слово, только если списка его ещё не содержит.

## 🔴 Уровень 3 — со звёздочкой (собери целое)

**21. Инвентарь героя.** *(повтор уроков 3–4: меню)*
Сделай меню на цикле: 1 — добавить предмет, 2 — удалить, 3 — показать всё, 0 — выход. Предметы храни в списке.
**Должно получиться:** рабочее меню, которое меняет и показывает инвентарь.
> 💡 Соедини знакомое: `List<string>` для предметов, `while(true)` + `break`, `switch` по выбору. Каждый пункт вызывает нужную операцию списка.

**22. Голосование.**
Собери «голоса» (несколько строк) и с помощью словаря посчитай, **сколько раз выбрали каждый вариант**.
**Должно получиться (голоса: кот, пёс, кот, кот, пёс):**
```
кот: 3
пёс: 2
```
> 💡 Тот же приём, что счётчик букв (задача 14), но ключ — не буква, а слово-вариант.

**23. Частота символов — самый частый.**
Спроси слово, посчитай частоту букв (как в задаче 14) и выведи **самую частую букву**.
**Должно получиться (для «миссисипи»):**
```
Чаще всего: и (4 раза)
```
> 💡 Сначала заполни словарь «буква → число». Потом пройди по парам словаря и найди пару с наибольшим значением (приём «рекордсмен», но по значениям пар).

**24. Оценки класса.** *(повтор урока 6: параллельные → словарь)*
Создай словарь «ученик → балл». Выведи всех, а также **средний балл** и **имя лучшего**.
**Должно получиться:**
```
Аня: 70
Боря: 95
Вика: 88
Средний балл: 84,33
Лучший: Боря
```
> 💡 Перебирай пары для вывода и попутно копи сумму баллов (для среднего) и запоминай имя с максимальным баллом. Словарь заменяет два параллельных массива из урока 6.

**25. Найди и почини ошибку.**
Программа должна вывести цену товара, но падает, если товара нет:
```csharp
var prices = new Dictionary<string, int> { { "хлеб", 40 } };
Console.Write("Товар: ");
string item = Console.ReadLine();
Console.WriteLine($"Цена: {prices[item]}");
```
**Должно получиться:** для существующего товара — цена, для несуществующего — «нет такого товара» (без падения).
> 💡 Обращение `prices[item]` к несуществующему ключу вызывает ошибку. Перед тем как брать цену, проверь, есть ли ключ (`ContainsKey`), или используй безопасный `TryGetValue`.

**26. Инвентарь со счётчиком.**
Сделай инвентарь, где у каждого предмета — **количество** (словарь «предмет → сколько»). При добавлении уже имеющегося предмета увеличивай его число.
**Должно получиться:**
```
меч: 1
зелье: 3
```
> 💡 Тот же приём счётчика: есть ключ — прибавь к значению, нет — заведи с 1. Это словарь `Dictionary<string, int>`.

**27. Топ по убыванию.** *(повтор урока 6: сортировка)*
Собери список чисел, отсортируй по убыванию и выведи **три самых больших**.
**Должно получиться (из 5, 3, 8, 1, 9, 7):**
```
1: 9
2: 8
3: 7
```
> 💡 Отсортируй список `Sort()` и переверни `Reverse()` (или используй `OrderByDescending`). Потом выведи первые три по индексам 0, 1, 2.

**28. Мини-магазин.** *(сборка)*
Словарь «товар → цена» и корзина-список. Пользователь добавляет товары в корзину, а в конце программа считает **общую стоимость**.
**Должно получиться (корзина: хлеб, молоко):**
```
Корзина: хлеб, молоко
Итого: 110
```
> 💡 Товары с ценами — в словаре. Названия добавленных товаров — в списке-корзине. Для итога перебирай корзину и складывай цены из словаря (`prices[товар]`).

**29. Список задач с отметками.**
Сделай список дел, где к каждому делу можно приписать «(готово)». Пользователь добавляет дела и отмечает их выполненными по номеру.
**Должно получиться:**
```
1. сделать уроки (готово)
2. погулять
```
> 💡 Храни дела в списке. Отметка «готово» — это замена элемента списка на его же текст плюс «(готово)» (по индексу `list[i] = ...`).

**30. Свой каталог/трекер.**
Собери **свою** программу на коллекциях — на выбор:
- 📖 каталог книг (список названий + меню добавить/найти/показать);
- 💰 учёт расходов (словарь «категория → сумма»);
- 🎵 плейлист (список песен, добавить/удалить/перемешать).
**Должно получиться:** рабочая программа, которая хранит и меняет набор данных.
> 💡 Выбери, что удобнее: список (просто набор) или словарь (пары «ключ → значение»). Добавь меню на цикле, как в задаче 21.

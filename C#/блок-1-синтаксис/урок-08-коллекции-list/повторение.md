# 🔁 Разминка (5 минут) · Урок 8

> Повторяем массивы и методы прошлых уроков — сегодня заменим «полку фиксированного размера» (массив) на «растущий рюкзак» (`List`).

## 🎤 Блиц-вопросы (устно, 2 мин)

1. Как в Уроке 6 узнать длину массива? (`.Length`) — у списка будет похожее, но `.Count`.
2. Можно ли у массива `int[5]` добавить 6-й элемент? (нет — размер фиксирован) — вот тут и нужен `List`.
3. Как в Python назывался «список»? (`[]`, `.append`) — сегодня это `List<T>` и `Add`.
4. Как в Python называлась пара «ключ→значение»? (словарь `{ }`) — в C# это `Dictionary`.

## ⌨️ Быстрый разогрев (2 мин)

Набери и запусти — список уже умеет расти:
```csharp
List<string> bag = new List<string>();
bag.Add("меч");
bag.Add("щит");
Console.WriteLine($"В рюкзаке {bag.Count}: {bag[0]}, {bag[1]}");
```

- Мы **нигде не указывали размер** — просто добавили два предмета, и `Count` стал 2. У массива так нельзя. В этом сила `List`.

## 🌉 Что нового будет сегодня

- **`List<T>`** — «массив, который растёт»: `Add`/`Remove`/`Sort`, размер `Count`.
- **`Dictionary<K,V>`** — «ключ → значение» (словарь `{ }` из Python).
- Проект — интерактивный «Инвентарь героя».

## 🔮 Что выведет этот код? (повторяем урок 7, на подумать)

Предскажи вывод, **не запуская**:

1. `int Square(int x) => x * x;` → `Console.WriteLine(Square(4));`
2. Подковырка (параметр по умолчанию):
```csharp
void Greet(string name = "гость") => Console.WriteLine($"Привет, {name}!");
Greet();
```
3. `int Max(int a, int b) { if (a > b) return a; return b; }` → `Console.WriteLine(Max(3, 9));`
4. Подковырка (массив в метод):
```csharp
int Sum(int[] a) { int s = 0; foreach (int n in a) s += n; return s; }
Console.WriteLine(Sum(new[]{1, 2, 3, 4}));
```

<details><summary>✅ Ответы и почему</summary>

1. `16` — 4 × 4.
2. `Привет, гость!` — аргумент не передали → взято значение по умолчанию `"гость"`.
3. `9` — вернётся большее из двух.
4. `10` — метод сложил все элементы массива: 1+2+3+4.
</details>

## 🐞 Есть ли здесь ошибка? (или всё верно?)

1. `int Add(int a, int b) { Console.WriteLine(a + b); }`
2. `void Hi() => Console.WriteLine("hi"); int x = Hi();`
3. `int Double(int x) => x * 2; Console.WriteLine(Double(5));`
4. `void Greet(string name) { Console.WriteLine(name); } Greet();`
5. `int Cube(int x) { return x * x * x; } Console.WriteLine(Cube(2));`

<details><summary>✅ Ответы</summary>

1. ❌ Метод объявлен `int`, но ничего не возвращает — нужен `return`.
2. ❌ `void` ничего не возвращает — нельзя присвоить результат в `x`.
3. ✅ Верно — выведет 10.
4. ❌ Не передан обязательный аргумент `name` (нет значения по умолчанию).
5. ✅ Верно — выведет 8.
</details>

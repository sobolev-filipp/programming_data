# 🔁 Разминка (5 минут) · Урок 8

> Повторяем массивы и методы прошлых уроков — сегодня заменим «полку фиксированного размера» (массив) на «растущий рюкзак» (`List`).

## 🎤 Блиц-вопросы (устно, 2 мин)

1. Как в Уроке 6 узнать длину массива? (`.Length`) — у списка будет похожее, но `.Count`.
2. Можно ли у массива `int[5]` добавить 6-й элемент? (нет — размер фиксирован) — вот тут и нужен `List`.
3. Как в Python назывался «список»? (`[]`, `.append`) — сегодня это `List<T>` и `Add`.
4. Как в Python называлась пара «ключ→значение»? (словарь `{ }`) — в C# это `Dictionary`.

## ⌨️ Быстрый разогрев (2 мин)

Набери и запусти — список уже умеет расти:
```csharp
List<string> bag = new List<string>();
bag.Add("меч");
bag.Add("щит");
Console.WriteLine($"В рюкзаке {bag.Count}: {bag[0]}, {bag[1]}");
```

- Мы **нигде не указывали размер** — просто добавили два предмета, и `Count` стал 2. У массива так нельзя. В этом сила `List`.

## 🌉 Что нового будет сегодня

- **`List<T>`** — «массив, который растёт»: `Add`/`Remove`/`Sort`, размер `Count`.
- **`Dictionary<K,V>`** — «ключ → значение» (словарь `{ }` из Python).
- Проект — интерактивный «Инвентарь героя».

> ⚙️ Учителю: покажи мотивацию через ограничение массива — «а если предметов заранее не знаем, сколько?». Массив тут неудобен → вводим `List`. Мостик Python сильный: `list`/`append`/`dict` детям знакомы. Финал — игровой «Инвентарь героя» с меню.

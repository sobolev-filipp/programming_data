## Главные мысли

1. **`List<T>`** — «массив, который растёт»: добавляй и удаляй сколько нужно.
2. Размер списка — **`.Count`** (не `.Length`!). Элемент по номеру — `list[i]` (с 0).
3. **`Dictionary<K,V>`** — «ключ → значение» (как словарь `{ }` в Python).
4. Доступ к словарю — по **ключу**: `prices["меч"]`. Ключи **уникальны**.
5. Перед `dict[key]` проверь `ContainsKey` (иначе `KeyNotFoundException`).
6. Классика словаря — **счётчик**: `ContainsKey` → `++`, иначе `= 1`.

## List — создать и наполнить

```csharp
List<string> bag = new List<string>();       // пустой
List<int> nums = new List<int> { 40, 90, 65 }; // сразу с числами

bag.Add("меч");            // добавить в конец
bag.Insert(0, "щит");      // вставить на позицию
bag.Remove("меч");         // удалить первое такое значение
bag.RemoveAt(0);           // удалить по индексу
Console.WriteLine(bag.Count);          // сколько
Console.WriteLine(bag.Contains("лук")); // есть ли (True/False)
Console.WriteLine(bag.IndexOf("лук"));  // индекс или -1
bag.Clear();               // очистить
```

## List — порядок и подсчёты

```csharp
nums.Sort();      // по возрастанию
nums.Reverse();   // перевернуть
Console.WriteLine(string.Join(", ", nums));  // печать одной строкой

nums.Max(); nums.Min(); nums.Sum(); nums.Average();  // LINQ
nums.Count(x => x >= 50);                             // сколько подходит
```

## Dictionary — ключ → значение

```csharp
Dictionary<string, int> prices = new();   // короткая запись new()
prices["меч"] = 100;      // положить/заменить
prices.Add("щит", 60);    // то же через Add
Console.WriteLine(prices["меч"]);          // 100

prices.ContainsKey("щит");                 // есть ли ключ
if (prices.TryGetValue("лук", out int p))  // безопасно взять
    Console.WriteLine(p);
prices.Remove("щит");
Console.WriteLine(prices.Count);

foreach (var pair in prices)               // перебор пар
    Console.WriteLine($"{pair.Key} = {pair.Value}");
```

## Счётчик через словарь

```csharp
Dictionary<string, int> counter = new();
foreach (string item in loot)
{
    if (counter.ContainsKey(item)) counter[item]++;
    else counter[item] = 1;
}
```

## Мостики Python → C#

| Python | C# |
|--------|-----|
| `lst = []` / `.append(x)` | `List<T> lst = new();` / `lst.Add(x);` |
| `len(lst)` | `lst.Count` |
| `x in lst` | `lst.Contains(x)` |
| `d = {}` / `d["k"]=v` | `Dictionary<K,V> d = new();` / `d["k"]=v;` |
| `"k" in d` | `d.ContainsKey("k")` |
| `for k,v in d.items():` | `foreach (var pair in d)` → `pair.Key`, `pair.Value` |

## Главные ошибки

| Симптом | Причина | Лечение |
|---------|---------|---------|
| `.Length` у списка не работает | у `List` размер — `.Count` | пиши `.Count` |
| `ArgumentOutOfRangeException` | плохой индекс | `i` в `0..Count-1` |
| `KeyNotFoundException` | ключа нет | `ContainsKey`/`TryGetValue` |
| пара в словаре «пропала» | тот же ключ перезаписал значение | ключи уникальны |

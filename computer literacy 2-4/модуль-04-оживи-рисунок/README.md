## 🖱 Управление Krita (для учителя — ЗАПОМНИТЬ, дети видят программу впервые)
- **Кисть** — клавиша **B** (Brush); размер кисти — **[** меньше / **]** больше; цвет — в круге-палитре (Advanced Color Selector).
- **Ластик** — клавиша **E** (переключает кисть в режим стирания; нажми ещё раз — обратно).
- **Заливка** — Fill Tool (ведёрко) — красит область.
- **Двигать слой** — **Move Tool (T)**; трансформировать — **Ctrl+T**.
- **Слои** — док **Layers** (справа внизу): **+** новый слой, 👁 глаз (скрыть/показать), перетащить = порядок, 2 клика = переименовать. Каждый слой — прозрачная плёнка.
- **Новый документ:** File → New → размер (напр. 1280×720) → Create. **Сохранить:** File → Save (`.kra`). **Экспорт картинки:** File → Export (`.png`).
- **Анимация (ур.13–14):** рабочая среда **Animation** (Window → Workspace → Animation) — доки **Timeline** и **Animation**. Кадр: в Timeline правой кнопкой → **Create Blank Frame** (пустой) / **Create Duplicate Frame** (копия). **Onion skin** (калька) — показывает прошлый кадр бледно. **FPS** — кадров в секунду (ставим ~8–12 для малышей). **Play ▶**. **Экспорт мультика:** File → **Render Animation** → GIF или видео.

В каждом уроке — вау-проект, подробное «как», разные активности, сноски «А вы знали?», своя игра-механика и `доп-задание.md`. Дальше — модуль 5 (командуем + интернет).

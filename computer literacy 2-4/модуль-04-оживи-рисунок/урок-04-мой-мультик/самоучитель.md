# 🧸 Самоучитель — «Повтори за картинкой» (Урок 14)

> Для тех, кто хочет позаниматься **дома** (нужна Krita — krita.org). Собираем свой мультик по шагам, взрослый рядом. 😊

---

### Задание 1. 🎬 Придумай сценку
Три момента: начало → середина → конец. Например: ракета на земле → взлетает → у звёзд.

### Задание 2. 🌌 Слой ФОН
Нижний слой назови **ФОН**, нарисуй фон (небо/космос) **в одном кадре**.

### Задание 3. 🚀 Слой ГЕРОЙ
Сверху слой **ГЕРОЙ**. Нарисуй героя (ракету) внизу. Включи **Animation** (Window → Workspace → Animation), FPS = 8.

### Задание 4. 🔁 Калька
Включи **Onion skin** (лампочку) на слое ГЕРОЙ.

### Задание 5. 🎞 Кадры движения
Кадр 3 → **Create Duplicate Frame** → подними героя. Кадр 5 → копия → ещё выше. По кальке удобно.

### Задание 6. ▶️ Play
Нажми **Play** — герой двигается на фоне! Поправь FPS, если надо.

### Задание 7. 🎥 Сохрани мультик
**File → Save** → **.kra**. Потом **File → Render Animation** → **GIF** → папка «Мои работы» → **Render**. Открой .gif — крутится сам!

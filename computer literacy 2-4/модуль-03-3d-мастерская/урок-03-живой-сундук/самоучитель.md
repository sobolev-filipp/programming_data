# 🧸 Самоучитель — «Повтори за картинкой» (Урок 6)

> Для тех, кто **не успел на уроке** или хочет позаниматься **дома** (нужен BlockBench — blockbench.net). Делай по одному, взрослый рядом помогает. 😊

---

### Задание 1. 🧰 Собери сундук
Открой BlockBench (New → Generic Model). **Add Cube** → **S**: глубокий **ящик**. Ещё **Add Cube** → **S**: плоская **крышка**, **W** поставь на верх ящика.

### Задание 2. 📁 Создай папку
Справа в панели **Outliner** нажми **иконку папки** → строка Group. **2 клика** → напиши **CHEST** → Enter. Перетащи ящик **левой кнопкой на папку CHEST**.

### Задание 3. 👪 Папка в папке
Создай ещё папку **LID** → положи в неё крышку. Теперь выбери CHEST, нажми **W** — весь сундук едет вместе!

### Задание 4. 🔩 Поставь петлю (Pivot, P)
Выбери папку LID → нажми **P (Pivot Tool)** → перетащи точку к **заднему нижнему ребру** крышки. Теперь нажми **E** и поверни — крышка откидывается назад, как настоящая! 🔓

### Задание 5. 💰 Положи клад
Сделай жёлтый плоский куб (слиток), нажми **Ctrl+D** (Duplicate) ещё пару раз, разложи внутри ящика. Добавь голубой самоцвет (поверни на 45°).

### Задание 6. 💾 Сохрани
**File → Save** → назови «мой сундук». Закрой крышку — клада не видно, открой — сокровища!

# 🖐 Практика урока 4 — «Мой 3D-герой и его меч» (BlockBench)

> Собираем своего героя из кубиков и куём ему меч. За работу — **+2 ⭐**. Дети программу видят впервые — не спешим, каждую кнопку показываем, «рука в руке» кому трудно.

> 🎥 **Запомни управление камерой:** **правая кнопка мыши (зажать) — крутить вокруг**, колёсико — приблизить. Левая кнопка — выбрать кубик.
> 🛠 **Три клавиши-инструмента:** **W — двигать (Move)**, **S — размер (Resize)**, **E — повернуть (Rotate)**. Отмена — **Ctrl+Z**.

---

## 🖥 Часть А. Создаём проект
1. Открой BlockBench → **New (Новый)** → **Generic Model (Универсальная модель)**.
2. Напиши имя `moy_geroy` → **Confirm**.
3. Появилась 3D-сцена. **Покрути камеру правой кнопкой** — привыкни к объёму.

## 🧊 Часть Б. Первый кубик
1. Нажми **Add Cube (Добавить куб)** — в центре появился кубик (и строка `Cube` в списке Outliner справа).
2. Нажми **W** (Move) → появились 3 стрелки. Потяни за 🟢 **зелёную** — кубик вверх, за 🔴 **красную** — вбок.
3. Нажми **S** (Resize) → потяни за точку — кубик растягивается. Сделай его **широким** — это **тело**.

## 🦸 Часть В. Собери своего героя
Учитель показывал робота — а ты сделай **своего**! Выбери:

**🐱 Кубик-котик** (образец — [Главный результат практики (котик).png](изображения/Главный%20результат%20практики%20(котик).png)):
1. 🟧 **Add Cube** → **S** — вытяни в длину → **тело** (котик стоит на лапках).
2. 🟧 **Add Cube** → **W** — поставь куб **спереди** тела (🔵 синяя стрелка) → **голова**.
3. 👂 **Add Cube** ×2 — маленькие кубики на макушку → **ушки**.
4. 🐾 **Add Cube** ×4 — кубики снизу по углам → **лапки** (трудно — сделай 2).
5. 〰️ **Add Cube** → **W** вверх сзади → **хвостик**.

**🤖 Или робот:** тело-куб → голова-куб сверху (**W**) → ножки → ручки по бокам → антенна.

> 🐶 Хочешь щенка/мишку/лягушонка — те же кубики, поменяй ушки и хвост. Главное — **свой** герой!

## ⚔️ Часть Г. Куём меч героя (бонус — самое интересное!)
1. **Add Cube** → **S** — сделай **длинным и тонким** → **лезвие**.
2. **Add Cube** → **S** покороче, **W** под лезвие → **рукоять**.
3. **E** (Rotate) → потяни за кольцо → наклони меч, будто герой держит его.
4. 💎 **Add Cube** маленький на рукоять → **E** поверни на **45°** → «кристалл-ромб».

> 🛡 **Успел? Сделай щит:** плоский широкий куб (**S**) + по краям рамка из тонких кубиков. Настоящий герой готов к приключениям!

## 🖼 Образец: кубик-котик (вид сбоку)
```
   🟧  🟧              ← ушки
   🟧🟧🟧   〰️         ← голова спереди + хвостик сзади
 🟧🟧🟧🟧🟧🟧          ← тело (длинный куб, растянут клавишей S)
  🟫  🟫  🟫  🟫       ← лапки-кубики снизу
```

## 💾 Часть Д. Сохраняем
1. **File → Save** → назови проект.
2. Проект `.bbmodel` сохранён — завтра раскрасим!

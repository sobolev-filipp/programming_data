# 🖐 Практика урока 4 — «Мой кубик-персонаж» (BlockBench)

> Главная работа: собрать 3D-персонажа из кубиков и покрутить его камерой. За работу — **+2 ⭐**. Лепим объём — новое дело! Не спешим, «рука в руке» кому трудно.

---

## 🖥 Часть А. Открываем мастерскую
1. Открыть **BlockBench** → **New (Новый)** → **Generic Model** (обычная модель).
2. Появилось 3D-поле с сеткой-полом.
3. 🔄 **Покрути камеру:** зажми **левую кнопку мыши** и веди — вид облетает вокруг. Колёсико — приблизить.

## 🧊 Часть Б. Первый куб
1. Нажми **Add Cube (Добавить куб)** — появился кубик.
2. ✋ Тяни за **цветные стрелки-оси**: 🔴 X — вбок, 🟢 Y — вверх, 🔵 Z — вперёд.
3. ↔️ Тяни за **грань** — меняй размер (шире/выше).
> Ошибся? **Ctrl+Z (Отмена)** — вернёт назад.

## 🦸 Часть В. Выбери и собери своего героя
Учитель показывал **робота**. А ты собери **своего, другого** героя — так интереснее! Выбери:

**🤖 Вариант 1 — робот** (как показывал учитель): тело-куб → голова-куб сверху → две ножки → по желанию ручки и антенна-куб.

**🐱 Вариант 2 — кубик-котик** (свой герой, шаги ниже):
1. 🟧 **Add Cube** — большой куб — **тело**.
2. 🟧 **Add Cube** → куб поменьше → подвинь **вверх по зелёной стрелке (Y)** → **голова** на теле.
3. 👂 **Add Cube** два **маленьких** кубика на макушку по краям — **ушки**.
4. 🐾 **Add Cube** два кубика снизу — **лапки**.
5. 〰️ **Add Cube** узкий куб сзади (двигай по синей стрелке Z назад) — **хвостик**.
6. 🔄 **Покрути камеру** — посмотри котика спереди, сзади и сверху!

> 🐶 Хочешь не котика — сделай **щенка, лягушонка или мишку**: те же кубики, поменяй ушки/хвост. Главное — свой герой!

## 🖼 Образец: кубик-котик
```
   🟧    🟧       ← ушки (два маленьких куба на макушке)
    🟧🟧🟧        ← голова (куб поменьше, поднят по Y)
   🟧🟧🟧🟧  〰️   ← тело (большой куб) + хвостик сзади
    🟫    🟫       ← две лапки (кубики снизу)
```
*У каждого — свой герой! Ушки, хвост и цвет делают его особенным.*

## 💾 Часть Г. Сохраняем проект
1. **File → Save** (Файл → Сохранить) → назови проект («мой герой»).
2. Проект `.bbmodel` сохранён — завтра продолжим и раскрасим!

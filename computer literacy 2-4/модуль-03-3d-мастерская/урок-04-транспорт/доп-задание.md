## 📺 Что мы делали на уроке (прочитай, чтобы понять)
На этом уроке мы собирали **транспорт** и узнали важные приёмы:
- **пропорции** — у машинки корпус **длинный**, у самолёта **пухлый**; сначала делаем правильную форму корпуса (**S**), а потом детали;
- **Duplicate (Ctrl+D)** для **симметрии** — колёса, крылья, лапки должны быть **одинаковыми**; делаешь одно, копируешь и ставишь на другой бок;
- **вращающаяся часть на Pivot** — винт самолёта/колесо должны крутиться; ставим **Pivot Tool (P)** в **центр** детали, тогда она вертится ровно;
- **скругление**: маленький куб + **E** на **45°** = скошенный уголок (фары, нос).

Камеру крутим **правой кнопкой**. Инструменты: **W** двигать, **S** размер, **E** повернуть, **Ctrl+D** копия, **Ctrl+Z** отмена.

## 🎯 Твоё задание — ВЕРТОЛЁТ 🚁
У вертолёта есть пухлый корпус, длинный хвост, лыжи (одинаковые — через Duplicate) и винт сверху, который **крутится на Pivot**.

### 🧊 Часть А. Корпус и хвост (пропорции)
1. **Add Cube** → **S** — **пухлый** куб спереди = **кабина-корпус**.
2. **Add Cube** → **S** тонкий длинный → **W** приставь сзади = **хвост** (длинная «палочка»).
3. По желанию — спереди куб со скошенным уголком: **E** на **45°** = округлый нос.

### 🛬 Часть Б. Лыжи (Duplicate — симметрия!)
1. **Add Cube** → **S** тонкий длинный → **W** поставь **снизу сбоку** = **посадочная лыжа**.
2. **Ctrl+D** → перетащи копию на **другой бок**. Две одинаковые лыжи — ровно!

### 🌀 Часть В. Винт на Pivot (крутится!)
1. **Add Cube** → **S** — тонкий **длинный** куб **сверху** корпуса = **лопасть винта**.
2. **Ctrl+D** → поверни копию **E** на 90° крест-накрест = два винта крестом.
3. Сложи лопасти в папку **PROP** (Outliner).
4. Возьми **Pivot Tool (P)** → поставь точку в **самый центр** винта.
5. Крутани **E** — винт вертится ровно вокруг центра! (Завтра, на уроке анимации, его можно оживить.)
6. 🪶 Сделай **маленький винт на хвосте** так же.

### 💾 Часть Г. Сохраняем
**File → Save** → назови «вертолёт». Покрути камерой — готов к полёту!

# 🧸 Самоучитель — «Собери мир по шагам» (Урок 10)

> Для тех, кто хочет позаниматься **дома** (нужен BlockBench — blockbench.net). Делай по одному, взрослый рядом помогает. 😊

---

### Задание 1. 🌍 Выбери тему
Реши, какой у тебя мир: лес, космос, город или подводный. Открой BlockBench → **New → Generic Model**.

### Задание 2. 🟩 Построй землю
**Add Cube** → **S** сделай **большой плоский** куб — это земля. Перейди в **Paint** и залей её цветом темы.

### Задание 3. 🏔 Поставь большой объект
Сделай одну **крупную** вещь (дерево / планету / дом) и поставь её **сзади**. Сложи детали в папку (Outliner).

### Задание 4. 🦸 Добавь героя
Собери из кубиков главного героя (зверёк / робот / рыбка) и поставь его **спереди и покрупнее**.

### Задание 5. ✨ Раскидай мелочи
Сделай маленький кубик (камушек / звезда / гриб) и размножь его **Ctrl+D**. Расставь по земле, но оставь пустое место.

### Задание 6. 🎨 Наведи красоту
Раскрась объекты, наведи **свет-тень** (верх светлее, бок темнее). По желанию — оживи одну деталь (режим **Animate**).

### Задание 7. 📸 Сделай фото
Покрути камеру правой кнопкой, найди красивый вид → **File → Export → Screenshot**. Сохрани и сам проект: **File → Save**.

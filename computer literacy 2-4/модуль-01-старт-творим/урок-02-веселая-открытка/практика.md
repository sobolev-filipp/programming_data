# 🎨 Практика урока 2 — «Моя весёлая открытка» (Tux Paint)

> Главная работа: сделать открытку с фоном, штампами и надписью, потом сохранить её. За готовую работу — **+2 ⭐**. Придумай, **кому** даришь — так теплее!

## 🧩 Что делаем
Открытку для того, кого любишь: маме, другу, бабушке — на праздник или просто так.

## 👉 Шаги (учитель показывает, дети повторяют)

1. 🖱 Открыть **Tux Paint** двойным кликом. При желании — **развернуть** окно 🔲 на весь экран (рисовать удобнее).
2. 🪣 **Заливка** — выбрать цвет и сделать **фон** открытки.
3. 🎟 **Штампы** — украсить: цветы 🌸, сердечки ❤️, звёзды ⭐, шарики 🎈.
4. ✨ По желанию — **Волшебство** (радуга, блёстки).
5. 🅰️ Инструмент **Текст** → щёлкнуть на открытке → **напечатать** поздравление: «С праздником!», «Поздравляю!» или имя. Выбрать цвет надписи.
6. 💾 Нажать **Сохранить** (дискета) — открытка стала файлом!

## 🖼 Образец результата
```
  ❤️  ⭐   🌸
   ┌───────────────┐
   │  С ПРАЗДНИКОМ! │   ← надпись
   │   🎈   🌸  ⭐   │
   └───────────────┘
       — для мамы —
```
*Яркий фон, штампы-украшения и тёплая надпись. У каждого — своя открытка!*

- [ ] Открытка сохранена (нажал «Сохранить»).

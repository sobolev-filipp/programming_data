# 🎨 Практика урока 3 — «Мой сказочный пейзаж» (Tux Paint)

> Главная работа: нарисовать сказочный мир и сложить работы в свою папку. За готовую работу — **+2 ⭐**. Придумай, какая у тебя сказка!

## 🌈 Часть А. Рисуем пейзаж
1. 🖱 Открыть **Tux Paint**, при желании развернуть окно 🔲.
2. 🪣 **Заливка** голубым → закрасить **верх** (небо).
3. 🪣 **Заливка** зелёным → закрасить **низ** (трава).
4. ☀️ Нарисовать/поставить **солнце** и облака вверху.
5. 🌳🏰 Добавить внизу: деревья, цветы, замок.
6. 🐉 Нарисовать **сказочного героя**: дракон, единорог, принцесса, робот.
7. 🌈 По желанию — **Волшебство** (радуга, блёстки).

## 🖼 Образец результата
```
  ☀️        ☁️
  ~~~~~~~~~~~~~~~~   ← небо (голубое)
  🌈   🏰
  🌳   🐉   🌸
  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  ← земля (зелёная)
```
*Небо вверху, земля внизу, сказочный герой в своём мире. У каждого — своя сказка!*

## 📁 Часть Б. Наводим порядок
1. 💾 **Сохранить** пейзаж (кнопка Сохранить).
2. 🖱 Правой кнопкой по Рабочему столу → **Создать → Папку** → напечатать **«Мои работы»** → Enter.
3. 🖼➡️📁 **Перетащить** пейзаж (и открытку с прошлого урока) в папку. Открыть — все работы вместе!

## 🌈 Кто быстро справился
- Добавь в мир речку, мостик или второе солнце.
- Помоги соседу создать папку правой кнопкой (+1 ⭐ 🤝).
- Пройди игру [игра.html](игра.html) «Разложи файлы» — набери больше очков, не потеряв жизни.

## ✅ Готово, если
- [ ] На пейзаже есть небо (вверху) и земля (внизу).
- [ ] Есть солнце, что-то на земле и сказочный герой.
- [ ] Создал папку «Мои работы» и положил туда работу.

# 🎨 Практика урока 4 — «Мой герой» + магия ИИ

> Главная работа: нарисовать своего героя и подписать имя. Потом — увидеть, как ИИ рисует героя по словам. За рисунок — **+2 ⭐**, за идею для ИИ — ещё ⭐.

## 🦸 Часть А. Рисуем своего героя (Tux Paint)
1. 🖱 Открыть **Tux Paint**.
2. 🪣 Заливкой сделать **фон** — где живёт герой (небо, космос, лес).
3. 🖌 Кистью нарисовать **героя**: голову, тело, ручки-ножки, лицо.
4. 🌈 Добавить детали: плащ, корону, крылья, суперсилу; штампы вокруг.
5. 🅰️ Инструментом **Текст** — **подписать имя** героя.
6. 💾 **Сохранить** (и по желанию — в папку «Мои работы»).

## 🖼 Образец результата
```
   ⭐  МОЛНИЯ-КОТ  ⭐   ← имя героя
        (=^･^=)
        /|⚡|\        ← плащ и суперсила
         | |
        боты
```
*Твой герой с именем и суперсилой. У каждого — свой!*

## 🤖 Часть Б. Придумай для ИИ
Учитель откроет нейросеть. Придумай **описание героя словами** — кто, какой, где:
- «золотой дракон с крыльями на радуге»
- «робот-супергерой в синем плаще»
- «пушистый кот-волшебник в звёздной шляпе»

Потренируйся в игре [игра.html](игра.html) «Придумай для ИИ» — собери смешное описание из слов!

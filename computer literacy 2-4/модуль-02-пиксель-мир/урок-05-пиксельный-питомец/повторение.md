# 🔁 Разминка-повтор всего модуля 2 (6 минут) — Урок 10

> Финиш модуля! Вспоминаем всё, чему научились в «Пиксель-мире». Отвечаем **хором** или по руке. За ответы — ⭐.

## 1. «Пиксели» (1,5 мин)
- «Из чего сделаны все картинки?» → из **пикселей** 🟦 (квадратиков).
- «Как называется рисование крупными пикселями?» → пиксель-арт.

## 2. «Спрайт и рисование» (1,5 мин)
- «Герой-картинка из пикселей — это…» → **спрайт** 🦸.
- «С чего удобно начинать рисовать?» → сверху вниз.
- «В какой программе рисуем?» → **Piskel**.

## 3. «Анимация» (1,5 мин)
- «Одна картинка из мультика — это…» → **кадр** 🎞.
- «Много кадров, быстро сменяются — это…» → **анимация** 🎬.
- «Файл с двигающейся картинкой?» → **GIF**.

## 4. «ИИ» (1,5 мин)
- «Кто рисует по нашим словам?» → **ИИ (нейросеть)** 🤖.
- «Три вопроса для описания?» → кто? какой? где?

# 🏠 Самоучитель — Урок 17: игра «Пинг-понг со счётом» (Scratch)

> Для дома или чтобы догнать класс. Делай по шагам — соберёшь пинг-понг со счётом! Scratch: **scratch.mit.edu → «Создать»**. Язык — глобус 🌐 → Русский. Без звука — реакции надписями.

### 1. Ракетка 🏓
Выбери спрайт **Paddle** (ракетка-полоска) или нарисуй прямоугольник. Скрипт: «когда ▶ нажат» → «всегда [ перейти в x: (позиция x у мыши) y: -130 ]». Проверь — ракетка едет за мышкой внизу.

### 2. Переменные 🟠
Раздел **«Переменные»** → **«Создать переменную»**. Сделай две: **очки** и **жизни**. Поставь галочки — числа появятся на сцене.

### 3. Мяч ⚪ — подача
Выбери спрайт **Ball**. Скрипт: «когда ▶ нажат» → «задать очки = 0» → «задать жизни = 3» → «перейти в x: 0 y: 0» → «указать направление 170».

### 4. Мяч скачет
Добавь «всегда [ идти 7 шагов · если на краю, оттолкнуться ]». Запусти — мяч летает и отскакивает от стен.

### 5. Отбил ракеткой — очко
Внутрь «всегда» добавь: «если <касается (Ракетка)?> то → изменить очки на 1 + указать направление (дать случайное -35..35) + идти 12 шагов». Теперь удар ракеткой даёт очко и отправляет мяч вверх.

### 6. Промах — минус жизнь
Ещё в «всегда»: «если <(y) < -150> то → говорить Мимо! 0.5 + изменить жизни на -1 + перейти в x: 0 y: 0 + указать направление 170».

### 7. Конец игры
И последнее в «всегда»: «если <жизни = 0> то → говорить Игра окончена! 2 → остановить всё».

### 8. ИГРАЙ! 🎮
Нажми флажок, двигай ракетку мышкой, отбивай мяч и набирай очки!

### 9. Рекорд 🏆 (по желанию)
Создай переменную **рекорд** (задать 0 только один раз, в начале проекта — НЕ в старте мяча). Рядом с «жизни = 0» добавь: «если <очки > рекорд> то → задать рекорд = очки + говорить Новый рекорд! 1».

### 10. Сохрани 💾
**Файл → Сохранить** → имя `пинг-понг`.

---
✅ Если мяч **скачет, ракетка его отбивает, очки растут, а промах отнимает жизнь** — ты собрал пинг-понг со счётом! На уроке повторим и добавим рекорд.

## 📺 Что делали на уроке

Мы собрали классику — **«Лови яблоки»**: с неба падают яблоки, игрок ловит их корзиной (стрелки ←→), за промах теряет жизнь.

Главные блоки:
- 🟦 **«изменить y на минус»** в «всегда» — падение; после поимки/падения — «перейти наверх»;
- 🟧 **«если … иначе»** — развилка: **поймал корзиной** (`касается Bowl?`) → «Ням!» и новое яблоко, **иначе** → проверяем, не упало ли (`y < -160`) → «Эх!» и минус жизнь;
- 🟠 переменная **«жизни»** — счётчик (задать 3, «изменить на -1»); «коробочка для числа», подробнее на уроке 17;
- 🟧 **«если жизни = 0 → остановить всё»** — конец игры.

Главная идея: программа **принимает решения** блоком «если … иначе» — это мозг игры. И правило «лови хорошее — пропускай плохое» (гнилые яблоки ловить нельзя).

## 🧤 Твоя игра: «Вратарь»

Собери ловилку с другим героем — те же навыки.

### Шаг 1. Вратарь и мяч
**🐱+** → спрайт **Goalie** (или любой человечек) как вратарь, поставь внизу. И спрайт **Soccer Ball** (мяч). Фон — футбольное поле.

### Шаг 2. Управление вратарём
«когда → нажата» → «изменить x на 20»; «когда ← нажата» → «изменить x на -20».

### Шаг 3. Жизни
Создай переменную **жизни**, поставь галочку.

### Шаг 4. Мяч летит и ловится
Мяч: «когда ▶ нажат» → «задать жизни = 3» → «перейти наверх (случайный x, y:170)» → «всегда»:
- «изменить y на -6»;
- «если <касается (Goalie)?> то → говорить Взял! 0.2 + перейти наверх; иначе → если <(y) < -160> то → говорить Гол! 0.2 + изменить жизни на -1 + перейти наверх»;
- «если <жизни = 0> то → говорить Матч окончен! 2 + остановить всё».

### Шаг 5. Сохрани
**Файл → Сохранить** → имя `вратарь`.

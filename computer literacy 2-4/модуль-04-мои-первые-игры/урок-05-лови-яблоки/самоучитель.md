# 🏠 Самоучитель — Урок 15: игра «Лови яблоки» (Scratch)

> Для дома или чтобы догнать класс. Делай по шагам — соберёшь аркаду на клонах! Scratch: **scratch.mit.edu → «Создать»**. Язык — глобус 🌐 → Русский. Без звука — реакции надписями.

### 1. Корзина 🧺
Выбери спрайт **Bowl** (🐱+ внизу), поставь внизу сцены. Котика удали.

### 2. Управление ←→
Два скрипта: «когда → нажата» → «изменить x на 20»; «когда ← нажата» → «изменить x на -20». Проверь — корзина ездит.

### 3. Переменная «жизни» 🟠
Раздел **«Переменные»** → **«Создать переменную»** → назови **жизни**. Поставь галочку (появится на сцене).

### 4. Яблоко-завод 🍎 (делает клоны)
Выбери спрайт **Apple**. Первый скрипт штампует копии:
«когда ▶ нажат» → «задать жизни = 3» → «скрыться» → «всегда [ создать клон (сам себя) · ждать 1 сек ]».
Сам спрайт прячется, а в небе появляются его клоны.

### 5. Что делает каждый клон
Второй скрипт — на шапочке **«когда я начинаю как клон»**:
«показаться» → «перейти в x: (случайное -220..220) y: 170» → «всегда [ изменить y на -6 ]». Запусти — клоны сыплются сверху.

### 6. Поймал или промах — «если … иначе»
Внутрь «всегда», под «изменить y», положи **«если <касается (Bowl)?> то … иначе …»**:
- в «то»: «говорить Ням! 0.2» + «удалить этот клон»;
- в «иначе»: «если <(y) < -160> то → говорить Эх! 0.2 + изменить жизни на -1 + удалить этот клон».

### 7. Конец игры
Ещё в «всегда», после развилки: «если <жизни = 0> то → остановить всё».

### 8. ИГРАЙ! 🎮
Нажми флажок, лови падающие яблоки корзиной!

### 9. Гнилое яблоко 🟢 (по желанию)
Сделай второй спрайт «Гнилое» (дублируй яблоко, перекрась). Дай ему такой же завод клонов. У клона: «если касается Bowl → Фу! + изменить жизни на -1 + удалить этот клон», иначе если упало вниз → просто «удалить этот клон». Лови спелые, пропускай гнилые!

### 10. Сохрани 💾
**Файл → Сохранить** → имя `лови-яблоки`.

---
✅ Если из одного яблока **сыплются клоны, корзина их ловит, а за промах минус жизнь** — ты собрал аркаду на клонах! На уроке повторим и добавим гнилые.

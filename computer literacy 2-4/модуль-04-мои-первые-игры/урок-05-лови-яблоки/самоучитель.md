# 🏠 Самоучитель — Урок 15: игра «Лови яблоки» (Scratch)

> Для дома или чтобы догнать класс. Делай по шагам — соберёшь аркаду! Scratch: **scratch.mit.edu → «Создать»**. Язык — глобус 🌐 → Русский. Без звука — реакции надписями.

### 1. Корзина 🧺
Выбери спрайт **Bowl** (🐱+ внизу), поставь внизу сцены. Котика удали.

### 2. Управление ←→
Два скрипта: «когда → нажата» → «изменить x на 20»; «когда ← нажата» → «изменить x на -20». Проверь — корзина ездит.

### 3. Переменная «жизни» 🟠
Раздел **«Переменные»** → **«Создать переменную»** → назови **жизни**. Поставь галочку (появится на сцене).

### 4. Яблоко падает 🍎
Выбери спрайт **Apple**. Скрипт: «когда ▶ нажат» → «задать жизни = 3» → «перейти в x: (случайное -200..200) y: 170» → «всегда [ изменить y на -6 ]». Запусти — яблоко падает.

### 5. Поймал или промах — «если … иначе»
Внутрь «всегда», под «изменить y», положи **«если <касается (Bowl)?> то … иначе …»**:
- в «то»: «говорить Ням! 0.2» + «перейти в x:(случайное) y:170»;
- в «иначе»: «если <(y) < -160> то → говорить Эх! 0.2 + изменить жизни на -1 + перейти наверх».

### 6. Конец игры
Ещё в «всегда»: «если <жизни = 0> то → говорить Игра окончена! 2 → остановить всё».

### 7. ИГРАЙ! 🎮
Нажми флажок, лови яблоки корзиной!

### 8. Гнилое яблоко 🟢 (по желанию)
Дублируй яблоко, перекрась, назови «Гнилое». У него: «если касается Bowl → Фу! + изменить жизни на -1 + наверх», иначе если упало → просто наверх. Лови спелые, пропускай гнилые!

### 9. Сохрани 💾
**Файл → Сохранить** → имя `лови-яблоки`.

---
✅ Если яблоки **падают, ловятся корзиной, а за промах минус жизнь** — ты собрал аркаду! На уроке повторим и добавим гнилые.

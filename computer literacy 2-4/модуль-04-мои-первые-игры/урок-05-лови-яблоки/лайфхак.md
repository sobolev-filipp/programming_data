# 💡 Лайфхаки — Урок 15 (Scratch, игра «Лови яблоки»)

### 1. 🔀 «если … иначе» — две пасти
У блока **«если … иначе»** две части: верхняя срабатывает, когда условие **верно**, нижняя — когда **неверно**. Именно он позволяет игре выбирать: поймал → +очко, **иначе** → минус жизнь. Если нужен только один вариант — бери обычное «если». Нужен выбор из двух — «если … иначе».

### 2. 🔁 Не забудь вернуть добычу наверх
Яблоко поймали или оно упало — его нужно **снова поднять наверх** («перейти в y: 170, случайный x»), иначе игра остановится после первого яблока. Возврат наверх делает поток яблок **бесконечным**.

### 3. 🟠 Переменная = коробочка для числа
**Жизни, очки, уровень, время** — всё это числа, которые меняются по ходу игры, поэтому их хранят в **переменных**. Создал переменную, задал начальное число, а потом «изменить на +1 / -1». Поставь галочку у переменной — и число будет видно на сцене, как в настоящей игре. (Подробно — на уроке 17.)

---

**👩‍🏫 Совет учителю.** Частые затыки: (1) игра замирает после первого яблока — забыли «перейти наверх» после поимки/падения; (2) нет проверки промаха — взяли «если» без «иначе»; (3) не видно жизней — не поставили галочку у переменной; (4) «если касается» не того спрайта. Переменную «жизни» вводим мягко («коробочка для числа») — глубоко на уроке 17. Для быстрых — очки (2-я переменная), гнилые/золотые яблоки, ускорение; для медленных — хватит корзины, падающего яблока и «если касается → наверх».

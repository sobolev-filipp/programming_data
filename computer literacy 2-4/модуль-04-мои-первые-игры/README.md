Собираем программу, перетаскивая **блоки-команды**, как конструктор. Игры детям не надоедают — модуль крупный (8 уроков), ставим его рано, сразу после 3D: геймдев мотивирует сильнее всего.

## 🧭 Управление Scratch (для учителя — ЗАПОМНИТЬ, дети видят среду впервые)
- **Сцена** (справа вверху) — где всё происходит, тут живёт спрайт (котик). **Зелёный флажок ▶** (над сценой) запускает программу, **красный знак ⏹** останавливает.
- **Спрайт** — герой/персонаж (по умолчанию рыжий котик). Список спрайтов — под сценой. Кнопка **🐱+** (внизу справа) добавляет нового спрайта из библиотеки.
- **Палитра блоков** (слева) — разноцветные команды по категориям: 🟦 **Движение**, 🟪 **Внешний вид**, 🟥 **Звук**, 🟨 **События** (флажок), 🟧 **Управление** (повторять, если), 🟩 **Сенсоры/Операторы**.
- **Скрипт-область** (центр) — сюда **перетаскиваем блоки мышкой** и **соединяем** сверху вниз (прилипают, как магнитики / детали LEGO). Чтобы запустить — **клик по стопке блоков** или по флажку.
- **Блоки-шапочки** (жёлтые, со скруглённым верхом, напр. «когда ▶ нажат») — только они начинают программу; обычные блоки ставятся под них.
- **Убрать блок:** перетащить обратно в палитру слева. **Дублировать стопку:** правой кнопкой → «Дублировать».
- **Сохранить:** в браузере — Файл → «Сохранить на компьютер» (`.sb3`); в Scratch Desktop — Файл → Сохранить. **Открыть:** Файл → «Загрузить с компьютера».
- **Костюмы и звук (ур.13):** вкладки **Костюмы** и **Звуки** (вверху слева) — у спрайта несколько костюмов (кадров), переключение костюма = анимация; звук можно выбрать из библиотеки 🔊.
- **Язык:** глобус 🌐 вверху → Русский.

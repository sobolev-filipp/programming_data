# 🏠 Самоучитель — Урок 18: игра «Космошутер» (Scratch)

> Для дома или чтобы догнать класс. Делай по шагам — соберёшь космошутер! Scratch: **scratch.mit.edu → «Создать»**. Язык — глобус 🌐 → Русский. Без звука — реакции надписями.

### 1. Переменные 🟠
Раздел **«Переменные»** → **«Создать переменную»**. Сделай **очки** и **жизни**. Поставь галочки. В начале игры у корабля добавь «задать очки = 0» и «задать жизни = 3».

### 2. Корабль 🚀
Поставь спрайт-корабль внизу. Управление: «когда → нажата → изменить x на 15»; «когда ← нажата → изменить x на -15». Проверь — корабль летает влево-вправо.

### 3. Пуля — стрельба клонами 🟡
Выбери тонкий спрайт **Пуля** (нарисуй палочку). Три программы:
- «когда ▶ нажат → скрыться»;
- «когда клавиша пробел нажата → создать клон себя»;
- «когда я начинаю как клон → показаться → перейти к [Корабль] → повторить 20 [ изменить y на 15 · если касается Астероид → удалить этот клон ] → удалить этот клон».

Нажимай пробел — из корабля вылетают пули.

### 4. Астероид-завод 🪨
Выбери спрайт **Астероид**. Первая программа (завод): «когда ▶ нажат → скрыться → всегда [ создать клон себя · ждать 1.5 сек ]».

### 5. Что делает астероид-клон
Вторая программа: «когда я начинаю как клон → показаться → перейти в x:(случайное -220..220) y:180 → всегда [ изменить y на -4 · если касается Пуля → изменить очки на 1 · удалить этот клон · если касается Корабль → изменить жизни на -1 · удалить этот клон · если y < -180 → удалить этот клон ]».

### 6. Конец игры
У корабля добавь: «всегда [ если жизни = 0 → говорить Игра окончена! 2 → остановить всё ]».

### 7. ИГРАЙ! 🎮
Нажми флажок, летай стрелками, стреляй пробелом, сбивай астероиды!

### 8. Босс 👾 (по желанию)
Сделай большой астероид «Босс» с переменной «здоровье» (задать 5). «если касается Пуля → изменить здоровье на -1 · ждать 0.1». «если здоровье = 0 → изменить очки на 10 · спрятаться». Босса надо попасть пять раз!

### 9. Сохрани 💾
**Файл → Сохранить** → имя `космошутер`.

---
✅ Если корабль **летает и стреляет, астероиды падают, за сбитый — очко, а столкновение отнимает жизнь** — ты собрал космошутер и заслужил значок «Юный геймдев»! 🏆

# 🏠 Самоучитель — Урок 13: «Костюмы и анимация» (Scratch)

> Для дома или чтобы догнать класс. Делай по шагам — к каждому подсказка. Scratch: **scratch.mit.edu → «Создать»** (или Scratch Desktop). Всё **без звука** — только картинки и надписи!

### 1. Открой костюмы 👗
Вкладка **«Костюмы»** (вверху слева). У котика **костюм1** и **костюм2** — две позы. Покликай по ним, посмотри, как меняется лапа.
*Подсказка: костюм = кадр-поза.*

### 2. Шапочка и цикл 🟨🟧
Вкладка «Код»: «События» → **«когда ▶ нажат»**, под ней «Управление» → **«всегда»**.

### 3. Движение в цикл 🟦
«Движение» → **«идти 5 шагов»** ВНУТРЬ «всегда».

### 4. Смена костюма 🟪
«Внешний вид» → **«следующий костюм»** внутрь. Запусти — лапы замелькали.
*Подсказка: это и есть анимация.*

### 5. Пауза 🟧
«Управление» → **«ждать 0.2 секунды»** внутрь. Теперь шаг видно красиво.
*Подсказка: меньше число — быстрее лапы.*

### 6. Не застревать 🟦
«Движение» → **«если на краю, оттолкнуться»** внутрь. Герой ходит туда-сюда.

### 7. Нарисуй новый костюм ✏️
Вкладка «Костюмы» → правый клик → **«Дублировать»** → чуть измени позу кистью. Запусти — анимация плавнее.

### 8. Переодевалка 🎩
Сделай пару костюмов-нарядов (дублируй и раскрась). Скрипт: «События» → **«когда клавиша пробел нажата»** → **«следующий костюм»**. Жми пробел — герой переодевается!

### 9. Эмоции по клику 😃
Нарисуй лица (весёлый/грустный). Скрипт: **«когда этот спрайт нажат»** → **«следующий костюм»** → **«говорить Ого! 1 секунду»**.
*Подсказка: без колонок «голос» — это облачко с текстом.*

### 10. Сохрани 💾
**Файл → Сохранить** → имя `живой-герой`.

---
✅ Если герой **шагает лапами**, **переодевается** по пробелу и **меняет лицо** по клику — ты освоил костюмы и анимацию! На уроке повторим и добавим трюков.

# 🏠 Самоучитель — Урок 13: игра «Живой аквариум» (Scratch)

> Для дома или чтобы догнать класс. Делай по шагам — оживишь аквариум! Scratch: **scratch.mit.edu → «Создать»**. Язык — глобус 🌐 → Русский. Без звука — реакции надписями.

### 1. Костюмы рыбки 👗
Выбери спрайт **Fish** (🐱+ внизу). Вкладка **«Костюмы»** — у рыбки несколько поз (плавник по-разному). Покликай, вернись на **«Код»**.

### 2. Подводный фон 🌊
Панель «Сцена» → «Выбрать фон» → **Underwater**.

### 3. Рыбка плывёт 🟨🟧🟦
«События» → **«когда ▶ нажат»** → «Движение» → **«способ вращения влево-вправо»** → «Управление» → **«всегда»**, внутрь: «Движение» → **«идти 3 шага»** + **«если на краю, оттолкнуться»**. Флажок — рыбка плавает туда-сюда.

### 4. Машет плавником 🟪🟧
В «всегда» добавь «Внешний вид» → **«следующий костюм»** и «Управление» → **«ждать 0.2 секунды»**. Теперь рыбка машет плавником!
*Подсказка: без «ждать» плавник мерцает.*

### 5. Стайка 🐠🐠
Правый клик по рыбке → **«Дублировать»** 2–3 раза. Каждой копии поставь разную «ждать» — поплывут по-своему.

### 6. Акула за мышкой 🦈
Выбери спрайт **Shark**. Программа: «когда ▶ нажат» → «способ вращения ←→» → «всегда [ повернуться к (указатель мыши) + идти 5 + следующий костюм + ждать 0.1 ]». Води мышкой — акула плывёт за ней.

### 7. Ловля рыбки 🟩
В скрипт рыбки добавь ещё «всегда [ если <касается (Shark)?> то → говорить «Ой!» 0.5 сек → перейти в случайную позицию ]». Акула касается — рыбка удирает!

### 8. Сохрани 💾
**Файл → Сохранить** → имя `аквариум`.

---
✅ Если рыбки **плавают и машут плавниками**, а акула **охотится за мышкой** — ты оживил аквариум! На уроке повторим и сделаем стайку.

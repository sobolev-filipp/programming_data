# 🏠 Самоучитель — Урок 12: «Движение и повороты» (Scratch)

> Для дома или чтобы догнать класс. Делай по шагам — к каждому подсказка. Scratch: **scratch.mit.edu → «Создать»** (или Scratch Desktop). Соберёшь — котик начнёт рисовать!

### 1. Поставь шапочку 🟨
«События» → **«когда ▶ нажат»**.
*Подсказка: с неё начинается программа.*

### 2. Поворот направо 🔄
«Движение» → **«повернуть ↻ 90 градусов»** под шапочку. Жми флажок.
*Подсказка: котик повернётся на уголок.*

### 3. Поворот налево
Поменяй на **«повернуть ↺ 90»**. Жми.
*Подсказка: ↺ — против часовой, налево.*

### 4. Направление ➡️
«Движение» → **«повернуться в направление 90»** — котик смотрит вправо. Попробуй 0 (вверх), 180 (вниз), -90 (влево).
*Подсказка: 0 — это ВВЕРХ, не «никуда».*

### 5. Подключи перо 🖊
Слева внизу **«Добавить расширение»** → **«Перо»**.
*Подсказка: появится зелёная категория.*

### 6. Опусти перо и иди
«Перо» → **«опустить перо»**, потом «Движение» → **«идти 100 шагов»**. Флажок — есть след!
*Подсказка: перо = прижатый карандаш.*

### 7. Цвет следа 🌈
«Перо» → **«установить цвет пера»** → выбери цвет.
*Подсказка: клик по кружку с цветом.*

### 8. Очисти лист
«Перо» → **«очистить»** поставь в начало (под шапочку).
*Подсказка: стирает старые линии.*

### 9. Блок «повторить» 🔁
«Управление» → **«повторить 4»**.
*Подсказка: повторит ровно 4 раза.*

### 10. Собери квадрат ⬜
Внутрь «повторить 4»: **«идти 80 шагов»** + **«повернуть ↻ 90»**. Флажок — квадрат!
*Подсказка: оба блока ВНУТРИ рамки.*

### 11. Треугольник 🔺
Поменяй на «повторить 3» и «повернуть ↻ 120».
*Подсказка: меньше сторон — больше угол.*

### 12. Звезда ⭐
«повторить 5» и «повернуть ↻ 144».
*Подсказка: красиво!*

### 13. Сохрани 💾
**Файл → Сохранить** → имя `прогулка`.

---
✅ Если котик рисует **цветной квадрат** по программе — ты освоил повороты, направление и перо! На уроке повторим и нарисуем узоры.

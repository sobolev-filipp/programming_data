## 📺 Что делали на уроке

Мы открыли новую программу **Scratch** — в ней делают игры из **блоков-кирпичиков** (как LEGO, только из команд). Разобрали **4 зоны экрана**:
- 🧱 **Палитра блоков** — слева, цветные команды по категориям (🟦 Движение, 🟪 Внешний вид, 🟥 Звук, 🟨 События, 🟧 Управление);
- 🛠 **Область скриптов** — «верстак» по центру, где СОБИРАЕМ программу;
- 🎭 **Сцена** — «экран игры» справа вверху, где живёт герой;
- 🐱 **Список спрайтов** — справа внизу (герои проекта).

Главное, что поняли: **программа — это команды по порядку**, компьютер слушается буквально. Команды не работают сами — их надо **соединить в стопку** и запустить 🟢 **флажком** (🔴 — стоп). Начинается стопка с жёлтой **шапочки** «когда ▶ нажат».

Мы собрали котику **ДВЕ программы сразу**:
1. **Ходьба** — флажок → `способ вращения влево-вправо` → `всегда` ( `идти 5 шагов` + `если на краю, оттолкнуться` ). Котик сам гулял по сцене туда-сюда.
2. **Мяу по клику** — отдельная шапочка `когда спрайт нажат` → `играть звук Мяу` → `говорить`. По клику котик мяукал и говорил.

Ещё узнали: блок **«всегда»** (🟧) повторяет команды без конца; у одного героя может работать **несколько скриптов одновременно**; проект сохраняется в файл **`.sb3`**.

## 🐟 Твой проект: «Живая рыбка»

Сделаем не котика, а **рыбку, которая плавает по аквариуму** — те же навыки (флажок, «всегда», разворот у края, второй скрипт по клику), но другой герой и другая тема.

### Шаг 1. Смени героя на рыбку
1. Внизу справа **🐱+** («Выбрать спрайт») → найди **Fish** (рыбка) → клик.
2. Котика удали: правый клик по нему → «Удалить».

### Программа 1 — рыбка ПЛАВАЕТ
- 🟨 «События» → **«когда ▶ нажат»**.
- 🟦 «Движение» → **«установить способ вращения `влево-вправо`»** (чтобы рыбка не плыла вверх брюхом).
- 🟧 «Управление» → **«всегда»**, а внутрь:
  - 🟦 **«идти `4` шага»**;
  - 🟦 **«если на краю, оттолкнуться»**.
- Нажми 🟢 флажок — рыбка **плавает туда-сюда**!

### Программа 2 — пузырь по клику
- 🟨 «События» → **«когда этот спрайт нажат»** (на пустое место).
- 🟥 «Звук» → **«играть звук … до конца»** (выбери через 🔊 «Выбрать звук» что-то вроде *Bubbles*).
- 🟪 «Внешний вид» → **«говорить `Буль-буль!` `1` секунду»**.
- Запусти флажок и **кликни по рыбке** — она пустит пузырь и скажет «Буль!».

### Шаг 3. Аквариум и сохранение
- Панель «Сцена» → **«Выбрать фон»** → **Underwater** (под водой).
- **Файл → Сохранить** → имя `рыбка`.

# 🏠 Самоучитель — Урок 14: игра «Собери звёзды» (Scratch)

> Для дома или чтобы догнать класс. Делай по шагам — соберёшь игру с управлением! Scratch: **scratch.mit.edu → «Создать»**. Язык — глобус 🌐 → Русский. Без звука — реакции надписями.

### 1. Герой-ракета 🚀
Выбери спрайт **Rocketship** (🐱+ внизу). Сделай размер 60. Котика удали.

### 2. Управление вверх ⬆️
«События» → **«когда клавиша стрелка вверх нажата»** → «Движение» → **«изменить y на 10»**. Нажми ↑ — ракета прыгнула вверх!

### 3. Все 4 стрелки
Сделай ещё 3 такие стопки:
- ↓ → «изменить y на -10»
- → → «изменить x на 10»
- ← → «изменить x на -10»
Теперь ракета ездит во все стороны!
*Подсказка: y — вверх/вниз, x — влево/вправо.*

### 4. Звезда-непоседа ⭐
Выбери спрайт **Star**. Скрипт: «когда ▶ нажат» → «всегда» → «перейти в случайную позицию» + «ждать 2 секунды». Звезда прыгает по сцене.

### 5. Собрать звезду 🎣
У звезды ещё скрипт: «когда ▶ нажат» → «всегда» → «если <касается (Rocketship)?> то» → «говорить +1! 0.3 сек» + «перейти в случайную позицию».

### 6. ИГРАЙ! 🎮
Нажми флажок, веди ракету стрелками, собирай звёзды!

### 7. Опасность-шип 🔺 (по желанию)
Добавь спрайт-шип: «всегда [перейти в случайную позицию + ждать 3]». У ракеты ещё скрипт: «всегда [если <касается (Шип)?> то → говорить Ой! + перейти в x:0 y:0]».

### 8. Сложнее ⚡
Поставь «изменить на 15» — ракета быстрее. «ждать 1» у звезды — прыгает чаще.

### 9. Сохрани 💾
**Файл → Сохранить** → имя `собери-звёзды`.

---
✅ Если ракета **слушается стрелок и собирает звёзды** — ты сделал игру с управлением! На уроке повторим и добавим шип.

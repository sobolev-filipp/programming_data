# Урок 02 (глобальный №20) — Условия и взаимодействия в Kodu

**Модуль 5. Трёхмерные игры в Kodu.** Главный проект: **«Яблочный патруль»**. 1,5 академического часа (≈67 минут).

## С чего начать

Преподавателю: сначала прочитайте `преподавателю.md` и `theory.md`, затем откройте `презентация.html` (офлайн). До урока проверьте карточки в установленном Kodu. Самостоятельная работа находится в `практика.md`, догоняющая — `доп-задание.md`.

**Примечание:** этот урок использует идеи из К. И. Астаховой, *Создаём игры с Kodu Game Lab* (2019), тема 2, §2.1. Текст и интерактивные материалы выполнены заново. Названия карточек могут различаться по версиям Kodu; рисунки — не скриншоты программы.


## Расширение v3 — несколько совместных проектов

В `theory.md` добавлены отдельные мини-проекты и пошаговое программирование. Расширенный сценарий можно провести **в два занятия по 67 минут**; исходный базовый урок сохранён. Практика дополнена независимыми заданиями, а не повторением общего проекта. См. дополнительные схемы в папке `изображения/`.

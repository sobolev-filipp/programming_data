# Самоучитель — девять маленьких шагов

Открывай Kodu и выполняй по одному заданию. Не спеши.

1. **Новый мир.** New World → пустая площадка. Найди нижнюю панель.
2. **Камера.** Рука → ЛКМ тяни, ПКМ поворачивай, колесо приближает. [Картинка](изображения/камера.svg).
3. **Земля.** Ground Brush → зелёный материал → ЛКМ по краю. Сделай маленький выступ. ПКМ убирает землю.
4. **Тропинка.** Выбери другой материал и маленькую кисть. Проведи по готовой земле.
5. **Холм и яма.** Up/Down → ЛКМ поднимает, ПКМ опускает. [Картинка](изображения/инструменты.svg).
6. **Вода и предмет.** Water Tool → ЛКМ на дне низины. Object Tool → клик по пустой земле → дерево или Kodu.
7. **Настройки героя.** Наведи на Kodu, стрелками поменяй цвет. ПКМ → Изменить размер. Попробуй сделать второго героя меньше. [Схема](изображения/персонажи.svg).
8. **Программа.** ПКМ по Kodu → Программа. Плюс КОГДА → Клавиши → Стрелки; плюс ДЕЛАТЬ → Двигаться. Esc → Play. Проверь стрелки. Для второго героя: Всегда → Двигаться → Свободно. [Схема](изображения/схема-движение.svg).
9. **Сохранение.** Home → Save My World. Назови свой мир. Покажи его с двух сторон.

Если всё получилось, переходи к [Лунной базе](практика.md).

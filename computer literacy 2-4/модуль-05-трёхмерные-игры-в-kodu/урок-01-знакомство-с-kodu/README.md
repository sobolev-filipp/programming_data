# Урок 19 — Остров приключений

Модуль 5 «Трёхмерные игры в Kodu — 1», урок 1 из 6. Основное занятие ≈67 минут. Открывай HTML двойным щелчком в браузере; все ресурсы локальные. Для проекта необходим установленный Kodu Game Lab на Windows. Файлы Markdown удобно читать в VS Code с предпросмотром.

- [Теория](theory.md) — подробный сценарий.
- [Преподавателю](преподавателю.md) — подготовка, минуты, ошибки, звёзды.
- [Презентация](презентация.html), [игра](игра.html), [викторина](викторина.html), [тренажёр](тренажёр.html).
- [Практика](практика.md), [самоучитель](самоучитель.md), [догоняющий урок](доп-задание.md), [повторение](повторение.md), [лайфхаки](лайфхак.md).
- [Изображения](изображения.md), [промпты](промпты-картинок.md).

Сохраняй всю папку вместе. Иллюстрации — авторские SVG-референсы, а не скриншоты Kodu. В архиве нет установщика Kodu и готового мира .kodu: дети создают мир самостоятельно. На этом уроке уже вводим правило «когда — делай», управление стрелками и свободное движение. Следующее занятие — углубление правил и взаимодействие объектов. Практика состоит из нескольких отдельных проектов.


## Расширение v3 — несколько совместных проектов

В `theory.md` добавлены отдельные мини-проекты и пошаговое программирование. Расширенный сценарий можно провести **в два занятия по 67 минут**; исходный базовый урок сохранён. Практика дополнена независимыми заданиями, а не повторением общего проекта. См. дополнительные схемы в папке `изображения/`.

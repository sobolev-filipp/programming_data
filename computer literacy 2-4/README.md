# 🧸 Компьютерная грамотность для малышей (2–4 классы)

Курс цифровой грамотности и творчества для детей **7–10 лет**, **у которых нет опыта работы за компьютером**. Объём — **108 ак.ч.** · **1 урок = 1.5 ак.ч.** (≈1 час 7 мин) · всего **72 урока**.

> **Философия курса:** _меньше слов — больше показа, игры и «попробуй сам»._ С первого урока ребёнок **что-то создаёт и уносит результат** (рисунок, игру, анимацию), чтобы было чем поделиться дома. Теорию (устройство ПК, файлы, интернет, безопасность) даём **маленькими кусочками вперемешку с активностью**, а не сухими блоками. **Оценок нет — есть рейтинг в ⭐ звёздах** за старание и активность.

## 🤖 Наш помощник — робот Бип

Через весь курс детей ведёт дружелюбный робот-маскот **Бип** (жёлто-голубой, с большими глазами-экранами). Он «объясняет» на слайдах, шутит, хвалит и раздаёт ⭐. Бип — один и тот же во всех презентациях и видео, чтобы дети его узнавали и любили.

## 📁 Как устроен урок

Каждый урок — папка `урок-YY-…/` с одинаковым набором файлов:

| Файл | Для кого | Что внутри |
|------|----------|------------|
| `презентация.html` | **экран урока** | главный носитель: крупные картинки, 1 мысль/слайд, Бип ведёт. Офлайн. |
| `theory.md` 🔒 | учитель | сценарий урока «что сказать / что показать / дать попробовать» |
| `повторение.md` | учитель | разминка-повтор в начале (5 мин) |
| `практика.md` | дети | задание «сделай сам» + образец результата |
| `самоучитель.md` | догоняющие/дома | 5–8 мини-заданий «повтори за картинкой» |
| `лайфхак.md` | все | 1–2 простых секрета по теме |
| `преподавателю.md` 🔒 | учитель | хронометраж на 1.5 ак.ч. + физминутки + **блок «⭐ Баллы за урок»** |
| `изображения.md` 🔒 | учитель | что показать на проекторе, промпты, где взять картинки |
| `викторина.html` | экран урока | 10–12 вопросов, 2–3 варианта, с картинками, читает учитель |
| `игра.html` (по необходимости) | экран урока | встроенная мини-игра/интерактив для закрепления темы, офлайн |
| `изображения/` | — | картинки, маскот, QR |

> 🔒 — файл зашифрован git-crypt (учительский). Открытые файлы видят все.

## 🛠 Инструменты курса (бесплатные, работают в РФ без VPN)

🖌 **Tux Paint** · 🟦 **Piskel** · 🧊 **BlockBench** · 🎬 **Krita** · 🎞 **Wick Editor** · ✏️ **Inkscape** · 🖼 **Photopea** · 🎨 **Canva** · 🧩 **Code.org / ПиктоМир** · 🎮 **Scratch** · 🌍 **Kodu** · 📄 **Google Документы/Презентации** · ⌨️ тренажёр печати. Интерфейс — русский.

> 🤖 **ИИ с детьми:** картинки — бесплатные сервисы **без регистрации** (draw.freeforai.com, pixova.io, creen.ai, vidmud.com, krea.ai — проверять перед уроком); информацию и идеи спрашиваем у **Алисы** и **GigaChat**. Генерирует/показывает учитель, дети придумывают запрос.

> 🧰 **Полезное помимо программ:** LearningApps/Wordwall (тренажёры), Excalidraw (онлайн-доска), QR-коды, скринкаст (Win+G), Google Формы, цифровая безопасность.

> ⚙️ **Установка:** Tux Paint, BlockBench, Krita, Inkscape, Kodu — ставятся на ПК. Остальное — в браузере. Стоп-моушн не берём (нет камеры) — анимацию делаем в Krita/Wick/Piskel.

> 🎬 **Видео для уроков** (правила, устройство ПК, интернет) учитель создаёт заранее (напр. Animaker/Vyond + ElevenLabs). На уроке с детьми используем только российские сервисы.

## ⭐ Главное про оценки

**Оценок в курсе нет.** Есть **рейтинг в ⭐ звёздах**: копим за старание и активность, **только начисляем — никогда не отнимаем**. В конце каждого модуля — «Звёздный финиш» с номинациями и маленькими призами (значки, наклейки, дипломы). Подробно — в [РЕЙТИНГ.md](РЕЙТИНГ.md).

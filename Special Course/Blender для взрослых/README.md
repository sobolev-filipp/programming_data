# 🖨️ Blender для взрослых — моделирование под 3D-печать

**Для взрослого ученика · 16 уроков по 1 часу · Blender 4.1**

---

## О курсе

Прикладной курс Blender с одной чёткой целью — **научиться моделировать вещи и готовить их к 3D-печати**. Без лишней теории: с первого урока ученик сразу работает в Edit Mode и делает реальные печатаемые детали.

Сквозные принципы всего курса:
- **Точные размеры в миллиметрах** — задаём числом, а не на глаз, с самого первого объекта.
- **Печатаемость** — модель это оболочка с толщиной и дном, без дыр (watertight), с плоским основанием.
- **Теория через практику** — на уроке постоянно что-то делаем; каждый урок = новый осязаемый объект.
- **Разнообразие** — объекты не повторяются: на уроке одно, в практике другое, дома третье.

> ⚙️ **Технология печати уточняется.** Правила даём универсальные, с упором на **FDM** (пластик PLA/PETG) и оговорками по фотополимерной (смоляной) печати. Когда станок определится — числа (толщина стенок, ориентация, дренаж) скорректируем.

## Как устроен каждый урок

Папка урока содержит 5 файлов:

| Файл | Для кого | Содержание |
|------|----------|------------|
| `theory.md` | ученик + учитель | теория + **главная сборка** урока (учимся на ходу); лайфхаки и разбор ошибок встроены |
| `практика.md` | ученик | доп. задание **на уроке** — другой объект, та же техника |
| `домашнее-задание.md` | ученик | задание **дома**, расписано подробно + подсказки |
| `преподавателю.md` | **только учитель** | сценарий урока: хронометраж, частые ошибки, контрольные точки |
| `изображения.md` | **только учитель** | промпты и описания картинок (референсы, инфографики) |

Картинки — в подпапке `изображения/`.

> 🔐 **Учительские файлы зашифрованы** (git-crypt): `theory.md`, `преподавателю.md`, `изображения.md`. Ученические (`практика.md`, `домашнее-задание.md`) — открытые. Подробности — в [HANDOFF.md](HANDOFF.md) и в корневой инструкции репозитория.

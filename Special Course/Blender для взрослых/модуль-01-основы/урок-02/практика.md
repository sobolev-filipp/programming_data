# Практика на уроке — Урок 2: круглая печать-монограмма

> 🧑‍🏫 Делаем **вместе на уроке**, сразу после штампа со словом. Объект **другой** — круглая **печать с монограммой** (твои инициалы, 2–3 буквы) в ободке. Закрепляем Text + зеркалирование + Join, но на круге и с коротким текстом. Подсказок меньше — приём знаком.

## Задача

Сделать **круглую печать** Ø60 мм с инициалами в приподнятом ободке. Текст — зеркальный (это печать!).

- Диаметр **60 мм**, толщина **12 мм**
- По краю — приподнятый **ободок** (Inset/Extrude)
- В центре — **монограмма** (2–3 буквы), выпуклая и **зеркальная**

![Референс: печать-монограмма](изображения/референс-печать-монограмма.png)

*Круглая печать с ободком и зеркальными инициалами. На самой печати буквы «наоборот» — на оттиске правильные.*

## Шаги

1. `Shift + A → Mesh → Cylinder` → **`F9` Vertices 48** → `N` Dimensions Ø **60 × 60 × 12** → `Ctrl + A → Scale`.
2. Ободок: `Tab` → `3` → верхняя грань → `I 5` → `E Z 1.5` (приподняли кольцо по краю) → `Tab`. (Можно наоборот: `E -1.5` — утопить центр. Любой вариант.)
3. `Shift + A → Text` → `Tab` → стереть, набрать **инициалы** (напр. «АФ») → `Tab`.
4. Зелёная **`a`**: Paragraph → Center; Font → жирный; Geometry → **Extrude 3**, **Bevel 0.3**.
5. `N` → Dimensions под центр печати → `Ctrl + A → Scale`.
6. **Зеркалим:** `S` → `X` → `-1` → `Enter` → `Ctrl + A → Scale`.
7. Поставь монограмму в центр лица (`Numpad 7` → `G`; `Numpad 1` → `G Z` на уровень лица) → `Object → Convert → Mesh`.
8. *(По желанию)* ручка сзади (Cylinder-кнопка) + `Ctrl + J`. Цвет, `Z`.

   ✅ *Должно получиться:* круглая печать с ободком и зеркальными инициалами.

## Проверь себя

- [ ] Инициалы **зеркальные** (`S X −1`) — на печати «наоборот»
- [ ] Текст **сконвертирован** в меш
- [ ] Vertices задал через `F9` (круг гладкий)
- [ ] Шрифт жирный, буквы не тонкие
- [ ] Scale применён (и у цилиндра, и у текста до Convert)

## Если успел — усложни

- Добавь по ободку мелкий узор-насечку (`I` поменьше + `E Z`) — печать «посолиднее».
- Сделай оттиск-проверку: рядом поставь **копию монограммы без зеркала** (`Shift + D` до зеркаления) — сравни, как читается «правильная» сторона.

# Практика на уроке — Урок 2: дверная табличка

> 🧑‍🏫 Делаем **вместе на уроке**, сразу после именной таблички и номера дома. Объект **другой** — маленькая **дверная табличка** с коротким словом (например «КАБИНЕТ», «WC», имя комнаты). Закрепляем объект Text + Extrude + Convert. Подсказок меньше — приём уже знаком.

## Задача

Сделать **дверную табличку** 90×40×8 мм с приподнятым коротким словом и скруглёнными углами.

- Габарит **90 × 40 × 8 мм**
- Углы скруглены (Bevel по вертикальным рёбрам, как у бирки с урока 1)
- Слово приподнято на **2,5 мм** (выпуклый текст), шрифт жирный рубленый

![Референс: дверная табличка](изображения/референс-дверная-табличка.png)

*Небольшая табличка на дверь с выпуклым словом и скруглёнными углами.*

## Шаги

1. `Shift + A → Mesh → Cube` → `N` → Dimensions **90 × 40 × 8** → `Ctrl + A → Scale`.
2. Скругли углы: `Tab` → `2` → `Alt+ЛКМ` + `Shift+Alt+ЛКМ` по 4 вертикальным рёбрам → `Ctrl + B` → `5`, 3 сегмента → `ЛКМ` → `Tab`.
3. `Shift + A → Text` → `Tab` → стереть, набрать слово → `Tab`.
4. Зелёная **`a`** → Paragraph → **Center**; Geometry → **Extrude 2.5**, **Bevel 0.3**. Выбери жирный шрифт (Font → Regular → загрузи .ttf жирного рубленого, если есть).
5. `N` → Dimensions по длине таблички (слово не впритык к краям) → `Ctrl + A → Scale`.
6. Поставь слово на поверхность и по центру: `Numpad 7` → `G`; `Numpad 1` → `G Z` на верх плашки.
7. `Object → Convert → Mesh`. По желанию — цвет, `Z`.

   ✅ *Должно получиться:* аккуратная дверная табличка с выпуклым читаемым словом.

## Проверь себя

- [ ] Текст **сконвертирован** в меш (`Convert`) — не остался текст-объектом
- [ ] Шрифт **жирный**, буквы не тонкие (переживут фрезу)
- [ ] Буквы приподняты на 2,5 мм, стоят на поверхности
- [ ] Углы скруглены (Bevel с сегментами)
- [ ] Scale применён, габарит 90×40×8

## Если успел — усложни

- Добавь под словом тонкую **линию-подчёркивание** (узкий Cube-выступ) или маленькую **пиктограмму** (стрелку из текста-символа, напр. «→»).
- Сделай вторую табличку с тем же словом, но **гравировкой-наброском**: оставь текст **кривой** (`Object → Convert → Curve` вместо Mesh) — это заготовка контура под V-гравировку/лазер. Сравни с выпуклой. (Подробно — урок 5.)

> 📚 Про привязки для точной посадки текста — [«Точность»](../../../../Blender/справочники/глубокое-погружение/точность.md).

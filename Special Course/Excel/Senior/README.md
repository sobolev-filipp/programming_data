# Курс «Microsoft Excel для работы: с нуля до профессионала»

Курс для **взрослого человека**, который хочет освоить Excel не «по верхам», а **профессионально** — для реальной работы: отчёты, аналитика, автоматизация.

- **Формат:** 14 уроков по **60 минут**.
- **Версия:** Microsoft 365 / Excel 2021, **русский интерфейс**. Функции — по-русски, в скобках английский аналог (`ВПР` (VLOOKUP)).
- **Подход:** каждый урок — вокруг рабочей задачи, много практики, домашние задания с разбором.

## Быстрый старт для преподавателя

1. Прочитайте [PLAN.md](PLAN.md) — программа целиком.
2. Прочитайте [СЦЕНАРИЙ-КУРСА.md](СЦЕНАРИЙ-КУРСА.md) — **сквозная история курса**: ученик играет роль аналитика, каждый урок — задача «от руководителя» с осязаемым результатом. Это делает курс не набором формул, а реальной работой.
3. Прочитайте [METHODOLOGY.md](METHODOLOGY.md) — принципы обучения **взрослого** (это важно: подход отличается от обучения детей).
3. Проверьте [TECH_REQUIREMENTS.md](TECH_REQUIREMENTS.md) — техника и файлы-заготовки.
4. К каждому уроку открывайте папку и читайте `lesson.md` — это «дирижёр» занятия.
5. После урока выдавайте ученику `summary.md` и напоминайте про `homework.md`.
6. Держите под рукой [справочник/](справочник/) — на любом уроке можно сослаться на горячие клавиши и лайфхаки.

## Принципы курса

- **Всё от рабочей задачи.** Не «вот функция ЕСЛИ», а «нам нужно проставить статус ‘просрочено/в срок’ — сделаем это функцией ЕСЛИ».
- **Руки на клавиатуре.** С первого урока приучаем к горячим клавишам — это главное отличие профессионала.
- **Понимание, а не заучивание.** Объясняем, *почему* формула работает и *почему* ломается (особенно `$` и типы данных).
- **Реальные «грязные» данные.** Учимся на выгрузках с ошибками, пробелами, «текстовыми» числами — как в жизни.
- **Уважение к опыту взрослого.** Человек уже что-то умеет — опираемся на это, не начинаем с «это кнопка мыши».

# Словарь терминов курса

> Короткие определения понятий, которые встречаются в курсе. Если где-то забыли слово — загляните сюда.

---

## Базовые понятия

- **Книга** — файл Excel (`.xlsx` / `.xlsm`). Содержит листы.
- **Лист** — одна «страница» книги с таблицей.
- **Ячейка** — клетка на пересечении столбца и строки; адрес вида `B2`.
- **Диапазон** — прямоугольник ячеек, `A1:C10` («от … до»).
- **Строка формул** — поле над таблицей; показывает **реальное** содержимое ячейки (формулу, а не результат).
- **Поле имени** — слева от строки формул; адрес активной ячейки; можно вписать адрес и прыгнуть.

## Данные

- **Тип данных** — число / текст / дата / логическое. Определяет, что можно с ячейкой делать. Число вправо, текст влево, дата = число.
- **Текстовое число** — число, записанное как текст (прижато влево, не суммируется). Лечится (ур. 1, 6).
- **Плоская таблица** — данные, где одна строка = один факт, один столбец = один признак, без пустот и объединений. Основа сводных.
- **«Умная» таблица** — диапазон, превращённый в объект «Таблица» (`Ctrl`+`T`): фильтры, итоги, авто-рост.
- **Структурированная ссылка** — ссылка по имени столбца умной таблицы: `[@Цена]`, `Продажи[Сумма]`.

## Формулы

- **Формула** — вычисление, начинается с `=`.
- **Ссылка** — адрес ячейки в формуле (`B2`). Делает таблицу «живой».
- **Относительная / абсолютная / смешанная ссылка** — `B2` (едет при копировании) / `$B$2` (не едет) / `A$1`, `$A1` (частично). Переключает клавиша `F4`.
- **Функция** — готовая операция с именем: `СУММ(...)`, `ВПР(...)`.
- **Аргументы** — то, что передаём функции в скобках, через `;`.
- **Имя диапазона** — понятное имя ячейки/диапазона (`Курс`) вместо адреса.
- **Массив / динамический массив** — формула, возвращающая несколько значений (`УНИК`, `ФИЛЬТР`), «разливается» на соседние ячейки.

## Поиск и логика

- **Ключ поиска** — значение, по которому сопоставляют таблицы (например, «Товар»).
- **Точное совпадение** — режим `0`/`ЛОЖЬ` в `ВПР`; ищет ровно то же значение.
- **`#Н/Д`** — «не найдено»; чаще всего из-за пробелов или разных типов.
- **Условие** — критерий в `ЕСЛИ`/`СУММЕСЛИ` (`">100"`, `"Москва"`, `"*ноут*"`).
- **Подстановочные знаки** — `*` (любой текст), `?` (один символ) в условиях/поиске.

## Анализ

- **Сводная таблица (PivotTable)** — инструмент, сворачивающий данные в отчёт «сколько по каждому…» перетаскиванием полей.
- **Область (сводной)** — Строки / Столбцы / Значения / Фильтры.
- **Кэш сводной** — «снимок» данных; поэтому сводную надо **«Обновить»** после изменения источника.
- **Срез (Slicer)** — панель-кнопки для фильтрации таблицы/сводной.
- **Временная шкала (Timeline)** — срез для дат.
- **KPI** — ключевой показатель (выручка, средний чек, % плана).
- **План-факт** — сравнение фактического результата с планом (`Факт/План` = % выполнения).
- **Дашборд** — одностраничный визуальный отчёт с KPI, графиками и срезами.

## Визуализация

- **Ряд данных** — набор значений на графике (столбцы/линия).
- **Ось значений / категорий** — вертикальная (Y, числа) / горизонтальная (X, подписи).
- **Вторая (вспомогательная) ось** — для второй величины другого масштаба (₽ и %).
- **Комбо-диаграмма** — разные типы в одном графике (столбцы + линия).
- **Спарклайн** — мини-график внутри ячейки.

## Автоматизация

- **Power Query** — инструмент подключения и преобразования данных «шагами», с обновлением одной кнопкой.
- **Шаг (PQ)** — одно записанное преобразование в «Применённых шагах».
- **Append / Merge** — дописать строки / подтянуть столбцы по ключу.
- **Макрос** — записанная последовательность действий, повторяемая кнопкой.
- **VBA** — язык, на котором записаны макросы.
- **VBE** — редактор кода VBA (`Alt`+`F11`).
- **`.xlsm`** — формат книги с поддержкой макросов (обычный `.xlsx` их не хранит).

## Прочее

- **Подбор параметра (What-If / Goal Seek)** — обратный расчёт: какой вход даст нужный результат.
- **Условное форматирование** — авто-подсветка ячеек по правилу.
- **Проверка данных** — ограничение ввода (списки, диапазоны).
- **Локаль / разделитель** — в русском Excel аргументы через `;`, в английском `,`.

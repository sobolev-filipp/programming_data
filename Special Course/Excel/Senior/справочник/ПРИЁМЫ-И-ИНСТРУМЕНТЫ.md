# Приёмы и инструменты Excel (не-формульные)

> Всё, что в курсе делается **не формулами**, а инструментами и меню: что это, как включить, в каком уроке разбираем. Держите рядом со [шпаргалкой функций](ШПАРГАЛКА-ФУНКЦИЙ.md).

---

## Данные: ввод, чистка, структура

| Инструмент | Что делает / зачем | Как вызвать | Урок |
|------------|--------------------|-------------|-----:|
| **Типы данных** (число/текст/дата) | понять, почему «не считается»; число слева = текст | смотреть выравнивание; `Ctrl`+`Shift`+`~` для проверки | 1 |
| **Специальная вставка** | вставить только значения / транспонировать / умножить | `Ctrl`+`Alt`+`V` | 1 |
| **Текст по столбцам** | разбить столбец по разделителю; чинить текст-числа/даты | Данные → «Текст по столбцам» | 1, 6 |
| **Мгновенное заполнение** (Flash Fill) | заполнить по образцу без формул | `Ctrl`+`E` | 6 |
| **Найти и заменить** | массовая замена по листу/книге | `Ctrl`+`F` / `Ctrl`+`H` | 6 |
| **Удалить дубликаты** | убрать повторы (необратимо — на копии!) | Данные → «Удалить дубликаты» | 8 |
| **Проверка данных** | выпадающие списки, ограничения ввода | Данные → «Проверка данных» | 8 |
| **Пользовательские списки** | своё автозаполнение (филиалы, отделы) | Параметры → Дополнительно → «Изменить списки» | 1 |

## Оформление и представление

| Инструмент | Что делает | Как вызвать | Урок |
|------------|-----------|-------------|-----:|
| **Числовой/пользовательский формат** | вид числа без изменения значения («1 500 ₽», «5 шт.») | `Ctrl`+`1` → «(все форматы)» | 3 |
| **«Умная» таблица** | фильтры, итоги, авто-формулы, авто-рост диапазона | `Ctrl`+`T` | 3 |
| **Условное форматирование** | подсветка по правилу (шкалы, значки, формула) | Главная → «Условное форматирование» | 3 |
| **Формат по образцу** | перенести оформление «кисточкой» | Главная → кисточка (двойной клик — залипает) | 3 |
| **Закрепить/Разделить окно** | шапка не уезжает; сравнить части | Вид → «Закрепить области» / «Разделить» | 1 |
| **Печать** | вписать в 1 страницу, сквозная шапка, колонтитулы | `Ctrl`+`P`; «Разметка страницы» | 3 |
| **Защита листа** | запретить случайные правки | Рецензирование → «Защитить лист» | 14 |

## Анализ

| Инструмент | Что делает | Как вызвать | Урок |
|------------|-----------|-------------|-----:|
| **Сортировка (многоуровневая)** | упорядочить по нескольким столбцам | Данные → «Сортировка» | 8 |
| **Фильтр / расширенный фильтр** | показать нужное; извлечь уникальные | `Ctrl`+`Shift`+`L`; Данные → «Дополнительно» | 8 |
| **Срезы (Slicers)** | фильтры-кнопки для таблиц и сводных | «Конструктор» / «Анализ» → «Вставить срез» | 8, 10 |
| **Временная шкала** | ползунок-фильтр по датам для сводной | «Анализ» → «Вставить временную шкалу» | 10 |
| **Промежуточные итоги** | итоги по группам + структура сворачивания | Данные → «Промежуточный итог» | 9 |
| **Сводная таблица** | свернуть тысячи строк в отчёт мышью | Вставка → «Сводная таблица» | 9, 10 |
| **Вычисляемое поле** | своя формула внутри сводной | «Анализ» → «Поля, элементы и наборы» | 10 |
| **Модель данных / связи** | соединить таблицы по ключу без ВПР | галочка «Добавить в модель…»; Данные → «Отношения» | 10 |
| **Диаграммы** | визуализация; правильный тип под задачу | `Alt`+`F1` / `F11`; Вставка → диаграмма | 11 |
| **Комбо-диаграмма / вторая ось** | две величины разного масштаба (₽ и %) | Вставка → «Комбинированная диаграмма» | 11 |
| **Спарклайны** | мини-график в ячейке | Вставка → «Спарклайны» | 11 |
| **Подбор параметра** (What-If) | обратный расчёт: какой вход даст нужный результат | Данные → «Анализ ‘что если’» | 14 |

## Автоматизация

| Инструмент | Что делает | Как вызвать | Урок |
|------------|-----------|-------------|-----:|
| **Power Query** | подключить, очистить, объединить данные шагами; обновление кнопкой | Данные → «Получить данные» | 12 |
| **Импорт из папки** (PQ) | собрать много файлов в одну таблицу | «Получить данные» → «Из файла» → «Из папки» | 12 |
| **Merge / Append** (PQ) | подтянуть столбцы по ключу / дописать строки | «Объединить запросы» / «Добавить запросы» | 12 |
| **Макрос (запись)** | повторить действия одной кнопкой | Разработчик → «Запись макроса» | 13 |
| **Редактор VBA (VBE)** | читать/править код макроса | `Alt`+`F11` | 13 |
| **Кнопка для макроса** | запуск макроса кликом | Разработчик → «Вставить» → «Кнопка» | 13 |

## Быстрая навигация «хочу сделать X»

- **Убрать лишние пробелы, из-за которых ВПР не находит** → `СЖПРОБЕЛЫ` (ур. 6) или «Обрезать» в Power Query (ур. 12).
- **Подтянуть данные из другой таблицы** → `ВПР`/`ПРОСМОТРX` (ур. 5) или Merge в PQ (ур. 12).
- **Отчёт «сколько по каждому…»** → сводная (ур. 9) или `СУММЕСЛИМН` (ур. 4).
- **Каждый месяц новый файл** → Power Query «Из папки» (ур. 12).
- **Сравнить факт с планом** → сводная + `ВПР` из `Планы.xlsx` (ур. 10).
- **Один экран для руководителя** → дашборд: сводные + диаграммы + срезы (ур. 14).
- **Повторяю одни и те же клики** → записать макрос (ур. 13).

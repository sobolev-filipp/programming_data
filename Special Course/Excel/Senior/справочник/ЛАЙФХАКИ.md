# Лайфхаки Excel — приёмы профессионала

> Трюки, которые экономят часы. Разбиты по темам. Пробуйте по одному — и они станут привычкой.

---

## Скорость и навигация

**1. Двойной клик по маркеру автозаполнения.**
Написали формулу в первой ячейке столбца рядом с таблицей? Наведите на правый нижний угол (чёрный крестик `+`) и **дважды кликните** — формула сама заполнится вниз до конца соседних данных. Не нужно тянуть мышью до 10000-й строки.

**2. Двойной клик по границе столбца.**
Дважды кликните по правой границе заголовка столбца — ширина подстроится под содержимое (автоподбор). Выделите несколько столбцов — подстроятся все сразу.

**3. Прыжки по данным `Ctrl` + стрелка.**
Вместо прокрутки колёсиком на тысячи строк — `Ctrl` + `↓` мгновенно переносит в конец данных. `Ctrl` + `Shift` + `↓` — ещё и выделит по пути.

**4. Быстрое перемещение блока данных.**
Выделите диапазон, наведите на его границу (курсор-стрелка), зажмите и перетащите. С зажатым `Ctrl` — скопируется. С `Shift` — вставится между другими данными, раздвинув их.

**5. `Ctrl` + `Enter` вместо протягивания.**
Выделите сразу все нужные ячейки, впишите формулу/значение и нажмите `Ctrl` + `Enter` — заполнятся все разом.

## Ввод данных

**6. Одинаковое значение в много ячеек.**
Выделите ячейки (даже несмежные, через `Ctrl`), введите значение, `Ctrl` + `Enter`.

**7. Умное автозаполнение рядов.**
Напишите `Янв`, потяните маркер — получите `Фев`, `Мар`… То же с датами, днями недели, «Квартал 1», «Отдел 1». Введите `1` и `2` в двух ячейках, выделите обе, потяните — пойдёт арифметическая прогрессия.

**8. Мгновенное заполнение (Flash Fill), `Ctrl` + `E`.**
Есть колонка «Иванов Иван Иванович». В соседней напишите вручную «Иванов И.И.» для первой строки и нажмите `Ctrl` + `E` — Excel **распознает шаблон** и заполнит остальное. Работает для извлечения, склейки, перестановки текста без единой формулы.

**9. Перенос строки внутри ячейки — `Alt` + `Enter`.**
Не тяните колонку, чтобы уместить длинный текст в две строки — просто `Alt` + `Enter` в нужном месте.

**10. Быстрый ввод даты/времени.**
`Ctrl` + `;` — сегодня. `Ctrl` + `Shift` + `;` — сейчас. Это **статичные** значения (не пересчитываются), в отличие от `=СЕГОДНЯ()`.

## Формулы

**11. `F4` — лучший друг ссылок.**
При вводе формулы нажимайте `F4` на ссылке, чтобы переключать `A1` → `$A$1` → `A$1` → `$A1`. Без этого формулы «съезжают» при копировании.

**12. `F9` — вычислить кусок формулы.**
В строке формул выделите часть выражения и нажмите `F9` — Excel покажет, чему она равна. Отлично для отладки длинных формул. (Не забудьте `Esc`, чтобы не заменить формулу числом.)

**13. `Ctrl` + `` ` `` — показать все формулы.**
Разом видно, где формулы, а где вбитые вручную числа. Полезно при проверке чужого файла.

**14. `ЕСЛИОШИБКА` вместо страшных `#Н/Д`.**
Оберните поиск: `=ЕСЛИОШИБКА(ВПР(...); "не найдено")` — вместо ошибок будет аккуратный текст.

**15. Автосумма `Alt` + `=`.**
Встаньте под столбцом чисел, `Alt` + `=`, `Enter`. Выделите сразу и строки, и столбцы с пустой «каёмкой» — просуммирует всё разом.

**16. Именованные диапазоны.**
Выделите диапазон, в «Поле имени» (слева от строки формул) впишите `Курс` и `Enter`. Теперь в формулах можно писать `=B2*Курс` вместо `=B2*$F$1`. Формулы читаются как предложения.

## Очистка «грязных» данных

**17. `СЖПРОБЕЛЫ` (TRIM) против лишних пробелов.**
Выгрузки часто приходят с пробелами в начале/конце — из-за них `ВПР` не находит совпадений. `=СЖПРОБЕЛЫ(A2)` убирает лишнее.

**18. «Текстовые» числа.**
Число слева в ячейке и зелёный уголок = это **текст**, а не число, оно не суммируется. Быстрый фикс: выделить → значок с ошибкой → «Преобразовать в число». Или умножить на 1 / прибавить 0 формулой.

**19. Удаление дубликатов.**
Данные → «Удалить дубликаты». Перед этим сделайте копию — операция необратима.

**20. «Текст по столбцам».**
Данные → «Текст по столбцам» — разбивает «Иванов;Иван» на две колонки по разделителю. Ещё это лечит «неправильные» даты и текстовые числа (проходим «Далее-Далее-Готово»).

## Форматирование и вид

**21. Формат по образцу (кисточка).**
Кнопка-кисточка на «Главной»: кликните на красиво оформленную ячейку, потом на кисточку, затем «покрасьте» другие. **Двойной** клик по кисточке — режим фиксируется для нескольких применений.

**22. «Умная» таблица `Ctrl` + `T`.**
Превращает диапазон в таблицу: авто-фильтры, чередование строк, формулы копируются сами, диапазон растёт автоматически. В формулах — понятные имена столбцов вместо `B2:B999`.

**23. Условное форматирование «светофор».**
Главная → Условное форматирование → «Цветовые шкалы» / «Наборы значков» — таблица становится наглядной за 2 клика.

**24. Закрепить шапку.**
Вид → «Закрепить области» → «Закрепить верхнюю строку». Шапка не уезжает при прокрутке.

**25. Скрыть нули.**
Файл → Параметры → Дополнительно → снять «Показывать нули». Или пользовательский формат, чтобы нули не засоряли отчёт.

## Анализ

**26. Мгновенный анализ выделения.**
Выделите числа — в **правом нижнем углу** (строка состояния) Excel сразу показывает Сумму, Среднее и Количество. Клик правой кнопкой по этой строке — можно добавить Минимум/Максимум.

**27. Срезы (Slicers) для таблиц и сводных.**
Красивые кнопки-фильтры. Вставка → «Срез». Кликаешь «Москва» — вся таблица/сводная фильтруется. Основа любого дашборда.

**28. Сводная за 30 секунд.**
Встаньте в данные → Вставка → «Сводная таблица» → перетащите поля. Самый быстрый способ ответить на «сколько продали по городам/менеджерам/месяцам».

**29. `Ctrl` + `T` перед сводной/графиком.**
Если источник — «умная» таблица, то при добавлении строк сводная и график обновляются автоматически (нужно только «Обновить»).

## Защита от потерь и ошибок

**30. `Ctrl` + `S` — рефлекс.**
Жмите каждые пару минут. Включите Автосохранение, если файл в OneDrive.

**31. Проверка данных (выпадающие списки).**
Данные → «Проверка данных» → «Список» — человек выбирает из списка, а не печатает «Мсква/Москва/москва». Меньше ошибок в данных.

**32. `F4` = «повторить действие».**
Вне режима формул `F4` повторяет последнее действие. Покрасили ячейку — встали на другую — `F4` — покрасилась так же. Удалили строку — `F4` удаляет следующую.

## Мелочи, которые впечатляют

- **Диаграмма одной клавишей:** выделите данные и нажмите `Alt` + `F1` — график на том же листе (или `F11` — на отдельном).
- **Скопировать только видимые ячейки** (после фильтра): выделить → `Alt` + `;` → `Ctrl` + `C`.
- **Быстрое умножение/деление всего столбца на число:** введите число в ячейку, `Ctrl`+`C`, выделите столбец → Специальная вставка (`Ctrl`+`Alt`+`V`) → «Умножить».
- **Транспонировать** (строки ↔ столбцы): `Ctrl`+`C` → Специальная вставка → галочка «Транспонировать».
- **Несколько листов сразу:** зажмите `Ctrl` и кликайте ярлычки листов — что напечатаете на одном, появится на всех (группировка листов).

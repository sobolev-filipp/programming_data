# Шпаргалка функций Excel

> Все функции курса в одном месте. Русское имя, английский аналог, синтаксис и живой пример.
> Разделитель аргументов в примерах — `;` (русская локаль). В английском Excel замените на `,`.

---

## Математика и статистика

| Рус (Англ) | Что делает | Синтаксис | Пример |
|------------|-----------|-----------|--------|
| `СУММ` (SUM) | Сумма | `СУММ(диапазон)` | `=СУММ(B2:B100)` → сумма продаж |
| `СРЗНАЧ` (AVERAGE) | Среднее | `СРЗНАЧ(диапазон)` | `=СРЗНАЧ(B2:B100)` |
| `СЧЁТ` (COUNT) | Кол-во чисел | `СЧЁТ(диапазон)` | `=СЧЁТ(B2:B100)` |
| `СЧЁТЗ` (COUNTA) | Кол-во непустых | `СЧЁТЗ(диапазон)` | `=СЧЁТЗ(A2:A100)` — сколько заполнено |
| `СЧИТАТЬПУСТОТЫ` (COUNTBLANK) | Кол-во пустых | `СЧИТАТЬПУСТОТЫ(диапазон)` | `=СЧИТАТЬПУСТОТЫ(A2:A100)` |
| `МИН` / `МАКС` (MIN/MAX) | Минимум / максимум | `МИН(диапазон)` | `=МАКС(B2:B100)` |
| `ОКРУГЛ` (ROUND) | Округление | `ОКРУГЛ(число; знаки)` | `=ОКРУГЛ(B2; 2)` → до копеек |
| `ОКРУГЛВВЕРХ`/`ОКРУГЛВНИЗ` (ROUNDUP/DOWN) | Округление вверх/вниз | `ОКРУГЛВВЕРХ(число; знаки)` | `=ОКРУГЛВВЕРХ(B2; 0)` |
| `ЦЕЛОЕ` (INT) | Целая часть | `ЦЕЛОЕ(число)` | `=ЦЕЛОЕ(4.9)` → 4 |
| `ОСТАТ` (MOD) | Остаток от деления | `ОСТАТ(число; делитель)` | `=ОСТАТ(A2; 2)` → чёт/нечёт |
| `ПРОМЕЖУТОЧНЫЕ.ИТОГИ` (SUBTOTAL) | Итог с учётом фильтра | `ПРОМЕЖУТОЧНЫЕ.ИТОГИ(9; диапазон)` | `=ПРОМЕЖУТОЧНЫЕ.ИТОГИ(9; B2:B100)` — сумма видимых |
| `ОКРУГЛТ` (MROUND) | Округл. до кратного | `ОКРУГЛТ(число; кратность)` | `=ОКРУГЛТ(A2; 50)` |

## Логические

| Рус (Англ) | Что делает | Синтаксис | Пример |
|------------|-----------|-----------|--------|
| `ЕСЛИ` (IF) | Ветвление | `ЕСЛИ(условие; если_да; если_нет)` | `=ЕСЛИ(B2>100; "Крупный"; "Мелкий")` |
| `ЕСЛИМН` (IFS) | Много условий подряд | `ЕСЛИМН(усл1; знач1; усл2; знач2; …)` | `=ЕСЛИМН(B2>=90;"A"; B2>=75;"B"; ИСТИНА;"C")` |
| `И` (AND) | Все условия верны | `И(усл1; усл2; …)` | `=И(B2>0; C2="Опт")` |
| `ИЛИ` (OR) | Хотя бы одно верно | `ИЛИ(усл1; усл2; …)` | `=ИЛИ(B2>100; C2="VIP")` |
| `НЕ` (NOT) | Отрицание | `НЕ(условие)` | `=НЕ(B2=0)` |
| `ЕСЛИОШИБКА` (IFERROR) | Заглушка при ошибке | `ЕСЛИОШИБКА(формула; значение)` | `=ЕСЛИОШИБКА(ВПР(...); "нет")` |
| `ЕПУСТО` (ISBLANK) | Проверка «пусто ли» | `ЕПУСТО(ячейка)` | `=ЕСЛИ(ЕПУСТО(A2);"—";A2)` |

## Условные подсчёты

| Рус (Англ) | Что делает | Синтаксис | Пример |
|------------|-----------|-----------|--------|
| `СЧЁТЕСЛИ` (COUNTIF) | Считать по условию | `СЧЁТЕСЛИ(диапазон; условие)` | `=СЧЁТЕСЛИ(C:C; "Москва")` |
| `СЧЁТЕСЛИМН` (COUNTIFS) | Считать по нескольким | `СЧЁТЕСЛИМН(д1; у1; д2; у2)` | `=СЧЁТЕСЛИМН(C:C;"Москва"; D:D;"Опт")` |
| `СУММЕСЛИ` (SUMIF) | Сумма по условию | `СУММЕСЛИ(диапазон; условие; сумма)` | `=СУММЕСЛИ(C:C;"Москва"; E:E)` |
| `СУММЕСЛИМН` (SUMIFS) | Сумма по нескольким | `СУММЕСЛИМН(сумма; д1;у1; д2;у2)` | `=СУММЕСЛИМН(E:E; C:C;"Москва"; D:D;"Опт")` |
| `СРЗНАЧЕСЛИ` (AVERAGEIF) | Среднее по условию | `СРЗНАЧЕСЛИ(диапазон; условие; ср)` | `=СРЗНАЧЕСЛИ(C:C;"Москва"; E:E)` |

> Подстановочные знаки в условиях: `*` — любой текст, `?` — один символ. Например `"Мос*"`. Сравнения — в кавычках: `">100"`, `"<>0"`.

## Поиск и подстановка

| Рус (Англ) | Что делает | Синтаксис | Пример |
|------------|-----------|-----------|--------|
| `ВПР` (VLOOKUP) | Поиск по вертикали | `ВПР(что; таблица; № столбца; 0)` | `=ВПР(A2; Прайс!$A:$C; 3; 0)` |
| `ГПР` (HLOOKUP) | Поиск по горизонтали | `ГПР(что; таблица; № строки; 0)` | `=ГПР(A2; Данные!$A$1:$Z$5; 3; 0)` |
| `ПРОСМОТРX` (XLOOKUP) | Современный поиск | `ПРОСМОТРX(что; где_искать; что_вернуть; [если_нет])` | `=ПРОСМОТРX(A2; Прайс!B:B; Прайс!C:C; "нет")` |
| `ИНДЕКС` (INDEX) | Значение по номеру | `ИНДЕКС(диапазон; строка; столбец)` | `=ИНДЕКС(C:C; 5)` |
| `ПОИСКПОЗ` (MATCH) | Номер позиции | `ПОИСКПОЗ(что; диапазон; 0)` | `=ПОИСКПОЗ(A2; B:B; 0)` |
| `ИНДЕКС+ПОИСКПОЗ` | Гибкий поиск | `ИНДЕКС(рез; ПОИСКПОЗ(что; ключ; 0))` | `=ИНДЕКС(C:C; ПОИСКПОЗ(A2; B:B; 0))` |

> Последний аргумент `ВПР`/`ГПР` — `0` (или `ЛОЖЬ`) означает **точное** совпадение. Почти всегда нужен именно он.

## Текст

| Рус (Англ) | Что делает | Синтаксис | Пример |
|------------|-----------|-----------|--------|
| `ЛЕВСИМВ` (LEFT) | Слева N символов | `ЛЕВСИМВ(текст; N)` | `=ЛЕВСИМВ(A2; 3)` |
| `ПРАВСИМВ` (RIGHT) | Справа N символов | `ПРАВСИМВ(текст; N)` | `=ПРАВСИМВ(A2; 4)` |
| `ПСТР` (MID) | Из середины | `ПСТР(текст; старт; длина)` | `=ПСТР(A2; 4; 3)` |
| `ДЛСТР` (LEN) | Длина текста | `ДЛСТР(текст)` | `=ДЛСТР(A2)` |
| `НАЙТИ` (FIND) | Позиция (регистрозависимо) | `НАЙТИ(что; текст)` | `=НАЙТИ(" "; A2)` |
| `ПОИСК` (SEARCH) | Позиция (без регистра, `*?`) | `ПОИСК(что; текст)` | `=ПОИСК("ул"; A2)` |
| `СЖПРОБЕЛЫ` (TRIM) | Убрать лишние пробелы | `СЖПРОБЕЛЫ(текст)` | `=СЖПРОБЕЛЫ(A2)` |
| `ЗАМЕНИТЬ` (REPLACE) | Замена по позиции | `ЗАМЕНИТЬ(текст; старт; N; новый)` | `=ЗАМЕНИТЬ(A2; 1; 3; "+7")` |
| `ПОДСТАВИТЬ` (SUBSTITUTE) | Замена по значению | `ПОДСТАВИТЬ(текст; старое; новое)` | `=ПОДСТАВИТЬ(A2; "-"; "")` |
| `СЦЕПИТЬ`/`&` (CONCAT) | Склейка текста | `текст1 & текст2` | `=A2 & " " & B2` |
| `ОБЪЕДИНИТЬ` (TEXTJOIN) | Склейка с разделителем | `ОБЪЕДИНИТЬ(разд; ИСТИНА; диап)` | `=ОБЪЕДИНИТЬ("; "; ИСТИНА; A2:A5)` |
| `ПРОПИСН`/`СТРОЧН`/`ПРОПНАЧ` (UPPER/LOWER/PROPER) | Регистр | `ПРОПНАЧ(текст)` | `=ПРОПНАЧ(A2)` → «Иван Иванов» |
| `ТЕКСТ` (TEXT) | Число → текст по формату | `ТЕКСТ(значение; формат)` | `=ТЕКСТ(A2; "ДД.ММ.ГГГГ")` |

## Дата и время

| Рус (Англ) | Что делает | Синтаксис | Пример |
|------------|-----------|-----------|--------|
| `СЕГОДНЯ` (TODAY) | Текущая дата | `СЕГОДНЯ()` | `=СЕГОДНЯ()` |
| `ТДАТА` (NOW) | Дата и время | `ТДАТА()` | `=ТДАТА()` |
| `ДАТА` (DATE) | Собрать дату | `ДАТА(год; месяц; день)` | `=ДАТА(2026; 8; 2)` |
| `ГОД`/`МЕСЯЦ`/`ДЕНЬ` (YEAR/MONTH/DAY) | Часть даты | `ГОД(дата)` | `=ГОД(A2)` |
| `РАЗНДАТ` (DATEDIF) | Разница дат | `РАЗНДАТ(нач; кон; "Y/M/D")` | `=РАЗНДАТ(A2; СЕГОДНЯ(); "Y")` → полных лет |
| `ДЕНЬНЕД` (WEEKDAY) | День недели (число) | `ДЕНЬНЕД(дата; 2)` | `=ДЕНЬНЕД(A2; 2)` → 1=Пн |
| `РАБДЕНЬ` (WORKDAY) | Дата ± рабочие дни | `РАБДЕНЬ(старт; дней; [празд])` | `=РАБДЕНЬ(A2; 5)` |
| `ЧИСТРАБДНИ` (NETWORKDAYS) | Рабочих дней между | `ЧИСТРАБДНИ(нач; кон; [празд])` | `=ЧИСТРАБДНИ(A2; B2)` |
| `КОНМЕСЯЦА` (EOMONTH) | Конец месяца | `КОНМЕСЯЦА(дата; смещение)` | `=КОНМЕСЯЦА(A2; 0)` |

## Динамические массивы (Microsoft 365 / Excel 2021)

| Рус (Англ) | Что делает | Синтаксис | Пример |
|------------|-----------|-----------|--------|

## Частые ошибки и что значат

| Ошибка | Причина | Как чинить |
|--------|---------|-----------|
| `#####` | Столбец узкий | Расширить столбец (двойной клик по границе) |
| `#ДЕЛ/0!` | Деление на ноль/пусто | `=ЕСЛИОШИБКА(...; 0)` или проверить делитель |
| `#Н/Д` | Поиск не нашёл | Проверить пробелы (`СЖПРОБЕЛЫ`), тип данных, точное совпадение `0` |
| `#ИМЯ?` | Опечатка в имени функции/диапазона | Проверить написание, язык функции |
| `#ЗНАЧ!` | Не тот тип (текст вместо числа) | Проверить, что в ячейках числа, а не текст |
| `#ССЫЛКА!` | Ссылка на удалённую ячейку | Восстановить/переписать ссылку |
| `#ПУСТО!` | Неверный оператор диапазонов | Проверить пробелы между диапазонами |

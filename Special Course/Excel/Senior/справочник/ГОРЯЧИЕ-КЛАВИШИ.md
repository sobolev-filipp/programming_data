# Горячие клавиши Excel — настольная шпаргалка

> Главное отличие профессионала от обычного пользователя — **руки на клавиатуре**. Не пытайтесь выучить всё сразу. Осваивайте по 3–5 сочетаний в неделю, начиная с раздела «Топ-15».
>
> Обозначения: `+` — нажать вместе; `,` — нажать по очереди. Для macOS обычно `Ctrl` → `Cmd (⌘)`, `Alt` → `Option (⌥)` (заметные отличия помечены).

---

## ⭐ Топ-15, которые изменят вашу скорость

| Клавиши | Что делает |
|---------|-----------|
| `Ctrl` + `C` / `X` / `V` | Копировать / вырезать / вставить |
| `Ctrl` + `Z` / `Y` | Отменить / повторить |
| `Ctrl` + стрелка | Прыжок к краю данных (конец таблицы одним нажатием) |
| `Ctrl` + `Shift` + стрелка | Выделить до края данных |
| `Ctrl` + `Home` | В начало листа (ячейка A1) |
| `Ctrl` + `A` | Выделить всю таблицу / весь лист |
| `Ctrl` + `S` | Сохранить (жмите постоянно!) |
| `Ctrl` + `T` | Превратить диапазон в «умную» таблицу |
| `F4` | Зафиксировать ссылку (`A1` → `$A$1`) / повторить последнее действие |
| `Ctrl` + `1` | Формат ячеек (главное окно форматирования) |
| `Alt` + `=` | Автосумма выделенного |
| `Ctrl` + `Shift` + `L` | Включить/выключить фильтр |
| `Ctrl` + `;` | Вставить сегодняшнюю дату |
| `F2` | Редактировать активную ячейку |
| `Ctrl` + `Enter` | Ввести значение/формулу сразу во все выделенные ячейки |

## Навигация по листу

| Клавиши | Действие |
|---------|----------|
| Стрелки | На одну ячейку |
| `Ctrl` + стрелка | К краю блока данных в направлении стрелки |
| `Ctrl` + `Home` | К ячейке A1 |
| `Ctrl` + `End` | К последней использованной ячейке |
| `Home` | В начало строки (столбец A) |
| `Page Up` / `Page Down` | На экран вверх / вниз |
| `Alt` + `Page Up`/`Down` | На экран влево / вправо |
| `Ctrl` + `Page Up`/`Down` | Между листами книги |
| `Ctrl` + `G` (или `F5`) | «Перейти» к ячейке/диапазону по адресу |

## Выделение

| Клавиши | Действие |
|---------|----------|
| `Shift` + стрелка | Расширить выделение на ячейку |
| `Ctrl` + `Shift` + стрелка | Выделить до края данных |
| `Ctrl` + `A` | Вся таблица (повторно — весь лист) |
| `Ctrl` + `Space` | Выделить весь столбец |
| `Shift` + `Space` | Выделить всю строку |
| `Ctrl` + `Shift` + `End` | От текущей ячейки до конца данных |
| `Shift` + клик | Выделить прямоугольник до места клика |
| `Ctrl` + клик | Добавить несмежные ячейки к выделению |

| Клавиши | Действие |
|---------|----------|
| `=` | Начать формулу |
| `F4` | Переключить тип ссылки: `A1` → `$A$1` → `A$1` → `$A1` |
| `Alt` + `=` | Автосумма |
| `Ctrl` + `` ` `` (клавиша над `Tab`) | Показать/скрыть все формулы на листе |

## Секрет: клавиша `Alt` и «горячие подсказки»

Нажмите **`Alt`** (и отпустите) — на ленте появятся **буквы**. Дальше нажимайте буквы, чтобы попасть в любую команду **без мыши**. Например:
- `Alt`, `H`, `A`, `C` — выравнивание по центру.
- `Alt`, `A`, `S`, `S` — сортировка.
- `Alt`, `W`, `F`, `F` — закрепить области.

Это работает для **любой** кнопки на ленте — можно управлять всем Excel с клавиатуры.

## Как тренироваться

1. Заклейте себе стикер с 5 клавишами из «Топ-15» на монитор.
2. Неделю запрещайте себе делать эти действия мышью.
3. Через неделю добавьте следующие 5. Через 2 месяца работаете «как пианист».

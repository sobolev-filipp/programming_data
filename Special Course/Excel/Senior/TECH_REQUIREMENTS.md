# Технические требования курса

> Что нужно из техники, ПО и файлов, чтобы курс прошёл гладко.

---

## 1. Программное обеспечение

### Рекомендуется
- **Microsoft Excel** для Windows или macOS: **Microsoft 365** (самый актуальный) или **Excel 2021**.
  Почему важно: только в 365/2021 есть современные функции `ПРОСМОТРX` (XLOOKUP), `ЕСЛИМН` (IFS), динамические массивы (`УНИК`, `ФИЛЬТР`, `СОРТ`). Урок 5 и часть лайфхаков на них опираются.

### Допустимо (с оговорками)
- **Excel 2016 / 2019** — подойдёт для 90% курса, но **нет** `ПРОСМОТРX` и динамических массивов. На уроке 5 делаем упор на `ИНДЕКС+ПОИСКПОЗ` и `ВПР`, а `ПРОСМОТРX` показываем «на будущее».
- **Excel 2013 и старше** — Power Query (урок 12) ставится отдельной надстройкой; часть интерфейса отличается. Лучше обновиться.

### Не подходит для полного курса
- **Только веб-версия Excel Online** — урезаны Power Query, макросы/VBA (уроки 12–13), часть настроек. Годится для базовых уроков 1–11, но проф-инструменты нужны десктопные.
- **Google Таблицы, LibreOffice Calc** — другой продукт. Логика похожа, но интерфейс, функции и Power Query/VBA отличаются. Этот курс — про **Microsoft Excel**.

> **Обязательно уточните версию ученика до урока 1.** От неё зависит, что показывать на уроках 5, 12, 13. Как узнать: Файл → Учётная запись → «Сведения о продукте».

## 2. Техника

- Компьютер/ноутбук с Windows 10/11 или macOS.
- **Полноразмерная клавиатура удобнее** — курс про горячие клавиши; на ноутбуке без отдельного блока проверьте, где `F4`, `Home`, `End`, `Delete`.
- Мышь (тачпад тоже работает, но с мышью удобнее на первых уроках).
- Для онлайн-формата: стабильный интернет и программа демонстрации экрана (Zoom / Google Meet / любая). Хорошо, если ученик может **расшарить свой экран** — так вы видите его ошибки.

## 3. Настройки Excel «под курс» (сделать до урока 1)

Проверьте вместе с учеником на первом занятии:

1. **Строка формул и заголовки видны.** Вкладка «Вид» → галочки «Строка формул», «Заголовки», «Сетка».
2. **Разделитель аргументов.** В формулах курса используется `;`. Если у ученика формула не считается — Файл → Параметры → Дополнительно → раздел «При вычислении» / «Разделители». Обычно достаточно системных.
3. **Вкладка «Разработчик»** (нужна на уроке 13). Файл → Параметры → Настроить ленту → поставить галочку «Разработчик».
4. **Автосохранение / резервные копии** — чтобы не потерять учебные файлы.
5. **Стиль ссылок A1** (не R1C1). Файл → Параметры → Формулы → снять галочку «Стиль ссылок R1C1», если она стоит.

## 4. Учебные файлы (заготовки)

Для практики нужны простые таблицы-выгрузки. Их можно **сделать за 5 минут перед уроком** или подготовить заранее. Рекомендованный набор (сквозная тема — вымышленная компания «Продажи»):

| Файл | Для уроков | Что внутри |
|------|-----------|-----------|
| `Продажи.xlsx` | 2–4, 8–11 | Таблица заказов: дата, менеджер, город, товар, категория, количество, цена, сумма (200–500 строк). |
| `Прайс.xlsx` | 5 | Справочник: товар → цена, категория. Для отработки `ВПР`/`ПРОСМОТРX`. |
| `Сотрудники.xlsx` | 6–7 | ФИО одной строкой, даты приёма, телефоны в разном формате — «грязные» данные для чистки. |
| `Выгрузка_грязная.csv` | 12 | CSV с лишними пробелами, «текстовыми» числами, пустыми строками — для Power Query. |
| `Данные_для_дашборда.xlsx` | 14 | Больший набор продаж за год — основа итогового проекта. |

> Готовые датасеты можно взять/сгенерировать где угодно; главное — чтобы данные были «как в жизни» (с небольшими ошибками). Конкретную структуру каждой заготовки описывает `practice.md` соответствующего урока.

## 5. Что подготовить преподавателю

- [ ] Свой Excel той же (или новее) версии, что у ученика.
- [ ] Файлы-заготовки из таблицы выше (хотя бы `Продажи.xlsx` и `Прайс.xlsx` к первым урокам).
- [ ] Открытый `справочник/` для быстрых ссылок.
- [ ] Проектор / демонстрация экрана настроены и проверены.
- [ ] На урок 13 (VBA) — заранее включённая вкладка «Разработчик» и понимание настроек безопасности макросов.

## Задание 1. Первый макрос — запись (8 минут)

1. Разработчик → «Запись макроса». Имя `ОформитьОтчёт`, сочетание `Ctrl`+`Shift`+`O`, сохранить в «Эта книга» → ОК.
2. **Выполните действия** (они записываются):
   - выделите шапку `A1:N1`, сделайте жирной (`Ctrl`+`B`), залейте цветом, белый шрифт;
   - включите фильтр (`Ctrl`+`Shift`+`L`);
   - закрепите верхнюю строку (Вид → Закрепить).
3. Разработчик → «Остановить запись».
4. **Проверьте:** отмените форматирование вручную (`Ctrl`+`Z` несколько раз), затем запустите макрос (`Ctrl`+`Shift`+`O`) — всё оформилось заново одним нажатием.

---

## Задание 2. Смотрим код (10 минут)

1. Откройте редактор: `Alt`+`F11`. Слева в «Модули» → двойной клик по `Module1`.
2. Найдите `Sub ОформитьОтчёт()` … `End Sub`. Прочитайте код.
3. **Свяжите строки с действиями:** `Range("A1:N1").Select` = выделили шапку; `Selection.Font.Bold = True` = сделали жирным; и т.д.
4. Найдите строку с заливкой (`Interior.Color`) — это выбранный вами цвет в формате RGB.

---

## Задание 3. Правим код (12 минут)

1. **Смените цвет заливки:** в строке `Selection.Interior.Color = RGB(...)` поставьте свои числа, например `RGB(0, 112, 192)` (синий). Вернитесь в Excel, запустите — цвет изменился.
2. **Добавьте автоширину столбцов** — в конце макроса перед `End Sub` допишите:
   ```vba
   Columns("A:N").AutoFit
   ```
   Запустите — столбцы подстроились по содержимому.
3. (Опционально) Уберите лишний шаг, если при записи затесалось что-то ненужное — просто удалите строку.

---

## Задание 4. Кнопка + свой мини-макрос (12 минут)

1. **Кнопка:** Разработчик → «Вставить» → «Кнопка (форма)» → нарисуйте на листе → выберите макрос `ОформитьОтчёт` → ОК. Переименуйте в «Оформить отчёт». Проверьте клик.
2. **Свой макрос «Показать выручку».** В `Alt`+`F11` в модуле допишите:
   ```vba
   Sub ПоказатьВыручку()
       Dim итог As Double
       итог = Application.Sum(Range("H2:H301"))
       MsgBox "Общая выручка: " & Format(итог, "# ##0 ₽")
   End Sub
   ```
3. Вернитесь, добавьте вторую кнопку «Выручка» и назначьте ей `ПоказатьВыручку`. Кликните — всплывёт окно с суммой.
4. **Сохраните** как `.xlsm` (`Ctrl`+`S`). Если Excel предупреждает про макросы — вы сохраняете правильно (в `.xlsm`).

> **Итог:** у вас книга с кнопками, которые в один клик оформляют отчёт и показывают выручку — вы автоматизировали рутину и умеете читать/править код.

## ⏱️ Если осталось время (бонус-задания)

1. **Макрос «Обновить и сохранить».** Запишите/напишите `Sub ОбновитьСохранить(): ActiveWorkbook.RefreshAll: ActiveWorkbook.Save: End Sub` и повесьте на кнопку — одним кликом обновить все данные и сохранить.
2. **Цикл по листам (посмотреть код).** Запишите действие на одном листе, затем в коде оберните его в `For Each ws In Worksheets ... Next` (с помощью преподавателя) — прочувствуйте, как макрос повторяет действие по всем листам.
3. **MsgBox с вопросом.** Сделайте `MsgBox` с кнопками Да/Нет (`vbYesNo`) перед очисткой — «Точно очистить формат?».

> 💡 **Как лучше, а не так.** ❌ Не сохраняйте книгу с макросами в обычный `.xlsx` — код молча пропадёт. ✅ Только **`.xlsm`**. И не включайте макросы в чужих файлах из почты «на автомате» — это запуск чужой программы; включайте лишь от доверенных источников.

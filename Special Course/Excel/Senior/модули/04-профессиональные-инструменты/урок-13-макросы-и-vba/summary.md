# Урок 13. Макросы и VBA — резюме

---

## Что это
- **Макрос** — записанные действия, повторяемые одной кнопкой.
- **VBA** — язык, на котором они записываются.
- Вкладка **«Разработчик»** (включить: Файл → Параметры → Настроить ленту).

## Запись
Разработчик → «Запись макроса» → имя без пробелов → делаем действия → **«Остановить запись»**.
Запуск: «Макросы» → «Выполнить», сочетание клавиш или кнопка.
- «Относительные ссылки» — работать от текущей ячейки (иначе по записанным адресам).

## Редактор VBE (`Alt`+`F11`)
- Код живёт в **Модулях**; процедура `Sub Имя() … End Sub`.
- Читается как «протокол»: `Объект.Свойство = Значение`.
```vba
Range("A1:N1").Select
Selection.Font.Bold = True
Selection.Interior.Color = RGB(48, 84, 150)
```
- Цель — **читать и слегка править** (сменить цвет, диапазон, добавить `Columns("A:N").AutoFit`).

## Кнопка
Разработчик → «Вставить» → «Кнопка (форма)» → назначить макрос → переименовать.

## ⚠️ Важно
- Сохранять книгу с макросами как **`.xlsm`** (обычный `.xlsx` макросы не хранит!).
- Безопасность: чужие макросы включать только от доверенных источников.

---

## Что должно остаться в голове
1. Макрос = «повтор действий» одной кнопкой.
2. Код — это расшифровка ваших кликов; его можно прочитать и поправить.
3. Кнопка на листе запускает макрос.
4. Файл с макросами — только **`.xlsm`**.

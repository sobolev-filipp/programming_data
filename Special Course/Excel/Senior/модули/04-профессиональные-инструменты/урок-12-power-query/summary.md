# Урок 12. Power Query — резюме

---

## Идея
Power Query **записывает шаги** очистки как редактируемый рецепт. Настроил один раз → каждый месяц новые данные обрабатываются кнопкой **«Обновить»**. Исходный файл не меняется.

## Подключение
Данные → «Получить данные» → «Из файла» → выбрать файл → **«Преобразовать данные»** (не «Загрузить»!) — открывается редактор.

## Редактор и шаги
- Справа — **«Применённые шаги»** (история действий). Клик по шагу — состояние данных; крестик — откат.
- Загрузить результат: «Закрыть и загрузить» → лист / подключение / сводная.

## Очистка (по шагам)
- Удалить пустые строки; «Формат» → «Обрезать» (пробелы), «Каждое слово с заглавной» (регистр).
- «Замена значений» (СПб → Санкт-Петербург).
- **Типы данных** (значок в шапке) — PQ сам чинит текст-числа/даты.
- «Разделить столбец», «Столбец из примеров» (аналог `Ctrl`+`E`), «Заполнить вниз».

## ⭐ Из папки
Данные → «Из файла» → **«Из папки»** → «Объединить и преобразовать». Склеивает все файлы в одну таблицу. Новый файл в папке → «Обновить» → он уже в таблице.

## Объединение
- **Append** («Добавить запросы») — дописать строки (месяцы, филиалы).
- **Merge** («Объединить запросы») — подтянуть столбцы по ключу = **`ВПР`, но повторяемый** и без ограничений.

## Обновление
Данные → «Обновить всё» (`Ctrl`+`Alt`+`F5`) — применяет весь рецепт к новым данным.

---

## Что должно остаться в голове
1. Действия = **шаги**, их можно править и откатывать.
2. «Из папки» собирает много файлов в один; новый файл — «Обновить».
3. Merge заменяет `ВПР` (обновляемо).
4. Главная выгода — **«Обновить» вместо часов ручной работы**.

## ✅ Вывод урока
Вы построили автоматический «конвейер» подготовки данных. То, что раньше отнимало полдня каждый месяц, теперь — одна кнопка. Это профессиональный уровень работы с данными.

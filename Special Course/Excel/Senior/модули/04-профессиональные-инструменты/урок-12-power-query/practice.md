# Урок 12. Практика на занятии

> ## 🎯 Рабочая ситуация
> **Марина Викторовна:** *«Из старой системы каждый месяц выгружается вот такой бардак — пробелы, города вразнобой, числа как текст. И лежат они по месяцам отдельными файлами. Устала это чистить и склеивать вручную. Сделай так, чтобы новый файл обрабатывался сам»*.
> **Что сдать:** настроенный запрос Power Query, который чистит грязную выгрузку и **собирает помесячные файлы в одну таблицу**, обновляемую одной кнопкой.

> Файлы: `материалы/Выгрузка_грязная.csv`, папка `материалы/Выгрузки_по_месяцам/`, `материалы/Прайс.xlsx`.
>
> 📂 **Скачать материалы:** [Выгрузка_грязная.csv](../../../материалы/Выгрузка_грязная.csv) · папка [Выгрузки_по_месяцам/](../../../материалы/Выгрузки_по_месяцам/) · [Прайс.xlsx](../../../материалы/Прайс.xlsx).

## Задание 1. Подключение и знакомство с редактором (8 минут)

1. Данные → «Получить данные» → «Из файла» → «Из текстового/CSV» → выберите `Выгрузка_грязная.csv`.
2. В окне предпросмотра нажмите **«Преобразовать данные»** (НЕ «Загрузить») — открылся редактор Power Query.
3. Осмотритесь: слева данные, справа — «Применённые шаги» (пока «Источник», «Повышенные заголовки», «Изменённый тип»).
4. Кликните по разным шагам — увидите, как выглядели данные на каждом этапе.

---

## Задание 2. ⭐ Чистим грязную выгрузку по шагам (14 минут)

Выполняйте по очереди — следите, как растёт список шагов справа:

1. **Пустые строки:** «Главная» → «Удалить строки» → «Удалить пустые строки».
2. **Пробелы:** выделите текстовые столбцы (Город, Товар) → «Преобразование» → «Формат» → «Обрезать».
3. **Регистр городов:** столбец «Город» → «Формат» → «Каждое слово с заглавной».
4. **Замена сокращений:** столбец «Город» → «Замена значений» → «СПб» на «Санкт-Петербург».
5. **Типы данных:** кликните значок типа в шапке «Дата» → «Дата»; «Количество» и «Сумма» → «Целое число». Числа-как-текст стали числами.
6. **Переименуйте** столбцы понятно (двойной клик по шапке).
7. **Загрузите результат:** «Главная» → «Закрыть и загрузить» → на новый лист. Получилась чистая «умная» таблица.

> Проговорите: всё это теперь **записано**. Пришлёт бухгалтерия такой же файл — подменим источник и «Обновим».

## Задание 3. ⭐⭐ Сборка из папки (12 минут)

1. Данные → «Получить данные» → «Из файла» → **«Из папки»** → укажите папку `Выгрузки_по_месяцам`.
2. В окне — список из 3 файлов. Нажмите **«Объединить и преобразовать данные»** → в диалоге выберите образец → ОК.
3. PQ склеил 3 месяца в **одну** таблицу (обратите внимание на столбец с именем файла-источника).
4. Почистите при необходимости (типы данных) → «Закрыть и загрузить».
5. **Проверьте магию обновления:** (демо) представьте, что появился файл за апрель. Можно скопировать `2025-03.csv` в `2025-04.csv` в той же папке → в Excel: Данные → «Обновить всё» → новые строки **сами** добавились в таблицу.

---

## Задание 4. Merge вместо ВПР + обновление (12 минут)

1. Загрузите `Прайс.xlsx` как запрос (Данные → «Из книги» → «Только создать подключение»).
2. К таблице продаж: «Главная» → «Объединить запросы» → выберите запрос «Прайс» → общий столбец **«Товар»** → тип соединения «Левое внешнее».
3. Разверните (значок ↔ в шапке нового столбца) → отметьте «Категория», «Цена» → ОК. Данные из прайса подтянулись — как `ВПР`, но повторяемо.
4. «Закрыть и загрузить».
5. **Итоговое обновление:** измените что-нибудь в исходном CSV (сохраните) → Данные → «Обновить всё» → результат пересчитался по всем шагам.

> **Итог:** вы построили «конвейер»: грязные файлы → авто-очистка → сборка из папки → подтягивание прайса → чистая таблица, обновляемая кнопкой.

## ⏱️ Если осталось время (бонус-задания)

1. **Группировка в PQ.** В редакторе сделайте «Группировать по» город → сумма — получите готовый свод прямо в запросе (без сводной).
2. **Развернуть/свернуть.** Потренируйте «Отменить свёртывание столбцов» (unpivot) — превратите «широкую» таблицу (месяцы в шапке) в «плоскую» (столбец «Месяц»). Это частая реальная задача.
3. **Параметр запроса.** Вынесите путь к папке в параметр — чтобы запрос легко переключать на другую папку.

> 💡 **Как лучше, а не так.** ❌ Не чистите каждую новую выгрузку заново руками — это часы и ошибки. ✅ Настройте очистку в Power Query **один раз** и обновляйте кнопкой. И жмите **«Преобразовать данные»**, а не «Загрузить», иначе не попадёте в редактор шагов.

## Задание 1. Чистый запрос из грязного CSV
Повторите очистку `Выгрузка_грязная.csv` самостоятельно:
- удалить пустые строки, обрезать пробелы, единый регистр городов, заменить «СПб», задать типы, переименовать столбцы.
Запишите, **сколько шагов** получилось в «Применённых шагах».

## Задание 2. Сборка из папки
1. Соберите `Выгрузки_по_месяцам/` в одну таблицу («Из папки»).
2. Добавьте столбец «Сумма» = Количество × Цена (в PQ: «Добавление столбца» → «Настраиваемый столбец» или «Умножение»).
3. Загрузите на лист.
4. **Тест обновления:** скопируйте один из CSV под именем `2025-04.csv` в ту же папку → «Обновить всё». Добавились ли строки? Запишите, что произошло.

## Задание 3. Merge с прайсом
К собранной таблице подтяните «Категорию» из `Прайс.xlsx` через «Объединить запросы» по столбцу «Товар». (Аналог `ВПР`, но обновляемый.)

## Задание 4. Отчёт поверх запроса
Постройте сводную **по результату Power Query** (выручка по городам). Измените исходный CSV → «Обновить всё» → проверьте, что сводная тоже обновилась (запрос → таблица → сводная — вся цепочка).

`PowerQuery_ДЗ_Урок12.xlsx` с очищенным запросом, таблицей из папки (+Сумма), merge с прайсом и сводной поверх. Письменные ответы по Заданиям 1 и 2.

# Урок 8. Сортировка, фильтры, проверка данных — резюме

---

## Сортировка
- Многоуровневая: Данные → «Сортировка» → уровни (сначала город, потом сумма).
- По цвету, по пользовательскому списку (месяцы).
- ⚠️ Сортируйте **всю** таблицу, не один столбец (иначе строки «рассыплются»). На «умной» таблице безопасно.

## Фильтры
- `Ctrl`+`Shift`+`L` — вкл/выкл. `Alt`+`↓` — меню.
- Числовые (топ-10, больше/меньше), текстовые (содержит), по дате (этот месяц).
- **Живой итог по видимым:** `=ПРОМЕЖУТОЧНЫЕ.ИТОГИ(9; диапазон)` (в отличие от `СУММ`, которая считает всё).

## ⭐ Срезы (Slicers)
- «Конструктор таблиц» → «Вставить срез». Фильтры-кнопки.
- Клик = мгновенный фильтр; `Ctrl` — несколько. **Основа дашборда** (урок 14).

## Проверка данных (чистый ввод)
- Данные → «Проверка данных» → «Список» → `=Города` — выпадающий список.
- Ограничения: целое 1–1000, дата, длина текста; сообщение об ошибке.
- Зачем: грязный ввод («москва»/«МСК») ломает сводные.

## Чистка
- Дубликаты: Данные → «Удалить дубликаты» (**на копии**, необратимо!). Увидеть — условное форматирование «Повторяющиеся».
- Уникальные: расширенный фильтр или `=УНИК(...)`.
- Пустые/ошибки: `Ctrl`+`G` → «Выделить» → «Пустые».

---

## Что должно остаться в голове
1. Срезы — фильтр в один клик, будущие «ручки» дашборда.
2. `ПРОМЕЖУТОЧНЫЕ.ИТОГИ` считает только видимое.
3. Выпадающие списки = чистые данные = правильные сводные.

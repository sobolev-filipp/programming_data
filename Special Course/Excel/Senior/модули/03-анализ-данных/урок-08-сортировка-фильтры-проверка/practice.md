# Урок 8. Практика на занятии

> ## 🎯 Рабочая ситуация
> **Марина Викторовна:** *«На совещании будут спрашивать по-разному: покажи Москву, покажи топ заказов, только опт. Сделай, чтобы данные фильтровались в один клик. И ещё — менеджеры вносят города кто как хочет (‘Мсква’, ‘москва’), из-за этого отчёты врут. Поставь выпадающие списки, чтобы вносили правильно»*.
> **Что сдать:** таблица со срезами (Город/Менеджер/Категория), «живым» итогом по видимым строкам, выпадающими списками для ввода и без дубликатов.
> Легенда — в [СЦЕНАРИЙ-КУРСА.md](../../../СЦЕНАРИЙ-КУРСА.md).

> Файл: `материалы/Продажи.xlsx` («умная» таблица `Продажи`).

---

## Задание 1. Сортировка и фильтры (10 минут)

1. **Многоуровневая сортировка:** Данные → «Сортировка»: сначала «Город» (А→Я), затем «Сумма» (по убыванию). Внутри каждого города — заказы от крупных к мелким.
2. **Автофильтр:** убедитесь, что фильтр включён (`Ctrl`+`Shift`+`L`). Через `Alt`+`↓` на «Город» оставьте только «Москва».
3. **Числовой фильтр:** «Сумма» → «Числовые фильтры» → «Первые 10» — топ крупнейших заказов.
4. **Фильтр по дате:** «Дата заказа» → отфильтруйте один месяц.
5. **Итог по видимым:** в свободной ячейке `=ПРОМЕЖУТОЧНЫЕ.ИТОГИ(9; Продажи[Сумма])`. Меняйте фильтр — итог пересчитывается (сравните с обычной `=СУММ(Продажи[Сумма])`, которая не меняется).
6. Снимите фильтры (`Ctrl`+`Shift`+`L` дважды или «Очистить»).

---

## Задание 2. ⭐ Срезы (12 минут)

1. Встаньте в таблицу → «Конструктор таблиц» → «Вставить срез» → отметьте «Город», «Менеджер», «Категория» → ОК.
2. Появились 3 панели-кнопки. Кликните «Москва» — таблица отфильтровалась. Добавьте «Казань» с `Ctrl` — теперь два города.
3. Кликните менеджера — комбинированный фильтр (город + менеджер).
4. Сбросьте срез значком-фильтром в его углу.
5. Оформите срезы (цвет, число столбцов кнопок) — «Конструктор срезов». Проговорите: это будущие «ручки управления» дашбордом.

---

## Задание 3. Проверка данных — выпадающие списки (12 минут)

1. Сделайте на отдельном листе `Справочники` список городов (столбцом) и задайте ему имя `Города` (поле имени).
2. Возьмите пустой столбец (или новый лист для ввода новых заказов). Выделите ячейки → Данные → «Проверка данных» → «Список» → Источник `=Города`.
3. Проверьте: в ячейке появилась стрелка, можно только выбрать из списка. Попробуйте вписать «Мсква» вручную — Excel не даст.
4. Настройте «Сообщение об ошибке»: заголовок «Стоп», текст «Выберите город из списка».
5. **Количество 1–1000:** на столбце «Количество» задайте правило «Целое число, между 1 и 1000». Впишите `0` или текст — получите отказ.
6. **Обвести неверные:** «Проверка данных» → «Обвести неверные данные» — если в существующих данных есть нарушения, они подсветятся.

---

## Задание 4. Дубликаты и поиск ошибок (10 минут)

1. **Увидеть дубликаты (без удаления):** выделите «Товар» → Условное форматирование → «Повторяющиеся значения».
2. **Список уникальных городов:** Данные → «Дополнительно» (расширенный фильтр) → «Только уникальные записи» → скопировать в другое место. (В 365 — быстрее `=УНИК(Продажи[Город])`.)
3. **Удаление дубликатов (на копии!):** скопируйте таблицу на новый лист → Данные → «Удалить дубликаты» → по всем столбцам. Сколько удалилось?
4. **Найти пустые:** `Ctrl`+`G` → «Выделить» → «Пустые ячейки» (если есть). Или `=СЧИТАТЬПУСТОТЫ(Продажи[Город])`.

> **Итог:** данные фильтруются в клик срезами, итог живой, ввод защищён списками, дубли под контролем — таблица готова к сводным.

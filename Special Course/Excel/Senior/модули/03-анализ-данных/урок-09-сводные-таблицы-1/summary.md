# Урок 9. Сводные таблицы (часть 1) — резюме

---

## Что такое сводная
Сворачивает тысячи строк в отчёт **мышью**, без формул. Источник — плоская/«умная» таблица. Не меняет исходные данные.

## 4 области
| Область | Что кладём |
|---------|-----------|
| **Строки** | по чему группируем (Город, Менеджер) |
| **Столбцы** | второе измерение (Категория, Месяц) |
| **Значения** | что считаем (Сумма, Количество) |
| **Фильтры** | общий фильтр (Год, Канал) |

Создать: Вставка → «Сводная таблица».

## Группировка
- Даты → правый клик → «Группировать» → «Месяцы»/«Кварталы».
- Числа → по диапазонам; вручную — объединить в свою группу.

## ⭐ «Показать значения как»
Без формул: **% от общей суммы**, % по строке, **ранг**, с нарастающим итогом, % от предыдущего.
Приём «для начальства»: два поля Суммы — рубли + доля %.

## Важно
- Сводная **не обновляется сама!** Правый клик → «Обновить» (`Alt`+`F5`; все — `Ctrl`+`Alt`+`F5`).
- Числовой формат задавайте в **параметрах поля**, чтобы держался при обновлении.
- Сводная диаграмма связана со сводной.
- Быстрая альтернатива: Данные → «Промежуточный итог» / «Группировать».

---

## Что должно остаться в голове
1. Свод = перетащить поля по 4 областям.
2. Группировка дат «по месяцам» — самый частый разрез.
3. «% от общей суммы» и «Ранг» — без формул.
4. После изменения данных — **Обновить**.

## ✅ Вывод урока
Вы освоили главный инструмент аналитика: то, на что уходил час ручных `СУММЕСЛИМН`, теперь делается за минуту перетаскиванием. Отчёты «кто где сколько» и «доли по городам» — готовы к совещанию.

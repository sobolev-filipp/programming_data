# Урок 9. Практика на занятии

> ## 🎯 Рабочая ситуация
> **Марина Викторовна:** *«К совещанию нужен свод: сколько выручки по каждому городу, кто из менеджеров сколько продал, и как идут продажи по месяцам. И покажи доли — какой город даёт основную выручку. Только быстро, без ручных формул»*.
> **Что сдать:** сводная «город × выручка» с долями (%), свод по менеджерам, динамика по месяцам и сводная диаграмма.
> Легенда — в [СЦЕНАРИЙ-КУРСА.md](../../../СЦЕНАРИЙ-КУРСА.md).

> Файл: `материалы/Продажи.xlsx` («умная» таблица `Продажи`, столбец «Сумма» посчитан).
>
> 📂 **Скачать материалы:** [Продажи.xlsx](../../../материалы/Продажи.xlsx).

---

## Задание 1. Первая сводная

1. Встаньте в данные → Вставка → «Сводная таблица» → «На новый лист» → ОК.
2. В списке полей: перетащите **«Город»** в область **Строки**, **«Сумма»** — в **Значения**.
   - ✅ Готово: выручка по городам. 300 строк свернулись в 6 строк за секунды.
3. Отсортируйте сводную по убыванию суммы (правый клик по числам → Сортировка).
4. Смените имя листа на `Свод_города`.

---

## Задание 2. Двумерный отчёт и фильтр

1. Добавьте **«Менеджер»** в **Столбцы** — получилась матрица «город × менеджер».
2. Уберите «Менеджер», вместо этого положите **«Категория»** в Столбцы — «город × категория».
3. Добавьте **«Канал продаж»** в область **Фильтры** — сверху появился фильтр. Выберите «Онлайн-магазин» — весь свод пересчитался только по онлайну.
4. Верните фильтр на «Все».

---

## Задание 3. Группировка по месяцам + доли

1. Новая сводная (или очистите поля): **«Дата заказа»** в Строки.
2. Правый клик по любой дате в сводной → «Группировать» → выберите **«Месяцы»** → ОК. Теперь строки — месяцы.
3. **«Сумма»** в Значения — динамика выручки по месяцам.
4. **Доли:** перетащите «Сумма» в Значения **второй раз**. По второму полю: клик → «Дополнительные вычисления» → **«% от общей суммы»**. Переименуйте столбцы «Выручка, ₽» и «Доля, %».
5. Обсудите: руководитель видит и рубли, и вклад каждого месяца.

---

## Задание 4. Ранг, диаграмма, обновление

1. **Ранг менеджеров:** сводная «Менеджер (Строки) × Сумма (Значения)». Добавьте второе поле «Сумма» → «Показать значения как» → **«Ранг по убыванию»**. Видно место каждого (1-й, 2-й…).
2. **Сводная диаграмма:** встаньте в сводную → «Анализ сводной таблицы» → «Сводная диаграмма» → «Гистограмма» → ОК. График по менеджерам.
3. **Обновление (важно!):** вернитесь на лист `Продажи`, измените количество в первом заказе (сумма вырастет). Вернитесь в сводную — **она не изменилась**. Правый клик → «Обновить» (`Alt`+`F5`) — теперь пересчиталась. Проговорите: сводная не живая, надо обновлять.
4. **Промежуточные итоги (бонус):** на копии данных отсортируйте по «Город» → Данные → «Промежуточный итог» → «При каждом изменении в: Город», «Операция: Сумма», «Добавить итог по: Сумма». Слева появилась структура со сворачиванием.

> **Итог:** вы собрали несколько сводных отчётов и диаграмму мышью за минуты — то, на что раньше уходил час.

# Урок 10. Домашнее задание

> **Файлы:** `Продажи.xlsx`, `Планы.xlsx` → копия `Продажи_ДЗ_Урок10.xlsx`.
> 📂 [Продажи.xlsx](../../../материалы/Продажи.xlsx) · [Планы.xlsx](../../../материалы/Планы.xlsx)
> **Роль:** аналитик готовит интерактивный отчёт с план-фактом.

---

## Задание 1. Интерактивный свод
1. Две сводные: «Город × Выручка» и «Канал продаж × Выручка».
2. Один срез «Категория», подключённый **к обеим** («Подключения к отчётам»).
3. Временная шкала по «Дате заказа».
4. Проверьте: клик по срезу перестраивает обе сводные.

## Задание 2. Вычисляемое поле
1. Сводная «Менеджер × Сумма».
2. Вычисляемое поле «Бонус» = `Сумма * 0,03`.
3. Второе поле «Сумма» как «% от общей суммы» (доля менеджера).

## Задание 3. ⭐ План-факт
1. Свод факта по менеджерам.
2. Рядом: Факт, План (`ВПР`/`ПРОСМОТРX` из `Планы.xlsx`), Выполнение = Факт/План (%).
3. Условное форматирование: <100% — красным, ≥100% — зелёным.
4. Ответьте письменно: сколько менеджеров выполнили план? Кто хуже всех?

## Задание 4. Плитки через GetPivotData
Сделайте 3 «плитки» (крупные ячейки) с ключевыми числами через `ПОЛУЧИТЬ.ДАННЫЕ.СВОДНОЙ`:
- «Общая выручка», «Лучший менеджер (сумма)», «Выручка по Москве».
(Поставьте `=`, кликните нужную ячейку сводной — функция подставится сама.)

---

## Что сдать
`Продажи_ДЗ_Урок10.xlsx` с интерактивным сводом, план-фактом (с подсветкой) и плитками. Письменный ответ по Заданию 3.

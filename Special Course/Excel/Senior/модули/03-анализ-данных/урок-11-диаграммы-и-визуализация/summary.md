# Урок 11. Диаграммы и визуализация — резюме

---

## ⭐ Тип графика под задачу
| Задача | Тип |
|--------|-----|
| Сравнить категории | Столбчатая / линейчатая |
| Динамика во времени | График (линия) |
| Доли целого (≤5) | Круговая / кольцевая |
| Связь двух величин | Точечная |
| Две разные величины | Комбинированная (§ вторая ось) |
| Факт vs план | Комбо / гистограмма с целью |

Правила: категории → столбцы, время → линия, круг — только для долей и ≤5 секторов.

## Построение
- `Alt`+`F1` — график на листе; `F11` — на отдельном.
- «+» рядом с графиком — элементы (заголовок, подписи данных, легенда).
- Подписи данных часто заменяют легенду и чище.

## ⭐ Комбо + вторая ось
Для величин **разного масштаба** (₽ и %): Вставка → «Комбинированная» → одному ряду «Вспомогательная ось». Выручка — столбцы (левая ось), % выполнения — линия (правая).

## Спарклайны
Мини-график в одной ячейке (Вставка → «Спарклайны»). Тренд рядом с числами.

## Оформление «для руководителя»
Чисто: осмысленный заголовок, без 3D/лишних цветов, один акцент, сортировка по величине, убрать сетку. График отвечает на вопрос за 2 секунды.

## Сводная диаграмма
Связана со срезами → живой график дашборда.

---

## Что должно остаться в голове
1. Сначала выбери **правильный тип**, потом рисуй.
2. Разные масштабы → **вторая ось** (комбо).
3. Меньше украшательств — лучше читается.
4. Сводная диаграмма + срез = интерактив.

# Урок 6. Работа с текстом — резюме

---

## Чистка (рефлексы)
- `=СЖПРОБЕЛЫ(A2)` (TRIM) — убрать лишние пробелы. **Делать перед любым поиском/сравнением!**
- `=ПРОПНАЧ/ПРОПИСН/СТРОЧН(A2)` — регистр.
- `=ДЛСТР(A2)` — длина; `=ПЕЧСИМВ(A2)` — убрать служебные символы.

## Извлечение
| Функция | Что |
|---------|-----|
| `=ЛЕВСИМВ(A2; N)` | N символов слева |
| `=ПРАВСИМВ(A2; N)` | N справа |
| `=ПСТР(A2; старт; длина)` | из середины |
| `=НАЙТИ(" "; A2)` | позиция символа |

**Фамилия из ФИО:** `=ЛЕВСИМВ(A2; НАЙТИ(" "; A2)-1)`.

## Замена
- `=ПОДСТАВИТЬ(текст; старое; новое)` — по значению (убрать дефисы: `ПОДСТАВИТЬ(A2;"-";"")`).
- `=ЗАМЕНИТЬ(текст; старт; N; новое)` — по позиции.

## Склейка
- `=A2 & " " & B2` — быстро склеить.
- `=ОБЪЕДИНИТЬ("; "; ИСТИНА; A2:A10)` — диапазон через разделитель.
- `=ТЕКСТ(число; "ДД.ММ.ГГГГ")` — число/дата в текст по формату.

## ⭐ Без формул
- **«Текст по столбцам»** (Данные) — разбить по разделителю.
- **`Ctrl`+`E`** (Мгновенное заполнение) — один образец → Excel заполнит по шаблону.
  - Формулы пересчитываются; `Ctrl`+`E` — разовое действие.

---

## Что должно остаться в голове
1. `СЖПРОБЕЛЫ` — рефлекс (лечит `#Н/Д` из урока 5).
2. Извлечение = «найти позицию (`НАЙТИ`) → взять кусок (`ЛЕВСИМВ`/`ПСТР`)».
3. `Ctrl`+`E` — быстрая чистка без формул.
4. `&` — склейка; `ТЕКСТ` — число в текст с форматом.

## ✅ Вывод урока
Любая «грязная» выгрузка теперь вам по плечу: чистите пробелы, разбираете ФИО, нормализуете телефоны — формулами и `Ctrl`+`E`. Это то, с чего начинается почти любая реальная задача с чужими данными.

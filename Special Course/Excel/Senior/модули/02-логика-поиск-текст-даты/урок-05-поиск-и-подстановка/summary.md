# Урок 5. Поиск и подстановка — резюме

---

## Зачем
«Сшить» таблицы: подтянуть данные из справочника по **ключу**, который есть в обеих (например, «Товар» → «Цена» из прайса).

## `ВПР` (VLOOKUP)
```
=ВПР(что_ищем; таблица; № столбца; 0)
=ВПР(E2; Прайс!$A$2:$C$17; 3; 0)
```
**Три правила намертво:**
1. Ключ — в **первом** столбце справочника (ищет только вправо).
2. Последний аргумент — **`0`** (точное совпадение).
3. Справочник фиксируем **`$`** (или имя / «умная» таблица).

Обёртка: `=ЕСЛИОШИБКА(ВПР(...); "нет в прайсе")`.

## Ошибки `ВПР` (почему «не находит»)
- **Пробелы** в ключе → `#Н/Д` (лечим `СЖПРОБЕЛЫ`, урок 6).
- **Текст vs число** — разные типы не совпадают.
- Забыли `0` → неверный результат.
- Справочник без `$` → «уехал».
- Нужен **поиск влево** — `ВПР` не умеет.

## `ИНДЕКС` + `ПОИСКПОЗ`
```
=ИНДЕКС(столбец_результата; ПОИСКПОЗ(что; столбец_ключа; 0))
```
- Ищет в **любую** сторону, устойчив к вставке столбцов.

## `ПРОСМОТРX` (XLOOKUP, 365/2021) — современный дефолт
```
=ПРОСМОТРX(что; где_искать; что_вернуть; "если_нет")
```
- Любая сторона, точное совпадение по умолчанию, «не найдено» встроено.

## Что выбрать
- 365/2021 → **`ПРОСМОТРX`**. Старые версии → `ВПР` / `ИНДЕКС+ПОИСКПОЗ`. Читать `ВПР` уметь всегда.

---

## Что должно остаться в голове
1. `ВПР`: ключ в первом столбце, `0` в конце, справочник в `$`.
2. `#Н/Д` — сначала проверь **пробелы и типы**, потом формулу.
3. Поиск влево — `ИНДЕКС+ПОИСКПОЗ` или `ПРОСМОТРX`.

## ✅ Вывод урока
Вы умеете соединять данные из разных таблиц — ключевой навык аналитика. Заказы теперь автоматически «обрастают» данными из справочников, и вы знаете, как чинить `#Н/Д`, когда поиск капризничает.

## Задание 1. ⭐ `ВПР` — подтягиваем категорию и цену (14 минут)

На листе `Продажи` добавим столбец «Цена из прайса».

1. Сделайте прайс «умной» таблицей или запомните его диапазон (напр. `Прайс!$A$2:$C$17`).
2. В новом столбце первая формула:
   `=ВПР(E2; Прайс!$A$2:$C$17; 3; 0)`
   - `E2` — товар из заказа; `3` — столбец «Цена» в прайсе; `0` — точное совпадение.
   - **Зафиксируйте справочник `$`** (нажмите `F4` на диапазоне) — обязательно!
3. Залейте вниз двойным кликом. Проверьте `E100`: справочник не «уехал» (`Прайс!$A$2:$C$17` тот же).
4. Аналогично подтяните «Категорию» (столбец `2`): `=ВПР(E2; Прайс!$A$2:$C$17; 2; 0)`.
5. **Оберните от ошибок:** `=ЕСЛИОШИБКА(ВПР(E2; Прайс!$A$2:$C$17; 3; 0); "нет в прайсе")`.

> Сравните подтянутую цену с исходным столбцом «Цена» — должны совпасть (данные согласованы).

## Задание 2. Ломаем и чиним `ВПР` (10 минут)

Учимся диагностировать `#Н/Д`.

1. **Слом пробелом:** на листе `Прайс` в названии одного товара допишите пробел в конце («Мышь беспроводная »). Вернитесь в `Продажи` — по этому товару появился `#Н/Д`.
2. **Диагностика:** ключи вроде одинаковые, но не совпадают из-за пробела. Проговорите: `ВПР` требует **точного** совпадения символ-в-символ.
3. **Лечение:** уберите пробел в прайсе (или примените `СЖПРОБЕЛЫ` — забежим вперёд в урок 6: `=ВПР(СЖПРОБЕЛЫ(E2); ...)` не поможет, если пробел в справочнике; чинить надо источник).
4. **Слом номером столбца:** поставьте в `ВПР` номер `5` (которого нет) → `#ССЫЛКА!`. Верните `3`.
5. **Забыли `0`:** уберите последний аргумент → возможен неверный результат. Верните `0`. Проговорите, почему `0` критичен.

## Задание 3. `ИНДЕКС` + `ПОИСКПОЗ` — поиск влево (12 минут)

Задача, которую `ВПР` не решает: по **цене** найти **товар** (результат левее ключа).

1. Сначала `ПОИСКПОЗ` отдельно — найдём позицию товара «Монитор 27" IPS» в прайсе:
   `=ПОИСКПОЗ("Монитор 27"" IPS"; Прайс!$A$2:$A$17; 0)` → номер строки.
2. `ИНДЕКС` отдельно — цена в этой позиции:
   `=ИНДЕКС(Прайс!$C$2:$C$17; <номер>)`.
3. Соедините в одну формулу (подтянуть категорию по товару из заказа):
   `=ИНДЕКС(Прайс!$B$2:$B$17; ПОИСКПОЗ(E2; Прайс!$A$2:$A$17; 0))`
4. **Демо «поиск влево»:** попробуйте по цене вернуть товар — с `ВПР` невозможно (товар левее цены), с `ИНДЕКС+ПОИСКПОЗ` — легко:
   `=ИНДЕКС(Прайс!$A$2:$A$17; ПОИСКПОЗ(18990; Прайс!$C$2:$C$17; 0))`.

## Задание 4. `ПРОСМОТРX` — современный способ (10 минут)

> Если версия 365/2021. В 2016/2019 — пропустить или показать «на будущее».

1. Та же цена из прайса, но короче и надёжнее:
   `=ПРОСМОТРX(E2; Прайс!$A$2:$A$17; Прайс!$C$2:$C$17; "нет в прайсе")`
   - Точное совпадение по умолчанию, «не найдено» встроено — без `ЕСЛИОШИБКА`.
2. **Поиск влево** без `ИНДЕКС+ПОИСКПОЗ`:
   `=ПРОСМОТРX(18990; Прайс!$C$2:$C$17; Прайс!$A$2:$A$17)` → товар по цене.
3. Обсудите: одна функция заменила `ВПР` и `ИНДЕКС+ПОИСКПОЗ`, решив их проблемы.

> **Итог:** вы умеете «сшивать» таблицы тремя способами и чинить ошибки поиска — ключевой рабочий навык.

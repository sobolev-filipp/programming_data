# Урок 4. Домашнее задание

> **Файл:** `Продажи.xlsx` → копия `Продажи_ДЗ_Урок4.xlsx`.
> **Цель:** закрепить `ЕСЛИ`, условия и `СУММЕСЛИМН` на реальных вопросах.
> **Время:** 30–40 минут.

---

## Задание 1. Статусы через `ЕСЛИ`

1. Столбец «Размер сделки»: `Крупная` при сумме ≥ 80 000, иначе `Мелкая`.
2. Столбец «Скидка положена»: `ЕСЛИ` количество ≥ 4 → «10%», иначе «0%».
3. Столбец «Приоритет»: с помощью `ИЛИ` — «Высокий», если сумма > 100 000 **или** количество ≥ 6; иначе «Обычный».

---

## Задание 2. Категории `ЕСЛИМН`

Постройте столбец «Грейд» по количеству в заказе:
- ≥ 8 → «Оптовик»,
- ≥ 4 → «Средний»,
- ≥ 1 → «Розница».

Сделайте это функцией `ЕСЛИМН` (с завершающим `ИСТИНА; "—"` на всякий случай).

---

## Задание 3. `ЕСЛИОШИБКА`

Добавьте столбец «Доля скидки от цены»: `= (Цена − что-то) / Цена`, где в паре строк специально сделайте пустую/нулевую цену. Оберните формулу в `ЕСЛИОШИБКА(...; "—")`, чтобы вместо ошибок был прочерк.

---

## Задание 4. ⭐ Отчёт по условиям

Соберите на отдельном листе `Отчёт` (ссылайтесь на таблицу `Продажи`):

| Вопрос | Функция |
|--------|---------|
| Сколько всего заказов из Казани? | `СЧЁТЕСЛИ` |
| Выручка по Казани | `СУММЕСЛИ` |
| Сколько заказов дороже 50 000? | `СЧЁТЕСЛИ` с `">50000"` |
| Выручка Ивановой по опту (кол-во ≥ 5) | `СУММЕСЛИМН` (2 условия) |
| Средний чек по Санкт-Петербургу | `СРЗНАЧЕСЛИ` |
| Сколько строк с «Монитор» в названии | `СЧЁТЕСЛИ` с `"*Монитор*"` |

**Матрица «менеджер × город»** (со звёздочкой):
- В строках — менеджеры, в столбцах — города.
- В каждой ячейке — `СУММЕСЛИМН`, где условия ссылаются на заголовки строки/столбца.
- Подсказка про `$`: зафиксируйте столбец у менеджера (`$A2`) и строку у города (`B$1`) — тогда одна формула зальётся на всю матрицу. (Это прямое применение смешанных ссылок из урока 2!)

---

## Задание 5 (проверка себя)

Сумма выручки по всем городам (через `СУММЕСЛИ` по каждому) должна совпасть с общим `=СУММ(Продажи[Сумма])`. Если не совпало — где-то опечатка в названии города (пробел, регистр). Найдите и объясните.

# Урок 4. Логика и условные подсчёты — резюме

---

## Сравнения (кирпичики)
`=` `<>` `>` `<` `>=` `<=` → дают `ИСТИНА`/`ЛОЖЬ`.

## `ЕСЛИ` (IF)
```
=ЕСЛИ(условие; если_да; если_нет)
=ЕСЛИ(H2>=100000; "Крупный"; "Обычный")
```
- Текст в кавычках, числа без. Пусто = `""`.

## Много условий
- **Вложенные `ЕСЛИ`:** `=ЕСЛИ(...;"A"; ЕСЛИ(...;"B";"C"))` — от строгого к мягкому.
- **`ЕСЛИМН`** (читабельнее): `=ЕСЛИМН(усл1;"A"; усл2;"B"; ИСТИНА;"C")`.
- **`И`/`ИЛИ`/`НЕ` — функции:** `=ЕСЛИ(И(F2>=5; C2="Москва"); ...)`. Не `and`!

## `ЕСЛИОШИБКА`
```
=ЕСЛИОШИБКА(формула; "заглушка")
```
Аккуратные ошибки. НО: не прячьте настоящие баги — сначала поймите ошибку.

## ⭐ Условные подсчёты (сердце отчётов)
```
=СЧЁТЕСЛИ(диапазон; условие)
=СУММЕСЛИ(диап_условия; условие; диап_суммы)
=СЧЁТЕСЛИМН(диап1;усл1; диап2;усл2; …)
=СУММЕСЛИМН(диап_суммы; диап1;усл1; диап2;усл2; …)   ← сумма ПЕРВАЯ!
```
- Условия: `"Москва"`, `">100000"`, `"<>0"`, подстановка `"*Ноутбук*"`, `"А?"`.
- **Запомнить порядок:** у `СУММЕСЛИ` диапазон суммы — последний; у `СУММЕСЛИМН` — первый.

---

## Что должно остаться в голове
1. `ЕСЛИ` — таблица принимает решения; `ЕСЛИМН` — для многих градаций.
2. `И`/`ИЛИ` — функции со своими скобками.
3. `СУММЕСЛИМН` — главный инструмент отчётов; следи за порядком аргументов.
4. `ЕСЛИОШИБКА` — гасит ошибки, но не прячь баги.

# Урок 4. Практика на занятии

> Файл: `материалы/Продажи.xlsx` («умная» таблица `Продажи`). Пишем формулы принятия решений и условные отчёты.

## Задание 1. `ЕСЛИ` — статус заказа (10 минут)

1. Добавьте столбец «Тип заказа». В первой ячейке:
   `=ЕСЛИ([@Сумма]>=100000; "Крупный"; "Обычный")`
   (если не «умная» таблица — `=ЕСЛИ(H2>=100000;"Крупный";"Обычный")`, залейте вниз).
2. Добавьте столбец «Канал»: опт при количестве ≥ 5, иначе розница:
   `=ЕСЛИ([@Количество]>=5; "Опт"; "Розница")`
3. Столбец «Относительно среднего»:
   `=ЕСЛИ([@Сумма]>СРЗНАЧ(Продажи[Сумма]); "выше среднего"; "ниже среднего")`
   - Разберите: `СРЗНАЧ(Продажи[Сумма])` — среднее по всему столбцу (в «умной» таблице фиксировать `$` не нужно, имя столбца уже абсолютно).

## Задание 2. Много условий: вложенные `ЕСЛИ` и `ЕСЛИМН` (12 минут)

Присвоим заказам категорию A/B/C/D по сумме.

1. **Вложенные `ЕСЛИ`:**
   ```
   =ЕСЛИ([@Сумма]>=100000;"A";
      ЕСЛИ([@Сумма]>=50000;"B";
         ЕСЛИ([@Сумма]>=10000;"C";"D")))
   ```
2. **То же через `ЕСЛИМН`** (в соседнем столбце — сравнить):
   ```
   =ЕСЛИМН([@Сумма]>=100000;"A"; [@Сумма]>=50000;"B"; [@Сумма]>=10000;"C"; ИСТИНА;"D")
   ```
   Обсудите: результат одинаковый, но `ЕСЛИМН` читается легче.
3. **`И` в условии:** столбец «VIP-опт»:
   `=ЕСЛИ(И([@Количество]>=5; [@Сумма]>=100000); "ДА"; "")`
   - Специально сначала попробуйте написать через `... >=5 И ...` — получите ошибку, потом почините на `И(...)`.

## Задание 3. `ЕСЛИОШИБКА` (8 минут)

1. Добавьте столбец «Цена за шт (проверка)»: `=[@Сумма]/[@Количество]`.
2. Смоделируйте ошибку: временно поставьте в одной строке количество `0` — появится `#ДЕЛ/0!`.
3. Оберните: `=ЕСЛИОШИБКА([@Сумма]/[@Количество]; 0)` — вместо ошибки 0.
4. Проговорите предупреждение: `ЕСЛИОШИБКА` прячет **все** ошибки — сначала убеждаемся, что формула верна. Верните количество обратно.

## Задание 4. ⭐ Условный отчёт (`СУММЕСЛИМН`) (14 минут)

Соберём мини-отчёт в свободной области (или на листе `Итоги`).

1. **Сколько заказов из Москвы:** `=СЧЁТЕСЛИ(Продажи[Город]; "Москва")`
2. **Выручка по Москве:** `=СУММЕСЛИ(Продажи[Город]; "Москва"; Продажи[Сумма])`
3. **Крупных заказов (>100 000):** `=СЧЁТЕСЛИ(Продажи[Сумма]; ">100000")`
4. **Выручка Петрова из Москвы (2 условия):**
   `=СУММЕСЛИМН(Продажи[Сумма]; Продажи[Город];"Москва"; Продажи[Менеджер];"Петров С.")`
   - Подчеркните: у `СУММЕСЛИМН` диапазон суммы — **первый** аргумент.
5. **Опт-выручка по Москве:**
   `=СУММЕСЛИМН(Продажи[Сумма]; Продажи[Город];"Москва"; Продажи[Количество];">=5")`
6. **Мини-матрица по менеджерам:** слева впишите список менеджеров, справа — `=СУММЕСЛИ(Продажи[Менеджер]; A_ячейка; Продажи[Сумма])`, залейте вниз. Получилась выручка по каждому — прообраз сводной.
7. **Подстановочные знаки:** `=СЧЁТЕСЛИ(Продажи[Товар]; "*Ноутбук*")` — сколько строк с ноутбуками.

> **Итог:** таблица теперь «думает» (статусы, категории) и вы умеете строить любые условные отчёты — фундамент под сводные и дашборд.

# Урок 2. Формулы и ссылки — резюме

---

## Формула
- Всегда начинается с **`=`**.
- Ссылка на ячейку (`=B2*C2`) делает таблицу «живой»: поменял исходные — результат пересчитался.
- Порядок действий как в математике: `^` → `* /` → `+ -`. Скобки первыми.

## ⭐ Типы ссылок (главное урока)

| Ссылка | Поведение при копировании | Когда |
|--------|---------------------------|-------|
| `B2` | **едет** (относительная) | построчные расчёты (кол-во × цена) |
| `$B$2` | **не едет** (абсолютная) | общий курс, скидка, ставка, итог |
| `A$1` | строка стоит, столбец едет | таблицы (тянем и вниз, и вбок) |
| `$A1` | столбец стоит, строка едет | то же |

**Клавиша `F4`** переключает: `B2` → `$B$2` → `B$2` → `$B2` → по кругу.

**Правило:** «Должна ли ссылка поехать при копировании? Нет → жми `F4` (поставь `$`)».

## Базовые функции

| Функция | Что |
|---------|-----|
| `=СУММ(E2:E100)` | сумма |
| `=СРЗНАЧ(...)` | среднее |
| `=СЧЁТ(...)` / `=СЧЁТЗ(...)` | кол-во чисел / кол-во непустых |
| `=МИН(...)` / `=МАКС(...)` | минимум / максимум |
| `=ОКРУГЛ(число; 2)` | округлить (2 = до копеек, 0 = до рубля) |

💡 **Автосумма:** `Alt`+`=` под столбцом чисел.
💡 **Залить формулу вниз:** двойной клик по маркеру (или `Ctrl`+`D`).

## Имена диапазонов
- Выделить ячейку → в **поле имени** вписать `Курс` → `Enter`.
- Теперь `=H2/Курс` вместо `=H2/$K$1`. Читаемо, и `$` не нужен (имя абсолютно).

## Отладка «не считается»
- `Ctrl`+`` ` `` — показать все формулы.
- `F9` — вычислить кусок формулы (потом **`Esc`**!).
- Причины: формат ячейки «Текст»; включён показ формул; «текстовые» числа.

---

## Что должно остаться в голове
1. `=` — начало формулы; ссылки делают таблицу живой.
2. `$` (клавиша `F4`) — фиксирует ссылку, чтобы не «уехала».
3. `СУММ/СРЗНАЧ/СЧЁТ/МИН/МАКС/ОКРУГЛ` + `Alt`+`=`.
4. Двойной клик по маркеру заливает формулу на весь столбец.

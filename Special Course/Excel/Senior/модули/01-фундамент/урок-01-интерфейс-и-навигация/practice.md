# Урок 1. Практика на занятии

> ## 🎯 Рабочая ситуация
> **Ваш первый день аналитиком в «ТехноТрейд».** Коммерческий директор **Марина Викторовна** пишет: *«Скинула тебе выгрузку заказов и список из отдела кадров. Разберись, что там за данные, всё ли в порядке, и приведи в рабочий вид. И покажи на маленьком примере, как это вообще считается»*.
> **Что сдать:** данные, приведённые в порядок (типы, структура), ваша первая посчитанная мини-таблица и лист «Итоги» с базовыми показателями.
> Легенда курса — в [СЦЕНАРИЙ-КУРСА.md](../../../СЦЕНАРИЙ-КУРСА.md).

> Файлы: `материалы/Продажи.xlsx`, `материалы/Сотрудники.xlsx`. Задания — реальная работа, а не «нажми кнопку». Клавиши применяем по ходу.
>
> 📂 **Скачать материалы:** [Продажи.xlsx](../../../материалы/Продажи.xlsx) · [Сотрудники.xlsx](../../../материалы/Сотрудники.xlsx) (или пересоздать — см. [материалы/README.md](../../../материалы/README.md)).

## Задание 1. Проф-настройка и ориентация (5 минут)

1. Откройте `Продажи.xlsx`. Оцените массив: `Ctrl`+`End` — адрес последней ячейки, сколько строк данных?
2. Закрепите шапку и первый столбец: встаньте в `B2` → Вид → «Закрепить области». Прокрутите `Ctrl`+`↓` — заголовки на месте.
3. Добавьте на панель быстрого доступа «Специальная вставка» (правый клик по кнопке на ленте → «Добавить…»).
4. Выделите столбец «Количество» (`Ctrl`+`Shift`+`↓`) — прочитайте Сумму/Среднее в строке состояния (без формул).

## Задание 2. ⭐ Собираем таблицу с нуля и пишем первые формулы (12 минут)

На **новом листе** (`Shift`+`F11`, назовите `Мой отчёт`) построим мини-отчёт по продажам.

1. **Введите шапку и данные** (используйте `Tab` для перехода вправо, `Enter` — вниз):

   | A | B | C | D |
   |---|---|---|---|
   | Товар | Кол-во | Цена | Сумма |
   | Мышь | 3 | 1490 | |
   | Монитор | 2 | 18990 | |
   | Клавиатура | 5 | 4990 | |
   | Наушники | 1 | 12990 | |

2. **Первая формула.** В `D2` напечатайте `=`, кликните `B2`, напечатайте `*`, кликните `C2`, `Enter`. Получилось `=B2*C2`. Посмотрите: в ячейке — число, в **строке формул** — формула.

3. **Оживите таблицу.** Измените `B2` с 3 на 10 — `D2` пересчиталась сама. Верните 3. Проговорите: формула со ссылками = живой расчёт.

4. **Залейте формулу вниз.** Встаньте на `D2`, дважды кликните по маркеру (крестик в углу). `D3:D5` заполнились, ссылки сдвинулись (`=B3*C3`…). Проверьте `D4` в строке формул.

5. **Итог функцией.** В `D6` нажмите `Alt`+`=` (автосумма) — Excel подставит `=СУММ(D2:D5)`. Проверьте диапазон, `Enter`. В `C6` подпишите «Итого».

6. **Средняя цена.** В `F1` напишите «Средняя цена», в `F2`: `=СРЗНАЧ(C2:C5)`.

✅ За 10 минут вы построили рабочую таблицу и посчитали её формулами. Глубину формул возьмём на уроке 2.

## Задание 3. ⭐ Диагностика и лечение типов данных (12 минут)

Откройте `Сотрудники.xlsx` — «грязная» выгрузка.

1. **Найдите проблему с датами.** Столбец «Дата приёма» прижат **влево** → это **текст**, не даты. Проверка: выделите столбец — в строке состояния нет «Суммы».
2. **Докажите.** Встаньте на дату, `Ctrl`+`Shift`+`~` (общий формат). Настоящая дата стала бы числом (~45000); текстовая — не изменится. `Ctrl`+`Z`.
3. **Вылечите «Текст по столбцам»:** выделить столбец → Данные → «Текст по столбцам» → Далее → Далее → формат «дата: ДМГ» → Готово. ✅ Даты прижались вправо, теперь сортируются.
4. **Текст-числа (демо):** на пустом листе `A1` = `'1000` (с апострофом), `A2` = `2000`. `A1` слева (текст), `A2` справа (число). Сравните `=A1+A2` и `=СУММ(A1:A2)` — `СУММ` проигнорирует текст.
5. **Лечение «умножить на 1»:** `B1` = `1`, `Ctrl`+`C`, выделить `A1` → `Ctrl`+`Alt`+`V` → «Умножить» → ОК. `A1` стал числом.

## Задание 4. Специальная вставка: 3 реальных сценария (12 минут)

Работаем на листе `Мой отчёт` (та самая мини-таблица с формулами из Задания 2).

1. **«Значения» — готовим к отправке.**
   - Выделите столбец «Сумма» (с формулами `=B2*C2`) → `Ctrl`+`C` → `Ctrl`+`Alt`+`V` → «Значения» → ОК.
   - Проверьте `D2`: в строке формул теперь **число**. Формула «застыла» — файл можно отправлять, ничего не «поедет». (`Ctrl`+`Z`, чтобы вернуть формулы.)

2. **«Умножить» — поднять цены на 10%.**
   - Скопируйте столбец «Цена» на пустой лист (чтобы не портить исходные).
   - В свободную ячейку впишите `1,1`, `Ctrl`+`C`.
   - Выделите скопированные цены → `Ctrl`+`Alt`+`V` → «Умножить» → ОК. Все цены выросли на 10% без единой формулы.

3. **«Транспонировать» — развернуть шапку.**
   - Скопируйте шапку `A1:D1` → встаньте в свободную ячейку → `Ctrl`+`Alt`+`V` → «Транспонировать» → ОК. Горизонтальная шапка стала вертикальным списком.

## Задание 5. Организация книги и связь листов (7 минут)

На `Продажи.xlsx`:

1. Создайте лист `Итоги` (`Shift`+`F11`, переименуйте, задайте цвет ярлычка).
2. Соберите показатели **ссылками на лист `Продажи`** (используем столбцы, которые уже заполнены):
   - `A1` = `Всего заказов`, `B1` = `=СЧЁТЗ(Продажи!B2:B301)`.
   - `A2` = `Средняя цена`, `B2` = `=СРЗНАЧ(Продажи!G2:G301)`.
   - `A3` = `Макс. количество в заказе`, `B3` = `=МАКС(Продажи!F2:F301)`.
3. Проверьте живую связь: измените цену в первом заказе на `Продажи` — «Средняя цена» на листе `Итоги` пересчитается.
4. Проговорите: данные и отчёт — на разных листах.

> **Выручку** (сумму по столбцу «Сумма») посчитаем на **уроке 2** — там заполним пустой столбец «Сумма» в `Продажи` формулой на все 300 строк и углубимся в ссылки `$`.

> **Итог практики:** вы построили таблицу и посчитали её формулами, починили типы данных, применили спец-вставку в трёх сценариях и связали листы — это уже профессиональная работа.

## ⏱️ Если осталось время (бонус-задания)

> Необязательные задания «на закрепление», если урок идёт быстрее плана. Можно взять бОльшую выгрузку: 📂 [Данные_для_дашборда.xlsx](../../../материалы/Данные_для_дашборда.xlsx) (1200 строк за год).

1. **Навигация на большом файле.** Откройте `Данные_для_дашборда.xlsx`. Дойдите `Ctrl`+`End` до конца, `Ctrl`+`Home` обратно; выделите весь столбец «Сумма» одним `Ctrl`+`Shift`+`↓` и прочитайте итог в строке состояния.
2. **Диагностика типов.** Найдите в `Сотрудники.xlsx` минимум 3 ячейки с «текстовыми» проблемами (даты-текст, двойные пробелы) и почините их тремя разными способами (значок ошибки / текст по столбцам / умножить на 1).
3. **Специальная вставка.** Скопируйте любую мини-таблицу и вставьте её в трёх вариантах рядом: только значения, транспонированно, только форматы. Сравните результат.

> 💡 **Как лучше, а не так.** Единицы измерения («шт.», «₽», «кг») **не пишите текстом в ячейку** (`5 шт.`) — тогда это станет текстом и перестанет считаться. ✅ Правильно: храните число `5`, а «шт.» задайте **пользовательским форматом** (урок 3). Число останется числом, а на экране будет «5 шт.».

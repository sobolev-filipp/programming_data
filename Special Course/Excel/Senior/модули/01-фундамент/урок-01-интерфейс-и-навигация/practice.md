# Урок 1. Практика на занятии

> Работаем на `материалы/Продажи.xlsx` и `материалы/Сотрудники.xlsx`. Задания — реальные рабочие ситуации, а не «нажми кнопку». Клавиши применяем по ходу.

---

## Задание 1. Проф-настройка и ориентация в данных (7 минут)

1. Откройте `Продажи.xlsx`. Оцените размер массива: `Ctrl`+`End` — какой адрес последней ячейки? Сколько строк данных?
2. **Закрепите шапку и первый столбец одновременно:** встаньте в `B2` → Вид → «Закрепить области». Прокрутите `Ctrl`+`↓` — шапка и столбец «Дата» на месте.
3. **Разделите окно:** Вид → «Разделить». Прокрутите верхнюю и нижнюю части независимо — сравните первые и последние заказы. Уберите разделение.
4. **Настройте панель быстрого доступа:** правый клик на любой кнопке ленты → «Добавить на панель быстрого доступа». Добавьте «Формат по образцу». Обратите внимание на `Alt`+цифра.
5. **Быстрый итог без формул:** выделите столбец «Количество» (`Ctrl`+`Shift`+`↓`) — прочитайте Сумму и Среднее в строке состояния внизу справа.

## Задание 2. ⭐ Диагностика и лечение типов данных (12 минут)

Это ядро урока. Откройте `Сотрудники.xlsx` — «грязная» выгрузка.

1. **Найдите проблему с датами.** Столбец «Дата приёма»: посмотрите на выравнивание. Даты прижаты **влево** → это **текст**, а не даты. Проверка: выделите столбец — в строке состояния нет «Суммы», только «Количество».
2. **Докажите, что это текст.** Встаньте на дату, `Ctrl`+`Shift`+`~` (общий формат). Настоящая дата стала бы числом (~45000). Текстовая — не изменится. Верните формат (`Ctrl`+`Z`).
3. **Вылечите через «Текст по столбцам»:**
   - Выделите столбец «Дата приёма» → Данные → «Текст по столбцам» → «Далее» → «Далее» → в шаге 3 выберите формат «дата: ДМГ» → «Готово».
   - ✅ Даты прижались вправо — теперь это настоящие даты, их можно сортировать и вычитать.
4. **Теперь про текст-числа (демо на своём примере):**
   - На пустом листе в `A1` введите `'1000` (с апострофом впереди), в `A2` — `2000` (обычное). Обратите внимание: `A1` прижато влево (текст), `A2` вправо (число).
   - `=A1+A2` — посмотрите результат. Excel всё же сложит, но `СУММ` текст бы проигнорировал — покажите `=СУММ(A1:A2)` vs `=A1+A2`.
   - **Лечение «умножить на 1»:** в `B1` введите `1`, `Ctrl`+`C`. Выделите `A1` → `Ctrl`+`Alt`+`V` → «Умножить» → ОК. `A1` стал числом (прижался вправо).

> **Проговорить:** это самая частая беда с выгрузками. Теперь вы её видите и чините тремя способами (значок ошибки, текст по столбцам, умножить на 1).

## Задание 3. Специальная вставка в деле (10 минут)

На `Продажи.xlsx` (со столбцом «Сумма», если он посчитан; если нет — впишите в `H2` `=F2*G2` и залейте двойным кликом по маркеру).

1. **«Заморозить» формулы в значения:**
   - Выделите столбец «Сумма» → `Ctrl`+`C` → `Ctrl`+`Alt`+`V` → «Значения» → ОК.
   - Проверьте `H2`: в строке формул теперь **число**, а не `=F2*G2`. Формула «застыла».
   - Обсудите: так делают перед отправкой отчёта, чтобы ничего не «поехало». (Сейчас можно `Ctrl`+`Z`, чтобы вернуть формулы для будущих уроков.)

2. **Транспонирование:**
   - Скопируйте шапку таблицы `A1:H1` (`Ctrl`+`C`).
   - Встаньте на пустую ячейку ниже → `Ctrl`+`Alt`+`V` → галочка «Транспонировать» → ОК.
   - ✅ Горизонтальная шапка стала вертикальным списком.

3. **Арифметика вставкой:**
   - Представьте, цены надо поднять на 10% (умножить на 1,1). В пустой ячейке напишите `1,1`, `Ctrl`+`C`.
   - Выделите **копию** столбца «Цена» (сначала скопируйте цены на пустой лист, чтобы не портить данные) → `Ctrl`+`Alt`+`V` → «Умножить» → ОК. Все цены выросли на 10% без единой формулы.

## Задание 4. Организация книги и связь листов (10 минут)

1. **Создайте лист `Итоги`:** `Shift`+`F11`, переименуйте (двойной клик по ярлычку) в `Итоги`, задайте цвет ярлычка.
2. **Свяжите листы:** на листе `Итоги` в `A1` напишите `Всего заказов`, в `B1`: `=СЧЁТЗ(Продажи!B2:B301)`.
   - Разберите: `Продажи!` — обращение к другому листу, `!` — разделитель.
3. Добавьте в `Итоги`: `A2` = `Выручка`, `B2` = `=СУММ(Продажи!H2:H301)`.
4. **Проверьте живую связь:** вернитесь на `Продажи`, измените количество в первом заказе — итог на листе `Итоги` пересчитался.
5. **Принцип:** данные — на одном листе, отчёт — на другом. Не мешаем их в кучу.

## Задание 5. Пользовательский список автозаполнения (6 минут)

1. Файл → Параметры → Дополнительно → «Изменить списки» (кнопка внизу).
2. Введите свой список филиалов, каждый с новой строки: `Москва`, `Санкт-Петербург`, `Казань`, `Новосибирск` → «Добавить» → ОК.
3. На пустом листе напишите `Москва`, потяните маркер вниз — Excel продолжит вашим списком в заданном порядке.
4. Обсудите реальную пользу: повторяющиеся справочники (отделы, филиалы, категории) заполняются автоматически, без копирования.

> **Итог практики:** вы диагностировали и починили типы данных, применили специальную вставку в трёх сценариях, связали листы и настроили автозаполнение под свои данные — это уже профессиональная работа, а не «клики».

# Урок 1. Данные, структура и скорость — резюме

> Настольная шпаргалка урока.

---

## Первая таблица и формулы

- Формула начинается с **`=`**. `=B2*C2` — «перемножь ячейки». В ячейке результат, в строке формул — формула.
- Ссылки делают таблицу **живой**: поменял исходные — итог пересчитался.
- Залить формулу вниз — **двойной клик по маркеру** (крестик в углу ячейки).
- Итог: `=СУММ(D2:D5)` или автосумма **`Alt`+`=`**. Среднее: `=СРЗНАЧ(...)`.
- (Глубину формул и `$` — на уроке 2.)

## ⭐ Типы данных — главное

| Тип | Выравнивание | Особое |
|-----|--------------|--------|
| Число | вправо | считается |
| Текст | влево | не считается |
| Дата | вправо | это **число** дней от 1900 г. |

**Правило:** «число» прижато **влево** = это **текст**, он не суммируется и не находится `ВПР`.

**Лечение «текстовых» чисел и дат:**
1. Значок ошибки (ромбик) → «Преобразовать в число».
2. Данные → «Текст по столбцам» → Готово (для дат — выбрать формат ДМГ).
3. Вписать `1` → скопировать → Специальная вставка → «Умножить».

## Структура данных («плоская таблица»)

Основа будущих сводных и графиков:
- одна строка = один факт, один столбец = один признак;
- шапка в одну строку, без объединённых ячеек;
- никаких пустых строк/столбцов и итогов внутри данных;
- категории единообразно («Москва», не «МСК/москва»).

**Данные и отчёт — на разных листах.**

## Специальная вставка — `Ctrl`+`Alt`+`V`

| Режим | Зачем |
|-------|-------|
| Значения | «заморозить» формулы перед отправкой |
| Транспонировать | строки ↔ столбцы |
| Умножить/Разделить | арифметика по столбцу; чинить текст-числа (×1) |
| Форматы | перенести оформление |

## Связь листов
- `=Продажи!H2` — ячейка с другого листа (`!` — разделитель).
- `Ctrl`+`PageUp`/`Down` — между листами; `Shift`+`F11` — новый лист.

## Скорость
- `Ctrl`+стрелки — прыжок к краю данных; `Ctrl`+`Shift`+стрелки — выделить до края.
- Выделили числа → **строка состояния** внизу: Сумма/Среднее/Кол-во (без формулы).
- `Ctrl`+`Enter` — во все выделенные сразу; двойной клик по маркеру — залить вниз.
- **Пользовательские списки** (Параметры → Изменить списки) — своё автозаполнение (филиалы, отделы).

---

## Что должно остаться в голове
1. Тип данных решает всё; «число слева» — чиню сразу.
2. Данные храню плоской таблицей — потом легко анализировать.
3. Специальная вставка (значения/транспонирование/умножить) — экономит часы.
4. Данные и отчёт держу на разных листах, связываю ссылкой.

## ✅ Вывод урока

# Урок 1. Интерфейс и навигация — резюме

> Короткая шпаргалка по уроку. Держите под рукой первую неделю.

---

## Карта интерфейса

- **Строка формул** (значок `fx`) — показывает *реальное* содержимое ячейки (формулу, а не результат).
- **Поле имени** (слева) — адрес активной ячейки; можно вписать адрес и прыгнуть.
- **Ячейка** = столбец + строка (`B2`). **Диапазон** = `A1:C10` (от … до).
- **Книга** = файл; **лист** = страница; листов может быть много.

## Навигация без мыши (главное)

| Клавиши | Действие |
|---------|----------|
| `Ctrl` + стрелка | прыжок к краю данных |
| `Ctrl` + `Home` / `End` | в начало / в конец таблицы |
| `Ctrl` + `Shift` + стрелка | выделить до края данных |
| `Ctrl` + `A` | выделить таблицу/лист |
| `Ctrl` + `Space` / `Shift` + `Space` | выделить столбец / строку |

💡 Выделите числа → **внизу справа** видно Сумму, Среднее, Количество (без формулы!).

## Типы данных (определяем на глаз)

- **Число** — прижато **вправо**.
- **Текст** — прижат **влево**.
- **Дата** — прижата вправо (внутри это число дней от 1900 г.).
- ⚠️ Число прижато **влево** = это **текст**, он не суммируется. Запомнить и лечить (урок 6).

## Ввод данных

| Клавиши | Действие |
|---------|----------|
| `Enter` / `Tab` | подтвердить вниз / вправо |
| `Ctrl` + `Enter` | ввести во **все** выделенные сразу |
| `Alt` + `Enter` | перенос строки **внутри** ячейки |
| `F2` | редактировать ячейку |
| `Ctrl` + `;` | сегодняшняя дата (статичная) |

## Автозаполнение

- Тянуть **маркер** (чёрный крестик в углу ячейки) — продолжает ряд.
- **Прогрессия:** ввести два значения (`1`, `2`), выделить оба, потянуть.
- **Ряды:** `Янв→Фев`, `Пн→Вт`, даты, `Отдел 1→Отдел 2`.
- 💡 **Двойной клик по маркеру** — заполнить вниз до конца соседних данных.
- `Ctrl`+`D` / `Ctrl`+`R` — заполнить вниз / вправо.

## Порядок и сохранность

- **Закрепить шапку:** Вид → Закрепить области → верхняя строка. Шапку + первый столбец — встать в `B2`.
- **`Ctrl`+`S`** — сохранять рефлекторно.

---

## Что должно остаться в голове

1. По таблице двигаюсь **клавишами**, а не мышью.
2. Число вправо, текст влево — вижу тип на глаз.
3. `Ctrl`+`Enter` и автозаполнение экономят кучу времени.
4. Строка формул — «правда» о ячейке.
5. `Ctrl`+`S` — постоянно.

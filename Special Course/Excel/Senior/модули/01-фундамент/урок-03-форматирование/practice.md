## Задание 1. Числовые и пользовательские форматы

1. Выделите столбцы «Цена» и «Сумма» → `Ctrl`+`Shift`+`4` (денежный) или через `Ctrl`+`1` задайте формат `# ##0 ₽`.
2. **Пользовательский формат «шт.»:** выделите «Количество» → `Ctrl`+`1` → «(все форматы)» → в поле «Тип» введите `0" шт."` → ОК. Теперь показывается «3 шт.», но внутри — число 3.
   - Проверьте: `=СУММ(...)` по «Количеству» всё ещё работает (формат не мешает расчёту).
3. **Дата словами:** выделите «Дата заказа» → `Ctrl`+`1` → «(все форматы)» → `ДД ММММ ГГГГ` → получаем «02 августа 2025».
4. **Отрицательные красным (демо):** в пустой ячейке введите `-500`, задайте формат `[Красный]-# ##0;# ##0` — минус станет красным.

## Задание 2. ⭐ «Умная» таблица `Ctrl`+`T`

1. Встаньте в любую ячейку данных → **`Ctrl`+`T`** → проверьте «Таблица с заголовками» → ОК.
   - Появились фильтры, полосатость. В шапке — стрелки фильтра.
2. **Имя таблицы:** «Конструктор таблиц» → поле «Имя таблицы» → введите `Продажи`.
3. **Строка итогов:** «Конструктор» → галочка «Строка итогов». Внизу появилась строка — в столбце «Сумма» выберите из выпадающего «Сумма», в «Количество» — «Сумма».
4. **Авто-формула по всему столбцу:** добавьте столбец справа — в ячейке шапки напишите `Со скидкой 10%`, в первой ячейке данных: `=[@Сумма]*0,9`, `Enter`.
   - ✅ Формула сама заполнила **весь** столбец. Обратите внимание на структурированную ссылку `[@Сумма]` вместо `H2`.
5. **Автоматический рост:** прокрутите в конец таблицы, допишите новую строку заказа сразу под таблицей — она **втянулась** в таблицу, формула и форматы применились сами.
6. **Ссылка по имени:** на листе `Итоги` (или в свободной ячейке) напишите `=СУММ(Продажи[Сумма])` — сумма всего столбца по имени.

> **Проговорить:** теперь любой анализ — на «умной» таблице. Данные растут → отчёты подхватывают.

## Задание 3. Условное форматирование

1. **Цветовая шкала:** выделите столбец «Сумма» → Условное форматирование → «Цветовые шкалы» → красно-жёлто-зелёная. Мгновенно видно крупные и мелкие заказы.
2. **Значки-«светофоры»:** на копии столбца — «Наборы значков» → светофор.
3. **Правило «больше»:** выделите «Сумма» → «Правила выделения ячеек» → «Больше…» → введите, например, `100000` → заливка. Крупные заказы подсвечены.
4. **Дубликаты:** выделите столбец «Товар» → «Правила выделения» → «Повторяющиеся значения». Видно, что товары повторяются (это нормально для продаж; приём пригодится для чистки справочников).
5. **⭐ Подсветить всю строку правилом-формулой:**
   - Выделите весь диапазон данных `A2:N301` (все столбцы, чтобы подсветилась вся строка).
   - Условное форматирование → «Создать правило» → «Использовать формулу».
   - Формула: `=$C2="Москва"` (подсветить строки с городом Москва). Задайте заливку → ОК.
   - ✅ Целые строки заказов из Москвы подсвечены. Разберите роль `$` перед `C` (фиксируем столбец, строка «едет»).
6. **Управление:** Условное форматирование → «Управление правилами» — посмотрите список, попробуйте изменить/удалить.

## Задание 4. Оформление и печать

1. **Границы и шапка:** выделите таблицу → `Ctrl`+`1` → «Граница» (тонкие внутри, жирная снаружи). Шапку — заливка + `Ctrl`+`B`.
2. **Формат по образцу:** оформите одну ячейку красиво → двойной клик по кисточке → «покрасьте» несколько других → `Esc`.
3. **Подготовка к печати:**
   - `Ctrl`+`P` — посмотрите предпросмотр. Скорее всего таблица «не влезает» по ширине.
   - «Разметка страницы» → «Вписать» → «1 страница в ширину».
   - «Печатать заголовки» → «сквозные строки» = строка шапки `$1:$1`. Теперь шапка на каждой странице.
   - Вставка → «Колонтитулы» → добавьте название «Отчёт по продажам» и номер страницы.
   - Снова `Ctrl`+`P` — проверьте, что теперь красиво и по столбцам не режется.
4. Сохраните: `Ctrl`+`S`.

> **Итог:** «сырая» таблица стала оформленным отчётом: умная таблица с итогами, подсветка важного, аккуратная печать.

## ⏱️ Если осталось время (бонус-задания)

1. **Пользовательский формат «светофор».** Сделайте формат для столбца «прибыль»: положительные — зелёным, отрицательные — красным со знаком, ноль — прочерком: `[Зелёный]# ##0;[Красный]-# ##0;"-"`. Проверьте на `100`, `-100`, `0`.
2. **Условное форматирование по дате.** Подсветите строки, где «Дата отгрузки» приходится на выходные: правило-формула `=ДЕНЬНЕД($M2;2)>5` (забегаем в урок 7 — но приём тот же).
3. **Печать.** Настройте печать так, чтобы поместилось в 1 страницу по ширине, шапка повторялась, а в колонтитуле были дата и номер страницы. Сохраните в PDF.

> 💡 **Как лучше, а не так.** ❌ Не объединяйте ячейки (`Объединить и поместить в центре`) внутри таблиц — это ломает сортировку, выделение `Ctrl`+`Shift`, копирование и сводные. ✅ Чтобы «отцентрировать заголовок над таблицей», используйте `Ctrl`+`1` → Выравнивание → по горизонтали → **«по центру выделения»**: выглядит так же, но ячейки не склеены.

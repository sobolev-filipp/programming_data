# Материалы курса (учебные файлы)

Готовые файлы-заготовки для практики и домашних заданий. Все данные **вымышленные**.

| Файл | Используется в уроках | Что внутри |
|------|----------------------|-----------|
| `Продажи.xlsx` | 2–5, 7–11 | Реалистичная выгрузка заказов (300 строк, **14 столбцов**): A Дата заказа, B Менеджер, C Город, D Категория, E Товар, F Количество, G Цена, **H Сумма (пустой — считаем на уроке 2)**, I № заказа, J Клиент, K Тип клиента (Опт/Розница), L Канал продаж, M Дата отгрузки, N Статус оплаты (Оплачен/Ожидает/Просрочен). |
| `Прайс.xlsx` | 5 | Справочник: Товар → Категория → Цена (16 товаров). Названия совпадают с `Продажи.xlsx`. |
| `Планы.xlsx` | 9, 10, 11, 14 | План выручки по менеджерам. Для **план-факт** анализа (сравнить факт из `Продажи` с планом). |
| `Сотрудники.xlsx` | 1, 6, 7 | «Грязные» данные кадров (40 строк): ФИО с лишними пробелами, Отдел, Дата приёма **как текст**, Телефон в 4 форматах, Email. |
| `Выгрузка_грязная.csv` | 12 | «Грязный» CSV (`;`): пустые строки, разнобой городов (Москва/москва/СПб), числа-как-текст. Для чистки в Power Query. |
| `Выгрузки_по_месяцам/` | 12 | 3 помесячных CSV (2025-01/02/03) одинаковой структуры. Сценарий Power Query **«собрать из папки»** (каждый месяц — новый файл). |
| `Данные_для_дашборда.xlsx` | 14 | Заказы за целый год (1200 строк, те же 14 столбцов, № заказа с 200001). Основа итогового дашборда. |

## Как пересоздать файлы

Если файлы потерялись или нужно сгенерировать свежий вариант:

```bash
python generate_materials.py
```

Требуется Python 3 и библиотека `openpyxl`:

```bash
pip install openpyxl
```

Данные детерминированы (`random.seed(42)`) — при повторном запуске получаются **те же** файлы, поэтому решения в `solutions.md` остаются актуальными.

---

## Если Python недоступен

Все файлы уже сгенерированы и лежат в этой папке — Python нужен **только** для пересоздания. Для прохождения курса достаточно готовых `.xlsx` и `.csv`.

Как альтернатива — любую из таблиц можно за пару минут набрать вручную по описанию из `practice.md` соответствующего урока (структура столбцов там указана).

# Материалы курса (учебные файлы)

Готовые файлы-заготовки для практики и домашних заданий. Все данные **вымышленные**.

| Файл | Используется в уроках | Что внутри |
|------|----------------------|-----------|
| `Продажи.xlsx` | 2, 3, 4, 8, 9, 10, 11 | Таблица заказов (300 строк): Дата, Менеджер, Город, Категория, Товар, Количество, Цена. **Столбец «Сумма» пустой** — ученик считает его формулой на уроке 2. |
| `Прайс.xlsx` | 5 | Справочник: Товар → Категория → Цена (16 товаров). Для `ВПР`/`ПРОСМОТРX`/`ИНДЕКС+ПОИСКПОЗ`. Названия товаров совпадают с `Продажи.xlsx`. |
| `Сотрудники.xlsx` | 6, 7 | «Грязные» данные (40 строк): ФИО одной строкой (с лишними пробелами), Отдел, Дата приёма **как текст**, Телефон в 4 разных форматах, Email. Для чистки текста и работы с датами. |
| `Выгрузка_грязная.csv` | 12 | Специально «грязный» CSV (разделитель `;`): пустые строки, разнобой в названиях городов (Москва/москва/СПб), числа-как-текст с пробелами. Для Power Query. |
| `Данные_для_дашборда.xlsx` | 14 | Продажи за целый год (1200 строк), та же структура. Основа итогового дашборда. |

---

## Как пересоздать файлы

Если файлы потерялись или нужно сгенерировать свежий вариант:

```bash
python generate_materials.py
```

Требуется Python 3 и библиотека `openpyxl`:

```bash
pip install openpyxl
```

Данные детерминированы (`random.seed(42)`) — при повторном запуске получаются **те же** файлы, поэтому решения в `solutions.md` остаются актуальными.

---

## Если Python недоступен

Все файлы уже сгенерированы и лежат в этой папке — Python нужен **только** для пересоздания. Для прохождения курса достаточно готовых `.xlsx` и `.csv`.

Как альтернатива — любую из таблиц можно за пару минут набрать вручную по описанию из `practice.md` соответствующего урока (структура столбцов там указана).

# Курс «Нейросети и машинное обучение» для школьников

Курс рассчитан на школьников 7–11 классов с опытом программирования на Python.
Общий объём — **135 академических часов** (≈ 67 уроков по 2 ак.ч.).

## Структура репозитория

```
neural-networks-course/
├── README.md                  # этот файл
├── PLAN.md                    # полный план курса (модули и уроки)
├── TECH_REQUIREMENTS.md       # требования к технике и ПО
├── METHODOLOGY.md             # общая методичка по всем темам
├── modules/                   # учебные модули
│   ├── 00-introduction/
│   │   ├── lesson-01-what-is-ai/
│   │   │   ├── theory.md       # подробная теория для преподавателя
│   │   │   ├── practice.md     # задачи и примеры на уроке
│   │   │   ├── homework.md     # домашнее задание
│   │   │   └── summary.md      # краткое резюме для ученика
│   │   └── lesson-02-.../
│   ├── 01-python-math-refresh/
│   ├── 02-data-handling/
│   ├── 03-classical-ml-basics/
│   ├── 04-classical-ml-algorithms/
│   ├── 05-neural-networks-foundations/
│   ├── 06-computer-vision/
│   ├── 07-nlp-and-text/
│   ├── 08-generative-ai-and-llm/
│   └── 09-final-project/
└── resources/                 # дополнительные ресурсы (датасеты, ссылки)
```

## Быстрый старт

1. Прочитайте [PLAN.md](PLAN.md) — посмотрите программу.
2. Прочитайте [TECH_REQUIREMENTS.md](TECH_REQUIREMENTS.md) — подготовьте технику и ПО.
3. Перед первым занятием изучите [METHODOLOGY.md](METHODOLOGY.md) — общая навигация.
4. К каждому уроку открывайте папку модуля и читайте `theory.md` → `practice.md` → `homework.md`.
5. Резюме (`summary.md`) выдавайте ученикам после занятия.

## Авторские принципы курса

- **Полезность и интерес** — каждая тема даёт «осязаемый» результат (модель, картинка, чат-бот).
- **Баланс теории и практики** — на каждые ~30 мин теории ~60 мин практики.
- **Минимум сухой математики** — формулы вводим только когда нужно, с интуитивным объяснением.
- **«Зачем мне это»** — в каждом уроке примеры реального применения (фильтры в TikTok, рекомендации в YouTube, голосовые ассистенты и т.п.).

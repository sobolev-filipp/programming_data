# План курса «Нейросети и машинное обучение»

**Общий объём:** ~139 ак.ч. (изначально 135, расширен на 4 ак.ч. ради двух новых уроков по ООП и продвинутым конструкциям Python — без них дальнейший материал «не сядет»).
**Базовая единица планирования:** урок = 2 ак.ч. (90 минут).
**Всего уроков:** 69 (138 ак.ч.) + 1 ак.ч. резерва на защиту проектов.

При формате «1 раз в неделю по 3 часа (4 ак.ч.)» — два соседних урока проводятся подряд.
При формате «2 раза в неделю по 1.5 часа (2 ак.ч.)» — по одному уроку за занятие.

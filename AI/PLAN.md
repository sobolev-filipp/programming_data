# План курса «Нейросети и машинное обучение»

**Общий объём:** ~139 ак.ч. (изначально 135, расширен на 4 ак.ч. ради двух новых уроков по ООП и продвинутым конструкциям Python — без них дальнейший материал «не сядет»).
**Базовая единица планирования:** урок = 2 ак.ч. (90 минут).
**Всего уроков:** 69 (138 ак.ч.) + 1 ак.ч. резерва на защиту проектов.

При формате «1 раз в неделю по 3 часа (4 ак.ч.)» — два соседних урока проводятся подряд.
При формате «2 раза в неделю по 1.5 часа (2 ак.ч.)» — по одному уроку за занятие.

## Модуль 8. Работа со звуком и голосовой помощник (8 уроков / 16 ак.ч.)

> **Изменение плана.** Раньше здесь был «Генеративный ИИ и LLM» с API Claude/OpenAI. Но **выдавать ученикам API-ключи невозможно**, поэтому модуль заменён на **работу со звуком** — на **открытых библиотеках без API-ключей** (Whisper open weights, pyttsx3/gTTS, librosa). Итог модуля — **собственный голосовой помощник**, работающий офлайн.

Цель: научить работать со звуком как с данными, распознавать и синтезировать речь без платных API, собрать голосового помощника «по командам».

| Урок | Тема |
|-----:|------|
| 8.1 | Что такое звук. Аудио как массив чисел (numpy). Загрузка WAV |
| 8.2 | Визуализация аудио — волна, осциллограмма (librosa + matplotlib) |
| 8.3 | Спектрограммы и преобразование Фурье «на пальцах» |
| 8.4 | Распознавание речи через **Whisper** локально (open weights, без API) |
| 8.5 | Синтез речи через **pyttsx3** (offline) или **gTTS** (free, без ключа) |
| 8.6 | Классификация аудио — мини-CNN на спектрограммах (звуки: кошка/собака/…) |
| 8.7 | Собственный голосовой помощник (распознал → ответил по правилам → озвучил) |
| 8.8 | Мини-проект: расширение помощника собственными командами |

**Адаптация под школьников:**
- Без математики БПФ на формулах — только интуиция «звук = много синусов».
- Готовые библиотеки, без углубления в реализацию.
- Whisper: `whisper.load_model("base")` — работает офлайн после первой загрузки.
- Финальный проект — голосовой ассистент «по командам» (распознал «который час» → ответил «сейчас 14:30» → озвучил).

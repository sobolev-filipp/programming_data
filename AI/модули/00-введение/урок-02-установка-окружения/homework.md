## Задание 1. Оформить README репозитория (5 минут)

Открой `README.md` в своём репозитории `neural-networks-course-<логин>` **прямо на github.com** (клик по файлу → карандаш ✏️ «Edit») и сделай его осмысленным.

```markdown

- Имя: ...
- Класс: ...
- Что хочу научиться делать к концу курса: ...

## Структура
- `homework/` — работы по урокам
- `notebooks/` — Jupyter-тетрадки с занятий
- `projects/` — мини- и финальный проект
```

Внизу страницы редактирования нажми **«Commit changes»** (сообщение — `Обновил README`).

## Задание 2. Шпаргалка по Markdown (7 минут)

Это упражнение — освоить Markdown, на котором написаны все материалы курса.

Создай файл прямо на GitHub: в репозитории **`Add file → Create new file`**, в поле имени впиши `homework/lesson-0-2/markdown_practice.md` (GitHub сам сделает папки по слэшам). В нём должны быть **все** перечисленные элементы Markdown:

- [ ] Заголовки трёх уровней (`#`, `##`, `###`)
- [ ] Жирный текст (`**`) и наклонный (`*`)
- [ ] Маркированный список
- [ ] Нумерованный список
- [ ] Чек-бокс (`- [ ]` и `- [x]`)
- [ ] Гиперссылка на внешний сайт
- [ ] Картинка по ссылке из интернета
- [ ] Цитата (`>`)
- [ ] Блок кода с подсветкой `python`:
  ```python
  print("Hello, AI!")
  ```
- [ ] Inline-код (`в обратных кавычках`)
- [ ] Таблица из 2 столбцов и 3 строк

Внизу нажми **«Commit new file»**.

> **Совет:** справа сверху в редакторе GitHub есть вкладка **«Preview»** — сразу видно, как отрисуется Markdown.
> **Шпаргалка:** [https://www.markdownguide.org/cheat-sheet/](https://www.markdownguide.org/cheat-sheet/)
>
> **Проверка:** открой свой файл на GitHub — все элементы должны корректно отображаться.

## Задание 3. Квест по `pip` в Colab (3 минуты)

В Colab команды системе пишут в ячейке с **`!`** впереди. В текстовой ячейке своей тетрадки **запиши команды**, которые нужны, чтобы:

1. Узнать версию Python.
2. Установить пакет `requests`.
3. Удалить пакет `requests`.
4. Посмотреть список всех установленных пакетов.
5. Сохранить список установленных пакетов в файл `requirements.txt`.
6. Установить все пакеты из файла `requirements.txt`.

Запиши команды (в текстовой ячейке тетрадки). **Не обязательно их запускать** — главное помнить, что в Colab перед ними ставится `!`.

> **Ответы (если застрял):**
> ```bash
> !python --version
> !pip install requests
> !pip uninstall requests
> !pip list
> !pip freeze > requirements.txt
> !pip install -r requirements.txt
> ```

# Урок 0.2. Практика на занятии: настраиваем рабочее место в Colab

> ### 💻 Как мы работаем весь курс
> Весь код курса пишем в **Google Colab** — тетрадках (`.ipynb`) в облаке, прямо в браузере. Один логический шаг — одна **ячейка**, запускаем сверху вниз (`Shift+Enter`). Переменные сохраняются между ячейками, поэтому импорты, данные, модель держим в **разных** ячейках. Ответы на 🤔-вопросы пишем в **текстовых (Markdown) ячейках**. Отдельные `.py`-файлы и установка Python на компьютер **не нужны** — всё в облаке. Перед сдачей запускаем тетрадку целиком: `Среда выполнения → Перезапустить и выполнить всё`.


> Все шаги делаем **синхронно вместе с классом**, каждый на своём компьютере в браузере. Устанавливать на компьютер ничего не нужно — только браузер (Chrome удобнее всего).

## Шаг 1. Google-аккаунт (5 минут)

Colab — сервис Google, поэтому нужен вход в Google-аккаунт.

1. У кого есть **Gmail** — аккаунт уже есть, переходим к Шагу 2.
2. У кого нет — завести бесплатно: [https://accounts.google.com/signup](https://accounts.google.com/signup) (нужен номер телефона для подтверждения).
3. Проверить, что получилось войти: открыть [https://mail.google.com](https://mail.google.com) — должна открыться почта.

> **Школьная Google-почта** тоже подойдёт, если она у вас есть.

## Шаг 2. Открываем Google Colab и делаем первую тетрадку (12 минут)

1. Открыть [https://colab.research.google.com](https://colab.research.google.com)
2. Войти под своим Google-аккаунтом (кнопка «Sign in» справа сверху), если ещё не вошёл.
3. В открывшемся окне: **`Файл → Создать блокнот`** (`File → New notebook`).
4. Откроется пустая тетрадка с одной ячейкой. Впиши в неё:

```python
print("Привет, машинное обучение!")
```

5. Запусти ячейку: нажми **`Shift + Enter`** (или кнопку ▶ слева от ячейки).
6. Под ячейкой должно появиться: `Привет, машинное обучение!`

> **Что произошло:** твой код улетел на сервер Google, там выполнился, и результат вернулся обратно в браузер. Твой компьютер почти ничего не делал — вот почему мощность не важна.

7. Добавь новую ячейку: наведи мышку под ячейкой → кнопка **`+ Код`** (или `Ctrl+M B`). Впиши:

```python
2 + 2
```

Запусти — Colab покажет результат последней строки: `4`.

8. **Переименуй тетрадку:** клик по названию `Untitled0.ipynb` сверху слева → напиши `урок-0-2-проба.ipynb`.

> **Важно:** тетрадка уже **сохранилась сама** на твой Google Drive. Проверим это на следующем шаге.

## Шаг 4. Текстовые ячейки и Markdown (7 минут)

В тетрадке бывают два вида ячеек: **Код** и **Текст**. Ответы на вопросы и пояснения мы будем писать в текстовых.

1. Под ячейкой нажми **`+ Текст`** (`Ctrl+M M`).
2. Впиши в неё (это Markdown):

```markdown
## Мои заметки
Сегодня я научился(лась) работать в **Google Colab**.

- код пишу в ячейках
- запускаю через Shift+Enter

> Мощный компьютер не нужен — считает облако!
```

3. Запусти ячейку (`Shift+Enter`) — текст превратится в красиво оформленный: заголовок, жирный, список, цитата.

> **Так мы будем оформлять ответы на 🤔-вопросы** в каждом уроке — в текстовых ячейках, чтобы работу было приятно читать.

## Шаг 5. Регистрируемся на GitHub (10 минут)

GitHub нужен как **портфолио** и для **сдачи домашних заданий**.

1. Открыть [https://github.com/signup](https://github.com/signup)
2. Ввести email, придумать пароль и **логин**.
   - **Логин выбирай серьёзно** — это твоё «лицо» в IT-мире. `cool-coder-2010` плохо, `ivan-petrov-dev` хорошо.
3. Подтвердить email (письмо придёт почти сразу).
4. **Включить двухфакторную аутентификацию (2FA)** — GitHub этого требует.
   - Settings → Password and authentication → Two-factor authentication.
   - Поставить на телефон [Google Authenticator](https://play.google.com/store/apps/details?id=com.google.android.apps.authenticator2) или Microsoft Authenticator.
   - **Сохранить резервные коды** в надёжное место (например, в заметки телефона).

## Шаг 6. Создаём репозиторий-портфолио на GitHub (6 минут)

**Репозиторий** — это просто папка-проект на GitHub. Заведём один на весь курс.

1. На github.com нажать **«+»** справа сверху → **«New repository»**.
2. Имя: `neural-networks-course-<ваш_логин>` (например, `neural-networks-course-ivan`).
3. Описание: `Мои работы по курсу нейросетей`.
4. Выбрать **Public** (публичный — это портфолио, его можно показать).
5. Поставить галочку **«Add a README file»**.
6. Нажать **«Create repository»**.

> Готово: у тебя есть страница-портфолио. Пока там только `README.md` (файл-описание). Скоро добавим туда тетрадки.

## Шаг 7. ⭐ Связываем Colab и GitHub — сдаём работу без единой команды (10 минут)

Это главный навык урока: отправить тетрадку из Colab прямо на GitHub, **без установки Git и без терминала**.

1. Вернись во вкладку с тетрадкой `урок-0-2-проба.ipynb` в Colab.
2. Меню **`Файл → Сохранить копию в GitHub`** (`File → Save a copy in GitHub`).
3. Первый раз откроется окно GitHub с просьбой разрешить доступ — нажми **«Authorize googlecolab»** (это официальная связка Colab↔GitHub, безопасно).
4. Вернувшись, в окошке выбери:
   - **Repository:** свой `neural-networks-course-<логин>`.
   - **File path:** можно оставить как есть или написать `homework/lesson-0-2/проба.ipynb`.
   - **Commit message:** «Первая тетрадка».
5. Нажать **OK**.
6. Открой свой репозиторий на github.com и обнови страницу — тетрадка появилась!

> 🎉 **Вот и вся «сдача работы».** Никаких `git add`/`git commit`/`git push` в терминале — Colab сделал всё сам одной кнопкой. Так мы будем сдавать каждую домашку.

> **Если кнопка просит логин при каждом сохранении** — значит, не сработала авторизация (Шаг 7.3). Повтори `Файл → Сохранить копию в GitHub` и нажми «Authorize».

## Troubleshooting: типичные проблемы

| Проблема | Причина | Решение |
|----------|---------|---------|
| Не заходит в Colab | Не выполнен вход в Google | Войти в Google-аккаунт (mail.google.com), затем открыть Colab |
| «Сохранить копию в GitHub» просит логин каждый раз | Не прошла авторизация Colab↔GitHub | Повторить `Файл → Сохранить копию в GitHub` → «Authorize googlecolab» |
| Тетрадка «отвалилась», переменные пропали | Сессия заснула (~30 мин без действий) | Это норма. `Среда выполнения → Перезапустить и выполнить всё` |
| `!pip install` не помог | Иногда после установки нужно перезапустить среду | `Среда выполнения → Перезапустить сеанс`, потом заново сверху |
| GitHub не пускает из-за 2FA | Не настроен аутентификатор | Восстановить по резервным кодам / переустановить приложение-аутентификатор |
| Тетрадки нет на Drive | Не сохранилась / другой аккаунт | `Ctrl+S` в Colab; проверить, что Drive и Colab под одним аккаунтом |

> Если что-то не решается за 5 минут — **не зависайте классом**. Запишите ученика в «доделать индивидуально» и идите дальше.

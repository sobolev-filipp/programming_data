## Главные термины

- **Colab** — сервис Google, где Python-тетрадки работают в браузере, в облаке.
- **Тетрадка (notebook, `.ipynb`)** — файл из **ячеек** (код + текст + результаты).
- **Ячейка** — один кусочек кода или текста. Запуск — `Shift+Enter`.
- **Google Drive** — облачное хранилище, куда Colab сам сохраняет тетрадки.
- **Репозиторий** — папка-проект на GitHub.
- **README.md** — файл-описание репозитория (рендерится прямо на странице).
- **GPU** — видеокарта; Colab даёт её бесплатно для тяжёлых нейросетей (включим в Модуле 5).

## Что надо уметь (главные действия)

### В Google Colab

- **Создать тетрадку:** `Файл → Создать блокнот`.
- **Запустить ячейку:** `Shift + Enter` (или ▶).
- **Добавить ячейку кода:** кнопка `+ Код`.
- **Добавить текстовую ячейку:** кнопка `+ Текст` (там пишем ответы на 🤔-вопросы в Markdown).
- **Сохранить:** `Ctrl+S` (обычно сохраняется само на Drive).
- **Перезапустить всё перед сдачей:** `Среда выполнения → Перезапустить и выполнить всё`.

### Сдать работу на GitHub (без терминала!)

```
Файл → Сохранить копию в GitHub → выбрать свой репозиторий → OK
```

Первый раз нажать **«Authorize googlecolab»** в окне GitHub.

### Библиотеки

```python
# Проверить, что стоит (в Colab почти всё уже есть):
import numpy as np
print(np.__version__)

# Доставить то, чего нет (например, в Модулях 7–8):
!pip install имя_библиотеки
```

> **`!` перед `pip`** — значит «команда системе, а не код Python». Ставится на текущую сессию; после «засыпания» тетрадки выполнить снова.

## Главные термины

- **Окружение (environment)** — изолированный набор Python + библиотек для проекта.
- **Репозиторий** — папка под управлением Git.
- **Коммит** — снимок состояния проекта.
- **Push / Pull** — отправить / забрать коммиты на GitHub.
- **Clone** — скачать репозиторий с GitHub.
- **README.md** — главный файл-описание репозитория (рендерится прямо на странице).

## Команды, которые надо запомнить

### Git

```bash
# Один раз для компьютера
git config --global user.name "Имя Фамилия"
git config --global user.email "you@example.com"

# Скачать репозиторий
git clone <url>

# Базовый цикл
git add <файл>             # добавить файл к следующему коммиту
git add .                  # добавить ВСЕ изменения
git commit -m "сообщение"  # сделать коммит
git push                   # отправить на GitHub
git pull                   # забрать новые коммиты с GitHub

# Проверка
git status                 # что изменилось
git log                    # история коммитов
```

### Anaconda / pip

```bash
# Версия Python
python --version

# Установка пакета
pip install <имя>

# Несколько сразу
pip install numpy pandas matplotlib

# Удалить
pip uninstall <имя>

# Список установленного
pip list

# Сохранить в файл
pip freeze > requirements.txt

# Поставить из файла
pip install -r requirements.txt
```

### Jupyter

```bash
# Локально (откроется браузер)
jupyter notebook

# Современная альтернатива
jupyter lab
```

В тетрадке: `Shift+Enter` — запустить ячейку.

# Урок 3.2 — признаки и три части данных

**Признак** — известное сведение для прогноза. Длина — количество, цвет — категория. Номер сам по себе не делает категорию количеством.

**One-hot** задаёт отдельный флажок 0/1 для каждого названия. Например, sun превращается в weather_rain=0, weather_snow=0, weather_sun=1. Для этого используем `pd.get_dummies(table, columns=["weather"], dtype=int)`. Расстояние поездки оставляем числом. Время пока не предсказываем; классификацию и разделение исследуем на Iris.

| Часть | Зачем нужна |
|---|---|
| Train | Подобрать веса модели |
| Val | Выбрать признаки или настройки |
| Test | Проверить выбранное решение |

Для Iris получили 90/30/30 объектов: сначала 20% от 150, затем 25% от оставшихся 120. `stratify=y` сохраняет доли классов настолько близко, насколько позволяют целые количества.

**Команды:** `value_counts(normalize=True)` считает доли, `[:, [2, 3]]` выбирает все строки и два столбца, `fit` подбирает параметры, `predict` применяет их, `accuracy_score` проверяет совпадения.

**Ошибки:** повторно делить весь исходный набор вместо pool; выбирать по test; вычислять медиану заполнения по всей таблице; путать долю класса с accuracy. Стратификация сама по себе не гарантирует честную проверку: для времени и групп нужны подходящие способы разделения.

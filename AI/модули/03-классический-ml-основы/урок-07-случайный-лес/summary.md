## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Ансамбль** | Команда из многих моделей; ответ общий (голосование/среднее) |
| **Bagging** | Обучить деревья на разных случайных кусках данных, усреднить |
| **Случайный лес** | Ансамбль из множества деревьев, голосующих большинством |
| **`n_estimators`** | Число деревьев в лесу (больше → стабильнее) |
| **Бустинг** | Деревья по очереди исправляют ошибки предыдущих |
| **GradientBoosting / XGBoost** | Популярные бустинги (XGBoost — «король Kaggle») |
| **Кросс-валидация** | Оценка модели по нескольким разбиениям (честнее) |
| **`cross_val_score`** | Функция кросс-валидации в sklearn |

---

## Главные мысли

1. **Ансамбль = «мудрость толпы».** Много разных моделей вместе сильнее одной.
2. **Случайный лес** = много деревьев на разных кусках данных + случайные признаки → голосование.
3. Лес **точнее и меньше переобучается**, чем одно дерево — ошибки деревьев **гасятся** при усреднении.
4. Условие работы ансамбля — модели должны быть **разными**.
5. **Бустинг** строит деревья по очереди, исправляя ошибки (часто чуть точнее, но капризнее).
6. **Кросс-валидация** честнее одного split: проверяем модель несколько раз и усредняем.

### Кросс-валидация
```python
from sklearn.model_selection import cross_val_score

scores = cross_val_score(model, X, y, cv=5)   # передаём ВСЕ данные!
print(f"{scores.mean():.3f} ± {scores.std():.3f}")
```

## Лес против бустинга

| | Случайный лес (bagging) | Бустинг |
|---|---|---|
| Деревья строятся | параллельно, независимо | по очереди, исправляя ошибки |
| Плюс | прост, устойчив | часто точнее |
| Минус | — | легче переобучить |
| Когда брать | надёжный выбор по умолчанию | за максимальной точностью |

| Модель | Стандартизация | Особенность |
|--------|----------------|-------------|
| Логистическая регрессия | нужна | простая, прямые границы |

> **Главное правило оценки:** сравнивай модели по **`cross_val_score`**, а не по одному split.

## Главные ошибки

| Ошибка | Что не так | Как исправить |
|--------|-----------|---------------|
| Верят одному split | Точность скачет от везения | Кросс-валидация |
| `cross_val_score(model, X_train, ...)` | CV сам делит данные | Передавать весь `X` |
| «1000 деревьев лучше» | После плато роста нет | ~100 деревьев достаточно |
| Стандартизуют перед лесом | Бесполезно | Лесу/дереву не нужно |
| Путают bagging и boosting | Разный принцип | Параллельно vs по очереди |

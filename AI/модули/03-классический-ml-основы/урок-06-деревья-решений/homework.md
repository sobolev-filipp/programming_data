## Шпаргалка (минимум команд)

```python
from sklearn.tree import DecisionTreeClassifier, plot_tree

# Модель с ограничением глубины
tree = DecisionTreeClassifier(max_depth=4, random_state=42)
tree.fit(X_train, y_train)
tree.score(X_test, y_test)          # точность

# Визуализация
plot_tree(tree, feature_names=..., class_names=..., filled=True)

# Важность признаков
tree.feature_importances_

# Проверка переобучения
tree.score(X_train, y_train)        # train — если ≫ test, переобучение
tree.score(X_test, y_test)          # test
```

> Напоминание: деревьям **НЕ нужна** стандартизация. `StandardScaler` тут не понадобится.

---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Дерево решений** | Модель из цепочки вопросов «если… то…» |
| **Узел (node)** | Точка с вопросом про признак («Age < 18?») |
| **Лист (leaf)** | Конечная точка с ответом (классом) |
| **Глубина (depth)** | Сколько вопросов подряд от вершины до листа |
| **Gini** | Мера «грязности» группы: 0 — чисто, 0.5 — 50/50 |
| **Переобучение** | Модель зубрит train, плохо работает на test |
| **`max_depth`** | Ограничение глубины (главный «тормоз») |
| **`feature_importances_`** | Важность каждого признака |
| **`DecisionTreeClassifier`** | Дерево для классификации |

---

## Главные мысли

1. **Дерево = цепочка вопросов** «да/нет», как игра «Угадай животное».
2. Дерево **объясняет себя** — его можно нарисовать и прочитать словами.
3. Дерево выбирает вопросы так, чтобы группы становились **чище** (минимизирует Gini).
4. **Глубокое дерево переобучается** — зубрит train, проседает на test. Лечится `max_depth`.
5. Дерево даёт **важность признаков** бесплатно.
6. **Стандартизация дереву НЕ нужна** (в отличие от KNN!) — оно сравнивает с порогом.

## Шаблон ML-кода для дерева

```python
from sklearn.tree import DecisionTreeClassifier, plot_tree
import matplotlib.pyplot as plt

# Модель (ВСЕГДА ограничивай глубину!)
tree = DecisionTreeClassifier(max_depth=4, random_state=42)
tree.fit(X_train, y_train)   # никакой стандартизации не нужно!

# Проверка на переобучение
print("Train:", tree.score(X_train, y_train))
print("Test: ", tree.score(X_test, y_test))   # если train ≫ test → переобучение

# Визуализация
plt.figure(figsize=(16, 9))
plot_tree(tree, feature_names=X.columns, class_names=['Класс0','Класс1'],
          filled=True, rounded=True)
plt.show()

# Важность признаков
for name, imp in zip(X.columns, tree.feature_importances_):
    print(f"{name}: {imp:.3f}")
```

## Глубина дерева — шпаргалка

| Глубина | Поведение | Проблема |
|---------|-----------|----------|
| **1–2** | Очень простое | Недообучение (грубо) |
| **3–5** | «Золотая середина» | — |
| **большая (10+)** | Зубрит каждый объект | Переобучение (train≫test) |

> **Признак переобучения:** train accuracy высокая, test — заметно ниже. Разрыв = мера переобучения.

## Три модели Модуля 3 — сравнение

| | Логрегрессия | KNN | Дерево |
|---|---|---|---|
| Принцип | формула `w·x+b` | соседи голосуют | вопросы по порогам |
| Стандартизация | желательна | **обязательна** | **не нужна** |
| Объяснимость | средняя | низкая | **высокая** |
| Болезнь | только прямые границы | медленный, шкала | переобучение |

---

## Главные ошибки

| Ошибка | Что не так | Как исправить |
|--------|-----------|---------------|
| «Чем глубже, тем лучше» | Глубокое дерево зубрит | Ограничить `max_depth` |
| Смотрят только train | Не видят переобучения | Сравнивать train и test |
| Стандартизируют перед деревом | Бесполезно | Дереву это не нужно |
| Забыли `feature_names` в `plot_tree` | Дерево нечитаемо | Подписать признаки |

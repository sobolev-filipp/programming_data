## Уровень 2. Углубление

### 2.1. Своё разделение train/test (вместо `train_test_split`) (5 минут)

> **Что от тебя требуется:** разделить данные **сам**, без помощи sklearn. Это поможет понять, что `train_test_split` делает «под капотом».

**Зачем мы это делаем:** магия sklearn перестанет быть магией.

**Идея:**
1. **Перемешать** все индексы (от 0 до 149) случайно.
2. **Взять первые 80%** перемешанных индексов — это train.
3. **Остальные 20%** — это test.

**Код-подсказка (продолжи):**

```python
np.random.seed(42)                      # фиксируем случайность

n = len(X)                              # сколько у нас цветков (=150)
indices = np.random.permutation(n)      # перемешиваем числа 0..149

split = int(0.8 * n)                    # точка разделения = 120
train_idx = indices[:split]             # первые 120 индексов = train
test_idx = indices[split:]              # последние 30 = test

# Выбираем строки из X и y по этим индексам
X_train_manual = X[train_idx]
X_test_manual = X[test_idx]
y_train_manual = y[train_idx]
y_test_manual = y[test_idx]

# Дальше — обычное ML
model = LogisticRegression(max_iter=200)
model.fit(X_train_manual, y_train_manual)
print("Точность (ручное разделение):", model.score(X_test_manual, y_test_manual))
```

**Что должно получиться:** примерно **0.97**.

**Это и есть то, что `train_test_split` делает за тебя.**

```python
url = "https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv"
```

**Шаг 2. Быстрая очистка:**
- Заполни возраст медианой.
- Удали строки без `Embarked` (их всего 2).


**Шаг 3. Преобразование признаков.**
Модель умеет работать **только с числами**. Но `Sex` — это `'male'` или `'female'`. Превратим в число: `'female' → 1`, `'male' → 0`.


> **Что делает `(df['Sex'] == 'female').astype(int)`:**
> - `df['Sex'] == 'female'` даёт столбец True/False.
> - `.astype(int)` превращает True → 1, False → 0.
> - Теперь у нас есть **числовой** столбец «является ли пассажир женщиной».

**Шаг 4. Выбираем X и y:**

```python
df['total_bedrooms'] = df['total_bedrooms'].fillna(df['total_bedrooms'].median())
df = df.drop(columns=['ocean_proximity'])     # категориальный столбец — пока убираем
```

**Шаг 3. X и y:**
- Целевая переменная — `median_house_value` (цена).

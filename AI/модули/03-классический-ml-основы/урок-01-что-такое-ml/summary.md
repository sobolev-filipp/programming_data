# Урок 3.1 — первая модель: кратко

**Задача:** по четырём размерам цветка предсказать его вид. Это классификация с учителем: в учебных данных есть правильные ответы.

| Слово | Простыми словами |
|---|---|
| Модель | Правило, параметры которого подбираются по примерам |
| Признак | Известная характеристика, например длина лепестка |
| X | Таблица: строка — цветок, столбец — измерение |
| y | Правильные ответы в том же порядке, что строки X |
| Train | Примеры для обучения |
| Test | Отложенные примеры для проверки |
| Accuracy | Верные ответы / все проверенные объекты |

💬 Train похож на тренировочные задачи, test — на новые задачи для проверки. Высокий балл на тренировке ещё не гарантирует успеха на новых задачах.

## Команды

После загрузки Iris и разделения данных:

```python
model = LogisticRegression(max_iter=1000)
model.fit(X_train, y_train)
y_pred = model.predict(X_test)
acc = accuracy_score(y_test, y_pred)
```

Создали объект → подобрали параметры → получили ответы → сравнили с истиной. `max_iter` — предел итераций, не гарантия качества. `predict` не получает правильные ответы.

**Считаем:** 24 верных из 30 — это `24 / 30 = 0.8`, то есть 80%. 100% на одном тесте не означает, что ошибок никогда не будет.

**Читаем графики:** у scatter координаты — размеры в сантиметрах, цвет — известный вид. У столбчатого графика высоты — количества верных ответов и ошибок. Цвет точек сам по себе не показывает точность модели.

## Частые ошибки

- Перемешать X и y отдельно: измерения потеряют правильные подписи.
- Назвать задачу регрессией из-за меток 0, 1, 2: это номера категорий.
- Принять качество на train за независимую проверку.
- Передать один цветок без внешних скобок: модели нужна таблица.
- Перепутать сантиметры и миллиметры или порядок столбцов.

`random_state` помогает повторить разбиение. `stratify=y` сохраняет доли классов. На следующем уроке подробнее исследуем признаки и разделение.

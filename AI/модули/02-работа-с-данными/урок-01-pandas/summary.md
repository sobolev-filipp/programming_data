## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Таблица / датасет** | Данные в виде строк и столбцов. |
| **CSV** | Текстовый файл с таблицей; значения через запятую. |
| **DataFrame** | Главный объект Pandas: двумерная таблица. |
| **Series** | Один столбец DataFrame. |
| **Индекс (index)** | Метка строки (по умолчанию — номера 0, 1, 2...). |
| **dtype** | Тип данных столбца (`int64`, `float64`, `object`, `bool`). |
| **Булева маска** | Series из True/False для фильтрации (как в NumPy). |
| **`.str`** | Аксессор у Series со строками: даёт доступ к строковым методам. |
| **`loc` vs `iloc`** | `loc` — по меткам (включает границы), `iloc` — по числам (как NumPy). |

---

## Главные мысли

1. **Pandas = таблицы**. Это Excel, но в коде и в 100 раз мощнее.
2. **DataFrame** — главный объект. **Series** — один столбец.
3. **`df.head()`, `df.info()`, `df.describe()`** — первое, с чего начинают любой датасет.
4. **`df['col']`** — один столбец, **`df[['col1', 'col2']]`** — несколько.
5. **Фильтрация:** `df[df['col'] > 5]`. Несколько условий — через `&` и `|` (НЕ `and`/`or`).

## Шпаргалка по командам

### Импорт и чтение

```python
import pandas as pd

df = pd.read_csv('file.csv')
df = pd.read_csv('https://example.com/data.csv')

df.to_csv('output.csv', index=False)
```

### Просмотр

```python
df.head()              # первые 5 строк
df.head(10)            # первые 10
df.tail()              # последние
df.shape               # (строки, столбцы)
df.columns             # имена столбцов
df.dtypes              # типы данных
df.info()              # полная сводка
df.describe()          # статистика по числам
```

### Выбор столбцов

```python
df['name']             # один столбец (Series)
df[['name', 'age']]    # несколько столбцов (DataFrame)
```

### Выбор строк

```python
# По номеру (iloc)
df.iloc[0]              # первая строка
df.iloc[-1]             # последняя
df.iloc[0:3]            # строки 0, 1, 2 (3 не входит)

# По метке (loc)
df.loc[0]               # строка с меткой 0
df.loc[0:3]             # строки 0, 1, 2, 3 (3 ВХОДИТ!)

# Строка и столбец
df.loc[0, 'name']
df.iloc[0, 1]
```

### Фильтрация

```python
df[df['age'] > 15]
df[(df['age'] > 15) & (df['grade'] >= 4)]
df[df['name'].isin(['Иван', 'Ольга'])]
df[~df['name'].isin(['Мария'])]              # НЕ
df[df['name'].str.startswith('М')]
df[df['name'].str.contains('и')]
```

### Сортировка

```python
df.sort_values('age')                        # по возрастанию
df.sort_values('age', ascending=False)       # по убыванию
df.sort_values(['class', 'age'])             # несколько столбцов
df.sort_index()                              # по индексу
```

### Статистика

```python
df['age'].mean()
df['age'].std()
df['age'].min(), df['age'].max()
df['class'].value_counts()                   # сколько каждого значения
```

### Новый столбец

```python
df['age_months'] = df['age'] * 12
df['avg'] = (df['math'] + df['phys']) / 2
df['passed'] = df['grade'] >= 4
```

## Главные ошибки

| Ошибка | Что не так | Как исправить |
|--------|-----------|---------------|
| `df[df['a'] > 5 and df['b'] > 0]` | `and` не работает на столбцах | `df[(df['a'] > 5) & (df['b'] > 0)]` |
| Забыли скобки в фильтре | Неправильный приоритет | Каждое условие в скобки |
| `df.sort('age')` | Нет такого метода | `df.sort_values('age')` |
| `df.shape()` (со скобками) | `shape` — атрибут | `df.shape` (без скобок) |
| `df.avg = ...` (через точку) | Создаёт атрибут, не столбец | `df['avg'] = ...` |
| `iloc[0:5]` ожидают 6 строк | `iloc` не включает правую | Помнить: `iloc` как NumPy |

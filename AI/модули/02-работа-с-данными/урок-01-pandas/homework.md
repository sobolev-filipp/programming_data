## Шпаргалка для быстрого старта

```python
import pandas as pd

df = pd.read_csv(url)              # загрузка
df.head() / df.tail() / df.shape   # просмотр
df.info() / df.describe()          # сводки
df.columns                         # имена столбцов

df['col']                          # один столбец (Series)
df[['a', 'b']]                     # несколько столбцов (DataFrame)

df.loc[i] / df.iloc[i]             # строка (label / integer)

df.sort_values('col')              # сортировка

df['new'] = df['a'] * df['b']      # новый столбец
```

## Уровень 1. Обязательная база

Используй тот же `df`, что мы создали на уроке.

### 1.1. Описать данные

> **Что от тебя требуется:** распечатать 4 базовых характеристики таблицы.

**Шаги:**

```python
print("Форма:", df.shape)
```

> **Подсказка:**

> - `df.columns` — тоже без скобок.

> - `value_counts()` — для категориального столбца.

**Что должно получиться:**
```
Форма: (7, 6)
Столбцы: ['name', 'age', 'class', 'math', 'phys', 'rus']

9А     2
```

### 1.2. Простые фильтры

> **Что от тебя требуется:** для каждого условия отфильтровать строки и распечатать.

**Задачи:**

1. **Возраст = 14 лет.**
   ```python
   df[df['age'] == 14]
   ```

2. **Оценка по математике = 5.**
   ```python
   df[df['math'] == 5]
   ```

3. **Возраст ≥ 15 И оценка по физике ≥ 4.**

   > **Подсказка:** **И** = `&`. Каждое условие **в скобках**.

   ```python
   df[(df['age'] >= 15) & (df['phys'] >= 4)]
   ```

4. **Класс — 9А или 9Б.**

   > **Подсказка:** **или** = `|`. Или короче — через `.isin([...])`.

   ```python
   # Способ 1
   df[(df['class'] == '9А') | (df['class'] == '9Б')]

   # Способ 2 (короче)
   df[df['class'].isin(['9А', '9Б'])]
   ```

> **Главное правило:** **`and`/`or`** в Pandas **не работают**. Всегда `&`/`|` со скобками вокруг условий.

### 1.3. Сортировка

> **Что от тебя требуется:** освоить `sort_values`.

**Задачи:**

1. **По убыванию возраста.**
   ```python
   df.sort_values('age', ascending=False)
   ```

2. **По math (убыв), при равенстве — по phys (убыв).**

   > **Подсказка:** передать **список** имён столбцов и **список** направлений (или одно значение для всех).

   ```python
   df.sort_values(['math', 'phys'], ascending=[False, False])
   # короче:
   df.sort_values(['math', 'phys'], ascending=False)
   ```

> **Важно:** `sort_values` **возвращает новый DataFrame**, исходный не меняется. Если хочешь сохранить — `df = df.sort_values(...)`.

## Уровень 2. Новый столбец + сортировка

### 2.1. Средняя оценка

> **Что от тебя требуется:** добавить столбец `avg` со средней оценкой ученика.

```python
df['avg'] = ((df['math'] + df['phys'] + df['rus']) / 3).round(2)
df
```

> **Подсказка по скобкам:** обязательно **внешние скобки** вокруг суммы! Иначе деление применится только к `rus` (приоритет операций).
>
> ❌ Без скобок: `df['math'] + df['phys'] + df['rus'] / 3` — это `math + phys + (rus/3)`!
> ✅ Со скобками: `(df['math'] + df['phys'] + df['rus']) / 3`.

> **Подсказка про `.round(2)`:** округляет каждое число до 2 знаков после запятой.

---

### 2.2. Топ-3 учеников

> **Что от тебя требуется:** через `sort_values` и срез вывести 3 учеников с самым высоким `avg`.

```python
top3 = df.sort_values('avg', ascending=False)[:3][['name', 'class', 'avg']]
print(top3)
```

> **Разбор по шагам:**
> 1. `df.sort_values('avg', ascending=False)` — отсортировали по убыванию `avg`.
> 2. `[:3]` — взяли первые 3 строки.
> 3. `[['name', 'class', 'avg']]` — выбрали 3 столбца (**двойные скобки!**).

**Альтернатива через `head(3)`:**
```python
df.sort_values('avg', ascending=False).head(3)[['name', 'class', 'avg']]
```

### 2.3. Списки «хорошистов» и «троечников»

> **Что от тебя требуется:** посчитать и распечатать тех, у кого `avg ≥ 4.5`, и тех, у кого `< 3.5`.

```python
excellent = df[df['avg'] >= 4.5]
print(f"Хорошисты: {len(excellent)} человек")

poor = df[df['avg'] < 3.5]
```

```python
url = "https://raw.githubusercontent.com/mwaskom/seaborn-data/master/iris.csv"
```

### 3.2. Найти самый «нестабильный» класс

> **Что от тебя требуется:** для каждого класса посчитать **разницу** между макс и мин оценкой по math.

```python
max_math = df.groupby('class')['math'].max()
min_math = df.groupby('class')['math'].min()
spread = max_math - min_math

print(spread.sort_values(ascending=False))
```

> **Подсказка:** `spread.sort_values(ascending=False)` — самый «нестабильный» класс будет в начале.

**Альтернатива без `groupby` (через цикл):**
```python
for cls in df['class'].unique():
    subset = df[df['class'] == cls]
    spread = subset['math'].max() - subset['math'].min()
    print(f"{cls}: разброс {spread}")
```

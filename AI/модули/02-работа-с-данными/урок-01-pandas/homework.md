```python
import pandas as pd
df = pd.DataFrame({
    "name":  ["Иван","Мария","Пётр","Ольга","Алина","Никита","Дарья","Егор"],
    "class": ["9А","9А","9Б","9Б","9А","9В","9В","9Б"],
    "age":   [15, 14, 15, 16, 14, 15, 16, 15],
    "math":  [4, 5, 3, 5, 4, 3, 5, 4],
    "phys":  [3, 5, 4, 4, 5, 3, 4, 5],
    "rus":   [5, 5, 4, 4, 5, 4, 3, 4],
})
```

## Шпаргалка

```python
df.shape, df.columns              # форма, имена столбцов (без скобок!)
df.head(), df.describe()          # просмотр, статистика
df['math']                        # один столбец   |   df[['name','math']] — несколько
df.iloc[0]                        # строка по номеру   |   df.loc[0,'name'] — ячейка
df[df['age'] > 14]                # фильтр
df[(df['age']>=15) & (df['phys']>=4)]   # два условия — в скобках, через &
df['class'].value_counts()         # счётчик значений
df.sort_values('age', ascending=False)  # сортировка
df.groupby('class')['math'].mean() # статистика по группам
```

## 🟢 Уровень 1 — базовый (просмотр, выбор, фильтры, сортировка)

**2. Первый взгляд.** Выведи первые 5 строк (`head`) и сводную статистику по числовым столбцам (`describe`). ✅ В `describe` будут только 4 числовых столбца (`age`, `math`, `phys`, `rus`), имена и классы пропущены.
> 💡 Это две разные команды: `df.head()` и `df.describe()`. У текстовых столбцов статистики нет — поэтому их там не будет.

**3. Выбор столбцов.** Выведи отдельно столбец `math`, а потом два столбца сразу — `name` и `math`. ✅ Первое — Series (один столбец), второе — маленькая таблица из двух столбцов.
> 💡 Один столбец — одинарные скобки `df['math']`, несколько — двойные `df[['name','math']]`.

**4. Выбор строк.** Выведи первую строку таблицы (по номеру) и отдельно — имя ученика из строки с индексом 3. ✅ Имя из строки 3 — `Ольга`.
> 💡 Строка по номеру — `df.iloc[0]`; одна ячейка — `df.loc[3, 'name']`.

**5. Сколько в каждом классе.** Посчитай, сколько учеников в каждом классе. ✅ Ожидаемо: 9А — 3, 9Б — 3, 9В — 2.
> 💡 Для «сколько раз встречается каждое значение» есть готовый метод `.value_counts()`.

**6. Фильтр по возрасту.** Выведи всех, кому 14 лет. ✅ Должно найтись двое: Мария, Алина.
> 💡 Фильтр — это маска внутри `df[...]`. Равенство проверяют двойным `==`.

**7. Фильтр по оценке.** Выведи всех, у кого пятёрка по математике. ✅ Их трое: Мария, Ольга, Дарья.
> 💡 Условие `df['math'] == 5` внутри `df[...]`.

**8. Два условия.** Выведи учеников, которым **15 лет или больше** И у кого физика **≥ 4**. ✅ Подойдут четверо: Пётр, Ольга, Дарья, Егор.
> 💡 «И» — это `&`, каждое условие в скобках; `and` тут не сработает.

**9. Класс из списка.** Выведи всех, кто учится в 9А **или** 9Б (одной проверкой). ✅ Получится 6 строк.
> 💡 Для «значение из списка» удобнее метод `.isin([...])`, чем два условия через `|`.

**10. Сортировка по возрасту.** Выведи таблицу, отсортированную по возрасту от старших к младшим. Потом снова выведи `df` и проверь: он **не изменился**. ✅ Вверху окажутся 16-летние (Ольга, Дарья).
> 💡 `sort_values('age', ascending=False)`. Сортировка возвращает **новую** таблицу, а старую не трогает — поэтому `df` прежний.

**11. Сортировка по двум столбцам.** Отсортируй по `math` (по убыванию), а при равной математике — по `phys` (по убыванию). ✅ Первыми пойдут отличники по математике, а среди них — те, у кого выше физика.
> 💡 Передай **списки**: `sort_values(['math','phys'], ascending=[False, False])`.

**21. Почему `&`, а не `and`?** *(единственная «на подумать» — короткий ответ в Markdown-ячейке)* Объясни одной фразой, почему в фильтрах Pandas условия соединяют через `&`/`|`, а не через `and`/`or`.
> 💡 Вспомни схему с маской: фильтр — это не одно «да/нет», а **целый столбец** галочек True/False. Подумай, с чем умеют работать обычные `and`/`or`.

## Шпаргалка (минимум команд)

```python
import pandas as pd

df.shape, df.columns                  # форма, столбцы
df.head(), df.info(), df.describe()   # просмотр

df['col']                              # один столбец
df[['a', 'b']]                         # несколько

df.loc[i], df.iloc[i]                  # строка
df.loc[i, 'col']                       # ячейка

df[df['col'] > 5]                      # фильтр
df[(df['a'] > 5) & (df['b'] < 0)]      # несколько условий
df[df['col'].isin(['x', 'y'])]         # значение из списка
df[df['name'].str.startswith('M')]     # текстовая проверка

df.sort_values('col', ascending=False) # сортировка
df['col'].value_counts()                # счётчик
df['new'] = df['a'] * df['b']           # новый столбец
```

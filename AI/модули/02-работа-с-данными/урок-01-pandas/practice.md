## Задание 1. Знакомство с DataFrame (15 минут)

### 1.1. Создаём DataFrame вручную

```python
df = pd.DataFrame({
    'name':  ['Иван', 'Мария', 'Пётр', 'Ольга', 'Алина', 'Кирилл', 'Лена'],
    'age':   [15, 14, 16, 15, 17, 16, 14],
    'class': ['9А', '9Б', '10А', '9А', '10Б', '10А', '9Б'],
    'math':  [4, 5, 3, 4, 5, 4, 5],
    'phys':  [4, 5, 4, 5, 5, 3, 4],
    'rus':   [3, 5, 4, 4, 4, 4, 5]
})
df
```

**Разбор:**
- Создали DataFrame, передав **словарь**. Ключи стали столбцами, списки — значениями.
- Просто написать `df` (без `print`) в Jupyter — он покажет **красивую таблицу**.

### 1.2. Первое знакомство

```python
df.head(3)            # первые 3 строки
df.tail(3)            # последние 3 строки
df.shape              # (7, 6) — 7 строк, 6 столбцов
df.columns            # Index([...]) — имена столбцов
df.dtypes             # типы каждого столбца
```

**Что должно быть:**
- `shape` = `(7, 6)`.
- В `dtypes` имена-строки → `object`, числа → `int64`.

### 1.3. `info` — полная сводка

```python
df.info()
```

Что видим: 7 строк, 6 столбцов, у каждого «Non-Null Count» = 7 (нет пропусков), типы.

### 1.4. `describe` — статистика по числам

```python
df.describe()
```

Что видим:
- Считается только для **числовых** столбцов (`age`, `math`, `phys`, `rus`).
- Имена и классы пропущены — у них тип `object`.
- Для каждого числового — count, mean, std, min, квартили, max.

### 1.5. Чтение CSV (мини-эксперимент)

Создадим CSV-файл прямо в тетрадке и загрузим обратно:

```python
df.to_csv('students.csv', index=False)        # сохраняем в файл
df_loaded = pd.read_csv('students.csv')       # загружаем обратно
df_loaded.head()
```

**Что произошло:**
- `df.to_csv(...)` сохранил наш DataFrame в файл `students.csv`.
- `index=False` — не сохранять колонку индекса (нам она тут не нужна).
- `pd.read_csv(...)` прочитал тот же файл обратно в DataFrame.

Откройте файл в Colab (слева вкладка «Files») и посмотрите — это обычный текст с запятыми.

## Задание 2. Выбор столбцов и строк (15 минут)

### 2.1. Один столбец

```python
df['name']             # Series — все имена
df['math']             # Series — оценки по математике
type(df['name'])       # <class 'pandas.core.series.Series'>
```

### 2.2. Несколько столбцов

```python
df[['name', 'math']]   # DataFrame с двумя столбцами
```

**Подсветить:** двойные скобки! Внутри `df[...]` мы передаём **список** имён.

### 2.3. Строки по `iloc` — по номеру

```python
df.iloc[0]            # первая строка (Series)
df.iloc[-1]           # последняя
df.iloc[1:4]          # строки 1, 2, 3 (не 4!)
```

**Разбор:** `iloc` — это «как в NumPy». Срезы НЕ включают правую границу.

### 2.4. Строки по `loc` — по метке

```python
df.loc[0]             # строка с индексом 0
df.loc[1:4]           # ВНИМАНИЕ: включает 4!
```

**Подсветить разницу:**
- `iloc[1:4]` → 3 строки (1, 2, 3).
- `loc[1:4]` → 4 строки (1, 2, 3, 4).

> Запомнить: **`loc` включает обе границы**, потому что метки могут быть строками («Москва»–«Питер»), и тогда непонятно, что значит «не включать».

### 2.5. Строки и столбцы вместе

```python
df.loc[0, 'name']                    # 'Иван'
df.loc[:, 'name']                    # все имена (Series)
df.loc[0:2, ['name', 'math']]        # 3 строки, 2 столбца
df.iloc[0:3, [0, 3]]                 # то же самое через числа
```

**Разбор:** `df.loc[строки, столбцы]` — две части через запятую. `:` означает «все».

## Задание 3. Фильтрация (15 минут)

### 3.1. Простой фильтр

```python
df[df['age'] >= 15]
```

**Разбор по шагам:**

```python
# Шаг 1: что такое df['age'] >= 15 ?
mask = df['age'] >= 15
print(mask)
# 0     True
# 1    False
# 2     True
# ...
# dtype: bool

# Это Series из True/False — БУЛЕВА МАСКА.

# Шаг 2: вкладываем маску в df[...]
df[mask]
# Останутся только строки, где в маске True
```

В одну строку: `df[df['age'] >= 15]`.

### 3.2. Несколько условий

```python
# Возраст >= 15 И оценка по математике 5
df[(df['age'] >= 15) & (df['math'] == 5)]
```

**Подсветить ОЧЕНЬ важно:**
1. `&` — НЕ `and`! Если написать `and`, будет ошибка.
2. Каждое условие **в скобках**! Иначе Pandas неправильно поймёт приоритет.

```python
# Это РАБОТАЕТ
df[(df['age'] >= 15) & (df['math'] == 5)]

# Это ОШИБКА (TypeError)
df[df['age'] >= 15 and df['math'] == 5]
```

### 3.3. `|` — ИЛИ

```python
df[(df['class'] == '9А') | (df['class'] == '10А')]
```

### 3.4. `.isin()` — значение из списка

То же самое через `isin`:
```python
df[df['class'].isin(['9А', '10А'])]
```

**Короче и чище**, особенно если значений много.

### 3.5. `~` — НЕ

```python
df[~df['class'].isin(['9А'])]    # все, КРОМЕ 9А
```

### 3.6. Методы строк через `.str`

```python
# Имена, начинающиеся на 'А'
df[df['name'].str.startswith('А')]

# Имена, содержащие 'и'
df[df['name'].str.contains('и')]

# Имена длиннее 4 символов
df[df['name'].str.len() > 4]
```

**Разбор:** `df['name']` это Series. У текстовых Series есть **аксессор `.str`**, через который доступны методы строк (`startswith`, `contains`, `len`...).

### 3.7. Комбинируем фильтр и выбор столбцов

```python
# Имена и оценки по математике учеников 9-х классов с матем. >= 4
df[df['class'].str.startswith('9') & (df['math'] >= 4)][['name', 'math']]
```

**Разбор:**
- Сначала фильтруем строки: `df[df[...]...]`.
- К отфильтрованному применяем `[['name', 'math']]` — выбираем 2 столбца.

## Задание 4. Сортировка и статистика (13 минут)

### 4.1. Сортировка по возрасту

```python
df.sort_values('age')                # по возрастанию (по умолчанию)
df.sort_values('age', ascending=False) # по убыванию
```

### 4.2. Сортировка по нескольким столбцам

```python
df.sort_values(['class', 'math'], ascending=[True, False])
```

**Разбор:**
- `['class', 'math']` — сначала по `class`, потом по `math`.
- `ascending=[True, False]` — `class` по возрастанию, `math` по убыванию.

### 4.3. Сортировка не меняет исходный

```python
sorted_df = df.sort_values('age')
print(df.head())          # df НЕ изменился!
```

Чтобы изменить сам `df`: `df = df.sort_values('age')`.

### 4.4. Базовая статистика

```python
df['math'].mean()         # средняя оценка по математике
df['math'].median()       # медиана
df['math'].std()          # std
df['math'].min(), df['math'].max()
df['math'].sum()
```

### 4.5. `value_counts()` — кто сколько раз встретился

```python
df['class'].value_counts()
```

**Что покажет:**
```
9А     2
9Б     2
10А    2
10Б    1
```

То есть **сколько учеников в каждом классе**.

### 4.6. Добавление нового столбца

```python
# Средний балл каждого ученика
df['average'] = (df['math'] + df['phys'] + df['rus']) / 3
df
```

**Разбор:**
- Слева: имя нового столбца.
- Справа: выражение, использующее существующие столбцы.
- Pandas автоматически применит формулу **к каждой строке** (это broadcasting).

```python
# Будет ли отличник (average >= 4.5)?
df['is_excellent'] = df['average'] >= 4.5
df
```

Логическое сравнение даёт столбец из `True`/`False`.

## Задание 2. Выбор столбцов и строк (15 минут)

> 🎯 **Что делаем и зачем.** Учимся **доставать из таблицы кусочки**: один столбец, строку или ячейку. Это нужно постоянно — чтобы посчитать что-то по одному признаку или посмотреть на конкретного ученика.

### 2.1. Один столбец

```python
df['name']             # берём столбец 'name' — вернётся Series (все имена)
df['math']             # столбец 'math' — оценки по математике
type(df['name'])       # проверим тип: <class 'pandas.core.series.Series'>
```

💬 **Что происходит:** пишем имя столбца в квадратных скобках — получаем **Series** (один столбец: слева индекс, справа значения). `type(...)` показывает, что это именно Series — пригодится, чтобы не путать столбец и таблицу.
👉 **Что получим:** `df['math']` выведет 7 оценок (по одной на ученика) с индексами 0–6.

### 2.2. Несколько столбцов

```python
df[['name', 'math']]   # берём СРАЗУ ДВА столбца — вернётся DataFrame
```

💬 **Главное — двойные скобки!** Внутри `df[...]` мы кладём **список имён** `['name', 'math']` (у списка свои скобки), плюс внешние скобки таблицы. Если написать одинарные `df['name','math']` — будет ошибка.
👉 **Что получим:** маленькую таблицу из двух столбцов — имя и оценка по математике рядом.

### 2.3. Строки по `iloc` — по НОМЕРУ

```python
df.iloc[0]            # ПЕРВАЯ строка (номер 0) — вернётся Series
df.iloc[-1]           # ПОСЛЕДНЯЯ строка (минус считает с конца) — это Лена
df.iloc[1:4]          # срез: строки 1, 2, 3 (Мария, Пётр, Ольга). Строка 4 НЕ входит!
```

💬 **`iloc`** = «по номеру», работает **как в NumPy**: считаем с нуля, правую границу среза **не** включаем.
👉 **Что получим:** `df.iloc[1:4]` — три строки (Мария, Пётр, Ольга).

### 2.4. Строки по `loc` — по МЕТКЕ

```python
df.loc[0]             # строка с меткой 0 (Иван)
df.loc[1:4]           # метки 1, 2, 3 И 4 — граница ВХОДИТ! (4 строки)
```

**Сравните на одной и той же таблице:**
- `df.iloc[1:4]` → **3** строки (1, 2, 3) — правая граница не входит.
- `df.loc[1:4]`  → **4** строки (1, 2, 3, 4) — правая граница входит.

> 💬 **Почему `loc` включает обе границы?** Метки бывают не числами, а словами (например, «Москва»–«Питер»), и тогда «не включать последнюю» было бы странно. Поэтому `loc` берёт **всё от и до**, как в Excel. Это главная путаница урока — запомните разницу.

### 2.5. Строки И столбцы вместе

```python
df.loc[0, 'name']                    # одна ячейка: строка 0, столбец name -> 'Иван'
df.loc[:, 'name']                    # все строки, столбец name (двоеточие = «все»)
df.loc[0:2, ['name', 'math']]        # строки 0–2 (включая 2) и 2 столбца
df.iloc[0:3, [0, 3]]                 # то же самое, но через номера столбцов
```

💬 **Что делаем:** вырезаем из таблицы любой прямоугольник. Пишем `df.loc[строки, столбцы]` — слева от запятой какие строки, справа какие столбцы, `:` значит «все».
👉 **Что получим:** `df.loc[0:2, ['name','math']]` — таблицу 3×2 (первые три ученика, имя и математика).

## Задание 3. Фильтрация (15 минут)

> 🎯 **Что делаем и зачем.** Фильтрация — это «покажи мне только нужные строки» (например, только отличников). Самая частая задача в работе с данными. Работает через **маску** — столбик галочек True/False.

### 3.1. Простой фильтр — один критерий

```python
df[df['age'] >= 15]       # оставить только тех, кому 15 и больше
```

**Разбор по шагам — что внутри:**

```python
# Шаг 1: условие делает МАСКУ — столбик True/False
mask = df['age'] >= 15
print(mask)
# 0     True    (Иван, 15)
# 1    False    (Мария, 14)
# 2     True    (Пётр, 16)
# ...
# Name: age, dtype: bool

# Шаг 2: кладём маску в df[...] — останутся строки с True
df[mask]
```

💬 Маска — это галочки: напротив каждой строки True (подходит) или False (нет). `df[маска]` оставляет только True.
👉 **Что получим:** 5 учеников (все, кроме Марии и Лены — им по 14). Короткая запись в одну строку: `df[df['age'] >= 15]`.

### 3.2. Несколько условий — `&` (И)

```python
# Возраст >= 15 И пятёрка по математике
df[(df['age'] >= 15) & (df['math'] == 5)]
```

⚠️ **Два важнейших правила:**
1. `&` — это «И», а **не** слово `and`! С `and` будет ошибка.
2. Каждое условие — **в своих скобках** `(…) & (…)`, иначе Pandas перепутает порядок действий.

```python
df[(df['age'] >= 15) & (df['math'] == 5)]      # ✅ так ПРАВИЛЬНО
df[df['age'] >= 15 and df['math'] == 5]        # ❌ ОШИБКА (ValueError)
```
💬 **Почему нельзя `and`?** Обычный `and` сравнивает одно «да/нет», а у нас целый столбец галочек — для него нужен `&`.
👉 **Что получим:** одну ученицу — Алину (ей 17 и пятёрка по математике).

### 3.3. `|` — ИЛИ (хотя бы одно условие)

```python
df[(df['class'] == '9А') | (df['class'] == '10А')]   # из 9А ИЛИ из 10А
```
👉 **Что получим:** 4 ученика (Иван и Ольга из 9А, Пётр и Кирилл из 10А).

### 3.4. `.isin()` — значение из списка (короче, чем куча `|`)

```python
df[df['class'].isin(['9А', '10А'])]    # то же, что в 3.3, но короче
```
💬 `isin` проверяет для каждой строки: «её класс **есть в** списке?» Удобно, когда значений много — не писать пять `|`.
👉 **Что получим:** те же 4 ученика, что и в 3.3.

### 3.5. `~` — НЕ (наоборот)

```python
df[~df['class'].isin(['9А'])]    # все, КРОМЕ 9А
```
💬 Значок `~` переворачивает маску: где было True — станет False. Читается «не».
👉 **Что получим:** 5 учеников (все, кроме Ивана и Ольги из 9А).

### 3.6. Фильтр по тексту — методы строк `.str`

У **текстовых** столбцов есть «приставка» `.str`, открывающая команды для работы с текстом. Главные три:

```python
df[df['name'].str.startswith('А')]    # имя НАЧИНАЕТСЯ с 'А' (start+with = «начинается с»)
df[df['name'].str.contains('и')]      # имя СОДЕРЖИТ 'и' где угодно (contains = «содержит»)
df[df['name'].str.len() > 4]          # ДЛИНА имени больше 4 букв (len = length, длина)
```

💬 **Что это за команды:**
- `startswith('А')` — проверяет, что строка **начинается** с буквы «А». Как в обычном Python: `'Алина'.startswith('А')` → `True`.
- `contains('и')` — есть ли буква «и» **в любом месте** имени.
- `len()` — **сколько букв** в имени.

`.str` применяет эти проверки **сразу ко всему столбцу** (к каждому имени) и возвращает маску. Дальше — как всегда: `df[маска]`.
👉 **Что получим:** `startswith('А')` → Алина; `contains('и')` → Мария, Алина, Кирилл; `len() > 4` → Мария, Ольга, Алина, Кирилл.

### 3.7. Комбинируем: фильтр + выбор столбцов

```python
# Имена и математика учеников 9-х классов, у кого математика >= 4
df[df['class'].str.startswith('9') & (df['math'] >= 4)][['name', 'math']]
```

**Читаем слева направо:**
1. `df[ … ]` — фильтруем строки: класс начинается с «9» И математика ≥ 4.
2. `[['name', 'math']]` — из отфильтрованного берём только 2 столбца.

👉 **Что получим:** таблицу из столбцов `name` и `math` для Ивана, Марии, Ольги и Лены.

## Задание 4. Сортировка и статистика (13 минут)

> 🎯 **Что делаем и зачем.** Упорядочиваем таблицу (кто старше/лучше), считаем числа по столбцам (средний балл, разброс) и добавляем новые столбцы. Это то, ради чего вообще берут Pandas — **быстро получать выводы по данным**.

### 4.1. Сортировка по возрасту

```python
df.sort_values('age')                  # по возрастанию (младшие сверху) — так по умолчанию
df.sort_values('age', ascending=False) # по убыванию (старшие сверху)
```
💬 `sort_values('age')` переставляет строки по столбцу `age`. `ascending=False` значит «не по возрастанию», то есть от большего к меньшему.
👉 **Что получим:** ту же таблицу, но строки идут по возрасту — сверху 14-летние (Мария, Лена), снизу 17-летняя Алина.

### 4.2. Сортировка по нескольким столбцам

```python
df.sort_values(['class', 'math'], ascending=[True, False])
```

💬 **Как читать:**
- `['class', 'math']` — сначала упорядочить по `class`, а внутри одного класса — по `math`.
- `ascending=[True, False]` — `class` по возрастанию, `math` по убыванию (по одному значению на каждый столбец).

👉 **Что получим:** ученики сгруппированы по классам, а внутри класса — сильные по математике сверху. Удобно для «рейтинга по классам».

### 4.3. Сортировка НЕ меняет исходную таблицу

```python
sorted_df = df.sort_values('age')
print(df.head())          # df остался прежним!
```

💬 **Важно:** `sort_values` возвращает **новую** таблицу, а старую не трогает. Поэтому результат надо **сохранить** в переменную (`sorted_df = …`). Чтобы переупорядочить сам `df`, присвойте обратно: `df = df.sort_values('age')`.

### 4.4. Базовая статистика

```python
df['math'].mean()         # средняя оценка по математике
df['math'].median()       # медиана
df['math'].std()          # std
df['math'].min(), df['math'].max()
df['math'].sum()
```

> 👉 **Что получим** (math = [4,5,3,4,5,4,5]): `mean` ≈ 4.29, `median` = 4.0, `std` ≈ 0.76, `min`=3, `max`=5, `sum`=30.
> 🎯 **Зачем:** одной строкой «щупаем» столбец — средний уровень класса, разброс оценок. Эти же `mean`/`std` мы считали в Уроке 1.6, только теперь — прямо по столбцу таблицы.

### 4.5. `value_counts()` — кто сколько раз встретился

```python
df['class'].value_counts()
```

**Что покажет:**
```
9А     2
9Б     2
10А    2
10Б    1
```

То есть **сколько учеников в каждом классе**.

### 4.6. Добавление нового столбца

```python
# Средний балл каждого ученика
df['average'] = (df['math'] + df['phys'] + df['rus']) / 3
df
```

**Разбор:**
- Слева: имя нового столбца.
- Справа: выражение, использующее существующие столбцы.
- Pandas автоматически применит формулу **к каждой строке** (это broadcasting).

```python
# Будет ли отличник (average >= 4.5)?
df['is_excellent'] = df['average'] >= 4.5
df
```

Логическое сравнение даёт столбец из `True`/`False`.

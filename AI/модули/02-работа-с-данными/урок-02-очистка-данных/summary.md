## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **NaN** | Not a Number — обозначение пропуска в данных. |
| **Пропуск** | «Дыра» в таблице — NaN, None, пустая строка. |
| **Дубликат** | Повторяющаяся строка (полностью или по части столбцов). |
| **dtype** | Тип данных столбца (`int64`, `float64`, `object`...). |
| **`.apply()`** | Применить функцию к каждому элементу столбца или к каждой строке. |
| **Категориальный тип** | Pandas-тип для столбцов с ограниченным набором значений (быстрее, компактнее). |

---

## Главные мысли

1. **Реальные данные всегда грязные.** Чистка — 80% работы дата-сайентиста.
2. Для каждого столбца с пропусками — **своя стратегия**: удалить, заполнить средним/медианой/модой/0/'неизвестно'.
3. Удалить **много** строк — обычно плохо. Заполнить **с умом** — лучше.
4. **`.apply()`** — швейцарский нож. Через него можно сделать что угодно нестандартное.
5. **NaN ≠ NaN** — нельзя сравнивать через `==`. Используй `pd.isna()`.

## Шпаргалка команд

### Поиск пропусков

```python
df.isna()                       # True/False по каждой клетке
df.isna().sum()                 # число пропусков в столбцах
df.isna().sum() / len(df) * 100 # в процентах
df['col'].isna()                # для одного столбца
df['col'].notna()               # наоборот
```

### Удаление пропусков

```python
df.dropna()                     # удалить все строки с любым NaN
df.dropna(subset=['col'])       # только если NaN в col
df.dropna(axis=1)               # удалить СТОЛБЦЫ с NaN
df.drop(columns=['col'])        # удалить конкретный столбец
```

### Заполнение пропусков

```python
df['col'].fillna(0)                          # нулём
df['col'].fillna('Неизвестно')               # строкой
df['col'].fillna(df['col'].mean())           # средним
df['col'].fillna(df['col'].median())         # медианой
df['col'].fillna(df['col'].mode()[0])        # самым частым
```

### Дубликаты

```python
df.duplicated()                  # True/False — повтор это или нет
df.duplicated().sum()            # сколько дубликатов
df.drop_duplicates()             # удалить
df.drop_duplicates(subset=['col'])
```

### Переименование

```python
df.rename(columns={'old': 'new'})
df.columns = df.columns.str.lower()
df.columns = df.columns.str.replace(' ', '_')
```

### Типы данных

```python
df.dtypes
df['col'].astype(int)
df['col'].astype(float)
df['col'].astype(str)
df['col'].astype('category')
pd.to_datetime(df['col'])
```

### `.apply()`

```python
# Своя функция
def my_func(x):
    return x + 10

df['new'] = df['col'].apply(my_func)

# Лямбда
df['new'] = df['col'].apply(lambda x: x * 2)

# Для всей строки
df['new'] = df.apply(lambda row: row['a'] + row['b'], axis=1)
```

### `.str` для строк

```python
df['col'].str.lower()
df['col'].str.upper()
df['col'].str.contains('xyz')
df['col'].str.startswith('a')
df['col'].str.len()
df['col'].str.replace('old', 'new')
df['col'].str.split(' ')
```

## Главные ошибки

| Ошибка | Что не так | Как исправить |
|--------|-----------|---------------|
| `df['col'].fillna(0)` без присваивания | Изменение не сохраняется | `df['col'] = df['col'].fillna(0)` |
| `df.dropna()` теряет 80% данных | Слишком жёстко | `dropna(subset=['конкретный_столбец'])` |
| `df['col'] == NaN` | NaN не равен ничему | `df['col'].isna()` или `pd.isna(value)` |
| `.apply` без `axis=1` для строки | Применяется к столбцу | `df.apply(func, axis=1)` |
| `df['col'].astype(int)` при NaN | Float c NaN нельзя в int | Сначала заполнить, потом менять тип |

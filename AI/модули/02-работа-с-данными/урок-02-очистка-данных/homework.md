## Шпаргалка

```python
df.isna().sum()                 # число пропусков по столбцам
df = df.drop(columns=['Cabin']) # удалить столбец
df['Age'] = df['Age'].fillna(df['Age'].median())     # медианой
df['Embarked'] = df['Embarked'].fillna(df['Embarked'].mode()[0])  # модой
df.duplicated().sum()           # сколько дубликатов
df['new'] = df['col'].apply(func)                    # функция к каждому значению
df['new'] = df.apply(lambda row: ..., axis=1)         # функция к каждой строке
```

## 🟢 Уровень 1 — базовый (находим и чистим пропуски)

**1. Осмотр.** Выведи размер таблицы (сколько строк и столбцов) и её первые 5 строк. Сколько всего пассажиров? ✅ Форма `(891, 12)` — 891 пассажир, 12 столбцов.
> 💡 Это те же две команды, с которых начинали прошлый урок: одна показывает размер `(строки, столбцы)`, другая — верхушку таблицы.

**2. Сводка.** Выведи общий отчёт по таблице и определи по нему, **в каких столбцах есть пропуски**. ✅ Пропуски там, где непустых меньше 891: `Age` (714), `Cabin` (204), `Embarked` (889).
> 💡 Команда-отчёт показывает у каждого столбца число непустых значений (`Non-Null Count`). Меньше 891 — значит, есть дыры.

**3. Число пропусков.** Посчитай, **сколько** пропусков в каждом столбце (одним числом на столбец). ✅ Больше всего в `Cabin` (687) и `Age` (177), ещё 2 в `Embarked`.
> 💡 Есть метод, который помечает каждую клетку: пропуск это или нет (True/False). Если такие пометки сложить по столбцу — получишь количество пропусков.

**4. Доля пропусков.** Переведи число пропусков в **проценты** от всех строк, округли до 1 знака. ✅ `Cabin` ≈ 77.1%, `Age` ≈ 19.9%, `Embarked` ≈ 0.2%.
> 💡 У тебя уже есть числа пропусков (задача 3) и общее число строк (`len(df)`). Доля — это одно делить на другое, процент — умножить на 100.

**5. А если удалить всё?** Проверь, сколько строк **осталось бы**, если выбросить все строки, где есть хоть один пропуск. ✅ Осталось бы всего **183** из 891 — вот почему «удалить всё» плохо. (Только посмотри форму, **сам `df` не меняй**!)
> 💡 Есть метод, который удаляет строки с пропусками. Раз результат никуда не присваиваем — исходная таблица не меняется, просто смотрим её размер.

**6. Убрать бесполезный столбец.** У `Cabin` пропусков ~77% — заполнять нечем. Удали этот столбец целиком. ✅ После этого столбцов станет 11.
> 💡 Для удаления **столбца** у метода удаления есть параметр `columns=[...]`. Результат сохрани обратно в `df`.

**7. Заполнить возраст.** Заполни пропуски в `Age` **медианой** этого столбца (вместо пустых клеток подставится типичный возраст). Сохрани результат обратно в столбец. ✅ Медиана ≈ 28; после этого пропусков в `Age` станет 0.
> 💡 Нужен метод «заполнить пропуски» (его имя — «fill NA»). Чем заполнять — посчитай медиану этого же столбца. Медиана надёжнее среднего, если есть выбросы.

**8. Заполнить порт.** В `Embarked` всего 2 пропуска. Это **категория** (буква порта) — заполни их самым частым значением. ✅ Самый частый порт — `S` (Southampton).
> 💡 Для слов «типичное» значение — не среднее (его у слов нет), а **самое частое** (мода). У моды может быть несколько результатов, поэтому берут первый из них.

**9. Проверка.** Снова посчитай пропуски по столбцам (как в задаче 3). ✅ Во всех оставшихся столбцах должны быть нули — чисто!
> 💡 Это контрольная проверка. Если где-то не 0 — скорее всего, забыл присвоить результат `fillna` обратно в столбец.

**10. Дубликаты.** Посчитай, сколько в таблице **полностью повторяющихся** строк. ✅ В Titanic их **0**.
> 💡 Есть метод, который помечает строки-повторы (True/False). Сложи пометки — узнаешь их количество.

## 🟡 Уровень 2 — средний (новые признаки и `.apply()`)

**11. Размер семьи.** Создай новый столбец `family_size` — это число родственников на борту плюс сам пассажир (столбцы `SibSp` и `Parch` плюс 1). Выведи его среднее и максимум. ✅ Максимум — **11** (самая большая семья на борту).
> 💡 Столбцы можно складывать прямо знаком `+`. Не забудь `+ 1` на самого пассажира. Среднее и максимум — знакомые методы из прошлого урока.

**12. Кто как плыл.** Посчитай, **сколько человек было в семье какого размера** (счётчик по `family_size`). Сколько плыли **одни** (размер = 1)? ✅ Больше всего именно одиночек — около **537** человек.
> 💡 Это «счётчик значений» из прошлого урока. Чтобы строки шли по порядку размеров (1, 2, 3…), результат можно отсортировать по индексу.

**13. Признак «один».** Создай столбец `is_alone` из True/False: `True`, если пассажир плыл один (размер семьи равен 1). ✅ Это столбец из True/False.
> 💡 Сравнение целого столбца с числом сразу даёт столбец галочек — как в фильтрах прошлого урока, но результат записываем в новый столбец.

**14. Одиночки против семей.** Сравни **долю выживших** среди одиночек и среди тех, кто плыл с семьёй. У кого выше? ✅ Выше у тех, кто **с семьёй** (≈ 0.51 против ≈ 0.30 у одиночек).
> 💡 В столбце `Survived` стоят 0 и 1, поэтому его **среднее** — это и есть доля выживших. Посчитай это среднее отдельно для группы одиночек и отдельно для семейных.

**15. Категория цены.** Напиши функцию `fare_category(fare)`, которая возвращает слово: цена `< 10` → `'cheap'`, от 10 до 50 → `'medium'`, `≥ 50` → `'expensive'`. Примени её ко всему столбцу `Fare` и создай столбец `fare_category`. ✅ Появится столбец с тремя значениями.
> 💡 Внутри функции — `if/elif/else` и `return` слова. Чтобы прогнать функцию по всему столбцу, используем `.apply()`.

**16. Сколько каких билетов.** Посчитай, сколько билетов каждой категории, и определи самую многочисленную. ✅ Больше всего дешёвых/средних билетов, дорогих (`expensive`) — меньшинство.
> 💡 Снова «счётчик значений», но уже по новому столбцу `fare_category`. Сравни три числа.

**17. Титул из имени.** Из столбца `Name` вытащи только титул (`"Braund, Mr. Owen Harris"` → `"Mr."`) и запиши в столбец `title`. Посчитай, каких титулов сколько. ✅ Больше всего `Mr.` (517), затем `Miss.` (182), `Mrs.` (125), `Master.` (40).
> 💡 Имя устроено как «Фамилия, Титул Имя Отчество». Подумай, по каким разделителям его резать (сначала по запятой с пробелом, потом по точке с пробелом), чтобы остался только титул. Резать строку умеет `split`, а применить ко всему столбцу — `.apply()`.

**18. Выживаемость по титулу.** Посчитай **долю выживших отдельно для каждого титула** и отсортируй по убыванию. ✅ Высокая у `Mrs.`, `Miss.`, `Master.`; низкая у `Mr.` У `Master.` (мальчик до 13) — высокая, потому что «женщины и дети первыми».
> 💡 Доля выживших — это среднее `Survived`. «Отдельно для каждого титула» — значит, сгруппировать строки по `title` и в каждой группе взять среднее (команда группировки — `groupby`).

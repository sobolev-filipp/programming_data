## Шпаргалка

```python
df.isna().sum()                 # число пропусков по столбцам
df = df.drop(columns=['Cabin']) # удалить столбец
df['Age'] = df['Age'].fillna(df['Age'].median())     # медианой
df['Embarked'] = df['Embarked'].fillna(df['Embarked'].mode()[0])  # модой
df.duplicated().sum()           # сколько дубликатов
df['new'] = df['col'].apply(func)                    # функция к каждому значению
df['new'] = df.apply(lambda row: ..., axis=1)         # функция к каждой строке
```

**5. А если удалить всё?** Посмотри, сколько строк осталось бы, если удалить все строки с любым пропуском: `df.dropna().shape`. (Осталось бы очень мало — вот почему «удалить всё» плохо. **Сам `df` не меняй!**)

**6. Убрать бесполезный столбец.** У `Cabin` пропусков ~77% — удали этот столбец совсем.
> 💡 Если столбец почти пустой, заполнять его нечем — проще убрать.

**7. Заполнить возраст.** Заполни пропуски в `Age` медианой этого столбца. Не забудь присвоить обратно.

**8. Заполнить порт.** В `Embarked` всего 2 пропуска — заполни их самым частым значением (модой).
> 💡 Для категории (порт) среднее не имеет смысла — берут моду; `.mode()[0]` даёт самое частое значение.

**9. Проверка.** Выведи `df.isna().sum()` ещё раз — во всех оставшихся столбцах должны быть нули.

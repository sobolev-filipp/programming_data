---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **PyTorch** | Фреймворк нейросетей (autograd + GPU + готовые слои) |
| **Тензор** | Массив NumPy с суперсилой (градиенты, видеокарта) |
| **Autograd** | Авто-вычисление градиентов: `loss.backward()` |
| **`nn.Module`** | Базовый класс сети |
| **`nn.Linear`** | Слой `X·W + b` (веса внутри) |
| **Оптимизатор** | Обновляет веса (`SGD`, `Adam`) |
| **`Adam`** | «Умный» градиентный спуск |

---

## Главные мысли

1. **PyTorch = наш код, но профессиональный** (короче, быстрее, на GPU).
2. **Тензор** — как массив NumPy, но считает градиенты и работает на видеокарте.
3. **Autograd:** `loss.backward()` заменяет весь наш ручной backprop (5.5)!
4. **`nn.Linear`** = наш слой `X·W+b`, **`nn.Module`** = наш класс (5.6).
5. **Adam** (умный оптимизатор) → точнее простого SGD (наша версия из 5.4).
6. Мы понимаем PyTorch изнутри, потому что **строили сеть руками**.

## Сеть на PyTorch (шаблон)

```python
import torch, torch.nn as nn

class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(30, 16)        # слой 30 → 16
        self.fc2 = nn.Linear(16, 1)         # слой 16 → 1
    def forward(self, x):
        x = torch.relu(self.fc1(x))         # скрытый + ReLU
        return torch.sigmoid(self.fc2(x))   # выход + sigmoid

net = Net()
loss_fn = nn.BCELoss()
opt = torch.optim.Adam(net.parameters(), lr=0.01)

for epoch in range(300):
    opt.zero_grad()          # обнулить градиенты
    out = net(X)             # forward
    loss = loss_fn(out, y)   # loss
    loss.backward()          # backward (сам!)
    opt.step()               # update
```

## Наш код ↔ PyTorch

| Наш код (5.6) | PyTorch |
|---------------|---------|
| `np.random.randn` веса | `nn.Linear` |
| `X @ W + b` | `fc(x)` |
| ручной backward | **`loss.backward()`** |
| `W -= lr*dW` | `opt.step()` |
| своя `sigmoid` | `torch.sigmoid` |

## Главные ошибки

| Ошибка | Как правильно |
|--------|---------------|
| Забыли `opt.zero_grad()` | обнулять градиенты каждый шаг |
| Забыли стандартизацию | сети она нужна |
| Данные не тензоры | `torch.tensor(.., dtype=torch.float32)` |
| `y` не столбцом | `.reshape(-1, 1)` |

---

## Что должно остаться в голове после урока

1. **PyTorch** — профессиональный фреймворк нейросетей.
2. **Тензор** = массив NumPy с суперсилами.
3. **`loss.backward()`** = наш backprop, но автоматически.
4. Сеть = `nn.Module` + `nn.Linear` (= наш `W·x+b`).
5. Цикл: zero_grad → forward → loss → backward → step.

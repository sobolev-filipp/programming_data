## Шпаргалка (из практики)

```python
def relu(z): return np.maximum(0, z)
def sigmoid(z): return 1 / (1 + np.exp(-z))
def step(z): return (z > 0).astype(int)

# Forward pass (сеть 2 слоя)
H = relu(X @ W1 + b1)        # вход → скрытый
Y = sigmoid(H @ W2 + b2)     # скрытый → выход
```

Формы (сеть «вход → скрытый → выход»):
```
W1: (входов, нейронов_скрытого)
W2: (нейронов_скрытого, выходов)
```

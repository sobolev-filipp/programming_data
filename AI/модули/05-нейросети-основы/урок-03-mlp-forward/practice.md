## Задание 1. Прямое распространение своими руками (16 минут)

### Что мы хотим сделать

Написать forward pass для сети **2 → 3 → 1** (2 входа, скрытый слой из 3 нейронов, 1 выход) и прогнать через неё данные.

### 1.1. Активации (из Урока 5.2)

```python
def relu(z):
    return np.maximum(0, z)

def sigmoid(z):
    return 1 / (1 + np.exp(-z))
```

### 1.2. Задаём веса слоёв (пока случайные)

```python
np.random.seed(42)

# Сеть 2 → 3 → 1
# Слой 1 (скрытый): из 2 входов в 3 нейрона
W1 = np.random.randn(2, 3)      # форма (2, 3): 2 входа × 3 нейрона
b1 = np.random.randn(3)         # 3 смещения (по одному на нейрон)

# Слой 2 (выходной): из 3 нейронов в 1 выход
W2 = np.random.randn(3, 1)      # форма (3, 1)
b2 = np.random.randn(1)

print("W1 shape:", W1.shape)    # (2, 3)
print("W2 shape:", W2.shape)    # (3, 1)
```

#### Что мы делаем

- **`W1` формы (2, 3)** — веса от 2 входов к 3 нейронам скрытого слоя. Каждый из 3 нейронов имеет 2 веса (по одному на вход).
- **`W2` формы (3, 1)** — веса от 3 нейронов к 1 выходу.
- **`np.random.randn`** — случайные числа (нормальное распределение). Пока веса **случайные** — сеть «не обучена».

### 1.3. Пишем forward pass

```python
def forward(X, W1, b1, W2, b2):
    # Слой 1: вход → скрытый (с ReLU)
    Z1 = X @ W1 + b1            # взвешенная сумма (матричное умножение, Урок 1.5!)
    H = relu(Z1)               # активация скрытого слоя

    # Слой 2: скрытый → выход (с sigmoid)
    Z2 = H @ W2 + b2
    Y = sigmoid(Z2)            # активация выхода
    return Y
```

#### Что происходит по шагам — это сердце урока!

- **`Z1 = X @ W1 + b1`** — каждый нейрон скрытого слоя считает свою взвешенную сумму. `@` делает это **для всех 3 нейронов сразу** (Урок 1.5).
- **`H = relu(Z1)`** — пропускаем через ReLU (Урок 5.2). `H` — выход скрытого слоя.
- **`Z2 = H @ W2 + b2`** — выходной нейрон берёт `H` и считает свою сумму.
- **`Y = sigmoid(Z2)`** — финальный ответ (вероятность 0…1).

> **Вот вся нейросеть — 4 строки!** Данные `X` втекают, проходят 2 слоя (каждый = `@` + активация) и вытекают ответом `Y`. Это и есть прямое распространение.

### 1.4. Прогоняем данные

```python
X = np.array([
    [0.5, 0.2],
    [0.9, 0.7],
    [0.1, 0.4]
])

output = forward(X, W1, b1, W2, b2)
print("Выход сети:\n", output)
# 3 числа от 0 до 1 — по одному ответу на каждый из 3 объектов
```

**Что увидим:** 3 числа от 0 до 1 — сеть дала ответ для каждого объекта. Числа «случайные», потому что **веса случайные** (сеть не обучена). Но **механизм работает** — данные прошли через сеть!

#### Проверим формы (привычка из 1.5)

```python
Z1 = X @ W1 + b1
print("X:", X.shape, "@ W1:", W1.shape, "=", (X @ W1).shape)
# X: (3, 2) @ W1: (2, 3) = (3, 3)   ← внутренние 2 сократились
```

### Итог Задания 1

1. Собрали сеть 2→3→1 из матриц.
2. Написали forward pass (4 строки: 2 слоя по `@` + активация).
3. Прогнали данные — сеть выдала ответы (пока случайные, веса не обучены).

## Задание 2. Месть XOR: решаем сетью (14 минут)

### Что мы хотим сделать

Помнишь, в Уроке 5.1 один нейрон **провалил** XOR? Сейчас соберём сеть 2→2→1 и **вручную зададим веса**, чтобы она решила XOR. Месть!

### 2.1. Идея — собрать XOR из OR и AND

Из теории: `XOR = OR минус AND`. Скрытый слой посчитает OR и AND, выход их скомбинирует. Используем **ступеньку** (для чёткого 0/1).

```python
def step(z):
    return (z > 0).astype(int)

X = np.array([[0,0],[0,1],[1,0],[1,1]])    # все 4 комбинации
```

### 2.2. Задаём «умные» веса вручную

```python
# Скрытый слой: нейрон 1 = OR, нейрон 2 = AND
W1 = np.array([[1.0, 1.0],      # веса от x1 к (OR, AND)
               [1.0, 1.0]])     # веса от x2 к (OR, AND)
b1 = np.array([-0.5, -1.5])     # пороги: OR срабатывает легко, AND трудно

# Выходной слой: OR минус AND
W2 = np.array([[1.0],           # +OR
               [-1.0]])         # -AND
b2 = np.array([-0.5])
```

#### Почему эти веса работают

- **Нейрон OR:** `x₁ + x₂ − 0.5`. Срабатывает (>0), если хоть один вход 1.
- **Нейрон AND:** `x₁ + x₂ − 1.5`. Срабатывает только если **оба** входа 1 (сумма 2 > 1.5).
- **Выход:** `OR − AND − 0.5`. Срабатывает, когда OR есть, а AND нет — это и есть XOR!

### 2.3. Forward pass и проверка

```python
# Скрытый слой
H = step(X @ W1 + b1)
print("Скрытый слой [OR, AND]:\n", H)

# Выходной слой
Y = step(H @ W2 + b2)
print("\nВыход (XOR):", Y.ravel())
print("Ожидалось:  ", [0, 1, 1, 0])
print("XOR решён?", (Y.ravel() == [0, 1, 1, 0]).all())
```

**Что увидим:**
```
Скрытый слой [OR, AND]:
 [[0 0]      ← (0,0): OR=0, AND=0
  [1 0]      ← (0,1): OR=1, AND=0
  [1 0]      ← (1,0): OR=1, AND=0
  [1 1]]     ← (1,1): OR=1, AND=1

Выход (XOR): [0 1 1 0]
XOR решён? True
```

> 🎉 **ПОБЕДА!** Сеть из **двух слоёв** решила XOR — то, что было **невозможно** для одного нейрона в Уроке 5.1! Скрытый слой посчитал OR и AND, выход их скомбинировал. Вот она, сила многослойности: две прямые вместе образуют кривую границу.

### 2.4. Почему один нейрон не мог, а сеть может

```python
print("Урок 5.1: 1 нейрон = 1 прямая → XOR НЕ решить")
print("Урок 5.3: 2 нейрона = 2 прямые → их комбинация решает XOR!")
```

> **Скрытый слой «разложил» сложную задачу на простые** (OR и AND), которые каждый нейрон умеет. А выход собрал из них ответ. Так нейросети и работают: разбивают сложное на простое по слоям.

### Итог Задания 2

1. Собрали сеть 2→2→1 с **вручную заданными** весами.
2. **Решили XOR** (месть за Урок 5.1 свершилась!).
3. Поняли: слои разбивают сложную задачу на простые.

## Задание 3. Сеть учит XOR сама (8 минут)

### Что мы хотим показать

В Задании 2 мы **сами** придумали веса. А может ли сеть найти их **сама**? Да! Покажем готовой нейросетью из sklearn (а свою напишем в Уроках 5.6).

### 3.1. MLPClassifier обучается на XOR

```python
from sklearn.neural_network import MLPClassifier

X = np.array([[0,0],[0,1],[1,0],[1,1]])
y = np.array([0, 1, 1, 0])              # XOR

# Сеть с 8 нейронами в скрытом слое
clf = MLPClassifier(hidden_layer_sizes=(8,), activation='relu',
                    max_iter=5000, random_state=0)
clf.fit(X, y)                            # СЕТЬ САМА ИЩЕТ ВЕСА!

print("Предсказания:", clf.predict(X))   # [0 1 1 0]
print("XOR решён?", (clf.predict(X) == y).all())   # True
```

#### Что произошло

- **`hidden_layer_sizes=(8,)`** — скрытый слой из 8 нейронов.
- **`clf.fit(X, y)`** — сеть **сама** подобрала все веса (мы их не задавали!).
- Результат: `[0 1 1 0]` — **XOR решён автоматически**.

> **В Задании 2 мы час придумывали веса вручную. А здесь сеть нашла их сама за секунду!** Это и есть **обучение** — то, чем мы займёмся в Уроках 5.4–5.5. Сеть «нащупывает» правильные веса, минимизируя ошибку (как градиентный спуск в 1.7).

### 3.2. Заглянем в обученные веса

```python
print("Форма весов слоя 1:", clf.coefs_[0].shape)    # (2, 8)
print("Форма весов слоя 2:", clf.coefs_[1].shape)    # (8, 1)
```

**Что видим:** те же **матрицы весов**, что мы задавали руками — только сеть нашла их сама. Внутри `MLPClassifier` — ровно наш forward pass, плюс обучение.

### Итог Задания 3

1. `MLPClassifier` **сам** выучил XOR (мы не задавали веса).
2. Внутри — тот же forward pass из матриц.
3. **Как** сеть находит веса — узнаем в Уроках 5.4–5.5.

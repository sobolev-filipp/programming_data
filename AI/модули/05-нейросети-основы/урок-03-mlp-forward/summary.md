# Урок 5.3. MLP и прямое распространение — резюме

---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **MLP (многослойный перцептрон)** | Сеть из слоёв нейронов: вход → скрытый → выход |
| **Слой (layer)** | Пачка нейронов на одних входах |
| **Скрытый слой** | Слой между входом и выходом |
| **Прямое распространение (forward pass)** | Проход данных через слои от входа к выходу |
| **Архитектура** | Сколько слоёв и нейронов (напр. 2→4→1) |

---

## Главные мысли

1. **MLP** — нейроны, соединённые в слои: вход → скрытый → выход.
2. **Слой = `активация(X·W + b)`** — матричное умножение (Урок 1.5) + активация (5.2).
3. **Forward pass** — данные текут слой за слоем в одну сторону.
4. Связь с 1.5: каждый слой — это `X·W` (то самое «`W@x` = слой сети»).
5. **Сеть решает XOR!** Два нейрона = две прямые = кривая граница (один нейрон не мог).
6. Слои **разбивают** сложную задачу на простые (XOR = OR и AND).

---

## Forward pass (шаблон)

```python
def relu(z): return np.maximum(0, z)
def sigmoid(z): return 1 / (1 + np.exp(-z))

def forward(X, W1, b1, W2, b2):
    H = relu(X @ W1 + b1)        # вход → скрытый
    Y = sigmoid(H @ W2 + b2)     # скрытый → выход
    return Y
```

## Формы матриц (сеть вход→скрытый→выход)

| Что | Форма |
|-----|-------|
| `X` | (объектов, входов) |
| `W1` | (входов, нейронов скрытого) |
| `W2` | (нейронов скрытого, выходов) |
| `Y` | (объектов, выходов) |

> Если формы не стыкуются — печатай `.shape` (привычка из Урока 1.5).

---

## Как сеть решает XOR

```
Скрытый слой:  нейрон1 = OR,  нейрон2 = AND
Выход:         OR − AND  →  XOR

(0,0): OR=0 AND=0 → 0 ✓
(0,1): OR=1 AND=0 → 1 ✓
(1,0): OR=1 AND=0 → 1 ✓
(1,1): OR=1 AND=1 → 0 ✓
```

> Один нейрон = 1 прямая (XOR не решить). Слой = несколько прямых → кривая граница → XOR решён.

---

## Главные ошибки

| Ошибка | Как правильно |
|--------|---------------|
| Путают формы W | W1=(входов, нейронов скрытого) |
| Забыли активацию между слоями | иначе сеть = прямая |
| «forward pass = обучение» | нет, это только проход данных |
| ждут смысла от случайных весов | сеть не обучена, это норма |

## Что должно остаться в голове после урока

1. Нейросеть = **цепочка слоёв**, каждый = `активация(X·W + b)`.
2. **Forward pass** — данные текут от входа к выходу.
3. Слой = матричное умножение (Урок 1.5) + активация.
4. **Сеть решает XOR** — слои сильнее одного нейрона.
5. Веса пока задаём; **как найти сами** — следующие уроки.

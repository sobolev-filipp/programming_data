# Урок 5.4. Функция потерь и градиентный спуск — резюме

---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Функция потерь (loss)** | Число: насколько сеть ошибается |
| **MSE** | Потеря для регрессии (средний квадрат ошибки) |
| **Cross-entropy** | Потеря для классификации (штрафует уверенные ошибки) |
| **Обучение** | Поиск весов с минимальной потерей |
| **Кривая потерь** | График потери по эпохам (падает = учится) |
| **Цикл обучения** | forward → loss → gradient → update |

---

## Главные мысли

1. **Функция потерь** измеряет ошибку сети одним числом.
2. Потеря зависит от весов: **веса → предсказания → потеря**.
3. **Обучение = поиск весов с минимальной потерей** через градиентный спуск.
4. **Градиентный спуск из 1.7:** `вес = вес − lr · градиент`.
5. **MSE** — для регрессии, **cross-entropy** — для классификации.
6. **Падающая кривая потерь** = сеть учится.

---

## Функции потерь (код)

```python
def mse(y_true, y_pred):
    return np.mean((y_pred - y_true)**2)              # регрессия

def cross_entropy(y_true, p):
    return -np.mean(y_true*np.log(p+1e-9) + (1-y_true)*np.log(1-p+1e-9))  # классиф.
```

| Задача | Потеря |
|--------|--------|
| Регрессия (число) | MSE |
| Классификация (класс) | Cross-entropy |

---

## Цикл обучения (шаблон)

```python
for epoch in range(N):
    p = sigmoid(X @ w + b)          # 1. FORWARD — предсказания
    loss = cross_entropy(y, p)      # 2. LOSS — ошибка
    dz = (p - y) / len(y)           # 3. GRADIENT — куда двигать
    w = w - lr * (X.T @ dz)         # 4. UPDATE — шаг (формула из 1.7!)
    b = b - lr * dz.sum()
```

> **Падающая кривая потерь = сеть учится.** Если стоит/растёт → проверь `lr`.

---

## Холм ошибки

```
потеря (высота)
       ╲           ╱
        ╲         ╱
         ╲___▼___╱      ← дно = минимум потери = лучшие веса
```
Обучение = **скатиться на дно**. Градиент = компас «куда вниз». `lr` = размер шага.

---

## Главные ошибки

| Ошибка | Как правильно |
|--------|---------------|
| Путают потерю и точность | потеря гладкая (минимизируем), точность ступенчатая |
| MSE для классификации | cross-entropy |
| Большой lr | потеря скачет → уменьшить (как в 1.7) |
| Забыли стандартизацию | нейрону она важна |

---

## Что должно остаться в голове после урока

1. **Функция потерь** = мера ошибки сети.
2. **Обучение = минимизация потери** градиентным спуском.
3. `вес = вес − lr · градиент` — формула из Урока 1.7.
4. **MSE** для чисел, **cross-entropy** для классов.
5. **Падающая кривая потерь** = сеть учится.

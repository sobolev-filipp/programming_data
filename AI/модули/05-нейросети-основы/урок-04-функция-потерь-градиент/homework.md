## Шпаргалка (из практики)

```python
def mse(y_true, y_pred):   return np.mean((y_pred - y_true)**2)        # регрессия
def cross_entropy(y, p):   return -np.mean(y*np.log(p+1e-9) + (1-y)*np.log(1-p+1e-9))  # классиф.
def sigmoid(z):            return 1/(1+np.exp(-z))

# Цикл обучения нейрона
for epoch in range(N):
    p = sigmoid(X @ w + b)          # 1. forward
    loss = cross_entropy(y, p)      # 2. loss
    dz = (p - y)/len(y)             # 3. gradient
    w -= lr * (X.T @ dz)            # 4. update
    b -= lr * dz.sum()
```

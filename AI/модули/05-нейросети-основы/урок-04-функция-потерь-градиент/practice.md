## Задание 1. Измеряем ошибку: функции потерь (14 минут)

### Что мы хотим сделать

Написать MSE и cross-entropy и проверить: правильные предсказания → маленькая потеря, неправильные → большая.

### 1.1. MSE — для регрессии

```python
def mse(y_true, y_pred):
    return np.mean((y_pred - y_true) ** 2)

# Проверка: сеть предсказывает числа
y_true = np.array([10, 20, 30])

good_pred = np.array([11, 19, 31])    # близко к правде
bad_pred = np.array([50, 5, 80])      # далеко

print("MSE хорошего:", mse(y_true, good_pred))    # ~1.0 (маленькая)
print("MSE плохого: ", mse(y_true, bad_pred))     # ~2208 (огромная!)
```

**Что увидим:** у хорошего предсказания потеря **маленькая** (~1), у плохого — **огромная** (~2208). MSE «чувствует», насколько мы промахнулись. Это знакомо из Урока 3.3!

### 1.2. Cross-entropy — для классификации

```python
def cross_entropy(y_true, p):
    return -np.mean(y_true*np.log(p+1e-9) + (1-y_true)*np.log(1-p+1e-9))

# Правда: это класс 1 (кошка)
y_true = np.array([1])

print("Уверена и ПРАВА (p=0.99):", cross_entropy(y_true, np.array([0.99])))   # ~0.01
print("Не уверена (p=0.50):      ", cross_entropy(y_true, np.array([0.50])))   # ~0.69
print("Уверена и НЕ ПРАВА (p=0.01):", cross_entropy(y_true, np.array([0.01]))) # ~4.6 (!!)
```

#### Что увидим — главная особенность cross-entropy

| Предсказание (правда=1) | Потеря |
|-------------------------|--------|
| p=0.99 (уверена, права) | **0.01** — крошечная ✅ |
| p=0.50 (сомневается) | 0.69 — средняя |
| p=0.01 (уверена, НЕ права) | **4.6** — огромная ❌ |

> **Cross-entropy жестоко наказывает уверенные ошибки.** Сеть сказала «99% не кошка», а это кошка → потеря 4.6 (в 460 раз больше, чем за правильный уверенный ответ!). Это заставляет сеть быть **аккуратной с уверенностью**.

### Итог Задания 1

1. **MSE** (для чисел) — растёт с квадратом ошибки.
2. **Cross-entropy** (для классов) — карает уверенные ошибки.
3. Потеря — это «счётчик ошибок» сети.

## Задание 2. Холм ошибки (12 минут)

### Что мы хотим показать

Что потеря **зависит от веса**, и у неё есть **минимум** («долина»), к которому стремится обучение.

### 2.1. Простая задача — один вес

```python
# Данные: y ≈ 2*x (хотим, чтобы нейрон выучил вес w=2)
x = np.array([1, 2, 3, 4])
y = np.array([2, 4, 6, 8])

# Потеря как функция веса w (предсказание = w*x)
def loss_for_w(w):
    pred = w * x
    return np.mean((pred - y) ** 2)
```

### 2.2. Рисуем холм ошибки

```python
w_values = np.linspace(-1, 5, 100)        # пробуем разные веса
losses = [loss_for_w(w) for w in w_values]

plt.figure(figsize=(9, 5))
plt.plot(w_values, losses, linewidth=2)
plt.axvline(x=2, color='red', linestyle='--', label='минимум: w=2')
plt.xlabel("вес w")
plt.ylabel("потеря (MSE)")
plt.title("Холм ошибки: потеря в зависимости от веса")
plt.legend(); plt.grid(); plt.show()
```

**Что увидим:** **парабола** («холм») с **дном в точке w=2**. Это и есть правильный вес (ведь `y = 2·x`)!

> **Вот геометрия обучения:** потеря — это «холм» над весами. Обучение = **скатиться на дно** этого холма (где w=2). Слева и справа от минимума потеря растёт. Градиентный спуск находит дно автоматически.

### 2.3. Куда показывает градиент

```python
def slope_at(w, h=1e-4):
    return (loss_for_w(w + h) - loss_for_w(w - h)) / (2 * h)   # наклон (Урок 1.7)

for w in [0, 1, 2, 3, 4]:
    print(f"w={w}: потеря={loss_for_w(w):.1f}, наклон={slope_at(w):+.1f}")
# w=0: наклон отрицательный → идти ВПРАВО (увеличивать w)
# w=2: наклон ≈ 0 → мы на дне! (минимум)
# w=4: наклон положительный → идти ВЛЕВО (уменьшать w)
```

**Что замечаем:**
- Слева от минимума (w=0) наклон **отрицательный** → надо увеличивать w.
- В минимуме (w=2) наклон **≈ 0** → пришли!
- Справа (w=4) наклон **положительный** → надо уменьшать w.

> **Градиент — это компас:** он показывает, в какую сторону «вниз». Формула `w = w − lr·наклон` всегда двигает к минимуму. В этом весь градиентный спуск.

### Итог Задания 2

1. Потеря — это «холм» над весами, у него есть **дно** (минимум).
2. Правильный вес — на дне холма.
3. **Градиент показывает путь вниз** — к минимуму.

## Задание 3. Обучаем нейрон с нуля (12 минут)

### Что мы хотим сделать

Обучить **настоящий нейрон** (с сигмоидой) различать два класса — градиентным спуском, наблюдая, как **потеря падает**.

### 3.1. Данные

```python
from sklearn.datasets import make_blobs

X, y = make_blobs(n_samples=100, centers=2, random_state=42, cluster_std=1.2)
X = (X - X.mean(0)) / X.std(0)        # стандартизация (нейроны её любят!)

plt.scatter(X[:, 0], X[:, 1], c=y, cmap='coolwarm')
plt.title("Два класса — нейрон научится их различать")
plt.show()
```

### 3.2. Цикл обучения (сердце урока!)

```python
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

# Стартуем с нулевых весов
w = np.zeros(2)
b = 0.0
lr = 0.5

losses = []
for epoch in range(50):
    # 1. FORWARD: предсказания нейрона
    p = sigmoid(X @ w + b)

    # 2. LOSS: считаем потерю (cross-entropy)
    loss = -np.mean(y*np.log(p+1e-9) + (1-y)*np.log(1-p+1e-9))
    losses.append(loss)

    # 3. GRADIENT: куда двигать веса (для сигмоиды+CE градиент простой)
    dz = (p - y) / len(y)
    grad_w = X.T @ dz
    grad_b = dz.sum()

    # 4. UPDATE: шаг градиентного спуска (формула из 1.7!)
    w = w - lr * grad_w
    b = b - lr * grad_b

print(f"Потеря в начале: {losses[0]:.3f}")
print(f"Потеря в конце:  {losses[-1]:.3f}")
```

#### Что происходит — это весь цикл обучения

Каждая эпоха — **4 шага** из теории:
1. **Forward** — нейрон предсказывает (`p`).
2. **Loss** — считаем ошибку (cross-entropy).
3. **Gradient** — узнаём, куда двигать веса.
4. **Update** — `w = w − lr·градиент` (та самая формула из 1.7!).

**Что увидим:** потеря падает с **~0.69** (в начале, случайные предсказания) до **~0.03** (в конце). Нейрон **выучился**!

### 3.3. Рисуем кривую потерь — главный график

```python
plt.figure(figsize=(9, 5))
plt.plot(losses, linewidth=2)
plt.xlabel("эпоха")
plt.ylabel("потеря")
plt.title("Кривая потерь: сеть учится!")
plt.grid(); plt.show()
```

**Что увидим:** **падающая кривая** — круто вниз в начале, потом выходит на «дно». Это **визитная карточка обучения**: потеря падает = сеть учится.

### 3.4. Проверяем результат

```python
predictions = (sigmoid(X @ w + b) > 0.5).astype(int)
accuracy = (predictions == y).mean()
print(f"Точность после обучения: {accuracy:.2f}")     # 1.0 — 100%!
```

**Что увидим:** точность **1.0 (100%)**. Нейрон, начав с нулевых весов, **сам** научился идеально разделять классы — просто скатываясь вниз по холму ошибки.

> 🎉 **Вот оно, обучение!** Мы не задавали веса — нейрон нашёл их сам, минимизируя потерю градиентным спуском. Это **ровно** то, что делает любая нейросеть, от нашего нейрона до ChatGPT — только у них весов миллиарды.

### Итог Задания 3

1. Написали **цикл обучения** (forward → loss → gradient → update).
2. Увидели **падающую кривую потерь** — сеть учится.
3. Нейрон сам достиг **100% точности**, начав с нуля.

# Урок 5.5. Backpropagation — резюме

---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Backpropagation** | Алгоритм вычисления градиентов всех весов; ошибка течёт назад |
| **Forward pass** | Данные вперёд: вход → выход (предсказание) |
| **Backward pass** | Ошибка назад: выход → вход (градиенты) |
| **Правило цепочки** | Влияние «дальнего» = перемножить звенья |
| **«Вина» веса** | Вклад веса в общую ошибку (его градиент) |
| **Локальный минимум** | «Плохая долина», где сеть может застрять |

---

## Главные мысли

1. **Backprop** вычисляет градиент **каждого** веса — ошибка «течёт назад» через слои.
2. **Правило цепочки:** ошибка умножается на веса, двигаясь назад (перемножаем влияния).
3. Backprop = **«поиск виноватых»**: каждый вес узнаёт свою долю вины.
4. Обучение = **два прохода**: forward (данные →) + backward (ошибка ←) + update.
5. Backprop даёт **все** градиенты за **один** проход назад — поэтому обучение возможно.
6. Веса инициализируют **случайно** (не нулями); больше нейронов = надёжнее.

---

## Цикл обучения сети (полный)

```python
for epoch in range(N):
    # 1. FORWARD
    H = sigmoid(X @ W1 + b1)
    out = sigmoid(H @ W2 + b2)
    # 2. LOSS
    loss = cross_entropy(y, out)
    # 3. BACKWARD (backprop — ошибка назад)
    d_out = (out - y) / len(y)
    dW2 = H.T @ d_out
    d_H = (d_out @ W2.T) * dsigmoid(H)   # ← ошибка течёт назад
    dW1 = X.T @ d_H
    # 4. UPDATE
    W1 -= lr*dW1; W2 -= lr*dW2  # (+ смещения)
```

---

## Два прохода

```
FORWARD  →→→→→→  данные: вход → выход → предсказание
                                          │
                                       ОШИБКА
                                          │
BACKWARD ←←←←←←  ошибка: выход → вход → градиенты (вина весов)
```

---

## Главные ошибки

| Ошибка | Как правильно |
|--------|---------------|
| Веса = нули | случайная инициализация (`randn`) |
| Требуют формулы | важна идея (ошибка назад) |
| Забыли `dsigmoid(H)` | наклон активации в backward обязателен |
| «2 нейрона всегда решат XOR» | фрагильно, брать с запасом |

---

## Что должно остаться в голове после урока

1. **Backprop** = ошибка течёт назад, распределяя «вину» по весам.
2. **Правило цепочки** = перемножаем влияния (ошибка × веса).
3. Обучение = **forward + backward + update**.
4. Я **сам обучил сеть** решать XOR (с нуля!).
5. Backprop — **главный алгоритм** глубокого обучения.

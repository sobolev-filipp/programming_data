## Задание 1. Собираем сеть с backprop (18 минут)

### Что мы хотим сделать

Написать сеть **2 → 4 → 1** с прямым (forward) и обратным (backward) проходами.

### 1.1. Активация и её наклон

```python
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def dsigmoid(a):
    return a * (1 - a)        # наклон сигмоиды (через её ВЫХОД a)
```

> **`dsigmoid(a) = a·(1−a)`** — это наклон сигмоиды. Он нужен для backward прохода (помним: обучение идёт по наклону). Удобно, что он выражается через сам выход `a`.

### 1.2. Данные XOR

```python
X = np.array([[0,0],[0,1],[1,0],[1,1]], dtype=float)
y = np.array([[0],[1],[1],[0]], dtype=float)     # XOR (столбцом!)
```

### 1.3. Инициализируем веса

```python
np.random.seed(1)

# Сеть 2 → 4 → 1
W1 = np.random.randn(2, 4)      # вход → скрытый (4 нейрона)
b1 = np.zeros(4)
W2 = np.random.randn(4, 1)      # скрытый → выход
b2 = np.zeros(1)
```

> **Важно: веса СЛУЧАЙНЫЕ, не нулевые!** Если все веса нули, все нейроны скрытого слоя одинаковы и учатся одинаково — сеть не сможет различить их. Случайная инициализация «ломает симметрию». (Для одного нейрона в 5.4 нули годились, для сети — нет.)

### 1.4. Forward + Backward — одна эпоха

```python
lr = 0.5

# ===== FORWARD (данные вперёд) =====
H = sigmoid(X @ W1 + b1)        # скрытый слой
out = sigmoid(H @ W2 + b2)      # выход

# ===== LOSS =====
loss = -np.mean(y*np.log(out+1e-9) + (1-y)*np.log(1-out+1e-9))

# ===== BACKWARD (ошибка назад — backprop!) =====
d_out = (out - y) / len(y)         # ошибка на выходе
dW2 = H.T @ d_out                  # вина весов слоя 2
db2 = d_out.sum(axis=0)
d_H = (d_out @ W2.T) * dsigmoid(H) # ошибка ПРОТЕКЛА в скрытый слой
dW1 = X.T @ d_H                    # вина весов слоя 1
db1 = d_H.sum(axis=0)

# ===== UPDATE =====
W1 -= lr * dW1;  b1 -= lr * db1
W2 -= lr * dW2;  b2 -= lr * db2
```

#### Что происходит в BACKWARD — это сердце урока!

- **`d_out = (out - y)`** — ошибка на выходе (насколько промахнулись).
- **`dW2 = H.T @ d_out`** — «вина» весов **последнего** слоя.
- **`d_H = (d_out @ W2.T) * dsigmoid(H)`** — ошибка **«течёт назад»** в скрытый слой! Умножаем на `W2.T` (правило цепочки — «дотягиваемся» через веса) и на наклон сигмоиды.
- **`dW1 = X.T @ d_H`** — «вина» весов **первого** слоя.

> **Вот оно, backprop:** ошибка `d_out` с выхода **протекла назад** в скрытый слой (`d_H`), умножившись на веса `W2`. Каждый слой узнал свою вину. Это правило цепочки в действии.

### Итог Задания 1

1. Собрали сеть 2→4→1.
2. Написали **forward** (предсказание) и **backward** (backprop — ошибка назад).
3. Поняли: backward = ошибка течёт назад, перемножаясь на веса.

## Задание 2. Обучаем XOR с нуля! (12 минут)

### Что мы хотим сделать

Запустить обучение в цикле на много эпох — и **решить XOR сами** (без `MLPClassifier`!).

### 2.1. Полный цикл обучения

```python
# Заново инициализируем
np.random.seed(1)
W1 = np.random.randn(2, 4); b1 = np.zeros(4)
W2 = np.random.randn(4, 1); b2 = np.zeros(1)
lr = 0.5
losses = []

for epoch in range(5000):
    # FORWARD
    H = sigmoid(X @ W1 + b1)
    out = sigmoid(H @ W2 + b2)

    # LOSS
    loss = -np.mean(y*np.log(out+1e-9) + (1-y)*np.log(1-out+1e-9))
    losses.append(loss)

    # BACKWARD (backprop)
    d_out = (out - y) / len(y)
    dW2 = H.T @ d_out;  db2 = d_out.sum(axis=0)
    d_H = (d_out @ W2.T) * dsigmoid(H)
    dW1 = X.T @ d_H;  db1 = d_H.sum(axis=0)

    # UPDATE
    W1 -= lr * dW1; b1 -= lr * db1
    W2 -= lr * dW2; b2 -= lr * db2

print(f"Потеря в начале: {losses[0]:.3f}")
print(f"Потеря в конце:  {losses[-1]:.4f}")
```

**Что увидим:** потеря падает с **~0.74** до **~0.004** — сеть выучилась!

### 2.2. Проверяем — решён ли XOR

```python
H = sigmoid(X @ W1 + b1)
out = sigmoid(H @ W2 + b2)
predictions = (out > 0.5).astype(int)

print("Предсказания:", predictions.ravel())     # [0 1 1 0]
print("Правильно:   ", y.ravel().astype(int))    # [0 1 1 0]
print("XOR решён?", (predictions.ravel() == y.ravel()).all())   # True
```

**Что увидим:** `[0 1 1 0]` — **XOR РЕШЁН!** 🎉

> 🏆 **СВЕРШИЛОСЬ!** Мы **сами**, с нуля, на чистом NumPy, обучили нейросеть решать XOR. То, что **не смог** один нейрон (Урок 5.1), что раньше делал за нас `MLPClassifier` (5.3) — теперь сделали **мы**, понимая каждый шаг: forward, loss, backward, update. Это настоящая нейросеть, и ты построил её целиком.

### 2.3. Рисуем кривую потерь

## Задание 3. Эксперименты с обучением (8 минут)

### Что мы хотим показать

Как число нейронов и скорость обучения влияют на результат.

### 3.1. Оборачиваем обучение в функцию

```python
def train_xor(hidden=4, lr=0.5, epochs=5000, seed=1):
    np.random.seed(seed)
    W1 = np.random.randn(2, hidden); b1 = np.zeros(hidden)
    W2 = np.random.randn(hidden, 1); b2 = np.zeros(1)
    for epoch in range(epochs):
        H = sigmoid(X @ W1 + b1)
        out = sigmoid(H @ W2 + b2)
        d_out = (out - y) / len(y)
        dW2 = H.T @ d_out; db2 = d_out.sum(0)
        d_H = (d_out @ W2.T) * dsigmoid(H)
        dW1 = X.T @ d_H; db1 = d_H.sum(0)
        W1 -= lr*dW1; b1 -= lr*db1; W2 -= lr*dW2; b2 -= lr*db2
    out = sigmoid(sigmoid(X @ W1 + b1) @ W2 + b2)
    acc = ((out > 0.5).astype(int) == y).mean()
    return acc
```

### 3.2. Пробуем разное число нейронов

```python
# Пробуем каждое число нейронов на нескольких случайных стартах (seed)
for hidden in [1, 2, 4, 8]:
    accs = [train_xor(hidden=hidden, seed=s) for s in range(8)]
    print(f"Нейронов: {hidden} → точности при разных стартах: {accs}")
```

**Что увидим (примерно):**
```
Нейронов: 1 → [0.75, 0.75, ...]              ← 1 нейрона мало (почти как перцептрон!)
Нейронов: 2 → [0.5, 0.5, 1.0, 1.0, 0.5, ...] ← иногда решает, иногда застревает!
Нейронов: 4 → [1.0, 1.0, 1.0, 1.0, ...]      ← НАДЁЖНО 100%
Нейронов: 8 → [1.0, 1.0, 1.0, 1.0, ...]      ← надёжно
```

> **Важный вывод (и реальный эффект ML):**
> - **1 нейрон** — XOR не решает (≈как перцептрон в 5.1).
> - **2 нейрона** — *теоретически* хватает (2 прямые → кривая), но на практике сеть **часто застревает** в «плохом» решении (точность 0.5) — зависит от **случайного старта** весов! Это называется **локальный минимум**: сеть скатилась не в ту «долину».
> - **4+ нейрона** — решают XOR **надёжно** при любом старте.
>
> **Почему так:** больше нейронов = больше «путей» к правильному решению = меньше шанс застрять. Поэтому на практике берут нейронов **с запасом** — это страховка от неудачного старта. (Помнишь, как градиентный спуск в 1.7 мог застрять? Вот оно в сети.)

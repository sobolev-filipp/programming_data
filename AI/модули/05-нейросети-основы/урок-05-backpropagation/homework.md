## Шпаргалка (из практики)

```python
def sigmoid(z):  return 1/(1+np.exp(-z))
def dsigmoid(a): return a*(1-a)

# FORWARD
H = sigmoid(X @ W1 + b1)
out = sigmoid(H @ W2 + b2)
# BACKWARD (backprop)
d_out = (out - y)/len(y)
dW2 = H.T @ d_out
d_H = (d_out @ W2.T) * dsigmoid(H)    # ошибка течёт НАЗАД
dW1 = X.T @ d_H
# UPDATE
W1 -= lr*dW1; W2 -= lr*dW2  # (+ смещения)
```

> Веса инициализируй **случайно** (`np.random.randn`), не нулями!

# Урок 5.1. Нейрон и перцептрон — резюме

---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Нейрон (искусственный)** | Кирпичик сети: `z = w·x + b` → активация |
| **Веса (weights)** | Числа `w` — важность каждого входа |
| **Смещение (bias)** | Число `b` — сдвигает порог срабатывания |
| **Функция активации** | Превращает сумму `z` в выход (напр. ступенька) |
| **Перцептрон** | Нейрон со ступенчатой активацией (1958) |
| **Линейная разделимость** | Классы можно разделить **одной прямой** |
| **Эпоха** | Один полный проход по всем обучающим данным |

---

## Главные мысли

1. **Искусственный нейрон = `w·x + b` + активация** — формула, которую ты уже знаешь!
2. Нейрон скопирован с **биологического**: входы → сумма → порог → выход.
3. **Один нейрон с сигмоидой = логистическая регрессия** (Урок 3.4).
4. **Перцептрон учится** правилом: при ошибке — двигаем веса в сторону ответа.
5. Перцептрон решает **линейно разделимое** (AND, OR), но **НЕ XOR**.
6. Решение XOR — **соединить нейроны в слои** (многослойная сеть, Урок 5.3).

---

## Формула нейрона

```
z = w₁·x₁ + w₂·x₂ + ... + b        ← взвешенная сумма (как y = w·x + b!)
выход = активация(z)                ← напр. ступенька: 1 если z>0, иначе 0
```

## Перцептрон с нуля (шаблон)

```python
def predict(X, w, b):
    return (X @ w + b > 0).astype(int)      # сумма + ступенька

def train_perceptron(X, y, lr=0.1, epochs=20):
    w = np.zeros(X.shape[1]); b = 0.0
    for epoch in range(epochs):
        for xi, yi in zip(X, y):
            pred = 1 if (xi @ w + b) > 0 else 0
            update = lr * (yi - pred)         # ошибка × скорость
            w += update * xi                  # двигаем веса
            b += update
    return w, b
```

---

## Что перцептрон умеет и не умеет

| Функция | Линейно разделима? | Перцептрон осилит? |
|---------|--------------------|--------------------|
| AND, OR, NAND, NOR | да | ✅ да |
| **XOR** | **нет** (крест-накрест) | ❌ **нет** |

> Один нейрон = одна прямая. XOR прямой не разделить → нужны **слои**.

---

## Связь с прошлым

| Сейчас | Откуда знаем |
|--------|--------------|
| `z = w·x + b` | Линейная регрессия (3.3) |
| нейрон с сигмоидой | Логистическая регрессия (3.4) |
| обновление весов, `lr` | Градиентный спуск (1.7) |
| граница-прямая | SVM, логрег (3.4, 4.1) |

---

## Главные ошибки

| Ошибка | Как правильно |
|--------|---------------|
| «нейрон — это что-то новое и сложное» | это `w·x + b` + активация |
| «XOR не решился — баг» | XOR не линейно разделим, это ограничение |
| ждут 100% на перекрытых данных | только на линейно разделимых |

---

## Что должно остаться в голове после урока

1. Нейрон = **взвешенная сумма + активация** (`w·x + b` → активация).
2. Это **та же** линейная/логистическая модель, что в Модуле 3.
3. Перцептрон **сам учится**, подстраивая веса при ошибках.
4. Один нейрон решает только **линейно разделимое** (не XOR).
5. Сила нейросетей — в **соединении** нейронов в слои.

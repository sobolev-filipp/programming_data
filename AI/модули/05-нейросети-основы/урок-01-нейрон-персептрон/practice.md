## Задание 1. Нейрон своими руками: AND (16 минут)

### Что мы хотим сделать

Написать перцептрон и обучить его логике **AND**: выход 1, только если **оба** входа равны 1.

### 1.1. Данные — таблица истинности AND

```python
# 4 возможные комбинации входов
X = np.array([
    [0, 0],
    [0, 1],
    [1, 0],
    [1, 1]
])
# Правильные ответы для AND (1 только когда оба входа 1)
y_and = np.array([0, 0, 0, 1])

print("Входы:\n", X)
print("AND:", y_and)
```

### 1.2. Один шаг нейрона — предсказание

```python
def predict(X, w, b):
    z = X @ w + b                    # взвешенная сумма: w₁x₁ + w₂x₂ + b
    return (z > 0).astype(int)       # ступенька: 1 если z>0, иначе 0
```

#### Что делает эта функция

- **`X @ w + b`** — это **наша знакомая `w·x + b`**! `@` — матричное умножение (Урок 1.5): каждый вход умножается на вес и складывается.
- **`(z > 0).astype(int)`** — **ступенчатая активация**: если сумма больше 0, нейрон «срабатывает» (1), иначе молчит (0).

> Это **весь нейрон** — две строки. Взвешенная сумма + порог.

### 1.3. Обучение — нейрон сам подбирает веса

```python
def train_perceptron(X, y, lr=0.1, epochs=20):
    w = np.zeros(X.shape[1])         # начинаем с нулевых весов
    b = 0.0
    for epoch in range(epochs):
        errors = 0
        for xi, yi in zip(X, y):     # проходим по каждому примеру
            pred = 1 if (xi @ w + b) > 0 else 0   # предсказание нейрона
            update = lr * (yi - pred)              # ошибка × скорость
            w = w + update * xi                    # поправляем веса
            b = b + update                         # поправляем смещение
            if update != 0:
                errors += 1
        if errors == 0:              # если за эпоху ни одной ошибки — выучил!
            print(f"Выучил за {epoch + 1} эпох!")
            return w, b
    return w, b
```

#### Что происходит по шагам (это сердце урока!)

- **`w = np.zeros(...)`** — стартуем с нулевых весов (нейрон «ничего не знает»).
- **Эпоха** — один полный проход по всем примерам.
- Для каждого примера:
  - **`pred`** — что нейрон ответил сейчас.
  - **`update = lr · (yi − pred)`** — ошибка. Если угадал → 0 (не трогаем). Если ошибся → ±lr.
  - **`w = w + update · xi`** — двигаем веса в сторону правильного ответа.
- Если за целую эпоху **ни одной ошибки** — нейрон **выучил**, останавливаемся.

> **Это и есть обучение нейрона!** Никакой магии — пошаговая подстройка весов, как градиентный спуск в 1.7. Нейрон «нащупывает» нужные веса методом проб и ошибок.

### 1.4. Обучаем и проверяем

```python
w, b = train_perceptron(X, y_and)
print(f"Выученные веса: w = {w}, b = {b}")        # напр. w=[0.2 0.1], b=-0.2

# Проверяем на всех примерах
predictions = predict(X, w, b)
print("Предсказания:", predictions)                # [0 0 0 1]
print("Правильно:   ", y_and)                       # [0 0 0 1]
print("Всё верно?", (predictions == y_and).all())  # True
```

**Что увидим:** `Выучил за 6 эпох!`, предсказания `[0 0 0 1]` — **точно совпадают** с AND!

> **Нейрон сам, с нулевых весов, за 6 проходов выучил логику "И".** Мы не задавали правил — он **нашёл** веса сам. Это первое в твоей жизни обучение нейрона. 🎉

### Итог Задания 1

1. Написали перцептрон (взвешенная сумма + ступенька).
2. Написали обучение (подстройка весов при ошибке).
3. Нейрон **сам** выучил AND за 6 эпох.

## Задание 2. OR и граница решения (12 минут)

### Что мы хотим сделать

Обучить тот же перцептрон функции **OR** и **нарисовать** прямую, которой он разделяет классы.

### 2.1. Обучаем OR

```python
y_or = np.array([0, 1, 1, 1])        # OR: 1, если хотя бы один вход 1

w, b = train_perceptron(X, y_or)
print(f"Веса: w = {w}, b = {b}")
print("Предсказания:", predict(X, w, b))    # [0 1 1 1] — верно!
```

**Что увидим:** `Выучил за 4 эпох!`, предсказания `[0 1 1 1]` — это OR. Нейрон снова справился.

### 2.2. Рисуем границу решения

```python
plt.figure(figsize=(7, 7))

# Рисуем 4 точки, цвет = класс
colors = ['red' if label == 0 else 'green' for label in y_or]
plt.scatter(X[:, 0], X[:, 1], c=colors, s=300, edgecolor='black', zorder=3)

# Граница нейрона: там, где w₁x₁ + w₂x₂ + b = 0
# Выразим x₂: x₂ = -(w₁x₁ + b) / w₂
x_line = np.linspace(-0.5, 1.5, 100)
y_line = -(w[0] * x_line + b) / w[1]
plt.plot(x_line, y_line, 'b--', linewidth=2, label='Граница нейрона')

plt.xlabel("x₁"); plt.ylabel("x₂")
plt.title("Перцептрон разделяет OR прямой линией")
plt.legend(); plt.grid(); plt.show()
```

#### Что мы делаем

- Рисуем 4 точки (красные = 0, зелёные = 1).
- **Граница нейрона** — это линия, где `w₁x₁ + w₂x₂ + b = 0` (сумма ровно 0, нейрон «на грани»).
- Выражаем `x₂` через `x₁`, чтобы нарисовать прямую.

**Что увидим:** прямая **отделяет** зелёные точки (OR=1) от красной (OR=0). Нейрон нашёл линию, разделяющую классы!

> ### 📊 Как читать этот график (граница нейрона)
>
> **Зачем он нужен.** Понять, ЧТО геометрически делает нейрон. Он не «магия», а просто прямая линия, разделяющая классы — и это можно увидеть.
>
> **Что на осях.** X — вход x₁, Y — вход x₂. Четыре точки — все комбинации входов OR (красные = ответ 0, зелёные = ответ 1). Синяя пунктирная прямая — граница нейрона (там, где его сумма ровно 0).
>
> **Что мы видим.** Прямая проходит так, что одна красная точка `(0,0)` остаётся с одной стороны, а три зелёные — с другой.
>
> **Какой вывод.** Нейрон делит плоскость прямой: по одну сторону отвечает 0, по другую 1. Раз OR можно разделить одной прямой — нейрон его выучил. Это тот же принцип, что у логрегрессии и SVM. Дальше проверим XOR, где такой прямой НЕ существует.

> **Вот геометрический смысл нейрона:** он проводит **прямую** между классами (как SVM и логрег из Модулей 3–4). Для OR такая прямая есть — поэтому нейрон справился.

### Итог Задания 2

1. Нейрон выучил OR за 4 эпохи.
2. Увидели, что нейрон разделяет классы **прямой линией**.

## Задание 3. Проблема XOR (12 минут)

### Что мы хотим показать

Обучить перцептрон функции **XOR** — и убедиться, что он **не может** её решить.

### 3.1. Пробуем обучить XOR

```python
y_xor = np.array([0, 1, 1, 0])       # XOR: 1, если входы РАЗНЫЕ

w, b = train_perceptron(X, y_xor, epochs=20)
print(f"Веса: w = {w}, b = {b}")

predictions = predict(X, w, b)
print("Предсказания:", predictions)
print("Правильно:   ", y_xor)
print("Всё верно?", (predictions == y_xor).all())    # False!
```

**Что увидим:** **НЕТ** сообщения «Выучил за N эпох» (значит, за 20 эпох так и не выучил!). Предсказания **не совпадают** с XOR. `Всё верно? False`.

> **Перцептрон провалился.** Сколько ни увеличивай эпохи — XOR ему не даётся. Это не баг в нашем коде — это **фундаментальное ограничение** одного нейрона.

### 3.2. Почему? Рисуем XOR

```python
plt.figure(figsize=(7, 7))
colors = ['red' if label == 0 else 'green' for label in y_xor]
plt.scatter(X[:, 0], X[:, 1], c=colors, s=300, edgecolor='black', zorder=3)
for i, (xi, yi) in enumerate(zip(X, y_xor)):
    plt.annotate(f'XOR={yi}', (xi[0], xi[1]), fontsize=12,
                 xytext=(5, 10), textcoords='offset points')
plt.xlabel("x₁"); plt.ylabel("x₂")
plt.title("XOR: одной прямой не разделить!")
plt.grid(); plt.show()
```

**Что увидим:** зелёные точки (XOR=1) — в углах `(0,1)` и `(1,0)`. Красные (XOR=0) — в `(0,0)` и `(1,1)`. Они стоят **крест-накрест**.

**Попробуй сам провести ОДНУ прямую**, чтобы отделить зелёные от красных — **не получится!** Любая прямая оставит точки разных классов по одну сторону.

> ### 📊 Как читать этот график (почему XOR не решается)
>
> **Зачем он нужен.** Наглядно доказать, почему один нейрон провалил XOR — не через формулы, а геометрически.
>
> **Что на осях.** X — вход x₁, Y — вход x₂. Четыре точки-угла квадрата, подписанные значением XOR. Зелёные (XOR=1) — в углах `(0,1)` и `(1,0)`; красные (XOR=0) — в `(0,0)` и `(1,1)`.
>
> **Что мы видим.** Одинаковые цвета стоят **по диагонали**, крест-накрест: зелёные напротив зелёных, красные напротив красных.
>
> **Какой вывод.** Провести ОДНУ прямую, чтобы зелёные оказались по одну сторону, а красные по другую, физически невозможно — цвета «переплетены». А нейрон умеет только прямую. Вот почему он бессилен: XOR **не линейно разделим**. Отсюда и родилась идея многослойных сетей (несколько нейронов → ломаная граница).

> **Вот причина провала:** XOR **не линейно разделим**. А перцептрон умеет только прямые. **Одного нейрона физически недостаточно.**

### 3.3. Что это значит

```python
print("="*50)
print("ВЫВОД:")
print("Перцептрон (1 нейрон) решает AND и OR,")
print("но НЕ решает XOR — он не линейно разделим.")
print("РЕШЕНИЕ: соединить несколько нейронов в СЛОИ.")
print("Это будет в Уроке 5.3 (многослойная сеть)!")
print("="*50)
```

> **Это историческая проблема**, которая затормозила ИИ на 15 лет. Решение — **многослойная сеть**: несколько нейронов проведут несколько прямых, и вместе получится **кривая** граница, которая XOR осилит. Об этом — следующие уроки.

### Итог Задания 3

1. Перцептрон **не смог** выучить XOR (за любое число эпох).
2. Причина — XOR **не линейно разделим**, а нейрон умеет только прямые.
3. Решение — **слои нейронов** (Урок 5.3).

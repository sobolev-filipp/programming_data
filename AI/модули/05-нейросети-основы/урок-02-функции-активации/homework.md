## Шпаргалка (из практики)

```python
def sigmoid(z): return 1 / (1 + np.exp(-z))     # (0, 1)
def tanh(z):    return np.tanh(z)                # (-1, 1)
def relu(z):    return np.maximum(0, z)          # max(0, z)

# Наклон (производная) численно — как в Уроке 1.7
def slope(f, z, h=1e-5): return (f(z+h) - f(z-h)) / (2*h)
```

Шпаргалка «где какую»:
```
Скрытые слои       → ReLU
Выход (бинарный)   → sigmoid
Выход (многокласс) → softmax
Выход (регрессия)  → ничего
```

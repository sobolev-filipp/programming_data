## Задание 1. Рисуем три активации (14 минут)

### Что мы хотим сделать

Написать три активации и нарисовать их на одном графике — понять, кто как выглядит.

### 1.1. Пишем активации

```python
def sigmoid(z):
    return 1 / (1 + np.exp(-z))       # сжимает в (0, 1)

def tanh(z):
    return np.tanh(z)                  # сжимает в (-1, 1), numpy умеет сам

def relu(z):
    return np.maximum(0, z)            # max(0, z): отриц. → 0
```

#### Что делает каждая

- **`sigmoid`** — наша формула из Урока 3.4: `1 / (1 + e^(-z))`. `np.exp` — это `e` в степени.
- **`tanh`** — у NumPy есть готовая `np.tanh`.
- **`relu`** — `np.maximum(0, z)` сравнивает каждый элемент с 0 и берёт больший. Гениально просто.

### 1.2. Рисуем все три

```python
z = np.linspace(-5, 5, 200)        # 200 точек от -5 до 5

plt.figure(figsize=(12, 4))

plt.subplot(1, 3, 1)
plt.plot(z, sigmoid(z), 'b', linewidth=2)
plt.title("Sigmoid: (0, 1)"); plt.grid(); plt.axhline(0, color='gray'); plt.axvline(0, color='gray')

plt.subplot(1, 3, 2)
plt.plot(z, tanh(z), 'g', linewidth=2)
plt.title("tanh: (-1, 1)"); plt.grid(); plt.axhline(0, color='gray'); plt.axvline(0, color='gray')

plt.subplot(1, 3, 3)
plt.plot(z, relu(z), 'r', linewidth=2)
plt.title("ReLU: max(0, z)"); plt.grid(); plt.axhline(0, color='gray'); plt.axvline(0, color='gray')

plt.tight_layout()
plt.show()
```

#### Что увидим — три характера

- **Sigmoid** (синяя) — плавная S-кривая от 0 до 1. На краях **выполаживается** (становится плоской).
- **tanh** (зелёная) — такая же S, но от −1 до 1, проходит через ноль.
- **ReLU** (красная) — «сломанная прямая»: плоский 0 слева, прямая вверх справа.

> ### 📊 Как читать эти графики (три активации)
>
> **Зачем они нужны.** Функция активации — это «характер» нейрона. Формулы абстрактны, а форма кривой сразу показывает, что функция делает с числом: сжимает, симметрит или обнуляет.
>
> **Что на осях.** Три графика рядом (`subplot`). У каждого X — вход z (от −5 до 5), Y — выход активации. Серые линии — оси. Слева sigmoid, в центре tanh, справа ReLU.
>
> **Что мы видим.** Sigmoid — плавная S от 0 до 1, на краях выполаживается. tanh — такая же S, но от −1 до 1, проходит через центр. ReLU — «сломанная прямая»: слева ровный 0, справа прямая под 45°.
>
> **Какой вывод.** По форме видно поведение: sigmoid жмёт любое число в диапазон (0,1) — удобно для вероятности; tanh центрирует вокруг нуля (−1..1); ReLU просто отсекает отрицательные в 0, а положительные пропускает как есть. Плоские «хвосты» sigmoid позже окажутся её слабостью (Задание 3).

## Задание 2. Доказываем: без активации — прямая (12 минут)

### Что мы хотим показать

Главную мысль урока: **сложить линейные слои без активации = получить прямую**. Проверим на коде.

### 2.1. Два линейных слоя БЕЗ активации

```python
x = np.linspace(-5, 5, 100)

# Слой 1: h = w1*x + b1
w1, b1 = 2.0, 1.0
h = w1 * x + b1

# Слой 2 (БЕЗ активации между ними): y = w2*h + b2
w2, b2 = -0.5, 3.0
y = w2 * h + b2

plt.plot(x, y, 'b', linewidth=2, label='2 слоя без активации')
plt.title("Два линейных слоя без активации")
plt.legend(); plt.grid(); plt.show()
```

**Что увидим:** **прямая линия!** Два слоя, а на выходе — обычная прямая.

> ### 📊 Как читать этот график (два слоя без активации)
>
> **Зачем он нужен.** Доказать глазами главную мысль: если между линейными слоями нет активации, вся «глубина» сети бессмысленна.
>
> **Что на осях.** X — вход x, Y — выход сети из двух слоёв (без активации между ними).
>
> **Что мы видим.** Идеально **прямую** линию — ничем не отличается от одного слоя.
>
> **Какой вывод.** Два линейных слоя схлопнулись в одну прямую `y = Wx + B` (код ниже это подтверждает числами). Сколько бы слоёв ни ставили — без активации всегда получится одна прямая. Значит, глубина без активации бесполезна.

```python
# Проверим: это эквивалентно ОДНОМУ слою y = W*x + B
W = w2 * w1                  # -0.5 * 2 = -1.0
B = w2 * b1 + b2             # -0.5 * 1 + 3 = 2.5
print(f"Эквивалентно одному слою: y = {W}*x + {B}")     # y = -1.0*x + 2.5
```

> **Доказано!** Два слоя `w₂(w₁x+b₁)+b₂` свернулись в один `Wx+B`. Сколько слоёв ни добавь — без активации всё схлопнется в **одну прямую**. Глубокая сеть без активации **бесполезна**.

### 2.2. А теперь — С активацией между слоями

```python
# Слой 1 + ReLU
h = relu(w1 * x + b1)        # ← добавили активацию!
# Слой 2
y = w2 * h + b2

plt.plot(x, y, 'r', linewidth=2, label='2 слоя С ReLU')
plt.title("Те же 2 слоя, но с ReLU между ними")
plt.legend(); plt.grid(); plt.show()
```

**Что увидим:** теперь это **НЕ прямая** — линия **«сломалась»** (появился изгиб в точке, где ReLU обнуляет). Активация добавила **нелинейность**!

> ### 📊 Как читать этот график (те же слои, но с ReLU)
>
> **Зачем он нужен.** Показать разницу: та же сеть, но с активацией — и результат уже не прямая. Это источник «мощи» нейросети.
>
> **Что на осях.** X — вход x, Y — выход сети. Слои те же, что на прошлом графике, но между ними вставлен ReLU.
>
> **Что мы видим.** Линия с **изломом** — прямая, которая в одной точке меняет наклон (там, где ReLU обнулил отрицательную часть).
>
> **Какой вывод.** Один ReLU дал один излом. Много нейронов с активацией → много изломов → сеть может собрать из них **любую** сложную кривую. Именно активация превращает набор прямых в гибкую модель. Сравни с прошлым графиком: без активации — прямая, с активацией — изгиб.

> **Вот разница:** без активации — прямая, с активацией — изгиб. Если изгибов много (много нейронов с ReLU), сеть может нарисовать **любую** сложную кривую. Это и есть **источник мощи** нейросети.

### Итог Задания 2

1. **Доказали:** слои без активации = одна прямая (свернули `w₂(w₁x+b₁)+b₂` в `Wx+B`).
2. С ReLU линия **ломается** — появляется нелинейность.
3. Активация — то, что делает сеть способной на сложные формы.

## Задание 3. ReLU и затухающий градиент (8 минут)

### Что мы хотим показать

Почему ReLU лучше сигмоиды для глубоких сетей — увидим «плоские края» сигмоиды.

### 3.1. Наклон (производная) активаций

Сеть учится по **наклону** активации (вспомни градиент, Урок 1.7). Посчитаем наклоны численно:

```python
def numerical_slope(f, z, h=1e-5):
    return (f(z + h) - f(z - h)) / (2 * h)    # численная производная (Урок 1.7!)

z = np.linspace(-6, 6, 200)

plt.figure(figsize=(10, 4))
plt.plot(z, numerical_slope(sigmoid, z), 'b', label='Наклон sigmoid')
plt.plot(z, numerical_slope(relu, z), 'r', label='Наклон ReLU')
plt.title("Наклон активаций (важно для обучения)")
plt.xlabel("z"); plt.ylabel("наклон")
plt.legend(); plt.grid(); plt.show()
```

#### Что увидим — корень проблемы

- **Наклон сигмоиды** (синий): максимум 0.25 в центре, а на **краях падает до ≈0**. Там, где сигмоида «плоская», наклон почти ноль.
- **Наклон ReLU** (красный): для положительных z он **постоянно = 1**, не затухает!

> ### 📊 Как читать этот график (наклоны активаций)
>
> **Зачем он нужен.** Сеть учится по **наклону** (градиенту) активации. Если наклон близок к нулю — сигнал обучения «затухает» и слой перестаёт учиться. График показывает, у какой активации эта проблема есть.
>
> **Что на осях.** X — вход z. Y — наклон (производная) активации в этой точке. Синяя линия — наклон sigmoid, красная — наклон ReLU.
>
> **Что мы видим.** Синяя линия — «горка» с максимумом всего 0.25 в центре, а на краях прижимается к нулю. Красная линия — плоская: 0 для отрицательных z и ровно 1 для положительных.
>
> **Какой вывод.** У sigmoid на краях наклон ≈0 → в глубокой сети сигнал обучения гаснет («затухающий градиент»), слои учатся медленно. У ReLU наклон для положительных z всегда 1 → сигнал проходит без потерь. Поэтому в глубоких сетях по умолчанию берут ReLU, а не sigmoid.

### 3.2. Почему это важно

```python
# Наклон сигмоиды при больших z почти ноль
for z_val in [0, 2, 5, 10]:
    print(f"z={z_val:3}: наклон sigmoid = {numerical_slope(sigmoid, z_val):.5f}")
# z=  0: наклон sigmoid = 0.25000
# z=  5: наклон sigmoid = 0.00665
# z= 10: наклон sigmoid = 0.00005   ← почти ноль!
```

> **Вот она, проблема:** при `z=10` наклон сигмоиды = 0.00005 — практически ноль. «Нет наклона — нет обучения» (непонятно, куда двигать веса). В глубокой сети эти крошечные наклоны **перемножаются** и к первым слоям доходит **ноль** → они замирают.
>
> **ReLU спасает:** её наклон для положительных z всегда = 1, сигнал не затухает. Поэтому глубокие сети учат на ReLU. (Подробнее про градиенты — в Уроках 5.4–5.5.)

### Итог Задания 3

1. Сеть учится по **наклону** активации.
2. У сигмоиды наклон **затухает** на краях (до ≈0) → обучение замирает.
3. У ReLU наклон не затухает → глубокие сети учатся. Вот её главное преимущество.

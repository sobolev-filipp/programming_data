# Урок 5.2. Функции активации — резюме

---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Функция активации** | Функция над суммой `w·x+b`; источник нелинейности |
| **Нелинейность** | «Не прямая»; то, что даёт сети мощь |
| **Sigmoid** | Сжимает в (0, 1); для бинарного выхода |
| **tanh** | Сжимает в (−1, 1); центрирована |
| **ReLU** | `max(0, z)`; стандарт для скрытых слоёв |
| **Softmax** | «Сигмоида для многих классов» (сумма=1) |
| **Затухающий градиент** | Плоские края sigmoid/tanh мешают обучению |

---

## Главные мысли

1. **Без активации сеть = прямая.** Слои `w₂(w₁x+b₁)+b₂` сворачиваются в `Wx+B`.
2. **Активация даёт нелинейность** — источник всей мощи нейросети.
3. **Sigmoid** (0,1) — для бинарного выхода; **tanh** (−1,1) — центрирована.
4. **ReLU** `max(0,z)` — стандарт скрытых слоёв: быстро, не затухает.
5. **Затухающий градиент:** sigmoid/tanh на краях «плоские» (наклон≈0) → плохо учатся; ReLU спасает.
6. Современные сети (включая ChatGPT) работают на **ReLU** и её родственниках.

---

## Три активации (код)

```python
def sigmoid(z): return 1 / (1 + np.exp(-z))     # (0, 1)
def tanh(z):    return np.tanh(z)                # (-1, 1)
def relu(z):    return np.maximum(0, z)          # max(0, z)
```

---

## Где какую активацию

```
Скрытые слои       → ReLU      ⭐ выбор по умолчанию
Выход (бинарный)   → sigmoid   (вероятность да/нет)
Выход (многокласс) → softmax   (вероятности классов)
Выход (регрессия)  → ничего    (любое число)
```

---

## Сравнение

| Активация | Диапазон | Плюс | Минус |
|-----------|----------|------|-------|
| Sigmoid | (0, 1) | вероятность | затухает |
| tanh | (−1, 1) | центрирована | затухает |
| **ReLU** | [0, ∞) | быстро, не затухает | «умирает» |

---

## Главные ошибки

| Ошибка | Как правильно |
|--------|---------------|
| «активация — формальность» | без неё сеть = прямая! |
| sigmoid в скрытых слоях | ReLU лучше (не затухает) |
| забыли стандартизацию | нейросети она важна |
| ждут ровно 0/1 от sigmoid | только приближается |

---

## Что должно остаться в голове после урока

1. **Без активации даже глубокая сеть — прямая.**
2. Активация = **нелинейность** = мощь сети.
3. Три активации: sigmoid (0,1), tanh (−1,1), **ReLU** (max(0,z)).
4. **Скрытые слои → ReLU**, бинарный выход → sigmoid.
5. ReLU не затухает → на ней работают глубокие сети.

# Урок 6.6. Transfer learning — резюме

---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Transfer learning** | Взять готовую сеть и дообучить под свою задачу |
| **Предобученная сеть** | Сеть с уже обученными весами (готовая «умная») |
| **ImageNet** | Датасет: 1.2 млн фото, 1000 классов |
| **ResNet / MobileNet** | Готовые архитектуры (мощная / лёгкая) |
| **Заморозка** | `requires_grad=False` — веса не меняются |
| **Feature extraction** | Заморозить всё, учить только голову (быстро) |
| **Fine-tuning** | Разморозить и подучить маленьким `lr` (точнее) |
| **`fc` / `classifier`** | «Голова» сети — последний слой (его заменяем) |

---

## Главные мысли

1. **Transfer learning** = «взять чужой ум взаймы»: готовая сеть уже умеет видеть края, текстуры, формы.
2. Нижние признаки **универсальны** — их не надо переучивать под новую задачу.
3. **Три шага:** загрузить готовую сеть → заморозить тело → заменить последний слой.
4. Обучаем **только голову** (у ResNet18 — 5130 параметров из 11.7 млн = 0.05%).
5. ⚠️ Вход надо привести к **формату ImageNet**: размер 224 + нормализация.
6. **Два режима:** feature extraction (заморозь всё) и fine-tuning (разморозь, маленький `lr`).
7. Эффект: точность прыгает с ~70% до **80–90%+** почти бесплатно.

---

## Transfer learning в коде

```python
from torchvision import models
import torch.nn as nn

# 1. Загрузить готовую сеть (веса ImageNet, ~45 МБ)
net = models.resnet18(weights="IMAGENET1K_V1")

# 2. Заморозить тело
for p in net.parameters():
    p.requires_grad = False

# 3. Заменить голову под свои классы
net.fc = nn.Linear(512, 10)         # ResNet: было 1000 → стало 10

# 4. Обучать ТОЛЬКО голову
optimizer = torch.optim.Adam(net.fc.parameters(), lr=0.001)

# Вход — формат ImageNet:
tf = transforms.Compose([
    transforms.Resize(224),                     # CIFAR 32×32 → 224
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485,0.456,0.406],
                         std=[0.229,0.224,0.225])
])
```

---

## Где «голова» у разных сетей

| Сеть | Последний слой | Замена под 10 классов |
|------|----------------|------------------------|
| **ResNet18** | `net.fc` | `nn.Linear(512, 10)` |
| **MobileNet v2** | `net.classifier[1]` | `nn.Linear(1280, 10)` |

---

## Feature extraction vs Fine-tuning

| | Feature extraction | Fine-tuning |
|--|--------------------|-------------|
| Что обучаем | только голову | голову + (часть) тела |
| Скорость | быстро | медленнее |
| Данных нужно | мало | много |
| `lr` | обычный | **маленький** (1e-4) |
| Точность | высокая | максимальная |

---

## Главные ошибки

| Ошибка | Как правильно |
|--------|---------------|
| Забыл размер/нормализацию входа | Resize(224) + Normalize ImageNet |
| Не заморозил тело | `requires_grad=False` всем |
| Учит всё вместо головы | оптимизатору — `net.fc.parameters()` |
| Перепутал голову MobileNet | у неё `classifier[1]`, не `fc` |
| Большой `lr` при fine-tuning | маленький (1e-4), иначе сломает веса |

---

## Что должно остаться в голове после урока

1. **Transfer learning** — берём готовую сеть, не учим с нуля.
2. Три шага: **загрузить → заморозить → заменить голову**.
3. Учим только **голову** — крошечную часть сети.
4. Вход — в **формате ImageNet** (224 + нормализация).
5. Точность взлетает (70% → 90%+) — так работают профессионалы.

На этом построены беспилотные авто, камеры безопасности, подсчёт людей в толпе. Познакомимся с самой известной сетью для этого — **YOLO** («You Only Look Once»). 🚀

## Задание 1. Берём готовую сеть (12 минут)

### Что мы хотим сделать

Загрузить **готовую** ResNet18, посмотреть, что внутри, **заморозить** её и **заменить** последний слой под свои 10 классов.

### Что мы сделаем (шаги словами)

1. Скачаем ResNet18 с весами ImageNet.
2. Посмотрим её последний слой (он на 1000 классов).
3. Заморозим все веса.
4. Заменим последний слой на свой (на 10 классов) и посчитаем, **сколько** параметров реально будет обучаться.

### 1.1. Загружаем готовую сеть

```python
# weights="IMAGENET1K_V1" — взять веса, обученные на ImageNet (скачается ~45 МБ)
net = models.resnet18(weights="IMAGENET1K_V1")

print(net.fc)   # последний слой — "голова" сети
```

**Что произошло:** мы скачали сеть, которая **уже обучена** на 1.2 млн картинок. Она умеет распознавать 1000 классов ImageNet.

**Что увидим:**
```
Linear(in_features=512, out_features=1000, bias=True)
```

> **Что это значит:** последний слой `fc` («fully connected», полносвязный) принимает **512** признаков и выдаёт **1000** чисел — по одному на каждый класс ImageNet. Нам нужно **10** (классы CIFAR), а не 1000. Этот слой мы заменим.

### 1.2. Замораживаем тело сети

```python
# Запрещаем всем весам меняться при обучении
for param in net.parameters():
    param.requires_grad = False

# Проверим: сколько параметров теперь обучаемых?
trainable = sum(p.numel() for p in net.parameters() if p.requires_grad)
print("Обучаемых параметров после заморозки:", trainable)
```

**Что произошло:** мы прошли по всем весам сети и поставили `requires_grad = False` — «не учить». Теперь сеть **заморожена**.

**Что увидим:**
```
Обучаемых параметров после заморозки: 0
```

> **Что это значит:** обучаемых параметров — **ноль**. Вся сеть «застыла»: она будет работать как готовый извлекатель признаков, но меняться не будет. Это и есть **заморозка**.

### 1.3. Заменяем «голову» под свои 10 классов

```python
# Новый последний слой: из 512 признаков → в 10 классов (CIFAR)
# У нового слоя requires_grad=True по умолчанию — он БУДЕТ обучаться
net.fc = nn.Linear(512, 10)

net = net.to(device)

# Сколько теперь обучаемых параметров?
trainable = sum(p.numel() for p in net.parameters() if p.requires_grad)
total = sum(p.numel() for p in net.parameters())
print(f"Обучаемых: {trainable}  из  {total}  всего")
```

**Что произошло:** мы **выбросили** старый слой на 1000 классов и **поставили** новый — на 10. Новый слой не заморожен, значит, обучаться будет **только он**.

**Что увидим:**
```
Обучаемых: 5130  из  11181642  всего
```

> **Что это значит:** обучаться будет всего **5130** параметров (512×10 весов + 10 смещений) из **11.18 миллиона**! Это **0.05%** сети. Всё остальное — готовые знания ImageNet, мы их используем «как есть». Вот почему transfer learning быстрый: учим крошечную «голову», а гигантское «тело» уже умное.

### Итог Задания 1

1. Загрузили **готовую** ResNet18 (веса ImageNet).
2. **Заморозили** её — 0 обучаемых параметров.
3. **Заменили** последний слой под свои 10 классов — теперь учится только он (5130 параметров).

## Задание 2. Дообучаем на CIFAR (20 минут)

### Что мы хотим сделать

Подать в нашу сеть CIFAR (приведя картинки к формату ImageNet) и обучить **только новую голову**. Сравнить точность с нашей старой CNN (~70%).

### Что мы сделаем (шаги словами)

1. Зададим преобразования: увеличить картинки до 224 и нормализовать «как ImageNet».
2. Загрузим CIFAR (возьмём **подвыборку**, чтобы на уроке было быстро).
3. Обучим только голову несколько эпох.
4. Посмотрим точность.

### Что у нас будет в итоге

Точность **выше 80%** за пару минут обучения — притом что обучаем лишь 5130 параметров. Это заметно больше, чем ~70% у нашей CNN, обученной с нуля на всех данных.

### 2.1. Приводим картинки к формату ImageNet

```python
# Готовая сеть ждёт картинки 224×224, нормализованные "как ImageNet"
tf = transforms.Compose([
    transforms.Resize(224),                       # CIFAR 32×32 → увеличить до 224
    transforms.ToTensor(),                        # в тензор 0..1
    transforms.Normalize(mean=[0.485, 0.456, 0.406],   # числа ImageNet
                         std=[0.229, 0.224, 0.225])    # (просто копируем)
])
```

> **Зачем это:** сеть обучалась на картинках именно такого формата. Подай ей «не тот» вход — готовые веса собьются. Поэтому увеличиваем CIFAR до 224 и нормализуем как ImageNet. (Подробнее — в [theory.md, раздел 6](theory.md#6-важная-деталь-вход-надо-привести-к-формату-imagenet).)

### 2.2. Загружаем CIFAR (берём подвыборку — чтобы быстро)

```python
train_full = datasets.CIFAR10(root='./data', train=True,  download=True, transform=tf)
test_full  = datasets.CIFAR10(root='./data', train=False, download=True, transform=tf)

# Подвыборка: 3000 для обучения, 1000 для теста — чтобы урок шёл быстро
train_data = Subset(train_full, range(3000))
test_data  = Subset(test_full,  range(1000))

train_loader = DataLoader(train_data, batch_size=64, shuffle=True)
test_loader  = DataLoader(test_data,  batch_size=64)
```

> **Почему подвыборка:** картинки теперь 224×224 (в 49 раз больше пикселей, чем 32×32!), прогон тяжелее. На уроке берём 3000/1000, чтобы увидеть результат за минуты. Дома (или с GPU) можно взять **все** данные — точность будет ещё выше.

### 2.3. Обучаем ТОЛЬКО голову

```python
loss_fn = nn.CrossEntropyLoss()
# Внимание: оптимизатору даём ТОЛЬКО параметры новой головы (net.fc)
optimizer = torch.optim.Adam(net.fc.parameters(), lr=0.001)

for epoch in range(3):
    net.train()
    for x_batch, y_batch in train_loader:
        x_batch, y_batch = x_batch.to(device), y_batch.to(device)
        optimizer.zero_grad()
        loss = loss_fn(net(x_batch), y_batch)
        loss.backward()
        optimizer.step()

    # Оценка на тесте
    net.eval()
    correct = total = 0
    with torch.no_grad():
        for x_batch, y_batch in test_loader:
            x_batch, y_batch = x_batch.to(device), y_batch.to(device)
            preds = net(x_batch).argmax(dim=1)
            correct += (preds == y_batch).sum().item()
            total += len(y_batch)
    print(f"Эпоха {epoch+1}: точность {correct/total:.4f}")
```

**Что произошло по шагам:**
- `optimizer = Adam(net.fc.parameters(), ...)` — оптимизатор обновляет **только голову** (`net.fc`). Тело заморожено, и мы даже не передаём его параметры оптимизатору.
- Цикл обучения — **точно такой же**, как в уроках 5.8 и 6.4! Сменилась только сеть.
- Каждую эпоху считаем точность на тесте.

**Что увидим (примерно):**
```
Эпоха 1: точность 0.7580
Эпоха 2: точность 0.8020
Эпоха 3: точность 0.8180
```

> **Что это значит:** уже после **первой** эпохи — ~76%, а к третьей — **82%**! И это на **подвыборке** из 3000 картинок, обучая лишь 5130 параметров, на CPU. Наша CNN из урока 6.4 давала ~70% на **всех** 50 000 картинок и обучалась дольше. Готовые признаки ImageNet сделали всю тяжёлую работу за нас. 🎉

### 2.4. Сравнение с обучением «с нуля»

```python
final = correct / total
print(f"Наша CNN с нуля (Урок 6.4):      ~0.70")
print(f"+ аугментация (Урок 6.5):         ~0.75")
print(f"Transfer learning (сегодня):      {final:.2f}")
print()
print("Готовая сеть обошла нашу — обучив лишь 0.05% параметров!")
```

#### Что это значит

> 🎉 **Transfer learning обогнал нашу собственную CNN** — притом что мы почти ничего не обучали (только голову на 5130 параметров) и взяли лишь часть данных. В этом вся сила: **мы переиспользовали чужие знания**, выученные на миллионах фото.
>
> ⚠️ **Честно про числа:** мы взяли подвыборку и 3 эпохи ради скорости урока. На **полном** CIFAR, с GPU и большим числом эпох (а ещё лучше — с **fine-tuning**, разморозив часть тела с маленьким `lr`) точность доходит до **90%+**. Идея та же — просто больше данных и времени.

### 2.5. (Бонус, если есть GPU и время) MobileNet вместо ResNet

```python
# Та же идея, но лёгкая сеть для телефонов
mnet = models.mobilenet_v2(weights="IMAGENET1K_V1")
for p in mnet.parameters():
    p.requires_grad = False
# У MobileNet последний слой лежит в classifier[1]
mnet.classifier[1] = nn.Linear(1280, 10)   # заменяем голову под 10 классов
mnet = mnet.to(device)
print(mnet.classifier)
```

> **Что увидим:** у MobileNet «голова» — это `classifier[1]` (а не `fc`, как у ResNet). Меняем именно её: `Linear(1280 → 10)`. MobileNet легче (~3.5 млн параметров против 11.7 млн у ResNet) и быстрее — её ставят в телефоны. **Идея transfer learning та же**, отличается лишь имя последнего слоя.

### Итог Задания 2

1. Привели CIFAR к формату ImageNet (размер 224 + нормализация).
2. Обучили **только голову** — и получили **82%** против ~70% у CNN с нуля.
3. Цикл обучения не менялся — поменялась только сеть (взяли готовую).
4. У разных сетей «голова» называется по-разному: ResNet → `fc`, MobileNet → `classifier[1]`.

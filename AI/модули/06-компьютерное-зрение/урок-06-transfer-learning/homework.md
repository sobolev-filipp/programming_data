import torch.nn as nn

# 1. Загрузить готовую сеть
net = models.resnet18(weights="IMAGENET1K_V1")

# 2. Заморозить тело

    p.requires_grad = False

# 3. Заменить голову (под N классов)

## Уровень 3. Со звёздочкой

### 3.1. Попробуй fine-tuning

> **Задача:** разморозить часть тела и выжать больше точности.

**Что нужно сделать:**
1. Возьми предобученную ResNet18, замени голову.
2. **Разморозь** последний блок тела (например, `layer4`) вдобавок к голове.
3. Обучи **маленьким** `lr` (например, `1e-4`). Сравни с feature extraction.

> **Подсказка:** разморозить блок: `for p in net.layer4.parameters(): p.requires_grad = True`. Оптимизатору передай **все** обучаемые параметры: `[p for p in net.parameters() if p.requires_grad]`. Маленький `lr` обязателен — иначе сломаешь готовые веса.

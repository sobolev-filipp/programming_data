# Урок 6.3. Архитектура CNN — резюме

---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **CNN** | Свёрточная сеть: признаки + классификатор |
| **`Conv2d`** | Свёрточный слой (фильтры — учатся) |
| **`MaxPool2d`** | Пулинг (уменьшает картинку вдвое) |
| **Канал** | «Слой» данных (число = число фильтров) |
| **Извлекатель признаков** | Свёрточная часть (свёртки + пулинг) |
| **Классификатор** | Обычные `Linear` слои в конце |

---

## Главные мысли

1. **CNN = конвейер:** извлекатель признаков (свёртки+пулинг) + классификатор (Linear).
2. Структура: `свёртка → ReLU → пулинг` (повторяем) → `view` → `Linear` → ответ.
3. По ходу: **размер ↓** (пулинг), **каналы ↑** (больше фильтров).
4. `Conv2d` и `MaxPool2d` — готовые слои PyTorch, собираем как кубики.
5. Цикл обучения **тот же**, что у MLP — autograd сам считает градиенты свёрток.
6. CNN на MNIST даёт **~99%** — ошибается в 2+ раза реже, чем MLP.

---

## Класс CNN (шаблон)

```python
class CNN(nn.Module):
    def __init__(self):
        super().__init__()
        # извлекатель признаков
        self.conv1 = nn.Conv2d(1, 16, 3, padding=1)
        self.conv2 = nn.Conv2d(16, 32, 3, padding=1)
        self.pool = nn.MaxPool2d(2)
        # классификатор
        self.fc1 = nn.Linear(32*7*7, 64)
        self.fc2 = nn.Linear(64, 10)
    def forward(self, x):
        x = self.pool(torch.relu(self.conv1(x)))   # 28→14
        x = self.pool(torch.relu(self.conv2(x)))   # 14→7
        x = x.view(x.size(0), -1)                   # 32*7*7=1568
        x = torch.relu(self.fc1(x))
        return self.fc2(x)
```

---

## Динамика размеров (MNIST)

| Этап | Размер | Каналы |
|------|--------|--------|
| Вход | 28×28 | 1 |
| conv1 → pool | 14×14 | 16 |
| conv2 → pool | 7×7 | 32 |
| view | 1568 чисел | — |

> Размер падает, каналы растут. `32×7×7 = 1568` — вход классификатора.

---

## CNN vs MLP (MNIST)

| Модель | Точность | Ошибок /10000 |
|--------|----------|---------------|
| MLP (5.8) | ~97% | ~300 |
| **CNN** | **~99%** | **~130** |

> CNN ошибается в 2+ раза реже — свёртки хранят структуру картинки.

---

## Главные ошибки

| Ошибка | Как правильно |
|--------|---------------|
| Неверный размер в `fc1` | пересчитать каналы×H×W |
| Вытягивают картинку до CNN | CNN работает с 28×28 |
| Забыли `padding=1` | свёртка не уменьшит размер |
| softmax на выходе | он в CrossEntropyLoss |

---

## Что должно остаться в голове после урока

1. CNN = **извлекатель признаков + классификатор**.
2. Свёртка → ReLU → пулинг (повторяем), потом Linear.
3. Размер ↓, каналы ↑.
4. Собирается из `Conv2d`, `MaxPool2d` в PyTorch.
5. CNN **видит лучше** MLP (~99% на MNIST).

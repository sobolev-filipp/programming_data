## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Конвейер (pipeline)** | Цепочка шагов: данные → модель → обучение → оценка |
| **«Обучаемая машина»** | Универсальный код: меняешь данные → новая задача |
| **Матрица ошибок** | Таблица «кто с кем путается» (истина × предсказание) |
| **Инференс** | Применение обученной модели к новой картинке |
| **`ImageFolder`** | Загрузка картинок по папкам (папка = класс) |

## Главные мысли

1. Проект = **5 кубиков**: данные → аугментация → transfer learning → обучение → оценка.
2. Все кубики мы уже знали — урок про **сборку** в один конвейер.
3. **«Обучаемая машина»:** меняешь папки с картинками → распознаёшь что угодно. Один код — любая задача.
4. **Матрица ошибок** показывает, **ГДЕ** модель ошибается (не только «сколько процентов»).
5. У нас: ~94% на 3 классах; модель путала **бумагу и ножницы** (похожи), камень — идеально.
6. Нейросеть + обычный код = реальное приложение (игра против ИИ).

## Как читать матрицу ошибок

```
          предсказано
        paper rock scissors
истина:
paper  [ 103    2    19 ]   ← 19 раз бумагу приняли за ножницы
rock   [   0  124     0 ]   ← камень идеально
scissors[  2    0   122 ]
```

> **Диагональ** — верно. **Вне диагонали** — ошибки. Здесь видна путаница бумага↔ножницы (похожие жесты).

## Главные ошибки

| Ошибка | Как правильно |
|--------|---------------|
| Неверное N в голове | N = число папок-классов |
| Аугментация на тесте | только train |
| Читают матрицу наоборот | строка=истина, столбец=предсказание |
| Один фон у всех фото класса | разнообразь фон (иначе учит фон) |

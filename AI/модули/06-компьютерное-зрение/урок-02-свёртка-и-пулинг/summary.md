# Урок 6.2. Свёртка и пулинг — резюме

---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Свёртка** | Фильтр бежит по картинке, считает взвешенную сумму |
| **Фильтр (ядро)** | Маленькая матрица — «детектор» узора |
| **Карта признаков** | Результат свёртки (где нашёлся узор) |
| **Пулинг** | Уменьшить картинку, взяв максимум окошек |
| **Max pooling** | Из каждого окошка 2×2 берём максимум |
| **CNN** | Свёрточная сеть — учит фильтры сама |

---

## Главные мысли

1. **Свёртка** = фильтр (маленькая матрица) бежит по картинке и считает `w·x` на окошке.
2. **Числа в фильтре** решают, какой узор он находит (края, углы, размытие).
3. 🌟 **Сеть учит фильтры САМА** (как веса, через backprop) — главный прорыв CNN.
4. **Иерархия:** края → детали → части → объекты (простое → сложное).
5. **Пулинг** уменьшает картинку (максимум окошек), оставляя суть.
6. Свёртка **лучше вытягивания**: хранит структуру, мало весов, узор в любом месте.

## Свёртка и пулинг (код)

```python
from scipy.signal import convolve2d

# Свёртка с фильтром краёв
edge = np.array([[-1,0,1],[-2,0,2],[-1,0,1]])
result = convolve2d(gray, edge, mode='valid')
plt.imshow(np.abs(result), cmap='gray')

# Max pooling 2×2
def max_pool(img, size=2):
    h = img.shape[0]//size*size; w = img.shape[1]//size*size
    return img[:h,:w].reshape(h//size,size,w//size,size).max(axis=(1,3))
```

---

## Фильтры (ядра)

| Фильтр | Что находит |
|--------|-------------|
| `[[-1,0,1],[-2,0,2],[-1,0,1]]` | вертикальные края |
| `[[-1,-2,-1],[0,0,0],[1,2,1]]` | горизонтальные края |
| `ones(3,3)/9` | размытие |
| `[[0,-1,0],[-1,5,-1],[0,-1,0]]` | резкость |

> Фильтры краёв: сумма чисел ≈ 0 (ловят **разницу**, а не уровень).

---

## Свёртка vs «вытягивание» (MLP)

| | MLP (вытягивание) | Свёртка |
|---|---|---|
| Соседство пикселей | теряется | сохраняется (окошко) |
| Число весов | много | мало (фильтр 3×3) |
| Объект в другом месте | не узнаёт | находит везде |

---

## Главные ошибки

| Ошибка | Как правильно |
|--------|---------------|
| «свёртка — новое» | это `w·x` на окошке (нейрон) |
| Забыли `np.abs` для краёв | модуль — сила края |
| «фильтры задают руками» | CNN учит их сама |
| Путают пулинг и свёртку | пулинг = максимум (без весов) |

---

## Что должно остаться в голове после урока

1. **Свёртка** = фильтр бежит по картинке, считает сумму.
2. Числа фильтра = какой узор ищет.
3. **Сеть учит фильтры сама** (главная идея CNN).
4. **Пулинг** уменьшает картинку, беря максимум.
5. Свёртка хранит структуру → лучше для картинок.

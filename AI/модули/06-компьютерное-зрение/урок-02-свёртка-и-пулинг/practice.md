## Задание 1. Свёртка руками: края (16 минут)

### Что мы хотим сделать

Применить фильтр выделения краёв и **увидеть**, как из фото проступают контуры.

### 1.1. Берём серую картинку

```python
img = data.chelsea()                            # кот
gray = cv2.cvtColor(img, cv2.COLOR_RGB2GRAY).astype(float)
print("Форма:", gray.shape)                     # (300, 451)

plt.imshow(gray, cmap='gray'); plt.title("Оригинал (серый)"); plt.axis('off'); plt.show()
```

### 1.2. Задаём фильтр краёв

```python
# Фильтр Собеля для вертикальных краёв
edge_filter = np.array([
    [-1, 0, 1],
    [-2, 0, 2],
    [-1, 0, 1]
])
print("Наш фильтр (3×3):\n", edge_filter)
```

> **Этот фильтр находит вертикальные края:** где слева тёмно, а справа светло — большое число; на гладкой области — около нуля. (Левый столбец отрицательный, правый положительный → ловит «перепад» слева направо.)

### 1.3. Применяем свёртку

```python
edges = convolve2d(gray, edge_filter, mode='valid')

print("Форма результата:", edges.shape)         # чуть меньше (фильтр «съел» края)

plt.figure(figsize=(12, 5))
plt.subplot(1, 2, 1); plt.imshow(gray, cmap='gray'); plt.title("Оригинал"); plt.axis('off')
plt.subplot(1, 2, 2); plt.imshow(np.abs(edges), cmap='gray'); plt.title("После фильтра краёв"); plt.axis('off')
plt.show()
```

#### Что увидим

- **Слева** — обычное фото кота.
- **Справа** — **контуры**! Выделились границы: очертания кота, глаза, усы, края меха. Гладкие области (фон, щёки) — тёмные (нет краёв).

> 🎉 **Вот она, свёртка!** Маленький фильтр 3×3 пробежал по картинке и **нашёл все вертикальные края**. Мы не говорили ему, где кот — он просто везде искал «перепад яркости». Это и есть, как сеть начинает «видеть» — с поиска краёв.

#### `np.abs` — зачем

Края могут быть «слева-направо» (плюс) и «справа-налево» (минус). `np.abs` берёт модуль — нам важна **сила** края, а не направление.

### Итог Задания 1

1. Фильтр 3×3 + свёртка = **карта краёв**.
2. Сеть «видит» объект через его **контуры**.
3. Свёртка — `фильтр × окошко`, по всей картинке.

## Задание 2. Разные фильтры → разные узоры (10 минут)

### Что мы хотим показать

Что **числа в фильтре** решают, какой узор он находит.

### 2.1. Три разных фильтра

```python
filters = {
    "Размытие": np.ones((3, 3)) / 9,                          # усреднение
    "Резкость": np.array([[0,-1,0],[-1,5,-1],[0,-1,0]]),      # усиление деталей
    "Края (верт.)": np.array([[-1,0,1],[-2,0,2],[-1,0,1]]),   # вертикальные края
    "Края (гориз.)": np.array([[-1,-2,-1],[0,0,0],[1,2,1]]),  # горизонтальные края
}

plt.figure(figsize=(16, 4))
for i, (name, f) in enumerate(filters.items()):
    result = convolve2d(gray, f, mode='valid')
    plt.subplot(1, 4, i+1)
    plt.imshow(np.abs(result), cmap='gray')
    plt.title(name); plt.axis('off')
plt.show()
```

#### Что увидим — каждый фильтр своё

- **Размытие** — кот стал мутным (сгладились детали).
- **Резкость** — детали усилились (чёткие усы, мех).
- **Края вертикальные** — выделились **вертикальные** линии.
- **Края горизонтальные** — выделились **горизонтальные** линии (поменяли фильтр на 90°!).

> **Один и тот же приём (свёртка), но разные числа в фильтре → совершенно разные результаты.** Вертикальный и горизонтальный фильтры краёв отличаются только поворотом — и находят разные линии. **Числа фильтра = что он ищет.**

### 2.2. Вспоминаем главную идею

```python
print("Мы ЗАДАЛИ эти фильтры руками.")
print("А свёрточная сеть УЧИТ такие фильтры САМА —")
print("подбирает числа через backprop, чтобы узнавать объекты!")
```

> **Вот ключ:** мы придумали фильтры краёв сами. Но сеть может **выучить** тысячи фильтров — для усов, ушей, глаз, колёс — просто минимизируя ошибку (как веса в Модуле 5). Ей не нужен эксперт. В этом сила CNN.

### Итог Задания 2

1. Числа в фильтре решают, какой узор он находит.
2. Размытие, резкость, края — разные фильтры.
3. Сеть **учит** такие фильтры сама (главная идея).

## Задание 3. Пулинг: уменьшаем картинку (10 минут)

### Что мы хотим сделать

Применить **max pooling** и увидеть, как картинка уменьшается, сохраняя суть.

### 3.1. Пишем max pooling

```python
def max_pool(img, size=2):
    h = img.shape[0] // size * size
    w = img.shape[1] // size * size
    img = img[:h, :w]                                    # обрезаем до кратного
    # делим на окошки size×size и берём максимум каждого
    return img.reshape(h//size, size, w//size, size).max(axis=(1, 3))

pooled = max_pool(gray, 2)
print("Было:", gray.shape, "→ стало:", pooled.shape)     # в 2 раза меньше по каждой стороне
```

### 3.2. Сравниваем

```python
plt.figure(figsize=(12, 5))
plt.subplot(1, 2, 1); plt.imshow(gray, cmap='gray'); plt.title(f"Оригинал {gray.shape}"); plt.axis('off')
plt.subplot(1, 2, 2); plt.imshow(pooled, cmap='gray'); plt.title(f"После max pool {pooled.shape}"); plt.axis('off')
plt.show()
```

**Что увидим:** картинка стала **в 2 раза меньше** по каждой стороне (в 4 раза меньше пикселей!), но кот **всё ещё узнаваем**. Суть сохранилась, деталей меньше.

#### Что произошло

- Картинку поделили на окошки 2×2, из каждого взяли **максимум** (самый яркий пиксель).
- Размер уменьшился вдвое → **меньше вычислений** для сети.
- Кот узнаваем → **суть сохранена**.

> **Пулинг = «сжать картинку, оставив главное».** В CNN свёртка и пулинг чередуются: свёртка находит узоры, пулинг укрупняет их и уменьшает картинку. Так сеть постепенно от пикселей доходит до «это кот».

### 3.3. Пулинг даёт устойчивость к сдвигу

```python
print("Бонус: если объект чуть сдвинуть,")
print("максимум в окошке почти не изменится →")
print("сеть узнает объект, ГДЕ БЫ он ни был на картинке.")
```

> Это важный плюс пулинга: кот в левом углу или в правом — пулинг «сгладит» разницу, и сеть узнает его в любом месте.

### Итог Задания 3

1. Max pooling уменьшает картинку, беря максимумы окошек.
2. Суть сохраняется, деталей меньше → быстрее.
3. Даёт устойчивость к сдвигу объекта.

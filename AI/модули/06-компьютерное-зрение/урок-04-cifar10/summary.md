# Урок 6.4. CNN на CIFAR-10 — резюме

---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **CIFAR-10** | 60k цветных фото 32×32, 10 классов объектов |
| **Цветной вход** | 3 канала (RGB) → `Conv2d(3, ...)` |
| **(C, H, W)** | Порядок осей в PyTorch (каналы первые) |
| **Внутриклассовая изменчивость** | объекты класса выглядят по-разному |

---

## Главные мысли

1. **CIFAR-10** — реальные цветные объекты (самолёты, коты...), сложнее MNIST.
2. Цветная картинка = **3 канала** → первый слой `Conv2d(3, ...)`.
3. В PyTorch порядок осей **(каналы, H, W)** = (3, 32, 32).
4. CIFAR **труднее** MNIST: изменчивость, фон, цвет, низкое разрешение.
5. CNN даёт **~70%** (не 99%) — это **нормально** (наугад = 10%).
6. Поднять точность помогут: **аугментация** (6.5) и **готовые сети** (6.6).

---

## CNN для CIFAR (отличия от MNIST)

```python
class CNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(3, 32, 3, padding=1)   # 3 КАНАЛА (vs 1 у MNIST)
        self.conv2 = nn.Conv2d(32, 64, 3, padding=1)
        self.pool = nn.MaxPool2d(2)
        self.fc1 = nn.Linear(64*8*8, 128)             # 32→16→8 (vs 28→14→7)
        self.fc2 = nn.Linear(128, 10)
    def forward(self, x):
        x = self.pool(torch.relu(self.conv1(x)))
        x = self.pool(torch.relu(self.conv2(x)))
        x = x.view(x.size(0), -1)
        x = torch.relu(self.fc1(x))
        return self.fc2(x)
```

> Показ цветной картинки: `plt.imshow(img.permute(1,2,0))` — (C,H,W) → (H,W,C).

## MNIST vs CIFAR

| | MNIST | CIFAR-10 |
|---|---|---|
| Картинки | серые цифры | цветные объекты |
| Каналов | 1 | 3 |
| Размер | 28×28 | 32×32 |
| Сложность | лёгкая | трудная |
| Точность CNN | ~99% | ~70% |

---

## Почему ~70% — это нормально

- Наугад из 10 классов = **10%** → наша CNN в **7 раз** лучше.
- CIFAR труден: изменчивые объекты, фон, цвет, 32×32.
- Ошибки — на **похожих** классах (кот/собака, олень/лошадь).

---

## Главные ошибки

| Ошибка | Как правильно |
|--------|---------------|
| Расстраиваются из-за 70% | это норма для CIFAR |
| Забыли `Conv2d(3, ...)` | вход 3 канала |
| Забыли `permute` для показа | (C,H,W)→(H,W,C) |
| Без GPU | очень долго |

## Что должно остаться в голове после урока

1. **CIFAR-10** — цветные реальные объекты, трудная задача.
2. Цвет = **3 канала** → `Conv2d(3, ...)`.
3. CIFAR **сложнее** MNIST по многим причинам.
4. **~70% — это нормально** (наугад = 10%).
5. Поднять точность помогут аугментация и готовые сети.

## К следующему уроку

**Урок 6.5. Аугментация данных.** Будем:
- Учиться **умножать** данные: из одной картинки делать много (повёрнутые, отражённые, обрезанные).
- Понимать, почему это **поднимает** точность и борется с переобучением.
- Применять аугментацию к CIFAR и видеть рост точности.

> CIFAR дал ~70%. Первый способ поднять — **аугментация**: показать сети картинки в разных вариантах (кот вверх ногами, отражённый, обрезанный). Тогда сеть выучит «котность» устойчивее и не переобучится. Из 50 000 картинок получим как будто миллионы! Простой приём, заметный прирост. 🔄📈

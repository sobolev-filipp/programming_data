## Шпаргалка (из практики)

```python
from ultralytics import YOLO
model = YOLO("yolov8n.pt")               # готовый детектор, 80 классов COCO

results = model("фото.jpg", conf=0.5)    # conf — порог уверенности
r = results[0]

len(r.boxes)                             # сколько объектов
for box in r.boxes:
    cls  = r.names[int(box.cls)]         # класс
    conf = float(box.conf)               # уверенность 0..1
    xyxy = box.xyxy[0]                   # рамка (x1,y1,x2,y2)

r.plot()                                 # картинка с рамками (BGR → ::-1 для RGB)
```

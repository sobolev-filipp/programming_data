# Урок 6.7. Детекция объектов (YOLO) — резюме

---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Детекция объектов** | Найти все объекты и сказать «что **и где**» |
| **Рамка (bounding box)** | Прямоугольник вокруг объекта `(x1,y1,x2,y2)` |
| **YOLO** | «You Only Look Once» — детектор за один проход |
| **Уверенность (confidence)** | Насколько сеть уверена (0..1) |
| **Порог уверенности** | Отсекает слабые находки (`conf=`) |
| **NMS** | Убирает дубли-рамки одного объекта |
| **IoU** | Насколько рамка совпала с правильной |
| **COCO** | Датасет: 80 классов, на нём обучают YOLO |

---

## Главные мысли

1. **Классификация** = «что на фото» (1 ответ). **Детекция** = «что **и где**» (рамки + классы).
2. Детектор для **каждого** объекта выдаёт: **класс + уверенность + рамку**.
3. **YOLO** находит все объекты за **один** проход → быстро → реальное время (видео, авто, камеры).
4. «Наивный» способ (скользящее окно, тысячи прогонов) — слишком медленно.
5. ⚠️ Готовый YOLO знает только **80 классов** COCO. Нужен свой объект → дообучить (transfer learning).
6. **Порог уверенности** регулирует строгость: выше → меньше ошибок, но можно пропустить.

---

## Детекция в коде

```python
from ultralytics import YOLO

model = YOLO("yolov8n.pt")               # готовый детектор (скачается ~6 МБ)

results = model("фото.jpg", conf=0.5)    # conf — порог уверенности
r = results[0]

print(len(r.boxes))                      # сколько объектов
for box in r.boxes:
    cls  = r.names[int(box.cls)]         # класс
    conf = float(box.conf)               # уверенность
    xyxy = box.xyxy[0]                   # рамка (x1,y1,x2,y2)

# показать с рамками (r.plot() даёт BGR → ::-1 для RGB):
import matplotlib.pyplot as plt
plt.imshow(r.plot()[:, :, ::-1]); plt.axis('off'); plt.show()
```

## Что выдаёт детектор (на примере)

```
bus        0.87  [23, 231, 805, 757]
person     0.87  [49, 399, 245, 903]
person     0.85  [669, 392, 810, 877]
person     0.83  [222, 406, 345, 858]
```

| Часть | Смысл |
|-------|-------|
| `person` | класс объекта |
| `0.87` | уверенность (0..1) |
| `[49,399,245,903]` | рамка: углы `(x1,y1,x2,y2)` |

> Ширина рамки = `x2−x1`, высота = `y2−y1`.

## Три уровня задач CV

| Задача | Вопрос | Ответ |
|--------|--------|-------|
| Классификация | что? | один класс |
| **Детекция** | что и **где**? | рамки + классы |
| Сегментация | какие пиксели? | контуры/маски |

---

## Главные ошибки

| Ошибка | Как правильно |
|--------|---------------|
| Путают классификацию и детекцию | 1 ответ vs много + координаты |
| Ждут, что найдёт что угодно | только 80 классов COCO |
| Забыли про порог | `conf=` отсекает слабые |
| Показ без BGR→RGB | `r.plot()[:, :, ::-1]` |

---

## Что должно остаться в голове после урока

1. **Детекция** = «что **и где**», а не просто «что».
2. Каждый объект: **класс + уверенность + рамка**.
3. **YOLO** = один проход → все объекты → быстро.
4. Брали **готовый** детектор (не учили с нуля) — снова сила готовых сетей.
5. Детекция работает в авто, камерах, на видео — вокруг нас.

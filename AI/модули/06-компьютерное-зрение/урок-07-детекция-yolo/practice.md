## Задание 1. Запускаем готовый YOLO (14 минут)

### Что мы хотим сделать

Загрузить готовый детектор и запустить его на фото — увидеть объекты, обведённые рамками с подписями.

### Что мы сделаем (шаги словами)

1. Загрузим готовую модель `yolov8n` (обучена на COCO, 80 классов).
2. Запустим её на тестовом фото.
3. Покажем картинку с нарисованными рамками.

### 1.1. Загружаем готовую модель

```python
# "yolov8n.pt" — nano-версия YOLO v8: лёгкая и быстрая. Веса скачаются сами (~6 МБ).
model = YOLO("yolov8n.pt")

print("Модель знает классов:", len(model.names))
print("Примеры классов:", list(model.names.values())[:10])
```

**Что произошло:** мы скачали **готовый** детектор, обученный на COCO. Он уже умеет находить 80 типов объектов.

**Что увидим:**
```
Модель знает классов: 80
Примеры классов: ['person', 'bicycle', 'car', 'motorcycle', 'airplane', 'bus', 'train', 'truck', 'boat', 'traffic light']
```

> **Что это значит:** модель «из коробки» распознаёт **80** классов повседневных объектов — людей, машины, животных, мебель и т.д. Нам не нужно ничего обучать: эти знания уже внутри (как готовые признаки ResNet в прошлом уроке).

### 1.2. Запускаем детекцию на фото

```python
# YOLO сам скачает это тестовое фото (автобус и люди на остановке)
results = model("https://ultralytics.com/images/bus.jpg")

r = results[0]                    # результат для нашей одной картинки
print("Найдено объектов:", len(r.boxes))
```

**Что произошло:** YOLO **за один проход** проанализировал фото и нашёл все объекты.

**Что увидим:**
```
Найдено объектов: 6
```

> **Что это значит:** на фото детектор нашёл **6** объектов. Сейчас посмотрим, какие именно и где.

### 1.3. Показываем картинку с рамками

```python
# r.plot() возвращает картинку с нарисованными рамками и подписями (формат BGR)
annotated = r.plot()

plt.figure(figsize=(8, 8))
plt.imshow(annotated[:, :, ::-1])   # ::-1 — переводим BGR → RGB для matplotlib
plt.axis('off')
plt.title("Детекция YOLO")
plt.show()
```

**Что увидим:** фото автобуса и людей, где **каждый** объект обведён рамкой с подписью (класс + уверенность): `bus 0.87`, `person 0.87` и т.д.

> 🎉 **Вот она, детекция!** Не «на фото автобус» (один ответ), а **все** объекты сразу, каждый со своей рамкой и подписью. И всё — одной командой на готовой модели.

### Итог Задания 1

1. Загрузили **готовый** YOLO (80 классов COCO).
2. Запустили на фото — нашёл 6 объектов за один проход.
3. Увидели рамки с классами и уверенностью.

## Задание 2. Читаем результат и пробуем свои фото (18 минут)

### Что мы хотим сделать

Разобрать результат «по косточкам»: для каждого объекта вытащить **класс**, **уверенность** и **координаты рамки**. Посчитать объекты по классам. Затем — запустить на **своём** фото.

### 2.1. Что внутри результата

```python
# Пройдёмся по каждому найденному объекту
for box in r.boxes:
    cls  = r.names[int(box.cls)]            # класс (строкой)
    conf = float(box.conf)                  # уверенность 0..1
    xyxy = [round(float(v)) for v in box.xyxy[0]]   # рамка (x1,y1,x2,y2)
    print(f"{cls:12s} уверенность {conf:.2f}  рамка {xyxy}")
```

**Что увидим (примерно):**
```
bus          уверенность 0.87  рамка [23, 231, 805, 757]
person       уверенность 0.87  рамка [49, 399, 245, 903]
person       уверенность 0.85  рамка [669, 392, 810, 877]
person       уверенность 0.83  рамка [222, 406, 345, 858]
person       уверенность 0.26  рамка [0, 551, 63, 873]
stop sign    уверенность 0.26  рамка [0, 254, 33, 325]
```

#### Что это значит

> Для **каждого** объекта детектор выдал три вещи (ровно как в теории):
> - **класс** — что это (`bus`, `person`, `stop sign`);
> - **уверенность** — насколько уверен (0.87 — уверенно; 0.26 — сомнительно);
> - **рамка** `(x1, y1, x2, y2)` — где объект (левый верхний и правый нижний углы в пикселях).
>
> Обрати внимание: автобус и три человека найдены **уверенно** (0.83–0.87), а вот один «person» и «stop sign» с уверенностью **0.26** — это сомнительные находки (на краю кадра, частично видны). По **порогу уверенности** их можно отсечь.

### 2.2. Считаем объекты по классам

```python
from collections import Counter

names = [r.names[int(c)] for c in r.boxes.cls]
print(Counter(names))                      # сколько каждого класса
```

**Что увидим:**
```
Counter({'person': 4, 'bus': 1, 'stop sign': 1})
```

> **Что это значит:** на фото — 4 человека, 1 автобус, 1 знак. **Детекция позволяет считать объекты** — это используют, например, для подсчёта людей в очереди или машин на парковке.

### 2.3. Фильтруем по порогу уверенности

```python
# Запускаем с порогом 0.5 — отбросим слабые находки (< 0.5)
results = model("https://ultralytics.com/images/bus.jpg", conf=0.5)
r = results[0]
print("С порогом 0.5 осталось объектов:", len(r.boxes))
```

**Что увидим:**
```
С порогом 0.5 осталось объектов: 4
```

> **Что это значит:** с порогом 0.5 «сомнительные» (0.26) отсеялись — остались только уверенные: автобус и 3 человека. **Порог уверенности** регулирует строгость: выше порог → меньше ошибок, но можно пропустить реальный объект.

### 2.4. Пробуем на своём фото

```python
# Вариант А: фото по ссылке из интернета
results = model("ВСТАВЬ_ССЫЛКУ_НА_ФОТО.jpg")

# затем указать имя файла:

r = results[0]

```

> **Попробуй разные фото:** улица, твоя комната, фото с животными. Посмотри, что YOLO находит, а что путает или пропускает. Помни: он знает только **80 классов** COCO — если объекта нет в списке, детектор его не найдёт.

### Итог Задания 2

1. Результат детекции = список объектов, у каждого: **класс + уверенность + рамка**.
2. По классам можно **считать** объекты (`Counter`).
3. **Порог уверенности** (`conf=`) отсекает слабые находки.
4. YOLO находит только свои **80 классов**; на своих фото видно, что он умеет, а что нет.

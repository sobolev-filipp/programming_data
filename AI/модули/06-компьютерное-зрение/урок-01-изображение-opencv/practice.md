Загрузить изображение и **посмотреть на него как на массив чисел**.

### 1.1. Берём встроенную картинку

```python
img = data.chelsea()        # встроенное фото кота (из skimage) — всегда доступно

plt.imshow(img)
```

**Что увидим:** цветное фото кота. `data.chelsea()` — встроенный образец, работает без интернета.

### 1.2. Картинка — это массив!

```python
print("Тип:", type(img))            # numpy.ndarray — обычный массив!
print("Форма:", img.shape)          # (300, 451, 3) — высота, ширина, 3 канала
print("Тип чисел:", img.dtype)      # uint8 — числа 0..255
print("Мин/макс яркость:", img.min(), img.max())   # 0 ... 255
```

#### Что это значит

- **`type` = numpy.ndarray** — картинка это **обычный массив NumPy** (Урок 1.4)!
- **`shape` = (300, 451, 3)** — высота 300, ширина 451, **3 канала** (цветная).
- **`uint8`** — числа от 0 до 255 (яркости).

> **Вот оно, главное:** красивое фото кота — это массив `(300, 451, 3)` чисел. Никакой магии.

### 1.3. Заглянем в пиксели

```python
print("Пиксель в углу [0, 0]:", img[0, 0])     # [R, G, B], например [144 124 100]
print("Красный канал этого пикселя:", img[0, 0, 0])
print("\nКусочек картинки (5×5 пикселей, красный канал):")
print(img[0:5, 0:5, 0])             # таблица яркостей красного
```

**Что увидим:** `img[0,0]` — три числа (R, G, B) одного пикселя. А `img[0:5, 0:5, 0]` — таблица 5×5 яркостей красного канала. **Это и есть картинка изнутри** — числа.

## Задание 2. Каналы RGB и чёрно-белое (12 минут)

### Что мы хотим сделать

Разобрать картинку на **3 цветных канала** и сделать её **серой**.

### 2.1. Разделяем на каналы R, G, B

```python
red   = img[:, :, 0]        # красный канал (двумерный массив)
green = img[:, :, 1]        # зелёный
blue  = img[:, :, 2]        # синий

print("Форма одного канала:", red.shape)     # (300, 451) — БЕЗ тройки (один канал)

fig, axes = plt.subplots(1, 4, figsize=(16, 4))
axes[0].imshow(img);                  axes[0].set_title("Оригинал")
axes[1].imshow(red, cmap='Reds');     axes[1].set_title("Красный канал")
axes[2].imshow(green, cmap='Greens'); axes[2].set_title("Зелёный канал")
axes[3].imshow(blue, cmap='Blues');   axes[3].set_title("Синий канал")
for ax in axes: ax.axis('off')
plt.show()
```

#### Что мы делаем

- `img[:, :, 0]` — берём **только красный** канал (срез массива). Форма становится `(300, 451)` — без тройки (это уже как серая картинка).
- Рисуем каждый канал отдельно.

**Что увидим:** 4 картинки — оригинал и 3 канала. Где много красного (нос, язык кота) — красный канал **ярче**. Каждый канал — это «карта яркости» одного цвета.

> **Цветная картинка = три серых картинки (каналы), сложенные вместе.** Это ровно то, что было на иллюстрации в теории.

### 2.2. Делаем чёрно-белым

```python
gray = cv2.cvtColor(img, cv2.COLOR_RGB2GRAY)     # цветное → серое (OpenCV)

print("Форма серой картинки:", gray.shape)        # (300, 451) — ОДИН канал!

plt.imshow(gray, cmap='gray')
plt.title("Чёрно-белая")
plt.axis('off')
plt.show()
```

#### Что произошло

- `cv2.cvtColor(..., COLOR_RGB2GRAY)` — превратил цветную картинку в серую, **усреднив** каналы (с учётом, что глаз по-разному воспринимает цвета).
- Форма стала `(300, 451)` — **один канал** вместо трёх. Картинка «похудела» втрое!

> **`cmap='gray'`** обязательно при показе серой картинки, иначе matplotlib раскрасит её ложными цветами.

### Итог Задания 2

1. Цветная картинка = 3 канала (R, G, B), каждый — серая картинка яркости.
2. Один канал имеет форму `(H, W)` — без тройки.
3. Серое = усреднить каналы → форма `(H, W)`, в 3 раза меньше данных.

## Задание 3. Обрабатываем изображение (8 минут)

### Что мы хотим сделать

Покрутить картинку: размер, яркость, размытие.

### 3.1. Изменить размер и обрезать

```python
small = cv2.resize(img, (100, 100))      # сжать до 100×100
crop = img[50:200, 100:300]               # обрезать кусок (срез массива!)

fig, axes = plt.subplots(1, 3, figsize=(14, 4))
axes[0].imshow(img);   axes[0].set_title(f"Оригинал {img.shape[:2]}")
axes[1].imshow(small); axes[1].set_title("Сжатая 100×100")
axes[2].imshow(crop);  axes[2].set_title("Обрезанная")
for ax in axes: ax.axis('off')
plt.show()
```

> **Обрезка — это просто срез массива** `img[y1:y2, x1:x2]` (Урок 1.4)! Берём строки 50–200, столбцы 100–300. Вот зачем мы учили срезы.

### 3.2. Осветлить картинку

```python
brighter = cv2.add(img, 60)              # прибавить 60 к каждому пикселю

fig, axes = plt.subplots(1, 2, figsize=(10, 4))
axes[0].imshow(img);      axes[0].set_title("Оригинал")
axes[1].imshow(brighter); axes[1].set_title("Светлее (+60)")
for ax in axes: ax.axis('off')
plt.show()
```

> **Осветление = прибавить число ко всем пикселям.** Больше яркость каждого = светлее картинка. (`cv2.add` аккуратно держит значения в пределах 0–255, не «переполняясь».)

### 3.3. Размыть (тизер свёртки!)

```python
blurred = cv2.GaussianBlur(img, (15, 15), 0)    # размытие

fig, axes = plt.subplots(1, 2, figsize=(10, 4))
axes[0].imshow(img);     axes[0].set_title("Оригинал")
axes[1].imshow(blurred); axes[1].set_title("Размытая")
for ax in axes: ax.axis('off')
plt.show()
```

#### Что такое размытие

**Размытие** заменяет каждый пиксель на **среднее** его и соседей. Резкие переходы сглаживаются → картинка «мутнеет».

> **Это работает через ФИЛЬТР (свёртку)** — маленькое «окошко», которое бежит по картинке и усредняет пиксели. **Свёртка — основа компьютерного зрения!** Сейчас фильтр «размытие» задан вручную, а на Уроке 6.2 мы поймём, как сеть **сама учит** такие фильтры, чтобы находить глаза, уши, контуры. Запомни слово «свёртка» — оно главное в Модуле 6.

### Итог Задания 3

1. Resize и crop — операции над массивом (срезы!).
2. Яркость — прибавить число к пикселям.
3. **Размытие — это фильтр (свёртка)**, тизер главной темы Модуля 6.

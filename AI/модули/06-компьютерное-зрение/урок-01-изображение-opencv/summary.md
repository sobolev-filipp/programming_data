# Урок 6.1. Изображение для компьютера — резюме

---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Пиксель** | Точка картинки; серая — 1 число, цветная — 3 (R,G,B) |
| **Канал** | «Слой» цвета: серое — 1, цветное — 3 (R,G,B) |
| **RGB** | Цвет = смесь Red, Green, Blue (0–255) |
| **Разрешение** | Размер в пикселях (высота × ширина) |
| **OpenCV (cv2)** | Главная библиотека компьютерного зрения |
| **BGR** | Порядок каналов в OpenCV (не RGB!) |

---

## Главные мысли

1. **Изображение = массив чисел** 0–255 (яркости пикселей).
2. **Серая:** форма `(H, W)`, 1 канал. **Цветная:** `(H, W, 3)`, 3 канала.
3. **RGB:** любой цвет = смесь красного, зелёного, синего.
4. Картинка — это **массив NumPy** → любая обработка = операции с массивом.
5. **OpenCV читает в BGR** → перед показом перевести в RGB (`cvtColor`).
6. Размытие и края работают через **фильтры (свёртку)** — основа Модуля 6.

---

## Формы и операции

```python
img.shape              # (H, W, 3) цветная, (H, W) серая
img[y, x]              # пиксель [R, G, B]
img[:, :, 0]           # красный канал
img[y1:y2, x1:x2]      # обрезка (срез)

cv2.cvtColor(img, cv2.COLOR_RGB2GRAY)   # серое
cv2.cvtColor(img, cv2.COLOR_BGR2RGB)    # починить BGR
cv2.resize(img, (w, h))                  # размер
cv2.GaussianBlur(img, (15,15), 0)        # размытие (свёртка!)
```

---

## Цвета в RGB

| Цвет | (R, G, B) |
|------|-----------|
| Красный | (255, 0, 0) |
| Зелёный | (0, 255, 0) |
| Синий | (0, 0, 255) |
| Жёлтый | (255, 255, 0) |
| Белый | (255, 255, 255) |
| Чёрный | (0, 0, 0) |

---

## Главные ошибки

| Ошибка | Как правильно |
|--------|---------------|
| Ловушка BGR (синий кот) | `cvtColor(.., BGR2RGB)` |
| Забыли `cmap='gray'` | при показе серой картинки |
| Переполнение uint8 | `cv2.add` / `np.clip` |
| Меняют без `.copy()` | копировать перед изменением |
| Путают (H,W) порядок | высота, потом ширина |

---

## Что должно остаться в голове после урока

1. **Картинка = массив чисел** (H, W, каналы).
2. Серое — 1 канал, цветное — 3 канала (RGB).
3. Обработка картинки = операции над массивом (NumPy).
4. **OpenCV читает в BGR** — частая ловушка.
5. Размытие/края = **фильтры (свёртка)** — главная тема дальше.

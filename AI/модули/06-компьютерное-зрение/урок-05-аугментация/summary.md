# Урок 6.5. Аугментация данных — резюме

---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Аугментация** | Создание вариантов картинок (отражение, поворот...) |
| **Переобучение** | Сеть зубрит train, плохо на test |
| **Инвариантность** | Узнавать объект несмотря на изменения |
| **`transforms.Compose`** | Цепочка преобразований (как Pipeline) |
| **`RandomHorizontalFlip`** | Случайное отражение |
| **`RandomCrop`** | Случайная обрезка |

---

## Главные мысли

1. **Аугментация** = варианты картинок из имеющихся (бесплатные «новые данные»).
2. Помогает: больше данных → меньше **переобучения** + учит **инвариантности**.
3. ⚠️ **Главное правило: аугментация только на TRAIN, не на тест!**
4. Аугментация должна **сохранять класс** (кот зеркальный — кот, но 6↔9 — нельзя!).
5. Виды: flip, crop, rotation, color jitter, шум, cutout.
6. Эффект — рост точности и меньший разрыв train-test.

---

## Аугментация в коде

```python
# TRAIN — с аугментацией
train_transform = transforms.Compose([
    transforms.RandomHorizontalFlip(),       # отражение
    transforms.RandomCrop(32, padding=4),    # обрезка
    transforms.ToTensor()                    # всегда последним!
])
# TEST — БЕЗ аугментации!
test_transform = transforms.Compose([transforms.ToTensor()])

train_data = datasets.CIFAR10(..., transform=train_transform)
test_data = datasets.CIFAR10(..., transform=test_transform)
```

---

## Выбор аугментаций

| Объект | Можно | Нельзя |
|--------|-------|--------|
| Животные, машины | отражение, поворот, обрезка | сильные искажения |
| **Цифры, буквы** | малый поворот, сдвиг | переворот, отражение (6↔9!) |

> Правило: применять то, что **сохраняет класс**.

---

## Главные ошибки

| Ошибка | Как правильно |
|--------|---------------|
| Аугментация на тесте | только train! |
| `ToTensor` не последним | в конце Compose |
| Переворот цифр | портит класс (6→9) |
| Ждут эффект за 1 эпоху | нужно 15-30 эпох |

---

## Что должно остаться в голове после урока

1. **Аугментация** умножает данные (варианты картинок).
2. Борется с **переобучением**, учит инвариантности.
3. **Только на train** — тест честный.
4. Аугментация **сохраняет класс**.
5. Простой приём → заметный прирост точности.

## К следующему уроку

**Урок 6.6. Transfer learning (готовые сети).** Будем:
- Брать **готовую** сеть (ResNet/MobileNet), обученную на **миллионах** картинок.
- **Дообучать** её под свою задачу (transfer learning).
- Получать **90%+** там, где наша CNN давала 70%.

> Аугментация подняла CIFAR с 70% до ~75%. Но есть приём **намного** мощнее. Зачем учить сеть с нуля, если кто-то уже обучил гигантскую сеть на миллионах фото? Можно **взять её готовой** и чуть дообучить под себя — это **transfer learning**, и он даёт скачок до 90%+. Это секрет, как профессионалы решают CV-задачи. Самый практичный урок модуля! 🚀

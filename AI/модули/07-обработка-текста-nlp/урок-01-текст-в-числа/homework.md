## Шпаргалка (из практики)

```python
from sklearn.feature_extraction.text import CountVectorizer, TfidfVectorizer
import pandas as pd

cv = CountVectorizer()
X = cv.fit_transform(corpus)        # мешок слов
cv.get_feature_names_out()          # словарь
X.toarray()                         # матрица чисел

tf = TfidfVectorizer()
Xt = tf.fit_transform(corpus)       # TF-IDF
tf.idf_                             # веса редкости (IDF) слов
```

# Урок 7.1. Текст в числа — резюме

---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **NLP** | Обработка естественного языка (текста и речи) |
| **Токен / токенизация** | Слово / разрезание текста на слова |
| **Корпус / документ** | Набор текстов / один текст |
| **Словарь (vocabulary)** | Все уникальные слова с номерами |
| **Мешок слов (BoW)** | Вектор: сколько раз каждое слово в документе |
| **TF-IDF** | Вес слова: частые-везде ↓, редкие-отличительные ↑ |
| **TF / IDF** | Частота в документе / редкость по корпусу |

---

## Главные мысли

1. Модель понимает только **числа** → текст надо превратить в числа.
2. **Токенизация** → **словарь** → **вектор** (мешок слов).
3. **Мешок слов** = счётчики слов. Минус: **теряется порядок**.
4. **TF-IDF** = умные веса: общие слова вниз, отличительные вверх.
5. TF-IDF сам находит **важные** слова (пример: «фильм» в каждом отзыве → вес 1.00, бесполезно).
6. Всё это — **две строки** в sklearn (`CountVectorizer`, `TfidfVectorizer`).

---

## Текст в числа — в коде

```python
from sklearn.feature_extraction.text import CountVectorizer, TfidfVectorizer

# Мешок слов (счётчики)
cv = CountVectorizer()
X = cv.fit_transform(corpus)
cv.get_feature_names_out()      # словарь
X.toarray()                     # матрица: строка=документ, столбец=слово

# TF-IDF (веса)
tf = TfidfVectorizer()
Xt = tf.fit_transform(corpus)
tf.idf_                         # веса редкости слов
```

---

## Как читать матрицу мешка слов

```
Словарь: ['воду','кот','молоко','мышку','поймал','пьёт','собака']
"кот пьёт молоко" → [0, 1, 1, 0, 0, 1, 0]
                       ↑кот=1 ↑молоко=1 ↑пьёт=1
```

> Строка = документ, столбец = слово, число = сколько раз слово встретилось.

---

## BoW vs TF-IDF

| | Мешок слов | TF-IDF |
|--|-----------|--------|
| Что в ячейке | счётчик (сколько раз) | вес (важность) |
| Частые-везде слова | большой счёт | **низкий вес** |
| Редкие отличительные | малый счёт | **высокий вес** |
| Для моделей | базово | обычно лучше |

---

## Главные ошибки

| Ошибка | Как правильно |
|--------|---------------|
| Ждут 1-буквенные слова в словаре | по умолчанию выбрасываются |
| Путают строки/столбцы | строка=документ, столбец=слово |
| Думают, BoW знает порядок | нет, порядок теряется |
| «Больше счёт = важнее» | нет, для важности — TF-IDF |

---

## Что должно остаться в голове после урока

1. Текст превращают в **числа** (вектор по словарю).
2. **Мешок слов** = счётчики слов, порядок теряется.
3. **TF-IDF** взвешивает: частые-везде ↓, редкие-отличительные ↑.
4. TF-IDF сам находит важные слова.
5. В sklearn — `CountVectorizer` и `TfidfVectorizer`, как `fit_transform` в Модуле 3.

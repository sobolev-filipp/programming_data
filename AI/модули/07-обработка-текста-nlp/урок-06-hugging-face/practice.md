## Задание 1. Тональность и классификация без обучения (16 минут)

### Что мы хотим сделать

Запустить готовый анализатор тональности и классификатор, который сортирует текст в **любые** наши категории.

### 1.1. Анализ тональности (sentiment-analysis)

```python
classifier = pipeline("sentiment-analysis")     # одна строка — готовый анализатор!

for text in ["I love this course, it's amazing!",
             "This movie was a waste of time.",
             "The food was not bad at all."]:
    r = classifier(text)[0]
    print(f"{r['label']:8s} {r['score']:.2f}  <-  {text}")
```

> ### ⏳ Пока качается модель (~270 МБ) — не сидим без дела
> - **🔮 Предскажи:** какие метки даст модель трём фразам? Особенно третьей — «not bad at all» (с отрицанием)!
> - **💬 Обсуди:** мешок слов из 7.2 увидел бы в «not bad» слово «bad». Сможет ли трансформер понять, что это **позитив**?

**Что увидим:**
```
POSITIVE 1.00  <-  I love this course, it's amazing!
NEGATIVE 1.00  <-  This movie was a waste of time.
POSITIVE 1.00  <-  The food was not bad at all.
```

#### Что это значит

> 🎯 **Одна строка — и готовый анализатор тональности уровня индустрии!** Обрати внимание на третью фразу: **«not bad at all» → POSITIVE**. Трансформер понял **отрицание** — «не плохо» это хорошо! Мешок слов из 7.2 увидел бы «bad» и ошибся. Вот сила контекста (attention из 7.5), спрятанная за одной строкой.

### 1.2. Классификация без обучения (zero-shot)

```python
# Сортируем текст в ЛЮБЫЕ категории, которым модель НЕ училась!
zero_shot = pipeline("zero-shot-classification")

text = "I want to book a flight to Paris next week"
labels = ["travel", "food", "sport", "music"]      # наши категории — какие хотим!
r = zero_shot(text, candidate_labels=labels)

for label, score in zip(r['labels'], r['scores']):
    print(f"{label:8s} {score:.2f}")
```

**Что увидим:**
```
travel   0.98
sport    0.01
music    0.01
food     0.01
```

#### Что это значит

> 🪄 **Вот это магия!** Модель отнесла фразу про билет в Париж к **travel (0.98)** — хотя её **никто не учил** этим категориям! Мы просто **назвали** классы словами, и она поняла смысл. Поменяй `labels` на `["срочно", "не срочно"]` или `["вопрос", "жалоба"]` — и она отсортирует по-новому, без всякого обучения.
>
> Вспомни 7.2: чтобы классифицировать спам, мы **обучали** модель целый урок. А zero-shot делает классификацию **без обучения вообще** — за счёт понимания смысла слов (эмбеддинги + attention).

### Итог Задания 1

1. `sentiment-analysis` — тональность одной строкой (и понимает отрицание!).
2. `zero-shot-classification` — сортирует в **любые** твои категории **без обучения**.
3. Внутри — трансформеры (7.5), но всё спрятано за `pipeline`.

## Задание 2. Вопросы-ответы, перевод, генерация (18 минут)

### Что мы хотим сделать

Попробовать ещё три задачи: найти ответ в тексте, перевести и сгенерировать текст.

### 2.1. Ответы на вопросы (question-answering)

```python
qa = pipeline("question-answering")

context = "The Eiffel Tower is located in Paris and was built in 1889. It is 330 meters tall."

for question in ["Where is the Eiffel Tower?", "When was it built?", "How tall is it?"]:
    r = qa(question=question, context=context)
    print(f"{question}  ->  {r['answer']} ({r['score']:.2f})")
```

**Что увидим:**
```
Where is the Eiffel Tower?  ->  Paris (0.98)
When was it built?  ->  1889 (0.98)
How tall is it?  ->  330 meters (0.56)
```

> **Модель читает текст и находит ответ!** Мы дали ей **контекст** (факты про башню) и **вопросы** — она нашла точные ответы прямо в тексте (Paris, 1889, 330 meters). Так работают «умные» поисковики и помощники по документам. Заметь: модель не «знает» это заранее — она **находит** ответ в данном тексте.

### 2.2. Перевод (translation)

```python
# Модель Helsinki-NLP переводит с английского на русский
translator = pipeline("translation", model="Helsinki-NLP/opus-mt-en-ru")

for text in ["Hello, how are you?", "Machine learning is fun.", "The cat drinks milk."]:
    print(f"{text}  ->  {translator(text)[0]['translation_text']}")
```

**Что увидим:**
```
Hello, how are you?  ->  Привет, как дела?
Machine learning is fun.  ->  Машинное обучение - это весело.
The cat drinks milk.  ->  Кошка пьет молоко.
```

> 🌍 **Готовый переводчик одной строкой!** Модель `Helsinki-NLP/opus-mt-en-ru` обучена переводить с английского на русский — мы просто её взяли. Здесь мы указали **конкретную модель** (`model="..."`) — так можно выбрать любую из тысяч на Hugging Face Hub. *(Для перевода нужна библиотека `sentencepiece` — мы поставили её в начале.)*

### 2.3. Генерация текста (text-generation)

```python
# GPT-2 — «младший брат» ChatGPT — продолжает текст
generator = pipeline("text-generation", model="gpt2")

result = generator("Once upon a time, a robot learned to",
                   max_new_tokens=15, num_return_sequences=1)
print(result[0]['generated_text'])
```

**Что увидим (пример — каждый раз РАЗНЫЙ!):**
```
Once upon a time, a robot learned to play chess, and the robot
had no choice but to learn how to play
```

> **Модель продолжает текст**, предсказывая слово за словом (как мы обсуждали — GPT предсказывает следующее слово). GPT-2 — маленький предок ChatGPT. Результат **каждый раз разный** (есть случайность) и может быть смешным или странным — модель маленькая. Но принцип тот же, что у больших языковых моделей.

### Итог Задания 2

1. `question-answering` — находит ответ в тексте.
2. `translation` — переводит (можно указать конкретную модель).
3. `text-generation` — продолжает текст (как ChatGPT, только меньше).
4. Все — одной строкой, на готовых моделях.

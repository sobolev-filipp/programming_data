## Шпаргалка (из практики)

```python
from transformers import pipeline

pipeline("sentiment-analysis")("I love it")              # тональность
pipeline("zero-shot-classification")(текст, candidate_labels=["...","..."])  # свои классы
pipeline("question-answering")(question=..., context=...)# ответ по тексту
pipeline("translation", model="Helsinki-NLP/opus-mt-en-ru")("Hello")  # перевод EN→RU
pipeline("text-generation", model="gpt2")("Once upon a time")          # генерация
pipeline("summarization")(длинный_текст)                 # краткое содержание
```

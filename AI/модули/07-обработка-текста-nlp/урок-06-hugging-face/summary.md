# Урок 7.6. Готовые модели Hugging Face — резюме (и финал Модуля 7)

---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Hugging Face** | Платформа тысяч готовых моделей ИИ (бесплатно) |
| **`pipeline`** | Решает NLP-задачу одной строкой |
| **Предобученная модель** | Уже обучена кем-то; берём готовой |
| **Zero-shot** | Классификация в любые категории без обучения |
| **Галлюцинация** | Когда модель «выдумывает» неверное |

---

## Главные мысли

1. Большинство NLP-задач **уже решены** — бери готовую модель.
2. **Hugging Face** — «GitHub для моделей»; `pipeline` решает задачу **одной строкой**.
3. Внутри `pipeline`: скачать модель + токенизация + трансформер + результат.
4. Это **transfer learning** для текста (как готовые сети в 6.6).
5. **Zero-shot** сортирует в любые категории **без обучения** (по смыслу).
6. Готовое — для типовых задач; своё — для узкой специфики с данными.
7. ⚠️ Модели **ошибаются и предвзяты** — не доверяй слепо.

---

## Решаем задачи одной строкой

```python
from transformers import pipeline

pipeline("sentiment-analysis")("I love it")          # POSITIVE 1.00
pipeline("zero-shot-classification")(text, candidate_labels=["travel","food"])
pipeline("question-answering")(question=q, context=ctx)   # ответ из текста
pipeline("translation", model="Helsinki-NLP/opus-mt-en-ru")("Hello")  # → Привет
pipeline("text-generation", model="gpt2")("Once upon a time")
```

---

## Что увидели (проверено)

| Задача | Пример | Результат |
|--------|--------|-----------|
| Тональность | «not bad at all» | **POSITIVE** (понял отрицание!) |
| Zero-shot | билет в Париж | **travel 0.98** (без обучения) |
| Вопрос-ответ | «Where is Eiffel Tower?» | **Paris (0.98)** |
| Перевод | «The cat drinks milk» | **«Кошка пьёт молоко»** |
| Генерация | «Once upon a time...» | продолжает текст |

---

## Готовое или своё?

| Бери готовое | Обучай своё |
|--------------|-------------|
| типовая задача | узкая специфика |
| нет данных | есть свои данные |
| нужно быстро | нужна точность на своём |

> Можно и совместить: взять готовую и **дообучить** (transfer learning).

# Урок 7.2. Классификация текстов (спам) — резюме

---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **ham** | «не спам», нормальное сообщение |
| **Бинарная классификация** | два класса (спам / не спам) |
| **fit_transform / transform** | учим словарь на train / только преобразуем test |
| **Несбалансированные классы** | одного класса сильно больше (здесь 87% ham) |
| **Precision** | из помеченных спамом — сколько реально спам |
| **Recall** | из всего спама — сколько поймали |

---

## Главные мысли

1. Спам-фильтр = **классификация текста**: текст → TF-IDF → классификатор → метрики.
2. ⚠️ Словарь учим **только на train** (`fit_transform`); тест и новые тексты — **только `transform`**.
3. На несбалансированных данных **accuracy обманчива**: «всё ham» даёт 87% при нулевой пользе.
4. Правду говорят **precision** (не теряем ли письма) и **recall** (ловим ли спам).
5. Для спам-фильтра **precision важнее**: потерять письмо хуже, чем пропустить спам.
6. **Матрица ошибок** показывает всё: 0 ложных тревог + 39 пропусков спама.

---

## Конвейер в коде

```python
from sklearn.model_selection import train_test_split
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score, precision_score, recall_score, confusion_matrix

# 1-2. данные + split
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, stratify=y)

# 3. текст → числа (СЛОВАРЬ НА TRAIN!)
tfidf = TfidfVectorizer()
Xtr = tfidf.fit_transform(X_train)     # учим + преобразуем
Xte = tfidf.transform(X_test)          # только преобразуем

# 4. обучаем (как в 3.4!)
model = LogisticRegression(max_iter=1000).fit(Xtr, y_train)

# 5. оцениваем ПРАВИЛЬНО
pred = model.predict(Xte)
accuracy_score(y_test, pred)           # осторожно: обманчива!
precision_score(y_test, pred)          # не теряем письма?
recall_score(y_test, pred)             # ловим спам?
confusion_matrix(y_test, pred)         # вся правда
```

## Precision vs Recall (для спама)

| | Низкий precision | Низкий recall |
|--|------------------|---------------|
| Что значит | нормальные письма → спам | спам → в почту |
| Насколько плохо | **очень** (потеря письма!) | терпимо (удалишь) |
| Вывод | для спама **precision важнее** | |

## Главные ошибки

| Ошибка | Как правильно |
|--------|---------------|
| `fit_transform` на тесте | на тесте только `transform` |
| Смотреть только на accuracy | + precision, recall, матрица |
| «97% = идеально» | baseline «всё ham» уже 87% |
| Путать precision/recall | precision=ложные тревоги, recall=пропуски |

---

## Что должно остаться в голове после урока

1. Спам-фильтр = текст → TF-IDF → классификатор (как в 3.4).
2. Словарь учим **на train**, тест только `transform`.
3. **Accuracy врёт** на несбалансированных данных.
4. Смотрим **precision** (не теряем письма) и **recall** (ловим спам).
5. **Матрица ошибок** показывает всю правду о фильтре.

## Задание 1. Слова как векторы (16 минут)

### Что мы хотим сделать

Убедиться, что слово — это вектор, и что близость векторов отражает близость смысла.

### 1.1. Слово — это вектор чисел

```python
vec = wv['king']                 # вектор слова "king" (король)
print("Тип:", type(vec), "| длина:", len(vec))
print("Первые 8 чисел из 50:")
print(vec[:8].round(2))
```

**Что увидим:**
```
Тип: <class 'numpy.ndarray'> | длина: 50
Первые 8 чисел из 50:
[ 0.5   0.69 -0.59 -0.02  0.6  -0.14 -0.09  0.47]
```

> **Вот доказательство:** слово «king» — это **50 чисел**. Сами по себе они ничего не значат. Важна **близость** к другим словам — её и проверим.

### 1.2. Близость слов (косинус)

```python
pairs = [("cat", "dog"), ("cat", "car"), ("good", "great"),
         ("king", "queen"), ("king", "man")]
for a, b in pairs:
    print(f"{a:6s} ~ {b:6s}: {wv.similarity(a, b):.2f}")
```

**Что увидим:**
```
cat    ~ dog   : 0.92
cat    ~ car   : 0.36
good   ~ great : 0.80
king   ~ queen : 0.78
king   ~ man   : 0.53
```

#### Что это значит

> 🎯 **Компьютер понимает смысл!**
> - `cat ~ dog = 0.92` — кот и собака **очень похожи** (оба питомцы).
> - `cat ~ car = 0.36` — кот и машина **далеки** (хоть слова и похожи по написанию: cat/car!).
> - `good ~ great = 0.80` — синонимы **близки**. Вот чего не умел мешок слов из 7.2!
>
> Близость векторов = близость **смысла**, а не написания. Эмбеддинги выучили это сами из текстов.

### 1.3. Похожие слова

```python
for word in ["king", "dog"]:
    print(f"\nПохожие на '{word}':")
    for w, score in wv.most_similar(word, topn=5):
        print(f"   {w:10s} {score:.2f}")
```

**Что увидим (примерно):**
```
Похожие на 'king':
   prince     0.82
   queen      0.78
   emperor    0.77
   son        0.77
   ...

Похожие на 'dog':
   cat        0.92
   dogs       0.85
   puppy      0.78
   pet        0.77
   ...
```

> **Модель находит соседей по смыслу:** для «king» — принц, королева, император (всё про власть/титулы); для «dog» — кот, щенок, питомец (всё про животных). Никто не задавал эти связи руками — модель вывела их из текстов по принципу «слово узнаётся по соседям».
>
> ⚠️ Иногда среди соседей попадается «мусор» (редкие токены) — это нормально для готовых эмбеддингов, не все соседи осмысленны.

### Итог Задания 1

1. Слово — это вектор (у нас 50 чисел).
2. Близость векторов = близость **смысла** (cat~dog 0.92, cat~car 0.36).
3. `most_similar` находит слова-соседи по смыслу.

## Задание 2. Магия аналогий (14 минут)

### Что мы хотим сделать

Проделать арифметику смысла — самое удивительное в эмбеддингах.

### 2.1. Король − мужчина + женщина = ?

```python
# positive — что прибавляем, negative — что отнимаем
result = wv.most_similar(positive=["king", "woman"], negative=["man"], topn=3)
for w, score in result:
    print(f"{w}: {score:.2f}")
```

**Что увидим:**
```
queen: 0.85
throne: 0.77
prince: 0.76
```

#### Что это значит

> 🪄 **МАГИЯ!** `король − мужчина + женщина` дал в ответе **queen (королева)** с близостью 0.85! Мы сделали **арифметику смысла**: убрали «мужское», добавили «женское» — и попали из короля в королеву. Эмбеддинги закодировали понятие «пол» как направление, которое можно прибавлять и отнимать. Никто этому модель не учил — она вывела сама.

### 2.2. Ещё аналогии

```python
analogies = [
    (["paris", "italy"], ["france"], "Париж − Франция + Италия"),
    (["bigger", "small"], ["big"],   "bigger − big + small"),
]
for pos, neg, desc in analogies:
    w, score = wv.most_similar(positive=pos, negative=neg, topn=1)[0]
    print(f"{desc} = {w} ({score:.2f})")
```

**Что увидим (примерно):**
```
Париж − Франция + Италия = rome (0.85)
bigger − big + small = larger (0.92)
```

> **Отношения как направления:**
> - «страна → её столица»: убрали Францию из Парижа, добавили Италию → получили **Рим**!
> - сравнительная степень: bigger так относится к big, как larger к large.
>
> Модель уловила **связи между понятиями** (столица, степень сравнения, пол) и хранит их как направления в пространстве. Это и есть «понимание» на уровне векторов.

### 2.3. Найди лишнее слово

```python
groups = [
    ["breakfast", "lunch", "dinner", "cat"],
    ["red", "blue", "green", "dog"],
]
for g in groups:
    print(f"{g} -> лишнее: {wv.doesnt_match(g)}")
```

**Что увидим:**
```
['breakfast', 'lunch', 'dinner', 'cat'] -> лишнее: cat
['red', 'blue', 'green', 'dog'] -> лишнее: dog
```

> **Модель находит «не из этой компании»:** среди приёмов пищи лишний — `cat`; среди цветов — `dog`. Она измеряет, какое слово **дальше всех** от остальных по смыслу. Снова — понимание смысла в действии.

### Итог Задания 2

1. С векторами слов можно делать **арифметику смысла**.
2. `король − мужчина + женщина ≈ королева` (0.85) — реально работает!
3. Модель находит **лишнее слово** по смыслу.

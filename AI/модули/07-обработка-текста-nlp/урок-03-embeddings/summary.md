# Урок 7.3. Embeddings — резюме

---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Эмбеддинг** | Слово как вектор чисел; близость = смысл |
| **word2vec / GloVe** | Способы получить эмбеддинги (мы берём готовые) |
| **Косинусная близость** | Мера похожести векторов (1 — похожи, 0 — нет) |
| **Контекст** | Слова-соседи; по ним учат смысл |
| **Аналогия** | Арифметика смысла: король−мужчина+женщина≈королева |

---

## Главные мысли

1. Мешок слов не знал смысла: «good» и «great» — разные столбцы. Эмбеддинги это чинят.
2. **Эмбеддинг** = слово как вектор; похожие по смыслу слова — **рядом**.
3. **Близость векторов = близость смысла:** cat~dog 0.92, cat~car 0.36, good~great 0.80.
4. Идея **word2vec:** «слово узнаётся по соседям» (контексту).
5. Берём **готовые** векторы (GloVe) — transfer learning для текста.
6. **Магия:** `король − мужчина + женщина ≈ королева` — арифметика смысла работает!
7. Ограничение: один вектор на слово (контекст не учтён) → трансформеры (7.5).

---

## Эмбеддинги в коде

```python
import gensim.downloader as api
wv = api.load("glove-wiki-gigaword-50")    # готовые векторы (~66 МБ)

wv['cat']                                  # вектор слова (50 чисел)
wv.similarity('cat', 'dog')                # 0.92 — близость по смыслу
wv.most_similar('dog', topn=5)             # похожие слова
wv.most_similar(positive=['king','woman'], negative=['man'])   # → queen
wv.doesnt_match(['breakfast','lunch','dinner','cat'])          # → cat
```

---

## Близость = смысл (проверено)

| Пара | Близость | Вывод |
|------|:--------:|-------|
| cat ~ dog | 0.92 | похожи (питомцы) |
| good ~ great | 0.80 | синонимы близки! |
| cat ~ car | 0.36 | далеки (хоть буквы похожи) |

> ⚠️ Близость = «про одну тему», **не** «синоним»: `summer ~ winter` тоже близки (0.92) — противоположности, но один контекст.

## Магия аналогий

```
король − мужчина + женщина ≈ королева   (0.85)
Париж − Франция + Италия   ≈ Рим         (0.85)
Япония → Токио  (как Франция → Париж)
```

> Отношения (пол, столица) закодированы как **направления** в пространстве.

---

## Главные ошибки

| Ошибка | Как правильно |
|--------|---------------|
| «близко = синоним» | близко = одна тема (summer~winter!) |
| русское слово в англ. модели | `KeyError` — нужна англ. слова |
| ждут, что все аналогии сработают | часть ломается — это норма |
| заглавные/опечатки | модель в нижнем регистре |

## Что должно остаться в голове после урока

1. Эмбеддинг = слово как **вектор смысла**.
2. **Близость векторов = близость смысла** (cat~dog 0.92).
3. word2vec: «слово узнаётся по **соседям**».
4. **Арифметика смысла:** король−мужчина+женщина≈королева.
5. Один вектор на слово — ограничение (контекст решают трансформеры).

## К следующему уроку

**Урок 7.4. Рекуррентные сети (RNN, LSTM) — обзорно.** Будем:
- Понимать слабость мешка слов и эмбеддингов: они **не помнят порядок** слов.
- Знакомиться с **RNN** — сетями, которые читают текст **по порядку**, помня предыдущее.
- Понимать идею **«памяти»** в нейросети (LSTM).

> Эмбеддинги дали словам смысл, но и они, и мешок слов смотрят на слова **по отдельности**, не помня **порядок**. А «собака укусила человека» ≠ «человек укусил собаку»! Чтобы читать текст как **последовательность** и помнить, что было раньше, придумали **рекуррентные сети**. О них — дальше. 🚀

## Шпаргалка (из практики)

```python
import gensim.downloader as api
wv = api.load("glove-wiki-gigaword-50")

wv['cat']                     # вектор слова (50 чисел)
wv.similarity('cat', 'dog')   # близость двух слов (0..1)
wv.most_similar('cat', topn=5)               # похожие слова
wv.most_similar(positive=['king','woman'], negative=['man'])  # аналогия
wv.doesnt_match(['a','b','c','d'])           # лишнее слово
```

> **Ты увидел, как компьютер понимает смысл слов!** Эмбеддинги — фундамент всего современного NLP. Но у них (и у мешка слов) есть общая слабость: они смотрят на слова **по отдельности** и не помнят **порядок** и **контекст**. А ведь «собака укусила человека» и «человек укусил собаку» — это разные вещи! Чтобы читать текст **по порядку**, помня, что было раньше, придумали особые сети — **рекуррентные (RNN/LSTM)**.

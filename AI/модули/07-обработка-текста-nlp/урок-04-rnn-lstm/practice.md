## Задание 1. Видим проблему: мешок слов теряет порядок (10 минут)

### Что мы хотим сделать

Доказать на числах, что мешок слов **не различает** фразы с одинаковыми словами, но разным порядком.

### 1.1. Две фразы — один вектор

```python
a = "movie good not bad"      # фильм хороший, не плохой → ПОЗИТИВ
b = "movie bad not good"      # фильм плохой, не хороший → НЕГАТИВ

cv = CountVectorizer().fit([a, b])
print("Словарь:", cv.get_feature_names_out().tolist())
print(a, "->", cv.transform([a]).toarray()[0].tolist())
print(b, "->", cv.transform([b]).toarray()[0].tolist())
```

**Что увидим:**
```
Словарь: ['bad', 'good', 'movie', 'not']
movie good not bad -> [1, 1, 1, 1]
movie bad not good -> [1, 1, 1, 1]
```

#### Что это значит

> 😮 **Векторы одинаковые `[1,1,1,1]`!** Хотя фразы **противоположны** по смыслу (позитив vs негатив). Для мешка слов это одно и то же — он видит только **какие** слова есть, а **порядок** теряет. Так он никогда не отличит «не плохой» от «не хороший».
>
> Вот зачем нужны RNN: они читают слова **по порядку** и эту разницу **видят**.

### Итог Задания 1

1. Мешок слов даёт одинаковый вектор фразам с одними словами в разном порядке.
2. Поэтому он не ловит отрицания и смысл, зависящий от порядка.
3. Нужна модель, которая **читает по порядку** → RNN/LSTM.

## Задание 2. Собираем LSTM, которая читает по порядку (20 минут)

### Что мы хотим сделать

Построить маленькую LSTM и обучить её на спам-сообщениях. В отличие от 7.2, она будет **читать сообщение слово за словом**.

### Что мы сделаем (шаги словами)

1. Загрузим спам-датасет, разобьём на train/test.
2. Превратим тексты в **последовательности номеров слов** (не в мешок!).
3. Соберём LSTM: эмбеддинги → LSTM → ответ.
4. Обучим и оценим.

### 2.1. Данные и словарь

```python
url = "https://raw.githubusercontent.com/justmarkham/pycon-2016-tutorial/master/data/sms.tsv"
df = pd.read_csv(url, sep='\t', header=None, names=['label', 'message'])
y = (df['label'] == 'spam').astype(int).values

def tokenize(s):
    return re.findall(r"[a-z']+", s.lower())   # текст → список слов

X_train, X_test, y_train, y_test = train_test_split(
    df['message'].values, y, test_size=0.25, random_state=42, stratify=y)

# Словарь: каждому слову — свой номер. 0 = <pad> (пустое место), 1 = <unk> (незнакомое)
counter = Counter(w for s in X_train for w in tokenize(s))
vocab = {'<pad>': 0, '<unk>': 1}
for word, _ in counter.most_common(5000):
    vocab[word] = len(vocab)

print("Размер словаря:", len(vocab))
```

> **Отличие от 7.2:** там мы считали слова (мешок). Здесь каждому слову даём **номер**, чтобы сохранить **порядок**: предложение станет **списком номеров**, как читается — слева направо.

### 2.2. Превращаем тексты в последовательности номеров

```python
def encode(s, length=30):
    ids = [vocab.get(w, 1) for w in tokenize(s)][:length]   # слова → номера (обрезаем до 30)
    return ids + [0] * (length - len(ids))                  # добиваем нулями до длины 30

X_train_seq = torch.tensor([encode(s) for s in X_train])
X_test_seq  = torch.tensor([encode(s) for s in X_test])
y_train_t = torch.tensor(y_train)
y_test_t  = torch.tensor(y_test)

print("Пример:", X_train[0])
print("В номерах:", X_train_seq[0].tolist())
```

> Каждое сообщение теперь — **список из 30 номеров** (порядок сохранён!). Короткие добиты нулями (`<pad>`), длинные обрезаны. Это и есть **последовательность**, которую прочитает LSTM.

### 2.3. Строим LSTM

```python
class LSTMClassifier(nn.Module):
    def __init__(self, vocab_size):
        super().__init__()
        self.emb  = nn.Embedding(vocab_size, 32, padding_idx=0)   # слово-номер → вектор 32
        self.lstm = nn.LSTM(32, 64, batch_first=True)             # читает по порядку, память=64
        self.fc   = nn.Linear(64, 2)                              # память → 2 класса (spam/ham)

    def forward(self, x):
        e = self.emb(x)              # (батч, 30, 32) — каждое слово стало вектором
        out, (h, c) = self.lstm(e)   # LSTM прочитала всю последовательность
        return self.fc(h[-1])        # h[-1] — память ПОСЛЕ последнего слова → классификатор

net = LSTMClassifier(len(vocab)).to(device)
print(net)
```

#### Что мы собрали — разбор

- **`nn.Embedding`** — превращает номер слова в вектор (эмбеддинг, как в 7.3), но здесь он **обучается** под задачу.
- **`nn.LSTM`** — читает векторы слов **по порядку**, неся память (64 числа).
- **`h[-1]`** — память **после последнего слова**: в ней «сжат» смысл всего сообщения.
- **`fc`** — по этой памяти решает: спам или нет.

> Вот она — сеть, которая **читает по порядку**. Эмбеддинг даёт смысл словам, LSTM связывает их в последовательность.

### 2.4. Обучаем

```python
from torch.utils.data import TensorDataset, DataLoader
loader = DataLoader(TensorDataset(X_train_seq, y_train_t), batch_size=64, shuffle=True)

loss_fn = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(net.parameters(), lr=0.005)

for epoch in range(4):
    net.train()
    for xb, yb in loader:
        xb, yb = xb.to(device), yb.to(device)
        optimizer.zero_grad()
        loss = loss_fn(net(xb), yb)
        loss.backward()
        optimizer.step()

    net.eval()
    with torch.no_grad():
        pred = net(X_test_seq.to(device)).argmax(1).cpu()
    acc = (pred == y_test_t).float().mean().item()
    print(f"Эпоха {epoch+1}: точность {acc:.3f}")
```

> ### ⏳ Пока сеть учится — не сидим без дела
> Здесь обучение **быстрое** (SMS короткие) — но привыкаем использовать паузу:
> - **🔮 Предскажи:** побьёт ли LSTM наш спам-фильтр из 7.2 (accuracy 0.97)? Запиши прогноз.
> - **👀 Наблюдай:** точность по эпохам (≈0.96 → 0.98). Растёт ли она?
> - **💬 Обсуди:** чем чтение «по порядку» (LSTM) принципиально отличается от подсчёта слов (мешок слов из 7.2)?

**Что увидим (примерно):**
```
Эпоха 1: точность 0.963
Эпоха 2: точность 0.972
Эпоха 3: точность 0.976
Эпоха 4: точность 0.981
```

> 🎉 **~98% точности** — и это сеть, которая **прочитала** каждое сообщение по порядку! Сравни с 7.2: там логистическая регрессия на мешке слов давала ~97%.
>
> ⚠️ **Честно:** на этой простой задаче мешок слов из 7.2 уже отлично справлялся — спам выдают отдельные слова («free», «win»), и порядок не так важен. **Сила RNN/LSTM раскрывается там, где порядок решает** — в переводе, отрицаниях, длинных зависимостях. Здесь главное — **увидеть**, что сеть с памятью работает.

### 2.5. Проверяем на своих сообщениях

```python
def predict(text):
    seq = torch.tensor([encode(text)]).to(device)
    net.eval()
    with torch.no_grad():
        return "СПАМ" if net(seq).argmax(1).item() == 1 else "ham"

for msg in ["hey are we still on for lunch tomorrow",
            "WINNER!! claim your FREE prize now call 09061"]:
    print(f"[{predict(msg)}] {msg}")
```

**Что увидим:**
```
[ham ] hey are we still on for lunch tomorrow
[СПАМ] WINNER!! claim your FREE prize now call 09061
```

> Наша LSTM **прочитала** сообщения и распознала спам. Обрати внимание: для нового текста мы тоже превращаем его в **последовательность номеров** (`encode`) — тем же словарём.

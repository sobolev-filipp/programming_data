# Урок 7.4. Рекуррентные сети (RNN, LSTM) — резюме

---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Последовательность** | Упорядоченный набор (слова по порядку) |
| **RNN** | Сеть, читающая текст по одному слову, с памятью |
| **Скрытое состояние (память)** | Вектор «что прочитано до сих пор» |
| **LSTM** | RNN с умной памятью (запомнить/забыть) |
| **Развёртка (unfold)** | Одна ячейка, применённая к каждому слову |
| **padding (`<pad>`)** | Добивка нулями до общей длины |

---

## Главные мысли

1. Мешок слов и эмбеддинги **теряют порядок**: «не хороший» = «хороший не...».
2. **RNN** читает текст **по порядку**, слово за словом.
3. На каждом слове RNN обновляет **память** (скрытое состояние) и несёт её дальше.
4. **LSTM** — RNN с умной памятью: помнит важное, забывает мусор (длинные связи).
5. К последнему слову в памяти — смысл **всей** фразы; по нему делается вывод.
6. Применение: перевод, речь, автоподсказки, временные ряды.
7. Сейчас RNN потеснили **трансформеры** (7.5), но идея «памяти о последовательности» — фундамент.

---

## Мешок слов теряет порядок (проверено)

```
Словарь: ['bad', 'good', 'movie', 'not']
"movie good not bad" -> [1, 1, 1, 1]
"movie bad not good" -> [1, 1, 1, 1]   ← одинаково! (хотя смысл противоположный)
```

> RNN читает по порядку и эту разницу **видит**.

## LSTM-классификатор в коде

```python
class LSTMClassifier(nn.Module):
    def __init__(self, vocab_size):
        super().__init__()
        self.emb  = nn.Embedding(vocab_size, 32, padding_idx=0)  # слово → вектор (смысл)
        self.lstm = nn.LSTM(32, 64, batch_first=True)            # читает по порядку (память)
        self.fc   = nn.Linear(64, 2)                             # память → spam/ham
    def forward(self, x):
        e = self.emb(x)
        out, (h, c) = self.lstm(e)
        return self.fc(h[-1])        # память после последнего слова
```

> Текст → **последовательность номеров** (не мешок!): `encode("...")` → `[12, 5, 88, 0, 0, ...]`.

## Сравнение подходов

| Подход | Порядок? | Память? | Урок |
|--------|:--------:|:-------:|------|
| Мешок слов / TF-IDF | нет | нет | 7.1–7.2 |
| Эмбеддинги | нет | нет | 7.3 |
| **RNN / LSTM** | **да** | **да** | 7.4 |

> LSTM = эмбеддинги (смысл) **+** чтение по порядку (память).

---

## Главные ошибки

| Ошибка | Как правильно |
|--------|---------------|
| «RNN всегда лучше» | на простых задачах мешок слов не хуже |
| Путают эмбеддинг и LSTM | смысл слова vs порядок слов |
| Не согласованы размеры LSTM/Linear | `LSTM(.., H)` ↔ `Linear(H, 2)` |
| Слишком малая длина | обрезает текст |

---

## Что должно остаться в голове после урока

1. Порядок слов важен — мешок слов его теряет.
2. **RNN читает по порядку** и помнит прочитанное (память).
3. **LSTM** — умная память на длинные связи.
4. В коде: текст → **последовательность** номеров → Embedding → LSTM → ответ.
5. RNN — фундамент; дальше трансформеры (другой способ той же задачи).

## К следующему уроку

**Урок 7.5. Трансформеры и attention — на пальцах.** Будем:
- Понимать слабость RNN: читает строго по очереди (медленно), далёкие связи всё ещё трудны.
- Знакомиться с **attention**: модель смотрит на **весь** текст сразу и решает, какие слова **важны**.
- Понимать, что такое **трансформер** — основа ChatGPT и современных переводчиков.

> RNN читают текст по очереди и помнят прочитанное — но медленно и с трудом ловят очень далёкие связи. В 2017-м придумали **трансформеры**: они смотрят на **весь** текст сразу и сами решают, какие слова важны для каждого слова (**attention**). Это то, на чём работают современные языковые модели. Разберём идею на пальцах! 🚀

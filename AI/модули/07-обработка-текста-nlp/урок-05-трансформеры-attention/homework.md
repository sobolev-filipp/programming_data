## Шпаргалка (из практики)

```python
# Attention руками: 3 шага
scores  = E @ E[i]          # похожесть слова i со всеми
weights = softmax(scores)   # → веса внимания (сумма=1)
context = weights @ E       # → контекстный вектор

# Живой трансформер
from transformers import pipeline
unmasker = pipeline("fill-mask", model="distilbert-base-uncased")
unmasker("Paris is the [MASK] of France.", top_k=3)
```

## Задание 1. Attention своими руками (numpy) (14 минут)

### Что мы хотим сделать

На простом примере посчитать **веса внимания**: насколько каждое слово «смотрит» на другие, — и собрать **контекстный** вектор слова.

### 1.1. Зададим слова-векторы

```python
import numpy as np

# Фраза "кот пил молоко". Дадим каждому слову простой вектор (по 4 числа) — для наглядности.
words = ["кот", "пил", "молоко"]
E = np.array([
    [1.0, 0.0, 0.0, 0.2],   # кот
    [0.0, 1.0, 0.0, 0.1],   # пил
    [0.9, 0.0, 0.1, 0.3],   # молоко  (похож на "кот" по 1-й оси — связанные «объекты»)
])

def softmax(x):
    e = np.exp(x - x.max())
    return e / e.sum()       # превращает числа в веса, сумма = 1
```

### 1.2. Считаем attention для каждого слова

```python
# Для каждого слова: сравним его со всеми (похожесть) → веса → взвешенная сумма
for i, w in enumerate(words):
    scores  = E @ E[i]            # шаг 1: похожесть слова i на каждое (скалярное произведение)
    weights = softmax(scores)     # шаг 2: похожести → веса внимания (сумма = 1)
    context = weights @ E         # шаг 3: новый вектор = взвешенная сумма всех слов
    print(f"'{w}': внимание к [кот, пил, молоко] = {np.round(weights, 2).tolist()}")
```

**Что увидим:**
```
'кот':    внимание к [кот, пил, молоко] = [0.44, 0.16, 0.4]
'пил':    внимание к [кот, пил, молоко] = [0.21, 0.57, 0.21]
'молоко': внимание к [кот, пил, молоко] = [0.43, 0.17, 0.41]
```

#### Что это значит

> Это и есть **attention** в три шага: **похожесть → веса → взвешенная сумма**.
> - **«кот»** обращает внимание на себя (0.44) и на **«молоко»** (0.40) — мы специально сделали их векторы похожими (кот и молоко связаны!). А на «пил» — мало (0.16).
> - **«пил»** смотрит в основном на себя (0.57).
> - **«молоко»** тоже тянется к «коту» (0.43).
>
> Каждое слово **решило, на какие другие слова смотреть**, и собрало из них свой **контекстный** вектор. Никаких формул-страшилок — просто похожесть, веса и сумма. Настоящий трансформер делает **то же самое**, только векторы он выучивает сам на огромных текстах.

### Итог Задания 1

1. Attention = 3 шага: похожесть → веса (softmax) → взвешенная сумма.
2. Слово само решает, на какие слова обратить внимание (по похожести).
3. Получается **контекстный** вектор слова.

### 2.1. Трансформер угадывает слово по контексту (fill-mask)

```python
# Модель угадывает пропущенное слово [MASK] — по СМЫСЛУ всей фразы
unmasker = pipeline("fill-mask", model="distilbert-base-uncased")

for sentence in ["I love this movie, it was [MASK].",
                 "The weather today is really [MASK].",
                 "Paris is the [MASK] of France."]:
    print(f"\n{sentence}")
    for r in unmasker(sentence, top_k=3):
        print(f"   {r['token_str']:12s} {r['score']:.2f}")
```

**Что увидим (примерно):**
```
I love this movie, it was [MASK].
   amazing      0.12
   wonderful    0.05
   incredible   0.05

The weather today is really [MASK].
   bad          0.12
   good         0.07
   hot          0.04

Paris is the [MASK] of France.
   capital      0.98
```

#### Что это значит

> 🎯 **Трансформер понимает контекст!**
> - В отзыве про фильм («I love...») он подставляет **позитивные** слова (amazing, wonderful) — уловил тональность.
> - В «Paris is the ___ of France» с уверенностью **0.98** ставит **capital** (столица). Он «знает» из текстов, что Париж — столица Франции.
>
> Никто не задавал эти ответы руками. Модель через attention посмотрела на **всю** фразу и выбрала слово, подходящее **по смыслу**. Это та самая «магия» языковых моделей.

### 2.2. Одно слово — разный вектор по контексту (чиним 7.3!)

Помнишь ограничение из 7.3: у слова **один** вектор, и «банк» (река) = «банк» (деньги)? Проверим, что трансформер даёт «bank» **разные** векторы в разных фразах.

```python
from transformers import AutoTokenizer, AutoModel
import torch, numpy as np

tok = AutoTokenizer.from_pretrained("distilbert-base-uncased")
mdl = AutoModel.from_pretrained("distilbert-base-uncased")

def vector_of(sentence, word):           # вектор слова В КОНТЕКСТЕ фразы
    ids = tok(sentence, return_tensors="pt")
    with torch.no_grad():
        states = mdl(**ids).last_hidden_state[0]
    tokens = tok.convert_ids_to_tokens(ids["input_ids"][0])
    return states[tokens.index(word)].numpy()

def cos(a, b):
    return float(a @ b / (np.linalg.norm(a) * np.linalg.norm(b)))

bank_river = vector_of("i sat by the river bank", "bank")     # банк = берег
bank_money = vector_of("i deposited money in the bank", "bank")  # банк = деньги
print(f"'bank' (река) vs 'bank' (деньги): близость = {cos(bank_river, bank_money):.2f}")
```

**Что увидим:**
```
'bank' (река) vs 'bank' (деньги): близость = 0.76
```

#### Что это значит

> 🪄 **Вот оно — лечение проблемы из 7.3!** Одно и то же слово «bank» получило **разные** векторы (близость **0.76**, а не 1.0), потому что трансформер посмотрел на **соседей**: в одной фразе рядом «river» (река), в другой — «money» (деньги). Слово понято **в контексте**.
>
> В уроке 7.3 (обычные эмбеддинги) у «bank» был **один** застывший вектор на все смыслы. Трансформер даёт **контекстный** вектор — под конкретную фразу. Это и есть скачок к «настоящему пониманию» языка.

3. Одному слову даёт **разный** вектор в разных фразах (банк-река ≠ банк-деньги) — чинит 7.3.

# Урок 7.5. Трансформеры и attention — резюме

---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Трансформер** | Сеть, смотрящая на весь текст сразу; основа ChatGPT |
| **Attention (внимание)** | Слово смотрит на важные другие слова |
| **Self-attention** | Слова текста смотрят друг на друга |
| **Контекстный эмбеддинг** | Вектор слова зависит от соседей |
| **fill-mask** | Угадать пропущенное слово по контексту |

---

## Главные мысли

1. У RNN потолок: читает **по очереди** (медленно), далёкие связи трудны.
2. **Трансформер** смотрит на **весь** текст сразу.
3. **Attention:** каждое слово решает, на какие другие слова обратить внимание.
4. 3 шага attention: **похожесть → веса (softmax) → взвешенная сумма**.
5. Слово понимается **в контексте** → контекстный эмбеддинг.
6. Это чинит «один вектор на слово» из 7.3 (банк-река ≠ банк-деньги).
7. На трансформерах работают ChatGPT, перевод, поиск.

---

## Attention в 3 шага (руками)

```python
scores  = E @ E[i]          # 1. похожесть слова i со всеми словами
weights = softmax(scores)   # 2. похожести → веса внимания (сумма = 1)
context = weights @ E       # 3. взвешенная сумма → контекстный вектор слова
```

> Пример «кот пил молоко»: «кот» уделяет внимание «молоку» (0.40) — их векторы похожи (связаны).

---

## Живой трансформер (готовый)

```python
from transformers import pipeline
unmasker = pipeline("fill-mask", model="distilbert-base-uncased")
unmasker("Paris is the [MASK] of France.")    # → capital (0.98)
```

> Контекст решает: «movie was [MASK]» → amazing; «Paris is the [MASK]» → capital.

---

## Контекст меняет вектор слова

```
'bank' (river bank)  vs  'bank' (money bank):  близость 0.76   ← разные!
'bank' (money)       vs  'bank' (money):        близость 1.00   ← одинаковые
```

> Трансформер даёт слову **разный** вектор по контексту — чинит ограничение 7.3.

## Главные ошибки

| Ошибка | Как правильно |
|--------|---------------|
| Ждут страшных формул | урок про идею attention |
| Несколько `[MASK]` | один на фразу |
| Русский в англ. модели | модель английская |
| «Модель знает факты» | она отражает частоты текстов |

---

## Что должно остаться в голове после урока

1. Трансформер смотрит на **весь текст сразу**.
2. **Attention** = слово смотрит на важные другие слова.
3. 3 шага: похожесть → веса → взвешенная сумма.
4. Слово понимается **в контексте** (контекстный эмбеддинг).
5. Это основа ChatGPT, перевода, поиска.

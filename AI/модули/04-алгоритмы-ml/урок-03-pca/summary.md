# Урок 4.3. PCA — резюме

---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Размерность** | Число признаков у данных |
| **Снижение размерности** | Уменьшить число признаков, сохранив информацию |
| **PCA** | Метод главных компонент — «умное сжатие» признаков |
| **Главная компонента** | Новая ось — направление максимального разброса |
| **Проекция** | «Тень» точки на новую ось |
| **Дисперсия / разброс** | Насколько данные «размазаны» вдоль направления |
| **explained_variance_ratio_** | Доля информации, сохранённая компонентой |

---

## Главные мысли

1. **PCA сжимает признаки:** из 30 делает 2–3, сохраняя большую часть информации.
2. Главные компоненты — **направления максимального разброса** (там больше всего информации).
3. PCA **смешивает** все признаки в новые «суперпризнаки», а не выбрасывает их.
4. **PCA теряет** часть информации — `explained_variance_ratio_` показывает сколько.
5. Применения: **визуализация** многомерного, **ускорение** моделей, борьба с шумом.
6. **PCA требует стандартизации** и работает **без учителя** (не смотрит на `y`).

---

## Шаблон кода для PCA

```python
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler
import numpy as np

# ВСЕГДА стандартизация (клуб расстояний/разброса!)
X_scaled = StandardScaler().fit_transform(X)

# Сжатие до 2 компонент (для рисунка)
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_scaled)

print("Сохранили:", sum(pca.explained_variance_ratio_))

# Сколько компонент для 95%?
cumsum = np.cumsum(PCA().fit(X_scaled).explained_variance_ratio_)
n_95 = np.argmax(cumsum >= 0.95) + 1
```

## Когда что брать

| Цель | Число компонент |
|------|-----------------|
| **Нарисовать** данные | 2 (или 3) |
| **Ускорить** модель | столько, чтобы было 90–95% |
| Сохранить почти всё | 99% (но компонент много) |

## Карта алгоритмов «без учителя»

| Алгоритм | Что делает |
|----------|-----------|
| **K-Means** (4.2) | группирует объекты (кластеры) |
| **PCA** (4.3) | сжимает признаки (меньше осей) |

> Оба — **без меток `y`**, обоим нужна **стандартизация**.

---

## Кому нужна стандартизация (полная карта)

| Модель | Стандартизация |
|--------|----------------|
| KNN, SVM, K-Means, **PCA** | **обязательна** |
| Логистическая / линейная регрессия | желательна |
| Дерево / случайный лес | не нужна |

---

## Главные ошибки

| Ошибка | Что не так | Как исправить |
|--------|-----------|---------------|
| Без стандартизации | Компоненты «уедут» к большим признакам | `StandardScaler` всегда |
| «PCA ничего не теряет» | Теряет; смотри explained variance | Проверять долю |
| Называют компоненты как признаки | Они смеси | Не интерпретировать буквально |
| PCA как классификатор | Он сжимает, не предсказывает | Это разные задачи |

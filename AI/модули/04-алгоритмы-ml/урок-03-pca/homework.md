## Шпаргалка (минимум команд)

```python
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler
import numpy as np

# Стандартизация (для PCA обязательна!)
X_scaled = StandardScaler().fit_transform(X)

# Сжатие до 2 компонент
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_scaled)

pca.explained_variance_ratio_         # доля информации каждой компоненты
np.cumsum(pca.explained_variance_ratio_)   # накопленная доля
```

> Здесь нет accuracy внутри самого PCA — это обучение без учителя (сжатие признаков).

# Урок 4.2. K-Means — резюме

---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Обучение без учителя** | ML без правильных ответов (меток `y`) |
| **Кластеризация** | Разбить данные на группы похожих |
| **Кластер** | Группа похожих объектов |
| **K-Means** | Найти k центров и собрать точки вокруг них |
| **Центроид** | Центр кластера = среднее его точек |
| **Inertia** | Сумма расстояний точек до центров (кучность) |
| **Метод локтя** | Способ выбрать k по графику inertia |
| **`labels_`** | Номер кластера для каждой точки |

---

## Главные мысли

1. **Обучение без учителя** — данных есть, **правильных ответов нет**. Модель ищет структуру сама.
2. **K-Means** ставит k центров, прикрепляет точки к ближайшему, двигает центры в среднее — и так до сходимости.
3. **Число k мы задаём сами.** Выбираем **методом локтя** (точка перегиба графика inertia).
4. K-Means даёт **группы, но не названия** — смысл придаёт человек.
5. **K-Means требует стандартизации** — он считает расстояния (как KNN и SVM).
6. K-Means находит **«круглые»** кластеры; для сложных форм есть другие алгоритмы.

---

## Шаблон кода для K-Means

```python
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

# ВСЕГДА стандартизация (клуб расстояний!)
X_scaled = StandardScaler().fit_transform(X)

# Кластеризация
km = KMeans(n_clusters=5, random_state=42, n_init=10)
labels = km.fit_predict(X_scaled)     # номера кластеров
centers = km.cluster_centers_          # центры
print("Inertia:", km.inertia_)
```

### Метод локтя
```python
inertias = []
for k in range(1, 11):
    inertias.append(KMeans(n_clusters=k, random_state=42, n_init=10).fit(X_scaled).inertia_)
plt.plot(range(1, 11), inertias, 'o-')   # ищем «локоть»
```

## С учителем vs без учителя

| | С учителем (Модуль 3, SVM) | Без учителя (K-Means) |
|---|---|---|
| Есть метки `y`? | **Да** | **Нет** |
| Что делаем | предсказываем ответ | находим группы |
| Примеры | классификация, регрессия | кластеризация |
| Оценка | accuracy, R², F1 | inertia, осмысленность |

---

## Кому нужна стандартизация (обновлённая карта)

| Модель | Стандартизация |
|--------|----------------|
| KNN | **обязательна** |
| SVM | **обязательна** |
| **K-Means** | **обязательна** |
| Логистическая / линейная регрессия | желательна |
| Дерево / случайный лес | не нужна |

> **«Клуб расстояний»: KNN + SVM + K-Means — стандартизация обязательна.**

---

## Главные ошибки

| Ошибка | Что не так | Как исправить |
|--------|-----------|---------------|
| Без стандартизации | Режет по «большому» признаку | `StandardScaler` всегда |
| accuracy для кластеров | Нет правильных ответов | inertia / смысл групп |
| «Минимизируем inertia» → большое k | Inertia всегда падает | Метод локтя |
| Думают, кластер 0 = категория | Номера произвольны | Смысл придаёт человек |

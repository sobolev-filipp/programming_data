## Шпаргалка (минимум команд)

```python
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

# Стандартизация (для K-Means обязательна!)
X_scaled = StandardScaler().fit_transform(X)

# Кластеризация
km = KMeans(n_clusters=4, random_state=42, n_init=10)
labels = km.fit_predict(X_scaled)   # номер кластера каждой точки
km.inertia_                          # «кучность» (для метода локтя)
km.cluster_centers_                  # центры

# Метод локтя
for k in range(1, 11):
    inertia = KMeans(n_clusters=k, random_state=42, n_init=10).fit(X_scaled).inertia_
```

> Здесь **нет** train_test_split и нет accuracy — это обучение без учителя.

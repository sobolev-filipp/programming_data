## Задание 1. Сегментация клиентов магазина (18 минут)

### Что мы хотим сделать

Разбить клиентов торгового центра на **группы похожих** по двум признакам: **годовой доход** и **оценка трат** (1–100, насколько активно человек тратит).

**Что мы сделаем:**
1. Загрузим данные о клиентах.
2. Возьмём 2 признака (доход и траты).
3. Стандартизуем.
4. Запустим K-Means на 5 кластеров.
5. Раскрасим клиентов по группам и **дадим группам названия**.

### 1.1. Загрузка данных

```python
url = "https://raw.githubusercontent.com/SteffiPeTaffy/machineLearningAZ/master/Machine%20Learning%20A-Z%20Template%20Folder/Part%204%20-%20Clustering/Section%2024%20-%20K-Means%20Clustering/Mall_Customers.csv"
df = pd.read_csv(url)

print(df.shape)        # (200, 5)
df.head()
```

**Что мы видим:**
- 200 клиентов торгового центра.
- Столбцы: `CustomerID`, `Genre` (пол), `Age`, `Annual Income (k$)` (доход в тыс. $), `Spending Score (1-100)` (оценка трат).
- **Заметь:** нет столбца «тип клиента» — нам предстоит найти типы **самим**.

### 1.2. Берём 2 признака и смотрим на них

```python
X = df[['Annual Income (k$)', 'Spending Score (1-100)']].values

plt.figure(figsize=(8, 6))
plt.scatter(X[:, 0], X[:, 1])
plt.xlabel("Годовой доход (тыс. $)")
plt.ylabel("Оценка трат (1-100)")
plt.title("Клиенты — пока без групп")
plt.show()
```

**Что увидим:** облако точек, в котором **уже глазами** заметны несколько «сгустков». Например, в углах: «мало денег — мало тратит», «много денег — много тратит» и т.д. K-Means найдёт эти сгустки **формально**.

### 1.3. Стандартизация (обязательно!)

```python
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)
```

**Зачем:** доход (15–140) и траты (1–100) в разных шкалах. Без стандартизации K-Means считал бы группы в основном по доходу. Стандартизация уравнивает признаки. *(Правило «клуба расстояний» из теории.)*

### 1.4. Запускаем K-Means на 5 кластеров

```python
kmeans = KMeans(n_clusters=5, random_state=42, n_init=10)
kmeans.fit(X_scaled)

labels = kmeans.labels_          # номер кластера для каждого клиента
print("Первые 20 меток:", labels[:20])
print("Размеры кластеров:", np.bincount(labels))
```

#### Что произошло

- K-Means расставил **5 центров** и прикрепил каждого клиента к ближайшему (вспомни анимацию из теории).
- **`labels_`** — для каждого из 200 клиентов номер его группы (0–4).
- `np.bincount(labels)` — сколько клиентов в каждой группе.

> K-Means **сам**, без подсказок, разделил клиентов. Никто не размечал «это транжира» — алгоритм нашёл группы по структуре данных.

### 1.5. Рисуем кластеры с центрами

```python
plt.figure(figsize=(9, 7))

# Рисуем точки, раскрашенные по кластеру
plt.scatter(X[:, 0], X[:, 1], c=labels, cmap='viridis', s=50)

# Центры — вернём их в исходный масштаб (обратная стандартизация)
centers = scaler.inverse_transform(kmeans.cluster_centers_)
plt.scatter(centers[:, 0], centers[:, 1], c='red', s=300, marker='X', label='Центры')

plt.xlabel("Годовой доход (тыс. $)")
plt.ylabel("Оценка трат (1-100)")
plt.title("5 сегментов клиентов")
plt.legend()
plt.show()
```

#### Что мы делаем по шагам

- `c=labels` — раскрашиваем точки **по номеру кластера**.
- `scaler.inverse_transform(...)` — возвращаем центры из стандартизованного вида **обратно** в доллары и баллы (чтобы подписи осей были понятны).
- Красные крестики — **центроиды** (центры групп).

**Что увидим — 5 осмысленных групп:**

| Кластер | Доход | Траты | Название («смысл придаёт человек») |
|---------|-------|-------|-----------|
| 🟣 | низкий | низкие | «Экономные» |
| 🔵 | низкий | **высокие** | «Транжиры с малым доходом» (рискованные) |
| 🟢 | средний | средние | «Обычные» |
| 🟡 | высокий | низкие | «Богатые скряги» (есть деньги, но не тратят) |
| 🔴 | высокий | **высокие** | «Целевые клиенты» (мечта магазина!) |

> **Вот зачем нужна кластеризация:** магазин теперь может показывать **разную** рекламу каждой группе. «Целевым» — премиум-товары, «экономным» — скидки. Это реальная польза, и мы получили её **без всякой разметки**.

### Итог Задания 1

**Что мы сделали:**
1. Взяли клиентов **без меток**.
2. K-Means **сам** нашёл 5 групп.
3. Мы **придали им смысл** (названия) и поняли, как использовать в маркетинге.

## Задание 2. Метод локтя (12 минут)

### Что мы хотим сделать

В Задании 1 мы **наугад** взяли k=5. А вдруг лучше 3 или 6? Найдём оптимальное k **методом локтя**.

### 2.1. Считаем inertia для разных k

```python
inertias = []
k_values = range(1, 11)        # пробуем k от 1 до 10

for k in k_values:
    km = KMeans(n_clusters=k, random_state=42, n_init=10)
    km.fit(X_scaled)
    inertias.append(km.inertia_)        # «кучность» при этом k
    print(f"k={k}: inertia = {km.inertia_:.1f}")
```

#### Что мы делаем

- Для **каждого** k обучаем свой K-Means и записываем `inertia_` (сумму расстояний точек до центров).
- Складываем в список, чтобы потом построить график.

**Что увидим:** inertia **падает** с ростом k (больше групп → плотнее). Но падение **замедляется**.

### 2.2. Строим график «локтя»

```python
plt.figure(figsize=(9, 5))
plt.plot(k_values, inertias, 'o-')
plt.xlabel("Число кластеров k")
plt.ylabel("Inertia (кучность)")
plt.title("Метод локтя")
plt.grid()
plt.show()
```

**Что увидим и как читать:**

- Слева (k=1,2) линия падает **круто**.
- Потом — **перегиб** («локоть»), обычно около **k=5**.
- Дальше линия идёт **полого** — новые кластеры почти не помогают.

> **«Локоть» на ~k=5** подтверждает наш выбор из Задания 1! Это и есть оптимальное число сегментов: больше групп уже не даёт заметного выигрыша в «кучности».

### 2.3. Honest замечание

> «Локоть» не всегда чёткий — иногда перегиб «размазан», и точное k неочевидно. Тогда помогает **здравый смысл** или задача бизнеса. Метод локтя — **ориентир**, а не строгое правило.

### Итог Задания 2

**Что мы поняли:**
1. **Inertia** всегда падает с ростом k — поэтому нельзя «просто минимизировать».
2. **Метод локтя** ищет точку перегиба — лучший компромисс.
3. Для клиентов «локоть» подтвердил **k=5**.

## Задание 3. K-Means вслепую на Iris (8 минут)

### Что мы хотим показать

Хитрый эксперимент: у Iris **есть** настоящие виды (метки). Спрячем их, запустим K-Means **вслепую** — и проверим, **совпали** ли найденные кластеры с настоящими видами.

### 3.1. Кластеризуем без меток

```python
iris = pd.read_csv("https://raw.githubusercontent.com/mwaskom/seaborn-data/master/iris.csv")

X_iris = iris[['petal_length', 'petal_width']].values
X_iris_s = StandardScaler().fit_transform(X_iris)

# K-Means на 3 кластера (мы ЗНАЕМ, что видов 3 — но модели НЕ говорим, какие)
km = KMeans(n_clusters=3, random_state=42, n_init=10)
clusters = km.fit_predict(X_iris_s)
```

**Что произошло:** `fit_predict` обучил K-Means и сразу вернул номера кластеров. Модель **не видела** названий видов — только числа.

### 3.2. Сравниваем: кластеры vs настоящие виды

```python
fig, axes = plt.subplots(1, 2, figsize=(14, 5))

# Слева — что нашёл K-Means
axes[0].scatter(X_iris[:, 0], X_iris[:, 1], c=clusters, cmap='viridis')
axes[0].set_title("Кластеры K-Means (вслепую)")
axes[0].set_xlabel("petal_length"); axes[0].set_ylabel("petal_width")

# Справа — настоящие виды
species_num = iris['species'].astype('category').cat.codes
axes[1].scatter(X_iris[:, 0], X_iris[:, 1], c=species_num, cmap='viridis')
axes[1].set_title("Настоящие виды")
axes[1].set_xlabel("petal_length"); axes[1].set_ylabel("petal_width")

plt.show()
```

**Что увидим:** две картинки **очень похожи**! K-Means, **не зная** видов, разбил цветы почти на те же 3 группы. `setosa` отделена идеально; на границе `versicolor`/`virginica` — пара расхождений (там, где виды перекрываются — помним из 3.5).

> **Это впечатляет:** алгоритм **без единой метки** восстановил структуру, которую ботаники находили вручную. Кластеризация реально «видит» группы в данных.

### 3.3. Важная оговорка про номера

> ⚠️ K-Means называет группы «0, 1, 2» **в случайном порядке**. Его «кластер 0» может соответствовать `virginica`, а не `setosa`. Цвета на двух картинках могут не совпасть — важна **форма групп**, а не конкретные цвета/номера. K-Means находит **группы**, но не их **названия** (это мы помним из теории).

### Итог Задания 3

**Что мы поняли:**
1. K-Means **вслепую** нашёл почти те же группы, что настоящие виды.
2. Кластеризация «видит» реальную структуру данных.
3. Номера кластеров **произвольны** — смысл придаёт человек.

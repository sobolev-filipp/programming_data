# Урок 4.1. SVM — резюме

---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **SVM (SVC)** | Классификатор «самой широкой улицы» между классами |
| **Разделяющая граница** | Линия/плоскость, делящая классы |
| **Отступ (margin)** | Ширина «улицы»; SVM его максимизирует |
| **Опорные векторы** | Точки на краю улицы, держащие границу |
| **C** | Строгость: большой → переобучение, маленький → недообучение |
| **Kernel trick** | Разделение «неразделимого» через подъём в высшую размерность |
| **gamma** | Извилистость RBF-границы (большая → переобучение) |
| **`kernel`** | Тип границы: `linear` (прямая), `rbf` (кривая) |

---

## Главные мысли

1. **SVM = самая широкая улица** между классами. Граница — посередине, максимально далеко от обоих.
2. Границу держат лишь **опорные векторы** — несколько крайних точек. Остальные не влияют.
3. **C** регулирует строгость (баланс переобучение↔недообучение), как `max_depth` у дерева.
4. **Kernel trick** позволяет рисовать **кривые** границы — разделять то, что прямой не разделить.
5. **`rbf`** — ядро по умолчанию (гибкое). `linear` — если разделимо прямой.
6. **SVM требует стандартизации** — как KNN (считает расстояния).

---

## Шаблон кода для SVM

```python
from sklearn.svm import SVC
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline

# ВСЕГДА со стандартизацией (в пайплайне — честно)
model = make_pipeline(
    StandardScaler(),
    SVC(kernel='rbf', C=1.0, gamma='scale')
)
model.fit(X_train, y_train)
print(model.score(X_test, y_test))
```

---

## Параметры SVM — шпаргалка

| Параметр | Маленький | Большой |
|----------|-----------|---------|
| **C** | мягко, недообучение | строго, переобучение |
| **gamma** (rbf) | гладкая граница | извилистая, переобучение |
| **kernel** | `linear` — прямая | `rbf` — кривая |

---

## Кому нужна стандартизация (обновлённая карта)

| Модель | Стандартизация |
|--------|----------------|
| KNN | **обязательна** |
| **SVM** | **обязательна** |
| Логистическая / линейная регрессия | желательна |
| Дерево / случайный лес | не нужна |

> Запомни: **«клуб расстояний» (KNN, SVM) — стандартизация обязательна.**

---

## Главные ошибки

| Ошибка | Что не так | Как исправить |
|--------|-----------|---------------|
| SVM без стандартизации | «слепнет» на признаки | `make_pipeline(StandardScaler(), SVC())` |
| Большие C/gamma «для точности» | Переобучение | Подбирать (Урок 4.4) |
| Ждут вероятности от SVM | Плохо их даёт | Для вероятностей — логрег |
| Берут `linear` для сложных данных | Прямая не справится | `rbf` по умолчанию |

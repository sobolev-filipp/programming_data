## Шпаргалка (минимум команд)

```python
from sklearn.svm import SVC
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline
from sklearn.model_selection import cross_val_score

# Правильный способ: scaler + SVM в пайплайне
model = make_pipeline(StandardScaler(), SVC(kernel='rbf', C=1.0, gamma='scale'))
model.fit(X_train, y_train)
model.score(X_test, y_test)

# Опорные векторы (у обученного SVC внутри пайплайна)
# model.named_steps['svc'].n_support_

# Кросс-валидация
cross_val_score(model, X, y, cv=5)
```

Ключевые параметры: `kernel` (`linear`/`rbf`), `C` (строгость), `gamma` (извилистость RBF).

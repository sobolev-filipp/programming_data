```python
def prepare_basic(df):
    data = df.copy()
    data['Age'] = data['Age'].fillna(data['Age'].median())
    data['Sex'] = data['Sex'].map({'male': 0, 'female': 1})
    return data[['Pclass', 'Sex', 'Age', 'Fare']]    # 4 «сырых» признака

X_basic = prepare_basic(df)
y = df['Survived']

model = RandomForestClassifier(n_estimators=100, random_state=42)

print(f"БАЗОВАЯ точность (4 сырых признака): {base_score:.4f}")    # ~0.81
```

- Взяли те же 4 признака, что в Модуле 3.
- Оценили **честно** — кросс-валидацией (привычка из 3.7).
- **Запомнили** базовую точность ~**0.81**. С ней сравним всё дальше.

## Задание 2. Простые новые признаки (14 минут)

### Что мы хотим сделать

Добавить признаки-комбинации: размер семьи, флаг «один», цена за человека. Не меняя модель — посмотреть на прирост.

### 2.1. Создаём признаки

```python
def prepare_v2(df):
    data = df.copy()
    data['Age'] = data['Age'].fillna(data['Age'].median())
    data['Sex'] = data['Sex'].map({'male': 0, 'female': 1})
    data['Fare'] = data['Fare'].fillna(data['Fare'].median())

    # НОВЫЕ признаки:
    data['FamilySize'] = data['SibSp'] + data['Parch'] + 1      # размер семьи (+1 = сам)
    data['IsAlone'] = (data['FamilySize'] == 1).astype(int)      # плыл один?
    data['FarePerPerson'] = data['Fare'] / data['FamilySize']    # цена на человека

    return data[['Pclass', 'Sex', 'Age', 'Fare',
                 'FamilySize', 'IsAlone', 'FarePerPerson']]       # 7 признаков

X_v2 = prepare_v2(df)
score_v2 = cross_val_score(model, X_v2, y, cv=5).mean()
print(f"С новыми признаками: {score_v2:.4f}")
print(f"Было: {base_score:.4f}  →  Стало: {score_v2:.4f}  (прирост {score_v2-base_score:+.4f})")
```

#### Что мы сделали по шагам

- **`FamilySize`** — сложили `SibSp + Parch + 1` (родственники + сам человек).
- **`IsAlone`** — флаг: 1 если плыл один (`FamilySize == 1`), иначе 0.
- **`FarePerPerson`** — поделили цену билета на размер семьи (часто билет один на семью).

**Что увидим:** точность **подросла** (например, 0.81 → 0.82–0.83). Модель **та же** — выросли только признаки!

### 2.2. Проверим, что признаки осмысленные

```python
df['FamilySize'] = df['SibSp'] + df['Parch'] + 1
survival_by_family = df.groupby('FamilySize')['Survived'].mean()
print(survival_by_family)

survival_by_family.plot(kind='bar')
plt.ylabel("Доля выживших")
plt.title("Выживаемость по размеру семьи")
plt.show()
```

**Что увидим:** выживаемость **не плоская** по размеру семьи! Одиночки (FamilySize=1) выживали хуже, семьи из 2–4 — лучше, большие семьи (5+) — снова хуже. Это **реальная закономерность**, которую новый признак донёс до модели.

> ### 📊 Как читать этот график (выживаемость по размеру семьи)
>
> **Зачем он нужен.** Проверить, что придуманный признак `FamilySize` действительно связан с выживанием, а не бесполезен. Если доля выживших меняется от размера семьи — признак несёт информацию.
>
> **Что на осях.** X — размер семьи (1, 2, 3, …). Y — доля выживших в этой группе (от 0 до 1). Высота столбика = какая часть людей с такой семьёй спаслась.
>
> **Что мы видим.** Столбики **разной** высоты, а не одинаковые: низкий у одиночек, выше у семей 2–4 человека, снова низкий у больших семей (5+). Форма — «горка».
>
> **Какой вывод.** Раз высота столбиков заметно меняется — размер семьи влияет на выживание, и признак осмысленный. Будь все столбики одной высоты, признак был бы бесполезен. «Горка» объясняет, почему точность модели подросла: новый признак донёс до неё эту закономерность (одному тяжело, огромной семье тоже, оптимум — средняя семья).

> **Вот доказательство:** мы не выдумали признак из воздуха — он отражает **настоящую** структуру данных. Поэтому он и помог.

## Задание 3. Титул из имени — высший пилотаж (14 минут)

### Что мы хотим сделать

Извлечь **титул** (Mr/Mrs/Miss/Master) из столбца `Name` и сделать **бины возраста**. Это самые «умные» признаки урока.

### 3.1. Извлекаем титул из имени

```python
# Посмотрим, как выглядит имя
print(df['Name'].head())
```

#### Что произошло

- Видим: основные титулы — `Mr, Miss, Mrs, Master`, плюс редкие (`Dr, Rev, Col`...).

### 3.2. Группируем редкие титулы


### 3.4. Бины возраста + финальная сборка

```python
def prepare_v3(df):
    data = df.copy()
    data['Age'] = data['Age'].fillna(data['Age'].median())
    data['Sex'] = data['Sex'].map({'male': 0, 'female': 1})
    data['Fare'] = data['Fare'].fillna(data['Fare'].median())
    data['FamilySize'] = data['SibSp'] + data['Parch'] + 1
    data['IsAlone'] = (data['FamilySize'] == 1).astype(int)
    data['FarePerPerson'] = data['Fare'] / data['FamilySize']

    # Титул
    data['Title'] = data['Name'].str.extract(r' ([A-Za-z]+)\.')
    data['Title'] = data['Title'].replace(
        ['Dr','Rev','Col','Major','Capt','Sir','Lady','Don','Countess','Jonkheer'], 'Rare')
    data['Title'] = data['Title'].replace(['Mlle','Ms'], 'Miss').replace('Mme','Mrs')

    # Бины возраста
    data['AgeGroup'] = pd.cut(data['Age'], bins=[0,12,18,60,100],
                              labels=['child','teen','adult','senior'])

    # One-hot для категорий (титул и возрастная группа — без порядка)
    data = pd.get_dummies(data, columns=['Title', 'AgeGroup'])

    # Убираем то, что не признаки
    drop = ['PassengerId','Name','Ticket','Cabin','Embarked','Survived','SibSp','Parch']
    return data.drop(columns=[c for c in drop if c in data.columns])

X_v3 = prepare_v3(df)
score_v3 = cross_val_score(model, X_v3, y, cv=5).mean()
print(f"Финал (с титулом и бинами): {score_v3:.4f}")
```

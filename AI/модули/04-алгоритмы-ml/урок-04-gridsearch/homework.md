## Шпаргалка (минимум команд)

```python
from sklearn.model_selection import GridSearchCV, RandomizedSearchCV

# Сетка — словарь со списками
param_grid = {'param1': [...], 'param2': [...]}

# Полный перебор
grid = GridSearchCV(model, param_grid, cv=5)
grid.fit(X_train, y_train)
grid.best_params_       # лучшая комбинация
grid.best_score_        # её CV-точность
grid.best_estimator_    # готовая лучшая модель
grid.score(X_test, y_test)   # честная финальная оценка

# Случайный перебор (когда комбинаций много)
RandomizedSearchCV(model, param_grid, n_iter=20, cv=5, random_state=42)

# В Pipeline имена параметров: 'шаг__параметр'
param_grid = {'knn__n_neighbors': [3, 5, 7]}
```

# Урок 4.4. Подбор гиперпараметров — резюме

---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Гиперпараметр** | Настройка, которую задаём мы сами (k, max_depth, C...) |
| **Параметр** | Число, которое модель находит сама (веса, пороги) |
| **Подбор гиперпараметров** | Поиск лучших значений настроек |
| **Сетка (param_grid)** | Какие значения проверить (словарь со списками) |
| **GridSearchCV** | Перебор всех комбинаций + кросс-валидация |
| **RandomizedSearchCV** | Перебор случайных N комбинаций |
| **`best_params_`** | Лучшая найденная комбинация |
| **`best_estimator_`** | Готовая лучшая модель |

---

## Главные мысли

1. **Гиперпараметры** мы задаём сами, **параметры** модель находит сама.
2. Неправильные гиперпараметры портят даже хорошую модель → их надо **подбирать**.
3. **GridSearchCV** перебирает **все комбинации** из сетки, каждую оценивает **кросс-валидацией**, выдаёт лучшую.
4. Подбор идёт **на train (через CV)**, тест трогаем **только в конце**.
5. Когда комбинаций слишком много — **RandomizedSearchCV** (случайные N).
6. Стандартизацию кладём **в Pipeline**, чтобы не было утечки в CV.

---

## Шаблон кода

```python
from sklearn.model_selection import GridSearchCV

# 1. Сетка
param_grid = {'C': [0.1, 1, 10], 'gamma': [0.01, 0.1, 1]}

# 2. Подбор на train (CV внутри)
grid = GridSearchCV(SVC(), param_grid, cv=5)
grid.fit(X_train, y_train)

# 3. Результаты
print(grid.best_params_)            # лучшая комбинация
print(grid.best_score_)             # её CV-точность

# 4. Честная оценка на тесте (только сейчас!)
print(grid.score(X_test, y_test))
```

### С Pipeline (правильно, без утечки)
```python
pipe = Pipeline([('scaler', StandardScaler()), ('svm', SVC())])
param_grid = {'svm__C': [0.1, 1, 10]}     # имя_шага__параметр
GridSearchCV(pipe, param_grid, cv=5).fit(X_train, y_train)
```

---

## GridSearch vs RandomizedSearch

| | GridSearchCV | RandomizedSearchCV |
|---|---|---|
| Проверяет | **все** комбинации | случайные N (`n_iter`) |
| Когда | мало комбинаций (десятки) | много (сотни-тысячи) |
| Скорость | медленнее | быстрее |
| Лучшая | гарантирована (в сетке) | почти |

## Гиперпараметры всех моделей курса

| Модель | Главные гиперпараметры |
|--------|------------------------|
| KNN | `n_neighbors`, `weights` |
| Дерево | `max_depth`, `min_samples_leaf` |
| Случайный лес | `n_estimators`, `max_depth`, `max_features` |
| SVM | `C`, `gamma`, `kernel` |
| K-Means | `n_clusters` |
| PCA | `n_components` |

---

## Главные ошибки

| Ошибка | Что не так | Как исправить |
|--------|-----------|---------------|
| Подбор по тесту | Утечка, завышенная оценка | Подбор на train/CV |
| Scaler до GridSearch | Утечка в CV | Scaler в Pipeline |
| `шаг_параметр` (одно `_`) | Синтаксис | Двойное `__` |
| Огромная сетка с Grid | Очень долго | RandomizedSearch |

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Kaggle** | Платформа соревнований по машинному обучению |
| **train.csv** | Данные **с** ответами (учимся) |
| **test.csv** | Данные **без** ответов (предсказываем) |
| **submission.csv** | Файл предсказаний для отправки |
| **Лидерборд** | Рейтинг участников по точности |
| **Public / Private LB** | Рейтинг по части / другой части теста |

---

## Главные мысли

1. На соревновании у теста **нет ответов** — их знает только Kaggle.
2. Локально посчитать accuracy на test **нельзя** — доверяем **кросс-валидации**.
3. **CV — твой честный «лидерборд»** до отправки. Верь ему больше, чем public score.
4. **Подгонка под public лидерборд** = переобучение → провал на private.
5. **Признаки решают** больше, чем выбор и настройка модели (правило 4.5).
6. Соревнование = весь курс в одной задаче: данные → признаки → Pipeline → модель → submission.

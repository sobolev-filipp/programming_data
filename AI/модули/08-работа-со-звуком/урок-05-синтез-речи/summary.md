## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Синтез речи (TTS)** | Текст → голос |
| **gTTS** | Голос Google: онлайн, естественный, mp3 |
| **pyttsx3** | Синтез офлайн, голоса системы, wav |
| **Онлайн / офлайн** | С интернетом / без интернета |

---

## Главные мысли

1. **Синтез речи** = текст → голос (обратное к распознаванию, 8.4).
2. Два бесплатных инструмента **без ключей**: gTTS и pyttsx3.
3. **gTTS** — онлайн, естественный голос, mp3, ~69 языков.
4. **pyttsx3** — офлайн, голоса системы, wav, роботнее.
5. В **Colab** — gTTS (pyttsx3 там обычно не работает).
6. Озвучка одной строкой; русский и английский поддерживаются.
7. Теперь у помощника есть «рот» (8.5) и «уши» (8.4).

---

## Синтез речи в коде

```python
# gTTS (онлайн, mp3) — для Colab
from gtts import gTTS
from IPython.display import Audio
gTTS("Привет! Я говорю.", lang='ru').save("voice.mp3")
Audio("voice.mp3")                       # послушать

# pyttsx3 (офлайн, wav) — на своём ПК
import pyttsx3
e = pyttsx3.init()
e.setProperty('rate', 130)               # скорость
e.save_to_file("Hello", "voice.wav"); e.runAndWait()
```

---

## gTTS vs pyttsx3

| | gTTS | pyttsx3 |
|--|------|---------|
| Интернет | нужен | не нужен |
| Голос | естественный | роботнее |
| Формат | mp3 | wav |
| Языки | ~69 | голоса системы |
| В Colab | ✅ работает | ❌ обычно нет |
| Ключ | не нужен | не нужен |

> Colab/красивый голос → gTTS. Офлайн/приватность → pyttsx3.

## Главные ошибки

| Ошибка | Как правильно |
|--------|---------------|
| pyttsx3 в Colab | в Colab — gTTS |
| gTTS без интернета | gTTS онлайн; офлайн → pyttsx3 |
| Неправильный `lang` | язык = язык текста |
| Забыли `runAndWait()` | иначе pyttsx3 не сохранит |

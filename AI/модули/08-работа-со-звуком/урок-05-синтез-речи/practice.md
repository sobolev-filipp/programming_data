## Задание 1. gTTS — компьютер говорит (18 минут)

### Что мы хотим сделать

Превратить текст в голос с помощью gTTS и послушать.

### 1.1. Устанавливаем и озвучиваем

```python
!pip install gTTS -q
from gtts import gTTS
from IPython.display import Audio

text = "Привет! Я компьютер, и я научился говорить."
tts = gTTS(text, lang='ru')        # создаём озвучку на русском
tts.save("voice_ru.mp3")           # сохраняем в mp3
print("Готово! Файл voice_ru.mp3 сохранён.")

Audio("voice_ru.mp3")              # нажми ▶ — послушай!
```

> 📥 **gTTS бесплатна и без ключа**, но **нужен интернет** (она обращается к серверу Google). Результат — файл **mp3**.

> ### ⏳ Пока генерируется/устанавливается — разогрев
> - **🔮 Предскажи:** как будет звучать голос gTTS — как живой человек или «по-роботски»?
> - **💬 Обсуди:** где ты слышишь говорящий компьютер каждый день? *(навигатор, метро, помощники)*

**Что произойдёт:**
> 🔊 Компьютер **произнесёт** твою фразу естественным голосом! Из обычного текста родился голос. И это бесплатно, в три строки.

### 1.2. Английский (и другие языки)

> **~69 языков** — от английского до японского. Один инструмент озвучит почти любой текст.

## Задание 2. pyttsx3 (офлайн-голос) и настройки (14 минут)

> ⚠️ **Это задание лучше выполнять на своём компьютере** (Windows/Mac/Linux). В Google Colab pyttsx3 обычно **не работает** (нет звукового устройства). Если ты в Colab — прочитай код и переходи к выводам, а pyttsx3 попробуй дома.

### Что мы хотим сделать

Озвучить текст **офлайн** (без интернета) и настроить голос.

### 2.1. Синтез офлайн

```python
import pyttsx3
engine = pyttsx3.init()

engine.save_to_file("Hello, this is offline speech.", "offline.wav")
engine.runAndWait()        # выполнить задание (сохранить файл)
print("Готово: offline.wav (без интернета!)")
```

> **pyttsx3 работает без интернета** — синтезирует голос прямо на компьютере, используя голоса системы. Результат — **wav**.

### 2.2. Смотрим, какие голоса есть

```python
for v in engine.getProperty('voices'):
    print(v.name)
```

**Что увидим (пример на Windows):**
```
Microsoft Irina Desktop - Russian
Microsoft Zira Desktop - English (United States)
```

> В системе есть **голоса** (например, Irina — русский, Zira — английский). Их можно выбирать. На разных компьютерах голоса разные.

### 2.3. Настраиваем скорость и громкость

```python
engine.setProperty('rate', 130)      # скорость речи (слов в минуту); меньше = медленнее
engine.setProperty('volume', 0.9)    # громкость 0..1

engine.save_to_file("Я говорю медленнее и громче.", "slow.wav")
engine.runAndWait()
```

> Можно сделать голос **медленнее/быстрее** (`rate`) и **тише/громче** (`volume`). Это пригодится, чтобы помощник говорил понятно.

### 2.4. Сравнение gTTS и pyttsx3

```python
print("gTTS:    онлайн, естественный голос, mp3, ~69 языков")
print("pyttsx3: офлайн, роботнее, wav, голоса системы")
print()
print("В Colab → gTTS. На своём ПК офлайн → pyttsx3.")
```

### Итог Задания 2

1. pyttsx3 синтезирует **офлайн** (без интернета), даёт wav.
2. Использует **голоса системы**, можно менять скорость/громкость.
3. В Colab обычно не работает → там gTTS; pyttsx3 — на своём ПК.

# Урок 8.7. Голосовой помощник — резюме

---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Голосовой помощник** | Слышит → понимает → отвечает |
| **Конвейер помощника** | Аудио → текст → ответ → голос |
| **Правила (rule-based)** | Понимание по ключевым словам (`if`) |
| **Намерение (intent)** | Что человек хочет командой |

---

## Главные мысли

1. Голосовой помощник = **три части**: уши + голова + рот.
2. 👂 **Уши** — Whisper (речь → текст, 8.4).
3. 🧠 **Голова** — правила (ключевые слова → ответ).
4. 👄 **Рот** — gTTS (текст → голос, 8.5).
5. Цепочка: аудио → Whisper → правила → gTTS → голос.
6. «Мозг» = простые `if "слово" in text` (Python из Модуля 1).
7. Настоящие помощники — та же схема, но мощнее каждая часть.

---

## Помощник в коде

```python
import datetime
from gtts import gTTS
from IPython.display import Audio

def assistant(text):                          # 🧠 голова
    text = text.lower()
    if "час" in text or "врем" in text:
        return f"Сейчас {datetime.datetime.now():%H:%M}"
    if "привет" in text: return "Привет!"
    return "Не понял команду."

def say(text):                                # 👄 рот
    gTTS(text, lang='ru').save("a.mp3"); return Audio("a.mp3", autoplay=True)

def voice_assistant(path):                    # вся цепочка
    text = whisper_model.transcribe(path, language="ru")["text"]   # 👂 уши
    return say(assistant(text))
```

## Три части помощника

| Часть | Делает | Чем | Урок |
|-------|--------|-----|------|
| 👂 Уши | речь → текст | Whisper | 8.4 |
| 🧠 Голова | текст → ответ | правила | 8.7 |
| 👄 Рот | ответ → голос | gTTS | 8.5 |

---

## Цепочка работы

```
🎤 → [Whisper] → текст → [правила] → ответ → [gTTS] → 🔊
   услышал           понял              ответил
```

---

## Главные ошибки

| Ошибка | Как правильно |
|--------|---------------|
| Общие ключевые слова | специфичные/корни слов |
| Точное слово | корень (ловит склонения) |
| Не отладили мозг на тексте | сначала текст, потом звук |
| pyttsx3 в Colab | для ответа — gTTS |

---

## Что должно остаться в голове после урока

1. Помощник = **уши (Whisper) + голова (правила) + рот (gTTS)**.
2. «Мозг» — простые `if "слово" in text`.
3. Цепочка: услышал → понял → ответил.
4. Правила ищут **слова**, а не понимают смысл (ограничение).
5. Настоящие помощники — та же схема, но сложнее.

## Задание 1. «Мозг» помощника (правила) (14 минут)

### Что мы хотим сделать

Написать функцию, которая по тексту команды выбирает ответ. Это «голова» помощника.

### 1.1. Пишем правила

```python
def assistant(text):
    text = text.lower()                          # нижний регистр — чтобы ловить любые написания

    if "время" in text or "час" in text:
        return f"Сейчас {datetime.datetime.now():%H:%M}"
    if "привет" in text or "здравств" in text:
        return "Привет! Чем могу помочь?"
    if "как" in text and ("зовут" in text or "имя" in text):
        return "Меня зовут Помощник."
    if "спасибо" in text:
        return "Пожалуйста! Обращайся."
    if "дата" in text or "число" in text:
        return f"Сегодня {datetime.datetime.now():%d.%m.%Y}"

    return "Извините, я не понял команду."        # ничего не подошло
```

> **Это вся «голова»!** Помощник ищет **ключевые слова** в тексте и выбирает ответ. Простые `if` — но этого достаточно.

### 1.2. Проверяем «мозг» на тексте

```python
for q in ["Привет!", "Который час?", "Как тебя зовут?", "Спасибо большое", "Расскажи анекдот"]:
    print(f"Команда: {q:25s} -> Ответ: {assistant(q)}")
```

**Что увидим:**
```
Команда: Привет!                   -> Ответ: Привет! Чем могу помочь?
Команда: Который час?              -> Ответ: Сейчас 15:21
Команда: Как тебя зовут?           -> Ответ: Меня зовут Помощник.
Команда: Спасибо большое           -> Ответ: Пожалуйста! Обращайся.
Команда: Расскажи анекдот          -> Ответ: Извините, я не понял команду.
```

> **Мозг работает!** На знакомые команды — правильный ответ, на незнакомую («анекдот») — вежливое «не понял». Заметь: пока всё на **тексте**, без звука. Сначала отладим логику, потом добавим уши и рот.

### Итог Задания 1

1. «Мозг» = правила: ключевое слово → ответ.
2. Если ничего не подошло — вежливый отказ.
3. Логику удобно отлаживать на тексте (без звука).

## Задание 2. Собираем голосового помощника (20 минут)

### Что мы хотим сделать

Соединить три части: Whisper (услышал) → правила (понял) → gTTS (ответил голосом).

### 2.1. Функция «ответить голосом»

```python
def say(text):                                   # «рот»: текст → голос
    gTTS(text, lang='ru').save("answer.mp3")
    return Audio("answer.mp3", autoplay=True)
```

### 2.2. Полный помощник (цепочка)

```python
def voice_assistant(audio_path):
    # 1. УСЛЫШАЛ: речь → текст
    text = whisper_model.transcribe(audio_path, language="ru")["text"]
    print("🎤 Услышал:", text)

    # 2. ПОНЯЛ: текст → ответ (правила)
    answer = assistant(text)
    print("🧠 Отвечаю:", answer)

    # 3. ОТВЕТИЛ: ответ → голос
    return say(answer)
```

> **Вот он, весь помощник — в одной функции!** Три шага: услышал (Whisper) → понял (правила) → ответил голосом (gTTS). Ровно та схема из теории.

### 2.3. Готовим тестовую команду

```python
# Запиши свою команду или сгенерируй тестовую через gTTS:
gTTS("Который сейчас час?", lang='ru').save("my_command.mp3")
Audio("my_command.mp3")        # послушай команду
```

> 💡 Можно записать команду своим голосом (загрузить файл) — так честнее. Тестовую через gTTS делаем для удобства.

### 2.4. Запускаем помощника! 🎉

```python
voice_assistant("my_command.mp3")     # услышит, поймёт, ответит голосом!
```

**Что произойдёт:**
```
🎤 Услышал: Который сейчас час?
🧠 Отвечаю: Сейчас 15:21
```
🔊 **...и помощник произнесёт ответ вслух!**

> 🎊 **Готово — у тебя свой голосовой помощник!** Ты сказал команду — он услышал её (Whisper), понял (правила) и ответил голосом (gTTS). Три кубика, которые мы собирали весь модуль, стали живой программой. Это мини-Алиса, сделанная своими руками, бесплатно и без ключей!
>
> ⚠️ **Честно:** Whisper иногда распознаёт команду не идеально (особенно синтетический или шумный голос) — тогда правило может не сработать. На чёткой человеческой речи работает лучше. Это нормально для простого помощника.

### 2.5. Поговори с помощником

```python
# Попробуй разные команды (запиши свои или сгенерируй):
for phrase in ["Привет, помощник", "Какое сегодня число", "Как тебя зовут"]:
```

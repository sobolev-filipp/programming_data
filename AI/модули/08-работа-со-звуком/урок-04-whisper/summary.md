# Урок 8.4. Распознавание речи (Whisper) — резюме

---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Распознавание речи (speech-to-text)** | Превращение голоса в текст |
| **Whisper** | Нейросеть OpenAI для распознавания речи |
| **Open weights** | Открытые веса: скачать и пользоваться бесплатно |
| **`transcribe`** | Команда Whisper: аудио → текст |
| **Размер модели** | tiny/base/… — баланс точность/скорость |

---

## Главные мысли

1. **Распознавание речи** = голос → текст (голосовой ввод, субтитры).
2. **Whisper** — мощная сеть OpenAI, **open weights**: бесплатно, офлайн, без API-ключей.
3. Внутри: Whisper строит **спектрограмму** (8.3) и читает её **нейросетью** → текст.
4. Это **transfer learning** для звука (готовая модель, как ResNet/Hugging Face).
5. Использование — 2 строки: `load_model` + `transcribe`.
6. Модели: **tiny/base** (быстро, для CPU) … **large** (точнее, медленнее).
7. Качество зависит от **чистоты записи**: чёткая речь — почти идеально.
8. Понимает **десятки языков**, включая русский (определяет сам).

---

## Whisper в коде

```python
!pip install openai-whisper -q
import whisper

model = whisper.load_model("base")        # скачать модель (~140 МБ)
result = model.transcribe("audio.wav")    # распознать

print(result["text"])                     # текст
print(result["language"])                 # язык (определён сам)
result["segments"]                        # фразы с таймкодами → субтитры
```

## Размеры моделей

| Модель | Размер | Скорость | Точность |
|--------|-------:|----------|----------|
| tiny | ~75 МБ | очень быстро | базовая |
| **base** | ~140 МБ | быстро | хорошая |
| small | ~470 МБ | средне | выше |
| large | ~3 ГБ | медленно | лучшая |

> Для уроков/CPU — **tiny** или **base**.

---

## Как работает (связь с курсом)

```
речь → спектрограмма (8.3) → нейросеть читает картинку (Модуль 6)
     → выдаёт текст по словам (Модуль 7) → ТЕКСТ
```

> Whisper соединяет звук + зрение + язык. Курс сошёлся в одной модели!

---

## Главные ошибки

| Ошибка | Как правильно |
|--------|---------------|
| Ждут идеала на шуме/роботе | чистая речь → точно |
| Думают, нужен API-ключ | нет: open weights, офлайн |
| large на слабом CPU | бери tiny/base |
| «Whisper понимает смысл» | он распознаёт **слова** |

## Что должно остаться в голове после урока

1. **Whisper** превращает речь в текст одной командой.
2. Бесплатно, офлайн, **без API-ключей** (open weights).
3. Внутри читает **спектрограмму** (8.3) нейросетью.
4. Это **transfer learning** для звука.
5. Качество зависит от **чистоты** записи.

## К следующему уроку

**Урок 8.5. Синтез речи: компьютер заговорит (pyttsx3 / gTTS).** Будем:
- Делать обратное: **текст → голос** (синтез речи).
- Использовать **pyttsx3** (офлайн) или **gTTS** (бесплатно) — без API-ключей.
- Готовить «голос» для будущего голосового помощника.

> Whisper научил компьютер **слышать и понимать** речь. Но помощник должен ещё и **отвечать голосом**! На следующем уроке — обратная задача: **синтез речи**, превращение текста в голос. Компьютер заговорит — и тоже бесплатно, без ключей. А потом (8.7) соединим: услышал → понял → ответил голосом. 🚀

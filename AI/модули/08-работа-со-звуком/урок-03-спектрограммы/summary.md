# Урок 8.3. Спектрограммы и Фурье — резюме

---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Преобразование Фурье (FFT)** | Разбирает звук на синусоиды, находит частоты |
| **Спектр** | «Рецепт» частот для куска звука |
| **Спектрограмма** | Частоты во времени (X=время, Y=частота, цвет=сила) |
| **Гармоники** | Кратные частоты → тембр (полосы у музыки) |
| **Форманты** | Частоты, по которым различаем гласные |

---

## Главные мысли

1. **Главный секрет:** любой звук = **сумма синусоид** разных частот (идея Фурье).
2. **Преобразование Фурье (FFT)** находит, из каких частот состоит звук.
3. Тон → один пик; аккорд (440+660) → два пика. Фурье «слышит ноты».
4. **Спектр** — частоты куска; **спектрограмма** — частоты во времени.
5. Спектрограмма: X=время, Y=частота, цвет=сила. Тон=линия, музыка=полосы, речь=форманты.
6. ⭐ Спектрограмма — это **картинка** → можно применить **CNN** (Модуль 6)!
7. На этом работают распознавание речи, классификация звуков, Shazam.

## Фурье и спектрограмма в коде

```python
import numpy as np, librosa, librosa.display
import matplotlib.pyplot as plt

# Фурье: какие частоты в звуке
spectrum = np.abs(np.fft.rfft(y))
freqs = np.fft.rfftfreq(len(y), 1/sr)
freqs[np.argmax(spectrum)]                # главная частота

# Спектрограмма
S_db = librosa.amplitude_to_db(np.abs(librosa.stft(y)), ref=np.max)
librosa.display.specshow(S_db, sr=sr, x_axis='time', y_axis='hz')
plt.show()
```

## Как читать спектрограмму

| Что видно | Что за звук |
|-----------|-------------|
| Одна горизонтальная линия | чистый тон |
| Несколько полос (гармоники) | музыкальный инструмент |
| Полосы меняются во времени | мелодия (разные ноты) |
| Движущиеся тёмные полосы | речь (форманты, гласные) |
| Заполнено всё равномерно | шум (все частоты) |
| Поднимающаяся линия | растущая частота (сирена) |

## Осциллограмма vs спектрограмма

| | Осциллограмма | Спектрограмма |
|--|---------------|---------------|
| Y | амплитуда (громкость) | **частота** |
| Показывает | громкость во времени | **частоты** во времени |
| Видно «а» vs «о»? | плохо | **да** (форманты) |
| Для ИИ | базово | **картинка для CNN** |

---

## Главные ошибки

| Ошибка | Как правильно |
|--------|---------------|
| Путают спектр и спектрограмму | частоты куска vs во времени |
| Путают оси | Y=частота, X=время, цвет=сила |
| Частота ≠ громкость | спектрограмма про частоты |
| Боятся «Фурье» | это «разобрать на синусоиды» |

---

## Что должно остаться в голове после урока

1. Любой звук = **сумма синусоид**.
2. **Фурье** находит частоты (тон→пик, аккорд→2 пика).
3. **Спектрограмма** = частоты во времени.
4. Тон=линия, музыка=полосы, речь=форманты.
5. ⭐ Спектрограмма — **картинка** → CNN → распознавание звука.

## Задание 1. Фурье находит частоты (14 минут)

### Что мы хотим сделать

Доказать, что преобразование Фурье **находит** частоты, спрятанные в звуке.

### 1.1. Разбираем чистый тон

```python
sr = 22050
t = np.linspace(0, 1, sr, endpoint=False)
tone = np.sin(2*np.pi*440*t)              # чистый тон 440 Гц

# Преобразование Фурье (FFT): какие частоты в звуке?
spectrum = np.abs(np.fft.rfft(tone))       # сила каждой частоты
freqs = np.fft.rfftfreq(len(tone), 1/sr)   # список частот

peak = freqs[np.argmax(spectrum)]          # частота с самым большим пиком
print("Главная частота в звуке:", round(peak, 1), "Гц")
```

**Что увидим:**
```
Главная частота в звуке: 440.0 Гц
```

> **Фурье нашёл частоту!** Мы дали звук, не сказав, что в нём 440 Гц, — и Фурье **сам определил**: главная частота 440 Гц. Он «услышал» ноту.

### 1.2. Рисуем спектр

```python
plt.figure(figsize=(11, 3))
plt.plot(freqs, spectrum)
plt.xlim(0, 2000)                          # смотрим до 2000 Гц
plt.title("Спектр чистого тона: один пик на 440 Гц")
plt.xlabel("Частота, Гц"); plt.ylabel("Сила")
plt.show()
```

**Что увидим:** один острый пик ровно на **440 Гц**. Остальные частоты — почти ноль. Это «рецепт» тона: одна частота.

> ### 📊 Как читать спектр
>
> **Зачем он нужен.** Осциллограмма показывала громкость во времени. Спектр показывает другое — **из каких частот** состоит звук. Это «рецепт» звука.
>
> **Что на осях.** X — частота в герцах (высота звука), Y — сила этой частоты в звуке. Каждая вертикальная «свечка» = насколько громко звучит эта частота.
>
> **Что мы видим.** Один острый пик ровно на 440 Гц, всё остальное почти у нуля.
>
> **Какой вывод.** Один пик = звук состоит из одной частоты (чистый тон). Положение пика по X = высота ноты (440 Гц — это Ля). Фурье-преобразование само нашло эту частоту, хотя мы её не называли. Спектр — это «состав» звука по нотам.

### 1.3. Разбираем аккорд (две ноты)

```python
chord = np.sin(2*np.pi*440*t) + np.sin(2*np.pi*660*t)   # 440 + 660 Гц

spectrum = np.abs(np.fft.rfft(chord))
freqs = np.fft.rfftfreq(len(chord), 1/sr)

# два самых сильных пика
top2 = sorted(freqs[np.argsort(spectrum)[-2:]])
print("Найденные частоты:", [round(f, 1) for f in top2], "Гц")

plt.figure(figsize=(11, 3))
plt.plot(freqs, spectrum); plt.xlim(0, 2000)
plt.title("Спектр аккорда: два пика (440 и 660 Гц)")
plt.xlabel("Частота, Гц"); plt.show()

display(Audio(chord, rate=sr))             # послушай аккорд
```

**Что увидим:**
```
Найденные частоты: [440.0, 660.0] Гц
```

#### Что это значит

> ### 📊 Как читать этот спектр (аккорд)
>
> **Зачем он нужен.** Показать главное свойство спектра: он раскладывает сложный звук на отдельные ноты. Спектр аккорда — прямое доказательство.
>
> **Что на осях.** X — частота (Гц), Y — сила частоты. Тот же спектр, что и для тона, но звук теперь из двух нот.
>
> **Что мы видим.** **Два** острых пика — на 440 Гц и на 660 Гц. Между ними и по краям — почти ноль.
>
> **Какой вывод.** Сколько пиков — столько нот в звуке. Мы сложили две синусоиды, и Фурье нашёл обе, как музыкант, различающий ноты в аккорде на слух. Это доказывает: любой звук = сумма простых синусоид, и спектр умеет их разделить. На этом свойстве строится вся обработка звука.

### Итог Задания 1

1. Преобразование Фурье (FFT) находит частоты в звуке.
2. Тон → один пик; аккорд → два пика (нашёл обе ноты!).
3. Спектр — это «рецепт» звука по частотам.

## Задание 2. Строим спектрограмму (18 минут)

### Что мы хотим сделать

Спектр показывает частоты всего куска сразу. Спектрограмма покажет, как частоты **меняются во времени**.

### 2.1. Спектрограмма чистого тона

```python
def show_spectrogram(y, sr, title, fmax=2000):
    S = np.abs(librosa.stft(y))                    # частоты по кусочкам времени
    S_db = librosa.amplitude_to_db(S, ref=np.max)  # в децибелы (для красоты)
    plt.figure(figsize=(11, 4))
    librosa.display.specshow(S_db, sr=sr, x_axis='time', y_axis='hz')
    plt.ylim(0, fmax); plt.colorbar(label='дБ')
    plt.title(title); plt.show()

tone = np.sin(2*np.pi*440*np.linspace(0, 2, 22050*2, endpoint=False))
show_spectrogram(tone, 22050, "Спектрограмма тона 440 Гц")
```

**Что увидим:** одна яркая **горизонтальная линия** на высоте 440 Гц, тянущаяся всё время. Тон = одна частота, не меняется → линия.

> ### 📊 Как читать спектрограмму (главный график модуля!)
>
> **Зачем она нужна.** Спектр показывает частоты всего куска сразу, но не видно, КОГДА какая нота звучит. Спектрограмма добавляет ось времени — это «спектр в каждый момент», склеенный в картину.
>
> **Что на осях.** X — время. Y — частота (высота звука). **Цвет** каждой точки — сила этой частоты в этот момент (шкала в децибелах справа: ярче = громче). То есть спектрограмма — трёхмерная информация на плоской картинке через цвет.
>
> **Что мы видим.** Одну яркую **горизонтальную линию** на высоте 440 Гц, тянущуюся всё время.
>
> **Какой вывод.** Горизонтальная линия = частота постоянна во времени (чистый тон всё время звучит одну ноту). Высота линии по Y = какая это нота. Если бы нота менялась — линия пошла бы вверх/вниз. Запомни правило чтения: **Y — что за нота, X — когда, цвет — насколько громко.** Дальше увидим спектрограмму настоящей музыки.

> **Читаем:** по вертикали — частота, по горизонтали — время, яркость — сила. Тон даёт одну линию на 440 Гц: всё время звучит одна частота.

### 2.2. Спектрограмма музыки (труба)

```python
y, sr = librosa.load(librosa.ex('trumpet'))
print("Форма спектрограммы (частоты × кадры времени):", np.abs(librosa.stft(y)).shape)
show_spectrogram(y, sr, "Спектрограмма трубы", fmax=4000)
display(Audio(y, rate=sr))
```

**Что увидим:**
```
Форма спектрограммы (частоты × кадры времени): (1025, 230)
```
- Несколько **горизонтальных полос** на разных высотах — это нота и её **гармоники** (кратные частоты, дающие тембр трубы).
- Полосы **меняются** во времени — это разные ноты мелодии.
- К концу всё **гаснет** (звук затухает).

#### Что это значит

> ### 📊 Как читать спектрограмму трубы
>
> **Зачем она нужна.** Показать спектрограмму настоящего, сложного звука — и главную идею модуля: спектрограмма это картинка, а картинку умеет читать CNN.
>
> **Что на осях.** X — время, Y — частота, цвет — сила (как и для тона). Но звук теперь настоящий — мелодия трубы.
>
> **Что мы видим.** Не одну линию, а **стопку** горизонтальных полос (основная нота + гармоники над ней), причём полосы **сдвигаются** во времени (смена нот) и к концу гаснут.
>
> **Какой вывод.** Стопка полос = богатый тембр (гармоники — почему труба звучит «богато», а не «пиип»). Сдвиг полос = мелодия меняется. Главное: спектрограмма имеет форму (1025, 230) — это **таблица чисел, то есть картинка** 1025×230. А значит её можно подать в свёрточную сеть из Модуля 6 — так и работает распознавание звука (уроки 8.4, 8.6).

> 🎺 **Спектрограмма — отпечаток звука!** У трубы видно: основную ноту и стопку гармоник над ней (поэтому труба звучит «богато», а не «пиип»), смену нот во времени, затухание в конце. Спектрограмма имеет **форму (1025, 230)** — это **таблица чисел**, по сути **картинка** размером 1025×230! А картинку можно подать в CNN (Модуль 6) — так и работает распознавание звука.

### 2.3. Сравни: осциллограмма vs спектрограмма

```python
fig, ax = plt.subplots(2, 1, figsize=(11, 6))
librosa.display.waveshow(y, sr=sr, ax=ax[0]); ax[0].set_title("Осциллограмма (громкость во времени)")
S_db = librosa.amplitude_to_db(np.abs(librosa.stft(y)), ref=np.max)
librosa.display.specshow(S_db, sr=sr, x_axis='time', y_axis='hz', ax=ax[1])
ax[1].set_ylim(0, 4000); ax[1].set_title("Спектрограмма (частоты во времени)")
plt.tight_layout(); plt.show()
```

> ### 📊 Как читать эти графики (осциллограмма vs спектрограмма)
>
> **Зачем они нужны.** Поставить рядом два взгляда на ОДИН звук, чтобы понять, чем они отличаются и почему для ИИ нужна именно спектрограмма.
>
> **Что на осях.** Сверху осциллограмма: X — время, Y — амплитуда (громкость). Снизу спектрограмма того же звука: X — время, Y — частота, цвет — сила.
>
> **Что мы видим.** Верхний график — одна линия громкости (видно, когда громко/тихо, но не какие ноты). Нижний — полосы частот (видно, какие ноты и когда).
>
> **Какой вывод.** Осциллограмма отвечает «когда громко», спектрограмма — «какие частоты звучат». Для распознавания звука важнее спектрограмма: в ней «смысл» (ноты, форманты речи), и она — картинка для CNN. Осциллограмма проще, но информации в ней меньше.

> **Две картинки одного звука:** осциллограмма показывает **громкость** (когда громко/тихо), спектрограмма — **частоты** (какие ноты). Вместе они описывают звук полностью. Для ИИ важнее спектрограмма — в ней «смысл» звука.

### Итог Задания 2

1. Спектрограмма = частоты во времени (X=время, Y=частота, цвет=сила).
2. Тон=линия, музыка=полосы-гармоники, меняются во времени.
3. Спектрограмма — это **таблица чисел = картинка** → можно применить CNN!

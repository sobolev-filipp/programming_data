---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Навык (skill)** | Одна способность помощника (ветка `if`) |
| **Диалог в цикле** | Команды по очереди, выход по «пока» |
| **Устойчивость** | Понимать разные формулировки |
| **Навык-действие** | Реально что-то делает (считает) |

---

## Главные мысли

1. Помощник = **набор навыков** (как Алиса).
2. Каждый навык — ветка `if "слово" in t: return ...`.
3. Навык-**фраза** (заготовка) vs навык-**действие** (реальный код, калькулятор).
4. **Диалог в цикле** (`while`) с командой выхода («пока»).
5. **Устойчивость:** ловить корень слова, синонимы через `or`.
6. Голос: Whisper (услышал) + gTTS (ответил).
7. Собирали **вместе**; дома — каждый делает помощника **своим**.

## Расширенный помощник в коде

```python
def assistant(text):
    t = text.lower()
    if "привет" in t: return "Привет! Чем помочь?"
    if "час" in t or "врем" in t: return f"Сейчас {datetime.datetime.now():%H:%M}"
    if "дата" in t: return f"Сегодня {datetime.datetime.now():%d.%m.%Y}"
    if "посчита" in t or "плюс" in t: return calculate(t)    # действие!
    if "факт" in t: return random.choice(FACTS)
    if "пока" in t: return "__BYE__"
    return "Не понял команду."

# диалог: while True: ... if "пока" in t: break
# голос: voice_assistant(path) = Whisper -> assistant -> gTTS
```

## Шаг 2. Добавляем навыки: дата, факты, шутки (8 минут)

```python
def assistant(text):
    t = text.lower()
    # --- навыки общения ---
    if "привет" in t or "здравств" in t: return "Привет! Чем могу помочь?"
    if "зовут" in t or "имя" in t:       return "Меня зовут Помощник."
    if "спасибо" in t:                   return "Пожалуйста! Обращайся."
    # --- время и дата ---
    if "час" in t or "врем" in t:        return f"Сейчас {datetime.datetime.now():%H:%M}"
    if "дата" in t or "число" in t:      return f"Сегодня {datetime.datetime.now():%d.%m.%Y}"
    # --- факты и шутки ---
    if "факт" in t:                      return random.choice(FACTS)
    if "шутк" in t or "анекдот" in t:    return random.choice(JOKES)
    # --- не понял ---
    return "Извините, я не понял команду."
```

**Проверяем сразу (вместе):**
```python
for q in ["Привет", "Который час", "Какое число", "Расскажи факт", "Расскажи шутку"]:
    print(f"{q:20s} -> {assistant(q)}")
```

> **Каждый навык — отдельная ветка `if`.** Добавили общение, дату, факты, шутки. Помощник уже умеет больше! Заметь: факт и шутка — **случайные** (`random.choice`), каждый раз разные.

## Шаг 3. Добавляем действие: калькулятор (8 минут)

Теперь — навык, который **реально считает**, а не выдаёт заготовку.

```python
def calculate(t):
    nums = [int(n) for n in re.findall(r'\d+', t)]    # вытащить числа из текста
    if len(nums) < 2:
        return "Назови два числа."
    a, b = nums[0], nums[1]
    if "плюс" in t or "сложи" in t or "приба" in t:  return f"{a} плюс {b} равно {a + b}"
    if "минус" in t or "вычти" in t:                 return f"{a} минус {b} равно {a - b}"
    if "умнож" in t:                                 return f"{a} умножить на {b} равно {a * b}"
    return f"Сумма: {sum(nums)}"
```

Добавим вызов калькулятора в `assistant` (перед «не понял»):

**Проверяем (вместе):**
```python
print(calculate("посчитай 7 плюс 5"))      # 7 плюс 5 равно 12
print(calculate("посчитай 10 минус 3"))    # 10 минус 3 равно 7

```

> 🧮 **Помощник научился думать!** Он **извлекает числа** из команды (`re.findall(r'\d+')` находит все цифры) и **реально считает**. Это первый навык с настоящим **действием**, а не заготовленной фразой.

## Шаг 4. Диалог в цикле (10 минут)

Пусть помощник отвечает на команды **по очереди**, пока не скажешь «пока».

```python
def chat():
    print("Помощник готов! (для выхода скажи 'пока')")
    while True:
        command = input("Ты: ")                  # вводим команду текстом
        t = command.lower()
        if "пока" in t or "до свидан" in t:
            print("Помощник: До свидания!")
            break
        print("Помощник:", assistant(command))

# chat()      # запусти и поговори!
```

**Что увидим (пример диалога):**
```
Ты: Привет
Помощник: Привет! Чем могу помочь?
Ты: Посчитай 100 плюс 200
Помощник: 100 плюс 200 равно 300
Ты: Расскажи факт
Помощник: Осьминоги имеют три сердца.
Ты: Пока
Помощник: До свидания!
```

> **Теперь это разговор!** Помощник принимает команды одну за другой в цикле `while`. Команда «пока» **завершает** диалог (`break`) — без неё цикл был бы бесконечным. Пока вводим текстом, чтобы отладить логику; голос подключим на Шаге 6.

## Шаг 5. Устойчивость к формулировкам (5 минут)

Люди говорят по-разному. Сделаем, чтобы помощник ловил **разные** варианты одной команды.

```python
# Уже частично сделано: мы ловим КОРЕНЬ слова, а не точное слово
# "час" ловит "час", "часов"; "врем" ловит "время", "времени"
# Проверим разные формулировки времени:
for q in ["который час", "сколько времени", "время сейчас", "подскажи время"]:
    print(f"{q:22s} -> {assistant(q)}")
```

> **Хитрость:** ловим **корень** слова (`"врем" in t`), а не целое слово. Тогда и «время», и «времени», и «времён» сработают. Плюс несколько ключевых слов через `or`. Так помощник понимает команду в разных формулировках — как настоящий.

## Шаг 6. Голос и полный тест (14 минут)

Подключаем «уши» (Whisper) и «рот» (gTTS) — и тестируем целиком.

```python
def say(text):
    gTTS(text, lang='ru').save("answer.mp3")
    return Audio("answer.mp3", autoplay=True)

def voice_assistant(audio_path):
    text = whisper_model.transcribe(audio_path, language="ru")["text"]   # услышал
    print("🎤 Услышал:", text)
    answer = assistant(text)                                             # понял
    print("🧠 Отвечаю:", answer)
    return say(answer)                                                   # ответил голосом
```

**Готовим команду и запускаем (вместе):**
```python
gTTS("Посчитай пять плюс три", lang='ru').save("cmd.mp3")   # или запиши свой голос
voice_assistant("cmd.mp3")
```

> 🎊 **Наш помощник заговорил и поумнел!** Сказал команду → услышал (Whisper) → понял и **посчитал** (навык) → ответил голосом (gTTS). Это уже не игрушка, а настоящий помощник с навыками, собранный всем классом.
>
> ⚠️ **Честно:** на синтетическом или нечётком голосе Whisper иногда ошибается — тогда навык может не сработать. На чёткой человеческой речи лучше. Числа лучше говорить словами или чётко.

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Осциллограмма** | График звука: X — время, Y — амплитуда |
| **librosa** | Библиотека для работы со звуком |
| **`librosa.load`** | Загрузить звук → массив + sample rate |
| **`waveshow`** | Нарисовать осциллограмму (ось в секундах) |
| **Тембр** | Окраска звука (зависит от формы волны) |
| **Огибающая** | Контур громкости во времени |

---

## Главные мысли

1. Смотреть на тысячи чисел нельзя → звук **рисуют**.
2. **Осциллограмма**: X — время, Y — амплитуда (громкость).
3. Читаем: плоско = тихо, высокие колебания = громко, всплески = слова/ноты.
4. **librosa** — главная библиотека для звука (`load`, `waveshow`).
5. `librosa.load` → массив `y` + `sr` (по умолчанию приводит к 22050 Гц).
6. Тон / шум / музыка выглядят **по-разному** — видно без прослушивания.
7. Форма волны = **тембр** (синус/пила/прямоугольник звучат по-разному).

---

## Рисуем звук в коде

```python
import librosa, librosa.display
import matplotlib.pyplot as plt

y, sr = librosa.load(librosa.ex('trumpet'))    # массив + sample rate
print(len(y)/sr, "сек")                        # длительность

plt.figure(figsize=(12, 3))
librosa.display.waveshow(y, sr=sr)             # осциллограмма
plt.xlabel("Время, с"); plt.ylabel("Амплитуда")
plt.show()
```

## Как читать осциллограмму

| На графике | Звук |
|------------|------|
| Плоско у нуля | тишина / пауза |
| Высокие колебания | громко |
| Низкие колебания | тихо |
| Всплески с паузами | речь (слова) |
| Ноты с затуханием | музыка |
| Ровная полоса | непрерывный тон/гул |

---

## Виды звуков (вид на осциллограмме)

| Звук | Как выглядит |
|------|--------------|
| Чистый тон | ровная плотная полоса |
| Шум | «лохматая» полоса (хаос) |
| Музыка | отдельные ноты, паузы, затухание |
| Речь | всплески слов + паузы |

---

## Главные ошибки

| Ошибка | Как правильно |
|--------|---------------|
| Громкость ≠ высота | осциллограмма = громкость во времени |
| Ждут волну на длинном звуке | для формы — приблизить (срез) |
| Забыли про ресемплинг до 22050 | для исходного sr — `sr=None` |

3. **librosa** загружает и рисует звук.

**Урок 8.3. Спектрограммы и преобразование Фурье «на пальцах».** Будем:
- Понимать: любой звук = **сумма синусоид** разных частот (Фурье на пальцах).
- Строить **спектрограмму** — карту частот во времени.

> Осциллограмма показывает **громкость** во времени, но не **из каких частот** состоит звук. А ведь частоты делают «а» не похожим на «о»! На следующем уроке узнаем главный секрет звука: любой звук — это **сумма синусоид**. И научимся строить **спектрограмму** — самую важную картинку в работе со звуком, на которой видны все частоты. 🚀

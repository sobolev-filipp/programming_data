## Задание 1. Рисуем звук (librosa) (16 минут)

### Что мы хотим сделать

Загрузить реальный звук, узнать его параметры и построить осциллограмму.

### 1.1. Загружаем звук через librosa

```python
path = librosa.ex('trumpet')         # встроенный пример: труба (скачается)
y, sr = librosa.load(path)           # y — массив звука, sr — частота дискретизации

print("Частота дискретизации:", sr)
print("Сколько чисел (отсчётов):", len(y))
print("Длительность:", round(len(y) / sr, 2), "сек")
print("Минимум/максимум:", round(float(y.min()), 2), "/", round(float(y.max()), 2))
print("Тип:", y.dtype)
```

> ### ⏳ Пока качается пример (маленький, пара секунд) — разогрев
> - **🔮 Предскажи:** как, по-твоему, будет выглядеть осциллограмма трубы — ровной полосой или отдельными «нотами» с паузами?
> - **💬 Обсуди:** чем осциллограмма речи будет отличаться от осциллограммы музыки?

**Что увидим:**
```
Частота дискретизации: 22050
Сколько чисел (отсчётов): 117601
Длительность: 5.33 сек
Минимум/максимум: -0.69 / 0.63
Тип: float32
```

> **Что это значит:** truba — это **117 601 число** при 22 050 Гц = **5.33 секунды** звука. Значения — от −0.69 до 0.63 (librosa держит звук в районе −1..1). Это обычный массив, как мы делали в 8.1, только реальный. *(librosa по умолчанию приводит звук к 22 050 Гц — для анализа этого достаточно.)*

### 1.2. Послушаем

```python
Audio(y, rate=sr)            # нажми ▶ — услышишь трубу
```

### 1.3. Строим осциллограмму

```python
plt.figure(figsize=(12, 3))
librosa.display.waveshow(y, sr=sr)        # рисует волну с осью времени в секундах
plt.title("Осциллограмма: труба")
plt.xlabel("Время, с"); plt.ylabel("Амплитуда")
plt.show()
```

**Что увидим:** график, где видны **отдельные ноты** — каждая нота нарастает и затухает, между некоторыми есть паузы. К концу звук затихает (амплитуда падает к нулю).

#### Что это значит

> 🎺 **Вот звук "в лицо"!** На осциллограмме видно структуру мелодии: отдельные ноты как «холмики» громкости, паузы как плоские участки, затухание в конце. Мы **прочитали** музыку, не слыша её, — просто по форме графика. Это и есть сила визуализации: то, что в 117 601 числе не видно, на картинке очевидно.

### 1.4. Приблизим — увидим саму волну

```python
plt.figure(figsize=(12, 3))
plt.plot(y[20000:20400])             # маленький кусочек (≈ 18 миллисекунд)
plt.title("Кусочек волны вблизи (видна форма колебаний)")
plt.show()
```

**Что увидим:** если приблизиться, видно **колебания** волны — повторяющийся узор. Это форма волны трубы (её **тембр**). Не идеальная синусоида — поэтому труба звучит «как труба», а не «пиип».

### Итог Задания 1

1. `librosa.load` дал массив звука `y` + частоту `sr`.
2. Осциллограмма (`waveshow`) показала ноты, паузы, затухание.
3. Вблизи видна форма волны = тембр.

## Задание 2. Разные звуки — разные волны (14 минут)

### Что мы хотим сделать

Построить осциллограммы разных звуков рядом и увидеть, как они **отличаются**.

### 2.1. Готовим три звука

```python
sr = 22050
t = np.linspace(0, 2, sr*2, endpoint=False)

tone  = 0.5 * np.sin(2*np.pi*440*t)        # чистый тон (синусоида)
noise = np.random.uniform(-0.5, 0.5, sr*2) # шум (случайные числа)
music, sr_m = librosa.load(librosa.ex('trumpet'))   # музыка (труба)
```

### 2.2. Рисуем их рядом

```python
fig, axes = plt.subplots(3, 1, figsize=(12, 7))

librosa.display.waveshow(tone, sr=sr, ax=axes[0]);  axes[0].set_title("Чистый тон 440 Гц")
librosa.display.waveshow(noise, sr=sr, ax=axes[1]); axes[1].set_title("Шум")
librosa.display.waveshow(music, sr=sr_m, ax=axes[2]); axes[2].set_title("Музыка (труба)")

plt.tight_layout(); plt.show()
```

**Что увидим:**
- **Тон** — ровная плотная полоса **одинаковой** высоты (громкость постоянна).
- **Шум** — тоже полоса, но «лохматая», беспорядочная.
- **Музыка** — **отдельные ноты** с нарастанием, затуханием и паузами.

#### Что это значит

> Три звука — **три разных портрета**! Тон ровный (постоянная громкость), шум хаотичный, музыка структурная (ноты). По осциллограмме легко **отличить** их, даже не слушая. А если послушать (`Audio`) — увидишь, что картинка совпадает с тем, что слышишь.

### 2.3. Послушаем и сравним

```python
print("Тон:");   display(Audio(tone, rate=sr))
print("Шум:");   display(Audio(noise, rate=sr))
print("Музыка:"); display(Audio(music, rate=sr_m))
```

> 🎧 Слушай и смотри на графики одновременно: ровный график → ровный звук; хаотичный → шипение; структурный → мелодия. **Глаза и уши согласны!**

### Итог Задания 2

1. Тон, шум и музыка выглядят **по-разному** на осциллограмме.
2. По графику можно **отличить** тип звука, не слушая.
3. Картинка совпадает с тем, что слышим.

## Шпаргалка (из практики)

```python
import librosa, librosa.display
import matplotlib.pyplot as plt

y, sr = librosa.load(librosa.ex('trumpet'))   # массив + sample rate
librosa.display.waveshow(y, sr=sr)            # осциллограмма
plt.show()
len(y) / sr                                   # длительность в секундах
```

Встроенные примеры librosa: `'trumpet'` (труба, ~5 с), `'brahms'` (~46 с), `'nutcracker'` (~2 мин).

## Задание 1. Звук — это массив чисел (16 минут)

### Что мы хотим сделать

Сделать звук **из чисел** (синусоиду — чистый тон), сохранить в WAV, загрузить и убедиться, что аудио — это массив.

### 1.1. Создаём звук из чисел

```python
sample_rate = 44100        # частота дискретизации: 44100 замеров в секунду
duration = 2.0             # длительность звука, секунды
frequency = 440            # частота звука, Гц (нота «Ля»)

# Моменты времени: 44100*2 точек от 0 до 2 секунд
t = np.linspace(0, duration, int(sample_rate * duration), endpoint=False)

# Сама волна — синусоида. Это и есть звук в виде чисел!
wave = np.sin(2 * np.pi * frequency * t)

print("Сколько чисел в звуке:", len(wave))     # 88200
print("Первые 5 чисел:", wave[:5].round(3))
```

**Что произошло по шагам:**
- `t` — моменты времени (88 200 точек за 2 секунды).
- `np.sin(2*np.pi*frequency*t)` — значение волны в каждый момент. Это формула синусоиды (не пугайся: `2*pi*частота*время` — стандартная запись «как быстро крутится волна»).
- `wave` — массив из 88 200 чисел. **Это звук!**

**Что увидим:**
```
Сколько чисел в звуке: 88200
Первые 5 чисел: [0.    0.063 0.125 0.187 0.248]
```

> **Вот оно:** звук — это **массив чисел**. Числа плавно растут и падают (синусоида колеблется от −1 до 1). 88 200 чисел = 44 100 в секунду × 2 секунды. Мы сделали звук **из формулы**!

### 1.2. Слушаем наш звук! 🔊

```python
Audio(wave, rate=sample_rate)        # появится кнопка ▶ — нажми!
```

> 🎧 **Нажми play — услышишь ровный тон «пиип» (нота Ля).** Этот звук родился из чисел `np.sin`! Вот доказательство, что звук = числа: мы их придумали — и они зазвучали.

### 1.3. Сохраняем в WAV и загружаем обратно

```python
# Для WAV числа должны быть целыми (int16). Переводим: -1..1  →  -16000..16000
audio_int = (wave * 16000).astype(np.int16)
wavfile.write("my_tone.wav", sample_rate, audio_int)   # сохранили файл
print("Файл my_tone.wav сохранён!")

# Загружаем обратно
sr, data = wavfile.read("my_tone.wav")
print("Частота дискретизации:", sr)
print("Тип чисел:", data.dtype)
print("Форма (сколько чисел):", data.shape)
print("Длительность:", round(len(data) / sr, 2), "сек")
print("Первые 8 чисел:", data[:8].tolist())
```

**Что увидим:**
```
Частота дискретизации: 44100
Тип чисел: int16
Форма (сколько чисел): (88200,)
Длительность: 2.0 сек
Первые 8 чисел: [0, 1002, 2000, 2991, 3970, 4933, 5877, 6798]
```

#### Что это значит

> **WAV = частота дискретизации + массив чисел.** Загрузив файл, мы получили:
> - `sr = 44100` — столько замеров в секунду,
> - `data` — массив из **88 200** чисел (это и есть звук),
> - первые числа растут от 0 (синусоида стартует с нуля и идёт вверх).
>
> Никакой магии: открыл WAV — получил массив, как любой другой в NumPy. Дальше со звуком можно делать что угодно.

### 1.4. Рисуем кусочек волны

```python

plt.plot(data[:500])              # первые 500 чисел (≈ 11 миллисекунд)

plt.xlabel("Номер отсчёта"); plt.ylabel("Амплитуда")
```

**Что увидим:** красивую **синусоиду** — волну, которая плавно колеблется вверх-вниз. Это «портрет» нашего звука.

## Задание 2. Частота и громкость (14 минут)

### Что мы хотим сделать

Понять разницу: **частота** меняет высоту звука, **амплитуда** — громкость.

### 2.1. Разная частота = разная высота

```python
def make_tone(freq, duration=1.0, sr=44100):
    t = np.linspace(0, duration, int(sr*duration), endpoint=False)
    return np.sin(2 * np.pi * freq * t)

# Низкий, средний, высокий тон
for freq in [220, 440, 880]:
    print(f"Частота {freq} Гц:")
    display(Audio(make_tone(freq), rate=44100))    # послушай каждый!
```

> 🎧 **Слушай по очереди:** 220 Гц — низкий тон, 440 Гц — средний (Ля), 880 Гц — высокий. Чем **больше** частота, тем **выше** звук. Заметь: 880 — это ровно вдвое больше 440, и звучит как «та же нота, но октавой выше».

### 2.2. Смотрим, почему: частая волна vs редкая

```python
plt.figure(figsize=(12, 3))
plt.plot(make_tone(220)[:500], label="220 Гц (низкий)")
plt.plot(make_tone(440)[:500], label="440 Гц (выше)")
plt.legend(); plt.title("Чем выше частота, тем чаще колеблется волна")
plt.show()
```

**Что увидим:** волна 440 Гц колеблется **в 2 раза чаще**, чем 220 Гц (за тот же отрезок укладывается вдвое больше «горбиков»). Частота = как часто колеблется = высота звука.

### 2.3. Разная амплитуда = разная громкость

```python
quiet = 0.2 * make_tone(440)      # маленькая амплитуда — тихо
loud  = 0.9 * make_tone(440)      # большая амплитуда — громко

print("Тихий звук (амплитуда 0.2):"); display(Audio(quiet, rate=44100))
print("Громкий звук (амплитуда 0.9):"); display(Audio(loud, rate=44100))
print("Размах тихого:", round(quiet.max() - quiet.min(), 2))
print("Размах громкого:", round(loud.max() - loud.min(), 2))
```

**Что увидим и услышим:**
```
Размах тихого:  0.4
Размах громкого: 1.8
```
> 🎧 Второй звук **громче** — у него больше **амплитуда** (размах волны). Частота **та же** (та же нота Ля), меняется только громкость. Вот разница: **частота → высота**, **амплитуда → громкость**.

### Итог Задания 2

1. **Частота** (Гц) → высота звука: больше частота = выше тон.
2. **Амплитуда** (размах) → громкость: больше размах = громче.
3. Это два **разных** свойства звука — мы услышали оба.

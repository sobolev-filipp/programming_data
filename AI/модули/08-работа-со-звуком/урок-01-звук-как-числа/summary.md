# Урок 8.1. Звук как массив чисел — резюме

---

## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Звуковая волна** | Колебания воздуха, которые мы слышим |
| **Амплитуда** | Размах волны → **громкость** |
| **Частота звука** | Как часто колеблется → **высота** (Гц) |
| **Частота дискретизации** | Сколько замеров в секунду (sample rate, Гц) |
| **Отсчёт (сэмпл)** | Одно измерение = одно число в массиве |
| **WAV** | Формат: sample rate + массив чисел (без сжатия) |

---

## Главные мысли

1. Звук — это **волна** (колебания воздуха), меняется во времени.
2. Для компьютера звук = **массив чисел** (замеры волны).
3. **Частота дискретизации** — сколько замеров в секунду (44 100 Гц = CD).
4. За 2 секунды при 44 100 Гц → 88 200 чисел.
5. **WAV** = sample rate + массив чисел.
6. **Частота** → высота звука; **амплитуда** → громкость. Это разные вещи!
7. Звук можно сделать из чисел (`np.sin`) и послушать.

---

## Звук в коде

```python
import numpy as np
from scipy.io import wavfile
from IPython.display import Audio

sr = 44100                                   # замеров в секунду
t = np.linspace(0, 2, sr*2, endpoint=False)  # моменты времени
wave = np.sin(2*np.pi*440*t)                 # тон 440 Гц (нота Ля) — это звук!

Audio(wave, rate=sr)                         # послушать
wavfile.write("tone.wav", sr, (wave*16000).astype(np.int16))  # сохранить
sr2, data = wavfile.read("tone.wav")         # загрузить → массив чисел
```

---

## Два «герца» — не путать!

| | Частота дискретизации | Частота звука |
|--|----------------------|---------------|
| Что | замеров в секунду | как часто колеблется волна |
| Влияет на | **качество** записи | **высоту** звука |
| Пример | 44 100 Гц (CD) | 440 Гц (нота Ля) |

---

## Частота vs Амплитуда

| Свойство | Меняет | Пример |
|----------|--------|--------|
| **Частота** | высоту (низко/высоко) | 880 Гц выше, чем 440 |
| **Амплитуда** | громкость (тихо/громко) | ×0.9 громче, чем ×0.2 |

---

## Главные ошибки

| Ошибка | Как правильно |
|--------|---------------|
| Путают sample rate и частоту звука | замеры/сек vs высота |
| Путают амплитуду и частоту | громкость vs высота |
| Не перевели в int16 для WAV | `(wave*16000).astype(np.int16)` |
| Забыли `rate=sr` в Audio | звук на неверной скорости |

---

## Что должно остаться в голове после урока

1. Звук = **массив чисел** (замеры волны во времени).
2. **Sample rate** — сколько замеров в секунду.
3. Длительность = число отсчётов ÷ sample rate.
4. **Частота** → высота, **амплитуда** → громкость.
5. WAV = sample rate + массив; легко загрузить в NumPy.

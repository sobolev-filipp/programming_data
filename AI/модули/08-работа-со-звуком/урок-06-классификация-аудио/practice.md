## Задание 1. Превращаем звуки в картинки (14 минут)

### Что мы хотим сделать

Построить спектрограммы разных команд и убедиться, что они **выглядят по-разному**.

### 1.1. Функция: звук → мел-спектрограмма

```python
def make_spectrogram(path, sr=16000, n_mels=64, T=32):
    y, _ = librosa.load(path, sr=sr)            # загрузить звук (16 кГц)
    y = np.pad(y, (0, max(0, sr - len(y))))[:sr]  # привести к 1 секунде
    S = librosa.feature.melspectrogram(y=y, sr=sr, n_mels=n_mels)  # мел-спектрограмма
    S = librosa.power_to_db(S, ref=np.max)      # в децибелы
    S = np.pad(S, ((0,0),(0,max(0,T-S.shape[1]))))[:, :T]   # фикс. ширина
    return (S + 40) / 40.0                       # грубая нормализация
```

> **Каждый звук → картинка фиксированного размера 64×32.** CNN нужны картинки **одного** размера, поэтому приводим звук к 1 секунде, а спектрограмму — к форме 64×32 (как в 7.4 с padding).

### 1.2. Смотрим спектрограммы 4 команд

```python
words = ['yes', 'no', 'up', 'down']
```

**Что увидим:** четыре **разные** картинки. У «yes», «no», «up», «down» — разный узор: звук идёт в разное время, с разными частотами. Глазами видно, что они отличаются!

> 👀 **Вот ключ к классификации:** разные слова дают **разные спектрограммы**. А раз картинки разные — CNN сможет их различить, как различала кошек и собак. Звук стал задачей компьютерного зрения!

## Задание 2. Обучаем CNN различать команды (20 минут)

### Что мы хотим сделать

Собрать датасет спектрограмм, построить CNN и обучить её классифицировать команды.

### 2.1. Готовим данные (спектрограммы + метки)

```python
words = ['yes', 'no', 'up', 'down']     # 4 команды
N = 300                                  # записей на класс (для скорости на CPU)

X, Y = [], []
for label, w in enumerate(words):
    for f in sorted(glob.glob(f"{base}/{w}/*.wav"))[:N]:
        X.append(make_spectrogram(f)); Y.append(label)

X = np.array(X, dtype=np.float32)[:, None, :, :]   # (n, 1, 64, 32) — как картинки!
Y = np.array(Y)
print("Данные:", X.shape, "| классы:", words)

# Перемешать и разделить train/test
idx = np.random.permutation(len(X)); X, Y = X[idx], Y[idx]
n = int(0.8*len(X))
Xtr, Ytr = torch.tensor(X[:n]), torch.tensor(Y[:n])
Xte, Yte = torch.tensor(X[n:]), torch.tensor(Y[n:])
print("Train/test:", len(Xtr), len(Xte))
```

**Что увидим:**
```

Train/test: 960 240
```

> Спектрограммы сложились в массив формы **(1200, 1, 64, 32)** — это **1200 картинок** 64×32 с 1 каналом. Точь-в-точь как набор фото в Модуле 6!

### 2.2. Собираем CNN (как в Модуле 6)

```python
class AudioCNN(nn.Module):
    def __init__(self, n_classes):
        super().__init__()
        self.conv1 = nn.Conv2d(1, 16, 3, padding=1)
        self.conv2 = nn.Conv2d(16, 32, 3, padding=1)
        self.pool = nn.MaxPool2d(2)
        self.fc1 = nn.Linear(32 * 16 * 8, 64)    # 64→32→16, 32→16→8
        self.fc2 = nn.Linear(64, n_classes)
    def forward(self, x):
        x = self.pool(torch.relu(self.conv1(x)))   # 64×32 → 32×16
        x = self.pool(torch.relu(self.conv2(x)))   # 32×16 → 16×8
        x = x.reshape(x.size(0), -1)
        x = torch.relu(self.fc1(x))
        return self.fc2(x)

net = AudioCNN(len(words))
print(net)
```

> **Это та же CNN, что в Модуле 6!** Conv → Pool → Conv → Pool → Linear. Единственное отличие — вход 1×64×32 (спектрограмма) вместо 3×32×32 (фото CIFAR). Сеть не знает, что это звук.

### 2.3. Обучаем

```python
from torch.utils.data import TensorDataset, DataLoader
loader = DataLoader(TensorDataset(Xtr, Ytr), batch_size=32, shuffle=True)

loss_fn = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(net.parameters(), lr=0.001)

for epoch in range(8):
    net.train()
    for xb, yb in loader:
        optimizer.zero_grad()
        loss = loss_fn(net(xb), yb)
        loss.backward(); optimizer.step()
    net.eval()
    with torch.no_grad():
        acc = (net(Xte).argmax(1) == Yte).float().mean().item()
    print(f"Эпоха {epoch+1}: точность {acc:.3f}")
```

> ### ⏳ Пока сеть учится (на CPU — секунды!) — не сидим без дела

> - **💬 Обсуди:** почему сеть из Модуля 6 (для фото) работает и со звуком? *(спектрограмма — картинка!)*

#### Что это значит

> ⚠️ **Честно:** точность немного «скачет» по эпохам (мало данных и эпох) — это нормально. На полном датасете, с большим числом записей и эпох, точность выше. Но даже на подвыборке видно: **работает!**

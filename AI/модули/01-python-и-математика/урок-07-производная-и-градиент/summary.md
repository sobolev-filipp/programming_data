## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Функция** | «Машинка»: принимает число, возвращает число. |
| **Производная** | Скорость изменения функции в точке. |
| **Касательная** | Прямая, «касающаяся» графика в точке. Её наклон = производная. |
| **f'(x) или df/dx** | Обозначения производной. |
| **Частная производная** | Производная по одной из переменных, другие — заморожены. |
| **Градиент (∇f)** | Вектор частных производных. Указывает «в гору». |
| **Антиградиент** | Минус градиент. Указывает «вниз». |
| **Градиентный спуск** | Алгоритм: шагать в сторону антиградиента, чтобы попасть в минимум. |
| **Learning rate (η)** | Размер шага в градиентном спуске. |
| **Локальный минимум** | Минимум в окрестности точки, не обязательно глобальный. |
| **Loss / функция ошибки** | Функция, которую мы минимизируем при обучении модели. |

---

## Главные мысли

1. **Производная = скорость изменения функции.** Аналогия — физическая скорость.
2. **Геометрически — наклон касательной.** Где функция растёт — производная +, где убывает — −.
3. **В точке экстремума (max/min) производная = 0.**
4. **Градиент = производная для функций многих переменных.** Указывает в сторону максимального роста.
5. **Градиентный спуск:** `x_new = x_old - lr · grad`. Так обучаются все нейросети.

## Численная производная

```python
def derivative(f, x, h=1e-4):
    return (f(x + h) - f(x - h)) / (2 * h)
```

**Применение:**
```python
def f(x):
    return x ** 2

derivative(f, 5)        # ~10
```

Можно передавать массив:
```python
xs = np.linspace(-5, 5, 100)
dys = derivative(f, xs)        # массив производных
```

## Численный градиент

```python
def numerical_gradient(f, point, h=1e-4):
    grad = np.zeros_like(point)
    for i in range(len(point)):
        p_plus = point.copy()
        p_minus = point.copy()
        p_plus[i] += h
        p_minus[i] -= h
        grad[i] = (f(p_plus) - f(p_minus)) / (2 * h)
    return grad
```

---

## Градиентный спуск — алгоритм

```
1. Выбрать стартовую точку.
2. Посчитать градиент.
3. point = point - lr * grad
4. Повторять, пока не сошлись.
```

```python
point = np.array([5.0, 7.0])
lr = 0.1
for _ in range(50):
    grad = numerical_gradient(f, point)
    point = point - lr * grad
```

## Learning rate — главная настройка

| Размер `lr` | Что произойдёт |
|------------|----------------|
| **Слишком большой** | Точка «пролетает» минимум, алгоритм **расходится** |
| **Хороший** | Плавно сходится к минимуму |
| **Слишком маленький** | Сходится, но очень медленно |

**Типичные значения:** 0.1, 0.01, 0.001. Подбираются экспериментально.

## Простые правила производных (для справки)

| f(x) | f'(x) |
|------|-------|
| с (константа) | 0 |
| x | 1 |
| x² | 2x |
| x³ | 3x² |
| xⁿ | n · xⁿ⁻¹ |
| sin x | cos x |
| cos x | −sin x |
| eˣ | eˣ |
| ln x | 1/x |

Производная **суммы** = сумма производных. **Константу** выносим.

## Главные ошибки

| Ошибка | Что не так | Как исправить |
|--------|-----------|---------------|
| `point + lr * grad` | Со знаком + спускаешься **вверх** | Минус: `point - lr * grad` |
| Слишком большой `lr` | Расходится | Уменьшить в 10 раз |
| `h = 1e-15` в `derivative` | Float портит точность | `h = 1e-4` или `1e-5` |
| Не различают `grad` и `np.linalg.norm(grad)` | Длина — это число, сам grad — вектор | Подсветить разницу |
| Думают, что градиентный спуск всегда находит глобальный минимум | Нет — только локальный | Помнить про двугорбые функции |

## Где это в нейросетях

- **Параметры** нейросети (миллионы или миллиарды весов) — это точка в пространстве.
- **Функция ошибки (loss)** — то, что минимизируем.
- **Один шаг обучения** = один шаг градиентного спуска.
- **Эпоха** = проход по всем данным = много шагов.
- **Backpropagation** = эффективный способ посчитать градиент в нейросети. К Модулю 5.

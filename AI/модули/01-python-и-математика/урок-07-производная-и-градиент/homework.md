## Шпаргалка для быстрого старта

```python
import numpy as np

# Численная производная (1D)
def derivative(f, x, h=1e-4):
    return (f(x + h) - f(x - h)) / (2 * h)

# Численный градиент (multi-D)
def numerical_gradient(f, point, h=1e-4):
    grad = np.zeros_like(point)
    for i in range(len(point)):
        p_plus = point.copy()
        p_minus = point.copy()
        p_plus[i] += h
        p_minus[i] -= h
        grad[i] = (f(p_plus) - f(p_minus)) / (2 * h)
    return grad

# Градиентный спуск
point = np.array([5.0, 7.0])    # стартовая точка
lr = 0.1                         # learning rate
for _ in range(50):
    grad = numerical_gradient(f, point)
    point = point - lr * grad    # минус!
```

## Уровень 1. Производная

### 1.1. Производные в разных точках

> **Что от тебя требуется:** для функции `f(x) = 2x³ - 5x + 1` посчитать производную в 4 точках и сделать вывод о монотонности.

**Шаг 1: определи функцию**
```python
def f(x):
    return 2 * x**3 - 5 * x + 1
```

**Шаг 2: посчитай производную в `x = 0, 1, 2, -1`**
```python
for x in [0, 1, 2, -1]:
    d = derivative(f, x)
    print(f"x = {x}: f'(x) ≈ {d:.4f}")
```

**Шаг 3: где функция растёт? Где убывает?**

> **Подсказка по интерпретации:**
> - `f'(x) > 0` → функция **растёт** в этой точке.
> - `f'(x) < 0` → **убывает**.
> - `f'(x) = 0` → точка **экстремума** (макс или мин).

**Ожидаемое:**
```
x = 0:  f'(x) ≈ -5      (убывает)
x = 1:  f'(x) ≈ 1       (растёт)
x = 2:  f'(x) ≈ 19      (растёт круто)
x = -1: f'(x) ≈ 1       (растёт)
```

> **Что заметить:** между x=0 (где -5) и x=1 (где +1) производная **меняет знак**. Значит, **между ними есть локальный минимум** функции.

### 2.1. Градиент функции двух переменных

> **Что от тебя требуется:** найти градиент `f(p) = p[0]² + 3·p[1]²` в нескольких точках.

**Шаг 1: определи функцию**
```python
def f(p):
    return p[0]**2 + 3 * p[1]**2
```

**Шаг 2: посчитай градиент в 4 точках**
```python
points = [
    np.array([1.0, 1.0]),
    np.array([2.0, 0.0]),
    np.array([0.0, 2.0]),
    np.array([3.0, 4.0]),
]

for p in points:
    g = numerical_gradient(f, p)
    length = np.linalg.norm(g)
    print(f"Точка {p}: градиент {g}, длина {length:.3f}")
```

> **Подсказка по проверке:** аналитически градиент `∇f = [2x, 6y]` (производная по x — `2x`, по y — `6y`).
> - В (1, 1) → `[2, 6]`, длина ~6.32.
> - В (2, 0) → `[4, 0]`, длина 4.
> - В (0, 2) → `[0, 12]`, длина 12.
> - В (3, 4) → `[6, 24]`, длина ~24.7.

**Вопросы:**

1. **В какой точке длина градиента самая большая?**
   *Подсказка:* сравни числа.

2. **Каков градиент в точке (0, 0)?**
   *Подсказка:* в **минимуме** градиент `[0, 0]`.

### 2.2. Градиентный спуск со старта

> **Что от тебя требуется:** запустить градиентный спуск для функции из 2.1, начиная с точки (10, 10).

**Полный код:**
```python
def f(p):
    return p[0]**2 + 3 * p[1]**2

point = np.array([10.0, 10.0])    # старт
lr = 0.1                           # learning rate
n_steps = 50

for step in range(n_steps):
    grad = numerical_gradient(f, point)
    point = point - lr * grad
    if step % 10 == 0:
        print(f"Шаг {step}: точка = {point}, f = {f(point):.4f}")

print(f"\nИтог: {point}, f = {f(point):.6f}")
```

> **Подсказка по запуску:** если точка **«убегает»** (значения растут) — у тебя **плюс** вместо минуса в `point = point - lr * grad`. Проверь!

**Бонус: добавь условие выхода, когда `f(point) < 0.01`:**
```python
point = np.array([10.0, 10.0])
lr = 0.1

for step in range(1000):
    grad = numerical_gradient(f, point)
    point = point - lr * grad
    if f(point) < 0.01:
        print(f"Достигли f < 0.01 на шаге {step}")
        break
```

> **Что от тебя требуется:** показать, что **градиентный спуск находит ЛОКАЛЬНЫЙ минимум**, не обязательно глобальный.

**Дано:**
```python
def f(x):
    return x**4 - 4*x**2 + 2
```

Это «двугорбая» функция: два минимума и один локальный максимум.

**Шаг 1: построй график**
```python
xs = np.linspace(-3, 3, 200)
ys = f(xs)
plt.plot(xs, ys)
plt.grid()
plt.title("Двугорбая функция")
plt.show()
```

**Шаг 2: реализуй градиентный спуск для 1D**
```python
def gd_1d(f, start, lr=0.1, n_steps=100):
    x = float(start)
    for _ in range(n_steps):
        d = derivative(f, x)
        x = x - lr * d
    return x
```

**Шаг 3: запусти с трёх разных стартов**
```python
print(gd_1d(f, start=2.0))      # ожидаемое: ~1.414 (правый минимум)
print(gd_1d(f, start=-2.0))     # ~-1.414 (левый минимум)
print(gd_1d(f, start=0.01))     # уйдёт в правый
```

> **Главный вывод:** **с разных стартов → разные минимумы**. Это **классическая проблема ML**. На неё мы вернёмся в Модуле 5 (нейросети).

### 3.3. Найти минимум функции потерь (мини-ML!)

> **Что от тебя требуется:** **впервые обучить модель!** Найти `w`, при котором модель `y = w·x` лучше всего предсказывает данные.

**Дано — модель и данные:**
```python
def predict(w, x):
    return w * x

x_data = np.array([1, 2, 3, 4, 5])
y_data = np.array([2.1, 3.9, 6.0, 7.8, 10.2])
```

> **Заметь:** данные похожи на `y ≈ 2x` (с небольшим шумом). Идеальный `w` около 2.

**Функция потерь (loss):**
```python
def loss(w):
    predictions = predict(w, x_data)
    return ((predictions - y_data) ** 2).sum()
```

> **Подсказка:** loss — это **сумма квадратов отклонений** предсказания от правильного ответа. Чем меньше — тем лучше.

**Шаг 1: посчитай loss для нескольких w**
```python
for w in [0, 1, 2, 3, 4]:
    print(f"w = {w}: loss = {loss(w):.4f}")
```

> **Что должно получиться:** минимальный loss при `w = 2` — это и есть правильный ответ.

**Шаг 2: запусти градиентный спуск, чтобы НАЙТИ `w` сам**
```python
w = 0.0
lr = 0.01
for step in range(100):
    d_w = derivative(loss, w)
    w = w - lr * d_w
    if step % 10 == 0:
        print(f"Шаг {step}: w = {w:.4f}, loss = {loss(w):.4f}")

print(f"\nИтог: w = {w:.4f}")
```

> **Ожидаемое:** `w ≈ 2.0`.

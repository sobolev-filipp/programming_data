## Шпаргалка (готовые инструменты — просто используй)

```python
import numpy as np

def derivative(f, x, h=1e-4):
    return (f(x + h) - f(x - h)) / (2 * h)

def numerical_gradient(f, point, h=1e-4):
    grad = np.zeros_like(point)
    for i in range(len(point)):
        p_plus = point.copy(); p_minus = point.copy()
        p_plus[i] += h; p_minus[i] -= h
        grad[i] = (f(p_plus) - f(p_minus)) / (2 * h)
    return grad

# градиентный спуск
point = np.array([5.0, 7.0]); lr = 0.1
for _ in range(50):
    grad = numerical_gradient(f, point)
    point = point - lr * grad    # МИНУС!
```

### 3.3. ⭐ Обучи свою первую модель!

Это кульминация. Найдём `w`, при котором `y = w·x` лучше всего описывает данные, — то есть **обучим модель**.

```python
def predict(w, x):
    return w * x

x_data = np.array([1, 2, 3, 4, 5])
y_data = np.array([2.1, 3.9, 6.0, 7.8, 10.2])   # похоже на y ≈ 2x + шум

def loss(w):
    predictions = predict(w, x_data)
    return ((predictions - y_data) ** 2).sum()
```

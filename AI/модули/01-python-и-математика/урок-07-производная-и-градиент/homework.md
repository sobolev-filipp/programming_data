## Уровень 3. Со звёздочкой

### 3.1. Минимум функции с «трещиной»

```python
def f(x):
    return x**4 - 4*x**2 + 2
```

Это «двугорбая» функция: два минимума и один локальный максимум.

1. Построй график на `x ∈ [-3, 3]`.
2. Запусти градиентный спуск **со старта = 2.0** — в какой минимум придёт?
3. Запусти со старта `-2.0` — в какой минимум придёт?
4. Запусти со старта `0.01` — куда?

**Вывод:** градиентный спуск находит **локальный** минимум, не обязательно глобальный. Это **классическая** проблема в ML.

### 3.2. Подбор learning rate

3. Алгоритм сходится **очень медленно** (за 1000 шагов не доходит до `< 0.1`).

Распечатай свои подобранные значения.

### 3.3. Найти минимум функции потерь (мини-ML)

У нас есть «модель»:
```python
def predict(w, x):
    return w * x

# Данные: вход x, целевой ответ y
x_data = np.array([1, 2, 3, 4, 5])
y_data = np.array([2.1, 3.9, 6.0, 7.8, 10.2])
```

«Идеальный» `w` — это что-то около 2 (потому что данные похожи на `y = 2x`).

Функция ошибки (loss): сумма квадратов отклонений.
```python
def loss(w):
    predictions = predict(w, x_data)
    return ((predictions - y_data) ** 2).sum()
```

1. Посчитай loss для `w = 0, 1, 2, 3, 4`. В каком `w` он минимален?
2. Запусти градиентный спуск:
   - старт `w = 0`, `lr = 0.01`, `n_steps = 100`.
   - Куда пришёл `w`?
3. **Это и есть обучение модели!** Поздравь себя.

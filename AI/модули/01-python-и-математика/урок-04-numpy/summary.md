## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Массив (array)** | «Вагон» из чисел одного типа. По сути — Python-список из чисел. |
| **Вектор** | То же самое, что одномерный массив. Слово из математики. |
| **Матрица** | Таблица чисел. Двумерный массив. Пример — классный журнал. |
| **Тензор** | Обобщение: массив любой размерности. 0D = число, 1D = вектор, 2D = матрица, 3D = «куб» и т.д. |
| **Скаляр** | Просто одно число (не массив). |
| **`ndarray`** | Так называется тип данных NumPy-массива. |
| **Форма (`shape`)** | Кортеж с размерами по каждому измерению. Например, `(3, 4)` — 3 строки, 4 столбца. |
| **Векторизация** | Операция на всём массиве сразу, без `for`. |
| **Broadcasting** | Способность NumPy делать операции между массивами разной формы. |
| **Агрегация** | Операция, схлопывающая массив в одно число или меньший массив (sum, mean, ...). |
| **Ось (`axis`)** | Направление в массиве. У матрицы две оси: «вертикаль» (0) и «горизонталь» (1). |
| **Среднее** | Сумма чисел поделить на их количество. |
| **Дисперсия (`.var()`)** | Мера «разброса» чисел от среднего. = среднее квадратов отклонений. |
| **Стандартное отклонение (`.std()`)** | Квадратный корень из дисперсии. Удобнее для интуиции. |
| **Центрирование** | Вычитание среднего из каждого числа. После — среднее становится 0. |
| **Нормальное распределение** | «Колоколообразное» распределение чисел: большинство близко к среднему, далеко — редко. |
| **Маска (булева маска)** | Массив `True`/`False`. Используется для фильтрации. |

---

## Главные мысли

1. NumPy быстрее списков Python в **десятки раз** на больших данных.
2. `ndarray` — это **однотипный** массив фиксированной формы. Свойства: `shape`, `dtype`, `ndim`, `size`.
3. **Векторизация** = операция на всём массиве без `for`. Главное преимущество.
4. **Broadcasting** = операции между массивами разной формы (если формы совместимы).
5. **`axis`** в агрегациях: `axis=0` схлопывает строки → остаются столбцы. `axis=1` — наоборот.

## Создание массивов

```python
np.array([1, 2, 3])                  # из списка
np.array([[1, 2], [3, 4]])           # из вложенного списка → матрица

np.zeros(5)                          # [0 0 0 0 0]
np.ones((3, 4))                      # матрица 3×4 единиц
np.full((2, 3), 7)                   # матрица из семёрок

np.arange(10)                        # [0 1 2 ... 9]
np.arange(0, 1, 0.1)                 # дробный шаг
np.linspace(0, 1, 5)                 # 5 равноудалённых точек [0..1]

np.random.rand(5)                    # 5 случайных [0,1)
np.random.randint(0, 10, 5)          # 5 целых [0,10)
np.random.seed(42)                   # фиксация результата
```

## Свойства массива

```python
a.shape       # форма (кортеж)
a.dtype       # тип данных (int64, float64, ...)
a.ndim        # сколько измерений
a.size        # сколько всего элементов
```

## Индексация

```python
a[0]              # одномерный
a[-1]
a[1:4]
a[::-1]           # реверс

m[i, j]           # двумерный: строка i, столбец j
m[i]              # i-я строка
m[:, j]           # j-й столбец
m[0:2, 1:3]       # подматрица

# Булева
a[a > 5]          # элементы где условие истинно
m[m > 0] = 0      # изменить только нужные

# Комбинация условий — & | ~ (НЕ and/or/not!)
a[(a > 3) & (a < 8)]
```

---

## Векторизация

```python
a + 10           # +10 к каждому
a * 2
a ** 2
a + b            # поэлементно (если форма совпадает)

np.sqrt(a)
np.log(a)
np.exp(a)
np.abs(a)
```

---

## Broadcasting

```python
a + 5             # скаляр + массив (расширяется)
m + row           # матрица + вектор-строка
m + col           # матрица + вектор-столбец

# Правило: формы совместимы, если справа налево
# размеры равны ИЛИ один из них = 1
```

---

## Агрегации

```python
a.sum()
a.mean()
a.std()
a.min() / a.max()
a.argmin() / a.argmax()   # индекс минимума/максимума

# В 2D — axis
m.sum(axis=0)     # сумма по столбцам — остаётся строка
m.sum(axis=1)     # сумма по строкам   — остаётся столбец
m.mean(axis=0)
```

---

## Reshape

```python
a.reshape(3, 4)         # форма (3, 4)
a.reshape(2, -1)        # NumPy сам посчитает второе измерение
a.flatten()             # развернуть в 1D
```

## Главные ошибки

| Ошибка | Что не так | Как исправить |
|--------|-----------|---------------|
| `m[1][2]` | Работает, но медленно и неуклюже | `m[1, 2]` |
| `a > 5 and a < 10` | `and` не работает на массивах! | `(a > 5) & (a < 10)` |
| `m + row` где формы несовместимы | ValueError | Проверить `.shape`, использовать `reshape` |
| `a.sum` (без скобок) | Это метод, без `()` он не вызывается | `a.sum()` |
| Забыли `axis` | Получишь скаляр вместо вектора | Дописать `axis=0` или `axis=1` |

## Уровень 2. Связки

### 2.1. Статистика по таблице

Создай матрицу 5×3 случайных целых чисел от 50 до 100 (используй `np.random.randint`).
Считай, что это: 5 учеников × 3 предмета.

Найди и распечатай:
1. Средний балл каждого ученика.
2. Средний балл по каждому предмету.
3. Самого сильного ученика (по среднему).
4. Самый сложный предмет (по среднему).
5. Сколько отличников (среднее >= 90)?

### 2.2. Нормализация по столбцам

Создай матрицу 4×3 со случайными числами от 0 до 100.

Сделай **нормализацию по столбцам**: для каждого столбца вычти его минимум и поделили на (max − min). Так чтобы каждый столбец стал в диапазоне [0, 1].

Подсказка:
```python
m_norm = (m - m.min(axis=0)) / (m.max(axis=0) - m.min(axis=0))
```

Проверь: `m_norm.min(axis=0)` должно быть `[0, 0, 0]`, `m_norm.max(axis=0)` — `[1, 1, 1]`.

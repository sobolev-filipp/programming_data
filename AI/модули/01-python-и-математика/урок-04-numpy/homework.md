## Шпаргалка

```python
import numpy as np
np.array([1,2,3]) / np.zeros(5) / np.ones((3,4)) / np.arange(10) / np.linspace(0,1,12)
a.shape, a.dtype, a.size
a[1:4]           # срез 1D
m[i, j] / m[:, 0]  # 2D: элемент / столбец
a[a > 5]         # булева маска
a + 10, a * 2, np.sqrt(a)   # векторизация
m.sum(axis=0)    # по столбцам   |   m.sum(axis=1)  # по строкам
a.reshape(3, 4)
```

## 🟢 Уровень 1 — базовый (создание, срезы, векторизация)

**1. Числа по порядку.** Создай массив `a` из всех целых от 1 до 20 (и 20 тоже!). Выведи его, а ещё `a.shape`, `a.dtype`, `a.size`.
> 💡 Функция-счётчик даёт «1, 2, 3, …», но правую границу не включает — придётся взять на 1 больше.

**2. Заготовки.** Создай массив из 10 нулей, матрицу 3×4 из единиц и матрицу 2×3, целиком заполненную числом 7. Выведи каждую.

**3. Ровные промежутки.** Создай массив из 12 дробных чисел, равномерно разложенных от 0 до 1 (обе границы включены). Выведи его.
> 💡 Это отдельная функция (не та, что для целых по порядку) — она как раз про «равные промежутки».

**4. Срезы 1D.** Возьми `a = np.arange(1, 21)`. Достань и выведи: первые 5 чисел, последние 5, каждое второе, весь массив задом наперёд, и числа с индекса 5 по 14 включительно.
> 💡 Правая граница среза не входит — чтобы «включить 14-й индекс», подумай, какое число написать справа.

**5. Выход за границы.** Выведи `a[100:200]` (индексов таких нет). Упадёт с ошибкой или нет? Запусти и посмотри, что вернётся.

**6. Матрица целиком.** Создай `m = np.arange(1, 13).reshape(3, 4)`. Выведи: вторую строку, третий столбец, «уголок» из верхних 2 строк и 2 последних столбцов.

**7. Суммы по осям.** Для той же `m` посчитай: сумму всех чисел, сумму по строкам (3 числа) и сумму по столбцам (4 числа).
> 💡 Суммы по направлениям задаёт `axis` — какой номер что «схлопывает», проверь на этой маленькой матрице и запомни навсегда.

**8. Цельсий в Фаренгейты.** Дан `c = np.array([0, 5, 10, 20, 37])`. Одной операцией переведи все в Фаренгейты (`F = C * 9/5 + 32`). Ожидаемо `[32. 41. 50. 68. 98.6]`.

**9. Корни.** Из массива `[1, 4, 9, 16, 25]` одной операцией получи квадратные корни. Ожидаемо `[1. 2. 3. 4. 5.]`.

**10. Фильтр по маске.** Дан `data = np.array([3, 15, 8, 22, 5, 30, 11])`. Оставь только числа больше 10 (через булеву маску, без цикла) и выведи, **сколько** их прошло.
> 💡 Число элементов маски, где условие истинно, легко посчитать суммой.

## 🟡 Уровень 2 — средний (таблицы, нормализация, broadcasting)

**11. Классный журнал.** Создай оценки `np.random.seed(0); table = np.random.randint(50, 101, size=(5, 3))` — 5 учеников × 3 предмета. Посчитай средний балл каждого ученика (5 чисел) и по каждому предмету (3 числа).
> 💡 Ученик и предмет — это два разных `axis`; какой из них «схлопывать» в каждом случае, реши сам.

**12. Сильнейший ученик.** По той же таблице определи **номер** ученика с самым высоким средним баллом.
> 💡 «Номер самого большого» возвращает функция со словом `arg` в названии.

**13. Сколько отличников.** Посчитай, у скольких учеников средний балл ≥ 90.

**14. Нормализация столбцов (Min-Max).** Дана `np.random.seed(42); m = np.random.rand(4, 3) * 100`. Приведи **каждый столбец** в диапазон [0, 1] по формуле «(значение − минимум столбца) / (максимум − минимум)». Проверь: минимумы столбцов станут `[0, 0, 0]`, максимумы — `[1, 1, 1]`.
> 💡 Минимум и максимум надо брать **по столбцам** — снова вопрос про `axis`. Ошибёшься с осью — числа «поедут», проверка это сразу покажет.

**15. Прибавить вектор к матрице.** *(broadcasting)* Дана матрица `m = np.arange(1, 13).reshape(3, 4)` и вектор-строка `bonus = np.array([10, 20, 30, 40])`. Прибавь `bonus` к **каждой строке** матрицы одной операцией. Посмотри на результат и убедись, что первый столбец вырос на 10, второй на 20 и т.д.

## 🔴 Уровень 3 — со звёздочкой

**16. Шахматная доска.** Собери матрицу 8×8 из 0 и 1 в шахматном порядке и покажи её через `plt.imshow(board, cmap='gray')`.

**17. Расстояния от центра.** Даны `np.random.seed(0); points = np.random.rand(100, 2) * 10` и `center = np.array([5.0, 5.0])`. Посчитай расстояние от каждой точки до центра (100 чисел), найди самую близкую и самую дальнюю, и посчитай, сколько точек внутри радиуса 3.
> 💡 Расстояние — это теорема Пифагора: разности координат в квадрат, сложить по нужной оси, взять корень. Вычитание сработает благодаря broadcasting.

**18. Картинка из чисел.** Собери `img = np.zeros((10, 10), dtype=np.uint8)`, впиши белый прямоугольник `img[2:8, 3:7] = 200` и серый квадратик в центре. Покажи через `plt.imshow(img, cmap='gray')`. Потом *(на подумать)* впиши в какой-нибудь пиксель значение `300` и посмотри, что стало с картинкой.
> 💡 Тип `uint8` хранит числа только 0–255 — значение больше «перескочит через край».

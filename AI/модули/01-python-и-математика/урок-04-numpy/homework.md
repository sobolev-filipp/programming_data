### 3.2. Расстояния от точки

> **Задача:** для 100 точек на плоскости посчитать **расстояния** до центральной точки.

```python
np.random.seed(0)
points = np.random.rand(100, 2) * 10
center = np.array([5.0, 5.0])
```

**Формула евклидова расстояния:**
```
distance(p1, p2) = √((x1-x2)² + (y1-y2)²)
```

**Что нужно:**

1. **Расстояния** — массив из 100 чисел.
2. **Самая близкая** точка к центру.
3. **Самая дальняя** точка.
4. **Сколько точек** внутри радиуса 3 от центра.

**Подсказка по формуле в NumPy:**
- `points - center` (broadcasting).
- Квадраты — `** 2`.
- Сумма по строкам — `.sum(axis=1)`.
- Корень — `np.sqrt(...)`.

**Альтернатива:** `np.linalg.norm(points - center, axis=1)` — одна функция делает всё.

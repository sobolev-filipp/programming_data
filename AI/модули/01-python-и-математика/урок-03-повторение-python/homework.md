## Шпаргалка (подглядывать не стыдно)

```python
zip(a, b)                       # параллельный проход
enumerate(coll, start=1)        # индекс + значение
sorted(coll, key=..., reverse=) # сортировка
sum(coll), min(coll, key=)      # агрегации
all(...), any(...)              # все/хоть один
"a,b".split(",")                # ['a', 'b']
",".join(["a","b"])             # "a,b"
"hello".startswith("h")         # True
```

Знакомая задача из жизни — посчитать статистику по числам и найти «рекордсмена».


Программы часто пишут результаты в файлы и потом читают обратно — попробуй весь цикл сам.

**Сделай:**
1. Создай файл `text.txt` с любым текстом из 5–10 строк.

## Шпаргалка

```python
zip(a, b)                       # параллельный проход по двум спискам
enumerate(coll, start=1)        # индекс + значение
sorted(coll, key=..., reverse=) # сортировка (не меняет оригинал)
sum(coll) / min(coll) / max(coll, key=...)
all(...) / any(...)             # все / хоть один True
"a,b,c".split(",")              # ['a', 'b', 'c']
",".join(["a","b","c"])         # 'a,b,c'
"  Hi ".strip().lower()         # 'hi'
```

## 🟢 Уровень 1 — базовый (zip, enumerate, sorted, агрегации)

**1. Прайс из двух списков.** Есть `fruits = ["яблоко", "банан", "вишня"]` и `prices = [80, 60, 150]`. Собери из них словарь `{"яблоко": 80, ...}` одной строкой. Выведи его.
> 💡 Сначала «состегни» списки в пары, потом преврати пары в словарь — обе операции это функции-однословки.

**2. Ценник построчно.** Пройди те же два списка **параллельно** и выведи по строке на каждый фрукт: `яблоко — 80 руб`, `банан — 60 руб`, `вишня — 150 руб`.

**3. Пронумерованный список дел.** Есть `todo = ["учить Python", "сделать ДЗ", "погулять"]`. Выведи его с номерами, начиная с 1:
```
1. учить Python
2. сделать ДЗ
3. погулять
```
> 💡 Чтобы в цикле были и номер, и текст сразу, есть специальная функция-обёртка; начать нумерацию с 1 помогает её параметр `start`.

**4. Список с буквами.** Выведи тот же `todo`, но с буквами вместо цифр: `A. учить Python`, `B. сделать ДЗ`, `C. погулять`. (Букву можно получить из номера через `chr(65 + i)`.)

**5. Сортировка чисел.** Дан `nums = [42, 7, 19, 3, 88, 15]`. Выведи его отсортированным по возрастанию, а потом по убыванию. Убедись, что **сам** `nums` не изменился.
> 💡 `sorted` возвращает новый список и не трогает оригинал — в отличие от `.sort()`.

**6. Слова по алфавиту.** Дан `words = ["машина", "ai", "python", "код"]`. Отсортируй по алфавиту.

**7. Слова по длине.** Те же слова отсортируй по длине — от коротких к длинным. Ожидаемо: ai, код, машина, python.
> 💡 Чтобы сортировать «по длине», подскажи функции признак сравнения через `key`.

**8. Погода за неделю.** Даны `temps = [18, 22, 20, 23, 17, 19, 25]`. Посчитай и выведи: среднюю температуру (до 1 знака), минимум и максимум.

**9. Самый тёплый день.** К прошлой задаче добавь `days = ["пн","вт","ср","чт","пт","сб","вс"]`. Определи и выведи **название** самого тёплого дня (`вс`).
> 💡 Один путь — найти, на каком месте стоит максимум, и взять день с тем же номером; другой — «состегнуть» дни с температурами и выбрать пару с наибольшей температурой.

**10. Все ли сдали?** Дан список баллов `scores = [4, 5, 3, 5, 4]`. Одной командой проверь, все ли ≥ 3 (`all`), и другой — есть ли хоть одна пятёрка (`any`). Выведи оба ответа (`True`/`False`).

## 🟡 Уровень 2 — средний (строки и комбинации)

**11. Разбить и посчитать.** Дана строка `text = "искусственный интеллект меняет мир"`. Разбей её на слова и выведи, сколько слов получилось (`4`).

**12. Собрать через дефис.** Из списка `["ai", "ml", "dl"]` собери строку `ai-ml-dl`.

**13. Чистка ввода.** Дан «грязный» список имён `["  Иван ", "МАРИЯ", "пётр  "]`. Приведи каждое к аккуратному виду: без пробелов по краям и с маленькой буквы. Ожидаемо `['иван', 'мария', 'пётр']`.
> 💡 У строк есть методы «убрать пробелы по краям» и «сделать строчными» — их можно применить подряд.

**14. Слова с гласной.** Дан текст `"искусственный интеллект учится сам и помогает человеку"` и `vowels = "аеёиоуыэюя"`. Собери список слов, которые начинаются с гласной. Сколько их?
> 💡 Разбей текст на слова, а дальше проверяй **первую** букву каждого слова через `in`.

**15. Топ-3 учеников.** Дан список:
```python
students = [
    {"name": "Иван",  "grades": [4, 5, 5, 3, 4]},
    {"name": "Мария", "grades": [5, 5, 5, 4, 5]},
    {"name": "Пётр",  "grades": [3, 3, 4, 3, 4]},
    {"name": "Ольга", "grades": [4, 4, 5, 5, 4]},
    {"name": "Алина", "grades": [5, 4, 4, 5, 5]},
]
```
Посчитай каждому средний балл, отсортируй по нему по убыванию и выведи тройку лучших:
```
1. Мария — 4.80
2. Алина — 4.60
3. Ольга — 4.40
```
> 💡 Сортируй по среднему через `key`; формат до 2 знаков делается прямо в f-строке (`{x:.2f}`).

**16. Самый дорогой товар.** Дан список товаров `[{"name":"Сыр","price":600}, {"name":"Хлеб","price":50}, {"name":"Колбаса","price":450}]`. Найди через `max` товар с самой высокой ценой и выведи его название (`Сыр`).

**17. Средний балл по классу.** *(на подумать)* Из того же `students` (задача 15) посчитай **один** общий средний балл по всему классу (среднее из всех средних) и выведи до 2 знаков.

## 🔴 Уровень 3 — со звёздочкой

**18. Палиндромы.** Дан `words = ["шалаш", "топот", "Анна", "потом", "тут", "молоко"]`. Найди все слова, которые читаются одинаково в обе стороны (регистр не важен — «Анна» тоже палиндром). Выведи их.
> 💡 Строку «задом наперёд» даёт короткий трюк со срезом; чтобы регистр не мешал — приведи буквы к одному виду перед сравнением.

**19. Топ-5 частых букв.** Дан текст `"программирование на python это интересно"`. Посчитай, сколько раз встречается каждая буква (пробелы не считаем), и выведи 5 самых частых.
> 💡 Пройди по уникальным символам и для каждого посчитай, сколько раз он встречается в тексте, потом отсортируй по количеству и возьми верхушку.

**20. Файл: запиши и проанализируй.** Создай файл `text.txt` с любым текстом из 5–7 строк, потом прочитай его обратно и выведи: сколько строк, сколько всего слов и какое слово самое длинное.
> 💡 Файлы открывай через `with ... as f`; чтобы собрать все слова из всех строк, пригодится вложенный генератор `... for line in lines for w in line.split()`. Не забудь `encoding="utf-8"`.

**21. sort или sorted?** *(коротко в Markdown-ячейке)* Объясни одной фразой, чем `nums.sort()` отличается от `sorted(nums)` и почему `x = nums.sort()` кладёт в `x` значение `None`.

## Шпаргалка (если забыл синтаксис — подглядывай)

```python
lambda x: x * 2                                # функция в одну строку
sorted(данные, key=lambda el: el["поле"])      # сортировка по полю
max(данные, key=lambda el: el["поле"])         # максимум по полю

sum(coll) / min(coll) / max(coll)              # сборщики
all(усл for x in coll) / any(усл for x in coll) # все / хоть один True

def f(*args):     # args = (1, 2, 3)   — кортеж
def f(**kwargs):  # kwargs = {'имя': 'Иван'} — словарь
f(*список)        # распаковать список в аргументы
f(**словарь)      # распаковать словарь в именованные аргументы

"a,b,c".split(",")            # ['a', 'b', 'c']
"-".join(["a","b","c"])       # 'a-b-c'
"  Hi ".strip().lower()       # 'hi'
f"{x:.2f}"                    # число с двумя знаками
```

## 🟢 Уровень 1 — базовый (lambda, сортировка, агрегации)

Для задач 3–6 используй список товаров:

```python
products = [

    {"name": "Колбаса", "price": 450, "stock": 12},
```

**1. Сортировка чисел.** Дан `nums = [42, 7, 19, 3, 88, 15]`. Выведи его отсортированным по возрастанию, а потом по убыванию. Убедись, что **сам** `nums` не изменился.
> 💡 `sorted` возвращает новый список и не трогает оригинал — в отличие от `.sort()`.

**2. Слова по длине.** Дан `words = ["ai", "код", "слон", "робот", "нейросеть"]`. Отсортируй по длине слова — от коротких к длинным. Ожидаемо: `ai, код, слон, робот, нейросеть`.
> 💡 Чтобы сортировать «по длине», подскажи функции признак сравнения через `key` — здесь подойдёт готовая функция `len`, без `lambda`.

**3. Сортировка по цене.** Отсортируй товары по цене от дешёвых к дорогим и выведи их названия по порядку. Ожидаемо: Хлеб, Яблоко, Печенье, Колбаса, Сыр.
> 💡 И `sorted`, и `min/max` принимают `key` — маленькую функцию «по какому полю сравнивать»; здесь как раз просится `lambda`, достающая цену.

**4. Сортировка по остатку.** Отсортируй те же товары по количеству на складе (`stock`) **от большего к меньшему**. Первым должно идти «Яблоко» (50 штук).

**5. Самый дешёвый.** Найди товар с самой низкой ценой через `min` и выведи его название — «Хлеб».

**6. Самый ходовой запас.** Найди товар с самым большим `stock` через `max`. Должно получиться «Яблоко».

**7. Погода за неделю.** Даны `temps = [18, 22, 20, 23, 17, 19, 25]`. Посчитай и выведи: среднюю температуру (до 1 знака), минимум и максимум.

**8. Все ли сдали?** Дан список баллов `scores = [4, 5, 3, 5, 4]`. Одной командой проверь, все ли ≥ 3 (`all`), и другой — есть ли хоть одна пятёрка (`any`). Выведи оба ответа (`True`/`False`).

## 🟡 Уровень 2 — средний (*args/**kwargs и строки)

**9. `multiply_all` — перемножить сколько угодно чисел.** Напиши функцию, которая принимает **любое** число аргументов и возвращает их произведение: `multiply_all(2, 3)` → `6`, `multiply_all(2, 3, 4, 5)` → `120`, а вызов без аргументов `multiply_all()` → `1`.
> 💡 «Сколько угодно аргументов» ловит одна звёздочка. Накопитель начинай с 1, а не с 0 — подумай сам, что случится с произведением, если стартовать с нуля.

**10. `average` — среднее любого набора.** Напиши функцию, которая принимает любое число оценок и возвращает их среднее: `average(5, 4, 3)` → `4.0`, `average(5, 5, 4, 5)` → `4.75`. Если чисел не передали вообще — верни `0` (чтобы не делить на ноль).

**11. `describe` — карточка героя.** *(на подумать)* Напиши функцию `describe`, которая принимает любые именованные аргументы и печатает их по строчке. Вызов `describe(name="Ния", level=7, hp=100)` должен вывести три строки: `name: Ния`, `level: 7`, `hp: 100`.
> 💡 Именованные аргументы «сколько угодно» собирает `**kwargs` — внутри это обычный словарь, по нему можно пройти циклом.

**12. Разбить и посчитать.** Дана строка `text = "искусственный интеллект меняет мир"`. Разбей её на слова и выведи, сколько слов получилось (`4`).

**13. Собрать через дефис.** Из списка `["ai", "ml", "dl"]` собери строку `ai-ml-dl`.
> 💡 Склеивает разделитель: это он «вызывает» `join`, а список передаётся внутрь.

**14. Чистка ввода.** Дан «грязный» список имён `["  Иван ", "МАРИЯ", "пётр  "]`. Приведи каждое к аккуратному виду: без пробелов по краям и с маленькой буквы. Ожидаемо `['иван', 'мария', 'пётр']`.
> 💡 У строк есть методы «убрать пробелы по краям» и «сделать строчными» — их можно применить подряд одной цепочкой.

## 🔴 Уровень 3 — со звёздочкой

**17. Своя функция `repeat`.** Напиши функцию, которая вызывает **другую** функцию `n` раз с одними и теми же аргументами и собирает результаты в список:
```python
def add(a, b):
    return a + b

repeat(3, add, 5, 7)              # [12, 12, 12]

import random
repeat(5, random.randint, 1, 10)  # 5 случайных чисел, например [4, 9, 1, 7, 3]
```
> 💡 Твоя `repeat` должна принять **любые** аргументы для чужой функции и **передать их дальше**. Звёздочки тут работают в обе стороны — в этом вся соль. Тело удобно собрать генератором из `n` повторов.

**18. Палиндромы.** Дан `words = ["шалаш", "топот", "Анна", "потом", "тут", "молоко"]`. Найди все слова, которые читаются одинаково в обе стороны (регистр не важен — «Анна» тоже палиндром). Выведи их.
> 💡 Строку «задом наперёд» даёт короткий трюк со срезом `[::-1]`; чтобы регистр не мешал — приведи буквы к одному виду перед сравнением.

**19. Топ-5 частых букв.** Дан текст `"программирование на python это интересно"`. Посчитай, сколько раз встречается каждая буква (пробелы не считаем), и выведи 5 самых частых.
> 💡 Пройди по **уникальным** символам (вспомни множество с прошлого урока) и для каждого посчитай, сколько раз он встречается в тексте (`text.count(c)`), потом отсортируй по количеству и возьми верхушку.

**20. Собирают vs распаковывают.** *(коротко в Markdown-ячейке)* В функции `repeat` (задача 17) ты написал звёздочки дважды: в объявлении `def repeat(n, func, *args, **kwargs)` и в вызове `func(*args, **kwargs)`. Объясни одной-двумя фразами, почему в первом случае звёздочки **собирают** аргументы, а во втором — **распаковывают**. Это и есть главная идея темы `*args/**kwargs`.

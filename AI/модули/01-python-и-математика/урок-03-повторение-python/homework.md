## Уровень 1. Обязательная база

Если до этих заданий ты не дошёл — никуда дальше не двигаемся.

### 1.1. Объедини в словарь

Даны два списка:
```python
fruits = ["яблоко", "банан", "вишня", "груша"]
prices = [80, 60, 150, 90]
```

Сделай словарь `{фрукт: цена}` **в одну строку** (используй `zip` и `dict`).

### 1.2. Пронумерованный список

Дан список:
```python
todo = ["учить Python", "сделать ДЗ", "посмотреть фильм", "позвонить маме"]
```

Распечатай его как:
```
1. учить Python
2. сделать ДЗ
3. посмотреть фильм
4. позвонить маме
```

Используй `enumerate` со стартом 1.

### 1.3. Сортировка слов

Дан список слов:
```python
words = ["машина", "ai", "python", "ml", "нейросеть", "kaggle"]
```

1. Отсортируй по длине, от коротких к длинным.
2. Отсортируй в алфавитном порядке (по умолчанию).
3. Отсортируй по длине, от длинных к коротким.

### 1.4. Агрегации

Дан список температур за неделю:
```python
temps = [18, 22, 20, 23, 17, 19, 25]
```

Распечатай:
- Среднюю температуру (округли до 1 знака после запятой).
- Минимальную и максимальную.
- День (1–7), когда было теплее всего.

## Уровень 2. Связка с предыдущими уроками

```python

```

2. Алина — 4.60
3. Ольга — 4.40

### 2.3. Класс `Product` + сортировка списка объектов

(Использует ООП из урока 1.1.)

### 3.1. Палиндромы

Из списка слов выбери все **палиндромы** (читаются одинаково в обе стороны), игнорируя регистр.

```python
words = ["шалаш", "топот", "Анна", "потом", "тут", "молоко", "АРБА"]
```

Подсказка: `w.lower() == w.lower()[::-1]`.

### 3.2. Гистограмма частот букв

Дан текст:
```python
text = "программирование на python это интересно"
```

Построй словарь `{буква: количество_вхождений}`. Игнорируй пробелы.

Подсказка: можно через генератор словаря: `{c: text.count(c) for c in set(text) if c != " "}`.

Покажи **5 самых частых** букв через `sorted(..., key=, reverse=True)[:5]`.

### 3.3. Анализ файла

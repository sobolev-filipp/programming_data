## Шпаргалка для быстрого старта

```python
zip(a, b)               # параллельный проход: пары (a[0], b[0]), (a[1], b[1])
```

### 1.4. Агрегации — погода за неделю

> **Что от тебя требуется:** посчитать статистику температур и найти самый тёплый день.

**Дано:**
```python
days = ["пн", "вт", "ср", "чт", "пт", "сб", "вс"]
temps = [18, 22, 20, 23, 17, 19, 25]
```

**Шаги:**

**Шаг 1: средняя температура (округли до 1 знака)**
```python
avg = round(sum(temps) / len(temps), 1)
print(f"Средняя: {avg}°")    # 20.6°
```

**Шаг 2: минимум и максимум**
```python
print(f"Минимум: {min(temps)}°")
print(f"Максимум: {max(temps)}°")
```

**Шаг 3: день с максимумом**

**Способ 1 (через `index`):**
```python
hottest_idx = temps.index(max(temps))
print(f"Самый тёплый день: {days[hottest_idx]}")    # вс
```

> **Подсказка:** `temps.index(x)` возвращает **индекс** первого вхождения `x`. Нашли максимум — нашли его индекс — нашли день по индексу.

**Способ 2 (через `max + lambda`, более продвинуто):**
```python
day, temp = max(zip(days, temps), key=lambda pair: pair[1])
print(f"Самый тёплый день: {day} ({temp}°)")
```

Оба способа правильные.

### 2.1. Топ-3 учеников по среднему

> **Что от тебя требуется:** найти **3 лучших учеников** по среднему баллу.

**Дано:**
```python
students = [
    {"name": "Иван",  "grades": [4, 5, 5, 3, 4]},
    {"name": "Мария", "grades": [5, 5, 5, 4, 5]},
    {"name": "Пётр",  "grades": [3, 3, 4, 3, 4]},
    {"name": "Ольга", "grades": [4, 4, 5, 5, 4]},
    {"name": "Алина", "grades": [5, 4, 4, 5, 5]},
]
```

**Что хотим напечатать:**
```
1. Мария — 4.80
2. Алина — 4.60
3. Ольга — 4.40
```

**Шаги:**

**Шаг 1: добавить столбец `avg` к каждому**
```python
for s in students:
    s["avg"] = sum(s["grades"]) / len(s["grades"])
```

> **Подсказка:** мы **изменяем** словари прямо в списке. После этого у каждого ученика появляется новый ключ `avg`.

**Шаг 2: отсортировать по avg по убыванию**
```python
top = sorted(students, key=lambda s: s["avg"], reverse=True)[:3]
```

> **Подсказка:** `[:3]` берёт первые **3 элемента** среза.

**Шаг 3: распечатать в нужном формате**
```python
for i, s in enumerate(top, start=1):
    print(f"{i}. {s['name']} — {s['avg']:.2f}")
```

> **Подсказка:** `:.2f` округляет до 2 знаков после запятой.

### 2.3. Класс `Product` (использует ООП из 1.1)

> **Что от тебя требуется:** соединить **ООП из 1.1** и **утилиты из 1.3**.

**Шаг 1: написать класс**
```python
class Product:
    def __init__(self, name, price, quantity):
        self.name = name
        self.price = price
        self.quantity = quantity

    def total_value(self):
        return self.price * self.quantity

    def __repr__(self):
        return f"Product({self.name!r}, price={self.price}, qty={self.quantity})"
```

**Шаг 2: создать список из 5 продуктов**
```python
products = [
    Product("Хлеб", 50, 30),
    Product("Молоко", 80, 50),
    Product("Сыр", 600, 5),
    Product("Колбаса", 450, 10),
    Product("Печенье", 120, 0),       # ← нет в наличии
]
```

**Шаг 3: отсортировать по убыванию total_value**
```python
by_value = sorted(products, key=lambda p: p.total_value(), reverse=True)
for p in by_value:
    print(f"{p.name}: {p.total_value()}")
```

> **Подсказка:** `p.total_value()` — это **метод**, поэтому скобки `()` обязательны.

**Шаг 4: найти самый дорогой продукт за единицу**
```python
expensive = max(products, key=lambda p: p.price)
print(f"Самый дорогой: {expensive.name} (₽{expensive.price})")
```

**Шаг 5: проверить, все ли в наличии**

### 3.2. Гистограмма частот букв

> **Что от тебя требуется:** для каждой буквы строки посчитать, **сколько раз** она встречается.

**Дано:**
```python
text = "программирование на python это интересно"
```

**Подсказки:**
- `text.count(c)` — сколько раз символ `c` есть в `text`.
- `set(text)` — уникальные символы.
- Через генератор словаря: `{c: text.count(c) for c in set(text)}`.
- Не считаем пробелы — `if c != " "`.

**Шаг 1: словарь частот**
```python
freq = {c: text.count(c) for c in set(text) if c != " "}
```

**Шаг 2: топ-5 самых частых**
```python
top5 = sorted(freq.items(), key=lambda kv: kv[1], reverse=True)[:5]
for char, count in top5:
    print(f"  {char!r}: {count}")
```

> **Подсказка:** `freq.items()` даёт пары `(буква, число)`. Сортируем по второму элементу пары (`kv[1]`).

**Альтернатива через `collections.Counter`** (не давали на уроке, но если знаешь — отлично):
```python
from collections import Counter
counter = Counter(c for c in text if c != " ")
print(counter.most_common(5))
```

### 3.3. Анализ файла

> **Что от тебя требуется:** **записать** текст в файл, потом **прочитать** его и сделать анализ.

**Шаг 1: создать текстовый файл**
```python
text_content = """Программирование это интересный навык.
Машинное обучение открывает новые возможности.
Каждый школьник может научиться писать код.
Python язык, идеально подходящий для старта.
Нейронные сети это математические модели."""

with open("text.txt", "w", encoding="utf-8") as f:
    f.write(text_content)
```

> **Подсказка:** `with open(...) as f:` — стандарт. `"w"` = write (запись). `encoding="utf-8"` обязателен для русского.

**Шаг 2: прочитать**
```python
with open("text.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()
```

> `f.readlines()` возвращает список строк (с `\n` в конце каждой).

**Шаг 3: посчитать**
```python
n_lines = len(lines)
all_words = [w for line in lines for w in line.split()]
n_words = len(all_words)
longest = max(all_words, key=len)
avg_length = round(sum(len(w) for w in all_words) / n_words, 1)

print(f"Строк: {n_lines}")
print(f"Слов: {n_words}")
print(f"Самое длинное: {longest}")
print(f"Средняя длина: {avg_length}")
```

> **Подсказка:** `[w for line in lines for w in line.split()]` — **вложенный** генератор. Сначала перебираем строки, потом слова в каждой.

**Шаг 4: сохранить результат**
```python
result = f"""Строк: {n_lines}
Слов: {n_words}
Самое длинное: {longest}
Средняя длина: {avg_length}
"""
with open("analysis.txt", "w", encoding="utf-8") as f:
    f.write(result)
```

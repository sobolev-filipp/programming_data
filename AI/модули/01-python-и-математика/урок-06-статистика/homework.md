## Уровень 1. Обязательная база

### 1.1. Описать выборку

> **Что от тебя требуется:** посчитать **6 статистик** для одного массива и распечатать **в одном блоке**.

**Дано — баллы ЕГЭ:**
```python
scores = np.array([72, 88, 95, 65, 78, 82, 60, 91, 85, 76, 100, 55, 70, 84, 89])
```

**Что напечатать:**

```python
print(f"Среднее:    {scores.mean():.2f}")
print(f"Медиана:    {np.median(scores):.2f}")
print(f"Минимум:    {scores.min()}")
print(f"Максимум:   {scores.max()}")
print(f"Размах:     {scores.max() - scores.min()}")
print(f"Std:        {scores.std():.2f}")
print(f"Дисперсия:  {scores.var():.2f}")
```

> **Подсказка про `:.2f`:** это форматирование с 2 знаками после запятой. Без него число будет с кучей лишних знаков.

**Ожидаемое:**
```
Среднее:    79.33
Медиана:    82.00
Минимум:    55
Максимум:   100
Размах:     45
Std:        12.36
Дисперсия:  152.76
```

> **Заметь:** среднее ≈ 79, медиана 82. Среднее **немного меньше** медианы — это значит, что выборка **слегка скошена влево** (есть несколько низких баллов).

### 1.3. Стандартизация

> **Что от тебя требуется:** превратить массив так, чтобы среднее стало 0, std = 1.

**Формула:** `z = (x - mean) / std`.

**Дано:**
```python
ages = np.array([12, 13, 14, 15, 15, 16, 16, 17, 17, 18])
```

**Шаги:**

1. **Стандартизуй:**
   ```python
   z = (ages - ages.mean()) / ages.std()
   print(z)
   ```

2. **Проверь:**
   ```python
   print(f"Среднее после: {z.mean():.10f}")     # ≈ 0
   print(f"Std после:     {z.std():.10f}")     # ≈ 1
   ```

> **Подсказка:** среднее получится **очень близко** к 0 (например, `-1.11e-16`) — это **нормальная погрешность float**. Не идеально 0, но **достаточно близко**.

### 2.2. Симуляция роста

> **Что от тебя требуется:** сгенерировать рост 1000 людей и проверить **правило 68-95-99.7**.

**Дано:**
```python
np.random.seed(0)
heights = np.random.normal(170, 8, 1000)    # среднее 170, std 8
```

**Шаги:**

1. **Построй гистограмму:**
   ```python
   plt.figure(figsize=(8, 4))
   plt.hist(heights, bins=40, edgecolor='black')
   plt.axvline(170, color='red', linestyle='--', label='Среднее')
   plt.legend()
   plt.show()
   ```

> **Подсказка:** `plt.axvline(x)` рисует вертикальную линию.

2. **Доля людей выше 180 см:**
   ```python
   tall = (heights > 180).sum() / len(heights)
   print(f"Выше 180 см: {tall:.1%}")
   ```

> **Подсказка:** `(heights > 180)` даёт булеву маску. `.sum()` считает True. Делим на общее количество — получаем долю.

3. **Доля людей в пределах ±1 std от среднего** (162..178):
   ```python
   within_1_std = ((heights >= 162) & (heights <= 178)).sum() / len(heights)
   print(f"В ±1 std: {within_1_std:.1%}")
   ```

> **Подсказка:** правило 68-95-99.7 говорит, что должно быть **~68%**. Это **только для нормального распределения!**

## Уровень 3. Со звёздочкой — корреляция

### 3.1. Реальные данные — часы учёбы и оценки

> **Что от тебя требуется:** найти корреляцию между двумя величинами и сделать вывод.

**Дано:**
```python
hours = np.array([2, 3, 5, 4, 7, 6, 8, 10, 9, 12, 11, 14])
```


3. **Сделай вывод словами.** Например: «корреляция близка к 1 → сильная положительная связь → чем больше учиться, тем выше балл».

### 3.2. Корреляционная матрица

> **Что от тебя требуется:** посчитать корреляции **между всеми парами** четырёх предметов.

**Дано:**
```python
np.random.seed(42)
n = 100
math = np.random.normal(4.0, 0.5, n)
physics = math * 0.8 + np.random.normal(0, 0.3, n)
history = np.random.normal(4.0, 0.5, n)
chemistry = math * 0.7 + np.random.normal(0, 0.4, n)

data = np.array([math, physics, history, chemistry])     # shape (4, n)
```

**Шаги:**

1. **Полная матрица корреляций:**
   ```python
   corr_matrix = np.corrcoef(data)
   print(corr_matrix.round(2))
   ```

> **Подсказка:** результат — **матрица 4×4**. На диагонали единицы (корреляция с самим собой). Симметричная (corr(A, B) == corr(B, A)).

2. **Найди, какие предметы связаны сильнее всего.**

   > **Подсказка:** математика связана с физикой и химией (мы их **специально** сделали зависимыми). История — независима от остальных.

3. **Бонус — красивая печать через Pandas:**
   ```python
   import pandas as pd
   df = pd.DataFrame(corr_matrix,
                     index=['math', 'physics', 'history', 'chemistry'],
                     columns=['math', 'physics', 'history', 'chemistry'])
   print(df.round(2))
   ```


> **Должно получиться:** около **0.90** — очень высокая!

2. **В комментарии напиши: почему она высокая, хотя одно не вызывает другое?**

> **Подсказка для ответа:** оба зависят от **третьей переменной** — температуры. Это **«скрытая переменная»** (которую мы обсуждали в теории на примерах мороженого/утопающих и обуви/грамотности).

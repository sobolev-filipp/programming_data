### 3.2. Корреляционная матрица

Дано:
```python

history = np.random.normal(4.0, 0.5, n)                  # независим

data = np.array([math, physics, history, chemistry])     # shape (4, n)
```

```python

```

3. Какие — слабо или независимы?

**Подсказка:** можно красиво распечатать через `pd.DataFrame` (если Pandas установлен):

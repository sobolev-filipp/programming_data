## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Выборка (sample)** | Набор чисел, который мы анализируем. |
| **Среднее (mean)** | Сумма поделить на количество. `a.mean()` |
| **Медиана (median)** | Центральное число в отсортированной выборке. `np.median(a)` |
| **Мода (mode)** | Самое часто встречающееся число. `scipy.stats.mode(a)` |
| **Размах (range)** | Разница между макс и мин. `a.max() - a.min()` |
| **Дисперсия (variance)** | Среднее **квадратов** отклонений от среднего. `a.var()` |
| **Стандартное отклонение (std)** | Корень из дисперсии. Главная мера разброса. `a.std()` |
| **Стандартизация (Z-score)** | `z = (x - mean) / std`. Среднее становится 0, std = 1. |
| **Распределение** | «Форма», в которую вписываются числа. |
| **Равномерное распределение** | Все значения равновероятны. |
| **Нормальное (гауссово) распределение** | Колоколообразная кривая. Большинство вокруг среднего. |
| **Гистограмма** | Столбчатая диаграмма «сколько чисел в каждом диапазоне». |
| **Корреляция** | Число от -1 до +1: связаны ли две величины. |
| **Выброс (outlier)** | Аномально большое или маленькое значение в выборке. |

---

## Главные мысли

1. **Среднее ≠ медиана**, если есть выбросы. Зарплаты директора напоминают об этом.
2. **std** показывает разброс. Одинаковое среднее — разные std могут быть у очень разных данных.
3. **Нормальное распределение** — «правило 68-95-99.7». Заучить.
4. **Корреляция = связь, но не причина.** Мороженое и утопающие.

---

## Меры центра

```python
a.mean()                    # среднее
np.median(a)                # медиана
from scipy import stats
stats.mode(a).mode          # мода
```

**Когда что использовать:**
- Симметричные данные → среднее.
- Есть выбросы → медиана.
- Категориальные → мода.

---

## Меры разброса

```python
a.max() - a.min()           # размах
a.var()                     # дисперсия
a.std()                     # стандартное отклонение
```

**Стандартизация (Z-score):**
```python
z = (a - a.mean()) / a.std()
# Теперь mean(z) ≈ 0, std(z) ≈ 1
```

## Распределения

```python
import matplotlib.pyplot as plt

# Равномерное
np.random.uniform(0, 10, n)
np.random.randint(1, 7, n)   # дискретное

# Нормальное
np.random.normal(mean, std, n)

# Гистограмма
plt.hist(data, bins=30)
plt.show()
```

**Правило 68-95-99.7 (только для нормального):**
- **68%** значений в пределах ±1 std от среднего.
- **95%** в пределах ±2 std.
- **99.7%** в пределах ±3 std.

## Корреляция

```python
corr = np.corrcoef(a, b)[0, 1]
```

| Значение | Что значит |
|----------|-----------|
| +1 | Идеальная положительная связь |
| +0.5..+0.9 | Сильная положительная |
| ±0.1..0.4 | Слабая связь |
| 0 | Независимы |
| -0.5..-0.9 | Сильная отрицательная |
| -1 | Идеальная обратная связь |

**Помни:** **корреляция ≠ причина**. Мороженое и утопающие.

---

## Главные ошибки

| Ошибка | Что не так | Как исправить |
|--------|-----------|---------------|
| Делать вывод по среднему, не глядя на std | Можно «прозевать» большой разброс | Смотреть **и** mean, **и** std |
| Среднее у скошенных данных | Тянется выбросами | Использовать медиану |
| `np.random.randint(1, 6)` для кубика | 6 не входит | `np.random.randint(1, 7)` |
| Сравнение корреляций без проверки на нелинейность | Корреляция = только **линейная** связь | Построить scatter plot |
| «X коррелирует с Y → X влияет на Y» | Это не доказательство | Сначала исключить «третью переменную» |

## Где это в ML

- **Описать датасет** (mean, std, медиана признаков) — первый шаг любого анализа.
- **Стандартизация** перед обучением модели — почти всегда.
- **Поиск выбросов** — для очистки данных.
- **Корреляция признаков с целевой** — для отбора важных.
- **Корреляция признаков между собой** — для удаления дублей.

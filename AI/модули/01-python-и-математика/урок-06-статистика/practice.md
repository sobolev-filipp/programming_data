### 1.3. Симметричное vs «скошенное» распределение

```python
# Симметричное — все три совпадают
sym = np.array([3, 4, 5, 6, 7])
print("Симметричное:")
print(f"  mean={sym.mean()}, median={np.median(sym)}")

# Скошенное вправо — медиана меньше среднего
skewed_right = np.array([1, 1, 2, 2, 3, 3, 4, 5, 6, 10, 20])
print("\nСкошенное вправо:")
print(f"  mean={skewed_right.mean():.2f}, median={np.median(skewed_right):.2f}")
# mean ~ 5.18, median = 3 — среднее «тянется» вправо

# Скошенное влево — медиана больше среднего
skewed_left = -skewed_right
print("\nСкошенное влево:")
print(f"  mean={skewed_left.mean():.2f}, median={np.median(skewed_left):.2f}")
```

> **Когда смотрите на новый датасет** — сравните среднее и медиану. Если они **сильно разные** — у вас выбросы или скошенное распределение. Это сразу сигнал «надо разобраться».

## Задание 2. Разброс (15 минут)

### 2.1. Считаем std пошагово

```python
data = np.array([4, 5, 5, 3, 4, 5, 4, 3, 4, 5])

# Шаг 1: среднее
mean = data.mean()                  # 4.2
print("Среднее:", mean)

# Шаг 2: отклонения от среднего
deviations = data - mean
print("Отклонения:", deviations)

# Шаг 3: квадраты
squared = deviations ** 2
print("Квадраты:", squared)

# Шаг 4: дисперсия = среднее квадратов
variance = squared.mean()
print("Дисперсия:", variance)        # 0.56

# Шаг 5: корень = std
std = np.sqrt(variance)
print("Std:", std)                    # 0.748...

# Проверка через NumPy
print("Через NumPy:")
print("  np.var:", data.var())        # 0.56
print("  np.std:", data.std())        # 0.748...
```

### 2.2. Сравнение двух классов

```python
np.random.seed(42)

# Класс А — все более-менее одинаково учатся
class_a = np.random.normal(loc=4.0, scale=0.3, size=20)

# Класс Б — кто-то очень хороший, кто-то очень слабый
class_b = np.random.normal(loc=4.0, scale=1.0, size=20)

print(f"Класс А: средний {class_a.mean():.2f}, std {class_a.std():.2f}")
print(f"Класс Б: средний {class_b.mean():.2f}, std {class_b.std():.2f}")
```

**Спросить:** среднее ОДИНАКОВОЕ, std разный. Что это значит?

**Ответ:** в классе А ученики **похожи** по уровню, в классе Б — **очень разные**. Среднее не показывает разницу — нужен std.

### 2.3. Стандартизация

```python
data = np.array([170, 175, 168, 180, 172, 178, 182, 165, 174, 176])

# Стандартизация
z = (data - data.mean()) / data.std()
print("Стандартизованные:", z)

print(f"\nСреднее после: {z.mean():.10f}")   # ≈ 0
print(f"Std после: {z.std():.10f}")          # ≈ 1
```

**Объяснить:** теперь все данные «как бы» имеют тот же масштаб. **Это нужно перед обучением многих ML-моделей.**

### 3.3. Проверка правила 68-95-99.7

```python
np.random.seed(0)
data = np.random.normal(175, 10, 100000)
mean = data.mean()
std = data.std()

# В пределах 1 std
within_1 = ((data >= mean - std) & (data <= mean + std)).sum() / len(data)
# 2 std
within_2 = ((data >= mean - 2*std) & (data <= mean + 2*std)).sum() / len(data)
# 3 std
within_3 = ((data >= mean - 3*std) & (data <= mean + 3*std)).sum() / len(data)

print(f"В пределах 1 std: {within_1:.2%}")   # ~68%
print(f"В пределах 2 std: {within_2:.2%}")   # ~95%
print(f"В пределах 3 std: {within_3:.2%}")   # ~99.7%
```

> **Это работает только для нормального распределения!** Для других — не обязательно.

## Задание 4. Корреляция (10 минут)

### 4.1. Классический пример: рост и вес

```python
height = np.array([160, 165, 170, 172, 175, 178, 180, 182, 185, 190])
weight = np.array([55, 58, 65, 68, 70, 75, 78, 82, 85, 90])

corr = np.corrcoef(height, weight)[0, 1]
print(f"Корреляция роста и веса: {corr:.3f}")
# 0.994 — почти идеальная связь

# Покажем на графике
plt.figure(figsize=(8, 5))
plt.scatter(height, weight, s=80)
plt.xlabel("Рост (см)")
plt.ylabel("Вес (кг)")
plt.title(f"Рост vs Вес (corr = {corr:.2f})")
plt.show()
```

**Что увидим:** точки идут «по диагонали вверх» — растёт рост, растёт вес. Это положительная корреляция.

### 4.2. Отрицательная корреляция

Возраст автомобиля и его цена:

```python
age = np.array([1, 2, 3, 5, 7, 10, 12, 15])
price = np.array([1500, 1200, 1000, 800, 600, 400, 300, 200])

corr = np.corrcoef(age, price)[0, 1]
print(f"Корреляция возраста и цены: {corr:.3f}")

plt.xlabel("Возраст (лет)")

```

### 4.4. Корреляция ≠ причина

```python
# Пример: «продажи мороженого» и «утопающие» — оба зависят от температуры
np.random.seed(1)
temperature = np.random.uniform(15, 35, 100)
ice_cream = 5 * temperature + np.random.normal(0, 10, 100)    # продажи
drownings = 0.3 * temperature + np.random.normal(0, 2, 100)   # утопающие

corr = np.corrcoef(ice_cream, drownings)[0, 1]
print(f"Корреляция мороженого и утоплений: {corr:.3f}")
# ~0.8 — высокая!

# Но это не значит, что мороженое топит. Виновата ТРЕТЬЯ переменная — температура.
```

**Обсудить:** мы получили высокую корреляцию между двумя «независимыми» вещами, потому что обе зависят от температуры. **Это типичная ловушка** в анализе данных.

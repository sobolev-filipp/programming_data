## Глоссарий новых терминов

| Термин | Что это |
|--------|---------|
| **Вектор** | Массив чисел в один ряд. В геометрии — стрелка из (0,0). |
| **Скаляр** | Просто одно число. |
| **Норма (длина) вектора** | Длина стрелки. `np.linalg.norm(v)`. Считается через Пифагора. |
| **Скалярное произведение (`a @ b`)** | «Попарно перемножить и сложить». Получается одно число. |
| **Косинусная похожесть** | Скалярное произведение, делённое на произведение длин. От -1 до 1. |
| **Матрица** | Таблица чисел (двумерный массив). |
| **Транспонирование (`A.T`)** | Перевернуть матрицу: строки ↔ столбцы. |
| **Умножение матриц (`A @ B`)** | Каждый элемент результата = скалярное произведение строки A на столбец B. |

---

## Главные мысли

1. `@` — оператор скалярного произведения и умножения матриц. Запомни намертво.
2. `*` ≠ `@`. `*` — поэлементное, `@` — настоящее матричное.
3. Чтобы умножить матрицы — **внутренние размеры должны совпадать**: `(a×b) @ (b×c) → (a×c)`.
4. Простейший слой нейросети = `W @ x + b`.

## Скалярное произведение

```python
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

a @ b              # 32 — рекомендуемый стиль
np.dot(a, b)       # 32 — то же самое
(a * b).sum()      # 32 — пошагово
```

**Формула:** `a · b = a[0]*b[0] + a[1]*b[1] + a[2]*b[2] + ...`

**Геометрически:** `a · b = |a| * |b| * cos(угол)`.
- Сонаправлены → большое положительное.
- Перпендикулярны → 0.
- Противонаправлены → большое отрицательное.

**Косинусная похожесть:**
```python
sim = (a @ b) / (np.linalg.norm(a) * np.linalg.norm(b))
# От -1 до 1. 1 = одинаковое направление, 0 = перпендикулярны, -1 = противоположны.
```

## Матрицы

### Транспонирование

```python
A.T                # строки ↔ столбцы
(A.T).T == A       # двойное транспонирование возвращает исходное
```

### Умножение матриц

```python
A @ B
```

**Правило размерностей:**
```
(m × n) @ (n × k)  =  (m × k)
   └── равны ──┘
```

**Каждый элемент:** `C[i, j]` = `строка A[i] · столбец B[:, j]`.

### Умножение матрицы на вектор

```python
W @ x       # «слой нейросети» в одной строке!
```

Если `W.shape = (m, n)` и `x.shape = (n,)`, то результат — вектор формы `(m,)`.

## Главные ошибки

| Ошибка | Что не так | Как исправить |
|--------|-----------|---------------|
| `A * B` для умножения матриц | `*` — поэлементное | Используй `@` |
| Формы не сходятся | Внутренние размеры разные | `A @ B.T` или `A.T @ B` |
| `x @ W` где должно быть `W @ x` | Порядок важен! | Проверить формы |
| `np.norm(v)` | Такой функции нет | `np.linalg.norm(v)` |

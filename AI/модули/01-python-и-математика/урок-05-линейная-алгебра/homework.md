## Шпаргалка (минимум команд)

```python
import numpy as np

# Векторы
np.linalg.norm(a)            # длина вектора
a @ b                        # скалярное произведение
np.dot(a, b)                 # то же самое
(a * b).sum()                # тоже скалярное произведение

# Матрицы
A.T                          # транспонирование
A @ B                        # умножение матриц
W @ x                        # матрица × вектор
```

**Правило размерностей:** `(a × b) @ (b × c) → (a × c)`.

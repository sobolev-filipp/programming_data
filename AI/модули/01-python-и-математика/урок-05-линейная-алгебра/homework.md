## Шпаргалка (подглядывать можно)

```python
import numpy as np

np.linalg.norm(a)            # длина вектора
a @ b                        # скалярное произведение
A.T                          # транспонирование
A @ B                        # умножение матриц
W @ x                        # матрица × вектор — «слой нейросети»
```

**Правило форм:** `(a × b) @ (b × c) → (a × c)`.

### 1.1. Векторы и длина

Вектор — это стрелка на плоскости. Потренируемся складывать их, растягивать и измерять длину.

```python

```

Посчитай: `a + b`, `2 * a`, длину `a`, длину `b` и **расстояние** между концами векторов.

> **Направление:** длину вектора считает готовая функция (та, что живёт в `np.linalg`). А расстояние между двумя векторами — это длина их **разности**: сначала вычти один из другого, потом измерь.

### 1.2. Скалярное произведение

```python
u = np.array([2, -1, 3])
v = np.array([4,  5, 1])
```

Посчитай `u · v` **сначала в уме** по формуле «перемножить попарно и сложить», потом проверь через `u @ v`.

> **Ловушка:** во втором слагаемом `u[1] = -1`, поэтому `(-1) · 5 = -5`, а не +5. Из-за минусов такие вещи чаще всего и считают неверно — будь внимателен.

**🤔 Вопрос:** что получится, если у `u` поменять все знаки (`[-2, 1, -3]`)? Сначала предположи, каким станет результат, потом проверь.

### 2.3. Слой нейросети своими руками

### 3.2. Поворот точки на плоскости

Матрицы умеют **вращать** — на этом держится вся компьютерная графика. Поверни точку матрицей поворота.

```python

theta = np.pi / 2            # 90°

    [np.cos(theta), -np.sin(theta)],
    [np.sin(theta),  np.cos(theta)],
])
```

**Сделай:** поверни `p` на 90° (сначала предскажи, куда она попадёт), потом на 180°, а на бонус — поверни 5 случайных точек сразу.

## Шпаргалка для быстрого старта

```python
import numpy as np

a = np.array([1, 2, 3])

# Векторы
np.linalg.norm(a)            # длина вектора
a @ b                        # скалярное произведение → число
np.dot(a, b)                 # то же самое
(a * b).sum()                # тоже скалярное произведение

# Матрицы
A.T                          # транспонирование (строки ↔ столбцы)
A @ B                        # умножение матриц
A * B                        # ПОЭЛЕМЕНТНОЕ умножение (не то!)
W @ x                        # матрица × вектор = вектор
```

**Правило размерностей:** `(a × b) @ (b × c) → (a × c)`. Внутренние совпадают.

## Уровень 1. Обязательная база

### 1.1. Векторы и длина

> **Что от тебя требуется:** освоить базовые операции с векторами.

**Дано:**
```python
a = np.array([6, 8])
b = np.array([3, 4])
```

**Задачи:**

1. **`a + b`** — поэлементное сложение.
2. **`2 * a`** — умножение на скаляр.
3. **Длина `a`.** *Подсказка:* `np.linalg.norm(a)`.
4. **Длина `b`.**
5. **Расстояние между концами `a` и `b`.** *Подсказка:* это **длина вектора разности**: `np.linalg.norm(a - b)`.

**Ожидаемое:**
```
a + b = [9, 12]
2 * a = [12, 16]
|a| = 10  (это √(36+64) = √100)
|b| = 5
dist = 5
```

> **Подсказка:** `|a| = 10` — это «3-4-5 треугольник», увеличенный вдвое. Знакомая тема из геометрии.

### 1.3. Похожесть товаров

> **Что от тебя требуется:** для каждого товара посчитать «похожесть» с первым через **косинусную меру**.

**Дано:**
```python
товар1 = np.array([100, 8, 7])
товар2 = np.array([110, 7, 6])
товар3 = np.array([300, 9, 9])
товар4 = np.array([50, 3, 8])
```

**Формула косинусной похожести:**
```
sim(a, b) = (a · b) / (|a| · |b|)
```

**Шаг 1: определи функцию**
```python
def cos_sim(a, b):
    return (a @ b) / (np.linalg.norm(a) * np.linalg.norm(b))
```

**Шаг 2: посчитай для трёх пар**
```python
s12 = cos_sim(товар1, товар2)
s13 = cos_sim(товар1, товар3)
s14 = cos_sim(товар1, товар4)

print(f"sim(1,2) = {s12:.4f}")
print(f"sim(1,3) = {s13:.4f}")
print(f"sim(1,4) = {s14:.4f}")
```

**Шаг 3: какой товар больше всего похож на товар1?**

Сравни три значения. Самое большое — самая большая похожесть.

> **Подсказка:** все значения будут близки к 1 (≥ 0.98) — потому что у всех векторов **доминирует первая координата** (цена в сотнях). Это **типичная проблема разных масштабов признаков**, к которой мы вернёмся в Модуле 3.

## Уровень 2. Умножение матриц

### 2.1. Маленькое умножение 2×2

> **Что от тебя требуется:** сначала **на бумаге** посчитать `A @ B`, потом проверить.

**Дано:**
```python
A = np.array([[2, 1],
              [3, 4]])

B = np.array([[1, 0],
              [2, 5]])
```

**Шаг 1: посчитай на бумаге**

Заполни таблицу:

| Элемент C | Формула | Результат |
|-----------|---------|-----------|
| C[0,0] | строка 0 A · столбец 0 B = [2,1] · [1,2] = 2·1 + 1·2 | ___ |
| C[0,1] | [2,1] · [0,5] = 2·0 + 1·5 | ___ |
| C[1,0] | [3,4] · [1,2] = 3·1 + 4·2 | ___ |
| C[1,1] | [3,4] · [0,5] = 3·0 + 4·5 | ___ |

**Шаг 2: проверь через NumPy**
```python
print(A @ B)
```

**Ожидаемое:**
```
[[ 4  5]
 [11 20]]
```

> **Если получилось другое:** попробуй `A.shape` и `B.shape`. Возможно, забыл `@` (написал `*` — это поэлементно).

### 2.2. Совместимость форм

> **Что от тебя требуется:** заполнить таблицу — можно ли перемножить эти формы через `@`, и какая получится форма результата.

**Правило:** `(a × b) @ (b × c) → (a × c)`. **Внутренние совпадают**, внешние идут в результат.

**Заполни:**

| A | B | Можно? | Форма результата |
|---|---|--------|--------------------|
| (3, 4) | (4, 5) | ? | ? |
| (3, 4) | (5, 4) | ? | ? |
| (2, 3) | (3, 1) | ? | ? |
| (1, 5) | (5, 1) | ? | ? |
| (5, 1) | (1, 5) | ? | ? |
| (3, 3) | (3, 3) | ? | ? |

> **Подсказка:** возьми бумагу и для каждой пары **сравни средние числа** (b у первой матрицы и a у второй). Если совпали — можно. Если нет — ❌.

**Можешь проверить кодом:**
```python
shapes = [
    ((3, 4), (4, 5)),
    ((3, 4), (5, 4)),
    ((2, 3), (3, 1)),
    ((1, 5), (5, 1)),
    ((5, 1), (1, 5)),
    ((3, 3), (3, 3)),
]
for sa, sb in shapes:
    A = np.random.rand(*sa)
    B = np.random.rand(*sb)
    try:
        C = A @ B
        print(f"{sa} @ {sb} → {C.shape}  ✓")
    except ValueError:
        print(f"{sa} @ {sb} → ❌ несовместимо")
```

### 2.3. Слой нейросети

> **Что от тебя требуется:** посчитать **выход слоя нейросети** через одно умножение `W @ x`.

**Дано:**
```python
# Веса слоя: 2 нейрона, 4 входа
W = np.array([
    [0.2, 0.5, -0.1, 0.7],
    [-0.3, 0.4, 0.6, 0.2],
])

# Вход — 4 числа
x = np.array([1.0, 2.0, 3.0, 4.0])
```

**Задачи:**

1. **Какая форма у W? У x?**
   *Ответ:* W: (2, 4). x: (4,).

2. **Посчитай `W @ x`. Какая будет форма?**

   *Подсказка по форме:* `(2, 4) @ (4,) → (2,)`. Получим **2 числа** (по одному на каждый нейрон).

   ```python
   output = W @ x
   print("Выход:", output)
   print("Форма:", output.shape)
   ```

3. **Бонус: добавь bias.**
   ```python
   b = np.array([0.1, -0.2])
   output_with_bias = W @ x + b
   ```

> **Что это значит:** это **простейший слой нейросети без активации**. На Уроке 5 (в Модуле 5) мы вернёмся к этому коду и добавим **функцию активации**.

## Уровень 3. Со звёздочкой

### 3.1. Цвет картинки в чёрно-белый

> **Что от тебя требуется:** превратить **цветную** картинку (RGB) в **чёрно-белую** через одно умножение.

**Идея:** в компьютере цветной пиксель — **3 числа** (R, G, B). Чтобы получить серый:
```
gray = 0.299·R + 0.587·G + 0.114·B
```

Это и есть **скалярное произведение** пикселя на вектор `[0.299, 0.587, 0.114]`.

**Дано — «маленькая картинка» 4×4 пикселя:**
```python
np.random.seed(0)
image = np.random.randint(0, 256, size=(4, 4, 3))
# shape: 4 строки × 4 столбца × 3 цвета
```

**Задачи:**

1. **Покажи форму `image`.** *Ответ:* `(4, 4, 3)`.

2. **Достань первый пиксель** (`image[0, 0]`) — это **3 числа**.

3. **Преврати его в серый:**
   ```python
   gray_filter = np.array([0.299, 0.587, 0.114])
   gray_pixel = image[0, 0] @ gray_filter
   print(gray_pixel)    # одно число
   ```

4. **Бонус: преврати всю картинку в серую через `@`.**
   ```python
   gray_image = image @ gray_filter
   print(gray_image.shape)    # (4, 4) — три канала схлопнулись в один!
   ```

> **Магия:** `(4, 4, 3) @ (3,) → (4, 4)`. NumPy сделал скалярное произведение **по последней оси**. Это broadcasting в действии.

### 3.2. Поворот точки на плоскости

> **Что от тебя требуется:** повернуть точку через **матричное умножение**.

**Идея:** точку `(x, y)` можно повернуть на угол θ умножением на матрицу:
```
R = [[cos θ, -sin θ],
     [sin θ,  cos θ]]
```

**Дано:**
```python
p = np.array([1.0, 0.0])    # точка на оси X
theta = np.pi / 2            # 90° в радианах

R = np.array([
    [np.cos(theta), -np.sin(theta)],
    [np.sin(theta),  np.cos(theta)],
])
```

**Задачи:**

1. **Посчитай `R @ p`.** *Ожидаемое:* `(0, 1)` — точка повернулась на 90°.

   > **Если получилось** `[6e-17, 1]` — это **«вычислительный ноль»**, ошибка float. Используй `np.round(R @ p, 10)`.

2. **Поверни на 180°** (`theta = np.pi`). *Ожидаемое:* `(-1, 0)`.

3. **Бонус: поверни 5 точек одной операцией.**
   ```python
   np.random.seed(0)
   points = np.random.rand(5, 2)        # 5 точек, форма (5, 2)
   theta = np.pi / 4                     # 45°
   R = np.array([
       [np.cos(theta), -np.sin(theta)],
       [np.sin(theta),  np.cos(theta)],
   ])
   rotated = points @ R.T
   print(rotated)
   ```

   > **Магия `@ R.T`:** так как точки в `points` лежат в **строках**, для поворота надо использовать **транспонированную** матрицу поворота. Эквивалентно `(R @ points.T).T`.

   > **Главное:** **одно** матричное умножение поворачивает **все 5 точек** сразу. Никаких циклов!

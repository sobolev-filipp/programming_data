### 1.3. Похожесть товаров

В магазине 4 товара описаны векторами признаков `[цена, качество, популярность]`:
```python
товар1 = np.array([100, 8, 7])
товар2 = np.array([110, 7, 6])
товар3 = np.array([300, 9, 9])
товар4 = np.array([50, 3, 8])
```

Считаем «похожесть» двух товаров через **косинусную похожесть**:
```python
def cos_sim(a, b):
```

3. Похожесть `товар1` и `товар4`.
4. **Какой товар больше всего похож на `товар1`** (исключая его самого)?

## Уровень 3. Со звёздочкой

### 3.1. Цвет картинки в чёрно-белый

В компьютерах цветной пиксель — это 3 числа: красный, зелёный, синий (RGB).
Чтобы превратить его в **оттенок серого**, обычно делают:
```
gray = 0.299 * R + 0.587 * G + 0.114 * B
```

Это скалярное произведение пикселя на вектор `[0.299, 0.587, 0.114]`.

Дана «маленькая картинка» 4×4 пикселя:
```python
np.random.seed(0)
image = np.random.randint(0, 256, size=(4, 4, 3))
# shape: 4 строки × 4 столбца × 3 цвета
```

1. Покажи форму `image`.
2. Достань первый пиксель (`image[0, 0]`) — он должен быть из 3 чисел.
3. Преврати пиксель в серый: посчитай скалярное произведение с `[0.299, 0.587, 0.114]`.
4. **Бонус**: преврати **всю картинку** в серую через `@`. Подсказка: `image @ [0.299, 0.587, 0.114]`. Какая форма получится?

### 3.2. Поворот точки на плоскости

Точку `(x, y)` можно повернуть на угол θ умножением на матрицу поворота:
```
[[cos θ, -sin θ],
 [sin θ,  cos θ]]
```

```python
import numpy as np

# Точка
p = np.array([1.0, 0.0])

# Угол 90° в радианах
theta = np.pi / 2

# Матрица поворота
R = np.array([
    [np.cos(theta), -np.sin(theta)],
    [np.sin(theta),  np.cos(theta)],
])
```

1. Посчитай `R @ p`. Что получилось? (должно быть `(0, 1)` — поворот `(1, 0)` на 90° даёт `(0, 1)`)
2. Поверни ту же точку на **180°** (`theta = np.pi`). Что должно получиться?
3. **Бонус**: дано **5 точек** в виде матрицы 5×2. Поверни все на 45° одной операцией. Подсказка: `points @ R.T`.

### 1.2. Длина вектора (норма)

```python
v = np.array([3, 4])

# Способ 1 — руками через теорему Пифагора
length_manual = np.sqrt((v ** 2).sum())
print(length_manual)              # 5.0
# ── v ** 2 = [9, 16]; сумма = 25; корень = 5

# Способ 2 — встроенная функция
length_np = np.linalg.norm(v)
print(length_np)                  # 5.0
```

### 1.3. Длина в 3D

```python
v3 = np.array([3, 4, 12])

print(np.linalg.norm(v3))         # 13.0
# ── √(9 + 16 + 144) = √169 = 13
```

### 1.4. Расстояние между точками

> **Идея:** расстояние между двумя точками = длина вектора **разности**.

```python
p1 = np.array([1, 2])
p2 = np.array([4, 6])

distance = np.linalg.norm(p2 - p1)
print(distance)                   # 5.0
# ── p2 - p1 = [3, 4]; длина = 5
```

### 2.2. Через NumPy — три способа

```python

print(a @ b)                      # 32 — рекомендуемый стиль
print((a * b).sum())              # 32
```

**Подсветить ученикам:** `@` — новый оператор. Запомните его, дальше будем использовать.

### 2.3. Геометрический смысл

```python
# Угол между векторами
def angle_between(a, b):
    cos_angle = (a @ b) / (np.linalg.norm(a) * np.linalg.norm(b))
    # на всякий случай ограничим, чтобы не было ошибки округления
    cos_angle = np.clip(cos_angle, -1, 1)
    return np.degrees(np.arccos(cos_angle))

# Сонаправлены
print(angle_between([1, 0], [2, 0]))      # 0° — одинаковое направление

# Перпендикулярны
print(angle_between([1, 0], [0, 1]))      # 90°

# Противонаправлены
print(angle_between([1, 0], [-1, 0]))     # 180°
```

### 2.4. Реальный пример: похожесть пользователей

```python
анна = np.array([5, 4, 0, 3, 5])    # её оценки 5 фильмов
борис = np.array([4, 5, 1, 4, 4])
вика = np.array([1, 0, 5, 2, 1])

def similarity(u1, u2):
    """Косинусная похожесть — от -1 до 1."""
    return (u1 @ u2) / (np.linalg.norm(u1) * np.linalg.norm(u2))

print(f"Анна и Борис: {similarity(анна, борис):.3f}")    # ~0.94 — очень похожи
print(f"Анна и Вика:  {similarity(анна, вика):.3f}")     # ~0.40 — слабое сходство
```

> **Обсудить с классом:** на этом принципе работают рекомендации фильмов, музыки, товаров.

## Задание 3. Транспонирование (8 минут)

### 3.1. Простой пример

```python
A = np.array([
    [1, 2, 3],
    [4, 5, 6],
])
print("Исходная A:")
print(A)
print("Shape A:", A.shape)        # (2, 3)

print("\nТранспонированная Aᵀ:")
print(A.T)
print("Shape Aᵀ:", A.T.shape)     # (3, 2)
```

**Объяснить:** строки стали столбцами, столбцы — строками.

### 3.2. Свойства

```python
# Транспонирование транспонирования = исходное
print(np.array_equal((A.T).T, A))      # True

# Сумма не меняется
print(A.sum() == A.T.sum())            # True
```

### 3.3. Транспонирование вектора (нюанс)

```python
v = np.array([1, 2, 3])
print(v.shape)         # (3,) — одномерный
print(v.T.shape)       # (3,) — НЕ изменился! Одномерный вектор «непереворачиваемый»
```

Если хотим из вектора-строки сделать вектор-столбец:
```python
v_col = v.reshape(-1, 1)              # форма (3, 1)
print(v_col.shape)                    # (3, 1)
print(v_col)
# [[1]
#  [2]
#  [3]]
print(v_col.T.shape)                  # (1, 3) — теперь поворачивается
```

> **Совет:** если запутались с формами — пишите `.shape` после каждого шага и сверяйтесь.

## Задание 4. Умножение матриц (17 минут)

### 4.1. Простейший случай 2×2

Сначала **руками на доске**, потом проверяем кодом.

```python
A = np.array([[1, 2],
              [3, 4]])

B = np.array([[5, 6],
              [7, 8]])

C = A @ B
print(C)
# [[19 22]
#  [43 50]]
```

**Разбор с классом:**
```
C[0, 0] = строка 0 A · столбец 0 B = [1, 2] · [5, 7] = 1·5 + 2·7 = 19
C[0, 1] = строка 0 A · столбец 1 B = [1, 2] · [6, 8] = 1·6 + 2·8 = 22
C[1, 0] = строка 1 A · столбец 0 B = [3, 4] · [5, 7] = 3·5 + 4·7 = 43
C[1, 1] = строка 1 A · столбец 1 B = [3, 4] · [6, 8] = 3·6 + 4·8 = 50
```

### 4.2. Проверка размерностей

```python
A = np.random.rand(3, 5)      # форма (3, 5)
B = np.random.rand(5, 2)      # форма (5, 2)

C = A @ B
print(C.shape)                # (3, 2) — внутренние 5 совпали, остались внешние 3 и 2
```

### 4.3. Когда формы НЕ сходятся

```python
A = np.random.rand(3, 5)
B = np.random.rand(4, 2)      # 5 ≠ 4 — несовместимо!

try:
    C = A @ B
except ValueError as e:
    print("Ошибка:", e)
```

**Что делать?** Часто помогает **транспонирование**:
```python
B = np.random.rand(2, 5)      # форма (2, 5)
# A @ B по-прежнему не работает (5 ≠ 2)
# Но:
print((A @ B.T).shape)        # (3, 2) — теперь B.T имеет форму (5, 2), всё сошлось!
```

### 4.4. ВАЖНО: `*` vs `@`

```python
A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])

print("Поэлементно (A * B):")
print(A * B)
# [[ 5 12]
#  [21 32]]
# ── 1*5, 2*6, 3*7, 4*8

print("\nМатричное умножение (A @ B):")
print(A @ B)
# [[19 22]
#  [43 50]]
```

> **Это совершенно разные операции!** В ML почти всегда нужен `@`. Если по ошибке написали `*` — результат будет неверный.

### 4.5. Умножение матрицы на вектор — простейший «слой» нейросети

```python
# Веса слоя (3 нейрона, 4 входа)
W = np.array([
    [0.1, 0.2, 0.3, 0.4],     # веса первого нейрона
    [0.5, 0.6, 0.7, 0.8],     # веса второго
    [0.9, 1.0, 1.1, 1.2],     # веса третьего
])

# Вход (4 числа)
x = np.array([1.0, 2.0, 3.0, 4.0])

# Выход слоя
output = W @ x
print(output)            # [3.0 7.0 11.0]
print(output.shape)      # (3,) — три нейрона дали по одному ответу
```

**Что произошло:**
- `output[0]` = `W[0] · x` = `0.1*1 + 0.2*2 + 0.3*3 + 0.4*4` = `0.1 + 0.4 + 0.9 + 1.6` = `3.0`
- `output[1]` = `W[1] · x` = `0.5 + 1.2 + 2.1 + 3.2` = `7.0`
- `output[2]` = `W[2] · x` = `0.9 + 2.0 + 3.3 + 4.8` = `11.0`

> **Это весь нейрон в одной строке кода.** Запомните этот паттерн — в Модуле 5 мы из него соберём нейросеть.

## Главные мысли

1. **`zip`** идёт по двум спискам параллельно, **`enumerate`** даёт индекс + значение. Оба — замена корявому `range(len(...))`.
2. **Генератор списка** превращает 3 строки цикла в 1 строку.
3. **`if` в конце** генератора — это **фильтр** (включаем элемент или нет). **`if...else` в начале** — это **выбор значения** (включаем всегда). Не путать!
4. Тем же способом строятся **словарь** (`{ключ: значение for ...}`) и **множество** (`{выражение for ...}`).
5. `{}` **с двоеточием** — словарь; `{}` **без двоеточия** — множество.

---

## Друзья цикла — шпаргалка

```python
range(start, stop, step)      # последовательность чисел (stop не входит)
zip(a, b, c, ...)             # параллельный обход, пары/тройки
enumerate(coll, start=0)      # индекс + значение

for i, x in enumerate(items, start=1):
    ...

for x, y in zip(xs, ys):
    ...

dict(zip(keys, values))       # быстрый словарь из двух списков
```

---

## Генератор списка — шпаргалка

```python
# Базовый
[выражение for x in коллекция]
# Пример: [x ** 2 for x in range(10)]

# С фильтром
[выражение for x in коллекция if условие]
# Пример: [x for x in nums if x > 0]

# С выбором значения (тернарник)
[значение_А if условие else значение_Б for x in ...]
# Пример: ["чёт" if x % 2 == 0 else "нечёт" for x in range(10)]

# Вложенный
[выражение for внешн in коллекция1 for внутр in коллекция2]
# Пример: [x for row in matrix for x in row]
```

**Никогда не путай:**
- `if` **в конце** → ФИЛЬТР (включаем или нет).
- `if ... else ...` **внутри выражения** → ВЫБОР значения (включаем всегда).

---

## Генератор словаря и множества

```python
# Словарь
{ключ: значение for x in ...}
# Пример: {x: x ** 2 for x in range(5)}
# Пример со zip: {name: age for name, age in zip(names, ages)}

# Множество (уникальные значения)
{выражение for x in ...}
# Пример: {len(w) for w in words}
```

> `{...}` без двоеточия — это `set`.
> `{ключ: знач, ...}` — это `dict`.

---

## Где это используется в ML

| Кусок кода | Что использует |
|-----------|----------------|
| `predictions = [model.predict(x) for x in datasets]` | Генератор списка |
| `np.array([x ** 2 for x in nums])` | Генератор + конструктор массива |
| `{name: model.score(X, y) for name, model in models.items()}` | Генератор словаря |
| `for i, (x, y) in enumerate(zip(X, y)):` | `zip` + `enumerate` |
| `unique_labels = set(labels)` / `{f(x) for x in data}` | Множество уникальных |

---

## Главные ошибки

| Ошибка | Что значит | Как исправить |
|--------|-----------|---------------|
| `[x if x > 0 for x in nums]` | Перепутан тернарный оператор и фильтр | `[x for x in nums if x > 0]` |
| `for i in range(len(lst)): lst[i]` | Громоздко | `for i, x in enumerate(lst):` |
| `{len(w) for w in words}` ждали словарь | Без двоеточия это множество | Нужен `{w: len(w) for w in words}` |
| `list(zip(a, b))` с разной длиной | `zip` обрежет по короткой | Проверить длины заранее |

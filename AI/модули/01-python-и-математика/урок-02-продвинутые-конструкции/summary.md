## Главные мысли

1. **Генератор списка** превращает 3 строки цикла в 1 строку.
2. **`lambda`** — функция на одну строку, передаётся туда, где нужен «маленький ключ».
3. **`*args`** — «собрать любое число позиционных аргументов в кортеж».
4. **`**kwargs`** — «собрать любое число именованных аргументов в словарь».
5. **При вызове** `*` и `**` делают **обратное**: распаковывают коллекцию в аргументы.

---

## Генератор списка — шпаргалка

```python
# Базовый
[выражение for x in коллекция]
# Пример: [x ** 2 for x in range(10)]

# С фильтром
[выражение for x in коллекция if условие]
# Пример: [x for x in nums if x > 0]

# С выбором значения
[значение_А if условие else значение_Б for x in ...]
# Пример: ["чёт" if x % 2 == 0 else "нечёт" for x in range(10)]

# Вложенный
[выражение for внешн in коллекция1 for внутр in коллекция2]
# Пример: [x for row in matrix for x in row]
```

**Никогда не путай:**
- `if` **в конце** → ФИЛЬТР (включаем или нет).
- `if ... else ...` **внутри выражения** → ВЫБОР значения (включаем всегда).

## Генератор словаря и множества

```python
# Словарь
{ключ: значение for x in ...}
# Пример: {x: x ** 2 for x in range(5)}

# Множество (уникальные значения)
{выражение for x in ...}
# Пример: {len(w) for w in words}
```

> `{...}` без двоеточия — это `set`.
> `{ключ: знач, ...}` — это `dict`.

## `lambda` — шпаргалка

```python
# Шаблон
lambda аргументы: выражение

# Один аргумент
square = lambda x: x ** 2

# Несколько аргументов
add = lambda a, b: a + b

# Использование (главный случай — как ключ)
sorted(books, key=lambda b: b.rating)
max(students, key=lambda s: s.average())
nums.sort(key=lambda x: abs(x))
```

**Правила:**
- Только одно выражение в теле.
- Не больше ~30 символов.
- Чаще передаётся как аргумент, чем сохраняется в переменную.

## `*args` и `**kwargs` — шпаргалка

### Приём

```python
def f(*args, **kwargs):
    print(args)      # кортеж позиционных
    print(kwargs)    # словарь именованных

f(1, 2, 3, name="Иван", age=15)
# args = (1, 2, 3)
# kwargs = {'name': 'Иван', 'age': 15}
```

### Передача (распаковка)

```python
# Распаковка списка/кортежа в позиционные аргументы
def greet(name, age):
    print(name, age)

data = ["Иван", 15]
greet(*data)         # ← звёздочка распаковывает

# Распаковка словаря в именованные
data = {"name": "Иван", "age": 15}
greet(**data)        # ← две звёздочки распаковывают
```

### Полный шаблон

```python
def f(обычный, *args, ключевой=по_умолчанию, **kwargs):
    ...
```

Порядок строгий:
1. Обычные позиционные.
2. `*args`.
3. Именованные с дефолтами.
4. `**kwargs`.

## Где это используется в ML

| Кусок кода | Что использует |
|-----------|----------------|
| `predictions = [model.predict(x) for x in datasets]` | Генератор списка |
| `model.fit(X, y, verbose=1, batch_size=32)` | `**kwargs` (внутри) |
| `sorted(students, key=lambda s: s.score)` | `lambda` |
| `np.array([x ** 2 for x in nums])` | Генератор + конструктор массива |
| `{name: model.score(X, y) for name, model in models.items()}` | Генератор словаря |

---

## Главные ошибки

| Ошибка | Что значит | Как исправить |
|--------|-----------|---------------|
| `[x if x > 0 for x in nums]` | Перепутан тернарный оператор и фильтр | `[x for x in nums if x > 0]` |
| `lambda x: print(x)` (как функция от которой нужен результат) | `print` возвращает `None` | Если нужен результат — `lambda x: x` |
| `def f(*args): args.append(...)` | `args` — это кортеж, не список! | Сначала `list(args)`, потом изменять |
| `f(**list)` | `**` работает только со словарём | `f(*list)` или передать словарь |

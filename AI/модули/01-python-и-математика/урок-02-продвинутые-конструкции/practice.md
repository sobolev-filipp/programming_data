## Задание 1. `zip` и `enumerate` — разминка (13 минут)

Сначала уверенно вспоминаем перебор коллекций — это «строительный материал» для генераторов.

### 1.1. Простой `zip`

```python
students = ["Иван", "Мария", "Пётр", "Ольга"]
grades = [4, 5, 3, 5]

for name, grade in zip(students, grades):
    print(f"{name}: {grade}")
```

### 1.2. `zip` с тремя списками

```python
students = ["Иван", "Мария", "Пётр"]
grades = [4, 5, 3]
subjects = ["алгебра", "информатика", "химия"]

for name, grade, subj in zip(students, grades, subjects):
    print(f"{name} получил {grade} по {subj}")
```

### 1.3. Построить словарь через `zip`

```python
keys = ["name", "age", "grade"]
values = ["Иван", 15, 5]

profile = dict(zip(keys, values))
# {'name': 'Иван', 'age': 15, 'grade': 5}
```

> Запомните эту связку `dict(zip(...))` — через минуту повторим её уже генератором словаря.

### 1.4. `enumerate` — индекс + значение

```python
languages = ["Python", "JavaScript", "Rust", "Go"]

for i, lang in enumerate(languages):
    print(f"{i}: {lang}")
```

**А с другого индекса?**
```python
for i, lang in enumerate(languages, start=1):
    print(f"{i}. {lang}")
# 1. Python
# 2. JavaScript ...
```

### 1.5. Комбинация `enumerate` + `zip`

```python
students = ["Иван", "Мария", "Пётр"]
grades = [4, 5, 3]

for i, (name, grade) in enumerate(zip(students, grades), start=1):
    print(f"{i}. {name} — {grade}")
```

**Подсветить:** скобки `(name, grade)` обязательны, потому что `enumerate` отдаёт пары `(индекс, элемент)`, а элемент здесь — уже пара.

## Задание 2. Генератор списка (18 минут)

Дан кусок кода. Перепиши **в одну строку** через генератор списка. На каждой задаче спрашиваем ученика, как он перепишет — пишем на доске.

### 2.1. Кубы чисел

```python
result = []
for x in range(1, 8):
    result.append(x ** 3)
print(result)   # [1, 8, 27, 64, 125, 216, 343]
```

**Решение:**
```python
result = [x ** 3 for x in range(1, 8)]
```

### 2.2. Длины слов > 3

```python
words = ["я", "ты", "мы", "они", "Россия", "мир"]
result = []
for w in words:
    if len(w) > 3:
        result.append(len(w))
print(result)
```

**Решение:**
```python
result = [len(w) for w in words if len(w) > 3]
```

### 2.3. Преобразование строк в числа с фильтром

Дан список:
```python
data = ["1", "2", "three", "4", "five", "6"]
```

Получить список чисел (`int`), пропустив нечисловые.

**Решение:**
```python
result = [int(s) for s in data if s.isdigit()]
# [1, 2, 4, 6]
```

> **`s.isdigit()`** — метод строки, возвращает `True`, если в строке только цифры.

### 2.4. Чётность словами (фильтр vs тернарник)

Превратить список чисел в список меток «чёт»/«нечёт».

```python
nums = [1, 2, 3, 4, 5, 6, 7, 8]
```

**Решение:**
```python
labels = ["чёт" if x % 2 == 0 else "нечёт" for x in nums]
```

**Подсветить** для класса разницу — это ключевой момент урока:
- `if x % 2 == 0` **в конце** → фильтр (взять не всё).
- `"чёт" if ... else "нечёт"` **в выражении** → выбрать значение, но включаем всегда.

### 2.5. Развернуть матрицу в строку

```python
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
```

Получить плоский список `[1, 2, 3, 4, 5, 6, 7, 8, 9]`.

**Решение:**
```python
flat = [x for row in matrix for x in row]
```

### 2.6. Со звёздочкой: только нечётные клетки матрицы

В матрице 3×3 оставить только нечётные значения.

**Решение:**
```python
result = [x for row in matrix for x in row if x % 2 != 0]
# [1, 3, 5, 7, 9]
```

## Задание 3. Генераторы словаря и множества (12 минут)

### 3.1. Словарь «слово → его длина»

```python
words = ["машина", "учится", "сама", "по", "примерам"]

result = {w: len(w) for w in words}
# {'машина': 6, 'учится': 6, 'сама': 4, 'по': 2, 'примерам': 8}
```

### 3.2. Соединение через `zip`

```python
keys = ["a", "b", "c"]
values = [1, 2, 3]

result = {k: v for k, v in zip(keys, values)}
# {'a': 1, 'b': 2, 'c': 3}
```

> **Сравните с** `dict(zip(keys, values))` из Задания 1.3 — короче, делает то же самое. Покажите оба варианта: генератор нужен, когда по пути надо ещё и **преобразовать** ключ/значение.

### 3.3. Словарь с преобразованием значения

```python
prices = {"хлеб": 50, "сыр": 600, "яблоко": 80}

# Поднять все цены на 10%
new_prices = {name: round(p * 1.1) for name, p in prices.items()}
# {'хлеб': 55, 'сыр': 660, 'яблоко': 88}
```

### 3.4. Множество: сначала «схлопываем» повторы

Прежде чем писать генератор множества, покажите классу **саму идею**: множество убирает дубликаты. Наберите вместе:

```python
grades = [5, 4, 5, 3, 4, 5, 5, 3]
print(set(grades))        # {3, 4, 5}   ← остались только разные
print(len(set(grades)))   # 3           ← три вида оценок
```

> Спросите класс: «сколько чисел было? (8) а сколько разных? (3)». Пусть проговорят, что повторы слились.

### 3.5. Генератор множества — уникальные длины слов

Теперь то же, но с преобразованием. Сначала — генератор **списка** (с повторами), потом меняем `[]` на `{}`:

```python
words = ["кот", "собака", "птица", "рак", "кит"]

print([len(w) for w in words])   # [3, 6, 5, 3, 3]  ← повторы есть
print({len(w) for w in words})   # {3, 5, 6}        ← повторы убрались
```

**Подсветить:** единственное отличие — скобки. Смысл: «какие бывают длины слов?».

### 3.6. Ещё примеры множеств (разобрать 1–2 на выбор)

**Уникальные первые буквы:**
```python
words = ["мама", "мыло", "папа", "брат", "мир"]
print({w[0] for w in words})   # {'м', 'п', 'б'}  ← три «м» стали одной
```

**Сколько разных классов в датасете** (реальная ML-задача):
```python
labels = ["кошка", "собака", "кошка", "птица", "собака"]
print(set(labels))        # {'кошка', 'собака', 'птица'}
print(len(set(labels)))   # 3
```

**Уникальные расширения файлов:**
```python
files = ["cat.jpg", "dog.png", "note.txt", "car.jpg"]
print({name.split(".")[-1] for name in files})   # {'jpg', 'png', 'txt'}
```

### 3.7. Со звёздочкой: уникальные гласные в строке

```python
s = "программирование"
vowels = "аеёиоуыэюя"

result = {c for c in s if c in vowels}
# {'а', 'и', 'о', 'е'}
```

> Здесь сразу и генератор множества, и фильтр `if` в конце. Спросите: «а если бы взяли `[]` вместо `{}`? — получили бы список всех гласных подряд, с повторами».

## Финальная задача: всё вместе (10 минут)

Дан список словарей:

```python
students = [
    {"name": "Иван",  "grades": [4, 5, 5, 3, 4]},
    {"name": "Мария", "grades": [5, 5, 5, 4, 5]},
    {"name": "Пётр",  "grades": [3, 3, 4, 3, 4]},
    {"name": "Ольга", "grades": [4, 4, 5, 5, 4]},
]
```

**Задача:**
> Собери словарь `{имя: средний балл}`, а потом — список имён только тех, у кого средний ≥ 4.5.

### Решение по шагам

**Шаг 1.** Словарь «имя → средний балл» генератором:
```python
avg = {s["name"]: sum(s["grades"]) / len(s["grades"]) for s in students}
# {'Иван': 4.2, 'Мария': 4.8, 'Пётр': 3.4, 'Ольга': 4.4}
```

**Шаг 2.** Отличники — фильтром по словарю:
```python
best = [name for name, m in avg.items() if m >= 4.5]
# ['Мария']
```

> Обе строки — чистые генераторы: словаря и списка. Никаких `for + append`. Именно так выглядит «короткий ML-стиль» — и заметьте, `zip`/`enumerate`, которые мы повторили в начале, тут работают «за кадром» внутри `.items()`.

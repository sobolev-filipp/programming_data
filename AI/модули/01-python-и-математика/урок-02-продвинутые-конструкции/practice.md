## Задание 1. Переписать циклы через генератор списка (20 минут)

Дан кусок кода. Перепиши **в одну строку** через генератор списка. На каждой задаче спрашиваем ученика, как он перепишет — пишем на доске.

### 1.1. Кубы чисел

```python
result = []
for x in range(1, 8):
    result.append(x ** 3)
print(result)   # [1, 8, 27, 64, 125, 216, 343]
```

**Решение:**
```python
result = [x ** 3 for x in range(1, 8)]
```

### 1.2. Длины слов > 3

```python
words = ["я", "ты", "мы", "они", "Россия", "мир"]
result = []
for w in words:
    if len(w) > 3:
        result.append(len(w))
print(result)
```

**Решение:**
```python
result = [len(w) for w in words if len(w) > 3]
```

### 1.3. Преобразование строк в числа с фильтром

Дан список:
```python
data = ["1", "2", "three", "4", "five", "6"]
```

Получить список чисел (`int`), пропустив нечисловые.

**Решение (одним из способов):**
```python
result = [int(s) for s in data if s.isdigit()]
# [1, 2, 4, 6]
```

> **`s.isdigit()`** — метод строки, возвращает `True`, если в строке только цифры.

### 1.4. Чётность словами

Превратить список чисел в список меток «чёт»/«нечёт».

```python
nums = [1, 2, 3, 4, 5, 6, 7, 8]
```

**Решение:**
```python
labels = ["чёт" if x % 2 == 0 else "нечёт" for x in nums]
```

**Подсветить** для класса разницу:
- `if x % 2 == 0` **в конце** → фильтр (взять не всё).
- `"чёт" if ... else "нечёт"` **в выражении** → выбрать значение, но включаем всегда.

### 1.5. Развернуть матрицу в строку

```python
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
```

Получить плоский список `[1, 2, 3, 4, 5, 6, 7, 8, 9]`.

**Решение:**
```python
flat = [x for row in matrix for x in row]
```

### 1.6. Со звёздочкой: только нечётные клетки матрицы

В матрице 3×3 оставить только нечётные значения.

**Решение:**
```python
result = [x for row in matrix for x in row if x % 2 != 0]
# [1, 3, 5, 7, 9]
```

## Задание 3. `lambda` в `sort` и `max` (15 минут)

### 3.1. Сортировка списка кортежей

Список фильмов: `(название, рейтинг, год)`.

```python
movies = [
    ("Матрица", 8.7, 1999),
    ("Интерстеллар", 8.6, 2014),
    ("Зелёная миля", 9.0, 1999),
    ("Один дома", 7.7, 1990),
]
```

**Сортировка по рейтингу (по возрастанию):**
```python
movies.sort(key=lambda m: m[1])
```

**Сортировка по году (по убыванию):**
```python
movies.sort(key=lambda m: m[2], reverse=True)
```

### 3.2. Поиск максимума по ключу

**Найти фильм с самым высоким рейтингом:**
```python
best = max(movies, key=lambda m: m[1])
print(best)    # ('Зелёная миля', 9.0, 1999)
```

### 3.3. `sorted` vs `sort`

Объяснить разницу:

```python
movies.sort(key=lambda m: m[1])   # меняет сам movies, возвращает None
sorted_movies = sorted(movies, key=lambda m: m[1])   # создаёт новый список
```

### 3.4. Сортировка списка объектов

Если на предыдущем уроке проходили класс `Book`:

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

    def __repr__(self):
        return f"Book({self.title!r}, {self.pages})"

books = [Book("A", 100), Book("B", 250), Book("C", 80), Book("D", 500)]

books.sort(key=lambda b: b.pages, reverse=True)
print(books)
# [Book('D', 500), Book('B', 250), Book('A', 100), Book('C', 80)]
```

### 3.5. Со звёздочкой: цепочка сортировок

Отсортировать сначала по году, потом по рейтингу:

```python
movies.sort(key=lambda m: (m[2], m[1]))
```

> Если ключ — кортеж, Python сортирует «по первому полю; при равенстве — по второму».

## Задание 4. `*args` и `**kwargs` (25 минут)

### 4.1. `*args`: сумма любого числа аргументов

Объясняем теорию, потом пишем:

```python
def sum_all(*args):
    total = 0
    for x in args:
        total += x
    return total

print(sum_all(1, 2))          # 3
print(sum_all(1, 2, 3, 4))    # 10
print(sum_all())              # 0
```

**Усложнение: среднее любого числа аргументов.**
```python
def average(*args):
    if not args:
        return 0
    return sum(args) / len(args)
```

### 4.2. `**kwargs`: «карточка профиля»

```python
def print_profile(**kwargs):
    print("--- Профиль ---")
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_profile(name="Иван", age=15, school="Школа 42", hobby="музыка")
```

### 4.3. Комбинация всего

```python
def order(table_number, *dishes, **options):
    print(f"Столик: {table_number}")
    print(f"Блюда: {', '.join(dishes)}")
    print(f"Опции: {options}")

order(7, "пицца", "салат", "сок", delivery=True, payment="карта")
# Столик: 7
# Блюда: пицца, салат, сок
# Опции: {'delivery': True, 'payment': 'карта'}
```

### 4.4. Распаковка при вызове

```python
def greet(name, age, city):
    print(f"Привет, {name}, тебе {age} лет, ты из {city}")

# Список:
data_list = ["Иван", 15, "Москва"]
greet(*data_list)

# Словарь:
data_dict = {"name": "Иван", "age": 15, "city": "Москва"}
greet(**data_dict)
```

**Подсветите для класса:**
- В `def f(*args):` звёздочка означает «собрать».
- В `f(*list)` звёздочка означает «распаковать».
- Один и тот же символ, два разных действия. Это смущает поначалу — это норма.

### 4.5. Реальный сценарий — обёртка-логгер

```python
def log_call(func, *args, **kwargs):
    print(f"Вызываю {func.__name__} с args={args}, kwargs={kwargs}")
    result = func(*args, **kwargs)
    print(f"Результат: {result}")
    return result


def multiply(a, b):
    return a * b


log_call(multiply, 3, 5)
log_call(multiply, a=4, b=7)
```

Объяснить: `log_call` ничего не знает про конкретно `multiply` и его аргументы. Она просто прокидывает их «как есть». Этот паттерн часто встречается в декораторах и обёртках.

## Финальная задача: всё вместе (10 минут)

Дан список объектов (если на 1.1 проходили классы) или список словарей:

```python
students = [
    {"name": "Иван",  "grades": [4, 5, 5, 3, 4]},
    {"name": "Мария", "grades": [5, 5, 5, 4, 5]},
    {"name": "Пётр",  "grades": [3, 3, 4, 3, 4]},
    {"name": "Ольга", "grades": [4, 4, 5, 5, 4]},
]
```

**Задача:**
> Найди топ-2 учеников по среднему баллу.

### Решение по шагам

**Шаг 1.** Добавляем средний балл в каждый словарь (через генератор):
```python
for s in students:
    s["avg"] = sum(s["grades"]) / len(s["grades"])
```

**Шаг 2.** Сортируем по среднему по убыванию:
```python
students.sort(key=lambda s: s["avg"], reverse=True)
```

**Шаг 3.** Берём первые 2:
```python
top_2 = students[:2]
for s in top_2:
    print(f"{s['name']}: средний {s['avg']:.2f}")
```

**В одну цепочку:**
```python
top_2 = sorted(students, key=lambda s: sum(s["grades"]) / len(s["grades"]), reverse=True)[:2]
```

> Вот эта последняя строка — типичный «короткий ML-стиль». Включает в себя: `sorted`, `lambda`, генератор внутри `sum`. Каждая мелочь из урока — здесь.

## Уровень 2. `*args` и `**kwargs`

### 2.1. `multiply_all` — произведение всех аргументов

> **Что от тебя требуется:** написать функцию, которая умножает любое число аргументов.

**Подсказки:**
- `*args` собирает все позиционные аргументы в **кортеж**.
- Чтобы умножить — начни с `result = 1` и в цикле `result *= x`.
- `result = 1` — потому что **«нейтральный элемент»** умножения. Если `args` пустой — вернём 1.

**Шаблон:**
```python
def multiply_all(*args):
    result = 1
    for x in args:
        result *= x
    return result
```

**Проверка:**
```python
multiply_all(2, 3)         # 6
multiply_all(2, 3, 4, 5)   # 120
multiply_all()             # 1
```

### 2.2. `make_html` — построить HTML-тег

> **Что от тебя требуется:** написать функцию, которая строит HTML-тег из имени и атрибутов.

**Подсказки:**
- Тег имеет вид `<имя атрибут1="значение1" атрибут2="значение2"></имя>`.
- Атрибуты приходят через `**kwargs` — это **словарь**.
- Каждый атрибут оформляется как `ключ="значение"`.
- Все атрибуты соединяются пробелом через `" ".join(...)`.

**Шаблон:**
```python
def make_html(tag, **attrs):
    attrs_str = " ".join(f'{key}="{value}"' for key, value in attrs.items())
    if attrs_str:
        return f'<{tag} {attrs_str}></{tag}>'
    else:
        return f'<{tag}></{tag}>'
```

**Проверка:**
```python
print(make_html("a", href="https://example.com", target="_blank"))
# <a href="https://example.com" target="_blank"></a>

print(make_html("img", src="logo.png", width=100, height=50))
# <img src="logo.png" width="100" height="50"></img>

print(make_html("br"))
# <br></br>
```

> **Подсказка:** обрати внимание на **кавычки**. В f-строке `f'{key}="{value}"'` — внешние одинарные, внутренние двойные.

### 3.2. `repeat` — функция-обёртка

> **Что от тебя требуется:** написать функцию, которая вызывает другую функцию **n раз** с одними аргументами и собирает результаты.

**Подсказки:**
- Сигнатура: `def repeat(n, func, *args, **kwargs):` — n, потом сама функция, потом её аргументы.
- Внутри — генератор списка с `n` повторениями.
- Распаковка при вызове: `func(*args, **kwargs)`.

**Шаблон:**
```python
def repeat(n, func, *args, **kwargs):
    return [func(*args, **kwargs) for _ in range(n)]
```

> **Заметь:** `for _ in range(n)` — переменная цикла не нужна (отсюда `_`), важно просто **повторить** n раз.

**Проверка:**
```python
def add(a, b):
    return a + b

repeat(3, add, 5, 7)        # [12, 12, 12]

import random
repeat(5, random.randint, 1, 10)    # 5 случайных чисел от 1 до 10
```

## Шпаргалка (если забыл синтаксис — подглядывай)

```python
[выражение for x in коллекция if условие]   # генератор списка
{k: v for ... in ...}                       # генератор словаря
{x for ... in ...}                          # генератор множества

lambda x: x * 2                             # функция одной строкой

def f(*args):    # args = (1, 2, 3)
def f(**kwargs): # kwargs = {'name': 'Иван'}

f(*list_var)     # распаковка списка
f(**dict_var)    # распаковка словаря
```

### 2.2. `make_html` — собрать HTML-тег

Функция строит тег с любыми атрибутами:

```python
make_html("a", href="https://example.com", target="_blank")
# <a href="https://example.com" target="_blank"></a>

make_html("img", src="logo.png", width=100, height=50)
# <img src="logo.png" width="100" height="50"></img>

make_html("br")
# <br></br>
```

> **Направление:** имена атрибутов заранее неизвестны — их ловят двумя звёздочками в словарь. Дальше пройди по нему и собери для каждого кусочек `имя="значение"`, а потом склей всё вместе. Отдельно продумай **случай без атрибутов** (`make_html("br")`) — чтобы не вылезли лишние пробелы. И следи за кавычками: снаружи и внутри они должны быть разными.

**🤔 Вопрос:** что вернёт `make_html("div", **{"class": "container", "id": "main"})`? Почему словарь можно передать вот так, со звёздочками?

### 3.2. `repeat` — своя функция-обёртка

Напиши функцию, которая вызывает **другую** функцию `n` раз с одними и теми же аргументами и собирает результаты в список:

```python
def add(a, b):
    return a + b

repeat(3, add, 5, 7)             # [12, 12, 12]

import random
repeat(5, random.randint, 1, 10) # 5 случайных чисел от 1 до 10
```

> **Направление:** твоя `repeat` должна уметь принять **любые** аргументы для чужой функции и потом **передать их дальше**. Здесь звёздочки работают в обе стороны — в этом вся соль задачи. Тело удобно собрать генератором из `n` повторов.

**🤔 Вопрос (самый важный за урок):** в объявлении `def repeat(n, func, *args, **kwargs)` звёздочки **собирают** аргументы, а в вызове `func(*args, **kwargs)` — **распаковывают**. Объясни своими словами, почему одни и те же звёздочки делают тут противоположное.

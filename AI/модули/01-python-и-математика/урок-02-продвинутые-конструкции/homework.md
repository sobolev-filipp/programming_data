```python

{x for ... in ...}                          # генератор множества

def f(*args):    # args = (1, 2, 3)
def f(**kwargs): # kwargs = {'name': 'Иван'}
```

### 3.2. `repeat` — функция-обёртка

> **Задача:** написать функцию, которая вызывает другую функцию **n раз** с одними аргументами и собирает результаты.

**Требования:**

```python
def add(a, b):
    return a + b

repeat(3, add, 5, 7)        # [12, 12, 12]

import random
repeat(5, random.randint, 1, 10)    # 5 случайных чисел от 1 до 10
```

**Подсказки:**
- Сигнатура: `def repeat(n, func, *args, **kwargs):`.
- Внутри — генератор списка с `n` повторениями.
- Распаковка при вызове функции: `func(*args, **kwargs)`.

**🤔 Главные вопросы (это самое важное):**

1. В сигнатуре `def repeat(n, func, *args, **kwargs)` звёздочки **собирают** или **распаковывают**? А когда мы пишем `func(*args, **kwargs)` — звёздочки **собирают** или **распаковывают**?
2. Почему `repeat(3, add, 5, 7)` возвращает `[12, 12, 12]` (одинаковые), а `repeat(5, random.randint, 1, 10)` — разные числа?
3. Что вернёт `repeat(0, add, 5, 7)`? Что вернёт `repeat(-1, add, 5, 7)`?

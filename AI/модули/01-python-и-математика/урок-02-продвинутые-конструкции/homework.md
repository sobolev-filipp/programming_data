## Задание 1. Генератор списка — гимнастика (6 баллов, по 1)

Решить **в одну строку**:

1. Список квадратов всех чисел от 1 до 20, **кратных 3**.
2. Список длин всех слов в строке `s = "программирование это весело и круто"`, у которых длина больше 5.
3. Из списка `[12, -7, 0, 8, -3, 5, -1, 9]` получить список **модулей** всех **отрицательных** чисел.
4. Из строки `s = "Hello, World! 2026"` оставить только **цифры**, преобразовать в `int` и положить в список (одни цифры, не числа целиком).
5. Из списка пар `[(1, 'a'), (2, 'b'), (3, 'c'), (4, 'd')]` получить список вторых элементов, **где первый чётный**.
6. Развернуть матрицу `3×3` в строку из `n*n` элементов через **вложенный** генератор:
   ```python
   matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
   # должно получиться [1, 2, 3, 4, 5, 6, 7, 8, 9]
   ```

## Задание 5. `**kwargs` (4 балла)

## Задание 7 (бонусное, +2 балла)

Реализуй функцию-обёртку `repeat(n, func, *args, **kwargs)`, которая вызывает функцию `func` **n раз** с аргументами `args` и `kwargs` и возвращает список результатов.

```python
def add(a, b):
    return a + b

repeat(3, add, 5, 7)
# [12, 12, 12]

import random
repeat(5, random.randint, 1, 10)
# [случайные числа от 1 до 10, 5 штук — например, [3, 7, 1, 9, 4]]
```

Реши **в одну строку** через генератор списка.

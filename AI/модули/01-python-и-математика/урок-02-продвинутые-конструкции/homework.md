## Шпаргалка (если забыл синтаксис — подглядывай)

```python
[выражение for x in коллекция if условие]     # генератор списка с фильтром
[A if условие else B for x in коллекция]       # генератор с выбором значения
{ключ: значение for x in коллекция}            # генератор словаря
{выражение for x in коллекция}                 # генератор множества (set)

lambda x: x * 2                                # функция в одну строку
sorted(данные, key=lambda el: el["поле"])      # сортировка по полю

def f(*args):     # args = (1, 2, 3)   — кортеж
def f(**kwargs):  # kwargs = {'имя': 'Иван'} — словарь
f(*список)        # распаковать список в аргументы
f(**словарь)      # распаковать словарь в именованные аргументы
```

## 🟢 Уровень 1 — базовый (генераторы списков, словарей, множеств)

**1. Квадраты по порядку.** Собери генератором список квадратов чисел от 1 до 10. Должно получиться `[1, 4, 9, 16, 25, 36, 49, 64, 81, 100]`.

**2. Квадраты, но только кратных трём.** Теперь из чисел от 1 до 20 возьми только те, что делятся на 3 без остатка, и возведи их в квадрат. Ожидаемо `[9, 36, 81, 144, 225, 324]`.
> 💡 Фильтр ставится в **конце** генератора; «делится на 3» проверяют через остаток от деления.

**3. Только положительные.** Дан список `[12, -7, 0, 8, -3, 5, -1, 9]`. Собери новый список **модулей** только тех чисел, что **меньше нуля**. Ожидаемо `[7, 3, 1]`.
> 💡 Модуль числа берёт встроенная функция; условие — «число меньше 0».

**4. Длинные слова.** Из списка `["ai", "нейросеть", "ml", "python", "код", "данные"]` оставь только слова длиннее 4 букв. Должно получиться `['нейросеть', 'python', 'данные']`.

**5. Температура в Фаренгейты.** Дан список температур по Цельсию `[0, 10, 20, 30, 37]`. Одной строкой переведи каждую в Фаренгейты по формуле `F = C * 9/5 + 32`. Ожидаемо `[32.0, 50.0, 68.0, 86.0, 98.6]`.

**6. Разбор пар.** Дан список пар `[(1, 'a'), (2, 'b'), (3, 'c'), (4, 'd')]`. Собери **вторые** элементы только тех пар, где **первый чётный**. Ожидаемо `['b', 'd']`.
> 💡 Пару можно сразу разложить на две переменные прямо в `for a, b in ...`.

**7. Чёт или нечёт.** *(новый приём — выбор значения)* Для чисел от 1 до 8 собери список строк: `"чёт"` для чётных и `"нечёт"` для нечётных. Ожидаемо `['нечёт', 'чёт', 'нечёт', 'чёт', ...]`.
> 💡 Здесь фильтр не подойдёт — нужен **тернарный** выбор `A if условие else B` в начале генератора. Почувствуй разницу с задачами 2–3: там мы **отсеивали**, тут **включаем каждое**, но выбираем, что именно.

**8. Словарь кубов.** Собери генератором словарь, где ключ — число от 1 до 8, а значение — его куб. Проверь: `result[5]` должно вернуть `125`.

**9. Уникальные буквы.** Из слова `"программирование"` собери **множество** уникальных букв и выведи, сколько их получилось.
> 💡 Множество — это фигурные скобки **без** двоеточия. Повторы в множество не попадают — поэтому букв будет меньше, чем длина слова.

## 🟡 Уровень 2 — средний (lambda, сортировка, *args/**kwargs)

Для задач 10–14 используй список товаров:

```python
products = [
    {"name": "Яблоко",  "price": 80,  "stock": 50},
    {"name": "Хлеб",    "price": 50,  "stock": 20},
    {"name": "Сыр",     "price": 600, "stock": 8},
    {"name": "Колбаса", "price": 450, "stock": 12},
    {"name": "Печенье", "price": 120, "stock": 30},
]
```

**10. Сортировка по цене.** Отсортируй товары по цене от дешёвых к дорогим и выведи их названия по порядку. Ожидаемо: Хлеб, Яблоко, Печенье, Колбаса, Сыр.
> 💡 И `sorted`, и `min/max` принимают `key` — маленькую функцию «по какому полю сравнивать»; здесь как раз просится `lambda`, достающая цену.

**11. Сортировка по остатку.** Отсортируй те же товары по количеству на складе (`stock`) **от большего к меньшему**. Первым должно идти «Яблоко» (50 штук).

**12. Самый дешёвый.** Найди товар с самой низкой ценой через `min` и выведи его название — «Хлеб».

**13. Самый ходовой запас.** Найди товар с самым большим `stock` через `max`. Должно получиться «Яблоко».

**14. Сортировка слов по длине.** Отсортируй список `["машина", "ai", "python", "ml", "нейросеть"]` по длине слова от коротких к длинным. Ожидаемо: ai, ml, python, машина, нейросеть.

**15. `multiply_all` — перемножить сколько угодно чисел.** Напиши функцию, которая принимает **любое** число аргументов и возвращает их произведение: `multiply_all(2, 3)` → `6`, `multiply_all(2, 3, 4, 5)` → `120`, а вызов без аргументов `multiply_all()` → `1`.
> 💡 «Сколько угодно аргументов» ловит одна звёздочка. Накопитель начинай с 1, а не с 0 — подумай сам, что случится с произведением, если стартовать с нуля.

**16. `average` — среднее любого набора.** Напиши функцию, которая принимает любое число оценок и возвращает их среднее: `average(5, 4, 3)` → `4.0`, `average(5, 5, 4, 5)` → `4.75`. Если чисел не передали вообще — верни `0` (чтобы не делить на ноль).

**17. `describe` — карточка героя.** *(на подумать)* Напиши функцию `describe`, которая принимает любые именованные аргументы и печатает их по строчке. Вызов `describe(name="Ния", level=7, hp=100)` должен вывести три строки: `name: Ния`, `level: 7`, `hp: 100`.
> 💡 Именованные аргументы «сколько угодно» собирает `**kwargs` — внутри это обычный словарь, по нему можно пройти циклом.

## 🔴 Уровень 3 — со звёздочкой (комбинации и распаковка)

**18. Цепочка-однострочник.** Из списка `products` (см. выше) одной строкой собери список **названий** товаров, которые одновременно **дешевле 100** И которых **больше 10 на складе**. Проверь, кто попал в ответ.
> 💡 Это генератор списка с двумя условиями сразу; что достать из товара и как соединить условия — реши сам.

**19. Инвентарь в словарь.** *(на подумать)* Из `products` собери генератором словарь вида `{название: цена}`. Потом одной строкой посчитай общую стоимость всего склада (цена × остаток для каждого товара, всё сложить).
> 💡 Сумму удобно собрать функцией `sum(...)` прямо от генератора.

**20. Своя функция `repeat`.** Напиши функцию, которая вызывает **другую** функцию `n` раз с одними и теми же аргументами и собирает результаты в список:
```python
def add(a, b):
    return a + b

repeat(3, add, 5, 7)              # [12, 12, 12]

import random
repeat(5, random.randint, 1, 10)  # 5 случайных чисел, например [4, 9, 1, 7, 3]
```
> 💡 Твоя `repeat` должна принять **любые** аргументы для чужой функции и **передать их дальше**. Звёздочки тут работают в обе стороны — в этом вся соль. Тело удобно собрать генератором из `n` повторов.

**21. Главный вывод урока.** *(коротко в Markdown-ячейке)* В функции `repeat` ты написал звёздочки дважды: в объявлении `def repeat(n, func, *args, **kwargs)` и в вызове `func(*args, **kwargs)`. Объясни одной-двумя фразами, почему в первом случае звёздочки **собирают** аргументы, а во втором — **распаковывают**. Это и есть главная идея всего урока.

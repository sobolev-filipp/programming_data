## Уровень 1. Обязательная база (выбери минимум 5 из 7)

### 1.1. Генератор списка — гимнастика

Решить **в одну строку**:

1. Список квадратов всех чисел от 1 до 20, **кратных 3**.
2. Из списка `[12, -7, 0, 8, -3, 5, -1, 9]` получить список **модулей всех отрицательных** чисел.
3. Из списка пар `[(1, 'a'), (2, 'b'), (3, 'c'), (4, 'd')]` получить список **вторых элементов**, **где первый чётный**.

### 1.2. Генератор словаря / множества

4. Словарь `{n: n*n*n} ` для n от 1 до 8.
5. Из строки `s = "программирование"` получить **множество уникальных букв**.

### 1.3. `lambda` + сортировка

Дан список товаров:
```python
products = [
    {"name": "Яблоко",   "price": 80,  "stock": 50},
    {"name": "Хлеб",     "price": 50,  "stock": 20},
    {"name": "Сыр",      "price": 600, "stock": 8},
    {"name": "Колбаса",  "price": 450, "stock": 12},
    {"name": "Печенье",  "price": 120, "stock": 30},
]
```

6. Отсортировать товары по цене (по возрастанию). **В одну строку.**
7. Найти товар с самой низкой ценой (`min` + `lambda`). **В одну строку.**

## Уровень 2. `*args` и `**kwargs`

Если успел Уровень 1 — берись за эти.

### 2.1. `multiply_all`

Реализуй функцию `multiply_all(*args)`, которая возвращает **произведение** всех аргументов.

```python
multiply_all(2, 3)         # 6
multiply_all(2, 3, 4, 5)   # 120
multiply_all()             # 1   (нейтральный элемент для умножения)
```

### 2.2. `make_html`

Реализуй функцию `make_html(tag, **attrs)`, которая строит HTML-тег:

```python
make_html("a", href="https://example.com", target="_blank")
# '<a href="https://example.com" target="_blank"></a>'

make_html("img", src="logo.png", width=100, height=50)
# '<img src="logo.png" width="100" height="50"></img>'

make_html("br")
# '<br></br>'
```

Подсказка: используй `" ".join(...)` и генератор по `attrs.items()`.

### 3.1. Цепочка-однострочник

Из списка `products` (см. Уровень 1) получить **список названий** товаров, которые **дешевле 100 и есть в количестве больше 10**. **Одной строкой.**

**Ожидаемый ответ:** `['Хлеб', 'Печенье']`.

### 3.2. `repeat` — функция-обёртка

Реализуй функцию `repeat(n, func, *args, **kwargs)`, которая вызывает `func` **n раз** с аргументами `args` и `kwargs`, возвращает **список результатов**.

```python
def add(a, b):
    return a + b

repeat(3, add, 5, 7)
# [12, 12, 12]

import random
repeat(5, random.randint, 1, 10)
# [3, 7, 1, 9, 4]  # случайные числа
```

Реши **в одну строку** через генератор списка.

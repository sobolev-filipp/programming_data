## Шпаргалка (если забыл синтаксис — подглядывай)

```python
zip(a, b)                                      # пары из двух списков
enumerate(coll, start=1)                       # индекс + значение
dict(zip(keys, values))                        # словарь из двух списков

[выражение for x in коллекция if условие]      # генератор списка с фильтром
[A if условие else B for x in коллекция]       # генератор с выбором значения
{ключ: значение for x in коллекция}            # генератор словаря
{выражение for x in коллекция}                 # генератор множества (set)
```

## 🟢 Уровень 1 — базовый (zip, enumerate, генератор списка)

**1. Квадраты по порядку.** Собери генератором список квадратов чисел от 1 до 10. Должно получиться `[1, 4, 9, 16, 25, 36, 49, 64, 81, 100]`.

**2. Квадраты, но только кратных трём.** Из чисел от 1 до 20 возьми только те, что делятся на 3 без остатка, и возведи их в квадрат. Ожидаемо `[9, 36, 81, 144, 225, 324]`.
> 💡 Фильтр ставится в **конце** генератора; «делится на 3» проверяют через остаток от деления.

**3. Только отрицательные — по модулю.** Дан список `[12, -7, 0, 8, -3, 5, -1, 9]`. Собери новый список **модулей** только тех чисел, что **меньше нуля**. Ожидаемо `[7, 3, 1]`.
> 💡 Модуль числа берёт встроенная функция; условие — «число меньше 0».

**4. Длинные слова.** Из списка `["ai", "нейросеть", "ml", "python", "код", "данные"]` оставь только слова длиннее 4 букв. Должно получиться `['нейросеть', 'python', 'данные']`.

**5. Температура в Фаренгейты.** Дан список температур по Цельсию `[0, 10, 20, 30, 37]`. Одной строкой переведи каждую в Фаренгейты по формуле `F = C * 9/5 + 32`. Ожидаемо `[32.0, 50.0, 68.0, 86.0, 98.6]`.

**6. Чёт или нечёт.** *(новый приём — выбор значения)* Для чисел от 1 до 8 собери список строк: `"чёт"` для чётных и `"нечёт"` для нечётных. Ожидаемо `['нечёт', 'чёт', 'нечёт', 'чёт', ...]`.
> 💡 Здесь фильтр не подойдёт — нужен **тернарный** выбор `A if условие else B` в начале генератора. Почувствуй разницу с задачами 2–3: там мы **отсеивали**, тут **включаем каждое**, но выбираем, что именно.

**7. Прайс из двух списков.** Есть `fruits = ["яблоко", "банан", "вишня"]` и `prices = [80, 60, 150]`. Собери из них словарь `{"яблоко": 80, ...}` одной строкой и выведи его.
> 💡 Списки сначала нужно «состегнуть» в пары — вспомни функцию из разминки; дальше пары превращаются в словарь.

**8. Ценник построчно.** Пройди те же два списка **параллельно** и выведи по строке на каждый фрукт: `яблоко — 80 руб`, `банан — 60 руб`, `вишня — 150 руб`.

**9. Пронумерованный список дел.** Есть `todo = ["учить Python", "сделать ДЗ", "погулять"]`. Выведи его с номерами, начиная с 1:
```
1. учить Python
2. сделать ДЗ
3. погулять
```
> 💡 Чтобы в цикле были и номер, и текст сразу, есть специальная функция-обёртка; начать нумерацию с 1 помогает её параметр `start`.

## 🟡 Уровень 2 — средний (словари, множества, комбинации)

**10. Словарь кубов.** Собери генератором словарь, где ключ — число от 1 до 8, а значение — его куб. Проверь: `result[5]` должно вернуть `125`.

**11. Уникальные буквы.** Из слова `"программирование"` собери **множество** уникальных букв и выведи, сколько их получилось.
> 💡 Множество — это фигурные скобки **без** двоеточия. Повторы в множество не попадают — поэтому букв будет меньше, чем длина слова.

**12. Список с буквами вместо цифр.** Выведи `todo` из задачи 9, но с буквами: `A. учить Python`, `B. сделать ДЗ`, `C. погулять`.
> 💡 Номер по-прежнему берём обёрткой с индексом, а букву получаем из номера через `chr(65 + i)` (65 — это код буквы `A`).

**13. Поднять цены.** Дан словарь `prices = {"хлеб": 50, "сыр": 600, "яблоко": 80}`. Собери генератором **новый** словарь, где каждая цена увеличена на 20% и округлена. Ожидаемо `{'хлеб': 60, 'сыр': 720, 'яблоко': 96}`.
> 💡 Идёшь по `prices.items()`, ключ оставляешь, значение пересчитываешь.

**14. Слова с гласной.** Дан текст `"искусственный интеллект учится сам и помогает человеку"` и `vowels = "аеёиоуыэюя"`. Собери список слов, которые начинаются с гласной. Сколько их?
> 💡 Разбей текст на слова (метод `.split()`), а дальше проверяй **первую** букву каждого слова через `in`.

**15. Инвентарь в словарь.** *(на подумать)* Из списка товаров ниже собери генератором словарь вида `{название: цена}`. Потом одной строкой посчитай общую стоимость всего склада (цена × остаток для каждого товара, всё сложить).
```python
products = [
    {"name": "Яблоко",  "price": 80,  "stock": 50},
    {"name": "Хлеб",    "price": 50,  "stock": 20},
    {"name": "Сыр",     "price": 600, "stock": 8},
    {"name": "Колбаса", "price": 450, "stock": 12},
    {"name": "Печенье", "price": 120, "stock": 30},
]
```
> 💡 Сумму удобно собрать функцией `sum(...)` прямо от генератора: `sum(цена*остаток for ...)`.

## 🔴 Уровень 3 — со звёздочкой

**16. Цепочка-однострочник.** Из списка `products` (см. задачу 15) одной строкой собери список **названий** товаров, которые одновременно **дешевле 100** И которых **больше 10 на складе**. Проверь, кто попал в ответ.
> 💡 Это генератор списка с двумя условиями сразу; что достать из товара и как соединить условия (`and`) — реши сам.

**17. Только нечётные клетки матрицы.** Дана `matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]`. Одной строкой собери плоский список только **нечётных** значений. Ожидаемо `[1, 3, 5, 7, 9]`.
> 💡 Это вложенный генератор (два `for` подряд) плюс фильтр `if` в конце.

**18. Перевернуть словарь.** Дан `ru_to_en = {"кот": "cat", "пёс": "dog", "птица": "bird"}`. Генератором собери обратный словарь `{"cat": "кот", ...}`.
> 💡 Идёшь по `.items()` и меняешь местами ключ и значение.

**19. Главный вывод урока.** *(коротко в Markdown-ячейке)* В задаче 2 ты писал `if` **в конце** генератора, а в задаче 6 — `if...else` **в начале**. Объясни одной-двумя фразами, чем они отличаются: что делает каждый и почему их нельзя перепутать. Это и есть главная идея урока.

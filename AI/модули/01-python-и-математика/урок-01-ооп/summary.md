## Главные мысли

1. **Класс — это чертёж. Объект — конкретное изделие по чертежу.**
2. `__init__` — конструктор. Вызывается, когда создаём объект.
3. `self` — это **сам объект**. Первый параметр **каждого** метода.
4. **Атрибут** — `self.что_то`. Живёт внутри объекта.
5. **Метод** — функция внутри класса. Работает с конкретным объектом через `self`.
6. **Наследование** — один класс автоматически перенимает атрибуты и методы другого.
7. **Зачем это в курсе?** Все ML-модели — объекты классов. Без ООП дальше тяжело.

## Шаблон класса

```python
class ИмяКласса:
    def __init__(self, параметр1, параметр2):
        self.атрибут1 = параметр1
        self.атрибут2 = параметр2

    def метод1(self):
        # код, использующий self.атрибут1, self.атрибут2
        ...

    def метод2(self, доп_параметр):
        # ...
        return что_то

    def __repr__(self):
        return f"ИмяКласса(атрибут1={self.атрибут1!r}, ...)"


# Создание и использование
obj = ИмяКласса("значение1", "значение2")
obj.метод1()
print(obj.атрибут1)
print(obj)         # сработает __repr__
```

## Наследование

```python
class Родитель:
    def __init__(self, a):
        self.a = a

    def method_родителя(self):
        ...


class Потомок(Родитель):
    def __init__(self, a, b):
        super().__init__(a)    # вызвать конструктор родителя
        self.b = b             # свой новый атрибут

    def method_потомка(self):
        ...


obj = Потомок("значение", "ещё значение")
obj.method_родителя()    # унаследовано
obj.method_потомка()     # своё
```

## Главные ошибки и как их избежать

| Ошибка | Что значит | Как исправить |
|--------|-----------|---------------|
| `def метод():` без `self` | Метод не принимает объект | Добавить `self` первым параметром |
| `def __init__(self, x): x = x` | Атрибут не сохранится в объект | Писать `self.x = x` |
| `class Dog(Animal): def __init__(self): self.name = ...` (без `super`) | Конструктор родителя не вызван | Добавить `super().__init__(...)` |
| `print(obj)` показывает мусор `<object at 0x...>` | Нет `__repr__` | Определить `__repr__` |

## Где ООП в реальном коде

```python
from sklearn.linear_model import LinearRegression

model = LinearRegression()       # это объект класса!
model.fit(X, y)                  # вызов метода
predictions = model.predict(X)   # ещё метод
print(model.coef_)               # атрибут — обученные веса
```

> Зная ООП — это понятный код. Не зная — магия.

## Главное правило ООП — чек-лист

Перед тем как начать — **сверься**:

- ✅ `class` с большой буквы.
- ✅ `__init__(self, ...)` — `self` всегда **первый**!
- ✅ Все атрибуты привязаны через `self.`
- ✅ Все методы имеют `self` первым параметром.

### Вариант А. Класс `Pet` (домашний питомец)

> **Задача:** написать класс, описывающий питомца с двумя «шкалами» — голод и счастье.

**Что должен уметь класс:**

1. **Создаваться** с параметрами `name`, `species`, `age`. У всех питомцев `hunger` и `happiness` **начинаются с 50** (не передаются).

2. **Метод `feed()`** — покормить:
   - Если уже не голоден (`hunger == 0`) — напечатать сообщение и не делать ничего.
   - Иначе — уменьшить `hunger` на 20, но **не ниже 0**.

3. **Метод `play()`** — поиграть:
   - Увеличить `happiness` на 15, но **не выше 100**.
   - Увеличить `hunger` на 10, но **не выше 100**.

4. **Метод `status()`** — напечатать состояние в формате:
   ```
   Барсик (кошка, 3 лет): голод 30, счастье 65
   ```

5. **Метод `__repr__`** — `print(pet)` должен выводить:
   ```
   Pet(name='Барсик', species='кошка', age=3)
   ```

**Подсказки по функциям:**
- Чтобы значение не ушло ниже 0 → `max(0, ...)`.
- Чтобы не выше 100 → `min(100, ...)`.
- В `__repr__` для кавычек используй `!r`.

**Проверь сам:**
```python
cat = Pet("Барсик", "кошка", 3)
print(cat)
cat.status()
cat.feed()
cat.play()
cat.play()
cat.status()
```

### Вариант Б. Класс `Rectangle` (прямоугольник)

> **Задача:** написать класс прямоугольника, который умеет считать площадь и периметр.

**Что должен уметь класс:**

1. **Создаваться** с параметрами `width`, `height`.
2. **Хранить** `area` и `perimeter` как **атрибуты** (рассчитываются при создании).
3. **Метод `is_square()`** — возвращает `True`, если квадрат, иначе `False`.
4. **Метод `scale(factor)`** — умножает ширину и высоту на `factor` **И** обновляет `area` и `perimeter`.

**Подсказки:**
- Формулы: `area = width × height`, `perimeter = 2 × (width + height)`.
- В `scale` **самая частая ошибка** — забыть пересчитать `area` и `perimeter` после изменения сторон.

**Проверь сам:**
```python
r = Rectangle(3, 5)
print(r.area)           # 15
print(r.perimeter)      # 16
print(r.is_square())    # False
r.scale(2)
print(r.area)           # должно быть 60
print(r.perimeter)      # должно быть 32
```

**🤔 Вопросы:**

1. Что произошло бы, если бы `area` и `perimeter` были **методами** (с `()`) вместо атрибутов? В чём разница?
2. Если в `scale` забыть пересчитать `area`, то после `r.scale(2)` `r.area` будет **15 или 60**? Объясни почему.
3. Если `width = 5`, `height = 5`, то `is_square()` вернёт `True`. А что если `width = 5.0`, `height = 5`? Будет ли всё ещё `True`?

### Если выбрал Pet → сделай Dog (наследник)

> **Задача:** создать класс `Dog`, который **наследуется** от `Pet`.

**Что добавить:**

1. **Принимает** `name, age, breed` (порода).
2. **`species` фиксирован** как `"собака"` (не передаётся пользователем).
3. **Метод `bark()`** — печатает `<name> говорит: Гав!`.
4. **Свой `__repr__`** в формате `Dog(name='Бадди', age=3, breed='Лабрадор')`.

**Подсказка:** вызови **конструктор родителя** через `super().__init__(...)`. Это даст собаке все атрибуты Pet (включая `hunger`, `happiness`, методы).

**Проверь:**
```python
buddy = Dog("Бадди", 3, "Лабрадор")
print(buddy)
buddy.status()     # должен работать — унаследован!
buddy.feed()       # тоже унаследован
buddy.bark()       # свой
```

**🤔 Вопросы:**

1. Если **забыть** `super().__init__(...)`, что произойдёт при вызове `buddy.status()`? Почему?
2. Можно ли вызвать `buddy.species`? Что вернёт?
3. Что произойдёт, если ты переопределишь `feed()` в `Dog` — будет ли это «ломать» родителя?

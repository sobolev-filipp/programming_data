## Главное правило ООП — шпаргалка

Перед тем как начать — **сверься**:

```python
class ИмяКласса:
    def __init__(self, параметр1, параметр2):    # КОНСТРУКТОР
        self.атрибут1 = параметр1                # сохраняем в объект
        self.атрибут2 = параметр2

    def метод(self):                             # МЕТОД (self обязателен!)
        # код, использует self.атрибут1
        ...

    def __repr__(self):
        return f"ИмяКласса({self.атрибут1!r}, ...)"
```

**Чек-лист — что должно быть:**
- ✅ `class` с большой буквы.
- ✅ `__init__(self, ...)` — `self` первый!
- ✅ Все атрибуты привязаны через `self.`
- ✅ Все методы имеют `self` первым параметром.

## Уровень 1. Обязательная база (выбери ОДНО из двух)

### Вариант А. Класс `Pet` (домашний питомец)

> **Что от тебя требуется:** написать класс, описывающий питомца. У него есть имя, вид, возраст, и две «шкалы» — голод и счастье.

**Шаги:**

**Шаг 1: Каркас класса**
```python
class Pet:
    def __init__(self, name, species, age):
        self.name = name
        self.species = species
        self.age = age
        self.hunger = 50        # ← задаём начальное значение
        self.happiness = 50     # ← задаём начальное значение
```

> **Заметь:** `hunger` и `happiness` **не передаются** в `__init__` — они **всегда** начинаются с 50.

**Шаг 2: Метод `feed()` (покормить)**

Что должно делать:
- Если `self.hunger == 0` — напечатать «Я не хочу есть» и **выйти** (через `return`).
- Иначе — уменьшить `hunger` на 20, но **не ниже 0**.

```python
def feed(self):
    if self.hunger == 0:
        print("Я не хочу есть")
        return
    self.hunger = max(0, self.hunger - 20)    # max(0, ...) гарантирует не ниже 0
```

> **Подсказка:** `max(0, x)` возвращает **большее** из 0 и x. Если x отрицательное → вернёт 0.

**Шаг 3: Метод `play()` (играть)**

Что должно делать:
- Увеличить `happiness` на 15, но **не выше 100** → `min(100, ...)`.
- Увеличить `hunger` на 10, но **не выше 100** → `min(100, ...)`.

```python
def play(self):
    self.happiness = min(100, self.happiness + 15)
    self.hunger = min(100, self.hunger + 10)
```

**Шаг 4: Метод `status()` (показать состояние)**

Должен напечатать строку вида: `Барсик (кошка, 3 лет): голод 30, счастье 65`.

```python
def status(self):
    print(f"{self.name} ({self.species}, {self.age} лет): голод {self.hunger}, счастье {self.happiness}")
```

**Шаг 5: Метод `__repr__`**

```python
def __repr__(self):
    return f"Pet(name={self.name!r}, species={self.species!r}, age={self.age})"
```

> **`!r`** добавляет кавычки вокруг строки. Без него имя будет без кавычек.

**Шаг 6: Проверка**
```python
cat = Pet("Барсик", "кошка", 3)
print(cat)                  # Pet(name='Барсик', species='кошка', age=3)
cat.status()                # Барсик (кошка, 3 лет): голод 50, счастье 50
cat.feed()
cat.play()
cat.play()
cat.status()
```

**Что должно получиться** после двух `play()` и одного `feed()`:
- Голод: 50 - 20 (feed) + 10 + 10 (два play) = **50**.
- Счастье: 50 + 15 + 15 = **80**.

**Если получилось не так:**
- Проверь, что `hunger -= 20`, а не `+= 20`.
- Проверь, что `play()` **увеличивает** счастье, а не уменьшает.

### Вариант Б. Класс `Rectangle` (прямоугольник)

> **Что от тебя требуется:** написать класс прямоугольника, который умеет считать площадь и периметр.

**Шаги:**

**Шаг 1: Каркас**
```python
class Rectangle:
    def __init__(self, width, height):
        self.width = width
        self.height = height
        self.area = width * height                # сразу посчитали
        self.perimeter = 2 * (width + height)     # и здесь сразу
```

> **Важно:** `area` и `perimeter` — это **атрибуты**, не методы! Они сразу хранятся в объекте.

**Шаг 2: Метод `is_square()` (квадрат ли)**
```python
def is_square(self):
    return self.width == self.height        # вернёт True или False
```

**Шаг 3: Метод `scale(factor)` (масштабировать)**

Самая хитрая часть: **обновить area и perimeter** после изменения сторон.

```python
def scale(self, factor):
    self.width *= factor
    self.height *= factor
    # ВНИМАНИЕ: надо ПЕРЕСЧИТАТЬ area и perimeter!
    self.area = self.width * self.height
    self.perimeter = 2 * (self.width + self.height)
```

> **Типовая ошибка:** забыть пересчитать `area` и `perimeter` → они останутся **старыми**.

**Шаг 4: Проверка**
```python
r = Rectangle(3, 5)
print(r.area)           # 15
print(r.perimeter)      # 16
print(r.is_square())    # False (3 ≠ 5)
r.scale(2)
print(r.area)           # 60 (если посчитал правильно)
print(r.perimeter)      # 32
```

**Если получилось не так:**
- `area` после `scale(2)` должна быть **60**, не 15. Если 15 — значит, забыл пересчитать в `scale`.

## Уровень 2. Наследование

> **Только после того, как сделал Уровень 1!**

### Если выбрал Pet → сделай Dog (наследник)

> **Что от тебя требуется:** создать класс `Dog`, который **наследуется** от `Pet`. У собаки будет дополнительный атрибут `breed` (порода) и метод `bark()` (лаять).

**Шаги:**

**Шаг 1: Определи класс**
```python
class Dog(Pet):    # ← Dog наследуется от Pet
    def __init__(self, name, age, breed):
        # ВАЖНО: вызываем конструктор родителя
        # species у собаки всегда "собака" — задаём явно
        super().__init__(name, age=age, species="собака")
        self.breed = breed
```

> **`super().__init__(...)`** — вызов конструктора **родительского** класса. Без этого собака не получит атрибутов `name`, `species`, `age`, `hunger`, `happiness`.

**Шаг 2: Метод `bark()`**
```python
def bark(self):
    print(f"{self.name} говорит: Гав!")
```

**Шаг 3: Свой `__repr__`**
```python
def __repr__(self):
    return f"Dog(name={self.name!r}, age={self.age}, breed={self.breed!r})"
```

**Шаг 4: Проверка**
```python
buddy = Dog("Бадди", 3, "Лабрадор")
print(buddy)              # Dog(name='Бадди', age=3, breed='Лабрадор')
buddy.status()            # унаследован от Pet — работает!
buddy.feed()              # унаследован — работает!
buddy.bark()              # Бадди говорит: Гав!
```

> **Магия:** мы написали в Dog только новое. Все методы Pet (status, feed, play) **автоматически работают** на собаке.

### Если выбрал Rectangle → сделай Square

> **Что от тебя требуется:** создать класс `Square` (квадрат) — частный случай `Rectangle`, у которого ширина равна высоте.

**Шаги:**

**Шаг 1:**
```python
class Square(Rectangle):
    def __init__(self, side):
        # Передаём side и как width, и как height
        super().__init__(side, side)
```

> **Обрати внимание:** `Square` принимает **один** параметр `side`, но в `super().__init__` передаём **два** — `side, side`. Это и делает квадрат «равносторонним прямоугольником».

**Шаг 2: Переопределить `is_square`**
```python
def is_square(self):
    return True    # квадрат всегда квадрат
```

> **Технически** это не обязательно — `width == height` и так даст True. Но явное определение делает код понятнее.

**Шаг 3: Проверка**
```python
s = Square(4)
print(s.area)            # 16 (= 4 × 4)
print(s.perimeter)       # 16 (= 4 × 4)
print(s.is_square())     # True
s.scale(3)
print(s.area)            # 144 (= 12 × 12)
print(s.is_square())     # True (квадрат остался квадратом)
```

> **Магия:** `scale(3)` мы НЕ переопределяли — используется родительский метод. Квадрат с площадью 16 стал квадратом с площадью 144.

## Уровень 3. Со звёздочкой

### Список объектов и поиск

> **Что от тебя требуется:** создать **5 питомцев** (или прямоугольников), положить в список, и через цикл найти «самого несчастного» (или «самый большой по площади»).

**Шаги (для Pet):**

**Шаг 1: Создать 5 питомцев**
```python
pets = [
    Pet("Барсик", "кошка", 3),
    Pet("Рекс", "собака", 7),
    Pet("Кеша", "попугай", 2),
    Pet("Мурка", "кошка", 5),
    Pet("Бим", "собака", 4),
]
```

**Шаг 2: Изменить случайные значения**
```python
pets[0].play()        # Барсик поиграл → счастье 65
pets[1].feed()        # Рекса покормили → голод 30
pets[2].play()        # Кеша играл
pets[2].play()        # Кеша играл ещё раз
pets[3].feed()        # Мурку покормили
```

**Шаг 3: Показать статус каждого**
```python
for pet in pets:
    pet.status()
```

**Шаг 4: Найти самого несчастного**

Через **классический цикл с переменной-«лидером»**:
```python
saddest = pets[0]                    # начинаем с первого
for pet in pets:
    if pet.happiness < saddest.happiness:
        saddest = pet                # нашли более несчастного — запомнили
print(f"\nСамый несчастный: {saddest.name} (счастье {saddest.happiness})")
```

> **Подсказка:** алгоритм «начинаем с первого, перебираем остальных, обновляем лидера, если нашли лучше». Это классический паттерн.

**Если знаешь `min/max + lambda` (из 1.2)** — можно так:
```python
saddest = min(pets, key=lambda p: p.happiness)
```
Но **на этом уроке** ожидается цикл — он надёжнее.

## Задание 1. Класс `Pet` (домашний питомец) — 5 баллов

Создай класс `Pet`:

- Конструктор принимает: `name` (имя), `species` (вид — «кошка», «собака», «попугай», ...), `age`.
- Атрибут `hunger` — голод, число от 0 до 100. Изначально **50**.
- Атрибут `happiness` — счастье, число от 0 до 100. Изначально **50**.
- Метод `feed()` — кормление. Уменьшает `hunger` на 20 (не ниже 0). Если уже не голоден (`hunger == 0`) — выводит «Я не хочу есть».
- Метод `play()` — игра. Увеличивает `happiness` на 15 (не выше 100), но также увеличивает `hunger` на 10 (не выше 100).
- Метод `status()` — выводит:
  ```
  <имя> (<вид>, <возраст> лет): голод 30, счастье 65
  ```
- Перегрузка `__repr__` — `Pet(name='Барсик', species='кошка', age=3)`.

**Проверка (должна работать):**
```python
cat = Pet("Барсик", "кошка", 3)
print(cat)
cat.status()
cat.feed()
cat.play()
cat.play()
cat.status()
```

## Задание 2. Класс `Rectangle` (прямоугольник) — 4 балла

- Конструктор: `width`, `height`.
- Атрибут `area` (площадь) рассчитывается **внутри `__init__`** (не каждый раз заново).
- Атрибут `perimeter` (периметр) аналогично.
- Метод `is_square()` — возвращает `True`, если квадрат.
- Метод `scale(factor)` — умножает ширину и высоту на `factor`, **обновляет** `area` и `perimeter`.

**Проверка:**
```python
r = Rectangle(3, 5)
print(r.area)         # 15
print(r.perimeter)    # 16
print(r.is_square())  # False
r.scale(2)
print(r.area)         # 60
print(r.perimeter)    # 32
```

## Задание 3. Наследование: `Square` от `Rectangle` — 3 балла

Сделай класс `Square`, который наследуется от `Rectangle`.
- Принимает только **один** параметр `side`.
- Вызывает родительский конструктор так, чтобы прямоугольник был квадратом со стороной `side`.
- Метод `is_square()` всегда возвращает `True` (можно ничего не переопределять — родительский и так вернёт `True` для равных сторон, но мы переопределим явно).

**Проверка:**
```python
s = Square(4)
print(s.area)            # 16
print(s.is_square())     # True
s.scale(3)
print(s.area)            # 144 — работает родительский метод!
```

## Задание 6 (бонусное, +2 балла)

Реализуй класс `Calculator`:
- Атрибут `result` (изначально 0).
- Атрибут `history` — список строк вида `"2 + 3 = 5"`.
- Методы `add(n)`, `subtract(n)`, `multiply(n)`, `divide(n)` — изменяют `result` и добавляют запись в `history`.
- При делении на 0 — выводит сообщение, в `history` не записывает.
- Метод `show_history()` — печатает всю историю.
- Метод `reset()` — сбрасывает `result = 0` и очищает `history`.

```python
c = Calculator()
c.add(5)
c.multiply(3)
c.subtract(2)
c.divide(0)        # Деление на ноль невозможно
c.divide(2)
print(c.result)    # 6.5
c.show_history()
```

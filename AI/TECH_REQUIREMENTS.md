# Технические требования к курсу

## 1. Компьютеры для учеников

### Минимальная конфигурация (модули 0–4, 7, 8)

Этого хватит для классического ML, работы с данными и LLM через API.

- **Процессор:** Intel Core i3 (10-го поколения и новее) / AMD Ryzen 3 (3000-й серии и новее)
- **ОЗУ:** 8 ГБ
- **Накопитель:** SSD 256 ГБ
- **Видеокарта:** встроенная, не критично
- **Интернет:** стабильное соединение 20+ Мбит/с (нужно для Google Colab, Hugging Face, скачивания датасетов и API)
- **ОС:** Windows 10/11, macOS 12+, Ubuntu 22.04+

### Рекомендуемая конфигурация (модули 5–6 локально)

Если хотите, чтобы ученики тренировали нейросети **локально**, а не только в Google Colab:

- **Процессор:** Intel Core i5/i7 (12-го поколения и новее) / AMD Ryzen 5/7 (5000-й серии и новее)
- **ОЗУ:** 16 ГБ (32 ГБ — комфортно)
- **Накопитель:** SSD 512 ГБ NVMe
- **Видеокарта:** NVIDIA с поддержкой CUDA, минимум 8 ГБ видеопамяти
  - бюджет: RTX 3060 12 ГБ
  - оптимально: RTX 4060 Ti 16 ГБ / RTX 4070
- **Интернет:** 50+ Мбит/с

> **Важно про видеокарты:** PyTorch и TensorFlow эффективно работают только с NVIDIA (через CUDA). Видеокарты AMD на Windows для обучения нейросетей практически не подходят.
> Видеокарты Apple Silicon (M1/M2/M3/M4) работают через MPS, но многие туториалы заточены под CUDA — у учеников Mac могут быть мелкие проблемы.

### Альтернатива «без мощных компьютеров»: облако

Если бюджет на технику ограничен — **достаточно минимальной конфигурации**, а все тяжёлые вычисления делаем в облаке:

| Сервис | Что даёт | Стоимость |
|--------|----------|-----------|
| **Google Colab** (бесплатный) | Tesla T4 GPU, ограничения по времени | 0 ₽ |
| **Google Colab Pro** | Стабильный доступ к GPU | ~$10/мес |
| **Kaggle Notebooks** | Tesla P100, 30 ч GPU/нед | 0 ₽ |
| **Yandex DataSphere** | Российская альтернатива | оплата по часам |

**Рекомендация:** идти по схеме «минимальные ноуты + Google Colab». Это нормально работает на 95% курса.

## 4. Программное обеспечение

### Обязательное (устанавливаем на уроке 0.2)

| ПО | Зачем | Лицензия |
|----|-------|----------|
| **Python 3.11** (или 3.12) | Основной язык курса | Бесплатно |
| **Anaconda** или **Miniconda** | Менеджер окружений и пакетов | Бесплатно |
| **VS Code** | Редактор кода | Бесплатно |
| **Jupyter Notebook** / **JupyterLab** | Интерактивные тетрадки (идёт с Anaconda) | Бесплатно |
| **Git** | Контроль версий | Бесплатно |
| **GitHub Desktop** (опционально) | GUI для Git | Бесплатно |
| **Google Chrome** или **Firefox** | Для Colab, Kaggle, API-консолей | Бесплатно |

### Аккаунты (регистрируем на уроке 0.2)

- **GitHub** — для хранения и сдачи работ
- **Google** (если ещё нет) — для Google Colab и Google Drive
- **Kaggle** — для датасетов и соревнований
- **Hugging Face** — для готовых моделей (модули 7–8)
- **API-ключ Claude / OpenAI** — для модуля 8 (выдаёт преподаватель, расходы небольшие)

### Python-библиотеки

Устанавливаются по мере прохождения модулей. Финальный набор:

```bash
# Базовые
pip install numpy pandas matplotlib seaborn scipy

# Классический ML
pip install scikit-learn xgboost lightgbm

# Нейросети
pip install torch torchvision   # PyTorch — основной фреймворк курса
pip install tensorflow keras    # альтернатива, опционально

# Компьютерное зрение
pip install opencv-python pillow

# NLP и LLM
pip install transformers datasets huggingface_hub
pip install nltk spacy

# API
pip install anthropic openai

# Дополнительно
pip install jupyter notebook ipywidgets tqdm
pip install gradio streamlit    # для быстрых веб-демо
```

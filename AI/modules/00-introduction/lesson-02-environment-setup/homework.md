## Задание 2. Оформить README репозитория

Открой `README.md` в корне репозитория и сделай его осмысленным. Минимум:

```markdown
# Курс по нейросетям и машинному обучению

Это мой репозиторий с домашними заданиями и проектами курса.

## Обо мне
- Имя: ...
- Класс: ...
- Что хочу научиться делать к концу курса: ...

## Структура
- `homework/` — домашние задания по урокам
- `notebooks/` — Jupyter-тетрадки с занятий
- `projects/` — мини-проекты и финальный проект
```

Закоммить с сообщением `Обновил README`.

## Задание 3. Эксперимент с Markdown

Markdown — это язык разметки, на котором написаны все файлы курса. Освой минимум.

В файле `homework/lesson-0-2/markdown_practice.md` сделай **«шпаргалку по Markdown»**, в которой будут:

- [ ] Заголовки трёх уровней (`#`, `##`, `###`)
- [ ] Жирный (`**`) и наклонный (`*`) текст
- [ ] Маркированный список
- [ ] Нумерованный список
- [ ] Чек-бокс (`- [ ]` и `- [x]`)
- [ ] Гиперссылка на внешний сайт
- [ ] Картинка по ссылке из интернета
- [ ] Цитата (`>`)
- [ ] Блок кода с подсветкой `python`
- [ ] Inline-код (`в обратных кавычках`)
- [ ] Таблица из 2 столбцов и 3 строк

Запушь на GitHub. Проверь, что всё нормально рендерится прямо на странице файла.

> Подсказка: [https://www.markdownguide.org/cheat-sheet/](https://www.markdownguide.org/cheat-sheet/)

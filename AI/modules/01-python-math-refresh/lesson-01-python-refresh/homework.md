## Задание 2. Класс `Movie` (5 баллов)

Реализуй класс `Movie` со следующим функционалом:

- В конструкторе принимает: `title` (str), `year` (int), `genre` (str).
- Хранит атрибут `ratings: list[int]` (от 1 до 10), изначально пустой.
- Метод `add_rating(rating: int)` — добавляет оценку. Если она вне диапазона `[1, 10]` — выводит предупреждение, не добавляет.
- Метод `average_rating() -> float` — среднее. Если оценок нет, возвращает `0.0`.
- Метод `is_classic() -> bool` — возвращает `True`, если фильм вышел до 2000 года И средняя оценка >= 7.
- Перегрузка `__repr__` — чтобы print выглядел как `Movie('Матрица', 1999, action, avg=9.20)`.

**Пример использования (должен работать):**
```python
m = Movie("Матрица", 1999, "action")
m.add_rating(9)
m.add_rating(10)
m.add_rating(8)
m.add_rating(15)   # должно вывести предупреждение
print(m)
print(m.average_rating())
print(m.is_classic())   # True
```

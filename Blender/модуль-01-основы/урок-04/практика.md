# Самостоятельная работа — Урок 4: Светящийся артефакт

> 🧑‍🎓 Делаешь сам(а), применяя SubSurf, Solidify и Emission. Учитель помогает, если застрял.

## Задание

Создай **своё светящееся оружие или магический артефакт**, используя сглаживание и свечение.

**Идеи:**
- Энергетический меч другого цвета/формы
- Магический посох со светящимся кристаллом
- Лазерный пистолет-бластер
- Светящийся амулет / кристалл силы
- Энергетический щит

---

## Требования

- [ ] Использован **Subdivision Surface** хотя бы на одной детали
- [ ] Применены **поддерживающие петли** ИЛИ **Edge Crease** для контроля формы
- [ ] Использован **Solidify** хотя бы раз (плоская деталь → объём)
- [ ] Есть **светящийся элемент** (Emission + Bloom)
- [ ] Финальный **рендер** (F12) в режиме Rendered

---

## Подсказки

**Магический посох:**
1. Древко — длинный цилиндр + `Ctrl+2` + Shade Smooth
2. Навершие — UV Sphere или Ico Sphere с SubSurf
3. Кристалл — куб → масштаб → Edit Mode заострить верх/низ → Emission
4. Обмотка ручки — Torus + Array (как кольца меча)

**Бластер:**
1. Корпус — куб со скруглением (SubSurf + support loops)
2. Ствол — цилиндр
3. Плоские накладки — Plane + Solidify
4. Светящееся дуло / индикатор заряда — Emission

---

## Что сдать

`.blend` + рендер (в режиме Rendered, чтобы было видно свечение).

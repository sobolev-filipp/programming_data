# Лайфхак урока 4 — Управление остротой Subdivision Surface

> SubSurf скругляет всё подряд. Но настоящий мастер заставляет одни углы быть острыми, а другие — мягкими. Есть два способа.

---

## Проблема

Повесил SubSurf на куб — получил «подушку». А нужен скруглённый, но узнаваемый куб с чёткими гранями. Как?

![Без петель куб превращается в шар](изображения/subdivision-куб-сфера.png)

*Чем больше SubSurf — тем круглее. Чтобы сохранить форму, нужны поддерживающие петли.*

---

## Способ 1 — Поддерживающие петли (Support Loops) ⭐

Главный приём. Добавляем петлю рёбер `Ctrl + R` рядом с тем ребром, которое хотим сохранить острым.

**Правило:** чем **ближе** петля к ребру — тем **острее** угол.

### Попробуй на кубе:

1. Куб → `Ctrl + 2` (SubSurf) → стал шаром-подушкой
2. `Tab` → Edit Mode
3. `Ctrl + R` → наведи так, чтобы петли пошли вокруг куба → прокрути колесо до **2 петель** (по одной у каждого угла) → клик → ПКМ
4. Повтори в трёх направлениях (петли по всем осям)
5. `Tab` → куб снова чёткий, но с приятными скруглёнными фасками!

**Двигай петли ближе к ребру** (`G G` — слайд вдоль) → угол становится резче. Отодвигай → мягче.

> 📷 **[Вставь сюда картинку: support loops до и после →](изображения.md#support-loops)**

> Это самый «честный» способ — работает в любом софте, не ломает геометрию.

---

## Способ 2 — Edge Crease (складка ребра) `Shift + E`

Быстрый способ без добавления петель.

1. Выдели ребро (или петлю рёбер `Alt + ЛКМ`)
2. `Shift + E` → двигай мышь к **1.0** → Enter
3. Ребро становится острым под SubSurf, **без** новых петель

**Значение Crease:** 0 = мягкое (как было), 1 = максимально острое. Можно ввести числом: `Shift + E → 1` → Enter.

> 💡 **Фишка:** ребро с Crease подсвечивается **розовым/фиолетовым** в Edit Mode — сразу видно, где складки.

---

## Когда какой способ

| Способ | Плюсы | Минусы |
|--------|-------|--------|
| **Support Loops** | точный контроль, работает везде, переносится в игры | добавляет геометрию |
| **Edge Crease** | быстро, без лишних граней | хуже переносится в игровые движки |

**Совет:** для финальных моделей и игр — Support Loops. Для быстрых набросков — Edge Crease.

## Шпаргалка

| Хочу | Делаю |
|------|-------|
| Повесить SubSurf | `Ctrl + 1/2/3` |
| Убрать SubSurf | `Ctrl + 0` |
| Сохранить ребро острым (надёжно) | `Ctrl + R` петля рядом |
| Сделать ребро острым (быстро) | `Alt+ЛКМ` (петля) → `Shift + E → 1` |
| Острее / мягче угол | петлю ближе / дальше (`G G`) |

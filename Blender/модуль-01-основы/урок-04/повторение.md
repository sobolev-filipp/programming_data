# Повторение урока 3 — Викторина + «вместе» 🚀

> ⏱ 5–7 минут. Формат: **викторина** + быстрое совместное действие на проекторе.

---

## Вопросы

1. Что такое **модификатор**? Чем он удобен?
2. Какой модификатор делает **симметрию** (вторую половину)?
3. Какую галочку включают в Mirror, чтобы половинки не разъезжались по центру?
4. Какой модификатор создаёт **ряд копий**?
5. Что нужно добавить, чтобы копии Array встали **по кругу**?
6. Формула: на сколько градусов повернуть Empty для кольца из **6** копий?
7. Что делает `Ctrl + A → All Transforms` и зачем это перед модификаторами?
8. Что значит **применить (Apply)** модификатор? Можно ли потом его изменить?

---

## Делаем вместе (учитель на проекторе, дети повторяют) 🔁

За 2 минуты собираем **кольцо из 8 кубиков**:
1. Куб → отодвинуть от центра (`G → X → 2`)
2. `Shift + A → Empty` в центре
3. Array → Object Offset → выбрать Empty
4. Повернуть Empty: `R → Z → 45` (360 ÷ 8)
5. Count → 8 → кольцо замкнулось!

> Это разминка перед сборкой лазерного меча, где снова пригодится Array.

---

## Ответы (для учителя)

1. «Умная надстройка», меняет вид не разрушая модель; можно настроить/выключить/удалить
2. Mirror
3. Clipping
4. Array
5. Пустышка (Empty) + Object Offset
6. 360 ÷ 6 = **60°**
7. Обнуляет масштаб до 1.0 (сохранив форму); иначе модификаторы работают криво
8. «Запечь» в геометрию; после Apply изменить настройки нельзя

# Итоговая работа модуля 1 — на оценку

> 🧑‍🎓 Это **итоговая работа модуля**. Ты сдаёшь готовый проект, который показывает всё, чему научился.

---

## Что сдать

**На выбор:**
- 🎁 Игровой сундук (делали на уроке)
- 🏮 Фонарь / лампа
- 📦 Любой предмет окружения для игры (бочка, ящик, колодец, факел, дорожный указатель)

---

## Обязательные требования

Твоя работа должна показать навыки всего модуля:

- [ ] Использован **Edit Mode** (Extrude / Inset / Loop Cut)
- [ ] Использован хотя бы **один модификатор** (Array, Mirror, Bevel, Subdivision или Solidify)
- [ ] Минимум **2 разных материала** (например, дерево + металл)
- [ ] Хотя бы один объект **со скруглением** (Bevel или SubSurf)
- [ ] Аккуратная сборка (детали не торчат случайно, не висят в воздухе)
- [ ] Финальный **рендер** (`F12`)
- [ ] Сохранённый `.blend` файл

## Бонусы (плюс к оценке)

- [ ] Светящийся элемент (Emission) — фонарь, сокровища, руны
- [ ] Радиальный Array (через Empty)
- [ ] Аккуратно настроенный свет в сцене
- [ ] Origin крышки/дверцы выставлен для будущей анимации

---

## Идеи для фонаря

1. Основание — куб/цилиндр со скосом (Bevel)
2. Стеклянная часть — куб/цилиндр, материал Glass или прозрачный
3. Внутри — маленькая сфера с **Emission** (огонёк!) + Bloom
4. Верх — конусная крышка (Cone)
5. Ручка-дужка — Torus или изогнутый цилиндр
6. Декоративные уголки — Array по 4 углам

---

## Как оценивается

| Критерий | Баллы |
|----------|-------|
| Использование Edit Mode | 2 |
| Использование модификаторов | 2 |
| Материалы (минимум 2) | 2 |
| Аккуратность сборки | 2 |
| Рендер + сохранённый файл | 2 |
| **Бонусы** | +до 2 |

# Лайфхак урока 5 — Bevel: инструмент vs модификатор (и Auto Smooth)

> На фаски (скруглённые рёбра) держится «дороговизна» модели. Разберём, когда что использовать.

---

## Два способа сделать фаску

### 1. Инструмент Bevel (`Ctrl + B`)

- Работает в **Edit Mode** на **выделенных** рёбрах
- Сразу «впекается» в геометрию
- Точный контроль конкретного ребра

**Когда:** нужно скосить одно-два конкретных ребра по-разному.

```
Edit Mode → выдели ребро → Ctrl + B → двигай мышь → колесо = сегменты → Enter
```

### 2. Bevel-модификатор ⭐

- Работает на **всём объекте** сразу
- **Неразрушающий** — можно настроить/выключить в любой момент
- Режим **Limit Method → Angle** скашивает только острые рёбра

**Когда:** нужны аккуратные фаски на всей модели (короб, техника, мебель) — быстро и без ручной работы.

```
🔧 → Add Modifier → Bevel → Amount + Segments + Limit: Angle
```

---

## Сравнение

| | Инструмент `Ctrl+B` | Bevel-модификатор |
|---|---------------------|-------------------|
| Где | выделенные рёбра | весь объект |
| Обратимость | нет (впекается) | да (живой) |
| Контроль | точечный | автоматический |
| Лучше для | отдельных рёбер | всей модели разом |

> 💡 **Главный совет:** для новичка Bevel-модификатор с `Limit: Angle` — самый безопасный способ сделать всю модель аккуратной. Поставил один раз — работает на всём.

## Бонус-фишка: Auto Smooth (умное сглаживание)

Проблема: сделал `Shade Smooth` — а острые углы «поплыли», объект выглядит странно.

Решение — **Shade Auto Smooth**:
1. `ПКМ → Shade Auto Smooth`
2. Грани с углом **меньше** порога сглаживаются, **больше** — остаются острыми

Так металлический сундук будет гладким на плоскостях, но с чёткими углами. Идеально для hard-surface.

> 💡 В Blender 4.1 Auto Smooth добавляется как модификатор «Smooth by Angle» — он живой и настраиваемый.

## Шпаргалка

| Хочу | Делаю |
|------|-------|
| Скосить одно ребро | `Ctrl + B` в Edit Mode |
| Аккуратные фаски на всей модели | Bevel-модификатор + Limit: Angle |
| Больше сегментов (плавнее) | колесо мыши во время Bevel |
| Гладко, но с острыми углами | Shade Auto Smooth |

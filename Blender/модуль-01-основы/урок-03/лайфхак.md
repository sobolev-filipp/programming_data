# Лайфхак урока 3 — Array по кругу (радиальный массив через Empty)

> Один из самых полезных приёмов в Blender. Им делают: **зубцы и окна вокруг круглой башни**, колонны вокруг храма, спицы колеса, зубья шестерёнки, лепестки цветка, деления циферблата.

---

## Идея

Обычный Array ставит копии **в ряд**. Но если «сместитель» — это повёрнутая **пустышка (Empty)**, то каждая следующая копия не просто сдвигается, а **поворачивается** вокруг центра. Копии выстраиваются **по кругу**.

Чтобы всё получилось, нужны **две вещи одновременно**:
1. Точка опоры (**Origin**) зубца стоит **в центре** башни, а сам зубец сдвинут на радиус.
2. Empty **повёрнута** (именно повёрнута, не сдвинута!).

Если хоть одно не так — вместо круга выйдет **линия** или **куча**. Разберём по шагам, чтобы точно получилось.

---

## Пошагово: кольцо зубцов вокруг круглой башни

### Шаг 1 — Башня и один зубец

1. `Shift + A → Mesh → Cylinder` → `F9`: **Vertices 12** — круглая башня (стоит в центре мира, 0, 0, 0).
2. `Shift + A → Mesh → Cube` → `S → 0.15` → Enter — маленький зубец.

### Шаг 2 — Отодвинуть зубец, НЕ трогая его точку опоры ⭐ (тут все ошибаются)

Зубец должен вращаться вокруг **центра** башни. Значит его **Origin** (оранжевая точка) обязан **остаться в центре**, а сам кубик — уехать на край.

1. Выдели зубец → `Tab` (**Edit Mode**).
2. `A` — выделить всю сетку кубика.
3. `G → X → 1` → Enter — двигаем **саму сетку** вбок (Origin при этом **остаётся в центре**!).
4. `Tab` — назад в Object Mode.

✅ *Проверь:* оранжевая точка зубца — **в центре башни**, а сам кубик — на радиусе (сбоку).

> ⚠️ **ГЛАВНАЯ ошибка:** не двигай зубец обычным `G` в **Object Mode**! Тогда вместе с кубиком уедет и его Origin — и кольцо не соберётся вокруг центра (получится линия или кривой круг). Двигаем сетку **только в Edit Mode**.

### Шаг 3 — Пустышка (Empty) в центре

1. `Shift + C` — 3D-курсор прыгает в центр мира.
2. `Shift + A → Empty → Plain Axes`.
3. Проверь, что Empty стоит в **0, 0, 0** (панель `N` → Location = 0,0,0; если нет — `Alt + G`).

### Шаг 4 — Связать Array с Empty

1. Выдели **зубец** (не Empty!).
2. 🔧 → **Add Modifier → Generate → Array**.
3. **Сними** галочку **Relative Offset**.
4. **Поставь** галочку **Object Offset** → в поле **Object** выбери свою **Empty**.

✅ *Пока копии сложены в одном месте — это НОРМА:* Empty ещё не повёрнута.

### Шаг 5 — Повернуть ЕМПТИ = магия по кругу ⭐

1. Выдели **Empty** (именно её, НЕ зубец!).
2. `Numpad 7` — вид сверху (так видно круг).
3. `R → Z → 20` → Enter *(для 18 копий: 360 ÷ 18 = 20°)*.

✅ *Копии разошлись по кругу вокруг башни!* 🎉

> Крутим вокруг **вертикальной** оси **Z** (башня стоит вертикально). Можно и в панели `N` вписать Empty → Rotation **Z = 20**.

### Шаг 6 — Подогнать количество

1. Выдели зубец → в Array задай **Count** (например, **18**).
2. Главное правило: **угол поворота Empty × Count = 360°**.

**Формула:** угол = 360 ÷ Count.

| Зубцов (Count) | Поворот Empty |
|----------------|---------------|
| 6 | 60° |
| 8 | 45° |
| 12 | 30° |
| 18 | 20° |
| 24 | 15° |

## ❌ Не получается? Быстрая диагностика

| Что видишь | Причина | Как починить |
|-----------|---------|--------------|
| Копии идут **прямой линией** | **Empty НЕ повёрнута** (или повернули зубец) | Выдели **Empty** → `R Z 20`. Крутить надо Empty, не зубец! |
| Все копии в **одной куче** | Empty в центре и без поворота | Поверни Empty (Шаг 5) |
| Кольцо есть, но **не вокруг башни** / «уплывает» вбок | Origin зубца **не в центре** (двигали в Object Mode) | Переделай Шаг 2 в **Edit Mode**; или курсор в центр (`Shift+C`) → `Object → Set Origin → Origin to 3D Cursor` |
| Кольцо легло **набок / вертикально** | повернули не ту ось | для стоячей башни — ось **Z** (вид сверху `Numpad 7`) |
| Кольцо **не замкнулось** ровно | угол ≠ 360 ÷ Count | пересчитай: угол × Count = 360 |
| Copies есть, но их не видно/«призрачные» точки | это оригинал + пустые копии (нормально во вьюпорте) | добавь материал / глянь в Rendered (`Z`) |

> 💡 Именно «прямая линия вместо круга» — самая частая ошибка: **забыли повернуть Empty**. Первым делом выдели Empty и покрути её по Z.

## Шпаргалка

1. Зубец: сдвинуть **сетку в Edit Mode** (Origin — в центре!)
2. `Shift+C` → `Shift+A → Empty` в центре
3. Array → выкл **Relative**, вкл **Object Offset** → выбрать Empty
4. Выдели **Empty** → `R Z (360 ÷ Count)`
5. Зубец → Array → **Count** до замыкания кольца

> 💡 **Бонус — спираль:** хочешь винтовую лестницу вокруг башни? Кроме поворота, ещё подними Empty: `G → Z → 0.1`. Получишь винтовую расстановку.

# Лайфхак урока 3 — Array по кругу (радиальный массив через Empty)

> Один из самых полезных приёмов в Blender. Им делают: **зубцы и окна вокруг круглой башни**, колонны вокруг храма, спицы колеса, зубья шестерёнки, лепестки цветка, деления циферблата.

---

## Идея

Обычный Array ставит копии **в ряд**. Но если «сместитель» — это вращающаяся **пустышка (Empty)**, то каждая следующая копия не просто сдвигается, а **поворачивается** вокруг центра. Копии выстраиваются **по кругу**.

---

## Пошагово: кольцо зубцов вокруг круглой башни

### Шаг 1 — Круглая башня и один зубец

1. `Shift + A → Mesh → Cylinder` → `F9`: **Vertices: 12** *(круглая башня)*.
2. `Shift + A → Mesh → Cube` → `S → 0.15` → Enter *(маленький зубец)*.
3. Отодвинь зубец на **край** башни: `G → X → 1` *(это будет «радиус» кольца)*.

> ⚠️ Важно: зубец должен стоять **в стороне** от центра башни, иначе кольца не получится — всё схлопнется в одну точку.

### Шаг 2 — Добавить пустышку (Empty)

`Shift + A → Empty → Plain Axes`

Empty — это «невидимый» вспомогательный объект. Он не рендерится, но может управлять другими. Поставь его ровно **в центр** башни (координаты 0, 0, 0).

> 💡 **Фишка:** проверь, что Empty в центре. `Shift + C` ставит 3D-курсор в центр мира; или просто обнули позицию Empty в N-панели (Location = 0, 0, 0).

### Шаг 3 — Связать Array с Empty

1. Выдели **зубец** (не Empty!).
2. Добавь модификатор **Array** (если ещё нет).
3. **Выключи** Relative Offset (сними галочку).
4. **Включи** ✅ **Object Offset**.
5. В поле Object выбери свою **Empty**.

Пока ничего не изменилось — Empty не повёрнута.

### Шаг 4 — Повернуть Empty = магия по кругу

1. Выдели **Empty**.
2. `R → Z → 30` → Enter *(поверни на 30° вокруг вертикальной оси)*.
3. Смотри: зубцы **разошлись по дуге вокруг башни!**

> Ось вращения — та, вокруг которой «крутится» башня (обычно **Z**). Если кольцо легло не в той плоскости — пробуй `R → X` или `R → Y`.

### Шаг 5 — Замкнуть кольцо

- Выдели зубец → в Array увеличивай **Count**.
- Подбери угол поворота Empty и Count так, чтобы зубцы ровно обошли башню.

**Формула:** угол = 360 ÷ количество копий.
- 12 зубцов → поворот Empty на **30°** (360/12)
- 8 зубцов → **45°**
- 6 зубцов → **60°**

> 💡 **Фишка:** хочешь спираль (винтовая лестница вокруг башни)? Кроме поворота, ещё и подними Empty: `G → Z → 0.1`. Получишь винтовую расстановку.

## Где ещё применить

| Объект | Что размножаем по кругу |
|--------|-------------------------|
| 🏰 Башня | зубцы, окна-бойницы вокруг |
| ⚙️ Шестерёнка | зубья |
| 🎡 Колесо обозрения | кабинки |
| 🕐 Часы | деления циферблата |
| 🏛 Храм | колонны вокруг |
| 🌸 Цветок | лепестки |

---

## Шпаргалка

1. Зубец **в стороне** от центра
2. `Shift+A → Empty` в центре
3. Array → выкл **Relative**, вкл **Object Offset** → выбрать Empty
4. Повернуть **Empty** на `360 ÷ Count` градусов
5. Поднять **Count** до замыкания кольца

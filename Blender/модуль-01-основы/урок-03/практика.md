# Самостоятельная работа — Урок 3: Свой космический корабль

> 🧑‍🎓 Делаешь сам(а), применяя Mirror и Array. Учитель помогает, если застрял.

## Задание

Построй **свой** космический корабль или орбитальную станцию, обязательно используя симметрию (Mirror) и массив (Array).

**Идеи:**
- Истребитель с двумя крыльями
- Космическая станция-кольцо (тор + модули по кругу)
- Шаттл с грузовыми контейнерами в ряд
- Боевой крейсер с батареей двигателей

---

## Требования

- [ ] Использован **Mirror** для симметричной части (крылья, корпус)
- [ ] Использован **Array** — линейный ИЛИ по кругу (через Empty)
- [ ] Минимум **5 деталей** (корпус, крылья, двигатели, кабина, антенны…)
- [ ] Хотя бы один элемент со **свечением** (Emission) — сопла или окна
- [ ] Финальный **рендер** (F12)

---

## Подсказки

**Станция-кольцо:**
1. Торус (`Shift+A → Torus`) — основа кольца
2. Модуль (куб) → Array по кругу через Empty → жилые блоки по периметру
3. В центре — сфера или цилиндр (командный модуль), соединить спицами (Array)

**Истребитель:**
1. Корпус — вытянутый цилиндр/куб
2. Одно крыло в Edit Mode (Extrude вбок) → **Mirror X**
3. Кабина — сфера сверху
4. Два двигателя сзади → **Mirror** или **Array**

**Иллюминаторы по кругу:**
- Маленький цилиндр-окно → Array по кругу через Empty вокруг корпуса

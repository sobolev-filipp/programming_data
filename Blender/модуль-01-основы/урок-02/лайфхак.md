# Лайфхак урока 2 — Все способы Extrude (и «ёжик» из куба)

> Extrude — самый используемый инструмент моделирования. Кто знает все его режимы — моделирует быстро и аккуратно. Разберём по порядку.

---

## 1. Region — обычный Extrude (`E`)

Выдавливает выделенные грани **как единое целое**.

- `E` → двигай мышь → клик
- `E → Z → 1` → выдавить ровно на 1 по оси Z

**Где нужен:** башни, ступени, выступы, вытягивание корпуса.

---

## 2. Extrude на месте (`E` → Enter)

Если нажать `E` и сразу Enter (без движения) — грань дублируется **на том же месте**.

**Зачем:** потом её масштабировать или двигать. Классический приём «рамка-углубление»:
1. `E → Enter` *(дубль на месте)*
2. `S → 0.8` → Enter *(уменьшить)*
3. `E → Z → -0.1` → Enter *(вдавить)*

Получается утопленная кнопка с рамкой — за 3 движения.

---

## 3. Extrude Along Normals (`Alt + E` → *Extrude Faces Along Normals*)

Выдавливает грани **перпендикулярно поверхности** каждой грани.

**Зачем:** придать ровную толщину изогнутому объекту (купол, шлем, броня). Обычный `E` тянет в одну сторону, а Along Normals — «раздувает» равномерно во все стороны.

---

## 4. Extrude Individual Faces (`Alt + E` → *Extrude Individual Faces*) ⭐

Каждая выделенная грань выдавливается **в свою сторону, отдельно**.

### Демо «ёжик» (покажи детям — им нравится!):

1. Добавь куб → `Tab` → Edit Mode
2. `A` — выделить все грани
3. `Alt + E` → **Extrude Individual Faces**
4. Двигай мышь — каждая грань вылезает наружу в свою сторону!

Получается «ёжик» / звезда / кристалл.

**Где нужен по-настоящему:** шипы на броне, кристаллы, sci-fi выступы, кнопки на панели сразу пачкой.

> 📷 [изображения.md](изображения.md) → «Extrude Individual Faces — ёжик»

---

## 5. Extrude вдоль оси (`E` → `X` / `Y` / `Z`)

Сразу после `E` нажми ось — выдавливание пойдёт строго по ней. Плюс число для точности: `E → X → 2`.

**Где нужен:** ровные трубы, балки, рельсы — без перекосов.

---

## Шпаргалка

| Хочу | Делаю |
|------|-------|
| Вытянуть выступ | `E` |
| Точно по оси | `E → Z → число` |
| Рамка-углубление | `E→Enter, S→уменьшить, E→вдавить` |
| Равномерная толщина на изгибе | `Alt+E → Along Normals` |
| Шипы/зубцы в разные стороны | `Alt+E → Individual Faces` |
| Меню всех способов | `Alt + E` |

> 💡 **Главное правило:** не помнишь нужный режим — жми `Alt + E`, там всё меню Extrude. А `Ctrl+Z` всегда отменит неудачную попытку.

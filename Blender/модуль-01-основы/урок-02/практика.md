# Самостоятельная работа — Урок 2: Ретро-телевизор 📺

> 🧑‍🎓 Это задание ты делаешь **сам(а)**, применяя инструменты Edit Mode с урока. Учитель помогает, если застрял.

## Задание

На уроке мы делали sci-fi панель. Теперь — другой объект с теми же приёмами: собери **старый ретро-телевизор** (с пузатым экраном, кнопками и антенной-«рожками»).

> 💡 Этот телевизор встанет на полку рядом с роботом из прошлой практики — собираем общую сцену «моя комната».

| ![Ретро-телевизоры — референс](изображения/телевизор-референс.png) | ![Ретро-телевизор — пример](изображения/телевизор-пример.png) |

*Слева — разные ретро-телевизоры (форма корпуса, антенна-«рожки», ручки). Справа — пример готового: пузатый экран со «снегом»-помехами (Emission), кнопки, ножки. Собери **свой** в этом стиле.*

**Из чего состоит:**
- Корпус — куб (можно слегка пузатый)
- Экран — утопленная грань (Inset + Extrude внутрь), светится (Emission)
- Ручки-переключатели — маленькие цилиндры
- Кнопки — через Inset/Extrude
- Антенна — два тонких цилиндра «рожками» (V-образно)
- Ножки — короткие цилиндры

---

## Требования

- [ ] Использован **Inset + Extrude** для экрана (углубление)
- [ ] Использован **Loop Cut** или **Bevel** хотя бы раз
- [ ] Минимум **3 материала** (корпус, экран, ручки)
- [ ] Экран **светится** (Emission) — картинка/шум на экране
- [ ] Аккуратная сборка (антенна, ножки на месте)
- [ ] Рендер (`F12`)

---

## Подсказки

- Экран: выдели переднюю грань → `I` (рамка) → `E → внутрь` (углубление)
- Скруглить корпус ретро-ТВ — лёгкий Bevel по рёбрам
- **«Снег»/помехи на экран** — есть **готовый материал**, его надо просто подгрузить и применить (см. раздел ниже 📥). Материалы мы ещё не проходили — это на будущее, но покажет реалистичный «ненастроенный» телевизор.
- Антенна-рожки: цилиндр → наклонить `R`, продублировать и отзеркалить

## 📥 Готовый материал «ТВ-шум» для экрана 📺❄️

Чтобы экран выглядел как у **ненастроенного телевизора** — со «снегом»-помехами — тебе дали **готовый материал**. Материалы мы подробно изучим позже (Модуль 3), а сейчас просто **подгрузим готовый и применим** к экрану. Это как взять готовую наклейку.

### Что скачать
- Скачай файл **[тв-шум_4_1.blend](./материалы/тв-шум_4_1.blend)** — лежит в папке урока. *(Файл сделан в Blender 4.1 — откроется у всех.)*

### Как применить — по шагам

**Шаг 1. Подгрузить материал из файла (Append).**
1. В Blender: меню **File → Append** (Файл → Добавить).
2. В открывшемся окне зайди в скачанный файл **`тв-шум_4_1.blend`** (двойной клик — он открывается как папка).
3. Внутри открой папку **Material** → выбери материал **`ТВ-шум`** (он там один) → нажми кнопку **Append**.
   ✅ *Должно получиться:* материал `ТВ-шум` теперь **внутри твоего файла** (пока ни на чём не висит — назначим дальше).

**Шаг 2. Выделить грань экрана.**
1. Выдели свой **телевизор** → **`Tab`** (Edit Mode) → нажми **`3`** (режим граней).
2. Кликни по **грани экрана** (та утопленная грань, что делал через Inset+Extrude).
   ✅ *Должно получиться:* грань экрана подсветилась.

**Шаг 3. Назначить материал на экран.**
1. Справа в **Properties** открой вкладку **Материал** 🔴.
2. Нажми **+** (добавить слот материала), затем — кнопку-«шарик» слева от кнопки **New** (выпадающий список материалов) → выбери **`ТВ-шум`**.
3. Убедись, что грань экрана всё ещё выделена, и нажми кнопку **Assign** (Назначить).
   ✅ *Должно получиться:* материал закреплён **только за экраном**, остальной корпус не тронут.

**Шаг 4. Включить телевизор (увидеть свечение).**
1. Выйди из Edit Mode (**`Tab`**). Наведи курсор во вьюпорт → **`Z` → Rendered** (или Material Preview).
2. Убедись, что движок **EEVEE** (Render Properties → Render Engine = EEVEE). Для сияния включи **Bloom** (Render Properties → Bloom ✅).
   ✅ *Должно получиться:* экран покрыт мелким **светящимся «снегом»** — телевизор «работает», но не настроен! 📺

> ⚠️ **Если снега не видно:** проверь, что вьюпорт в **Rendered/Material Preview** (`Z`), а материал назначен именно на **грань экрана** (Edit Mode → выделить грань → **Assign**).

> 💡 **Не хочешь снег?** Можно вместо этого сделать экран просто светящимся (материал → Emission яркого цвета) — но «снег» смотрится куда реалистичнее.

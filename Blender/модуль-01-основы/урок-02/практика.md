# Самостоятельная работа — Урок 2: Свой пульт управления

> 🧑‍🎓 Это задание ты делаешь **сам(а)**, применяя инструменты Edit Mode с урока. Учитель помогает, если застрял.

## Задание

Мы сделали sci-fi панель вместе. Теперь сделай **свою версию** — измени её, добавь детали, придумай что это за панель.

**Идеи:**
- Пульт управления ракетой
- Панель лифта в небоскрёбе
- Пульт диджея
- Консоль медицинского отсека

---

## Что добавить к основной панели

**Задание-минимум:**
- [ ] Добавь минимум **2 новых элемента** которых не было на уроке
- [ ] Используй **Inset + Extrude** хотя бы один раз прямо внутри Edit Mode
- [ ] У каждого элемента свой материал или цвет
- [ ] Хотя бы одна деталь **светится** (Emission)

**Задание-максимум (для быстрых):**
- [ ] Добавь **индикаторные полосы** (тонкие вытянутые кубы)
- [ ] Сделай **рычаг** — длинный цилиндр с шариком на конце
- [ ] Сделай **экран с рамкой** используя Inset
- [ ] Добавь **декоративные полосы** через Loop Cut

---

## Подсказки по деталям

**Рычаг:**
1. Cylinder: `S → 0.1, S → Z → 0.8`
2. Наклонить: `R → X → 30` → Enter
3. Sphere на конце: `Shift + A → UV Sphere, S → 0.2`, прижать к верху рычага

**Индикатор (полоска):**
1. Cube: `S → X → 0.8, S → Z → 0.08, S → Y → 0.05`
2. Материал: яркий зелёный/красный, Emission Strength: 3

**Экран с рамкой (через Edit Mode):**
1. Plane на панели
2. `Tab` → Edit Mode
3. `I` → Inset → Enter
4. Внешняя грань — тёмная рамка, внутренняя — светлый цвет экрана
5. Assign разные материалы каждой зоне

# Материал «ТВ-шум» — как создать и отдать детям 📺❄️

> Файл **для учителя**. Здесь — как за 5 минут собрать материал «снега»/помех для экрана телевизора и сохранить его в `.blend`, чтобы дети на практике просто **подгрузили (Append)** его и применили к экрану (материалы они ещё не изучали — это Модуль 3).
>
> ⚠️ Сам файл `тв-шум.blend` нужно **создать один раз в Blender** (готовый бинарный `.blend` в репозитории не лежит — собери по этой инструкции и сохрани рядом, в эту же папку `материалы/`).

> 🚨 **ВАЖНО — версия Blender. Собирай файл в той же версии, что у детей (Blender 4.1).**
> `.blend` совместим только **назад** (старый файл открывается в новом Blender), но **не вперёд**. Файл, сохранённый в **новой** версии (5.x/4.2+), в **4.1 может не открыться, потерять данные или показать материал иначе**.
> Отдельно: в 4.2+ поменялся движок (**EEVEE Next**), **Bloom убран** (перенесён в компоузер), настройки прозрачности переехали — свечение «снега» может выглядеть не так. В 4.1 (**EEVEE Legacy**) всё как в уроке.
> Если под рукой только новая версия — поставь Blender **4.1** отдельно (портативная сборка с `download.blender.org/release/`, версии не конфликтуют) и собери материал в ней. Весь курс рассчитан на **4.1**, поэтому и все раздаваемые `.blend`-ассеты делаем в 4.1.

---

## Что это за материал

Экран невключённого/ненастроенного телевизора показывает **«снег»** — мелкие случайные чёрно-белые точки, да ещё и **светится**. Соберём это на нодах: случайный шум (**White Noise**) → свечение (**Emission**). Готовый материал назовём **`ТВ-шум`**.

---

## Часть 1. Собираем материал (нодами)

1. Открой Blender, добавь любой объект-«подопытный» (например, `Shift+A → Mesh → Plane`).
2. Вверху переключись на раскладку **Shading**.
3. В **Shader Editor** (нижнее окно) нажми **New** — создался материал с нодом **Principled BSDF**.
4. **Переименуй материал** сразу: сверху в Shader Editor (или в Properties → вкладка Материал 🔴) двойным кликом по имени впиши **`ТВ-шум`**.
5. Удали **Principled BSDF** (выдели его, `X`) — вместо него соберём свою цепочку.
6. Добавь три нода (`Shift+A`):
   - **Input → Texture Coordinate**
   - **Texture → White Noise Texture** — у него в шапке выбери размерность **3D**
   - **Shader → Emission**
7. Соедини по сокетам:

```
[Texture Coordinate] ──(Generated)──► [White Noise Texture] ──(Value)──► [Emission] ──(Emission)──► [Material Output]
                                          (3D)                              Strength = 1.5              Surface
```

8. На ноде **Emission** поставь **Strength = 1.5** (экран светится, но не «выжигает»).
9. Проверь: переключи вьюпорт в **Rendered** (`Z → Rendered`) на движке **EEVEE** — плоскость покрыта мелким светящимся «снегом». Готово.

### 🧩 Что делает каждый нод

| Нод | Аналогия | Что делает | Сокеты |
|-----|----------|-----------|--------|
| **Texture Coordinate** | «адрес точки» | даёт координаты каждой точки поверхности | выход **Generated** → вход White Noise |
| **White Noise Texture** | «телевизионный снег» | для каждой точки выдаёт **случайное** число → мелкие ч/б точки | вход Vector, выход **Value** (ч/б) / **Color** (цветной) |
| **Emission** | «лампочка» | заставляет экран **светиться** этим узором | вход Color/Strength → выход Emission |
| **Material Output** | «розетка» | финал материала | вход Surface |

> 💡 **Крупнее/мельче зерно:** между Coordinate и White Noise можно вставить `Vector → Mapping` и покрутить **Scale** (больше — мельче снег). Не обязательно.
>
> 💡 **Цветной снег** (как на некоторых ТВ): вместо `Value` подключи выход **Color** White Noise в Emission Color.
>
> 💡 **Мерцающий снег** (по желанию, это уже Модуль 6): у White Noise возьми размерность **4D**, на вход **W** поставь драйвер `#frame` — снег будет меняться каждый кадр. Для статичного рендера не нужно.

## Часть 2. Экспорт — сохраняем, чтобы дети подгрузили

В Blender материал «отдают» не отдельным файлом, а **внутри `.blend`**, откуда его берут командой **Append**. Чтобы материал сохранился, даже если он не висит ни на одном видимом объекте:

1. В Properties → вкладка **Материал** 🔴 рядом с именем `ТВ-шум` нажми кнопку **Fake User** (иконка-**щит** 🛡️).
   - Это критично! Без Fake User Blender удалит «неиспользуемый» материал при сохранении, и дети не найдут его в Append.
2. **File → Save As…** → сохрани файл как **`тв-шум.blend`** в эту же папку:
   `модуль-01-основы/урок-02/материалы/тв-шум.blend`
3. Готово — этот `.blend` кладём в репозиторий, дети скачивают его вместе с уроком.

> ✅ **Проверка:** открой **новый** пустой файл → `File → Append` → зайди в `тв-шум.blend` → папка **Material** → там должен лежать **`ТВ-шум`**. Если лежит — экспорт удался.

> 🧩 **Ещё удобнее (по желанию) — Asset Browser:** в Shader Editor ПКМ по материалу → **Mark as Asset**. Если папку `материалы/` добавить как Asset Library (Preferences → File Paths → Asset Libraries), дети смогут просто **перетаскивать** материал из Asset Browser на объект. Но для практики достаточно простого **Append**.

## Часть 3. Как дети это применят (кратко — подробно в практике)

1. `File → Append` → `тв-шум.blend` → папка **Material** → `ТВ-шум` → **Append**.
2. Выделить телевизор → **Edit Mode** (`Tab`) → режим граней (`3`) → выделить **грань экрана**.
3. Properties → Материал 🔴 → добавить слот **+** → в слоте через выпадающий список выбрать **`ТВ-шум`** → нажать **Assign**.
4. `Z → Rendered` → на экране светящийся «снег». 📺

Полные шаги с «✅ Должно получиться» — в [практика.md](../практика.md).

## Возможные проблемы

| Симптом | Причина | Решение |
|---------|---------|---------|
| В Append нет `ТВ-шум` в папке Material | не нажат **Fake User** перед сохранением | вернуться в файл-исходник, нажать 🛡️, пересохранить |
| Снег не светится | вьюпорт в Solid / движок не EEVEE | `Z → Rendered`, Render Engine = EEVEE |
| Снег слишком яркий/тусклый | Emission Strength | подправить Strength (1.0–2.0) |
| Материал лёг на весь ТВ, а не на экран | не выделена грань перед **Assign** | Edit Mode → `3` → выделить грань экрана → Assign |
| Снег «крупными пятнами», не мелкий | подключён Noise вместо **White Noise** | проверь, что нод именно **White Noise Texture** |

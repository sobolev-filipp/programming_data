# Самостоятельная работа — Урок 39: Разверни и раскрась монстра 🎨👹

> 🧑‍🎓 Делаешь сам(а): сделай монстру UV, кожу с SSS и раскрась его. Учитель помогает, если застрял.

## Задание

Возьми low-poly монстра (уроки 37–38 с запечёнными картами) и **заверши его**: аккуратная **симметричная UV** → материал **кожи с Subsurface** → **раскраска** (тон, глаз, рот, фактура).

> 🎬 У Майка: один тон тела (зелёный) + лёгкий **SSS**, ярко раскрашенный **большой глаз** (радужка, зрачок, блик), розоватый **рот**, пятна/неровности кожи.

---

## Этапы (делай по порядку)

1. **Швы:** в незаметных местах (под руками, по внутренней стороне ног, по спине). `Ctrl+E → Mark Seam`.
2. **Развернуть:** `A → U → Unwrap`; проверь Checker (без сильных растяжений).
3. **Симметрия UV:** наложи половины друг на друга (Mirror U в модификаторе **или** UV → Mirror X + придвинуть). Красить будешь один раз на обе стороны.
4. **Кожа:** материал → Base Color (цвет монстра) + **Subsurface Weight** 0.1–0.2, **Radius** чуть красноватый. Подключи запечённые **Normal** и **AO** (урок 38).
5. **Раскраска:** Texture Paint → New paint slot → симметрия X → нарисуй **глаз** (радужка/зрачок/блик), **рот/губы**, **пятна**, румянец/фактуру.
6. **Сохрани:** Save As картинки + **Pack Resources**.

---

## Требования

- [ ] Швы в **незаметных** местах; развёртка без сильных растяжений
- [ ] **Симметричная UV** (половины наложены)
- [ ] Материал кожи с **Subsurface (SSS)**
- [ ] Подключены запечённые **Normal** + **AO** с урока 38
- [ ] **Раскрашен** (минимум: тон + глаз + рот), использована **симметрия**
- [ ] Карты **сохранены** (Save As + Pack Resources)

---

## 💡 Подсказки (если что-то забыл)

- **Швы:** Edit Mode → `2` → `Alt+ЛКМ` петля → `Ctrl+E → Mark Seam`
- **Развернуть:** `A → U → Unwrap`; раскладка **UV Editing**
- **Симметрия UV:** модификатор Mirror → **Mirror U** перед Apply; или **UV → Mirror X** + наложить ([лайфхак](лайфхак.md))
- **Кожа:** Principled → **Subsurface Weight** (немного!) + **Radius** красноватый
- **Карты ур.38:** Image (Non-Color) → **Normal Map** → Normal; AO → **Mix Multiply** в Base Color
- **Покраска:** Texture Paint → Tool → Texture Slots `+` → Base Color → New; **симметрия X**; кисть Draw
- **Сохрани:** Save As + **Pack Resources**

---

## Что сдать

`.blend` (с Pack Resources) + рендер монстра (лицо крупно + общий план). Видно: кожа с SSS, раскрашенный глаз/рот, рельеф со скульпта.

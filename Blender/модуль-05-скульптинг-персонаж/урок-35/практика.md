# Самостоятельная работа — Урок 35: Собери тело своего монстра 🧍👹

> 🧑‍🎓 Делаешь сам(а): собери **тело** монстра с урока 34 (или своего). Учитель помогает, если застрял.

## Задание

Возьми голову/тело-«яйцо» монстра с урока 34 и **собери ему тело**: тонкие руки и ноги (как у Майка), при необходимости — туловище. Используй **базу из объёмов → Voxel Remesh → Grab/Clay Strips**.

> 🎬 Майк — отличный пример: к телу-«яйцу» приделай **две тонкие руки** (с кистями позже) и **две тонкие ноги** (со ступнями позже). Сегодня — гладкие «колбаски» правильной длины и позы.

### Как собрать тело Майка
1. Тело-«яйцо» уже есть (урок 34).
2. **Руки/ноги:** вытянутые тонкие сферы/цилиндры (`S` сузить, `S → Z` вытянуть), приставь **внахлёст** к телу — 2 руки по бокам, 2 ноги снизу.
3. `Ctrl+J` объединить → **Sculpt Mode → Voxel Remesh** (Voxel Size ~0.05) → конечности срослись с телом.
4. **Grab** — поза и пропорции (длинные тонкие ноги, чуть согнутые руки), **Shift**-Smooth стыки.

---

## Требования

- [ ] Тело собрано из **объёмов** (тело + руки + ноги, внахлёст)
- [ ] Применён **Voxel Remesh** — всё стало одной гладкой фигурой
- [ ] Пропорции узнаваемы (для Майка — тонкие длинные конечности, круглое тело)
- [ ] Поза задана **Grab**, стыки сглажены (**Shift**)
- [ ] Только **крупные формы** (кисти/ступни/пальцы — позже, урок 36)
- [ ] Файл сохранён

---

## 💡 Подсказки (если что-то забыл)

- **Объёмы:** `Shift+A → Mesh → UV Sphere`; тонкие конечности — `S` сузить + `S → Z` вытянуть
- **Нахлёст обязателен** — иначе Remesh не склеит
- **Объединить:** выдели всё (`A`) → `Ctrl+J`
- **Remesh:** Sculpt Mode → шапка **Remesh** → Voxel Size 0.05 → кнопка **Remesh** (или `Ctrl+R`)
- **Симметрия X** — правь обе стороны разом
- **Grab** — поза/пропорции; **Clay Strips** — массы; **Shift** — сгладить
- Каша в сетке? → **Voxel Remesh** ещё раз (см. [лайфхак](лайфхак.md))

# Самостоятельная работа — Урок 34: Вылепи свою голову/существо 👽

> 🧑‍🎓 Делаешь сам(а): слепи **другую** голову, не такую, как на уроке. Учитель помогает, если застрял.

## Задание

Вылепи из шара **голову** — но **другого** персонажа (не такого, как лепили вместе). Соблюдай принцип **крупное → среднее → мелкое** и пропорции (глаза посередине!). Симметрия X — включена.

**Идеи (выбери одну):**
- 👹 Орк/тролль (тяжёлая челюсть, клыки, нос-картошка)
- 🧝 Эльф (тонкие черты, острые уши, большие глаза)
- 🐲 Дракончик (морда, рога, гребень, ноздри)
- 🤖 Робот-голова (но мягкими формами — стилизовано)
- 😺 Кот/зверь (морда, уши, щёки)
- 👴 Старик/гном (морщины, борода-объём, крупный нос)
- 👽 Инопланетянин (огромные глаза, маленький рот)

---

## Требования

- [ ] База-шар, `Shade Smooth`, `Ctrl+A`
- [ ] Включены **Matcap**, **симметрия X**, **Dyntopo** (Detail Size средний)
- [ ] Сначала **крупная форма** (Grab), потом массы (Clay Strips), потом детали
- [ ] Узнаваемые **черты лица** по пропорциям (глаза посередине)
- [ ] Хотя бы одна **характерная деталь** (рога/уши/нос — Snake Hook)
- [ ] Поверхность сглажена (**Shift**-Smooth), силуэт проверен со всех сторон
- [ ] Файл сохранён

---

## 💡 Подсказки (если что-то забыл)

- **Войти в лепку:** список режимов (слева вверху) → **Sculpt Mode**
- **Глиняный вид:** шейдинг **Solid → Matcap**
- **Кисти:** левая панель (`T`): Grab, Clay Strips, Snake Hook, Draw, Crease, Inflate, Pinch
- **Сгладить:** зажми **`Shift`** + веди кистью
- **Вдавить вместо нарастить:** зажми **`Ctrl`**
- **Размер/сила кисти:** `F` / `Shift+F`
- **Dyntopo:** шапка → Dyntopo ✅, Detail Size ~15 (тормозит → больше число)
- **Глаза — посередине головы!** (частая ошибка — слишком высоко)
- **Порядок:** силуэт → массы → детали (не прыгай сразу к морщинам)

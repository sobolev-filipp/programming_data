# Лайфхак урока 34 — Симметрия оси X в скульптинге

> Лицо и тело симметричны. Скульпт умеет **зеркалить** мазки: лепишь одну сторону — вторая повторяется сама. Это экономит половину работы и держит лицо ровным.

---

## Где включить / проверить

1. В **Sculpt Mode**: вверху справа в шапке 3D-вида есть кнопки симметрии (иконки осей **X / Y / Z**), либо **Properties → вкладка Active Tool → раздел Symmetry**.
2. Для лица нужна ось **X** (она включена по умолчанию).

✅ *Результат:* проводишь кистью слева от центра — справа появляется зеркальный мазок.

---

## Как лепить асимметричные детали

Иногда нужно сделать что-то **только с одной стороны** (шрам, повязка на один глаз, скол рога):
1. **Выключи** ось **X** в Symmetry.
2. Слепи деталь на нужной стороне.
3. Хочешь снова симметрично — **включи** X обратно.

---

## Тонкости

| Хочу | Делаю |
|------|-------|
| Зеркалить лицо | Symmetry → **X** ✅ |
| Шрам/деталь на одной стороне | временно **выключить X** |
| Объект «сместился» — симметрия мажет мимо | `Object → Set Origin → Origin to Geometry`; центр должен быть по оси |
| Зеркалить по верх/низ или перёд/зад | включить **Y** или **Z** (редко) |

> ⚠️ **Важно — симметрия считается от центра объекта (Origin) по оси X.** Если до скульпта объект был сдвинут и не применён `Ctrl+A`, зеркало «уедет». Поэтому в начале урока мы делали `Ctrl+A → All Transforms`.

> 💡 **Главная мысль:** симметрия X — твой друг для лица и тела. Лепишь половину — получаешь целое. А для «изюминки» (асимметрии) её на минутку выключаешь.

# Самостоятельная работа — Урок 38: Запеки детали монстра 🔥

> 🧑‍🎓 Делаешь сам(а): перенеси детали скульпта монстра на его чистую сетку запеканием. Учитель помогает, если застрял.

## Задание

Возьми **скульпт** монстра (урок 36) и его **low-poly** (урок 37). Сделай быструю UV, запеки **Normal** и **AO** со скульпта на low-poly, победи артефакты **Cage**. Лёгкая сетка должна выглядеть как скульпт.

> 🎬 У Майка проверь чистоту запекания на **пальцах** и вокруг **большого глаза** — там чаще всего нужны Cage и подбор Ray Distance.

---

## Этапы (делай по порядку)

1. **UV:** low-poly → `Tab → A → U → Smart UV Project → OK → Tab`.
2. **Движок:** Render → **Cycles**.
3. **Холст:** Shader Editor low-poly → Image Texture → **New** (`монстр_normal`, 2048, **Non-Color**) → выдели.
4. **Выделение:** скульпт → `Shift` low-poly (активна) → Bake: **Normal**, **Selected to Active** ✅, Extrusion ~0.05, Ray Distance ~0.1 → **Bake**.
5. **Подключи:** Image → **Normal Map** → Principled [Normal]; спрячь скульпт — проверь, что low-poly «как скульпт».
6. **AO:** новый Image (`монстр_ao`, Non-Color) → Bake **Ambient Occlusion** → подмешай Multiply к цвету.
7. **Cage:** если на пальцах/глазу полосы — включи **Cage**, подбери Extrusion, перепеки.
8. **Сохрани:** Save As карт + **Pack Resources**.

---

## Требования

- [ ] У low-poly есть **UV** (Smart UV Project)
- [ ] Запечена **Normal** (Cycles, Selected to Active) и подключена через Normal Map
- [ ] Запечён **AO**, подмешан к Base Color
- [ ] Артефакты убраны **Cage / Ray Distance**
- [ ] Low-poly со спрятанным скульптом **выглядит детально**
- [ ] Карты **сохранены** (Save As + Pack Resources)

---

## 💡 Подсказки (если что-то забыл)

- **UV:** `U → Smart UV Project`
- **Движок:** Render Properties → **Cycles**
- **Мишень:** Image Texture **New** (Non-Color), оставить **выделенным**
- **Порядок:** high (скульпт) → `Shift` low (активна) → **Selected to Active** ✅
- **Типы:** Bake Type **Normal**, потом **Ambient Occlusion**
- **Подключить Normal:** Image (Non-Color) → **Normal Map** → Principled [Normal]
- **Артефакты на пальцах/ушах:** **Cage** + Cage Extrusion (см. [лайфхак](лайфхак.md))
- **Сохранить:** Save As + **Pack Resources**

`.blend` (скульпт + low-poly с картами) + рендер low-poly (скульпт спрятан) — видно детали скульпта на лёгкой сетке.

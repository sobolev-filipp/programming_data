## Часть 1 — Теория: запекание на персонаже и Multires (20 минут)

### 1.1 Зачем (повтор урока 29)
**Запекание (Bake)** «фотографирует» детали тяжёлой модели в **картинку-карту** и надевает её на лёгкую модель. У нас:
- **high-poly** = скульпт (миллионы граней, все морщины и мышцы);
- **low-poly** = ретопология (тысячи граней, чистая сетка).

Запечём детали скульпта в **карту нормалей** на low-poly → лёгкая модель будет **выглядеть** как скульпт, а тормозить как простая. (Подробно про карты нормалей и AO — урок 29.)

### 1.2 Два способа получить детали на чистой сетке
| Способ | Как | Когда |
|--------|-----|-------|
| **Скульпт → Ретопо → Bake** (наш путь) | лепим отдельно, строим чистую сетку, запекаем со скульпта на неё | когда формы уже разные/сложные |
| **Multires** | на **чистую** сетку вешаем модификатор, подразделяем и лепим прямо на ней | когда хочешь и чистую базу, и детали в одном объекте |

### 1.3 Что такое Multiresolution (Multires)
**Multires** — модификатор, который хранит **несколько уровней** сетки: на уровне 0 — твоя чистая low-poly, а выше — та же модель, но подразделённая в миллионы граней, где можно **лепить детали**. Магия: **база остаётся чистой** (для анимации), а детали живут на верхних уровнях. Потом их можно **запечь** в карту нормалей кнопкой **Bake from Multires**.

> 💡 **Фишка — Multires = «чистая база + детали в одном»:** не нужен отдельный скульпт. Но у нас скульпт уже есть (уроки 34–36), поэтому основной путь — **запечь со скульпта на ретопологию**. Multires покажем как второй инструмент.

### 1.4 Что нужно для запекания
- Движок **Cycles** (Bake работает в нём).
- У low-poly должна быть **UV-развёртка** (карта печётся «в UV»). Аккуратную UV сделаем на уроке 39, а сегодня — **быструю авто-развёртку** (Smart UV Project), её хватит, чтобы научиться печь.
- **Cage** — чтобы лучи запекания ложились чисто на изогнутых местах (пальцы, уши). Повтор лайфхака урока 29.

> 🔬 **Проверь сам (вспоминаем ур.29):** карта нормалей — это сине-фиолетовая картинка, где «зашит» рельеф. На плоской low-poly она создаёт **видимость** морщин и мышц без лишних граней.

## Часть 2 — Быстрая UV под запекание (12 минут)

1. Выдели **low-poly** (ретопологию с урока 37) → `Tab` Edit Mode → `A` (всё).
2. `U → Smart UV Project` → **OK** (настройки по умолчанию).
   ✅ *Должно получиться:* у low-poly появилась развёртка (увидишь острова в UV-редакторе). Этого достаточно для запекания.
3. `Tab` назад.

> 💡 **Фишка — почему быстрая:** Smart UV Project разрезает автоматически — некрасиво, но рабоче. Красивую симметричную развёртку для покраски сделаем на уроке 39. (Если потом переразвернёшь UV — **перепеки** карты.)

## Часть 3 — Запекаем Normal (скульпт → low-poly) (25 минут)

> Тот же приём «Selected to Active», что на уроке 29.

### Шаг 1 — Движок и холст
1. **Properties → вкладка Render** → **Render Engine → Cycles**.
2. Выдели **low-poly** → **Shader Editor** → `Shift+A → Texture → Image Texture` → **New** → имя `персонаж_normal`, размер **2048**, **Non-Color**.
3. **Оставь этот Image Texture выделенным** (он — мишень).

### Шаг 2 — Выделение и Bake
1. В 3D-виде: сначала кликни **скульпт (high)**, потом **с Shift — low-poly** (low активна).
2. **Properties → Render → панель Bake:**
   - **Bake Type → Normal**;
   - включи **Selected to Active** ✅;
   - **Extrusion ≈ 0.05**, **Max Ray Distance ≈ 0.1** (подбери под размер персонажа).
3. Нажми **Bake**.
   ✅ *Должно получиться:* картинка `персонаж_normal` заполнилась сине-фиолетовым — это детали скульпта (морщины, мышцы), записанные в карту.

### Шаг 3 — Подключаем карту
```
Image Texture (персонаж_normal, Non-Color) ─[Color]─► Normal Map ─[Normal]─► Principled [Normal]
```
1. `Shift+A → Vector → Normal Map`, соедини по схеме.
2. Спрячь скульпт (`H`).
   ✅ *Должно получиться:* лёгкая low-poly при свете **выглядит как скульпт** — видны морщины и мышцы, хотя граней мало! 🎉

> ⚠️ **Фишка — артефакты на пальцах/ушах?** Лучи запекания пересеклись. Лечится **Cage** (см. лайфхак) или меньшим Ray Distance.

## Часть 4 — Запекаем AO + Cage (15 минут)

### AO — мягкие тени в складках
1. Ещё `Image Texture → New` (`персонаж_AO`, 2048, **Non-Color**) → выдели.
2. Bake Type → **Ambient Occlusion** → **Bake**.
3. Подмешай к Base Color через **Mix Color (Multiply)** — складки и щели станут глубже (как на уроке 24/29).

### Cage — чистое запекание
1. В панели **Bake → Selected to Active** включи **Cage** ✅, задай **Cage Extrusion** (чуть «раздуть» оболочку), и перепеки.
   ✅ *Должно получиться:* полосы/артефакты на пальцах, ушах, в подмышках исчезли.

> 🎯 **ЛАЙФХАК — показать здесь!** Cage и Ray Distance для чистого запекания персонажа (особенно пальцы/уши) — в [лайфхак.md](лайфхак.md).

> 💡 **Фишка — сохрани карты:** Image Editor → `Image → Save As` (`персонаж_normal.png`, `персонаж_AO.png`), затем `File → External Data → Pack Resources`. Иначе пропадут (как на уроке 28/29).

> 📷 **[Вставь сюда картинку: AO в складках персонажа →](изображения.md#ao)**

## Часть 5 — Бонус: Multires (другой способ) (10 минут)

> Покажем второй путь — на будущее.

1. Выдели **чистую low-poly** (копию) → 🔧 **Add Modifier → Generate → Multiresolution**.
2. Нажми **Subdivide** 3–4 раза (сетка подразделяется в миллионы граней, **база остаётся чистой**).
3. Войди в **Sculpt Mode** и слепи деталь (морщину) — она ложится на верхнем уровне.
4. Запечь: в панели **Bake** включи **Bake from Multires** ✅ → Bake Type **Normal** → **Bake** — детали Multires уйдут в карту **без отдельного скульпта**.
   ✅ *Должно получиться:* понял идею — Multires хранит чистую базу + детали и сам отдаёт карту нормалей.

> 💡 **Фишка — когда что:** есть готовый скульпт → печём Selected to Active (наш путь). Хочешь всё в одном объекте → Multires. Оба дают карту нормалей на лёгкой сетке.

> 📷 **[Вставь сюда картинку: Multires — уровни сетки →](изображения.md#multires)**

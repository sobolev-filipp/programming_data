# Самостоятельная работа — Урок 37: Чистая сетка для монстра 🕸️

> 🧑‍🎓 Делаешь сам(а): сделай **чистую low-poly сетку** своему монстру. Учитель помогает, если застрял.

## Задание

Возьми детализированный скульпт монстра (урок 36) и сделай по нему **чистую сетку**: авто-ретопология **QuadriFlow** + проверка/правка потока + ручная заплатка **Poly Build + Shrinkwrap** на ключевой зоне (глаз/рот).

> 🎬 У Майка важна петля вокруг **большого глаза** и **рта** — на них и проверь поток.

---

## Этапы (делай по порядку)

1. **Копия:** в Object Mode `Shift+D → Esc` скульпта; оригинал спрячь (`H`) как эталон, копию назови **low**.
2. **Авто:** на копии `F3` → **QuadriFlow Remesh** → Target Faces **4000–6000** → OK.
   Включи каркас (`Z → Wireframe`) — проверь, что вышли **квады**.
3. **Поток:** `Tab` Edit Mode → добавь **кольца** (`Ctrl+R`) вокруг **глаза** и **рта**, поправь рёбра (`G`), чтобы шли кольцами.
4. **Ручная заплатка:** на скульпте-эталоне построй кусочек сетки **Poly Build** с модификатором **Shrinkwrap** (Target = скульпт) — обтяни щёку/вокруг глаза.
5. **Симметрия:** если делал половину — модификатор **Mirror (X)**.
6. **Финал:** `Shade Smooth`, проверь — сетка лёгкая (тысячи граней), квады, петли на месте. Скульпт-эталон **не удаляй** (нужен для урока 38).

---

## Требования

- [ ] Сделана копия; оригинал-скульпт сохранён как эталон
- [ ] **QuadriFlow** дал чистую сетку из **квадов** (разумный Target Faces)
- [ ] Есть **кольца рёбер** вокруг глаза/рта (поток поправлен)
- [ ] Построена **ручная заплатка** (Poly Build + Shrinkwrap) хотя бы на одной зоне
- [ ] Сетка **лёгкая** (тысячи, не миллионы граней)
- [ ] Файл сохранён (high-poly + low-poly рядом)

---

## 💡 Подсказки (если что-то забыл)

- **Копия:** `Shift+D → Esc`; спрятать/показать — `H` / `Alt+H`
- **Авто-ретопо:** `F3` → «QuadriFlow Remesh» → **Target Faces**
- **Каркас:** `Z → Wireframe`
- **Кольцо рёбер:** `Ctrl+R` (Loop Cut) → прокрутить → клик
- **Shrinkwrap:** 🔧 → Deform → Shrinkwrap → Target = скульпт, Nearest Surface, Offset 0.01
- **Poly Build:** Edit Mode → панель `T` → Poly Build; навести на ребро → тянуть ЛКМ
- **Симметрия:** модификатор **Mirror**, ось X
- Слабый ПК: Target Faces поменьше (3000–4000)

---

## Что сдать

`.blend` (скульпт + low-poly) + скриншот сетки в **Wireframe** (видно квады и петли вокруг глаза/рта).

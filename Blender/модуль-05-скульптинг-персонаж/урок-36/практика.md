# Самостоятельная работа — Урок 36: Детализируй своего монстра 🎭👹

> 🧑‍🎓 Делаешь сам(а): добавь монстру детали через **Mask**. Учитель помогает, если застрял.

## Задание

Возьми тело монстра с урока 35 и **детализируй** его, активно используя **маску (Mask)**: уточни лицо, наметь формы тела, сделай пальцы/ступни, добавь характерные детали. Не «гладкий болван», а живой персонаж.

> 🎬 Майк: уточни **большой глаз** (веко, зрачок-впадина), **рот** (губы Crease, наметь зубы), **пальцы** на тонких руках/ногах, фактуру кожи (лёгкая бугристость).

---

## Этапы (делай по порядку, с маской!)

1. **Глаз(а):** Mask изолируй зону глаза → **Crease** веко вокруг, **Inflate** глазное яблоко, **Draw+Ctrl** ямку зрачка.
2. **Рот:** **Crease** линия губ, **Inflate** губы, **Pinch** края; если есть зубы — наметь **Clay Strips** бугорки (по маске, чтобы не задеть губы).
3. **Пальцы/ступни:** Mask изолируй кисть/ступню (`Ctrl+I`) → **Crease** бороздки между пальцами → **Grab** слегка вытяни.
4. **Формы тела:** по маске наметь животик/мышцы (**Inflate/Clay Strips**) — мягко.
5. **Характер:** добавь свою деталь — складки на «коже», бугры, шипы, бородавки (Crease/Draw по маске).
6. **Доводка:** **Shift**-Smooth — баланс «детали есть, но силуэт чистый».

---

## Требования

- [ ] **Mask** реально использована (приём «изолируй → `Ctrl+I` → лепи»)
- [ ] Уточнено **лицо** (глаз/глаза, рот — Crease/Pinch/Inflate)
- [ ] Намечены **пальцы или ступни** по маске
- [ ] Есть **формы тела** (мышцы/животик) или фактура кожи
- [ ] Добавлена **характерная деталь** (шипы/складки/бугры)
- [ ] Силуэт читается, нет «каши»; файл сохранён

---

## 💡 Подсказки (если что-то забыл)

- **Маска:** кисть **Mask** красит защиту; **`Ctrl`** стирает; **`Ctrl+I`** инвертирует; очистить — **Sculpt → Mask → Clear Mask**; рамкой — **Box Mask**
- **Приём:** закрась зону → `Ctrl+I` → лепи только её
- **Веки/рот/складки:** **Crease** (борозда) + **Pinch** (острее)
- **Губы/мышцы/глаз:** **Inflate** (раздуть)
- **Ямки (ноздри, зрачок):** **Draw + `Ctrl`**
- **Сглаживание:** **Shift** + кисть
- **Симметрия X** — для парных деталей; для асимметрии (шрам) выключи

---

## Что сдать

`.blend` + рендер монстра крупно (лицо) и общим планом. Видно детали лица, пальцы, характерные черты.

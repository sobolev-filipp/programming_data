# Лайфхак урока 36 — Mask: изолируй зону и лепи только её

> Хочешь раздуть бицепс, но не задеть плечо? Прорезать складку, не «расползаясь» на соседнее? Закрась маской всё лишнее — и кисть будет работать **только** в нужной зоне. Это главный приём аккуратной детализации.

---

## Приём «изолируй и лепи» (по шагам)

1. Кисть **Mask** → закрась зону, которую хочешь **трогать** (например, руку).
2. **`Ctrl+I`** — инвертируй: теперь защищено ВСЁ, кроме руки.
3. Лепи смело (Inflate, Clay Strips, Crease) — двигается **только рука**.
4. Очисти маску: **Sculpt → Mask → Clear Mask**.

✅ *Результат:* деталь появилась ровно там, где надо, без «брызг» на соседние части.

---

## Шпаргалка по маске

| Действие | Как |
|----------|-----|
| Красить маску (защита) | кисть **Mask** |
| Стирать маску | **`Ctrl`** + Mask |
| Инвертировать | **`Ctrl+I`** |
| Прямоугольником | инструмент **Box Mask** (рамкой) |
| Очистить всю | **Sculpt → Mask → Clear Mask** |
| Размер/сила кисти | `F` / `Shift+F` |

---

## Где особенно выручает

- **Мышца:** изолировал руку → Inflate бицепс → ровный бугор, плечо не раздулось.
- **Складка:** изолировал низ футболки → Crease складки → не задел тело.
- **Палец:** изолировал кисть → вытянул палец, не растягивая всю руку.
- **Резкая граница:** маска даёт **чёткий край** (например, край брони/одежды): закрасил по линии → Inflate → ступенька-кант.

> 💡 **Фишка — острый край через маску:** закрась ровно по будущей границе (можно Box Mask), затем Inflate незакрашенное — получится чёткая «ступенька» (кант брони, край капюшона). Без маски такой ровный край кистью не сделать.

> 💡 **Главная мысль:** маска превращает «грубую кисть» в «точный инструмент». Изолируй зону — и лепи в ней спокойно, ничего не задевая.

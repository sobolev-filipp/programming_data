# 3D-моделирование в Blender — общий план

**Объём:** 145 академических часов. Один урок — 2 ак. ч. (1,5 часа). Формат занятий гибкий: два раза в неделю по одному уроку либо один раз в неделю по два урока подряд (4 ак. ч.).

**Версия Blender:** 4.1, интерфейс русский. Классные компьютеры слабые, поэтому упор на low-poly, лёгкие текстуры и движок EEVEE.

**Подход.** Минимум отвлечённой теории: на каждом уроке ученик создаёт конкретный объект. Теория даётся подробно, но по ходу дела, с объяснением «почему так» и разбором частых ошибок. На каждом уроке вводится хотя бы один новый инструмент, модификатор или нода, а объекты не повторяются — практический объект отличается от того, что делали на уроке.

Где брать текстуры, HDRI и модели — [справочники/где-скачать.md](справочники/где-скачать.md).

## Повторяющиеся темы

Проекты подобраны так, чтобы каждый урок давал новый осязаемый результат, а темы не повторялись. Сквозные направления, которые усложняются от модуля к модулю:

- космос и планеты (Земля, Луна, газовый гигант, звёзды, астероиды, орбиты);
- свечение и эффекты (Emission, Bloom, голограммы, стекло, вода);
- low-poly мир (животные, природа, ферма, окружение);
- персонаж (скульптинг → ретопология → риг → анимация);
- игровые ассеты (low-poly, текстуры, экспорт).

Ранние проекты в духе «космического корабля» заменены на самостоятельные объекты (замок, настольная лампа, аркадный автомат, лавка зельевара): так каждый урок остаётся свежим, а сложность растёт постепенно.

## Состояние разработки

Все семь модулей созданы (уроки 1–56 плюс дипломный модуль). Модуль 6 (анимация и физика) и модуль 7 (дипломный проект) закончены полностью. В модуль 6 добавлен **новый блок «продвинутые ноды и симуляция» (уроки 57–61)** — углубляет Geometry Nodes и закрывает симуляции (жидкость, дым, продвинутая ткань); этот блок в разработке. Сейчас идёт доработка уроков модулей 1–2 под единый подробный формат: пошаговые инструкции с проверками результата, отдельный разбор частых ошибок, отсылки к ранее пройденному, напоминания и схемы. Источник истины по статусу — [HANDOFF.md](HANDOFF.md).

## Формат каждого урока

Папка урока содержит: `theory.md`, `повторение.md`, `практика.md`, `лайфхак.md`, `преподавателю.md`, `изображения.md` и подпапку `изображения/`. Учительские файлы и теория зашифрованы (git-crypt); практика, лайфхаки, справочники и картинки — открыты.

Применение всех навыков в одном проекте и его защита. Объём сжат: один сильный проект вместо «всего сразу». Статус: создан — [README модуля](модуль-07-дипломный-проект/README.md), [этапы](модуль-07-дипломный-проект/этапы.md) и [рубрика](модуль-07-дипломный-проект/рубрика.md).

| Этап | Описание | Часов |
|------|----------|-------|
| Выбор темы и план | тема, референсы, список объектов, раскадровка | 1 |
| Моделирование | объекты сцены | 4 |
| Материалы и текстуры | UV, ноды, карты текстур | 3 |
| Свет и рендер | освещение, камера, Compositor | 2 |
| Анимация (по желанию) | оживление сцены или персонажа | 2 |

Каталог из 33 тем с описанием и разбивкой по сложности — [модуль-07-дипломный-проект/темы-проектов.md](модуль-07-дипломный-проект/темы-проектов.md). Коротко по уровням:

- сложные (11): идущий персонаж, боевая сцена, оживший город, резиденция с флагом, цепная машина, разрушение, монстр, короткая сценка, солнечная система, погода, премиум-реклама.

## Аддоны и дополнительные инструменты

Один из принципов курса — познакомить учеников с широким набором инструментов. Помимо базовых приёмов, в уроки встроены врезки про аддоны и приёмы интерфейса.

| Аддон (встроенный в Blender) | Где вводится |
|------------------------------|--------------|
| Import Images as Planes (референс) | М1 (урок 1), М5 (урок 34) |
| Add Mesh: Extra Objects (Gear, Bolt) | М1 (урок 1), М2 (урок 16), М6 (урок 44) |
| Add Curve: Extra Objects (спирали) | М2 (уроки 6, 8), М6 (урок 43) |
| Bool Tool | М2 (урок 7) |
| Carver | М2 (урок 7) |
| Loop Tools | М2 (уроки 7, 8, 9) |
| Auto Mirror | М1 (урок 3), М5 |
| F2 (умное заполнение) | М2 (урок 13) |
| Sapling Tree Gen, A.N.T. Landscape, Archimesh | М2 (уроки 14, 17), М7 |
| Node Wrangler | М3 (уроки 18, 19, 24, 25), М5 |
| Rigify | М6 (урок 50) |
| Quick Effects (дым, огонь, жидкость, мех) — Mantaflow | М6 (уроки 52, 59) |
| BlenderKit (библиотека) | М3–М7 |

BlenderKit — библиотека готовых материалов, моделей и HDRI внутри Blender (есть бесплатный раздел). Используется как ускоритель и источник примеров для второстепенных объектов: готовый материал берут, чтобы разобрать его ноды. Главные объекты сцены ученик делает сам.

Полный каталог аддонов — [справочники/аддоны.md](справочники/аддоны.md); приёмы интерфейса — [справочники/трюки.md](справочники/трюки.md).

## Что освоят ученики к концу курса

**Модификаторы:** Mirror, Array (линейный и радиальный), Subdivision, Solidify, Boolean, Screw, Bevel, Decimate, Weld, Remesh, Skin, Displace, Simple Deform, Lattice, Cast, Wave, Shrinkwrap, Wireframe, Weighted Normal, Multires, Armature, Cloth, Soft Body, Fluid (Mantaflow), Ocean, Geometry Nodes.

**Шейдерные ноды:** Principled BSDF, Noise, Voronoi, Wave, Gradient, Brick, Checker, Magic, ColorRamp, Mix Color, Map Range, Mapping, Texture Coordinate, Bump, Displacement, Normal Map, Fresnel, Layer Weight, Geometry (Pointiness/Normal), Emission, Transparent, Glass (IOR, Refraction), Volume Absorption и Scatter, Subsurface, Mix и Add Shader, Image Texture, Scene Time, RGB Curves, Hue/Saturation.

**Карты текстур:** Base Color/Albedo, Roughness, Metallic, Normal, AO, Height/Displacement, Emission.

**Работа с материалами:** Principled BSDF, слоты материалов, назначение по граням, Link Materials на много объектов, Select Similar, общий datablock, Object Info Random, Fake User.

**Geometry Nodes:** Distribute Points on Faces, Instance on Points, Random Value, Math, Combine и Separate XYZ, Grid, Mesh Line, Set Position, Scale Instances, Join Geometry; поля и атрибуты (Capture Attribute, Named Attribute, Index/Position), Align Euler to Vector, Set Material по атрибуту, Simulation Zones (симуляция в нодах).

**Трансформации и Edit Mode:** G/R/S с осью и числом, Transform Pivot Point, Proportional Editing, перемещение Origin, привязки и выравнивание (Snap, 3D-курсор, Align Objects), выделение петель и колец.

**Скульптинг:** Sculpt Mode, кисти (Draw, Grab, Smooth, Inflate, Crease, Pinch, Clay Strips), Dyntopo, Mask, симметрия, ретопология.

**Анимация и физика:** Keyframes, Graph Editor, Constraints, Drivers, Armature, IK и FK, Rigify, Shape Keys, частицы и Hair, Rigid Body, Cloth (в т.ч. Self Collision, Pressure), Soft Body, NLA; симуляция жидкости, дыма и огня (Mantaflow), симуляция в Geometry Nodes (Simulation Zones).

Принцип разнообразия: на каждом уроке — хотя бы один новый инструмент, нода или модификатор; модели не повторяют друг друга, а практический объект отличается от объекта урока.

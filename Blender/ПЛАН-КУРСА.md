# Полный план курса — 135 академических часов

> **Формат занятий:** 2 раза в неделю по 2 ак.ч. (1,5 часа) **или** 1 раз в неделю по 4 ак.ч. (3 часа)  
> **Версия Blender:** 4.1 | **Интерфейс:** Русский  
> **Принцип курса:** максимум практики — каждый урок создаём конкретный интересный объект, теория даётся тщательно, но по ходу. На каждом уроке — **новый инструмент/модификатор/нода**, чтобы модели не повторялись.

📥 Где брать текстуры/HDRI/модели: [справочники/где-скачать.md](справочники/где-скачать.md)

---

## 🎯 Сквозные темы курса

Усложняются от модуля к модулю:

- **🌌 Космос** — планеты (Земля, Луна, Марс), звёзды, астероиды, орбиты
- **🚀 Космический корабль** — моделирование, материалы, полёт
- **⚔️ Лазерный меч** — свечение, Emission, Bloom, анимация
- **🔷 Голограммы** — шейдерные ноды, прозрачность, сканлайны, мерцание
- **🐄 Low-poly мир** — животные (капибара, заяц, корова), ферма, природа
- **🧍 Персонаж** — скульптинг человека/существа → риг → анимация
- **🎮 Игровые ассеты** — low-poly, текстуры, экспорт

## 🔌 BlenderKit по ходу курса

**BlenderKit** — аддон-библиотека готовых материалов, моделей и HDRI прямо внутри Blender (есть бесплатный раздел). Включается: `Edit → Preferences → Add-ons → BlenderKit`. Используем как ускоритель и источник вдохновения — но **сначала** учимся делать сами.

| Где | Как используем BlenderKit |
|-----|---------------------------|
| Модуль 3 (материалы) | взять готовый материал → **разобрать его ноды** |
| Модуль 4 (свет/сцена) | готовые HDRI и модели окружения |
| Модуль 5 (персонаж) | материалы кожи/ткани, референсные модели для пропорций |
| Модуль 6 (анимация) | базовые модели-реквизит |
| Модуль 7 (диплом) | окружение и детали сцены |

> ⚠️ Принцип: BlenderKit — для **второстепенных** объектов и изучения чужих нод. Главные объекты ученик делает сам.

**Модификаторы:** Mirror, Array (линейный + радиальный), Subdivision, Solidify, Boolean, Screw, Bevel, Decimate, Weld, Remesh, **Skin**, **Displace**, Simple Deform, Lattice, Cast, Wave, Shrinkwrap, Wireframe, Multires, Armature, Cloth, Geometry Nodes

**Шейдерные ноды:** Principled BSDF, Noise, Voronoi, Wave, Gradient, Brick, Checker, Magic, ColorRamp, Mix Color, Map Range, Mapping, Texture Coordinate, Bump, **Displacement**, Normal Map, Fresnel, Layer Weight, Geometry, Emission, Transparent, Glass, Mix/Add Shader, Image Texture, RGB Curves, Hue/Saturation

**Карты текстур:** Albedo/Base Color, Roughness, Metallic, Normal, AO, Height/Displacement, Emission

**Geometry Nodes:** Distribute Points on Faces, Instance on Points, Random Value, Math, Combine/Separate XYZ, Grid, Mesh Line, Set Position, Scale Instances, Join Geometry

**Трансформации и Edit:** G/R/S + ось + число, **Transform Pivot Point** (Median / 3D Cursor / Individual Origins / Active), **Proportional Editing (O)**, **перемещение Origin** (Origin to Geometry / 3D Cursor / Center of Mass + Affect Only Origins), Snapping, выделение петель/колец

**Скульптинг:** Sculpt Mode, кисти (Draw, Grab, Smooth, Inflate, Crease, Pinch, Clay Strips), Dyntopo, Mask, симметрия, ретопология

> 💡 **Принцип разнообразия:** на каждом уроке — **хотя бы один новый** инструмент/нода/модификатор, и **созданные модели не должны повторять друг друга** (в т.ч. практика ≠ объект урока).

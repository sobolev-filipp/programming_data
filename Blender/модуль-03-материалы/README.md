# Модуль 3 — Материалы, текстуры, карты, ноды, UV

**25 академических часов | 13 уроков**

---

## Чему научимся

- Работать в **Shader Editor** и понимать **Principled BSDF**
- Делать **процедурные текстуры** (Noise, Voronoi, Wave, ColorRamp)
- Шейдер **голограммы** (Fresnel, прозрачность, сканлайны)
- Все **карты текстур** (Albedo, Roughness, Metallic, Normal, AO, Height)
- **UV-развёртку**: швы, проекции, упаковку, бесшовные текстуры (тайлинг)
- **Displacement** — настоящий рельеф из карты высот
- Текстурировать **Землю** (день, ночь, облака, атмосфера)
- **Texture Paint** и **запекание** (Bake)

> 🔌 Все ноды разбираем **по сокетам** и с объяснением, что делает каждый нод.
> 📖 Шпаргалка по быстрому назначению материалов: [справочники/материалы-приёмы.md](../справочники/материалы-приёмы.md)

# Самостоятельная работа — Урок 22: Разверни свой предмет 📐

> 🧑‍🎓 Делаешь сам(а): **смоделируй** простой предмет и **разверни** его UV. Учитель помогает, если застрял.

## Задание

Смоделируй простой предмет с разными сторонами и сделай ему **аккуратную UV-развёртку** (швы + Unwrap), проверь Checker-текстурой.

> 💡 Развёртка нужна для следующих уроков (карты текстур, роспись) — потом эту модель будем красить.

**Идеи (что-то с разными гранями):**
- 🎲 Игральный кубик (6 разных сторон)
- 📦 Коробка / посылка (с этикеткой)
- 📕 Книга (обложка + корешок + страницы)
- 🥫 Консервная банка (этикетка по кругу)
- 🥛 Пакет молока / сока
- 🪧 Дорожный знак / табличка

---

## Требования

- [ ] Объект **смоделирован**
- [ ] Поставлены **швы** (`Mark Seam`) осознанно (в незаметных местах / по углам)
- [ ] Развёрнут через **Unwrap** (или Smart UV Project)
- [ ] Проверено **Checker-текстурой** — клетки ровные, без сильных растяжений
- [ ] В UV-редакторе выкройка видна целиком (ничего не «уехало»)
- [ ] Рендер/скриншот модели с Checker

---

## 💡 Подсказки (если что-то забыл)

- **Швы:** Edit Mode → `2` (рёбра) → выдели → `Ctrl+E → Mark Seam` (красные). Убрать — `Clear Seam`
- **Петля рёбер:** `Alt+ЛКМ` (быстро отметить шов по кругу)
- **Где резать:** по углам/незаметным местам; цилиндр — вдоль + кольцо; см. [лайфхак](лайфхак.md)
- **Развернуть:** `A` (всё) → `U → Unwrap`; авто — `U → Smart UV Project`
- **Проверка:** материал → Base Color → **Checker Texture** → `Z → Material Preview`; ровные квадраты = ок
- **Раскладка UV Editing** сверху — слева видно выкройку
- Растягивается? → добавь шов, чтобы кусок «лёг плоско»

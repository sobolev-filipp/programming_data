# Самостоятельная работа — Урок 22: Разверни предмет и положи на него картинку 📐

> 🧑‍🎓 Делаешь сам(а): **смоделируй** предмет, **разверни** его UV, наведи порядок и **наложи на него настоящую картинку** по UV. Учитель помогает, если застрял.

## Задание

Смоделируй простой предмет с разными сторонами → сделай ему **аккуратную UV-развёртку** → проверь Checker-текстурой → и **положи на него картинку-файл по UV** (этикетку, рисунок, текстуру).

> 💡 Эта развёрнутая модель пригодится на следующих уроках — будем класть на неё карты и расписывать кистью. Сохрани её!

**Идеи (что-то с разными гранями) — НЕ ящик с урока:**
- 🎲 Игральный кубик (6 разных сторон с точками)
- 📕 Книга (обложка + корешок + страницы) с картинкой на обложке
- 🥫 Консервная банка (этикетка по кругу — шов как у банки)
- 🥛 Пакет молока / сока (рисунок на лицевой стороне)
- 🪧 Дорожный знак / табличка (символ на щите)
- 📦 Посылка с наклейкой-адресом

---

## Этапы (одна цельная работа)

1. **Смоделируй** предмет, `Ctrl+A → All Transforms`
2. Поставь **швы** (`Ctrl+E → Mark Seam`) осознанно — в незаметных местах / по углам
3. **Разверни** (`U → Unwrap` или Smart UV Project)
4. **Упакуй** острова (`UV → Pack Islands`, подкрути Margin)
5. **Проверь** Checker / UV-Grid — клетки ровные и одного размера
6. **Положи картинку:** Base Color → Image Texture → Open → подвинь UV-острова так, чтобы рисунок лёг туда, куда нужно

---

## Требования

- [ ] Объект **смоделирован** (не взят готовый)
- [ ] Поставлены **швы** осознанно
- [ ] Развёрнут через **Unwrap** (или Smart UV Project)
- [ ] Острова **упакованы** (Pack Islands), не налезают, примерно одной плотности
- [ ] Проверено **Checker/UV-Grid** — клетки ровные
- [ ] На модель **наложена картинка по UV**, и она стоит правильно (этикетка/рисунок там, где надо)
- [ ] Рендер/скриншот: модель с картинкой + видимая UV-выкройка

---

## 💡 Подсказки (если что-то забыл)

- **Швы:** Edit Mode → `2` (рёбра) → выдели → `Ctrl+E → Mark Seam` (красные). Убрать — `Clear Seam`
- **Петля рёбер:** `Alt+ЛКМ` (быстро отметить шов по кругу)
- **Где резать:** по углам/незаметным местам; банка — вдоль + кольцо; см. [лайфхак](лайфхак.md)
- **Развернуть:** `A` (всё) → `U → Unwrap`; авто — `U → Smart UV Project`
- **Упаковать:** `A` → `UV → Pack Islands` (подкрути Margin)
- **Проверка:** в UV-редакторе `+ New → UV Grid`, или Base Color → Checker; `Z → Material Preview`
- **Двигать острова:** `G`/`R`/`S`; `L` — выделить остров под курсором
- **Наложить картинку:** Base Color → жёлтая точка → **Image Texture → Open**
- **Подогнать картинку:** в UV-редакторе сверху **Open** ту же картинку фоном → двигай острова поверх неё (`G`/`S`)
- Растягивается? → добавь шов, чтобы кусок «лёг плоско»

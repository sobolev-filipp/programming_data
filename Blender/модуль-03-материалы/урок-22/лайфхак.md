# Лайфхак урока 22 — Где резать швы правильно

> Шов (Seam) — это «разрез», по которому модель разворачивается в плоскость. От того, где резать, зависит, будет ли шов виден и не растянется ли текстура. Несколько простых правил.

---

## Правило 1 — Режь там, где не видно

Шов оставляет «стык» текстуры. Прячь его в незаметных местах:
- по **задней/нижней** стороне
- в **углублениях**, под деталями
- там, куда редко смотрят

> Пример: у персонажа швы прячут под мышками, по внутренней стороне ног, за ушами.

---

## Правило 2 — Режь по «естественным» краям

Режь по местам, где в реальности есть стык:
- по **углам** коробки/ящика
- по **краю** одежды, шва, канта
- по резкому **сгибу** формы

> Так шов выглядит как настоящий стык, а не как ошибка.

---

## Правило 3 — Чтобы не тянулось — режь сложные формы

Если кусок сильно изогнут (рукав, рог, труба) — без шва текстура **растянется**. Разрежь, чтобы кусок мог «лечь плоско».

- Цилиндр/труба: шов вдоль + один по кругу (как этикетка с банки)
- Сфера: шов как у глобуса (по «меридиану»)
- Конечность: шов вдоль внутренней стороны

---

## Правило 4 — Меньше швов, но без растяжений

Баланс: много швов = много стыков (плохо); мало швов = растяжения (плохо). Режь **минимум необходимого**, чтобы куски легли плоско без искажений. Проверяй **Checker-текстурой** (ровные клетки = ок).

---

## Быстрые рецепты

| Форма | Где швы |
|-------|---------|
| 🧊 Ящик/куб | по вертикальным углам + по низу |
| 🥫 Цилиндр/банка | вдоль одной стороны + кольцо сверху/снизу |
| 🌐 Сфера | один «меридиан» (как глобус) |
| 🧤 Рукав/нога/рог | вдоль внутренней стороны |
| 🧱 Стена/плоскость | швы не нужны (уже плоская) |

---

## Шпаргалка

| Действие | Как |
|----------|-----|
| Поставить шов | выдели рёбра → `Ctrl+E → Mark Seam` |
| Убрать шов | `Ctrl+E → Clear Seam` |
| Выделить петлю под шов | `Alt+ЛКМ` по ребру |
| Развернуть по швам | `U → Unwrap` |
| Проверить искажения | Checker-текстура (ровные клетки) |

> 💡 **Главная мысль:** хороший шов — спрятанный и по естественному краю. Режь так, чтобы кусок лёг плоско без растяжений, и проверяй Checker’ом.

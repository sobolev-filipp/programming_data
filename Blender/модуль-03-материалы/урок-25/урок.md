## Часть 1 — Теория: Bump vs Displacement (15 минут)

На уроке 20 мы делали **Bump** — он только **обманывает свет** (геометрия плоская). **Displacement** — это **настоящее смещение вершин**: рельеф появляется в самой геометрии, и его видно **по силуэту**.

![Плоскость → карта высот → реальный рельеф](изображения/displacement.jpg)

*Сверху вниз: ровная сетка → **карта высот** (белое = выше) → сетка с реальным рельефом (буквы ABC **выдавлены в геометрии**). ([источник: Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Displacement.jpg))*

### Сравнение

| | **Bump / Normal** | **Displacement** |
|--|-------------------|------------------|
| Что меняет | только освещение (нормали) | **саму геометрию** (вершины) |
| Силуэт | гладкий (обман) | **рельефный** (по-настоящему) |
| Нагрузка на ПК | лёгкая | тяжёлая (нужно много граней) |
| Когда | мелкие детали, слабый ПК | крупный рельеф, край виден |

> 💡 **Фишка — Height map = карта высот:** серое изображение, где **белое = высоко, чёрное = низко**. И Bump, и Displacement читают одну и ту же карту — но Bump «рисует» рельеф светом, а Displacement реально двигает вершины.

> 💡 **Фишка — Displacement нужна геометрия:** двигать можно только существующие вершины. Поэтому перед Displacement плоскость **разбивают на много граней** (Subdivide).

## Часть 2 — Displace-модификатор (работает везде) (25 минут)

Самый надёжный способ (работает и в EEVEE, и на слабых ПК).

### Заготовка
1. `Shift+A → Mesh → Plane`, `S → 3` — плитка/пол. Разверни UV (`U → Unwrap`) — уроки 22–23
2. Добавь геометрию: 🔧 **Subdivision Surface** (Simple), уровень 4–5 — **много граней**

### Подключаем карту высот
1. 🔧 → **Add Modifier → Deform → Displace** (после Subdivision)
2. **New** texture → 🏁 Texture Properties → тип **Image or Movie** → **Open** → твоя **Height-карта**
3. (Если карты нет — тип **Clouds**, как на уроке 20)
4. Вернись в Displace → крути **Strength** → плоскость стала рельефной плиткой! Виден настоящий рельеф по краю.

> 💡 **Фишка — Midlevel и Strength:** Midlevel = «какой серый считать нулём» (обычно 0.5), Strength = сила рельефа. Подбирай, чтобы рельеф был заметным, но не «иглами».

> ⚠️ **Фишка для слабых ПК:** Displace + высокий Subdivision = много геометрии. Держи уровень разумным (4–5), не задирай до 8.

## Часть 3 — Displacement-нода и Adaptive (Cycles) (15 минут)

Более «умный» способ — через материал. Работает по-настоящему только в **Cycles** (с Adaptive Subdivision), но знать полезно.

### Схема
```
Image Texture (Height, Non-Color) ─[Color]─► Displacement ─[Displacement]─► Material Output [Displacement]
```
1. В материале: `Image Texture` (Height, **Non-Color**) → `Shift+A → Vector → Displacement` → в **Material Output [Displacement]**
2. Render Properties → движок **Cycles**
3. У объекта: `ПКМ → ... → Subdivision Surface`, в Render Properties включи **Subdivision → Adaptive**
4. Теперь рельеф вычисляется **только там, где видит камера** — детально и относительно экономно

> 💡 **Фишка — три уровня рельефа:** **Bump/Normal** (мелочь, везде) → **Displace-модификатор** (крупный рельеф, EEVEE) → **Displacement-нода + Adaptive** (максимальная детализация, Cycles). Выбирай по задаче и мощности ПК.

> 🎯 **ЛАЙФХАК — показать здесь!** Когда брать Bump, когда Displacement, и как **совместить** (крупный рельеф — Displace, мелкий — Normal сверху) — в [лайфхак.md](лайфхак.md).

## Часть 4 — Каменная стена и финал (10 минут)

1. Возьми PBR-набор камня/кирпича (с Height-картой): Base Color + Roughness + Normal (мелочь) + **Height** (крупный рельеф через Displace)
2. Так Displacement даёт крупные выступы, а Normal — мелкие поры → максимум реализма
3. Свет сбоку → `F12`

> 💡 **Фишка — Displacement + Normal вместе:** крупные камни/швы «выдавливает» Displacement (видно по краю), а мелкую шероховатость добавляет Normal. Это профессиональный приём.

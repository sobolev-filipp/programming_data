## Задание

Сделай поверхность/объект с **настоящим рельефом** через Displacement — но **другую** тему, чем плитка с урока.

**Идеи:**
- 🪨 Скала / валун (крупные выступы)
- 🏔 Кусок ландшафта / горы
- 🧱 Старая кирпичная стена с глубокими швами
- 🌊 Застывшая лава / потрескавшаяся земля
- 🛤 Брусчатка / мощёная дорога
- 🌑 Поверхность планеты с кратерами (Displace вместо Bump!)

---

## Требования

- [ ] Достаточно геометрии (**Subdivision** перед Displace)
- [ ] Применён **Displace-модификатор** с **картой высот** (или Clouds)
- [ ] Рельеф **виден по силуэту** (по краю), а не только в свете
- [ ] Бонус: **Normal Map** поверх для мелкой шероховатости
- [ ] Подобран Strength (рельеф заметный, без «игл»)
- [ ] Свет сбоку + рендер (`F12`)

---

## 💡 Подсказки (если что-то забыл)

- **Сначала геометрия:** Subdivision Surface (Simple) уровень 4–5 — иначе двигать нечего
- **Карта высот:** Displace → New texture → Texture Properties → **Image or Movie** → Open (Height-карта)
- **Процедурно:** тип текстуры **Clouds** (без файла)
- **Сила рельефа:** Displace → **Strength** (и Midlevel ≈ 0.5)
- **Слабый ПК:** не задирай Subdivision выше 5; можно Apply + **Decimate** (урок 10)
- **Совмести крупное и мелкое:** Displace (крупный рельеф) + Normal Map (мелочь)
- **Силуэт:** покрути вид — у Displacement край неровный (в отличие от Bump)

---

## Что сдать

`.blend` + рендер. Поверни так, чтобы был виден **рельефный силуэт**.

## Задание

Сделай поверхность/объект с **настоящим рельефом** через Displacement — **не** мощёную дорожку (она была на уроке). Сложи объект в коллекцию «двор/руины» (переклички с практиками уроков 23).

**Идеи:**
- 🪨 Скала / валун (крупные выступы)
- 🏔 Кусок ландшафта / горы
- 🧱 Старая кирпичная стена с глубокими швами
- 🌋 Застывшая лава / потрескавшаяся земля
- 🌳 Кора дерева крупным планом
- 🌑 Поверхность планеты с кратерами (Displace вместо Bump — пригодится на уроке 26!)

---

## Требования

- [ ] Объект **смоделирован** + развёрнут (UV)
- [ ] Достаточно геометрии (**Subdivision Surface Simple** перед Displace)
- [ ] Применён **Displace-модификатор** с **картой высот** (Non-Color), **Texture Coordinates = UV**
- [ ] Рельеф **виден по силуэту** (по краю), а не только в свете
- [ ] Подобран Strength (рельеф заметный, без «игл»), Midlevel ≈ 0.5
- [ ] Бонус: **Normal Map** поверх для мелкой шероховатости
- [ ] Свет сбоку + рендер (`F12`), виден рельефный край

---

## 💡 Подсказки (если что-то забыл)

- **Сначала геометрия:** Subdivision Surface (**Simple**) уровень 4–6 — иначе двигать нечего
- **Карта высот:** Displace → **New** → Texture Properties → **Image or Movie** → Open (disp-карта) → **Non-Color**
- **Координаты:** Displace → **Texture Coordinates → UV** (иначе рельеф не совпадёт с цветом)
- **Процедурно:** тип текстуры **Clouds** (без файла)
- **Сила рельефа:** Displace → **Strength** (начни с 0.1–0.2), Midlevel ≈ 0.5
- **Быстро весь набор:** сложи карты в одну папку → Principled → `Ctrl+Shift+T` (Node Wrangler, урок 24)
- **Слабый ПК:** не задирай Subdivision выше 6; можно Apply + **Decimate** (урок 10)
- **Силуэт:** покрути вид — у Displacement край неровный (в отличие от Bump)

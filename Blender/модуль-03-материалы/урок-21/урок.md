## Часть 1 — Теория: из чего сделана голограмма (10 минут)

Голограмма (как в фантастике) — это сочетание четырёх вещей:

| Признак | Чем делаем | Откуда знаем |
|---------|-----------|--------------|
| **Свечение** | Emission | урок 18 |
| **Полупрозрачность** | Transparent BSDF + Mix Shader | Mix Shader — урок 20 |
| **Сканлайны** (полоски/кольца) | Wave Texture + ColorRamp | урок 19 |
| **Мерцание/волна** | Geometry Nodes + Scene Time (анимация) | Geo Nodes — Модуль 2 |

> 💡 **Фишка — голограмма = «полупрозрачный светящийся объект с полосками, который слегка дрожит».** Разобьём на части и соберём заново.

## Часть 2 — Шейдер голограммы (35 минут)

### Заготовка
Возьми объект (сфера-планета, корабль из Модуля 2, или текст) → новый материал → раскладка **Shading**.

### 🧩 Новые/повторяемые ноды

| Нод | Что делает | Сокеты | Откуда |
|-----|------------|--------|--------|
| **Wave Texture** | полосы (**Bands**) или кольца (**Rings**) — сканлайны | Scale, выход **Color** | ур.19 |
| **Color Ramp** | красит сканлайны в цвет голограммы | вход **Fac**, выход **Color** | ур.19 |
| **Emission** | свечение | вход **Color**, **Strength**, выход **Emission** | ур.18 |
| **Transparent BSDF** | делает поверхность **сквозной** | выход **BSDF** | 🆕 |
| **Mix Shader** | смешивает свечение и прозрачность | **Fac**, два **Shader**, выход **Shader** | ур.20 |

### Схема (по сокетам)
```
Texture Coordinate [Object] ─► Mapping [Vector] ─► Wave Texture [Vector]
Wave Texture [Color] ─► Color Ramp [Fac]
Color Ramp [Color] ─► Emission [Color]   (Strength ≈ 5)
Emission [Emission] ─► Mix Shader [верхний Shader]
Transparent BSDF [BSDF] ─► Mix Shader [нижний Shader]
Mix Shader [Shader] ─► Material Output [Surface]
```

### Шаги
1. `Shift+A → Texture → Wave Texture` → выдели → `Ctrl+T` (добавит Texture Coordinate + Mapping — ур.20)
2. Тип Wave: **Bands** (горизонтальные сканлайны) или **Rings** (концентрические, как радар). Scale ≈ 20
3. `Wave [Color]` → новый **Color Ramp** [Fac]; в ColorRamp — голубой/бирюзовый цвет голограммы
4. `Color Ramp [Color]` → `Emission [Color]`, Strength 5
5. `Shift+A → Shader → Transparent BSDF`
6. `Shift+A → Shader → Mix Shader`: **Emission** → верхний вход, **Transparent** → нижний, **Factor ≈ 0.3**
7. `Mix Shader [Shader]` → `Material Output [Surface]`

> ⚠️ **Фишка — прозрачность в EEVEE:** чтобы Transparent работал, в Material Properties → **Settings → Blend Mode → Alpha Blend** (или Alpha Hashed). Иначе объект останется непрозрачным.

> 💡 **Фишка — Factor управляет «призрачностью»:** Mix Shader Factor ближе к 1 = прозрачнее (больше Transparent), ближе к 0 = плотнее (больше свечения). Подбери ~0.3–0.6.

## Часть 3 — Свечение по краям (Fresnel) (15 минут)

У настоящих голограмм **края ярче** (свет «скользит» по силуэту). Это даёт **Fresnel**.

### 🧩 Новый нод
| Нод | Что делает | Сокеты |
|-----|------------|--------|
| **Fresnel** | определяет края (грани, повёрнутые «от нас») — там значение выше | выход **Fac** |

### Как применить (просто)
- `Fresnel [Fac]` → в **Mix Shader Factor** (через сложение с прошлой маской) **или** усиль им Emission Strength на краях
- Самый простой путь: `Fresnel [Fac]` → `Color Ramp` → подмешать к свечению (ярче по краю)

> 💡 **Фишка — Fresnel = ободок света:** грани по краю силуэта «смотрят от камеры» → Fresnel там близок к 1. Подал в свечение — получил светящийся контур. Так делают щиты, пузыри, голограммы, атмосферу планет.

## Часть 4 — Дрожание и анимация: Geometry Nodes + Scene Time (25 минут)

Голограмма «живая» — она слегка дрожит/идёт волной. Сделаем это **геометрией** и **оживим временем**. Это повтор Geometry Nodes (Модуль 2) + новый нод **Scene Time**.

### 🧩 Ноды (повтор + новые)
| Нод | Что делает | Откуда |
|-----|------------|--------|
| **Set Position** | двигает вершины по **Offset** | ур.12 |
| **Position** | даёт координаты каждой вершины | 🆕 |
| **Separate XYZ / Combine XYZ** | разобрать/собрать вектор | ур.12 |
| **Math** (Multiply, Add, **Sine**) | считает; Sine — плавная волна | Math — ур.12, Sine 🆕 |
| **Scene Time** | даёт текущее **время/кадр** — основа анимации | 🆕 |

### Идея
Сдвинем каждую вершину по Z на синусоиду, которая **бежит вверх со временем**:
`offset.Z = sin( позиция.Z × частота + время ) × амплитуда`

### Схема (по сокетам)
```
Group Input [Geometry] ─► Set Position [Geometry] ─► Group Output [Geometry]

Position [Position] ─► Separate XYZ
Separate XYZ [Z] ─► Math:Multiply [A]      (B = 5  — частота волны)
Math:Multiply ─► Math:Add [A]
Scene Time [Seconds] ─► Math:Add [B]        ← вот она, анимация!
Math:Add ─► Math:Sine [Value]
Math:Sine ─► Math:Multiply2 [A]            (B = 0.1 — амплитуда, небольшая)
Math:Multiply2 ─► Combine XYZ [Z]
Combine XYZ [Vector] ─► Set Position [Offset]
```

### Шаги
1. Выдели объект → 🔧 → **Geometry Nodes → New** → открой Geometry Node Editor
2. `Shift+A → Geometry → Set Position`, встрой между Input и Output
3. `Shift+A → Input → Position` → `Separate XYZ`
4. Цепочка Math: `Multiply` (×5) → `Add` → `Sine` → `Multiply` (×0.1) (Math-нод, меняй режим в выпадающем списке)
5. `Shift+A → Input → Scene Time` → **Seconds** → в `Add [B]`
6. `Combine XYZ` (результат в Z) → `Set Position [Offset]`
7. Нажми **Пробел** (Play) — голограмма пошла волной! 🎉

> 🎯 **ЛАЙФХАК — показать здесь!** **Scene Time** — это «двигатель» анимации: подаёшь время в любой расчёт, и всё начинает двигаться **само, без ключевых кадров**. Полный разбор (что ещё можно оживить) — в [лайфхак.md](лайфхак.md). Это забег вперёд в **Модуль 6 (анимация)**.

> 💡 **Фишка — Sine (синус) = плавная волна:** функция Sine плавно колеблется от −1 до 1. Идеальна для волн, дрожания, пульсации, «дыхания». Частота (×больше) = чаще волны, амплитуда (×больше) = сильнее дрожь.

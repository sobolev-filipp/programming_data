# Самостоятельная работа — Урок 21: Своя анимированная голограмма 🔷

> 🧑‍🎓 Делаешь сам(а): **смоделируй** объект и сделай его **живой голограммой**. Учитель помогает, если застрял.

## Задание

Сделай **свою голограмму** — но **другой** объект (не тот, что на уроке). Смоделируй простое и преврати в светящуюся анимированную голо-проекцию.

> 💡 Голограммы пригодятся в космической/sci-fi сцене и дипломе (голо-интерфейс, голо-карта).

**Идеи (смоделируй простое):**
- 🗺 **Голо-карта/локация** (низкий рельеф + сетка)
- 🐉 **Голо-питомец** (простое существо/животное из Модуля 2)
- 🛸 **Голо-чертёж корабля** (возьми корабль из Модуля 2!)
- 🔤 **Голо-надпись/логотип** (текст: `Shift+A → Text`)
- 🌍 **Голо-планета** с сеткой меридианов
- 💍 **Голо-кольцо/иконка интерфейса**

---

## Требования

- [ ] Объект **смоделирован** (или взят свой с прошлых модулей)
- [ ] Шейдер голограммы: **Emission + Transparent + Mix Shader** (полупрозрачное свечение)
- [ ] **Сканлайны** (Wave Texture + ColorRamp)
- [ ] **Свечение по краям** (Fresnel)
- [ ] **Анимация** через **Geometry Nodes + Scene Time** (дрожание/волна/вращение)
- [ ] Тёмный фон + рендер (`F12`); проверь движение по **Пробелу**

---

## 💡 Подсказки (если что-то забыл)

- **Прозрачность в EEVEE:** Material Properties → Settings → **Blend Mode → Alpha Blend**
- **Сканлайны:** `Wave Texture` (Bands/Rings) → `Ctrl+T` (координаты) → `[Color]` → ColorRamp (голубой) → Emission
- **Смешать свечение и прозрачность:** `Mix Shader`: Emission → верх, Transparent → низ, Factor ~0.3
- **Ободок света:** `Fresnel [Fac]` → ColorRamp → подмешать к Emission (ярче по краю)
- **Анимация волной:** Geo Nodes → `Position → Separate XYZ → Math(Multiply→Add→Sine→Multiply) → Combine XYZ → Set Position [Offset]`, в Add подай **Scene Time [Seconds]**
- **Плывущие сканлайны (бонус):** Scene Time → Mapping [Location] текстуры в шейдере
- **Текст:** `Shift+A → Text`, в Edit Mode печатай, потом `Convert → Mesh`
- Нажми **Пробел**, чтобы увидеть анимацию; смотреть нод — `Ctrl+Shift+Click`

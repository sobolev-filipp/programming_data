## Часть 1 — Теория: материал и Shader Editor (12 минут)

**Материал** описывает, как поверхность взаимодействует со светом: какого она цвета, блестит или матовая, металл или стекло.

В Blender материал собирается из **шейдерных нодов** в редакторе **Shader Editor** (вкладка-раскладка **Shading** сверху).

### Два нода, с которых всё начинается

```
Principled BSDF ──[BSDF]──► Material Output ──(на экран)
```

### 🧩 Что делает каждый нод (простыми словами)

| Нод | Что делает | Главный сокет |
|-----|------------|---------------|
| **Principled BSDF** | «universсальный материал»: один нод задаёт цвет, блеск, металл, стекло, свечение | выход **BSDF** (готовый материал) |
| **Material Output** | «розетка»: куда втыкается материал, чтобы он появился на объекте | вход **Surface** |

**Связь:** `Principled BSDF [BSDF] → Material Output [Surface]`. Это уже есть по умолчанию при создании материала.

> 💡 **Фишка — Principled BSDF почти всё умеет сам:** не нужно собирать материал из десятка нодов. Один Principled + правильные параметры = металл, пластик, стекло, краска. Усложняем только когда нужно.

## Часть 2 — Разбираем параметры Principled BSDF (13 минут)

Это «ручки» материала. Главные:

| Параметр | Что меняет | Пример |
|----------|-----------|--------|
| **Base Color** | основной цвет | красный, синий… |
| **Metallic** | металл (1) или нет (0) | 1 = золото, 0 = пластик/дерево |
| **Roughness** | матовость: 0 зеркало, 1 матовый | 0.1 — глянец, 0.9 — резина |
| **IOR / Transmission** | прозрачность (стекло) | Transmission 1 = стекло |
| **Emission** | самосвечение | лампа, экран, лава |
| **Alpha** | прозрачность (невидимость) | 0 = прозрачно |

> 💡 **Фишка — два главных слайдера:** 90% материалов — это игра **Metallic** + **Roughness**. Запомни: Metallic = «металл/не металл», Roughness = «зеркало/матовость».

## Часть 3 — Витрина из 5 материалов (35 минут)

Сделаем 5 сфер с разными материалами — как образцы в магазине.

### Подготовка

1. `Shift + A → Mesh → UV Sphere` → `ПКМ → Shade Smooth`
2. Продублируй (`Shift+D`) 4 раза, поставь в ряд
3. Переключись на раскладку **Shading** (сверху) — внизу появится Shader Editor

### Материал 1 — Металл (золото)

1. Выдели сферу → в Shader Editor нажми **New**
2. Base Color: жёлтый · **Metallic: 1.0** · **Roughness: 0.2**
3. Золото! Чем выше Roughness — тем «потёртее» металл

### Материал 2 — Пластик

1. Новая сфера → New → Base Color: яркий цвет · **Metallic: 0** · **Roughness: 0.3**
2. Глянцевый пластик. Roughness 0.6 → матовый пластик

### Материал 3 — Дерево (пока однотонное)

1. Base Color: коричневый · Metallic 0 · **Roughness: 0.8** (дерево матовое)
2. *(Настоящую текстуру дерева добавим на след. уроках)*

### Материал 4 — Стекло

1. New → **Transmission: 1.0** · Roughness: 0.0 · IOR ≈ 1.45
2. Прозрачное стекло! (в EEVEE включи в настройках материала **Screen Space Refraction**, а в Render Properties — Refraction)

> 💡 **Фишка — стекло в EEVEE капризно:** Transmission в EEVEE требует включить Refraction. Если стекло «чёрное» — проверь эти галочки или переключись на Cycles для проверки.

### Материал 5 — Свечение (Emission)

1. New → подними **Emission Color** (яркий цвет) и **Emission Strength: 5**
2. Сфера светится. В EEVEE добавь **Bloom** (Render Properties) — ореол

## Часть 4 — Node Wrangler и раскраска модели (15 минут)

### Включить Node Wrangler

`Edit → Preferences → Add-ons` → **Node Wrangler** → ✅

> 🎯 **ЛАЙФХАК — показать здесь!** Node Wrangler — суперсила для работы с нодами: `Ctrl+Shift+Click` по ноду показывает его результат, `Ctrl+T` добавляет ноды текстуры разом и др. Полный разбор — [лайфхак.md](лайфхак.md).

### Раскрась свою модель

1. Открой свою модель (шахматы / кружка / животное / паровоз)
2. Назначь материалы из изученных типов (металл корпуса, матовый пластик, стекло окон, свечение фар)
3. Для разных частей — несколько материалов (выдели грани → Assign, как в уроке 2)
4. `Z → Material Preview` → `F12`

> 💡 **Фишка — материал переиспользуется:** один «золотой» материал можно назначить многим объектам (выбери из списка вместо New). Поменяешь — изменятся все.

# Лайфхак урока 18 — Суперсилы Node Wrangler

> Node Wrangler — встроенный аддон, который ускоряет работу с нодами в разы. Без него работать в Shader Editor «голыми руками» долго и больно.

---

## Включить

`Edit → Preferences → Add-ons` → **Node Wrangler** → ✅

---

## 1. `Ctrl + Shift + Click` — посмотреть нод (Viewer) ⭐

Кликни с `Ctrl+Shift` по любому ноду — его результат сразу выводится на объект.

**Зачем:** проверять, что делает каждый нод по отдельности. Кликаешь по Noise — видишь шум; по ColorRamp — видишь раскраску. Незаменимо для понимания нодов!

> 💡 Это лучший способ **учиться** нодам: собрал — кликнул — увидел, что нод делает.

---

## 2. `Ctrl + T` — Texture Coordinate + Mapping разом

Выдели нод текстуры → `Ctrl + T` → автоматически добавятся и соединятся **Texture Coordinate** и **Mapping**. (Подробно — на уроке 20.)

**Зачем:** управлять размером/положением текстуры. Вручную это 2 нода и 2 связи — Node Wrangler делает за секунду.

---

## 3. `Ctrl + Shift + T` — загрузить все PBR-карты ⭐

Выдели Principled BSDF → `Ctrl + Shift + T` → выбери файлы текстур (color, roughness, normal…) → аддон **сам** добавит все ноды и подключит к нужным входам. (Подробно — на уроке 24.)

**Зачем:** загрузка PBR-материала вручную — 5 нодов и куча связей. `Ctrl+Shift+T` делает это за один раз. **Главная экономия времени в материалах.**

---

## 4. Прочие удобства

| Клавиши | Что делает |
|---------|-----------|
| `Ctrl + Shift + Click` | Viewer — показать нод |
| `Ctrl + T` | Texture Coordinate + Mapping |
| `Ctrl + Shift + T` | загрузить PBR-текстуры |
| `Alt + Click` (по связи) | отсоединить и переподключить |
| `Ctrl + J` | сгруппировать ноды в рамку (Frame) |

---

## Шпаргалка

| Хочу | Делаю |
|------|-------|
| Понять, что делает нод | `Ctrl+Shift+Click` (Viewer) |
| Управлять размером текстуры | `Ctrl+T` |
| Загрузить готовый PBR-материал | `Ctrl+Shift+T` |
| Навести порядок в нодах | рамки (Frame) |

> 💡 **Главная мысль:** `Ctrl+Shift+Click` (смотреть ноды) и `Ctrl+Shift+T` (грузить текстуры) — два сочетания, которые сэкономят тебе сотни минут в Модуле 3.

# Лайфхак урока 19 — Noise + ColorRamp = что угодно

> Самая мощная связка процедурных материалов. Один шум + раскраска = ржавчина, мрамор, карта планеты, камуфляж, облака, грязь. Запомнишь её — будешь делать материалы без единой картинки.

---

## Базовая формула

```
Noise Texture ──[Fac]──► ColorRamp ──[Color]──► (Base Color / маска / куда нужно)
```

- **Noise** даёт случайные пятна (число 0–1)
- **ColorRamp** красит эти пятна в нужные цвета
- Меняешь **Scale** шума → крупнее/мельче пятна
- Двигаешь флажки ColorRamp → другой вид

> 💡 Смотри результат через `Ctrl+Shift+Click` (Viewer) на каждом ноде.

---

## Рецепты на базе Noise + ColorRamp

| Материал | Как |
|----------|-----|
| ☁️ **Облака** | Noise → ColorRamp (бело-голубой), большой Scale |
| 🪨 **Камень/грязь** | Noise → ColorRamp (тёмно-серый ↔ светлый) |
| 🟤 **Ржавчина** | Noise → ColorRamp (рыжий ↔ коричневый), подмешать через Mix к металлу |
| 🪵 **Дерево** | Noise сильно растянутый по одной оси + ColorRamp (волокна) |
| 🌍 **Карта планеты** | Noise → ColorRamp (синий=вода, зелёный/коричневый=суша) |
| 🎖 **Камуфляж** | Noise → ColorRamp в режиме **Constant** (резкие пятна) |
| 🐆 **Пятна/шкура** | Voronoi → ColorRamp |

---

## Усиливающие приёмы

### Искажение текстуры текстурой
Подай один Noise в **Distortion** другого узора (Wave/Noise) → вихри, разводы, мрамор. (Делали на Юпитере.)

### Несколько слоёв через Mix
Смешивай две текстуры нодом **Mix Color**: основа + пятна грязи сверху по маске (Factor = ещё один Noise). Так материалы становятся «грязными» и реальными.

### Detail и Roughness у Noise
У Noise есть **Detail** (мелкие детали) и **Roughness** — добавляют узору сложности. Крути, если шум слишком «гладкий».

### Bump из шума
Тот же Noise [Fac] → нод **Bump** → в Normal у Principled = рельеф (шероховатость) без геометрии. (Подробно — урок 20.)

## Шпаргалка

| Хочу | Делаю |
|------|-------|
| Любой природный узор | Noise → ColorRamp |
| Резкие пятна (камуфляж) | ColorRamp → Constant |
| Вихри/мрамор | Noise в Distortion другого узора |
| Грязь поверх материала | Mix Color (Factor = Noise) |
| Рельеф без геометрии | Noise → Bump → Normal |

> 💡 **Главная мысль:** не ищи картинку — собери узор из шума. Noise + ColorRamp покрывает половину всех материалов в мире.

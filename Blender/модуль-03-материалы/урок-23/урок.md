## Часть 1 — Зачем нужны разные методы (10 минут)

Швы + Unwrap (урок 22) — универсальны, но не всегда удобны:
- Для **простых форм** (труба, шар, ящик) быстрее «спроецировать», чем размечать швы.
- Для **повторяющихся поверхностей** (кирпичная стена, плиточный пол, дорога) важно, чтобы текстура **повторялась ровно** — это отдельный приём.
- Развёртку часто надо **довести до идеала автоматически** (одинаковая плотность, минимум растяжений) — для этого есть умные кнопки.

> Аналогия проекций — как **карты мира**: глобус (3D-шар) «проецируют» на цилиндр или плоскость, чтобы получить плоскую карту. В Blender то же самое: модель проецируем на куб, цилиндр или сферу.

## Часть 2 — Проекции под форму (20 минут)

Все они в Edit Mode в меню `U` (как и Unwrap). Выдели всё (`A`) и выбери метод.

| Метод (`U → …`) | Для чего | Аналогия |
|-----------------|----------|----------|
| **Cube Projection** | коробки, ящики, дома | проекция на 6 сторон куба |
| **Cylinder Projection** | трубы, банки, бочки, колонны | «этикетка» оборачивает цилиндр |
| **Sphere Projection** | шары, планеты, головы | как карта глобуса |
| **Project from View** | плоские щиты, наклейки, граффити | «фотографируем» модель с экрана |

### Пробуем на бочке/трубе
1. Смоделируй **цилиндр** (бочка/труба) → Edit Mode → `A`
2. `U → Cylinder Projection` — развёртка-«этикетка» готова мгновенно
3. Проверь UV-Grid: бок ровный, торцы — отдельными кружками

> 💡 **Фишка — проекция ≠ замена швов:** проекции идеальны для примитивов. Для сложных вещей (персонаж, машина) всё равно нужны швы + Unwrap. Выбирай метод под форму.

> 💡 **Фишка — Project from View для наклеек:** повернись так, чтобы смотреть прямо на грань, `U → Project from View` — UV ляжет ровно «как видишь». Удобно для плоских вывесок, надписей, граффити на стене.

## Часть 3 — Умные инструменты: плотность и растяжения (20 минут)

На уроке 22 одинаковую плотность мы подгоняли **вручную** (масштабировали острова `S`). Теперь — **автоматически**.

### Average Islands Scale — плотность одной кнопкой ⭐
1. В UV-редакторе выдели всё (`A`)
2. `UV → Average Islands Scale` — Blender приводит **все острова к одному масштабу** (одинаковая плотность текселей!)
3. Потом `UV → Pack Islands` — упаковать ровно

> 🎯 **ЛАЙФХАК — показать здесь!** Идеальная развёртка в 2 клика (Average Islands Scale → Pack Islands) — в [лайфхак.md](лайфхак.md).

### Minimize Stretch — убрать растяжения
- Выдели остров → `UV → Minimize Stretch` (или `Ctrl+V` в UV) → двигай мышь / крути колесо → Blender «расслабляет» сетку, убирая искажения. ЛКМ — применить.

### Pin (P) + Live Unwrap — закрепи и тяни
1. Выдели нужные точки UV → `P` (**Pin**) — они станут красными и «прибьются» на месте
2. Включи **UV → Live Unwrap**
3. Теперь, двигая закреплённые точки, остальная развёртка **дотягивается живьём** — как растягиваешь резиновую выкройку за уголки

> 💡 **Фишка — Pin для контроля:** закрепи 2–4 угла острова → Live Unwrap → меш развернётся аккуратно вокруг них. Снять закрепление — `Alt+P`.

## Часть 4 — Бесшовная плитка: Follow Active Quads (25 минут) ⭐

Самое полезное для окружения: сделать так, чтобы текстура (кирпич, плитка, доски) **повторялась ровно** по всей стене/полу.

### Шаг 1 — Follow Active Quads
1. Смоделируй **кирпичную стену** (Plane → `Ctrl+R` Loop Cut на несколько рядов) или плоскость-пол
2. Edit Mode → выдели все грани (`A`)
3. **Активной** сделай одну ровную грань: `Shift+ЛКМ` по ней (она — образец)
4. `U → Follow Active Quads` → выбери **Even** → Blender разложит все грани **ровной сеткой**, как по линейке

> 💡 **Фишка — что делает Follow Active Quads:** берёт твою активную грань как «эталон клетки» и выстраивает остальные грани в идеальную решётку UV. Текстура потечёт по стене ровными рядами без перекосов — то, что нужно для кирпича и плитки.

### Шаг 2 — Повтор текстуры (Repeat) + Mapping
Чтобы плитка повторялась нужное число раз:

```
Texture Coordinate [UV] ──→ Mapping [Vector] ──→ Image Texture [Vector] ──→ Principled BSDF [Base Color]
```

| 🧩 Нод | Аналогия | Что делает | Сокеты |
|--------|----------|------------|--------|
| **Texture Coordinate** | «откуда брать координаты» | даёт системы координат; берём выход **UV** | выход: **UV** (и Generated, Object…) |
| **Mapping** | «лупа и поворот» текстуры | масштабирует/сдвигает/крутит координаты — задаёт частоту плитки | вход: **Vector**; **Scale**; выход: **Vector** |
| **Image Texture** | проектор с картинкой | проецирует файл; повторяет за края, если Extension = Repeat | вход: **Vector**; выходы: **Color**, **Alpha** |

Подключения по сокетам:
- `Texture Coordinate [UV] → Mapping [Vector]`
- `Mapping [Vector] → Image Texture [Vector]`
- `Image Texture [Color] → Principled BSDF [Base Color]`

**Настройки:**
- В **Image Texture** параметр **Extension → Repeat** (картинка повторяется как плитка)
- В **Mapping** крути **Scale X / Scale Y** (например, 4 и 2) — столько раз текстура повторится по ширине/высоте

> 💡 **Фишка — бесшовная (seamless) текстура:** чтобы стыки плитки были не видны, бери **seamless**-текстуры (их края совпадают). На Poly Haven / ambientCG почти все такие. Обычная фотография при повторе даст видимые швы.

> 💡 **Фишка — Mapping управляет всеми сразу:** если позже добавишь карты (Roughness, Normal — урок 24), подключи их к **тому же** Mapping — тогда все карты будут повторяться одинаково и не «разъедутся».

## Часть 5 — Бонус: несколько UV-карт (8 минут)

У одного объекта может быть **несколько UV-развёрток** (UV Maps). Зачем:
- одна — для **цвета/текстуры**, вторая — для **запекания света/AO** (урок 29)
- зеркальные модели: можно **наложить половинки острова друг на друга** — левая и правая половина берут один кусок текстуры (экономия места ×2, рисуешь один раз)

**Где:** Properties → **Object Data Properties** (зелёный треугольник) → секция **UV Maps** → кнопкой `+` добавляешь ещё одну карту.

> 💡 **Фишка — зеркальная экономия:** у симметричной модели (робот, лицо) наложи правый остров поверх левого — текстура и роспись для одной стороны автоматически работают на обеих. Половина работы и в 2 раза чётче.

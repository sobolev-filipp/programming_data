# Лайфхак урока 23 — Одинаковая плотность текселей и выравнивание островов

> Чтобы вся модель была одинаково чёткой, а текстура легла ровно — острова должны быть одного масштаба и аккуратно выровнены. Несколько приёмов.

---

## 1. Одинаковая плотность текселей (главное)

Если один остров крупный, а другой мелкий — на крупном текстура чёткая, на мелком мыльная.

**Как привести к одному масштабу:**
1. Наложи **Checker / UV-Grid** текстуру
2. Смотри на клетки: где **мельче** — остров надо **увеличить**, где **крупнее** — уменьшить
3. Выдели остров (`L`) → `S` → подгони, чтобы клетки совпали по размеру со всей моделью

> 💡 Цель: клетки **одинакового размера** по всей модели = равномерная чёткость.

---

## 2. Выровнять острова прямыми (Loop Tools)

Если ряд UV-точек должен быть прямой линией (грани ящика, полосы):
- Выдели ряд точек → `ПКМ → LoopTools → Straighten` (или Align X/Y)
- Острова станут аккуратными прямоугольниками

> 🔁 Loop Tools мы включали в Модуле 2 (урок 9). Они работают и в UV-редакторе.

---

## 3. Выровнять по оси

- Выдели точки → `S → X → 0` (выстроить в вертикаль) или `S → Y → 0` (в горизонталь)
- Полезно для прямых краёв островов

---

## 4. Pin (закрепить) + Unwrap заново

Если поправил пару точек и хочешь, чтобы остальное «дотянулось»:
- Закрепи точки `P` (Pin) → `U → Unwrap` снова → меш развернётся с учётом закреплённых точек

---

## 5. Минимум растяжений — режь шов

Если остров **никак** не ложится ровно (клетки тянутся) — значит, кусок слишком изогнут. Добавь ещё один **шов** (урок 22), чтобы он «лёг плоско».

---

## Шпаргалка

| Хочу | Делаю |
|------|-------|
| Один масштаб (чёткость) | Checker → подогнать `S` острова к одному размеру клеток |
| Упаковать ровно | `UV → Pack Islands` (+ Margin) |
| Выпрямить ряд точек | LoopTools → Straighten / `S → X → 0` |
| Дотянуть после правок | Pin (`P`) → Unwrap |
| Убрать растяжение | добавить шов |

> 💡 **Главная мысль:** ровная развёртка = одинаковые клетки Checker по всей модели + плотная упаковка. Это «невидимая» работа, но именно от неё зависит, как ляжет текстура.

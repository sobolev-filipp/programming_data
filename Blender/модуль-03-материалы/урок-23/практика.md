# Самостоятельная работа — Урок 23: Порядок в развёртке 🧩

> 🧑‍🎓 Делаешь сам(а): доведи UV-развёртку до идеала. Учитель помогает, если застрял.

## Задание

Возьми свой развёрнутый предмет (с урока 22) **или смоделируй и разверни новый** — и наведи в его UV-развёртке **полный порядок**: ровные острова, одинаковая плотность, плотная упаковка.

> 💡 Аккуратная развёртка нужна для следующего урока — будем накладывать карты текстур.

**Идеи объектов (с разными по размеру частями):**
- 🏠 Домик (стены, крыша, дверь)
- 🤖 Робот (корпус, голова, руки)
- 🎮 Геймпад
- 🚪 Сундук (крышка, корпус, замок)
- 🪑 Стул / стол

---

## Требования

- [ ] Объект развёрнут (швы + Unwrap)
- [ ] Острова **не налезают** друг на друга
- [ ] Применён **Pack Islands** (плотно, с зазором Margin)
- [ ] **Одинаковая плотность** — клетки Checker примерно одного размера по всей модели
- [ ] Острова выровнены (без сильных перекосов/растяжений)
- [ ] Скриншот модели с Checker/UV-Grid + сама развёртка

---

## 💡 Подсказки (если что-то забыл)

- **UV-редактор:** раскладка **UV Editing**; в Edit Mode выдели грани — выкройка слева
- **Двигать острова:** `G`/`R`/`S` (как в 3D); `L` — выделить остров под курсором
- **Упаковать:** `A` → `UV → Pack Islands` (подкрути Margin)
- **Проверка:** материал → Base Color → **Checker** (или в UV-редакторе `+ New → UV Grid`)
- **Плотность:** где клетки мельче — увеличь остров (`S`); где крупнее — уменьши
- **Выпрямить ряд точек:** LoopTools → Straighten, или `S → X → 0`
- **Тянется и не лечится:** добавь шов (урок 22), чтобы кусок «лёг плоско»

# Самостоятельная работа — Урок 23: Проекции и бесшовная плитка 🧱

> 🧑‍🎓 Делаешь сам(а): **смоделируй** элемент окружения, разверни его **проекцией**, и сделай ему **бесшовную тайл-текстуру** (кирпич/доски/плитка). Учитель помогает, если застрял.

## Задание

Смоделируй объект для будущей диорамы (двор / руины / парк) и заверни его в **повторяющуюся текстуру**:
- разверни цилиндрическую часть **Cylinder Projection** (или плоскую — Cube/View),
- выровняй плотность **Average Islands Scale**,
- на стене/полу сделай **Follow Active Quads** + тайлинг (Repeat + Mapping).

> 💡 Эти объекты потом соберём в общую сцену-диораму (Модуль 3, урок 30). Складывай их в коллекцию «двор/руины».

**Идеи (НЕ кирпичная стена с урока):**
- 🛢 Бочка / металлическая труба (Cylinder Projection + тайл-металл/доски)
- ⛲ Колодец (кирпичный цилиндр + плиточный пол вокруг)
- 🧱 Каменная колонна / тумба (тайл-камень)
- 🪵 Деревянный забор / мостик (доски, тайлинг)
- 🛤 Дорожка / тротуар из плитки (Follow Active Quads на полу)
- 🗼 Башенка (цилиндр-кирпич + конус-крыша)

---

## Требования

- [ ] Объект **смоделирован** (не взят готовый)
- [ ] Использована хотя бы одна **проекция** (Cylinder / Cube / Sphere / Project from View)
- [ ] Применён **Average Islands Scale** (одинаковая плотность)
- [ ] На стене/полу — **Follow Active Quads** + **бесшовная (seamless)** текстура с **Repeat**
- [ ] Через **Mapping → Scale** подобрана частота плитки (текстура не растянута и не «мельчит»)
- [ ] Проверено UV-Grid/Checker — клетки ровные, плитка течёт без перекосов
- [ ] Рендер/скриншот объекта с тайл-текстурой

---

## 💡 Подсказки (если что-то забыл)

- **Проекции:** Edit Mode → `A` → `U → Cylinder/Cube/Sphere Projection` или `Project from View`
- **Плотность:** в UV-редакторе `A` → `UV → Average Islands Scale` → потом `Pack Islands`
- **Тайлинг-сетка:** выдели грани → активной сделай одну (`Shift+ЛКМ`) → `U → Follow Active Quads → Even`
- **Повтор текстуры:** Image Texture → **Extension → Repeat**
- **Частота плитки:** добавь **Mapping** (`Texture Coordinate [UV] → Mapping [Vector] → Image Texture [Vector]`), крути **Scale X/Y**
- **Растягивается:** `UV → Minimize Stretch` на острове
- **Seamless** текстуры бери на Poly Haven / ambientCG (см. ниже) — у них края совпадают

## 📥 Что скачать (бесшовные текстуры)

Нужна **seamless / tileable** текстура (кирпич, доски, камень, плитка):

- **ambientCG** — https://ambientcg.com — CC0, бесплатно. Ищи `Bricks`, `WoodFloor`, `PavingStones`, `Concrete`. Качай **1K** или **2K** (слабый ПК!). Нужен минимум файл **Color** (Diffuse).
- **Poly Haven** — https://polyhaven.com/textures — CC0. Раздел Textures → Bricks / Wood / Concrete.

> Для практики достаточно одной карты **Color**. Остальные карты (Roughness, Normal) подключим на уроке 24.

## Часть 1 — Теория: что такое Texture Paint (16 минут)

### 1.1 Рисуем прямо по модели
**Texture Paint** — режим, где ты **кистью рисуешь по 3D-модели**, как по холсту. Краска ложится на **текстуру-картинку**, а та показывается на модели **по UV-развёртке** (уроки 22–23).

Сравни три способа «раскрасить» из этого модуля:
| Способ | Кто создаёт узор | Урок |
|--------|------------------|------|
| **Процедурные** (Noise/Voronoi) | формула | 19 |
| **Карты-файлы** (PBR) | фотограф/художник заранее | 24 |
| **Texture Paint** | **ты сам, кистью, прямо сейчас** | 28 |

### 1.2 Что нужно, чтобы рисовать
Два обязательных условия:
1. **UV-развёртка** — чтобы краска знала, куда лечь на плоской текстуре (повтор 22–23).
2. **Изображение-холст** (paint slot) — пустая или залитая картинка в **Base Color** материала. Именно по ней «мажет» кисть.

### 1.3 Где можно рисовать (два окна)
- **В 3D-вьюпорте** — водишь кистью **по самой модели** (удобно, видно результат сразу).
- **В Image Editor** (слева в воркспейсе Texture Paint) — рисуешь **по плоской развёртке** (удобно для ровных краёв и мелочей).
Краска в обоих окнах идёт **в одну и ту же картинку** — можно переключаться.

### 1.4 Разрешение холста = чёткость рисунка
Холст — это картинка из пикселей. Чем больше её разрешение, тем **чётче** рисунок (вспомни **тексели**, урок 22). Но большой холст тяжелее.
- Для урока бери **1024×1024** или **2048×2048** (слабый ПК — 1024).

> 💡 **Фишка — рисуешь по пикселям текстуры:** мажешь по модели, а на деле закрашиваешь **пиксели холста** в том месте, куда смотрит UV. Кривая UV = краска «поплывёт». Хорошая развёртка (урок 22) важна и здесь.

## Часть 2 — Готовим щит и холст (20 минут)

### Шаг 1 — Модель щита (подробно)
1. Удали стартовый куб: наведи на него → `X` → **Delete**.
2. Добавь цилиндр: `Shift+A → Mesh → Cylinder`.
3. Слева внизу появилась плашка **«Add Cylinder»** — кликни по ней, чтобы развернуть (или нажми `F9`). Поставь: **Vertices = 32**, **Radius = 1**, **Depth = 0.2**.
   ✅ *Должно получиться:* плоский 32-гранный диск (как толстая монета) — это основа щита.
4. Применё масштаб: `Ctrl+A` → **All Transforms** (меню `Object → Apply → All Transforms`).
5. Скруглим обод: `Tab` (Edit Mode) → нажми `2` (режим **рёбер**) → наведи на верхнее круговое ребро обода → `Alt+ЛКМ` (выделит всё кольцо) → `Ctrl+B`, отведи мышь чуть в сторону, прокрути колесо до **2 сегментов**, `ЛКМ`.
   ✅ *Должно получиться:* край диска стал скруглённым (ловит свет).
6. Умбон (горбик в центре): нажми `3` (режим **граней**) → наведи на верхнюю круглую грань-крышку → `ЛКМ` → `I` (Inset), введи `0.3`, `Enter` → `E` (Extrude), введи `0.15`, `Enter`.
   ✅ *Должно получиться:* в центре щита поднялся круглый выступ-умбон.
7. `Tab` — вернись в Object Mode.

> 🔁 Это игровой ассет в наш средневековый сет (к руинам урока 20 и брусчатке урока 23/25).

### Шаг 2 — Развёртка (UV)
1. `Tab` (Edit Mode) → `A` (выделить всё).
2. `U` → в выпавшем меню выбери **Smart UV Project** → в окне настроек просто нажми **OK**.
   ✅ *Должно получиться:* Blender разрезал щит на острова развёртки (увидишь их, если слева открыт UV/Image-редактор).
3. (Точнее для лицевой стороны) Поверни вид прямо на лицо щита (`Numpad 1`), выдели только передние грани → `U → Project from View` — лицо ляжет «как видишь» (урок 23).
4. `Tab` — назад в Object Mode.

### Шаг 3 — Холст для рисования (paint slot) — ГДЕ это
1. В самом верху окна — строка воркспейсов (Layout, Modeling, … ). Кликни **Texture Paint**.
   ✅ *Должно получиться:* слева — **Image Editor**, справа — 3D-вид, курсор стал кругом-кистью. Но рисовать пока нельзя — нет холста (часто пишет «Missing texture slots»).
2. Открой **Properties** (панель свойств, обычно справа внизу) → сверху в столбце вкладок найди вкладку **Tool** (иконка — **отвёртка + гаечный ключ**) → кликни.
3. Прокрути до панели **«Texture Slots»** → нажми **`+`** → выбери **Base Color**.
4. В окошке задай: **Name** = `щит_роспись`, **Width/Height** = **2048** (слабый ПК — 1024), **Color** = базовый (тёмно-коричневое дерево). **OK**.
   ✅ *Должно получиться:* модель залилась базовым цветом; Blender **сам** создал картинку и подключил её как Image Texture в Base Color. Теперь кисть рисует.

```
Image Texture (щит_роспись) ─[Color]─► Principled BSDF [Base Color]
```

| 🧩 Нод | Что делает | Сокеты |
|--------|------------|--------|
| **Image Texture** | холст, по которому мажет кисть | выход **Color** → Base Color |

> 💡 **Фишка — если кисть «не мажет»:** значит нет холста (paint slot) или не выбран. Проверь: Properties → вкладка **Tool** → Texture Slots → там должна быть твоя картинка, и она выделена.

> 💡 **Фишка — запасной путь:** холст можно создать и через **Shader Editor** (как на уроках 24–25): `Shift+A → Texture → Image Texture → New` (2048) → соедини `[Color]` в **Base Color**. Тогда он тоже станет холстом.

## Часть 3 — Кисти и роспись (25 минут)

### Где что лежит
- **Кисти** — **левая панель инструментов** в 3D-виде (если её нет — нажми `T`): **Draw, Soften, Smear, Clone, Fill, Mask**.
- **Настройки кисти** — **верхняя строка** (header) над 3D-видом: образец **цвета**, **Radius**, **Strength**. То же есть в **N-панели** (`N`) → вкладка **Tool**.

| Кисть (левая панель) | Что делает |
|-------|-----------|
| **Draw** | основная — рисует выбранным цветом |
| **Fill** | заливка большой области/всего холста одним кликом |
| **Soften** | размывает (мягкие переходы, тени) |
| **Smear** | размазывает уже нанесённую краску (как пальцем) |
| **Clone** | копирует кусок из другого места |

### Настройки (как менять)
- **Цвет:** кликни по образцу цвета в верхней строке → откроется круг выбора. `X` — поменять основной/запасной цвет местами.
- **Radius (размер):** клавиша **`F`** → веди мышь (круг растёт/уменьшается) → `ЛКМ`. Или поле **Radius** вверху.
- **Strength (сила/непрозрачность):** **`Shift+F`** → веди мышь → `ЛКМ`. Или поле **Strength** вверху.

### Расписываем щит (по шагам)
1. Выбери инструмент **Fill** (левая панель) → задай цвет дерева → кликни по щиту.
   ✅ *Должно получиться:* весь щит залит ровным фоном-деревом.
2. Выбери **Draw** → смени цвет на металл (серый) → `F` сделай кисть крупной → обведи **обод** по краю.
   ✅ *Должно получиться:* по кругу появился цветной обод.
3. Меньшим радиусом (`F`) нарисуй **сектора/полосы** от центра и точки-**заклёпки** по ободу.
4. Тонкие линии удобнее в **Image Editor** (слева): там та же картинка плоская — подведи и дорисуй ровные края.
   ✅ *Должно получиться:* рисунок на модели и на плоском холсте слева меняется одновременно — это одна картинка.

> 💡 **Фишка — рисуй и в 3D, и на развёртке:** крупные мазки удобно в 3D (видно форму), а ровные линии и мелочь — на плоском холсте в Image Editor.

### Симметрия — половина работы ⭐
1. Properties → вкладка **Tool** (отвёртка+ключ) → панель **«Symmetry»** → поставь галочку **X**.
2. Теперь рисуешь слева — **справа появляется зеркально**.
   ✅ *Должно получиться:* мазок дублируется на другую половину щита. Идеально для гербов, лиц, узоров.

> 💡 **Фишка — симметрия экономит вдвое и держит ровно.** Для несимметричных деталей галочку X потом сними.

## Часть 4 — Эмблема через Stencil (штамп) (15 минут) ⭐

Ровный логотип (череп, звезду, герб) кистью от руки сделать трудно. Поможет **Stencil** — картинка-трафарет: кладёшь её поверх модели и прокрашиваешь сквозь неё.

### Как сделать (где находится)
1. Выбери кисть **Draw**.
2. Properties → вкладка **Tool** (отвёртка+ключ) → панель **«Texture»** (текстура кисти) → нажми **New** (или иконку **Open**, чтобы загрузить скачанную эмблему-PNG).
3. Чуть ниже найди параметр **Mapping** → поставь **Stencil**.
   ✅ *Должно получиться:* поверх 3D-вида появился полупрозрачный трафарет-картинка.
4. Размести трафарет на центр щита:
   - **ПКМ + тащить** — переместить
   - **Shift + ПКМ + тащить** — масштаб
   - **Ctrl + ПКМ + тащить** — поворот
5. Выбери цвет → **закрашивай кистью прямо поверх трафарета**.
   ✅ *Должно получиться:* краска ложится **только там, где фигура светлая** — проступает чёткая эмблема.

> 🎯 **ЛАЙФХАК — показать здесь!** Stencil — для ровных логотипов, надписей и повторяющихся штампов (звёзды, номера, руны). Полный разбор — в [лайфхак.md](лайфхак.md).

> 💡 **Фишка — контрастная эмблема:** бери **белую фигуру на чёрном** — Blender по яркости решает, где красить. Бледные/размытые картинки штампуются грязно.

> 💡 **Фишка — выключить трафарет:** чтобы вернуться к обычной кисти, в панели **Texture** поставь **Mapping → Tiled** (или убери текстуру). Иначе кисть продолжит «штамповать».

## Часть 5 — «Слои» и СОХРАНЕНИЕ (10 минут)

### Про «слои»
В Texture Paint нет слоёв как в Photoshop. Приёмы:
- рисуй продуманно на **одной** картинке (фон → детали → эмблема сверху);
- для отдельного «слоя» (грязь/наклейки) заведи **второй** paint slot (Texture Slots → `+`) и смешай через **Mix Color** в Shader Editor (урок 24).

### СОХРАНИ текстуру! (важно)
Нарисованная картинка живёт **только в памяти**, пока не сохранил. Закроешь Blender — пропадёт!
1. В **Image Editor** (левое окно): меню **Image → Save As…** → выбери папку рядом с .blend → формат **PNG** → **Save As Image**.
   ✅ *Должно получиться:* у имени картинки пропала звёздочка `*` (значит записано на диск).
2. И обязательно: верхнее меню **File → External Data → Pack Resources** — упакует картинку **внутрь** .blend (не потеряется при переносе).

> ⚠️ **Фишка — звёздочка `*` = не сохранено.** Привыкай: `Save As` + `Pack Resources`, иначе труд пропадёт.

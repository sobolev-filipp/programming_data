# Самостоятельная работа — Урок 28: Распиши свой объект 🎨

> 🧑‍🎓 Делаешь сам(а): **смоделируй** простой объект, разверни UV и **распиши его кистью** (узор + эмблема через Stencil). Учитель помогает, если застрял.

## Задание

Выбери объект **НЕ щит** (щит расписывали на уроке), смоделируй его, разверни UV и **распиши вручную**: фон-заливка → узор/рисунок → эмблема/надпись через **Stencil**. Не забудь **симметрию** и **сохранить** текстуру.

**Идеи:**
- ☕ Кружка с рисунком/смайлом
- 🍽 Тарелка с узором (радиальный орнамент — симметрия!)
- 👕 Футболка/худи с принтом
- 🚩 Флаг / вымпел отряда
- 🥚 Расписное яйцо (писанка) — узоры
- 🎭 Маска (симметрия: левая=правая)
- 🛹 Скейтборд с принтом снизу

> 💡 Объекты можно собрать в общую коллекцию (например, «моя комната» или «мой отряд»).

## Требования

- [ ] Объект **смоделирован** (не готовый) и **развёрнут** (UV)
- [ ] Заведён **холст** (Texture Slots → Base Color → New, 1–2K)
- [ ] **Залит фон** (Fill) и нарисован узор кистью **Draw**
- [ ] Использована **симметрия** (X) хотя бы для части рисунка
- [ ] Поставлена **эмблема/надпись через Stencil**
- [ ] Текстура **сохранена** (`Save As` .png) и **Pack Resources**
- [ ] Рендер/скриншот объекта

---

## 💡 Подсказки (если что-то забыл)

- **Холст:** воркспейс **Texture Paint** → Texture Slots → **+** → Base Color → **New** (2048/1024)
- **Радиус/сила:** `F` (радиус), `Shift+F` (сила); цвет — палитра сверху, `X` — поменять цвета
- **Заливка:** кисть **Fill** → клик по холсту
- **Симметрия:** включи ось **X** — рисуешь слева, справа зеркалится
- **Рисуй и в 3D, и на развёртке** (Image Editor) — одна картинка
- **Stencil:** Brush → Texture → New/Open → Mapping = **Stencil**; ПКМ двигать, Shift+ПКМ масштаб, Ctrl+ПКМ поворот; красить поверх
- **Кривая UV → краска плывёт** — сначала аккуратная развёртка (уроки 22–23)
- **СОХРАНИ:** Image → Save As (.png) + File → External Data → **Pack Resources** (иначе пропадёт!)

`.blend` (с **Pack Resources**) + сохранённый `.png` росписи + рендер объекта.

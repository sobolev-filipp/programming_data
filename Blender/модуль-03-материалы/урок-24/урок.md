## Часть 1 — Теория: что такое PBR и карты (15 минут)

**PBR** (Physically Based Rendering) — «физически достоверный» материал. Один материал описывается **набором карт**, где каждая отвечает за своё свойство поверхности.

### 🧩 Карты текстур (разбор каждой)

| Карта | Что задаёт | Какая на вид | Куда в Principled |
|-------|-----------|--------------|-------------------|
| **Base Color / Albedo** | чистый цвет (без теней и бликов) | цветная | **Base Color** |
| **Roughness** | шероховатость: чёрное = блеск, белое = матовость | серая | **Roughness** |
| **Metallic** | металл (белое) или нет (чёрное) | серая (часто чёрная/белая) | **Metallic** |
| **Normal** | мелкий рельеф (царапины, поры) через нормали | сине-фиолетовая | через **Normal Map** → **Normal** |
| **AO** (Ambient Occlusion) | мягкая тень в щелях/углах | серая | подмешать к **Base Color** |
| **Height / Displacement** | высоты (рельеф) | серая | **Bump** или **Displacement** |

> 💡 **Фишка — почему карт несколько:** одна картинка-цвет не передаст, что металл блестит, а ржавчина матовая. Поэтому свойства разнесли по картам: цвет — отдельно, блеск — отдельно, рельеф — отдельно. Вместе они дают «настоящую» поверхность.

> 💡 **Фишка — серые карты это «силы», а не цвет:** Roughness/Metallic/Height/AO/Normal — это **числа** (где сильнее/слабее свойство). Поэтому их Color Space = **Non-Color**. Только **Base Color** остаётся **sRGB** (это настоящий цвет).

## Часть 2 — Подключаем карты вручную (по сокетам) (25 минут)

Соберём материал «по правильному», чтобы понять, что куда.

### Схема
```
Base Color (sRGB)  ─[Color]─► Principled [Base Color]
Roughness (Non-Color) ─[Color]─► Principled [Roughness]
Metallic  (Non-Color) ─[Color]─► Principled [Metallic]
Normal    (Non-Color) ─[Color]─► Normal Map ─[Normal]─► Principled [Normal]
Height    (Non-Color) ─[Color]─► Bump ─[Normal]─► (в Normal Map → или отдельно)
```

### Шаги
1. На UV-объекте (ящик) — новый материал
2. `Shift+A → Texture → Image Texture` → **Open** → файл **Color** → `[Color]` → **Base Color** (Color Space оставь **sRGB**)
3. Ещё `Image Texture` → **Roughness** → **Color Space → Non-Color** → `[Color]` → **Roughness**
4. Ещё → **Metallic** → Non-Color → **Metallic**
5. Ещё → **Normal** → Non-Color → `Shift+A → Vector → Normal Map` → `[Color]`→Normal Map [Color], `Normal Map [Normal]` → **Principled [Normal]**
6. (Бонус) **Height** → Non-Color → **Bump [Height]** → встроить перед Normal; **AO** → подмешать к Base Color через **Mix Color (Multiply)**

> ⚠️ **Фишка — главная ошибка новичков:** забыть **Non-Color** на серых картах. Тогда Roughness/Normal «врут», материал выглядит неправильно. Цвет — sRGB, всё остальное — Non-Color.

> 💡 **Фишка — Normal только через Normal Map:** сине-фиолетовую карту нельзя втыкать прямо в Normal Principled — сначала через нод **Normal Map** (он расшифровывает цвет в направление).

## Часть 3 — `Ctrl+Shift+T`: все карты за клик (15 минут)

Вручную — долго. **Node Wrangler** делает это автоматически.

1. Выдели **Principled BSDF**
2. `Ctrl + Shift + T`
3. В окне выбери **все файлы** набора сразу (Color, Roughness, Normal, Metallic, Height…)
4. Аддон **сам** создаст все Image Texture, поставит Non-Color где надо, добавит Normal Map и подключит к нужным входам!

> 🎯 **ЛАЙФХАК — показать здесь!** `Ctrl+Shift+T` — главная экономия времени в текстурах: целый PBR-материал за один клик. Полный разбор — [лайфхак.md](лайфхак.md).

> 💡 **Фишка — Node Wrangler «читает» имена файлов:** он понимает по названиям (`_diff`, `_rough`, `_nor`, `_metal`), какая карта куда. Поэтому не переименовывай скачанные файлы как попало.

> 📷 **[Вставь сюда картинку: Ctrl+Shift+T собрал весь материал →](изображения.md#ctrl-shift-t)**

## Часть 4 — Реалистичный ящик и финал (10 минут)

1. Проверь масштаб текстуры: если узор слишком крупный/мелкий — `Ctrl+T` → Mapping → Scale (урок 20)
2. Свет сбоку — Normal/Height-рельеф читается
3. `Z → Rendered` → `F12`

> 💡 **Фишка — хорошая UV + PBR-набор = фотореализм почти даром:** вся «магия» уже в картах, твоя задача — развернуть (UV) и подключить (Ctrl+Shift+T). Поэтому уроки 22–23 были так важны.

# Повторение урока 23 — Викторина по проекциям и тайлингу 🧱

> ⏱ 5–7 минут. Формат: викторина.

---

## Вопросы

1. Какие есть **проекции** и под какие формы они подходят (Cube / Cylinder / Sphere / Project from View)?
2. Что делает **Average Islands Scale**? Почему это удобнее ручного масштабирования?
3. В каком порядке применяют Average Islands Scale и Pack Islands?
4. Что делает **Follow Active Quads** и для чего он нужен?
5. Что включить в **Image Texture**, чтобы текстура повторялась как плитка?
6. Каким нодом регулируют **частоту** повторения текстуры?
7. Зачем брать **seamless**-текстуры?

---

## Ответы (для учителя)

1. Cube — коробки/дома; Cylinder — трубы/бочки/банки; Sphere — шары/планеты; Project from View — плоские щиты, вывески, граффити
2. Приводит все острова к **одному масштабу** (одинаковая плотность текселей) одной командой — не нужно подгонять каждый остров мышкой
3. Сначала **Average Islands Scale**, потом **Pack Islands**
4. Раскладывает грани **ровной решёткой** по эталонной (активной) грани — для бесшовной плитки на стенах/полах
5. **Extension → Repeat**
6. **Mapping** (его **Scale X/Y**); схема `Texture Coordinate [UV] → Mapping → Image Texture`
7. У seamless края совпадают — повтор не даёт видимых швов

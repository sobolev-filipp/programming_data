## Задание

Смоделируй (или возьми свой) объект, **разверни UV** (уроки 22–23) и наложи **полный PBR-материал** из скачанного набора.

**Идеи (НЕ металлическая панель — она была на уроке):**
- 🪵 Деревянный сундук / стол / бочка
- 🧱 Кирпичная / каменная стена
- 📕 Старая книга (кожаная обложка)
- 🧳 Чемодан с кожей
- 🪑 Табурет / ящик с досками

---

## Требования

- [ ] Объект **развёрнут** (UV, ровный Checker)
- [ ] Подключены минимум **3 карты**: Base Color, Roughness, Normal
- [ ] Правильно стоит **Color Space**: Base Color = sRGB, остальные = **Non-Color**
- [ ] Normal подключён через нод **Normal Map**
- [ ] Использован **`Ctrl+Shift+T`** (загрузка набора)
- [ ] Подобран масштаб текстуры (Mapping → Scale)
- [ ] Свет сбоку + рендер (`F12`)

---

## 💡 Подсказки (если что-то забыл)

- **Быстрая загрузка:** выдели Principled → `Ctrl+Shift+T` → выбери все файлы набора
- **Не распозналось?** подключи вручную: Image Texture → нужный вход; серые карты → **Non-Color**
- **Normal:** Image (Non-Color) → **Normal Map** → Principled [Normal]
- **Крупный/мелкий узор:** `Ctrl+T` → Mapping → Scale
- **Без развёртки текстура поплывёт** — сначала UV (уроки 22–23)!
- **Файлы не переименовывай** — Node Wrangler читает суффиксы (`_diff`, `_rough`, `_nor`)

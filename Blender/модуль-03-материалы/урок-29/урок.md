## Часть 1 — Теория: что такое запекание (16 минут)

### 1.1 Запекание = «фотография» сложного в простую картинку
**Bake (запекание)** — это **один раз посчитать** сложную информацию (рельеф, тени, цвет) и **записать её в картинку-текстуру**. Дальше эта картинка просто «приклеена» к модели и ничего не пересчитывает — быстро и дёшево.

> Аналогия: вместо того чтобы каждый раз лепить сложный торт, ты один раз его **сфотографировал** — и используешь фото.

### 1.2 Главное применение — High-poly → Low-poly

![Слева детальная геометрия → карта нормалей → плоскость, которая выглядит объёмной](изображения/normal-запекание.png)

*Слева — **high-poly** (настоящий рельеф). В центре — его **карта нормалей** (запечённая). Справа — **плоская** поверхность с этой картой: выглядит объёмной, хотя это **плоскость**! ([Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Normal_map_example_with_scene_and_result.png))*

Игровой пайплайн:
1. Делаешь **детальную** модель (high-poly) — много полигонов, тяжёлая.
2. Делаешь **простую** (low-poly) — мало полигонов, лёгкая.
3. **Запекаешь** детали high-poly в карты на low-poly.
4. Low-poly + карты = выглядит детально, **а тормозит как простая**. Идеально для слабых ПК!

> 🔁 Вершина модуля: **Normal Map** (урок 24) теперь делаем сами; **карту высот** (урок 25) используем как источник рельефа. Displacement добавлял настоящую геометрию — а запекание **подделывает** её картой, чтобы было легко.

### 1.3 Что можно запекать
| Bake Type | Что записывает | Куда потом |
|-----------|----------------|------------|
| **Normal** | рельеф high-poly | Normal Map → Principled [Normal] |
| **Ambient Occlusion (AO)** | мягкие тени в щелях | подмешать к Base Color (Multiply) |
| **Diffuse** | цвет/расцветку | в Base Color |

> 💡 **Фишка — запекание идёт через Cycles:** Bake — функция движка **Cycles** (даже если рендеришь в EEVEE, для запекания переключись на Cycles). Готовая карта потом работает и в EEVEE.

## Часть 2 — Готовим high-poly (брусчатка) и low-poly (10+15 минут)

Высокодетальную брусчатку сделаем **из карты высот** (повтор урока 25), а low-poly — плоскость.

### A. High-poly — брусчатка из карты высот
1. Удали куб (`X`). `Shift+A → Mesh → Plane`, `S → 1.5`, `Enter`.
2. `Ctrl+A → All Transforms`. `Tab → A → U → Unwrap → Tab` (нужна UV под карту).
3. Открой **Properties → вкладка Modifier** (иконка **гаечный ключ**) → **Add Modifier → Generate → Subdivision Surface** → переключи на **Simple** → **Levels Viewport = 6**.
   ✅ *Должно получиться:* плоскость стала очень густой сеткой (много граней — есть что двигать).
4. Ещё модификатор: **Add Modifier → Deform → Displace** (он встанет ПОСЛЕ Subdivision).
5. В модификаторе Displace нажми **New** (создаст текстуру) → перейди в **Properties → вкладка Texture** (иконка **красно-белая шахматка**) → **Type = Image or Movie** → **Open Image** → выбери `cobblestone_floor_04_disp_1k.png`.
6. У этого изображения поставь **Color Space = Non-Color** (это высоты).
7. Вернись в **Modifier** (ключ) → в Displace: **Texture Coordinates = UV**, **Strength ≈ 0.15**, **Midlevel ≈ 0.5**.
   ✅ *Должно получиться:* плоскость покрылась рельефом брусчатки — камни выступают, швы провалены (поверни вид сбоку — виден рельеф).
8. (Цвет для bake Diffuse) Дай high-poly материал: Shader Editor → `Shift+A → Texture → Image Texture → Open` → `cobblestone_floor_04_diff_1k.jpg` → `[Color]` в **Base Color**.
9. **Примени модификаторы** (чтобы рельеф стал настоящей геометрией): наведи на Displace → выпадающее меню `∨` → **Apply**; так же Subdivision (или оставь — Cycles печёт по «вычисленной» поверхности, но Apply надёжнее). Переименуй объект в **high** (двойной клик в Outliner).

### B. Low-poly — простая плоскость
1. `Shift+A → Mesh → Plane`, `S → 1.5` — поставь **ровно на то же место** (та же позиция и размер, что у high).
2. `Ctrl+A → All Transforms`. `Tab → A → U → Unwrap → Tab` (low-poly **обязательно** нужна UV — на неё запечём карты!).
3. Переименуй в **low**.

> 💡 **Фишка — low «оборачивает» high:** low-poly должна быть вплотную/чуть снаружи high и повторять его силуэт, чтобы лучи запекания дотянулись от low до рельефа high.

## Часть 3 — Запекаем Normal (high → low) (22 минуты)

### Шаг 1 — Движок и холст для карты
1. **Properties → вкладка Render** (иконка как **задняя крышка камеры**) → **Render Engine → Cycles**.
   ✅ *Должно получиться:* появилась панель **Bake** (внизу в Render Properties).
2. Выдели **low** → открой **Shader Editor** → `Shift+A → Texture → Image Texture` → **New** → имя `плитка_normal`, размер **2048**, **Color Space = Non-Color**. **OK**.
3. **Оставь этот Image Texture выделенным** (белая рамка). Это **мишень** запекания — подключать его пока никуда не надо.

### Шаг 2 — Выделение и настройки Bake
1. В 3D-виде: сначала кликни **high**, потом **с Shift** кликни **low** (порядок важен — low должна стать **активной**, она ярче обведена).
2. **Properties → вкладка Render → панель Bake:**
   - **Bake Type → Normal**
   - раскрой подраздел **Selected to Active** и поставь галочку **Selected to Active** ✅
   - **Extrusion ≈ 0.1**, **Max Ray Distance ≈ 0.1**
3. Нажми кнопку **Bake** (вверху панели). Внизу — полоска прогресса.
   ✅ *Должно получиться:* картинка `плитка_normal` залилась сине-фиолетовым — это запечённый рельеф брусчатки.

### Шаг 3 — Подключаем карту к low-poly
```
Image Texture (плитка_normal, Non-Color) ─[Color]─► Normal Map ─[Normal]─► Principled BSDF [Normal]
```
1. В Shader Editor low-poly: `Shift+A → Vector → Normal Map`.
2. Соедини `Image Texture [Color] → Normal Map [Color]`, затем `Normal Map [Normal] → Principled [Normal]`.
3. Спрячь high: выдели **high** → `H`.
   ✅ *Должно получиться:* плоская low-poly при боковом свете выглядит как настоящая брусчатка — камни и швы «торчат», хотя геометрия плоская! 🎉

> 💡 **Фишка — «No active image to bake to»:** значит не создан/не выделен Image-нод в материале активного объекта. Кликни нужный Image Texture в Shader Editor, чтобы он стал активным (белая рамка).

## Часть 4 — Cage: чистое запекание (12 минут)

Иногда на краях/фасках карта «полосатая». Лучи от low-poly идут вкось и «мажут». Это лечит **Cage**.

### Что такое Cage
**Cage («клетка»)** — раздутая копия low-poly. Лучи идут **по её нормалям** (ровно, перпендикулярно) и аккуратно «накрывают» high-poly. Меньше искажений.

### Как включить (где находится)
1. **Properties → вкладка Render → панель Bake → подраздел Selected to Active** → найди галочку **Cage** ✅.
2. Ниже задай **Cage Extrusion** (насколько «раздуть» клетку) — чуть больше, чтобы охватить все детали.
3. Нажми **Bake** заново.
   ✅ *Должно получиться:* края карты стали чистыми, без полос.

> 🎯 **ЛАЙФХАК — показать здесь!** Как победить артефакты запекания (Cage, Ray Distance, Margin) — в [лайфхак.md](лайфхак.md).

> 💡 **Фишка — Margin (растекание):** в подразделе **Output** панели Bake есть **Margin**. Если по швам UV тонкие зазоры — увеличь Margin (несколько пикселей), запекание «растечётся» за края островов.

## Часть 5 — Запекаем AO, цвет и сохраняем (15 минут)

### AO — мягкие тени в щелях

![Пример Ambient Occlusion — мягкие контактные тени](изображения/ambient-occlusion.jpg)

*Чистый **AO**: свет не достаёт в углы и щели — там темнее. Добавляет объём. ([Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Screen_space_ambient_occlusion.jpg))*

1. В Shader Editor low-poly: `Shift+A → Texture → Image Texture → New` (`плитка_AO`, 2048, **Non-Color**) → **оставь выделенным**.
2. Properties → Render → Bake: **Bake Type → Ambient Occlusion** → (high выделен, low активна, Selected to Active ✅) → **Bake**.
   ✅ *Должно получиться:* картинка `плитка_AO` стала серой с тёмными швами.
3. Подмешай к цвету: `Shift+A → Color → Mix Color`, режим **Multiply**, Factor 1.0; в один вход — цвет/Diffuse, в другой — AO; `[Result] → Principled [Base Color]` (как на уроке 24).

### (Бонус) Цвет — bake Diffuse
1. Новый Image Texture → New (`плитка_color`, 2048, **sRGB**) → выдели.
2. Bake Type → **Diffuse**; в подразделе **Contributions** сними **Direct** и **Indirect**, оставь только **Color** → **Bake**.
   ✅ *Должно получиться:* на low-poly запеклась расцветка брусчатки (камни нужного цвета) — подключи в Base Color.

### СОХРАНИ карты! (как на уроке 28)
1. Image Editor → **Image → Save As…** → сохрани `плитка_normal.png`, `плитка_AO.png`, `плитка_color.png` рядом с .blend.
2. Верхнее меню **File → External Data → Pack Resources**.

> ⚠️ **Фишка — запечённое тоже надо сохранять:** карты живут в памяти, пока не сохранил (звёздочка `*`). Save As + Pack Resources — иначе запекание пропадёт.

   ✅ *Должно получиться:* лёгкая плоская брусчатка выглядит как тяжёлая детальная.

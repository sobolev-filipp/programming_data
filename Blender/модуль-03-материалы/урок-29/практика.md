# Самостоятельная работа — Урок 29: Запеки детали на low-poly 🔥

> 🧑‍🎓 Делаешь сам(а): сделай **детальный** объект и **простой**, и запеки рельеф high→low (Normal + AO). Учитель помогает, если застрял.

## Задание

Выбери объект **НЕ плитка** (плитку пекли на уроке). Сделай его в двух версиях — **high-poly** (с рельефом) и **low-poly** (простой), разверни low-poly и **запеки** на неё **Normal** и **AO**. Спрячь high-poly — low-poly должна выглядеть детально.

**Идеи:**
- 🪙 Монета/медаль с рельефом (профиль, надпись)
- 🚪 Sci-fi люк/панель с болтами и швами (callback к уроку 24)
- 🧱 Кусок кирпичной/каменной стены
- ⚙️ Шестерёнка с фасками
- 📟 Кнопочная панель/пульт
- 🛡 Щит с выпуклым гербом (можно из урока 28)

> 💡 High-poly можно сделать модификаторами: Bevel + Subdivision, или **Displace** (урок 25) как источник рельефа. Не обязательно лепить вручную.

## Требования

- [ ] Сделаны **high-poly** (детальная) и **low-poly** (простая) версии, в одном месте
- [ ] У low-poly есть **UV-развёртка**
- [ ] Создан **Image Texture** (Non-Color) и выделен как мишень
- [ ] Запечена **Normal** (Cycles, Selected to Active) и подключена через **Normal Map**
- [ ] Запечён **AO** и подмешан к Base Color (Multiply)
- [ ] При артефактах применён **Cage / Ray Distance / Margin**
- [ ] Карты **сохранены** (Save As) и **Pack Resources**
- [ ] Рендер low-poly (high-poly спрятан)

---

## 💡 Подсказки (если что-то забыл)

- **Движок:** Render Properties → **Cycles** (без него Bake недоступен)
- **Мишень:** в материале low-poly создай **Image Texture → New** (Non-Color) и **оставь выделенным**
- **Порядок выделения:** high-poly → затем **low-poly (активной)**; Bake → **Selected to Active** ✅
- **Тип:** Bake Type → **Normal**, потом отдельной картой → **Ambient Occlusion**
- **Подключить Normal:** Image (Non-Color) → **Normal Map** → Principled [Normal]
- **AO:** Image → **Mix Color (Multiply)** с Base Color
- **Грязное запекание:** включи **Cage**, подбери **Ray Distance**, подними **Margin** (см. [лайфхак](лайфхак.md))
- **СОХРАНИ:** Image → Save As (.png) + File → External Data → **Pack Resources**

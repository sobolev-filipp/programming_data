# Лайфхак урока 20 — Ctrl+T: координаты и Mapping за секунду

> Каждой текстуре нужны Texture Coordinate + Mapping, чтобы ей управлять. Тянуть их вручную каждый раз — долго. Node Wrangler делает это одной клавишей.

---

## Главный приём — `Ctrl + T`

1. Выдели нод текстуры (Noise / Voronoi / Image…)
2. Нажми **`Ctrl + T`**
3. Аддон **сам** добавит и подключит:
   ```
   Texture Coordinate ─[Generated]─► Mapping ─[Vector]─► твоя текстура [Vector]
   ```

Готово! Теперь крути Mapping (Scale/Location/Rotation) — управляешь узором.

> ⚠️ Нужен включённый **Node Wrangler** (`Edit → Preferences → Add-ons`).

---

## Что менять в Mapping

| Параметр | Эффект |
|----------|--------|
| **Scale** | размер узора (крупнее/мельче кратеры, полосы) |
| **Location** | сдвиг узора |
| **Rotation** | поворот узора |

> 💡 Хочешь крупные кратеры — уменьши Scale; хочешь мелкую «крупу» — увеличь.

---

## Какой выход координат выбрать

После `Ctrl+T` по умолчанию подключается **Generated**. Иногда нужно переподключить на другой выход Texture Coordinate:

| Выход | Когда |
|-------|-------|
| **Generated** | процедурные текстуры (по умолчанию) |
| **Object** | текстура «привязана» к объекту-пустышке (двигается с ней) |
| **UV** | картинки-текстуры по развёртке (уроки 23–24) |

---

## Бонус — анимация текстуры

Хочешь, чтобы узор **двигался** (плывущие облака, текущая лава)? Поставь ключи (Keyframe) на **Location** в Mapping — текстура поедет. (Анимацию разберём в Модуле 6.)

---

## Шпаргалка

| Хочу | Делаю |
|------|-------|
| Добавить координаты + Mapping | выделить текстуру → `Ctrl + T` |
| Изменить размер узора | Mapping → Scale |
| Сдвинуть/повернуть узор | Mapping → Location / Rotation |
| Привязать к объекту | Texture Coordinate → Object |
| Анимировать узор | ключи на Mapping Location |

> 💡 **Главная мысль:** `Ctrl+T` — рефлекс на каждую новую текстуру. Сразу получаешь «руль» (Mapping), которым управляешь узором.

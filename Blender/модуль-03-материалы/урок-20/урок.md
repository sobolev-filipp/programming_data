## Часть 1 — Теория: как текстура ложится на объект (12 минут)

Текстура должна знать, **куда** ей ложиться. За это отвечают **координаты**. Без управления координатами текстура «плывёт» или тянется неправильно.

### 🧩 Что делает каждый нод (простыми словами)

| Нод | Что делает (аналогия) | Главные сокеты |
|-----|------------------------|----------------|
| **Texture Coordinate** | «система координат»: откуда брать привязку текстуры | выходы **Generated**, **Object**, **UV**, **Normal** |
| **Mapping** | «руль текстуры»: двигает, вращает, масштабирует узор | входы **Location/Rotation/Scale**, выход **Vector** |
| **Bump** | «фальшивый рельеф»: делает поверхность шероховатой по карте, не меняя геометрию | вход **Height**, выход **Normal** |

**Базовая связка:**
```
Texture Coordinate ──[Generated]──► Mapping ──[Vector]──► Noise/Voronoi [Vector]
```

> 💡 **Фишка — какой выход координат брать:**
> - **Generated** — «обёртка по габаритам объекта» (для процедурных текстур по умолчанию)
> - **Object** — привязка к другому объекту (текстура двигается с ним)
> - **UV** — по развёртке (для картинок-текстур, уроки 23–24)
> Для процедурной Луны берём **Generated** (или Object).

> 💡 **Фишка — зачем Mapping:** без него ты не управляешь узором. С Mapping крутишь **Scale** (крупнее/мельче кратеры), **Location** (сдвиг), **Rotation** (поворот). Это «руль» любой текстуры.

## Часть 2 — Кратеры Луны (Voronoi + Mapping) (25 минут)

### Заготовка

1. `Shift + A → Mesh → UV Sphere` → `ПКМ → Shade Smooth`, новый материал

### Схема

```
Texture Coordinate ─[Generated]─► Mapping ─[Vector]─► Voronoi ─[Distance]─► ColorRamp ─► Base Color
```

### Шаги

1. `Shift + A → Input → Texture Coordinate`
2. `Shift + A → Vector → Mapping`
3. `Shift + A → Texture → Voronoi Texture`
4. Соедини:
   - **Texture Coordinate [Generated]** → **Mapping [Vector]**
   - **Mapping [Vector]** → **Voronoi [Vector]**
   - **Voronoi [Distance]** → **ColorRamp [Fac]**
   - **ColorRamp [Color]** → **Principled [Base Color]**
5. В Mapping крути **Scale** — кратеры крупнее/мельче
6. В ColorRamp — серые оттенки Луны (тёмные «моря» и светлые участки)

> 💡 **Фишка — Voronoi [Distance] = кратеры:** выход Distance даёт «ячейки» с тёмными центрами — похоже на кратеры. Поиграй типами Voronoi (F1, Smooth) для разных форм.

## Часть 3 — Рельеф через Bump (без геометрии!) (25 минут)

Сейчас кратеры — это только цвет (нарисованы плоско). Сделаем, чтобы они **выглядели объёмными**, не добавляя полигонов. Это нод **Bump**.

### Схема

```
Voronoi ─[Distance]─► Bump ─[Normal]─► Principled BSDF [Normal]
```

### Шаги

1. `Shift + A → Vector → Bump`
2. Соедини: **Voronoi [Distance]** → **Bump [Height]**
3. Соедини: **Bump [Normal]** → **Principled BSDF [Normal]** (вход внизу ноды)
4. Крути **Strength** у Bump — кратеры «продавились»!

> 💡 **Фишка — Bump обманывает свет:** геометрия остаётся гладкой, но свет ложится как на рельеф. Дёшево и сердито — идеально для слабых ПК (рельеф без лишних полигонов).

> 💡 **Фишка — добавь мелкий шум:** второй Noise малого масштаба → подмешать в Bump (через Mix или сложить) → лунная «пыль»-шероховатость поверх кратеров.

> ⚠️ **Bump vs Displacement:** Bump только **притворяется** рельефом (свет), геометрия плоская. Настоящий рельеф (с тенями по силуэту) — это **Displacement**, урок 25.

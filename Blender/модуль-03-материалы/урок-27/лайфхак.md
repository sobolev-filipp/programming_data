# Лайфхак урока 27 — Ocean-модификатор: море одной кнопкой

> Моделировать волны вручную — кошмар. Модификатор **Ocean** генерирует целое **анимированное море** автоматически: волны, пена, движение. Один из самых эффектных модификаторов.

---

## Как включить

1. `Shift+A → Mesh → Plane`, `S → 5` (или больше)
2. 🔧 → **Add Modifier → Physics → Ocean**
3. Плоскость превратилась в воду с волнами

> Нажми **Пробел** (Play) — волны движутся сами (Ocean анимирован по кадрам).

---

## Главные параметры

| Параметр | Что меняет |
|----------|-----------|
| **Geometry → Resolution** | детализация волн (выше = чётче, тяжелее для ПК) |
| **Spatial Size** | размер участка моря |
| **Wave Scale** | высота волн |
| **Choppiness** | острота гребней (0 — пологие, 1+ — острые) |
| **Wind Velocity** | сила «ветра» (крупнее волны) |
| **Time** | кадр анимации (двигается сам при Play) |

> 💡 Для слабых ПК держи **Resolution** небольшим (видовой — низкий, рендерный — повыше).

---

## Пена на гребнях (Foam)

1. В модификаторе включи **Spray / Foam**
2. Появится **Foam** как атрибут — подключи его в шейдере (через Attribute → ColorRamp → подмешать белую пену к воде)
3. Гребни волн покрылись пеной — как настоящий шторм!

---

## Материал воды

- **Transmission** (или Glass), **IOR 1.33**, лёгкий голубой
- **Volume Absorption** (бирюзовый, малый Density) — глубина «зеленеет»
- Пена (Foam) → белые пятна на гребнях
- **HDRI**-небо даёт воде красивые отражения

---

## Где пригодится

| Сцена | Как |
|-------|-----|
| 🌊 Море/океан | Ocean большой Scale |
| 🏝 Вокруг острова | Ocean + остров (Displace) |
| 🛶 Озеро/река | Ocean маленькие волны |
| 🌧 Лужи/потоп | Ocean слабый + отражения |

---

## Шпаргалка

| Хочу | Делаю |
|------|-------|
| Море с волнами | Plane → Ocean modifier |
| Выше/острее волны | Wave Scale / Choppiness |
| Пена на гребнях | включить Foam → в шейдер |
| Движение | Play (анимирован по времени) |
| Беречь ПК | низкий Resolution в виде |

> 💡 **Главная мысль:** не лепи волны — включи Ocean. Целое анимированное море с пеной и отражениями за минуту. Отличный новый модификатор в копилку.

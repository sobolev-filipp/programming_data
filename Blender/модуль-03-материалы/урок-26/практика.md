# Самостоятельная работа — Урок 26: Своя планета из реальных карт 🪐

> 🧑‍🎓 Делаешь сам(а): собери планету из реальных карт. Учитель помогает, если застрял.

## 📥 Что скачать заранее (нужно для практики!)

Карты планеты — бесплатно, бери **2K**:
- **Solar System Scope** — [solarsystemscope.com/textures](https://www.solarsystemscope.com/textures/) (Земля, Марс, Венера, Юпитер, Луна…)
- **NASA 3D Resources** — [science.nasa.gov/3d-resources](https://science.nasa.gov/3d-resources/)
- Правила и список карт: [справочники/где-скачать.md](../../справочники/где-скачать.md)

> Нужны карты: **Color/Day** (обязательно), а также по возможности **Normal**, **Specular/Water**, **Night**, **Clouds**.

---

## Задание

Собери **другую планету** (не Землю с урока — Марс, Венера, Юпитер, или фантастическую) из реальных карт, со всеми эффектами, что освоил.

**Идеи:**
- 🔴 **Марс** (рыжий, кратеры — Normal, без облаков)
- 🟡 **Венера** (плотные облака отдельным слоем + атмосфера)
- 🪐 **Юпитер** с реальной картой + кольца (Torus)
- 🌍 **Земля-2 / экзопланета** (свои цвета, фантазийная)

---

## Требования

- [ ] Цвет планеты из карты (**Day/Color** → Base Color)
- [ ] Хотя бы один доп. эффект: **Normal** (рельеф) ИЛИ **маска океана** (Roughness)
- [ ] Бонус: **облака** (отдельный слой) ИЛИ **ночные огни** (Emission) ИЛИ **атмосфера** (Fresnel)
- [ ] **Космос-фон** (World: звёзды)
- [ ] Свет сбоку (Sun) + рендер (`F12`)

---

## 💡 Подсказки (если что-то забыл)

- **UV-сфера уже развёрнута** под карты планет — разворачивать не нужно
- **Цвет:** Image Texture (sRGB) → Base Color
- **Рельеф:** Normal-карта (**Non-Color**) → **Normal Map** → Principled [Normal]
- **Океан/блеск:** Specular-маска (Non-Color) → ColorRamp → Roughness (вода = низкий)
- **Ночные огни:** Night-карта → **Emission**; Sun сбоку (см. [лайфхак](лайфхак.md))
- **Облака:** дубль сферы `S → 1.01`, Clouds-карта в Base Color + **Alpha**, Blend Mode → Alpha Blend
- **Атмосфера:** дубль `S → 1.03`, Fresnel → голубой Emission + Transparent (Mix Shader)
- **Звёзды:** World → Noise → ColorRamp (урок 19)

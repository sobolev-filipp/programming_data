## Что собрать

- 🧱 **Стена** — плоскость/куб с реальным PBR-набором (кирпич/бетон): Base Color + Normal + Roughness (повтор урока 24)
- 🔠 **Неоновая вывеска** — текст или фигура (трубки) со **свечением (Emission + Bloom)**
- 🪟 **Окна** — со стеклом и лёгким **Fresnel**-бликом (повтор)
- 🌙 Тёмная сцена, ночь — чтобы неон ярко горел

---

## Требования

- [ ] Стена с **реальным PBR-набором** (минимум Color + Normal)
- [ ] Вывеска со **свечением** (Emission), включён **Bloom** (EEVEE)
- [ ] Использован **Fresnel** хотя бы раз (ободок стекла/трубок)
- [ ] Карты-данные (Normal/Roughness) в **Non-Color**, цвет — sRGB
- [ ] Тёмная сцена, неон читается
- [ ] Рендер (`F12`)

---

## 💡 Подсказки (если что-то забыл)

- **Текст:** `Shift+A → Text`, в Edit Mode печатай, потом `Convert → Mesh`; неон-трубки — Bevel кривой (урок 6)
- **PBR-стена:** выдели Principled → `Ctrl+Shift+T` → выбери все карты (урок 24)
- **Свечение неона:** материал → Emission Color + Strength 5–10; Render Properties → **Bloom**
- **Fresnel-ободок:** `Fresnel [Fac]` → ColorRamp → подмешать к свечению/стеклу (урок 21, 26)
- **Развёртка стены:** для кирпича — UV (уроки 22–23), масштаб через Mapping
- **Тёмная сцена:** World потемнее, неон станет ярким акцентом

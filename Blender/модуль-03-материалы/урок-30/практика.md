# Итоговый проект — Урок 30: твоя текстурированная диорама 🏆

> 🧑‍🎓 Это **итог Модуля 3**. Собери свою сцену-диораму и примени **минимум 5 техник** модуля. В конце — защита по рубрике.

## Задание

Собери **маленькую сцену** на одну тему (НЕ Земля/Луна) и **затекстурируй** её, применив приёмы Модуля 3. Заверши **Pack Resources** и сделай рендер.

**Темы (или своя):** 🏰 средневековый двор · 🧪 магическая лаборатория · 🚀 отсек станции · 🏚 заброшенная комната · 💎 витрина сокровищ · 🏝 уголок острова · 🍄 сказочный лес.

---

## 📥 Что скачать (под тему)

- **PBR-текстуры:** [Poly Haven](https://polyhaven.com/textures) / [ambientCG](https://ambientcg.com) (1–2K) — дерево, камень, металл, ткань
- **Эмблема/узор для росписи:** [game-icons.net](https://game-icons.net) (PNG)
- **HDRI для света:** [polyhaven.com/hdris](https://polyhaven.com/hdris) (2K)
- Сложи всё в одну папку рядом с .blend. Подробно: [где-скачать.md](../../справочники/где-скачать.md)

---

## Требования

- [ ] Сцена **смоделирована** (не только готовые ассеты) и разложена по **коллекциям**
- [ ] Применено **минимум 5 техник** Модуля 3 (отметь какие)
- [ ] Есть **UV-развёртка** там, где нужны картинки/карты
- [ ] Хотя бы один объект с **PBR-набором** (Ctrl+Shift+T)
- [ ] Хотя бы один объект с **ручной росписью** (Texture Paint)
- [ ] Есть **акцент** (главный объект) и заполнены края
- [ ] Свет + камера + **рендер** (`F12`)
- [ ] **Pack Resources** сделан (текстуры не потеряются)

## 📊 Рубрика оценки (показать ДО старта)

| Критерий | 2 балла | 1 балл | 0 |
|----------|---------|--------|---|
| **Моделирование** | своя аккуратная сцена | простая/частично готовая | только чужие ассеты |
| **Техники модуля** | 5+ уместных | 3–4 | менее 3 |
| **UV и карты** | чисто, без растяжений | мелкие огрехи | текстуры «плывут» |
| **Роспись/детали** | аккуратная, к месту | есть, грубовато | нет |
| **Композиция** | акцент + заполнено | средне | «куча объектов» |
| **Защита** | внятно, показал техники | коротко | молча |
| **Сборка** | Pack + рендер сохранён | частично | нет |

**Итог:** 12–14 — отлично · 8–11 — хорошо · 5–7 — норм · <5 — доработать.

## 💡 Подсказки (если что-то забыл)

- **Коллекции:** выдели объекты → `M` → New Collection
- **UV:** `Tab → A → U → Smart UV Project`
- **PBR за клик:** Principled выделен → `Ctrl+Shift+T` → выбери все файлы набора
- **Процедурно:** `Shift+A → Texture → Noise/Voronoi` → ColorRamp → Base Color
- **Износ:** Geometry **[Pointiness]** → ColorRamp → маска (ур.20)
- **Рельеф:** Subdivision (Simple) + Displace, **Texture Coordinates = UV**
- **Роспись:** Texture Paint → Tool → Texture Slots `+` → Base Color → New (2048)
- **Стекло/SSS:** Transmission=1 / Subsurface Weight (ур.27)
- **Камера:** наведи вид → `Ctrl+Numpad0`; рендер `F12`
- **НЕ потерять текстуры:** File → External Data → **Pack Resources** (ур.30 лайфхак)

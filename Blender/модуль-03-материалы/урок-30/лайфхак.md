# Лайфхак урока 30 — Сборка проекта в один файл (Pack Resources)

> В диораме много внешних файлов: скачанные PBR-текстуры, карты Земли, сохранённые росписи и запечённые карты. Если перенести .blend на другой ПК (или сдать учителю) — Blender **потеряет** их, и материалы станут розово-чёрными. Решение — упаковать всё внутрь файла.

---

## Главная команда — Pack Resources

**File → External Data → Pack Resources**

✅ *Что произойдёт:* все картинки-текстуры зашьются **внутрь .blend**. Теперь файл самодостаточен — переноси куда хочешь, ничего не отвалится.

> Признак, что упаковано: в Outliner (режим **Blender File → Images**) у картинок появляется значок «подарочной коробки».

---

## Проверить, не потеряно ли что-то

**File → External Data → Report Missing Files**
- Если внизу выскочило сообщение про missing — какие-то текстуры не найдены (ты двигал/удалял файлы).
- Лечение: **File → External Data → Find Missing Files** → укажи папку с текстурами → Blender сам их подтянет → потом **Pack Resources**.

---

## Розово-чёрная «шахматка» на модели?

Это Blender кричит: «не нашёл текстуру!».
1. **Find Missing Files** (укажи папку) — подтянет.
2. Потом **Pack Resources** — чтобы больше не терялось.
3. На будущее: держи текстуры **в одной папке рядом с .blend** ещё ДО назначения.

---

## Перед сдачей работы — чек-лист

| Шаг | Команда |
|-----|---------|
| Сохранить росписи/карты | Image → Save As (.png) |
| Упаковать всё внутрь | File → External Data → **Pack Resources** |
| Проверить пропажи | File → External Data → Report Missing Files |
| Сохранить файл | `Ctrl+S` |
| Рендер кадра | `F12` → Image → Save As |

> 💡 **Главная мысль:** красивая диорама бесполезна, если при переносе «рассыпались» текстуры. **Pack Resources** делает .blend самодостаточным — это первое, что делают перед сдачей и публикацией проекта.

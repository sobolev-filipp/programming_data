1. Как из кривой сделать трубу? (урок 6)
2. Три булевы операции + правило перед Boolean? (урок 7)

4. Что делает Bridge Edge Loops и Loop Tools → Circle? (урок 9)
5. Какой модификатор уменьшает полигоны? (урок 10)
6. Distribute Points + Instance on Points — что делают? (урок 11)
7. Mesh Line и Grid — для чего? (урок 12)
8. Как лепят low-poly животное? Что главное? (урок 13)
9. Что делают Skin и Displace? (урок 14)
10. Что такое Asset Browser и китбашинг? (уроки 15–16)

---

## Ответы (для учителя)

1. Curve → Geometry → Bevel → Depth
2. Difference/Union/Intersect; `Ctrl+A → Scale` до Boolean
3. Screw / Spin (вращение профиля)
4. Bridge — соединяет кольца переходом; Circle — выравнивает в круг
5. Decimate
6. Distribute рассыпает точки; Instance ставит объект на каждую точку
7. Mesh Line — ряд; Grid — сетка
8. Бокс-моделинг + Mirror + Proportional; главное — силуэт
9. Skin — объём из линий (деревья); Displace — рельеф из текстуры
10. Asset Browser — своя библиотека ассетов; китбаш — сборка из набора деталей

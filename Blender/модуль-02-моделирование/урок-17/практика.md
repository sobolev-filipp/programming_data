# Итоговая работа Модуля 2 — на оценку 🏆

> 🧑‍🎓 Это **итоговая работа модуля**. Покажи всё, чему научился, в одной большой сцене.

---

## Что сдать

**Большая сцена на выбор:**
- 🌌 **Космическая сцена** — корабль + астероиды + станция + звёзды
- 🐄 **Low-poly мир** — деревня / ферма / остров с природой и животными
- 🎪 **Своя тема** — парк, город, биом (согласуй с учителем)

---

## Обязательные требования

Сцена должна показать навыки модуля:

- [ ] Есть **главный объект-акцент** + продуманная композиция
- [ ] Использован **Boolean** ИЛИ **Screw** ИЛИ **кривые** (техническое моделирование)
- [ ] Использован **Geometry Nodes** (разброс или сетка)
- [ ] Использован **Skin** ИЛИ **Displace** (природа/деревья/рельеф) — для low-poly мира
- [ ] **Разнообразие** объектов (нет одинаковых клонов)
- [ ] Сцена организована **коллекциями**
- [ ] Использован **Asset Browser** (переиспользование своих ассетов)
- [ ] Камера + свет + финальный **рендер**
- [ ] Защита: рассказ о работе классу

## Бонусы (плюс к оценке)

- [ ] Свечение (Emission) — двигатели / окна / костёр
- [ ] Оптимизация (Decimate тяжёлых объектов)
- [ ] Атмосферный фон / настроение
- [ ] Особо аккуратная композиция (правило трети)

---

## Критерии оценки

| Критерий | Баллы |
|----------|-------|
| Техническое моделирование (Boolean/Screw/кривые) | 2 |
| Geometry Nodes / Skin / Displace | 2 |
| Композиция и разнообразие | 2 |
| Организация (коллекции, Asset Browser) | 2 |
| Рендер + защита | 2 |
| **Бонусы** | +до 2 |
| | **Итого: 10 (+2)** |

> Критерии показываются **до** начала работы.

---

## Совет

Не делай всё с нуля — **собери из готового** (корабль, животные, природа с прошлых уроков) и улучши. Итоговая проверяет умение **собрать и подать**, а не скорость лепки.

## Обязательные требования

Сцена должна показать навыки модуля:

- [ ] Есть **главный объект-акцент** + продуманная композиция
- [ ] Использован **Boolean** ИЛИ **Screw** ИЛИ **кривые** (техническое моделирование)
- [ ] Использован **Geometry Nodes** (разброс или сетка)
- [ ] Использован **Skin** ИЛИ **Displace** (природа/деревья/рельеф) — для low-poly мира
- [ ] **Разнообразие** объектов (нет одинаковых клонов)
- [ ] Сцена организована **коллекциями**
- [ ] Использован **Asset Browser** (переиспользование своих ассетов)
- [ ] Камера + свет + финальный **рендер**
- [ ] Защита: рассказ о работе классу

## Бонусы (плюс к оценке)

- [ ] Свечение (Emission) — двигатели / окна / костёр
- [ ] Оптимизация (Decimate тяжёлых объектов)
- [ ] Атмосферный фон / настроение
- [ ] Особо аккуратная композиция (правило трети)

## 💡 Подсказки (если что-то забыл из модуля 2)

- **Кривые-трубы:** Curve → Geometry → Bevel → Depth
- **Вырезать/соединить:** Boolean (Bool Tool: `Ctrl+Numpad −`); до этого `Ctrl+A → Scale`
- **Тела вращения:** Screw (сопла, кольца, башни), Spin
- **Соединить кольца:** Bridge Edge Loops; выровнять отверстие: Loop Tools → Circle
- **Облегчить модель:** Decimate (следи за Statistics)
- **Рассыпать (трава/звёзды/камни):** Geo Nodes — Distribute Points + Instance on Points + Random Value
- **Ряд/сетка:** Mesh Line / Grid; вывести параметр на ползунок — связь от Group Input
- **Деревья:** Skin (толщина `Ctrl+A`); **рельеф:** Displace
- **Сборка сцены:** Asset Browser (`Mark as Asset`), коллекции (`M`), Weighted Normal для чистого затенения

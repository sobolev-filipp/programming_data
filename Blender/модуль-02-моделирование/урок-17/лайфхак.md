# Лайфхак урока 17 — Быстрый красивый кадр для защиты

> Хорошая работа должна и выглядеть хорошо. Полноценно свет и камеру разберём в Модуле 4, а сейчас — три быстрых приёма, чтобы сцена «заиграла» на защите.

---

## 1. Ракурс камеры

1. Найди красивый вид в Viewport (чуть сбоку и сверху — почти всегда выигрышно)
2. `Ctrl + Numpad 0` — сделать текущий вид камерой
3. Подправь: `N → View → Camera to View` ✅, двигай вид → поймал кадр → сними галочку

> 💡 **Фишка — правило трети:** главный объект не по центру, а чуть в сторону. Оставь «воздух» в кадре — смотрится профессиональнее.

---

## 2. Простой свет (3 минуты)

Самый быстрый способ — **через World (фон)**:
1. Properties → 🌍 **World** → Color — задай не чёрный, а цветной фон (космос — тёмно-синий, день — голубой)
2. World даёт мягкий общий свет на всю сцену

Добавь один **Sun**:
1. `Shift + A → Light → Sun`
2. Поверни (`R`), чтобы свет падал чуть сбоку — появятся тени и объём

> 💡 **Фишка — свет сбоку, не в лоб:** боковой свет создаёт тени и подчёркивает форму. Свет «в лоб» делает картинку плоской.

---

## 3. Фон и атмосфера

- **Космос:** тёмный World + звёзды (Geo Nodes, урок 11) + свечение двигателей (Emission)
- **Low-poly мир:** голубой World + лёгкий туман (можно позже) + тёплый Sun
- Включи в Viewport **Rendered** (`Z`) — увидишь свет и материалы сразу

---

## 4. Рендер для слабого ПК

- Движок **EEVEE** (быстрый) — Render Properties → Render Engine
- Разрешение для защиты: 1280×720 хватит (Output Properties)
- `F12` → `Image → Save As` (PNG)

---

## Шпаргалка

| Хочу | Делаю |
|------|-------|
| Поставить камеру | `Ctrl+Numpad0`, Camera to View |
| Красивый ракурс | сбоку-сверху, правило трети |
| Быстрый свет | цветной World + один Sun сбоку |
| Увидеть результат | `Z → Rendered` |
| Сохранить кадр | `F12 → Image → Save As` |

> 💡 **Главная мысль:** даже простая сцена с хорошим ракурсом и боковым светом выглядит в разы лучше, чем сложная при плоском освещении. Подача решает!

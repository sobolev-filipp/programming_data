# Самостоятельная работа — Урок 6: Американские горки 🎢

> 🧑‍🎓 Делаешь сам(а), применяя кривые. Учитель помогает, если застрял.

## Задание

На уроке мы гнули кривые для настольной лампы (стойка, держатель, провод). Теперь — другое применение кривых: построй **трассу американских горок** (а для смелых — ещё и **водную горку**).

> 💡 Горки дополнят сцену «парк развлечений» с каруселью из практики урока 3.

**Из чего состоит:**
- Рельсы — кривая **Path**, изогнутая петлями и подъёмами, с **Bevel** (труба-рельс)
- Второй рельс рядом — параллельная кривая (или дубль)
- Шпалы-перекладины — маленький куб + **Array along curve** (или вручную)
- Опоры — вертикальные цилиндры под трассой
- Вагончик — простой куб/капсула на рельсах

---

## Требования

- [ ] Трасса построена **кривой** с изгибами (петля, подъём, спуск)
- [ ] Кривой задана **толщина** (Bevel кривой → рельс-труба)
- [ ] Осознанно использован **тип ручек** (`V`: Auto для плавности, Vector для углов)
- [ ] Минимум **2 параллельных рельса** (дубль/соединение кривых)
- [ ] Трасса превращена в меш (`Convert → Mesh`)
- [ ] Материалы (металл рельсов, опоры) + рендер (`F12`)

---

## Подсказки

![Основные шаги: американская горка и водная горка с параметрами](изображения/практика-горки-шаги.png)

*Шпаргалка со всеми шагами и значениями: рельс (Path → Bevel Depth 0.05, Resolution 3–4), петля (ручки Aligned), шпалы (Array → Fit Curve + Curve-модификатор), второй рельс (`Alt+D`); жёлоб водной горки (Bevel → Object, U-профиль), вода (Alpha Blend), бассейн (Cylinder, Scale Z 0.2).*

### 🛤️ Рельс — по шагам

1. `Shift + A → Curve → Path` (или Bezier) — заготовка трассы. **Начинай строить от центра мира (0,0,0)** — так начало трассы совпадёт с Origin (это важно для шпал, см. ниже).
2. **Сразу примени масштаб:** `Ctrl + A → Scale` (иначе труба-рельс выйдет разной толщины — см. подводные камни в теории).
3. Рисуй трассу **сбоку** (`Numpad 1`) для подъёмов/спусков и **сверху** (`Numpad 7`) для поворотов, чередуя виды.
4. Наращивай трассу: выдели крайнюю точку → `E` → клик, ещё `E` → клик… так «ведёшь» рельс.
5. Плавные виражи — ручки **Auto/Aligned** (`V`); резкий поворот — **Vector**.
6. Толщина рельса: 📈 **Object Data → Geometry → Bevel → Depth 0.05** → линия стала рельсом-трубой.
7. Гладкость: **Bevel → Resolution 3–4** (low-poly), **Resolution Preview U** — плавность изгиба вдоль трассы.

### 🌀 Петля («мёртвая петля»)

1. Смотри строго **сбоку** (`Numpad 1`).
2. Веди трассу вверх, затем точками закрути **кольцо**: вверх → назад → вниз → вперёд.
3. Ручки **Aligned** (`V`) — чтобы петля была круглой, без изломов.
4. Совет: сделай кольцо из 5–6 точек; при желании замкни `Alt + C`.

### 🪜 Второй рельс и шпалы

- **Второй рельс:** выдели трассу → `Alt + D` (**связанная** копия) → сдвинь вбок на ширину колеи. У связанной копии толщина меняется у обоих рельсов сразу — удобно подбирать диаметр.
- **Шпалы (перекладины) автоматически вдоль трассы** *(вспомни Array из урока 3!):*

  > ⚠️ **Сначала про Origin (точки опоры) — именно из-за них шпалы «уплывают»!**
  > - **Начало трассы = Origin кривой.** Шпалы раскладываются от Origin кривой. Чтобы они шли **с самого начала** трассы: Edit Mode → выдели **первую** точку трассы → `Shift + S → Cursor to Selected` → Object Mode → `Object → Set Origin → Origin to 3D Cursor`. Теперь Origin кривой — в начале трассы. *(А если строил трассу от центра мира — он уже там.)*
  > - **Origin шпалы — по центру.** У нового `Cube` центр на месте. Если двигал сетку в Edit Mode — верни: `Object → Set Origin → Origin to Geometry`. Иначе шпалы встанут **вбок** от рельса.

  Шаги:
  1. Сделай одну шпалу — маленький `Cube`, сплющи `S`. Поставь её в **центр мира**: `Alt + G` (сбросить положение в 0,0,0).
  2. Модификатор **Array** → Fit Type **Fit Curve** → Curve = твоя трасса.
  3. Ниже добавь модификатор **Curve** → Object = та же трасса → **Deform Axis = X** (та же ось, вдоль которой идёт массив). Шпалы легли вдоль рельсов, повторяя изгибы. 🎉
  4. Шпалы «уехали» вбок или сквозь рельс? Подвинь шпалу-оригинал (`G` в Object Mode) — её сдвиг от центра = сдвиг **поперёк** трассы; поставь ровно на рельсы.
  5. **Count / Relative Offset** — подбери частоту шпал.
- **Проще (вручную):** поставь одну шпалу и продублируй `Shift + D` вдоль трассы.

### 🏗️ Опоры

- Под низкими точками трассы поставь вертикальные **цилиндры** (`Shift+A → Cylinder`), подгони высоту до трассы.
- Одинаковые опоры быстро: **Array** (Constant Offset по X) или дубли `Shift + D`.

### 💧 Водная горка — по шагам (если делаешь её)

Водная горка — это **жёлоб** (открытая труба-полукруг), по которому «течёт вода».

1. Нарисуй трассу горки — **Path** с плавными спусками и поворотами (пологие ручки **Auto**). `Ctrl + A → Scale`.
2. **Профиль-жёлоб (буква U) — подробно.** Профиль — это **отдельная маленькая кривая** в форме **U**. Blender «протащит» её вдоль трассы, и получится жёлоб:
   1. `Shift + A → Curve → Circle` — добавили кривую-кольцо (4 точки по кругу).
   2. `Tab` → **Edit Mode**, `Numpad 1` — **вид спереди** (рисуем профиль «в лицо»).
   3. `A` (выделить всё) → `Alt + C` — **разомкнуть** кольцо: из круга получилась открытая дуга-«чаша».
   4. Открытая сторона смотрит не вверх? `R` — поверни «чашу» так, чтобы она открывалась **вверх** (как буква U).
   5. *(по желанию)* выдели лишние верхние точки → `X → Vertices`, чтобы верх был ровно раскрыт, а дно — округлое. Ручки точек оставь **Auto** (`V`) — дно будет плавным.
   6. `Tab` → профиль готов. Дай ему понятное имя (например, `U_profile`).
   > ⚠️ Профиль должен быть **отдельным объектом** и **открытым** (не замкнутым) — тогда жёлоб будет с открытым верхом. Снова замкнёшь (`Alt + C`) — получится закрытая труба.
3. Выдели **трассу** → 📈 **Object Data → Geometry → Bevel → Object** → выбери свой `U_profile`. Труба превратилась в **открытый жёлоб**! 🎉
   > ⚠️ **Жёлоб смотрит вбок или перекручен?** Поверни точки профиля (`R` в Edit Mode) или подкрути **наклон** трассы: Edit Mode на трассе → `A` → `Ctrl + T` двигай мышь (Tilt), либо сбрось наклон `Alt + T`.
4. **Вода:** продублируй трассу `Shift + D`, дай ей тонкий Bevel Depth и **голубой полупрозрачный** материал (**Alpha Blend** — стекло из урока 4) или лёгкий Emission — будто вода блестит.
5. Внизу — **бассейн:** цилиндр, сплющенный `S → Z`, с тем же голубым материалом.
6. По желанию — брызги: несколько маленьких **Ico Sphere** у выхода из горки.

> 💡 **Не хочешь возиться с профилем?** Сделай водную горку **закрытой круглой трубой** (обычный Bevel → Depth) — получится крытая аквапарковая труба, тоже здорово.


### Общие советы

- Перед `Convert → Mesh` **сохрани копию** — потом ручки не вернуть.
- Труба «сплющена» или разной толщины? Забыл(а) `Ctrl + A → Scale`.

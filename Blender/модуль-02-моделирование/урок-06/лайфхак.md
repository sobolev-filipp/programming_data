# Лайфхак урока 6 — Много труб из одной кривой (и как их соединить)

> Рисовать каждую трубу заново — долго. Покажу, как из одной настроенной кривой быстро получить целую оснастку: пучки кабелей, трубопровод, ветви.

---

## Приём 1 — Дублируем готовую кривую

Самый быстрый способ «размножить» трубу с уже настроенной толщиной:

1. Сделай одну кривую-трубу (с Depth, материалом)
2. В Object Mode: `Shift + D` → сдвинь рядом → готова вторая труба с теми же настройками
3. Чуть измени форму ручками в Edit Mode, чтобы трубы не были одинаковыми

> 💡 Дублируешь `Alt + D` (связанная копия)? Тогда **толщина у всех труб меняется разом** — удобно подбирать диаметр для всего пучка сразу.

---

## Приём 2 — Несколько труб в ОДНОЙ кривой

Один объект-кривая может содержать **несколько отдельных линий** — это удобно: один материал, одна толщина, один объект в Outliner.

1. Кривая в Edit Mode
2. `A` → выделить всё → `Alt + A` снять
3. Поставь курсор где нужно → `Shift + правый клик` ставит 3D-курсор... или проще:
4. Выдели существующую точку → `E` тянем новую ветку
5. Чтобы начать **отдельную** линию: `Shift + A` (в Edit Mode кривой добавляет новый отрезок) или продублируй точки `Shift+D` и отсоедини

> 💡 **Фишка:** все линии внутри одной кривой получают **одинаковый Depth** (толщину). Идеально для пучка одинаковых кабелей.

---

## Приём 3 — Соединить две трубы в одну линию

Есть две кривые, хочешь соединить их концы в единую трубу:

1. Выдели обе кривые в Object Mode → `Ctrl + J` (Join) — стали одним объектом
2. `Tab` → Edit Mode
3. Выдели **две концевые точки** (по одной от каждой кривой): `ЛКМ`, затем `Shift + ЛКМ`
4. `F` — соединить! Теперь это одна непрерывная труба

> 💡 **Фишка:** `F` (как и в меше) соединяет выделенные концы кривых. Так из коротких кусков собирают длинный трубопровод.

---

## Приём 4 — Труба точно по поверхности (Shrinkwrap)

Нужно, чтобы кабель «лёг» по корпусу корабля? После конвертации в меш добавь модификатор **Shrinkwrap** с целью = корпус — труба прилипнет к поверхности.

---

## Шпаргалка

| Хочу | Делаю |
|------|-------|
| Копия трубы с теми же настройками | `Shift + D` (или `Alt + D` — связанная) |
| Пучок одинаковых кабелей | несколько линий в одной кривой |
| Соединить концы труб | `Ctrl + J`, выделить концы, `F` |
| Положить кабель на поверхность | Convert to Mesh → Shrinkwrap |

# Повторение урока 8 — «Сделай сам» + опрос 🌀

> ⏱ 5–7 минут. Формат: быстрое задание + вопросы по телам вращения.

---

## Разминка руками: «Ваза за минуту» ⚡

Каждый по памяти:
1. Добавь Plane → Edit Mode → оставь линию-профиль сбоку от центра
2. Повесь модификатор **Screw**
3. Получи вазу/сопло

---

## Вопросы

1. Что такое **тело вращения**? Из чего оно строится?
2. Чем отличается инструмент **Spin** от модификатора **Screw**?
3. Почему профиль нужно рисовать **сбоку** от оси?
4. Какой параметр Screw превращает кольцо в **пружину**?
5. Чем сделать **толстые стенки** у вазы/сопла?
6. Как из полудуги получить идеальную сферу?

---

## Ответы (для учителя)

1. Объект, симметричный вокруг оси; строится из профиля (силуэта), вращаемого вокруг оси
2. Spin — разовый инструмент в Edit Mode; Screw — живой модификатор, умеет спирали
3. Иначе тело схлопнется в точку на оси
4. Screw value (+ Iterations для числа витков)
5. Модификатор Solidify
6. Полудуга → Screw 360°

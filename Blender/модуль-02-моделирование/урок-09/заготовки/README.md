# Заготовки урока 9 — «сломанные» меши для тренировки

> Готовые файлы с **намеренными ошибками топологии**. Импортируй в Blender (`File → Import → Wavefront (.obj)`) и почини — тренировка к Части 4.6 «Чиним топологию по ситуациям».

| Файл | Что сломано | Чем чинить |
|------|-------------|-----------|
| `01-двойные-вершины.obj` | плоскость разъехалась на две половины — **видимая щель** по центру (задвоенные вершины на стыке) | `A` → `M → By Distance` (**Merge Distance ≈ 0.3**) или **Weld** |
| `02-вывернутые-нормали.obj` | **UV-сфера**, одно полушарие вывернуто (в solid выглядит целой; `Face Orientation` — половина **красная**, после `Shade Smooth` — **тёмная**) | `A` → `Shift + N` (Recalculate Outside). Проверка: `Overlays → Face Orientation` |
| `03-кривая-дырка.obj` | **большая рваная дыра** с кривым, ломаным ободком | режим рёбер (`2`) → `Alt+ЛКМ` по ободку → `LoopTools → Circle` |
| `04-треугольники.obj` | сетка раскромсана на **треугольники** в разные стороны | `A` → `Alt + J` (Tris to Quads) |

> 💡 Порядок общей уборки: `M By Distance` → `Shift + N` → `Alt + J` → кривые отверстия `LoopTools → Circle`.

> ⚙️ Как сгенерированы: скриптом (чистые геометрические примитивы, без копирайта). Можно пересоздать/дополнить.

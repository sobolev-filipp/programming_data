# Самостоятельная работа — Урок 9: Свой робот-персонаж 🤖

> 🧑‍🎓 Делаешь сам(а), применяя Bridge, Knife и Loop Tools. Учитель помогает, если застрял.

## Задание

На уроке мы собрали голову ретро-робота. Теперь — **твой собственный персонаж-техника**: робот, дрон, шлем космонавта или игровой геймпад. Главное — пустить в дело все четыре приёма урока.

> 💡 Выбери, что ближе: **робот-помощник**, **летающий дрон**, **шлем**, **геймпад** или **техно-кружка**. Приёмы везде одни и те же.

![Референс: роботы, дроны, шлемы и их детали](изображения/практика-робот-референс.png)

*Сверху — готовые модели. Обрати внимание: панельные швы (расшивка), идеально круглые глаза/линзы/вентиляции, трубки и «уши»-переходы, россыпь болтов. Всё это ты уже умеешь.*

**Что собрать (на выбор):**
- 🤖 **Робот** — голова/корпус с глазами-линзами, антенной, болтами
- 🛸 **Дрон** — корпус + круглые отверстия под винты + камера-линза
- 🪖 **Шлем** — забрало, вентиляции, дыхательная трубка
- 🎮 **Геймпад** — расшивка корпуса, круглые кнопки, провод-трубка

## Миссии (выполни минимум 3 приёма)

- [ ] 🌉 **Bridge Edge Loops** — сделай переход/трубку: ухо-наушник, антенна, провод или ручка
- [ ] 🔪 **Knife** — нарежь панельные швы (расшивку); зажимай `C` для ровных линий
- [ ] ⭕ **Loop Tools → Circle** — выровняй хотя бы одно круглое отверстие (глаз/линза/вентиляция)
- [ ] 🔩 **Greebles** — добавь мелкие детали (болты, заклёпки, панельки, решётку)
- [ ] 🧲 Одинаковые детали поставь **ровным рядом/по кругу** (Align Objects / радиальный Array), не на глаз
- [ ] ✨ Светящаяся деталь (глаз/линза/огонёк) через **Emission** (урок 4)
- [ ] 🧹 Чистая топология (квады), без артефактов: `M → By Distance` + `Shift + N`
- [ ] 🎨 Материалы + рендер (`F12`)

## Как выделять петли правильно (это ускоряет всё)

Главный навык урока — **не кликать рёбра по одному**:

1. `Alt + ЛКМ` по ребру → выделится вся **петля** (loop).
2. `Ctrl + Alt + ЛКМ` по ребру → выделится **кольцо** (ring).
3. Добавить ещё петлю к выделению — тот же клик с `Shift`.

> ✅ **Проверка перед Bridge:** выделено ровно **два замкнутых кольца краёв** (у двух дырок). Если Bridge ругается — почти всегда выделены грани или рёбра посреди поверхности, а не края.

---

## 🩹 Если не получается — быстрая проверка

Самые частые затыки и как их мигом починить (подробнее — в теории, Часть 4.5):

| Что вижу | Почему | Что нажать |
|----------|--------|-----------|
| **Bridge** ничего не сделал / ошибка | выделено не два кольца краёв | `Alt+ЛКМ` по каждому краю (второй с `Shift`) |
| Bridge скрутил «восьмёркой» | кольца сдвинуты по фазе | в `F9` поставь **Twist = 1** |
| **Нож** режет криво | не зажат `C` | зажми `C` — линии по углам/осям |
| Нож прорезал только перёд | не нажал `Z` | во время реза нажми `Z` (насквозь) |
| **Circle** раскидал вершины | выделена не петля | выдели именно петлю края (`Alt+ЛКМ`) |
| Край отверстия — кривой эллипс | так бывает после Boolean | петля → `LoopTools → Circle` |
| Тёмные/чёрные грани | нормали внутрь | `A` → `Shift + N` |
| Щель/шов, двойные точки | не слиты вершины | `A` → `M → By Distance` |
| **Loop Tools** нет в меню | аддон выключен | `Preferences → Add-ons → Loop Tools` ✅ |

> ✅ **Правило «чисто с первого раза»:** стремись к квадам → выделяй петли `Alt+ЛКМ` → после Boolean край чини `Circle` → в конце `M By Distance` + `Shift + N`.

## Подсказки

- Ухо/антенна/провод: два кольца (`Alt+ЛКМ`, второе с `Shift`) → `Edge → Bridge Edge Loops`.
- Симметричные детали (два уха, два глаза) — делай одно и вешай **Mirror** (урок 3), не лепи дважды.
- Кривой край после Boolean → петля → **Loop Tools → Circle**.
- Болты рядами — **Align Objects** (урок 2); по кругу — **радиальный Array** через Empty (урок 3).
- Стенки «бумажные»? **Solidify** (урок 4).
- Светящиеся глаза/огоньки — **Emission** + `Bloom` в настройках EEVEE (урок 4).

## 🎯 А попробуй (по желанию)

- 🧵 **Расшей корпус целиком** — нарежь ножом панели по всей модели и чуть вдави швы: техника станет «настоящей».
- 🔗 **Соедини две части Bridge'ем** — например, голову с шеей-кольцом: получится гибкий переход.
- 🌀 **GStretch** — нарисуй карандашом линию, и вершины петли лягут точно по ней (`LoopTools → GStretch`).
- 💡 **Семейка роботов** — скопируй своего робота 2–3 раза, поменяй цвет/детали. Выстрой их в ряд через Align Objects.

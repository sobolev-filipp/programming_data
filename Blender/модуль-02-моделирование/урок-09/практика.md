# Самостоятельная работа — Урок 9: Детализация и чистая топология

> 🧑‍🎓 Делаешь сам(а), применяя Bridge, Knife, Loop Tools. Учитель помогает, если застрял.

## Задание

Доведи **корпус своего корабля** до «технологичного» вида: панельные швы, аккуратные отверстия, переходы, greebles.

---

## Требования

- [ ] Нарезаны **панельные швы** (Knife или Loop Cut)
- [ ] Использован **Bridge Edge Loops** хотя бы раз (туннель/переход)
- [ ] Применён **Loop Tools → Circle** (выровнять отверстие в круг)
- [ ] Применён **Loop Tools → Space** ИЛИ **Relax** (выровнять петлю)
- [ ] Добавлены **greebles** (минимум 5 мелких деталей)
- [ ] Выделение петель через `Alt+ЛКМ` (а не по одному ребру)
- [ ] Рендер (`F12`)

---

## Подсказки

- Кривое отверстие после Boolean → выдели край → Circle
- Швы: `K`, зажми `C` для ровных линий
- Туннель: два отверстия → выдели оба края → Bridge
- Greebles раскидывай неравномерно — так «живее»
- Стремись к квадам; `Alt+ЛКМ` для петель экономит время

---

## Что сдать

`.blend` + рендер.

# Самостоятельная работа — Урок 9: Кружка с ручкой ☕

> 🧑‍🎓 Делаешь сам(а), применяя Bridge, Knife, Loop Tools. Учитель помогает, если застрял.

## Задание

На уроке мы детализировали корпус корабля. Теперь — другой объект, где те же приёмы работают идеально: сделай **кружку с ручкой** (или термос / чайник / игровой геймпад).

> 💡 Главный вызов — **ручка через Bridge Edge Loops**: то, ради чего этот приём и существует.

**Кружка:**
- Тело — цилиндр, выдолбленный внутри (Inset + Extrude вниз)
- **Ручка** — два отверстия на боку (Boolean или удалить грани) → выдели оба края → **Bridge Edge Loops** → дуга-ручка
- Аккуратные круглые края — **Loop Tools → Circle**
- Декор — поясок (Knife/Loop Cut) + заклёпки/узор (greebles)

---

## Требования

- [ ] Использован **Bridge Edge Loops** (ручка кружки)
- [ ] Применён **Loop Tools → Circle** (ровный край)
- [ ] Нарезан декоративный поясок **Knife** или Loop Cut
- [ ] Выделение петель через `Alt+ЛКМ` (а не по ребру)
- [ ] Добавлены мелкие детали (узор/заклёпки/надпись)
- [ ] Чистая топология (квады), без артефактов
- [ ] Материалы + рендер (`F12`)

---

## Подсказки

- Ручка: сделай два круглых отверстия на боку → выдели оба кольца краёв (`Alt+ЛКМ`, второе с Shift) → Bridge
- Кривой край после выдалбливания → выдели петлю → Loop Tools → Circle
- Толщина стенок: Solidify или ручной Inset+Extrude
- Геймпад как альтернатива: кнопки = greebles, швы = Knife, круглые кнопки = Circle

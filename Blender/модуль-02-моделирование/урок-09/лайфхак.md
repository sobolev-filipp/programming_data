# Лайфхак урока 9 — Loop Tools: Circle и Space (спасатели топологии)

> После Boolean или ручного моделирования вершины часто «кривые». Loop Tools приводит их в порядок за секунду.

---

## Включить Loop Tools

`Edit → Preferences → Add-ons` → **Loop Tools** → ✅
Вызов в Edit Mode: `ПКМ → LoopTools`.

---

## Circle — идеальный круг из кривого отверстия ⭐

После Boolean край иллюминатора может быть неровным эллипсом. Чиним:

1. Edit Mode → выдели **петлю** края отверстия (`Alt + ЛКМ`)
2. `ПКМ → LoopTools → Circle`
3. Вершины мгновенно встают по **идеальному кругу**!

> 💡 В настройках Circle (панель F9) можно задать **Flatten** (выровнять в плоскость) и радиус. Так кривое отверстие становится аккуратным за один клик.

**Где нужно:** круглые иллюминаторы, отверстия под трубы, колёса, циферблаты, любые «должно быть круглым».

---

## Space — ровное распределение ⭐

Петля рёбер получилась с неравными промежутками (после Loop Cut, Knife)? Выровняем:

1. Выдели петлю вершин
2. `ПКМ → LoopTools → Space`
3. Вершины встают на **равном расстоянии** друг от друга

**Где нужно:** равномерные сегменты, аккуратные швы, сетка под текстуру.

---

## Relax — сгладить неровную петлю

Петля «гуляет» волной? `LoopTools → Relax` сглаживает её, сохраняя форму. Можно применить несколько раз.

**Где нужно:** разгладить топологию после скульпта/Boolean.

---

## Flatten — выровнять в плоскость

Вершины должны лежать в одной плоскости (например, грань стыковки)? `LoopTools → Flatten` прижимает их к плоскости.

---

## Bridge — мост между петлями

То же, что Bridge Edge Loops, но из Loop Tools — соединяет два выделенных кольца переходом.

---

## Шпаргалка

| Проблема | Решение |
|----------|---------|
| Отверстие — кривой эллипс | LoopTools → **Circle** |
| Неравные промежутки | LoopTools → **Space** |
| Петля «волной» | LoopTools → **Relax** |
| Вершины не в плоскости | LoopTools → **Flatten** |
| Соединить два кольца | LoopTools → **Bridge** |

> 💡 **Главный совет:** запомни хотя бы **Circle** и **Space** — это 90% случаев, когда топология «поехала».

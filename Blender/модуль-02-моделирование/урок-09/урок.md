## Часть 1 — Теория: топология (10 минут)

**Топология** — это то, как устроена сетка модели: из каких полигонов и как они расположены.

| Полигон | Углов | Оценка |
|---------|-------|--------|
| **Квад** (Quad) | 4 | 👍 лучший — ровно делится, гнётся, дружит с SubSurf |
| **Тригон** (Tri) | 3 | 🟡 ок для жёстких деталей и игр |
| **N-gon** | 5+ | 👎 капризный — кривится при сглаживании |

**Edge Loop** (петля рёбер) — непрерывная цепочка рёбер по поверхности. **Edge Ring** — кольцо параллельных рёбер.

> 💡 **Фишка — выделение петель:**
> - `Alt + ЛКМ` на ребре → выделить **петлю** (Loop)
> - `Ctrl + Alt + ЛКМ` на ребре → выделить **кольцо** (Ring)
> Это ускоряет работу в разы — не выделяй рёбра по одному!

> 💡 **Фишка — зачем чистая сетка:** ровные квады легко резать петлями, сглаживать SubSurf и анимировать. Грязная сетка (n-gons, треугольники где попало) ломается при сглаживании. Стремись к квадам.

## Часть 2 — Bridge Edge Loops (15 минут)

**Bridge** соединяет два кольца рёбер «мостом» — создаёт переход, туннель, ручку.

### Пример: туннель между двумя отверстиями

1. Куб → Edit Mode → вырежи два отверстия на противоположных гранях (Inset + удалить грань, или Loop Cut)
2. Выдели **оба** кольца краёв отверстий (`Alt + ЛКМ` по каждому, второе с `Shift`)
3. `Edge → Bridge Edge Loops`
4. Между отверстиями появился туннель!

> 💡 **Фишка:** Bridge нужен для ручек кружки, выхлопных каналов, переходов между секциями корабля, дверных проёмов с глубиной.

## Часть 3 — Knife (нож) (15 минут)

**Knife** (`K`) режет произвольные линии прямо по поверхности — для панельных швов и нестандартных форм.

### Как резать

1. `K` — активируй нож
2. Кликай `ЛКМ` — ставь точки разреза
3. `Enter` — подтвердить, `Esc` — отменить
4. Зажми `C` во время реза — привязка к углам (ровные горизонтали/вертикали)
5. `Z` во время реза — резать насквозь (сквозь невидимые грани)

> 💡 **Фишка — панельные швы:** ножом нарезают «расшивку» корпуса — линии, делящие гладкую поверхность на панели. Потом эти рёбра можно слегка вдавить или скосить Bevel — корабль выглядит технологичным.

## Часть 4 — Аддон Loop Tools (20 минут)

**Loop Tools** — набор инструментов для аккуратной работы с петлями.

### Включить

`Edit → Preferences → Add-ons` → **Loop Tools** → ✅

Вызов: в Edit Mode `ПКМ → LoopTools` (или из меню).

| Инструмент | Что делает |
|------------|-----------|
| **Circle** | расставляет выделенные вершины по идеальному кругу |
| **Space** | равномерно распределяет вершины вдоль петли |
| **Relax** | сглаживает неровную петлю |
| **Flatten** | выравнивает вершины в плоскость |
| **Bridge** | мост между петлями (как Bridge Edge Loops) |
| **GStretch** | выравнивает вершины по нарисованной линии |

> 🎯 **ЛАЙФХАК — показать здесь!** Разбери Loop Tools → **Circle** и **Space**: как кривое отверстие превратить в идеальный круг и как ровно распределить вершины. Это спасает топологию после Boolean и кривого моделирования. Полный разбор — [лайфхак.md](лайфхак.md).

## Часть 5 — Детализируем корпус (20 минут)

Собираем приёмы вместе на корпусе корабля:

1. **Панельные швы** — Knife или Loop Cut расчерчивают корпус на секции
2. **Аккуратное отверстие** — после Boolean (урок 7) выдели край отверстия → Loop Tools → **Circle** (стало идеально круглым)
3. **Переход секций** — Bridge Edge Loops между двумя частями
4. **Утопленные панели** — выдели грань-секцию → Inset → Extrude вглубь чуть-чуть
5. **Greebles** (мелкие детали) — раскидай мелкие кубики/цилиндры по корпусу для «технологичности»

> 💡 **Фишка — greebles:** мелкие нефункциональные детали (коробочки, трубки, болты) делают технику «живой» и сложной на вид. В кино так детализируют звездолёты. Не жалей мелочи!

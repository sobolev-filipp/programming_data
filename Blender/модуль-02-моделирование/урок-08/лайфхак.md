# Лайфхак урока 8 — Сфера из дуги и пружина через Screw

> Screw умеет больше, чем вазы. Два приёма, которые удивляют: идеальная сфера из одной дуги и настоящая пружина.

---

## Приём 1 — Идеальная сфера из полудуги

UV Sphere иногда не нужна — а ровную сферу хочется. Screw делает её из **полуокружности**.

1. `Shift + A → Mesh → Circle` → `F9`: Vertices ~16, **Fill: Nothing**
2. `Tab` → Edit Mode → удали **половину** вершин (оставь полукруг-дугу)
3. Дуга должна примыкать концами к оси Z (центру)
4. `Tab` → Object Mode → модификатор **Screw**, Angle 360
5. Полудуга обернулась в **идеальную сферу**!

> 💡 Меняешь число вершин дуги — меняется гладкость сферы. Низкое число = стильная low-poly сфера.

---

## Приём 2 — Пружина / спираль

Главный секрет — параметр **Screw** (смещение вдоль оси).

1. `Shift + A → Mesh → Circle` (это будет сечение пружины — «проволока»)
2. Поверни и отодвинь его **в сторону** от центра (радиус витка)
3. Модификатор **Screw**:
   - **Angle: 360**
   - **Screw: 0.5** ← вот оно! Виток поднимается вдоль оси
   - **Iterations: 5** ← пять витков
   - **Steps: 16** ← гладкость

Получилась пружина! 🌀

> 💡 **Фишка:** Screw value = насколько виток поднимается за оборот. Iterations = сколько витков. Вместе они задают «растянутость» пружины.

**Где пригодится:** пружины, винтовые лестницы, резьба болта, спиральные провода, ракушки, рога.

---

## Приём 3 — Неполное вращение (Angle < 360)

Поставь Angle, например, **270°** — получится незамкнутое тело: жёлоб, полутруба, лепесток, аркада.

---

## Шпаргалка

| Хочу | Делаю |
|------|-------|
| Идеальная сфера | полудуга → Screw 360° |
| Ваза/сопло/бутылка | силуэт-профиль → Screw 360° |
| Пружина/спираль | сечение сбоку → Screw value + Iterations |
| Жёлоб/полутруба | Screw с Angle < 360 |
| Толстые стенки | после Screw → Solidify |

# Лайфхак урока 12 — больше домов, та же ширина улиц

> Если увеличить Vertices у Grid и оставить Size прежним, дома сблизятся. Вычислим размер сетки из числа домов и шага.

## Правило

**Size = (Vertices − 1) × шаг.** Пять домов — четыре промежутка. При шаге 3 размер сетки равен 12.

## Сделай по шагам

1. Открой City_Grid. Выведи Vertices X во вход группы Integer «Дома X», минимум 2.
2. Добавь Math Subtract. Подай «Дома X» в верхний Value, во втором задай 1.
3. Добавь Math Multiply: верхний Value от Subtract, второй = 3.
4. Соедини Multiply Value → Grid Size X. Провод «Дома X» → Vertices X тоже должен остаться.
5. В модификаторе поменяй «Дома X» с 5 на 7.

✅ Размер по X вырос с 12 до 18, а расстояние между центрами домов осталось 3.

| Откуда: выход | Куда: вход |
|---|---|
| Group Input — Дома X | Grid — Vertices X |
| Group Input — Дома X | Math Subtract — первый Value |
| Math Subtract — Value | Math Multiply — первый Value |
| Math Multiply — Value | Grid — Size X |

## Почему вычитаем единицу

Между двумя домами один промежуток. Между тремя — два. Здесь считаем расстояние между центрами крайних домов, а не общую ширину всех зданий.

## Шпаргалка

| Задача | Формула |
|---|---|
| Размер сетки по X | (Vertices X − 1) × шаг X |
| Размер сетки по Y | (Vertices Y − 1) × шаг Y |
| Длина настила из модулей | Count × длина модуля |
| Центрированный мост с Origin в начале модуля | Start X = −Count × шаг / 2 |

💡 Шаг — расстояние между центрами, а не ширина улицы. Если дом шириной 2, при шаге 3 между домами остаётся 1.

## А попробуй

Повтори вычисление для Y. Затем выведи шаг в отдельный Float-вход группы. Не уменьшай его ниже ширины дома.

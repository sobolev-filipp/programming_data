# Повторение урока 11 — найди ошибку в ряду кубов

> 5–7 минут. Сначала объясни словами, затем проверь в Blender.

## Разминка руками

Открой учебный ряд кубов из теории урока 11. Установи Count = 5 и шаг X = 2. Убедись, что пять кубов стоят в ряд. Сохрани исходную работу отдельно.

## Найди ошибку

1. Кубы стоят друг на друге. В Mesh Line Offset = (0, 0, 0). Что изменить?
2. Точки есть, кубов нет. К Instance у Instance on Points ничего не подключено. Какой провод нужен?
3. На площадке видны камни, но пропала земля. Что объединить перед Output?
4. Duplicate Elements создал пять экземпляров, но виден один куб. Это обязательно ошибка?
5. Чем отличается шаблон от точки размещения?

## Проверь себя действием

Измени только модель в Object Info. Изменились ли места экземпляров? Объясни, какая ветка отвечает за расположение.

## Ответы (для учителя)

1. Offset X = 2, Y = Z = 0.
2. Cube Mesh → Instance on Points Instance.
3. Землю и Instances через Join Geometry.
4. Нет: копии могут совпадать. Проверить число экземпляров в Spreadsheet и разнести их через Duplicate Index и Translate Instances.
5. Шаблон задаёт форму, точка — место. При смене шаблона точки сохраняются, если их ветка не менялась.

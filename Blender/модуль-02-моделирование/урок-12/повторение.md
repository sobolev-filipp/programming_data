# Повторение урока 11 — Geometry Nodes

## Разминка (7 минут)

Открой поезд. Установи 5, 10 и 50 вагонов, затем верни 5. Покажи провода Mesh Line → Points и Object Info → Instance. Уменьши Offset X до 2: предскажи результат. Верни 3.4. Объясни, почему локомотив не должен повторяться. Если файла нет, создай ряд кубиков, как в части 5 урока 11.

## Вопросы

1. Что передаёт Group Input, а что Group Output?
2. Чем Mesh отличается от Instance?
3. Что делает Transform Geometry в одной из двух веток Join Geometry?
4. Какой вход Instance on Points отвечает за места, а какой за модель?
5. Почему после Duplicate Elements несколько кубов могут выглядеть одним? Как раздвинуть их?
6. При Count 10 сколько промежутков между центрами вагонов? Как изменится длина, если Count 20 при прежнем шаге?
7. Почему камни исчезают вместе с исходной землёй, если не подключить Join Geometry?

## Ответы для преподавателя

1. Входы группы и исходная геометрия; результат группы.
2. Сетка содержит вершины/рёбра/грани; экземпляр ссылается на форму и имеет свои трансформации.
3. Меняет только ветку, через которую проходит геометрия.
4. Points — места, Instance — форма.
5. Дубликаты совпадают в координатах; Translate Instances получает вектор смещения, вычисленный из Duplicate Index.
6. Девять; ряд удлинится на десять шагов.
7. Instance on Points выдаёт инстансы, а не исходный меш; Join Geometry возвращает землю отдельной веткой.

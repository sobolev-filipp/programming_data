## Часть 1 — Теория: от россыпи к порядку (10 минут)

На прошлом уроке мы рассеивали объекты **случайно** (Distribute Points). Сегодня расставим их **по порядку** — в ряд и в сетку. Это нужно для заборов, колонн, окон, городов, рельсов.

| Нод | Что делает |
|-----|-----------|
| **Mesh Line** | создаёт ряд точек на равном расстоянии (линия) |
| **Grid** | создаёт сетку точек (поле/город) |
| **Math** | считает: умножить, сложить (например, расстояние × количество) |
| **Combine XYZ** | собирает число в вектор (X, Y, Z) |
| **Set Position** | сдвигает точки/вершины (волны, рельеф, хаос) |

> 💡 **Фишка — два подхода к расстановке:** *случайно* (Distribute Points — трава, камни) и *по сетке* (Mesh Line / Grid — заборы, города). Выбирай по задаче.

## Часть 2 — Процедурный забор (25 минут)

### Шаг 1 — Столб-шаблон

Сделай одну секцию забора: столб (узкий куб) + 2-3 доски. Это «кирпичик».

### Шаг 2 — Ряд через Mesh Line

1. Новый объект (Plane/Empty mesh) → модификатор **Geometry Nodes → New**
2. `Shift + A → Mesh → Mesh Line`
3. **Count: 10**, **Offset: (1, 0, 0)** — 10 точек в ряд по X
4. `Shift + A → Instances → Instance on Points` → Object Info с секцией забора
5. Забор выстроился в ряд! 🎉

> 💡 **Фишка — Count и Offset:** Count = сколько секций, Offset = расстояние между ними. Меняешь Count — забор длиннее, и всё само. Это сила процедурности.

### Шаг 3 — Длина одним числом (Math)

Хочешь задавать **длину забора в метрах**, а не «на глаз»?
1. `Shift + A → Utilities → Math` (Divide): длина ÷ шаг = Count
2. Подключи результат к Count

> 💡 **Фишка:** Math-ноды превращают «магические числа» в понятные параметры. Делёж/умножение связывает длину, шаг и количество.

## Часть 3 — Сетка домиков: город (20 минут)

### Шаг 1 — Домик-шаблон

Простой low-poly дом: куб + крыша-призма. (Один — остальные размножит сетка.)

### Шаг 2 — Grid

1. Новый Geo Nodes сетап
2. `Shift + A → Mesh → Grid` → **Size X/Y**, **Vertices X/Y** (плотность квартала)
3. **Instance on Points** + Object Info с домиком
4. Появился ровный квартал домов!

### Шаг 3 — Оживляем город

- **Random Value → Scale (по Z)** — дома разной высоты (как настоящий город)
- **Random Value → Rotation (по Z, 0/90/180/270)** — дома повёрнуты по-разному
- Несколько типов домов из коллекции (Collection Info + Pick Instance — урок 11)

> 💡 **Фишка — города по сетке + случайная высота:** ровная сетка кварталов + случайная высота зданий = мгновенный мегаполис. Так делают фоны городов в играх и кино.

## Часть 4 — Set Position: рельеф и волны (15 минут)

**Set Position** сдвигает вершины/точки — добавляет рельеф земле или «дышащие» волны.

1. Возьми Grid (землю) → **Set Position**
2. В **Offset** подай высоту: `Noise Texture → Combine XYZ (в Z)` — земля стала холмистой!

> 💡 **Фишка — Noise в Z:** шум, поданный в высоту (Z), превращает плоскость в холмы/дюны/волны. Масштаб шума = размер холмов. Это процедурный рельеф без ручной лепки.

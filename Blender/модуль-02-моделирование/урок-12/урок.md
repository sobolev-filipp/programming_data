## Часть 1 — Теория: от россыпи к порядку (10 минут)

На прошлом уроке мы рассеивали объекты **случайно** (Distribute Points). Сегодня расставим их **по порядку** — в ряд и в сетку. Это нужно для заборов, колонн, окон, городов, рельсов.

| Нод | Что делает (аналогия) | Главные сокеты/параметры |
|-----|------------------------|--------------------------|
| **Mesh Line** | «линейка с точками»: ставит точки в ряд на равном шаге | **Count** (сколько), **Offset** (шаг и направление), выход **Mesh** |
| **Grid** | «тетрадь в клетку»: точки сеткой по полю | **Size X/Y** (размер), **Vertices X/Y** (сколько точек), выход **Mesh** |
| **Math** | «калькулятор»: складывает, умножает, делит числа | режим (Add/Multiply/Divide…), два входа-числа, выход **Value** |
| **Combine XYZ** | «сборщик»: из трёх отдельных чисел собирает стрелку-вектор (X, Y, Z) | входы **X/Y/Z**, выход **Vector** |
| **Set Position** | «толкатель»: сдвигает каждую точку/вершину | вход **Geometry**, вход **Offset** (на сколько и куда сдвинуть) |
| **Noise Texture** | «генератор пятен»: в каждой точке выдаёт плавно меняющееся число 0…1 | **Scale** (размер пятен), выход **Fac** (число) |

> 💡 **Главная мысль:** точки можно ставить **случайно** (Distribute, урок 11) или **по порядку** (Mesh Line — ряд, Grid — сетка). А Math и Combine XYZ — это «математика» для управления числами (сколько, как далеко, как высоко).

> 💡 **Фишка — два подхода к расстановке:** *случайно* (Distribute Points — трава, камни) и *по сетке* (Mesh Line / Grid — заборы, города). Выбирай по задаче.

## Часть 2 — Процедурный забор (25 минут)

### Шаг 1 — Столб-шаблон

Сделай одну секцию забора: столб (узкий куб) + 2-3 доски. Это «кирпичик».

### Шаг 2 — Ряд через Mesh Line

**Схема:**
```
Mesh Line ──[Mesh]──► Instance on Points ──[Instances]──► Group Output
                           ▲
   Object Info (секция) ──[Geometry]──┘  (вход "Instance")
```

1. Новый объект → модификатор **Geometry Nodes → New**
2. `Shift + A → Mesh → Mesh Line` — нод. Задай **Count: 10**, **Offset: (1, 0, 0)** (10 точек в ряд по X)
3. `Shift + A → Instances → Instance on Points`. Соедини:
   - **Mesh Line [Mesh]** → **Instance on Points [Points]**
   - **Instance on Points [Instances]** → **Group Output [Geometry]**
4. `Shift + A → Input → Object Info`, выбери секцию забора. Соедини:
   - **Object Info [Geometry]** → **Instance on Points [Instance]**
5. Забор выстроился в ряд! 🎉

> ⚠️ Mesh Line даёт точки → они идут во вход **Points**. Сам забор (Object Info) → во вход **Instance**.

> 💡 **Фишка — Count и Offset:** Count = сколько секций, Offset = расстояние между ними. Меняешь Count — забор длиннее, и всё само. Это сила процедурности.

### Шаг 3 — Длина одним числом (Math)

Хочешь задавать **длину забора в метрах**, а не «на глаз»?
1. `Shift + A → Utilities → Math`, в ноде выбери режим **Divide** (деление)
2. Впиши в первое поле длину (например 20), во второе — шаг (1)
3. Соедини: **Math [Value]** → **Mesh Line [Count]**
4. Теперь меняешь длину в Math — забор сам пересчитывает число секций

> 💡 **Фишка:** Math-ноды превращают «магические числа» в понятные параметры. Делёж/умножение связывает длину, шаг и количество.

## Часть 3 — Сетка домиков: город (20 минут)

### Шаг 1 — Домик-шаблон

Простой low-poly дом: куб + крыша-призма. (Один — остальные размножит сетка.)

### Шаг 2 — Grid

**Схема:**
```
Grid ──[Mesh]──► Instance on Points ──[Instances]──► Group Output
                      ▲                      ▲
 Object Info (дом) ──[Geometry]──┘          │ (вход "Instance")
 Random Value (Vector) ──[Value]────────────┘ (вход "Scale")
```

1. Новый Geo Nodes сетап
2. `Shift + A → Mesh → Grid`. Задай **Size X / Size Y** (размер квартала) и **Vertices X / Vertices Y** (сколько домов в ряд)
3. `Shift + A → Instances → Instance on Points`. Соедини:
   - **Grid [Mesh]** → **Instance on Points [Points]**
   - **Instance on Points [Instances]** → **Group Output [Geometry]**
4. `Shift + A → Input → Object Info`, выбери домик. Соедини:
   - **Object Info [Geometry]** → **Instance on Points [Instance]**
5. Появился ровный квартал домов!

### Шаг 3 — Оживляем город (случайная высота)

1. `Shift + A → Utilities → Random Value`, тип **Vector**
2. Задай Min `(1, 1, 1)`, Max `(1, 1, 3)` — разброс **только по Z** (высота)
3. Соедини: **Random Value [Value]** → **Instance on Points [Scale]**
4. Дома стали разной высоты — как настоящий город!

> Для разных типов домов: собери дома в коллекцию → `Input → Collection Info` → **Instance on Points [Instance]**, включи **Pick Instance**, а индекс задай ещё одним Random Value (тип Integer). См. урок 11, лайфхак.

> 💡 **Фишка — города по сетке + случайная высота:** ровная сетка кварталов + случайная высота зданий = мгновенный мегаполис. Так делают фоны городов в играх и кино.

## Часть 4 — Set Position: рельеф и волны (15 минут)

**Set Position** сдвигает вершины/точки — добавляет рельеф земле или «дышащие» волны.

**Схема:**
```
Grid ─[Mesh]─► Set Position ─[Geometry]─► Group Output
                   ▲ (вход "Offset")
   Noise Texture ─[Fac]─► Combine XYZ ─[Vector]─┘
                            (Fac подаём в канал Z)
```

1. Возьми Grid (землю) → `Shift + A → Geometry → Set Position`, встрой между Grid и Output:
   - **Grid [Mesh]** → **Set Position [Geometry]**
   - **Set Position [Geometry]** → **Group Output [Geometry]**
2. `Shift + A → Texture → Noise Texture` и `Shift + A → Vector → Combine XYZ`
3. Соедини высоту в канал Z:
   - **Noise Texture [Fac]** → **Combine XYZ [Z]**
   - **Combine XYZ [Vector]** → **Set Position [Offset]**
4. Земля стала холмистой! Меняй **Scale** у Noise — крупнее/мельче холмы.

> 💡 **Фишка — Noise в Z:** шум, поданный в высоту (Z), превращает плоскость в холмы/дюны/волны. Масштаб шума = размер холмов. Это процедурный рельеф без ручной лепки.

# Заготовки урока 10 — меши для оптимизации и починки

> Готовые файлы для тренировки **оптимизации** (Decimate/Weld/Remesh). Импортируй в Blender (`File → Import → Wavefront (.obj)`), включи `Overlays → Statistics` и почини/облегчи.

| Файл | Что это | Чем чинить / оптимизировать |
|------|---------|------------------------------|
| `01-тяжёлая-сфера.obj` | «тяжёлая» UV-сфера (~2000 граней) | модификатор **Decimate** (Ratio вниз), следи за Statistics |
| `02-грязная-дубли-дыра.obj` | коробка разъехалась — **видимая щель** на стыке (дубли) + **две дыры** сверху | **Weld** / `M → By Distance` (**Distance ≈ 0.3**); дыры закрыть — выдели ободок → `F` |
| `03-рваная-для-remesh.obj` | **комок из 6 повёрнутых пересекающихся** кубов (внутренние грани, non-manifold) | **Remesh** (Voxel) → чистая оболочка; потом **Decimate** |
| `04-вывернутые-нормали.obj` | **UV-сфера**, одно полушарие вывернуто (в solid выглядит целой; `Face Orientation` — половина красная) | `A` → `Shift + N` (Recalculate Outside) |

> 💡 Рабочий порядок: сначала **почини** (Weld/Remesh/Shift+N) → потом **облегчи** (Decimate) → сравни вес «было/стало».

## Космический фон (HDRI)

| Файл | Что это | Как применить |
|------|---------|----------------|
| `космос-фон-hdri.png` | equirectangular (360°, 2:1) панорама космоса для фона сцены | **World** → `Color` → `Environment Texture` → **Open** → выбери этот файл. Сразу и фон, и мягкий свет. |

> ⚙️ Меши сгенерированы скриптом (чистые примитивы, без копирайта). HDRI — сгенерирован по промпту. Можно пересоздать/дополнить.

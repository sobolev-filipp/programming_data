# Самостоятельная работа — Урок 7: Детализация корпуса

> 🧑‍🎓 Делаешь сам(а), применяя Boolean. Учитель помогает, если застрял.

## Задание

Возьми свой **космический корабль** (или станцию) и детализируй корпус **отверстиями и врезками** через Boolean.

**Что можно вырезать/добавить:**
- Иллюминаторы (круглые окна)
- Люки и двери (прямоугольные с фаской)
- Вентиляционные щели (ряд через Array + Boolean)
- Углубления под панели
- Стыковочный шлюз (большое круглое отверстие)

---

## Требования

- [ ] Минимум **3 разных отверстия** через Boolean Difference
- [ ] Хотя бы раз использован **Bool Tool** (горячие клавиши)
- [ ] Применено комбо **Array + Boolean** (ряд одинаковых отверстий)
- [ ] Использован хотя бы один раз **Union** (приварить деталь)
- [ ] Результат **без артефактов** (применены правила из лайфхака)
- [ ] Boolean применён (Apply), сцена чистая
- [ ] Рендер (`F12`)

---

## Подсказки

- **Всегда** `Ctrl+A → Scale` перед Boolean
- Резак протыкает деталь **насквозь**
- Чёрные грани? → `Shift+N`
- Ряд окон: резак → Array → Apply → Boolean
- Скошенный край иллюминатора: Bevel резаку до Boolean

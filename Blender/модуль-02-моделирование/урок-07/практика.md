# Самостоятельная работа — Урок 7: Тыква-фонарь 🎃

> 🧑‍🎓 Делаешь сам(а), применяя Boolean. Учитель помогает, если застрял.

## Задание

На уроке мы вырезали иллюминаторы в корпусе. Теперь — весёлое применение Boolean: вырежи **тыкву-фонарь** (Jack-o'-lantern) со светящимся лицом. Или, если хочешь, **игральный кубик** (с выемками-точками) либо **сырный блок с дырками**.

> 💡 Тыква пригодится для сезонной сцены — её можно поставить рядом с другими предметами окружения.

**Тыква-фонарь:**
- Тело — сфера, сплюснутая (`S → Z`), с дольками (Loop Cut + сжать петли)
- Глаза, нос, рот — резаки-фигуры (треугольники, полумесяцы) → **Boolean Difference**
- Внутри — светящаяся сфера (Emission) → лицо светится через прорези
- Стебель — короткий цилиндр/конус сверху

---

## Требования

- [ ] Минимум **3 выреза** через **Boolean Difference** (глаза, нос, рот)
- [ ] Хотя бы раз использован **Bool Tool** (горячие клавиши)
- [ ] Соблюдено правило `Ctrl+A → Scale` **до** Boolean
- [ ] Результат **без артефактов** (правила из лайфхака)
- [ ] Внутри — **светящийся** элемент (Emission), лицо светится
- [ ] Рендер (`F12`)

---

## Подсказки

- Дольки тыквы: Loop Cut по вертикали + Proportional Editing или сжать петли внутрь
- Резаки-лицо: маленькие кубы/призмы, протолкни сквозь стенку тыквы
- Глаза-треугольники: куб → повернуть на 45°
- Чёрные грани после Boolean? → `Shift+N`
- Альтернатива: игральный кубик — 21 сферка-резак Boolean Difference

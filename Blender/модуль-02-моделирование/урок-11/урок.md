## Часть 1 — Теория: что такое Geometry Nodes (12 минут)

Раньше мы лепили руками. **Geometry Nodes** — это когда мы пишем «рецепт» из блоков (нодов), а Blender по нему **сам создаёт геометрию**. Поменял число в рецепте — всё пересчиталось.

> 🍰 **Аналогия:** обычное моделирование — лепишь пирог руками. Geometry Nodes — пишешь рецепт: «возьми плоскость → раскидай 500 точек → на каждую поставь травинку». Меняешь «500» на «5000» — поле гуще, и всё само.

**Чем отличается от других нодов:**
| Где | Что делают |
|-----|-----------|
| **Shader Editor** | как объект **выглядит** (цвет, блеск) — Модуль 3 |
| **Geometry Nodes** | какая у объекта **геометрия** (создаёт/меняет меш) |

**Главные плюсы:**
- **Процедурно** — поменял параметр, всё пересчиталось
- **Не разрушает** — исходный меш цел
- **Тысячи объектов** почти без ручной работы (трава, лес, камни, звёзды)

> 💡 **Фишка:** Geometry Nodes — это модификатор! Добавляется через 🔧, но открывается в отдельном редакторе **Geometry Nodes** (вкладка-раскладка сверху или смени тип окна).

## Часть 2 — Первый нод-сетап: рассеиваем камни (25 минут)

### Шаг 1 — Земля и заготовка камня

1. `Shift + A → Mesh → Plane`, `S → 5` (это «земля»)
2. Отдельно сделай маленький камень (Ico Sphere + Randomize с прошлого урока) — он будет «рассеиваться»
3. Спрячь камень в сторонку (он станет «шаблоном»)

### Шаг 2 — Добавить Geometry Nodes

1. Выдели **Plane** → 🔧 → **Add Modifier → Geometry Nodes**
2. Нажми **New** — создался пустой нод-сетап
3. Смени тип одного окна на **Geometry Node Editor** (или вкладка Geometry Nodes сверху)
4. Видишь два нода: **Group Input** → **Group Output** (вход и выход «рецепта»)

> 💡 **Фишка — поток слева направо:** геометрия «течёт» от Group Input к Group Output. Все ноды вставляем **между** ними. Связь тянем мышью **от кружка-выхода (справа на ноде) к кружку-входу (слева на ноде)**.

> 💡 **Как читать схему нодов в методичке:** запись `НодА [Выход] → НодБ [Вход]` означает: потяни связь от сокета «Выход» на ноде А к сокету «Вход» на ноде Б. У каждого нода входы — слева, выходы — справа. Сокеты подписаны (наведи мышь — увидишь имя).

### Наша схема целиком (к чему придём)

```
Group Input ──[Geometry]──► Distribute Points on Faces ──[Points]──► Instance on Points ──[Instances]──► Group Output
                                                                          ▲
                                              Object Info (камень) ──[Geometry]──┘  (вход "Instance")
                                                                          ▲
                                  Random Value (Vector) ──[Value]─────────┘  (вход "Rotation")
                                  Random Value (Float)  ──[Value]─────────┘  (вход "Scale")
```

Соберём её по шагам. Но сначала разберём, **что делает каждый нод** — иначе мы просто соединяем провода вслепую.

### 🧩 Что делает каждый нод (простыми словами)

| Нод | Что делает (аналогия) | Главные сокеты |
|-----|------------------------|----------------|
| **Group Input** | «вход рецепта» — отдаёт нашу исходную геометрию (плоскость) | выход **Geometry** = плоскость |
| **Distribute Points on Faces** | «сеятель»: рассыпает невидимые точки-семена по поверхности | вход **Mesh** (на чём сеять), выход **Points** (точки), параметр **Density** (густота) |
| **Instance on Points** | «штамп»: ставит копию объекта на каждую точку | вход **Points** (куда ставить), вход **Instance** (что ставить), выход **Instances** (готовая россыпь) |
| **Object Info** | «рука»: берёт другой объект из сцены и передаёт его форму в ноды | поле **Object** (какой объект), выход **Geometry** (его форма) |
| **Random Value** | «кубик»: бросает случайное число для каждой копии (чтоб не были одинаковыми) | **Min/Max** (границы), выход **Value** (число) |
| **Group Output** | «выход рецепта» — то, что в итоге увидим в сцене | вход **Geometry** = финал |

> 💡 **Главная мысль:** точки — это «невидимая разметка, где будут объекты». Сначала рассыпаем точки (Distribute), потом на каждую ставим объект (Instance). Точки сами по себе в рендере не видны.

### Шаг 3 — Рассеиваем точки (Distribute Points on Faces)

1. В нод-редакторе `Shift + A → Point → Distribute Points on Faces` — появился нод
2. Перетащи его мышкой **на линию** между Group Input и Group Output — он встроится сам. Должно получиться:
   - **Group Input [Geometry]** → **Distribute Points on Faces [Mesh]** (вход «Mesh» — самый верхний слева)
   - **Distribute Points on Faces [Points]** → **Group Output [Geometry]**
3. Покрути параметр **Density** — на плоскости появились точки! (пока только точки)

> ⚠️ Если точек нет — проверь, что линия идёт именно во вход **Mesh** ноды Distribute (а не мимо).

### Шаг 4 — Ставим камень на каждую точку (Instance on Points)

1. `Shift + A → Instances → Instance on Points` — новый нод
2. Поставь его **после** Distribute Points и соедини:
   - **Distribute Points on Faces [Points]** → **Instance on Points [Points]** (верхний вход)
   - **Instance on Points [Instances]** → **Group Output [Geometry]**
3. Теперь добавим, ЧТО ставить: `Shift + A → Input → Object Info`
   - В ноде Object Info выбери свой объект-**камень** (поле Object)
   - **Object Info [Geometry]** → **Instance on Points [Instance]** (второй вход, называется «Instance»)
4. На каждой точке появился камень! 🎉

> ⚠️ Не перепутай два входа Instance on Points: **Points** (куда ставить) и **Instance** (что ставить). Камень идёт во вход **Instance**.

> 💡 **Фишка — Instance ≠ копия:** инстансы «лёгкие» — Blender хранит один камень и показывает его много раз. Поэтому тысячи камней не вешают ПК.

## Часть 3 — Случайность: чтобы не были клонами (15 минут)

Сейчас все камни одинаковые и стоят ровно. Добавим хаос.

### Случайный поворот и размер

1. `Shift + A → Utilities → Random Value` — нод
2. Вверху ноды переключи тип на **Vector** (для поворота нужен вектор XYZ)
3. Соедини: **Random Value [Value]** → **Instance on Points [Rotation]** → камни повернулись по-разному
4. Добавь **второй** `Random Value`, тип оставь **Float** (одно число)
5. Соедини: **Random Value [Value]** → **Instance on Points [Scale]** → камни разного размера
6. Задай в Random Value границы: для Scale, например, Min `0.7`, Max `1.3`

> 🎯 **ЛАЙФХАК — показать здесь!** Random Value — главный секрет «живого» процедурного разброса. Полный разбор (поворот, масштаб, Seed, плотность по маске) — в [лайфхак.md](лайфхак.md).

> 💡 **Фишка — Seed:** параметр Seed у Distribute Points меняет рисунок разброса. Не нравится расстановка — крути Seed, пока не понравится.

> ⚠️ **Фишка для слабых ПК:** держи Density небольшой! Тысячи инстансов с высокой плотностью могут затормозить. Начни с малого, повышай постепенно.

## Часть 4 — Применяем: трава и звёзды (15 минут)

### Лужайка с травой

- Та же схема: Plane → Distribute → Instance травинки (узкий конус/плоскость)
- Random Value на поворот по Z (травинки смотрят в разные стороны)
- Добавь немного камней и цветов — разнообразие!

### Звёздное поле

- Возьми большую сферу (вывернутую) или плоскость-фон
- Distribute Points → Instance крошечной светящейся сферы (Emission)
- Random на размер → звёзды разной величины

> 💡 **Фишка — звёзды попроще:** для звёзд можно даже не ставить объекты, а оставить **точки** и включить им материал-эмиссию (Point Cloud). Но Instance маленьких сфер — нагляднее для детей.

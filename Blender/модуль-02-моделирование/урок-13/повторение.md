# Повторение уроков 11–12 — Викторина по Geometry Nodes 🎯

> ⏱ 5–7 минут. Формат: викторина по нодам (закрываем большой блок Geo Nodes перед low-poly).

---

## Вопросы

1. Чем **Geometry Nodes** отличаются от обычной лепки руками?
2. Что делает нод **Distribute Points on Faces**? А **Instance on Points**?
3. Чем вход **Points** отличается от входа **Instance** у Instance on Points?
4. Как поставить объекты **в ряд**? А **сеткой**?
5. Что делает **Random Value** и зачем он нужен?
6. Как вывести параметр (например, длину) на **ползунок** панели?

---

## Мини-задача (устно или показать) 🧩

Опиши словами схему: «как сделать так, чтобы по плоскости рассыпались деревья разного размера». Какие ноды и в каком порядке?

*(Ответ: Plane → Geometry Nodes → Distribute Points on Faces → Instance on Points (дерево через Object Info) → Random Value на Scale.)*

---

## Ответы (для учителя)

1. Geo Nodes — «рецепт» из нодов, всё пересчитывается при смене параметра; не разрушает исходник
2. Distribute — рассыпает точки по поверхности; Instance on Points — ставит объект на каждую точку
3. Points — куда ставить; Instance — что ставить
4. В ряд — Mesh Line; сеткой — Grid
5. Выдаёт случайное число каждой копии (разный размер/поворот) — чтобы не были клонами
6. Потянуть связь от Group Input к нужному входу → назвать параметр → появится ползунок в Modifier Properties

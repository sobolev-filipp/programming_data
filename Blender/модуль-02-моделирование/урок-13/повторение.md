# Повторение урока 12 — «Найди ошибку» + мини-опыт

> 5–7 минут. Вспоминаем управляемые конструкции и Geometry Nodes.

---

## Разминка руками

Открой копию забора. В модификаторе измени «Число секций» с 5 на 8. Покажи, какой вход Mesh Line получает это значение. Если файла нет, объясни соединение Group Input → Count на схеме из справочника.

---

## Найди ошибку и объясни

1. У Mesh Line Count = 5. Ученик говорит, что между первой и последней точкой пять промежутков. Верно?
2. В Grid увеличили Vertices X, но оставили Size X. Почему дома сблизились?
3. Вектор (0,0,высота) подали в Set Position Position вместо Offset. Почему земля собралась в линию?
4. Деревья распределены по исходной плоскости, а земля уже стала холмами. Что переподключить?
5. Где удобнее менять число секций, чтобы не искать нод каждый раз?
6. Чем форма шаблона отличается от мест размещения экземпляров?

---

## Ответы (для учителя)

1. Нет, четыре промежутка.
2. Размер остался прежним, больше точек уложились в ту же ширину. Для постоянного шага Size = (Vertices − 1) × шаг.
3. Position заменяет координаты, X и Y стали нулями. Offset добавляет высоту к исходным координатам.
4. Подать поверхность после Set Position в Distribute Points on Faces Mesh.
5. В панели модификатора через подключённый параметр Group Input.
6. Шаблон задаёт внешний вид, точки — расположение. Сегодня будем создавать саму форму.

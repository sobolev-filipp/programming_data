# Лайфхак урока 14 — Skin: деревья, кабели и существа из линий

> Skin — один из самых недооценённых модификаторов. Любую «трубчатую» вещь он делает за секунды: нарисовал линию-скелет → получил объём.

---

## Главный принцип

1. Рисуешь **скелет из вершин** (линии)
2. Вешаешь **Skin** → линии «надуваются» в трубы
3. Управляешь **толщиной** каждой вершины: `Ctrl + A` (в Edit Mode) + двигай мышь

> 💡 `Ctrl + A` при активном Skin = **радиус вершины**, а не Apply! Толстый низ, тонкие концы — и получается естественная форма.

---

## Что можно сделать Skin

| Объект | Как |
|--------|-----|
| 🌳 **Дерево** | ствол вверх + ветки в стороны (Extrude), низ толстый, концы тонкие |
| 🪸 **Коралл / куст** | много ветвлений из одной точки |
| 🔌 **Кабель / шланг** | одна изогнутая линия, равная толщина |
| 🍄 **Гриб** | короткая толстая ножка + шляпка сверху |
| 🐛 **Червяк / змея** | линия с утолщением посередине |
| 🦴 **Простой персонаж** | «человечек из палочек» → Skin → болванка тела (база для скульпта!) |
| ⚡ **Молния / корни** | резкие ветвления |

---

## Полезные настройки Skin

- **Smooth Shading** (в модификаторе) — сразу гладкие трубы
- **Корневая вершина** (Mark Root) — задаёт, откуда «растёт» (важно для существ)
- После Skin часто ставят **Subdivision** (1–2) — мягкость
- Для веток разной толщины — выделяй вершины и меняй радиус `Ctrl+A` по отдельности

---

## Быстрое дерево за 1 минуту

1. Одна вершина → `E` вверх (ствол) → `E` × 3-4 в стороны (ветки)
2. Skin → `Ctrl+A` на корень (толстый), на концы (тонкие)
3. Ico Sphere-кроны сверху
4. Готово!

---

## Шпаргалка

| Хочу | Делаю |
|------|-------|
| Объём из линии | модификатор Skin |
| Изменить толщину | `Ctrl + A` (Edit Mode) + мышь |
| Гладкие трубы | Smooth Shading в Skin |
| Мягкость | + Subdivision после Skin |
| «Откуда растёт» | Mark Root |

> 💡 **Главная мысль:** если объект можно нарисовать как «палку с ветками» — это работа для Skin. Думай линиями, объём добавит модификатор.

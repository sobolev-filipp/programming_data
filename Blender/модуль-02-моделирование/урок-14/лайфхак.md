# Лайфхак — разные растения из одного каркаса

> Skin превращает рёбра в объём. Чтобы сделать другой силуэт, не обязательно моделировать всё заново.

---

## Попробуй на копии

1. Object Mode: выдели ствол и все его отдельные кроны. Shift+D → X → 2.5. Не используй Alt+D, если хочешь независимо менять сетку.
2. Выбери ствол копии → Tab → режим вершин 1. Alt+A снимает выделение.
3. Выбери кончик ветки, G → X/Z: измени наклон. Ctrl+A → 0.8 уменьшит радиус в этой точке.
4. Верни Object Mode, подвинь крону к изменённому концу. Измени её размер и поворот.
5. Проверь дерево сбоку: корень на земле, крона касается ветвей.

✅ Два дерева используют один приём, но отличаются силуэтом.

---

## Что ещё можно сделать

| Форма каркаса | Результат |
|---|---|
| Ствол и наклонные ветки | Дерево |
| Ствол и две ветки, загнутые вверх | Кактус |
| Несколько коротких ответвлений | Коралл |
| Длинная извилистая цепочка | Корень или кабель |

**Не перепутай:** G меняет положение точки, Ctrl+A в Edit Mode — радиус Skin, обычный S меняет сам каркас. Ctrl+A в Object Mode открывает Apply.

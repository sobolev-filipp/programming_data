# Модуль 2 — Полигональное моделирование + Low-poly

**30 академических часов | 12 уроков**

---

## Чему научимся

- Моделировать кривыми (провода, трубы, антенны)
- Вырезать и соединять формы булевыми операциями (Boolean)
- Создавать тела вращения (Screw, Spin) — турбины, сопла
- Продвинутым приёмам меша (Bridge, Knife, Loop Tools)
- Оптимизировать модели (Decimate, Weld, Remesh)
- **Geometry Nodes** — процедурная генерация
- **Low-poly животные и природу** (Skin, Displace) — собрать ферму
- Собрать большую **сцену** (космос или low-poly мир)

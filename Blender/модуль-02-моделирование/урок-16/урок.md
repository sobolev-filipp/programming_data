## Часть 1 — Теория: китбашинг (10 минут)

**Китбашинг** — это сборка сложной модели из множества **готовых мелких деталей** (как из деталей конструктора). Так делают звездолёты в кино: один набор «греблов» раскидывают по корпусу, и техника выглядит безумно сложной.

**План корабля (думай модулями):**
1. **Корпус** — главная форма (силуэт!)
2. **Двигатели** — сопла, турбины (сзади)
3. **Детали** — иллюминаторы, люки, антенны, трубы, греблы
4. **Акценты** — кабина, свечение двигателей

> 💡 **Фишка — сначала силуэт, потом детали:** сделай узнаваемую крупную форму корабля, и только потом «обвешивай» деталями. Детали на плохом силуэте не спасут.

## Часть 2 — Корпус и двигатели (30 минут)

### Шаг 1 — Корпус (Mirror)

1. Возьми корабль с урока 3 (или собери заново): фюзеляж + крылья через **Mirror** (Clipping)
2. Уточни силуэт: нос, кабина (сфера/скос сверху), общая форма
3. `Ctrl + A → All Transforms`

### Шаг 2 — Двигатели (Screw)

1. Сопла-колокола через **Screw** (урок 8) — посади сзади
2. Турбина с лопастями (радиальный Array) — по желанию
3. Внутри сопла — диск с **Emission** (свечение тяги)

### Шаг 3 — Иллюминаторы и люки (Boolean)

1. Резак-цилиндр → **Array** → **Boolean Difference** (урок 7) — ряд окон
2. Люк с фаской, стыковочное кольцо
3. Помни: `Ctrl+A → Scale` до Boolean, `Shift+N` если чёрные грани

## Часть 3 — Детали и китбашинг (25 минут)

### Трубы и антенны (кривые)

- Кабели вдоль корпуса (кривые, урок 6), антенна-штырь

### Греблы через Asset Browser

1. Сделай 5–6 мелких деталей: коробочки, цилиндры, решётки, болты
2. Пометь их **Mark as Asset** (урок 15)
3. **Перетаскивай** из Asset Browser на корпус, поворачивай, масштабируй — корабль «обрастает» техникой

> 🎯 **ЛАЙФХАК — показать здесь!** Китбашинг — секрет «дорогих» моделей: библиотека греблов + раскидать = мгновенная сложность. Полный разбор (свой кит, повтор деталей, плотность) — в [лайфхак.md](лайфхак.md).

> 💡 **Фишка — плотность деталей неравномерна:** скапливай греблы группами (у двигателей, стыков, люков), оставляй чистые «дышащие» зоны. Равномерная «крупа» по всему корпусу выглядит хуже.

## Часть 4 — Чистое затенение и финал (20 минут)

### Weighted Normal — чинит «грязное» затенение

После Bevel/Boolean на гранях бывают тёмные пятна-артефакты затенения. Лечит **Weighted Normal**.

1. Сделай объекту `ПКМ → Shade Smooth`, включи **Auto Smooth** (Smooth by Angle)
2. 🔧 → **Add Modifier → Normals → Weighted Normal**
3. Тёмные пятна исчезли — поверхность читается чисто

> 💡 **Фишка — Weighted Normal для hard-surface:** на технике (корабли, оружие, роботы) этот модификатор делает затенение «как в играх» — ровное, без грязи на фасках. Почти всегда ставят последним в стек.

### Материалы и рендер

- Корпус: крашеный металл (Metallic 0.6, Roughness 0.4)
- Сопла: тёмный металл + голубое свечение тяги (Emission)
- Окна: тёмное стекло или лёгкая эмиссия
- Разложи по коллекциям: Корпус / Двигатели / Детали
- Камера на эффектный ракурс → `F12`

# 🎨 Курс 3D-моделирования в Blender 4.1

**Для учеников 6–11 классов | 135 академических часов**

---

## О курсе

Этот курс — полное погружение в 3D-моделирование с нуля до уверенного владения Blender 4.1.  
Никакого скучного теоретизирования — с первого урока мы создаём реальные модели: меч, sci-fi панель, игровые ассеты.

К концу курса каждый ученик создаёт **дипломный проект** — полноценную 3D-сцену с моделями, материалами, освещением и анимацией — и защищает его перед классом.

## Как пользоваться этим репозиторием

Каждый урок — отдельная папка. Внутри:

| Файл | Для кого | Содержание |
|------|----------|------------|
| `повторение.md` | дети + учитель | разминка-повторение прошлого урока (викторина / «сделай сам» / опрос) |
| `урок.md` | дети + учитель | теория + практика вместе с детьми |
| `лайфхак.md` | дети | лайфхак урока |
| `практика.md` | дети | **самостоятельное задание** для закрепления |
| `преподавателю.md` | **только учитель** | сценарий урока: тайминг, частые ошибки, что проверить |
| `изображения*.md` | учитель | промпты для генерации/поиска картинок |

Уроки связаны навигацией: внизу каждого `урок.md` — ссылка на **следующий урок**.

**Учитель** начинает с `преподавателю.md` (готовится к уроку), ведёт занятие по `урок.md`.  
**Дети** открывают `урок.md` и следуют шагам, затем делают `практика.md` самостоятельно.

## Что понадобится

- **Blender 4.1** (бесплатно: [blender.org](https://www.blender.org/download/))
- Компьютер с видеокартой (даже встроенная подойдёт — курс рассчитан на слабые ПК)
- Мышь с колёсиком — обязательно
- Желание творить 🚀

# Лайфхак урока 33 — Glare: свечение бликов, подсветки и эмиссии

> Яркие и блестящие места (блики на металле/золоте, луч прожектора, лазерный меч, голограмма, неон) в рендере выглядят «плоско». **Glare** в Compositor добавляет им настоящий **ореол свечения** — и они «загораются».

---

## Базовая связка

1. Воркспейс **Compositing** → **Use Nodes** ✅, **Backdrop** ✅.
2. `Shift+A → Filter → Glare` → вставь между **Render Layers** и **Composite**.
3. Подключи ещё **Viewer** (`Shift+A → Output → Viewer`), чтобы видеть на фоне.

---

## Какой Type под что

| Эффект | Type | Где пригодится |
|--------|------|----------------|
| Мягкий ореол (bloom) | **Fog Glow** | фары, эмиссия, лазерный меч, лава |
| Лучи-звёздочки | **Streaks** | звёзды, блики на металле, солнце |
| Блики объектива | **Ghosts** | сай-фай, отражения, фонари |

## Настройки

- **Threshold** — с какой яркости начинается свечение. Ниже Threshold = светится больше всего (даже не очень яркое). Для аккуратного свечения только самых ярких мест — Threshold повыше.
- **Mix** — сила: ближе к **+1** эффект сильнее. (−1 = только свечение без картинки — для проверки.)
- **Size** (у Fog Glow) — насколько широкий ореол.

---

## Рецепты

| Хочу | Делаю |
|------|-------|
| Лазерный меч/голограмма «горят» | Fog Glow, Threshold ~0.7, Mix ~+0.6 |
| Звёзды с лучиками | Streaks, Streaks=4–6, Threshold повыше |
| Неон города | Fog Glow + чуть Ghosts |
| Только самые яркие точки | поднять **Threshold** |

> 💡 **Главная мысль:** Emission даёт цвет свечения, а **Glare** — сам ореол вокруг него. Вместе светящиеся объекты (лазер ур.4, голограмма ур.21, звёзды ур.31) выглядят как в кино.

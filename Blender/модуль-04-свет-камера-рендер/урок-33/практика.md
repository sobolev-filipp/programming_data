# Самостоятельная работа — Урок 33: Обработай свой кадр ✨

> 🧑‍🎓 Делаешь сам(а): доведи свой кадр в Compositor (свечение + цвет + объектив). Учитель помогает, если застрял.

## Задание

Возьми **свой** рендер (диораму/сцену/портрет с уроков 31–32) и сделай **пост-обработку**: Glare на ярких местах + цветокоррекция под настроение + Lens Distortion (и/или виньетка). Сохрани финал.

**Идеи настроения:**
- 🏛 Музейный каталог: мягкий Fog Glow на бликах, тёплый грейд, виньетка
- 🔥 Тёплый закат: золотые света, мягкий Fog Glow
- 🧪 Магия: свечение зелий/рун (Fog Glow) + лёгкая хроматика
- 🛍 Реклама продукта: чистый контраст, блики (Streaks) на металле/стекле
- 🎮 Игровой постер: контраст, виньетка, яркое свечение акцентов

---

## Требования

- [ ] Сделан рендер (`F12`) и включён Compositor (**Use Nodes**, **Backdrop**)
- [ ] Добавлен **Glare** (подобран Type и Threshold) — свечение ярких мест
- [ ] Сделана **цветокоррекция** (Color Balance) под настроение
- [ ] Применён **Lens Distortion** (хроматика) **или** виньетка
- [ ] Цепочка идёт в **Composite**; финал отрендерен `F12` и сохранён
- [ ] Видна разница «до/после» обработки

---

## 💡 Подсказки (если что-то забыл)

- **Включить:** воркспейс **Compositing** → **Use Nodes** ✅ + **Backdrop** ✅; добавь **Viewer** для предпросмотра
- **Свечение:** `Shift+A → Filter → Glare` → между Render Layers и Composite; Type (Fog Glow/Streaks), **Threshold**, **Mix**
- **Цвет:** `Shift+A → Color → Color Balance` → Lift(тени)/Gamma/Gain(света)
- **Объектив:** `Shift+A → Distort → Lens Distortion` → **Dispersion** ~0.02
- **Виньетка:** Ellipse Mask → Blur → Mix (Multiply)
- **Сохранить:** конец цепочки → **Composite**; `F12` → Image → Save As

# Самостоятельная работа — Урок 32: Сними свой кадр 🎥

> 🧑‍🎓 Делаешь сам(а): выстрой камеру, кадр и рендер своей сцены. Учитель помогает, если застрял.

## Задание

Возьми **другую** сцену (НЕ музейный экспонат с урока) — свою диораму, животное, продукт — и **сними красивый кадр**: ракурс по третям + фокусное под настроение + DOF на главный объект + рендер 1920×1080.

**Идеи кадров:**
- 🏰 Диорама «от первого лица» (низкая камера, широкий угол — масштаб)
- 🐉 Портрет существа/животного (телевик 85 мм, DOF, размытый фон)
- 🍎 Натюрморт с едой (мягкий свет + DOF на передний предмет)
- 🚗 «Реклама» машинки/игрушки (низкий ракурс, блики)
- 🏠 Уголок комнаты (естественный свет, обзорный кадр 35 мм)

---

## Требования

- [ ] Камера выставлена через **Lock Camera to View**
- [ ] Кадр по **правилу третей** (Composition Guides включены)
- [ ] Подобрано **фокусное расстояние** под замысел (широкий/тele)
- [ ] Включён **DOF**, резкость на главном объекте (F-Stop подобран)
- [ ] Выбран движок (EEVEE/Cycles), при Cycles — **Denoise**
- [ ] Вывод **1920×1080**, `F12`, сохранён `.png`

---

## 💡 Подсказки (если что-то забыл)

- **Смотреть из камеры:** `Numpad 0`
- **Кадрировать летая:** `N → View → Camera to View` ✅ (потом снять)
- **Фокусное:** камера → **Object Data Camera** (зелёная камера) → **Lens → Focal Length**
- **Трети:** там же → **Viewport Display → Composition Guides → Thirds**
- **DOF:** там же → **Depth of Field** ✅ → **Focus Object** = главный объект → **F-Stop** ~2
- **Движок:** Render Properties → Render Engine; Cycles → Sampling → **Denoise** ✅
- **Размер:** Output Properties (принтер) → 1920×1080, PNG
- **Тест быстрее:** сначала `%=50`, потом 100%

---

## Что сдать

`.blend` + рендер `1920×1080 .png`. Подпиши: фокусное, F-Stop, движок.

# Самостоятельная работа — Урок 54: Ткань на ветру 🚩⛵

> 🧑‍🎓 Делаешь сам(а) — **с нуля**. Смоделируй объект с тканью и оживи её симуляцией: развевающийся флаг, парус кораблика, палатку или занавеску. Моделирование + Cloth + Pin + ветер.

## Задание

Выбери один вариант, смоделируй и запусти симуляцию ткани:

### 🚩 Вариант А — Флаг своей страны/команды
1. Древко (Cylinder) + полотнище (**Grid** 40×25).
2. **Pin Group** = край у древка. **Wind** сбоку.
3. Рисунок флага — материал (или Texture Paint, урок 28).

### ⛵ Вариант Б — Кораблик с парусом
1. Смоделируй лодочку (корпус, мачта, рея — повтор Модулей 1–2).
2. **Парус** — Grid; **Pin Group** = края у мачты и реи.
3. **Wind** надувает парус → плывём!

### ⛺ Вариант В — Палатка / навес
1. Каркас (цилиндры) + **тент** (Grid), **Pin** по углам/краям крепления.
2. Лёгкий ветер колышет тент.

### 🪟 Вариант Г — Комната с занавеской
1. Окно (рамка) + **штора** (Grid), **Pin** = верхний край на карнизе.
2. Ветер из окна колышет занавеску.

---

## Требования

- [ ] Объект **смоделирован сам** (древко/лодка/каркас/окно — повтор Модулей 1–2)
- [ ] Ткань — **густая сетка** (Grid или Subdivide), не одна грань
- [ ] Включён **Cloth**, задан **Pin Group** (нужный край закреплён)
- [ ] Есть **Wind** (или движение) — ткань развевается
- [ ] (Если ткань обтекает предмет) на предмете включён **Collision**
- [ ] Симуляция **запечена** (Bake); файл сохранён

---

## 💡 Подсказки (повтори прошлое + ткань)

- **Ткань = Grid** (`Shift+A → Mesh → Grid`, задай Subdivisions), а не Plane (у Plane нет складок).
- **Pin Group:** Edit Mode → выдели край → Object Data → Vertex Groups `+` → `Pin` → Assign; затем Physics → Cloth → **Shape → Pin Group**.
- **Ветер:** `Shift+A → Force Field → Wind`; стрелка = направление; Strength 300–800 (ткань лёгкая).
- **Обтекание предмета:** предмету → Physics → **Collision**.
- **🖥 Слабый ПК:** Subdivisions умеренно (20–30), **Quality Steps 7–10**, **обязательно Bake**.
- **Характер ткани:** пресеты Cloth — **Silk** (лёгкая, летящая), **Denim/Leather** (тяжёлая).
- **Улетает/падает:** проверь Pin Group и умерь ветер.

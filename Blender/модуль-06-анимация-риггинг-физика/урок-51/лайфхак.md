# Лайфхак урока 51 — «Пульт эмоций» из Shape Keys 🎛😊

> Несколько базовых ключей формы — это не «несколько эмоций», а **конструктор из десятков выражений**. Секрет — в смешивании Value и в паре приёмов управления. Собери «пульт эмоций» — и играй лицом персонажа как актёр.

---

## Смешивание — эмоций больше, чем ключей

Value всех ключей работают **одновременно** и складываются:

| Улыбка | Удивление | Моргание | Что получилось |
|--------|-----------|----------|----------------|
| 1.0 | 0 | 0 | улыбка |
| 1.0 | 0 | 1.0 | жмурится от счастья |
| 0.5 | 0.5 | 0 | приятно удивлён |
| 0 | 1.0 | 0.3 | изумлён, прищурился |
| 0.3 | 0 | 0 | лёгкая полуулыбка |

> 💡 Из 3 ключей — уже с десяток выражений. Добавь `Грусть` (уголки рта вниз) и `Злость` (брови внутрь-вниз) — получишь полный актёрский набор из 5 ключей.

---

## Приёмы управления

**1. Value больше 1 и меньше 0 (осторожно).**
В настройках ключа есть **Range Min/Max**. Поставь Max = 1.5 — улыбка станет «мультяшно-широченной» (форма продолжится дальше цели). Min = −0.5 у улыбки даст… лёгкую грусть (сдвиг в обратную сторону)! Работает, если топология позволяет.

**2. Драйвер от кости-«ползунка» (мини-пульт).**
Профи вешают Value на **контрол-кость**: двигаешь косточку-слайдер рядом с головой — лицо улыбается.
1. Добавь маленькую кость `Пульт-улыбка` рядом с головой (в арматуре).
2. ПКМ по Value `Улыбки` → **Add Driver** → переменная **Transform Channel** → Object = арматура, Bone = `Пульт-улыбка`, **Type = X Location**, Space = Local.
3. Expression: `var * 2` (сдвиг кости на 0.5 = улыбка на 100%).
→ Теперь мимика управляется прямо во вьюпорте, вместе с позой — не лазая в панели.

**3. Авто-жизнь через `frame` (урок 44).**
- Авто-моргание: `max(0, sin(frame*0.35)**16)` на `Моргание`.
- Лёгкое «дыхание» лица: `0.05 + 0.05*sin(frame*0.1)` на слабый ключ `Улыбка`.

## Частые затыки

| Симптом | Причина | Решение |
|---------|---------|---------|
| Новый ключ «не лепится» | лепишь при выделенном Basis | выдели **нужный ключ** в списке, Value=1, потом Edit Mode |
| Все ключи «поехали» | изменил Basis после создания ключей | Basis не трогать; правки базы — до создания ключей |
| Выражение действует не там | задел лишние вершины | в Edit Mode проверь выделение; Proportional-радиус меньше |
| Смешивание даёт «кашу» | конфликтующие ключи на одних вершинах | делай ключи локальными (рот отдельно, брови отдельно) |
| Value не двигается | ключ заблокирован/драйвер висит | проверь замочек и фиолетовый цвет поля (драйвер) |

> 💡 **Главная мысль:** строй мимику как **конструктор**: несколько маленьких локальных ключей (рот, брови, веки — отдельно) вместо одного «лица целиком». Тогда смешиванием Value собирается любая эмоция, а драйверы превращают всё это в удобный пульт.

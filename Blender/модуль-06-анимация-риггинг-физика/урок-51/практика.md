# Самостоятельная работа — Урок 51: Оживший предмет с эмоциями ☕😀

> 🧑‍🎓 Делаешь сам(а) — **с нуля**. Как в мультиках Pixar, где чайники и лампы «живые»: **смоделируй мультяшный предмет-персонажа**, слепи ему лицо и подари **эмоции через Shape Keys**. Моделирование + мимика + мини-сценка.

## Задание

Смоделируй предмет с «лицом» и сделай ему **3+ ключа формы** (улыбка, удивление, моргание/грусть), затем разыграй **сценку смены эмоций** ключами на Value.

### Идеи (выбери одно)
- ☕ **Чашка** — глаза-выпуклости, рот на боку; ручка как «рука в бок».
- 🍎 **Яблоко** — щекастое, с листиком (листик может «удивлённо» подпрыгивать — тоже Shape Key!).
- 🎃 **Тыква** — вырезанное лицо (Boolean, урок 7), эмоции меняют вырезы… или лепи мягкое лицо вершинами.
- ⏰ **Будильник** — круглое лицо-циферблат, звонки-«уши» (дрожат от злости — ключ формы!).
- 📦 **Коробка** — квадратный характер: крышка-рот открывается «от удивления».

### Шаги

1. **Смоделируй предмет** (повтор Модулей 1–2): база из примитивов → **SubSurf/Bevel** для мягкости → детали (ручка/листик/звонки). Достаточно вершин на «лице» — иначе мимику не слепить (добавь **Loop Cut**/Subdivide в зоне лица).
2. **Материалы** (Shading): цвет корпуса, глаза (тёмные сферы или нарисованные грани-Assign).
3. **Basis:** Object Data → Shape Keys → **+** (база, не трогать).
4. **Ключи:** `+` → `Улыбка` (Value=1 → Edit Mode → уголки рта вверх, **Proportional `O`**), `+` → `Удивление` (брови/крышка вверх, рот «О»), `+` → `Моргание` или `Грусть`.
5. **Сценка (60–80 кадров):** ключи `I` на Value — предмет «просыпается»: моргнул → удивился → заулыбался. Easing по вкусу (урок 42).
6. **Бонус-драйвер:** авто-моргание `max(0, sin(frame*0.35)**16)` (урок 44/51).

## Требования

- [ ] Предмет **смоделирован сам** (примитивы + SubSurf/Bevel + детали; на «лице» хватает сетки)
- [ ] Материалы назначены (Shading)
- [ ] **Basis + 3 ключа формы минимум**, названы понятно
- [ ] Ключи **смешиваются** без «каши» (проверь улыбка+моргание)
- [ ] **Сценка** смены эмоций ключами на Value играется по `Пробел`
- [ ] (Бонус) авто-моргание драйвером; файл сохранён

## 💡 Подсказки (повтори прошлое)

- **Мягкая форма:** SubSurf (урок 4) + Loop Cut для плотности в зоне лица.
- **Сначала `+` ключ, потом лепить!** Лепишь при выделенном ключе (его Value = 1). Basis не трогать.
- **Proportional Editing (`O`)** — главный инструмент мимики; радиус — колесо мыши.
- **Глаза** проще отдельными сферами (веки — ключ формы на корпусе поверх).
- **Value = обычное свойство:** курсор на ползунок → `I` (ключ анимации); ПКМ → Add Driver.
- **Смешение:** улыбка 1 + моргание 1 = «жмурится от радости» — проверь, не ломается ли сетка.
- **Моргание быстрое:** 2–4 кадра вниз, 3–5 вверх.
- **Крышка/листик/звонок** — тоже Shape Key (или отдельный объект с ключами `I` на Rotation).

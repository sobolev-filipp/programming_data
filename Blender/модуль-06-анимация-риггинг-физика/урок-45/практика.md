# Самостоятельная работа — Урок 45: Свой оживший перекрёсток 🚦🏙️

> 🧑‍🎓 Это **мини-проект** на оценку. Собери **свою** анимированную городскую сцену, применив все 4 инструмента модуля. Не копируй урок один-в-один — сделай по-своему (другой перекрёсток, кольцо, двор, парковка).

## Задание

Создай оживший уголок города, где работают **минимум 4 техники модуля**:

1. **Светофор или мигающие огни** — цикл через ключи Emission (можно взять **свой светофор из урока 41**!).
2. **Транспорт с движением и Easing** — машина/автобус тормозит и разгоняется плавно (ключи + Graph Editor).
3. **Колёса/механизм от движения** — драйвер (`x / радиус`).
4. **Follow Path или пустышка-родитель** — автобус по дуге / круговое движение / вращающаяся вывеска.
5. **Камера Track To** — держит сцену в кадре.

### Идеи (выбери своё)
- 🔁 **Кольцевой перекрёсток** — машины едут по кругу (пустышка-родитель!).
- 🅿️ **Парковка/двор** — шлагбаум поднимается (ключи+Easing), машина въезжает.
- 🚶 **Пешеходный переход** — человечек идёт по «зебре» (Follow Path), машины ждут.
- 🚌 **Автобусная остановка** — автобус подъезжает, двери (ключи), уезжает.

## 💡 Подсказки (если что-то забыл)

- **Светофор (ключи Emission):** материал лампы в Shading → Emission Strength; кадр→значение→`I`.
- **Easing:** Graph Editor → выдели ключи → `T → Sinusoidal` → `Ctrl+E → Ease In/Out`.
- **Колесо от движения:** ПКМ по Rotation → Add Driver → Transform Channel = кузов X Location → `x / радиус`. Copy/Paste Driver на другие колёса.
- **Follow Path:** объекту `Alt+G`; ограничитель Follow Path → Target = кривая → ✓ Follow Curve → **Animate Path**; скорость — Frames у кривой.
- **Пустышка-родитель:** Empty в центр → выдели детей, потом Empty → `Ctrl+P → Object` → вращай Empty (ключи или `frame*…`).
- **Track To:** камере ограничитель Track To → Target = Empty-центр → To = −Z, Up = Y.
- **Синхронь ритм:** машина должна стоять, пока горит красный, и ехать на зелёный — сверь кадры.

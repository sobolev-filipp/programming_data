# Лайфхак урока 52 — Hair для волос, эмиттер для эффектов (и не повесить ПК) 💇✨🖥

> Два типа частиц — под две разные задачи. Перепутаешь — либо не получится эффект, либо ПК «ляжет». Вот как выбрать правильно и остаться в живых на слабой машине.

---

## Какой тип для чего

| Хочу | Тип | Почему |
|------|-----|--------|
| Волосы, шерсть, трава, мех, шипы, перья | **Hair** | застывшие волоски, «растут» и стоят на месте |
| Искры, дым, дождь, снег, брызги, магия, пыль, листья | **Emitter** | частицы рождаются, летят и гибнут |

> Правило: **что-то ЛЕТИТ и исчезает → Emitter. Что-то ТОРЧИТ и остаётся → Hair.**

---

## 🖥 Как НЕ повесить слабый ПК (главное!)

Частицы — самое тяжёлое в курсе. Соблюдай:

| Приём | Зачем |
|-------|-------|
| **Мало Number** (100–500) | направляющих/частиц немного = легко считать |
| **Много Children** (10–30) | густота волос почти **бесплатно** (интерполируются) |
| **Bake** (Particle → Cache → Bake) | посчитал раз → играется мгновенно, не пересчитывает |
| **Render As Halo/Points** для искр | легче, чем Object-инстансы |
| **Simplify** (Render → Simplify) | глобально срезать частицы для вьюпорта |
| Дым/огонь — **низкий Resolution + Bake** | объёмная симуляция самая тяжёлая; лучше демо учителя |

> ⚠️ Никогда не ставь Number в тысячи «для красоты» — это первая причина зависаний. **300 волос + Children 20** выглядит гуще, чем 5000 волос, и летает.

---

## Мини-рецепты

**Волосы (Hair):**
Vertex Group `Волосы` (где растут) → Hair, Number 300, Length под масштаб → Particle Edit **Comb** причесать → Children Interpolated 20 → материал-цвет.

**Искры/магия (Emitter):**
Emitter, Number 200, Lifetime 30, Velocity Normal 1 → Gravity 0.2 (чтобы взлетали) → Render Halo или Object с **Emission** → Force Field **Wind/Turbulence** для «сдува» → **Bake**.

**Трава на земле (Hair):**
на плоскости-земле Hair, Length короткая, Children много, материал зелёный с градиентом (темнее у корней).

---

## Частые затыки

| Симптом | Причина | Решение |
|---------|---------|---------|
| ПК завис при частицах | Number в тысячах | снизить Number, добавить Children, Bake |
| Волосы растут отовсюду | нет Vertex Group | указать группу в Density |
| Волосы «взрыв» | не причёсаны | Particle Edit → Comb |
| Искры падают вниз | полная гравитация | Field Weights → Gravity 0.1–0.2 |
| Искры не видно | нет Emission/материала | Render As Object с Emission + Bloom |
| Каждый раз пересчитывает/тормозит | не запечено | Particle → Cache → **Bake** |

> 💡 **Главная мысль:** сначала выбери **тип** (летит → Emitter, торчит → Hair), потом держи **число маленьким** и **пеки**. Красивый эффект — это не «много частиц», а **правильные настройки** небольшого числа.

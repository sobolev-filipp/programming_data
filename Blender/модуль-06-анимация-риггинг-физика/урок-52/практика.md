# Самостоятельная работа — Урок 52: Костёр / факел / волшебный посох 🔥🪄

> 🧑‍🎓 Делаешь сам(а) — **с нуля**. Смоделируй предмет-источник эффекта и **оживи его частицами**: искры, магия, дым. Моделирование + система частиц + Force Fields.

## Задание

Смоделируй **один** предмет и дай ему **эффект-эмиттер** (+ по желанию ветер):

### Идеи (выбери одно)
- 🔥 **Костёр** — брёвнышки (боксы/цилиндры), угли (Emission) → **искры** вверх (Emitter) + бонус **Quick Smoke** (демо).
- 🔦 **Факел** — палка + «пламя» → искры/огоньки, лёгкое покачивание.
- 🪄 **Волшебный посох** — стержень + кристалл (Emission, урок 27) → **магические блёстки** ✨ + Force Field вихрь.
- 🎆 **Фонтан/салют** — источник → частицы дугой (гравитация) разных цветов.
- 🌿 Бонус: **лужайка** — плоскость + **Hair**-трава (Children!).

### Шаги

1. **Смоделируй предмет** (повтор Модулей 1–2): из примитивов + Bevel; светящиеся части — **Emission** (Shading, урок 18).
2. **Эмиттер:** источник → Particle Properties → **+** → Type **Emitter**. Number **~200**, Lifetime 30, Velocity Normal, Gravity уменьшить (Field Weights).
3. **Вид искр:** Render As **Halo** или **Object** (звёздочка/сфера с Emission) + **Bloom**.
4. **Force Field:** `Shift+A → Force Field → Wind` или **Turbulence** — «сдувай» искры.
5. **Bake** (Particle → Cache → Bake) — чтобы не тормозило.
6. **Кадр:** тёмный фон, чтобы искры сияли; короткая анимация.

## Требования

- [ ] Предмет **смоделирован сам** (примитивы + Bevel + Emission-детали)
- [ ] Работает **эмиттер** (частицы летят из источника)
- [ ] Настроены Number/Lifetime/Velocity (**щадящее число!**)
- [ ] Искры **видны** (Halo/Object + Emission/Bloom)
- [ ] Добавлен **Force Field** (ветер/вихрь) ИЛИ бонус-эффект (Hair-трава / Quick Smoke)
- [ ] Частицы **запечены** (Bake); файл сохранён

---

## 💡 Подсказки (повтори прошлое + слабый ПК)

- **Свечение:** материал **Emission** (урок 18) + **Bloom** (EEVEE) — искры засияют.
- **Тип частиц:** летит и гаснет → **Emitter**; торчит (трава/шерсть) → **Hair**.
- **Искры вверх:** уменьши **Gravity** в Field Weights (0.1–0.2), направление — **Velocity Normal**.
- **🖥 Слабый ПК:** Number **не больше ~300**; трава/шерсть — мало Number + много **Children**; **обязательно Bake**.
- **Ветер:** `Shift+A → Force Field → Wind/Turbulence`, крути Strength.
- **Дым (демо):** `Object → Quick Effects → Quick Smoke`; низкий Resolution + Bake; в EEVEE после Bake.
- **Кадр:** тёмный World — эффект читается лучше.

# Самостоятельная работа — Урок 53: Боулинг или крепость на снос 🎳🏰

> 🧑‍🎓 Делаешь сам(а) — **с нуля**. Смоделируй объекты и устрой **физическое разрушение**: сбей кегли шаром или разнеси крепость. Моделирование + Rigid Body.

## Задание

Собери сцену, где **физика сама** роняет/разбивает твою постройку. Выбери один вариант:

### 🎳 Вариант А — Боулинг
1. Смоделируй **кеглю** (тело вращения: профиль → **Screw**, урок 8) и **10 кеглей** расставь треугольником.
2. Смоделируй **шар** и **дорожку** (Plane).
3. Физика: кегли и шар — **Active**; дорожка — **Passive**. Шар анимируй/скати по дорожке.
4. `Пробел` → шар сбивает кегли! **Bake**.

### 🏰 Вариант Б — Крепость на снос
1. Смоделируй **стену/башню/крепость** из блоков-кирпичей (кубы; можно **Array**, потом Apply, чтобы стали отдельными телами).
2. Смоделируй **снаряд** (ядро/шар-разрушитель).
3. Физика: блоки и снаряд — **Active**; земля — **Passive**. Снаряд — тяжёлый (Mass большой), при желании **Animated** (размах).
4. `Пробел` → крепость рушится! **Bake** (можно **Speed 0.3** для слоу-мо).

### 🧱 Вариант В — Домино-машина
Длинная трасса домино (змейкой, с горкой, разными цветами) → толкни первую → цепная реакция.

---

## Требования

- [ ] Объекты **смоделированы сам** (кегли/блоки/домино — повтор Модулей 1–2)
- [ ] Правильно расставлены **Active** (падают) и **Passive** (пол/земля)
- [ ] Настроены **Collision Shape** (Box/Sphere) и **Mass**
- [ ] Использован **Copy from Active** (раздать физику многим)
- [ ] Разрушение **работает** по `Пробел`
- [ ] Симуляция **запечена** (Bake); файл сохранён

---

## 💡 Подсказки (повтори прошлое + физика)

- **Кегля:** профиль-линия → модификатор **Screw** (урок 8) = тело вращения.
- **Много блоков:** **Array** (урок 3) → потом **Apply** и `P → By Loose Parts`, чтобы каждый стал **отдельным телом** (иначе физика считает их одним куском).
- **Раздать физику:** выдели все, активным — настроенное тело, **Object → Rigid Body → Copy from Active**.
- **Формы столкновения:** кубы/кегли — **Box** (или Convex Hull), шар — **Sphere**. **Mesh не бери** — тяжело и дёргается.
- **Тяжёлый снаряд:** Mass побольше (10–20), чтобы всё разлетелось.
- **Толкнуть/раскачать:** анимируй снаряд ключами + галочка **Animated** (толкает блоки).
- **🖥 Слабый ПК:** число тел умеренное (20–40), **Box/Sphere**-формы, **обязательно Bake**.
- **Слоу-мо:** Scene → Rigid Body World → **Speed = 0.3**.

# Лайфхак урока 48 — IK для естественного сгиба 🦵

> Главный секрет правдоподобной ходьбы и опоры: **стопа должна стоять на полу**, пока тело движется. С IK это происходит само. Вот когда включать IK, как «прибить» стопу к полу и зачем обязателен Pole Target.

---

## Когда IK, а когда FK

| Хочу | Беру |
|------|------|
| Стопа стоит на полу (ходьба, прыжок, стойка) | **IK** |
| Рука опёрлась о стол / держит фиксированный предмет | **IK** |
| Свободный мах рукой, хвост, верёвка, причёска | **FK** |
| Толчок от опоры, лазание | **IK** |

Правило: **есть контакт с миром → IK; свободное движение по дуге → FK.**

---

## Как «прибить» стопу к полу (для ходьбы)

1. Поставь **IK** на голень (Target = Empty `Цель-нога`, Chain Length = 2).
2. Теперь Empty-цель **на полу** = стопа на полу. Двигаешь **тело/таз** вверх-вниз — нога **сама** сгибается в колене, а стопа **остаётся на месте**.
3. Шаг делаешь так: переставляешь **Empty-цель** в новую точку на полу (а не крутишь суставы). Нога догоняет.

> 🧠 Вот почему IK незаменим для ходьбы: опорная нога стоит (цель неподвижна на полу), пока корпус едет вперёд — колено само подгибается. На FK пришлось бы вручную докручивать каждый сустав каждый кадр.

---

## Зачем Pole Target (обязательно для колен/локтей)

Без Pole колено может **вывернуться** вбок или «щёлкать» при сгибе. **Pole Target** — Empty **перед коленом** — задаёт направление сгиба:
- колено всегда «смотрит» на Pole;
- крутишь **Pole Angle** (часто −90°), пока колено не встанет ровно вперёд;
- двигаешь Pole-Empty вбок — колено доворачивается (полезно для «носки врозь»).

---

## Частые затыки

| Симптом | Причина | Решение |
|---------|---------|---------|
| Нога не тянется к цели | не выбран Target | в IK Constraint указать Empty-цель |
| Гнётся вся спина/таз | Chain Length слишком большой | для ноги Chain Length = **2** |
| Колено выворачивается/щёлкает | нет Pole Target / не тот Pole Angle | добавить Pole-Empty, подобрать Pole Angle |
| Стопа «висит» носком вниз | стопа не привязана к цели | **Copy Rotation** на стопе → Target = Empty-цель |
| Нога «дрожит»/перещёлкивает у предела | цель слишком далеко (нога выпрямлена в струну) | держи цель чуть ближе, чем полная длина ноги |

> 💡 **Главная мысль:** IK переворачивает управление — ты ведёшь **цель**, а не суставы. Прибил стопу к полу — и ходьба собирается из перестановки целей, а колени гнутся сами (Pole Target держит их «лицом вперёд»). Это фундамент урока 49.

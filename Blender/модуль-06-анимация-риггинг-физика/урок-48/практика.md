# Самостоятельная работа — Урок 48: Экскаватор за работой 🚜⛏️

> 🧑‍🎓 Делаешь сам(а) — **с нуля**. Смоделируй **экскаватор**, оснасти его ригом с **IK** и анимируй, как он **копает**. Это большой проект: ты повторишь моделирование (Модули 1–2), материалы (Модуль 3) и применишь IK + анимацию (Модуль 6). Именно с экскаватора мы начали урок — теперь построй свой!

> ⏱ Проект на 2 занятия: **смоделировал и оснастил** → **анимировал копание** (можно часть дома).

---

## Этап 1 — Моделирование (повторяем Модули 1–2)

Собери экскаватор из простых форм (low-poly!):

| Часть | Как смоделировать (повтор навыков) |
|-------|-------------------------------------|
| **Гусеницы** (2 шт) | вытянутый Cube → **Bevel** (Ctrl+B) скруглить → траки через **Array** (повтор урока 3); вторую гусеницу — **Mirror** |
| **Поворотная платформа** | Cube сверху на гусеницах — на ней крутится весь верх |
| **Кабина** | Cube → окно через **Inset/Boolean** (повтор уроков 1, 7) |
| **Стрела** (boom) | длинный Cube, **Bevel** рёбра |
| **Рукоять** (stick) | Cube покороче |
| **Ковш** | Cube → **Inset** + **Extrude** внутрь (выемка), скос зубьев |
| **Шарниры/цилиндры** | Cylinder в местах сгибов (детализация) |

> 🎨 **Материалы (Модуль 3, в Shading нодами):** жёлтый металл корпуса (Metallic + Roughness), тёмные гусеницы, стекло кабины (повтор урока 27). Не забудь **Shade Smooth + Auto Smooth** и **Weighted Normal** для чистого вида (📚 [нормали](../../справочники/глубокое-погружение/нормали-сглаживание.md)).

## Этап 2 — Риг и IK (навык урока)

1. **Скелет** (урок 46): арматура с цепочкой костей по руке — `Платформа → Стрела → Рукоять → Ковш` (+ кость базы). Кости — точно в шарнирах. **In Front**.
2. **Привязка:** к каждой кости — свою часть (Parent → With Automatic Weights, или по объектам **Parent to Bone**, если части отдельные).
3. **IK:** Empty `Ковш-цель` у зубьев ковша → на кость **Рукоять** повесь **Inverse Kinematics** → Target = `Ковш-цель`, **Chain Length = 2** (рукоять+стрела). Теперь двигаешь Empty — стрела и рукоять **сами сгибаются**, ведя ковш (как на картинке урока!).
4. **Поворот платформы** — отдельной костью/ключами (вращение верха вокруг оси — повтор пустышки-родителя, урок 45).

✅ *Итог этапа:* водишь `Ковш-цель` — рука экскаватора послушно изгибается.

## Этап 3 — Анимация копания (уроки 41–42, 45)

Сделай цикл «копнул — повернулся — высыпал»:
1. **Замах:** ковш вверху сбоку (ключи на `Ковш-цель` + поворот ковша).
2. **Копок:** `Ковш-цель` опускается к земле → ковш «зачерпывает» (поворот) — с **Easing** (урок 42).
3. **Подъём + поворот платформы** к самосвалу (ключи поворота верха).
4. **Высыпал:** ковш переворачивается.
5. **Возврат** в начало (можно зациклить — **Make Cyclic**, урок 42).

✅ *Итог:* экскаватор копает по кругу — живая машина!

## 💡 Подсказки (повтори прошлое)

- **Гусеничные траки:** один блок-трак → **Array** вдоль (как заклёпки на паровозе, урок 16); загиб по кругу — по желанию (Curve/Array+Empty).
- **Симметрия:** вторую гусеницу и парные цилиндры — **Mirror** (урок 3) или **Auto Mirror** (аддон).
- **Окно кабины:** **Inset** грань → задвинь внутрь, или **Boolean** (урок 7).
- **Ковш-выемка:** Inset + Extrude внутрь; зубья — мелкие Extrude по краю.
- **IK:** Pose Mode → кость рукояти → Bone Constraint → **Inverse Kinematics** → Target = Empty, Chain Length 2. Двигаем **Empty**, не кости.
- **Поворот платформы:** ключи `R Z` на кости базы/платформы; **Easing** в Graph Editor.
- **Чистый вид:** Shade Smooth + Auto Smooth; **Weighted Normal** (урок 16).
- **Не усложняй:** всё из простых боксов — это low-poly, не фотореализм.

# Самостоятельная работа — Урок 48: IK для своей лампы/крана 🦾🎯

> 🧑‍🎓 Делаешь сам(а). На уроке IK поставили на ногу человечка — а ты повесь **IK на свою лампу / робо-руку / кран** из уроков 46–47. Будешь двигать **кончик** (плафон/ковш/клешню), а вся рука **сама** изогнётся к нему. Тот же приём, другой объект.

## Задание

Сделай так, чтобы твой объект **тянулся кончиком к цели**: двигаешь Empty — сегменты сами сгибаются.

### Шаги

1. **Открой** свой риг из урока 46 (объект + цепочка костей, кожа привязана).
2. **Цель:** `Shift+A → Empty → Plain Axes` у **кончика** (плафон лампы / ковш / клешня). Назови `Цель`.
3. **IK:** Pose Mode → выдели **последнюю** кость цепочки → Bone Constraint → **Inverse Kinematics** → **Target = `Цель`**, **Chain Length** = число костей цепи (напр. 3).
4. **Проверь:** выдели `Цель` → `G` → поводи. Сегменты должны изгибаться, дотягиваясь кончиком до Empty.
5. **Pole (если изгиб «не туда»):** добавь Empty сбоку/спереди → в IK укажи **Pole Target** → покрути **Pole Angle**.
6. **Анимируй цель:** поставь 2–3 ключа на `Цель` (Empty ездит) — рука «работает» сама (как кран копает).

> 🏗 Кран/экскаватор — самый наглядный пример: двигаешь «ковш», стрела гнётся. Лампа — «заглядывает» в точку. Змейка — дотягивается головой до цели.

## Требования

- [ ] На последнюю кость цепи повешен **IK Constraint** с **Target = Empty**
- [ ] Задан корректный **Chain Length** (сколько костей гнётся)
- [ ] Двигаешь Empty — цепочка **сама** изгибается к нему
- [ ] (Если нужно) добавлен **Pole Target** для направления изгиба
- [ ] Поставлены ключи на Empty — объект «работает» в анимации

## 💡 Подсказки (если что-то забыл)

- **IK — это костный ограничитель:** Pose Mode → выдели кость → **Bone Constraint Properties** (иконка кость+цепь) → Add → **Inverse Kinematics**.
- **Target** — выбери свой **Empty** (`Цель`). Двигаем именно Empty, не кости!
- **Chain Length** — сколько костей вверх гнётся (0 = вся цепь; обычно ставь точное число сегментов).
- **Изгиб «не в ту сторону»:** добавь **Pole Target** (Empty сбоку) и подбери **Pole Angle**.
- **Кончик не дотягивается:** цель слишком далеко — придвинь Empty ближе (не дальше вытянутой длины).
- **Анимация:** на кадрах двигай `Цель` и ставь `I → Location` (как корабль из урока 42; добавь Easing).
- Кость с IK не нужно вращать вручную — ею теперь «рулит» цель.

# Самостоятельная работа — Урок 46: Оснасти гибкий объект 🦾💡

> 🧑‍🎓 Делаешь сам(а). Человечка мы оснастили вместе — а ты **построй скелет И привяжи кожу** к другому гибкому объекту: **настольной лампе**, **робо-руке**, **башенному крану** или **змейке**. Это **цепочка костей** — те же шаги (скелет + привязка), но проще.

## Задание

Смоделируй объект из сегментов, вставь **цепочку костей** и **привяжи** меш, чтобы он сгибался.

### Идеи (выбери одну)
- 💡 **Настольная лампа** (Pixar): основание → нижнее колено → верхнее → плафон.
- 🦾 **Робо-рука / манипулятор:** база → секции → клешня.
- 🏗 **Башенный кран:** башня → стрела → крюк.
- 🐍 **Змейка / червяк / щупальце:** длинная цепочка из 6–10 костей.

### Шаги

1. **Модель:** собери объект из нескольких сегментов (цилиндры/кубы) встык.
2. **Скелет:** `Shift+A → Armature` у основания. Включи **In Front** и **Names**. `Tab` (Edit Mode) → ставь кость в сегмент → выделяй **Tail** → `E` → следующий сегмент. Кости — точно **в суставах**.
3. **Привязка:** Object Mode → выдели **меш**, потом `Shift`-**арматуру** (активна) → `Ctrl+P → With Automatic Weights`.
4. **Тест:** арматура → **Pose Mode** → поверни кость в середине → меш гнётся вместе с костями.
5. **Доводка (если надо):** Weight Paint → 🔴 добавить / 🔵 убрать / **Blur** сгладить.

> 🐍 Для змейки красиво, когда стык влияют две кости 0.5/0.5 — «резиновый» плавный изгиб (поиграй Blur).

---

## Требования

- [ ] Объект из **нескольких сегментов**
- [ ] **Цепочка костей** построена (`E`), кости **в суставах**
- [ ] Включены **In Front** и **Names**
- [ ] Меш **привязан** (Automatic Weights, есть модификатор Armature)
- [ ] В Pose Mode объект **гнётся** вслед за костями
- [ ] (Если нужно) дефекты поправлены в Weight Paint; файл сохранён

---

## 💡 Подсказки (если что-то забыл)

- **Видеть кости сквозь меш:** Object Data → Viewport Display → **In Front** (+ **Names**).
- **Растить кости:** выдели **Tail** → `E`. Кости — точно в местах сгиба.
- **Порядок привязки:** сначала **меш**, потом `Shift`-**арматура** (активна) → `Ctrl+P → With Automatic Weights`.
- **Тест:** Pose Mode → `R` на кости; сброс — `Alt+R`.
- **Не гнётся:** проверь, что привязал **с Automatic Weights** и у меша есть модификатор Armature.
- **Часть мнётся/улетает:** Weight Paint → 🔴/🔵 поправить, **Normalize All**.
- **Кость гнётся «не в суставе»:** в Edit Mode подвинь её Head/Tail в сустав.

# Самостоятельная работа — Урок 46: Скелет для гибкого объекта 🦾💡

> 🧑‍🎓 Делаешь сам(а). Человечка мы рискнём вместе — а ты построй скелет для **другого** гибкого объекта: **настольной лампы**, **робо-руки**, **башенного крана** или **змейки**. Это **цепочка костей** — те же кости и иерархия, но проще (без зеркала).

## Задание

Смоделируй простой объект из сегментов и вставь в него **цепочку костей**, чтобы его можно было сгибать.

### Идеи (выбери одну)
- 💡 **Настольная лампа** (как у Pixar): основание → нижнее «колено» → верхнее → плафон. 4 кости цепочкой.
- 🦾 **Робо-рука / манипулятор:** база → секции → «клешня».
- 🏗 **Башенный кран:** башня → стрела → крюк.
- 🐍 **Змейка / червяк / щупальце:** длинная цепочка из 6–10 костей (гибко изгибается).

### Шаги

1. **Модель:** собери объект из нескольких сегментов (цилиндры/кубы) встык по высоте/длине.
2. **Арматура:** `Shift+A → Armature` у основания. Включи **In Front** и **Names** (Object Data → Viewport Display).
3. **Строй кости:** `Tab` (Edit Mode) → ставь первую кость в первый сегмент → выделяй **Tail** → `E` → следующий сегмент. Повторяй по числу сегментов.
4. **Проверка:** `Tab` → Object Mode → **Pose Mode** → выдели кость в середине → `R`. Верхние сегменты должны ехать за ней (иерархия).
5. Назови кости понятно (`База`, `Сегмент1`, `Плафон`…). Для змейки можно `Кость.001`, `.002`…

> 🐍 Кости должны стоять **точно в суставах** (там, где объект должен сгибаться). Поставишь между суставами — согнётся не там.

---

## Требования

- [ ] Объект из **нескольких сегментов** (не один кусок)
- [ ] **Цепочка костей** построена через `E` (Extrude)
- [ ] Кости **в суставах** (где должно гнуться)
- [ ] Включены **In Front** и **Names** (кости видно, подписаны)
- [ ] В **Pose Mode** проверено: поворот кости тянет за собой верхние сегменты
- [ ] Кости названы понятно; файл сохранён

> ℹ️ Привязывать кожу к костям (чтобы меш реально гнулся) будем на **уроке 47** — сегодня только скелет и проверка иерархии в Pose Mode.

---

## 💡 Подсказки (если что-то забыл)

- **Добавить арматуру:** `Shift+A → Armature` (одна кость от курсора вверх).
- **Видеть кости сквозь модель:** Object Data Properties (зелёный человечек) → Viewport Display → **In Front** ✅ (+ **Names**).
- **Edit Mode арматуры:** `Tab`. Выдели **Tail** (кончик) → `E` → тяни → новая кость прицепится.
- **Двигать кость/сустав:** выдели head или tail → `G`.
- **Pose Mode:** выпадающий список режимов слева вверху → Pose Mode; поворот — `R`; сброс позы — `Alt+R`.
- **Кость не там гнётся:** в Edit Mode подвинь её Head/Tail точно в сустав.
- **Цепочка «рассыпается»:** кости должны быть **connected** (выдавлены из Tail предыдущей), а не отдельные.

# Самостоятельная работа — Урок 42: Прыгающий мяч 🎾

> 🧑‍🎓 Делаешь сам(а). На уроке мы разгоняли и тормозили **корабль**. Ты сделаешь **прыгающий мяч** — это «упражнение №1» каждого аниматора в мире: на нём проверяют, понял ли человек **Easing**.

## Задание

Анимируй **мяч**, который падает, **отскакивает** и постепенно успокаивается. Главное — правильные кривые в **Graph Editor**: мяч должен **лететь быстро** и **замирать на вершине** (как на стробоскопе с урока), а у пола — резко менять направление.

### Шаги

1. **Мяч:** `Shift+A → Mesh → UV Sphere`, `Shade Smooth`. Подними повыше (`G Z 4`).
2. **Ключи высоты (Z Location):**
   - кадр **1** — мяч вверху (Z=4) → `I → Location`
   - кадр **12** — мяч у пола (Z=0.5) → `I → Location`
   - кадр **24** — мяч снова вверху, но **ниже** (Z=2.5) — отскок слабее → `I`
   - кадр **34** — у пола (Z=0.5) → `I`
   - кадр **42** — низкий подскок (Z=1.2) → `I`
   - кадр **48** — лёг на пол (Z=0.5) → `I`
3. **Открой Graph Editor**, канал **Z Location**, нажми `Home`.
4. **Главное — характер кривой:**
   - В **точках у пола** движение **быстрое и резкое** (мяч ударяется) → сделай ручки этих точек **острыми** (`V → Vector`), получится «галочка» ∨.
   - В **точках на вершинах** мяч **замирает** → ручки **пологие/плавные** (Auto Clamped) — мяч «зависает».
   ✅ Кривая станет похожа на серию «горок», острых внизу и круглых вверху — как на фото стробоскопа.
5. **Бонус — отскок пресетом:** вместо ручной возни выдели пару ключей → `T → Bounce` → `Ctrl+E → Ease Out`.
6. **Бонус — squash & stretch:** у самого пола чуть сплющи мяч (`S Z 0.8`) и поставь ключ Scale — «лепёшка» при ударе, как в мультиках.
7. **Движение вперёд:** добавь ключи **X Location** (мяч катится вбок) — Linear, ведь по горизонтали мяч не тормозит.

## 💡 Подсказки (если что-то забыл)

- **Открыть Graph Editor:** раскладка **Animation** вверху → нижний редактор переключи на **Graph Editor** (иконка кривой).
- **Вписать кривую в экран:** наведи на поле кривых → `Home`.
- **Сменить тип ручки:** выдели точку(и) → **`V`** → Vector (острые, для удара) / Auto Clamped (плавные, для вершины).
- **Сменить интерполяцию:** выдели ключи → **`T`** (Bezier / Bounce / Sinusoidal…).
- **Направление easing:** **`Ctrl+E`** (Ease In / Out / In-Out).
- **Крутизна = скорость:** круто = быстро (у пола), полого = медленно (на вершине).
- **Порядок:** встал на кадр → передвинул мяч → `I`. Не наоборот!
- **Видно мало:** колесо мыши — зум; `Home` — вписать.
- **Затухание:** каждый следующий отскок **ниже** предыдущего (как настоящий мяч теряет энергию).

> 🎾 **Почему именно мяч:** на нём сразу видно, понял ли ты Easing. Ровные «горки» = механический мяч; острые внизу + плавные вверху = **живой**. Сверяйся с фото стробоскопа из урока!

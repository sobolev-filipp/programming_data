# Лайфхак урока 43 — Орбита через Follow Path 🛤🪐

> Заставить планету (или вагонетку, спутник, дрон) бесконечно кружить по орбите можно **без единого ключа вручную** — через **Follow Path**. А скоростью, направлением и стартом управляют три простые настройки.

---

## Базовый рецепт (повтор урока)

1. **Путь:** `Shift+A → Curve → Circle` (или любая кривая) — кольцо-орбита.
2. **Объект:** выдели планету → `Alt+G` (обнулить позицию, чтобы села на путь ровно).
3. **Ограничитель:** Properties → 🔗 → **Add Object Constraint → Follow Path** → **Target =** кривая → ✓ **Follow Curve**.
4. **Запуск:** кнопка **Animate Path** → планета поехала.

---

## Три ручки управления

| Хочу | Где крутить |
|------|-------------|
| **Скорость** (как долго один круг) | выдели **кривую** → Object Data Properties (зелёная иконка) → **Path Animation → Frames** (больше = медленнее) |
| **Старт не с той точки** | в ограничителе Follow Path меняй **Offset** (сдвиг по пути), или поверни саму кривую (`R Z`) |
| **Обратное направление** | поставь **Frames** отрицательными — или разверни кривую: Edit Mode → `Alt+F` / Segments → **Switch Direction** |

> 💡 **Фишка — несколько планет, разные скорости:** каждой планете — **своя кривая-орбита** (дубли `Shift+D`, масштаб `S`) со **своим Frames**. Ближние орбиты — меньше Frames (быстрее), дальние — больше (медленнее). Получается настоящая Солнечная система.

---

## Частые затыки

| Симптом | Причина | Решение |
|---------|---------|---------|
| Объект не на пути, висит сбоку | не обнулена позиция | выделить объект → `Alt+G` |
| Не едет после Animate Path | путь без анимации / Frames=0 | кривая → Path Animation → Frames > 0; нажать Animate Path |
| Объект «лежит» не туда носом | не включён Follow Curve / не та ось | ✓ Follow Curve; в ограничителе Forward/Up оси |
| Едет рывками | кривая неравномерная | у Circle всё ровно; для своей кривой — равные сегменты |

> 💡 **Главная мысль:** Follow Path — это «рельсы» для чего угодно: орбиты, поезда, американские горки, облёт камеры по дуге. Один раз нарисовал путь — и объект катится по нему сам, сколько угодно кругов.

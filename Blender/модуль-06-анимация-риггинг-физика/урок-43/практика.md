# Самостоятельная работа — Урок 43: Гонка и камера-оператор 🏎️🎥

> 🧑‍🎓 Делаешь сам(а). На уроке планеты кружили в космосе — а ты сделаешь **земную** сцену: гоночная машина едет по трассе (**Follow Path**), а **камера-оператор** (или прожектор) всё время держит её в кадре (**Track To**). Те же два ограничителя, но другой объект.

## Задание

Собери мини-сцену гонки:
1. **Машина** (или кораблик/дрон/животное) **едет по трассе-кривой** — Follow Path.
2. **Камера** (или прожектор/«глаз робота») **постоянно смотрит на машину** — Track To.

### Шаги

1. **Трасса:** `Shift+A → Curve → Circle` или `Bezier` → в Edit Mode согни в форму трассы (петля, восьмёрка). Можно `Alt+C`-замкнуть.
2. **Машина:** слепи простую (куб + колёса-цилиндры) или возьми из своих моделей. `Alt+G` (обнулить позицию).
3. **Follow Path:** машине → Properties 🔗 → **Add Object Constraint → Follow Path** → Target = трасса → ✓ **Follow Curve** → **Animate Path**.
4. **Скорость:** трасса → Object Data → **Path Animation → Frames** (короче = быстрее).
5. **Камера-оператор:** камере → 🔗 → **Track To** → Target = **машина** (а не Empty!) → To = −Z, Up = Y. Теперь камера ведёт машину по кругу взглядом.
6. **Проверь:** `Numpad 0` (вид с камеры) → `Пробел`. Машина мчит, камера её «пасёт».

> 🏁 **Бонус:** добавь **второго оператора** — прожектор (Spot) с Track To на ту же машину (свет ведёт гонщика). И/или **второй болид** на своей трассе-дубле с другой скоростью.

---

## Требования

- [ ] Объект (машина/дрон/…) едет по **кривой-трассе** через **Follow Path**
- [ ] **Камера или прожектор** держит объект в прицеле через **Track To**
- [ ] Скорость движения настроена (Path Animation → Frames)
- [ ] Объект сидит **на пути** (не висит сбоку) — не забыл `Alt+G`
- [ ] Сцена проигрывается по `Пробел`; вид с камеры адекватный
- [ ] Файл сохранён

---

## 💡 Подсказки (если что-то забыл)

- **Ограничители живут тут:** Properties → вкладка с иконкой **цепь/косточка 🔗** → **Add Object Constraint**.
- **Объект не на трассе?** Выдели его → **`Alt+G`** (обнулить Location), он сядет на путь.
- **Не едет?** Нажми в Follow Path кнопку **Animate Path**; проверь, что у кривой **Frames > 0**.
- **Носом не туда?** Включи ✓ **Follow Curve**; поиграй осями Forward/Up в ограничителе.
- **Камера заваливается / крутится?** Поменяй **Up** (Y↔Z) в Track To.
- **Камера смотрит мимо?** Проверь, что **Target = машина**, а **To = −Z** (камера смотрит по −Z).
- **Развернуть направление езды:** кривая → Edit Mode → меню Segments → **Switch Direction**; или Frames со знаком минус.
- **Несколько объектов одинаково настроить:** аддон **Copy Attributes** (`Ctrl+C → Copy Constraints`), потом поменяй Target у каждого.

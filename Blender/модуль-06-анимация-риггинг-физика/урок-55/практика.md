# Самостоятельная работа — Урок 55: Мини-сценка из клипов 🎬

> 🧑‍🎓 Делаешь сам(а). Собери **короткую сценку** своего персонажа из **действий-клипов** через NLA: он ведёт себя как «живой» — стоит, идёт, машет, прыгает. Меньше рутины — больше монтажа.

## Задание

Создай **2–4 коротких действия** и **смонтируй** их в NLA в связную сценку (~150–250 кадров): последовательность + повтор + плавный переход.

### Кого анимируем
- Твой **человечек** (риг из уроков 46–50) или **животное** (урок 49) — своя, руками сделанная модель.
- Хочешь новый персонаж — смоделируй простого (робот из боксов, урок 50) и оснасти Rigify.

### Шаги
1. **Сделай клипы** (Action Editor, повтор урока 47/49): напр. `Idle` (лёгкое покачивание), `Ходьба`, `Взмах`, `Прыжок`. Каждый — назови, нажми **F** (Fake User).
2. **Push Down** первый клип в NLA.
3. **Собери сцену** (NLA → Add Action Strip): расставь клипы по очереди (`G`), **повтори** ходьбу (Repeat), при желании **ускорь/замедли** (Scale).
4. **Плавные переходы:** наложи клипы внахлёст на разных дорожках → **Blend In/Out**. Попробуй **Add** (махать на ходу!).
5. Проиграй `Пробел` — сценка идёт без рывков.

> 🎭 Идея сценки: персонаж **стоит** → **идёт** к центру → **машет** зрителю → **прыгает** от радости → **уходит** (та же ходьба ещё раз).

## Требования

- [ ] Создано **2–4 действия**, названы, с **Fake User (F)**
- [ ] Клипы **опущены в NLA** (Push Down / Add Action Strip)
- [ ] Собрана **последовательность** (клипы по очереди)
- [ ] Есть **повтор** одного клипа (Repeat) — переиспользование
- [ ] Есть **плавный переход** (Blend In/Out) хотя бы между двумя клипами
- [ ] Сценка играется по `Пробел` без рывков; файл сохранён

## 💡 Подсказки (NLA)

- **Action Editor:** нижний редактор Dope Sheet → режим **Action Editor**; **New** — новый клип; **F** — не потерять.
- **Новое действие:** New → анимируй (Auto Keying) → переименуй.
- **Push Down** (⤓) — опустить активное действие в дорожку NLA.
- **NLA Editor:** тип редактора **Nonlinear Animation**; **Add → Add Action Strip** — вставить клип.
- **Двигать клип:** выдели полоску → `G`. **Повтор/скорость:** `N → Strip → Playback → Repeat / Scale`.
- **Переход:** наложи клипы внахлёст (разные дорожки) → `N → Blending → Blend In/Out`; **Add** = поверх, **Replace** = вместо.
- **Рывок между клипами:** увеличь Blend In/Out или подвинь стыки.

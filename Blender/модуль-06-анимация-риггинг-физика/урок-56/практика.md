# Самостоятельная работа — Урок 56: ТВОЯ РЕКЛАМА 📺⚡

> 🧑‍🎓 **Итоговый проект Модуля 6** (на несколько занятий / с домашней работой). Ты придумаешь **свой продукт** и снимешь про него **рекламный ролик 10–15 секунд** — с готовым видеофайлом в конце. Здесь собирается **весь модуль**: моделирование, материалы, анимация, камера, свет, эффекты, слоган и — главное — **рендер в видео**. Это репетиция перед дипломом (Модуль 7)!

## Задание

Создать **рекламный видеоролик 10–15 сек** (`.mp4`) про **свой продукт**: продукт красиво показан, камера облетает его, играет эффектный свет, в финале — слоган. Ролик **отрендерить в видео**.

### Придумай свой продукт (НЕ энергетик с урока!)

Продукт с урока — «ВОЛЬТ». Твой — **другой** (чтобы было интересно и честно):

| Категория | Идеи продукта |
|-----------|---------------|
| 📱 Гаджет | смартфон, наушники, умные часы, игровая мышь |
| 👟 Вещь | кроссовок, рюкзак, кепка, часы |
| 🍫 Еда/напиток | шоколадка, мороженое, сок, газировка, пицца |
| 🧸 Игрушка | робот, машинка, конструктор, фигурка |
| 🎮 Игровое | меч, зелье, монета, лут-сундук (переклички с курсом!) |
| 🚗 Транспорт | спорткар, мотоцикл, летающая доска |

Придумай **название бренда** и **слоган** (3–5 слов): «*Название* — *обещание*». Напр.: «ФЕНИКС — обгони ветер», «НИМБ — вкус облаков».

## Этапы (чек-лист проекта)

### Этап 1 — Раскадровка ✏️
Распиши ролик по секундам (что в кадре, какой приём). Без раскадровки — не начинай 3D.

### Этап 2 — Смоделируй продукт (Модули 1–2)
- Собери **сам** из простых форм (Cube/Cylinder/Sphere + **Bevel/Array/Mirror/Inset** — повтор курса). Держи **low-poly**.
- ✅ *Итог:* узнаваемый продукт.

### Этап 3 — Материалы в Shading (Модуль 3)
- Назначь материалы **нодами** (Shading): металл/стекло/пластик/Emission-логотип. Свечение — **Bloom**.
- ✅ *Итог:* продукт выглядит «дорого».

### Этап 4 — Анимация (Модуль 6)
- **Появление** продукта (ключи Scale/`I` + **Easing**, уроки 41–42).
- **Облёт камеры** по кругу (**Follow Path** + **Track To**, урок 43).
- По желанию: **искры/дым** (Particles, урок 52), физика (урок 53), ткань-флажок (урок 54).
- Много действий — собери через **NLA** (урок 55).
- ✅ *Итог:* сцена живёт 10–15 секунд.

### Этап 5 — Свет и слоган (Модуль 4 + текст)
- **Эффектный свет**: Spot-луч + тёмный фон (урок 31).
- **3D-слоган** (Text-объект, Extrude, Emission) — выезжает в финале.
- ✅ *Итог:* кадр как в настоящей рекламе.

### Этап 6 — 🎬 РЕНДЕР В ВИДЕО (главное!)
- **Output Properties**: 1920×1080, **25 fps**, Frame End под длину (10 сек = 250, 15 сек = 375).
- **File Format = FFmpeg Video** → MPEG-4 / H.264 → **Render → Render Animation**.
- *(Длинный/тяжёлый ролик — рендерь кадрами PNG → склей в Video Sequencer, см. [лайфхак.md](лайфхак.md).)*
- ✅ *Итог:* **готовый `.mp4`** — можно показать всем!

## 💡 Подсказки (что повторить)

- **Модель:** Bevel/Array/Mirror/Inset+Extrude (Модули 1–2) — из простых форм.
- **Материалы:** Shading-ноды; стекло — Transmission+IOR (урок 27); свечение — **Emission + Bloom**.
- **Появление:** ключи `I` на Scale + **Ease Out** в Graph Editor (уроки 41–42).
- **Облёт:** камера + Circle → `Ctrl+P → Follow Path`; `Track To` на продукт; скорость = **Path Animation → Frames** (урок 43).
- **Слоган:** `Shift+A → Text`, кириллица — загрузи шрифт в Object Data → Font; Extrude для объёма.
- **Рендер видео:** Output Properties (принтер) → 25 fps → **FFmpeg Video → MPEG-4/H.264** → **Render Animation** (`Ctrl+F12`, НЕ `F12`!).
- **🖥 Слабый ПК:** EEVEE, low-poly, мало частиц + Bake; тест-рендер на 50% и коротком отрезке.

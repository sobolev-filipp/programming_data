# Лайфхак урока 47 — Weight Paint кистью 🎨

> Когда Automatic Weights ошибается (защип в подмышке, палец не двигается, живот едет за рукой) — лечим кистью весов. Вот **пошаговый рецепт**, который решает 90% проблем привязки.

---

## Рецепт «выбрал → красный → синий → сгладил → проверил»

1. **Найди дефект.** Выдели арматуру → **Pose Mode** → согни проблемную кость (рука вверх, нога вперёд). Теперь дефект видно.
2. **Зайди красить.** Выдели меш → режим **Weight Paint**. **`Ctrl`+клик по нужной кости** — выбрать, чьи веса правим (активная группа). Появится её красно-синяя карта.
3. **Добавь влияние (🔴).** Вверху **Weight = 1.0** → закрась **красным** то, что должно двигаться за этой костью (например, забытый палец).
4. **Убери лишнее (🔵).** **Weight = 0.0** (или кисть **Subtract**) → закрась **синим** то, что НЕ должно за ней двигаться (живот, что «прихватило» рукой).
5. **Сгладь переход (Blur).** Кисть **Blur** по границе сустава — резкий скачок 🔴→🔵 превращается в плавный градиент. Это лечит **защипы**.
6. **Проверь позой.** Покрути кость — стало плавно? Нет — повтори шаги 3–5.

---

## Ускорители

| Приём | Зачем |
|-------|-------|
| **Symmetry → Mirror X** (шапка Weight Paint) | красишь левую руку — правая красится зеркально (нужны имена `.L`/`.R`) |
| `F` / `Shift+F` | размер / сила кисти |
| **Weights → Normalize All** | сумма весов каждой вершины = 1 (убирает перекосы, «разъезды») |
| **Weights → Clean** | убрать крошечные мусорные веса |
| **Weights → Smooth** | мягко усреднить веса в выделении (альтернатива Blur) |

---

## Карта «симптом → лечение»

| Симптом | Что делать |
|---------|-----------|
| Защип «фантиком» в подмышке/паху | **Blur** по границе; раздать вес 0.5/0.5 между двумя костями |
| Палец/ухо не двигается | выбрать его кость → Weight 1.0 → закрасить 🔴 |
| Живот/одежда едет за рукой | выбрать кость руки → Weight 0.0 → закрасить 🔵 на животе |
| Сустав «разъезжается» при сгибе | **Normalize All**, затем подкрасить |
| Половина тела кривая, вторая ок | включить **Mirror X** и перекрасить заново |

> 💡 **Главная мысль:** не правь веса «вслепую» в T-позе. **Сначала согни** проблемную кость, чтобы видеть дефект, потом крась: 🔴 добавить, 🔵 убрать, **Blur** сгладить. Проверяй каждое исправление позой. Так привязка доводится быстро и предсказуемо.

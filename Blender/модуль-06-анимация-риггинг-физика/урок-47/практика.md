# Самостоятельная работа — Урок 47: Привяжи кожу к своему скелету 🎨🦾

> 🧑‍🎓 Делаешь сам(а). На уроке мы оживили человечка — а ты **привяжи кожу к своему скелету из урока 46** (настольная лампа / робо-рука / змейка / кран). Те же приёмы: Automatic Weights + Weight Paint, только объект другой и проще.

## Задание

Возьми свой риг из урока 46 и сделай так, чтобы при сгибе костей **меш гнулся вместе с ними**.

### Шаги

1. **Открой** свой файл из урока 46 (объект + скелет-цепочка).
2. **Привязка:** Object Mode → выдели **меш**, потом `Shift`-клик по **арматуре** (активна последней) → `Ctrl+P` → **With Automatic Weights**.
3. **Тест:** выдели арматуру → **Pose Mode** → поверни кость в середине → меш должен согнуться.
4. **Найди дефекты:** где сгиб ломается/защипывает или сегмент «отстаёт».
5. **Почини в Weight Paint:** выдели меш → Weight Paint → `Ctrl`+клик по кости → 🔴 добавить (Weight 1.0), 🔵 убрать (Weight 0.0), **Blur** сгладить.
6. **Доводка:** Weights → **Normalize All**; проверь сгиб в нескольких позах.

> 🐍 Для **змейки/щупальца**: красиво, когда соседние кости влияют на стык 0.5/0.5 — тогда изгиб плавный, «резиновый». Поиграй Blur.

---

## Требования

- [ ] Меш привязан к арматуре (**Automatic Weights**, есть модификатор Armature + Vertex Groups)
- [ ] В Pose Mode меш **гнётся** вслед за костями
- [ ] Найден и **исправлен** хотя бы один дефект в Weight Paint
- [ ] Переходы плавные (нет грубых защипов) — применён **Blur** / Normalize
- [ ] Проверено в 2–3 позах; файл сохранён

> ℹ️ Если объект **очень простой** (мало сегментов) — Automatic Weights может сразу сработать идеально. Тогда покажи, что **понимаешь** карту весов: зайди в Weight Paint и объясни, где красное/синее у каждой кости.

---

## 💡 Подсказки (если что-то забыл)

- **Порядок привязки:** сначала **меш**, потом `Shift`+**арматура** (родитель = активный/последний) → `Ctrl+P → With Automatic Weights`.
- **Тест сгиба:** арматура → **Pose Mode** → `R` на кости; сброс — `Alt+R`.
- **Зайти в Weight Paint:** выдели меш → выпадающий список режимов → **Weight Paint**.
- **Выбрать кость для покраски:** **`Ctrl`+клик** по кости.
- **Цвета:** 🔴 = вес 1 (держит), 🔵 = вес 0 (не держит), 🟢🟡 = частично.
- **Кисть:** Weight (целевой вес сверху), `F` радиус, `Shift+F` сила; **Blur** — сгладить.
- **Меш не гнётся вообще:** проверь, что привязал с **Automatic Weights** (а не Empty/Bone), и что у меша есть модификатор Armature.
- **Часть улетает/мнётся:** убери лишний вес (🔵) у чужой кости, добавь нужный (🔴), Normalize All.

`.blend` + 2–3 кадра: меш в нейтрали и в согнутой позе (+ при желании карта весов). Подпиши, какой дефект чинил и как.

> 💡 **Перекличка:** твоя гибкая лампа/змейка/рука пригодится в итоговом ролике модуля (урок 56) — теперь её можно по-настоящему анимировать.

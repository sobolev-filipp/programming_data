# Самостоятельная работа — Урок 47: Анимируй действие по принципам 🎭

> 🧑‍🎓 Делаешь сам(а). На уроке мы оживили **взмах рукой** — а ты анимируй **другое действие** и примени те же приёмы (позы, anticipation, follow-through, arcs). Персонаж или простой объект — на выбор.

## Задание

Сделай короткую (1–2 сек) анимацию одного **действия**, в которой видны **минимум 2 принципа** движения.

### Идеи (выбери одно)
- 🤸 **Прыжок** — присел (anticipation) → толчок → полёт по дуге → приземление с лёгким «проседанием».
- 🙇 **Поклон / кивок** — голова по дуге, мягкий старт-стоп (Easing).
- ✋ **Подобрать предмет** — рука тянется (дуга) → берёт → возвращается.
- 😮 **Удивление** — резкий вдох-замах назад (anticipation) → подался вперёд.
- 🦾 Простой объект: **пружинка / антенна** качается с инерцией (follow-through).

### Шаги

1. Pose Mode → включи **Auto Keying** (урок 41).
2. Поставь **ключевые позы**: подготовка → действие → завершение (как кадры прыжка Майбриджа).
3. Добавь **anticipation** (замах против движения перед действием).
4. Добавь **follow-through** (часть тела довершает движение по инерции).
5. Проверь **дугу** через **Motion Paths** (Pose → Motion Paths → Calculate) — поправь, если ломаная.
6. Дай ключам **Ease In/Out** в Graph Editor (урок 42).

## 💡 Подсказки (если что-то забыл)

- **Auto Keying** — красный кружок в Timeline: позы пишутся сами при изменении.
- **Ключевая поза вручную:** наведи на вьюпорт → `I → Rotation` (или LocRotScale).
- **Anticipation** — короткий замах **в противоположную** сторону перед действием (присесть перед прыжком).
- **Follow-through** — после остановки дай кончику (кисть/голова/хвост) чуть «доехать» и вернуться.
- **Motion Paths:** Pose → Motion Paths → Calculate; после правок — **Update Paths**.
- **Тайминг:** в **Dope Sheet** двигай/растягивай ключи (`G`/`S`).
- **Easing:** Graph Editor → выдели ключи → `T → Sinusoidal` → `Ctrl+E → Ease In/Out`.
- **Дуга «ломаная»:** приподними среднюю позу или правь ручки в Graph Editor.

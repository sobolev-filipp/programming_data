# Самостоятельная работа — Урок 50: Робот на Rigify 🤖⚡

> 🧑‍🎓 Делаешь сам(а) — **с нуля**. Смоделируй простого **робота-гуманоида** (из боксов) и оживи его **профессиональным ригом Rigify**. Сначала строим (повтор Модулей 1–2), потом — кнопка Generate и удобные контролы.

> 🤖 Робот удобен: тело из коробок-сегментов — легко моделить и легко подгонять мета-риг.

---

## Этап 1 — Моделирование робота (повтор Модулей 1–2)

Собери блочного человекоподобного робота:

| Часть | Как |
|-------|-----|
| **Торс** | Cube → **Bevel** рёбра |
| **Голова** | Cube/сфера + «глаз»-Emission (урок 18) |
| **Руки** | плечо/предплечье/кисть — цилиндры/боксы, шарниры-цилиндры |
| **Ноги** | бедро/голень/стопа — боксы |
| **Детали** | антенна, панель (Inset/Boolean) |

- **Симметрия:** работай с **Mirror**-модификатором (урок 3) — половина сама.
- **Материалы (Shading):** металл корпуса (Metallic+Roughness), цветные «лампочки» Emission.

✅ *Итог:* стоящий человекоподобный робот в Т-позе (руки в стороны — удобно для рига).

---

## Этап 2 — Rigify (навык урока)

1. **Включи Rigify** (Preferences → Add-ons).
2. `Shift+A → Armature → **Human (Meta-Rig)**`. In Front + X-Ray.
3. **Подгони кости** мета-рига в суставы робота (Edit Mode, **X-Axis Mirror**): плечи, локти, запястья, бёдра, колени, щиколотки, шея.
4. **Generate Rig** (Object Data → Rigify). Появится **RIG** с контролами.
5. **Привяжи:** меш → `Shift`-RIG → `Ctrl+P → With Automatic Weights`.

✅ *Итог:* робот позируется за контролы; есть FK/IK-переключатель.

---

## Этап 3 — Оживи (повтор уроков 41–49)

Сделай короткую анимацию робота: **махнуть рукой / шагнуть / кивнуть**:
- ключевые позы (Auto Keying), **Easing** (урок 42);
- **Paste Flipped** для зеркальных движений (урок 49);
- дуги через **Motion Paths** (урок 47).

✅ *Итог:* робот «играет» — машет или шагает.

## 💡 Подсказки (повтори прошлое)

- **Робот = коробки:** торс/конечности — Cube/Cylinder; **Bevel** скруглить; **Mirror** парные части.
- **Т-поза для рига:** руки в стороны — мета-риг легче подгонять.
- **Подгонка мета-рига:** Edit Mode, двигай кости в суставы; включи **X-Axis Mirror** (Options).
- **Generate:** Object Data Properties → раздел **Rigify** → **Generate Rig**. Анимируй **RIG**, не мета-риг.
- **Не гнётся:** привязал к RIG с **Automatic Weights**? защипы — Weight Paint (урок 46).
- **FK/IK:** контрол руки/ноги → `N` → ползунок **IK-FK**.
- **Поправить кости:** правь мета-риг → **Generate снова**.

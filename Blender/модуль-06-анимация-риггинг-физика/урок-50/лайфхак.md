# Лайфхак урока 50 — Rigify за 5 минут ⚡

> Полный профессиональный риг персонажа — за пять шагов. Держи этот чек-лист под рукой: «мета-риг → подгонка → Generate → привязка → анимируй».

---

## Чек-лист (5 шагов)

1. **Включи Rigify:** `Edit → Preferences → Add-ons → «Rigify» → ✅`.
2. **Добавь мета-риг:** `Shift+A → Armature → Human (Meta-Rig)`. Включи **In Front** + **X-Ray**.
3. **Подгони под персонажа** (Edit Mode): двигай кости в суставы (плечи/локти/колени/щиколотки/шея). Включи **X-Axis Mirror** — правишь одну сторону, вторая сама.
4. **Generate:** выдели мета-риг → Object Data → **Rigify → Generate Rig**. Появится объект **`RIG`** с контролами.
5. **Привяжи кожу:** выдели меш, `Shift`-**RIG** → `Ctrl+P → With Automatic Weights`. Готово — позируй за контролы!

✅ *Результат:* проф-риг с IK/FK, пальцами и лицом за минуты.

---

## Важные мелочи

| Момент | Помни |
|--------|-------|
| Анимируешь | **RIG** (контролы), не мета-риг |
| Нужно поправить кости | правь **мета-риг** → **Generate снова** (обновит RIG) |
| FK/IK руки/ноги | ползунок **IK-FK** в `N`-панели контрола (0 FK / 1 IK) |
| Качество сгибов | зависит от **точности костей в суставах** (как урок 46) |
| Меш не гнётся | привязал не к RIG / не Automatic Weights → перепривязать |
| Защипы | поправить **Weight Paint** на DEF-костях (урок 46) |

---

## Когда Rigify, когда вручную

| Персонаж | Риг |
|----------|-----|
| Человек, гуманоид, стандартное существо | **Rigify** (быстро) |
| Животное (есть квадро-/птица-сэмплы Rigify) | **Rigify** сэмпл |
| Необычное (лампа, щупальце, кран, механизм) | **вручную** (уроки 46–48) |

> 💡 **Главная мысль:** Rigify — это «собранный за тебя» риг из того, что ты уже умеешь делать руками. Поэтому и порядок такой: сначала понял механику (46–49), потом жмёшь кнопку (50). Понимание + скорость = профессионализм.

# Каталог модификаторов Blender 4.1

> Модификатор — это «волшебная надстройка» над мешем. Они не ломают исходную геометрию и применяются сверху. Их можно включать/выключать, менять порядок и удалять.

**Как добавить:** выделить объект → вкладка 🔧 (Modifier Properties) → «Добавить модификатор»

---

## Generate (Генерирующие)

Эти модификаторы **добавляют** геометрию к объекту.

---

### 🔲 Array (Массив)

**Что делает:** создаёт копии объекта по заданному направлению и расстоянию.

**Когда использовать:**
- Забор из досок
- Ступени лестницы
- Цепочка, гусеница танка
- Орнамент, паттерн

**Основные параметры:**
| Параметр | Что делает |
|----------|----------|
| Count | Количество копий |
| Relative Offset | Смещение относительно размера объекта (1.0 = вплотную) |
| Constant Offset | Смещение в единицах Blender |
| Object Offset | Смещение и вращение по пустому объекту (Empty) |

**Лайфхак:** используй **Object Offset** с пустым объектом-вращателем чтобы сделать расставленные по кругу объекты (например, зубья шестерни).

---

### 🪞 Mirror (Зеркало)

**Что делает:** зеркально отражает меш по выбранной оси.

**Когда использовать:**
- Симметричные объекты: лицо, машина, меч, дом
- Лепить только половину — Mirror делает вторую

**Основные параметры:**
| Параметр | Что делает |
|----------|----------|
| X / Y / Z | Ось отражения |
| Bisect | Обрезать меш по оси перед отражением |
| Flip | Отразить в другую сторону |
| Mirror Object | Зеркалить относительно другого объекта |
| Clipping | Не давать вершинам пересекать ось (важно для швов!) |

**Лайфхак:** включи **Clipping** когда моделируешь симметричный объект — вершины на оси симметрии не разойдутся.

---

### 📐 Subdivision Surface (Сглаживание, SubSurf)

**Что делает:** делит каждую грань на 4, многократно сглаживая объект.

**Когда использовать:**
- Органические формы (персонажи, животные, фрукты)
- Скруглить углы
- Hard-surface моделирование с мягкими изгибами

**Основные параметры:**
| Параметр | Что делает |
|----------|----------|
| Levels Viewport | Уровень сглаживания в viewport |
| Levels Render | Уровень при рендере (обычно выше) |
| Catmull-Clark | Стандартный алгоритм (используй его) |
| Simple | Делит без сглаживания |

**Лайфхак:** добавь Loop Cut (`Ctrl + R`) рядом с углом — SubSurf оставит его острым. Чем ближе петли, тем острее угол.

> ⚠️ Уровень 3+ очень нагружает слабый компьютер. Используй 1–2 в viewport.

---

### 🧱 Solidify (Придание толщины)

**Что делает:** добавляет толщину плоскому меша.

**Когда использовать:**
- Стены из плоского прямоугольника
- Лезвие меча
- Листья, крылья
- Крышки и панели

**Основные параметры:**
| Параметр | Что делает |
|----------|----------|
| Thickness | Толщина |
| Offset | Направление (-1 внутрь, +1 наружу, 0 по центру) |
| Fill Rim | Заполнить торцы |

---

### 🌀 Screw (Винт/Штопор)

**Что делает:** вращает профиль (кривую или плоский меш) вокруг оси, создавая объект вращения.

**Когда использовать:**
- Вазы, кувшины, бутылки
- Болты, спирали
- Пружины (Screw + угол)
- Лестничные перила

**Основные параметры:**
| Параметр | Что делает |
|----------|----------|
| Angle | Угол вращения (360° = полный круг) |
| Screw | Смещение вдоль оси за один оборот (для пружины) |
| Steps | Количество шагов (больше = плавнее) |
| Iterations | Количество оборотов |

**Лайфхак:** создай полуокружность из вершин, добавь Screw 360° — получишь идеальную сферу/тор.

---

### 📡 Bevel (Фаска)

**Что делает:** скругляет или срезает рёбра объекта.

**Когда использовать:**
- Реалистичные объекты (у них нет идеально острых углов)
- Hard-surface детали
- После Boolean операций

**Основные параметры:**
| Параметр | Что делает |
|----------|----------|
| Amount | Размер фаски |
| Segments | Количество сегментов (больше = плавнее) |
| Profile | Форма профиля фаски |
| Limit Method → Angle | Применять только к острым углам |

---

### 🔗 Boolean (Булевы операции)

**Что делает:** вычитает, складывает или пересекает два меша.

**Когда использовать:**
- Вырезать отверстие (иллюминатор, окно, кнопка)
- Соединить два объекта в один
- Сложные пересекающиеся формы

**Режимы:**
| Режим | Действие |
|-------|---------|
| Union (Объединение) | Складывает два меша в один |
| Difference (Разность) | Вычитает один меш из другого |
| Intersect (Пересечение) | Оставляет только область пересечения |

**Лайфхак:** используй аддон **Bool Tool** (встроен, надо включить) — он ускоряет Boolean в разы.

---

### 📋 Geometry Nodes

**Что делает:** процедурная система — создаёт геометрию через визуальные ноды.

**Когда использовать:**
- Расставить деревья/камни/траву
- Создать процедурный паттерн
- Анимированные паттерны

*(Отдельные уроки в Модуле 2)*

---

## Deform (Деформирующие)

Эти модификаторы **деформируют** существующую геометрию.

---

### 〰️ Simple Deform (Простая деформация)

**Что делает:** изгибает, скручивает, растягивает объект.

**Режимы:**
- **Twist** — скрутить (штопор, тюбик)
- **Bend** — согнуть (банан, дуга)
- **Taper** — сузить к концу
- **Stretch** — растянуть

---

### 🌊 Wave (Волна)

**Что делает:** добавляет волновую анимацию.

**Когда использовать:** вода, флаг на ветру, пульсирующие поверхности.

---

### 📦 Lattice (Решётка)

**Что делает:** деформирует объект через управляющую решётку.

**Когда использовать:** изменить форму высокополигональной модели без редактирования каждой вершины.

---

### 🪝 Hook (Крюк)

**Что делает:** привязывает группу вершин к объекту-контроллеру.

**Когда использовать:** анимация деформаций (например, персонаж открывает рот).

---

## Generate (Специальные)

---

### 🔻 Decimate (Упрощение)

**Что делает:** уменьшает количество полигонов.

**Когда использовать:**
- Оптимизация для игры
- Упрощение скульптурной модели
- Low-poly стиль из high-poly

**Режимы:**
| Режим | Когда |
|-------|-------|
| Collapse | Общее упрощение (обычно используй его) |
| Un-Subdivide | Отменить Subdivision |
| Planar | Убрать лишние вершины на плоских гранях |

---

### 🧹 Remesh (Перетопология)

**Что делает:** пересчитывает топологию меша.

**Когда использовать:** после скульптинга, чтобы получить чистую сетку.

---

### 🔧 Weld (Сварка)

**Что делает:** сливает близкие вершины.

**Когда использовать:** после Boolean, при импорте объектов с дублирующимися вершинами.

---

### 💪 Armature (Арматура)

**Что делает:** деформирует меш по костям скелета.

**Когда использовать:** риггинг персонажей, анимация. *(Модуль 5)*

---

### 🎭 Multires (Мультирезолюция)

**Что делает:** как SubSurf, но позволяет скульптить на каждом уровне отдельно.

**Когда использовать:** скульптинг с последующим запеканием Normal Map.

---

## Порядок модификаторов (важно!)

Порядок в стеке **критически важен**. Каждый модификатор получает результат предыдущего.

**Типичный правильный порядок:**
```
1. Mirror
2. Array
3. Boolean
4. Solidify
5. Bevel
6. Subdivision Surface
```

> ⚠️ SubSurf всегда идёт **последним** — он сглаживает финальный результат.  
> ⚠️ Mirror должен быть **перед** Boolean — иначе зеркало не отразит вырезанные отверстия.

---

## Apply — применить модификатор

Нажми `Ctrl + A` на модификаторе или кнопку **▾ Apply** чтобы «запечь» его в меш.

> ⚠️ После Apply изменить настройки уже нельзя! Применяй только когда уверен в результате.

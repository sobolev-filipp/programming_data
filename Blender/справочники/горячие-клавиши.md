# Горячие клавиши Blender 4.1

> Распечатай и держи рядом! Эти сочетания сэкономят тебе сотни часов.

---

## Навигация в 3D Viewport

| Клавиша | Действие |
|---------|----------|
| `Колёсико мыши` | Приближение / удаление |
| `Средняя кнопка мыши` (зажать) | Вращение вида |
| `Shift + СКМ` | Перемещение вида (Pan) |
| `Numpad 1` | Вид спереди (Front) |
| `Numpad 3` | Вид сбоку (Right) |
| `Numpad 7` | Вид сверху (Top) |
| `Numpad 5` | Переключить перспективу / ортографию |
| `Numpad 0` | Вид с камеры |
| `Numpad .` | Сфокусироваться на выделенном объекте |
| `Numpad /` | Изолировать выделенный объект |
| `Ctrl + Numpad 1` | Вид сзади |
| `Ctrl + Numpad 3` | Вид слева |
| `~` (тильда) | Меню Вид (Pie Menu) |
| `Z` | Меню режимов отображения (Pie Menu) |

---

## Выделение

| Клавиша | Действие |
|---------|----------|
| `ЛКМ` | Выделить объект/элемент |
| `A` | Выделить всё / снять выделение |
| `Alt + A` | Снять всё выделение |
| `B` | Рамочное выделение |
| `C` | Круглое выделение (скролл = размер) |
| `Ctrl + ЛКМ` | Лассо-выделение |
| `Shift + ЛКМ` | Добавить к выделению |
| `Ctrl + I` | Инвертировать выделение |
| `L` | Выделить связанное (в Edit Mode) |
| `Alt + ЛКМ на ребре` | Выделить Edge Loop |
| `Ctrl + Alt + ЛКМ на ребре` | Выделить Edge Ring |

---

## Трансформации (Object Mode и Edit Mode)

| Клавиша | Действие |
|---------|----------|
| `G` | Переместить (Grab) |
| `G → X / Y / Z` | Переместить по оси |
| `G → Shift+X` | Переместить по плоскости YZ (кроме X) |
| `R` | Вращать |
| `R → X / Y / Z` | Вращать вокруг оси |
| `R → R` | Вращать в плоскости экрана |
| `S` | Масштабировать |
| `S → X / Y / Z` | Масштабировать по оси |
| После G/R/S: ввод числа | Точное значение (например `G Z 2`) |
| `Ctrl` (во время трансформации) | Шаг = 1 единица (Snap) |
| `Shift` (во время трансформации) | Точная корректировка |
| `Ctrl + Z` | Отменить |
| `Ctrl + Shift + Z` | Повторить |

---

## Объекты (Object Mode)

| Клавиша | Действие |
|---------|----------|
| `Shift + A` | Добавить объект |
| `X` или `Delete` | Удалить |
| `D` | Дублировать (копия со своими данными) |
| `Alt + D` | Дублировать (связанная копия, Linked) |
| `Ctrl + A` | Apply (применить трансформации) |
| `Ctrl + J` | Объединить объекты (Join) |
| `P` | Разделить объект (Separate, в Edit Mode) |
| `M` | Переместить в коллекцию |
| `H` | Скрыть объект |
| `Alt + H` | Показать все скрытые |
| `Numpad .` | Сфокусироваться |
| `F3` | Поиск команды |
| `N` | Открыть/закрыть панель свойств |
| `T` | Открыть/закрыть Toolbar |

---

## Edit Mode

| Клавиша | Действие |
|---------|----------|
| `Tab` | Переключить Object ↔ Edit Mode |
| `1` | Режим вершин (Vertex) |
| `2` | Режим рёбер (Edge) |
| `3` | Режим граней (Face) |
| `E` | Extrude (выдавить) |
| `E → E` | Extrude по нормали |
| `I` | Inset Faces (вставить грань внутрь) |
| `Ctrl + R` | Loop Cut — добавить петлю |
| `Ctrl + B` | Bevel — скосить ребро/вершину |
| `V` | Rip — разорвать меш |
| `F` | Создать ребро/грань из выделенного |
| `K` | Knife — нож |
| `Alt + M` | Merge (слить вершины) |
| `M` | Merge (в Edit Mode) |
| `Ctrl + M` | Mirror (отразить) |
| `O` | Proportional Editing вкл/выкл |
| `Ctrl + L` | Выделить связанный меш |
| `Shift + N` | Пересчитать нормали |
| `Alt + N` | Меню нормалей |

---

## Режимы и панели

| Клавиша | Действие |
|---------|----------|
| `Ctrl + Tab` | Меню выбора режима (Pie Menu) |
| `Ctrl + Space` | Развернуть / свернуть окно |
| `Shift + Space` | Меню инструментов |
| `F9` | Последнее действие (F-9 Panel) |
| `G, G` (два раза) | Slide Edge/Vertex вдоль ребра |
| `Ctrl + F` | Меню операций с гранями |
| `Ctrl + E` | Меню операций с рёбрами |
| `Ctrl + V` | Меню операций с вершинами |

---

## UV Editor

| Клавиша | Действие |
|---------|----------|
| `A` | Выделить всё |
| `G / R / S` | Трансформации (как в 3D) |
| `U` | Меню развёртки (в Edit Mode) |
| `Ctrl + A` | Align (выровнять) |
| `V` | Stitch (сшить) |

---

## Рендер и камера

| Клавиша | Действие |
|---------|----------|
| `F12` | Рендер кадра |
| `Ctrl + F12` | Рендер анимации |
| `Numpad 0` | Вид с камеры |
| `Ctrl + Numpad 0` | Сделать текущий вид камерой |
| `G → G` (в виде камеры) | Перемещение камеры в виде камеры |

---

## Анимация

| Клавиша | Действие |
|---------|----------|
| `I` | Вставить ключевой кадр (Keyframe) |
| `Space` | Запустить / остановить анимацию |
| `Shift + Left` | Первый кадр |
| `Shift + Right` | Последний кадр |
| `Left / Right` | Предыдущий / следующий кадр |
| `Alt + I` | Удалить ключевой кадр |

---

## Быстрые советы

> 💡 **Не знаешь как называется действие?** Нажми `F3` и введи что хочешь по-английски — Blender найдёт!

> 💡 **Провалился внутрь меша?** Нажми `Alt + H` чтобы показать скрытую геометрию.

> 💡 **Потерял объект?** Нажми `A` чтобы выделить всё, затем `Numpad .` чтобы сфокусироваться.

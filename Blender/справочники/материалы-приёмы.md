# Материалы: быстрые приёмы и шпаргалка

> Как назначать материалы быстро — на много объектов и на отдельные полигоны, без рутины «выдели-назначь» по одному. Плюс полезные мелочи о материалах.

---

## 1. Один материал на НЕСКОЛЬКО ОБЪЕКТОВ

### Link Materials (`Ctrl + L`) ⭐ — главный приём

1. Выдели объекты, которым нужен материал
2. **Последним** (с `Shift`) выдели объект, у которого материал **уже есть** (он станет «активным», подсветится ярче)
3. `Ctrl + L → Link Materials`
4. Материал мгновенно скопировался на **все** выделенные объекты!

> 💡 Активный объект (ярко-оранжевый) — «донор». Все остальные получают его материал. Так за 1 секунду красишь хоть 100 объектов.

### Переиспользование материала (общий datablock)

В списке материалов нажми не «New», а **шарик-кнопку слева** → выбери уже созданный материал.
- Объекты делят **один и тот же** материал
- Поменяешь его у одного — изменится у всех (это и плюс, и осторожность!)

---

## 2. Один материал на ЧАСТЬ ПОЛИГОНОВ (внутри объекта)

Объекту можно дать несколько материалов и раздать их разным граням.

1. Material Properties → **+** добавь второй слот → **New** (или выбери существующий)
2. `Tab` → Edit Mode → выдели нужные грани
3. Нажми **Assign** — выделенные грани получили этот материал

**Кнопки слотов (Edit Mode):**
| Кнопка | Что делает |
|--------|-----------|
| **Assign** | назначить материал слота выделенным граням |
| **Select** | выделить все грани с этим материалом |
| **Deselect** | снять выделение с граней этого материала |

> 💡 **Select** удобен, чтобы потом перекрасить: нажал Select у слота → все его грани выделены → меняй.

---

## 3. Быстрое ВЫДЕЛЕНИЕ нужных граней

Чтобы не тыкать грани по одной:

| Приём | Клавиши | Что выделяет |
|-------|---------|--------------|
| **Select Linked** | навести + `L` | связанный кусок меша (например, всю крышку) |
| **Select All Linked** | `Ctrl + L` (в Edit Mode) | связанное с уже выделенным |
| **Select Similar** | `Shift + G` | похожие грани: по нормали, по материалу, по площади, копланарные |
| **Select by Material** | кнопка Select в слоте | все грани с данным материалом |
| Петля/кольцо | `Alt+ЛКМ` / `Ctrl+Alt+ЛКМ` | петлю/кольцо рёбер |

> 💡 **Select Similar (`Shift+G`) → Normal** — выделит все грани, смотрящие в ту же сторону (например, все «верхние» грани крыш). Дальше один Assign — и все крыши покрашены.

> 💡 **Select Similar → Material** — выделит все грани с тем же материалом во всём объекте. Удобно перекрашивать.

---

## 4. Копирование материала между объектами

- **Меню материалов** (стрелка вниз ⌄ рядом со списком) → **Copy Material** / **Paste Material**
- Или `Ctrl + L → Link Materials` (см. выше — быстрее для многих)

---

## 5. Полезные мелочи о материалах

### Random-цвет: один материал — разные цвета! ⭐
Хочешь, чтобы у сотни астероидов/деревьев был **разный оттенок одним материалом**?
1. В Shader Editor: `Input → Object Info`
2. **Object Info [Random]** → в **ColorRamp** → в Base Color
3. Каждый объект получит свой случайный цвет из градиента. Один материал — вся пёстрая толпа!

### Fake User (щит 🛡)
Материал без объекта Blender удаляет при сохранении. Нажми **щит** рядом с именем — материал сохранится в файле даже неиспользуемый (полезно для библиотеки).

### Имена материалов
Называй материалы понятно («Металл_корпус», «Стекло_окна») — в большой сцене спасает.

### Цвет во вьюпорте (Viewport Display)
В Material Properties → **Viewport Display → Color** задаёт цвет для режима Solid (когда материалы не показываются). Удобно различать объекты.

### Make Single User
Если материал общий, а нужно изменить только у одного объекта — нажми число рядом с именем материала (например «2») → материал станет отдельной копией.

## Шпаргалка

| Хочу | Делаю |
|------|-------|
| Один материал на много объектов | выделить все → активным донор → `Ctrl+L → Link Materials` |
| Общий материал (меняется у всех) | шарик-кнопка → выбрать существующий |
| Материал на часть граней | слот → грани → **Assign** |
| Выделить все грани материала | слот → **Select** |
| Выделить похожие грани | `Shift+G` (Normal / Material / Area) |
| Выделить связанный кусок | навести + `L` |
| Разные цвета одним материалом | Object Info [Random] → ColorRamp → Base Color |
| Сохранить материал без объекта | щит (Fake User) |

> 💡 **Главная мысль:** не крась по одному. Сначала **быстро выдели** (Shift+G / L / Select), потом **один раз назначь** (Assign / Ctrl+L). Это экономит часы.

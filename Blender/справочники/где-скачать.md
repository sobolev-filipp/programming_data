# Где скачать ассеты — текстуры, HDRI, модели, аддоны

> Все ресурсы ниже **бесплатные** и безопасные для учебного использования.  
> Уроки ссылаются сюда, когда для проекта нужны внешние материалы.

---

## 🖼 Текстуры (PBR: цвет, шероховатость, нормали)

| Сайт | Что есть | Регистрация | Ссылка |
|------|----------|-------------|--------|
| **Poly Haven** ⭐ | Текстуры, HDRI, модели — всё CC0 (бесплатно даже для коммерции) | Не нужна | [polyhaven.com/textures](https://polyhaven.com/textures) |
| **ambientCG** ⭐ | Огромная база PBR-текстур, всё CC0 | Не нужна | [ambientcg.com](https://ambientcg.com) |
| **Texture.ninja** | Фото-текстуры | Не нужна | [texture.ninja](https://texture.ninja) |
| **Texture Haven** | (теперь часть Poly Haven) | — | см. Poly Haven |

> 💡 **Как скачивать с Poly Haven:** выбери текстуру → справа выбери разрешение (для слабых ПК бери **1K** или **2K**, не 4K/8K!) → скачай ZIP → распакуй. Внутри будут файлы: `_diff` (цвет), `_rough` (шероховатость), `_nor_gl` (нормали), `_ao` (затенение).

## 🌍 Текстуры планет (Земля, Луна, Марс, Юпитер)

| Сайт | Что есть | Ссылка |
|------|----------|--------|
| **Solar System Scope** ⭐ | Карты всех планет: цвет + **карты высот (bump/displacement)** для Земли, Луны, Марса, Юпитера… | [solarsystemscope.com/textures](https://www.solarsystemscope.com/textures/) |
| **NASA 3D Resources** ⭐ | Официальные текстуры и 3D-модели планет, Луны, аппаратов | [science.nasa.gov/3d-resources](https://science.nasa.gov/3d-resources/) |
| **NASA Visible Earth** | Реальные спутниковые карты Земли (Blue Marble) | [visibleearth.nasa.gov](https://visibleearth.nasa.gov) |
| **NASA CGI Moon Kit** | Карты Луны очень высокого разрешения (цвет + рельеф) | [svs.gsfc.nasa.gov/4720](https://svs.gsfc.nasa.gov/4720) |

> 💡 **Какие карты качать для планеты/Луны:**
> - **Color / Day Map** — цвет поверхности → в **Base Color**
> - **Bump / Displacement / Height Map** (серая) — рельеф → в **Bump** или **Displacement** (поставь **Non-Color**!)
> - для Земли ещё: **Night Map** (огни городов → Emission), **Clouds** (облака), **Specular/Water** (блик океана)
>
> 🌕 **Луна:** на Solar System Scope в разделе **Moon** есть `Moon Color Map` и `Moon Displacement Map` (это и есть bump). Бери **2K** для слабых ПК.

## ⚠️ Правила скачивания для урока

1. **Бери низкое разрешение** (1K–2K) — компьютеры в классе слабые, 4K/8K их «убьют».
2. **Проверяй лицензию:** CC0 = можно всё, CC-BY = нужно указать автора.
3. **Складывай ассеты рядом с .blend файлом** — иначе Blender «потеряет» текстуры. Лучше: `File → External Data → Pack Resources` (упаковать всё внутрь .blend).
4. Заранее скачай нужные ассеты **до урока** и положи в общую папку класса — не трать время урока на скачивание.

# 📚 Глубокое погружение — Шейдерные ноды: как читать и строить сети

> **Ноды** — это «схема», по которой Blender рисует материал: коробочки соединены проводами, данные текут **слева направо** и приходят в **Material Output**. Уроки 18–29 строили материалы нодами; здесь — полная картина: как понимать сокеты, из чего собирать сети и не соединять вслепую. Всё — в раскладке **Shading** (Shader Editor).

> 💡 Аддон **Node Wrangler** (`Edit → Preferences → Add-ons`) — обязателен: `Ctrl+T` (добавить Texture Coordinate+Mapping к текстуре), `Ctrl+Shift+ЛКМ` по ноде (предпросмотр), `Ctrl+Shift+T` (набор PBR-карт сразу). См. [аддоны](../аддоны.md).

---

## 1. Сокеты = типы данных (по цвету провода)

Главное правило: **цвет кружка-сокета говорит, ЧТО по нему течёт**. Соединяй похожее с похожим.

| Цвет | Тип данных | Что это | Примеры |
|------|-----------|---------|---------|
| 🟡 **Жёлтый** | Color | цвет (RGB) | Base Color, выход Image Texture |
| ⚪ **Серый** | Float (число) | одно значение 0…1 или больше | Roughness, Metallic, Fac, Strength |
| 🟣 **Фиолетовый** | Vector | направление/координаты (3 числа) | Normal, координаты, Mapping |
| 🟢 **Зелёный** | Shader | «готовый материал» (как считать свет) | выход Principled/Emission/Glass |

> 🧠 **Под капотом:** Blender можно «подмешать» число в цветной вход (серое→жёлтый превратится в оттенок серого) — это законно. А вот **Shader (зелёный)** нельзя воткнуть в Color: это разные сущности («готовый материал» vs «цвет»). Если провод **не тянется** — почти всегда перепутал тип сокета.

> ⚠️ Частая ошибка: воткнуть **цветную карту (Color)** в вход, который ждёт **число** (Roughness), и наоборот. Работать будет, но результат странный. Смотри на цвет сокета.

## 2. Principled BSDF — «universal» материал по входам

Один нод покрывает 90% материалов. Разбор ключевых входов (Blender 4.1, Principled v2):

| Вход | Тип | Что делает | Значения-ориентиры |
|------|-----|-----------|--------------------|
| **Base Color** | 🟡 | основной цвет/альбедо | для металла — цвет отражения |
| **Metallic** | ⚪ | металл ли это | 0 = диэлектрик, 1 = металл (промежуток — редко) |
| **Roughness** | ⚪ | шероховатость (микрофасеты) | 0 = зеркало, 1 = матовое |
| **IOR** | ⚪ | преломление; правит **силу блика** | стекло 1.45, вода 1.33 (нет ползунка Specular!) |
| **Transmission** | ⚪ | прозрачность (стекло/вода) | 1 = насквозь. Это НЕ Alpha! |
| **Emission Color / Strength** | 🟡/⚪ | собственное свечение | Strength 2–5 + Bloom |
| **Alpha** | ⚪ | непрозрачность пикселя | для дырок по маске (листва) |
| **Normal** | 🟣 | «наклон» микроповерхности | сюда идёт Normal Map |
| **Coat / Sheen / Subsurface** | ⚪ | лак / ворс ткани / просвет кожи | тонкая доводка |

> 💡 **Металл vs не-металл — главная развилка.** Metallic = 0: цвет в Base Color, блик по IOR. Metallic = 1: Base Color = цвет **отражения** (золото жёлтое, хром серый), диффузного цвета нет. Подробнее — [урок 24, карты PBR].

## 3. Ноды-«перемешиватели» (самые частые)

| Нод | Аналогия | Что делает | Ключевые сокеты |
|-----|----------|-----------|-----------------|
| **Mix Color** | смеситель красок | смешивает два цвета/карты по **Fac** | Fac (⚪), A/B (🟡) → Result |
| **ColorRamp** | градиент-полоса | превращает число (0…1) в **цвет по шкале** | Fac (⚪) → Color; двигай флажки |
| **Math** | калькулятор | операции над числами (Multiply/Add/Greater Than…) | Value+Value → Value |
| **Bump** | «псевдо-рельеф» | из карты высот делает наклон нормали (дёшево) | Height (⚪) → Normal (🟣) |
| **Normal Map** | «настоящий рельеф» | читает синюю карту нормалей | Color (🟡, Non-Color) → Normal (🟣) |
| **Mix Shader** | развилка материалов | смешивает **два шейдера** (напр. металл+ржавчина) | Fac + Shader/Shader (🟢) |

> 🧠 **ColorRamp — король процедурных материалов:** любая текстура даёт «серое поле» (число). ColorRamp раскрашивает его: чёрное→один цвет, белое→другой, с плавным/резким переходом. Так из шума рождаются планеты, ржавчина, карты масок.

## 4. Как ЧИТАТЬ чужую сеть (и свою)

1. Найди **Material Output** (крайний справа) — это финиш.
2. Иди **справа налево**: что воткнуто в Surface? (обычно Principled/Mix Shader).
3. Смотри, что кормит **важные входы** (Base Color, Roughness, Normal) — оттуда тянутся текстуры.
4. Слева обычно **Texture Coordinate → Mapping** — «система координат» (см. [процедурные текстуры](процедурные-текстуры.md)).

> 🔬 **Проверь сам:** возьми готовый материал в **BlenderKit**, открой Shader Editor и «прочитай» его справа налево. `Ctrl+Shift+ЛКМ` (Node Wrangler) по любому ноду — увидишь, что он выдаёт. Так учатся быстрее всего — разбирая готовое (урок 18).

## 5. Порядок и удобство

| Приём | Как | Зачем |
|-------|-----|-------|
| **Node Wrangler `Ctrl+T`** | на выделенной текстуре | сразу добавляет Coord+Mapping |
| **Frame (рамка)** | `Ctrl+J` вокруг группы | подписать блок сети |
| **Reroute (точка)** | `Shift+ПКМ` по проводу | аккуратно развести провода |
| **Node Group** | `Ctrl+G` | свернуть кусок сети в один нод (переиспользовать) |
| **Mute** | `M` на ноде | временно отключить (сравнить с/без) |
| **Отключить/подключить** | тянуть провод | всё пересчитывается сразу |

## 6. Частые проблемы и решения

| Симптом | Причина | Решение |
|---------|---------|---------|
| Провод не тянется | разные типы сокетов | соединяй похожий тип (цвет кружка) |
| Карта Roughness/Normal «пересвечена» | стоит sRGB вместо Non-Color | у Image Texture → Color Space = **Non-Color** |
| Normal Map не работает | воткнули Color прямо в Normal | через нод **Normal Map** (и Non-Color) |
| Стекло чёрное/странное | Transmission без толщины/в EEVEE без настроек | добавь толщину; в EEVEE включи Refraction |
| Материал «плоский» | нет вариаций Roughness | подмешать текстуру/шум в Roughness |
| Свечение без сияния | нет Bloom | Render Properties → Bloom ✅ |

## 7. Мини-практика

1. Собери простой материал: `New` → покрути Base Color/Metallic/Roughness — почувствуй каждый вход.
2. Добавь **Noise Texture → ColorRamp → Base Color** — процедурные пятна.
3. Тот же Noise воткни в **Roughness** — блик «заиграет» неравномерно.
4. Сделай **Mix Shader**: Principled (металл) + Principled (ржавчина), Fac от Noise — материал «состарился».
5. Открой материал из BlenderKit и **прочитай** его справа налево.

> 💡 **Главная мысль:** ноды — не магия, а схема потока данных. Знаешь **типы сокетов** (цвет=тип) и роль ключевых нодов (Mix/ColorRamp/Math/Bump) — читаешь и строишь любой материал осознанно, а не «тыкая провода».

# 📚 Глубокое погружение — Выделение: вершины, рёбра, грани

> Выделение — это **половина моделирования**. Кто умеет быстро и точно выделять нужное, тот лепит вдвое быстрее. Здесь — **все** способы, горячие клавиши и хитрости, плюс типичные трудности и как их обойти. Работает в **Edit Mode** (`Tab`).

---

## 0. Три режима выделения

В Edit Mode вверху слева — три кнопки (или клавиши):

| Клавиша | Режим | Когда |
|---------|-------|-------|
| `1` | **Вершины** (Vertex) | точная правка формы, перемещение точек |
| `2` | **Рёбра** (Edge) | петли, фаски, швы (Mark Seam), Loop Cut |
| `3` | **Грани** (Face) | выдавливание (Extrude), назначение материалов, UV |

> 💡 Можно переключаться **на лету**: выделил петлю рёбер → нажми `3` → выделятся грани между ними. Режимы «перетекают» друг в друга.

---

## 1. База: клик и наборы

| Действие | Клавиши |
|----------|---------|
| Выделить один элемент | `ЛКМ` |
| Добавить/убрать из выделения | `Shift+ЛКМ` (повторный клик — снять) |
| **Выделить всё** | `A` |
| **Снять всё** | `Alt+A` (или дважды `A` в старых сборках) |
| **Инвертировать** (выделить наоборот) | `Ctrl+I` |
| Выделить **больше** (нарастить кайму) | `Ctrl+Numpad +` |
| Выделить **меньше** (сузить) | `Ctrl+Numpad −` |

---

## 2. Рамкой, кругом, лассо (выделить много сразу)

| Способ | Как | Нюанс |
|--------|-----|-------|
| **Box (рамка)** | `B`, тянуть прямоугольник | классика для «всё в области» |
| **Circle (кисть)** | `C`, водить мышью; колесо — размер; ПКМ/Esc — выйти | `ЛКМ` рисует выделение, `Shift`+водить — стирает |
| **Lasso (петля от руки)** | `Ctrl+ЛКМ` обвести | удобно для неровных зон |
| Просто провести `ЛКМ` (Tweak) | потащить по пустоте | рамкой-выделение по умолчанию |

> ⚠️ **Главная трудность — выделяется только передняя сторона.** По умолчанию рамка/круг берут лишь видимые элементы. Чтобы захватить **насквозь** (и заднюю стенку) — включи **X-Ray** (`Alt+Z`) перед выделением. Это ошибка №1 у новичков: «почему выделилась только половина куба» — потому что X-Ray выключен.

---

## 3. Петли и кольца (сила Edge-режима)

| Способ | Как | Что выделит |
|--------|-----|-------------|
| **Loop (петля)** | `Alt+ЛКМ` по ребру | кольцо рёбер вокруг формы (вдоль) |
| **Ring (кольцо)** | `Ctrl+Alt+ЛКМ` по ребру | поперечные рёбра (поперёк петли) |
| **Loop граней** | `Alt+ЛКМ` в Face-режиме | полоса граней |
| **Shortest Path (кратчайший путь)** | выделить элемент → `Ctrl+ЛКМ` по другому | выделит дорожку между ними |
| Добавить петлю к выделению | `Shift+Alt+ЛКМ` | несколько петель разом |

> 💡 **Фишка — куда навести при `Alt+клик`:** Blender смотрит, **вдоль какого ребра** ты кликнул. Наведёшь вдоль «трубы» — петля пойдёт по кругу; наведёшь поперёк — по длине. Чуть промахнулся направлением — петля пойдёт не туда; целься точнее.

> ⚠️ **Петля «обрывается» на треугольниках и полюсах.** Loop Select идёт только по «чистым» четырёхугольникам (quad). Где сходятся 3 или 5 рёбер (полюс) или есть треугольник — петля останавливается. Это не баг, а свойство сетки (подробнее — в гайде «Топология»).

## 4. Умное выделение по признаку

### Select Similar — `Shift+G`
Выделить **похожие** на активный элемент. Меню зависит от режима:
- **Грани:** по **нормали** (смотрят в ту же сторону), **площади**, **материалу**, **числу сторон** (копланарность), perimeter.
- **Рёбра:** по длине, направлению, числу граней у ребра, **острому углу (Sharp)**, шву (Seam), bevel weight.
- **Вершины:** по числу рёбер, по группе вершин (Vertex Group).

> Пример: выдели одну грань крыши → `Shift+G → Normal` → выделятся все грани, смотрящие так же (весь скат). Удобно красить/выдавливать.

### Select All by Trait (Select → All by Trait)
- **Loose Geometry** — «висящие» точки/рёбра без граней (мусор для чистки).
- **Interior Faces** — грани внутри объёма (ошибки).
- **Faces by Sides** — грани с заданным числом сторон (найти **n-gon**/треугольники).
- **Non-Manifold** (`Shift+Ctrl+Alt+M`) — «дырявые»/неправильные места (важно для печати/Boolean).
- **Ungrouped Verts** — точки без весовой группы (риггинг!).

### Прочее меню Select
- **Select More/Less** — то же, что `Ctrl+Numpad ±`.
- **Select Loops → Edge Loops / Loop Inner-Region / Boundary Loop** — выделить внутренность петли или её границу.
- **Checker Deselect** — снять выделение «через один» (для равномерных узоров/Array вручную).
- **Select Random** — случайная доля (для разброса).
- **Select Linked (`L` под курсором / `Ctrl+L` от выделения)** — весь связанный «остров» меша.
- **Select Mirror (`Shift+Ctrl+M`)** — симметричное выделение по оси.

## 5. Прятать как способ выделять

Иногда проще **спрятать лишнее**, чем выделять нужное:

| Клавиша | Действие |
|---------|----------|
| `H` | спрятать выделенное |
| `Shift+H` | спрятать всё, **кроме** выделенного (изолировать зону) |
| `Alt+H` | показать всё обратно |

> 💡 Приём: выделил руку персонажа → `Shift+H` → работаешь только с рукой, остальное не мешает → `Alt+H` вернул.

---

## 6. Частые трудности и решения

| Симптом | Причина | Решение |
|---------|---------|---------|
| Рамкой выделилась только передняя стенка | X-Ray выключен | `Alt+Z` (X-Ray) перед выделением |
| Петля (`Alt+клик`) идёт не в ту сторону | навёл вдоль не того ребра | целься точнее вдоль нужного направления |
| Петля «обрывается» | треугольник/полюс на пути | петли живут на quad-сетке; дочисти топологию |
| `Shift+G` выделил «не похожее» | не тот критерий | выбери нужный пункт (Normal/Material/Area…) |
| Не могу снять выделение | привычка из других программ | `Alt+A` снять всё, `Shift+ЛКМ` точечно |
| Выделяю сквозь, а не хочу | X-Ray включён | выключи `Alt+Z` |
| «Пропал» инструмент выделения | активен другой Tool | `W` циклом или выбери Tweak/Box в панели `T` |

---

## 7. Мини-практика (проверь себя)

1. На кубе-сетке (Subdivide 3×) выдели **одну петлю** по экватору (`Alt+клик`) и сделай Bevel.
2. Выдели **кольцо** (`Ctrl+Alt+клик`) и сделай Loop Cut между ними.
3. Выдели **все грани одного ската** через `Shift+G → Normal`.
4. Найди и удали «мусор» через `Select → All by Trait → Loose Geometry`.
5. Изолируй половину модели (`Shift+H`) и поработай, потом `Alt+H`.

> 💡 **Главная мысль:** не «кликай по одному». Сначала спроси: «это петля? кольцо? похожие по признаку? остров?» — и возьми всё нужное **одним** приёмом. Скорость моделирования — это скорость выделения.

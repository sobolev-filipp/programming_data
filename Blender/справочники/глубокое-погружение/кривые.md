# 📚 Глубокое погружение — Кривые (Bezier, NURBS, профили)

> **Кривая** — гладкая линия, заданная **несколькими опорными точками** (а не сотней вершин). Идеальна для труб, дорог, проводов, орбит, текста-по-контуру и путей движения камеры (Follow Path). Тему вели уроки 6 и 8 — здесь полная картина: виды кривых, как ими управлять, как превращать в 3D-объём и в меш.

> Где: `Shift+A → Curve`. Правится в **Edit Mode** (`Tab`), настройки — **Object Data Properties (иконка кривой)**.

---

## 1. Bezier vs NURBS vs Path

| Тип | Как управляется | Когда брать |
|-----|-----------------|-------------|
| **Bezier** | опорные точки + **ручки (handles)** | основная: точная форма, буквы, дороги |
| **NURBS** | точки-«магниты» тянут кривую к себе | супер-гладкие плавные формы (корпуса) |
| **Path** | цепочка точек | пути движения (Follow Path, урок 43) |
| **Circle** (Bezier/NURBS) | замкнутая | орбиты, кольца, основания |

> 💡 Для детей основа — **Bezier** (предсказуема) и **Circle** (орбиты/облёт камеры).

---

## 2. Ручки Bezier (handles) — характер изгиба 🧠

У каждой опорной точки Bezier — **две ручки**, они задают наклон и «плавность» захода кривой. Тип ручки — клавиша `V`:

| Тип ручки | Поведение | Когда |
|-----------|-----------|-------|
| **Auto** | Blender сам держит гладко | по умолчанию, плавные линии |
| **Aligned** | ручки на одной линии (гладкий проход) | плавный, но управляемый изгиб |
| **Vector** | смотрят на соседние точки — **острый угол** | углы дорог, гранёные контуры |
| **Free** | обе ручки независимы | полный ручной контроль |

> 🧠 **Под капотом:** длина ручки = «насколько далеко тянется дуга» до следующей точки; направление = куда кривая выходит из точки. Длинные ручки — размашистые плавные дуги, короткие/Vector — резкие повороты.

> 🔬 **Проверь сам:** Bezier-линия, выдели точку, `V → Vector` — угол стал острым; `V → Auto` — снова гладко. Потяни ручку (`G`) — дуга «раздувается».

---

## 3. Из линии — в объём (панель Geometry)

Кривая по умолчанию невидима в рендере — ей нужен **объём/толщина** (Object Data → **Geometry**):

| Параметр | Что делает | Пример |
|----------|-----------|--------|
| **Extrude** | «лента»/толщина по бокам | плоские полосы |
| **Bevel → Depth** | круглая **труба** вдоль кривой | провода, трубы, стебли (урок 6) |
| **Bevel → Object** | **свой профиль** (другая кривая как сечение) | рельс, плинтус, рамка сложного сечения |
| **Taper Object** | сужение вдоль длины (по кривой-таперу) | рог, сосулька, кнут |
| **Resolution** | гладкость | выше = глаже, дороже |
| **Fill Caps** | закрыть торцы | труба с крышками |

> 💡 **Bevel Object = мощь кривых:** нарисуй профиль-сечение (звёздочку, П-образный рельс) отдельной кривой и назначь — он «протянется» вдоль всей кривой. Так делают сложные погонажи одним движением.

---

## 4. Кривая как путь движения (Follow Path)

- **Path/Circle** + объект с **Constraint → Follow Path** = объект едет по кривой (камера-облёт, планеты, автобус на повороте — уроки 43/56).
- Скорость: **Object Data → Path Animation → Frames** (за сколько кадров пройти путь).
- **Offset** — сдвиг по пути (разные планеты на орбите стартуют в разных точках).

---

## 5. Кривая ↔ меш

| Операция | Как | Зачем |
|----------|-----|-------|
| **Кривая → меш** | Object → Convert → Mesh | дальше редактировать вершинами |
| **Меш-контур → кривая** | Object → Convert → Curve | из выделенной цепочки рёбер |
| **Текст → кривая** | у Text: Convert → Curve | править буквы как контуры |

> 💡 Сначала **набросай форму кривой** (быстро, мало точек), доведи Bevel/Extrude — и лишь потом **Convert to Mesh**, если нужна ручная детализация. Обратного пути (меш→кривая один-в-один) почти нет — поэтому конвертируй в конце.

---

## 6. Полезные приёмы

| Приём | Как |
|-------|-----|
| Замкнуть/разомкнуть | `Alt+C` (Toggle Cyclic) |
| Добавить точку | выдели крайнюю → `E` (Extrude) |
| Врезать точку в сегмент | выдели два соседних → **Subdivide** |
| Сгладить/выровнять | `Shift+S` привязки; ручки `V` |
| **Radius** точки | `Alt+S` — толщина трубы **локально** (толще/тоньше вдоль) |
| **Tilt** (закрутка) | `Ctrl+T` — крутить профиль вдоль (винт, лента Мёбиуса) |

---

## 7. Частые проблемы и решения

| Симптом | Причина | Решение |
|---------|---------|---------|
| Кривая не видна в рендере | нет толщины | Geometry → **Bevel Depth** / Extrude |
| Труба «схлопнулась»/перекручена | Tilt/ручки кривые | сбрось Tilt (`Alt+T`), выровняй ручки |
| Углы «мыльные», нужны острые | ручки Auto/Aligned | `V → Vector` в углах |
| Профиль (Bevel Object) огромный/крошечный | масштаб профиля-кривой | масштабируй профиль, `Ctrl+A` Scale |
| Follow Path не едет | не задан **Frames** | Path Animation → Frames |
| Труба гранёная | низкий Resolution | поднять Resolution Preview U |

---

## 8. Мини-практика

1. Bezier-«провод» → Geometry **Bevel Depth** — круглая труба (урок 6).
2. В углах `V → Vector` — острые повороты «дороги».
3. Нарисуй профиль-звёздочку → назначь как **Bevel Object** основной кривой — фигурный погонаж.
4. **Circle** + камера **Follow Path** + Frames — облёт (урок 43/56).
5. **Convert to Mesh** и подредактируй вершинами.

> 💡 **Главная мысль:** кривая = гладкая форма из немногих точек с **ручками** (Auto/Vector — плавно/остро). Она даёт трубы/профили/пути почти без ручной геометрии, а **Bevel Object + Taper** превращают линию в сложный объём. Конвертируй в меш — только в конце.

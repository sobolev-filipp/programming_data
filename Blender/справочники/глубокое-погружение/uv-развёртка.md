# 📚 Глубокое погружение — UV-развёртка: полный разбор

> Уроки 22–24 дают рабочий минимум UV. Здесь — **вся картина**: зачем выделять грани, как ставить швы, чем разворачивать в разных ситуациях, как **чинить** кривую развёртку и какие есть доп-возможности. UV — это «выкройка»: разрезаем 3D-«одежду» на плоские куски, чтобы аккуратно положить текстуру.

---

## 1. Зачем вообще UV (и зачем выделять грани)

Текстура — плоская картинка (квадрат **0–1** по осям **U** и **V**). Модель — объёмная. **UV-развёртка** говорит, **какой кусочек картинки** ложится на **какую грань**. Без неё текстура «плывёт» и тянется.

- **Грани выделяют**, потому что разворачиваешь именно **выбранные** грани: можно развернуть всю модель (`A`) или только часть (например, перекрасить один элемент заново).
- Каждый «разрезанный» кусок на плоскости — **остров (island)**.
- **Тексель** — сколько пикселей текстуры приходится на единицу поверхности. Одинаковый тексель на всех островах = ровная чёткость (см. Average Islands Scale ниже).

---

## 2. Швы (Seams) — где «разрезать одежду»

**Шов (Seam)** — линия, по которой Blender разрежет меш в плоскую выкройку.

| Действие | Как |
|----------|-----|
| Пометить шов | выдели рёбра (Edge-режим) → `Ctrl+E → Mark Seam` (или `U → Mark Seam`) |
| Снять шов | `Ctrl+E → Clear Seam` |
| Подсветка швов | красные рёбра в Edit Mode |

**Где ставить швы (стратегия):**
- В **незаметных местах**: под мышками, внутри ног, на спине, за ушами, по «естественным» стыкам (край рукава, шов одежды).
- По **симметрии**: тогда половины можно наложить и красить один раз (Mirror).
- Так, чтобы куски **разворачивались плоско** без сильного натяжения (цилиндр — шов вдоль; шар — как у глобуса).

> 💡 **Правило:** меньше швов = меньше видимых стыков, но больше натяжение. Больше швов = легче разложить плоско, но больше границ. Ищи баланс: режь там, где шов не видно.

---

## 3. Методы развёртки — что для какой формы

Меню `U` в Edit Mode (с выделенными гранями):

| Метод | Для чего | Нюанс |
|-------|----------|-------|
| **Unwrap** | органика и всё со швами | сначала **пометь швы**, потом Unwrap — раскроет по ним |
| **Smart UV Project** | hard-surface, быстро, много деталей | сам режет по углам; задай Angle Limit, Island Margin |
| **Cube Projection** | коробки, здания, ящики | проецирует с 6 сторон |
| **Cylinder Projection** | трубы, банки, стволы, конечности | поставь шов вдоль + выровняй ось |
| **Sphere Projection** | шары, головы, планеты | как карта глобуса |
| **Project from View** | плоскости, лицо-декаль, этикетка | разворачивает «как видит камера» — для наклеек |
| **Follow Active Quads** | ровные тайлящиеся поверхности (кирпич, плитка, дорога) | задаёт равномерную сетку по активной грани |
| **Lightmap Pack** | запекание света (продвинуто) | плотная упаковка без перекрытий |
| **Reset** | сбросить UV в квадрат | каждая грань на весь 0–1 (для тайлинга/начать заново) |

> 💡 **Как выбрать:** *органика/персонаж* → швы + **Unwrap**. *Механика/sci-fi* → **Smart UV**. *Труба/конечность* → **Cylinder**. *Этикетка/лицо-декаль* → **Project from View**. *Плитка/кирпич/дорога* → **Follow Active Quads** или **Cube**.

## 4. Как ЧИНИТЬ развёртку (UV Editor)

Открой **UV Editing** (раскладка вверху). Слева — UV Editor с островами. Инструменты (меню **UV** или горячие):

| Проблема | Инструмент | Как |
|----------|-----------|-----|
| Острова **разного масштаба** (где-то чётче) | **Average Islands Scale** (`Ctrl+A` в UV) | выровнять тексель у всех |
| Текстура **тянется** | **Minimize Stretch** (`Ctrl+V`) | расслабляет сетку, убирает натяжение |
| Острова **налезают** друг на друга | **Pack Islands** | разложить без перекрытий, по полю 0–1 |
| Нужно **закрепить** точку и доразвернуть | **Pin** (`P`) / **Unpin** (`Alt+P`) + **Live Unwrap** | пин держит, Unwrap пересчитывает остальное |
| Сшить два острова обратно | **Stitch** (`V`) | соединяет по общим рёбрам |
| Выпрямить ряд/петлю | **Align / Straighten** (Follow Active Quads тоже) | ровные тайлящиеся UV |
| Проверить искажения | оверлей **Stretching** (в UV Editor → Overlays) | синий = ок, красный = тянется |

**Главный тест — шахматка:** назначь временно текстуру **UV Grid / Color Grid** (или Checker). Ровные квадратики = развёртка хорошая; вытянутые/кривые = есть натяжение, чини Minimize Stretch / правь швы.

## 5. Доп-возможности (про запас)

- **Несколько UV-карт** у одного объекта (Object Data → UV Maps): одна для цвета, другая для запекания света/AO.
- **UV Sync Selection** (кнопка в шапке UV Editor): синхронизирует выделение 3D ↔ UV.
- **Привязки в UV** (Snap), **Pack по выделению**, поворот/масштаб островов (`R`/`S`) — раскладывай плотнее.
- **Live Unwrap** (UV → Live Unwrap): двигаешь пины — развёртка пересчитывается в реальном времени.
- **Экспорт развёртки** (UV → Export UV Layout) — PNG-схема, чтобы рисовать текстуру в редакторе по контуру.
- **Тайлинг через ноды** (Texture Coordinate → Mapping → Image «Repeat») — повторять текстуру без частых швов (урок 23).
- **UDIM** (продвинуто) — несколько «плиток» 0–1 для очень детальных моделей.

## 6. Частые трудности и решения

| Симптом | Причина | Решение |
|---------|---------|---------|
| Текстура «плывёт»/тянется | нет UV или сильное натяжение | развернуть; Minimize Stretch; добавить швы |
| Одни части чётче других | разный тексель островов | **Average Islands Scale** |
| Острова налезают (грязь на текстуре) | не упакованы | **Pack Islands** |
| Шов видно на модели | шов в заметном месте | перенести шов в скрытую зону |
| Развернул, а всё в одной точке | не помечены швы перед Unwrap | пометить Seam, потом Unwrap |
| «Зебра»/Checker кривой | натяжение/перекос | править швы + Minimize Stretch |
| Симметричная текстура не совпала | не наложены половины | Mirror U / наложить острова друг на друга |

---

## 7. Мини-практика (проверь себя)

1. Разверни **куб** (Cube Projection) и проверь шахматкой — квадраты ровные?
2. Разверни **цилиндр**: шов вдоль (`Mark Seam`) → Cylinder Projection.
3. Возьми **простого персонажа/зверя**: швы под мышками/внутри ног → Unwrap → Average Islands Scale → Pack.
4. Положи **этикетку** на бутылку через Project from View.
5. Включи оверлей **Stretching** — найди и поправь самый «красный» остров.

> 💡 **Главная мысль:** UV — это выкройка. Сначала реши, **где разрезать** (швы в скрытых местах), выбери **метод под форму**, потом **проверь шахматкой** и **выровняй** (Average Scale + Pack). Хорошая развёртка незаметна — а плохую видно сразу по «плывущей» текстуре.

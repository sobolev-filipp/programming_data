# 📚 Глубокое погружение — Точность: привязки, Pivot, ориентации, 3D-курсор

> Разница между «слепил на глаз» и «инженерная точность» — в четырёх вещах: **числовой ввод**, **привязки (Snap)**, **точка опоры (Pivot)** и **3D-курсор**. Освоишь — будешь ставить всё ровно, в стык, под нужным углом.

---

## 1. Числовой ввод и оси (база точности)

Главный паттерн (повтор урока 1): **Действие → Ось → Число → Enter**.

| Хочу | Как |
|------|-----|
| Сдвинуть ровно на 2 по X | `G X 2 Enter` |
| Повернуть на 90° по Z | `R Z 90 Enter` |
| Масштаб ×2 по Y | `S Y 2 Enter` |
| По **локальной** оси | дважды ось: `G Z Z` |
| **Исключить** ось (в плоскости) | `G Shift+Z` (двигать по X-Y) |
| Точная копия со сдвигом | `Shift+D X 3 Enter` |

---

## 2. Привязки (Snapping) — `Shift+Tab` (магнит)

Включается кнопкой-**магнитом** вверху (или `Shift+Tab`). Рядом — выпадушки настроек.

**Snap To (к чему липнуть):**
| Тип | Липнет к |
|-----|----------|
| **Vertex** | вершинам (стыковать точно в точку) |
| **Edge** | рёбрам / середине ребра |
| **Face** | поверхности граней (раскладывать по поверхности) |
| **Increment** | шагам сетки |
| **Grid** | узлам сетки |
| **Volume** | внутрь объёма |

**Snap With (чем липнуть)** — Closest (ближайшей точкой) / Center (центром) / Median / **Active**.
Доп: **Align Rotation to Target** (повернуть объект по нормали поверхности — класс для «приклеить деталь к стене под наклоном»).

> 💡 Удержание **`Ctrl`** во время перемещения **временно включает** привязку (или выключает, если магнит уже горит). Удобно: магнит выключен, а зажал Ctrl — прилип куда надо.

---

## 3. Точка опоры (Pivot Point) — `.` (точка)

Вокруг чего идут **вращение и масштаб**:

| Pivot | Вокруг чего |
|-------|-------------|
| **Median Point** (по умолч.) | середина выделения |
| **3D Cursor** | вокруг 3D-курсора (поставь его — крути вокруг него) |
| **Individual Origins** | каждый элемент вокруг себя |
| **Active Element** | вокруг активного |
| **Bounding Box Center** | центр габаритной коробки |

> 🔬 Пример: хочешь расставить лампы по кругу — поставь 3D-курсор в центр, Pivot = **3D Cursor**, и `R Z` крутит вокруг центра. (Круговой Array через Empty — то же по сути.)

---

## 4. Ориентации трансформации — `,` (запятая)

По каким **осям** двигать/крутить:

| Ориентация | Оси идут |
|-----------|----------|
| **Global** | по миру (X-Y-Z сцены) |
| **Local** | по собственным осям объекта |
| **Normal** | по нормали грани/вершины (выдавить «от поверхности») |
| **View** | по экрану |
| **Gimbal / Custom** | для риг/особых случаев |

> 💡 Связка **Normal-ориентация + `G Z Z`** = двигать строго «наружу из поверхности», даже если грань под углом. Незаменимо для наклонных деталей.

---

## 5. 3D-курсор — недооценённый помощник

3D-курсор — это «точка-маркер»: где появляются новые объекты, и опорная точка для Pivot/Snap.

| Действие | Как |
|----------|-----|
| Поставить курсор | `Shift+ПКМ` (с привязкой липнет к точкам) |
| Вернуть в центр мира | `Shift+C` |
| **Меню Snap** | `Shift+S` (Cursor to Selected, Selection to Cursor, Cursor to World Origin…) |
| Курсор точно на вершину | выдели вершину → `Shift+S → Cursor to Selected` |

> 💡 Рабочий приём: `Shift+S → Cursor to Selected` (курсор на нужное место) → `Shift+A` (новый объект появится **ровно там**). Или поставь Origin объекта в эту точку (см. ниже).

---

## 6. Origin (точка опоры объекта)

| Действие | Как |
|----------|-----|
| Origin в геометрию (центр) | `Object → Set Origin → Origin to Geometry` |
| Origin в 3D-курсор | `Set Origin → Origin to 3D Cursor` |
| Origin в центр масс | `Set Origin → Center of Mass` |
| Двигать **только Origin** | вкл. `Options → Affect Only Origins`, затем `G` |

> Origin важен для вращения (дверь от петли), Mirror (от центра), Follow Path и риггинга. Криво стоит Origin — «едет» всё.

---

## 7. Частые трудности

| Симптом | Причина | Решение |
|---------|---------|---------|
| Деталь не липнет в стык | Snap выкл / не тот тип | `Shift+Tab`; Snap To = Vertex |
| Крутится «не вокруг того» | не тот Pivot | `.` → 3D Cursor / Individual Origins |
| Выдавить «от наклонной грани» не выходит | Global-ориентация | Orientation = **Normal**, `E`/`G Z Z` |
| Новый объект появляется не там | 3D-курсор смещён | `Shift+C` или `Shift+S → Cursor to World Origin` |
| Дверь вращается от центра | Origin не на петле | Affect Only Origins → подвинуть Origin |

---

## 8. Мини-практика

1. Состыкуй два куба **точно гранями** через Vertex Snap.
2. Поставь 4 объекта по кругу: 3D-курсор в центр, Pivot = 3D Cursor, `R Z`.
3. «Приклей» деталь к наклонной крыше: Snap Face + Align Rotation to Target.
4. Выдави грань строго наружу наклонной поверхности: Orientation = Normal → `E`.
5. Сдвинь Origin двери на петлю (Affect Only Origins) и поверни.

> 💡 **Главная мысль:** точность — это не «аккуратнее тянуть мышь», а **правильные настройки**: число+ось, нужный Snap, нужный Pivot, нужная ориентация, и 3D-курсор как маркер. Тогда всё встаёт идеально с первого раза.

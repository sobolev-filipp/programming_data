# 📚 Глубокое погружение — Модификаторы: стек и порядок

> **Модификатор** — «умный эффект поверх меша», который считается **на лету** и **не портит исходную геометрию** (можно снять/поправить в любой момент). Каталог всех — в [модификаторы.md](../модификаторы.md). Здесь — то, что важнее списка: как работает **стек**, почему **порядок решает всё**, и как их правильно применять.

> Где: **Properties → вкладка с гаечным ключом 🔧 (Modifier Properties)** → **Add Modifier**.

---

## 1. Что такое стек модификаторов 🧠

Модификаторы стоят **списком (стеком)** и считаются **сверху вниз**: результат верхнего идёт на вход нижнего — как конвейер.

```
   Базовый меш
      │
   [Mirror]      ← сначала отзеркалить
      │
   [Subdivision] ← потом сгладить (обе половины)
      │
   [Bevel]       ← потом фаски
      │
   Итоговая форма (в кадре)
```

> 🧠 **Под капотом:** сам меш (вершины) **не меняется** — Blender каждый кадр «прогоняет» его через стек и показывает результат. Поэтому можно крутить параметры или выключить модификатор «глазом» — база цела. Это **неразрушающее** (non-destructive) моделирование.

---

## 2. Порядок = разный результат ⚠️

Переставь модификаторы — получишь другое. Классические примеры:

| Порядок | Результат |
|---------|-----------|
| **Mirror → Subdivision** | шов по центру сглаживается **как единое целое** ✅ |
| **Subdivision → Mirror** | каждая половина сглаживается отдельно → **щель/наплыв по центру** ❌ |
| **Bevel → Subdivision** | фаска тоже сгладится (мягкий кант) |
| **Subdivision → Bevel** | фаска по уже сглаженной форме (иначе) |
| **Array → Curve** | ряд копий **изгибается** по кривой ✅ |
| **Curve → Array** | сначала гнём одну, потом размножаем (не то) |

> 💡 **Правило-ориентир:** сначала то, что **строит/размножает** форму (Mirror, Array, Screw), потом то, что **сглаживает/скругляет** (Subdivision, Bevel), в конце — деформации (Curve, Simple Deform, Cast).

> 🔬 **Проверь сам:** полукуб + Mirror + Subdivision. Поменяй их местами в стеке (кнопки ⋮⋮ / перетащить) — увидишь, как по центру появляется/исчезает наплыв.

## 3. Верхняя панель каждого модификатора (иконки)

| Иконка | Что делает |
|--------|-----------|
| 🖥 **Realtime** | показывать во вьюпорте |
| 📷 **Render** | учитывать в рендере |
| ✏️ **Edit Mode** | показывать эффект в режиме редактирования |
| △ **On Cage** | редактировать по форме **после** модификатора |
| **⋮⋮ / drag** | переставить в стеке |
| **∨ Dropdown → Apply** | «запечь» в геометрию (`Ctrl+A`) |

> 💡 Выключи 🖥 у тяжёлого модификатора (Subdivision/Array) на время лепки — вьюпорт летает; включишь на рендер.

---

## 4. Apply — когда «запекать» в геометрию

**Apply** превращает эффект в реальные вершины (стек исчезает). После этого править «параметром» уже нельзя.

**Применять, когда:**
- нужно **редактировать результат руками** (Array-копии стали отдельными для физики — урок 53);
- перед **экспортом** / запеканием;
- Mirror перед скульптингом/UV (симметрия «зашита»).

**НЕ применять раньше времени** — потеряешь гибкость. Держи неразрушающим, сколько можешь.

> ⚠️ **Порядок Apply тоже важен:** применяй **сверху вниз** (как считается стек), иначе результат исказится.

---

## 5. Вершинные группы как маски

Многие модификаторы принимают **Vertex Group** в поле влияния — так эффект действует **только на часть** меша:

- **Bevel / Subdivision / Displace** по группе — скруглить/сгладить/выдавить только выбранное.
- **Mask**-модификатор — временно спрятать часть.
- Это тот же принцип весов, что в скиннинге ([риггинг-веса](риггинг-веса.md)).

## 6. Частые связки (рецепты)

| Задача | Стек |
|--------|------|
| Симметричный гладкий объект | **Mirror → Subdivision** |
| Hard-surface с мягкими кантами | **Bevel (или support loops) → Subdivision** |
| Ряд по дуге (забор, рельсы) | **Array → Curve** |
| Труба/пружина/резьба | **Screw** (урок 8) |
| Ветки/провода по кривой | **Curve** |
| Рельеф по карте высот | **Subdivision → Displace** (Texture Coord = UV, урок 25) |
| Low-poly оптимизация | **Decimate** (урок 10) |
| Толщина плоскости | **Solidify** |

---

## 7. Частые проблемы и решения

| Симптом | Причина | Решение |
|---------|---------|---------|
| Наплыв/щель по центру Mirror | Subdivision **выше** Mirror | Mirror поставить **выше** |
| Array не гнётся по кривой | Curve выше Array | Array **выше** Curve, оба на одном объекте |
| Модификатор «не редактируется руками» | забыл, что эффект виртуальный | **Apply**, если нужна правка вершин |
| Вьюпорт тормозит | тяжёлый Subdivision/Array «вживую» | выключить 🖥, снизить Levels Viewport |
| После Apply форма исказилась | применяли не по порядку | Apply **сверху вниз** |
| Bevel «залезает» сам на себя | нет Clamp Overlap | включить Clamp Overlap (`F9`) |

---

## 8. Мини-практика

1. Полукуб → **Mirror → Subdivision**. Поменяй местами — найди наплыв.
2. **Array → Curve**: сделай «поезд по рельсам»-дугу.
3. Плоскость → **Subdivision(Simple) → Displace** с текстурой — рельеф.
4. Выключи 🖥 у Subdivision — вьюпорт летает; включи на рендер.
5. **Apply** Array, затем `P → By Loose Parts` — копии стали отдельными (для физики).

> 💡 **Главная мысль:** стек — это **конвейер сверху вниз**, и **порядок меняет результат** (Mirror перед Subdivision!). Держи моделирование **неразрушающим** как можно дольше, а **Apply** делай только когда нужна ручная правка/экспорт/физика — и всегда сверху вниз.

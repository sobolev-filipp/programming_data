# 📚 Глубокое погружение

> Серия **подробных разборов** ключевых тем для тех, кто хочет идти глубже, чем в уроке. Уроки дают **рабочий минимум**, чтобы двигаться по проекту; эти гайды — **полная картина**: все способы, горячие клавиши, нюансы, типичные трудности и как их решать. Учитель берёт отсюда ответы на «а как ещё можно?» и материал для сильных учеников.

## Зачем это нужно

Заказчик попросил, чтобы дети **не получали поверхностную информацию**, а **углублялись в моделирование**. Поэтому, помимо пошаговых уроков, у нас есть эти разборы-справочники — к ним отсылают врезки **📚 Глубже** в уроках.

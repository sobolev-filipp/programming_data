# 📚 Глубокое погружение — Инструменты редактирования меша

> Полный «верстак» моделлера: что делает каждый инструмент, где он, какие у него **скрытые опции** (часто самое полезное прячется в панели `F9` или в подменю). Всё — в **Edit Mode** (`Tab`).

> 💡 После почти любого инструмента жми **`F9`** (или разверни панель слева внизу) — там его параметры (число сегментов, глубина, смещение). Это «второй этаж» каждого инструмента.

---

## 1. Extrude (выдавливание) — `E`

Главный инструмент роста формы. Вытягивает выделенное, создавая новые грани.

| Вариант | Как | Что делает |
|---------|-----|------------|
| **Region** | `E` | выдавить как единое целое (обычный) |
| По оси | `E` затем `X/Y/Z` | строго по оси |
| **Individual** | `Alt+E → Extrude Individual` | каждую грань отдельно (шипы, окна) |
| **Along Normals** | `Alt+E → Along Normals` | наружу по нормали (равномерное «вздутие») |
| **Manifold** | `Alt+E → Manifold` | выдавить внутрь, авто-убирая пересечения |
| Extrude to Cursor | `Ctrl+ПКМ` | выдавить к точке клика |

> ⚠️ Частая ошибка: `E`, потом передумал и `ПКМ`/Esc — грань **остаётся на месте, но дубль уже создан** (нулевая толщина). Лучше `E` → сразу двигай, а отменить — `Ctrl+Z`.

---

## 2. Inset (врезка грани) — `I`

Создаёт грань внутри грани (рамка). Для панелей, кнопок, окантовок.

| Вариант | Как |
|---------|-----|
| Обычный | `I`, двигай мышь, ЛКМ |
| **Individual** (каждую отдельно) | `I` затем `I` |
| Глубина (вдавить/выпуклость) | при insete нажми `D` или в `F9` → Depth |
| Толщина точно | впиши число при insete |

---

## 3. Bevel (фаска/скос) — `Ctrl+B`

Скашивает рёбра — главный приём «дорогого» вида (нет идеально острых краёв).

| Параметр | Как |
|----------|-----|
| Ширина | тянуть мышь |
| **Сегменты** (округлость) | **колесо мыши** при bevele (или `S`) |
| Профиль (острый↔круглый) | `P` при bevele или `F9` → Shape |
| Bevel вершин | `Ctrl+Shift+B` |
| Зажать (не залезать) | Clamp Overlap в `F9` |

> 💡 1 сегмент = простая фаска; 2–3 сегмента = мягкий округлый край. Для hard-surface это +50% к «дорогому» виду.

---

## 4. Loop Cut (петля) — `Ctrl+R`

Добавляет петлю рёбер (новый «сустав»/пояс).

| Действие | Как |
|----------|-----|
| Поставить | `Ctrl+R`, навести (жёлтая линия) |
| **Сколько петель** | **колесо мыши** перед кликом |
| Сдвинуть | ЛКМ, затем двигать; `ПКМ` — оставить по центру |
| Ровно посередине | `Ctrl+R` → ЛКМ → `ПКМ` |

---

## 5. Knife (нож) — `K`

Режет грани произвольно (рисуешь разрез).

| Действие | Как |
|----------|-----|
| Резать | `K`, клики по точкам, `Enter` — подтвердить |
| Привязка к точкам | наводись на вершины (зелёный кружок) |
| Под прямым углом | зажми `C` (ограничить угол) |
| Насквозь (через всю модель) | зажми `Z` |
| Отмена | `Esc` |

> Похожий: **Bisect** (Mesh → Bisect) — режет ровной плоскостью насквозь, можно сразу удалить половину.

---

## 6. Соединить / заполнить

| Инструмент | Как | Для чего |
|-----------|-----|----------|
| **Fill** | `F` | сделать грань/ребро по выделенным |
| **Grid Fill** | Face → Grid Fill | заштопать дырку **квадами** (аккуратно) |
| **Bridge Edge Loops** | Edge → Bridge | соединить две петли «трубой» |
| **Connect** | `J` | прорезать ребро между двумя вершинами |
| **Spin** | Mesh → Spin | прокрутить профиль вокруг оси (тела вращения, урок 8) |
| **F2** (аддон) | `F` умно | достраивает грань по контексту |

---

## 7. Разрезать / разделить / разорвать

| Инструмент | Как | Что делает |
|-----------|-----|------------|
| **Subdivide** | ПКМ → Subdivide | дробит грани (в `F9` — число разрезов) |
| **Separate** | `P` | вынести часть в **отдельный объект** (Selection/By Material/Loose) |
| **Split** | `Y` | отделить, но в том же объекте |
| **Rip** | `V` | «разорвать» вершины/рёбра (расстегнуть) |
| **Poke** | Face → Poke | разбить грань на треугольники из центра |

---

## 8. Merge и Delete vs Dissolve — ВАЖНО

**Merge (`M`)** — слить вершины в одну:
- At Center / At Cursor / At First / At Last / **Collapse** / **By Distance** (убрать дубли).

**Delete (`X`) vs Dissolve (`Ctrl+X`)** — разница принципиальная:

| | Что делает | Когда |
|--|-----------|-------|
| **Delete** (`X`) | удаляет элемент **и оставляет дыру** | реально убрать геометрию |
| **Dissolve** (`Ctrl+X` / `X → Dissolve`) | убирает элемент, **сохраняя поверхность** | упростить топологию без дыр |

> 💡 Хочешь убрать лишнюю петлю, но не порвать модель — **Dissolve Edges**, а не Delete. Это частая ошибка новичков: жмут `X → Edges` и получают дыру.

---

## 9. Мини-практика

1. Из куба сделай «сундук»: Inset крышку → Extrude → Bevel рёбра (3 сегмента).
2. Loop Cut поперёк → сдвинь → Knife наискосок.
3. Сделай дырку (Delete Faces) и заштопай **Grid Fill**.
4. Поставь лишнюю петлю и убери её **Dissolve** (а не Delete) — поверхность цела.
5. Слей близкие вершины **Merge by Distance**.

> 💡 **Главная мысль:** у каждого инструмента есть «второй этаж» (`F9`) — сегменты, глубина, варианты (Individual/Along Normals). Знаешь опции — лепишь точно и быстро. И помни: **Dissolve ≠ Delete**.

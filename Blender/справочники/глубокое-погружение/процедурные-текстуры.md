# 📚 Глубокое погружение — Процедурные текстуры

> **Процедурная текстура** — узор, который Blender **вычисляет по формуле**, а не берёт из картинки. Плюсы: бесконечное разрешение (не мылится с любого расстояния), не нужна UV-развёртка, легко менять. Трогали на уроке 19 (звёзды) — здесь полная картина: какие бывают, как ими управлять и по каким «координатам» они рисуются.

> ⚠️ **Blender 4.1:** нода **Musgrave удалена** — её возможности влиты в **Noise Texture** (параметр Detail/Roughness). Не ищи Musgrave.

---

## 1. «Система координат»: по чему рисуется узор

Процедурной текстуре нужно знать, **где она на объекте**. Это задаёт связка **Texture Coordinate → Mapping → Vector-вход текстуры** (Node Wrangler `Ctrl+T` ставит её сразу).

| Выход Texture Coordinate | Что значит | Когда брать |
|--------------------------|-----------|-------------|
| **Generated** | «родные» 0…1 координаты объекта | процедурным без UV (по умолчанию) |
| **Object** | привязка к центру/осям объекта | узор двигается/крутится с объектом; анимация Mapping |
| **UV** | по развёртке | картинки и когда узор должен «сидеть» на модели |
| **Normal / Camera / Window** | направление/экран | эффекты (Френель, экранные) |

**Mapping** — «руль» узора: **Location** (сдвиг), **Rotation** (поворот), **Scale** (масштаб). Анимируя Location, можно гнать узор (бегущая энергия клинка, урок 41).

> 🧠 **Под капотом:** текстура — это **функция от точки пространства**: «дай координату (x,y,z) — верну число/цвет». Mapping меняет, какие координаты попадут в формулу (сдвинул/повернул/сжал вход → сдвинулся/повернулся/сжался узор).

## 2. Главные процедурные ноды

| Нод | Что рисует | Ключевые параметры | Для чего |
|-----|-----------|--------------------|----------|
| **Noise Texture** | плавные облака (Перлин-шум) | Scale, Detail, Roughness, Distortion | камень, облака, неровности, рельеф |
| **Voronoi Texture** | ячейки/клетки (расстояние до точек) | Scale, Randomness, режимы (F1/Distance) | чешуя, соты, трещины, галька |
| **Wave Texture** | полосы/кольца (синус) | Bands/Rings, Distortion | дерево, вода, энергия, мрамор |
| **Gradient Texture** | плавный переход | тип (Linear/Radial…) | маски, затухание |
| **Magic / Brick / Checker** | психоделика / кирпич / шахматы | своё | спецэффекты, тест UV |

> 🔬 **Проверь сам:** добавь `Noise → ColorRamp → Base Color`. Крути **Scale** (частота пятен), **Detail** (мелкие детали внутри), **Distortion** (муть). Одна нода — сотни фактур.

---

## 3. Параметры, которые всё решают

| Параметр | Что делает | Наглядно |
|----------|-----------|----------|
| **Scale** | частота узора | больше = мельче и чаще |
| **Detail** | сколько «слоёв» мелочи | больше = богаче, но дороже |
| **Roughness** (у Noise) | контраст мелких слоёв | грубость шума |
| **Distortion** | искажает узор | «размазать»/сделать живее |
| **Randomness** (Voronoi) | разброс ячеек | 0 = ровная сетка, 1 = хаос |

---

## 4. ColorRamp — превращаем «серое» в материал

Любая процедурная текстура выдаёт **число/чб-поле**. Само по себе оно скучное. **ColorRamp** раскрашивает его по шкале:

```
   Noise ──▶ [ColorRamp]  чёрное──►коричневый  белое──►песочный  ──▶ Base Color
                 ▲ двигай флажки: где переход и какого цвета
```

- **Флажки** двигаешь → двигается граница цветов.
- **Interpolation = Constant** → резкая граница (маска, пятна без растяжки).
- Добавь флажков → многоцветные карты (ржавчина, планета).

> 💡 ColorRamp + Noise/Voronoi = 80% всех процедурных материалов курса (планеты урок 19, износ урок 20, маски).

---

## 5. Слои и смешивание (как в фотошопе)

- **Mix Color** — смешать две текстуры по Fac (одна текстура управляет смесью другой).
- Несколько **Noise разного Scale** сложить (Math Add / Mix) → крупные формы + мелкая крошка.
- **Voronoi (Distance) → Bump** → выпуклая галька/чешуя без реальной геометрии.
- Текстура в **Roughness** → мокрые/сухие пятна (блеск неравномерный).

---

## 6. Процедурное vs картинка (когда что)

| | Процедурное | Картинка (Image Texture) |
|--|-------------|--------------------------|
| Разрешение | бесконечное, не мылится | ограничено пикселями |
| UV нужна? | нет (Generated/Object) | да |
| Точный рисунок (логотип, лицо) | ❌ трудно | ✅ легко |
| Природные фактуры (камень, облака) | ✅ идеально | ок |
| Вес | считается на лету (чуть дороже) | память под картинку |

> 💡 Часто **комбинируют**: базовый цвет — картинка (PBR-карта), а грязь/вариации/маски — процедурно сверху.

---

## 7. Частые проблемы и решения

| Симптом | Причина | Решение |
|---------|---------|---------|
| Узор «плывёт» при движении объекта | координаты Generated/UV | возьми **Object** (узор привязан к объекту) |
| Узор растянут/сжат неравномерно | несоразмерный объект/Scale | примени Scale (`Ctrl+A`) или правь Mapping |
| Ищу Musgrave — нет | удалён в 4.1 | используй **Noise** (Detail/Roughness) |
| Слишком «шумно»/грязно | большой Detail/Distortion | убавь Detail, Distortion к 0 |
| Границы цветов мыльные | нужен резкий переход | ColorRamp → **Constant** |

---

## 8. Мини-практика

1. `Noise → ColorRamp → Base Color`: сделай «камень». Покрути Scale/Detail.
2. `Voronoi (Distance) → ColorRamp`: «чешуя/соты». Тот же Voronoi → **Bump → Normal** — рельеф.
3. `Wave (Bands) → ColorRamp`: «дерево». Добавь Distortion — живые волокна.
4. Texture Coordinate → **Object** → Mapping: покрути Rotation — узор поворачивается с объектом.
5. Смешай два Noise разного Scale через **Mix** — крупное+мелкое.

> 💡 **Главная мысль:** процедурка = **формула по координатам**. Управляешь входом (Texture Coordinate/Mapping) и раскраской (ColorRamp) — и из трёх нодов (Noise/Voronoi/Wave) собираешь бесконечные фактуры без единой картинки и без UV.

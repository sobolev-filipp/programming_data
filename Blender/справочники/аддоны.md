# Полезные аддоны Blender 4.1

> Аддон — это расширение для Blender, которое добавляет новые возможности. Многие уже встроены, просто нужно включить.

**Как включить аддон:**  
`Edit → Preferences → Add-ons` → ввести название → поставить галочку ✅

---

## Встроенные аддоны (уже в Blender, просто включи)

### Node Wrangler ⭐⭐⭐⭐⭐

**Для чего:** ускоряет работу в Shader Editor и Geometry Nodes.

**Как включить:** Edit → Preferences → Add-ons → «Node Wrangler»

**Главные функции:**

| Горячая клавиша | Действие |
|----------------|---------|
| `Ctrl + Shift + ЛКМ` на ноду | Показать этот нод (Viewer) |
| `Ctrl + T` | Автоматически добавить Texture Coordinate + Mapping |
| `Ctrl + Shift + T` | Загрузить PBR-текстуры (albedo, roughness, normal) за один раз! |
| `Alt + ЛКМ` | Выделить связанные ноды |
| `Ctrl + D` | Дублировать с сохранением связей |

**Зачем учить:** `Ctrl + Shift + T` загружает сразу все PBR-текстуры и соединяет их — экономит 5 минут на каждом материале.

---

### Bool Tool ⭐⭐⭐⭐

**Для чего:** упрощает работу с Boolean операциями.

**Как включить:** Edit → Preferences → Add-ons → «Bool Tool»

**Главные функции:**

| Горячая клавиша | Действие |
|----------------|---------|
| `Ctrl + Numpad -` | Difference (вычесть) |
| `Ctrl + Numpad +` | Union (объединить) |
| `Ctrl + Numpad *` | Intersect (пересечение) |
| `Ctrl + Numpad /` | Slice (разрезать) |

**Зачем учить:** позволяет делать «живые» булевы операции — объект-резак остаётся и его можно двигать.

---

### Loop Tools ⭐⭐⭐⭐

**Для чего:** дополнительные инструменты для работы с петлями рёбер.

**Как включить:** Edit → Preferences → Add-ons → «Loop Tools»

**Главные функции:**
- **Circle** — расставить вершины по идеальному кругу
- **Relax** — сгладить распределение вершин
- **Space** — равномерно распределить вершины вдоль ребра
- **Gstretch** — выровнять вершины по кривой

**Когда использовать:** после Loop Cut получились неровные петли — Loop Tools → Space, и они сразу выравниваются.

---

### Extra Objects ⭐⭐⭐

**Для чего:** добавляет дополнительные примитивы при `Shift + A`.

**Как включить:** Edit → Preferences → Add-ons → «Add Mesh: Extra Objects»

**Что добавляет:**
- Gear (шестерня)
- Torus Knot (узел-тор)
- Geodesic Sphere
- Bolt (болт с резьбой)
- Round Cube

---

### Curve Extra Objects ⭐⭐⭐

**Для чего:** дополнительные кривые.

**Как включить:** Edit → Preferences → Add-ons → «Add Curve: Extra Objects»

**Что добавляет:** спираль, развёртка кривой, pipe joint (соединение труб).

---

### Rigify ⭐⭐⭐⭐⭐

**Для чего:** автоматически создаёт готовый контроллер-риг для персонажа.

**Как включить:** Edit → Preferences → Add-ons → «Rigify»

**Что умеет:** генерирует профессиональный риг с FK/IK переключателем, контроллерами пальцев, лица и т.д.

*(Разбираем в Модуле 5)*

---

### Archimesh / A.N.T. Landscape ⭐⭐⭐

**Для чего:**
- **Archimesh** — быстрое создание архитектурных элементов (стены, двери, окна, лестницы)
- **A.N.T. Landscape** — генерация ландшафта, горы, холмы

**Как включить:** Edit → Preferences → Add-ons → поиск по названию.

---

### Snap Utilities Line ⭐⭐⭐

**Для чего:** точное черчение в Blender, привязка к точкам.

---

## Бесплатные сторонние аддоны

### Hard Ops + BoxCutter ⭐⭐⭐⭐⭐

**Для чего:** профессиональный hard-surface моделинг.  
**Цена:** платные (~$20 вместе), но есть на [Gumroad](https://gumroad.com)  
**Что умеют:** быстрые булевы операции, фаски, sci-fi детали.

> Если на компьютерах установлены — разбираем! Если нет — показываем концепты.

---

### Modifier Tools ⭐⭐⭐

**Для чего:** кнопки «применить все модификаторы» и «удалить все» прямо в панели.

---

### Material Library VX ⭐⭐⭐

**Для чего:** библиотека готовых материалов (металл, стекло, кирпич и т.д.).

---

### Speedflow ⭐⭐⭐⭐

**Для чего:** быстрый доступ к частым операциям через `Ctrl + Alt + мышь`.

## Как проверить, включён ли аддон

1. `Edit → Preferences → Add-ons`
2. В поиске введи название
3. Если галочка стоит — аддон активен ✅
4. Если не находит — возможно, это сторонний аддон (нужно установить через «Install»)

**Установка стороннего аддона:**  
`Edit → Preferences → Add-ons → Install` → выбрать ZIP-файл → поставить галочку

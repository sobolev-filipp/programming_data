# Трюки и удобства Blender 4.1 ⚡

> Маленькие приёмы, которые экономят кучу времени и делают работу приятнее. Это **не аддоны** (их каталог — в [аддоны.md](аддоны.md)), а встроенные возможности и привычки профи. Внедряем их по ходу курса.

---

## 🚀 Скорость и поиск

| Трюк | Как | Зачем |
|------|-----|-------|
| **Поиск операции** | `F3` | забыл, где кнопка — введи название, Blender найдёт |
| **Повторить последнее** | `Shift+R` | повторить последнее действие (напр. Loop Cut) |
| **Настроить последнее** | `F9` | открыть панель параметров только что сделанного |
| **Quick Favorites** | `Q` (вызов), ПКМ по кнопке → Add to Quick Favorites | свой мини-набор любимых команд |
| **Repeat history** | `F3` → Repeat History | список недавних операций |

|------|-----|

| Пай-меню видов | `` ~ `` (с аддоном Pie Menus) |

## 🎯 Точность: привязка, Pivot, оси

| Трюк | Как | Зачем |
|------|-----|-------|
| **Snapping (магнит)** | `Shift+Tab` вкл/выкл; верхняя панель — тип привязки (Vertex/Edge/Face/Grid) | ставить объекты точно «в стык» |
| **Точка опоры (Pivot)** | `.` (точка) → выбрать: 3D Cursor, Individual Origins, Median… | вокруг чего вращать/масштабировать |
| **3D-курсор на место** | `Shift+ПКМ` поставить; `Shift+C` вернуть в центр; `Shift+S` — меню Snap | задать центр для новых объектов/вращения |
| **Заблокировать ось** | `G`/`R`/`S` → `X`/`Y`/`Z`; дважды — локальная ось | двигать строго по оси |
| **Исключить ось** | `G` → `Shift+Z` | двигать в плоскости XY (не по Z) |
| **Точное число** | `G Z 2 Enter` | сдвиг ровно на 2 м |
| **Proportional Editing** | `O`, колесо мыши — радиус | «мягко» тянуть соседние вершины |

## 🧱 Дубли, связи, выделение

| Трюк | Как | Зачем |
|------|-----|-------|
| Дубликат | `Shift+D` | копия (независимая) |
| **Связанный дубликат** | `Alt+D` | копии делят меш — правишь один, меняются все |
| **Link/Transfer Data** | `Ctrl+L` | раздать материал/модификатор/данные на выделенные |
| **Select Similar** | `Shift+G` | выделить похожие (по нормали, материалу, размеру…) |
| Выделить связанное | наведи + `L` (Object/Edit) | выбрать весь «островок» |
| Растущее выделение | `Ctrl+Numpad +` / `−` | расширить/сузить выделение |
| Inset/Bevel/Loop Cut | `I` / `Ctrl+B` / `Ctrl+R` | базовая тройка моделинга |

## 🎨 Просмотр и оверлеи

| Трюк | Как | Зачем |
|------|-----|-------|
| Шейдинг | `Z` → пай-меню (Solid / Material Preview / Rendered / Wireframe) | как смотрим сцену |
| **Matcap** | Solid → выпадашка шейдинга → Matcap | объём для скульпта без света |
| Каркас поверх | оверлеи → Wireframe | видеть топологию |
| Спрятать/показать | `H` / `Alt+H`; `Shift+H` спрятать всё кроме | убрать лишнее с глаз |
| Annotate (рисовать) | левая панель `T` → карандаш | пометки/наброски прямо в 3D |
| X-Ray | `Alt+Z` | выделять сквозь объект |

## ⚙️ Модификаторы и данные

| Трюк | Как | Зачем |
|------|-----|-------|
| Применить модификатор | `Ctrl+A` в меню модификатора (или Apply) | «запечь» эффект в геометрию |
| Копировать модификатор | `Ctrl+L → Copy Modifiers` (или Copy Attributes) | раздать стек модификаторов |
| Shade Smooth/Flat | ПКМ → Shade Smooth / Auto Smooth | сглаживание без новых граней |
| Очистить трансформации | `Alt+G` / `Alt+R` / `Alt+S` | сбросить позицию/поворот/масштаб |
| **Применить трансформации** | `Ctrl+A → All Transforms` | обязательно перед ригом/модификаторами |

## 🎬 Анимация (Модуль 6)

| Трюк | Как |
|------|-----|
| Вставить/удалить ключ | `I` / `Alt+I` |
| **Auto Keying** | красный кружок ⏺ в Timeline (см. урок 41) |
| Прыжок по ключам | `↑` / `↓` (вверх/вниз по соседним ключам) |
| Play/Stop | `Пробел` |
| Цвет поля = есть ключ | жёлтое = ключ здесь · зелёное = анимировано · серое = нет |

## 🖥 Для слабых ПК

| Трюк | Зачем |
|------|-------|
| **Simplify** (Render → Simplify) | глобально срезать Subdivision/частицы для вьюпорта |
| Скрыть в вьюпорте (иконка монитора в Outliner) | не считать тяжёлый объект, пока не нужен |
| Wireframe/Bounds display | показывать тяжёлый объект каркасом/коробкой |
| Bake симуляций | посчитать физику один раз, дальше — играть готовое |

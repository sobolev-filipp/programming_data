<h2>🎮 Блок «Игры разных жанров» (20–27) — каждый урок другой жанр</h2>
<ul>
  <li><b>20. Космический полёт</b> — жанр: полёт/уворот (вид сверху, большой мир). Новое: <code>SKCameraNode</code> — настоящая камера едет за кораблём; параллакс-фон из слоёв.</li>
  <li><b>21. Виртуальный питомец</b> — жанр: забота/симулятор. Новое: анимация из спрайт-листа <code>SKAction.animate(with:)</code>, состояния существа (спит / ест / играет / грустит), реакция на кнопки ухода.</li>
  <li><b>22. Пушка / птички</b> — жанр: меткость/физика. Новое: прицел перетаскиванием (drag-aim), запуск снаряда импульсом, отскоки и разрушение (углубляем физику из урока 15 в новом геймплее).</li>
  <li><b>23. Подземелье по тайлам</b> — жанр: приключение сверху. Новое: <code>SKTileMapNode</code> (уровень из плиток), ключи/двери/сокровища и простой ИИ — патрульный страж, который замечает героя.</li>
  <li><b>24. Наклони телефон</b> — жанр: ловкость. Новое: акселерометр (CoreMotion) — шар катится от наклона; собери/докатись до цели на время.</li>
  <li><b>25. Свайп-головоломка 2048</b> — жанр: логика/головоломка (не аркада). Новое: жесты-свайпы, сетка-массив 4×4, логика слияния плиток, сохранение поля (<code>Codable</code>).</li>
  <li><b>26. Своя игра — часть 1</b> — ребёнок выбирает жанр, придумывает механику, собирает каркас (меню, сцена, управление).</li>
  <li><b>27. Своя игра — часть 2</b> — звук/частицы/рекорды, иконка приложения, экран запуска, сборка и запуск на реальном iPhone.</li>
</ul>
